# 搜集与入库操作手册 v1.0

> 配合 `02_待搜集_书目.csv`、`03_待搜集_论文与讲义.csv` 使用。
> 目标：让你在浏览器里"照着清单点"，每拿到一份文件就能在 3 分钟内完成验收、改名、入库、登记。

---

## 1. 开工前：先查重

1. 打开 `04_编号登记表.csv`，按**原题/中译名/编号**搜一遍；在库的不再下载。
2. 打开 `03_待搜集_论文与讲义.csv`，看 `是否已有` 列：
   - **未收** = 要去找；
   - **已收待译** = 原文已在 `待完成的翻译工程\`，只需排期；
   - **已译** = 只作登记，不动。
3. 同一文献若已有英译本而你要译原文，登记时用 `-R` 记参照本，别发两个号。

## 2. 渠道优先级（免费 → 可买 → 馆藏）

| 优先级 | 渠道 | 适用 | 备注 |
|---|---|---|---|
| 1 | **arXiv** `arxiv.org/abs/<id>` | 论文/讲义/学位论文 | 下载 PDF 时记版本号（v1/v2…） |
| 2 | **Numdam** `numdam.org` | 法国学派：Astérisque、Séminaire Bourbaki、Publ. IHÉS | Bourbaki 单篇免费；整卷可能收费 |
| 3 | **HAL** `hal.science` | 法语教材/讲义（如 Audin） | 有反爬（Anubis），用浏览器手动下 |
| 4 | **mathnet.ru** | 俄语 УМН 全文 | 记 `rus/rm####` 页面；个别 PDF 字体编码坏，需换源 |
| 5 | **J-STAGE** `jstage.jst.go.jp` | 日本数学会《数学》等日文综述 | 免费，日文文字层通常可用 |
| 6 | **RIMS 講究録** `kurims.kyoto-u.ac.jp/~kyodo/kokyuroku/` | 京都 RIMS 研究集会报告 | 免费；同卷按 `contents/pdf/1918-XX.pdf` 取 |
| 7 | **作者主页** | 植田一石（东大）、Auroux、Gross 等 | 课程页常挂最新讲义 |
| 8 | **出版社** | 岩波、サイエンス社、SMF、AMS、CUP、OUP、Springer | 电子版/纸书；优先买有电子版的 |
| 9 | **馆藏/馆际互借** | 绝版书（如深谷《ゲージ理論》旧版） | 扫描后仅自用 |

---

## 3. 验收标准（五条，缺一不可）

- [ ] **完整**：封面、目录、正文、参考文献、索引（若有）都在，无缺页；
- [ ] **文字层**：`python -c "import pymupdf; d=pymupdf.open('x.pdf'); print(len(d[0].get_text()))"` 能出正文；扫描件允许，但要标注"需 OCR / 回页图"；
- [ ] **页数可数**：记录 PDF 总页数与"正文起页"，算出 `原书页 = PDF 页 − 偏移`；
- [ ] **来源可追溯**：URL / 购买订单号 / 馆藏编号写进 §6 的记录表；
- [ ] **版权合规**：公开渠道或自购；成品只写"仅供学术研读"；扫描件不外传。

---

## 4. 命名与入库

1. 文件名：`<文献号>_<作者>_<原题>_<页数>p.pdf`
   - 例：`JPB04_高橋篤史_原始形式・ミラー対称性入門_252p.pdf`
   - 作者用通行写法（植田一石 / Claire Voisin / Виктор Батырев）。
2. 存放：
   - 日语 → `待完成的翻译工程\01_日本学派\`
   - 法语 → `02_法国学派\`；俄语 → `03_俄罗斯学派\`
   - 英语参考件 → `_参考（英文本）\`
3. 入库后**立刻**改登记表：`是否已有`/状态 → `已入库`，填页数与来源。
4. 开工时把工程目录建在 `待完成的翻译工程\` 下，交付后整体移入 `归档\<主题域>\`。

## 5. 踩坑清单（都是已经踩过的）

| 坑 | 现象 | 处理 |
|---|---|---|
| 俄文 PDF 字体编码坏 | 页面渲染空白/乱码 | 换 mathnet 的另一个链接，或改用英译本作底本（如 Kapustin–Orlov） |
| HAL 反爬 | 下到的是验证页 | 浏览器打开，人工点下载 |
| Numdam 整卷收费 | 单篇免费、整卷要订阅 | 只取单篇 PDF |
| 扫描件无文字层 | `get_text()` 返回空 | 接受 OCR，但公式必须回页图 |
| arXiv 版本变化 | v2/v3 页数不同 | 登记版本号；页映射以所用版本为准 |
| 同一文献两个来源 | 重复下载 | 以登记表编号去重；参照本加 `-R` |
| 文件名含全角括号/空格 | 脚本处理出错 | 入库时统一改名，去掉多余空格 |

## 7. 每周五的例行检查（10 分钟）

1. `04_编号登记表.csv` 里 `已入库待译` 的条目 → 是否已排期？
2. `02`/`03` 清单里 `未收` 的高优先级项 → 本周收了几项？
3. 新入文件是否都改了名、登记了来源？
4. 交付的工程是否都移入 `归档\` 并更新状态？
