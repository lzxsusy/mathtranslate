3. **所以本总纲的主线不是"再多译几篇"，而是"把散落的译稿变成一个有编号、有术语、有导读、可成书的文库"**——编号制度是骨架，术语库是血液，集成卷是出口。

## 1. 编号与登记制度 v1.0

### 1.1 为什么要编号

现有家底已经有 `JP01`、`JP02`、`JP11`、`FR01–FR05`、`RU01`、`REF01` 这样的编号，但只覆盖"待完成清单"那 15 份，60 多个已交付工程里大半仍以 arXiv 号或中文标题命名。结果是：

- 同一个作者的不同讲义无法排序（植田三篇靠人工记）；
- 新任务无法判断"这个编号用过没有"；
- 归档、登记、引用三处对不上号。

v1.0 把已有的 `语种前缀 + 两位流水` 推广成**全库唯一编号**，并要求"一物一号、一号一档、登记表为唯一真相源"。

### 1.2 编号格式

```
文献号 = 语种码 + 类型位 + 两位流水
        例：JP12（日语第 12 号论文/讲义）  JPB01（日语第 1 部专著）  ENB03（英语第 3 部专著）
```

| 组成 | 取值 | 说明 |
|---|---|---|
| 语种码 | `JP` 日 / `FR` 法 / `RU` 俄 / `DE` 德 / `EN` 英 / `ZH` 中 | 按**原文语言**，不按作者国籍 |
| 类型位 | 空 = 论文/讲义/综述/学位论文共用流水；`B` = 专著（book） | 专著周期以月计，与短文（周计）分开排产，故单独流水 |
| 流水 | 两位数字，`01` 起；满 99 升三位 | 语种内连续、**永不复用**、不因废项回收 |
| 对照件 | 后缀 `-R` | 如 `RU02` 俄文原刊、`RU02-R` 英译参照本 |

**现有编号全部保留**：`JP01–JP11`、`JPB01–JPB03`、`FR01–FR05`、`RU01`、`ENB01–ENB05`、`REF01` 不动；`REF` 是"参考件"专用号段，不占正式流水。

### 1.3 主题域（只登记，不进编号）

沿用 `归档\` 的十个主题目录，缩写供登记表使用：

| 码 | 主题 | 码 | 主题 |
|---|---|---|---|
| 01 | 镜像对称与同调镜像对称 | 06 | 黑洞热力学与引力 |
| 02 | 几何朗兰兹与电磁对偶 | 07 | 课程作业与其他文档 |
| 03 | 量子场论与规范理论 | 08 | 教材与参考书 |
| 04 | 弦论与紧致化 | 09 | 春弦抄（个人书稿） |
| 05 | 辛几何·拓扑·纽结与指标定理 | 10 | 杂项 |

一篇文献可挂多个主题（登记表用 `/` 分隔，第一个为主归档位）。

### 1.4 工程目录与产物命名

```
归档\<主题域>\<文献号>_<作者>_<中文短题>_中文译注\
├── src\                     # 可编译源（main.tex + chunks\ + figures\）
├── deliverable\             # 交付物七件套
│   ├── <中文短题>_中文译注本.pdf
│   ├── README.md            # 这本书是什么、底本、页映射、编译方式
│   ├── 译注汇总.md           # 全部批注的机器可读汇总
│   ├── 阅读参考指南.md        # 前置知识、阅读路线、分章导读（大部头才配）
│   └── 工程总结.md           # 流程复盘（≥150 页的工程必写）
├── review\                  # 分章校对报告
└── work\                    # 抽取文本、页面图像、临时脚本（不入交付）
```

- 成品 PDF 文件名 = `<中文短题>_中文译注本.pdf`（与现有深谷、河野、梶浦、Atiyah 一致）。
- 待译 PDF 的临时命名沿用 `待完成的翻译工程` 习惯：`<文献号>_<作者>_<原题>_<页数>p.pdf`。

### 1.5 状态机

```
待搜集 → 已入库 → 待译 → 在译 → 已交付 → 已校订
   ↑                                    │
   └────────────── 返工 ←───────────────┘
```

`04_编号登记表.csv` 是唯一真相源：状态一改，登记表先改，再动文件。

### 1.6 发号规则

1. 新任务开工前**先发号**（查登记表该语种最大号 +1），再建目录。
2. 一本书里的章节、一篇论文里的节，**不另发号**。
3. 同一部书的"原文 + 英译参照"只发一个号，参照本加 `-R`。
4. 合集（如 RIMS 講究録 1918）按单篇发号，合订本用区间号（如 `JP05–JP10A`）。
5. 已交付但无号的旧工程，在登记表"旧编号"列回填 arXiv 号或日期，**不重命名文件**。
6. **历史号 H**：2026-11 之前交付、又没赶上正式编号的 52 个工程，统一编为 `H001–H052`，只用于检索，不再扩号；正式号只发新项目。

## 3. 总目标与三阶段

### 3.1 总目标（到 2028 年底）

- **数量**：累计 100 个译注工程（现 ~54，新增 ~46）。
- **结构**：日/法/俄各成系列；专著 ≥15 部；六个主题各有一部"集成卷"。
- **质量**：全部通过《纪律》§9 交付清单；公式 100% 回页图核对；编译 0 error / 0 undefined / 0 overfull / 0 缺字。
- **资产**：一套统一术语库（≥1500 条，四语对照）、一个 BibTeX 文献库、一套可复用 LaTeX 模板与审计脚本。

### 3.2 阶段划分

|---|---|---|---|---|
| **一、补学派** | 2026Q4–2027Q2 | 日/法/俄三语学派文献 | 短文 20 项 + 专著 2 部 | 把已下载的 15 份待译清完；开法语第一枪（Voisin K3）；俄语先做术语卡 |

## 4. 七条主线

每条主线写清：定位 / 已有 / 缺口 / 下一批 / 依赖 / 里程碑。

### L1 镜像对称与同调镜像对称（主战场，主题 01）

- **定位**：全库的旗舰线，B 侧（导出范畴/相干层）与 A 侧（Fukaya 范畴/辛几何）的对应。
- **已有**：Bocklandt 365 页教材级译本；植田 HMS / 入门 / K3；Frenkel–Witten；Imparato 两篇学位论文；Hori 2016 讲义；36 篇原文综述集。
- **缺口**：① SYZ 的**证明线**（Gross–Siebert 之后）；② Fukaya 范畴的**专著层**；③ K3/四次曲面等**具体例子**的可复算讲义；④ 法语学派对 K3 的讲法。
- **下一批**：Seidel 四次曲面（math/0310414）、Sheridan（1111.0632）、Gross–Hacking–Keel（1106.4977）、Auroux（0706.3207）、Voisin《Symétrie miroir》（FRB01）、Voisin K3 论文（FR01）。
- **依赖**：L2（辛几何）、L7（导出范畴与 Hodge 理论）。
- **里程碑**：2027Q2 前"镜像对称入门三件套"（Bocklandt + 植田入门 + Voisin 法文本）齐；2028 出集成卷。

### L2 辛几何与 Floer 理论（主题 05）

- **定位**：A 侧的语言基础：辛流形、Lagrange 子流形、Floer 同调、Fukaya 范畴。

- **缺口**：Floer 同调的**系统教材层**（McDuff–Salamon、Seidel 书）；Gromov–Witten 不变量的严格基础；Arnold 经典力学式直觉。
- **下一批**：Seidel《Fukaya Categories and Picard–Lefschetz Theory》（已有扫描，见家底）、McDuff–Salamon（ENB08）、Fukaya 阿贝尔簇论文（EN10，arXiv 号待核实）。
- **依赖**：L7。
- **里程碑**：2027Q4 前出"辛几何与 Floer 理论"集成卷骨架。

## 6. 搜集清单怎么用

- **书目**：见 `02_待搜集_书目.md` / `.csv`，**29 本**（日 2 / 法 6 / 俄 1 / 英 19 / 德 1），按语种分组，标了 `是否已有`、`优先级`、`获取渠道`。
- **论文与讲义**：见 `03_待搜集_论文与讲义.md` / `.csv`，**68 条**（未收 34 / 已收待译 24 / 已译 10），分「未收 / 已收待译 / 已译」三档，`未收` 的才需要上网找。
- **计划号**：两份清单里的编号已在 §1.7 预先发号，搜集到就直接入库，不再改号。
- **搜集验收标准**（拿到 PDF 后逐条打勾）：
  1. 完整（封面到参考文献，无缺页）；
  2. 文字层可用（`pymupdf` 能提取正文；扫描件则接受 OCR 但标注）；
  3. 页码可映射（记录 `原书页 = PDF 页 − 偏移`）；
  4. 来源可追溯（URL/购买凭证写进 `05_搜集与入库操作手册.md` 的登记行）；
  5. 版权声明（仅学术研读，不外传扫描件）。
- **搜集顺序**：公开免费（Numdam / HAL / mathnet / J-STAGE / RIMS / arXiv / 作者主页）→ 可购买（SMF、岩波、AMS、CUP、OUP、Springer）→ 馆际互借。
- **入库动作**：改名为 `<文献号>_<作者>_<原题>_<页数>p.pdf` → 放进 `待完成的翻译工程\<语种学派目录>\` → 登记表状态改「已入库」。

## 7. 生产流程（把《纪律》变成流水线）

### 7.1 九步流程

1. **立项**：发号 → 建目录 → 写 README（底本、版次、页映射、术语冻结表）。
2. **抽取**：`pymupdf` 提正文，按页加 `===== BOOK PAGE n (PDF m) =====`；渲染 150–200 dpi 页面图像备核。
3. **通读与疑点清单（第 0 步，v2.0 新增）**：按《纪律》§1.0 通读全文（按篇幅分级），产出 `work/通读笔记.md` 与 `work/疑点清单.tsv`；疑点逐条查证（先查本库 `corpus/` 既有译法，再查 nLab／Stacks／EMS 等词条源，最后落到 A 级文献），**`未解` = 0 才允许开译**。
4. **样板章**：Lead 亲译一章，定术语、文风、批注体例（术语「依据」列须标来源等级 A／B／I）。
5. **分块并行**：按节切 chunk，子智能体各领一块；**术语冻结后禁止跨块改词**；译手开译前须完整读本块原文。
6. **双校**：对原文校（语义/漏译）+ 对页面图像校（公式/图表）+ 抽检译注来源是否真实可查。
7. **编译与审计**：单章自检 → 整书 `xelatex ×2`；审计旧术语残留、`\label` 不变、Undefined/Overfull/缺字为 0；扫描来源黑名单与语料等级标注。
8. **交付七件套**：PDF + 源 + 译注汇总 + README + （大部头）阅读指南 + 工程总结 + 术语表。
9. **归档登记**：移入 `归档\<主题域>\`；更新 `04_编号登记表.csv`；写复盘（≥150 页必写）。

### 7.2 质量闸门（未过不许交付）

| 闸门 | 判据 |
|---|---|
| G0 通读 | 《纪律》§1.0：通读笔记与疑点清单齐备，`未解` = 0，核心术语依据已标 A／B／I |
| G1 底本 | 页映射、版次、来源三项齐全 |
| G2 术语 | 术语表冻结且全文一致（grep 旧词 = 0）；「依据」列无空项 |
| G3 数学 | 公式逐符号回页图；定理/定义编号与原书一致 |
| G4 语言 | 《纪律》§5 病灶清单为 0（"被……所""进行……的"等） |
| G5 工程 | 0 error / 0 undefined / 0 overfull / 0 缺字 / 字体嵌入 |
| G6 批注 | 只进附录/边注，不改正文；原书笔误登记；每条解释性批注带 `[来源：` 或 `[译者按`，且来源不在黑名单（《纪律》§2.5.9） |
| G7 交付 | 七件套齐；PDF 页数写入 README |

## 8. 多智能体协作规范

- **角色**：Lead（发号、样板章、术语冻结、终审）、译手（chunk）、校对（双校报告）、审计脚本（自动检查）。
- **写作用域互斥**：一人一块；`main.tex`、`references.tex`、术语总表只由 Lead 改。
- **术语冻结**：Lead 先做全局替换并审计，再并行；并行期间术语只读。
- **上下文预算**：单块 ≤ 8–10 页；大部头拆 10+ 块；每块交付"chunk + 分章报告 + 单章编译结果"。
- **冲突裁定**：术语/异文冲突由 Lead 裁定并写进术语表，执行者不得擅自统一。
- **提示词模板**：直接用《纪律》§10，逐字粘贴，改书名与章号即可。
- **通读先行（v2.0 新增）**：Lead 先交《通读笔记》《疑点清单》再分块；译手开译前必须完整读本块原文，新疑点回填清单，由 Lead 裁定或分派查证。
- **内部语料共享（v2.0 新增）**：查证第一步先查本库——`python corpus/build_corpus.py` 生成 `corpus/out/terms.tsv`（2026-11 实测 692 条术语／16 个工程）与各工程术语表；本库译法与 A 级文献冲突时报 Lead 裁定，裁定后回写术语库。
- **来源红线（v2.0 新增，v2.1 修订）**：只引 A／B／I 级；**社区类来源白名单＝nLab、Stacks Project、ProofWiki**（B 级，须与 A 级交叉验证，正文不缓存，新增须 Lead 书面批准）；白名单之外的维基百科与问答平台只作线索；知乎、百度百科、CSDN、简书、公众号、博客等一律不看、不引、不缓存，黑名单内容不得进入上下文、笔记、术语库、语料库与任何训练数据（《纪律》§2.5.9）。

## 10. 风险与对策

| 风险 | 表现 | 对策 |
|---|---|---|
| 版权 | 扫描件传播 | 只自用/学术研读；成品注明"原文版权归原作者与出版方"；不外传底本 |
| 底本质量 | 扫描件 OCR 错、公式丢层级 | 公式一律回页图；OCR 只做定位；错字登记不擅改 |
| 术语分裂 | 并行后"导出范畴/导来圏"混用 | 冻结 + 审计脚本 + 三同步（正文/索引/术语表） |
| 上下文溢出 | 大部头后半段质量下降 | 分块、每块独立上下文、预留余量 |
| 重复劳动 | 两处译同一篇 | 登记表先行；开工前查号 |
| 烂尾 | 工程开了不交 | 产能红线（在译 ≤4）；季度最小集；复盘制 |
| 过度扩张 | 见猎心喜收一堆用不上 | 清单按主线过滤；★★★ 不超过 1/4 |
