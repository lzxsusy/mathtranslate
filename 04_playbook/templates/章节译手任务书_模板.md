# 章节译手任务书（模板 v1）

> 用法：Lead 每开一个块，复制本模板，只改 `<…>` 里的内容；块大小以 `translate_kit.py prep` 生成的 `chunks.json` 为准（默认 6 页/块）。
> 一条硬规矩：**块与块之间只通过"文件"交接**（通读笔记 / 衔接卡 / 术语表），不通过聊天历史交接。

---

你是「译者 <代号>」，负责本项目 `<编号> <书名>` 的 **`<chunk-id>` 块（原书 p.<a>–p.<b>）**。

## 一、开工前按顺序读（只读这些，不要翻全书）

1. 本任务书（纪律摘要已压缩在下面，不用再读全文纪律）
2. `工程文件/work/contracts/<chunk-id>.md`（**译前契约卡：断言清单与下游接口以它为准；状态须为「已审」**）
3. `工程文件/work/通读笔记.md`
4. `工程文件/work/definitions.tsv`（本块涉及的条目）+ `工程文件/work/glossary.tsv`（查与你块相关的行；表格里的译法就是终审，不许自创第二种）
5. `工程文件/work/handoff/<prev-chunk>.md`（若有；上一块留给你的 200 字）
6. **本章原文** `工程文件/work/<chunk-id>.txt`（一次读完，p.<a>–p.<b>，不许跳读、不许边读边译）
7. 文风样板 `<源码/chunks/sample.tex>` 与 `templates/译注范例_10条.md`（5 好 5 坏；照好例的写法，别照坏例）

> 通读笔记里没写、你又拿不准的：登记到 `work/疑点清单.tsv`，问 Lead，不要臆造。

## 二、纪律摘要（固定前缀，不必另读全文）

- 先通读、后落笔：本块原文必须**完整读一遍**再写第一句（第 0 定律）。
- 数学正确性高于一切；文字层公式不可信，公式与定理陈述回页面图核对。
- 术语先定：`glossary.tsv` 是唯一裁决书；新术语先入表、再使用。
- 译为正文；解释、出处、异文只进译注命令（本项目既有工程用 `\transnote{…}` / `\tutornote{…}`，样式见 `源码/preamble.tex`；新工程统一 `\zhnote{…}`），且必须带 `[来源：…]`（A/B/I 级）或 `[译者按（无外部依据）…]`。
- **路线注**：作者"为什么先证这个/哪条路被放弃"这类结构说明写 `\routenote{…}`，**必须带原文页码 `p.NN`**——它是可回查的路线，不是知识补充。
- 黑名单：知乎 / 百度百科 / CSDN / 简书 / 博客园的内容不得进入任何工作文件。
- 不补写、不改写、不掩盖作者原文；疑似笔误保留原样 + 译注说明。

## 三、本块任务

- **对账契约**：译完逐条核对契约卡上的「断言清单」是否都在译文里、假设条数是否与 `statements.tsv` 一致；契约里的「明确不做的」一条都不许做。
- 输出文件：`源码/chunks/<chunk-id>.tex`（直接写盘；**不要在对话里贴译文全文**）
- 公式核对：只在以下位置读页面图（用 `crop.py` 裁区域，200 dpi，单图 ≤ 1200 px）：
  - <列 3–5 处最可能出错的公式/交换图表>
- 译注：本块预计 <n> 条；每条一句话说清"为什么这样译/这里为什么需要解释"
- 本块有 <n> 个不可平推步：<label 列表>；译文不得把它们译成「显然 / 易证」。
- 所有 `\begin{theorem|lemma|proposition|definition}` 必须保留原 `\label`；缺失的要补并登记。
- 原文 gap（One can show / It is easy to see 带过）在译注里标 `[难点]`，并回填疑点清单。
- 不确定的地方：写进 `work/疑点清单.tsv`，状态填 `未解`，**不要糊过去**

## 四、收尾（三件，缺一不算完成）

1. `work/handoff/<chunk-id>.md`：200 字以内，只写下一块需要的——新术语、记号约定、未决点、文风提醒
2. `work/reports/<chunk-id>.md`：5 行——完成度 / 存疑 / 与上一块衔接 / 给下一块提醒 / 译注条数
3. **回写词表**：本块新出现的定义/记号追加到 `definitions.tsv`（含定义要点与依据等级）、`glossary.tsv`（只加译法裁决）
4. 把本块 token 与轮次记到 `work/cost_log.tsv`（会话结束前一行）

## 五、预算与退出

- 本会话目标：≤ 15 轮工具调用，输入上下文 ≤ 30K token，回答 ≤ 400 字/轮（译文落盘不算回答）。
- 超过 15 轮或上下文 30K：先把已完成的落盘、写好衔接卡，**结束会话**，下一块换新会话。
- 不要做的事：重读全书；重读别的块；为了省 token 跳过本块原文；把整章译文回贴到聊天里。
