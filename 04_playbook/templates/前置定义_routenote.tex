% route note（路线注）宏 —— 供新工程导言区使用；已有工程可直接 \input 本文件
% 作用：在正文里标出「作者为什么这样走 / 为什么先证这个 / 哪条路被放弃了」，
%       必须带原文页码（p.NN），因为它是"可回查的路线"，不是知识补充。
% 与译注的分工：译注解释**概念**（带来源）；路线注解释**结构**（带页码）。
% 检验：python translate_kit.py check <工程> 会扫 \routenote 是否带页码。
\makeatletter
\newif\ifshowroutenote
\showroutenotetrue
\newcounter{routenote}
\newcommand{\routenote}[1]{%
  \ifshowroutenote
    \refstepcounter{routenote}%
    \par\smallskip\noindent
    {\small\itshape ［路线 \theroutenote］#1\par}%
    \smallskip
  \fi}
\makeatother
