## 7. 标注员 / 审校员 prompt（可直接用）

### 7.1 标注员（起草 units）

```
你是数学文献标注员。给你一篇论文的若干片段（含 TeX 行号）和已有定义表。
任务：抽出原子知识单元，输出 JSONL，每行一个 unit，字段按 unit.schema.json。
硬规则：
1. statement 必须自足，不写「由上式」；
2. role 只能是 spine/key/routine/gap/background，key/spine/gap 必须 score>=3 并写 why_hard/check；
3. gap 必须写 jump.missing（原文省了哪一步）；
4. 每个 unit 必须给 locator（tex_file+tex_lines 优先）；
5. 拿不准的标 review.status=needs_review，不要猜。
只输出 JSONL，不要解释。
```

### 7.2 标注员（起草 inferences）

```
给你 units.jsonl 和原文片段。抽推理边，输出 JSONL，字段按 inference.schema.json。
硬规则：
1. premises/conclusion 必须是已存在的 unit_id；
2. rule 只能取 SUB/APPLY/EXPAND/COLLECT/COMPONENT/CONSTRUCT/COMPAT/COMBINE/OPAQUE；
3. warrant 必须回答「为什么前提足以推出结论」，禁止复述结论；
4. evidence.quote 必须是原文逐字子串（10–300 字），找不到就删掉这条边；
5. and_or 必须显式：合取才够写 and，任一即可写 or。
只输出 JSONL。
```

### 7.3 审校员

```
你是审校员，只做三件事：
1. 每条边：evidence.quote 是否真在原文、是否支撑这条边；
2. 每个 score>=3 的 unit：why_hard 是否说清卡点、check 是否可自证；
3. chain：problem_state 是否具体、move 是否唯一、counterfactual 是否指出断点。
输出：逐条 PASS/FAIL + 一句理由；FAIL 必须给修改建议。不要重写全文。
```
