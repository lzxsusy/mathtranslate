# 发布与合规（把「筛出来的难点」安全地传到网上）

> 目标：让「难点标注 / 思考链 / 概念页」可以公开访问，同时不碰上游版权红线。
> 现有基础设施：`site/` 静态站 + `mt_daily.py`（每晚 21:30 自动打包/同步/双推）+ AtomGit/Gitee 双远端。

---

## 1. 发什么、不发什么

| 发 | 不发 |
|---|---|
| 自己写的难点说明（`why_hard` / `check`） | 论文/书籍整节译文 |
| 自己画的思考链（chain.json 渲染） | 原始 PDF 下载 |
| 概念页：定义的一句话转述 + 别名 + 出现书目 | 出版社排版页图 |
| ≤200 字短引用（带页码/行号） | 大段原文摘录（>200 字） |
| 锚点（页码/行号）与统计 | 未脱敏的会话记录、密钥、私人信息 |

依据：`05_seminar_witten/04_网站MVP/README.md` 的 L0 内容契约（只放自写摘要/章节地图/自绘论证图/claims/术语表/短引用）。

---

## 2. 许可分层

| 层 | 内容 | 许可 | 说明 |
|---|---|---|---|
| 事实层 | `kn_` ID、边、计数、书目 | CC0 | 事实不受版权保护；便于别人复用 |
| 标注层 | one_line、why_hard、chain、译注、页面文字 | CC BY 4.0 | 要求署名；不强制传染 |
| 上游原文 | 只存链接 + ≤200 字引用 | 不适用 | 引用属合理使用范围，逐条标注出处 |
| 特殊子图 | Stacks Project（GFDL）、zbMATH 评论（CC-BY-SA） | 隔离 | 不与 CC BY 内容混库；单独目录/声明 |

**不要**把 zbMATH 评论或 nLab 正文抓进主库再整体发 CC BY——这是调研里点名的最常见翻车方式。

## 4. 发布流水线（挂到 mt_daily）

现有顺序（`mt_daily.py run --go`）：

```
scan → pack → curate → regen → sync → site → commit(内容) → manifest → commit(清单) → push → report
```

新增两处（**最小改动**）：

1. `curate`：`<工程根>/论证精读.md` → `投稿包/<id>/论证精读.md`（与 `精选片段.md` 并列，互不替代）；
2. `sync`：`投稿包/<id>/论证精读.md` → `09_annotations/<id>_论证精读.md`（新目录，语义清晰；也可先放 `02_trajectories/`）。

`site` 步骤再从 `09_annotations/` + `kn.sqlite` 生成页面。

**上线顺序**：
1. 先本地 `site/` 验证 3 个页面；
2. 推到 `atomgit-sync` 分支做预览（不直接推 `main`）；
3. 主人看一眼，确认后再 `mt_daily.py push --go` 进 `main`/`master`。

## 5. 三端同步策略

| 端 | 用途 | 规则 |
|---|---|---|
| AtomGit `main` | 公开镜像（瘦身） | 只接受 `mt_daily push`；不 force-push；Release 放会话语料/成品 PDF |
| Gitee `master` | 国内镜像 | 由 `mt_daily push` 补齐；浏览器被 TLS 中间人劫持，命令行正常 |
| 本地 `master` | 工作副本 | 可领先；推送前先 `fetch`，禁止直接 force-push 远端 |

**发布前检查**：

```powershell
$repo = "<本地路径>"
git -C $repo status --porcelain          # 确认只含预期文件
git -C $repo fetch atomgit
git -C $repo rev-list --left-right --count master...atomgit/main   # 看分叉
```

## 6. 发布前 checklist（每次）

- [ ] `validate_annotations.py` PASS；
- [ ] 每条边有 `evidence.quote`，且 quote 在原文可子串匹配；
- [ ] 页面无 >200 字连续原文；无整页图；无 PDF 下载；
- [ ] `copyright_scan.py` 0 超阈值；
- [ ] 每条断言有锚点；无锚点的进了 `questions.jsonl`，没上页面；
- [ ] 概念页只显示 `accepted` 边；
- [ ] 页面底部有许可与快照日期；
- [ ] 预览分支给主人看过；
- [ ] `mt_daily.py run`（dry-run）输出符合预期。
