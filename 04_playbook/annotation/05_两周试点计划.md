### D2（周二）：扩到 3 部书 + 边抽样

**验收**：3 部书 ≥800 节点 / ≥1,500 边；50 条边 precision ≥0.9。

### D3（周三）：WIT S3 全量标注（units）
- 用 `02` §7.1 prompt 起草；

### D4（周四）：WIT S3 推理 + 难度校准
- 起草 inferences（必须带 quote）；人工删无证据边；

**验收**：≥8 条 accepted inference；κ ≥0.6（或明确记录偏差原因）。

### D5（周五）：WIT 思考链 + 周复盘

- 更新规范 v0.2（只改被证明有问题的地方）。

**验收**：chain 校验通过；反事实能指出具体断点；复盘纪要 1 页。

## 6. 风险与预案

| 风险 | 征兆 | 预案 |
|---|---|---|
| 结构抽取错得多 | 20 个抽查错 >2 | 先修 `\newtheorem` 收集与宏展开，不扩书 |
| LLM 边幻觉 | quote 匹配失败 >20% | 降温度、强制子串校验、只保留 rule 边 |
| 难度打不准 | κ<0.4 | 重写判据；改用 obligation 失败率为主，人工分为辅 |
| 概念合并过猛 | 30 对 precision <0.9 | 只合并「名称完全一致 + 同 MSC」；其余标 related |
| 版权 | 页面出现整节译文 | 发布前跑 `copyright_scan.py`；只留 ≤200 字引用 |
| 与定时任务冲突 | `mt_daily run` 报错/覆盖 | 所有改动走新文件；发布前 `git status` 确认 |
