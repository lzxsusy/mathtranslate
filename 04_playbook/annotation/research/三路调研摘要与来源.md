## 1. 路线一：AI 辅助数学研究系统（f6bfd921）

### 结论
- 形式化侧（Lean/prover）有编译器 ground truth，进展是硬的；非形式化侧（读论文、判难度、提炼思路）2026 年才刚有基准，指标未收敛。
- **没有任何系统专门做「标注论文中困难/不平凡的论证步骤」**。最接近五条支线：依赖图、局部 obligation、角色标注、论证图验证、难度度量。
- 没有产品级「AI 精读 → 论证图」；可拼的组件：PaperTrail（claim/evidence 界面）、Paper Graph（occurrence/state/inference record + AND/OR）、ProofFlow（proof DAG + ProofScore）。

### 可用数字
- AlphaProof / Goedel-Prover / DeepSeek-Prover：miniF2F 88.9%、PutnamBench 49/658（编译器验证）。
- PaperQA2 / OpenScholar：超 GPT-4o 约 5%，但引用幻觉 78–90%（相对专家级）。
- STORM：组织性 +25%（NAACL）。
- AI Scientist v2：独立审计 0/24 达同行评审线、引用幻觉 1.12/篇、2 bugs 24/24 复现（zenodo 21754162）。
- CrowdMath：164 条链，判「功能意义」最好 macro-F1 仅 0.42。

### 最该抄 5 条
1. 先建 statement 级依赖图当骨架（先 3 部书试点）；
2. 难度分 = 局部 obligation 补全失败率（挖结论 + 采样 k=5~8，人工抽检 10%）；
3. claims.jsonl 加 premises / mode(AND|OR) / warrant / status，孤儿节点做质询队列；
4. 确定性 gate 先于 LLM judge；
5. 双视图知识网络（statement 节点 + 策略层），先合并跨书重复定理成概念页。

### 不抄
自建 prover/追 IMO；端到端自动写论文；用 LLM judge 或图深度当难度裁判。

### 判别标准
有无独立于模型的验证器、有无第三方复现、指标能否被对手复算、失败模式是否主动披露。

## 2. 路线二：论证结构 / 思考链 / 难度标注（f4808669）

### 结论
- 最值得抄的 5 条：三层数据模型（source occurrence / contextual state / inference record，AND/OR 用 inference record）；操作注册表（SUB/APPLY/EXPAND/COLLECT/COMPONENT/CONSTRUCT/COMPAT/COMBINE/OPAQUE）；每条边强制 evidence quote + review status；难度不是内在属性（depth/bulk 只是结构度量）；锚点五元组 + TeX/GROBID/MinerU 双通道。
- 3 个陷阱：把引理依赖图当论证结构图；全自动全量铺开、没有 5–10 篇金标准；过早跨文档合并 + schema 一上来 20 种边。
- 前人：ProofFlow（ICLR26，DAG + PROOFSCORE）、KnowTeX（LaTeX 依赖图）、TheoremGraph（1,170 万定理环境 / 1,830 万候选依赖）、Nanopublication（四图 + TrustyURI 发布层）。
- 数据集缺口：「论证步骤难度 + 理由」的中文数学集没有，自建即贡献。

## 3. 路线三：概念级数学知识网络（7940cff3）

### 结论
- 没有可复用的「概念级数学知识图谱」API；论文级基础设施只提供出处层；OpenAlex concepts 已废弃，topics 只有 4,516 个，粒度是领域。
- 三类先例：形式库（Mathlib 140,021 定义 / 294,052 定理；Mizar；Stacks 21,446 tag）、半自动图（AutoMathKG 5,238 Def / 3,419 Thm / 1,084 Prob；NaturalProofs；MathGloss）、百科（nLab/Wikidata/ProofWiki）。
- 最值得照抄：LeanExplore（StatementGroup + 拓扑序翻译 + 三路混合排序 1.0:1.0:0.2，盲评 55.4% vs 46.3% vs 12.0%）。
- 存储：SQLite/DuckDB 为主；10 万–100 万节点内图数据库无收益（Kuzu 可备选）。
- 冷启动免费午餐：89 部书源码里的 `\begin{definition}/\begin{theorem}` + `\label/\ref/\cite` 就是节点与边；估算 41k 段中 15% 是 def/thm ≈ 6k 节点、2–4 万候选边。
- 许可：OpenAlex CC0；S2 免费 key 1 rps；zbMATH 评论 CC-BY-SA（传染）；Stacks GFDL 与 CC BY-SA 不兼容；nLab 无正式许可（只链接）。
- 检索：三路召回 + RRF；GraphRAG 全量重建贵，先普通 RAG，真要上选 LazyGraphRAG。
- 三个翻车点：名字当主键；边无证据入库；许可证混装。

### 已核验来源
- LeanExplore: A search engine for Lean 4 declarations：<https://huggingface.co/papers/2506.11085>（arXiv:2506.11085）
