## 0. 前置：先把"对齐单位"定对

整书复核的第一个决定不是"怎么改"，而是**按什么单位把中文段落和英文原文配起来**。

- 底本必须**有文字层**：`pdftotext -layout` 能整本抽出（本次 697 页 → 1,891,233 字符）。
- 抽出后用 `\f` 分页，**第 N 段 = PDF 第 N 页**，页码映射立刻可得：本次 **原书印刷页 = PDF 页 − 10**。
- 译本工程里每个中文段落前都有 `\SourceParagraph{id}{原书PDF页号}` 锚点（本次 2 929 个）→ **页粒度对齐**：某页英文 ↔ 该页所有中文段落，并带上 tex 行号区间。
- **不要用两边印刷页码互推**：本次译本 530 页 vs 原书 697 页，同一内容在两边的印刷页码毫无关系。所有比对只认 `\SourceParagraph` 里的 PDF 页号。
- 底本入库先记 SHA256：本次 Clay 官方 `cmim04.pdf` 与微信里流传的 z-lib 版本**哈希完全相同**，说明"另一个来源"其实是同一份文件——省掉一轮争论。

## 1. 材料准备（一次性，可脚本化）

```powershell
python make_align.py      # review/<chap>_align.txt：每页英文原文 + 该页中文段落（含 [Lstart-Lend] 行号）
python make_chunks.py     # review/chunks/<chap>/pNNN-NNN.txt：每 10 页一块（本次 72 块）
python estimate_tokens.py # 每块 token，用于估算单人气力、决定是否拆分
```

- 对齐文件是**唯一的工作材料**：正文明文 + 原文同屏，不需要校对员来回开 PDF。
- 10 页一块的粒度最好用：足够让上下文连贯（一整节），又不至于一口气读不完。单块约 1.5–2 万 token，一人一天能核 5–8 块。
- 需要看版式（公式排得对不对、图有没有出框）时，才用 `pdftoppm -r 110 -png` 渲染对应页，别整本渲染。

## 2. 分工：写作用域必须互斥

- **一人一章**，写作用域 = 该章 `.tex` + 该人自己的 `review/log_<chap>.md`，别的一律只读。
- **大章要物理拆分**：本次 ch03（572 段）、ch05（699 段）各拆成 `ch03a/ch03b`、`ch05a/ch05b` 两个文件，在 section/段落边界切（记 `_split_map.txt` 行号偏移；`main.tex` 改 `\InputIfFileExists` 分别引入），**合并回单文件是交付前最后一步**。
- 团队有并发上限（DSH Agent Teams 默认 8 人）：先派满 8 个，谁先完成谁**接手下一个任务**（本次 ch07/ch08/参考文献就是这样派出去的），不要干等名额。
- 每块开始前先 `claim` 共享任务，跑完 `complete`；日志里写清"已核对范围"，这样漏块能被一眼看出。

## 3. 判据：什么必须改、什么不许动

**必须改（P1，改变数学含义）**
- 译反（相关/无关、内/外、左/右、上/下同调）
- 丢掉 `only / never / any / equivalent / precisely` 之类的限定词（断言强度走形）
- 蕴含关系被译成并列要求（A implies B → "A 且要求 B"）
- 公式符号、指标、上下标错（本次 (3.83) 扭转公式 `±½∂J` 两处符号全反）
- 整句漏译；**原文所无的整句增译**（本次第 1 章多出 Thomas–Yau 条件整句）
- 交叉引用编号错、定义对象错位（D3 膜译成 D0 膜）

**必须改（P2，一致性）**
- 术语一译多名（quintic：三次不同译法）、同构/等价混用、内射/单射消解混用
- `\BookRef` 显示编号与 label 不一致、图号/定理号前多余空格

**不许动**
- 文风、断句、译注语气；**译者对原书笔误的数学修正**（本次如原书 `(−1)^{deg φ}` 应为 `q^{deg φ}`、thm 4.78/4.88 缺条件、`Stab⁰(X)` 写成 `Stab⁰(D)` 的统一记号）——**一律保留**，只在日志标"原文疑误/译者补正"。把这种地方"改回原文"等于把正确数学改坏。

**日志格式**（每处一行表格）：`位置 | 原文 | 原译 | 改为 | 理由`。没有改动的块也要登记"已核对范围"，否则事后无法证明没漏。

## 4. 第二轮：术语与记号一致性（单独跑，只读审计 + 断言式批改）

第一轮按章跑完，各章的"局部一致"往往不等于"全书一致"。第二轮分两步：

1. **只读审计**（一人，不碰 tex）：产出 `term_audit.md`，按 A（术语多译）/ B（记号字体）/ C（中英混排）分类，每条给出现次数与位置。
2. **断言式批改**（Lead 亲自跑）：`fix_terms.py` 里每条规则写成
   `(file, old, new, expected_count)`，**实际命中数 ≠ 期望值就整体退出**，不做"猜着改"。
   本次 90 处：quintic 译名 5、`\mathcal Hom`→`\mathcal{H}om` 15、`\mathbb Z`→`\mathbb{Z}` 5、`\operatorname{}` 包群名 7、`\BookRef` 显示串去空格 57、`\mathbb P^k`→`\mathbb{CP}^k` 1。

**取舍要写进报告**：本次保留 ch01/ch05/ch07 共 6 处"五次超曲面"（确指 P⁴ 里的 quintic hypersurface，不是三维流形）、保留 ch06–ch08 的 `\mathbb Z` 无括号写法（整章统一风格），不改"取商/模去"（风格差异）——不改的理由和改的理由一样重要。

## 5. 落地核验：日志说改了不算，tex 里得真改了

`verify_landed.md`：把每份日志的"改为"列拿去 tex 里找。

- 精确行号命中优先；行号因合并/插入而漂移时，退化为全文检索该改动片段。
- 本次 **201/201（100%）**，其中 56 条严格行号命中、145 条全文检索命中。
- 注意**假阴性**：日志"原译"列记的是旧版，若回查脚本拿"原译"反查，会把已改对的判成"未落地"。本次 3 条"否"都是这个原因——结论要看"改为"列，不是"原译"列。

## 6. 结构完整性审计（只读，最后一关）

对 15 个 tex、304 个 hunk 做机器检查（`integrity_audit.md`）：

| 检查项 | 判据 |
|---|---|
| 花括号 / `$` / `\begin-\end` / `\left-\right` / `\[ \]` 平衡 | 全平衡 |
| 编码 | UTF-8 无 BOM、纯 LF |
| 未转义 `%` | 0 |
| `\label` 唯一 | 0 重复（拆分件删除后 1 521 个） |
| 引用闭合 | `\BookCite` 键 ⊆ bib 476 条；`\BookRef` 目标 854 个全可解析 |
| 改动局部性 | 单 hunk ≤ 2 行、纯删除 < 5 处且均有日志 |
| 构建产物 | `main.bbl` 之类不入库 |

这一步的价值：把"人改出来的错"挡在交付前，而不是等读者发现。

## 7. 合并、清理、重建

```powershell
python merge_back.py      # ch03a+b → ch03.tex、ch05a+b → ch05.tex；恢复 main.tex；备份拆原件
# 删除拆分件（否则 727 个重复 label）、删除 0 字节 main.bbl 与临时日志
latexmk -xelatex main.tex
```

- 重建后必须仍是 **0 error / 0 undefined reference**（本次 530 页；Overfull 2 条、Underfull 4 条、唯一字体警告 `TU/KaiTi(0)/m/it undefined` 属中文斜体回退，无害）。
- **先合并再重建**，不要拿"分文件的构建结果"当交付物：交付源码与交付 PDF 必须来自同一份文件树。

## 8. 交付装配与"可复现"证明

`assemble.py` 生成交付目录：`成品 PDF` + `源码/`（排除 build/.git/review）+ `原文/` + `校对记录/` + `校订报告.md`。

**可复现证明**：把 `源码/` 复制到一个**干净目录**实编译一次，比较产物。

- 本次：exit 0、530 页、24,434,480 B；`pdftotext -layout` 抽取文本与交付 PDF **完全一致**（1,895,725 字符）。
- 措辞要准：PDF 里带 CreationDate，**不能写"逐字节相同"**，应写"抽取文本完全一致"。

## 9. 踩过的坑（按踩到的顺序）

1. `.latexmkrc` 把 biber 交给 `python3 tools/run_biber.py`：Windows 的 `python3` 是 stub（exit 9009），latexmk 直接失败。改成直接调 `biber`。
2. biber 按 kpathsea 找到系统里**同名的 `references.bib`**（MiKTeX 自带的 `feupphdteses/references.bib`），bbl 只有 5.8 KB、文献全错。必须 `--input-directory=.`（bbl 变 143 KB）。
3. 在错误目录跑 `latexmk`：上级目录恰好有别人的 `main.tex`（input `sections/00-introduction`）→ exit 12，还误删了不该删的东西。**跑之前先 `Get-Location` 确认**。
4. `references.bib` 里的 Unicode 弯引号/连接号：xeCJK 把 U+2019 当 CJK 标点加宽 → PDF 显示 `Almgren’ s`；U+2013 两端加空格。修法：NFC 合成重音、U+2019→`'`、U+2013→`--`、U+2032→`'`，数学符号包 `$...$`。
5. 图题只有编号、没有说明文字：原书很多图题就是 `Figure 31`，译文用 `\BookNumberOnlyCaption` **是对的**，不是漏译。审计脚本第一版把 21 处行内示意图误报成"缺题注"。
6. 索引页码：`\BookIndexPage{id}` → `\pageref*{src:id}`，重编译自动更新，**不需要外部脚本重跑**；但索引条目合并策略会让页数从 11 页变 6 页，这是排版密度，不是缺条目。
7. 页码不可互推（见 §0）；`\BookRef{fig:3.5}{图 12}` 这类"label 编号 ≠ 显示编号"是原书每章单编号的还原，不是错。
