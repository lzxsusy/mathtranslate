## 拼接（Linux / macOS / 任一装了 bash 的机器）

```bash
cd 06_sessions_raw
curl -L -O https://atomgit.com/lzxSUSUY/mathtranslate/releases/download/v1.0.1/sessions_plain.scrubbed.jsonl.zst.part01
curl -L -O https://atomgit.com/lzxSUSUY/mathtranslate/releases/download/v1.0.1/sessions_plain.scrubbed.jsonl.zst.part02
curl -L -O https://atomgit.com/lzxSUSUY/mathtranslate/releases/download/v1.0.1/sessions_tools.scrubbed.jsonl.zst.part01

cat sessions_plain.scrubbed.jsonl.zst.part* > sessions_plain.scrubbed.jsonl.zst
cat sessions_tools.scrubbed.jsonl.zst.part* > sessions_tools.scrubbed.jsonl.zst
sha256sum sessions_plain.scrubbed.jsonl.zst sessions_tools.scrubbed.jsonl.zst
```

## 拼接（Windows PowerShell）

```powershell
cd '06_sessions_raw'
$parts = @("sessions_plain.scrubbed.jsonl.zst.part01","sessions_plain.scrubbed.jsonl.zst.part02")
$out = [System.IO.File]::Create('sessions_plain.scrubbed.jsonl.zst')
foreach ($p in $parts) { $b = [System.IO.File]::ReadAllBytes($p); $out.Write($b,0,$b.Length) }
$out.Close()
# 校验
(Get-FileHash 'sessions_plain.scrubbed.jsonl.zst' -Algorithm SHA256).Hash.ToLower()
```

## 解压与读取

```bash
# 只解压到 stdout（推荐，解压后约 300 MB + 200 MB）
zstd -dc sessions_plain.scrubbed.jsonl.zst | head -1

# 或解到文件
zstd -d sessions_plain.scrubbed.jsonl.zst
```

`*.jsonl` 每行一条 JSON：

- `sessions_plain`：`{"session": "...", "role": "user|assistant", "text": "...", "ts": ...}`
- `sessions_tools`：`{"session": "...", "name": "工具名", "input": {...}, "output": "...", "is_error": bool}`

字段与抽取方式见同目录 `_extract_sessions.py`（本仓库发布的原始事件流的生成脚本）。
机器可读的附件元数据见同目录 `_attachments.json`。
