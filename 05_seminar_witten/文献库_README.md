## 索引怎么读

`索引_全量253篇.md` 用一张表统管全部论文，每行给：年份、arXiv、主题（A–H 或数学/其他）、**判定**、引用数、本地文件名。

判定是**机器初判**，只为帮你快速分区，不是学术结论：

- **主线（第一批）**：已选进第一批 50 篇，逐篇有一句话理由（见 `第一批_50篇_索引.md`）。
- **主线**：其余数学物理强相关论文，是第二、三批的候选池（152 篇）。
- **边界（AdS/CFT 场论侧）**：标题涉及 brane/大 N/CFT，可能读你可能不读（6 篇）。
- **范围外（引力/黑洞/超引力/宇宙学）**：按你的偏好不收（45 篇）——但它们**已经在库里**，只是标了记号；你说一句「黑洞不读」时不会浪费时间翻。

## 第一批 50 篇（精读序）

主题分布：A 超对称规范理论与电磁对偶 7、B 拓扑场论/Chern–Simons/纽结 10、C 弦论与 M 理论 10、D 镜像对称与 Calabi–Yau 4、E 几何 Langlands 6、F 振幅与可积 5、G 拓扑物相与反常 5、H 综述 3。

每篇的「为什么读」是给主持人的锚点，不是摘要；摘要请读原文。
`01_1994_hep-th_9407087_...pdf` 就是已完成研讨班 SEM-9407087 的原文，体例可对照。

## 怎么用（配合 AI 研讨班工程）

1. 先读 `阅读路线与批次计划.md`，选一条路线，按 A/B/C 三级深度排期。
2. 开一班：从本库取 PDF → 拷进 `AI研讨班工程\seminars\SEM-xxx\source\`（或建链接）。
3. dossier 的「原文精读」一律指向本库文件，不另存副本。
4. 完成一班，回本库索引的「为什么读」栏补一行「读后一句话」——文献库与研讨班档案互为索引。
