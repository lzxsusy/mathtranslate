# SEM-9407087 一页纸

**Seiberg–Witten (1994), hep-th/9407087**  
纯 N=2 SU(2) SYM 的低能有效解：它做到了什么，没做到什么。

---

## 五句话

1. **解的是低能有效理论**：预势 `F(a)`、模空间度规 `Im τ |da|²`、单值性、BPS 质量公式（给定电荷）、软破缺后的磁单极凝聚与电禁闭。
2. **不是完整 BPS 谱**：p42 明说谱会跳变；哪些电荷存在、在哪些墙跳，本文没有给。
3. **三个奇点是定理**（给定标准事实）：若单值性阿贝尔，`a²` 整体坐标，`Im τ` 是 C 去 punctures 上的正调和函数 ⇒ 常数，与 `Im τ∼(2/π)ln|a|→∞` 矛盾；故需非阿贝尔表示，至少再加两个有限奇点。
4. **SW 曲线是构造 + 验证**：`y²=(x²−1)(x−u)`、`λ=(√2/2π)dx√(x−u)/√(x²−1)`；`a,a_D` 是周期，`τ=b₁/b₂`；曲线是猜出来再验证单值性/渐近/正定性的，不是第一原理推出。
5. **“精确”有范围**：质量公式对给定电荷精确；唯一性只是 proof-gap；p42 是条件性排除，不是无条件定理。
