## 1. 硬性要求

- **必须通读全部 45 页**（p1–p45）。你的 lens 只决定报告重心，不决定阅读范围。
- 每条实质性断言必须有锚点：`[src p.N]`、`[eq x.y]`、`[sec x.y]`。没有锚点的，只能写进“疑点”，不能写进“结论”。

- 禁止修改别人的报告、`map.yaml`、`seminar.yaml`、`participant_memo.md`。
- 用中文写；术语首次出现给英文原文，例如“预势（prepotential）”。

## 2. 三个 lens（各有侧重，但都读全文）

### r01 — 物理结构与论证链

重点：§1、§4、§5。

要回答：
- 论文的问题是什么？为什么纯 N=2 SU(2) 是可解的？
- 论证链：渐近自由 → 低能有效作用量 → 对偶 → BPS 质量 → 奇点 → 无质量磁单极 → 凝聚/禁闭。每一环依赖前一环的什么？
- 哪些步骤是“严格证明”，哪些是“一致性论证/物理动机”？
- 两个强耦合奇点为什么必须是磁单极/双荷子？第三个奇点是什么？
- 软破缺 N=2→N=1 后，禁闭的机制到底是什么？

报告里至少画出**一条完整的论证链**（文字版即可），标出每个节点的页码。

### r02 — 数学工具与计算

重点：§2.3、§3、§6。

要回答：
- 特殊 Kähler 几何、prepotential、Legendre 变换、τ 的定义与变换律。
- SL(2,Z) 作用在 (a_D,a) 和 τ 上的公式；单值性矩阵怎么算。
- 椭圆曲线 y²=(x²−1)(x−u)、微分 λ、周期 (a_D,a) 的构造；Γ(2) 与 H/Γ(2)。
- 至少核对 6 个关键公式（写出公式号、页、你的核对结果：对/错/文字层坏/需要页图）。
- 哪些地方是“数学上严格”，哪些是“物理论证”？

### r03 — 文本、证据与批判

重点：全文 + 参考文献 + 用户备忘 + 与桌面文献的连接。

要回答：
- 摘要/引言里的每个大 claim，正文是否真的证明了？有没有被后续文献修正？
- 论文的论证有没有循环、缺口、未证明的假设？
- 用户备忘 M1–M12 逐条判定：`accept` / `reject` / `open`，给锚点；错的写清楚错在哪。
- 与桌面文献的连接：至少 3 条“本文 → 后续文献”的具体连接（例如 SW → Nekrasov → AGT；SW → Higgs 丛/几何 Langlands；SW → 广义对称性/禁闭）。
- 找出 5 个最值得在圆桌上吵的问题。
