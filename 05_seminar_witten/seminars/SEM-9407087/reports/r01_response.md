## 4. 附录：c14 的补全版（应 r03-Q2 的"检验"要求）

1. (a_D,a) 是模空间上的截面；单值性给出 ρ: π₁(M) → SL(2,Z)（p.12、p.35）。
2. 若 Im ρ 阿贝尔：则 (a_D,a) 的变换只含平移与对角缩放，可取 A=½a² 作为 u 的整体单值坐标（p.24 "a² is a good global coordinate"），度规全局为 Im τ da dā，Im τ = τ(a) 的虚部是 C 上的**正调和函数**。
3. C 上正调和函数由 Liouville/Harnack 必为常数；而 (2.15) 给 Im τ ≈ (2/π)ln|a|/... → ∞，矛盾（这里用"无界"，不是"无极小"）。
4. 故 ρ 非阿贝尔；π₁(CP¹ 去 n 点) 是 n−1 元自由群，要非阿贝尔表示需 n−1 ≥ 2，即除 ∞ 外至少两个奇点。
5. 再加 u→−u 的 Z₂ 交换两奇点，取最少即"恰好两个"——**这一步是假设**（p.24 "the minimal assumption"）。
6. 剩余假设：du≠0 处处（p.34，本文 "we will assume"）；因此 §5.2 的结论是"单值 + 正定 ⇒ ≥2 奇点（标准数学）"，"恰好 2"才是假设。c14 的新 type 应理解为第 1–4 步。
