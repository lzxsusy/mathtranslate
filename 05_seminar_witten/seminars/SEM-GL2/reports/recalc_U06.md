## 1 't Hooft 算子的奇点与粘合数据

### 1.1 问题
取 U(1) Dirac 单极子与 SU(2) 例，写出法向平面/链接上 G-丛的粘合数据（转移函数、绕数），验证它给出 (9.10)/(9.12) 的奇点分量，并说明为何「算子 = 粘合数据」而非「算子 = 场配置」。

### 1.2 原文式与页
- 静态情形线算子支撑于 R×p（B p.123）；线算子不是既有 Hilbert 空间上的算子，而是必须并入物理态空间的定义——原文：「line “operators” … are not operators in the usual sense」(B p.123)。
- 奇点曲率：F ∼ ⋆d( i m /(2|~x−p|) )，∮_S c₁ = m（(9.10)，B p.130）；U(N) 为 diag(m_i) 版本（(9.12)，B p.131–132）。
- 原文明确算子由 CP¹ 上 G-丛指定：「an ’t Hooft operator is specified by the choice of a G-bundle over CP¹」(B p.139)；修改空间 = 带 p₀ 外固定同构的丛（B p.145）。
- 粘合数据的最简代表：g_ji = z^{−m_j}δ_ji（(9.31)，B p.147）。

### 1.3 逐步推导
**(a) 局部几何。** 线算子 L = R_t ×{p}，p = (y₀,p₀) ∈ R×C。其法向 R³ = R_y × C 的链接为 S²；赤道 S¹ ≅ C\* = 法向平面（z-平面）去心。S² 上 G-丛的两个半球平凡化在赤道上的转移函数 g(z) ∈ G(C\*)，绕数即拓扑荷。

**(b) U(1)。** 由 (9.5) F = ⋆dφ₀ 取 φ₀ = −m/(2|x̃−p|)（x̃∈R³，r=|x̃−p|）：dφ₀ = (m/2)r^{−2}dr，⋆₃dr = r²dΩ ⇒ F = (m/2)dΩ，∮_{S²}F = 2πm，c₁ = ∮F/2π = m。这与 (9.10) 的奇异项一致（B 把 2πi/反厄米因子吸收进 (9.10) 的写法）。同一 m 的丛侧数据：O(m) 在赤道上的转移函数 g = e^{imφ} = (z/z̄)^{m/2}（等价地 z^{−m} 依定向），绕数
(1/2πi)∮ g^{−1}dg = m。数值：m=3 时绕数 3.000000、通量 18.8496=2π·3（附录 A5）。**「粘合数据 ↔ 奇点分量」= 同一整数 m**。

**(c) SU(2)。** 转移函数 g = diag(z^{m}, z^{−m})；det g = 1 ⇒ c₁ = 0，但丛为 O(m)⊕O(−m)（B p.139 的 U(2) 分类特例），奇异曲率 diag(m,−m)⋆d(i/2r) 与 (9.12) 一致、迹为零。拓扑侧：H²(S²,π₁(SU(2)))=0，故 SU(2) 无 mod-2 荷；对 SO(3)=SU(2)/Z₂ 才有 H²(S²,Z₂)=Z₂、w₂ = m mod 2。这正是 R §2.1.2 的 ξ∈H²(S²,π₁(G))≅π₁(G)≅center(^LG)：SU(2)↔0、SO(3)↔Z₂ 两个例都核对为真。

**(d) 为什么「算子=粘合数据」而非「场配置」。** 三条理由，均可落到原文：
1. 场在奇点附近没有规范不变的局域 profile：任何 A, φ 的 ansatz 都可被规范变换改写，且 (9.10)/(9.12) 只是解的渐近奇异项（它由粘合数据经 Bogomolny 方程决定，不是算子的定义数据）。
2. B p.123 明确：此类线算子不作用在既有 Hilbert 空间上，而是并入物理态空间定义——即算子就是「允许的边界/奇点条件」。
3. B p.139 明确：算子由 CP¹ 上 G-丛的选择指定；约化到 3d 后同一数据 = 法向平面 C\* 上的转移函数（即 Gr_G 的点）。场配置是给定奇点数据后 Bogolmolny 方程的解（代表元，gauge 相关）；算子的合成 = 粘合数据的拼接，不是场的叠加。

### 1.4 具体算例
- U(1)，m=1,2,3：g = z^{−m}，绕数 m；∮_{S²}c₁ = m；(9.10) 的 1/r 奇异项系数 = m/2。
- SU(2)，m=1：g = diag(z, z^{−1})，丛 O(1)⊕O(−1)，c₁=0，奇异 diag(1,−1)；m=2：O(2)⊕O(−2)，奇异 diag(2,−2)，仍 c₁=0。
- 与 (9.31) 对接：N=1 时 g = z^{−m}，det 绕数 = −m，丛次数 = +m，与 (9.15) c₁ 加 m 一致（附录 A5）。

### 1.5 与报告比
R §2.1.1–2.1.2（算子数据=奇点处规范等价类；链接 S²≅CP¹；ξ∈H²(S²,π₁(G))≅π₁(G)≅center(^LG)）方向正确，SU(2)/SO(3) 例可核为真。
R §2.1.3 说「4d 线算子法向 3 维、链接 S² 与 Hecke 粘合 C\* 上转移函数模 G(O) 是同一个 Gr_G 的点」——**不精确**：S² 上的丛（无平凡化）是无框数据，Gr_G 的点是「丛 + 一侧平凡化」（修改数据）；只有把链接视为「两半球沿赤道粘合」并固定一侧平凡化时，转移函数才是 Gr_G 的点。R §2.3.4 自己已写了正确的「带 p₀ 外固定同构的丛」，故此处是 R 内部措辞不一致（E6，低）。

### 1.6 判定
✓ 成立（粘合数据 = 转移函数/绕数；U(1) m 与 (9.10) 的 ∮c₁=m 一致；SU(2) 给出 (9.12) 对角奇异项与 w₂ 图像）。R 的物理结论对，§2.1.3 措辞需加「带平凡化」。

## 2 U(N) 显算

### 2.1 问题
在 p₀ 附近 E_y = ⊕L_i 分解下算 T(^Lw)：L_i ↦ L_i⊗O(p₀)^{m_i}；验证 Σm_i 与奇点荷的关系；给 N=2、N=3 各一组具体 m_i 与结果；核 R 自报的「分解无关性只对 N=2」。

### 2.2 原文式与页
(9.11) ρ(e^{iα})=diag(e^{im₁α},…)，Lw=(m₁≥…≥m_N) 模置换；(9.12) 对角奇异曲率；
(9.13) ∧^k V 的最高权 w(k)=(1,…,1,0,…,0)（k 个 1）；(9.14) Σm_i=0 ⟺ 中心平凡；(9.15) c₁(E)→c₁(E)+Σm_i；
B p.132：「L_i→L_i⊗O(p₀)^{m_i} … This is the basic link」。

### 2.3 逐步推导
1. 近 p₀ 方程约化到极大环面 U(1)^N：A、φ₀ 的奇异项取对角 diag(m_i)（(9.11)），交叉项在高阶可忽略；于是 E_y 的全纯型逐支按阿贝尔情形变化（B p.131–132）。
2. 阿贝尔链（B p.130–131）：L₊⊗L₋^{−1} 在 p₀ 外有处处非零无零极截面、p₀ 处零点阶 q ⇒ L₊⊗L₋^{−1}=O(p₀)^q；由 D=C₊−C₋−S 是边界得 0=q₊−m−q₋ ⇒ q₊=m+q₋；故 L₊≅L₋⊗O(p₀)^m。逐支套用得 L_i↦L_i⊗O(p₀)^{m_i}。
3. Σm_i：取 (9.12) 的迹。tr diag(m_i)=Σm_i = 奇点曲率的 U(1) 分量 = 磁荷的 U(1) 部分；同时 c₁ 改变量 = Σm_i（(9.15)）。对 U(N)，CP¹ 上丛 O(m₁)⊕…⊕O(m_N) 的唯一拓扑不变量正是 c₁=Σm_i（B p.139 的 N=2 说法推广）。中心 exp(iα) 作用乘 exp(iαΣm_i)：Σm_i=0 时中心平凡（(9.14)），此时算子不改变 c₁，是纯非阿贝尔荷（如 SU(N) 情形）。
4. 关键推论（R 未点明）：**c₁（即 Σm_i）不足以确定算子**。U(2) 中 (2,0) 与 (1,1) 都有 Σ=2，但 (2,0) 对应不稳定丛 O(2)⊕O、Y 有奇点且闭包并入 (1,1)，(1,1) 对应 O(1)⊕O(1)=E₋⊗O(p₀)（B p.139–143）。所以「奇点荷」= 完整 Lw（dominant coweight），Σm_i 只是其 U(1) 分量；SU(N) 中 Σm_i=0 但 Lw≠0 仍是不同算子。R §2.3.2 已隐含（O(2)⊕O 不稳定），但未把「拓扑荷 vs 完整型」的分野写清。

### 2.4 具体算例
N=2（E₋ 平凡，C=P¹；dim Y=Σ_{i<j}(m_i−m_j)，附录 A4）：
| (m₁,m₂) | E₊ | c₁=Σm | Σ(m_i−m_j) | Y |
|---|---|---|---|---|
| (1,0) | O(1)⊕O | 1 | 1 | CP¹ = Gr(1,2) |
| (2,0) | O(2)⊕O | 2 | 2 | WCP²(1,1,2)∖pt，闭包⊃(1,1) |
| (1,1) | O(1)⊕O(1)=E₋⊗O(p₀) | 2 | 0 | 一点 |
| (2,2) | E₋⊗O(p₀)² | 4 | 0 | 一点 |
N=3：
| ^Lw | E₊ | Σm | dim Y=⟨2ρ,λ⟩ | Y |
|---|---|---|---|---|
| (1,0,0)=w(1) | O(1)⊕O⊕O | 1 | 2 | Gr(1,3) |
| (1,1,0)=w(2) | O(1)⊕O(1)⊕O | 2 | 2 | Gr(2,3) |

维数公式 Δ=Σ_{i<j}(a_i−a_j) 与 ⟨2ρ,λ⟩ 逐例相等；minuscule λ=(1^k,0^{N−k}) 给出 dim=k(N−k)=dim Gr(k,N)（N=3,4,5 全部核对，附录 A4）。

### 2.5 与报告比（含「分解无关性只对 N=2」）
R 的 (9.29)–(9.31) 与 §2.3.2/2.3.3 正确，维数（9.25）三处对账正确。
但 R §5.3 原话「B 的例子 (9.16)–(9.19) 只覆盖 N=2，我无法确认一般 N 下『分解无关性』的证明」——**不成立**：(i) B p.136–137 的等价关系「p₀ 外的自然同构能否延拓过 p₀」对任意 N 直接成立，与分解无关（换分解 s→g s，g∈GL(N,O)，E₊ 的 O-模不变）；(ii) B p.145–148 的 Gr_N 表述（右乘 GL(N,O) 被商掉）本身就是一般 N 的证明；(iii) R 自己在 §2.4.5–2.4.6 已用过一般 N 的 (9.23)–(9.25)。独立验证：N=3、^Lw=(1,0,0)，分解 s 与 s′=(s₁+zs₂,s₂,s₃) 生成的 O-模相同（附录 A6，rank 3=3=3，并集 rank 3）。正确表述应为：「B 的**显式参数化**只到 N=2，一般 N 由 §9.3 的 Gr 商表述保证」。
（另：R §2.3.3 说「限定『相对于某个分解』无害」，与 §5.3 的怀疑自相矛盾——E2，低。）

### 2.6 判定
✓ 成立：L_i→L_i⊗O(p₀)^{m_i} 与 (9.12)/(9.15) 一致；Σm_i=磁荷 U(1) 分量=Δc₁；N=2/N=3 表见上。R 的计算对，「分解无关性只对 N=2」的自我保留过头且与其 §2.3.3 矛盾。

## 3 Hecke 修改的形式定义

### 3.1 问题
写清 Bun_G 上的 Hecke 对应（Hecke_G^H 或 Hecke_G^λ）：输入 (E, 改动点 p, 抛物/子群数据)，输出「p 外同构、p 处被修改」的丛；GL₁ 与 GL₂ 各一例；核 R 的定义是否精确。

### 3.2 原文式与页
(9.28) U_∞=CP¹−{0}, U₀=CP¹−{∞}，σ 在 U_∞、σ′ 在 U₀，C\* 上 σ′=g(z)σ，g∈GL(N,X)，X=C\* 上全纯可亚纯延拓的函数环；σ′→h₀σ′ 给 g→g h₀^{−1}；故 {丛+固定平凡化}≅GL(N,X)/GL(N,O)=Gr_N（B p.145–147）。
(9.29) s_j=z^{−m_j}f_j；(9.31) g_ji=z^{−m_j}δ_ji；(9.32) g 是 ρ(e^{iα})=diag(e^{im_jα}) 的复化；Y(^Lw;p₀)=[g] 的 G_C(O)-左轨道（B p.147–148）。
(9.34) Gr_G=G_C(X)/G_C(O)（B p.148）。修改等价的判据：「p₀ 外自然同构能延拓过 p₀」（B p.136–137）。

### 3.3 定义（我给出的精确版本）
固定连通约化 G、光滑射影曲线 C、p∈C、λ∈X_*(T)_dom（或 V∈Rep(^LG)）。**Hecke 对应**
Hecke_G^λ ⊂ Bun_G(C) × Bun_G(C) × C：
Hecke_G^λ = { (E,E′,p,β) : β: E|_{C∖p} ≅ E′|_{C∖p}，且 β 在 p 处的修改型为 λ }。
「型 λ」的精确含义：取 p 的形式圆盘 D 与坐标 z，把 E,E′ 在 D 上平凡化；β 给出 g∈G(K)（K=C((z))），其类 [g]∈Gr_G=G(K)/G(O)；型 λ ⟺ [g]∈Gr_G^λ := G(O)·g_λ。换平凡化只右乘 G(O)，故良定（与 (9.28) 中 g→g h₀^{−1} 同）。E 与 E′ 在 p 外同构、p 处被修改；两个修改 β,β′ 等价 ⟺ β′β^{−1} 延拓过 p（B p.136–137）。「抛物/子群数据」= 当 λ 为 minuscule 时 Y_λ≅G/P_λ，纤维就是 G/P_λ 的点（GL_N 的 (1^k,0) 给 Gr(k,N)=GL(N)/P_k）；一般 λ 下 Y_λ→G/P_λ 只是满射而非同构。算子：投影 h^←,h^→: Hecke→Bun×C，Hecke 函子 H_V = h^→_* (h^←)^*（R §2.3.4 引 D p.8 的对应正确）。

### 3.4 例子
**GL₁（λ=k∈Z）**：Gr_{GL₁}=Z，无抛物数据；Hecke_{GL₁}^k 是图 {(L, L⊗O(p)^k, p)}；纤维一点。局部 g=z^{−k}（det 绕数 −k，次数 +k）。k=1：L↦L(p)（O↦O(1)）；k=0：恒等。
**GL₂（λ=(1,0)，fundamental）**：E 平凡时 E₊=⟨z^{−1}s₁,s₂⟩=O(1)⊕O；一般截面 s=c z^{−1}s₁(0)+(h₁,h₂)（(9.16)），只依赖 s₁(0) 的缩放类，即纤维中的直线 ℓ∈P(E|_p)；故**纤维=P(E|_p)=CP¹**，抛物数据=直线，Y=CP¹（B p.137）——这正是 (9.24) 的 k=1、N=2 情形。
**GL₂（λ=(2,0)）**：E₊=O(2)⊕O；参数 (u,u′,v,v′) 经缩放/平移得 WCP²(1,1,2)（权 (1,1,2)），少一点 (0,0,1)（B p.137–138）；闭包并入 (1,1)（Σm 相同，见 §4）。λ=(a,0) 时 dim Y=a（(9.23)）。

### 3.5 与报告比
R §2.3.4 的**方向**对：数据 = 改动点 p₀ + 输出丛 E + p₀ 外固定同构 σ；等价 = 延拓过 p₀；并给出 h^←/h^→ 与 Hecke 函子；两个「抛物数据」实例（纤维中直线、k 维子空间）也在。但**不够精确**：
1. 「输入」未把型 λ（=^Lw）列为一等数据，而 λ 恰恰决定 Y_λ；任务要求的「抛物/子群数据」只在 minuscule 时才是 G/P 的点，R 说「一般权下 Y 映到某个部分旗流形 G/P」缺「仅 minuscule 为同构」。
2. 未给 GL₁ 的具体 Hecke 例（R §2.3.1 只给了 U(1) 的算子作用，未写成对应）。
3. 把「对应（Bun×Bun 上的子簇）」与「纤维（修改空间 Y）」混在同一段，未点明 Y_λ = Hecke 纤维、Gr_G 是万有模空间（R §2.5.2 第三句其实说对了）。
（E5，中）

### 3.6 判定
定义方向正确、可用于计算，但不到「精确」；建议按 §3.3 补 (E,p,λ) 三元组与 minuscule 限定。

## 4 仿射 Grassmannian

### 4.1 问题
Gr_G 的定义、ind-概形、连通分支；与 §9.2 修改空间对比哪侧是 Gr_G、哪侧是 ^LGr；g=0（C=P¹）时维数/连通性检查。

### 4.2 定义与性质（原文式+页）
- Gr_G := G(K)/G(O)，K=C((z))，O=C[[z]]（B p.147 的 GL(N) 版；p.148 (9.34) 一般 G 的 G_C(X)/G_C(O)）。**注意方向**：任务里的 Gr_G=G(O)/G(K) 写反了——G(O) 是子群，作用在右侧被商掉；原文与 R 都是 G(K)/G(O)（R 此处正确）。
- 模空间解释：Gr_G ≅ { (E,φ) : E 是 D 上 G-丛，φ: E|_{D\*}≅trivial }/≅（D=形式圆盘），正是「粘合数据/修改数据」。故 (9.31) 的 g 是 Gr_N 的点（B p.147）。
- ind-概形：Gr_G = ⋃_n Gr_G^{≤n}，Gr_G^{≤n} = ⋃_{⟨2ρ,λ⟩≤n} X_λ，X_λ=G(O)·g_λ≅G(O)/G(O)_λ 是有限维射影簇（dim=⟨2ρ,λ⟩）；故 Gr_G 是 ind-射影 ind-概形（ind-projective ind-scheme，等价地 union of finite-dimensional projective varieties）。GL_N 的显式版本：Gr_N^{(i)}={L: z^i O^N⊂L⊂z^{−i}O^N} 有限维射影（B p.148 的 Gr_N(i)）。
- 连通分支：π₀(Gr_G)=π₁(G)=X_*(T)/Q^∨（连通约化 G）；G(O)-轨道 ↔ X_*(T)_dom。若 G 单连通则 π₁=0、Gr_G 连通；若 G=T 是环面则 Gr_T=X_*(T)（离散点集）。**所以「G 单连通时连通分支=X_*(T)」不准确**：恒真的是「轨道 ↔ X_*(T)_dom」，而「分支=X_*(T)/Q^∨=π₁(G)」；只有在 T 的情形才是字面的 X_*(T)。
- 与 §9.2 对比：**修改空间一侧是 Gr_G**，即被修改的 G-丛的 Grassmannian（Y(^Lw)=G_C(O)·g_λ ⊂ Gr_G，B p.148）；**^LGr 在 §9.2 不出现**。对偶侧只以「标号」形式进入：^Lw∈X^*(T_{^LG})=X_*(T_G)（B p.131「it will be a weight of the dual group ^LG」）。^LGr 描述的是 ^LG-丛（谱侧/局部系统）的修改，若出现应在 GL 对偶的 Hecke 本征层一侧，与本节的 Bun_G 侧不同。

### 4.3 g=0（C=P¹）检查
- 维数：dim Y(λ)=⟨2ρ,λ⟩=Σ_{i<j}(a_i−a_j)（(9.25)）。N=2：(1,0)→1=dim CP¹ ✓，(2,0)→2=dim WCP²(1,1,2) ✓；N=3：(1,0,0)→2=dim Gr(1,3) ✓，(1,1,0)→2=dim Gr(2,3) ✓，(2,0,0)→4 ✓；minuscule 全族 k(N−k) ✓（附录 A4）。
- 连通性：Y(λ) 是连通群 G_C(O)（或 G(O)）的像，故连通；其闭包是射影 Schubert 簇，紧。例：U(2) (2,0) 的闭包 = Y(2,0) ⊔ Y(1,1)；两者 Σm 都=2，处于 Gr 的同一连通分支（c₁=2），对应 B p.139 的形变 O(2)⊕O → O(1)⊕O(1)。而 (1,0) 的 Σm=1 在另一分支，其闭包不能并入 (1,1)——正好解释 B p.139「O(1)⊕O 不能微扰」。
- 结论：g=0 时 Gr_G 的分支被 c₁=Σm_i 区分（U(N)：π₁=Z）；修改空间是分支内的 Schubert 胞腔/轨道，紧化=Schubert 闭包（B p.148）。

### 5.4 (9.2) 的独立核算（R 判错）

**A6 N=3 分解无关性：{z⁻¹s₁,s₂,s₃} 与 {z⁻¹(s₁+zs₂),s₂,s₃} 生成同一 O-模**
```python
import numpy as np
K=2
def vec(pairs):
    v=np.zeros((2*K+1,3),dtype=complex)
    for (k,i,c) in pairs: v[k+K,i]+=c
    return v
def rref(vs):
    M=np.array([v.flatten() for v in vs],dtype=complex); r=0
    for c in range(M.shape[1]):
        p=next((i for i in range(r,M.shape[0]) if abs(M[i,c])>1e-9),None)
        if p is None: continue
        M[[r,p]]=M[[p,r]]; M[r]/=M[r,c]
        for i in range(M.shape[0]):
            if i!=r: M[i]-=M[i,c]*M[r]
        r+=1
    return M[:r]
G1=[vec([(-1,0,1)]),vec([(0,1,1)]),vec([(0,2,1)])]
G2=[vec([(-1,0,1),(0,1,1)]),vec([(0,1,1)]),vec([(0,2,1)])]
B1,B2=rref(G1),rref(G2)
print(B1.shape[0],B2.shape[0],np.linalg.matrix_rank(np.vstack([B1,B2])))   # 3 3 3 => 同一模
```
