## 2. 哪几类真能训

### 2.1 PRM / 过程监督：`reasoning` + `verify` + `recalc`
三条 reasoning 都是「先走错 → 发现 → 改」的完整轨迹，例如 U03 的三条死路是：

1. 用「μ_J、μ_K 相加相减」去对 Hitchin 方程（错：三个实矩映射与三条方程一一对应）；
2. 把 ω_J + iω_K 当成 J 的 (2,0) 形式（实为 I 下的 Ω_I）；
3. 在 §4 里读出 T-对偶（实际首见 §5.3 p.70）。

**训练价值最高的是「错在哪一步、怎么发现的」**：这三条都不是"知识不足"，而是"过度统一"——把三条并列的方程压成一个机制。
这是模型最典型的失败模式，也最难从教科书里学到。**可用**：过程奖励模型的负例 + 修正后的正例。

### 2.2 引用与核验：`challenge` + `verify`
6 条 challenge 全是「声明 → 反证 → 修正」的三元组，且 `diff.before/after` 是真实文本差异，不是人造的。
证据审计给了每轮的命中率：**U01 50/56、U02 48/55、U03 58/66**（命中率 88%–91%），偏页/无据逐条可查。
**可用**：训练「给出 locator 之前先自我核验」的能力；也可作评测集（给定断言，判断页锚真伪）。

### 2.3 跨文本对照：`crosswalk`
3 条对照（B 的物理语言 / C 的 15 页浓缩 / D 的 Bourbaki 视角）是同一件事的三种说法。
**可用**：多源一致性对齐；但样本还太少（每轮 1 条），要攒到 20 条以上才有统计意义。

## 4. 诚实的天花板

1. **覆盖不全**：8 节只做完 3 节（U01–U03），后面 §6–§12 才是 Hecke / D-模 / 膜的部分，也是全文最难、最值钱的部分。
2. **每节只有 14 条**：对训练一个模型来说这个量级太小；真正有意义的是**生产方法**——这套七拍流程可以复制到任何一篇论文，产出同样的结构。
3. **校对深度不均**：U01 有 55 条抽核、U02 55 条、U03 66 条，但都是"抽样"；没有做全量核对。
4. **一个真实收获**：讨论班第一轮就抓出了**已发布解经本里的一个实质错误**（(3.52) 的共轭位置写反，见 `SEM-0604151/reports/v1.2_勘误.md`）。
   这说明流程不是在自产自销——它能纠正上一层的错误。这一条比任何单条语料都更能说明这套数据的价值。
