## 1. 参数空间的维数：16 → 2 个不变超荷，射影化得 CP¹

### 1.1 问题
扭化（GL twist）后为什么出现一族以 CP¹ 为参数的拓扑场论？从 16 个超荷里保留 2 个不变超荷出发，独立参数有几个？t 与 −t 为什么等价？为什么射影化后是 CP¹（而不是别的）？

### 1.2 原文依据
- (2.14)（B p.11，`p011.txt:42`）：16 个实超荷复化后为 (2,1,4)⊕(1,2,4̄)。
- κ 与 Spin′(4)：(3.2) 一带（B p.17–18，`p019.txt:28–32`）：κ: Spin(4)_E → Spin(6)_R，4 ↦ (2,1)⊕(1,2)；Spin′(4) = (1×κ)Spin(4)_E。
- 超荷分解 (3.5)(3.6)（B p.20，`p021.txt`）：(3.5) = (2,1)_0 ⊗ [(2,1)_{−1}⊕(1,2)_1] = (3,1)_{−1}⊕(1,1)_{−1}⊕(2,2)_1；(3.6) = (1,2)_0 ⊗ [(2,1)_1⊕(1,2)_{−1}] = (1,3)_{−1}⊕(1,1)_{−1}⊕(2,2)_1。
- 不变旋量的构造 (3.7)–(3.11)（B p.20–21，`p022.txt`）：ǫ_ℓ、ǫ_r 由 Γ̂_E 本征值区分；(3.9) ǫ_ℓ=−Nǫ_r，故 ǫ_r 由 ǫ_ℓ 决定；(3.11) Γ₈₉ǫ=−iǫ，K=Γ₈₉ 在 ǫ_ℓ、ǫ_r 上本征值相同。
- CP¹ 段（B p.21，`p022.txt` 末）：「We now can see why this construction gives a family of topological field theories parametrized by CP¹ (fig. 1). We pick any nonzero complex linear combination of ǫ_ℓ and ǫ_r, ǫ = uǫ_ℓ+vǫ_r (3.12) ... An overall scaling of ǫ would not matter, so the possible choices for the topological symmetry are parametrized by CP¹.」
- t~−t 段（B p.22，`p023.txt`）：(3.13) t→((cτ+d)/|cτ+d|)t；SU(4)_R 中心生成元 I：(3.14) I(t)=−t；「the topological field theories with parameter t or −t are equivalent. This is a trivial equivalence ... The Z₂ symmetry (3.14) is the only trivial equivalence ... it is essential that ǫ_ℓ and ǫ_r have the same eigenvalue of K. Otherwise, a transformation in the group ℂ* generated by K would act non-trivially on t and would cause the whole CP¹ family ... to be trivially equivalent.」；Fig.1 标出 t=i,−1,0,1,∞,−i。

### 1.3 推导
第 1 步（16 的分解）。16 个实超荷在 Spin(4)_E×Spin(6)_R 下是 (2,1,4)⊕(1,2,4̄)，复化后 8+8=16 个复分量（附录 S2.1）。取 κ 后按 Spin′(4) 分解：每个 8 维部分只含一个 (1,1) 单态，(3.5) 给出 (1,1)_{−1}、(3.6) 给出 (1,1)_{−1}（附录 S2.2–S2.4，两个单态的 K 都是 −1）。**16 个超荷里恰有 2 个不变超荷**，就是 ǫ_ℓ、ǫ_r。

第 2 步（为什么是一族）。不变性对线性组合封闭：ǫ = uǫ_ℓ+vǫ_r 对任意 (u,v)≠0 都是不变的（不变子空间是复 2 维的）。产生超对称的算符是 δ_T=[ϵ^A Q_A, ·]，对 ϵ 线性，所以 ϵ 与 λϵ（λ∈ℂ*）给出同一个 δ_T。于是参数空间 = (ℂ²∖{0})/ℂ* = CP¹：**复维 1、实维 2**。因 (3.9) ǫ_r 由 ǫ_ℓ 自然决定（CP¹ 不是抽象拷贝），p.22 给出自然仿射坐标 t=v/u（t=0 只用 ǫ_ℓ，t=∞ 只用 ǫ_r）。不同 t 给出不同超对称方程 (3.29)（p.25），所以是一族理论而非一个理论的不同描述。

第 3 步（t 与 −t）。I（SU(4)_R 中心的生成元）作用 ǫ_ℓ→iǫ_ℓ、ǫ_r→i^{−1}ǫ_r，于是 u→i^{−1}u、v→iv，t=v/u→(iv)/(i^{−1}u)=−t，即 (3.14)。I 是经典作用量的对称（不是 S-对偶），故 t 与 −t 的扭化理论相同：平凡等价。唯一性：ǫ_ℓ、ǫ_r 的 K 本征值相同（(3.11)），K 不产生额外的射影等价；若本征值不同，K 生成的 ℂ* 会在 t 上非平凡作用，把整个 CP¹ 族变成平凡等价（p.22 原话）。

第 4 步（射影化后再射影仍是 CP¹）。t~−t 的商是 CP¹/(t↦−t)；映射 t↦w=t² 是 2:1 分支覆盖，Riemann–Hurwitz −2=2(2·0−2)+R 给 R=2（附录 S2.8），故 CP¹/ℤ₂≅CP¹。事实上 Ψ（§3）只依赖 t²（附录 S1.10），t→−t 在 Ψ 上不可见；理论族的内禀参数正是 Ψ，也取值于 CP¹。

第 5 步（独立参数计数）。复参数 (u,v) 共 2 个，减去 1 个复整体标度 = 1 个复参数 = 2 个实参数；再商掉 t~−t 这个有限群不改变维数。故扭化理论的参数空间是复 1 维（实 2 维），即 CP¹。

### 1.4 数值/特例检验
- 附录 S2：16=(2,1,4)+(1,2,4̄)（8+8）；(3.5)=[(3,1)₋₁ 3 个 + (1,1)₋₁ 1 个 + (2,2)₁ 4 个]=8；(3.6)=[(2,2)₁ 4 个 + (1,3)₋₁ 3 个 + (1,1)₋₁ 1 个]=8；单态两个，K=[−1,−1]。
- (3.14) 数值：取 t=−0.1+1.7i，I(t) 与 −t 给出同一复数（S2.6）；t² 在 t→−t 下不变（S2.7）。
- Fig.1 的六个点 t=i,−1,0,1,∞,−i（p.21）：t=0、∞ 是坐标卡边界，t=±1 是反定向不动点（§3.5，p.38），t=±i 是 Ψ=∞ 的两点（§3）。
- 由 §3 的 (3.50) 也可看出 CP¹ 参数不是独立的：t² 的分式线性像 Ψ 与 t 一一对应（两张 t 卡之间 t→1/t 对应 Ψ→conj Ψ，见 §3.4），内禀参数只有 1 个复的。

### 1.5 与报告 v1 比较
- v1 §2.2（L61–L73）给出：不可约表示 (3.5)(3.6) 各含一个不变生成元、ϵ=uϵ_ℓ+vϵ_r、只有 v/u 有意义 ⇒ CP¹、t=v/u、t~−t 由 (3.14) 实现、K 本征值相同。**这部分核对通过**。
- 缺：v1 没有把 16 个超荷数到 2（L61 只说 "(3.5)(3.6) 各含一个不变生成元"，未给 16 的分解与计数），也没有给 CP¹ 的维数（复 1/实 2）⇒ **E13（低）**。
- v1 L73「族参数之所以恰好是 CP¹，是因为 K 只把 ϵ 旋转一个相位，而 ϵ 的整体缩放本来就不算参数」：因果表述不准确。CP¹ 的直接原因是「不变子空间复 2 维 + 整体标度不产生新理论」（p.21 原文 "An overall scaling of ϵ would not matter"）；K 本征值相同只用于论证 **t~−t 是唯一平凡等价**（p.22），不是 CP¹ 的来源 ⇒ **E3（低）**（v2 L85 仍保留此句）。

### 1.6 判定
**核对通过**：答案是「16 个实超荷 → 2 个不变超荷 → (ℂ²∖0)/ℂ* = CP¹，复 1 维/实 2 维；独立复参数 1 个；t~−t 由 (3.14) 的 I 实现，是唯一的平凡等价；CP¹/ℤ₂≅CP¹，内禀参数是 Ψ」。报告在此处的物理结论正确，但缺计数与维数（E13），且 L73 的因果句要改（E3）。

## 2. 超荷代数：δ_t²=−i(1+t²)£_σ、(2.15) 的口径与符号

### 2.1 问题
验证 δ_t²=−i(1+t²)£_σ（(3.42)，B p.33），说明 t=±i 时 Q²=0（严格拓扑）、其它 t 时 Q² 是规范变换；用 (2.15) 核对符号约定；若报告把 Q² 口径写混（p.18 的代数 vs §3.4 的 δ_t²）该怎么修。

### 2.2 原文依据
- (2.15) 本体在印刷 p.11（`p012.txt:1–19`）：{Q_A^X, Q_Y^{Ȧ}} = δ^X_Y Σ_μ Γ^μ_{AȦ} P_μ，{Q,Q}={Q̄,Q̄}=0。**注意：任务单写的「(2.15)（p.18）」不准确**——(2.15) 在 p.11；p.18 是引用它论证 Q²=0 的地方（`p019.txt:3–7`）。
- (2.15) 之后紧接的原文（p.11）：「With suitable boundary conditions, additional terms appear [13] on the right hand side of (2.15) (they are related to the extra six momenta that were dropped in going to four dimensions, and their magnetic duals). They will make a brief appearance at the end of this section.」
- p.18 的论证（`p019.txt:3–7`）：「We also want to pick κ such that the action of Spin′(4) on S₊ has a non-zero invariant vector. ... It will automatically obey Q²=0, by virtue of (2.15). (There is no Spin′(4) invariant operator on the right hand side of (2.15), so as Q²=½{Q,Q} is Spin′(4)-invariant, it must vanish.)」
- §3.1 变换规则 (3.23)–(3.28)（B pp.23–24，`p024.txt`–`p025.txt`）：(3.23) δ_T A_μ = iuψ_μ+ivψ̃_μ；(3.24) δ_T φ_μ = ivψ_μ−iuψ̃_μ；(3.25) δ_T σ=0，δ_T σ̄=iuη+ivη̃；(3.27) δ_T χ^±、δ_T η、δ_T η̃；(3.28) δ_T ψ = uDσ+v[φ,σ]，δ_T ψ̃ = vDσ−u[φ,σ]。
- p.25 的准确说法（`p026.txt:3–4`）：「the general theory with Q=uQ_ℓ+vQ_r obeys Q²=0 (modulo a gauge transformation)」（原文 "modulo a gauge transformation"）。
- (3.35)(3.36)（B p.31，`p032.txt`）：δ_T²A=−i(u²+v²)(−Dσ)、δ_T²φ=−i(u²+v²)[σ,φ]、δ_T²ψ=−i(u²+v²)[σ,ψ]、δ_T²ψ̃ 同、δ_T²σ=0；统一写 δ_T²Φ=−i(u²+v²)£_σ(Φ)，£_σ(A)=−Dσ、其余 £_σ(Φ)=[σ,Φ]；展开即 (3.36) δ_ℓ²Φ=δ_r²Φ=−i£_σ(Φ)、{δ_ℓ,δ_r}Φ=0（K<0 场只在线性运动方程上成立）。
- (3.41)(3.42)（B p.33，`p034.txt`）：δ_tχ=H、δ_tH=−i(1+t²)[σ,χ]；δ_t²(Φ)=−i(1+t²)£_σ(Φ)（Φ=χ,H）。

### 2.3 推导
第 1 步（由 (3.23)(3.24)(3.28) 直接算 δ_T²）。对 A：
δ_T²A = iuδ_Tψ+ivδ_Tψ̃ = iu(uDσ+v[φ,σ])+iv(vDσ−u[φ,σ]) = i(u²+v²)Dσ。
因 £_σ(A)=−Dσ，这正是 δ_T²A=−i(u²+v²)£_σ(A) ✓。对 φ：
δ_T²φ = ivδ_Tψ−iuδ_Tψ̃ = iv(uDσ+v[φ,σ])−iu(vDσ−u[φ,σ]) = i(u²+v²)[φ,σ] = −i(u²+v²)[σ,φ] ✓。
对 ψ：δ_T(Dσ)=[δ_TA,σ]=iu[ψ,σ]+iv[ψ̃,σ]，δ_T[φ,σ]=[δ_Tφ,σ]=iv[ψ,σ]−iu[ψ̃,σ]；于是
δ_T²ψ = u(iu[ψ,σ]+iv[ψ̃,σ])+v(iv[ψ,σ]−iu[ψ̃,σ]) = i(u²+v²)[ψ,σ] = −i(u²+v²)[σ,ψ] ✓；
ψ̃ 同法得 i(u²+v²)[ψ̃,σ]；δ_T²σ=0（因 δ_Tσ=0）。这五行就是 (3.35)（附录 S3.1 全 True）。

第 2 步（展开成 (3.36)）。δ_T=uδ_ℓ+vδ_r，故 δ_T²=u²δ_ℓ²+v²δ_r²+uv(δ_ℓδ_r+δ_rδ_ℓ)。与 δ_T²=−i(u²+v²)£_σ 比较 u²、v²、uv 的系数：δ_ℓ²=δ_r²=−i£_σ、{δ_ℓ,δ_r}=0，即 (3.36)（附录 S3.2 对 A,φ,ψ,ψ̃,σ 全 True）。

第 3 步（δ_t 与 (3.42)）。固定 t，令 δ_t=δ_ℓ+tδ_r（即 (3.16) 的 (u,v)=(1,t)），则
δ_t² = δ_ℓ²+t²δ_r²+t{δ_ℓ,δ_r} = −i(1+t²)£_σ = (3.42)。
t=±i：1+t²=0 ⇒ δ_t²=0（严格零，Q²=0）。t≠±i：δ_t²=−i(1+t²)£_σ 是场依赖的规范变换（参数 ∝σ），在规范不变观测量上为零——这正是 p.25 的 "Q²=0 modulo a gauge transformation"。

第 4 步（χ,H 的闭包/为什么必须重标 δ_t）。(3.41) 的 δ_tχ=H、δ_tH=−i(1+t²)[σ,χ] 满足
δ_t²χ=δ_tH=−i(1+t²)[σ,χ] ✓；δ_t²H=−i(1+t²)δ_t[σ,χ]=−i(1+t²)([δ_tσ,χ]+[σ,H])=−i(1+t²)[σ,H] ✓（δ_tσ=0）。
所以 (3.41) 与 (3.42) 相容（附录 S3.4 全 True）。t≠±i 时可令 δ′_t=δ_t/√(1+t²)，得 (δ′_t)²=−i£_σ 与 t 无关（p.36），从而每个多重态写成 δ′_tU=V、δ′_tV=−i£_σU 的 Cartan 型。注意 1+t²=0 ⇔ Ψ=∞（t=±i，§3），这就是重标在 t=±i 失效、须单独处理的原因。

第 5 步（与 (2.15) 的符号约定）。(2.15) 的 RHS 是 δ^X_Y Σ_μΓ^μ_{AȦ}P_μ，没有 i；把 P_μ=−i∂_μ 代入（欧氏约定下平移生成元 P_μ=−i∂_μ），{Q,Q}=2(⋯)P_μ 给出 Q²=−i(⋯)£_∂——**−i 正是 P_μ=−i∂_μ 带来的**，与 (3.42) 的 −i 一致。另一方面，p.18 的论证只用了「RHS 没有 Spin′(4)-不变算符」，它只证明 Q² 的**平移部分**为零；p.11 早已说明 (2.15) 的 RHS 在适当边界条件下会出现「additional terms」（与降维丢掉的六个动量及其磁对偶有关）。在 4d 扭化理论里这六个动量就是六个标量（中心荷）方向，扭化后它们贡献 ∝[σ,·] 的项——正是 (3.35)(3.36) 的 £_σ 部分。所以 (2.15) 与 (3.35)(3.36) 不矛盾：**(2.15) 管平移部分（为零），additional terms 管场依赖规范部分（∝σ）**。

第 6 步（报告的口径怎么修）。报告的错法是把两层口径理解为「平直 M 上严格、弯曲 M 上模规范变换」（v2 L17/L97 的写法）。正确修法：
1) 把 v1 L84 的「Q²=0（模规范变换）… (B p.18)」改成：「p.18 证明 Q² 的平移部分为零（(2.15) RHS 无 Spin′(4) 不变算符）；『modulo a gauge transformation』的准确出处是 p.25（`p026.txt:3–4`）」。
2) 把 v1 L126 的「这与 §2.3 说的『Q²=0 模规范变换』是同一件事的两层口径（我们的观察，B 级）」改成：「同一件事的两部分：平移部分=0（p.18）；场依赖规范部分=−i(u²+v²)£_σ（(3.35)(3.36)，p.31，对任意 M 都成立，与弯曲/平直无关）」。
3) 不要再说「平直 ℝ⁴ 严格、弯曲 M 模规范」（v2 L17/L97）：(3.35)(3.36) 正是从 (3.23)–(3.28) 这些与度规无关的变换规则算出来的，平直 ℝ⁴ 上同样有 σ 项。

### 2.4 数值/特例检验
- 附录 S3.1：δ_T² 在 A、φ、ψ、ψ̃ 上都得 −i(u²+v²)£_σ，σ 上得 0（True）；S3.2：(3.36) 全 True；S3.3：δ_t²=({'Dsigma': i t²+i}, …) 在 t=±i 代入得空集（严格 0）；S3.4：χ,H 的 (3.41)(3.42) 闭包 True（含 t=i）；S3.5：δ_t²≡0 ⇔ t²=−1。

```python
def tens(r1, r2):
    """SU(2)xSU(2) tensor product; labels are twice-spin (j,k), dim (j+1)(k+1)."""
    a, b = r1
    c, d = r2
    out = []
    for j in range(a + c, abs(a - c) - 1, -2):
        for k in range(b + d, abs(b - d) - 1, -2):
            out.append((j, k))

    return (r[0] + 1)*(r[1] + 1)
```

### C. 超荷代数检查器：δ_T²、δ_ℓ²、δ_r²、δ_t²（对应 §2）

```python
"""S3: twisted superalgebra -- (3.35), (3.36), (3.42); Q^2 = 0 only at t = +-i.
Rule set = (3.23)-(3.28) of the paper with supercharges Q = u Q_l + v Q_r.
Run:  python s3_superalgebra.py
"""
import sympy as sp

u, v, t = sp.symbols('u v t')
i = sp.I

# atom -> delta_T image, from (3.23)-(3.28):
#   A -> i u psi + i v psit ,  phi -> i v psi - i u psit ,  sigma -> 0
#   psi -> u Dsigma + v [phi,sigma] ,  psit -> v Dsigma - u [phi,sigma]
# derived with the Leibniz rules D(delta sigma)=0, delta(D sigma)=[delta A, sigma],
# delta[phi,sigma]=[delta phi,sigma]:
rules = {
    'A':             {'psi': i*u, 'psit': i*v},
    'phi':           {'psi': i*v, 'psit': -i*u},
    'sigma':         {},
    'psi':           {'Dsigma': u, 'c_phi_sigma': v},
    'psit':          {'Dsigma': v, 'c_phi_sigma': -u},
    'Dsigma':        {'c_psi_sigma': i*u, 'c_psit_sigma': i*v},
    'c_phi_sigma':   {'c_psi_sigma': i*v, 'c_psit_sigma': -i*u},
}

# L_sigma : the gauge transformation generated by sigma, with the paper's £_sigma(A) = -Dsigma
ell_rule = {'A': {'Dsigma': -1}, 'phi': {'c_phi_sigma': -1}, 'psi': {'c_psi_sigma': -1},
            'psit': {'c_psit_sigma': -1}, 'sigma': {}}
# note: the atom c_X_sigma is [X,sigma] (that is what the rules above produce), while
# L_sigma(X) = [sigma,X] = -[X,sigma]; hence the -1 signs for phi, psi, psit.

def apply_rule(E, rule):
    out = {}
    for atom, c in E.items():
        for a, c2 in rule.get(atom, {}).items():
            out[a] = out.get(a, 0) + c*c2
    return {a: sp.expand(c) for a, c in out.items() if sp.expand(c) != 0}

def same(E1, E2):
    return all(sp.expand(E1.get(k, 0) - E2.get(k, 0)) == 0 for k in set(E1) | set(E2))

def at(uu, vv):
    return {k: {a: sp.expand(c.subs({u: uu, v: vv})) for a, c in d.items()} for k, d in rules.items()}

fields = ['A', 'phi', 'psi', 'psit', 'sigma']

print("S3.1  delta_T^2 = -i(u^2+v^2) L_sigma   on K>=0 fields  (3.35):")
for f in fields:
    d2 = apply_rule(apply_rule({f: 1}, rules), rules)
    pred = {a: sp.expand(-i*(u**2 + v**2)*c) for a, c in apply_rule({f: 1}, ell_rule).items()}
    print("   ", f, ": delta^2 =", d2, "  ok:", same(d2, pred))

print("\nS3.2  decomposition in u,v  =>  (3.36):")
rl, rr = at(1, 0), at(0, 1)
for f in fields:
    dl2 = apply_rule(apply_rule({f: 1}, rl), rl)
    dr2 = apply_rule(apply_rule({f: 1}, rr), rr)
    cr = {a: sp.expand(apply_rule(apply_rule({f: 1}, rl), rr).get(a, 0) +
                       apply_rule(apply_rule({f: 1}, rr), rl).get(a, 0))
          for a in set(apply_rule(apply_rule({f: 1}, rl), rr)) | set(apply_rule(apply_rule({f: 1}, rr), rl))}
    ell = apply_rule({f: 1}, ell_rule)
    p = {a: sp.expand(-i*c) for a, c in ell.items()}
    print("   ", f, ": delta_l^2 ok:", same(dl2, p), "  delta_r^2 ok:", same(dr2, p),

rt = {k: {a: sp.expand(c.subs({u: 1, v: t})) for a, c in d.items()} for k, d in rules.items()}
```

### D. 根系、n_g、Table 1 与 4、9、√2、√3（对应 §4）

```python
"""S4: n_g = (long root / short root)^2 from root systems; Table 1 (G <-> ^L G);
'4' and '9' are n_g^2, sqrt(2) and sqrt(3) are the length ratios themselves.
Run:  python s4_ng_table1.py
"""
from fractions import Fraction
import sympy as sp
import math

def cartan(tp, n=None):
    """Cartan matrix A_ij = <alpha_i, alpha_j^vee> (Bourbaki). 'A2' -> ('A',2)."""
    if tp and tp[0] in 'ABCD' and tp[1:].isdigit():
        tp, n = tp[0], int(tp[1:])
    if tp == 'A1':
        tp, n = 'A', 1
    if tp == 'A':
        return [[2 if i == j else (-1 if abs(i - j) == 1 else 0) for j in range(n)] for i in range(n)]
    if tp == 'B':
        A = [[0]*n for _ in range(n)]
        for i in range(n):
            A[i][i] = 2
        for i in range(n - 1):
            A[i][i + 1] = -1
            A[i + 1][i] = -1
        A[n - 2][n - 1] = -2
        return A
    if tp == 'C':
        B = cartan('B', n)
        return [[B[j][i] for j in range(n)] for i in range(n)]
    if tp == 'D':
        if n == 2:
            return [[2, 0], [0, 2]]
        A = [[0]*n for _ in range(n)]
        for i in range(n):
            A[i][i] = 2
        for i in range(n - 2):
            A[i][i + 1] = -1
            A[i + 1][i] = -1
        A[n - 3][n - 1] = -1
        A[n - 1][n - 3] = -1
        return A
    if tp == 'G2':
        return [[2, -1], [-3, 2]]
    if tp == 'F4':
        return [[2, -1, 0, 0], [-1, 2, -2, 0], [0, -1, 2, -1], [0, 0, -1, 2]]
    if tp == 'E8':
        A = [[2 if i == j else 0 for j in range(8)] for i in range(8)]
        for i in range(6):
            A[i][i + 1] = -1
            A[i + 1][i] = -1
        A[4][7] = -1
        A[7][4] = -1
        return A
    raise ValueError(tp)

def diag_gram(A):
    """d_i = (alpha_i,alpha_i) from A_ij d_j = A_ji d_i ; Gram G_ij = A_ij d_j / 2."""
    n = len(A)
    d = [None]*n
    d[0] = Fraction(1)
    for _ in range(n*n):
        changed = False
        for i in range(n):
            if d[i] is None:
                continue
            for j in range(n):
                if i != j and A[i][j] != 0 and d[j] is None:
                    d[j] = d[i]*Fraction(A[j][i], A[i][j])
                    changed = True
        if not changed:
            break
    for i in range(n):
        if d[i] is None:
            d[i] = Fraction(1)   # disconnected component (e.g. D_2 = A_1 x A_1): normalize it
    G = [[Fraction(A[i][j]*d[j], 2) for j in range(n)] for i in range(n)]
    assert all(G[i][j] == G[j][i] for i in range(n) for j in range(n))
    return d, G

def roots(A):
    n = len(A)
    start = [tuple(1 if k == i else 0 for k in range(n)) for i in range(n)]
    seen = set(start)
    stack = list(start)
    while stack:
        b = stack.pop()
        for i in range(n):
            c = sum(b[k]*A[k][i] for k in range(n))
            nb = tuple(b[k] - (c if k == i else 0) for k in range(n))
            if nb not in seen:
                seen.add(nb)
                stack.append(nb)
    return seen

def len2(b, G):
    n = len(b)
    return sum(b[i]*b[j]*G[i][j] for i in range(n) for j in range(n))

    det = int(sp.Matrix(A).det())
    return A, d, G, R, L, ng, det
```
