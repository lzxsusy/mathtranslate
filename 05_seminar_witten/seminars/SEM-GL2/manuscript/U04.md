# U04 讲义：K–W 2006 §5（pp.56–78）——二维拓扑场论、广义复几何与 S-对偶 = 镜像对称

## 一、本讲一句话

§5 把四维 N=4 扭化理论在 Σ×C 上约化出来的二维拓扑场论族 CP1_g，认成 Hitchin 系统二维 sigma-模型族 CP1_h×CP1_h 的一个子族；翻译表是 (5.11) (w₊,w₋)=(−t,t⁻¹)，而 S-对偶在这套参数上就是 Ψ ↦ −1/(n_gΨ)。于是四维的 S-对偶在二维读作镜像对称：B_J(M_H(G)) ≅ A_K(M_H(^LG))，复合 𝒥:φ→iφ 后得到 J 下互为镜像的两个 Hitchin 系统 (B p.70)。

这一讲的所有技术细节，都服务于这一句话。

## 二、三个必答问题

**问题一：为什么 §5 非要把四维族放进二维族里？** 因为「S-对偶 = 镜像」这句话只能在二维 sigma-模型的参数空间里被陈述。四维一侧只有族 CP1_g（(5.21)(5.22) 的 S 作用），二维一侧才有复结构参数 (w₊,w₋)、(5.5)(5.6) 的全纯方程与 B-/A-模型之分。§5.1 的全部工作就是造桥：把 (5.1)(5.2) 扭化后的超对称条件降到二维，得 (5.5)(5.6)，再把 (5.8) 阿贝尔化、按二形式的自对偶性拆成 (5.9)(5.10)，逐项比对出 (5.11)。桥一旦造成，t=±i 与 t 实就分别落到 B-模型与 A-模型（B p.61）。若停在四维，S 作用只是 τ 与 t 的 SL(2,ℤ) 变换，没有「镜像」可言。

**问题二：Ψ 是什么，为什么只有一个？** §5.2 用广义复几何把每个 t≠±i 的模型写成「带 B 场的 A-模型」：(5.31) ℐ_t=M(B₀)ℐ_{ω₀}M(B₀)⁻¹，其中 ω₀、B₀ 由 (5.32) 显式给出。A-模型只依赖复化 Kähler 类 [B₀+iω₀]，而 (5.33) 把这个类算成 −iImτ[(t−t⁻¹)/(t+t⁻¹)][ω_I]，再用 4d θ 角的 B′=−Reτ ω_I（(4.19)）并进去，整条类就是 −[ω_I]·Ψ，其中 Ψ=Reτ+iImτ(t−t⁻¹)/(t+t⁻¹) (5.34) (B p.68)。所以 t 与 τ 不是两个独立耦合：理论只通过 Ψ 一个复数看到它们。Ψ 是模型在族里的身份标签，不是可独立调节的耦合常数。

**问题三：为什么 B-/A-模型的分界恰好是 t=±i 与 t 实？** 这不是坐标卡的偶然，而是复结构的相等/相反条件。(5.5) 与 (5.6) 分别用 J₊ 与 J₋；B-模型要求两者相同 J₊=J₋，即 w₊=w₋，由 t⁻¹=−t 得 t=±i；A-模型要求两者相反、只依赖辛形式，即 w₋=−1/w₊，由 t⁻¹=1/t̄ 得 t 实，其中 t=±1 给复结构 K/−K，t=0,∞ 给 I/−I (B p.61)。分界由模型定义决定，不是由参数化奇点决定——这正是后面区分 t=±i 与 t=±1 的根据。

## 四、五步推导主线

**第一步（§5.1 前段，B pp.56–59）：扭化与二维约化。** 从 (5.1)(5.2) 出发，一般四维流形 M 上 φ₀–φ₃ 被扭成一形式 φ、φ₄ 与 φ₅ 保持标量；降到 ℝ⁴×C 后只剩 φ₀、φ₁、φ₄、φ₅，用 (5.3) 与 (5.4) 把 8 个超荷配成 (2,1)₋⊕(1,2)₊，得二维超对称的 (4,4) 结构。取 Σ 半径远大于 C，丢掉 T*Σ 分量，(5.5)(5.6) 就是二维 sigma-模型的全纯方程。

**第二步（B pp.60–62）：主定理的成立。** (5.8) 给出 (A,φ) 的一阶方程；二形式按自对偶/反自对偶拆开，(5.9) 来自 dȳ∧dz̄（自对偶，(0,2) 型），(5.10) 来自 dy∧dz̄（反自对偶，primitive (1,1) 型）。把两式与 (5.5)(5.6) 逐项比对得 (5.11)。再判模型类型：B 要 w₊=w₋ 得 t=±i；A 要 w₋=−1/w₊ 得 t 实。注意源文本层把两处二形式的下标与横线丢了，两式在文本里长得一样，必须按页图核。

**第三步（B pp.63–64）：整个四维族而不是两点。** 把 (5.13)–(5.18) 的扭化推广到一般 (α,β) 组合，得两独立参数 (5.20) 与全族 CP1_h×CP1_h；S 的作用由 (5.21)(5.22) 给出。(0,0) 的 B-模型不在四维族 CP1_g 内，但可微扰逼近族中任意点（q=α/β 可调）；(0,0) 与 (0,∞) 在 S 下不变。

**第四步（§5.2，B pp.65–69）：广义复几何连续化。** 对每个 t≠±i，用 (5.27) 造出拼装广义复结构，代入 (5.7)(5.11) 化简成 (5.30)：只含 J、ω_I、ω_K，故不依赖 C 的复结构或度量。再用 (5.31)(5.32) 写成 A-模型的 B 场变换，(5.33) 给出复化 Kähler 类，(5.34) 得 Ψ；t=±i 是例外，此时 Ψ=∞ 且与 τ 无关，模型是 B-模型 ±J。

**第五步（§5.3，B pp.70–71）：S 的二维像与镜像。** (5.35) 的 S 在 Ψ 上按 Möbius 作用 Ψ↦−1/(n_gΨ)，交换 Ψ=0 与 Ψ=∞。取 t=i 得 (−i,−i)=J_B；S 给 t′=1、(−1,1)=K_A；故 B_J(M_H(G))≅A_K(M_H(^LG))。复合 𝒥:φ→iφ（(4.7) U₁ 的 λ=i）把 K 转回 J，得 J 下的镜像对，但 𝒥「not quite natural」、把人移出 CP1_g，所以这一步比族内结论弱 (B pp.70–71)。

**延伸（§5.4–5.6，B pp.71–78）：为什么可信、它意味着什么。** §5.4 在 Hitchin 底空间与纤维上分别论证：S 在底空间 B 上经典作用（2d 的 graded ring R(G)≅R(^LG)，4d 的 half-BPS 算符 D_n，B pp.72–74），纤维上发生 T-对偶。§5.5 从零膜出发：零膜 B_p 是 (B,B,B)，S 后变成 (B,A,A) 的 B̃_p，支撑是纤维 F̃=Ξ(F)，模空间是平坦 unitary 秩 1 丛，得 F≅ĴF̃ (B pp.74–77)。§5.6 给出四类膜 (B,B,B)(B,A,A)(A,B,A)(A,A,B) 与 S 的作用（表 2，B p.71；B pp.77–78）。

## 五、三个易错点

**易错点一：t=±i 与 t=±1 不是同一类例外。** t=±1 是 (5.32) 的 0/0 可去奇点，极限 ω₀→∓Imτ ω_K、B₀→0，仍是 A-模型；t=±i 是 (5.31)(5.32) 的真极点，原文明说此时 Ψ 的分析失效，模型是复结构 ±J 的 B-模型，且 Ψ=∞ 与 τ 无关 (B pp.68–69)。判 t=±i 必须退回 (5.30) 直接读 diag(J,−Jᵗ)，不能套 (5.31)(5.32)。

**易错点二：S 对 Ψ 是 Möbius，不是乘子。** 原文说 S「maps Ψ → −1/n_gΨ and hence exchanges Ψ = 0 and Ψ = ∞」(B p.70)。若写成 −(1/n_g)Ψ，0 与 ∞ 都成了不动点，与原文矛盾；乘子形式也解释不了表 2 的 J_B→K_A 行。另注意 n_g=1 的条件是 G simply-laced（单链 A-D-E），不是单连通；G₂ 单连通但非 simply-laced，SU(n)/ℤ_m 非单连通却 simply-laced。

**易错点三：belief 不能当定理，C/D 不能裁 B。** §5.2 明写「It is believed that, in general, each of these topological field theories is determined by one of the two generalized complex structures and independent of the second.」(B p.66)，并说完整证明 unknown (B p.67)；A-模型只依赖 [B+iω] 但 B 有 (2,0)⊕(0,2) 分量一点原文自认「may require some clarification」(B p.69)。引用 Witten 2008 (C) 或 Frenkel 2009 (D) 时只能作重述与使用方的旁证，不能反过来充当 B 的证据；§6 开篇对膜的提及只是预告 (B p.78)，正式建立要等 §6.4 与 §11–12。

## 六、与 U03、U05 的接口

**从 U03 接过来：** (4.6) 的复结构族 I_w、(4.7) 的 U₁（λ=i 即 𝒥）、(4.15) 的 Imτ、(4.19) 的 B′=−Reτ ω_I、(4.25)(4.26) 的 Hitchin 哈密顿量与可积性、以及 (4.1) 的 Hitchin 方程与 (4.11) 的三矩映射。§5 用 I_w 写 (5.7)、用 U₁ 定义 𝒥、用 Imτ 与 B′ 把 (5.34) 的 Ψ 拼出来；没有 U03 的 (4.25)(4.26)，§5.4 的 H_{P,α} (5.37) 就无从解释。

**交给 U05 的：** 表 2 (B p.71)、§5.6 的四类膜 (B pp.77–78)、零膜到纤维膜的对应 F≅ĴF̃ (B p.76)、以及主结论 B_J(M_H(G))≅A_K(M_H(^LG)) (B p.70)。U05 起要把这些读成几何 Langlands 里的 eigenbrane 与线算子：B 侧的 F≅ĴF̃ 有膜论证，D 侧的 (5.2) 仍是「we therefore expect」(D p.18)，桥尚未严格化——这两条要分开引用。

**边界与留白：** G 的中心与基本群讨论在 §7；C 上 spin 结构的角色只提了 [26]；B 的 (2,0)⊕(0,2) 分量问题留在 B p.69；(A,B,A)/(A,A,B) 的 coisotropic 例子要到 §11；「二维族不依赖 C 复结构」的严格证明不属于本文，见 KW 2007（C p.5）。
