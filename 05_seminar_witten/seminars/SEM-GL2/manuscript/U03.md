# U03 讲稿：Kapustin–Witten §4 —— Hitchin 模空间的经典几何

## ① 本轮一句话目标

用一句话说：**§4 要把四维扭化 𝒩=4 超杨–米尔斯理论在 M=Σ×C 上约化后出现的靶空间 M_H 讲清楚**——它是 Hitchin 方程 (4.1) 的解模规范群，是无穷维仿射空间 W 的超凯勒商，是复结构 I 下的稳定 Hitchin 对模空间、J 下的稳定同态模空间，最后是一个以 Hitchin 纤维化为骨架的完全可积系统 (B p.38; B p.46; B p.49; B p.51; B p.54)。

先把边界钉死：§4 从印刷 p.38 开始（标题在 p.38 页首），到 p.56 结束；§4.1 是 p.40–p.48，§4.2 是 p.49–p.51，§4.3 是 p.52–p.56 (B p.39; B p.49; B p.52; B p.56)。§4 开篇明说约化结论 follows from our results in section 3.4，玻色作用量被写成平方和 (3.47)(3.48)，所以这一节的任务不是「再证一遍约化」，而是**在已经相信约化的前提下认识靶空间**：它为什么是复流形、奇点从哪来、为什么维数是 (2g−2)dim G (B p.38; B p.39)。

一句话目标里还要去掉一个诱惑：§4 并不证明 S-对偶=镜像对称。§4 全节（pp.38–56）没有 T-dual、SYZ、mirror 这些词，镜像对首次出现在 §5.3 (B p.70)，SYZ 图像在 §5.5 (B p.77)，都属于下一轮 U04。本轮读到的「终点」只是：纤维是对 Ω_I（等价地 ω_J、ω_K）Lagrange 的紧复环面 (B p.56)。

## ② 读前预备：三个必须先懂的概念

**预备 1：超凯勒结构。** 一个流形带三个复结构 I、J、K，满足四元数关系 IJ=−JI=K（及循环置换），并且同一个度量对三个复结构都是 (1,1) 型。于是有三个 Kähler 形式 ω_I、ω_J、ω_K，以及三个全纯辛形式 Ω_I=ω_J+iω_K、Ω_J=ω_K+iω_I、Ω_K=ω_I+iω_J (4.8)(4.9) (B p.44)。要记住的不是公式本身，而是「同一个实流形、三套全纯描述」——§4.2 的全部内容都建立在这句话上。

**预备 2：超凯勒商。** 若李群 H 保超凯勒流形 X 的度量与三个辛形式，就有三个矩映射 μ_I、μ_J、μ_K；它们的公共零点集模掉 H，得到超凯勒商 X///H，仍超凯勒。§4.1 要证的正是 M_H=W///G：W 是全体 (A,φ) 构成的仿射空间，规范群的作用 manifestly preserves 度量 (4.2) 与三个辛形式 (4.8) (B p.45; B p.46)。

**预备 3：Hitchin 方程与 Hitchin 对。** Hitchin 方程是 (4.1)：F−φ∧φ=0，Dφ=D*φ=0，其中 φ 是 C 上取值在 ad E 里的 (1,0) 形式、A 是 E 上的酉联络 (B p.39)。在复结构 I 下看，复方程 ν_I=μ_J+iμ_K=0 等价于 D̄φ=0，于是 φ 给出 ϕ=φ_z dz ∈ H⁰(C,K_C⊗ad E)，(E,ϕ) 称为 Hitchin pair 或 Higgs bundle (B p.49)。J 下看则是另一套：𝒜=A+iφ 平坦，给 π₁(C) 到 G_ℂ 的同态 (B p.51)。同一个方程，两套全纯语言，这就是 §4.2 的骨架。

## ③ 主线：§4.1–§4.3 三段

### §4.1 M_H 作为超凯勒商：超凯勒结构从哪来

**要解决什么。** M_H 原本只是「Hitchin 方程的解模规范群」，是一个由方程定义的集合。要把它当几何对象用，必须先回答：它为什么是复流形？度规、复结构、辛形式从哪来？(B p.40)

**关键一步。** 先在 W（所有 (A,φ) 的仿射空间）上写平直度量 (4.2)，它把 A 与 φ 的变分按 Tr 配对；再在 W 的余切空间上定义三个**平移不变**的复结构 (4.3)–(4.5)：I 让 A_z̄、φ_z 全纯；J 让 A_z̄+iφ_z̄ 与 A_z+iφ_z 全纯（等价地让 𝒜=A+iφ 全纯）；K 让 A_z̄−φ_z̄ 与 A_z+φ_z 全纯 (B p.41; B p.42)。然后用一个短计算验证 I^tJ^t=−J^tI^t=−K^t，转置即 IJ=−JI=K，并验证 ds² 对三个复结构都是 (1,1) 型，于是「we have obtained a flat hyper-Kahler structure on W」(B p.42)。

第二步才是商：规范群的作用保持 (4.2) 与 (4.8) (B p.45)；三个矩映射由 (4.8) 短算得到 (4.11)，Hitchin 方程 (4.1) 恰好等价于 μ_I=μ_J=μ_K=0 (B p.46)。所以 M_H=W///G 是超凯勒商，超凯勒结构由 W 继承 (B p.46)。物理上这不是巧合：二维 (4,4) 规范理论里超多重态的参数空间就是超凯勒流形，低能靶是 X///H；四维扭化理论紧化到二维落进同一个模子 (B p.46)。

**结论。** M_H 是超凯勒流形；它的超凯勒结构是从 W 的平直结构继承来的；Hitchin 方程与三矩映射零点等价。沿路还得到 ℂP¹_h 族 I_w（w=0→I，1→K，−i→J，∞→−I）与 U₁ 作用 φ_z→λφ_z、φ_z̄→λ⁻¹φ_z̄（I_w→I_{λ⁻¹w}）(4.6)(4.7) (B p.43)；族里只有 J 与 −J 不依赖 C 的复结构 (B p.43)。以及 (4.12)(4.13)(4.15)(4.19)：四维动能=二维 σ-模型动能，ds²_g=(4π/e²)ds²=(Im τ)ds²，θ 项对应 B=−(θ/2π)ω_I=−(Re τ)ω_I (B p.46; B p.47; B p.48)。

### §4.2 M_H 的复结构：I 下是 Hitchin 对，J 下是平坦丛

**要解决什么。** 同一个实流形 M_H 带三个复结构，那它在每个复结构下参数化什么全纯对象？稳定性怎么定？(B p.49)

**关键一步。** 先看 I。组合 ν_I=μ_J+iμ_K 在 I 下全纯，因为它是 Ω_I 给出的矩映射，而 Ω_I=ω_J+iω_K 是 I 的 (2,0) 形式 (B p.49; B p.44)。ν_I 的具体形式是 ν_I=−(1/π)∫|d²z|Tr εD_z̄φ_z (4.20)，令它为零即 D̄φ=0，于是 (E,ϕ) 是 Hitchin pair；M_H 在 I 下就是稳定 Hitchin pairs 的模空间（严格半稳定另加等价关系），这是引 [20] 的定理 (B p.49; B p.50)。SU(2) 时稳定判据很具体：ϕ 不变的线丛 L 满足 c₁(L)<0 为稳定、≤0 为半稳定 (B p.50)。

再看 J。ν_J=μ_K+iμ_I=−(i/2π)∫Tr εF (4.21)，令它为零等价于 𝒜=A+iφ 平坦，于是得 Y₀=Hom(π₁(C),G_ℂ)/共轭 (B p.51)。J 下的稳定性不是「不稳定表示」那套：原文说 in complex structure J, there is no notion of an unstable representation；稳定条件写成单值不能同时三角化（SU(2) 时即 [[α,β],[0,α⁻¹]] 这种形状，4.22）(B p.51)。Corlette–Donaldson 定理把两边接起来：M_H 在 J 下是稳定同态模空间 Y 加半稳定等价类 (B p.51)。一般 I_w（w≠0,∞）的全纯变量是 A_z̄−wφ_z̄ 与 A_z+w⁻¹φ_z，全纯条件等价于相应复联络平坦，所以这些复结构下的描述都等价于 Y (B p.52)。

**结论。** I 下 M_H=稳定 Hitchin pairs 模空间；J 下 M_H=稳定同态模空间 Y；两者作为实流形同构，但作为复流形不同构（D p.15 明说 non-abelian Hodge theory 只给实流形层面的同构）。注意这不是三个模空间，而是同一个 M_H 的三套复结构——这是本轮最容易读错的一处。

### §4.3 Hitchin 纤维化：完全可积与 Lagrange 纤维

**要解决什么。** M_H 除了超凯勒结构，还有什么整体结构？它和规范理论那边的模空间 M 什么关系？为什么叫「完全可积系统」？(B p.52)

**关键一步。** 先把 M 放进 M_H：令 φ=0 得 (E,0)，M 是 M_H 的 I-全纯子流形，在 J、K 下不 holomorphic 而是 Lagrange (B p.52)。再把 T*M 嵌进来（切空间用 H¹ 与 Serre 对偶配对），并验证 Ω_I 在 T*M 上限制为 Σdp_α∧dq^α (B p.52; B p.53)。然后定义 Hitchin map：SU(2) 时 π(E,ϕ)=Trϕ² ∈ H⁰(C,K²)；一般 G 用次数 d_i 的 Casimir 多项式，(4.24) Σ(2d_i−1)=dim G，B=⊕H⁰(C,K^{d_i}) (B p.53)。维数账给出 dim B=(g−1)dim G=½dim M_H=dim F (4.25) (B p.54)；满射性有一个漂亮的定性说明：3g−3 个二次方程对 3g−3 个变量，generic 有 2^{3g−3} 个解 (B p.54)。完全可积性靠 ½dim M_H 个函数 H_a=∫_C α_a∧Trϕ² (4.26)：它们在 I 下全纯、代数独立、对 Ω_I 的 Poisson 括号两两交换，故 H_a 的流给出复环面作用 (B p.54; B p.55)。

**结论。** M_H 是复结构 I 下的完全可积 Hamilton 系统；generic 纤维是复环面，且因纤维紧、由 ½dim M_H 个 H_k−h_k=0 定义、Ω_I 各向同性而维数对半，纤维是 Lagrange 子流形——原文同时给出等价说法：对 Ω_I，或对 ω_J 与 ω_K (B p.55; B p.56)。§4.3 到此为止，没有再往下走：T-对偶与镜像在 §5.3 才出现 (B p.70)。

## ④ 三处最容易卡的地方

**卡点 1：把三个矩映射当成「相加相减」去对 Hitchin 方程。** 诊断：μ_J 与 μ_K 的被积式看起来就是 Dφ 的 z、z̄ 分量组合，很容易想成「相加得 D*φ、相减得 Dφ」。出路：先数独立实条件。(4.1) 是三条实方程；μ_I 的被积式就是 F−φ∧φ，故 μ_I=0 即第一条；μ_J 的被积式是 D_zφ_z̄+D_z̄φ_z，μ_J=0 单独就是 D*φ=0；μ_K 的被积式是 i(D_zφ_z̄−D_z̄φ_z)，μ_K=0 单独就是 Dφ=0——三条一一对应，无需组合 (B p.46 eq 4.11)。相加相减得到的是 2D_zφ_z̄ 与 2D_z̄φ_z，那是复方程 D̄φ=0 的实部与虚部，属于复矩 ν_I=μ_J+iμ_K (4.20) 的内容，不是 (4.1) 的实方程 (B p.49)。

**卡点 2：把 ω_J+iω_K 当成 J 的 (2,0) 形式。** 诊断：Ω_I=ω_J+iω_K 里出现下标 J，就顺手把它配给 J。出路：Ω 的配方是循环轮换的 (4.9)：Ω_I=ω_J+iω_K、Ω_J=ω_K+iω_I、Ω_K=ω_I+iω_J；判断 (2,0) 型看的是相对哪个复结构，原文直接说 Ω_I 是 I 下的 (2,0) 形式，Ω_J、Ω_K 相对各自复结构同理 (B p.44)。另一个独立内证是 (4.20)：ν_I=μ_J+iμ_K 在 I 下全纯，正因为它来自 I 的 (2,0) 形式 Ω_I (B p.49)。顺带记住三层依赖不是同一批对象：复结构层只有 J 与 −J 不依赖 C；Kähler 形式层 ω_J 依赖而 ω_I、ω_K 不依赖；全纯 (2,0) 形式层 Ω_I、Ω_K 依赖而 Ω_J 不依赖 (B p.43; B p.44)。

**卡点 3：把 §4.3 读出 T-对偶/镜像对称。** 诊断：纤维是紧复环面又 Lagrange，太像 SYZ 的舞台，于是把「§4 备好全部对偶前提」写进报告。出路：§4 全节没有 T-dual、SYZ、mirror 字样；B 到 p.56 只给单侧（G 侧）几何，连 special Lagrangian 都没出现；镜像对首次在 B p.70，SYZ 在 B p.77，都属 §5 (B p.70; B p.77)。对偶侧需要的 ^L B≅B、两纤维化同底、^L F_b 与 F_b 逐纤维对偶，出自 D p.16，而 D 自己注明这是 Hausel–Thaddeus 2002 的结果，晚于 B；C p.4 也只说 believed 的 T-duality。把这一侧读成 §4.3 的前提，就是把 2008/2009 年的综述结论倒灌回 2006 年的原文，最多只能标 (C) 级事后补足 (D p.16; C p.4)。

## ⑤ 与前后轮的接口

**U02 给了什么。** 本轮反复用到 §3 的成果：(3.47)(3.48) 的平方和是「约化结论」的来源 (B p.38)；族参数 t、τ=θ/2π+4πi/e² 与 §3.5 的 canonical parameter Ψ 是三套互不相等的参数，本轮只通过 (4.15)(4.19) 用到它们与度规、θ 项的关系 (B p.47; B p.48)。U02 还给了扭化理论的整体框架（4d TFT 族），没有它，§4.1 的「二维 (4,4) 规范理论给出超凯勒商」就接不上 (B p.46)。

**U04 要用什么。** U04 进入 §5：§5.3 说 M_H(G,C) 与 M_H(^L G,C) 在复结构 J 下是 mirror pair (B p.70)，§5.5 说 SYZ 图像 (B p.77)。届时会用到本轮的三样东西：一是 Hitchin 纤维化与「两纤维化同底」的底空间（^L B≅B，D p.16）；二是纤维是复环面、对 Ω_I Lagrange 这一事实（C p.4 进一步说 A-模型下是 special Lagrangian 环面）；三是 J 与 Ω_J 不依赖 C 的复结构，这正是镜像叙述里「复结构 J 那一侧」稳定的原因 (B p.43; C p.3)。另外 U04 会读到 D p.15–p.17 的 S-对偶↔镜像与逐纤维 T-对偶、以及 D p.17 对 M_H 非紧的警告——本轮先记住：紧的是纤维，不是 M_H (B p.56; D p.17)。

## ⑥ 自测五问（答案要点）

**1. 写出 I、J、K 的全纯变量，并说明 W 为什么是平坦超凯勒流形。** I：A_z̄、φ_z；J：A_z̄+iφ_z̄ 与 A_z+iφ_z，即 𝒜=A+iφ 全纯；K：A_z̄−φ_z̄ 与 A_z+φ_z (B p.42)。四元数关系由 I^tJ^t=−J^tI^t=−K^t 转置得到；ds² 对三个复结构均为 (1,1) 型，W 是仿射空间、复结构平移不变，故平坦 (B p.42)。

**2. 为什么三个矩映射与 (4.1) 的三条实方程一一对应？μ_J+iμ_K 给出什么？** μ_I=0 即 F−φ∧φ=0；μ_J=0 即 D_zφ_z̄+D_z̄φ_z=0，也就是 D*φ=0；μ_K=0 即 D_zφ_z̄−D_z̄φ_z=0，也就是 Dφ=0 (B p.46 eq 4.11)。组合得 ν_I=μ_J+iμ_K=−(1/π)∫|d²z|Tr εD_z̄φ_z (4.20)，在 I 下全纯，零点等价于 D̄φ=0 (B p.49)。

**3. 「依赖 C 的复结构」这句话在哪三个层面成立、各有哪些例外？** 复结构层：只有 J 与 −J 不依赖 C；Kähler 形式层：ω_J 依赖，ω_I、ω_K 不依赖；全纯 (2,0) 形式层：Ω_I、Ω_K 依赖，Ω_J 不依赖 (B p.43; B p.44)。三层例外不是同一批对象，答题时必须分开说。

**4. dim B 与完全可积性怎么来的？** dim B=(g−1)dim G=½dim M_H=dim F (4.25) (B p.54)；满射性由 3g−3 个二次方程对 3g−3 个变量的定性论证支持 (B p.54)；完全可积靠 ½dim M_H 个 I-全纯、代数独立、Poisson 交换的 H_a=∫_C α_a∧Trϕ² (4.26)，其流在 generic 纤维上是复环面 (B p.54; B p.55)。

**5. §4.3 证明 T-对偶/镜像对称了吗？** 没有。§4.3 只证到：π:M_H→B 满射、纤维紧且是复环面、纤维对 Ω_I（等价 ω_J、ω_K）Lagrange (B p.54; B p.56)。镜像对首次出现在 §5.3 (B p.70)，SYZ 在 §5.5 (B p.77)；对偶侧几何前提出自 D p.16，且 D 注明为 Hausel–Thaddeus 2002 的结果 (D p.16)；C p.4 的 T-duality 是 believed 口径。
