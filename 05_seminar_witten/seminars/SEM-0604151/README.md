## 一句话结论

Kapustin–Witten (2006) 做的事情可以压成一句话：**四维 N=4 超杨–米尔斯理论的 S-对偶，
在手性扭化并紧化到 Riemann 面之后，恰好变成 Hitchin 模空间上二维 sigma 模型的镜像对称；
而这条对应正是几何 Langlands 纲领的物理化身。**

它不是一个证明，而是一张**翻译表**：
| 四维物理 | 二维几何 | 代数几何 |
|---|---|---|
| 规范群 G 与 ^L G 的 S-对偶 | π₁(C) 上的镜像对称 | 朗兰兹对偶 |
| 线算子（Wilson / 't Hooft） | 膜上的算子 | Hecke 算子 |
| 特征膜（eigenbrane） | 本征对象 | Hecke 特征层 |
| 典范余各向同性 A-膜 | 开弦 BRST | D-模 |
