# 语料规范（M 线）v1.0

本工程的双产物之一：把"解经过程"本身做成可训练语料。语料**不是**原文翻译对齐语料，而是
**推理链语料**：每一步都记录"问题 → 想法 → 技术手段 → 结论 → 依赖 → 失败模式"。

目录：`derivation/`。全部 UTF-8，每行一个 JSON 对象（JSONL），字段名固定。
**禁止**写入本机绝对路径、原文长段落、原文页图；引用原文只用 ≤200 字短引。

---

## 1. `derivation/skeleton.jsonl` — 论证骨架推导链（80–120 条）

```json
{
  "id": "KW06-S001",
  "node": "S2",
  "section": "§3.1",
  "step": 1,
  "title": "为什么要扭化",
  "question": "在 N=4 上直接找拓扑不变量为什么不行？",
  "idea": "需要一个标量超荷 Q 满足 Q^2=0，才能定义 BRST 型上同调；N=4 原始的超荷都是旋量，没有标量分支。",
  "technique": "把 R-对称群的一部分嵌进时空旋转群（twisting），重排超荷的表示，使某个分量变成标量。",
  "claim": "扭化后存在一个标量超荷，其上同调给出 4d TFT 的观测量代数。",
  "anchor": "src p.16",
  "provenance": "A",
  "depends_on": ["S1"],
  "why_it_matters": "没有这一步，后面所有'拓扑算子'都无从定义，Hecke 算子的作用也无法与拓扑无关性共存。",
  "failure_mode": "若直接取原始 N=4 的超荷做上同调，会得到非拓扑的量，依赖于度规。",
  "next": "S3"
}
```

字段要求：
- `id`：`KW06-S###` 顺序编号；`node`：与 `10_layer0.tex` 的节点编号一致（S1–S7 主链，N1–N12 章节节点）。
- `provenance`：`A` 原文明确 / `B` 原文暗示我们重建 / `C` 我们的判断。B、C 必须在 `idea` 或 `claim` 中写"我们重建/我们判断"的依据。
- `anchor`：`src p.N` 或 `eq x.y` 或 `§x.y`；必须真实存在。
- `failure_mode`：这条推理如果走错会怎样（负样本价值）。凡能想到就给，尽量 ≥60% 条目有。

## 3. `derivation/concepts.jsonl` — 概念图（60–80 个节点）

```json
{"id":"C01","name_zh":"希格斯丛","name_en":"Higgs bundle","kind":"几何对象|物理对象|代数结构|范畴/层|算子|参数",
 "first_section":"§4.1","anchor":"src p.39",
 "definition_our":"……（我们自己的话，≤200 字，禁止抄原文定义）",
 "why_needed":"没有它，T-对偶的'底空间'就不存在……",
 "physical_reading":"……","math_reading":"……",
 "nlab":"https://ncatlab.org/nlab/show/Higgs+bundle",
 "stacks":"（可选）https://stacks.math.columbia.edu/tag/...",
 "edges":[{"to":"C02","type":"depends_on"},{"to":"C07","type":"dual_to"}]}
```

边的类型只允许：`depends_on`、`dual_to`、`specializes_to`、`generalizes`、`equivalent_to`、
`acts_on`、`categorifies`、`deforms_to`、`obstruction_to`。每条边在 `edges` 里只写一次（无向关系的方向约定：
`depends_on` 从依赖者指向被依赖者）。
