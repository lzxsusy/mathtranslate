# 符号与风格卡 v1.0

## 一、排印规则

1. 中文正文用全角标点；数学公式内标点用半角。
2. 英文术语首次出现：`\term{Higgs bundle}{希格斯丛}`，之后用中文或英文均可，但同一文件内保持一致。
3. 人名：首现有原文（Kapustin、Witten、Hitchin、Beilinson、Drinfeld、Frenkel、Gaiotto、Atiyah、GNO），之后可只写姓。
4. 方程编号交给 `equation` 环境自动编号；正文引用写 `式~\eqref{eq:xxx}`，请给每个要引用的公式打 `\label{}`。
5. 章节引用写 `§9.2`（用 `\S` 命令，不要写 § 字符，ctex 下 `\S` 正常）。
6. 图表标题：`\caption{}`，图用 `tikzpicture` 自绘，禁止引用原 PDF 页图。
7. 不写"我们认为这篇文章很重要"这类空话；每一段都要有新信息。

| $C$ | 紧致 Riemann 面，亏格 $g$ |

| $\MC$ | $C$ 上全纯 $G$-主丛的模空间（原文记号） |
| $\mathcal{M}_{\mathrm{Dol}}$ / $\mathcal{M}_{\mathrm{dR}}$ | （若用到）Dolbeault / de Rham 模空间 |
| $\tau$ | 复规范耦合 $\tau=\dfrac{\theta}{2\pi}+\dfrac{4\pi\ii}{g_{\mathrm{YM}}^2}$ |
| $t$, $\Psi$ | 扭化参数与 canonical parameter（首次出现按原文定义，见 §3.5） |

**新增符号**：在你文件的 `\subsection{符号约定}`（文件开头第一小节，可写 `\subsection*`）里列出，格式 `$x$ — 含义 — 出处锚点`。不要占用上表符号。

## 三、写作风格（很重要）

1. **结论先行**：每小节第一段就告诉读者"这一节要拿到什么、为什么需要它"，不要悬念式铺陈。
2. **讲必要性，不讲史实**：不写"1991 年某某提出"，只写"因为没有 X，Y 就做不到，所以必须引入 X"。
3. **区分三种语气**，与 provenance 对应：
   - A：陈述句，"原文在 §3.1 给出……"（附锚点）
   - B：建构句，"要得到这一族理论，最省力的重建是……"
   - C：判断句，"我们判断作者在此处有意采用 Y 约定，理由是……"
4. **遇到概念卡壳**，除了给出定义，必须补三件事：① 为什么需要它；② 一个最小例子；③ 它和上一个概念怎么接上。
5. **禁止**：大段历史、人物轶事、空泛评价、"众所周知"、"不言而喻"（要写清怎么显然的）。
6. **术语一致性**：按术语表统一（见 `40_layer3_terms.tex`，写作时若未生成，用本文第二节 + 原文用词）。
7. 每节结尾鼓励一句"读到这里的自检问题"（1–3 条），用 `enumerate` 列出。
