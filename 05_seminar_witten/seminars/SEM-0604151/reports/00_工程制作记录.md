# 工程制作记录：K–W 2006 分层解经本

本文件记录这本 207 页解经本的**生产过程**，供复核与复用。它回答三个问题：谁做了什么、
怎么验证的、怎么从零复现。

- 底本：A. Kapustin, E. Witten, *Electric–Magnetic Duality And The Geometric Langlands
  Program*, arXiv:hep-th/0604151，231 页，12 节，146 条参考文献（CINT 第 1 卷 (2007) No.1）。
- 产物：`deliverables/WIT-0604151-EMDGL_exegesis.pdf`，v1.0（2026-11-15），207 页。
- 规模：约 51 万字符；1262 处原文锚点；provenance A/B/C = 782/174/201
  （A＝原文明写，B＝原文暗示、我们重建，C＝我们的判断）。
- 法律立场：L0 层。正文是我们自己的解读文字，不含原文 PDF、页图、逐页文本或整节译文；
  短引每条 ≤ 200 字符。原文的阅读请自行取得 arXiv 版。

## 2. 统一口径（所有单元共同遵守）

1. **锚点**：每条事实性断言后面标 `\anchor{src p.N}`，N 为底本**印刷页**；
   逐页文本在 `source/text/p{N+1:03d}.txt`（PDF 页 = 印刷页 + 1）。
2. **三级标注**：`\pA` 原文写了 / `\pB` 原文暗示、我们重建 / `\pC` 我们的判断。
   凡是"作者的动机""为什么这样选而不那样选"一律只能标 C。
3. **公式号**：引用原文公式一律写 `(3.50)` 这种原文编号，不用本书自己的编号。
4. **禁止**：`\usepackage`、新增全局宏（`\Lw`/`\LR` 由 lead 统一放进 preamble）、
   外部图片、原文页图、超过 200 字符的引文、本机绝对路径。
5. **每节必须**：一段「卡在哪」（`\stuck`）、一条「容易误解」（`\caveat`）、
   至少三条「排除错误直觉」（骨血层）。
6. 所有文件中文正文、术语首现中英对照；人名保留原文拼写。

## 4. 复现步骤

```powershell
cd papers\WIT-0604151-EMDGL
# 1) 抽取底本逐页文本（需 MiKTeX 的 pdftotext）
#    source/pages/KW06.pdf -> source/text/p001.txt ... p232.txt
# 2) 校验语料
python tools\check_jsonl.py
# 3) 编译全书
powershell -NoProfile -ExecutionPolicy Bypass -File build\compile.ps1
# 4) 审计与打包（L0 发布层）
python tools\audit_manuscript.py
python tools\package_release.py
```

本机没有 `pwsh`，只有 Windows PowerShell 5.1；`.ps1` 必须保持纯 ASCII
（5.1 把无 BOM 的 UTF-8 当 ANSI 读，中文注释会导致解析失败）。
中文 PDF 的渲染别用 Poppler（缺 Adobe-GB1 语言包，中文会消失），用
`build/render_pages.ps1` 调 Ghostscript。

## 5. 已知薄弱处

见 `00_front.tex` 末节「版本与已知薄弱处」与各单元的 self-report（`reports/`）。
最需要人工复核的六处：

1. §5.2 广义复几何：原文只到 belief，我们给的是结论链。
2. §3.4 辅助场 P/H 与 I₀/I₁/I₂ 的拼装被压缩成结论。
3. §10.3 无穷维辛商「所有轨道稳定」、§10.5 消失定理的前置假设未逐条验证。
4. §11.2–11.3「每个 A-膜 ⇒ D-模」与全局粘接修正 `f(Ψ)=Ψ` 只到 B 级。
5. 附录 A 的两条低置信判断（2009 未绕开四维扭化；c.c. 膜 D-模 = Hitchin 量子化 D-模）。
6. 语料（附录 B）A 级占比 77.8%，高于 55% 的设计目标；锚点是页级近似；
   Stacks Project 链接全空（本机访问超时）。
