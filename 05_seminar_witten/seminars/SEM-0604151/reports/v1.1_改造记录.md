## 1. 概念图：一张全景图 → 四张交换图

**旧做法（v1.0）**：`10_layer0.tex` 的 §8 用一张 tikz 大图，四簇（四维物理 / 二维几何 /
代数几何与表示论 / 翻译器）11 个节点 16 条边，试图一次画完所有概念与接口。
问题是它把"网络的形状"和"每一步的论证"混在一起，读者看不出哪条路径给出同一个结论。

**新做法（v1.1）**：拆成四张**交换图**，每张只讲一件事——两条路径给出同一个结果：

| 图 | 内容 | 对应主链 | 页 |
|---|---|---|---|
| 图 1 | `N=4 SYM(G) --扭化--> 4d TFT_Ψ(G)`，竖边 S-对偶、Ψ ↔ 1/Ψ | S1 + S2 | p18 |
| 图 2 | `4d TFT_Ψ(G) on Σ×C --紧化--> 2d σ-model on (M_H(G),J)`；右边镜像到 `(M_H(^LG),K)`；方块：先 S-对偶再紧化 = 先紧化再镜像 | S3 + S4 | p19 |
| 图 3 | 三行竖链：线算子 L --作用在膜上--> 膜范畴的自函子 --本征对象--> 局部系统 ρ:π₁(C)→^L G_C | S5 + S6 | p19 |
| 图 4 | 方块：上 `'t Hooft T_a --§9.1--> Hecke H_a`，下 `电特征膜 B --c.c. A-膜⇒D-模--> Hecke 特征 D-模` | S7 + S8 | p20 |

接口概念（Ψ / M_H / ^L G / 膜）改在 §8.5 用四条文字说明「它在哪几张图之间」，不再挤进图里。

**技术坑（三条，供复用）**

1. `tikz-cd` 的**节点内容是文本模式**，数学要写 `$...$`，否则报
   `LaTeX Error: \mathcal allowed only in math mode.`；箭头标签 `"..."` 是数学模式，
   中文放 `\text{}` 里。
2. 单元格里**不能直接写 `\\` 换行**——它被当作矩阵行分隔符，图会被打散成分散的竖排。
   正解：`\shortstack{第一行\\[1pt]第二行}`。用 `{|[align=center]| {A \\ B}}` 的花括号保护
   也不行（`Package tikz Error: Giving up on this path.`）。
3. 横向长链时箭头标签会压到节点文字（"作用在膜上" 压在 "膜范畴" 上）。
   短链宁可**改竖排**：`row sep=3.2em` + 标签用 `"..."'` 放右侧。

**验证**：Ghostscript 逐页渲染（`gswin64c.exe -r220`）目检四张图；编译 0 error、0 overfull。

## 2. 附录 D：与原文的问答录（60 条）

新增三个 part 文件与一个引言文件：

- `53_dialogue.tex`：附录 D 引言与装配（选取标准 = **只收原文明确陈述（A 级）**，与附录 B 的
  推导链语料互补：附录 B 记"我们怎么把这一步做出来"，附录 D 记"原文到底怎么说的"）。
- `53a_dialogue_A.tex`：§1–§5，pp.2–77，**20 条**（dlg-a）
- `53b_dialogue_B.tex`：§6–§8，pp.78–122，**18 条**（dlg-b）
- `53c_dialogue_C.tex`：§9–§12，pp.123–222，**22 条**（dlg-c）

每条三段：`\QAq{问}` / `\QAa{答}` / `\QAs{src p.N}{"英文短引"}`。
约束：引文 ≤120 字符，答案 2–4 句，印刷页锚点回 `source/text/p{N+1}.txt` 核对。
**机器可读版**：`tools/make_dialogue_jsonl.py` 把 60 条解析成 `derivation/dialogue.jsonl`
（字段 id / part / sections / pages / anchor / question / answer / quote_en / provenance="A"），
校验项：引文长度、答案长度、问句以问号结尾、无绝对路径、同页 ≤3 条。

**诚实边界**（也写进了书的前言）：本附录只覆盖原文**明写**的内容；原文只是暗示或属于
我们推断的，一律不收（那些在正文里标 B / C）。有些问句为了可读做了同页合并，
引文在语段中间时用省略号截断。
