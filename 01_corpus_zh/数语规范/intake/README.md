# 教材术语表投稿箱（intake）

> 用途：把**中文数学教材里已有的中英术语对照**收进来，作为本库术语的 **B 级依据**（外部权威：标准教材 + 页码）。
> 目的不是搬正文，而是让我们的译名跟着**中文学界已经通行的叫法**走，而不是每次另起炉灶。

---

## 一、拍照／扫描要求（给投稿人）

1. 只拍**术语表／索引页／名词对照页**，不必拍正文；正文一律不收。
2. 每页要完整入框，**书名页与版权页各拍一张**（要记录书名、版次、出版社、年份）。
3. 能拍页码就拍页码（页码是「依据」列的唯一凭据，没有页码的条目只能进 D 级）。
4. 格式随意（照片 PDF 均可），命名：`<书简称>-<版次>.pdf`，例如 `代数数论-第2版.pdf`。
5. **在版图书只取术语对照**：我们记录的是「某书把某英文术语译作某中文」这一事实 + 页码，不复制正文、不重排、不再分发。

## 二、录入格式

每条一行 TSV，文件名 `<书简称>.tsv`，放在本目录下：

```
英文	中文	来源书	版次	页码	备注
perfectoid space	完满空间	代数数论	第 2 版	412	书中作「完满空间」，与香蕉空间「完全胚空间」不同
```

- `英文`、`中文`：**照书中原样抄**，不要顺手「改正」成我们的译名——差异正是我们要看的东西。
- `页码`：书中印刷页码；术语表按字母分段时可写 `412（P 段）`。
- `备注`：可留空；书里同时给了异名、或与其他书冲突时写在这里。
- 文件名以 `_` 开头或含 `模板` 的文件会被脚本跳过。

## 三、跑脚本

```bash
python tools/term_intake.py            # 生成冻结表并出差异报告
python tools/build_norm.py             # 并入 TERMS.tsv / 刷新 CONFLICTS.tsv
python tools/build_norm.py --check     # 闸门
```

产物：

- `01_corpus_zh/terms_frozen_教材_<书简称>.tsv`（等级 B，可被 `build_norm.py` 直接吸收）
- `01_corpus_zh/数语规范/intake/_报告_<书简称>.md`（新增 / 一致 / 与我们不同的三条清单）

## 四、裁定顺序（同一英文出现多种中文时）

1. 本库**已冻结**（`状态=frozen`）的译名优先——跨工程一致性不容许被单本书推翻；
2. 未冻结的，看**多少本书、多少工程**用过同一译名，从众；
3. 学科惯例优先于字面直译（`perverse sheaf` 用「反常层」而非「错致层」，是本库冻结的裁定，教材若不同则记异名，不改）；
4. 仍无法裁定的，保留英文，登记进 `_meta/冲突台账.tsv`，等 Lead 裁决。

> 教材投稿的价值在于**证据**，不在于**投票**：它告诉我们「中文学界怎么叫」，最终译名仍由本库冻结表裁决。
