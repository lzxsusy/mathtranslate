# raskin_lcft 资料卡生产流程

本文件写给之后往 `cards/` 里放卡的人：材料从哪来、每一步做什么、哪些事绝对不能做。

## 0. 输入

| 材料 | 用途 | 是否入库 |
|---|---|---|
| 讲义原 PDF（印刷页 1–115，MIT OCW 版） | 核对定义、公式、页码；`anchor` 的唯一依据 | **否**（L4 禁入） |
| 中文译稿（91 页，2026-11-26 校对轮后） | 裁卡的底本；正文**不复制** | 否 |
| 术语表（109 条）与译注 | 术语裁决、勘误卡的 `why` | 只入结论 |
| Milne *CFT*、Neukirch–Schmidt–Wingberg、Weibel、Serre *Local Fields* | 逐条核对术语与数学陈述 | 文献名写进 `provenance_note` |
| `工程文件/ERRATA.md`（29 条） | 勘误卡的 `original` / `corrected` | 只入片段 |
| 译稿行内 `% [原文疑误：…]` 注释 | 校订出处与译稿行号 | 否（结论入卡） |

译稿本身、原 PDF、页面图、OCR 中间产物都不进仓库；仓库里只有卡、索引、渲染版与流程文档。

## 1. 五个阶段

1. **逐讲复核**。第一轮逐讲对讲义原文，改误译、补漏译；第二轮只对公式、上下标、编号与页码，逐式回原 PDF 页面图核对（`pdftotext -layout` 重抽 + `pdftoppm` 逐页看图，印刷页 = 物理页 − 4）。两轮结论留档在工程目录，不入库。
2. **术语与陈述核对**。每个要落卡的概念，按 Milne *CFT* / NSW / Weibel 的对应条目核对：定义是否同义、条件是否漏写、记号是否冲突（比如 $X^{hG}$ 与 $X_{hG}$、$\hat H^0$ 与 $\hat H^1$ 的配对方向）。核对结论写进卡的 `provenance_note`（写文献名与页码/条目号，不写链接堆）。
3. **按讲裁卡**。以 [MAP.md](../MAP.md) 的讲为单位，决定该讲出概念卡、推导卡还是勘误卡；一讲可出多张，但同一主题只落一张。
4. **三道门禁**。`lint_cards.py --strict` → `build_index.py` → `render_md.py`，全绿才继续。
5. **人工复核**。逐卡读一遍：`summary` 是否一句话讲清、`question` 是否能独立发问、`pitfalls` 是否真踩过、`related` 是否指对了卡。复核通过才把 `status` 从 `draft` 改成 `reviewed`。

## 2. 每类卡的取材原则

### 概念卡

- 只收「全书反复使用、且讲义给了实质定义」的概念；一次性记号不单独落卡。
- 一张卡 = 一个定义 + 至少一个可检验的定理 / 命题 + 至少一条公式。
- `definition.text` 用自己的话写，公式照录；`notation` 写清符号约定（如 $(a,b)_K$ 的两个变元都在 $K^\times/(K^\times)^2$ 里）。
- `key_points` 3–6 条，每条回答「为什么需要它 / 它解决了什么」，不重复定义。
- `theorems[].proof.status` 没走完就标 `sketch`，`gap_note` 写缺在哪一步；不许把 `sketch` 标成 `complete`。本数据集 22 条定理陈述里 `complete` 只给讲义确实逐式写完的那几条。

### 推导卡

- 只收「跨讲、讲义只给路线或只给结论」的论证；一页内能读完的推导不单独落卡。
- `steps` 至少 3 步，每步 `locator` 指到「原书 p.N 某命题」，`provenance` 标 `A`（讲义明写）/ `B`（由讲义推出、我们补的中间步）/ `C`（我们的判断）。
- `setup` 写全前提（循环扩张、$G$ 的作用、复形是否有界、系数域是否含 $n$ 次单位根）；`result` 写最终得到的式子或结论。
- `gaps` 至少 1 条：写「本卡没覆盖什么」，不要为了凑字段编一个假缺口。本数据集 13 条 `gaps` 里多数是「底本这里跳步了」。

### 勘误卡

- 只收**实际改过**的条目：底本笔误 / 记号冲突，以及译本因此做的订正。存疑但没改的（如第 22 讲 $\Z/2^{r-2}$ 的阶）留在 `ERRATA.md` 的「存疑未改」，不落卡。
- `original` / `corrected` 只留足以辨认差异的片段；不整段抄译文，更不抄讲义原文。
- `why` 必须给依据：数学推导、上下文的定义、术语表或标准文献。不得写「更通顺」「更准确」。
- `note` 写影响范围（这个记号在全书还有哪几处、译文是否已统一改掉）；没有就写空字符串。
- 图复原类（断言 19.4 / 20.13 / 23.10）的卡要写清**原 PDF 那一页长什么样**、旧译错在哪一处，否则复核时无法判断改得对不对。

## 3. 禁止事项

1. **不得整段抄原文**：讲义原文、译稿正文、教材条目正文都不能成段搬进卡里。定义与证明一律重写；引用单处 ≤ 60 字并注页码。
2. **不得写本机绝对路径**：`C:\Users\...`、`/c/Users/...`、`file:///...` 一律不许出现（`lint_cards.py` 会拦）。要指材料就写「讲义原 PDF p.N」或「译稿第 N 讲」。
3. **不得把勘误卡写成抱怨**：不写「译者太粗心」「这里明显错了」；只写「原文是什么、改成什么、依据是什么」。
4. **不得伪造页码或锚点**：`pages` 必须落在 1–115，`anchor` 必须以「原书 p.」开头且与 `pages` 一致；没回原 PDF 核对的页码不要写。页码一律用印刷页，不用 PDF 物理页、也不用译本页序。
5. **不得让 `related` 悬空**：引用的 id 必须已存在；分批写卡时用 `--allow-missing` 过渡，提交前必须去掉这个参数跑一遍。
6. **不得一卡多轨**：跨讲内容只落一张卡、放进一个 track，另一边用 `related` 指过去。
7. **不得改 id 不同步文件名**：id 末段 = 文件名，改了 id 就要改名，反之亦然。
8. **不得入库底本 PDF、页面图或 OCR 文本**：这些是库规 L4，`check_compliance.py` 会直接判违规。

## 4. 门禁

| 门 | 检查 | 谁拦 |
|---|---|---|
| G0 来源 | 每张卡至少 1 条 `sources`；`book` 逐字一致；`pages` 在 1–115；`anchor` 合法 | `lint_cards.py` |
| G1 结构 | 三类卡各自必填字段齐全；概念卡 key_points ≥ 3、formulas ≥ 1；推导卡 steps ≥ 3 且每步有 locator / provenance；勘误卡 page / original / corrected / why 齐全 | `lint_cards.py` |
| G2 引用 | `related` ≥ 2 且全部可解析；id 唯一、与目录和文件名一致 | `lint_cards.py` |
| G3 权利 | `rights = rewritten`；无本机绝对路径；无长段原文 | `lint_cards.py` + 人工抽检 |
| G4 渲染 | `index.jsonl` 与 `md/` 可重建且条数一致 | `build_index.py` / `render_md.py` |
| G5 内容 | 定义、定理、页码与讲义一致 | **人工逐卡**（机器不能替代） |

## 5. 状态与已知缺口

- 卡的 `status`：本数据集 27 张全部 `reviewed`（写过一轮逐卡复核）；没有 `published`，因为还没有外部读者反馈。
- 勘误卡只覆盖 22 条原文疑误中值得单独成卡的 10 条；其余 12 条是记号或下标重排，一句话即可说明，留在 `ERRATA.md`。4 条图复原里 3 条落卡（19.4 / 20.13 / 23.10 中的两张半），第 17 讲的图因只是排布整齐、无实质错误，未落卡。
- 页码以讲义原 PDF 的印刷页为准；译本物理页 = 印刷页 + 4，换算不要凭印象写。
- 第 18 讲（track `D`）只落 1 张卡：存在定理并进了 `norm-group`，Kummer 配对单独成卡。若之后要把第 18 讲拆细，新卡挂 `D` 轨并更新 MAP 的「未落卡的页」一节。
- 习题集（Problem Sets 1–8）只在正文引用处出现，没有单独落卡。
