# 精译摘录（4 段）

[p.2] 顶点模型的出发点是把纽结投影到平面上，使投影只有简单的二重点、且高度函数只有简单的极大与极小。除去这些例外点之后，纽结被切成若干段弧，每一段落在相邻两个例外点之间，可以独立地标上 $+$ 或 $-$ 两个符号之一；交叉点附近则按 fig. 2 与 fig. 3 给出的权重赋值——这些权重都是 $q$ 的函数，只取 $q^{\pm1/4}$ 或 $q^{1/4}-q^{-3/4}$ 这样的项。对所有可能的标号求和，所得的量是框架纽结的不变量：它是 $q$ 的 Laurent 多项式乘上一个固定的分数幂，而那个分数幂只依赖框架的选取。fig. 1 用三叶结做例子：三个交叉加两个极大、两个极小，共 7 个例外点，于是纽结被切成 7 段，求和共有 $2^7$ 项。

[p.11] 先在实联络的空间上练习。取度量为 $|\delta A|^2=-\int_W \mathrm{Tr}\,\delta A\wedge\star\delta A$，Chern–Simons 泛函的梯度流就是 $\partial A/\partial t=-\delta\,\mathrm{CS}/\delta A=-\star_3 F$。这个方程并不新鲜：它其实是瞬子方程 $F^+=0$ 的规范固定形式，因此继承了完整的四维对称性，Donaldson 与 Floer 的读者对此早已熟悉。更准确地说，把联络复化、写成 $A=A+i\varphi$（$A$ 为实联络，$\varphi$ 是取值于伴随丛的一形式）之后，同一套推导给出由四个方程组成的一阶方程组 $F-\varphi\wedge\varphi=\star d_A\varphi$ 与 $d_A\star\varphi=0$。它是 Hitchin 方程在四维的表亲；也可以读作复联络在三维流形上的流方程，但作为四维方程它是椭圆的——正是椭圆性使后面的顶针、模空间与计数成为可能。

[p.16] 到这里我们只是把东西搬了个位置。然而在 $\mathcal V$ 上还会有一个「微分」$Q$：它与 $P$ 交换、把 $F$ 加一、并满足 $Q^2=0$。这些性质意味着可以取 $Q$ 的上同调 $\mathcal H$，而且 $\mathcal H$ 是 $\mathbb Z\times\mathbb Z$ 分次的，两个次数分别由 $P$ 与 $F$ 给出。从 $\mathcal V$ 走到 $\mathcal H$ 的重要性在于：$\mathcal H$ 是拓扑不变量，而 $\mathcal V$ 不是。迹 $Z(q)=\mathrm{Tr}_{\mathcal V}(-1)^Fq^P$ 与 $\mathrm{Tr}_{\mathcal H}(-1)^Fq^P$ 相等，因为具同一 $P$、而 $F$ 相差一的玻色–费米对在两边的贡献相消。但 $\mathcal H$ 比 $Z(q)$ 多带两样信息：其一，$F$ 是整值的，而迹只记得 $F$ 的奇偶；其二，$\mathcal H$ 上可以定义自然的算子，它们来自链环的配边（link cobordism），这正是把不变量范畴化的入口。

[p.20] 作为描述边界条件的准备，我需要介绍规范理论里一个重要方程，即 Nahm 方程。它是李代数 $\mathfrak g$ 中三元组 $X_1,X_2,X_3$ 的常微分方程组：$\mathrm{d}X_1/\mathrm{d}y+[X_2,X_3]=0$，以及它的循环置换。在开半直线 $y>0$ 上，Nahm 方程有奇异解 $X_i=t_i/y$，其中 $t_i$ 满足 $\mathfrak{su}(2)$ 的对易关系 $[t_1,t_2]=t_3$ 及循环置换，因而是 $\mathfrak{su}(2)$ 的标准基在某个同态 $\varrho:\mathfrak{su}(2)\to\mathfrak g$ 下的像。把这个解嵌进四维的 KW 方程——取解在 $\mathbb R^3$ 方向平移不变、$A=0$、$\varphi=\sum\varphi_i\,\mathrm{d}x^i$ 且没有 $\mathrm{d}y$ 分量——KW 方程就约化为 $\mathrm{d}\varphi_1/\mathrm{d}y+[\varphi_2,\varphi_3]=0$，其解为 $\varphi_i=t_i/y$，这就是所谓的 Nahm 极点。这个奇异解在 Nahm、Kronheimer、Atiyah 与 Bielawski 等人的工作中反复出现；本文用它定义椭圆边界条件：$y\to0$ 处只允许渐近于 $t_i/y$ 的解（模去更弱奇异的项），另一端 $y\to\infty$ 则要求 $A$ 与 $\varphi$ 都趋于零。
