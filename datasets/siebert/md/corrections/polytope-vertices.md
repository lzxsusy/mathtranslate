# 式 (4.94) 不补 $=[-1,1]^3$：顶点集不等于多胞体

> `siebert/correction/polytope-vertices` ｜ 原书 p.74 ｜ draft

**一句话**：$\conv\{(\pm1,\pm1,\pm1)\}$ 中三元组已取遍 8 种符号组合，凸包就是立方体，原式完整；补上 $=[-1,1]^3$ 是把「顶点集」偷换成「多胞体」。

**自测**：为什么不能给式 (4.94) 补上「$=[-1,1]^3$」，尽管两者确实给出同一个立方体？

## 初版

```
有校订建议把式 (4.94) 写成 $\Xi=\conv\{(\pm1,\pm1,\pm1)\}=[-1,1]^3$。
```

## 改后

```
保持原式 $\Xi=\conv\{(\pm1,\pm1,\pm1)\}$，不追加 $=[-1,1]^3$。
```

## 为什么改

数学事实：$(\pm1,\pm1,\pm1)$ 是三种坐标各自独立取 $\pm1$ 的三元组，共 $2^3=8$ 个点，即立方体的 8 个顶点，其凸包已经是整个立方体。原式把 $\Xi$ 定义为这些点的凸包，本身完整无误；而 $[-1,1]^3$ 是那个多胞体作为集合的写法，把它接在等号后，等于宣称「这 8 个点等于整个立方体」，把顶点集与它张成的多胞体混为一谈。讲义原文也只写 $\conv\{(\pm1,\pm1,\pm1)\}$，没有这个等号。

## 补注

同一例 4.23 的对偶是 (4.95)（p.75）$\Xi^\circ=\conv\{\pm e_1,\pm e_2,\pm e_3\}$，即八面体：它同样只列 6 个顶点，不写「$=\{v:\sum|v_i|\le1\}$」。两处保持同一写法，才与「用顶点列多胞体」的惯例一致。

## 易错点

- 别因为「$\conv\{(\pm1,\pm1,\pm1)\}$ 与 $[-1,1]^3$ 是同一个集合」就认为补等号无害：多胞体由顶点集唯一决定，但「顶点集」与「多胞体」是两个对象，等号两边类型不同。
- 也不要把「8 个顶点」写成「$2^3$ 个顶点」再展开成别的集合：顶点数 8 只是计数，不是新信息。
