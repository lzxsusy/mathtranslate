# 「非常丰」应统一为「甚丰」（very ample）

> `siebert/correction/very-ample-term` ｜ 原书 p.80 ｜ draft

**一句话**：全书把 ample 译「丰」、very ample 译「甚丰」；第 4 章命题 4.20 的证明里新出现「非常丰」是漏统一，改回「甚丰」。

**自测**：命题 4.20 证明末尾的「非常丰」为什么必须改成「甚丰」？

## 初版

```
……故丰，事实上非常丰。
```

## 改后

```
……故丰，事实上甚丰。
```

## 为什么改

术语表与全书译法已固定：ample 译「丰」，very ample 译「甚丰」（第 2 章出现 4 次、第 3 章与第 6 章均作「甚丰」），此处「非常丰」是第 4 章新出现的写法，属漏统一而非有意区分。讲义原文为「hence ample, in fact very ample」，两个层次（丰 / 甚丰）分别对应两个英文词，用「非常丰」会让读者以为存在第三种强度。nLab「ample line bundle」条目亦区分 ample 与 very ample 两个不同概念。

## 补注

只改术语，不动数学内容：命题 4.20 的结论仍是「$\OO_X(D)$ 丰，且当 $\varphi$ 严格凸时由 $\OO(1)$ 给出、事实上甚丰」。全书其余出现 very ample 的地方已是「甚丰」，不改；也不要把「丰」改成「丰富」之类的意译。

## 易错点

- 只改这一处，不要顺手把其它地方的「丰」也改成「甚丰」：两者是不同概念，$\OO_X(D)$ 丰不等于甚丰。
- 「非常丰」不是术语表里的词，别再造「极其丰」「超丰」之类的变体。
