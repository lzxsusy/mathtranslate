# 「四组格」实为三对格（六个格）

- **id**：`gw06/correction/three-pairs-of-lattices`
- **类型**：correction
- **位置**：附录A
- **问题**：「四组格」与「三对格」差别在哪，为什么不是无关紧要的计数错误？

> 附录 A 开头概括说「四组格」，实际列出的是三对、共六个格。

## 位置

附录 A，sA-duality.tex:16

## 原文片段

```latex
建立四组格：根格／权格／特征格与余根格／余权格／余特征格
```

## 改为

```latex
建立三对格：根格／权格／特征格与余根格／余权格／余特征格
```

## 依据

列举本身给出三对（根/余根、权/余权、特征/余特征），共六个格；写「四组」与列举不符。格的个数是附录 A 的记账基础（对偶把每一对互换），数目错了会让读者以为还有一个未列出的格。

## 说明

只改数目词；六格的记号与包含关系 $(A.5)$–$(A.7)$ 未动。

## 批注

### 易错预警：数词与列举必须自洽

技术文本里的「N 组/N 条」是给读者的索引；与紧随其后的列举不符时，读者会花时间找一个不存在的第四组。

### 含糊点拨：「组」与「对」

六个格按对偶成三对；说「三对格」既点出数目又点出结构，比「六组格」更贴合附录 A 的论证（对偶逐对互换）。

### 背景直觉：为什么格的对数是关键

朗兰兹对偶在格层面就是把根格与余根格、权格与余权格互换；三对格正是这套互换的完整清单。
