# 「实一维形式」应为「实一形式」

- **id**：`gw06/correction/real-one-form`
- **类型**：correction
- **位置**：§5.1
- **问题**：one-form 的 one 是次数还是维数，译错会引出什么误解？

> real one-form 被译成「实一维形式」，把微分形式的次数说成了维数。

## 位置

§5.1，s05a-framework.tex:169 脚注

## 原文片段

```latex
局部地用实一维形式表示
```

## 改为

```latex
局部地用实一形式表示
```

## 依据

英文是 real one-form，指次数为 1 的微分形式，不是「一维」。译作「一维形式」会被读成「一维空间里的形式」，与后文 $A$ 是一形式、$F=dA$ 是二形式的次数记账冲突；同一译本 s02a/s02b 均作「一形式」。

## 说明

脚注内仅改这一处，脚注编号与位置未动。

## 批注

### 易错预警：次数不是维数

$p$-形式（$p$-form）的 $p$ 是微分形式的次数，不是所在空间的维数：$A$ 是一形式、$F=dA$ 是二形式，四维时空中二者同时存在，正好说明「次数」与「维数」不是一回事，把它读成「一维」会让整个次数记账失效。

### 含糊点拨：「一维」在中文里太顺

「一维形式」读起来像个正常词组，所以这个错很难被读者察觉；判断依据只能是英文 one-form 与上下文 $F=dA$ 的次数。

### 背景直觉：为什么脚注也要校

脚注常是译者自己补的约定说明，错译不会被正文的数学矛盾暴露出来，只能靠逐条对照原文抓。
