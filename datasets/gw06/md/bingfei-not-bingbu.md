# 「并不不变」连排两个「不」

- **id**：`gw06/correction/bingfei-not-bingbu`
- **类型**：correction
- **位置**：附录A
- **问题**：为什么「并不不变」不算语法错，却必须改？

> 「并不不变」字面像双重否定，读者要在句内回头重读才知道是「并非不变」。

## 位置

附录 A，sA-duality.tex:261

## 原文片段

```latex
故此方案在对偶下并不不变
```

## 改为

```latex
故此方案在对偶下并非不变
```

## 依据

「并不」+「不变」在书面上连排两个「不」，初读会被当成双重否定（即「变」），而原意是「不变」。改成「并非不变」后否定层次唯一；此句正是附录 A 讨论根长平方归一化不对称的关键句。

## 说明

仅改这一处，公式 $(\mu^*)^*=n_{\mathfrak g}\mu$ 未动。

## 批注

### 易错预警：双重否定的读法陷阱

「并不」是否定副词、「不变」是否定形容词，两个否定叠在一起时中文没有形态标记，读者只能靠语义回推。技术文本里这类句子必须改写。

### 含糊点拨：这里到底变不变

原意：用固定度规把 $\mathfrak t$ 与其对偶等同的方案，在对偶下不是不变的（差一个 $n_{\mathfrak g}$ 因子）。改后句子与随后的 $(\mu^*)^*=n_{\mathfrak g}\mu$ 一致。

### 背景直觉：为什么这句重要

非单根系（$B,C,F_4,G_2$）的根长不对称正是 $n_{\mathfrak g}$ 因子的来源；这句话读反，就会以为 S-对偶保持度规不变，后面所有 $n_{\mathfrak g}$ 都成了无源之水。
