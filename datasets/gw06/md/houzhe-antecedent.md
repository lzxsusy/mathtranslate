# 「后者」的先行词错位：留数 vs 特征多项式

- **id**：`gw06/correction/houzhe-antecedent`
- **类型**：correction
- **位置**：§2.4
- **问题**：一句「后者在对偶下变换很简单」，为什么会让人误以为 S-对偶直接作用在留数上？

> 英文关系代词 which 指特征多项式，译文「后者」紧接「留数」，把对偶的变换对象指错了。

## 位置

§2.4，s02b-duality.tex:30

## 原文片段

```latex
而后者在对偶下的变换很简单
```

## 改为

```latex
而特征多项式在对偶下的变换很简单
```

## 依据

英文作 because $\beta$ and $\gamma$ determine a pole … which transforms simply under duality，which 的先行词是 characteristic polynomial。中文「后者」紧接「留数」，会被读成「留数变换很简单」，与下文用 $\beta,\gamma$ 重标度特征多项式系数的论证不符；改后与 $ (\beta,\gamma)\to|\tau|(\beta^*,\gamma^*)$ 的半密度重标度一致。

## 说明

仅改指代词，未动公式与 $\beta,\gamma$ 的记号。

## 批注

### 易错预警：对偶作用在多项式上，不在留数上

S-对偶把 $\tau\to-1/(n_{\mathfrak g}\tau)$，希格斯场的极点留数本身不是被变换的对象；被重标度的是特征多项式的系数（按半密度权）。把留数当对象，会算不出正确的 $\beta,\gamma$ 变换。

### 含糊点拨：中文没有 which

英文靠关系代词消歧，中文必须重复名词。凡是「后者/前者/其」承接两个以上候选对象的句子，都要回原文确认先行词。

### 背景直觉：为什么留数看着像主角

前一句刚说「决定极点时的留数」，读者的注意力停在留数上；但数学上留数只是极点数据的一半，真正随对偶变换的是整个特征多项式。
