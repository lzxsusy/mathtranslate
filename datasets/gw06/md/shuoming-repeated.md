# 「说明一个说明其运作的例子」：动宾搭配错乱

- **id**：`gw06/correction/shuoming-repeated`
- **类型**：correction
- **位置**：§4.5
- **问题**：一句病句除了难读，为什么还值得单独立一张勘误卡？

> 原句「说明一个说明…」两个「说明」叠用且动宾不搭，读者会卡在句法上。

## 位置

§4.5，s04b-lines.tex:174

## 原文片段

```latex
我们简要说明一个说明其运作的简单例子
```

## 改为

```latex
我们简要给出一个简单例子来说明它是如何运作的
```

## 依据

英文 We will briefly indicate a simple example of how this works。原译把 indicate 与 example 的动宾关系弄成「说明一个例子」（应为「举出/给出一个例子」），又把 of how this works 译成「说明其运作」，两个「说明」叠在一起。改后动宾关系清楚，且「它是如何运作的」保留了 works 的指代。

## 说明

仅改这一句的句法，未动其后 $K(\MH)$ 的论述。

## 批注

### 易错预警：indicate an example 不是「说明例子」

中文里「说明一个例子」搭配不成立，应作「举出一个例子」；英文 indicate 此处是「指出/给出」，不是 explain。逐词直译最容易在这里翻车。

### 含糊点拨：works 指什么

this works 的 this 指前一段刚描述的构造（膜与线算符的对应），不是「例子」本身；译成「它是如何运作的」比「其运作」更不易被误读为例子在运作。

### 背景直觉：病句为何值得记卡

病句不改变数学，但会让读者在关键论证的入口处停顿、甚至读反主客。校订流水线把这类问题记为 P2 并留痕，正是为了让「读得顺」与「读得对」分开记账。
