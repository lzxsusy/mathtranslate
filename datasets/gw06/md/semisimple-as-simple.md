# semi-simple 译作「单」，断言范围被悄悄加强

- **id**：`gw06/correction/semisimple-as-simple`
- **类型**：correction
- **位置**：§4.6
- **问题**：为什么把 semi-simple 译成「单」不是笔误而是 P1，读者会因此误信什么？

> 原文说「半单李群」，译本作「单李群」；这把一个对半单成立的命题缩到了单群上，数学含义变了。

## 位置

§4.6，s04b-lines.tex:673

## 原文片段

```latex
之外的单李群含有
```

## 改为

```latex
之外的半单李群含有
```

## 依据

英文原文是 semi-simple Lie groups。译作「单」把断言范围从半单缩到单：单群是半单的特例，故改后的命题严格更强。上下文讨论的是半单李代数的轨道分类（半单 = 单 + 阿贝尔），用「单」会与论证链不符，属改变数学含量。

## 说明

已改回「半单」；同一段其余术语（rigid noncentral orbit = 刚性非中心轨道）未动。

## 批注

### 易错预警：半单与单差在哪

半单 = 单李代数的直和再加阿贝尔部分；单群只是其中一档。凡断言「半单成立」的定理，缩到「单」后仍成立但已被削弱，而读者会以为作者只处理了单群这一特例。

### 背景直觉：为什么这一段偏爱半单

刚性非中心轨道的研究（与 Slodowy 切片、Springer 表示相关）本来就是半单李代数的框架；单群只是最常见的例子，不是论证的边界。

### 含糊点拨：改一个字的代价

「单」与「半单」在中文里只差一个字，但在轨道分类里差一个阿贝尔直和项；这类一字之差的 P1 最容易被当作笔误放过。
