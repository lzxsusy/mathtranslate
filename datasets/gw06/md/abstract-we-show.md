# 摘要 “we show” 译作「我们证明」，语气偏强

- **id**：`gw06/correction/abstract-we-show`
- **类型**：correction
- **位置**：§1
- **问题**：把 we show 译成「我们证明」在物理文献里会造成什么误导？

> 本文的结论多为「说明／论证」，摘要却写成「我们证明」，把纲领性论证说成了定理。

## 位置

摘要，s00-front.tex:14

## 原文片段

```latex
随后，在紧化到一个黎曼面之后，我们证明：关于面算符的 $S$-对偶假设，会导出几何朗兰兹纲领在
```

## 改为

```latex
随后，在紧化到一个黎曼面之后，我们说明：关于面算符的 $S$-对偶假设，会导出几何朗兰兹纲领在
```

## 依据

英文摘要作 “we show that …”。本文对几何朗兰兹纲领的推导依赖若干物理假设（面算符的 $S$-对偶、超对称膜的稳定性），作者通篇用的是 show／argue，不是 prove。中译「证明」会让读者以为这些结论已有数学定理的地位，与正文「我们猜测」「应当」等限定语气不符，也与 §3.5 明确标为猜想的 $H^2$ 命题冲突。

## 说明

改一个词，不动句子结构；摘要其余部分与英文逐句相符。

## 批注

### 含糊点拨：物理文章里的 show

show 在物理写作中通常是「说明／表明」，其证明力来自物理自洽性而非公理推演；prove 才对应数学意义上的证明。本文标题里的 program 也提示这是纲领，不是定理。读这类文章时，把 show 一律读成「证明」会高估结论的确定性。
