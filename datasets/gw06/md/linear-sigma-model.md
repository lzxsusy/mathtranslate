# $G_\C=SL(2,\C)$ 的线性西格玛模型

- **id**：`gw06/concept/linear-sigma-model`
- **类型**：concept
- **位置**：§6.1
- **问题**：一个二维 $U(1)$ 规范理论怎么会知道四维面算符的参数 $(\alpha,\beta,\gamma,\eta)$？它的参数空间为何要再除以 $\Z_2$？

> $U(1)$ 规范群加一对超多重态的二维线性西格玛模型，其 FI 参数与 θ 角实现 $A_1$ 奇点的超 Kähler 消解，并承载外尔群作用。

## 定义

二维 ${\mathcal N}=(2,2)$ 线性西格玛模型：规范群 $U(1)$，一对超多重态 $H_1,H_2$，其玻色分量参数化四元数平面 $\mathbb{H}^2\cong\R^8$ 并按 $U(1)$ 作用；$(\alpha,\beta,\gamma)$ 是该 $U(1)$ 向量多重态的三个 Fayet–Iliopoulos 参数（$D$-项），$\eta$ 是 $\theta$ 角。把三个 $D$-项取为常数值并对 $U(1)$ 取超 Kähler 商，得到的经典真空模空间 $X(\alpha,\beta,\gamma)=\mathbb{H}^2/\!/\!/U(1)$ 即 $A_1$ 奇点的超 Kähler 消解。物理上这就是面算符局部模型在 $G_\C=SL(2,\C)$ 时的显式实现：四维侧的三个奇点参数变成靶空间的三个模参数，$\theta$ 角则控制轨形扇区的离散扭转，因此二维模型能逐项重现四维面算符的量子数。

**记号**：$H_1,H_2$：两个超多重态，玻色分量参数化 $\mathbb{H}^2$、$(\alpha,\beta,\gamma)$：$U(1)$ 的 FI 参数（三个 $D$-项）、$\eta$：$U(1)$ 的 $\theta$ 角、$\mathfrak{K}_0=\R^3\times S^1$：参数空间，再按 $w$ 取商得 $\mathfrak{K}=\mathfrak{K}_0/\Z_2$

## 关键点

- $U(1)$ 对称性可扩充为 $O(2)$，且 $(SU(2)\times O(2))/\Z_2\subset Sp(2)$（式 (6.4)），交集是共同中心 $\Z_2$，故不是直积。
- $(\alpha,\beta,\gamma)$ 是向量多重态的 Fayet–Iliopoulos 参数，经典真空模空间恰为超 Kähler 商 $X(\alpha,\beta,\gamma)$。
- $\theta$ 角以 $\exp(i\eta\int_DF)$ 进入路径积分（式 (6.5)）；因 $\int_DF\in2\pi\Z$，模型有对称性 $\eta\to\eta+1$（式 (6.6)）。
- $O(2)$ 非连通类中的元素 $w$ 把 $(\alpha,\beta,\gamma,\eta)$ 全部变号（式 (6.7)），充当 $SU(2)$ 外尔群的非平凡元，故真实参数空间是 $\mathfrak{K}_0/\Z_2$。
- 模型恰在 $P_0:\alpha=\beta=\gamma=\eta=0$ 处奇异；另一个 $\Z_2$ 不动点 $P_1:\eta=1/2$ 处经典几何只看到轨形奇点 $\R^4/\Z_2$，对应可解共形场论。

## 公式

```latex
\left(SU(2)\times O(2)\right)/\Z_2\subset Sp(2).
```
```latex
\exp\left(i\eta\int_DF\right).
```
```latex
\eta\to \eta+1.
```
```latex
w:(\alpha,\beta,\gamma,\eta)\to(-\alpha,-\beta,-\gamma,-\eta).
```

## 常见错误

- 把 $\eta$ 的周期当成 $2\pi$ 或把 $\eta\to\eta+1$ 当成规范等价：在纯 $U(1)$ 理论中 $\int_DF\in2\pi\Z$ 使 $\eta$ 以 $2\pi$ 为周期，而 $\eta\to\eta+1$ 之所以是模型的对称性，是因为 $\MH$ 侧 $\eta$ 取值于 $^L\TT$；把两者混同会算错轨道积分。
- 把 $(SU(2)\times O(2))/\Z_2$ 当成直积，于是认为 $w$ 与 $U(1)$ 对易，从而看不出 $w$ 是外尔群的非平凡元、也得不到参数空间的 $\Z_2$ 商。
- 把参数空间直接写成 $\R^3\times S^1$ 而漏掉 $/\Z_2$：这样 $P_0$ 与 $P_1$ 会被当成两个不同的理论点，而实际上一个是奇异点、另一个才是轨形 $CFT$。

## 批注

### 易错预警：两个周期，别混用

$\eta$ 是角变量，但它「模 1」还是「模 2」取决于底层的 $U(1)$ 丛：对真正的 $U(1)$ 丛有 $\int_DF\in2\pi\Z$，$\theta$ 周期是 $2\pi$；而模型里的对称性 $\eta\to\eta+1$ 来自把结构群换成 $SO(3)$ 时式 (6.11) 的 $1/2$，物理周期要到 $\eta\to\eta+2$。若把 $\eta\to\eta+1$ 当作规范等价，就会把 $\eta=1/2$ 的轨形点 $P_1$ 误判成与 $P_0$ 同一理论，从而漏掉 $P_1$ 这个独立的轨形共形场论。

### 含糊点拨：为什么经典几何看不到 η

在 $\alpha=\beta=\gamma=0$ 处超 Kähler 商是 $\R^4/\Z_2$，这是一个轨形点，经典几何不含任何连续参数，$\eta$ 自然无从出现。$\eta$ 只在量子层面可分辨：它标记轨形共形场论的离散扭转扇区，改变 $\eta$ 等价于改变这些扇区的相位。这正是 $P_1$ 需要单独讨论、而不能用经典超 Kähler 商描述的原因。

### 背景直觉：外尔群从哪来

$SU(2)$ 的外尔群只有 $\pm1$ 两个元素，其非平凡元在四维侧是极大环面的翻转 $t\to t^{-1}$。线性西格玛模型里这个作用由 $O(2)$ 的非连通部分 $w$ 实现：它同时翻转三个 $D$-项与 $\theta$ 角。局部模型能承载外尔群作用，靠的正是这个几何事实；也正因如此，参数空间必须再除以 $\Z_2$，否则同一物理理论会被数成两个不同的点。
