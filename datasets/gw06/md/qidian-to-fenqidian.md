# 「歧点」应作「分歧点」：术语表外的自造省写

- **id**：`gw06/correction/qidian-to-fenqidian`
- **类型**：correction
- **位置**：§4.5
- **问题**：「歧点」与「分歧点」只差一个字，为什么必须统一？

> branch point 在术语表里固定为「分歧点」，译本有三处省写成「歧点」，与 ramification=分歧 的体系脱节。

## 位置

§4.5，s04b-lines.tex:416（另见 :700、:701）

## 原文片段

```latex
在 $q$ 趋近歧点 $p$ 的极限下
```

## 改为

```latex
在 $q$ 趋近分歧点 $p$ 的极限下
```

## 依据

SPEC 术语表把 ramification 固定为「分歧」、branch point 固定为「分歧点」；「歧点」不在表内，是行文中的省写。同一分片内「分歧点」出现 11 次而「歧点」3 次，读者会疑心二者是否指不同对象（如「奇点」与「分歧点」并列时尤其如此）。

## 说明

三处一并改为「分歧点」，改后全片「歧点」0 处。

## 批注

### 易错预警：省写会造出第二个术语

术语表的意义是让同一概念只有一个中文名。一旦允许「歧点」这种省写，检索与交叉引用都会漏掉它，读者也无法判断它是不是另一个概念。

### 含糊点拨：branch point 与 singularity

分歧点是覆盖 $\pi:C\to C'$ 的临界值，奇点是模空间或轨道退化的位置；中文若把 branch point 写成「歧点」，与「奇点」只差一字，在同一段里同时出现时读者几乎无法分辨。

### 背景直觉：为什么这一段反复出现

§4.5 讨论线算符在 $q\to p$ 时的极限，$p$ 是分歧点，几乎每段都要提；术语统一在这里收益最大，因为同一分片内「分歧点」出现十余次，读者会不断被「歧点」打断。
