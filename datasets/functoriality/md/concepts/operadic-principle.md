# 操作子原理

> `functoriality/concept/operadic-principle` ｜ track A ｜ draft

**一句话**：操作子原理断言：计数刚性伪全纯映射得到的辛不变量，其代数性质继承自定义域模空间族的操作子结构；实现分紧化、粘合、操作子语言三步。

**自测**：操作子原理凭什么让几何计数「自动」满足 A∞ 方程，它的三步实现各起什么作用？

## 定义

辛几何中的操作子原理：通过计数刚性伪全纯映射而定义的辛不变量，其代数性质继承自底层定义域模空间族的操作子结构。其精确版本是：若按 Maslov 指标分层紧化的定义域模空间族在链层面构成操作子 $C_*^{\mathrm{cell}}(K)\coloneqq(C_*^{\mathrm{cell}}(K_r))_{r\ge1}$，而 0 维模空间上的计数给出范畴 $\mathscr A$，则 $\mathscr A$ 是 $C_*^{\mathrm{cell}}(K)$ 上的范畴（式(24) 的复合用胞腔上的计数定义）；于是 $\mathscr A$ 的运算自动满足由操作子相容性导出的方程，例如 A∞ 方程（式(29)）。

记号：三步实现：①分层紧化伪全纯映射模空间并确定定义域模空间；②证明粘合定理，把 1 维模空间的边界与 0 维模空间构造的空间等同；③用操作子语言解释这一递归结构。

## 要点

- 分工明确：几何只负责「模空间 + 粘合定理」，代数结构自动继承；这就是为什么同一个 A∞ 框架能同时容纳 Floer 理论、Gromov–Witten 理论与 Fukaya 范畴。
- 证明 A∞ 方程不必逐项操作：方程是操作子相容性（边界配边为零）的翻译，几何输入只是模空间的递归结构（结合多面体的面）。
- 第一步的技术难点最大：模空间须是拓扑上良定义的对象；一般紧辛流形需要虚计数框架（FOOO 的虚方法、polyfold、Pardon 的方法），见注 thm:2.15。
- 函子性与不变量同源：两者都从同一个操作子结构导出——不变量来自 0 维计数，函子性来自操作子映射与模空间族的相容性（原书 §1.2 提出纲领，§3.11 实现）。

## 定理与证明

### 操作子原理（原书 §1.2 的表述与 §2.3 的三步实现）

通过计数刚性伪全纯映射定义的辛不变量，其代数性质继承自底层定义域模空间族的操作子结构；实现方式是分层紧化模空间、证明粘合定理、再用操作子语言解释递归结构。

（sketch；来源：原书 p.4 §1.2、p.13 §2.3）

1. 把伪全纯映射模空间按 Maslov 指标分层紧化，并确定每个映射对应的定义域模空间（结合多面体）。  
   为什么：只有紧化后的分层空间才有 0 维层可数，也才能谈论边界。
2. 证明粘合定理：1 维模空间的边界层与由 0 维模空间构造的空间同构。  
   为什么：这把「边界」翻译成「已知低阶运算的复合」，是方程成立的几何根源。
3. 用操作子语言解释递归结构：0 维计数得到的范畴是定义域链操作子上的范畴，故其运算满足操作子相容性所给的关系。  
   为什么：相容性即 A∞ 方程；这一步把几何结论转成代数陈述。

缺口：原文把它作为原理陈述并给出三步纲领，未给一般性证明；各具体情形（如 Fukaya 范畴）的证明依赖额外技术框架。

### 第一个实例：四元 A∞ 方程

固定输入 a,b,c,d，把伪全纯五边形的 1 维模空间看作零配边并投影到定义域模空间 K_4；边界端点给出来自 μ_i(…μ_j(…)) 且 i,j≥2 的项，内部端点给出 i=1 或 j=1 的项，合起来即四元 A∞ 方程。

（sketch；来源：原书 p.13 §2.3）

1. 取固定输入的伪全纯五边形模空间，其维数为 1，紧化后是带边界的 1 维流形。  
   为什么：1 维紧流形的边界点数为偶数，边界计数相消。
2. 投影到定义域模空间 K_4（五边形），把边界点按落在 K_4 的哪个面分类。  
   为什么：K_4 的面偏序集对应括号化，边界层正是各种插入方式。
3. 边界端点对应各项之和为零；其中落在 K_4 边界上的端点给 μ_i(…μ_j…)（i,j≥2），内部端点给 i=1 或 j=1 的项。  
   为什么：这正是式(21) 的四元 A∞ 方程。

缺口：原文以图示意该投影（图 8），未逐项写出符号与系数；完整验证需要虚基本类与粘合定理。

### 命题 thm:2.20（线性 A∞-范畴即胞腔链操作子上的范畴）

线性 A∞-范畴可以与操作子 C_*^cell(K) 上的范畴等同。

（sketch；来源：原书 p.13 §2.3）

1. 从操作子上的范畴出发：$\mu_1$ 取态射复形的微分，$r\ge2$ 时把基本类 $[K_r]$ 代入复合运算得 $\mu_r$。  
   为什么：这正是「定义域模空间的操作子结构变成代数运算」的机制。
2. 由链映射性与结合多面体的递归结构导出 A∞ 方程（式(29)），故得到线性 A∞-范畴；反向由 A∞-范畴的 $\mu_r$ 与 $[K_r]$ 的配对重建操作子上的范畴。  
   为什么：两个方向合起来给出等价，也说明 A∞ 方程来自操作子相容性而非人为公理。

缺口：原文在 §2.3 只详细证明逆向方向，正向方向与符号约定从略；完整推理链见本数据集 operadic-construction 推导卡。

## 易错点

- 把原理当成定理：它是纲领性陈述，具体情形仍需构造虚基本类、验证粘合定理，技术成本很大（注 thm:2.15）。
- 以为只要数曲线就能得到 A∞ 结构：没有分层紧化与粘合定理，边界项无法配对，方程不成立。
- 混淆「操作子结构」与「操作子上的代数」：原理说的是定义域模空间族本身构成操作子，不变量是该操作子上的代数/范畴。
