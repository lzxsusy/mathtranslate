# 把 Barr–Beck 搬到 Fukaya 范畴

> `functoriality/deriv/barr-beck-to-fukaya` ｜ track D ｜ draft

**目标**：把 §5.7.1 的 Barr–Beck 判据（定理 5.12）搬到 Fukaya 情形：对拉格朗日对应 L12 诱导的伴随 Φ#_{L12} ⊣ Φ#_{L12^T}，说明 BB1 与 BB2 分别能验证到什么程度，并指出完整判据尚缺什么，从而得到预期 5.14 的地位。

**自测**：把 Barr–Beck 判据搬到 Φ#_{L12} ⊣ Φ#_{L12^T} 时，BB1 与 BB2 各自能验证到什么程度，剩下的缺口在哪？

## 前提

- 拉格朗日对应：L12 ⊂ M1^- × M2，经 Wehrheim–Woodward 形式体系诱导函子 Φ#_{L12}: Fuk M1 → Fuk M2，其右伴随为 Φ#_{L12^T}: Fuk M2 → Fuk M1（式 (137)）。
- Barr–Beck 的两个条件在此的含义：BB1 要求 Φ#_{L12^T} 保守（反映同构）；BB2 要求 Fuk M2 具有所有余等化子、且相应函子保持它们（原文把 BB2 写成合并形式）。
- 可用的工具：拼接闭--闭映射（式 (138)）SH*(M1)⊗HH*(CF*(L12,L12);CF*(L12,L12)) → SH*(M2)，以及超出一维的 Cardy 型交换图。
- 核心困难：BB2 要求对 M2 中每个拉格朗日 L2 验证相应的余等化子计算；当 dim M2 > 2 时并无 M2 中全部拉格朗日的具体描述，无法逐一验证。

## 步骤

1. **BB2 的「不难」一半：Fuk#(M2) 是预三角 A∞-范畴，故有有限余极限，特别有余等化子；再由伴随性得到保持余极限的一侧。**  
   为什么：原文把 BB2 称为容易验证的部分。注意原文此处写作 Φ#_{L12^T} ⊣ Φ#_{L12}，与式 (137) 的方向相反，属原文不严谨；这里按 (137) 的方向理解。  
   锚点：原书 p.62 §5.7.2（证据 A）

2. **BB1 的启发式：用 Cardy 型交换图（式 (140)）把拼接闭--闭映射、Hochschild 同调与 HF*(L2) 联系起来；假设 QCC 的像含单位，且余单位保持单位，则式 (141) HH*(CF*(L12);CF*(L2#L12^T)) → HF*(L2) 的像含 id_{L2}。**  
   为什么：这是原文启发式论证的第一步，把「单位在像中」的假设转化为 L2 层面对单位元的陈述。  
   锚点：原书 p.63 §5.7.2（证据 A）

3. **从 Step 2 推出 BB1：设 f 是 Fuk#(M2) 中的态射且 Φ#_{L12^T}(f) 是同构，取 L2 = cone(f)；则 cone(Φ#_{L12^T}(f)) 为零，由 Φ# 保持余极限得 Φ#(cone f) = cone(f)#L12^T 为零，于是式 (140) 右上角为零；结合 Step 2 得 id_{L2} = 0，故 L2 = 0，从而 f 是同构。**  
   为什么：这正是「保守性」的证明：由 Φ#_{L12^T}(f) 同构反推 f 同构，即 BB1。  
   锚点：原书 p.63–64 §5.7.2（证据 A）

4. **交换图的来源：计数一维族拼接曲面（带内圆的圆盘、泡出的拼接球面、矩形插入、接缝上的标记点、内部带标架点），比较两种边界退化，得到式 (140) 的链同伦。**  
   为什么：原文说明该交换图是计数一维族拼接曲面得到的；这是链层面论证的几何来源。  
   锚点：原书 p.64 §5.7.2（证据 B）

5. **结论：BB1 的启发式成立，但完整 BB2（对每个 L2 的验证）并未给出；remark 5.13 承认 Barr–Beck 定理对 A∞-函子的精确表述留待未来工作，因此整个结论只是预期 5.14，而不是定理。**  
   为什么：按原文语气与译者注，5.14 被明确标为 expectation、弱于定理，且只附启发式论证。  
   锚点：原书 p.62–65 §5.7.2（证据 C）

## 结果

得到条件性的路线：若单位 id_{M2} ∈ SH*(M2) 位于拼接闭--闭映射的像中，则 BB2 的剩余部分可望成立，从而 Fuk M2 与 Mod(Φ#_{L12^T}∘Φ#_{L12}) 拟同构。该陈述就是预期 5.14，仅由启发式论证支持，尚非定理。

## 缺口

- 完整 BB2 未验证：需要对 M2 中每个拉格朗日 L2 验证余等化子计算，dim M2 > 2 时缺少全部拉格朗日对象的描述。
- Barr–Beck 定理 5.12 只对普通伴随函子陈述，A∞-函子版本的精确表述留待未来工作（remark 5.13）。
- 5.14 的结论落在伪完美模范畴，而 Abo10/RS17 的生成判据给出完美模；两者一般不同，仅在 A∞-代数光滑时相等。
- 启发式中 Step 1 的「保持余极限的一侧」与式 (137) 的伴随方向不一致，原文写法不严谨，需按 (137) 修正。

## 易错点

- 把预期 5.14 当定理：它只有启发式论证，BB1/BB2 并未真正验证。
- 把 BB2 理解成单一条件：原文的 BB2 合并了「Fuk M2 有余等化子」与「相应函子保持余等化子」。
- 把伪完美模与完美模混为一谈：5.14 给出的是伪完美模，Abo10/RS17 给完美模。
