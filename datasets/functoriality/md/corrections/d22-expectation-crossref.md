# 原文 p.65：预期引用的应是开--闭映射 (143)

> `functoriality/correction/d22-expectation-crossref` ｜ 原书 p.65 ｜ draft

**一句话**：预期 5.15 的假设引式 (138)，但句中说的是拼接开--闭映射，其编号是 (143)。

**自测**：式 (138) 是闭--闭映射，为什么预期的假设会引它？

## 初版

```
in the image of the quilted open-closed map \eqref{eq:QCC}（式 (138)）
```

## 改后

```
…\eqref{eq:QOC}（式 (143)）
```

## 为什么改

式 (138) 是拼接闭--闭映射；句中说的是开--闭映射，其式 (143)。

## 补注

中译本保留原引用，加译注说明此处应引 (143)。

## 易错点

- (138) 与 (143) 是两个不同的映射，不能互换。
- 预期的假设针对单位在开--闭映射像中，须引 (143)。
