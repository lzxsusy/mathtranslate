# 原文 p.39：三个输入端的第四个端才是输出端

> `functoriality/correction/d10-unit-ends` ｜ 原书 p.39 ｜ draft

**一句话**：计数常值拼接曲面时说「三个端为输入、第三个端为输出」，同一句自相矛盾。

**自测**：四个端里三个是输入、剩下那个为什么写成「第三个」？

## 初版

```
with the unit as input in three of the ends and as output at the third end
```

## 改后

```
…as output at the fourth end
```

## 为什么改

被计数的常值拼接曲面有四个端（图 27）：三个输入、一个输出；「three」与「the third」在同一句里互相冲突。

## 补注

中译本照录原文并加译注。

## 易错点

- 不要按字面理解成「三个端同时既输入又输出」。
- 该计数是常值曲面存在唯一性的关键，端部数目不能读错。
