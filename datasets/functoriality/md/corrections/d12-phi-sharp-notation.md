# 原文 p.40：$\Phi^\#_{L_{12}}$ 与 $\Psi^\#$ 的记号写错

> `functoriality/correction/d12-phi-sharp-notation` ｜ 原书 p.40 ｜ draft

**一句话**：第 4 章开篇把 $\#$ 写成上标、把 $\Psi$ 写成 $\psi$，与式 (97) 的记号不一致。

**自测**：开篇提到的 $\Phi_{L_{12}^\#}$ 与 $\psi$ 为什么和后面的记号不一样？

## 初版

```
$\Phi_{L_{12}^\#}$ 与 $\psi_{L_{12},L_{23}}$
```

## 改后

```
$\Phi^\#_{L_{12}}$ 与 $\Psi^\#_{L_{12},L_{23}}$
```

## 为什么改

同书式 (97) 统一写作 $\Phi^\#_{L_{12}}$ 与 $\Psi^\#$；开篇两处把 $\#$ 误置为上标、把 $\Psi$ 误作 $\psi$。

## 补注

中译本按式 (97) 统一记号，并在首次出现处加译注。

## 易错点

- $\#$ 是函子名的下标，不是 $L_{12}$ 的上标。
- $\Psi^\#$ 是 2-态射，不是一阶的 $\psi$。
