# 原文 p.56：Donaldson 在同一句中出现两次

> `functoriality/correction/d24-donaldson-duplicate` ｜ 原书 p.56 ｜ draft

**一句话**：列举前人工作时「Donaldson, Floer, Fukaya, Donaldson, Salamon–Wehrheim」重复了 Donaldson。

**自测**：同一句里 Donaldson 为什么出现两次，名单本应是什么？

## 初版

```
Donaldson, Floer, Fukaya, Donaldson, Salamon--Wehrheim
```

## 改后

```
Donaldson, Floer, Fukaya, Salamon--Wehrheim
```

## 为什么改

同一句里 Donaldson 出现两次；按贡献者名单应只列一次。

## 补注

中译本照录原文，分章报告记录该笔误。

## 易错点

- 这是名单重复，不是两位不同的 Donaldson。
- 不要据此改动历史叙述或增删作者。
