# 15 · 原文精译节选

[p.2] 本文研究扭化的 N=4 超对称杨–米尔斯理论中 Wilson-'t Hooft 算符的乘积展开。扭化把理论变成四维拓扑场论，于是圈算符的乘积不再依赖两圈之间的距离，所有圈算符张成一个交换代数。Wilson 圈按规范群 G 的不可约表示标号，'t Hooft 圈按朗兰兹对偶群 ^LG 的不可约表示标号；Montonen–Olive 对偶断言 G 与 ^LG 的理论等价，从而把这两类算符互换。作者进一步指出，'t Hooft 圈可以等同于仿射 Grassmannian 上等变反常层范畴的对象，而圈算符代数就是该范畴的 K0；在 G=SU(2) 的情形，对偶加上这个几何字典足以完全定出乘积展开的全部系数。

[p.23] 对 G=PSU(2) 与 SU(2)，圈算符代数可以写得非常具体。把 PSU(2) 的余权格 Z 的群代数看作 x 的洛朗多项式，把权格 2Z 看作 y² 的洛朗多项式，外尔群同时把 x、y 送到各自的逆。于是纯磁算符是 WT_{0,n}=y^n+y^{n−2}+…+y^{−n}，纯电算符是 WT_{m,0}=x^m+x^{m−2}+…+x^{−m}；一般的 WT_{m,n} 则沿 S-对偶轨道等差求和，项为 x^{m−2a}y^{n−2b}，其中 m/n=a/b 既约且 a、b 与 m、n 同号。S-对偶在这里的作用是 (m,n)↦(n,−m)，恰好把电与磁互换；利用它可以先把任意荷对化到纯电情形，再逆变换回来。对 SU(2) 则把 x、y 的角色对调：权格是 2Z、余权格是 Z，故纯电与纯磁的等差和分别在 x² 与 y 上进行，这正体现了两群互为朗兰兹对偶。

[p.35] 第二个关键简化来自「极小余权」。PSU(2) 的最小非零余权是 minuscule 的，因此当两个 't Hooft 算符的余权都取 1、且放在 C 上同一点时，Bogomolny 方程的模空间是紧的，不会出现单极冒泡的边界层。这个模空间是 Hirzebruch 曲面 F₂，也就是 P¹ 上的 P¹ 丛；它同时是加权射影平面 WP_{112} 在唯一的 Z₂ 轨形点处的爆破。轨形点对应没有单极奇点的平凡解，而它的补集同构于 TP¹，对应一个 µ=±2 的奇点。于是两个 µ=±1 算符的乘积可以分解为 µ=0 的冒泡部分与 µ=±2 的体部分，两部分的波函数分别是 Eguchi–Hanson 空间与 TP¹ 上取值于全纯线丛的 L² 形式。

[p.53] 最后一步是自洽性检验。把 TP¹ 上各阶上同调按 (−1)^{p+q} 求和，体部分给出 1+(2m+1)−(2m−1)=3；把 T*P¹ 上的交替和算出来，冒泡部分给出 (2m+1)−1−(2m−1)=1。两者相加等于 4，正好等于乘积公式右边四个算符的 Euler 特征之和。左边则利用「把两个算符移到 C 上不同点后零模空间张量分解」这一点：WT_{1,0} 的 Hilbert 空间纯偶且二维，WT_{1,2m} 的 Euler 特征对任意 m 都等于 2，乘积也是 4。左右相等虽只是一个数值检验，却把 S-对偶、几何 Satake 与 L² 上同调三件事扣在了一起。它也解释了 (43) 里两个减项的来源：正是它们让冒泡部分只剩下一维，而不是 2m+1 维。
