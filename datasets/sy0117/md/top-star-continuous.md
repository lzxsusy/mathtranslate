# Top_* 的态射漏了“连续”

- **id**：`sy0117/correction/top-star-continuous`
- **类型**：correction
- **章**：第1章
- **问题**：为什么 Top_* 的态射不能只是任意基点保持映射？

> 拓扑空间带基点范畴的态射必须是连续映射；原译只写“把基点映到基点的映射”。

## 位置

§1.1，ch01.tex:29

## 原文片段

```latex
把选定点映到选定点的映射
```

## 改为

```latex
把选定点映到选定点的连续映射
```

## 依据

Top 的对象是拓扑空间，态射按定义是连续映射；同段 Man_* 已写“光滑映射”，两处体例应一致。若允许任意映射，Top_* 就不再是 Top 的子范畴。

## 说明

本轮依据范畴定义与同段体例判定；未逐页核对英文原书。

## 批注

### 易错预警：范畴的态射由结构决定

写 Top 或 Top_* 时，态射必须连续；只写“映射”会把范畴换成 Set 的带点版本。
