# 箭图表示与路径代数

- **id**：`sy0117/concept/quiver-representation`
- **类型**：concept
- **章**：第4章
- **问题**：为什么箭图表示可以用路径代数 A=kQ/I 的模来统一描述？

> 箭图表示给每个顶点一个向量空间、每条箭一个线性映射；路径代数使表示等价于左模。

## 定义

箭图 $Q$ 由顶点集 $Q_0$ 与箭集 $Q_1$ 组成。表示给每个顶点 $i$ 一个向量空间 $V_i$、每条箭 $a\colon i\to j$ 一个线性映射 $V_a\colon V_i\to V_j$。路径代数 $kQ$ 以路径为基，关系 $I$ 取商后，$Q$ 的表示等价于左 $A$-模。

**记号**：$S_i$ 是第 $i$ 个单模，$P_i=Ae_i$ 是第 $i$ 个投射模；$e_i$ 是顶点 $i$ 的平凡路径。

## 关键点

- 顶点 $i$ 的投射模 $P_i$ 的维数向量由从 $i$ 出发的路径数决定。
- 关系 $I$ 改变模范畴，但不改变底层箭图。
- 路代数有限维当且仅当 $Q$ 无有向圈。

## 公式

```latex
A=kQ/I
```
```latex
\operatorname{Rep}(Q)\simeq A\text{-}\mathrm{Mod}
```
```latex
P_i=Ae_i
```

## 常见错误

- 把箭的方向与线性映射的方向写反；箭 $i\to j$ 对应 $V_i\to V_j$。
- 忘记关系 $I$ 的商，把 $kQ$ 的模当成带关系箭图的模。

## 批注

### 易错预警：S_i 与 P_i

$S_i$ 只在顶点 $i$ 取 $k$、其余取 $0$；$P_i$ 的维数向量是“从 $i$ 出发的路径数”，两者常被混写。

### 含糊点拨：关系的方向

关系写成路径的线性组合；商掉 $I$ 后，表示必须让这些组合作用为零，而不是只让每条箭满足某个等式。
