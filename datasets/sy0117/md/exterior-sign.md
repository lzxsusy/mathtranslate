# 外代数商的符号写反

- **id**：`sy0117/correction/exterior-sign`
- **类型**：correction
- **章**：第7章
- **问题**：为什么外代数用减号、对称代数用加号？

> 对称代数是 v⊗u-u⊗v=0 的商；写成加号会把对称代数误成外代数。

## 位置

§7.2，ch07.tex:755

## 原文片段

```latex
u\otimes v-v\otimes u
```

## 改为

```latex
u\otimes v+v\otimes u
```

## 依据

外代数的关系是 u⊗v+v⊗u=0（奇元素反交换），对称代数是 u⊗v-v⊗u=0。此处构造的是对称代数，故应取减号；取加号得到的是外代数。

## 说明

本轮依据对称代数/外代数的泛性质判定；未逐页核对英文原书。

## 批注

### 易错预警：先看构造的是哪一个

看到 u⊗v±v⊗u 时，先确认目标是对称代数还是外代数；两者的关系只差一个符号。
