# 未定义的 Λ_Z 应为 E_Z^±

- **id**：`sy0117/correction/lambda-z`
- **类型**：correction
- **章**：第12章
- **问题**：为什么“Λ_Z 同构于外代数 Λ_3”中的 Λ_Z 是未定义记号？

> 前文只定义 E_Z^±=topFuk^±(Z,Z)，Λ_Z 没有定义；同构陈述的主语应改为 E_Z^±。

## 位置

§12.4，ch12.tex:582

## 原文片段

```latex
\Lambda_Z
```

## 改为

```latex
E_Z^{\pm}
```

## 依据

本章只定义了 $E_Z^{\pm}:=\operatorname{topFuk}^{\pm}(Z,Z)$，从未定义 $\Lambda_Z$；同构陈述的主语必须是 $E_Z^{\pm}$。$\Lambda_3$ 的下标 $3$ 是生成元个数，不是外幂次数。

## 说明

本轮依据前文定义与记号使用判定；未逐页核对英文原书。

## 批注

### 易错预警：先查定义

遇到带下标的 Λ 或 E，先回前文找定义；没有定义的记号不能凭上下猜。
