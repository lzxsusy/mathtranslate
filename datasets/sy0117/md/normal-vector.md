# 第三边法向量符号写反

- **id**：`sy0117/correction/normal-vector`
- **类型**：correction
- **章**：第8章
- **问题**：为什么 n_3 必须取 (-1,-1) 而不是 (1,1)？

> 三锥要构成扇，第三边的内法向量应指向 (-1,-1)；写成 (1,1) 会使九条 P^1 落空。

## 位置

§8.4，ch08.tex:810

## 原文片段

```latex
n_3=(1,1)
```

## 改为

```latex
n_3=(-1,-1)
```

## 依据

扇的三条边围成完整锥，内法向量要指向锥内；取 (1,1) 时第三边与另外两条不围成扇形，九条 P^1 的相交图也随之落空。

## 说明

本轮依据扇的内法向量与相交图判定；未逐页核对英文原书。

## 批注

### 易错预警：法向量指向锥内

画扇时先画三条边，再把内法向量画在锥内；符号取反会把边移到对侧。
