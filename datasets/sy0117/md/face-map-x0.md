# 面映射的几何实现漏了 x_0

- **id**：`sy0117/correction/face-map-x0`
- **类型**：correction
- **章**：第2章
- **问题**：面映射 δ_i 到底把哪个坐标置零，像为什么必须在 Simp_n 中？

> 面映射的像应落在 n+1 个坐标的标准单形中；原式只有 n 个坐标且丢掉 x_0。

## 位置

§2.2，ch02.tex:234

## 原文片段

```latex
(x_0,\ldots,x_{n-1})\longmapsto(x_1,\ldots,x_{i-1},0,x_i,\ldots,x_{n-1})
```

## 改为

```latex
(x_0,\ldots,x_{n-1})\longmapsto(x_0,\ldots,x_{i-1},0,x_i,\ldots,x_{n-1})
```

## 依据

标准 n-单形有 n+1 个坐标，和为 1；面映射 δ_i 在第 i 位插入 0，其余坐标保持原顺序。原式右端只有 n 个坐标，且把 x_0 丢了，像不可能落在 Simp_n 中。

## 说明

本轮依据单纯形坐标与 δ_i 的定义判定；未逐页核对英文原书。

## 批注

### 易错预警：坐标个数

δ_i 的源有 n 个坐标、靶有 n+1 个坐标；写完后先数坐标个数，再看是否插入 0。
