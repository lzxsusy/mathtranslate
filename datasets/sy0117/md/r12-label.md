# MF 的交集环应为 R_12

- **id**：`sy0117/correction/r12-label`
- **类型**：correction
- **章**：第9章
- **问题**：为什么 M_Z=0 不能在 R_1 上证明，而要到 R_12？

> M_Z=0 的证明用到 Z^{-1}，只在交集环 R_12 上成立；原式写 R_1。

## 位置

§9.5，ch09.tex:865

## 原文片段

```latex
\mathrm{MF}^{\pm}(R_1,\ell)
```

## 改为

```latex
\mathrm{MF}^{\pm}(R_{12},\ell)
```

## 依据

R_12 同时把 X 与 Z 的坐标局部化；证明 M_Z=0 需要 Z^{-1}，而 R_1 只局部化 X，缺少 Z^{-1}。

## 说明

本轮依据局部化环与证明用到的逆元判定；未逐页核对英文原书。

## 批注

### 易错预警：下标是局部化的变量

R_12 表示允许 X^{-1} 与 Z^{-1}；读 R_I 时先看 I 里有哪些变量可逆，再判断证明能否进行。
