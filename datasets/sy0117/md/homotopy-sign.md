# Hochschild 同伦的左下块符号

- **id**：`sy0117/correction/homotopy-sign`
- **类型**：correction
- **章**：第3章
- **问题**：为什么 u 的第二项必须是 -μ̃(1_B,h) 而不是 +μ̃(1_B,h)？

> φφ^{-1} 的左下块要等于 h-h=0；第二项应取负号，原式取正号会得到 2h。

## 位置

§3.2，ch03.tex:1062

## 原文片段

```latex
u=\widetilde\mu(h,1_A)+\widetilde\mu(1_B,h)+\cdots
```

## 改为

```latex
u=\widetilde\mu(h,1_A)-\widetilde\mu(1_B,h)+\cdots
```

## 依据

φ 的左下块是 h，φ^{-1} 的左下块是 -h；两块相乘时 h+(-h)=0。若第二项取正号，左下块变成 2h，同伦等式不成立。

## 说明

本轮依据矩阵块乘法与同伦等式判定；未逐页核对英文原书。

## 批注

### 易错预警：先算块再读公式

遇到分块矩阵的逆，先写出左下块的乘积 h+(-h)=0，再回看公式的符号；只看单项很容易漏负号。
