# 分次曲面与线场

- **id**：`sy0117/concept/graded-surface`
- **类型**：concept
- **章**：第10章
- **问题**：线场的绕数怎样决定分次曲面的镜像？

> 分次曲面由带线场的曲面给出，线场的绕数决定分次；其 Fukaya 范畴与矩阵分解/箭图表示相联系。

## 定义

分次曲面是带线场 $\ell$ 的曲面 $S$：线场给每个点的切方向一个 $\pi$ 周期的选择。绕数 $w$ 沿闭曲线计算，指标 $I_m=1-w/2$ 决定分次。线场的奇点对应 punctures 或 orbifold 点。

**记号**：线场不是向量场：它以 $\pi$ 为周期，故绕数可取半整数；$w$ 的奇偶决定分次是 $\mathbb Z$ 还是 $\mathbb Z_2$。

## 关键点

- 线场的绕数决定分次群的平移。
- 分次曲面上的弧与带的分次由线场的局部相位决定。
- 分次曲面的镜像可以是矩阵分解或带关系箭图的表示。

## 公式

```latex
I_m=1-w/2
```
```latex
\ell\subset TS
```
```latex
w\in\tfrac12\mathbb Z
```

## 常见错误

- 把线场当向量场；向量场绕数是整数，线场可给半整数。
- 把绕数的奇偶弄反，导致分次群选错。

## 批注

### 易错预警：半整数指标

线场以 $\pi$ 为周期，绕一圈可能只转半圈；因此指标可以是半整数，分次平移也随之半整。

### 背景直觉：分次是“相位”

线场给每个切方向一个相位；沿弧移动时相位的变化就是分次，正如向量场给辛流形提供分次。
