# 有限生成模不都同构于 R 与 S^λ 的直和

- **id**：`sy0117/correction/free-resolution`
- **类型**：correction
- **章**：第11章
- **问题**：为什么“每个有限生成模都是 R 与 S^λ 的直和”不成立？

> C[X]/(X-λ)^n 只是迭代扩张，不是若干 R 与 S^λ 的直和；应改为自由分解/K_0 表述。

## 位置

§11.1，ch11.tex:32

## 原文片段

```latex
每个有限生成模都同构于若干个 $R$ 与 $S^\\lambda$ 的直和
```

## 改为

```latex
每个有限生成模都有长度不超过 $1$ 的自由分解，故在格罗滕迪克群中其类由 $[R]$ 与 $[S^\\lambda]$ 生成
```

## 依据

$\mathbb C[X]/(X-\lambda)^n$（$n\ge2$）不是 $R$ 与 $S^\lambda$ 的直和：它只是在 $S^\lambda$ 上迭代扩张。正确结论只在 $K_0$ 或导出范畴层面成立。

## 说明

本轮依据模的扩张结构判定；未逐页核对英文原书。

## 批注

### 易错预警：直和 vs 扩张

短正合列 0→S^λ→C[X]/(X-λ)^n→… 说明它是扩张，不是直和；直和会分裂。
