# Landau–Ginzburg 模型与矩阵分解

- **id**：`sy0117/concept/lg-model`
- **类型**：concept
- **章**：第8章
- **问题**：为什么 LG 模型的 B 模型是矩阵分解，而不是凝聚层？

> Landau–Ginzburg 模型由 (X,W) 给出，矩阵分解是其 B 模型；Orlov 定理把它与超曲面的导出范畴联系起来。

## 定义

LG 模型 $(X,W)$ 由复流形 $X$ 与全纯函数 $W$ 组成。B 模型的对象是矩阵分解：$\mathbb Z_2$-分次向量丛 $E_0,E_1$ 与微分 $d_0\colon E_0\to E_1$、$d_1\colon E_1\to E_0$，满足 $d_1d_0=W\cdot1$、$d_0d_1=W\cdot1$。

**记号**：$W$ 是超势；矩阵分解的微分不是平凡微分，而是“平方等于乘以 W”。

## 关键点

- Orlov 定理把 $W^{-1}(0)$ 的奇异导出范畴与 $W$ 的矩阵分解范畴联系起来。
- LG 模型的 A 模型是 Fukaya–Seidel 范畴，B 模型是矩阵分解。
- 矩阵分解的态射要模去同伦，才能得到三角范畴。

## 公式

```latex
(X,W)
```
```latex
d_1d_0=W\cdot1
```
```latex
d_0d_1=W\cdot1
```
```latex
D^b_{\mathrm{sing}}(W^{-1}(0))\simeq\operatorname{MF}(W)
```

## 常见错误

- 把 $W$ 的临界值当成正则值；LG 模型只在临界纤维上退化。
- 忘记模去同伦；矩阵分解的态射空间不是朴素 Hom。

## 批注

### 易错预警：微分的平方是 W

矩阵分解的微分满足 $d^2=W$，不是 $d^2=0$；把 $W$ 丢掉就退化成普通复形。

### 背景直觉：B 模型的“代数化”

凝聚层在超曲面上退化；矩阵分解把退化数据线性化，使导出范畴可用线性代数计算。
