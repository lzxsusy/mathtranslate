# 中心元：exp(2πi k/N) 的 N 次幂为 1

- 卡号：`leanstmt/gno1977-s03`　轨道：GNO77　scope：`discrete-core`　验证：**certified**
- 来源：Goddard, Nuyts, Olive, Gauge Theories and Magnetic Charge（Nucl. Phys. B125 (1977) 1-28（CERN-TH-2255 预印本影印本））4-5，印刷页 13–15
- 锚点：§4–§5（量子化条件把磁权整量化）；式 (1.6) 前后的权格讨论

## 原文陈述

> 对正整数 N 与整数 k，ζ = exp(2πi k/N) 满足 ζ^N = 1。这是磁权和的模 N 条件的单变量原型：SU(N) 的权格中 Σ p_i ≡ 0 (mod N)，等价于 diag(ζ^{p_1},…,ζ^{p_N}) 落在 SU(N) 里。

英文：zeta = exp(2 pi i k / N) satisfies zeta^N = 1.
