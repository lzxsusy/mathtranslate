## 7.2 形式化现状

本页条目 `datasets/leanstmt/cards/statements/laumon906-g01.json` 是 **gap 卡**：`scope: "gap"`、`verification.status: "gap"`、`verification.sorry_count: 1`（sorry=1），`checker` 注明「未编译（gap 卡：占位签名…）」。它只记录 Laumon 定理 1.2（GL(1) 的 Aut_E）的**语句骨架**；`Gaps.lean:25–42` 的 `Curve`、`PicZero`、`abelJacobi` 等六个声明全为 `opaque` 占位，`Gaps.lean:10–15` 明说「**这不是对定理 1.2 的形式化**」，`Gaps.lean:57` 的 `sorry` 只用于通过语法检查。缺口：无光滑射影曲线、Pic⁰/Jacobian、Abel–Jacobi、六函子（`gaps[0]`）；刚性化未定义（`gaps[1]`）；m*Aut≅Aut⊠Aut 未记录（`gaps[2]`）。故该卡＝1 条语句骨架、0 条编译通过，**不是「已形式化/已机器验证」**。

## 7.3 开放问题

1. **高秩/一般 G 的函子性**：定理 2.11 只给固定 G 的等价；Langlands 函子性（群同态 φ:G→H、Levi/抛物诱导与对应的相容）一般情形仍开放，所读页未述为已证（S 中译 p.14／原文 p.19；R 中译 p.17／原文 p.14）。
2. **正特征一般 p**：定理 2.12 仅覆盖 p 大于由 G 决定的常数（且 p 非 G 的挠素数），并须把 LocSys 换成开闭子叠 LocSys′；一般 p、小 p 未知（S 中译 p.14／原文 p.19–20、脚注 15）。
3. **形式化缺口**：`laumon906-g01` 是 gap 卡（scope=gap、sorry=1、未编译），只形式化 GL(1) 定理 1.2 的语句骨架（`Gaps.lean:10–15`）；距定理 2.11 的一般 G 等价极远，Mathlib 亦缺曲线/Jacobian/六函子基础（json 的 `gaps`）。

## 易错点

1. **char 0 已证 ≠ 全特征已证**：正特征只到 p 充分大（且 p 非 G 的挠素数），并须换 LocSys′（S 中译 p.14／原文 p.19–20）。
2. **LocSys′=LocSys 仅 SL_n 已知**：一般 G 只是「预期」，别当定理（S 中译 p.7、p.14／原文 p.9、p.19）。
3. **定理 4.3.2 是 char 0**：F_σ 的反常、尖点、半单及通用秩公式均以 char 0 为前提（R 中译 p.17／原文 p.14）。
4. **gap 卡不是已形式化**：`scope=gap`、`sorry_count=1`、未编译，仅 GL(1) 定理 1.2 语句骨架（json 的 `scope`、`verification`；`Gaps.lean:10–15`）。
5. **函数域 F_q 与 char 0 曲线勿混**：定理 1.7 是 F_q 上、p 充分大的函数域陈述；定理 2.11 是 char 0 曲线的范畴等价（S 中译 p.7、p.14／原文 p.9、p.19）。
