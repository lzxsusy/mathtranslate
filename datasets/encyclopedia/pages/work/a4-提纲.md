# A4 提纲：GL(1) 与几何类域论

## 4.1 Abel–Jacobi（≤500 字）

设 $X$ 为 $\mathbb C$ 上连通、光滑、射影曲线，亏格 $g$，基点 $x_0$。取 $H_1(X,\mathbb Z)$ 的基 $(\delta_1,\dots,\delta_{2g})$ 与 $H^0(X,\Omega^1_X)$ 的基 $(\omega_1,\dots,\omega_g)$；周期向量 $(\int_{\delta_i}\omega_1,\dots,\int_{\delta_i}\omega_g)$ 在 $\mathbb Z$ 上线性无关，生成格 $\Lambda\subset\mathbb C^g$，定义 $J(X)=\mathbb C^g/\Lambda$（Laumon p.4）。定理 1.1（Abel–Jacobi，p.5）：$J(X)$ 是阿贝尔簇 $\mathrm{Pic}^0(X)$ 的底层复环面，且解析态射 $\varphi:X\to J(X)\cong\mathrm{Pic}^0(X)$ 正是代数态射 $x\mapsto\mathcal O_X([x]-[x_0])$。

两个要点。其一，目标必须是次数 $0$ 的 $\mathrm{Pic}^0$，所以公式要减 $[x_0]$；$\varphi(x_0)=0$。其二，"底层复环面"指 $J(X)$ 的复环面结构来自 $\mathbb C^g/\Lambda$，其阿贝尔簇结构由 $\mathrm{Pic}^0$ 赋予，$\varphi$ 把这套解析结构实现为代数态射。$\varphi$ 诱导 $\pi_1(X,x_0)\twoheadrightarrow\pi_1(J(X),0)\cong H_1(X,\mathbb Z)=\Lambda$；于是每个特征标 $\chi:\pi_1(X,x_0)\to\mathbb C^\times$ 唯一地分解为 $\mathrm{Aut}_\chi\circ\varphi_*$，其中 $\mathrm{Aut}_\chi:\pi_1(\mathrm{Pic}^0,0)\to\mathbb C^\times$。这就是定理 1.2 的解析证明（p.5）：局部系统就是基本群的有限维表示。

## 4.2 定理 1.2：Aut_E 的存在唯一（≤700 字）

定理 1.2（Laumon p.5）：对 $X$ 上任意秩 $1$ 局部系统 $E$，存在 $\mathrm{Pic}^0(X)$ 上唯一的秩 $1$ 局部系统 $\mathrm{Aut}_E$（在原点刚性化），使 $\varphi^*\mathrm{Aut}_E\cong E$；若 $m:\mathrm{Pic}^0\times\mathrm{Pic}^0\to\mathrm{Pic}^0$ 为群运算，还有典范同构 $m^*\mathrm{Aut}_E\cong\mathrm{Aut}_E\boxtimes\mathrm{Aut}_E$。

存在性有两路：解析路用定理 1.1 与 $\pi_1$ 交换化（p.5）；代数路见 4.3。

**"唯一"必须带"在原点刚性化"。** 定理的"唯一"不是单说"存在唯一的局部系统"，而是说"存在唯一的刚性化局部系统 $(\mathrm{Aut}_E,\ \mathrm{Aut}_E|_0\cong\mathbb C)$"。秩 $1$ 局部系统有 $\mathbb C^\times$ 自同构；不把 $0\in\mathrm{Pic}^0$ 处的纤维固定为 $\mathbb C$，"唯一"就只是 up to 同构（而同构不唯一）。陈麟在导出范畴里把类似的不唯一表述为"忽略与 $\mathrm{Shv}(\mathrm{Spec}\,k)$ 中对象的张量积后唯一"（p.8，书页 p.3）；那是另一种放松，与原点刚性化的严格关系待核。

群律同构 $m^*\mathrm{Aut}_E\cong\mathrm{Aut}_E\boxtimes\mathrm{Aut}_E$ 记录 $\mathrm{Aut}_E$ 与 $\mathrm{Pic}^0$ 群结构的相容性；秩 $1$ 时它对应特征标 $\pi_1(\mathrm{Pic}^0)\to\mathbb C^\times$（p.5）。Raskin 的 Hecke 形式是 $\chi_\sigma|_{L(x)}\cong\chi_\sigma|_L\otimes\sigma_x$，并要求 $\chi_\sigma|_{\mathcal O_X}\cong 1$（p.4）；后者相应于原点刚性化。对应 $E\leftrightarrow\mathrm{Aut}_E$ 把 Galois 侧送到自守侧；$E$ 扮演 Hecke 特征值的角色。注意 $\mathrm{Aut}_E$ 住在 $\mathrm{Pic}^0(X)$，而完整的 Hecke 特征层住在 $\mathrm{Bun}_{G_m}\simeq\mathrm{Jac}(X)\times\mathbb Z\times BG_m$（Raskin p.3）；前者应是后者在次数 $0$ 因子上的限制并归一化（待核 3）。

## 4.3 代数证明的三步（≤600 字）

**第一步（对称幂）。** $X^{(d)}=X^d/S_d$ 连通、光滑、射影，维数 $d$；定义 $\varphi^{(d)}:X^{(d)}\to\mathrm{Pic}^0(X)$，$D\mapsto\mathcal O_X(D-d[x_0])$。关键几何事实：$d\ge 2g-1$ 时 $\varphi^{(d)}$ 是秩 $d-g$ 的射影丛，纤维 $\cong\mathbb P^{d-g}$，故单连通（Laumon p.5）。这一步把"除子"变成"纤维单连通的丛"。

**第二步（外张量积下降到对称幂）。** $E^{\boxtimes d}$ 是 $X^d$ 上秩 $1$ 局部系统，带 $S_d$ 作用；令 $E^{(d)}=(r_*E^{\boxtimes d})^{S_d}$，$r:X^d\to X^{(d)}$。其纤维满足 $(E^{(d)})_D=\bigotimes_x\mathrm{Sym}^{d_x}E_x$（式 1.3，p.5）。秩 $1$ 时 $\mathrm{Sym}^{d_x}E_x$ 仍秩 $1$，故 $E^{(d)}$ 是 $X^{(d)}$ 上秩 $1$ 局部系统。

**第三步（沿单连通纤维下降）。** $E^{(d)}$ 在 $\varphi^{(d)}$ 的每条纤维上常值（单连通 $+$ 秩 $1$ 局部系统 $\Rightarrow$ 无单值化）；射影丛局部有截面，故 $E^{(d)}$ 下降为 $\mathrm{Pic}^0(X)$ 上秩 $1$ 局部系统 $\mathrm{Aut}_E$，且由构造 $\varphi^*\mathrm{Aut}_E\cong E$（原点刚性化用来固定下降所得局部系统在 $0$ 处的标架）。全程只用对称幂、Riemann–Roch（$h^0=d+1-g$）与射影丛纤维的单连通性，没有用积分或 $\pi_1$ 的解析理论；Raskin 的同一论证写作 $d>2g-2$（p.5）。

## 4.4 为什么这是“处处非分歧”的 GL(1) 情形（≤400 字）

"处处非分歧"不是额外假设，它与"$E$ 是 $X$ 上局部系统"同义：局部系统就是 $\pi_1(X)$ 的有限维表示，处处不分歧（`local-system`）；自守侧 $\mathrm{Aut}_E$ 是 $\mathrm{Pic}^0$ 上的 lisse 层（p.5）。Laumon 在代数证明后说："这是处处非分歧的 Drinfeld–Langlands 对应中的 GL(1) 情形"（p.5）。

$G=\mathrm{GL}(1)=\mathbb G_m$ 交换，此时即非分歧整体几何类域论。陈麟定理 1.1.5 称"等价地说，是 $\mathrm{GL}_1$ 的非分歧整体几何 Langlands 对应"（p.8）。Raskin §1.2 标题含"交换几何 Langlands"（p.3），§1.3 转入 $G=\mathrm{PGL}_2$ 的非交换理论（p.5）。它只是 $G=\mathrm{GL}(1)$、处处非分歧的交换情形，不是"几何 Langlands 的全部"。

类比：讲义概括为"Frobenius 的迹应当与 Hecke 特征值相匹配！"（p.48）；匹配即 $\varphi^*\mathrm{Aut}_E\cong E$ 及 Hecke 性质。

## 易错点（3–5 条）

1. **漏掉"原点刚性化"**：秩 $1$ 局部系统有 $\mathbb C^\times$ 自同构；只说"存在唯一 $\mathrm{Aut}_E$"会留下标架不确定性。Laumon 把 $\mathrm{Aut}_E$ 在 $0$ 处刚性化（$\mathrm{Aut}_E|_0\cong\mathbb C$，p.5），才得到严格唯一；陈麟的"本质唯一"是导出范畴里忽略常值张量积的另一种放松（p.8），两者关系待核。
2. **把代数证明说成"用分析"**：代数证明走 $X^{(d)}\to\mathrm{Pic}^0(X)$，$d\ge 2g-1$ 时是射影丛、纤维 $\mathbb P^{d-g}$ 单连通，再让 $E^{(d)}$ 沿纤维常值下降（Laumon p.5）；解析证明是另一条路（定理 1.1 $+$ $\pi_1$），两者不能混。
3. **$\varphi$ 的公式写错**：$\varphi(x)=\mathcal O_X([x]-[x_0])$，必须减 $[x_0]$ 才落在 $\mathrm{Pic}^0$；写成 $\mathcal O_X([x])$ 或 $[x]$ 就跑到 $\mathrm{Pic}^d$ 去了（Laumon p.5）。
4. **把 GL(1) 说成"几何 Langlands 的全部"**：它只是交换情形/类域论；Raskin §1.2 标题含"交换几何 Langlands"（p.3），§1.3 才进入 $\mathrm{PGL}_2$ 的非交换理论，输出从 lisse 变为反常层（p.5）。
5. **把 $\mathrm{Aut}_E$ 与完整 Hecke 特征层混同**：Laumon 的 $\mathrm{Aut}_E$ 在 $\mathrm{Pic}^0(X)$ 上；完整对象在 $\mathrm{Bun}_{G_m}\simeq\mathrm{Jac}(X)\times\mathbb Z\times BG_m$ 上（Raskin p.3）。`picard-variety` 词条把 $\operatorname{Pic}_X=\bigsqcup_d\operatorname{Pic}_X^d$ 与 $\operatorname{Pic}_X^0=\operatorname{Jac}(X)$ 分开（definition），可说明完整对象的底空间不止 $\mathrm{Pic}^0$。

## 待核（≤5 条）

1. Laumon 定理 1.2 "在原点刚性化"的法文原文措辞与精确定义（固定 $\mathrm{Aut}_E|_0\cong\mathbb C$，还是别的归一化）；未读法文原版。
2. "$d\ge 2g-1$ 时 $\varphi^{(d)}$ 是秩 $d-g$ 的射影丛"的证明（Riemann–Roch/单连通性）未在所读页展开；"秩"是否指纤维维数，待核。
3. 陈麟"本质唯一"（忽略 $\mathrm{Shv}(\mathrm{Spec}\,k)$ 张量积）与 Laumon"原点刚性化唯一"的严格关系；前者在 $\mathrm{Pic}_{X/k}$ 全空间，后者在 $\mathrm{Pic}^0$，需核对限制与归一化。
4. 不同 $d$ 下降所得 $\mathrm{Aut}_E$ 的标架/同构如何统一；原点刚性化是否已足够，Laumon 所读页未明说。
5. 讲义第 6 讲是经典 $\mathrm{GL}_2/\mathbb Q$ 的 Langlands 互反，不是几何 $\mathrm{GL}(1)$；本提纲只把它当作"Frobenius 迹 $\leftrightarrow$ Hecke 特征值"的类比来源，需确认综述页是否允许这种跨语境类比。
