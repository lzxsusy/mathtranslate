[p.2]

一个 n 维 TFT 是否也给更低维的闭定向流形指派什么东西？一个显然的猜测是：给 n−2 维流形配一个 C-线性范畴，给 n−3 维流形配一个 C-线性 2-范畴，依此类推；所得的物件通常称为扩展拓扑场论。之所以要往低维扩张，是因为我们本来就要把闭流形从带边流形粘出来：设 N1、N2 是两个定向 n−1 维流形，∂N1 → ∂N2 是反转定向的微分同胚，沿公共边界粘合便得到闭流形 N12。扩展 TFT 给 ∂N1 配一个 C-线性范畴 F(∂N1)，给 N1 与 N̄2（N2 的反向定向）配该范畴的对象 F(N1) 与 F(N̄2)；N12 能由 N1、N2 粘成，意味着向量空间 F(N12) 正是从 F(N1) 到 F(N̄2) 的态射空间。这一猜想长期没有公理化定义，原因很直接：n>2 时 n-范畴没有公认的定义；这一技术障碍又因人们对高阶范畴的物理含义缺乏理解而加重。

[p.11]

RW 模型的作用量可以写成 S = Q(V) + S₀，其中 S₀ 不依赖 M 上的度量，V 是某个依赖度量的奇函数。Q 是满足 {Q,Q} = 0 的奇向量场，花括号表示超 Lie 括号；因此给 S 加上形如 Q(f) 的项并不改变配分函数。非 Q-正合的那部分作用量为 S₀ = ∫_M (Ω(ρ,Dρ) + ⅓Ω(ρ,R(ρ,ρ,η)))，其中 Ω 是 X 上的全纯辛形式，D 是 φ*T^{1,0}X⊗T*M 上关于拉回联络的协变微分，R ∈ Hom(T^{1,0}X⊗T^{1,0}X⊗T^{0,1}X, T^{1,0}X) 是该联络的曲率。把它与 Chern–Simons 作用量 S_CS = ∫_M (κ(A,dA) + ⅓κ(A,[A,A])) 对照：ρ 与 A 对应、Ω 与 κ 对应，于是 RW 模型是 CS 理论的奇类比。

[p.14]

如下自然猜想由 [17] 提出：设 M_Y 是 Maurer–Cartan 方程 (3) 的解空间，其中 β 是 Y 上 (0,q) 型的不齐次形式、q 为奇数、取值于丛 (2)。则存在从 M_Y 到范畴 D_{Z2}(Coh(Y)) 的 monoidal 形变空间的满射；两个 monoidal 形变等价，当且仅当对应的 Maurer–Cartan 方程解由一个无穷小形式为 (4) 的规范变换相联系。若猜想成立，它给出 D_{Z2}(Coh(Y)) 全体 monoidal 形变的简洁描述；这一描述与「把 D^b(Coh(Y)) 看成 A∞ 范畴时其全体形变」的描述惊人地相似，后者用取值于 Λ•TY 的 (0,q) 形式 P 的方程 ∂̄P + ½[P,P]_SN = 0 表述，括号是多重向量场上的 Schouten–Nijenhuis 括号，P 的总次数（形式次数与多向量次数之和）为偶。

[p.17]

Q 的整体归一不影响理论，所以 GL 扭化理论实际上是以 CP¹ 的点为参数的一族 4d TFT。把 CP¹ 认同为复平面的一点紧化，用参数 t ∈ C∪{∞} 标记具体的理论。Montonen–Olive 对偶不仅把 G 换成它的 Langlands 对偶 ^LG，还作用在参数 t 上；几何 Langlands 对偶来自把 t = i 映到 t = 1 的那一个 MO 对偶特例。固定紧单群 G、取闭定向 2-流形 C，规范群为 G 的 4d 拓扑规范论给 C 配一族以 t 为参数的 C-线性范畴，记其中一员为 F(G,t,C)；MO 猜想蕴含范畴等价 F(G,i,C) ≃ F(^LG,1,C)。剩下的问题是理解这两个范畴：F(G,t,C) 是 4d 理论在 C 上 Kaluza–Klein 约化所得 2d TFT 的膜范畴。
