# 讲义生产协议：SEM-0604151（K–W 2006 分层解经本）

> 本文是「把一篇 231 页数学物理论文做成 219 页分层解经本 + 语料」的可复现协议。
> 配套数据：`datasets/traces/KW06-04.lead.jsonl`（导的决策流，52 条）与
> `datasets/traces/KW06-04.units.jsonl`（12 个写作单元的回执，17 条）。
> 成品见 `05_seminar_witten/seminars/SEM-0604151/`。

---

## 0. 一句话

**先固定编号与卡片格式，再按单元并发写作，最后统一做机器审计与目检。**
三件事不能省：①页码锚点（每句断言都能回原文）；②provenance 三级（A 原文写了 / B 原文暗示我们重建 / C 我们的判断）；
③自编译（每个单元交付前自己编译 0 error，否则下游一改就是连锁报错）。

## 1. 分层结构（产品定义）

| 层 | 回答什么 | 载体 | 篇幅参考 |
|---|---|---|---|
| L0 骨架 | 这篇文章在做什么、为什么这样排 | 一页看懂 + 主链 S1–S8 + 五个 miracle + 概念图 | 14–15 页 |
| L1 结构 | 每一节的任务、输入、输出、出口 | 每节一张六栏卡片（kcard） | 23–24 页 |
| L2 骨血 | 关键技术怎么算出来的 | 动机→推导→结论三段式 + 「排除错误直觉 ≥3 条」 | 19–26 页/块 |
| L3 细度 | 术语、符号、前置概念、外链注释 | 术语表 113 条 + 注释卡 36 张 | 34 页 |

L0 决定编号，其余各层必须复用同一编号（S1–S8、M1–M5、N1–N12），不许各自发明。

## 2. 分工与并发模型

- **lead**：清点、规范、骨架层、整合、审计、发布。
- **写作单元**（每个只写一个文件）：结构层 2 个、骨血 4 个、细度 2 个、附录 3 个、问答录 3 个。
- **并发上限 8**：超出直接派发失败（本工程第一次派 12 个，4 个被拒，后来排队补派）。
- **单文件所有权**：每个单元只写自己那一个 `.tex`，不改 `main.tex` / `preamble.tex` / 他人文件；
  需要新宏就回报 lead，由 lead 统一加进 preamble。这条是防止并发写冲突的核心。
- **回执格式**（≤250 字）：文件路径、页数、锚点数、A/B/C 计数、编译结果、最弱两处。

## 3. 提示词模板（writer）

```
你是本次讲义的一个写作单元，只写 <文件路径>。
【必读】plan/01_分层讲义规范.md、plan/02_符号与风格卡.md、plan/04_骨架编号表.md、source/meta.md
【任务】<覆盖哪些原文章节 + 页段>，<多少页>，<几张卡片/图>
【硬约束】
1. 每一条断言都带 provenance：\pA（原文写了）/\pB（原文暗示我们重建）/\pC（我们的判断），
   并给 \anchor{src p.N}（N 是印刷页，对应 source/text/p{N+1}.txt）。
2. 原文短引 ≤200 字符，用 \begin{origquote}...\end{origquote}；禁止整段复制。
3. 只用 preamble 已定义的宏；不得 \usepackage、不得 \newcommand。
4. 不使用原文页图；图一律自己画 tikz。
5. 写完自建 build/check_<name>/check.tex 跑两遍 xelatex，必须 0 error。
【回报】≤250 字：文件、页数、锚点数、A/B/C、编译结果、最弱两处。
```

问答录（附录 D）另有一套：只收 A 级、每条 `\QAq{问}` / `\QAa{答}` / `\QAs{src p.N}{"英文短引"}`、
引文 ≤120 字符、答案 2–4 句、必须逐条回 `source/text` 核对。

## 4. 共享约定

- **页码映射**：印刷页 N ↔ `source/text/p{N+1:03d}.txt`（p001 标题页、p002 目录页）。
- **公式号**：正文引用必须能在原文找到。工程里有 `tools/verify_labels.py` 做全量核对
  （本工程：源文件 362 个公式号、正文引用 225 个、0 个编造；顺手抓到 1 个 typo）。
- **三级标注**：A 级可以「断言原文这么写」；B 级必须写「原文暗示，我们重建了哪一步」；C 级必须写「我们判断，理由是什么」。
- **卡片格式**：L1 六栏（任务/输入/关键构造/结论/出口/锚点索引）；L2 三段式 + 排除错误直觉。

## 5. 验收门（lead 侧）

1. **每单元自编译** 0 error、0 overfull；全书两遍 xelatex 0 error。
2. **机器审计**（`tools/audit_manuscript.py`）：逐文件统计字符数、锚点、A/B/C、卡片、tikz、超 200 字引文、
   绝对路径、TODO、违规宏、重复 label。硬指标：引文 0 违规、绝对路径 0、重复 label 0。
3. **统计口径一致**：编译脚本与审计脚本必须报同一组数字（本工程踩过坑，见 §6）。
4. **目检**：抽目录页、每层首节、附录首末页渲染成 PNG 肉眼过一遍（重叠/溢出/空白页）。
5. **风险登记**：每个单元必须写「最弱两处」，lead 汇总进前言「已知薄弱处」。

## 6. 环境坑表（Windows + MiKTeX + 中文，全部踩过）

| 坑 | 症状 | 对策 |
|---|---|---|
| 没有 `pwsh` | `pwsh: 无法识别` | 只有 Windows PowerShell 5.1：`powershell -NoProfile -ExecutionPolicy Bypass -File ...` |
| `.ps1` 无 BOM | 中文注释乱码，报 `Unexpected token ')'` | 脚本写成纯 ASCII，或写文件时加 UTF-8 BOM |
| xelatex 参数 `$Out` 未展开 | 日志写进字面 `$Out` 目录 | 用参数数组 `$xargs=@(...); & $Xelatex @xargs` |
| `\input{preamble}` 找不到 | `File 'preamble.tex' not found` | 先 `Push-Location manuscript/`，输出目录用绝对路径 |
| `\colorbox` + `minipage` + xeCJK | `Extra }, or forgotten \endgroup` | 一切色块改用 `tcolorbox` 环境 |
| `\caveat` 当环境用 | `Argument of \textbf has an extra }` | 它是命令不是环境；要框就用 `warn` 环境 |
| 圈号 ①–⑥ 缺字 | `Missing character` ×16 | `\xeCJKDeclareCharClass{CJK}{"2460 -> "2473}` |
| Poppler 缺 Adobe-GB1 | 渲染时中文全丢、pdftotext 乱码 | 用 Ghostscript 渲染页码/看版式；pdftotext 只读西文原文 |
| CRLF 的 README | Python 改一处整文件坏行尾 | `io.open(..., newline="")` 读写，插入 `\r\n` |
| `Select-String` 默认忽略大小写 | `\part`/`\partial` 被算成 `\pA`，A 级虚高 400+ | `-CaseSensitive -Pattern '\\pA\b'` |
| `tikz-cd` 节点是文本模式 | `\mathcal allowed only in math mode` | 数学包 `$...$`，中文放 `\text{}` |
| 单元格里 `\\` 换行 | 图被打散成竖排 | 用 `\shortstack{A\\[1pt]B}` |
| 绝对路径正则 | 数学 `S:\tau`、`\Phi:\Sigma` 被当盘符，误报几十处 | 正则只匹配已知路径前缀（`Users|Desktop|dsh|...`） |

## 7. 成本与产出（本工程实测）

- 写作单元 15 个（含 lead 自己写的骨架层与前言）；lead 另做整合、审计、发布。
- 全书 219 页、534,303 字符、1330 锚点、A/B/C = 846/177/204；编译 0 error / 0 overfull。
- 语料 368 条：推导链 308（skeleton 119 / qa 66 / concepts 85 / branches 38）+ 问答录 60。
- 主要人时成本在两处：图表目检（tikz 标签重叠要来回改）与统计口径对齐。
