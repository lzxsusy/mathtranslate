# 译文修订 section-16-cd.tex:10

> `seidel/correction/a09-section-16-cd-10` ｜ 原书 p.224 ｜ draft

**一句话**：初版「而 $-|\xi|/2$ 的时间 $2\pi$ 流成为对径映射」改为「而 $-|\xi|^2/2$ 的时间 $2\pi$ 流成为对径映射」：原书 p224 印作 $|\xi|^2/2$，译文回改以忠于原书；其与上下文矛盾处见注 A09-04。

**自测**：初版这里错在哪，为什么必须改？

## 初版

```
而 $-|\xi|/2$ 的时间 $2\pi$ 流成为对径映射
```

## 改后

```
而 $-|\xi|^2/2$ 的时间 $2\pi$ 流成为对径映射
```

## 为什么改

原书 p224 页图印作 $-|\xi|^2/2$，译文初版误作 $-|\xi|/2$，现回改为忠于原书。该式与同句「导数趋于 $-1/2$」及分解 $b(r)=\beta(r^2)-r/2$ 矛盾，译者注 A09-04 已说明此处应读作 $|\xi|/2$；本条属「译文回改原书」，不是另立新说。

## 补注

见分章报告 A09 修订表第 5 行（report-A09.md 第 21 行）；修订总表第 24 条（section-16-cd.tex:10，印刷页 224）。该行 TSV 的竖线被误写成制表符，字段错位损坏（old 字段只剩半句、new 字段只剩一个希腊字母），本条 original/corrected 据 report-A09.md 与译者注 A09-04 复原；注 A09-04 说明原书 $|\xi|^2/2$ 与上下文矛盾、应读 $|\xi|/2$。

## 易错点

- 只看改后的句子不足以判断对错；须对照原书同一页的公式与上下文。
- 术语改动要全书统一，不能只改这一处。
