# 译文修订 section-10-cd.tex:41

> `seidel/correction/a05-section-10-cd-41` ｜ 原书 p.138 ｜ draft

**一句话**：初版「$H^3(\pi_0(G);\pi_1(G))$ 中一个典范类」改为「$H^2(\pi_0(G);\pi_1(G))$ 中一个典范类」：同句英文作 in H²(π0(G);π1(G))；同段第 7 条把 $H^3(\Gamma;\HH^0(A,A)^\times)$ 一并改为 $H^2$。

**自测**：初版这里错在哪，为什么必须改？

## 初版

```
$H^3(\pi_0(G);\pi_1(G))$ 中一个典范类
```

## 改后

```
$H^2(\pi_0(G);\pi_1(G))$ 中一个典范类
```

## 为什么改

同句英文作 an element of $H^2(\Gamma;\HH^0(A,A)^\times)$，其典范类落在 $H^2(\pi_0(G);\pi_1(G))$（原书 p138 同一段，页图核对）。「对任意拓扑群都存在」的典范类是覆盖群扩张类，本身住在 $H^2$。同段第 7 条（$H^3(\Gamma;\HH^0(A,A)^\times)$ 中的元素）同理改为 $H^2$。

## 补注

见分章报告 A05；修订总表第 7、8 条（同为 section-10-cd.tex:41，因同 slug 合并）：第 7 条 $H^3(\Gamma;\HH^0(A,A)^\times)\to H^2(\Gamma;\HH^0(A,A)^\times)$；第 8 条 $H^3(\pi_0(G);\pi_1(G))\to H^2(\pi_0(G);\pi_1(G))$。本卡 original/corrected 取第 8 条，第 7 条同页同段、仅系数群不同，已由 why 覆盖。
