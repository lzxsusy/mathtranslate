# 译文修订 section-14-c.tex:15

> `seidel/correction/a08-section-14-c-15` ｜ 原书 p.203 ｜ draft

**一句话**：初版此处误译：英文 p203 作 “There is a Z worth of possible choices for σ”

**自测**：初版这里错在哪，为什么必须改？

## 初版

```
“$\sigma$ 的可能选择构成一个 $\Z$ 族”
```

## 改后

```
“$\sigma$ 的可能取值有 $\Z$ 个，彼此相差 $\pi$ 的整数倍”
```

## 为什么改

英文 p203 作 “There is a Z worth of possible choices for σ”。原译是字面直译，易被误读为“取值集合有 $\Z$ 个元素”，且漏掉了关键的“相差 $\pi$ 的整数倍”这一事实（由 $D\pi(TL_x)=e^{i\sigma}\R$ 中 $\sigma$ 只定到 $\pi\Z$ 决定）。
