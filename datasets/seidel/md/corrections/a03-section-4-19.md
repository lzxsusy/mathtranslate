# 译文修订 section-4.tex:19

> `seidel/correction/a03-section-4-19` ｜ 原书 p.55 ｜ draft

**一句话**：初版「对任意 $A$，都有一个**自然的**分裂闭包构造」改为「**平凡的**」：英文 p55 作 tautological，指照定义写出即可、无需论证；「自然」在范畴论中是专门术语，此处误用会造成歧义。

**自测**：初版这里错在哪，为什么必须改？

## 初版

```
对任意 $A$，都有一个**自然的**分裂闭包构造
```

## 改后

```
对任意 $A$，都有一个**平凡的**分裂闭包构造
```

## 为什么改

英文 p55 为 "there is a **tautological** construction of a split-closure"。tautological 指"照定义写出即可、无需论证"，不是"自然"；且"自然"在范畴论中是专门术语（natural transformation），此处误用会造成实质性歧义。注 A03-01 已就地说明该构造的分量形式。

## 补注

见分章报告 A03；修订总表第 5 条（section-4.tex:19，印刷页 55）；译者注 A03-01 已就地说明该构造的分量形式。

## 易错点

- 只看改后的句子不足以判断对错；须对照原书同一页的公式与上下文。
- 术语改动要全书统一，不能只改这一处。
