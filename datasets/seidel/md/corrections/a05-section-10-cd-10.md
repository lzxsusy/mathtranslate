# 译文修订 section-10-cd.tex:10

> `seidel/correction/a05-section-10-cd-10` ｜ 原书 p.138 ｜ draft

**一句话**：初版此处误译：英文 "the Floer data for the pairs ((L0,γ0), φ(Ld,γd))"

**自测**：初版这里错在哪，为什么必须改？

## 初版

```
由对子对象 $((L_0,\gamma_0),\phi(L_d,\gamma_d))$ 的 Floer 数据确定
```

## 改后

```
由对象对 $((L_0,\gamma_0),\phi(L_d,\gamma_d))$ 的 Floer 数据确定
```

## 为什么改

英文 "the Floer data for the pairs ((L0,γ0), φ(Ld,γd))"。原译"对子对象"是 "for the pairs" 的误合，既读作 subobject（子对象），又使"由对子对象……的 Floer 数据"句法断裂。

## 补注

见分章报告 A05；修订总表第 7 条。

## 易错点

- 只看改后的句子不足以判断对错；须对照原书同一页的公式与上下文。
- 术语改动要全书统一，不能只改这一处。
