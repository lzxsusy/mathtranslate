# 译文修订 section-11-ef.tex:123

> `seidel/correction/a06-section-11-ef-123` ｜ 原书 p.161 ｜ draft

**一句话**：初版「$\alpha(s)$ 有非零零空间」改为「有非平凡的零空间」：零空间永远含零向量，nonempty null space 指非零维；主语也应是 $s$ 而非「时刻」。

**自测**：初版这里错在哪，为什么必须改？

## 初版

```
更确切地说，来自 $\alpha(s)$ 的零空间非零的时刻 $s$。
```

## 改后

```
更确切地说，来自使 $\alpha(s)$ 的零空间非平凡的那些 $s$。
```

## 为什么改

原文 p161 为 those $s$ where $\alpha(s)$ has a nonempty null space。零空间是子空间，「非零」不适用于子空间（零空间永远含零向量），应为「非平凡（非零维）」；主语也应是 $s$ 而非「时刻」。
