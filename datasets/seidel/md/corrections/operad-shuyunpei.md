# 术语：operad 由「运算胚」改为「操作子」

> `seidel/correction/operad-shuyunpei` ｜ 原书 p.7 ｜ draft

**一句话**：初版「运算胚」改为「操作子（operad）」：operad 的通行中文译名是「操作子」；「运算胚」不是标准术语，且「胚」在中文数学中另有 germ 的含义，易致误

**自测**：初版这里错在哪，为什么必须改？

## 初版

```
运算胚
```

## 改后

```
操作子（operad）
```

## 为什么改

operad 的通行中文译名是「操作子」；「运算胚」不是标准术语，且「胚」在中文数学中另有 germ 的含义，易致误。

## 补注

涉及 chapter-i.tex:4、section-1.tex:407，全书仅此两处；首处加夹注。

## 易错点

- 只看改后的句子不足以判断对错；须对照原书同一页的公式与上下文。
- 术语改动要全书统一，不能只改这一处。
