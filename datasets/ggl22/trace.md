## 3. ⚠ 弯路：$n_f=2n_c$ 时「$q_R=1$ 的荷序列」我记错了

- **判断点**：balanced 情形到底哪个 $a_i$ 给 $q_R=1$。
- **依据**：p025 原文「the monopole operators in which the $a_i$ are $(\pm1,0,\ldots,0)$ have $q_R=1$」。
- **结论与理由**：**写错**——我最初按「对称性增强为 $SU(2)$」的物理图像，记成 $a_i=(\pm1,\mp1,0,\dots,0)$（即两个分量互为相反数），以为这样才有 $SU(2)$ 的根向量。**发现**：用 (2.17) 核算，$(\pm1,\mp1,\dots)$ 的 $\sum|a_i|=2$、交叉项 $|1|+|1|-|2|=0$，给 $q_R=2$（当 $n_f=2n_c$），不是 1；而**单个** $\pm1$ 分量给 $\sum|a_i|=1$、交叉项全 0，正好 $q_R=1$。**改正**：按「单分量」写，并在 good-bad-ugly 卡的 key_points 里明确写 $(1,0,\dots,0)$。
- **事后确认**：这条也解释了为什么 $SU(2)$ 的增强是「在 Coulomb 分支上」——单分量 $a_i$ 的稳定化子确实是 $SU(2)$ 型，与 p025 的叙述自洽。

## 4. ⚠ 弯路：errata E2（$d_i$ 的单调性）判了三次才定

- **判断点**：p055 说 $d_i$ 可设为 nondecreasing、p056 说 non-increasing，哪一处是笔误。
- **依据**：p055「positive integers that we can assume to be arranged in nondecreasing order」；p056「Since we take the $d_i$ to be non-increasing, the D5-branes can be separated in the y direction」；p014 的第二约束要求同类五膜的 linking number 从左到右非降，而 p056 又说 D5 的 linking number 就等于 $d_i$。
- **结论与理由**：**第一次判**：p056 错——因为它与 p014 的非降要求直接冲突，且 brane 构型里 D5 是从左到右排的。**第二次判**：p055 错——因为 Young 图的惯例是行长度非增（从上往下），p055 自己在同一段就按 Young 图第 $i$ 行长度 $d_i$ 排。**第三次判**：两处说的不是同一件事——p055 说的是「把分拆画成图时的行序」，p056 说的是「brane 在 $y$ 方向可分离」，而方向只影响画法（$\{d_i\}$ 是多重集，物理不变），**无法判定谁错**。于是从 medium 降为 **low（存疑）**，卡片不改，只在 errata 里记「三方冲突、建议以 p056 为准」。
- **事后确认**：这正是 BRIEF §9 说的「只有一处冲突记 low 存疑、卡片不改」；教训是**不要在无法定案时硬判 high**。

## 5. ⚠ 弯路：$T_\rho$ 与 $T^\rho$ 的下标方向，先写反了

- **判断点**：$T_\rho$ 是 Higgs 侧还是 Coulomb 侧？$T^\rho$ 呢？
- **依据**：p058 算出 $\mathcal H_{T_\rho}=\overline{\mathcal O_{\rho^{D}}}$；p059 说 $T^\rho$ 的 Higgs 分支是 $S_\rho\cap\mathcal N$；p060 只写「$T_\rho$、$T^\rho$ 都是 $T^{\rho}_{\rho'}$ 的特例」，没指明下标方向。
- **结论与理由**：**写错**——最初按「下标=左边、上标=右边」的直觉，把 $T_\rho$ 当成 $T^\rho_0$（左端极点、右端平凡），于是 p058 与 p059 两条分支公式对不上（$\overline{\mathcal O_{\rho^D}}$ 与 $S_\rho\cap\mathcal N$ 会互换）。**发现**：用 $T^{\rho}_{\rho'}$ 的 Higgs 公式 $\mathcal H=S_\rho\cap\overline{\mathcal O_{\rho'^D}}$ 检验，只有当 $\rho'=0$ 时它给 $S_\rho\cap\mathcal N$（因为 $\mathcal O_{0^D}=\{0\}$ 的闭包是 $\{0\}$，而 $0^D$ 是正则嵌入），故 $T^\rho=T^\rho_0$；同理 $T_\rho=T^0_\rho$。**改正**：按这个约定写，并把推理过程标成 provenance B（推断，非原文直述），写进 `t-rho-rhoprime` 卡与 notes §6 第 8 条。
- **事后确认**：`gaps` 里明写了「这条是推断」；若后续有人核出相反约定，只需改这一个卡与 notes 的一行。

## 7. A/B/C/D 四类 source 的选择标准

- **判断点**：同一句话，什么时候标 A、什么时候标 B。
- **依据**：BRIEF 规定 A = 原文直接陈述（必须逐字 quote）、B = 由原文多处合并/推断、C = 本文档自己的推导、D = 二手（表格/图注转述）。
- **结论与理由**：凡是**能逐字引**的段落一律标 A（本篇 60 条 A 类 quote 全部通过机器核对）；Table 的逐格内容标 D（我只重述、不逐格抄）；我自己的合并与推断（如 $T_\rho=T^0_\rho$、$T(G)$ 与 mirror 的方向论证）标 B。**放弃**「为了好看全标 A」：Table 1/3/4 的内容无法用一句 12–120 字符的引文覆盖，硬标 A 会让 `verify_pages` 失败或让 quote 与内容不符。
- **事后确认**：`verify_pages` 报「核对 60 条，跳过非 A 0 条，问题 0 条」——说明所有 A 类 quote 都在正确页上。
