# 「重正化」应为「重整化」

- **id**：`bdh/correction/renormalization-not-chongzheng`
- **类型**：correction
- **位置**：§10
- **问题**：为什么 10.1.4 里的「重正化泛包络代数」必须改成「重整化泛包络代数」？

> 同一个 $U^{\natural}$ 在一处叫「重正化泛包络代数」，在 §5.6 标题与别处叫「重整化」。

## 位置

§10.1 ch10.tex:48

## 原文片段

```latex
重正化泛包络代数
```

## 改为

```latex
重整化泛包络代数
```

## 依据

同一对象的专名在 §5.6 标题（ch05.tex:881「重整化泛包络代数」）与 5.2.17（ch05.tex:125「「重整化」包络代数 $U^{\natural}$」）都作「重整化」，10.1.6（ch10.tex:76）与 10.1.4 的同一 $U^{\natural}$ 也作「重整化」；术语表把 renormalization 冻结为「重整化」。译名并存会让读者把「重正化」当成另一个代数——物理文献里两种写法虽都见得到，但本书必须统一，否则 10.1 与 5.6 的指称对不上。

## 说明

译本改译：改 ch10.tex:48 一处「重正化」→「重整化」；ch05.tex:125（5.2.17）原有的同类一处在本轮也一并统一。依据是 §5.6 标题与术语表，未对照英文印刷页。

## 批注

### 易错预警：「重正化」与「重整化」在本书不能并存

两者都是 renormalization 的常见译法，物理文献里常混用；但在同一本书里，$U^{\natural}$ 只有一个。读者若在 10.1 读到「重正化」、在 5.6 读到「重整化」，会以为是两个不同的代数，而 10.1.6 的 $a^{\flat}$ 恰好依赖它们其实是同一个对象。

### 含糊点拨：为什么以「重整化」为准

§5.6 的节标题是全书最早、最显眼地引入 $U^{\natural}$ 的地方，且术语表已把 renormalization 冻结为「重整化」；10.1 只是引用 5.6 的构造。统一到标题与术语表的写法，比让正文各处各自为政更安全，也便于交叉引用。
