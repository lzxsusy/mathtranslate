# 4.2.5 证明 (i) 中 $L_1\cap L_2$ 应为 $L_+\cap L_-$

- **id**：`bdh/correction/l1-l2-should-be-l-plus-minus`
- **类型**：correction
- **位置**：§4
- **问题**：为什么 4.2.5 证明 (i) 里的 $L_1\cap L_2$ 必须读作 $L_+\cap L_-$？

> 4.2.5 的记号只有 $L_+$、$L_-$，证明里却冒出未定义的 $L_1$、$L_2$。

## 位置

§4.2 ch04.tex:308

## 原文片段

```latex
V^{2}:=(L_{1}\cap L_{2})\oplus P
```

## 改为

```latex
L_+\cap L_-
```

## 依据

4.2.5 通篇只有 Lagrange 三元组 $(V;L_+,L_-)$ 这一组记号，没有 $L_1$、$L_2$。证明要造正交分解 $V=V^1\oplus V^2$，使 (i) 中 $L^2_+=L^2_-$ 成立；能同时落在 $L_+$ 与 $L_-$ 里的最大子空间正是 $L_+\cap L_-$，所以第二块只能取 $V^2=(L_+\cap L_-)\oplus P$。若照原样读，$V^2$ 无定义，$V^1=(V^2)^{\perp}$ 也随之失效，4.2.5 的整个归纳构造从一开始就断了。

## 说明

译文未改，照原文保留。校订时在 ch04.tex:309 加 [Tutor Note] 指出按上下文应为 $L_+\cap L_-$，正文仍照底本印作 $L_1\cap L_2$，未径改。这是判断而非事实：依据是 4.2.5 自身的记号与分解的正交性，未对照英文印刷页。

## 批注

### 易错预警：这里的下标 1、2 是「块」的编号

$V^1$、$V^2$ 是分解的两块，$L^1_\pm$、$L^2_\pm$ 是各块上的 Lagrange 子空间；$L_1$、$L_2$ 不是本节的记号。看到 $L_1\cap L_2$ 时，应当把它读成两块上的 $L_+$ 与 $L_-$ 的交，而不是另外两个子空间——否则会去找它们的定义而找不到。

### 含糊点拨：为什么第二块要取 $L_+\cap L_-$

4.2.5(i) 要的是 $L^2_+=L^2_-$，即两个子空间在 $V^2$ 上重合；同时落在 $L_+$ 与 $L_-$ 里的最大子空间正是 $L_+\cap L_-$，取它再加上 $P$ 才能让 $V^2$ 是 Lagrange 的，并让 $V^1=(V^2)^{\perp}$ 自动满足对偶条件。
