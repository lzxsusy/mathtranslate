# 13_lecture_notes · 视频讲义笔记专栏

本专栏收**视频形式**的数学讲义（会议报告、系列课、暑期学校），把「只有录像」的知识变成
可检索、可引用、可训练的文本：**逐页幻灯片转写 + 讲者原话摘录 + 时间轴**。

2026-11-27 新建。规程见 [`04_playbook/24_视频讲义提取与笔记规范_v1.md`](../04_playbook/24_视频讲义提取与笔记规范_v1.md)。

## 为什么单开一栏

录像里至少有三层信息是 PDF 讲义给不了的：

| 层 | 内容 | 怎么来 |
|---|---|---|
| 文字层 | 幻灯片上的正文、公式、图注 | 关键帧逐页视觉转写（公式转 LaTeX） |
| 口述层 | 讲者怎么解释这一页、为什么这么讲、哪里是"我认为"、哪里是"已知" | Whisper 转写 + 术语表清洗 |
| 时间层 | 每一页在录像里的出现时段，把两层按时间对齐 | 帧差分割 + 区间合并 |

第三层是关键：它让「这句英文」和「这页公式」落在同一个时间戳上，于是笔记可以逐段带
`[t=hh:mm:ss]` 出处，读者能立刻回录像核对，机器也能把一段话对到一页幻灯片。

## 编号与目录

```
13_lecture_notes/
  README.md                      本文件（专栏索引）
  VLN-<三位序号>_<姓氏><年份>_<短题>/
    README.md                    元数据卡 + 产物清单 + 复现命令
    notes/main.tex               笔记源码（xelatex/ctexart）
    notes/VLN-xxx_讲义笔记_v1.pdf 成稿 PDF（自撰，随仓公开）
    source/                      语料：逐页 markdown、blocks jsonl、ASR srt/json
    tools/                       本条用的提取脚本（可从模板改）
    _local/                      只在本机：录像、关键帧、原 deck 页面图（gitignore）
```

编号只增不改，`VLN-001` 起。`_local/` 一律不进仓库（见下"红线"）。

## 准入标准

收一条要有：**清晰度够读公式**（≥720p 的屏幕录制）、**讲者本人出镜讲解**（不是配乐幻灯片）、
**内容有分量**（新结果、综述、或把某套工具讲透）。三者缺一就只做索引不做笔记。

## 质量等级

| 等级 | 含义 | 判定 |
|---|---|---|
| A | 可直接引用 | ≥30 条公式逐条回帧核对、≥5 处时间轴回放核对、术语与 `01_corpus_zh/数语规范/` 对齐 |
| B | 可用待校 | 逐页转写完整、公式抽检 10–20 条、时间轴未逐条回放 |
| C | 部分 | 缺页、音频缺失、或只做了章节级摘要 |

等级写在笔记首页与元数据卡里，**引用前先看等级**。

## 红线（与 COMPLIANCE.md §4 一致）

- ✅ 可发布：自己的中文叙述、术语表、时间轴、slide **正文短句**摘录（带时间戳）、公式、自写 LaTeX/PDF。
- ❌ 不发布：录像文件、关键帧、**原 deck 的任何页面图像**（含据此重建的 PDF）、模型权重。
  这些只存在 `_local/`，`.gitignore` 已挡。
- 引用一律短句 + 时间戳；不复刻整页讲稿。讲者若提出撤下，按 COMPLIANCE §9 处理。

## 新增一条的流程

1. 复制 `VLN-template/` 骨架，改编号与短题。
2. 拉录像 → 抽帧（1 fps）→ 帧差分割出页 → 逐页视觉转写（公式转 LaTeX）。
3. 音频切块并行转写（Whisper），用术语表清洗专名（不动原转写）。
4. `merge_corpus.py` 按时间对齐两层，折叠 build 链，产出 `blocks.jsonl` 与逐页 markdown。
5. 写 `notes/main.tex`（结构见规程 §6）→ `xelatex` 两遍 → 填元数据卡 → 跑仓库闸门再提交。

## 与其它专栏的分工

- `05_seminar_witten/`：Witten **论文**的研讨班产出；本栏是**讲座录像**，不重复。
- `08_source_code/`：文献译注工程；本栏不译文献，只记讲者讲了什么。
- `datasets/`：结构化资料卡；本栏的 `blocks.jsonl` 可作为后续建卡的原料，但不直接进 `datasets/`。
