PLAYBOOK-02 ｜ v1.0 ｜ 2026-11-18 ｜ 强制前置：MEMORANDUM-01

适用对象：Deligne, Etingof, Freed, Jeffrey, Kazhdan, Morgan, Morrison, Witten, Quantum Fields and Strings: A Course for Mathematicians, Vol. 1–2, AMS 1999（IAS 1996–97 专题年讲义）。Vol. 2 收录 Witten 整理的 Homework（pp. 609–717：秋季题单、Fall exam、Superhomework 等），以及 D'Hoker（pp. 807–1011）、Witten（pp. 1119–1424）、Seiberg（pp. 1425–1495）的题单；这套题附解答。

效力：本文件是 MEMORANDUM-01 在"习题课"场景下的实例化。两者冲突时以 MEMORANDUM-01 为准；本文件可以更严，不可以更松。

开工条件：python tools/check_memo_gate.py --role <你的角色> 返回 OK。没有回执不许开工。

§0 一句话

把"学生卡在哪一步"变成可复现的坐标，而不是一句感慨。

不是"学生做不出题"这件事值钱，是"卡点 + 最小能解开它的提示 + 事后归因"这三样合起来值钱。只统计做对做错，这数据一文不值。

§1 为什么这件事值得做（三条，每条都有代价）

1.1 这套题自带答案——ground truth 不需要我们造。
本库最贵的东西是"判断的轨迹"（MEMO §1.1），而这道题的成本结构罕见地对：题面是现成的、答案是有出处的、难度是作者设计过的。相比自己出题再自己判卷，这里每一步都有第三方锚点（书页）。

1.2 卡点是天然的难度标签，提示是天然的过程标签。
MEMO §5 的 obligation 测试要我们"挖掉结论让模型补、数失败次数"；这套题不用挖——学生本来就要补。而最小能让对话继续的那一级提示，就是"缺口有多大"的度量：

  • 一级都不用 → 题目在能力之内，只值一条"已会"；
  • 要到 L3（命名技巧）才通 → 缺口是"没想到那个招"，这是最值钱的一类；
  • 要到 L4（给第一步式子）才通 → 缺口是"不会起手"；
  • 到 L5 才懂 → 不算解出，但这是负样本，同样要留。

1.3 三个人卡在同一处，那个 locator 就是正文的缺口。
这是本工程最想拿的副产品：三个独立学生、同一道题、卡在同一页同一行，说明正文那一处在数学上跳了一步——正好填 datasets/math/ 的 gap 字段和 datasets/deepread/ 精读卡。你原来靠人工找"作者跳过的那一步"，现在有机器帮你指出来。

反向警告（写在最前）：如果这一周只产出"4 题全对"或"2 题没做出来"这种结论，说明流程没设计对。没有 stuck_at、没有 minimal_rung、没有归因，就等于没做。

§2 角色（五个机器角色 + 你）

角色谁干什么绝不能干什么
主持人你（人）每周一次课，只做三件事：定题、看卡点、裁决争议不给提示。你一旦提示，样本就废了
题库官机器按 section 选题、逐字抽题面与答案、标 rights 与 depends_on不改写题面；不挑"看起来好做"的题
提示作者机器不看学生任何尝试，只据题面+答案写 L0–L5 阶梯不得事后改阶梯；不得因某学生卡住而特调
复算员机器独立复算书中答案，标 verified / as_printed / disputed不得参考学生解答；不得"照抄答案当验证"
学生 ×3机器只拿正文 + 题面，独立 session，尝试并当场报告卡点不得看答案、不得看别人 transcript、不得看提示阶梯全文
审计员机器课后读 transcript：卡点归类、泄漏检查、假解判定不得参与出题、出提示、当学生

模型分配硬规矩：教师（提示作者/复算员）与学生必须不同模型族（MEMO §6 角色分离）。同一模型既当学生又当老师，学生的"卡点"会退化成"老师没想到的点"，不是认知卡点。

§3 选题：按 section 抽，不按难度抽

每周 4 道，同一节内：

配额类型目的
2 道正文可直接推基线；用来确认学生真的读了正文
1 道需要组合正文两处抓"跨段引用"缺口
1 道原文没给动机/没给起手抓"未见技巧"缺口（C3 的主要来源）

排除：纯体力计算题（除非这周就想练规范化）、依赖未译章节的题、题面本身有歧义的题。

每题必须记：src_page（题面页）、answer_page、rights、depends_on（正文哪几页）、section。

权利口径：题面与答案都是商书内容，只进 _internal/；对外只发布"卡点坐标 + 归因 + 补法"，不复制题面（COMPLIANCE 第 3 类，"book 派生只进 _internal"）。

§4 提示阶梯 L0–L5（预注册，不许临场加级）

级给什么判据（给完看学生能不能往下走）
L0复述题意：确认对象、指标、要证的结论学生能用自己的话重述
L1回指定义/定理：只给正文 locator，不给内容学生能自己翻到并引用
L2给同类已解例子：书内或本库的结构同型例子学生能说出"这里对应哪一步"
L3命名技巧/ansatz：只给名字，不给式子学生能自己写出起手式
L4给第一步式子 / 给关键恒等式学生能续到收尾
L5全解本轮记 solved: false，但轨迹全留

五条硬规矩：

  1. 一次只给一级，给完必须等学生的下一步再决定是否升级；
  2. 教师不得跳级（不许 L1 直接到 L4）；
  3. 教师不得临场编造阶梯外的提示；实在需要，标 improvised: true，单独统计，不进主表；
  4. 学生不得先看阶梯全文再描述卡点（顺序反了，卡点数据就废——他描述的是"看完提示后的卡点"）；
  5. L5 之后不再追问，直接进入课后复盘。

§5 卡点冻结（全流程最关键的一步）

学生一旦说出"我不知道下一步""这里应该用什么"，立刻执行冻结，顺序不能反：

  1. stuck_at：他自己认为卡在哪——必须带 locator（题号/小问/自己推到的式子）；
  2. claim：原话照抄，不改写、不润色；
  3. student_state：三个字段——已建立的对象、已用的公式、当前目标；
  4. 然后才允许教师给下一级提示。

审计员事后要分两栏记：

字段含义
self_reported学生自己说的卡点
audited审计员读 transcript 后判定的实际断点

两者不一致本身是高价值标签（元认知缺口）：学生以为卡在"不会算积分"，实际卡在"没意识到该用哪个守恒量"——这类错位，恰好是训练"自我诊断"最缺的样本。

§6 归因：7 类 + 1 类假解

代号类别判据（怎么认出它）修复动作
C1前提缺失缺一个定义/定理，题面用了但正文在后面才给补 prereq，记 locator
C2记号/约定指标、符号、归一化、约定（如 $i\epsilon$）不一致补一页"约定卡"
C3未见技巧全对但想不到 ansatz / 对偶 / 变换记"技巧名 + 触发条件"
C4计算滑步方法对，算错（因子、符号、指标）记错误类型，不记题
C5逻辑跳跃不知道"凭什么这一步成立"（交换极限、取值域、收敛）补 warrant（MEMO §3）
C6目标误解解错了对象/答非所问/漏小问记"他以为要证什么"
C7不知何时停止过度计算 / 不知道完成判据补"done 判据"
C8假解自认为做完，实际错；且无自检最高权重（判别力样本）

每条归因必须三件套：class + locator（正文/题面/答案的页行）+ evidence（原话）。没有 locator 的归因不入库（MEMO §0 铁律 1）。

一致性门槛：两个审计员独立标 30 条，κ ≥ 0.6 才允许把归因当标签用；不到就回去改判据，不是改数据（MEMO §9）。

§7 数据 schema：datasets/exercise/exercise.jsonl

一条记录 = 一道题 × 一个学生 × 一次运行。

{
  "ex_id": "QFS2-HW-<页>-<题号>",
  "book": "QFS-1999",
  "volume": 2,
  "section": "<节标题>",
  "src_page": 000,
  "answer_page": 000,
  "rights": "book",
  "depends_on": [000, 000],
  "statement_verbatim": "<逐字抄录，不改写>",
  "answer_status": "verified|as_printed|disputed",
  "answer_sha": "<前 16 位>",
  "hints": [
    {"level": "L0", "text": "..."},
    {"level": "L1", "text": "...", "locator": "[src p.000]"}
  ],
  "student_model": "<族/版本/温度/上下文预算>",
  "turns": 0,
  "stuck_at": {"locator": "[src p.000, eq x.y]", "claim": "<原话>"},
  "self_reported": "C1..C8",
  "audited": "C1..C8",
  "minimal_rung": "L0..L5",
  "solved": true,
  "wallclock_s": 0,
  "tokens": {"student": 0, "teacher": 0},
  "leak_check": "pass|fail",
  "auditor_note": "<为什么这么归类>"
}

入库门槛：stuck_at 有 locator、audited 有 evidence、leak_check=pass、answer_status≠disputed（disputed 先挂起）。四条缺一条不入库。

§8 每周一次课：90 分钟时间盒

你只有每周一次讨论，所以流程必须课前机器跑完、课上只看人。

T−1 天（机器，约 30 分钟，不占你的时间）

  1. 题库官：按 §3 抽 4 题，抽题面/答案/依赖页，写 week_XX/intake.json；
  2. 提示作者：盲写 4 套 L0–L5 阶梯（不接触学生）；
  3. 复算员：独立复算 4 个答案，标 answer_status；
  4. 起 3 个学生 session（互不可见），每人拿 1–2 题，只给正文页。

课上（60–75 分钟，你在场）

  • 三个学生并行尝试，教师按阶梯逐级给提示；
  • 你只看两件事：卡点落在哪一页；提示有没有越级。看到越级就喊停；
  • 每题 10–15 分钟封顶，到点未解 → L5 + 记负样本，不恋战。

课后 20 分钟（机器）

  • 审计员：归类 + 泄漏检查 + 判定 C8 假解；
  • 产出 week_XX/report.md：卡点地图（按 locator 聚合）+ 3 条"正文缺口待补" + 本周 minimal_rung 分布；
  • 你周末花 10 分钟读这一页，决定下周是换 section 还是回补。

一学期（约 16 周）：4 题 × 16 周 = 64 道题 × 3 学生 ≈ 190 条轨迹；一学年 ~380 条。这个量不够训模型，够做评测集、够训提示模型、够定位正文缺口——定位要诚实（MEMO §1.2 推论三）。

§9 费用与规模（学生预算版）

项预算说明
学生每回合≤1.5K token学生不需要长篇推理，要的是"下手"
教师每回合≤3K token只输出一级提示，禁止讲解全文
单题单学生≈8 回合 ≈ 40K token4 题 × 3 学生 ≈ 480K token/周
模型档位学生用便宜档/本机小模型；教师中档；L0–L2 绝不用贵档贵档只在 L3+ 的一两轮用

明确不做（与 MEMO §8 一致）：

  • 不并行多 agent 解同一题（12 人并行 = 八个自说自话，本库实证）；
  • 不追求"每题都解出"（解出率 100% 说明题选得太水）；
  • 不为省钱删掉"卡点冻结"和"归因"（那等于删掉全部价值）。

§10 怎么算成功（四条，少一条都不算）

  1. 可复核卡点：30 条轨迹里 ≥20 条有能被人复现的 stuck_at 坐标；
  2. 归因一致：C1–C8 的 κ ≥ 0.6；
  3. 正文缺口：同一 locator 被 ≥2 个学生卡住的地方 ≥5 处（这是给 datasets/math 的 gap 条目）；
  4. 提示分布：L3 以上占比稳定在 30–60%——太高说明题太难或正文没读，太低说明题太水。

第 8 周做一次中期校准：抽 10 条人审，若和审计员判定差太多，先修判据再继续。

§11 与现有流水线对接

week_XX/                      →  数据集
  intake.json                 →  datasets/exercise/exercise.jsonl（主表）
  hints/（4 套阶梯）           →  exercise.jsonl 的 hints 字段
  transcript/（3 学生）        →  turns / stuck_at / minimal_rung
  report.md                   →  卡点地图 → datasets/math 的 gap_filling
                              →  datasets/deepread 的精读卡（正文缺口）
  • 每周报告存 _meta/weeks/week_XX/，不进发布层；
  • 正文缺口每条单独开一条 datasets/math 候选，走 MEMO §4 的八字段；
  • 每周末在 _meta/read_receipts.jsonl 追加本周回执（见 §13）。

§12 红线（本文件增量，不替代 MEMO §8）

#红线
R1学生 session 的上下文里不得出现答案文件、答案页、阶梯全文
R2提示只能从预注册阶梯里选；临场编造必须标 improvised: true 并单独统计
R3不许把"做出来"当唯一成功；失败轨迹必须保留（负样本是资产）
R4不许同一模型同时当学生和教师
R5学生模型版本、温度、上下文预算必须记录，否则以后无法复现
R6书中答案与复算不符，先记 disputed 并挂起，不得悄悄改书
R7题目/答案不进发布层；对外只发卡点坐标与归因（版权口径见 COMPLIANCE）

§13 开工前 8 问 / 交付前 6 检

开工前

  1. check_memo_gate.py 通过了吗？本周回执记了吗？
  2. 这 4 道题的答案 status 是 verified 吗？
  3. 三个学生是不是独立 session、互不可见？
  4. 学生上下文里有没有答案页？
  5. 阶梯写完了吗？是先写阶梯再开课吗？
  6. 教师和学生是不同模型族吗？
  7. 每题的 depends_on 页在正文里都有吗？
  8. 时间盒定了吗（每题 15 分钟封顶）？

交付前

  1. 每条回合一都有 turns 与 token 数？2. 每条 stuck_at 都有 locator？3. 每条 audited 都有 evidence？
  2. leak_check 全 pass？5. report.md 聚合了卡点地图？6. 本周回执已写？

§14 第一周最小可行版（先跑通，再谈规模）

只做 1 道题、2 个学生、1 个教师、1 个审计员。
目标不是数据量，是验证三件事：

  1. 学生会不会当场说卡点（还是事后编）；
  2. 教师会不会越级（大概率会，这是第一周要发现的）；
  3. 审计员的 audited 能不能对上 self_reported（对不上是正常的，记录差在哪）。

跑通这一周，再上 4 题 × 3 学生。第一周失败是廉价失败，规模上去以后失败才贵（MEMO §11 第 4 条）。
