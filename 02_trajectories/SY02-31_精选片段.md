# SY02-31《朗兰兹纲领 II》精选片段

> 本文件收录全书翻译施工中 10 条典型判定，只保留「当时的信息 → 判断 → 证据」，
> 完整工作流见 `09_thinking/chains/SY02-31_朗兰兹纲领II_翻译工作流.md`。

## 1. 583 页专著怎么通读：按篇分级，不按全书通读

- **任务意图**：施工纪律 §1.0 要求先通读后落笔，但 583 页、六位作者、六篇独立长文，逐页通读在预算上不可行。
- **关键动作**：① 抽目录与各篇导言，建「篇—印刷页—PDF 页」映射表；② 每篇标注中心问题、主定理、依赖前篇的部分；③ 把「每章开译前细读整章」下沉给该篇 worker，lead 只保留篇级地图。
- **验证证据**：`工程文件/reports/U00_通读与结构测绘.md`、`work/通读笔记.md`；第 5、6 篇的速读描述在拿到真实摘要后**整段重写**过一次。
- **结论**：分级通读不是偷懒，是把「全局一致性」和「局部准确」分给不同角色；篇级地图错了，47 个分片会一起错。

## 2. 书籍底本不发布成品 PDF：R3 优先于「交付七件套」

- **任务意图**：仓库惯例要求 `deliverable/*.pdf`，但底本是 AMS 在版图书。
- **关键动作**：查 `04_playbook/17_仓库理念与上传规范.md` §3.3 与 R3 判定，对照 SY02-25（同为在版图书）先例。
- **验证证据**：`工程文件/deliverable/README.md` 写明「不入库成品 PDF，附三遍编译命令」；`RELEASE_REGISTER.csv` 该行「成品级别=成品不公开、成品在仓=否」。
- **结论**：合规优先。译文源码是演绎作品，PDF 是完整替代品——两者的法律风险不是一个量级。

## 3. 页锚用 `\ysrc` 而不是「页码对照表」

- **任务意图**：译注要能回原文核对，最省事的做法是文末放一张「译文页↔原书页」对照表。
- **关键动作**：改为在正文每个原书页起点插 `\ysrc{印刷页}`，渲染成页边灰色小号页码 + `\hypertarget`。
- **验证证据**：`pageaudit.py` 逐块核对锚的递增与跨块衔接，全书 562 个锚、0 缺失、0 重复；读者在 PDF 里直接看到原书页码。
- **结论**：对照表会随重排失效，页边锚跟着内容走；代价是 worker 每页都要记得插锚，所以把它写进了硬性回报格式。

## 4. 定理编号必须复刻原书，不能由 LaTeX 重新编号

- **任务意图**：底本编号是「篇.节.编号」（如 4.5.3），直接 `\begin{theorem}` 会得到「定理 4.1」之类，交叉引用全错。
- **关键动作**：`\newtheorem{ithm}{定理}` + 包装环境 `\begin{thm}{4.5.3}`，在计数器步进前 `\renewcommand{\theithm}{#1}`，`\label`/`\ref` 因此解析成原文编号。
- **验证证据**：`partial.toc` 与底本小节号逐条比对（7.1–7.9、9.1–9.6 完全一致）；`audit_num.py` 抽 802 条编号陈述核对类型分布。
- **结论**：译本的编号是「引用接口」，不是排版细节；编号错一位，读者按图索骥就找不到原书。

## 5. 47 个分片并行：并发上限 8 是硬约束

- **任务意图**：253 页的第 4 篇必须并行，否则单线程做不完。
- **关键动作**：按 10–13 页切片、每片一个 worker 直写 `源码/chunks/`；实测第 9 个 worker 直接报 `Error: subagent limit reached (active child limit: 8)`，于是改成「完成一个补派一个」。
- **验证证据**：47 片全部落盘；`partial.tex`（`\IfFileExists` 包住缺片）让 36 片时也能整书编译，365 页 0 error。
- **结论**：并行度是平台给的，不是计划的；能增量编译，才敢在缺片状态下继续推进。

## 6. tikzcd 的空单元格不是节点（两次事故）

- **任务意图**：把原书交换图重绘成 tikz-cd。
- **关键动作**：两次报 `! Package pgf Error: No shape named tikz@f@…`，回看原图发现箭头指向的格子是空的；改法是把箭头挪到有内容的格子上，或在目标格补节点。
- **验证证据**：`ch-a4-06`（5.3.9）把 `\iota` 从 `D` 移到 `D'`、给 `z^N\mathcal R(\eta_2)` 补上钩；`ch-a4-07` 五节点图改 `\arrow[ddll]\arrow[dl]\arrow[dr]`。
- **结论**：这是 tikzcd 的语义限制，不是笔误；把它写进 worker 提示词后同类错误归零。

## 7. perfectoid 一次性统一：48 处、一个决定

- **任务意图**：第 3 篇三块里，a3-01 用英文 perfectoid 44 处，a3-02/03 用「完美胚」，同篇不一致。
- **关键动作**：查本库既有译法与中文文献通行度，决定用「完美胚（perfectoid）」，脚本替换 48 处，首现补括注，glossary 加三条。
- **验证证据**：`lint.py` 旧术语规则删除后复扫 `terms=0`；glossary 230→279 行。
- **结论**：术语统一要一次性做，不能留给「以后再说」；但决定之前必须先证明库里没有相反先例。

## 8. Langlands 保留拉丁：546 处 vs 7 处的取舍

- **任务意图**：正文里「朗兰兹」与「Langlands」混用。
- **关键动作**：统计全书 chunk：拉丁 546 处、中文 7 处；书名仍作《朗兰兹纲领 II》。据此定「正文拉丁、书名中文」，并改前言/导读/译者说明与 glossary 前 5 行。
- **验证证据**：`fix_langlands.py` 全量替换 + 空格规整；glossary 等级标 I（本库既有译法，SY02-08 标题同此）。
- **结论**：术语一致性以「全书统计 + 本库先例」为准，不以个人语感为准。

## 9. 参考文献整段保留英文

- **任务意图**：参考文献占 40 余页，逐条翻译题名既无收益又易错。
- **关键动作**：条目整体保留英文，仅译「参考文献」标题；作者名重音、DOI、MR 号照录；`refs` 环境加 `\raggedright` 防长作者名溢出。
- **验证证据**：`coverage.py` 把文献页标为低比值异常，逐页核过后确认「非漏译」；U04 报告留档。
- **结论**：译本的可回检性优先于「全中文」的表面完整性；这条要写进译者说明，否则读者会以为是漏译。

## 10. 对齐卡只标 `status: g`，不冒充已形式化

- **任务意图**：仓库有 Lean 对齐卡制度，容易顺手写成 `certified`。
- **关键动作**：6 张卡全部 `status: "g"`（gap），只给候选 Lean 陈述与缺口说明；生成用 Python 字典 + `json.dumps`，写完 `json.loads` 逐行回读。
- **验证证据**：`资料卡/对齐卡/alignment.jsonl` 6 行可解析；首版手写 JSON 因 Lean 代码反斜杠未转义报 `Invalid \escape`，已重写。
- **结论**：对齐卡的价值在「缺口写得准」，不在状态好看；谎报 certified 会让下游形式化工作直接踩空。
