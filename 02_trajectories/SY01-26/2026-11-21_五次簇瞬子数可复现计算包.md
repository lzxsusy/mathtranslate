# SY01-26 增补：五次三维簇瞬子数的可复现计算包（2026-11-21）

## 目标

用户要求：① 把 412 页修订版 PDF 放到桌面，等他去「数译」网站覆盖旧版；② 让读者能**亲手验证**
书里那十个瞬子数 $n_1,\dots,n_{10}$——去网上找现成程序、本地跑通，把程序与计算过程入库，
或直接放进书里。

## 依据

- 公式出处：Cox–Katz §5.6.4 例 5.6.4（中译本式 (5.72)，`chapters/chapter05.tex` 标签
  `eq:quintic-normalized-yukawa`）：$Y=\dfrac{5}{(1+5^5z)y_0^2}\big(\tfrac qz\tfrac{dz}{dq}\big)^3$；
  第 2 章瞬子展开 $Y=5+\sum_d n_d d^3 q^d/(1-q^d)$。
- 网上检索（2026-11-21）：
  - Gathmann 的 habilitation（Kaiserslautern）附 **Maple** 脚本，用 `N1 := Phi(FI((5*H2)^6))` 手算，
    <https://agag-gathmann.math.rptu.de/pub/habil.pdf>；
  - J. Straat 的 Utrecht 硕士论文提到 `quintic.py` 算到 $d=5$ 并列表，
    <https://utrecht-theses-test.atmire.com/bitstream/handle/20.500.12932/49915/thesis_JesseStraat.pdf>；
  - `SuperInstance/lau-mirror-symmetry`（Rust）只硬编码 2875、609250 等前几项，不是真算；
  - 讲义里的 Frobenius/Γ 函数周期通式，<https://arxiv.org/abs/2610.14189>。
  结论：**没有可 `pip install`、维护良好的现成包**。
- 项目内已有第三条实现：`工程文件/工作流/scripts/verify_quintic_frobenius.py`（逐项递推，136 行）。

## 判断

1. 既然网上没有可复用程序，就把"复算"做成**两条互不共享代码的路径**，比单脚本更有说服力：
   - 路径 A（`quintic_gw.py`）：`Fraction` 精确算术；镜像映射 $q=-ze^{G}$ 的逆用 **Lagrange 反演闭式**
     $z=\sum\frac1n[z^{n-1}](-e^{-G})^n q^n$；复合进 $Y(z)$ 后读系数。0.01 秒。
   - 路径 B（`quintic_gw_contour.py`）：`mpmath` 60 位；沿 $|q|=r$ 圆周采样做**围道积分**
     $c_d=\frac1M\sum_k Y(q_k)/q_k^d$，每个采样点的 $z(q)$ 用**牛顿迭代**。
2. 书里放"读者可自己算"的最小侵入方式：附录 C 加一条译注（原书 PDF p133 = 印刷 p110），
   给目录名与仓库地址；不新增附录，页数仍 412，页码对位不受影响。
3. 顺带修掉附录 C p27 条里漏进 LaTeX 正文的 Markdown 星号（`**…**`）。

## 结论

- 两条路径独立给出 $n_1,\dots,n_{10}$，与文献值、与第 2 章表格（$N_1=2875$、$N_2=4876875$、
  $N_3=8564575000$）逐位一致；输出存 `out_exact.txt`、`out_contour.txt`。
- 调试记录：路径 B 首版把累加器写成 `mp.mpf(0)+0j`，退化为 float64，$n_{10}$ 末位偏 835；
  改 `mp.mpc(0)` 后全对。这说明精度必须落在 mpmath 复数上，不能靠 Python `complex`。
- 编译：412 页，0 undefined reference；术语四项源码层与 PDF 层均为 0。
- 提交 `991311c6`，已推 atomgit `master:main` 与 gitee `master`。
