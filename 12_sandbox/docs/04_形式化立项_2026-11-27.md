## 3. 车道 B：定义库（两周试点）

试点目标不是「证明定理」，是**把一条链上的每个类型都变成有真实定义的类型**，让定理陈述合法而可 sorry。

**B1（19:00 第一跑）骨架四定义**，新建 `datasets/leanstmt/lean/ShuyiFormal/GeomLanglands/Basic.lean`：

| 定义 | 形态 | 说明 |
|---|---|---|
| `HuberPair` | `structure`（`A : Type u`，`Aplus : Subring A`，完备性/有界性作为字段 `Prop`） | 不用 mathlib 的 `Valued`，因为 adic 谱要的是环 + 开子环对 |
| `Spa` | `def`（`HuberPair → Type`，先给 `Set`/`PrimeSpectrum` 上的子类型） | 只要类型可陈述，不用真的证明连续性 |
| `Perfectoid` | `structure`（`p` 固定、`Aplus` 的 Frobenius 满射等作为字段） | 先把 `p` 写成显式参数，避免 `Fact p.Prime` 地狱 |
| `tilt` | `def`（`Perfectoid → Perfectoid`），`R^♭ := lim_{←Frob} R/p` | 与 `04-术语文献勘误` 的「倾斜」一致；`untilt` 保留英文 |

硬约束：**禁止 `def X := PUnit`**；禁止 `axiom` 出现在这四者里（`opaque` 只允许出现在接口卡，且必须在 gap ledger 里登记）。允许 `sorry` 只出现在定理陈述的证明位。

**B2（第二、三跑）去占位**：把 `ScholzeFF/Gaps.lean` 里 `PicardGroup`/`SupercuspidalRep`/`WeilGroup`/`SatakeCategory` 等 `PUnit` 占位，替换成 B1 定义之上的真实结构；`scholzeff-g01` 的「FF 曲线 Pic ≅ ℤ」因此从
`Nonempty (PicardGroup E ≃ ℤ)` 变成一句有内容的陈述。

**B3（第四跑起）接口卡**：GLC I（arXiv:2405.03599）§1.5「$G=T$ 的情形」——`Bun_G`、`Loc_Ǧ`、Hecke 作用、`IndCoh_N` 四张 A3 接口卡，用 `structure` + 显式 `hypotheses` + gap ledger，**不声称证明对应**。

**验收（B 车道第一段）**：`lake build` 0 error；`check_lean.py --run` 43 卡全部 exit=0；`gaps/` 里登记 ≥8 条缺失定义（每条带：名字、为何缺、建议签名、上游页码）；`ScholzeFF` 里占位 `PUnit` 数量从 5 降到 0。

## 5. 风险与止损

| 风险 | 表现 | 处置 |
|---|---|---|
| 定义库变成无底洞 | 每个定义都要先造三层前置 | 每跑只允许**一个**新前置定义；超了就退回接口卡 + gap 登记 |
| 陈述弱化（vacuous） | 类型全是占位，`Nonempty (A ≃ B)` 永真 | `lint_cards.py --strict` 加规则：`PUnit` 占位出现在 certified 卡即 fail |
| 版本漂移 | mathlib rev 与卡里 `mathlib_rev` 不一致 | CI 比对 `verification.jsonl`，不一致即红 |
| 沙盒先建 API 后补内容 | 空壳平台 | 路线图原则：**先复现，再公开，再基线**；L3 只做 Docker + 判分，不做前端 |
| 语料继续膨胀挤占算力 | 又开新翻译项目 | 形式化跑批期间，翻译类排期维持现状、不新增 |
