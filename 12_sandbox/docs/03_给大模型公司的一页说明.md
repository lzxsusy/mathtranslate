# 给大模型公司的一页说明

**这是什么**：一个免费、开源、中文语境的研究级数学形式化沙盒与语料库。  
**谁做的**：数译项目（142 部数学文献的中文译注 + 页码锚定资料卡 + Lean 形式化）。  
**费用**：免费。没有付费墙，没有商业授权，没有「专家服务」包装。  
**怎么用**：拿去评测、拿去训练、拿去补 mathlib、拿去改；引用即可，不改也随意。

## 为什么可能对你有用

1. **研究级，不是竞赛题**。FATE 最好模型在 FATE-H 上只有 3/100，FATE-X 零有效证明；TCSEXAM 研究级 Lean 最好 70%、第二 38%。竞赛级 benchmark 已经饱和，研究级是下一个前沿。
2. **有出处，抗污染**。每条陈述带 paper / page / display；是从书里重新形式化的，不是从网上抓的。你可以追到原书第几页，也可以证明它不在训练集里。
3. **有判断，不只是证明**。除了 Lean 证明，还有「这条形式化是否忠实」「缺哪个定义」「为什么是 gap」的判断数据。typecheck ≠ 忠实（ProofGate / The Faithfulness Gap），研究级的 judgment ground truth 目前很缺。
4. **中文/双语**。中文研究级数学形式化目前是空位；CMM-Math 是 K-12，OlymMATH 是奥赛。这里是几何朗兰兹、镜像对称、Hitchin 模空间这一层。

## 现在有什么（v0.1 preview）

- 40 张 Lean 卡（21 certified + 19 gap），6 个 Lean 文件，Lean 4.36.0 + mathlib d33c49ca。
- 1,676 张页码锚定资料卡（GLC 154 卡、nLab DAG 67 卡等）。
- 100 张抽样审计 + GLC 154 卡全量审计 + 每日 20 卡外部核验。
- 19 条 gap 的缺口清单（缺 curve genus、缺 Bun_G、缺 Hitchin 模空间……）。

**诚实的短板**：21 条 certified 里不少是研究定理的「离散影子」（整数权、U(1)、有限群、单位根），不是定理本身；主定理（Hitchin、谱曲线、本征膜、镜像对称）还在 gap。v0.1 是 preview，不是 300 题的 benchmark。

## 怎么接

- **数据集**：HuggingFace（v0.1 上线后）——40 卡 + Lean + anchor + status + datasheet。
- **代码/CI**：GitHub——`lake build` + `#print axioms` + 40/40 校验，一条命令复现。
- **Atlas**：静态站——按概念浏览 gap / 定义 / 依赖 / 页码。
- **API**：暂不自建；需要的话用 Lean4Web / HF Spaces / OpenReward 托管。
- **榜单**：v1.0 再说；先有 300 题和 3 个基线。

## 许可边界（重要）

- **自产层**（陈述、Lean、判分脚本、文档）：CC BY 4.0，可商用，署名即可。
- **译文层**：演绎作品，我们不额外设限，但**不能代替原作者/出版社授权**；对外发布只做 clean-room 导出（事实性陈述 + 页码锚 + Lean + 自写注记），不打包译文原文。
- **原文 PDF**：不发布。

## 我们不做的事

- 不卖数据、不设付费墙、不做商业授权。
- 不承诺 SLA、不做 live service；按版本发布（v0.1/v0.2/v1.0）。
- 不刷榜、不造「影子定理」冒充研究级。

## 一句话

如果它对你有用，拿去用、 cite、fork、提 PR；如果没用，它至少是一份可检索、可训练的中文数学语料。  
**我们做这件事，是因为它应该存在，不是因为能赚钱。**
