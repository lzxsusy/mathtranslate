## 2. 每条主线的阅读顺序

### T0 起点四问（Witten 为何写 / CS 量子化难在哪 / 经典相空间是什么）
1. **R01 Atiyah 1988** → 先看"两问"的原始语境：3/4 维流形的新不变量与量子场论的关系。*为什么先读它：本文 §0 的两问不是修辞，是 Atiyah 1988 的转述 [src p.351]。*
2. **R04 Witten TQFT 1988** → 看"拓扑不变性"如何被表述成"配分函数不依赖度规"。*为什么第二：本文 §1 的论证结构完全是这篇的 3 维版。*
3. **E02 Atiyah 书** → 用书版补齐几何动机（Jones 多项式—纽结—3 维流形—规范场）。*为什么第三：R01 只有 15 页，书版有完整的"为什么是 CS"。*
4. **R05 Jones 1985 + R06 FYHLMO 1985** → 确认"要解释的东西"到底是什么。*为什么放后面：Jones 多项式的构造本身不含物理，先有动机再读定义不容易迷路。*
5. **E04 Grabovsky 2022（中译）** → 用一篇现代教学综述把 CS 的经典/量子两端过一遍。*为什么最后：它是二手综述，用于自检，不能替代 1–4。*
6. 回到本文 §1（p.353–356）与 (1.1)–(1.6)，此时应能自己复述"经典相空间 = 平坦联络模空间"。

### T1 几何量子化（预量化 → 极化 → 全纯截面）
1. **E12 Axelrod–Della Pietra–Witten 1991** → 先看"CS 的几何量子化"被完整做过一遍是什么样。*为什么先读它：本文 §2 的路径积分论证在 1991 年被改写成几何量子化，两者对照最能看出 Witten 在 §2 想说什么。*
2. **R27 Ray–Singer 1971/1973** → 解析挠率的定义。*为什么第二：本文 §2 的"一圈 = Ray–Singer 挠率"（p.356–365）没有它就只是口号。*
3. **R33 Atiyah–Bott 1982** → 平坦丛模空间的辛几何/复结构。*为什么第三：极化要选，选哪个由模空间的复结构决定。*
4. **R34 Quillen 1986** → 行列式线丛的 Quillen 度量。*为什么第四：预量化线丛的 Hermite 结构就是它，§2 的"真空能量"归一化靠这个。*
5. **E32 李思《量子力学与几何》中译 第 1 章**（或 E33《量化辛几何导引》）→ 若完全没学过几何量子化，先用 20 页把"预量化—极化—极化截面"三件事弄懂。*为什么放最后：它是补课材料，不是主线。*
6. **R29 Atiyah–Patodi–Singer** 只在需要 eta 不变量细节时查，不必通读。

### T2 Wilson 线 → 模空间穿刺点 → Gauss 约束 → Borel–Weil–Bott
1. **R33 Atiyah–Bott 1982** → 模空间、稳定丛、Borel–Weil–Bott 的原始陈述。*为什么第一：§3.2–§3.3 的每一步都在用它。*
2. **R30 Wilczek–Zee 1983** → Wilson 线与 linking number / 统计的物理含义。*为什么第二：先知道 Wilson 线"物理上是什么"，再读 §3.3 的穿刺。*
3. **E11 Hitchin 1987** → 自对偶方程的解空间 = Hitchin 系统。*为什么第三：它给出"穿刺点 = 标记"的几何解释，是本文 §3.2 与后世 Hitchin 语言的桥。*
4. **R37 Kac 书（第 1、2 章 + 第 12 章）** → 只查 Kac–Moody 表示与可积最高权。*为什么第四：Borel–Weil–Bott 在仿射情形就是"可积表示"，不查书读不下去。*
5. 回本文 §3.3 (3.4)（p.371–373），把 "Wilson 线沿结 = 在模空间上插入一个标记点" 这句话自己写一遍。
6. 可选：**E23 Gukov–Schwarz–Vafa** 用于看 T2 的现代去向（BPS 态计数），但这是 T6 的入口，不是 T2 的必读。

### T3 共形块与 WZW
1. **R26 Witten 1984 WZW** → WZW 模型本身（作用量、手征代数、与自由费米子的等价）。*为什么第一：共形块是它的东西。*
2. **E34 Knizhnik–Zamolodchikov 1984 + R32 BPZ 1984** → 先看 current algebra 的 KZ 方程（共形块满足的微分方程），再看 BPZ 建立的"共形族"语言。*为什么第二：§3.2 说"共形块"时技术内核就是 KZ 方程（Witten 正文用到、但 39 条参考文献未列），BPZ 提供术语。*
3. **R37 Kac 书 + Kac–Peterson 1984** → 可积最高权表示、WZW 的特征标。*为什么第三：Verlinde 公式的左边是特征标。*
4. **R11 Tsuchiya–Kanie 1988** → SU(2) WZW 的共形块与编织群表示。*为什么第四：这是本文 §3.2 唯一直接对应的数学定理。*
5. **E13/R16 Segal 1988** → 把上面全部重述成函子。*为什么第五：读完 1–4 再读它，才看得出"定义"在定义什么。*
6. **E08 Kac 书 / E09 Pressley–Segal** 作工具书常备，不通读。

### T4 Verlinde 公式
1. **R12 Verlinde 1988** → 融合规则与模变换（S 矩阵）。*为什么第一：公式本身。*
2. **R11 Tsuchiya–Kanie 1988** → 共形块维数 = 融合系数这一具体情形。*为什么第二：先看 SU(2) 的算例，再看一般证明。*
3. **E28 Moore–Seiberg 1989** → RCFT 公理、模张量范畴。*为什么第三：Verlinde 公式的"为什么"在范畴公理里。*
4. **E14 Reshetikhin–Turaev 1991** → 量子群侧的同一套融合规则。*为什么第四：两边一对照，就知道 §3.4 的 H = Inv(⊗R_i) 是什么。*
5. **E15 Turaev–Viro 1992**（选读）→ 纯组合的 6j-symbol 版本，用于自检。
6. 回本文 §3.4（p.373–374）与 §4 的 (4.x)：此时 (3.4) 的维数公式应能自己从 S 矩阵推一遍。

### T5 2d/3d 对偶（与 AdS3/CFT2 的区别）
1. **R38 Witten 2+1 gravity（IAS HEP-88/32；NPB 311 (1988) 46）** → 3 维引力 = CS 的第一步。*为什么第一：本文 §5 的"3 维引力"论述就靠它 [src p.394–397]。*
2. **R23 Polyakov 1988** → Fermi–Bose transmutation，2d 与 3d 的第一次握手。*为什么第二：它给出"3d CS ↔ 2d CFT"的物理直觉。*
3. **E22 Witten 2007（arXiv:0706.3359）** → 3 维引力的 modern 版：哪些 CFT 可能对偶、monster 理论。*为什么第三：2007 年这篇把 R38 的猜想收紧成可检验的陈述。*
4. **E21 Kapustin–Witten 2007** → 2d/3d 对偶的现代形态（几何 Langlands）。*为什么第四：本文 §5 的"对偶"与今天的"对偶"不是一个东西，读它才知道差别在哪。*
5. **E24 Dimofte–Gaiotto–Gukov 2011**（选读）→ 3d-3d 对应：用 3d N=2 规范理论给 3 维流形赋值。*为什么第五：这是"3d-3d"这个词的出处，与本文的 2d/3d 对偶是两回事，务必分清。*
6. **E29 Kapustin 2010 中译 / E30 Ben-Zvi 2021 中译** 作为"现代语言 vs 1989 语言"的对照读物，按兴趣取一。

### T6 纽结范畴化（Witten 1989 之后的线）
1. **E16 Khovanov 2000** → 范畴化的定义与存在性。*为什么第一：不知道 Khovanov 复形长什么样，后面全无从谈起。*
2. **E20 Witten 2014（1401.6996）** → Witten 自己讲"从 Jones 到 Khovanov"的两讲，最省力的入口。*为什么第二：它把 1989 的 CS 与 2011 的五维理论接起来。*
3. **E17 Witten 2011（1101.3216）** → 五维 / D3–NS5 系统给 Khovanov 同调的构造。*为什么第三：这是 T6 的主论文，但 148 页，先有 1–2 再读。*
4. **E18/E19（1108.3103, 1603.03854）** → 更短的两版重述，用于复习。
5. **E27 Gaiotto–Witten 2011（1106.4789）** → 4d 规范场论给纽结不变量，T6 的另一条腿。
6. **E23 Gukov–Schwarz–Vafa 2005** → 拓扑弦/BPS 视角，读完 3–5 后再看。

## 6. 本表不覆盖什么

- **不覆盖本文的逐节译注**：§1–§5 的公式推导、符号约定、（4.x）的具体计算，是 lead 与其他组员的活；本表只给"读什么"。

- **不覆盖 4 维 Donaldson/Floer 理论的细节**（R02/R03 只标"选读"，因为本文只是类比使用）。
- **不覆盖 modular tensor category 的完整公理体系**（Bakalov–Kirillov 一类教材未列）：E14/E28 够研讨班用，再深是另一门课。
