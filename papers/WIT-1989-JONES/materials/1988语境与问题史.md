## 2. Witten 为什么写这篇（Atiyah 两问 + 两个动机）

### 2.1 直接缘由：Atiyah 的第二问

| 环节 | 原文 | 锚点 |
|---|---|---|
| 两问的提出 | 「在去年 Hermann Weyl 讨论会的一次演讲中 [1]，Michael Atiyah 向量子场论学家提出了两个问题。第一个问题是为 Donaldson 理论给出物理解释；第二个问题是为纽结理论中的 Jones 多项式寻找一个内蕴的三维定义。」 | [src p.351] |
| 第一问已解决 | 「结果证明，Donaldson 理论确实可以给出物理解释 [4]。」 | [src p.352] |
| **本文接的是第二问** | 摘要：「本文证明，以纯粹由陈–西蒙斯项构成的作用量的 2+1 维量子杨–米尔斯理论是可精确求解的，并且为从三维角度理解纽结理论中的 Jones 多项式提供了一个自然的框架。」 | [src p.351 摘要] |
| **本文的体裁** | 脚注：「本文是 1988 年 7 月在 Swansea 举行的 IAMP 大会上所作报告的一个扩充版本。」 | [src p.351 脚注 *] |

> 注意：原刊引言里**没有**「本文解决第二个问题」这句话——那是中文译本导语框（译者所加 `keypoints` 环境）的概括。原文只在摘要里用「gives a natural framework for understanding the Jones polynomial … in three dimensional terms」表态。研讨班引用时请引摘要或 [p.356] 的 *assert*，不要引译本导语。
>
> 易误读：本文**不是** [4] 的续篇。两者的出发点不同——[4] 用拓扑扭曲的 $\mathcal N=2$ 超对称杨–米尔斯，本文用**纯陈–西蒙斯作用量**（不含度规、不含额外场）。译者批注亦如此提醒 [src p.352 批注]。

### 2.2 数学动机：Jones 多项式有「二维算法」而没有「三维定义」

原文（原文明确说）：

- 「这些对象是三维情形的拓扑不变量，但人们并没有一个内蕴三维的定义。」[src p.352]
- 「纽结多项式有许多优雅的定义，但它们都以某种方式依赖于纽结的二维投影或切片，给出的是二维的计算算法，然后再证明所得结果与所选取的投影无关。」[src p.352]
- 类比：「这类似于研究一个实际上是相对论性的物理理论、而人们却不知道它的明显相对论性的表述——就像 1930 年代的量子电动力学。」[src p.352]

这个类比的落点很具体：**不是**「缺一个漂亮公式」，而是「缺一个明显表现三维性的表述」。1930 年代 QED 的病是「量子化做对了，相对论性却藏在计算里」；1988 年 Jones 的病是「拓扑不变性算对了，三维性却藏在投影里」。Witten 给的药方同构：找一个**作用量层面就不含度规**的理论。

### 2.3 物理动机：二维来源太多，要找统一主题、并找出「什么是三维的」

原文（原文明确说）：

- 「纽结多项式的各种构造以令人眼花缭乱的方式把它们与二维（或 1+1 维）多体物理联系起来，主要涉及可解格点模型 [7]、Yang–Baxter 方程的解 [8]、以及共形场论的单值性 [11]。」[src p.352]
- 「对物理学家而言，纽结多项式带来的挑战在于：为这种多样性带来秩序、找到统一的主题，并弄清二维共形场论中究竟是什么东西是三维的。」[src p.352–353]

**这句话就是全文的路线图**（我们据上下文重建）：三条已知的二维来源 = (i) 可解格点模型/Temperley–Lieb、(ii) Yang–Baxter/辫群表示、(iii) 共形场论单值性（KZ 方程）。Witten 的答案是第四条、且是三维的：**三维 CS 理论的物理希尔伯特空间 = 二维共形块的向量空间**。所以「什么是三维的」的答案不是某个二维模型的参数，而是**共形块空间本身**。

### 2.4 「拓扑不变性 = 广义协变性」：为什么放弃杨–米尔斯

| 论证 | 原文 | 锚点 |
|---|---|---|
| 拓扑不变性的物理含义 | 「其物理含义其实就是『广义协变性』。」 | [src p.353] |
| 广义相对论是**一种**实现，不是定义 | 「广义相对论为我们提供了原型——我们引入一个度规，然后对所有度规积分。这个例子对我们的思维影响如此之大，以至于我们倾向于把广义协变理论按定义理解为『度规是动力学变量』的理论。」 | [src p.353] |
| 教训 | 「存在高度非平凡的量子场论，其中广义协变性以其他方式实现。」 | [src p.353] |
| 本文的做法 | 「本文将描述一个可精确求解的广义协变量子场论，其中广义协变性不是通过对所有度规积分实现的，而是因为我们从一个不含度规的规范不变拉格朗日量出发。」 | [src p.353] |
| 为什么不用杨–米尔斯 | 杨–米尔斯作用量 (1.2) 含度规，故弃用；改用 CS 作用量 (1.3)（不含度规） | [eq 1.2–1.3, p.353–354] |

## 4. CS 量子化为什么困难 & 经典相空间是什么

### 4.1 十二条清单（每条带锚点；★ = 后世才严格化的部分）

| # | 困难 / 结构 | 内容 | 锚点 |
|---|---|---|---|
| 1 | **作用量不含度规 ⇒ 常规量子化入口全失效** | 不能「对所有度规积分」；没有背景度规来定义传播子、正规化、能动量张量。好处正是拓扑不变性 | [src p.353]，[eq 1.3] |
| 2 | **大规范变换使作用量平移** | $\pi_3(G)\cong\mathbb Z$；绕数 $m$ 的变换使 $L\to L+\text{const}\cdot m$ | [eq 1.4, p.355] |
| 3 | **能级量子化 $k\in\mathbb Z$** | 只要求 $e^{iL}$ 单值 ⇒ 平移常数必须是 $2\pi$ 的整数倍 ⇒ $k$ 整数（推论，非额外假设） | [src p.355] |
| 4 | **一阶作用量、无正定哈密顿量** | $A_0=0$ 后 $L=\frac{k}{8\pi}\int dt\int_\Sigma \epsilon^{ij}\mathrm{Tr}\,A_i\dot A_j$：一阶于时间导数，正则动量就是 $A$ 本身 | [eq 3.1, p.366] |
| 5 | **泊松括号是常数的（辛形式平坦）** | $\{A_i^a,A_j^b\}=(4\pi/k)\epsilon_{ij}\delta^{ab}\delta^2$ | [eq 3.2, p.366] |
| 6 | **高斯约束 = 平坦性** | $\epsilon^{ij}F^a_{ij}=0$ ⇒ 相空间 = 平坦联络模规范 = $\mathcal M$，$\dim\mathcal M=(2g-2)d\ (g>1)$ | [eq 3.3, p.367] |
| 7 | **$\mathcal M$ 无自然复结构，必须选极化** | 选 $J$ 后 $\mathcal M_J$ = 稳定全纯 $G_{\mathbb C}$ 丛模空间（射影代数簇）；Narasimhan–Seshadri 给平坦联络 ↔ 稳定全纯丛 | [src p.367–368] |
| 8 | **预量子化线丛与 $k$** | 行列式线丛 $L$，$c_1(L)$ 对应 $k=1$ 的辛形式；一般 $k$ 用 $L^{\otimes k}$；$\mathcal H_\Sigma=\Gamma(\mathcal M_J,L^{\otimes k})$（全纯截面） | [src p.368] |
| 9 | **与 $J$ 无关性只是启发式** ★ | $\{\mathcal H^{(J)}\}$ 构成模空间上的（射影）平坦丛；平坦性由 Segal 严格证明，物理论证（路径积分测度存在性）只是启发式 | [src p.369–370] |
| 10 | **行列式 = Ray–Singer 挠率；$\eta$ 不变量进入** | 驻相给出平坦联络求和 (2.4)(2.8)，行列式绝对值是拓扑不变的挠率；APS 定理把 $\eta$ 与 CS 项联系起来，$\frac12(\eta(A)-\eta(0))=\frac{c_2(G)}{2\pi}I(A)$ | [eq 2.8, p.357–358]；[eq 2.16, p.359] |
| 11 | **level shift：$k\to k+c_2(G)/2$** | (2.16) 的效果是把 $k$ 替换为 $k+c_2(G)/2$；SU(2) 得 $k+2$，这正是 $q=e^{2\pi i/(k+2)}$ 的来源 | [eq 2.17, p.359]；[eq 2.26] |
| 12 | **标架反常：只能定义在带标架流形上** | $\eta(0)$ 依赖度规 ⇒ 加引力 CS 抵消项 (2.20)；切丛平凡化的扭转 $s$ 使 $I(g)\to I(g)+2\pi s$；合成 (2.22) 才是「定向 + 切丛平凡化」的拓扑不变量 ⇒ $Z$ 在标架平移下乘 $e^{2\pi i s\,d/24}$，有限 $k$ 推广为 $e^{2\pi i s\,c/24}$ | [eq 2.20–2.25, p.360–361] |

### 4.2 经典相空间：一句话与三句话

- **一句话**：$A_0=0$ 之后，约束方程就是平坦性方程，故**经典相空间 = 平坦联络的模空间 $\mathcal M$**（模去规范变换），$\dim=(2g-2)d$ [eq 3.3, p.367]。
- 它**紧**（含奇点）、**辛体积有限**，所以「量子化后的 Hilbert 空间是有限维的」[src p.367]。
- 它**没有**自然的 Kähler 结构；所有「全纯」都是选了一个复结构 $J$ 之后的产物，而 $J$ 的选择不进入最终的物理 Hilbert 空间（这一点就是本文与 2d CFT 相遇的地方）[src p.367–370]。
- 它**就是** Atiyah–Bott 的模空间（[33] 已核）：本文的 §3 用的正是 1982 年那套几何。

> 层次提醒（我们据上下文重建）：$\mathcal M$ 的**辛**结构是原文明确说的（由 (3.2) 的常数泊松括号直接给出）；$\mathcal M_J$ 的**复/Kähler** 结构、$L^{\otimes k}$ 的**预量子化**、**Borel–Weil–Bott** 的用法，原文都说了，但「这些拼起来构成严格几何量子化」是**后人（1990s 几何量子化文献）** 的语言。研讨班上引用时不要把最后这句安到 1988 年头上。

## 6. T5 辨析：CS/WZW 与 AdS₃/CFT₂ 到底是不是一回事

**结论：不是一回事，而且不是同一种「对偶」。** 本文的 CS/WZW 关系是**态空间的等同**（同一物理的两种描述），AdS₃/CFT₂ 是**两个不同动力学理论之间的等价**（全息对偶）。二者唯一的真实接触点是「3d 引力可写成 CS 理论」——那是一个**改写**，不是**等同**。

### 6.1 精确对照表

| 维度 | CS/WZW（本文，1988） | AdS₃/CFT₂（1997 后） |
|---|---|---|
| **体理论** | 3d 陈–西蒙斯规范理论：不含度规、无局部激发、可精确求解 [eq 1.3, p.354] | 3d 量子引力（含度规，渐近 AdS₃ 边界条件） |
| **边界理论** | 2d WZW 模型 / 手征代数；其**共形块空间** | 2d 共形场论（一般是有大 $c$ 的 CFT） |
| **关系的类型** | 「量子化 3d 理论所得的 Hilbert 空间 = 2d 共形块空间」——**态空间等同** [p.368–369, 394–397] | 「体理论配分函数 = 边界 CFT 配分函数」——**动力学等价/全息字典** |
| **体自由度** | **无**：$\mathcal H_\Sigma$ 有限维 [p.366–367]；体里没有传播的粒子 | 有：引力自由度、BTZ 黑洞、黑洞熵 |
| **有无引力子** | **无**。理论里根本没有度规，谈不上引力子 | **有**（无质量引力子） |
| **中心荷来源** | 边界流代数的 level $k$（= CS 的 $k$），加上 level shift (2.17)；$c$ 决定标架反常相位 $e^{2\pi i s c/24}$ [eq 2.25, p.361] | 渐近对称代数（Virasoro），由 Brown–Henneaux 算出 $c=3l/2G$（卷页未核） |
| **可证性** | 数学上可逐条检验：几何量子化 + Narasimhan–Seshadri + Borel–Weil–Bott（T3 的活）；严格化 = RT/TUY（未核） | **没有定理**；只有弱耦合、对称性、可积性等层面的检验 |
| **全息字典** | **不存在**「体场 ↔ 边界算子」的字典；对应只在态空间 $\mathcal H_\Sigma\cong\mathcal H_{\text{blocks}}$ 这一层 | 存在（GKPW 型字典：体场在边界的渐近值 ↔ 耦合常数）——未核具体文献 |
| **谁提出** | 本文 1988（+ 姊妹篇 [38]） | Maldacena 1997 等（卷页未核） |

### 6.2 唯一的接触点（别把它当成等同）

| 事实 | 出处 | 为什么不是等同 |
|---|---|---|
| 3d 引力可写成 CS 理论（规范群 ISO(2,1) 或其覆盖群） | 本文 [38] = IAS 预印本 HEP-88/32（已核）；Achúcarro–Townsend 1986（卷页未核） | 这个改写要求**非紧**规范群、要求特定边界条件；本文的 CS 用**紧**群、无边界引力自由度。改写保留了经典方程，**没有**把 3d 引力变成拓扑场论意义上的有限维理论 |
| 本文在 §5 结尾说「正是这类考虑促成了对 2+1 维引力的研究」 | [src p.397] | 这是**动机链**，不是等价性陈述。原文从未出现 AdS、从未出现「全息」这个词 |

**研讨班口径（建议原话）**：
> 本文的「3d/2d 对应」是**同一套量子化数据的两种组织方式**——3d 理论的态空间就是 2d 共形块空间；它不涉及体引力、不涉及体自由度、也没有全息字典。AdS₃/CFT₂ 是**两个理论之间的动力学等价**。把两者都叫「3d/2d 对偶」，是把「维度数相同」误当成「对偶类型相同」。

## 7. T6 辨析：Jones → Khovanov 范畴化是什么级别的提升

**结论：不是「把 1988 的论证补严」，而是把一个**数值不变量**提升为**同调不变量**（categorification）。** 它更细、更强，但**不回答**本文的问题（内蕴三维定义）；本文给的是 Jones 的 CS 描述，Khovanov 是它的「升级版」，且物理来源在 2007/2011 年才出现。

### 7.1 层级对照

| 维度 | Jones 多项式（1988 语境） | Khovanov 同调（2000） |
|---|---|---|
| 数学对象 | Laurent 多项式 $\in\mathbb Z[q^{\pm1/2}]$（一个**数**） | 双分次同调群 $\bigoplus_{i,j} H^{i,j}(L)$（一个**范畴化对象**） |
| 与 Jones 的关系 | —— | Euler 特征（分次维数的交错和）= Jones 多项式 |
| 不变量强度 | 基准 | 更强：给 slice genus 下界、区分 Jones 相同而 Khovanov 不同的链环 |
| 额外结构 | 无 | 辫群作用、cohomology operations、与 Temperley–Lieb/泡沫代数的关系（后世） |
| 物理来源 | **本文**：3d CS + Wilson 圈 [eq 1.6, p.355–356] | Witten 2011（5d/4d 规范论、D3 膜终止于 NS5 膜、非零 θ 角）[arXiv:1101.3216，已核]；Kapustin–Witten 2007 的几何 Langlands 框架提供 Wilson/'t Hooft 算子背景 [arXiv:hep-th/0604151，已核] |
| 与本文的关系 | 本文的结论 | **超出本文范围**；不得写成 Witten 1989 的结论 |

### 7.2 三句必须说的话

1. **「范畴化」是结构升级，不是证明补全**：Khovanov 没有证明 (1.6) 等于 Jones 多项式——他假定 Jones 多项式已知，构造一个以它为 Euler 特征的同调。所以 T6 与 T0 的四个起点问题**不在同一层**。
2. **物理来源是后世的**：Witten 2011 用 5d/4d 规范论（而非 3d CS）给出 Khovanov 同调的「manifestly invariant description」；这与本文的 3d CS 图景是**并列的两套物理实现**，不是同一套的延伸。
3. **研讨班用法**：T6 只作**延伸阅读**放在 S0 末尾一页，标注「后世（2000/2007/2011）」，明确「本文不涉及」。任何把 Khovanov 说成「Witten 1989 已经预示」的表述都属时代错置。
