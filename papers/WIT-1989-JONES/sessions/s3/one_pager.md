# S3 一页纸：Witten 是怎么把 Wilson 线"变掉"的

**一句话**：他把 (3.4) 这个解不出来的算符约束，换成"把表示 R 也量子化"的几何构造——R ↔ (G/T,ω_R) 的 BWB 定理，于是约束变经典、相空间可做辛商；但这条路上没有一步是他证明的。

## 五条结论

1. **(3.4) 不是方程，是约束**：算符值的高斯定律，约束态而非联络；不能经典解有两个独立理由（算子不对易、点源奇异）`[src p.371–372]`。
2. **"量子群"是评论**：p.372 带 hedging，全文无构造；不可写成结论。
3. **BWB 是定理、扩大相空间是构造、等于共形块是论证**：②③④无一由本文证明 `[src p.372–373]`。
4. **λ 不加 ρ 是因为不做半形式**：ρ 是 K^{1/2}=L_{−ρ} 的位移；这与 S2 的 k→k+h∨ 是同一缺口 `[src p.372]`。
5. **可积性 2j≤k 是重建**：原文无此公式；来自仿射代数（河野命题1.5，0≤λ≤k），不是 BWB 推论。
