# B｜Verlinde 公式的数学地位（T4）

**一句话**：Verlinde 公式在数学上是"共形块空间维数 = 广义 theta 函数空间维数"的显式公式（[Schottenloher p.177] 定理11.6），等价于"S 矩阵对角化融合代数"（[河野 p.37] 命题1.22；[上野 p.106] (5.37)(5.38)）；Witten §4.5 标题虽叫 "Proof of Verlinde's Conjecture"，但那是**物理推导**（手术 + 配分函数的形式性质），不是数学证明；1994 年 Faltings 才有独立于路径积分的数学证明。

## 一、数学陈述

设 Σ 紧 Riemann 面 genus g，标记点 P₁..P_m 带不可约表示 R₁..R_m；M_J 为相应抛物稳定全纯丛模空间（SU(r)、次数 0），L 为行列式丛（Quillen 度规）；定义

  z_k(g; n₁..n_m) := dim H⁰(M_J, L^k)，k 为非负整数（level），R_i 限可积表示（权在 Weyl 房内）。

- [Schottenloher p.177] 定理11.6（SU(2)，无标记点）：z_k(g) = ((k+2)/2)^{g−1} Σ_{j=1}^{k+1} (sin²(jπ/(k+2)))^{1−g}；
  SU(r), r≥2：z_k(g) = (r/(k+r))^g Σ_{S⊂{1..k+r}, |S|=r} ∏_{s∈S, t∉S} |2 sin π(s−t)/(r+k)|^{g−1}。
- 一般形即融合系数：N_{ijk} = Σ_l S_{il}S_{jl}S_{kl}/S_{0l}（[河野 p.37] 命题1.22；[上野 (5.38) p.106]）。
- 平移：分母里的 k+h∨（h∨ = 对偶 Coxeter 数 = 伴随表示 Dynkin 指数；SU(r) 时 h∨=r）来自 S 矩阵（[上野 (5.30) p.103] 的 ℓ+g*，g*=h∨）；Schottenloher 把它归给亚辛修正：K_{M_G} ≅ L^{−2h∨}，故 K^{1/2} = L^{−h∨}，修正态空间 H⁰(L^k⊗K^{1/2}) = H⁰(L^{k−h∨})，"平移消失"[p.178]。这接上 S4 的符号疑问①：几何量子化侧修正给 **−h∨**，与 (2.17) 的 +c₂/2 方向相反；我不主张二者是同一操作，只能说分母的 h∨ 与修正的 h∨ 是同一个常数。
- 三个"奇迹"（书中自己列 [p.177]）：右端是自然数、是 k 的多项式、与复结构 J 无关。第三点本来要证：P=∅ 由 [APW91]、Hitchin [Hit90] 证；P≠∅ 需 Hitchin 非交换 Hodge 理论 + metaplectic 修正 [ScSc95]。

## 二、证明路线：TUY89 → Moore–Seiberg → Faltings 94，及现代组合证明

1. **TUY89**（Tsuchiya–Ueno–Yamada）：把共形块做成稳定曲线模空间上的向量丛，给出其射影平坦联络（KZ 联络的几何化），并对 A 型给出维数公式。Schottenloher 只说"从 [TUY89] 开始"[p.171]，我未读原文，故"证到什么程度"按转述记。
2. **Moore–Seiberg 1989**：物理证明。上野 [p.106] 定理5.22 前原话："下述定理由 Verlinde 猜测，并最先由 Moore–Seiberg 证明"。
3. **Faltings 94**（J. Alg. Geom. 3, 347–374）：代数几何证明，把 dim H⁰(M,L^k) 经 rank-level 对偶化到另一个模空间的 theta 函数上，再做正性/GIT 估计；此后 Beauville、Szenes、Sorger、Kumar 等简化推广。
4. **现代组合证明**（Schottenloher §11.3–11.4 自己走的路）：融合规则 (F1)–(F6) ⇒ 融合环是 Frobenius 代数（11.11–11.12）⇒ 抽象 Verlinde 公式 11.13（Z(g)_{v₁..v_m} = ∫α^g v₁···v_m）⇒ 谱分解 11.14（Z(g)=Σ_h μ(h)^{g−1}）⇒ 对 SU(2) 用 V_k = R(G)/(b_{k+1})、特征标 h_z(b_n)=sin((n+1)z)/sin z 与 μ(h_n)=(2/(k+2))sin²(nπ/(k+2)) 得 (11.2)。这条把"为什么是自然数"变成组合代数，概念上最干净。

**为什么"这些证明都不容易理解"**（原话 [p.171]）：① 两边都是重机器——左边要 KZ 单值性 + Hitchin 的非交换 Hodge 理论/模空间几何，右边要广义 theta 函数、GIT、正性与 rank-level 对偶；② 公式右端是 Weyl 房上的正项 sin 幂求和，"自然数""k 的多项式"都不显然；③ 各证明给的层次不同（维数公式 / 等变指标 / 代数结构），彼此推出还要额外工作。

## 三、河野命题1.22 vs 定理2.16：同一个 S，两种角色，别混

| | 命题1.22（[河野 p.37]） | 定理2.16（[河野 p.60]） |
|---|---|---|
| 对象 | 融合系数/三点共形块维数 N_{λμν} | 三维流形不变量 Z_k(M) |
| 内容 | N_{λμν}=Σ_α S_{λα}S_{μα}S_{να}/S_{0α}；等价幂等元 w_μ=S_{0μ}Σ_λ S_{λμ}v_λ，w_λ·w_μ=δ_{λμ}w_λ | 沿链环 L 做 Dehn 手术：Z_k(M)=S_{00}C^{σ(L)}Σ_λ S_{0,λ(1)}···S_{0,λ(m)}J(L;λ) |
| 角色 | S 作**基变换**：把乘法对角化（代数侧） | S 作**手术核**：把链环不变量变成流形不变量（几何侧） |
| 证明 | N_λ 被 S 对角化 + 多项式特征值 | Kirby 手术不变性；关键砖命题2.15 J(H;λ,μ)=S_{λμ}/S_{00} |

关键：定理2.16 的证明**用到了**命题1.22 作砖，但两者回答不同问题（几维 vs 等于多少）；把手术公式当成"Verlinde 公式的证明"是范畴错误。

## 四、S 矩阵由 q=e^{2πi/(k+N)} 决定：SU(2) 小 k 显式检验

[上野 p.103] (5.29)(5.30)：S_{λ,μ}=S_{λ,0}·ch_μ(e^{−2πi(λ+ρ)/(ℓ+g*)})，S_{λ,0}=|P/(ℓ+g*)Q^∨|^{−1/2}∏_{α>0}2 sin(π(λ+ρ,α)/(ℓ+g*))，入的是 q=e^{2πi/(ℓ+h∨)}；例5.23 [p.106]：S^j_i = √(2/(ℓ+2)) sin((i+1)(j+1)π/(ℓ+2))。

数值检验（j 标自旋，允许 j≤k/2）：

- k=1：S = (1/√2)[[1,1],[1,−1]]；N 非零只有 N_{000}=N_{011}=N_{101}=N_{110}=1，N_{111}=0。对应 1/2⊗1/2 = 0（自旋 1 在 k=1 不可积，被截断）✔
- k=2：S = [[0.5,0.7071,0.5],[0.7071,0,−0.7071],[0.5,−0.7071,0.5]]；非零 N 全为 1：(0,0,0),(0,1,1),(0,2,2),(1,1,0),(1,1,2),(1,2,1),(2,2,0) 及其对称。对应 1/2⊗1/2 = 0⊕1、1/2⊗1 = 1/2（3/2 截断）、1⊗1 = 0⊕1（2 截断）✔

即：代入 q=e^{2πi/(k+2)} 的 S 矩阵确实把截断后的融合规则原样还原，不是口号。

## 五、物理推导 vs 数学证明的边界（Witten §4.5，[src p.391–393]）

- 原文标题 "Proof of Verlinde's Conjecture"，但正文第一句自认："该猜想**已由 Moore 与 Seiberg [13] 证明**。我们可以用这些方法在流代数的情形给出 Verlinde 猜想的一个**新证明**。"
- 推导链：Z(X×S¹)=dim H_X（§4.3）→ (4.36) Z(S²×S¹;R_a,R_b,R_c)=N_{abc} [p.388] → 图15b 沿 C 手术 S²×S¹→S³，C 上加 R_i 的 Wilson 线 ⇒ S³ 上两条**链接** Wilson 线 L(R_i;R_j) → 用 (4.46) 型分解独立算左端 ⇒ **(4.51) S_{ij}S_{ik}/S_{0,i}=Σ_m S_i{}^m N_{mjk}** [p.393] → 新基 w_i=S_{0,i}Σ_m S_i{}^m v_m 使 w_iw_j=δ_{ij}w_j。
- 边界：这里的"手术下配分函数如何变换"(4.28)、"Z(X×S¹)=dim H_X"、"(4.46) 分解"都是把路径积分当 TQFT 公理用的**形式性质**，没有一条是从 CS 测度出发证的；所以 (4.51) 的成立前提是"TQFT 存在且满足公理"。Witten 的贡献是给出与 MS 不同的、只用手术与 Wilson 线的推导，而不是第一个数学证明。
- 数学侧：TUY89/Faltings94 不用 CS 路径积分，直接在代数几何里证维数；1994 之后仍有简化（Beauville、Szenes、Sorger、Kumar；现代 FHT03 用等变扭 K 理论重述 V_k）。
- 结论口径：Verlinde 公式 = 1988 物理猜想 [Ver88] → 1989 MS 物理证明 + 本文"新证明" → 1989–1994 数学证明。物理推导与数学证明覆盖的是同一命题的不同层面，不可互相替代。
