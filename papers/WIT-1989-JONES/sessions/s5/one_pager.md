# S5 一页纸：Verlinde 公式（T4）

**一句话**：Verlinde 公式 $N_{ijk}=\sum_l S_{il}S_{jl}S_{kl}/S_{0l}$ 在本文里不是从共形块动力学推出的，而是从三维 TQFT 的手术后自洽性推出的；它与"共形块的融合规则"是同一命题的两种语言。

## 五条结论

1. **三处输入**：推导链只用手术律 (4.27)/(4.28)、$N_{abc}$ 的定义 (4.36)、秩一性 (4.49)；没有 Virasoro、没有 KZ、没有模不变性。
2. **两种读法等价**：(4.51) = $S$ 对角化融合规则 = 幂等元 $w_i w_j=\delta_{ij}w_j$。
3. **(4.41) 不在主链**：标架反常只在 $T^nST^m$ 时出现；主链用标准 $S$，比值自消相位。
4. **"Proof" 是物理推导**：猜想已由 Moore–Seiberg 证明，数学证明是 TUY 1989 / Faltings 1994。
5. **河野 1.22 ≠ 2.16**：同一 $S$ 的两个用途（融合代数基变换 vs 手术核），不能互相冒充。
