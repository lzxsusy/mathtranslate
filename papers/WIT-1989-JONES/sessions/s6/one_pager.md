# S6 一页纸：两个"延伸"问题

**一句话**：CS/WZW 是**态空间等同**（不是全息对偶），Khovanov 同调是**范畴化升级**（不是本文推论）；两者都是"层级判据"的练习题。

## 五条结论

1. 本文 p.370 用 "are" 把三维态空间与二维共形块说成同一对象；证据只到对象级与射影平坦丛，函子性只有 p.397 的 "It is obvious"。
2. 三维与二维的唯一接触是 X×S¹ 上 Z=dim H_X（p.387–388）；**没有**体配分函数 = 边界配分函数，所以不是全息。
3. AdS₃/CFT₂ 是动力学等价（体引力 + 边界条件 + 字典）；本文无度规、无引力子、无 AdS/全息字样。
4. "3d 引力=CS"只在非紧群与经典/相空间层面成立，是改写而非等同。
5. Khovanov 同调以 Jones 为 Euler 特征；其物理来源是 2007–2011（Witten 2011 p.107："范畴化 = 从高一维理论导出"）；本文无任何范畴化暗示。
