## 报告 A（historian）：预量子化的链条，以及 Witten 为什么可以跳过它

**结论一：标准链条是五步，一步不能少。**
辛流形 (M,ω) → ①整性 `[\omega]∈H²(M;Z)` → ②预量子化线丛 (L,∇,⟨,⟩) 使 `F_∇=−(i/ℏ)ω` → ③极化 P → ④P-极化截面空间 ℋ_P → ⑤可观测量提升为算子。李思 5.4.3–5.4.4（印刷 p.301–309）讲得最全；曲率约定是 `F_∇=−(i/ℏ)ω`（定义 5.4.2、例 5.4.4，见 `src/chunks/ch05b.tex:872,885`），**不是** −iℏω。

**结论二：Witten 没有漏写整性条件，他是构造性绕过。**
§3.1–3.2（p.368–369）通篇没有出现"[\omega] 必须整"这句话。他直接说 M_J 上有行列式线丛 L（Quillen 度规），`[\omega]=c₁(L^{⊗k})`。**线丛已经存在，第一陈类当然整**——整性条件被"先有 L"这件事吸收了。所以正确的说法不是"Witten 忘了预量子化"，而是"他把预量子化当作已完成的输入"。`[src p.368–369]`（证据：全节无整性讨论）

**结论三：两个 ℏ 换算式差 2π，不能混用。**
- 李思例 5.4.11（p.308）：`L=L₀^{⊗k}`、`ℏ=1/(2πk)`，即 `k=1/(2πℏ)`；
- 河野 p.107：`k 换成 1/ℏ`，其 `∇=d−2π√−1α`（书 p.8）。
两者差 2π，来自 c₁ 归一化不同。引哪本，就用哪本的换算式。

**结论四：level shift 是真的，但不在本文里。**
本文 (2.16)–(2.17)（p.359）与 (4.21)（p.382）已经出现 `k→k+c₂/2`，`c₂(SU(N))=2N` 即 `h∨=N`，所以 `q=e^{2πi/(N+k)}`、SU(2) 是 `e^{2πi/(k+2)}`。但**半形式修正（K^{1/2}）本文没写**；真 level shift `k→k+h∨` 是补上这一项的结果。因此本文的 k 与 WZW 的 level 差 h∨，`k` 不能直接当 level 用。

**结论五：T² 上的 k 与 §4.3 的 t=k+1 不是一回事。**
阿贝尔情形 dim H⁰(M_J,L^{⊗k})=k（黎曼–罗赫，我们算的）；§4.3 的 t=k+1 是 pillowcase（带四个标记点的球面商）。两个相空间不同，不能相减来"验证" shift。

## 报告 B（bibliographer）：极化为什么必须，以及"与 J 无关"到底多强

**结论一：极化不是技术选择，是被紧性逼出来的。**
若不做极化，量子态是 L²(M,L) 的全截面，同时依赖 q 与 p。Witten 自己在 p.368 说 `p_j are definitely unbounded`；而 M_Σ 紧、辛体积有限（p.368）。在有限体积里塞不进"p 的无限自由度"，所以必须选一半变量丢掉——这就是极化。`[src p.368]`

**结论二：Kähler 极化把问题变成复几何。**
取 J 后 M_J 是 Kähler，极化取 (0,1) 方向，极化截面 = 全纯截面，ℋ = H⁰(M_J, L^{⊗k})，有限维。这一步把"辛商"变成"复代数簇上的上同调"。`[src p.368–369]`

**结论三："与 J 无关"只到射影。**
p.370 原句：`only a projectively flat connection, with the projective factor being canonically odd under reversal of orientation`。所以：
- 没有典范的 ℋ_Σ，只有射影空间 Pℋ_Σ；
- 单值性（p.371）是映射类群在 Pℋ_Σ 上的作用；
- 这个"射影因子在定向反转下变号"，就是后来标架反常的二维影子（留 S5 核）。

**结论四：半形式修正的落点已经能指出来。**
(2.16)–(2.17)（p.359）的 `k→k+c₂/2` 与 (4.21)（p.382）的 `q=e^{2πi/(N+k)}` 是同一件事的两端；c₂(SU(N))=2N ⇒ `h∨=N`。但"为什么是 K^{1/2}、为什么恰好 h∨"三本教材都只有等价陈述（河野 p.107、上野 p.125），**没有一本给机制**。这是本文的真实缺口，也是我们写笔记时必须标"我们未推导"的地方。

## 质询与交锋

**Q1（证据官 → A）**：你说"Witten 绕过整性"，证据是"全节没有这句话"。这是**缺席证据**，够吗？
A：不够单独成立。补两条正面证据：①他直接写 `[\omega]=c₁(L^{⊗k})`（p.368），线丛已存在；②(3.3) 的辛商在 M 上做，M 是代数簇，ω 的 de Rham 类自动整。缺席 + 正面构造，两条合起来才是"绕过"。
**裁定**：c-s2-03 置信度 medium，status=provisional。

**Q2（主席 → B）**："只到射影"是不是说本文的量子化不成立？
B：不是。成立的是**射影**量子化；代价是态空间没有典范等同，只有 Pℋ。物理上这正好对应"大规范变换下态可差相位"，与 (1.4) 的 k∈Z 是同一件事的两面。

**Q3（A → B）**：那 k→k+h∨ 到底该记在谁头上？
B：记在"半形式修正"头上，且**本文没做**。笔记里应写：本文的 k 与 WZW 的 level 差 h∨；这个差是后世补的，不是 Witten 1989 的结论。

**D1（分歧）**：`[\omega]` 整性在本文是"不需要"还是"被隐藏"？
- A：被隐藏（先有 L）。
- B：严格说本文只对**代数簇上的行列式线丛**工作，一般辛流形仍需整性；本文的特殊性不能推广成"整性不重要"。
- **保留**。写笔记时按 B 的版本：这是特殊构造，不是普遍定理。

**D2（分歧）**：`M_{P_i,R_i}`（S3 会用到）的辛形式是 `ω_flat + Σ k ω_{R_i}` 还是带别的系数？

## 收束（五条）

1. 几何量子化三步在本文是：**行列式线丛（预量子化已给）→ Kähler 极化 → H⁰(L^{⊗k})**；整性被构造吸收。
2. 极化的必要性来自紧性 + q,p 不可同时对角化；这不是本文的发明，是标准几何量子化。
3. "与 J 无关"= 射影平坦，不是典范等同；单值性 = 映射类群作用。
4. 本文的 k 与 WZW level 差 h∨；半形式修正本文未做，`k→k+2`（SU(2)）是后世补的。
5. 三个换算式（李思、河野、本文）差 2π/归一化，引用必须锁定一本。
