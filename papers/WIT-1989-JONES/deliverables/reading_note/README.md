## 读者与承诺

**目标读者**：学过量子力学与一学期场论/微分几何、但没读过 TQFT 文献的数学/物理研究生。

**读完能做什么**（写作前必须先写死这一段，写不出来不许动笔）：

1. 用三句话说清 Witten 为什么写这篇、解决了什么、没解决什么；
2. 独立写出 CS 作用量的变分与 k∈Z 的整性论证（含大规范变换的绕数计算）；
3. 说清“几何量子化”三步各自的前提，并能对 SU(2)、g=1 手算 Hilbert 空间维数；
4. 说清 Wilson 线 → 穿刺点 → BWB → 共形块这条链，每一步是定理、构造还是猜想；
5. 陈述 Verlinde 公式并说明它在本文里是“被证明”还是“被验证”；
6. 区分 CS/WZW 对应与 AdS₃/CFT₂ 全息对偶，指出前者缺什么；
7. 说明 Jones 多项式与 Khovanov 同调的关系，并指出本文不蕴含后者。
