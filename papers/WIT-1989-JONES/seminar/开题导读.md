## 0. 一页纸

**一句话**：把 3 维陈–西蒙斯（CS）规范理论的 Wilson 线期望值，定义为 Jones 多项式及其推广的内蕴三维定义；并论证这个 3 维理论的量子化恰好产生 2 维共形场论的共形块空间。

**技术路线一句话**：沿曲面 Σ 切开 3 维流形 → 在 Σ×ℝ 上正则量子化（辛商 + Kähler 极化）→ 得到有限维 H_Σ = 共形块空间 → 用手术把 S³ 拼回去 → 得到可计算的纽结/流形不变量。

**四个起点问题的短答**：

| 问题 | 短答 |
|---|---|
| Witten 为什么写？ | 回答 Atiyah 1988 年 Hermann Weyl 演讲两问中的第二问：给 Jones 多项式一个内蕴三维定义 [原文 p.351] |
| 他要解决什么？ | 构造一个不依赖投影图/切片的三维不变量，并把它从 S³ 推广到任意 3 维流形 |
| CS 量子化为什么难？ | 难在约束后的相空间是**模空间**（非线性、紧、有奇点），不在作用量本身；作用量在 A₀=0 下其实是二次型 |
| 经典相空间是什么？ | Σ 上平坦联络模去规范变换：Hom(π₁Σ,G)/G；g>1 时实维数 (2g−2)dim G |

**七主线的结构关系**（不是七个并列话题）：
T0 问题来源 → **T1 几何量子化（机器）** → **T2 Wilson 线/穿刺/BWB（载荷）** → **T3 共形块（输出与字典）** → T4 Verlinde（可计算推论）→ T5 对偶辨析（边界）→ T6 范畴化（后世延伸）。

## 1. Q1：Witten 为什么写这篇文章？他要解决什么问题？

### 1.1 直接动机：Atiyah 的两问

Atiyah 在“去年的 Hermann Weyl 讨论会”上提出两问 [原文 p.351]：

1. 为 Donaldson 的四维光滑结构理论找一个物理解释；
2. 为 Jones 多项式找一个**内蕴的三维定义**。

第一问已由 Witten 自己在《Topological quantum field theory》（CMP 117 (1988) 353）中用扭曲 N=2 超对称 Yang–Mills 解决 [原文 p.351, 文献 [4]]。**本文接的是第二问。**

### 1.2 为什么第二问是一个真问题

Jones 多项式的原始定义依赖二维投影图（Kauffman 括号、辫群表示、R-矩阵），它是“图上的组合规则”。这不是三维定义：换一张投影图得到同一个多项式，这件事本身需要证明（Reidemeister 移动），而“为什么它能不依赖于图”没有内蕴解释。

原文的类比很关键 [原文 p.351]：1930 年代人们知道 QED 是相对论性的，却不知道一个**明显**相对论性的表述；Jones 多项式与三维拓扑的关系也是这样——大家知道它“应该”是三维的，但没有一个从三维流形出发的构造。

### 1.3 更深的动机：二维来源太多，要找统一主题

原文列了当时纽结多项式的四个来源 [原文 p.351–352]：可解格点模型、Yang–Baxter 方程、共形场论的单值性、量子群（当时叫“量子包络”）。Witten 的原话大意是：要为这种多样性带来秩序、找到一个统一主题，并弄清**二维共形场论中究竟什么东西是三维的**。

这句话是理解全文的钥匙：本文的产出不只是“又一个不变量”，而是“2d CFT 的共形块 = 3d 拓扑场论的 Hilbert 空间”这条字典。Jones 多项式只是这条字典的一个可计算推论。

### 1.4 目标拆解与状态

| # | 子目标 | 本文状态 |
|---|---|---|
| 1 | 写出一个不依赖度规的 3 维作用量（CS 作用量） | 定义，[原文 p.353–354]，(1.3) |
| 2 | 证明它只在 k∈ℤ 时良定义（大规范变换） | 证明，[原文 p.354–355]，(1.4) |
| 3 | 论证其 Wilson 线期望值在 S³ 上复现 Jones 多项式 | **论证/断言**，[原文 p.355–356]，(1.5)(1.6)；“we will assert” |
| 4 | 精确求解该理论（正则量子化 → 有限维 H_Σ） | 构造性论证，[原文 p.366–374]，§3 |
| 5 | 证明 H_Σ 与共形块空间一致 | 论证 + 与 Segal 模函子对接，[原文 p.369–374] |
| 6 | 给出任意 3 维流形不变量的手术算法 | 构造 + 大量算例，[原文 p.374–394]，§4 |
| 7 | 证明 Verlinde 猜想 | 给出一个新证明，[原文 p.388–393]，§4.5 |

**本文没有解决的**（研讨班要盯住）：
- 路径积分测度在无度规流形上没有严格定义；§2 用弱耦合极限 + Ray–Singer 挠率绕开，不是构造性 QFT。
- 半形式（half-form）修正被略去，因此 k 与 k+h^∨ 的差别在本文中不显式 [译注]。
- 模空间有奇点（可约联络处），本文按“一般点”处理。
- 非整数 k、复化 k 的几何意义没有解释。
- “H_Σ 与 J 无关”只论证到“存在典范平坦联络”这一层，严格性依赖 Segal [16] 与 Hitchin 的工作 [后世]。

## 2. Q2：CS 场论的量子化为什么困难？

先纠正一个常见误判：**困难不在 (1.3) 是非线性作用量。** 取 A₀=0 后，拉格朗日量立刻变成对时间一阶的二次型 (3.1)，非线性全部被赶到高斯定律约束 (3.3) 里 [原文 p.366；译注]。真正困难的是下面八条。

| # | 困难 | 本文怎么处理 | 锚点 |
|---|---|---|---|
| 1 | 无度规流形上路径积分测度没有定义 | 不构造测度；取大 k 弱耦合，用驻相 + Ray–Singer 挠率算行列式 | §2，p.356–365 |
| 2 | 作用量对时间一阶，没有通常动能项；(1.3) 的耦合常数在指数上，弱耦合是大 k 而非小 k | 明确“大 k 极限”，与大 N 展开区分 | p.356–357；译注 |
| 3 | 约束 F=0 是非线性的（F=dA+A∧A），“先量子化再约束”几乎不可行 | **先约束再量子化**：辛商，把无穷维 A 空间压成有限维模空间 | p.367–368 |
| 4 | 辛商后的相空间是模空间 M：非线性、紧、有奇点，不是矢量空间 | 用 Kähler 极化代替 q/p 分离；奇点按一般点处理 | p.368–369 |
| 5 | 紧相空间不能做 q/p 分离；必须选极化，而极化不唯一 | Kähler 极化：态 = 全纯截面；不同极化只差射影幺正等价 | p.368–369；译注 |
| 6 | 预量子化要求 [ω] 整；k 的整性还有第二条来源（大规范变换） | 两条路给出同一个 k∈ℤ：大规范变换 (1.4) 与行列式线丛第一陈类 | p.354–355, 369–370 |
| 7 | 半形式修正、标架反常 | 半形式略去；标架反常显式计算，给出 c=k·dimG/(k+h^∨) 与相位 e^{2πi·c/24} | p.388–393，(4.41)；译注 |
| 8 | Wilson 线的穿刺约束右端是**算符值**，不能当经典方程解 | 不直接解；把每个表示 R 换成 (G/T,ω_R) 的几何量子化（Borel–Weil–Bott），扩大相空间后再量子化 | p.371–373，(3.4) |

补一条结构性的：模空间上的向量丛只有**射影**平坦（共形反常），不是平坦；“H_Σ 与 J 无关”这句话必须打这个折扣 [原文 p.370；译注]。这正是 2d CFT 中心荷在 3d 侧的几何来源，不是缺陷。

**一句话**：CS 的可解性来自“约束把无穷维问题压成有限维模空间上的复几何问题”；困难也全部来自这个模空间不够好（非线性、奇异、只射影平坦）。

## 3. Q3：经典相空间是什么？

### 3.1 从作用量读出辛形式

在 Σ×ℝ 上取 A₀=0，由 (1.3) 得 [原文 p.366]：

$$\mathcal{L}=\frac{k}{8\pi}\int dt\int_\Sigma \varepsilon^{ij}\,\mathrm{Tr}\,A_i\,\frac{d}{dt}A_j \tag{3.1}$$

它已对时间一阶，所以 A_i 本身就是正则坐标，正则 1-形式是

$$\theta=\frac{k}{8\pi}\int_\Sigma \varepsilon^{ij}\,\mathrm{Tr}\,A_i\,\delta A_j,\qquad
\omega=\delta\theta=\frac{k}{8\pi}\int_\Sigma \varepsilon^{ij}\,\mathrm{Tr}\,\delta A_i\wedge\delta A_j$$

由此得等时泊松括号 [原文 p.366]：

$$\{A_i^a(x),A_j^b(y)\}=\frac{4\pi}{k}\varepsilon_{ij}\delta^{ab}\delta^2(x-y) \tag{3.2}$$

### 3.2 高斯定律约束与辛商

A₀ 是拉格朗日乘子，变分给约束 [原文 p.366–367]：

$$\varepsilon^{ij}F^a_{ij}=0 \tag{3.3}$$

二维中 F 只有一个独立分量，故 (3.3) ⇔ F=0，即联络平坦。约束是第一类，生成规范变换。经典施加约束分两步：

1. 限制到约束面 F=0；
2. 按规范群作用取商（Marsden–Weinstein 辛商 [补]，Atiyah–Bott 的做法 [33]）。

合起来：

$$\mathcal{M}=\{\text{Σ 上平坦联络}\}/\mathcal{G}=\mathrm{Hom}(\pi_1\Sigma,G)/G$$

g>1 时 dim_ℝ M=(2g−2)·dim G [原文 p.367]。M 紧、带奇点（可约联络处）、辛体积有限。

**为什么有限体积重要**：半经典地“相空间每单位体积一个量子态”，体积有限 ⇒ 量子 Hilbert 空间有限维 [原文 p.368]。这是“可精确求解”的结构性原因，不是技术细节。

### 3.3 有 Wilson 线时：穿刺点

M 被 Wilson 线切开后，Σ 上出现标记点 P₁,…,P_k，各带表示 R_i [原文 p.366–367]。约束变成 [原文 p.371]：

$$\frac{k}{8\pi}\varepsilon^{ij}F^a_{ij}(x)=\sum_s \delta^2(x-P_s)\,T^a_{(s)} \tag{3.4}$$

右端是算符值——这就是“不能直接经典求解”的根源。Witten 的绕法见 Q5。相空间相应扩大为：平坦 G 联络 + 在每个 P_i 处结构群约化到极大环面 T（等价于带抛物结构的平坦联络 [补]）。

### 3.4 复结构进来之后

选 Σ 上一个复结构 J，M 获得新解释：它是 Σ 上稳定全纯 G_ℂ 丛的模空间 M_J，且是复 Kähler（射影代数）簇 [原文 p.368]。关键字典：

> 一个平坦联络 = 一个全纯结构 + 一个相容的平坦幺正结构。

反向断言（每个 c₁=0 的稳定全纯丛上恰有一个相容平坦幺正联络）就是 Narasimhan–Seshadri 定理，即 Donaldson–Uhlenbeck–Yau 的二维情形 [补；译注]。Witten 用一句 “can be given a new interpretation” 带过了这一定理；**这是本文被引用最多、也最常被读漏的一句。**

## 4. Q4：几何量子化的三步，各自的前提

### 4.1 第一步：预量子化（prequantization）

要量子化 (M,ω)，先要求 [ω]∈H²(M,ℤ)。然后取线丛 L，带联络 ∇，使 curv(∇)=ω。

本文的具体对象：L = ∂̄ 算子的**行列式线丛**（Quillen 用 ζ 函数正则化给出自然度规 [34]），并且

$$[\omega]=c_1(L^{\otimes k})$$

k=1 时就是 c₁(L)；对 E₈ 这类群，L 是基本线丛的 30 次幂（30=h^∨）[原文 p.369–370，脚注 9]。

**前提**：整性。本文有两条独立来源给出 k∈ℤ——(1.4) 的大规范变换，和 c₁ 的整性；二者一致，这不是巧合，而是同一件事的两个面 [原文 p.354–355, 369–370]。

### 4.2 第二步：极化（polarization）

相空间上的量子化不唯一：预量子化只给线丛，还要选“哪些方向算位置、哪些算动量”。紧相空间不能做 q/p 分离，故取 **Kähler 极化**：态 = L^{⊗k} 的全纯截面。

$$\mathcal{H}_\Sigma=H^0(\mathcal{M}_J,L^{\otimes k})$$

M 紧 ⇒ 有限维 [原文 p.368–369]。

**前提**：M_J 是 Kähler。这靠 J 的选取 + Narasimhan–Seshadri。**代价**：极化依赖 J，所以严格说得到的是 H_Σ^{(J)}。

**本文略去的**：半形式修正 K^{1/2}。一般认为它给出能级平移 k→k+h^∨（SU(2)：k→k+2）[译注]。读 §4 里 q=exp(2πi/(k+2)) 时要记住这个差别。

### 4.3 第三步：全纯截面 + 内积 + 与 J 无关

H⁰ 上的内积由 Quillen 度规/Bergman 核给出（再生核），这就是脚注 7 说的“平坦向量丛上的一个度规” [原文 p.366 脚注；译注]。

然后是最关键的一步，也是全文的枢纽 [原文 p.369–371]：

> H_Σ^{(J)} 全纯地依赖 J，构成复结构模空间上的一个向量丛；
> “H_Σ 典范地与 J 无关” ⇔ “该向量丛有典范平坦联络”。

因为共形反常，这个联络只**射影**平坦。它就是 Hitchin 联络（有穿刺时是 Knizhnik–Zamolodchikov 联络）[后世；译注]。BPZ 方程 [32] 是它的微分方程形式，Friedan–Shenker [31] 强调它是共形场论的枢纽。

**这一步的级别**：Witten 是论证，不是证明；严格性靠 Segal 的模函子框架 [16]。研讨班必须把“论证”与“定理”分开记。

### 4.4 三步之后才出现的东西

三步只给出“每个 Σ 一个向量空间”。真正的 3 维内容是**胶合**：沿边界粘合两个 3 维流形 = 对两个共形块空间作配对（Segal 的 CFT 公理）。这一步在 §5 才明说 [原文 p.394–397]。

## 5. Q5：Wilson 线、穿刺点与 Borel–Weil–Bott

### 5.1 问题在哪

约束 (3.4) 的右端是 T^a_{(s)} 的算符值。若硬把它当经典方程解，得到的不是普通联络，而是“q 数联络”——直接解会把人推向量子群 [原文 p.371；译注]。这条路 1988 年走不通。

### 5.2 Witten 的绕法

不去解 (3.4)，而是**把表示 R 本身量子化**：

1. 取旗流形 G/T，带辛形式 ω_R，其 de Rham 类等于最高权 λ；
2. Borel–Weil–Bott：H⁰(G/T, L_λ)=V_λ（不可约表示），λ 是最高权，**不加 ρ**；
3. 于是把三维理论中“在 P_i 处插入表示 R_i”，替换为“在 P_i 处粘上一个 (G/T, ω_{R_i}) 的几何量子化”；
4. 扩大后的相空间 M_{P_i,R_i} 上，(3.4) 变成有意义的经典约束，可解；
5. 量子化后得到的正是 Segal 的流代数共形块空间 [原文 p.371–373]。

**级别**：这是构造，不是定理。它把“表示论插入”翻译成“辛商”，使几何量子化机器能处理 Wilson 线。严格化在后世（抛物丛、模空间上的指标定理）。

### 5.3 可积性条件

只有可积表示才有非零截面：SU(2) 时 2j≤k，否则 H=0，该 Wilson 线“退耦” [原文 p.373]。这与 WZW 模型的 level-k 可积最高权完全一致——这本身就是 3d/2d 对应的一个证据。

### 5.4 带标记点的黎曼球（§3.4）

大 k 时 H=Inv(⊗_i R_i) [原文 p.373–374，(3.5)]；有限 k 时是它的子空间。几个可直接核对的维数：

| 标记点数 | 维数 |
|---|---|
| 0 | 1 |
| 1 | δ_{R,0} |
| 2 | δ_{R_j,R̄_i} |
| 3 | N_{ijk}（融合系数） |
| 4（R,R,R̄,R̄） | s，其中 R⊗R=⊕_{i=1}^s E_i [(3.6)] |

SU(N) 定义表示 s=2（k=1 例外，1 维）。**这张表就是 Verlinde 公式的入口。**

**主线之间的三条边**（讨论时用来串场）：
- T1→T3：几何量子化的输出就是共形块；这一步是全文的技术核心。
- T2→T4：BWB 把表示变成辛商，才使“穿刺点维数=融合系数”可算，Verlinde 公式才有 3d 证明。
- T3→T5：T3 是“态空间对应”，T5 要问的是“这是不是全息对偶”。两者不是同一件事。

## 7. T4 与 T5 的预备澄清（避免开场就吵错）

### 7.1 Verlinde 公式在本文中的位置

Verlinde 1988 从 RCFT 的模不变性猜出 N_{ijk}=Σ_l S_{il}S_{jl}S_{kl}/S_{0l} [12]。本文 §4.5 用手术关系 (4.28) 给出一个 3d 证明 [原文 p.388–393]：

- 把 S²×S¹ 沿某个圈手术成 S³，同时留下链接的 Wilson 线；
- 同一配分函数用两种方式算：一种给 S 矩阵，一种给融合系数；
- 对比得 (4.51)：Σ_k S_i{}^k N_{kl}{}^m = S_{il}S_i{}^m/S_{0,i}；
- 即 S 对角化融合规则；在新基 w_i=S_{0,i}Σ_m S_i{}^m v_m 下，融合代数变成幂等元代数 w_i w_j=δ_ij w_j。

**物理意义**（三个层次，讨论时要分开）：
1. 数学意义：融合代数被模变换 S 对角化；
2. CFT 意义：S 是环面模变换 τ→−1/τ 在共形块空间上的作用，故“融合规则由模性质决定”；
3. 3d 意义：N_{ijk}=dim H(S²; R_i,R_j,R_k)，即融合系数 = CS 理论在三穿孔球面上的 Hilbert 空间维数。**这才是本文给出的“为什么”。**

### 7.2 T5：CS/WZW 与 AdS₃/CFT₂ 是两码事

| | CS/WZW（本文） | AdS₃/CFT₂ |
|---|---|---|
| 体理论 | 3d 拓扑场论，**无度规、无引力子** | 3d 量子引力，有引力子 |
| 边界理论 | 2d 手征代数/RCFT 的共形块（全纯部分） | 2d  unitary CFT（含反全纯部分） |
| 对应内容 | 态空间 = 共形块空间；胶合 = 配对 | 配分函数 = 边界配分函数 |
| 中心荷 | c=k·dimG/(k+h^∨)，来自标架反常 | c=3l/(2G)，来自 Brown–Henneaux |
| 可证性 | 构造性论证 + 手术计算 | 弱形式可算，强形式是猜想 |

**接触点**：3d 引力可写成 CS 理论（Achúcarro–Townsend；Witten 1988 [38]），此时“CS/WZW”与“AdS₃/CFT₂”在技术上有重叠；但**重叠不等于等同**：本文的 CS 没有引力子，边界只取全纯一半。**结论：不是同一种对偶。** 说“CS/WZW 是全息对偶的一个 toy model”可以，说“CS/WZW 就是 AdS₃/CFT₂”不行。

### 7.3 T6：范畴化，只作延伸

Jones 多项式是某个同调不变量的 Euler 特征：Khovanov 2000 构造了 Khovanov 同调，取维数（Euler 特征）回到 Jones [后世]。物理来源不是本文的 CS，而是 4d N=4 理论/五维膜构造（Witten 2011, arXiv:1101.3216；Kapustin–Witten 2007 的几何 Langlands 一侧）[后世]。

**所以 T6 的正确提法是**：“本文给了 Jones 一个 3d TQFT 解释；范畴化给的是另一层结构（同调而非数），它的物理来源是另一个理论。两者是什么关系，是开放问题。” —— 不要说成“Witten 1989 已经蕴含 Khovanov”。
