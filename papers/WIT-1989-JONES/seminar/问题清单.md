## 0. 先说结论：你的问题整体是好的，但有四类病

你的七条主线不是“外行提问”，是读过结构之后提的——尤其第三、四、五、六、七条里反复问“什么级别”“是等价还是联系”“是不是两码事”，这是在追问**论证强度**，是专业提问的方式。问题在于：

| 病 | 表现 | 后果 |
|---|---|---|
| **话题化** | “预量子化、极化、全纯截面的选取。每一步的数学前提是什么？” | 这不是一个问题，是一个话题。AI 会给你一段教科书目录，你无法判对错 |
| **预设未检** | “Verlinde 公式怎么从共形块推出来？” | 预设了推导方向；本文其实是反过来的（从 3d 手术推） |
| **缺判据** | “这个对应是什么级别的同构？” | 方向极好，但没有梯子，答“同构”和答“等价”听起来都对 |
| **缺边界** | 七条里没有一条问“什么情况下不成立” | 得到的全是“一般情况下成立”，无法反驳 |

**好问题的五条标准**（与 CHARTER §2 的答案契约配套）：

1. **有答案类型**：你要的是定义、定理、构造、数值，还是边界？
2. **有对象**：点名到公式 `(3.4)`、句子、页码，不是“那部分”。
3. **有边界**：在什么 k、什么群、什么亏格下答案会变？
4. **有核查出口**：翻到哪一页/哪个式子能判你答错？
5. **有依赖**：答它之前必须先答什么？（这决定讨论顺序）

下面逐条改写。每条给：原问题 → 诊断 → 改写后的子问题（带答案类型）→ 判定标准 → 常见错误答案。

## T0 起点

**原问题**：“Witten 为什么写这篇文章？他要解决什么问题？Chern-Simons 场论的量子化为什么困难？经典相空间是什么？这些是起点。”

**诊断**：四问都对，但每问都能被一段综述糊过去。“为什么难”这一问尤其危险，因为最容易得到的答案是**错的**——“因为 CS 是非线性作用量”。真实答案是“难在约束后的相空间”。

**改写**：

| # | 子问题 | 答案类型 | 锚点 |
|---|---|---|---|
| 0.1 | Atiyah 两问分别是什么？第一问由谁在哪篇解决？本文接哪一问？ | 文献事实 | p.351 |
| 0.2 | 给你一个候选的“Jones 多项式三维定义”，你用什么操作标准判断它够不够“内蕴”？ | 判据 | p.351–352 |
| 0.3 | 取 A₀=0 后 (1.3) 变成什么？为什么说“作用量的非线性不是困难所在”？ | 公式 + 论证 | (3.1)，p.366 |
| 0.4 | 经典相空间有三个层次：约束前的联络空间、约束面、辛商。各自维数多少？哪个才是“相空间”？ | 数值 + 定义 | p.366–368 |
| 0.5 | 本文哪些结论是“证明”，哪些是“断言/论证”？列出至少三条“we will assert”。 | 分级 | p.355–356 等 |

**判定标准**：0.3 若答“因为 CS 非线性所以难”，判错；正确答法是“A₀=0 后是二次型 (3.1)，非线性全部进入高斯定律约束 (3.3)；难在约束后的模空间”。
0.4 若答“相空间是联络空间”，判错；正确是“约束后、取辛商后的平坦联络模空间，g>1 时维数 (2g−2)dim G”。

**常见错误答案**：①“CS 是非线性理论，无法微扰”；②“相空间是所有联络构成的空间”；③“Witten 证明了 Jones 多项式就是 CS 的 Wilson 线期望值”（原文是 assert，证明在后世）。

## T1 几何量子化

**原问题**：“第二条主线，几何量子化的核心步骤。预量子化、极化、全纯截面的选取。每一步的数学前提是什么？这里涉及辛流形、线丛、复结构。AI 可以帮你查，但你要能判断它说的对不对。”

**诊断**：这是七条里最像“教科书目录”的一条，也最需要改成“本文在哪一步用了什么前提、缺了哪一步会怎样”。

**改写**：

| # | 子问题 | 答案类型 | 锚点 |
|---|---|---|---|
| 1.1 | 预量子化的充要条件是什么？本文的 [ω] 整性有哪两条独立来源？为什么二者必然一致？ | 定理 + 本文机制 | (1.4)；c₁(L^{⊗k})，p.369–370 |
| 1.2 | 为什么紧相空间不能做 q/p 分离？极化的严格定义是什么（用复化切丛说）？ | 定义 | p.368–369；译注 |
| 1.3 | Kähler 极化下“态=全纯截面”为什么有限维？这里用了 M 的什么性质？ | 论证 | p.368–369 |
| 1.4 | 本文在哪一步略去了半形式修正？后果是什么（哪个公式里的 k 实际应是 k+h∨）？ | 边界 | 译注；§4 |
| 1.5 | “不同极化给出射影幺正等价的量子化”——这是本文证明的，还是引用的期望？ | 分级 | 全节未证 |

**判定标准**：1.1 必须给出两条：大规范变换 (1.4) 与行列式线丛第一陈类整性；只说一条算半对。
1.2 必须说出“极化=复化切丛的 Lagrange 子丛（或等价地，可积分布）”，而不是“选一组 q 和 p”。
1.5 正确答案是“本文没有证明；这是几何量子化的普遍期望/定理（Kostant 等），本文只用到 Kähler 情形”。

**常见错误答案**：①把预量子化当成量子化；②把 [ω] 整性说成“技术假设”（它是 k∈ℤ 的另一面）；③忽略“射影”二字，说 H_Σ 与 J 无关是严格相等。

## T2 Wilson 线、穿刺点、BWB

**原问题**：“威尔逊线怎么对应到模空间上的穿刺点？穿刺点上的高斯约束是什么？怎么用 Borel-Weil-Bott 定理把约束反量子化回去？”

**诊断**：三个问题都好，尤其“反量子化回去”这个说法抓住了 Witten 的关键动作。缺一个前置：**为什么不能正向解约束？** 不问这个，就会把 BWB 当成一个技巧而不是被逼出来的办法。

**改写**：

| # | 子问题 | 答案类型 | 锚点 |
|---|---|---|---|
| 2.1 | (3.4) 的右端为什么是算符值？一个“算符值约束”在经典哈密顿形式里意味着什么？ | 结构 | (3.4)，p.371 |
| 2.2 | 如果硬把 (3.4) 当经典方程解，会得到什么？原文是否明说“量子群”？ | 文献 + 待核 | p.371；**待核** |
| 2.3 | BWB 的精确陈述是什么？为什么 λ 是最高权而**不加 ρ**？ρ 去了哪里？ | 定理 | 译注；后世 |
| 2.4 | 把每个 R_i 换成 (G/T, ω_{R_i}) 后，相空间维数怎么变？(3.4) 为什么变成可解的经典约束？ | 构造 | p.371–373 |
| 2.5 | 可积性条件 2j≤k 是几何量子化的结论，还是 WZW 表示论的输入？ | 分级 | p.373 |

**判定标准**：2.3 必须答出“H⁰(G/T,L_λ)=V_λ，λ 最高权，ρ 出现在 Weyl 维数公式而非 λ 的移位”——若说“λ+ρ”，判错（那是 Borel–Weil 的另一种写法，本文不用）。
2.4 必须答出“扩大相空间 → 约束变成经典可解 → 量子化给出带插入的共形块”，而不是“把 R 张量到共形块上”。
2.5 正确答案：本文用它作为**事实**（可积表示才有非零截面），机制属于 WZW 表示论/后世。

**常见错误答案**：①把 (3.4) 当经典方程；②说 BWB 是“把表示变成截面”而不说“把表示实现为辛商”；③把 2j≤k 当作 Witten 证明的定理。

## T3 共形块与 WZW

**原问题**：“几何量子化之后的模空间，怎么跟 WZW 模型的共形块对应？这个对应是什么级别的同构？是等价还是只有某种意义上的联系？”

**诊断**：**七个问题里最好的一个。** 它问的是“级别”，这是判断一个数学物理断言真伪的核心。缺的只是梯子。

**改写**：

| # | 子问题 | 答案类型 | 锚点 |
|---|---|---|---|
| 3.1 | 对每个带标记点 Σ，H_Σ 与共形块空间 V(Σ;R_i) 的对应在哪一级（L0–L4）？ | 分级 | p.369–374 |
| 3.2 | 胶合相容性在哪一节论证？用的是 Segal 的哪条公理？ | 构造 | §5，p.394–397 |
| 3.3 | “与 J 无关”给出的是平坦丛还是**射影**平坦丛？为什么？ | 边界 | p.370；译注 |
| 3.4 | 本文是否给出范畴等价（L4）？如果没有，L4 是哪一年、谁给的？ | 后世 | 待文献表 |
| 3.5 | 本文的内积（Quillen 度规）与 Segal/Friedan–Shenker 的内积是否同一个？ | 细节 | p.366 脚注 7 |

**判定标准**：3.1 正确答案是 **L1（每个 Σ 的向量空间同构）+ L2（胶合相容）**；说“L4 等价”判错（本文没有 MTC）；说“只有维数相等（L0）”判过弱。
3.3 必须答“射影平坦，因为共形反常/标架依赖；严格平坦要等半形式修正或改用射影丛”。

**常见错误答案**：①“等价”；②“H_Σ 就是 WZW 的 Hilbert 空间”（漏了“共形块/全纯部分”）；③“Witten 证明了模函子存在”（他论证，Segal 已有构造）。

## T4 Verlinde 公式

**原问题**：“Verlinde 公式怎么从共形块推出来？它的物理意义是什么？”

**诊断**：**预设了一个方向**。Verlinde 1988 是从 RCFT 的模不变性**猜**出来的；本文 §4.5 是从 3d 手术**证**出来的。问题里的“从共形块推”需要先问“哪个推导”。

**改写**：

| # | 子问题 | 答案类型 | 锚点 |
|---|---|---|---|
| 4.1 | Verlinde 1988 原始的输入是什么？输出是什么？ | 文献 | [12] |
| 4.2 | 本文 §4.5 的两条独立计算分别是什么？为什么对比就能得 (4.51)？ | 构造 | (4.28)(4.51)，p.388–393 |
| 4.3 | N_{ijk} 在本文里的几何身份是什么？ | 定义 | N_{ijk}=dim H(S²;R_i,R_j,R_k) |
| 4.4 | “物理意义”至少有三种读法（数学/CFT/3d），本文给的是哪一种？ | 分级 | §4.5 |
| 4.5 | 公式在什么情况下失效？（非 rational、对数 CFT、非 unitary） | 边界 | 后世 |

**判定标准**：4.2 必须说出“同一配分函数两种算法：一种给 S 矩阵，一种给融合系数”；只说“用 S 矩阵对角化”不算。
4.4 正确答案：本文给的是 **3d 意义**（融合系数=三穿孔球面 Hilbert 空间维数）；数学意义（S 对角化融合代数）是手段，CFT 意义是 Verlinde 原本的语境。

**常见错误答案**：①“本文从共形块推出 Verlinde 公式”；②把 S 矩阵当输入（它在本文里也是要算的对象）；③忽略 S_{0i} 归一化。

## T5 2d/3d 对偶

**原问题**：“这里的对偶跟 AdS3/CFT2 有什么区别？CS/WZW 对偶和全息对偶是两码事吗，这个得搞清楚。”

**诊断**：极好的问题，方向完全对。需要的是**判据**，不是描述。判断“是不是同一种对偶”，最硬的一条是“体理论有没有引力子”。

**改写**：

| # | 子问题 | 答案类型 | 锚点 |
|---|---|---|---|
| 5.1 | 两者的体理论自由度分别是什么？有无引力子？ | 判据 | §5；[38] |
| 5.2 | 中心荷的来源与公式分别是什么？（c=k dimG/(k+h∨) vs c=3l/2G） | 公式 | (4.41)；后世 |
| 5.3 | 边界理论分别取“全纯一半”还是“整块”？ | 结构 | §5 |
| 5.4 | “3d 引力=CS”在什么条件下成立？它是否使两者同一？ | 条件 | [38]；Achúcarro–Townsend |
| 5.5 | “CS/WZW 是 AdS3/CFT2 的特例”这句话，在什么意义下对、什么意义下错？ | 边界 | — |

**判定标准**：5.1 必须答“CS 无度规无引力子；AdS₃ 有引力子”——这一条就能定性。
5.4 正确答案：“3d 引力可写成两个 CS 的差（或 SL(2,R)×SL(2,R)），但那是引力，不是本文的紧致群 CS；等式成立不蕴含对偶等同。”

**常见错误答案**：①“都是 3d/2d 对偶，所以是一回事”；②忽略引力子；③把 Brown–Henneaux 的 c 与标架反常的 c 混为一谈（数值形式像，来源不同）。

## T6 范畴化

| 6.2 | Khovanov 的物理来源是什么理论？与本文的 CS 是同一条路径吗？ | 文献 | 后世 |

## 3. 怎么把要求“给”出去（给 AI 派活的模板）

不要写“请深入分析”。写这五行：

```
任务：回答 <子问题编号与原文>。
输出格式：<定义 / 定理陈述 + 证明梗概 / 构造步骤 / 数值表>，≤800 字。
允许的资料：<原文页图 p.N–M；译本对应节；指定 2 篇文献>。
判定标准：<必须出现 X；若出现 Y 则判错；必须标 原文/补/后世>。
反例要求：给出至少一个“该结论不成立”的情形。
禁止：综述式段落；无锚点断言；把“we will assert”写成“证明了”。
```

这套模板就是 CHARTER §2 的五条升级要求在“派活”层面的落地。**要求给得越具体，AI 越难用漂亮话糊过去；反过来，模糊的要求只会得到模糊的正确答案。**
