## 一、这是什么系列

Gaiotto–Moore–Neitzke（GMN）是 2008–2013 年间把 **4d N=2 超对称规范理论的 BPS 谱**、
**穿墙公式**、**超凯勒几何**与**二维可积系统**串起来的一组工作；2015 年他们又与 Witten 合作，
把这套「BPS 态 ↔ 网（web）/ junction」的图像推到 2d (2,2) 场论的「红外代数」。
本系列按原文顺序精译五篇，属于「先把基础设施建好，再谈形式化」的路线。

## 二、五篇之间的关系（读之前先看这个）

1. **GMN1 是地基**：把 4d N=2 放在 $\mathbb{R}^3\times S^1$ 上，BPS 粒子变成三维瞬子，
   度量的「必须光滑」逼出 KS 穿墙公式。技术核心是**黎曼–希尔伯特问题**与**扭量构造**。
2. **GMN2 是几何化身**：同一套穿墙公式在 Hitchin 系统 + WKB 近似里变成「谱网络」的跳跃，
   把 GMN1 的积分方程变成 WKB 曲线上的流动（TBA 关系在此显形）。
3. **GMN3 是把 $\Omega$ 精细化**：引入 framed BPS 态与线缺陷，回答「$\Omega$ 到底是什么的指标」。
4. **GMW1 是导读**：2d (2,2) 理论的网/junction 形式，篇幅小，适合先读。
5. **GMW2 是全书**：430 页的红外代数，把 GMW1 的草图补成完整结构；与 GMN1–3 是同一图像的二维版。

**建议读序**：GMN1 → GMW1（短，建立二维直觉）→ GMN2 → GMN3 → GMW2。

## 四、讨论班用法（这是本目录存在的理由）

后期要开专门的讨论班精读，建议每篇按这个顺序切：

1. **先读资料卡 `00-速览.md`**（10 分钟）——建立地图，不要一上来就翻原文。
2. **再读阅读报告**（40 分钟）——知道"哪些是硬的、哪些是物理论证"，避免把 §5/§7 当定理引用。
3. **精读时对照 `03-条款索引.md`**——每个式号都能定位到译本页码，原文页码在资料卡里给出。
4. **疑点落在 `04-术语文献勘误.md`**——术语争议、原文笔误都在这里，讨论时不要重复发现。
5. **每场讨论的结论写回 `研究笔记/`**，文件名 `<篇号>_讨论_<主题>.md`。

## 五、施工规范（跨篇不变）

- 术语冻结：以 `术语/glossary_master.tsv` 为准，已有条目不许改，新增要写依据（原文式号或定义处）。
- 公式不增删：带编号的一律 `equation`，编号与原文 `(x.y)` 逐节对齐；原文不编号用 `\[...\]`。
- 原文错误照译 + 记入该篇 `工程文件/work/02_疑点清单.md` 的勘误表。
- 编译硬指标：`xelatex` ×3，0 error，无 overfull > 3pt，无 `??`，无未定义引用。
- 人名一律保留拉丁原文；中文与拉丁之间不加多余空格（`\xspace` 慎用）。
- 依据只能是原文、nLab、arXiv；知乎/公众号/CSDN/AI 摘要等二手来源一律不看、不引。
