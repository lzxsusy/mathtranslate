# Seiberg — 《超对称非阿贝尔规范理论中的电磁对偶》

> arXiv:hep-th/9411149 ｜ 22 页 ｜ 第 2 组（4d N=2 与 Seiberg–Witten）

## 一、这篇是什么

N=1 超对称 QCD 的「对偶」：SU(N_c) 与 SU(N_f − N_c) 两个不同的 UV 理论在红外给出同一套物理，一方的夸克与胶子是另一方的非阿贝尔磁单极（孤子）。文章先在 3N_c/2 < N_f < 3N_c 的非阿贝尔库仑相里把两套描述摆出来，再用形变把对偶、禁闭与希格斯机制串起来。

## 二、与本系列哪一处接口

- **GMN1 §7（穿墙公式的证明，译本 p48）**：那里的策略是「同一希尔伯特空间、两套弱耦合变量」，本文是这一策略最干净的范例。清单注明本文不在 GMN1 那 46 条引用内，属背景层。
- **GMN1 §2.2（译本 p11）**：KS 公式之所以可用，是因为 K_γ、Ω(γ) 都是精确可算的全纯对象；本文 §1（p2）即以此类全纯量的精确可算性为出发点。
- **GMN2 §9（译本 p127，N_f=4）**：把 N_f = 4 单列为超共形，用的判据就是本文 §2（p5）的非平凡不动点窗口 3N_c/2 < N_f < 3N_c。

## 三、核心内容

- §2（p5）给精确 beta 函数 (2.1)，论证非平凡不动点的存在，把讨论限制在 3N_c/2 < N_f < 3N_c 的相互作用非阿贝尔库仑相。
- p6：幺正性要求无自旋算符 D ≥ 1（自由场取等号），手征算符取等号 D = 3R/2；由 (2.3) 的 D(Q̃Q) = 3(N_f − N_c)/N_f 反推出窗口端点，并证明手征算符成环。
- §3（p7）给出对偶描述：电侧可延到 3N_c ≤ N_f 的自由区，磁侧延到 N_c + 2 ≤ N_f ≤ 3N_c/2；p9 明说 q、q̃ 与对偶胶子都是磁的。
- §4（p10）变形对偶理论（§4.1 p10、§4.2 p11），p12–p13 把对偶变量解释成原始理论的磁单极；§5（p15）推广到 SO(N_c)，§5.2（p19）处理 N_f = N_c−1, N_c−2, N_c−3。

## 四、读法建议

必读 §1 的判据（p2–p4）、§2（p5–p6）、§3（p7–p9）、§4（p10–p14）。§5 的 SO(N_c) 可跳。约 12 页；与 GMN 的关系是方法论上的，不必逐式对读。
