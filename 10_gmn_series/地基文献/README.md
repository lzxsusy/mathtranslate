# 地基文献库 · 导读

> GMN 三部曲（0807.4723 / 0907.3987 / 1006.0146）与 GMW（1506.04086–04087）的**基础文献库**。
> 建立于 2026-11-21。清单 `00_清单.md`，台账 `01_下载台账.tsv`，PDF 在 `..\..\00_原文\基础文献\`。

## 这个库是什么

33 条条目，按 8 个主题分组：**① 穿墙公式与稳定性 ② 4d N=2 与 Seiberg–Witten ③ Cecotti–Vafa 与 tt\* ④ Denef–Moore 与多中心解 ⑤ TBA 与可积 ⑥ Hitchin 与 WKB 谱网络 ⑦ 超凯勒与扭量 ⑧ 综述与构造**。其中 **29 篇有 arXiv 全文（已下载校验）**，**4 篇只登记书目**（CV 1991、Zamolodchikov TBA 1989、Hitchin 1987、HKLR 1987——arXiv 上确实没有，已用标题检索核对）。第 0 条是锚点：GMN1 自己的 PDF。

收录原则：**只收真正地基性的**。GMN1 的 46 条引用里，有 24 条是单篇技术引用或纯工具文献，没有收（清单附录 B 逐条列了为什么），宁少勿滥。

## 怎么用

1. **查一条文献该读多少、为什么读** → `00_清单.md`。每条都有「为什么需要它」，写的是与 GMN1–3 的**哪个式子/哪一节**接口。
2. **找 PDF** → 看清单的「arXiv」列，按主题目录取：`00_原文\基础文献\<主题序号>_<主题名>\<arxiv>_<短名>.pdf`。
3. **核对下载是否可信** → `01_下载台账.tsv` 有页数与 sha256 前 16 位；PDF 首页标题已逐篇抽查，与 arXiv 元数据一致。
4. **要一篇的骨架** → 本目录下 **31 个** `<arxiv>_<短名>.md`（29 篇有全文的写四段式摘要，4 篇只有书目的写短条目；合计 33 条），每篇四段：这篇是什么 / 与 GMN 哪一处接口（篇号+式号+译本页）/ 核心内容 / 读法建议。

## 按什么顺序读

不要从头到尾读。跟着 GMN2 的翻译进度走：

| 阶段 | 读什么 | 目标 |
|---|---|---|
| 0. 热身 | GMN1 §1–§2（已译）+ 清单第 6、7 条（SW） | 拿到 Z_γ = ∮λ、τ(a)、库仑分支 B |
| 1. 穿墙 | 第 1、2、3 条（KS → Bridgeland → BTL） | 看懂 (2.15)/(2.16) 的 K_γ 与「乘积 = 恒等」 |
| 2. 四维类比 | 第 12、11、13、14 条（CV 系） | 看懂 GMN1 摘要那句「tt\* 的四维类比」 |
| 3. 束缚态 | 第 15、16、17 条（Denef → Denef–Moore） | 看懂 GMN1 §7 的证明为什么能成立 |
| 4. GMN2 几何 | 第 22 条书目 + GMN2 §4 + 第 25、26 条 | 谱曲线 Σ → C、电荷格、WKB 曲线 |
| 5. TBA | 第 20 条讲义 → 第 18 条书目 → 第 19、21 条 | 看懂 GMN1 附录 E 与 (5.13) |
| 6. 背景 | 第 30、31 条综述 → 第 32、33、28、29 条 | 需要时再翻 |

## 必须先读的五篇（≤5）

1. **KS, 0811.2435**（第 1 条）——穿墙公式的唯一源头。GMN1 全篇的骨架就是它；先读 §1.1–§1.4 + §2.1–§2.3，约 40 页。
2. **Seiberg–Witten, hep-th/9407087**（第 6 条）——给出 Z_γ = ∮λ 与 τ(a)。没有它，(2.35) 的 g_sf 是从天上掉下来的。
3. **Denef–Moore, hep-th/0702146 §3.2.3**（第 17 条）——「BPS 态可以分裂/重排但希尔伯特空间不变」，这是 GMN1 §7 物理证明的全部内容。只读 §1.1 + §3.2.3，约 20 页。
4. **Cecotti–Vafa, hep-th/9211097 §1–§2**（第 12 条）——tt\* 方程与「由 S-矩阵自举出谱」的范式；GMN1 的 RH 问题就是它的四维版。
5. **Hitchin 1987**（第 22 条，仅书目）——GMN2 的几何地基是 Hitchin 系统。手上没有 PDF 时的替身：**GMN2 §4（p.59）** 已把 Hitchin 纤维化讲全，再配 **1204.4824 §5.1（p.21）** 看 WKB 曲线怎么长出来。

## 边界与维护

- 本库**只做地基**：具体技术引文（如 Gaiotto 0904.2715 的 class S 构造、Boalch 0806.1050 的 wild 情形）请按 GMN2 §1 的叙述按需另补。
- 名录/台账由 `_make_docs.py` 从同目录的 `_lib_results.json`（arXiv 元数据 + 下载校验结果 + 首页抽查）生成；改了文案重跑即可。
- 下载脚本 `_build_library.py` 保留（输出也写回同目录 `_lib_results.json`），改 id 列表即可增量补篇。
- 校验口径：文件 > 20 KB、`fitz.open()` 可开、页数 > 1、首页标题与 arXiv 元数据一致。
