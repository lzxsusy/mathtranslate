## 一、这篇文章在讲什么（给没读过原文的人）

**一句话**：在 $d=4$、$\CN=2$ 超对称场论中，**线算子的真空期望值**恰好是模空间 $\CM$ 上的**达布坐标**（本文第一主结果 (6.3)）；要证明这一点必须先给「线算子存在时的 BPS 态」一个自洽的定义与计数，于是作者引入**带框 BPS 态**（framed BPS state）与**保护自旋特征标**（protected spin character, PSC），用它们的生成函数把**带框穿墙公式**写成生成函数代数的乘法，从而把 Kontsevich–Soibelman（KS）穿墙公式归约到**半本原**（semiprimitive）情形并给出**新证明**；最后在六维 $(2,0)$ 理论于黎曼面 $C$ 上紧化（class $\CS$）的模型里，把线算子分类为 $C$ 上的**叶层**（lamination），并给出计算 framed BPS 谱的 **traffic rule** 算法。

**逻辑链**（五步，任何一节译文都不能与它冲突）：

1. **对象**：$d=4$、$\CN=2$ 理论中保持**四个**超对称的线算子 $L_\zeta$（$\zeta$ 是 $S^1$ 约化后的角变量，'t Hooft–Wilson 算子给出例子）。在线算子存在时，理论的希尔伯特空间 $\CH_L$ 仍是未破缺超对称的表示；**带框 BPS 态**就是其中能量达到**修正 BPS 界** $E\geq -\Re(Z_\gamma/\zeta)$ 的态（§3.1，(1.2)），$\gamma$ 是电磁荷、$L$ 是「框」。没有线算子时的普通 BPS 态被称为**「原味」BPS 态**（vanilla BPS state）。
2. **计数**：按电荷 $\gamma$ 分次后的带自旋计数由 **PSC** $\fro(L_\zeta,\gamma;y)$ 给出（§3.2，(3.12)(3.14)）；$y=-1$ 时退化为 framed BPS 指标 $\fro(L_\zeta,\gamma)\in\IZ$（(1.1) 的系数）。带框 BPS 态的几何图像是 **halo**：BPS 粒子松散地束缚在线算子上，形成 halo Fock 空间（§3.3），这与超引力中的 halo 束缚态同源。
3. **代数结构**：生成函数 $F(L_\zeta):=\sum_\gamma\fro(L_\zeta,\gamma;y)X_\gamma$ 的元素满足 $X_\gamma X_{\gamma'}=y^{\langle\gamma,\gamma'\rangle}X_{\gamma+\gamma'}$（(1.3)(1.4)，海森堡型代数/量子环面）。$\zeta$ 掠过一条 BPS 射线时 $F$ 按**带框穿墙公式**跳变；该公式等价于用量子双对数（§3.4）作共轭，于是**半本原** KS 公式的乘积可解，motivic KS 公式随之得出（§3.5）——这是本文第三主结果、也是 KS 公式的新证明。
4. **几何解释**（第一主结果）：把 $\fro(L_\zeta,\gamma)$ 当作系数，$\langle L_\zeta\rangle=\sum_\gamma\fro(L_\zeta,\gamma)\CY_\gamma$ 正是 §6 的达布坐标展开 **(6.3) = (1.1)**：达布坐标就是线算子的 vev。$S^1$ 约化后，$\langle L_\zeta\rangle$ 又是 $\CM$ 上平坦联络的和乐（§7，(7.13)），于是「vev 的 IR 展开」给出了达布坐标的物理意义。
5. **六维视角与算例**（第四主结果）：class $\CS$ 中 $A_1$ 型 $(2,0)$ 理论在 $C$ 上部分扭转紧化，线算子由 $C$ 的**装饰版本上的叶层**（Fock–Goncharov）分类（§9.4），framed BPS 指标由 **traffic rule** 组合地计算（附录 F）。算例：$SU(2)$、$N_f=0$ 的 Wilson 线基态由三项组成 (1.5)=(10.33)；$N_f=4$ 强耦合下 Wilson 线支持 **7 个**带框 BPS 超多重态 (10.44)；另有 $U(1)$/Taub-NUT、$N=3$ 与 $N=4$ Argyres–Douglas 等（§8、§10）。末尾 §5（簇代数）与 §12（热带标签）指出两条通往数学的方向，§13 列开放问题。

**技术内核**（硬骨头，逐块施工时参考）：

- **PSC 与 refined index 的关系**（§3.2）：$y\to -1$ 得到指标；$y$ 记录 $2J_3$，与 $SU(2)_R$ 的 $I_3$ 的组合化成 $(2J_3)_{\rm tot}$；带框态的自旋由线算子与 halo 共同贡献。
- **带框穿墙与量子双对数**（§3.4–3.5）：$F$ 在 $\zeta$ 跨越 $\arg Z_\gamma$ 时的跳变是**共轭**（而非乘），共轭子由量子双对数给出，因此半本原情形可解；(3.47)(3.48) 是 motivic 版的乘法公式。
- **形变环**（§3.6）：PSC 生成函数的乘法定义 $\CM$ 上全纯函数代数的形变（(3.38)），与 §4 的形式线算子、§11 的量子和乐相连。
- **形式线算子**（§4）：在 $U(1)$、$N=3$ AD、纯 $SU(2)$ 等可解模型中把生成函数写成显式乘积（含 $q$-Pochhammer 类因子），用来**检验**带框穿墙（§4.5 讨论物理 vs 形式）。
- **达布展开**（§6）：(6.3) 及其变体；多个模空间、极大互局部格（6.3）、扭模空间（6.4）。
- **六维**（§7）：$(2,0)$ 理论在 $C$ 上紧化，BPS 态 = 弦网，线算子 = 端点/叶层；§7.5 给出线算子编目。
- **叶层与 traffic rule**（§9.4 + 附录 F）：Fock–Goncharov 坐标、装饰三角剖分、traffic 的局部规则（F.2），把 framed BPS 指标算成组合和。

**读者定位**：读过 GMN1（0807.4723）与 GMN2（0907.3987）的数学物理读者；本文原本是 GMN1 的一节，独立成篇后仍以那两篇为背景（$[1,2]$ 即前两篇）。数学读者可从 §5、§9.4、附录 F 切入；$d=4$ 的物理读者可先读 §3、§4、§8、§10，把 §7 与 §9 当作六维的「翻译词典」。

## 六、已知坑

1. **原文宏有毒，不能抄**：`\a \b \c \p \la \ra \re \im` 与一大批 `\ba…\bZ`（加 bar 的单字母）会与 LaTeX 的 `\c`（重音）、`\b`（下划线重音）冲突；译文一律写完整命令。
2. **`\be`/`\ee` 在本文真的是公式环境**：`\def\be{\begin{equation}}`、`\def\ee{\end{equation}}`（原文 220–223 行）——与 GMN2 恰好相反（GMN2 的 `\be` 是 `\bar e`）。移植 GMN2 的施工经验时**别搞反**；译文公式一律写 `\begin{equation}…\end{equation}` 或 `align`。
3. **`\sect` 宏会重置式号**：`\newcommand{\sect}[1]{\setcounter{equation}{0}\section{#1}}`（原文 84 行）。译文用 `\numberwithin{equation}{section}` 复现；若原文某节用了 `\section` 而非 `\sect`，式号会整体错位 —— 每块译完抽 5 条回 PDF 核对（`work/eqnum.py` 已给出全文 label→式号）。
4. **`\insfig` 参数不同**：原文 `\insfig{名字}{图注}`（2 参，scale=0.275，内部拼 `figures/名字-crop.pdf`）；本译本改成 `\insfig[宽度]{名字}{图注}`（3 参，宽度缺省 `0.8\textwidth`）。**图名照抄原文第一参数**，图注照译；`\instwofigs` / `\insthreefigs` 照原文定义（6 / 9 参）。
5. **framed 译名两派**：术语表第 75 行 `framed BPS state → framed BPS 态`（状态「定」）、第 99 行同名条（「待议」）；本书名取**带框 BPS 态**，正文首次出现时写「带框 BPS 态（framed BPS state）」，冲突记入 `work/02_疑点清单.md`，**不改旧行**。
6. **lamination 译名**：术语表第 76 / 100 行均为「叶层」且标「待议」；本文 §9.4 才有正式定义，沿用「叶层」，首次出现括注 lamination。
7. **halo 与 traffic rule 保留拉丁原文**：halo（束缚态/构型/Fock 空间）、traffic rule（算法）不译；`\emph{}` 标首次出现。
8. **三类对象不许混**：① 模空间的**边缘稳定墙**（wall of marginal stability，穿墙的墙）；② §3.3 halo 讨论里 BPS 粒子云的**边界**；③ §9.4 叶层的**端点/边界**（叶层在穿刺点附近的行为）。译文中 ① 一律「墙」、② 写「halo 边界」、③ 写「叶层的端点」。
9. **`\N` 是 $\mathcal N$（超对称数）**，`\CN` 同义（bbl 里有一处 `\N`，make_bbl.py 已转成 `\CN`）；不要与规范群 $N$（如 $N_f$ 的 $N$）混。
10. **$y$ 与 $\zeta$ 的角色不同**：$\zeta\in\IC^\times$ 是 $S^1$ 约化的角变量（穿墙发生在 $\arg Z_\gamma$ 处），$y$ 是 PSC 的自旋变量（$y=-1$ 退化到指标）。两者在 §3–§4 反复出现，抄公式时逐字符核对。
11. **式号跨块引用**：v0.1 阶段一律写原文编号（如 (6.3)、(10.33)）并加 `% TODO 合稿改 \eqref{...}`；label 名照抄原文 `\label{eq:...}`，合稿时机械替换。
