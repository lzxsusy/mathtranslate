## 1. §1 逐段要点（对应 ch01.tex）

1. **开场（原 361–366）**：$\CM$ 是 $d=4$、$\CN=2$ 理论在 $\IR^3\times S^1$ 上的真空模空间，带完全可积结构；[1,2] 研究其上的「达布坐标」$\CY_\gamma$。实用的理由：算超凯勒度量、证明 KS 穿墙公式、构造 $\CN=4$ 散射振幅；有趣的理由：热力学 Bethe 拟设、Teichmüller 理论的 Fock–Goncharov 坐标。
2. **预告（368）**：本引言余下部分对四个主要结果作说明性描述。
3. **第一结果 + (1.1)（370–390）**：达布坐标就是 $\CN=2$ 理论中**线算子的 vev**；集中表现为 (6.3)即 (1.1)：$\inprod{L_\zeta}=\sum_\gamma\fro(L_\zeta,\gamma)\CY_\gamma$。
4. **对 (1.1) 两端的解释（391–411）**：左端是超对称线算子（保四个庞加莱超荷，角度 $\zeta$；'t Hooft–Wilson 算子是例子）；右端是达布坐标展开，$\CY_\gamma$ 可看成「插入无穷重双荷子」得到的 IR 线算子 vev。
5. **带框 BPS 态与修正 BPS 界 (1.2)（412–427）**：系数 $\fro(L_\zeta,\gamma)\in\IZ$ 是新指标；$\CH_L$ 仍按 $\gamma$ 分次；带框 BPS 态 = 取到 $E\ge-\Re(Z_\gamma/\zeta)$ 等号的态；对照「原味 BPS 态」。
6. **PSC（428–436）**：精细化指标以记录自旋 → 保护自旋特征标 $\fro(L_\zeta,\gamma;y)$（§3.2 的 (3.12)(3.14)）；$y=-1$ 得 BPS 指标。
7. **生成函数 (1.3) 与海森堡代数 (1.4)（437–460）**：$F(L_\zeta)=\sum_\gamma\fro(L_\zeta,\gamma;y)X_\gamma$，$X_\gamma X_{\gamma'}=y^{\langle\gamma,\gamma'\rangle}X_{\gamma+\gamma'}$；**第二结果**：这个代数是 $\CM$ 上全纯函数代数的非交换形变，$y$ 是形变参数。
8. **乘法法则的落点（461–468）**：物理论证在 §3.6；具体例子在 §4；交换环的对照在 §8；$A_1$ 情形与量子 Teichmüller 的量子测地长度算子代数相关（§11）。
9. **PSC vs refined index 与强正性猜想（469–478）**：PSC 是先验的指标；在检查过的例子里与 refined index 相符 → 蕴涵某些超对称表示不存在 → §3.2 的「强正性猜想」；强正性蕴涵线算子之环与 vev 可用形式代数算出（§4）；联系 Lusztig–Kashiwara 典范基、簇代数洛朗现象、Fock–Goncharov 泛洛朗多项式。
10. **带框穿墙与 halo（479–493）**：带框 BPS 态经历与「原味」态类似的穿墙；边缘稳定墙的类比物是 (3.9) 的 **BPS 墙**；墙附近部分带框态有类 Denef 多中心超引力「halo」构型；越墙瞬间 halo 构型的 Fock 空间被产生/湮灭；**第三结果**：生成函数如何穿墙——本质是量子双对数的共轭（精确式 (3.47)(3.48)）。
11. **motivic 穿墙公式的推论（494–507）**：由带框穿墙给出 KS motivic 公式（对「原味」PSC）的简单物理推导；思路是通过「原味」态对带框态的影响间接研究前者；与 [1] 的推导方式类比；结论：motivic KSWCF 直接来自 halo Fock 空间的物理。
12. **第四结果与 class $\CS$（508–520）**：class $\CS$ = $d=6$ $(2,0)$ 理论在亏格 $g$、$n$ 个穿刺点的黎曼面 $C$ 上部分扭转紧化；§7 回顾六维理论；关键结果 (7.13)：$\CM$ ≅ $C$ 上平坦联络模空间，线算子量子期望值 = 经典和乐。
13. **$A_1$、叶层与 traffic rule（521–534）**：§10 的算例来自 $A_1$ 类（$\lieg=su(2)$）；§9 把 Drukker 的共形 $A_1$ 线算子分类推广到渐近自由；闭曲线同痕类 → **叶层**（§9.4）；与 Fock–Goncharov 的联系；framed BPS 指标化归为 traffic rule 算法（附录 F）。
14. **算例 (1.5)=(10.33) 与 7 个超多重态 (10.44)（535–547）**：$SU(2)$、$N_f=0$ Wilson 线振幅 = $\CY_{\gamma_e}+\CY_{-\gamma_e}+\CY_{\gamma_m}$；第三项弱耦合指数小、出人意料；$N_f=4$ 强耦合下 Wilson 线支持 7 个带框 BPS 超多重态。
15. **簇代数与热带标签预告（548–553）**：§5 形式线算子代数 = 量子簇代数，构造 $\CN=2^*$ 的形式线算子、精细化正性猜想、引入「簇 $\CN=2$ 理论」；§12「热带 $\CN=2$ 理论」与热带标签 = 线算子枚举的 UV→IR 映射。
16. **收尾（554–558）**：技术论证与约定入附录；篇幅虽长仍留下许多未翻的石头；§13 列开放问题。
