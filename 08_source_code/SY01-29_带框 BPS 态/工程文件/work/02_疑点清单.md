## C. 施工风险

1. **`% TODO` 债**：ch01 已埋 26 处「中文原文编号 + `% TODO \ref/\eqref`」。合稿前必须清零（机械替换），否则会留下「第 6 节」这类硬编码节号。
2. **式号错位**：`\sect` 只在部分节用；若某节实际用 `\section`，`\numberwithin` 会整体错位。**每块译完抽 5 条**与 `work/eqnum.py` 的表对照。
3. **图宽**：`\insfig` 缺省 `0.8\textwidth`，但原文按 `scale=0.275` 排；宽图（如 `WeakCoupling`、`millipede`）可能要 `0.6\textwidth` 或 `0.9\textwidth`，逐图目检。`\instwofigs` / `\insthreefigs` 用原文 6/9 参定义。
4. **ch15 含 `\appendix`**：合稿时 main.tex 不要重复 `\appendix`，否则附录字母翻倍。
5. **图内英文不译**：52 幅图的标注保持英文（图注照译），这是系列惯例。
6. **密度最高块**：ch12（7 页、34 式、14 图）与 ch05（11 页、29 式、9 图）工时最长，排期时留足。
7. **附录 G 依赖 §10.3**：Tchebyshev 展开式（`eq:chebyshev-form`）引用了 §10.3 的记号，最后做，且合稿时对照 §10.3。
8. **编译时间**：全文 124 页 + 52 图，三遍约 3–6 分钟；分块阶段 main.tex 只 `\input` 已译块，避免误报。
9. **术语表追加格式**：5 列 tab 分隔（英文 / 中文 / 注释 / 出处 / 状态），追加在文件末尾、空行之后；旧行一字不改。
10. **字体警告**：`pdftotext` 对本文 PDF 报 `Missing language pack for 'Adobe-GB1'`——是 poppler 缺 CJK 映射，**不是文档问题**；取文本用 PyMuPDF。
