## 六、怎么用这张索引

1. **查式号→页码**：先在 §一 的 52 条核心表里找（覆盖全篇引用的 90%），找不到再查 §三 的 333 式总表或 `eq_index.tsv`。式号在两版相同，可直接对 arXiv 版引。
2. **查节→起始页**：用 §二 的表；章内小节页码（如 §10.3 起于 p88）见 00 卡第四节或 `main.toc`。
3. **查图**：用 §五，图名与 `figures/*-crop.pdf` 一一对应；图 1、15–21、45–52 是「示意图」（谱、叶层、路径），图 3–14、22–44 是「切面图」（腔、BPS 墙在 $\zeta$ 平面的投影），引用时区分。
4. **校对优先级**：式号缺/重 → 先跑 `build_index.py`（§三 的表应恰好 333 行）；图号错 → 跑 `fig_list.py`；页码错 → 重跑脚本比手改可靠。两个脚本都只读文件，可以放心重跑。
