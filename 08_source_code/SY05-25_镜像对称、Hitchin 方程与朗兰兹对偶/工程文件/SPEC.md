## 1. 底本

- 原文日期行作 "February, 2007"；文末地址行为 IAS 与 `dgaiotto@gmail.com, witten@ias.edu` 并列，按预印本原样保留（译注中点出）。

## 2. 翻译判据

| 判据 | 做法 |
| --- | --- |
| 语义级忠实 | 不改写、不删节、不合并段落、不调整论证次序 |
| 语气 | 第一人称复数、判断强弱（it turns out / we expect / is believed / it seems）照译 |
| 留白 | 原文只给结论处，译文同样只给结论，展开全部移入译注 |
| 符号 | 完全沿用原文；复值联络 `\bm{A}=A+i\phi`、Hodge 星算子 `\star`、群名正体 |
| 瑕疵 | 拼写与排印问题按语义翻译、不代改；影响理解者出译注说明 |
| 标点 | 中文全角；英文术语两侧半角空格；术语首现括注英文 |

## 3. 译注判据

- **必须加注**的场合：原文一句带过、但读者无法自行补出的定义或定理；原文使用了未定义的记号；跨节呼应的关键结论；物理/几何名词（膜、扭转、超凯勒商、叠）首次出现。
- **不得加注**的场合：原文已展开之处；可由原文前后文直接读出之处（避免把译注变成第二篇论文）。
- 每条译注结构：**编号（x.y）→ 注文 → 来源行**。来源行三级：
  - `A`：原文自身或原文所引的原始文献（Atiyah–Bott 1982、Hitchin 1987a 等）
  - `B`：nLab 等社区维护的百科/综述，**须与 A 级交叉核对**，并给完整 URL 与访问日期
  - `I`：本库内部文档，或纯由原文可推得（行文标「译者按」，并说明推断理由）
- 不允许：以「众所周知」「容易看出」代替来源；引用未打开过的 URL；引用黑名单来源（问答社区、百科转载站、博客、公众号等）。

## 4. 版式判据

- 节标题形如「1、A-模型与 B-模型」；公式编号随节，与原文 (2.1)–(5.1) 对齐。
- 脚注全文连续编号，【原注】与【译注 x.y】混排但前缀可区分；译注来源行用 `\scriptsize` 以免与注文同号。
- 前置页 roman（凡例 ii、摘要 iii、目录 iv），正文 arabic 自 1 起。
- 两张图均以 TikZ 重排（原文图 1 为文字排出的示意图，图 2 为译者后记新增依赖图），caption 说明「内容未变/为译者所加」。
