# 通读笔记：Witten, *Mirror Symmetry, Hitchin's Equations, and Langlands Duality*（arXiv:0802.0999v1）

读法：先读全文两遍（第一遍求结构，第二遍逐段核公式与引文），再逐节落笔。底本 15 页、6 节、5 条作者脚注、22 条参考文献。

## 一、总体判断

- **不是综述，是「框架文」**：全文不证新定理，做的事是把四组独立发展出来的东西摆成一个可互相翻译的框架，并逐处标注翻译的代价（要添参数、要换范畴、要放弃严格性）。
- **六节是一条单向链，不是六章并列**：每节为下一节准备一件不可替代的工具；第 6 节还有一个「回头修正第 1 节定义」的反向作用（模空间应读作叠）。
- **贯穿的三条主线**：对偶的谱系（T-对偶 → 镜像 → S-对偶 → 几何 Langlands）；复结构与实结构的张力（陈述只依赖实二维拓扑，证明必须借复结构）；奇性即参数（单值性 → 共轭类 → Simpson 参数 → 量子参数 → 极点系数 → 辫群/映射类群）。

## 三、写作风格与翻译要点

- 句式短、判断留有余地（"it seems"、"we expect"、"is believed"），译文照译，不加强也不减弱。
- 大量「一句话带过一个定理」，读者若不知出处会断链——这正是译注要补的地方（46 条，按节 6/8/8/7/7/10）。
- 作者自引偏多（Kapustin–Witten 2007、Witten 2007、Gukov–Witten 2006），读时应把它们看作本文的「前篇/续篇」而非背景。
- 底本为预印本工作稿：个别拼写错误、文末邮箱行并列作者与合作者、第 11 页脚注中 orbifold 一词用法需据上下文判断——一律按语义翻译，不代改，必要时出译注。

## 四、通读后的风险清单（落笔前已知）

1. 公式字符（$\star$、$\wedge$、上下标）必须以页面图核对，文本层不可信。
2. 第 5 节的 $T_k$ 缩放、第 4 节的 $\exp$ 符号约定是两处最容易「顺手改对」而违背「不改原文」的地方。
3. 第 6 节的「叠」是全文最陡的一跳，译注必须补足「为什么没有有限维全局商」。
4. 「SYZ」一词原文并未出现，是译者为概括第 3 节而引入的说法——只能出现在译注与后记，不得进入正文。
