## 1. L318：$M_Z$ 的矩阵与英文文本层不一致

- 中文（`chapters/ch10.tex:318`）：$M_Z=\left(R\oplus R[1-\deg Z],\begin{pmatrix}0&Z\\XY&0\end{pmatrix}\right)$。
- EN p.303（文件行 504–509）文本层作 `0 Z / XZ 0`。
- 判断：电位为 $XYZ$，三个标准矩阵分解应为 $M_X=(0,X;YZ,0)$、$M_Y=(0,Y;XZ,0)$、$M_Z=(0,Z;XY,0)$，中文的 $XY$ 才使三段复形首尾相接；英文 $XZ$ 应是排印/文本层之误。故不改，按中文为准。

## 2. L470：「想成 $\mathbb C\setminus\{0,1\}$」与英文 `C∗\ {0}`

- 中文：可以把这个分次曲面想成 $\mathbb C\setminus\{0,1\}$，其线场沿径向向外。紧接一句把 $R$、$R/(X)$、$R/(Y)$ 依次对应 $(-\infty,0)$、$(0,1)$、$(1,+\infty)$。
- EN p.306（文件行 764）：`We can picture this graded surface as C∗\ {0} with a line field that points radially outwards.`
- 判断：这里的曲面是裤子曲面 $\mathbb P^1\setminus\{0,1,\infty\}=\mathbb C\setminus\{0,1\}$，实轴恰被切成上述三段；`C∗\ {0}` 既非通顺记号也与三段划分不合，应是文本层把 $\mathbb C\setminus\{0,1\}$ 提坏。中文正确，不改。

## 4. 例题编号与原书不同（提醒，勿按英文编号回改）

- `elegantbook.cls` 中 `example` 用独立计数器 `\newcounter{exam}[chapter]`、`exercise` 用独立计数器 `\newcounter{exer}[chapter]`，`note` 环境不计号；英文原书则共用一套 Example 编号。
- 因此 $k=5$ 那一例在中译本是「例 10.11」（本章第 11 个例题），原书为 Example 10.27；`chapters/ch10.tex:555` 的 Tutor Note 写「例 10.11」、`:598`/`:611` 图注写「习题 10.4」「习题 10.5」，都与本译本实际编号一致，**不是**笔误，请勿按英文数字回改。
