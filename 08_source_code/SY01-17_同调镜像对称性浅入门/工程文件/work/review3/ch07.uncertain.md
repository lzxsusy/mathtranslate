# 第 7 章 存疑与未改事项（ch07.uncertain.md）

以下各项**未改动**，请主校决断。

1. **环境编号机制（全书层面）**：elegantbook 未启用 `usesamecnt`，例题、定理、定义各自独立计数——`build/main.aux` 中 `\newlabel{def:affine-ring}{{7.1}` 与 `\newlabel{thm:affine-rings-varieties-antiequivalence}{{7.1}` 同为 7.1，编译 PDF 中“例题 7.21”与“定义 7.21”并存，与书中连续编号 7.1–7.97 不一致。属 main.tex/class 层面，本章未动；若要统一，需在 main.tex 的 `\documentclass` 选项加 `usesamecnt`（会牵动全书交叉引用，须整体重编译核对）。正因如此，note 环境的“注 7.x.”全是手写标签（note 无计数器），本轮只删了 381 处多出的“注 7.21.”，其余 14 个保留。

2. **反 Fano 簇 vs general type（ch07.tex:1339–1344，定义 7.73）**：原书 Definition 7.73 第三款作 “anti-Fano if the canonical bundle $K$ is ample”，紧接正文却作 “a Fano or of general type”，定理 7.76 又作 “Fano or anti-Fano”。中文按定义作“反 Fano 簇（英文常称 general type，亦称一般型簇）”，两种说法并存忠实于原文；如需统一请主校定夺。

3. **相干层 / 凝聚层**：GUIDE 冻结术语表作“凝聚层 coherent sheaf”，但全书正文通用“相干层”（各章合计 95 处，本章 48 处），单改本章会不一致，故未动（与 ch03.uncertain.md 第 1 条同）。

4. **例 7.90 的矩阵指标（ch07.tex:1679–1687）**：书中写作 $1_k$，但按箭图两端维数应为 $(k+2)\times(k+1)$ 与 $(k+1)\times k$ 等；前轮已按尺寸改写为 $1_{k+1}$、$1_{-k-1}$，数学自洽。若严格贴原文可回退，但会与所标矩阵尺寸不符。

5. **英文文本层笔误（未照抄）**：例 7.29（EN p.185）“$=0$ if $\ell<k<\ell-3$”应为 $\ell<k<\ell+3$；EN p.212 “the total space of the canonical bundle of $Y=|K_{\mathbb P^n}|$” 本身同义反复（$Y$ 已定义为该全空间）。中文按数学正确者书写，勿照文本层回改。

6. **注 7.21 已改（备案）**：原书该句无编号、书中无 Remark 7.21，本轮删去手写编号改为“注意，”，以免与例 7.21 撞号（见 JSON 第 1 条）；如主校另有编号策略请回改。
