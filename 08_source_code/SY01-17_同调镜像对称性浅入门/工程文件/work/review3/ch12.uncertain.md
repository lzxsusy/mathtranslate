# 第 12 章存疑条目（未改）

## 1. `chapters/ch12.tex:925` 张量积的底环

- 英文 p.362："where the tensor products are taken over $k=\mathbb C Q_0=\mathbb C Q_0^{\mathrm{op}}$."
- 中文：`其中张量积分别在 $\mathbb C Q_0$ 与 $\mathbb C Q_0^{\mathrm{op}}$ 上取。`
- 两种读法：① 英文说两个张量积都取在同一个 $k=\mathbb C Q_0=\mathbb C Q_0^{\mathrm{op}}$ 上，中文“分别”是误译；② 对偶路径 $p^\vee$ 的两个等式确实分别以 $\mathbb C Q_0$ 与 $\mathbb C Q_0^{\mathrm{op}}$ 为底，英文只是说明二者作为 $k$-代数相同。由于 $\mathbb C Q_0=\mathbb C Q_0^{\mathrm{op}}$ 字面成立，中文不算数学错误，未改。

## 2. 习题 12.2(iii) 的指标次序

- 英文 p.370："deform the relations to $x_{i+1}y_{i+1}-y_i x_i=\lambda_i$."
- 中文 1273 行：`$x_i y_i-y_{i+1}x_{i+1}=\lambda_i$`。
- 英文 (i) 的关系是 $x_i y_i-y_{i+1}x_{i+1}=0$，与中文 (i) 一致；(iii) 却把指标整体平移了一位。中文 (iii) 与 (i) 自洽，疑英文 (iii) 笔误，保留中文。

## 3. 定理 12.21 的公式

- 英文 p.363：`μ_{n_f}(α_{i+rn_f-1}, …, α_i) = λ_f t(α_i)`（文本层多一个 $r$）。
- 中文 496 行：`\mu_{n_f}(\alpha_{i+n_f-1},\ldots,\alpha_i)=\lambda_f t(\alpha_i)`。
- 中文与证明中的 $\sum_f\lambda_f\ell_f$（即 $r=1$）自洽；英文的 $r$ 疑为 $\ell_f^r$ 的残留。中文可读且数学上成立，未改。
