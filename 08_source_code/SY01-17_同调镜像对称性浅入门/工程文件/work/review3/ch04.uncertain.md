2. **$B'_1$ 首行的归一化（chapters/ch04.tex:442）**
   中文：通过右乘可逆矩阵，可以假定 $B_1'$ 的第一行除第一个元素外全为零。
   英文 p.82 文本层：By multiplying both on the right by an invertible matrix we can assume that B′1 starts with a zero row（即第一行全为零）。
   上下文（`chapters/ch04.tex:439-440`）为 $B_0=\begin{pmatrix}0&*\\0&B'_0\end{pmatrix}$、$B_1=\begin{pmatrix}1&*\\0&B'_1\end{pmatrix}$。我验算：取右乘矩阵 $R=[e_1\mid C]$（$C$ 的列张成 $B_1$ 首行中 $*$ 部分的核）可把 $B_1$ 首行化成 $(1,0,\dots,0)$，同时保持 $B_1e_1=w$、$B_0e_1=0$ —— 即中文的"除第一个元素外全为零"在数学上是正确的归一化，英文文本层读不通。故照中文保留，未改。
