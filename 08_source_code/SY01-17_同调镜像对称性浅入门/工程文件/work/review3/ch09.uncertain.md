# ch09 存疑与未改项

1. `chapters/ch09.tex:541`「例如模型论\bookcite{239}」——英文 p.269 作 "such as model theory [239]"，而 [239] 是 Hovey 的 *Model categories*，此处指模型范畴，与数理逻辑的模型论不是一回事。查 chapters/*.tex 全书无「模型范畴」用例，为免另造新词，本轮未改；建议主校考虑统一为「模型范畴理论」。

2. `chapters/ch09.tex:224`、`226` 轨形点用「次数 $d_i$」对应英文的 order $d_i$（阶）。本章「次数」同时承担 $\mathbb Z_2$ 次数、分次（如 L53、L73、L119、L1424），两义并存略易混。若要统一为「阶」，只需改 L224 两处（「赋予次数 $d_i\ge2$」「含有次数为 $d_i$ 的轨形点」）；L226 的 `\underbrace{...}_{d_i\text{ 次}}` 读作「重复 $d_i$ 次」是通顺的，不必连带改。

3. `chapters/ch09.tex:1026`「若 $\alpha\in Q_1$ 是一条从 $b=t(\alpha)$ 到 $a=h(\alpha)$ 的角」——本章「角」指两条弧所夹的角（箭即画成这种小角），量词用「条」略勉强；英文 p.283 此处即 "an angle"。属语感小疵，未改。

4. 英文底本笔误，中文已正确，未按其改动（供主校知悉，不必回改）：
   - p.282「a cover of degree 2」：$Z_3$ 作用、三个下标、基本区域六个三角形都表明是三重覆盖，中文 L1056「三重覆盖」正确。
   - p.283 引理 9.24 的命名 $p^*=1_c$、$p=\lambda_1^{ac}\alpha_{ac}-\lambda_2^{cb}\alpha_{cb}$ 与证明中「把 $1_c$ 记为 $p$」相反（原书 p.264 亦如此），译文保留原书证明的写法，L429 的 Tutor Note 已作说明。
   - p.293 生成子范畴的公式漏下标（印作「$\langle M_a\rangle$」与「$a\in Q_0$」），中文 L1398–1405 已写全 $\langle M_a\mid a\in Q_1\rangle$、$\langle L_a\mid a\in Q_1^{\vee}\rangle$。
