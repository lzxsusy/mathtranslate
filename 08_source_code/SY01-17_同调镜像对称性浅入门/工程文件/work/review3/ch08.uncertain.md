## 1. L411：`$D\mathrm{mod}^{\bullet}\mathbb C Q_3^+$` 中的箭图记号

- 中文：会得到一个与 $D\mathrm{mod}^{\bullet}\mathbb C Q_3^+$ 等价的有向 Fukaya 范畴。
- EN p.220（文件行 420–421）：`a directed Fukaya category that is equivalent to D mod• +3.`（“C Q_3”在文本层被压成了“+3”，属坏字形）。
- 两种理解：(a) 原书此处用的就是该箭图的专用记号 $Q_3^+$，应原样保留；(b) 记号被写坏，本应是与例 6.74 相同的二顶点双箭图 $Q=(\bullet\rightrightarrows\bullet\right)$，即 $D\mathrm{mod}^{\bullet}\mathbb C Q$。
- 依据不足：全仓库只有 ch09:1308 的表格里出现过无关的 $Q_3$；ch06:1401 把该箭图记作 $Q$。故不改。

## 2. L227（例 8.5）：格 $M$ 还是 $N$

- 中文：令 $N=\mathbb Z^2$，取 $v_1=(1,0),v_2=(0,1),v_3=(-1,-1)$。
- EN p.220（文件行 236）：`Let M = Z2, set v1 = (1, 0), v2 = (0, 1) and v3 = (−1, −1)`。
- 判断：扇的射线属 $N$，本章约定一致（L415 亦作“$N$ 中的 $\pm 1$”），英文疑为 $M/N$ 笔误，中文正确，不改。

## 3. L757：$Y^2_\square$ 与 $Y^2_\boxtimes$ 的原书不一致

- 中文原句：……把拉格朗日截面 $L_d\in Y^2_v$ 提升为 $Y^3_\square$ 中的拉格朗日球面。
- EN p.233（文件行 928–929）：`lift the Lagrangian section Ld ∈Y2` / `v to a Lagrangian sphere`——“下标 v”是坏字形，$Y^2_v$ 无定义。
- 本轮按同页图（文件行 955–961 的标注为 `Ld / Y2□`）与 §8.4 的二维模型 $Y^2_\square$（L553、L628/631）改为 $Y^2_\square$。
- 但原书 §8.4 自身不统一：L719（EN 行 846）把同一对象写作 $Y^2_\boxtimes$。若主校认为此处应随 $\boxtimes$，请把 L719 与 L757 一并统一。
