## 存疑未改

- **L557**（medium / high）：同一句中字母 $A$ 同时充当两个不同对象：$D\mathrm{Mod}^{\bullet}A$ 的 $A$ 是 L534 定义的轨形代数 $A=\mathbb C[X,Y]/(XY)\star\mathbb Z_k$，而 $\mathrm{Gtl}^{\bullet}$ 的自变量按 §10.1–10.3 的约定必须是弧系；本段开头又写“即得到弧系 $A$”。读者无法判断 $\mathrm{Gtl}^{\bullet}A$ 的 $A$ 是代数还是弧系。 建议：给弧系换一个字母（如 $\mathcal A$），把 $\mathrm{Gtl}^{\bullet}$ 的自变量统一改为该弧系名；或把轨形代数改记作 $R$。
- **L461**（medium / medium）：右端不正合：$R=\mathbb C[X,Y]/(XY)$ 时 $f\mapsto Xf\bmod (Y)$ 的像为 $X\cdot\mathbb C[X]$（不含常数 1），远小于 $R/(Y)=\mathbb C[X]$，故末箭头不是满射（中段核像是 $ (Y)$，没问题）。若沿用“$X\cdot R\cong R/(Y)$”的默认认同也应说明，否则按字面读该列不精确；第二条列同理。 建议：把末箭头改为商映射 $R\twoheadrightarrow R/(Y)$（即模掉 $Y$），或把目标写成 $X\cdot R\cong R/(Y)$ 并在正文点明这一认同。
