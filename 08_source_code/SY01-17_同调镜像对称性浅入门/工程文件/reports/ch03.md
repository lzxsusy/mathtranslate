## 原书疑似笔误

1. **p.56 例 3.43**：印作短正合列的元素属于 $\operatorname{Ext}_A^1(N,M/N)=D\mathrm{MOD}^1_A(N,M/N)$。$0\to N\to M\to M/N\to0$ 的扩张类应在 $\operatorname{Ext}_A^1(M/N,N)$（$\operatorname{Ext}^1$ 的第一个变量是商模）。译文（原 L1068）已按后者排版。
2. **p.56–57 引理 3.45（更高的乘积与锥）**：左端 $\mu(f_1,\ldots,f_{k-1})$ 有 $k-1$ 个因子，右端末尾却作 $f_k$；而按因子个数，右端把 $f_{i-1},f_i,f_{i+1}$ 换成 $\widetilde f_{i-1},\widetilde f_{i+1}$ 两个因子后只剩 $k-2$ 个。译文把 $f_k$ 改成 $f_{k-1}$（原 L1097），计数差仍在，已加批注说明正确用法（L1107）。
3. **p.51 "Add $\mathcal C^\bullet$" 的 Hom 公式**：第二个直和印作 $\bigoplus_iB_i[\ell_i]$、移位印作 $[\ell_i-k_j]$；按定义应为 $\bigoplus_jB_j[\ell_j]$、$[\ell_j-k_i]$。译文（原 L728–731）已是正确指标。
4. **p.57 引理 3.46 证明**：扭曲对象写成 $\operatorname{Cone}\bigl((A_1[i_1]\oplus\cdots\oplus A_k[i_{k-1}],\delta|_{1\cdots k-1\times1\cdots k-1})\to(A_k,0)\bigr)$，第一个直和的末项应为 $A_{k-1}[i_{k-1}]$。译文（原 L1122）已作 $A_{k-1}[i_{k-1}]$。
