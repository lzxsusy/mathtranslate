## 原书疑似笔误

（沿用首轮核对记录；本轮无英文原文，未新增判定。）

1. **原书 p.253（定义 9.6）**：正文作 $\beta_1,\ldots,\beta_l$，两条乘积公式却作 $\beta_1,\ldots,\beta_k$；按上下文两处应同为 $\beta_l$。译文保留原样，已加批注（L61）。
2. **原书 p.264（引理 9.24 及证明）**：引理作 $p^*:=1_c$、$p:=\lambda_1^{ac}\alpha_{ac}-\lambda_2^{cb}\alpha_{cb}$；证明却把 $1_c$ 记作 $p$、把 $\lambda_1^{ac}\alpha_{ac}-\lambda_2^{cb}\alpha_{cb}$（次数 1）记作 $p^*$。按引理 9.26 的 $p\cdot p^*=\iota^*_{B_1}$，引理的命名自洽，证明中的命名互换。译文保留，已加批注（L429）。
3. **原书 p.274（例 9.40）**：$\mathrm{Gtl}^{\pm}A_2$ 的关系印作 $(\alpha_2\beta_1-1_{a_2},\ \beta_1\alpha_1-1_{a_1})$，其中第二式应为 $\beta_1\alpha_2-1_{a_1}$（$\alpha_2$ 与 $\beta_1$ 才互为逆，且只有这样才能得到 $\mathbb C[\alpha_1\beta_1]$ 的 Morita 型）。译文已作 $\beta_1\alpha_2$，已加批注（L683）。
4. **原书 p.276（定理 9.41 证明）**：验证 $\mu(\zeta_1,\xi_1,\eta_1)=1_{M_X}$ 的推导末行印作 $=-\,\mathbb{1}$，与结论矛盾（$\pi(1\,0;0\,0)+\pi(0\,0;0\,1)=\mathbb{1}$）。译文取 $1_{M_X}$，已加批注（L802）。
5. **原书 p.284（例 9.48）**：正文“The basic morphisms $\zeta_1:M_X\to M_Y$ and $\zeta_2:M_X\to M_Y$”把两个态射的方向写成相同，但紧接着给出 $\zeta_{2,\phi}:M_{Y_\phi}\to M_{X_\phi}$；由上一节 $\mu(\zeta_1,\xi_1,\eta_1)=1_x$ 的循环结构，二者中必有一个反向。译文保留原样，已加批注（L1105）。
6. **原书 p.293（9.7 节第三项）**：生成子范畴写作 $\langle L_a\mid a\in Q_0\rangle$，但 $L_a$ 由箭 $a\in Q_1$（镜像二聚体的弧）编号，应为 $Q_1$ 或 $Q^\vee_1$。译文作 $a\in Q^{\vee}_1$。
7. **原书 p.260**：扭曲复形的微分为 $\sum_{j=1}^{k-1}\alpha_u$，求和指标与项不一致；译文统一为 $u$。
