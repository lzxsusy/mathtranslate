## 存疑未改

- **L391**（low / low）：$note$ 环境在 elegantbook.cls:1185 是无计数器、无标题参数的环境（`\newenvironment{note}{\par\noindent...\textbf{\color{second}\notename} \citshape}{\par}`），因此 `\ref{note:dgla-deformation-theory}` 给出的是最近一次 `\refstepcounter` 的编号（所在定理或节），不是「注」的编号，措辞「第 X 节的注」与实际指向的对象可能不符。第 8 章同类引用写作「见注~\ref{note:unitary-local-systems}」（chapters/ch08.tex:1081），未加「第…节」。本章 L1198 有同型写法（「按照第~\ref{note:ribbon-graph-skeleton}~节的注」，id ch12-05）。 建议：与第 8 章统一：改为「与~\ref{note:dgla-deformation-theory}~处的注类似」这类不带「第…节」的写法；若保留「节」，须改引该注所在节的 label，而不是 note 的 label。
- **L1198**（low / low）：同 ch12-04：note 环境无计数器，`\ref{note:ribbon-graph-skeleton}` 取到的是最近一次被 step 的编号（很可能是本节或附近定理的编号），却被称为「节」；指向的文字又确实是「注」。同一本书内第 8 章采用「见注~\ref{...}」的写法。 建议：改为「按照~\ref{note:ribbon-graph-skeleton}~处的注」或「见注~\ref{note:ribbon-graph-skeleton}」，与第 8 章一致。

## 原书疑似笔误

（沿用首轮核对记录；本轮无英文原文，未新增判定。）

（以下均未改动译文语义，只在报告中登记；凡译文已按上下文补正者注明。）

1. p.341：$\exp(a(X)\partial_X)\cdot b(X)=b(e^{a(X)})$ 与时间 1 流不符（仅 $a(X)=cX$ 时成立）；参见批注 L113。
2. p.343：Bardzell 分解的微分 $d[a_1\cdots a_n]=a_1[a_2\cdots a_n]-(-1)^k[a_1\cdots a_{n-1}]a_n$ 中 $k$ 未定义，按分次应为 $(-1)^{n-1}$ 或 $(-1)^{n}$。译文保留 $(-1)^k$。
3. p.344：$d[\alpha_{i+rn-1}\cdots\alpha_i\to v_i]=[\alpha_{i+rn}\cdots\alpha_i\to\alpha_i]-[\alpha_{i+rn}\cdots\alpha_i\to\alpha_i]$ 右端两项完全相同（相减为零），疑漏写被消去另一项的下标；译文与原文一致。
4. p.344：$\operatorname{Hom}_{E^e}(B_{rk},E)$ 中的 $B_{rk}$ 疑为 $B_{rn}$；译文保留。
5. p.344：$\ell^i\delta\in\mathrm{HH}^0(A)$ "acts on $\mathrm{HH}^0(E)$" 疑应为 $\mathrm{HH}^{-1}(E)$；译文按原文作 $\mathrm{HH}^0(E)$ 并加批注。
6. p.350（定理 12.21）：$\mu_{n_f}(\alpha_{i+rn_f-1},\ldots,\alpha_i)=\lambda_f t(\alpha_i)$ 中 $r$ 未定义，应为 $\alpha_{i+n_f-1}$；译文已按后者处理。
7. p.361（等价链末项）：原书印作 $D\,\mathrm{Coh}^\bullet\mathbb{E}$，按全书记号应为 $D^\infty\mathrm{Coh}^\bullet\mathbb{E}$；译文作 $D^\infty$。
8. p.368：定理 12.42 的 $\mu(\alpha_2,\ldots,\alpha_k)=-\mu(\beta_2,\ldots,\beta_k)=\alpha^*$ 中第二组应为 $\beta_2,\ldots,\beta_\ell$（多边形为 $b_1\cdots b_\ell$）；译文已作 $\beta_\ell$。
9. p.362：Koszul 一节 "for each vertex $a\in Q_1$ we set $r_a=\ldots$" 应为 "for each arrow $a\in Q_1$"；译文作"箭头"。
10. p.370（练习 12.2）：$gX=e^{2\pi i/n}$、$gY=e^{2\pi i/n}$ 漏写 $X,Y$，应为 $gX=e^{2\pi i/n}X$、$gY=e^{2\pi i/n}Y$；译文已补 $X,Y$。
11. p.371（练习 12.8）：$p^*:L_1\to L_1$ 应为 $p^*:L_1\to L_0$；译文已作 $L_1\to L_0$。
