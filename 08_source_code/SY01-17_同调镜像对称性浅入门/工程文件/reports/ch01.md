## 存疑未改

- **L426**（clarity / medium）：定义句没有给出对象，也没说明是 $\operatorname{Split}(\operatorname{Add}\mathcal C)$ 还是 $\operatorname{Add}(\operatorname{Split}\mathcal C)$；读者要等到例 1.32 看见对象写成 $(A^{\oplus n},U)$，才知道是先加后分裂。两种次序虽在等价意义下一致，但定义处应把对象交代清楚，否则“分裂加法完备化”在定义后仍不可计算。 建议：先取加法完备化再取分裂闭包，记作 $\operatorname{SplitAdd}\mathcal C:=\operatorname{Split}(\operatorname{Add}\mathcal C)$，称为分裂加法完备化（两种次序给出等价的范畴）。
- **L243**（clarity / medium）：紧接着 L245 就把这个代数写成 $\mathcal C:=\bigoplus_{X,Y\in\operatorname{Ob}(\mathcal C)}\mathcal C(X,Y)$，于是同一段里 $\mathcal C$ 既是范畴又是代数；L269、L277–L279 又两次要求“令 $\mathcal C$ 表示相应的代数”。“$\mathcal C$-模”中的 $\mathcal C$ 究竟指哪一个只能靠上下文猜，而 L277–L282 讨论 $F_M$ 时两种含义交替出现。 建议：把该代数记作 $\mathcal C^{\mathrm{alg}}:=\bigoplus_{X,Y\in\operatorname{Ob}(\mathcal C)}\mathcal C(X,Y)$，并统一 L245、L269、L277–L279 的用法。
- **L468**（clarity / medium）：$\operatorname{SplitAdd}\mathcal C$ 的对象是二元组 $(X,e)$（L403），并不是模；只有再经 Yoneda 把 $X$ 换成 $\mathcal C(-,X)$、把 $(X,e)$ 换成 $\operatorname{im}$ 的像之后，才得到 $\mathrm{MOD}\text{-}\mathcal C$ 的全子范畴（L430–434 正是这样等同的）。因此紧接的范畴塔 $\mathcal C\subset\operatorname{Add}\mathcal C\subset\operatorname{SplitAdd}\mathcal C\subset\mathrm{MOD}\text{-}\mathcal C$ 只是“等价意义下”的包含，字面上并不成立。 建议：在 Yoneda 嵌入下，$\operatorname{SplitAdd}\mathcal C$ 等同于 $\mathrm{MOD}\text{-}\mathcal C$ 中由 $\mathcal C$ 中对象的有限直和的直和项组成的全子范畴。
- **L37**（clarity / medium）：$\Pi_1(X)(p,p)=\pi_1(X,p)$ 对任意拓扑空间 $X$ 与任意基点 $p$ 都成立（无非把“环路的同伦类”按基本群胚的复合读一遍），并不需要连通性；加上“若 $X$ 连通”会让读者误以为该等式依赖连通性假设。 建议：注意，按定义有

## 原书疑似笔误

（沿用首轮核对记录；本轮无英文原文，未新增判定。）

1. **p.5 Example 1.12**：印作 $C^\infty\colon\mathrm{Man}\to\mathrm{Rings}$，但该构造是反变函子，应为 $C^\infty\colon\mathrm{Man}^{\mathrm{op}}\to\mathrm{Rings}$。译文已改正并在 L133 加批注。
2. **p.8 Example 1.23**：印作 “the vector space $F_M:=1_XM$”，应为 $F_M(X):=1_XM$（$F_M$ 是函子，$1_XM$ 是它在对象 $X$ 上的值）。译文已改正并在 L282 加批注。
3. **p.9 Example 1.24**：印作 $C^\infty\colon\mathrm{Man}\to\mathrm{VECT}(\mathbb R)$，应为 $\mathrm{Man}^{\mathrm{op}}\to\mathrm{VECT}(\mathbb R)$（右模即反变函子）。译文已改正。
4. **p.13 Exercise 1.7**：幂等元公式印作 $e_\rho=\frac{1}{|G|}\sum_{g}\operatorname{Tr}\rho(g)\,g$，缺少因子 $\dim\rho$ 且应为 $\rho(g^{-1})$；正确形式为 $e_\rho=\frac{\dim\rho}{|G|}\sum_g\operatorname{Tr}\bigl(\rho(g^{-1})\bigr)g$。译文已改正并在 L556 加批注。
5. **p.9 Example 1.25**：微分记作下标 $d_n$，与同一式中的 $\Omega^n$、$H^n$ 上标体系不一致（记法不统一，非数学错误）；译文统一为上标 $d^n$。
