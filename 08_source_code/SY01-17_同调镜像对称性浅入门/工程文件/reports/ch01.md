## 存疑未改

- **原书 Example 1.25（p.9）的微分记法**：原书印作 $d_n\colon\Omega^n\to\Omega^{n+1}$、$H^n_{\mathrm{dR}}=\ker d_n/\operatorname{im}d_{n-1}$（微分用下标，上同调/形式用上标）；译文统一写作 $d^n$，与第 2 章的上标记法一致。此处保留译文，未改回原书下标；是否统一由主校裁定（若统一，建议全书取上标 $d^n$）。
- **$\mathrm{Vect}(k)$ / $\mathrm{VECT}(k)$ 混用**：原书 §1.5 首段印作 $Vect(k)$（p.8），定义 1.22 等处印作 $\mathrm{VECT}(k)$；译文按各处原样保留，未强行统一。
- 例 1.24（p.9）原文的 $C^\infty\colon\mathrm{Man}\to\mathrm{VECT}(\mathbb R)$ 与例 1.12 同类，译文已按 $\mathrm{Man}^{\mathrm{op}}$ 校正，未再单列批注（避免同类批注重复计条）。
- 练习 1.8 (i)（p.13）原书只说有限维 $A$-模可分解为 $A/(X-\lambda)^k$，译文在括号中补出 $B$-模对应的 $B/(X-\lambda)^k$（数学上必要且正确），属澄清性增译，保留未改。

## 原书疑似笔误

1. **p.5 Example 1.12**：印作 $C^\infty\colon\mathrm{Man}\to\mathrm{Rings}$，但该构造是反变函子，应为 $C^\infty\colon\mathrm{Man}^{\mathrm{op}}\to\mathrm{Rings}$。译文已改正并在 L133 加批注。
2. **p.8 Example 1.23**：印作 “the vector space $F_M:=1_XM$”，应为 $F_M(X):=1_XM$（$F_M$ 是函子，$1_XM$ 是它在对象 $X$ 上的值）。译文已改正并在 L282 加批注。
3. **p.9 Example 1.24**：印作 $C^\infty\colon\mathrm{Man}\to\mathrm{VECT}(\mathbb R)$，应为 $\mathrm{Man}^{\mathrm{op}}\to\mathrm{VECT}(\mathbb R)$（右模即反变函子）。译文已改正。
4. **p.13 Exercise 1.7**：幂等元公式印作 $e_\rho=\frac{1}{|G|}\sum_{g}\operatorname{Tr}\rho(g)\,g$，缺少因子 $\dim\rho$ 且应为 $\rho(g^{-1})$；正确形式为 $e_\rho=\frac{\dim\rho}{|G|}\sum_g\operatorname{Tr}\bigl(\rho(g^{-1})\bigr)g$。译文已改正并在 L556 加批注。
5. **p.9 Example 1.25**：微分记作下标 $d_n$，与同一式中的 $\Omega^n$、$H^n$ 上标体系不一致（记法不统一，非数学错误）；译文统一为上标 $d^n$。
