# 校订规范（《同调镜像对称性浅入门》中译本校对）

本文件是本次校订工作的唯一技术规范。所有参与校订的人员必须严格遵守；与英文原书冲突时以英文原书为准，并在报告中记录。

## 0. 工作对象

- 待校订译稿：`chapters/chNN.tex`（N = 01…12），只修改分配给你的章节文件。
- 英文原书：英文原文对照文本（工作材料，未随包提供）（按原书页分块，含 `===== BOOK PAGE n (PDF m) =====` 标记）。
- 原书页面图像（公式/图形核对用）：原书页面图像（工作材料，未随包提供）：原书第 18 页 = PDF 第 30 页。
- 插图文件：`figures/Fig_NNN_PDFxxx_Bookyyy.pdf`；`Bookyyy` 即该图在原书中的页码（yyy）。
- 术语表：`glossary.md`；索引词表：`index-terms.tsv`。

原书页码 = PDF 页码 − 12（前言 i–xii 共 12 页）。

## 1. 总原则

1. **不重写译文**。原文语义正确、只是风格不同的句子一律保留；只改真正的错误：误译、漏译、增译、术语不一致、数学符号错误、事实性错误。
2. **以数学正确性为最高优先级**。凡是公式、定义、定理陈述，逐符号对照原书页面图像核对，不能只对照 OCR 文本（公式 OCR 常丢失上下标）。
3. **不臆造**。原书省略的证明或含糊之处，不得自行补写正文，只能以批注说明。
4. **保持体例**。不得删除或改动 `\label{}`、`\index{}`、`\hyperlink{ref:...}`、`\begin{...}{名称}{标签}` 结构；不得改动定理/例子的编号顺序。
5. **只动自己的文件**。不要修改 `main.tex`、`references.tex`、其他章节、`figures/` 下的文件。需要全局改动时写进报告由主校处理。

### 2.1 保留英文的专业术语（v2.0 增补）

同调镜像对称的文献长期以英文流通，部分术语在中文里没有稳定、无歧义的通行译名，硬译反而妨碍读者对照原始文献。以下术语一律保留英文，首次出现处或“译校说明”中给出解释：

| 英文 | 处理 | 理由 |
|---|---|---|
| `wrapped` / `partially wrapped`（wrapped Fukaya 范畴、wrapped Floer 复形） | 保留英文 | 旧译“卷绕”与曲线的卷绕数（winding number）易混 |
| `thimble`（Lefschetz thimble） | 保留英文 | 旧译“消失帐篷”误；“帐篷”为 tent，实为 Picard–Lefschetz 理论中的“顶针”。注意 `Lefschetz pencil` 才译“莱夫希茨铅笔”，是另一概念 |
| `stop`（部分 wrapped Fukaya 范畴中的 stop） | 保留英文 | 旧译“停止子”易被误读为算子；stop 指截断 Reeb 流的超曲面 |
| `Fukaya`、`Floer`、`Reeb`、`Lefschetz`、`Landau–Ginzburg`、`Novikov`、`Kontsevich`、`SYZ` 等 | 不译 | 专名 |

## 3. 数学与排版细节

1. 行内公式的标点：中文句末标点放在公式之后（`……为 $x^2$。`），公式内部不加标点。
2. `\operatorname{Ob}`、`\mathrm{VECT}(k)` 等直立记号保持原样。
3. 上下标、希腊字母、`\mathcal`/`\mathbb` 字体一律按原书；原书用花体 $\mathcal{C}$ 的不要改成 $\mathbb{C}$。
4. 矩阵、交换图、长公式若原书排版复杂，按现有写法核对符号是否正确即可，不追求视觉复刻。
5. 若发现**原书笔误**（如符号矛盾、指标不对），保留译文原样并在该处插入批注：
   `% [Tutor Note: 原文此处作 XXX，疑为笔误，按上下文应为 YYY（见原书 p.N）。]`
6. 若译文有明确数学错误，直接改正，并在报告中登记。

## 4. 批注（Tutor Note）

在关键位置插入 LaTeX 注释，形如（单独一行，紧跟在相关段落之后）：

```latex
% [Tutor Note: 这里的 $\delta$ 是可逆的，故 $h$ 的存在性等价于复形分裂；初学者常把 $h$ 误当作同伦逆。]
```

要求：
- 每个章节 4–8 条，宁精勿滥；覆盖三类内容：
  1. **易错预警**：符号约定、指标升降、张量缩并、代数变换中容易出错处；
  2. **含糊点拨**：作者写“显然”“容易看出”而实际省略了论证的地方，说明省略了什么、依据哪条定理；
  3. **直觉/背景**：该构造的几何或物理意义，一两句点到为止。
- 中文书写，可用行内公式；**不要**在注释里写 `%` 字符（会截断注释）。
- 不要写空话（“很重要”“值得注意”），每条必须给出具体信息。
- 注释是源码级批注，不进入 PDF；同时把每条批注登记到报告，便于汇总成批注索引。

## 5. 本节重点（Key Takeaways）

每个 `\section{...}` 标题之后（若有导读性首段，则放在首段之后）插入一个：

```latex
\takeaway{核心图像……；关键工具……；结论……}
```

要求：
- 全文 1–3 句，或 2–4 个分句用 `；` 分隔，总长不超过约 120 字；
- 必须包含：本节的核心对象/构造、用到的数学工具、得到的关键结论（三者不必全有，但至少两项）；
- 用陈述句，不写“本节介绍……”这类空话，直接给内容；
- 数学公式用 `$...$`，避免过长的公式。

## 6. 图表

1. 每个 `figure` 环境的 `\caption{}` 若描述有误（与图形不符），直接改正；描述过简的可以补充，但不要臆造图中不存在的信息。
2. 若发现图的位置与正文所指不符（比如图应属于下一节），不要移动，在报告中登记，由主校统一处理。
3. `\caption` 末尾不要自行加“（原书 p.N）”，主校会统一添加页码标注。
