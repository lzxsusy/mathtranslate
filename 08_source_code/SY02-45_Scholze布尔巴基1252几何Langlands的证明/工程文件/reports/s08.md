## 三、疑点（页码 + 原文 + 处理）

1. **p38 原文笔误（已加译注，等级“原文笔误（第 38 页；上下文推断）”）**：例 8.1 第二个复形的微分写作
   `$m\otimes a\otimes b\mapsto ma\otimes b-m\otimes ab+ma\otimes b$`，
   末项与首项完全相同（放大核对，确为 `ma⊗b`）。对照上一式中循环项 `$ca\otimes b$`，此处应为 `$mb\otimes a$`。
   **处理：正文照录原文，加译注说明**，不擅改公式。
2. **p38** `\e[\epsilon]` 与 `\D(\e)`：`e` 是正体（`\e` 宏），不是斜体 $e$，已核对。
3. **p39** `\Bun_G^{\Frob=\id}`：指数里是 `Frob = id`，`id` 正体（`\id` 宏）。
4. **p39** 定理 8.2 的归属（Arinkin、Gaitsgory、Kazhdan、Raskin、Rozenblyum 与 Varshavsky，2021）放在可选参数里，`check_sections.py` 不会把它误判成手写编号（其中无 `\d+\.\d+`）。
5. **p39** `(M,N)\mapsto\pi_{!}(M\otimes N)`：`\pi_{!}` 是叹号推前，`\otimes` 与 `K_D` 下标位置照录。
6. **p40** `\tr(\Frob\circ H|\D(\Bun_G\times X^{I}))`：竖线紧接在 `H` 之后、`\D` 之前，照录。
7. **p40** 交叉引用“定理 1.7”（Remark 8.3）与“定理 8.2”（正文）按体例写成文字，未用 `\ref`；数值取自原文。
