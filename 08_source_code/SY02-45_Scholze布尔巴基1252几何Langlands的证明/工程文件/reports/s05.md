4. **p31 注 5.6 为一整段**：p31 顶部 "Then the Hecke action always gives rise to……" 与 "Unfortunately, while $D_{\Nilp}(\Bun_G)$……" 均齐左，故注 5.6（自 p30 "let $D_{\qc}(\ast/\Gd)_{\Ran}$" 至 p31 "……$D_{\qc}(\ast/\Gd)_{\Ran}$。"）作一段排。
