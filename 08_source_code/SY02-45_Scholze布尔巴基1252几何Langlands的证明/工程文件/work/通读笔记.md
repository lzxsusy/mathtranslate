## 0. 三句话主旨

- **问题**：把（特征 0、处处非分歧、整体）几何 Langlands 猜想表述成范畴等价，
  并说明它如何反过来给出函数域 Langlands 纲领的精确答案。
- **方法**：六函子形式化 + 谱作用（Dqc(LocSys) 作用于 D(Bun_G)）+ Beilinson 谱投影子
  + Whittaker 系数的保守性 + Kac–Moody 局部化 + Eisenstein 级数归纳 + 尖点部分的几何分析。
- **结论**：定理 2.11（特征 0，de Rham/Betti/étale 三种 setting）与定理 2.12（特征 p，
  模开闭子叠 LocSys′）；取 Frobenius 迹得定理 1.7（Gaitsgory–Raskin）。

## 2. 主线（证明链）

1. 表述：D(Bun_G) ≃ IndCoh_Nilp(LocSys_Ǧ)（猜想 2.10），归一化由 Whittaker 层给出。
2. 特征 0：de Rham/Betti/étale 三者等价（Riemann–Hilbert，Gaitsgory–Raskin 2025b）→ 只需 de Rham。
3. 对 G 的秩归纳：连续谱（Eisenstein，来自真 Levi）+ 尖点部分。
   - Whittaker 系数保守性（§9）保证「被检测到」；
   - Kac–Moody 局部化（§11）给出 Galois→automorphic；
   - LocSys 的几何（不可约局部系统构成连通族）允许插值（§12）。
4. 特征 p：Witt 向量环上提升 → 退化 → 得到 LocSys′（开闭子叠），障碍是混合特征 étale 奇异支撑理论。
5. 取 tr(Fr)：定理 2.12 ⇒ 定理 1.7。
