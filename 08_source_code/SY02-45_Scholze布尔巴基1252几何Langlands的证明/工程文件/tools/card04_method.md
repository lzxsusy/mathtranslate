## 五、方法与局限

**工作分解**：全文按 13 个节（12 节正文 + 参考文献）切分为 `工程文件/work/src/src-sNN.txt`，8 名译手分包（每人 1–3 节）→ 每节跑 `工程文件/tools/check_sections.py`（页锚覆盖、环境配对、编号条目序列、禁用命令）+ `compile_section.py` 单节编译 → 主控整篇 xelatex 两遍 → 独立校对 → `check_terms.py` 术语一致性（123/123）→ 本卡与 `05-溯源表.tsv`。第二轮（本轮）独立校对另做三件事：13 节逐段对文本层、6 页公式密集页对页面图像（p012、p020、p026、p031、p037、p046）、56 条文献逐条外部核验（arXiv API + Crossref，脚本 `工程文件/work/verify_refs.py`）。结论：0 处数学硬错，13 个 tex 未改；逐节记录见 `工程文件/reports/校对-v2.md`。

**口径说明（与任务书的差异）**：

1. **编号条目 57 条，不是 89 条**。任务书所据的 89 条是按「类型名出现次数」粗估，其中含大量**行首交叉引用**（如 `Conjecture 1.5 would be even more precise…`、`Theorem 2.2 shows…`）。本工程按「类型名 + 本节号.序号，且节号等于当前节，并做 1..max 连续性检验」重新清点，全篇唯一编号条目为 **57 条**：注 32、定理 14、定义 3、猜想 2、推论 2、假设 1、问题 1、命题 1、例 1（由 `工程文件/work/条目总表.tsv` 脚本统计）。逐节：§1 九条、§2 十三条、§3 四条、§4 零条、§5 十一条、§6 一条、§7 一条、§8 三条、§9 七条、§10 二条、§11 五条、§12 一条、§13 零条。
2. **页数**：原文 56 页（p1 为 Séminaire 版头与目录），译文 45 页 A4；页界不同，逐页用左边注 `1252--NN` 回查原文页。
3. **术语 123 条**：开工前从 12 节正文抽出 129 条，其中 6 条（affinoid、perfectoid、diamond、prism、solid、isocrystal）在本文**完全不出现**，移入 `工程文件/work/glossary-本文未用.tsv` 以免覆盖率检查假阳性；实际冻结 123 条，`check_terms.py` 覆盖率 123/123。
4. **文献 56 条**：21 条有 arXiv 号、18 条有 DOI（3 条两者兼有），20 条两者都无（书/讲义/网页，其中 4 条给了作者主页 URL），只能按出版社页核书名、年份与卷期（明细与状态见 `05-溯源表.tsv`）。

**局限**：

- 原文无插图，故「图号」一项无从核对；译文亦未加图。
- 图像复核只做了 6 页（挑公式最密、最容易丢上下标的页），其余页按文本层逐段核；文本层对连字、上下标有粘连，遇到可疑处以同页上下文与记号表回查，但未逐页 OCR 全图。
- 56 条文献中 20 条「无法核验」：多为 1980–2000 年代的书/讲义/网页（无 DOI 与 arXiv 号），或数据库只命中同题异文（Fargues 2025）；均照原文录入，不补全、不推测。
- 符号与余切/余切约定的核对只做到「与原文一致」（含 $(-^*,-_!)$ 与 $(-^!,-_*)$ 两套形式化的取向），未对每篇被引文献的原始约定再核。
- 编译只剩 1 条 Overfull（0.37 pt，视觉不可见），未为消除而改写句子；Underfull 0、Missing character 0。
