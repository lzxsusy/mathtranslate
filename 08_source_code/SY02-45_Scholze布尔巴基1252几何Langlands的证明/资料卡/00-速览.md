## 一句话

这篇报告回答的是：**几何 Langlands 猜想（函数域、特征 0 与特征 p）如今为什么算被证明了，证明由哪几块拼成，每一块各自引用谁**（p1–2）。

## 三条主线

1. **从数域到函数域**：经典 Langlands 把 $G(\mathbb A_F)$ 的自守表示与 Galois 表示相配；函数域上 $\Gamma=G(\mathbb Z)\subset G(\mathbb F_q((t)))$ 的 Hecke 特征值给出 $G$ 的 $\ell$-进局部系统，于是"自守侧 = 向量空间 $A(M/\Gamma)$"（p2–4，问题 1.2）。
2. **几何化两层**：先把 $A(M/\Gamma)$ 换成层范畴 $D(\Bun_G)$，把 $\check G$-局部系统换成 $\LocSys_{\check G}$（p6，猜想 1.5）；再把 $\LocSys_{\check G}$ 的拟凝聚层换成带幂零奇异支撑的 $\IndCoh_{\mathrm{Nilp}}$（p17–18，猜想 2.10）。
3. **证明的拼装**：GR 五部曲给出特征 0 的定理（p18，定理 2.11）与特征 $p$ 的定理（p18，定理 2.12）；本报告的核心是把"谱作用 + shtuka + Whittaker + Eisenstein + Kac–Moody 局部化"接成一条链，最后经 Færgeman–Raskin 与 Beraldo–Kazhdan–Schlank 收到尖点情形（p52–53，§12）。

## 读法（约 3 小时）

- **第 1 小时**：§1–§2。抓住"两个域 $k$ 与 $e$"（注 2.1，p11）、$D(\Bun_G)$ 是什么（p12）、定理 1.7 与猜想 1.5 的差别。
- **第 2 小时**：§3–§8。这一段是技术主干：六函子两种取法只差 Verdier 对偶（注 3.1–3.3，p20–21），$D_{\mathrm{Nilp}}$ 的三条件等价（定理 3.4，p21），Beilinson 投影子把 $D(\Bun_G)$ 打到 $D_{\mathrm{Nilp}}$（§7，p35–38），最后用 Frobenius 迹把层论送回函数（定理 8.2，p39）。
- **第 3 小时**：§9–§12。Whittaker 层（§9，p40–45）→ 粗函子与唯一提升（定理 9.3，p42）→ Eisenstein 与第二伴随（§10）→ Kac–Moody 局部化（§11）→ 尖点（§12）。若只读一段，读 §12（p52–53），它把全篇收口。

## 与 SY02-41 的关系

SY02-41（Berkeley 讲义）讲的是局部 Langlands 的几何化（Fargues–Fontaine 曲线、菱形）；本篇讲整体 Langlands 的证明，二者共用 $\check G$、$\LocSys$、六函子语言，但底域不同（本篇是函数域上的曲线 $X/k$，系数域 $e=\overline{\mathbb Q}_\ell$ 或 $\mathbb C$）。对照读时注意：SY02-41 的"菱形"在本篇不出现，本篇的"shtuka"在 SY02-41 中也不出现。
