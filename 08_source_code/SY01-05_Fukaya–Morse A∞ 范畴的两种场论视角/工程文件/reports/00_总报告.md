## 2. 体例决定（已写入 main.tex 的"译校说明"与 work/style.md）
1. **编号一律照录原文**：式号、定理号、例号、图号都手工落号，读者可拿中译与原 PDF 逐条对读；批注里的"见式 (31)""原书 p.14"因此才有意义。
2. **术语冻结**：`work/glossary.md` 为唯一裁决书。保留英文者（Fukaya、Morse–Smale、Lefschetz thimble、BV、Feynman 图、Kontsevich–Soibelman…）首次出现给括注，此后一律英文；中文用学界通行译名（复合映射、余指标、横截性、有效作用量、规范固定、慢场、超传播子、度量树模空间…）。
3. **记号统一**（Lead 裁定，跨章执行）：范畴用黑板体 $\mathbb{F}$（与原书一致）、同伦转移复形 $\mathbb{M}$、模空间 $\mathcal M$（Morse 树）与 $MT$（度量树）；外微分与 Morse 微分统一 `\mathrm{d}`（原书用斜体 $d$，属排版惯例差异，已在译校说明登记）；Morse 复形统一 `\mathrm{MC}`。
4. **批注三类**：易错预警（符号/指标/次数/约定）、含糊点拨（作者说"显然"处，点出所用定理与可查文献）、背景直觉。行内写作 `% [Tutor Note: …]`，不进入排版结果；附录 A 按节汇总，开关 `\shownotesfalse` 可整体隐藏；"本节重点"由 `\showtakeawayfalse` 隐藏。
5. **不擅改原文**：所有笔误、记号不一致一律照译 + 同处批注 + 本报告登记。
