## 二、记号约定

| 记号 | 含义 |
|---|---|
| $\alpha$ | 面算符的单值性参数，取值于 $\mathfrak t/\Lambda_{\cochar}=\TT$；$\mathbb L=G$ 时退化为 ${\mathcal Z}(G)$ 中的离散元素 |
| $\eta$ | 二维 $\theta$ 角，取值于 $\mathfrak t$ 的对偶；极大列维时取值于 ${\rm Hom}(\pi_1(G),U(1))$ |
| $\xi$ | $D$ 上 $G$-丛的拓扑类，$\xi\in H^2(D,\pi_1(G))\cong\pi_1(G)$；**不是** $\alpha$ 的另一种写法 |
| $\tau$ | 复化耦合，$\tau=\theta/2\pi+4\pi i/e^2$；$S:\tau\to-1/n_{\mathfrak g}\tau$ |
| ${}^LG$ | 朗兰兹对偶群；$S$-对偶同时换 $G\leftrightarrow{}^LG$ |
| $\M_H$ | 希格斯丛模空间（超 Kähler），面算符的靶空间 |
| $\M_\mathbb{L}(\alpha;p)$ | 带 $\mathbb L$-抛物结构的模空间，$\alpha\in\mathfrak t/\Lambda_{\cochar}$ |
| $\AffWeyl$ | 仿射外尔群 $=\Lambda_{\rm cort}\rtimes\Weyl$ |
| $B_{\rm aff}$ | 仿射辫群；$B_{\rm aff}\to\AffWeyl$ 不分裂 |
| $(B,A,A)$ | $I$ 上 $B$-模型、$J,K$ 上 $A$-模型的超对称型 |
| $\EURV$（源码宏） | §5.3 中 $\cong\mathbb{CP}^1$ 的曲面 |
| $\tilde{\mathcal Z}$（源码宏 `\eurz`） | $\AffWeyl$ 自由作用的正则序对 $(\alpha,\beta)\in\mathfrak t\times\mathfrak t$ 构成的空间 |
