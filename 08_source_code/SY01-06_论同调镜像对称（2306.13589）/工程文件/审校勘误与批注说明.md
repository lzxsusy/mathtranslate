# 审校勘误与批注说明

> 针对 A. Imparato, *About Homological Mirror Symmetry*（arXiv:2306.13589v2）中文译本。
>
> 本文档汇集译校过程中发现的**原文笔误、记号不一致与实质存疑处**，并说明
> 译本的处理方式与全部 `[Tutor Note]` 批注的分类。
>
> **总原则**：译文**不擅改原稿的数学内容**。凡疑为原文错误者，公式照抄，
> 仅在源码中以 `% [Tutor Note: ...]` 就地注明；确属排版/拼写层面且不影响数学者，
> 在正文按正确词义译出并在本表登记。这样教授可以自己判断是「作者错」还是「我们错」。

**四类批注的典型例子**：

1. **易错预警** — 例如 U09 中对 Serre 函子证明那一长串等式的提醒：三步易错处
   （$[n]$ 被吸收进 $\mathsf{R}^n$ 的上标、$\mathsf{R}\mathcal{H}om$ 与张量积的伴随关系被"心算"、
   倒数第二步要求 Hom-空间有限维）；又如 U10 指出 $e^{2\pi i\int\phi^*(\rho dx\wedge dy)}$
   中辛面积与 B-场合成为复化参数 $\rho=B+iA$ 的物理根源，以及定向约定反向后指数项符号翻转。
2. **含糊点拨** — 例如 U01 对 Freyd–Mitchell 嵌入定理的补充、U02 对 Ore 条件与
   屋顶分式演算的展开、U06 对「自然性留作练习」处所需验证内容的补出、
   U08 对 $\check{H}^n$ 并非上同调函子的警告。
3. **术语/记号辨析** — 例如 U06 指出 `flabby`／`flasque` 两名并用、U07 指出
   $\mathsf{QCoh}$ 两种记号混用、U10 指出「生成类（spanning class）」与「生成（generation）」
   名近义远。
4. **几何/物理直观** — 例如 U05 对锥与八面体公理的图解、U08 对 $B$-侧几何图像的说明、
   U11 对 $K3$ 曲面与椭圆纤维化的直观。

## 三、译本的编辑决断（需要教授知情）

1. **公式一律不改**。即使是上表标注的实质性错误（如 §5.5 的「诺特 ⟹ 分离」、
   §6.3 的伴随方向），也照原稿印，只在批注中说明。这样译本与原稿可逐式对照。
2. **两处例外**（非数学内容，属排版）：`cases` 环境中的 `$if $`/`$else$` 伪代码
   改排为 `\text{若}`/`\text{否则}`；`\text{and}`、`\text{resp.}` 等图内说明词译为中文。
3. **索引保留英文词条**（理由见 README §四）；书末增补 171 条英中术语对照表。
4. **增补内容均明确标注**：译者说明页、附录 A 术语表。正文无任何增补段落。
5. **未做的事**：未对原稿的 73 幅交换图作任何重绘（保留 `tikz-cd` 源码）；
   未改定理编号（与原稿完全一致，便于对照）。
