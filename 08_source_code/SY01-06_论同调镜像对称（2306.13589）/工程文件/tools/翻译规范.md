# 翻译工作手册（GUIDE）— 《About Homological Mirror Symmetry》中译本

> **本手册是全体译者的唯一规范。动笔前必读，动笔时逐条对照。**

---

## 0. 文档事实（必读，避免误判）

- **原件**：arXiv:2306.13589v2，Alessandro Imparato（ETH Zürich 数学系），硕士论文，
  138 页，导师 Paul Biran。原标题 *About Homological Mirror Symmetry*。
- **学科**：**纯粹数学**（math.AG：代数几何 / 同调代数 / 范畴论 / 同调镜像对称）。
  **不是** 量子场论、弦论或广义相对论论文。作者不是 Witten。
  本文讨论的是 Kontsevich 同调镜像对称猜想的 **B-侧**（导出范畴与凝聚层）。
- **因此**：术语必须按数学界（而非物理界）约定翻译。例如
  *sheaf → 层*，*derived category → 导出范畴*，*coherent → 凝聚*。
  物理术语仅在作者类比时出现（如 D-brane → D-膜），此时保留物理译名。
- **底本权威性**：我们持有作者提交的**原始 LaTeX 源码**。数学公式一律**逐字照抄**，
  因此不存在"公式识别错误"的风险——除非译者自己改动了公式。

## 1. 铁律（违反即返工）

1. **不做摘要，不做改写。** 原文每一个句子都必须在译文中找到对应。作者行文啰嗦、
   夹带大量括注与个人评论，**必须全部译出**，不得精简。
2. **数学内容零改动。** 所有 `$...$`、`\[...\]`、`equation`/`align`/`tikzcd` 环境中的
   内容**原样复制**。包括空格、`\,`、`\qquad`、上下标、希腊字母。
   - 唯一允许的例外：图式（tikzcd）**节点中的英文单词**（如 `\text{and}`、`\text{for all}`）
     应译为中文（`\text{与}`、`\text{对一切}`）；纯数学符号不得动。
   - `\qquad\text{and}\qquad` → `\qquad\text{与}\qquad`。
3. **标签与引用零改动。** `\label{...}`、`\ref{...}`、`\eqref{...}`、`\cite{...}`、
   `\index{...}` 里的**键名不得修改**（避免交叉引用断裂）。`\index` 的显示文本可译成中文，
   但命令结构必须保留；含 `!`、`@`、`|` 的索引写法保持原样。
4. **环境名零改动。** `Def`、`Lem`、`Pro`、`Cor`、`Con`、`Thm`、`Ex`、`Rem`、`proof`
   等环境名原样保留（编号由导言区统一设定，改了就错位）。
5. **禁止 AI 幻觉。** 不确定的句子按字面直译并加批注，**绝不**自行补充原文没有的物理/数学内容。
6. **不新增文献引用。** 批注中提及的文献只能写"建议查阅 xxx（作者原文引用的 [KEY]）"，
   不得凭空编造参考文献条目。

## 2. 译文风格

- 语体：严谨的**学术书面语**。避免口语（"咱们"、"搞"、"东西"），避免过度文学化。
- 学术名词首次出现：`中文（English）`，例如「导出范畴（derived category）」，
  同一小节内第二次起只用中文。**全书统一以本手册第 7 节词表为准。**
- 长句拆分：作者喜用长从句，允许拆成 2–3 个中文短句，但**因果与限定关系必须保留**。
  若拆分可能损失逻辑，保留长句并加 `% [Tutor Note: ...]` 说明。
- 破折号、括注：保留作者的插话习惯（用「——」或全角括号）。
- 数学符号中文化：`\text{and}`→`与`，`\text{or}`→`或`，`\text{where}`→`其中`，
  `\text{such that}`→`使得`，`\text{if and only if}`→`当且仅当`，`\text{for all}`→`对任意`。
  但**若该符号出现在公式的严格排版位置可能破裂**，则保留英文并加注。
- 引号：中文用「」；原文的 *italics* 强调用 `\textit{}` 保留；`\emph` 保留为 `\emph`。
- 不得使用全角标点进入数学模式；数学模式内一律 ASCII。

## 4. 批注规范（本任务的核心增值）

在以下位置插入 LaTeX 注释，**格式严格为**（单独一行，缩进与上下文一致）：

```latex
% [Tutor Note: 批注正文]
```

**四类批注，每小节至少 2 条、至多 5 条，宁精勿滥：**

1. **易错预警**——涉及指标缩并、符号约定、上下标、正负号、复形平移方向的推导：
   > `% [Tutor Note: 此处极易出现符号错误。作者采用上链复形约定 $d^{n+1}\circ d^n=0$，`
   > `平移函子记为 $[1]$ 且 $(X[1])^n=X^{n+1}$；若改用链复形约定，所有指标须整体下移一位。]`
2. **含糊点拨**——作者写 "It is obvious that…" / "one easily checks…" / "we leave it to the reader"
   而跳过证明处，指出省略了什么、依赖哪条定理、应查哪本参考书（只用原文已有的 `\cite` 键）。
   > `% [Tutor Note: 作者以"显然"跳过。此处实为需要 Freyd–Mitchell 嵌入定理把 $\mathsf{A}$`
   > `嵌入模范畴后再追图；完整证明见 \cite[Thm.~IV.7.2]{[GM03]}。]`
3. **术语/记号提醒**——同一记号在不同文献含义不同（如 $\mathsf{D(A)}$ 与 $\mathsf{D}^b(\mathsf{A})$），
   或作者记号与主流文献不一致处。
4. **物理/几何直观**（仅当作者本人给出类比时）——帮助教授快速回忆对应图像。

**禁止**：批注中写"这里翻译可能有误"这类自我指涉的话；禁止批注比正文还长。

## 5. 章节结构要求

- 凡本单元包含 `\section{...}` 者（即单元首行是该 Section 的开头），
  必须在 `\section{中文标题}` 之后、正文之前插入：

```latex
\takeaway{%
  \textbf{物理图像：}……\\
  \textbf{数学工具：}……\\
  \textbf{主要结论：}……%
}
```

  - 三条各 1–3 句，**必须是该节真实内容的提炼**，不得空话。
  - `\takeaway` 宏由主控在导言区定义，**译者直接使用，不要自己定义**。
- Section / Subsection 标题翻译要求：准确、简短、术语规范。
  例如 *The universal property of derived categories* → `导出范畴的泛性质`。
- 若单元首行是 `\subsection`，则**不需要** `\takeaway`（只有 Section 级需要）。
