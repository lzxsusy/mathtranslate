## 〇、先说明一件事：这不是一篇物理论文

委托说明中把本文预期为「Witten 的量子场论／弦论论文」，并要求按
「Gauge theory → 规范场论、Holonomy → 和乐群、Anomaly → 反常」的物理术语体系翻译。
**实际情况与此不符**，如实报告：

- 本文属**纯粹数学**（math.AG：代数几何、同调代数、范畴论），**不是** QFT/弦论/广义相对论；
- 作者不是 Witten，也没有 IAS／哈佛背景，而是 ETH 的硕士生；
- 全篇讨论的是 Kontsevich **同调镜像对称猜想的 B-侧**——导出范畴与凝聚层；
- 文中确实出现物理词汇（D-膜、B-场、A/B 模型），但那是作者**援引物理类比**，不是物理推导。

因此术语一律按**数学界**约定翻译（sheaf → 层，derived category → 导出范畴，
coherent → 凝聚，triangulated → 三角的），仅在作者本人作物理类比处保留物理译名。
若按「规范场论／和乐群／反常」那套物理术语去套，本书会译得处处不通。

## 三、翻译与审校说明

1. **底本权威性**：译文依据作者提交 arXiv 的**原始 LaTeX 源码**（并非 PDF 图像识别），
   故全部公式、符号、上下标与原稿**逐字符一致**，不存在 OCR 误识风险。
2. **公式零改动**：`$…$`、`\[…\]`、`equation`/`align`/`tikzcd` 环境体一律原样复制；
   仅翻译了两类非数学内容：`\text{and}`→`\text{与}` 之类图内说明词，
   以及原文写在 `cases` 里的 `$if $`/`$else$` 伪代码（改排为 `\text{若}`/`\text{否则}`）。
   逐单元做了「行内公式 + 显示公式」多重集比对，保留率 99.3%–100%。
3. **术语本土化**：按数学界通行译名；关键术语首次出现给出「中文（English）」；
   数学专名（Kontsevich、Fukaya、Calabi–Yau、Fourier–Mukai…）保留原文；
   作者记号（$\mathsf{D^b}(\mathsf{A})$、$\mathsf{D}^\pi(\widetilde{\mathscr{F}}(X))$ 等）一律沿用。
   书末附 **171 条英中术语对照表**。
4. **图表**：全书 2 个正式 `figure` 环境、4 张位图。四张图均由原 PDF **无损提取**
   （PDF 内以 FlateDecode 存储，与 arXiv 源文件中的 PNG **逐像素相同**，已脚本验证），
   图题译为中文并标注原稿页码。此外书中的 **73 幅交换图**本是 `tikz-cd` 矢量代码，
   译本**保留为可编辑源码**，未转为位图——这点很重要，教授可直接改图。
5. **审校批注**：正文源码含 **130 条** `% [Tutor Note: ...]`，分四类：
   - **易错预警**（符号约定、指标升降、复形平移方向、Koszul 符号律）；
   - **含糊点拨**（作者写 "It is obvious/clearly/strightforward" 而跳过之处，
     指出省略了什么、依赖哪条定理、该查哪本参考书）；
   - **术语/记号辨析**（同一记号在不同文献的不同含义、作者记号与主流不一致处）；
   - **物理/几何直观**（仅当作者本人给出类比时）。
   批注是 LaTeX 注释，**编译后不出现在版面中**，仅供阅读源码时参考；
   全部批注的分类说明见 `审校勘误与批注说明.md`。
6. **本节重点**：7 个 `\section` 开头均有 `\takeaway{}` 方框，提炼该节的
   物理图像（实质上是几何图像）、所用数学工具与主要结论。

## 四、与原稿的已知差异

| 项目 | 原稿 | 译本 |
|---|---|---|
| 页数 | 138 | 128（中文更紧凑） |
| 版式 | article 10pt a4paper | 同（`ctex` 接管中文） |
| 定理环境名 | Theorem/Lemma/… | 定理/引理/命题/推论/猜想/定义/例/注（**编号规则完全一致**） |
| 索引 | 英文词条 | **保留英文词条**（见下） |
| 术语表 | 无 | 增补 171 条英中对照（附录 A，已标注为译者所增） |

**关于索引的英文词条**：各单元曾出现中文词条，最终统一回英文原词条。原因是
`makeindex` 对中文只能按 Unicode 码位排序，会得到一个乱序索引；保留英文键则
索引按字母序正常排列，符合中文学术译著惯例。阅读时可用书末附录 A 的
英中对照表查中文；正文中每个术语首次出现处也都给了中文（English）对照。

**原文疑似笔误**：原稿有 60 余处拼写错误、记号不一致、乃至实质性的数学表述错误
（例如 §5.5 断言「诺特概形的任意态射都分离」、§6.3 的伴随方向写反、
§7 的若干记号错位）。**译本一律不动公式本身**，只在源码中以 `[Tutor Note]`
标注并说明；全部条目汇编为 `审校勘误与批注说明.md`，供教授核对。
