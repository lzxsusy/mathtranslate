## 6. 可选改（附替换文本与理由，按优先级）

### 6.1 `$SL(2)$` 应为正体（1 处正文 + 2 处批注）

- 位置：`tr06a.tex:154`（正文），`tr06a.tex:164`、`:165`（批注同）
- 现文：`$SL(2)$ WZW 理论 [47]；其瞬子贡献此前已被研究过 [48]。`
- 替换：`$\mathrm{SL}(2)$ WZW 理论 [47]；其瞬子贡献此前已被研究过 [48]。`
- 理由：全书群名一律正体（`\SU`、`\SO`、`\U`…），且 §5.3.2（tr-05, tr05c.tex:68）已写作 `$\mathrm{SL}(2)$`；preamble 未定义 `\SL`，故用 `\mathrm{SL}(2)`。现值渲染为斜体 S L，与全书不一致。

### 6.2 `\mathcal{S}_G` 建议改用 preamble 宏 `\cS`

- 位置：`tr06a.tex:176`、`:178`（正文）；批注 `:182/:185/:186/:188`
- 现文：`$\mathcal{S}_G(S^1\times S^3)$`、`$\mathcal{S}_G(S^4)$`
- 替换：`$\cS_G(S^1\times S^3)$`、`$\cS_G(S^4)$`
- 理由：preamble 第 110 行已定义 `\newcommand{\cS}{\mathcal{S}}`，§5 全部用 `\cS(X_4)`；渲染完全相同，仅统一源码写法（便于日后全书批量替换）。

### 6.3 批注内部自相矛盾（p.38 那条关于 `\mathcal{S}_G` 的批注）

- 位置：`tr06a.tex:182–189`
- 问题：批注先说「式 (5.25)、(5.26) 就是对 $\mathcal{S}(X_4)$ 的**配分函数**写下的 2d 等式」，紧接着又说「严格说 $\mathcal{S}_G(X_4)$ 是 4d 理论本身，它的配分函数才与 2d 配分函数相等」——前后冲突。按 §5.3.2 原文，(5.25)(5.26) 是**理论之间**的等式（`𝒮(S¹×S³) = 二维 q-形变 YM`），不是配分函数之间的等式。
- 建议替换文本（替换批注中「式 (5.25)、(5.26) 就是对 … 相等。」这一段）：

```text
%  式 (5.25)、(5.26) 是对 $\cS(X_4)$ 本身写下的 2d 等式——是理论相等，不是
%  配分函数相等；这一点容易误读。严格说 $\cS_G(X_4)$ 是 4d 理论本身，它的
%  配分函数才（相应地）与 2d 一侧匹配。
```

- 影响：仅注释，不进排版；但批注是交付物的一部分（见《译注汇总》），值得改正。

### 6.4 致谢末句「（东京大学 IPMU）」可更贴原文
