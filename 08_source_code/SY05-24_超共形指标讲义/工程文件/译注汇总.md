## c02 §1 Witten 指标 + §1.1 超对称谐振子（原文 p3–5）

1. （原文 p.5）术语：指标（index）带 $(-1)^F$ 分级、只数零能态；配分函数（partition function）数所有态。这是全篇最易混的一对概念。
2. （原文 p.5）易错：$(-1)^F$ 中 $F$ 是费米子数算符，玻色态取 +1、费米态取 −1；非零能态成对抵消的正是这一符号。
3. （原文 p.5）动机：$Q$ 与 $\bar Q$ 把玻色态与费米态互相映射，(1.14) 说明 $E\neq0$ 时 $\bar Q|\psi\rangle$ 必是能量相同的伙伴态。
4. （原文 p.5）易错：$\Z_2$ 只保留 $F \bmod 2$，因此 $(-1)^F$ 良定义；整数费米子数本身在超对称代数中并不守恒。
5. （原文 p.5）易错：(1.8) 是普通配分函数、没有 $(-1)^F$；(1.15) 才是指标。自由谐振子两者都可算，但只有后者受保护。
6. （原文 p.5）术语：逸度 $x = \ee^{-\beta}$，其中 $\beta$ 是 Euclidean 时间圆周长（逆温度）；$x^H$ 即 $\ee^{-\beta H}$。
7. （原文 p.5）动机：单字母指标 $i(x) = i_B(x) - i_F(x)$ 带相对负号，正是分级的体现；PE 把它组装成多粒子指标。
8. （原文 p.5）动机：$\widetilde{PE}$ 与 $PE$ 每项差 $(-1)^n$，恰好生成费米子的 $(1+x)$ 展开，从而 (1.10) 成立。
9. （原文 p.5）文献：Witten 1982 [10] 提出 Witten 指标；脚注 [11] 讨论形变可能导致非归一化真空，需另行排除。
10. （原文 p.5）易错：(1.12) 中 $\mathbf{f}$ 为原文引入的费米子逸度占位符，但 (1.9)–(1.10) 的 $z_F$ 只依赖 $x$，后文亦未再用；此处照原文保留。
11. （原文 p.5）术语：superpotential 译「超势」；$W'$ 给出势能、$W''$ 给出费米子质量项，(1.13) 是 $\sN=1$ 量子力学的标准形式。
12. （原文 p.5）动机：自由理论中能量可加，故多粒子谱是单粒子谱的组合；齐次指数正是这个组合运算的生成函数。
13. （原文 p.5）语病：原文 p.4 「compute the partition function it so easily」中的 it 疑为衍字，应为「compute the partition function so easily」；照译并登记 ERRATA。
14. （原文 p.5）语病：原文 p.5 「It is seems like」系动词重复，应为「It seems like」；已登记 ERRATA。

## c04 §2 超共形指标 + §2.1 手征多重态（原文 p8–12）

1. （原文 p.12）术语：本节的「指标」$\sI$ 即四维 SCFT 的 Witten 指标在径向量子化下的版本；与 §1 的配分函数 $Z(x)$ 不同，它能对超共形代数做精细计数。

6. （原文 p.12）动机：$Q$ 的对易子 $\SU(2,1|\sN-1)$ 的秩决定可开启的逸度个数；$\sN=1$ 时秩 2，故 $\sI$ 依赖 $p,q$。
7. （原文 p.12）易错：(2.4) 第二个等号只在 $\delta=0$ 的态上成立，它把较难确定的共形维数 $\Delta$ 换成 $r$ 荷。
8. （原文 p.12）术语：$\Gamma(z;p,q)$ 是椭圆 gamma 函数，不要与普通 gamma 函数 $\Gamma(z)$ 混淆；后者是 $p,q\to0$ 的极限。
9. （原文 p.12）动机：表 1 的分母 $(1-p)(1-q)$ 来自两个 $\delta=0$ 的时空导数 $\partial_{+\dot+}$、$\partial_{+\dot-}$ 的塔。
10. （原文 p.12）易错：表 1 第三组第 2、3 行的 $\delta$ 与 $\sI$ 列疑有笔误：按 $\delta=\Delta-2j_1+\frac32 r$，$\partial_{-\dot+}$ 的 $\delta$ 应为 $2$、$\partial_{+\dot-}$ 的 $\delta$ 应为 $0$（$q$ 应随 $\delta=0$ 行）；译文照录，已登记 ERRATA。

13. （原文 p.12）术语：Romelsberger 处方＝用自由理论的字母、但按相互作用理论的 R 荷赋权；文献 [13,14] 提出，[18] 用 $S^3\times S^1$ 上的超对称流解释。
