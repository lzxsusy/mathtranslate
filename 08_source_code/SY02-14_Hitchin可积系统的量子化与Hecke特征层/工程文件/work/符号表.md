# 符号表（冻结版 v1）

| 原书 | LaTeX | 读法/备注 |
|---|---|---|
| ℂ | `\mathbb{C}` | 复数域 |
| ℤ | `\mathbb{Z}` | 整数环 |
| 𝕃？ | 见下 | 底本中偶见 `𝕃`（应为 ℂ 的子集/格），按上下文处理并在报告登记 |
| 𝔤 | `\mathfrak{g}` | 李代数 |
| 𝔩 | `\mathfrak{l}` | 通常 = Der O |
| 𝔷 | `\mathfrak{z}` | 交换环 / 中心 |
| 𝔪 | `\mathfrak{m}` | 极大理想 |
| 𝔫, 𝔟, 𝔥 | `\mathfrak{n}`, `\mathfrak{b}`, `\mathfrak{h}` | 幂零、Borel、嘉当 |
| 𝔉 | `\mathfrak{F}` | 丛 / oper |
| 𝒪 | `\mathcal{O}` | 结构层 |

| Spec, Aut, Der, Sym, Hom, End, Ext, Tor, det, gr | `\operatorname{...}` | |

| 𝔷^cl | `\mathfrak{z}^{cl}` | 经典 Hitchin 代数 |

书写规则：

- 上下标用 `_{}` / `^{}`；多重上下标写成 `\omega_{\operatorname{Bun}_G}^{-1/2}`。
- 分数用 `1/2` 形式（原文即如此），不要改成 `\frac`。
- 箭头：`\to`（→）、`\hookrightarrow`（↪）、`\twoheadrightarrow`（↠）、`\mapsto`（↦）、
  `\longrightarrow`（⟶，长箭头用于映射）。
- 花体用 `\mathcal{}`；德文哥特体（fraktur）用 `\mathfrak{}`。
