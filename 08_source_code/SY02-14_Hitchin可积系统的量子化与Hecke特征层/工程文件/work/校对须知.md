# 第二轮校订须知（校对员必读）

本文件给「校订员」子智能体看。你的活是对照原文逐句复核已经译好的章，**动手改掉确凿的错误**，
并且写一份校订日志。你不是译者，不重译、不改文风、不重新排版。

## 一、你负责什么

- 输入：`源码/chapters/chNN.tex`（由 `源码/units/chNN_u*.tex` 装配而成）＋原书页面图像
  `工程文件/work/pages/pNNN.png`（PNG，170 dpi，可直接打开读）＋原书文本层
  `工程文件/work/en/pNNN.txt`（只用来查词定位，**公式不可信**）＋译者简报 `工程文件/reports/chNN_u*.md`。
- 输出：① 直接修改 `源码/chapters/chNN.tex` 里确凿的错误；② 写 `工程文件/校对/chNN_校对.md`。
- **只碰这两个文件**（章文件 + 你自己的校对日志）。不要改 `源码/units/`（那是译者原件，
  留作追溯），也不要动 `main.tex`、其他章、其他日志。

## 二、怎么对

按「页」为单位对齐：章文件里每处 `\SourcePage{N}` 标出原书第 N 页的开头，顺着读到下一个
`\SourcePage` 就是该页的全部内容。逐句读原文页面图像，再读译文，判断下面两类问题。

### P1（必须改）

1. 译反、译丢否定或限定词（「不」「仅」「唯一」「至多」）；
2. 蕴含关系与并列关系混译（if/only if/iff；and/or）；
3. 公式符号、上下标、指标、系数错（以页面图像为准）；
4. 整句漏译或整句增译（原文没有的内容）；
5. 交叉引用编号错（原文写「见 3.1.13」，译文写成别的号）；
6. 定理/命题/定义/引理的编号或陈述条件错（例如把「连通」丢了）。

### P2（必须改）

1. 同一术语在章内出现两种译法（以 `工程文件/work/术语表.md` 为准）；
2. 同构 ≅ 与等价 ≃、等号 = 混用；⊂ 与 ⊆ 混用；
3. 编号不一致：`\bdp{2.6.7}` 与原书段落号不符、`\tag{}` 与原书公式号不符；
4. 中文与拉丁字母之间缺空格、标点用了半角。

### 不许动

- 文风、断句长短、译注（`% [Tutor Note: ...]`）的语气；
- **译者对原书笔误的处理**：原书印错而译者照录并加批注的，一律保留（这是纪律，不是错误）；
- 数学上「更正确」的改写：原文怎么写就怎么译，除非属于上面 P1 的硬错。

## 三、日志格式

写 `工程文件/校对/chNN_校对.md`，五段：

```markdown
# 第 N 章 校订日志

## 1. 已核对范围
逐页列：p.6–p.14 已核对（逐句对照页面图像）。

## 2. 问题清单
| 位置 | 原文 | 原译 | 改为 | 理由 |
|---|---|---|---|---|
| ch01.tex:42 | ... | ... | ... | P1 丢否定词 |

（没有改动的页也要登记「已核对，无改动」。）

## 3. 未改动但存疑
（拿不准的、需要主译裁决的，逐条写，注明页码与理由。）

## 4. 术语与记号一致性
（章内发现的多译、混用，以及你统一后的结果。）

## 5. 自检
- 编译：`xelatex` 退出码 0，errors 0，Overfull __，缺字 __
- `$` 奇偶：__；`\begin/\end`：__；`\label` 唯一：__
- 改动行数：__；改动是否都在本文件内：是
```

## 四、收尾

1. 改完在 `源码/` 目录编译两次：

   ```bash
   export PATH="/c/Users/admin/AppData/Local/Programs/MiKTeX/miktex/bin/x64:$PATH"
   xelatex -interaction=nonstopmode main.tex
   ```

   要求 `errors=0`；若你只改了本章而全书还在增量装配，允许其它章暂缺，但**你这一章不得引入新错误**。
2. 报告里写清「改动条数」「P1 条数」「P2 条数」，以及你有没有发现需要主译统一裁定的问题。
