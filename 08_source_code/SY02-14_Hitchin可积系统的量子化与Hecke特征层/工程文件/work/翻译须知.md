## 三、LaTeX 体例（必须严格遵守）

工程预定义宏（已在 main.tex 里）：

- `\SourcePage{页码}`：每个原书页的正文开头插一次。**每页都要插，页码照抄原书**。
- `\bdp{2.6.7}`：原书编号段落（形如 `2.6.7.` 的粗体段首）。**编号原样照抄**，不要自己改。
- `\bdsec{2.2. Hitchin 构造 I}`：原书节标题（形如 `2.2.` 的小节标题），编号写在标题里。
- 章标题由主译在 `chapters/chNN.tex` 里给，你不要写 `\chapter`。

其它要求：

- 不编号的显示公式用 `\[ ... \]`；带原书编号的用
  `\begin{equation}\tag{26} ... \end{equation}`（amsmath 自动加圆括号，`\tag` 里只写数字）。
- **数学符号一律用 LaTeX 命令**，不要贴 Unicode 符号：
  `\mathbb{C}`、`\mathfrak{g}`、`\mathcal{O}`、`\mathcal{D}`、`\operatorname{Bun}`、
  `\operatorname{Spec}`、`\operatorname{Aut}`、`\operatorname{Conn}`、`\operatorname{Der}`、
  `\operatorname{Sym}`、`\operatorname{gr}`、`\operatorname{Hom}`、`\operatorname{End}`、
  `\otimes`、`\oplus`、`\cong`、`\simeq`、`\subset`、`\hookrightarrow`、`\twoheadrightarrow`、
  `\mapsto`、`\nabla`、`\partial`、`\omega`、`\theta`、`\Gamma`、`\Sigma`。
- 交叉引用**写死原书编号**，用汉字/数字，不写 `\ref`、`\eqref`：
  「见 3.1.3」「式（26）」「定理 8.1.6」「命题 2.6.2(ii)」。
- 原书笔误（例如引用印成 `???`、明显的上下标错位）**不许擅自改**：
  译文按原样保留，该处加一行注释
  `% [Tutor Note: 原书 p.N ……，底本如此，保留原样。]`
- 脚注用 `\footnote{...}`，脚注编号不必与原书一致。
- 数学环境名（Proposition / Theorem / Lemma / Corollary / Definition / Remark）统一写成
  `\emph{命题.}`、`\emph{定理.}`、`\emph{引理.}`、`\emph{推论.}`、`\emph{定义.}`、`\emph{注.}`
  （原书是斜体小标题，不是定理环境）。
- 列表用 `\begin{enumerate}[label=(\roman*),leftmargin=2.2em]` 之类，标签与原书一致
  （(i)(ii) 用 `\roman*`，(a)(b) 用 `\alph*`，(1)(2) 用手写 `\item[(1)]`）。

## 四、中文文风（纪律 §5）

- 一句不超过 60–70 汉字；长句拆开。
- 中英文之间留一个半角空格（如「Hodge 结构」「oper 的模空间」）。
- 中文标点用全角；行内公式后的句末标点放在公式之后。
- 禁用句式：「被……所……」「进行……的讨论」「对于……而言」「关于……的讨论」「使得……得以」。
- 不要增译、不要解释、不要加原文没有的话。译注只能出现在 `% [Tutor Note: ...]` 注释里。
- 术语按冻结表；表里没有的新术语，在报告里登记「建议译法」，正文里先用你的选择，**不要中英混用两种译法**。

## 五、逐符号核对的做法

对每个显示公式、每个定义/命题的陈述：

1. 先看 `work/en/pNNN.txt` 的这一行，知道大概是什么；
2. 再 `read_image` 看 `work/pages/pNNN.png`，逐字符核对该公式；
3. 上下标、求和指标、负号、撇号、帽子、波浪号都要对；
4. 拿不准就 `zoom.py` 放大局部再核。

**没核对过图像就写出来的公式，视为不合格。**
