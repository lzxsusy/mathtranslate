## 1. 第 0 章（p3–5）

- 0.1：$X$ 为 $\mathbb{C}$ 上亏格 $g>1$ 的连通光滑射影曲线，$G$ 半单，$\operatorname{Bun}_G$ 为 $G$-丛模栈；
  Hitchin [Hit87] 在余切栈上定义泊松交换函数代数 $\mathfrak{z}^{cl}$。
- 0.2：(a) 存在扭微分算子的交换环 $\mathfrak{z}$，象征为 $\mathfrak{z}^{cl}$；(b) $\mathfrak{z}$ 的谱 $\cong$ $^{L}\mathfrak{g}$-oper 模空间；
  (c) 商出极大理想得扭 $\mathcal{D}$-模 $N_\mathfrak{F}$；(d) 造通常 $\mathcal{D}$-模 $M_\mathfrak{F}$；
  (e) 主定理：$M_\mathfrak{F}$ 是 Hecke 特征层（交叉引用在底本印作 `???`）。
- 0.3：oper 的来历（[DS85]）、$\mathrm{GL}_n$ 的完全旗解释、$\mathrm{PSL}_2$-oper = 射影联络、oper 结构至多一个。
- 0.4：局部对应（Feigin–Frenkel [FF92]、Bruhat–Tits 仿射 Grassmann 流形、临界扭消灭定理）。
- 0.5–0.8：只给证明概要；Witten 独立发现；弱版本见 [BD96]；致谢。

## 2. 第 1 章（p6–14）

- 1.1.1：光滑等维代数栈 $\mathcal{Y}$，余切栈 $T^*\mathcal{Y}$；恒有 $\dim T^*\mathcal{Y}\ge 2\dim\mathcal{Y}$ (1)；
  等号成立称「良」(2)，$>$ 成立称「极良」(4)，等价于对 $\dim G_y=n$ 的层做余维估计 (3)。
- 1.1.2：光滑拓扑 $\mathcal{Y}_{sm}$、相对切层 $\Theta_{S/\mathcal{Y}}$、正合列 $\Theta_{S/\mathcal{Y}}\to\Theta_S\to\pi_S^*\Theta_\mathcal{Y}\to 0$；
  象征代数 $P_\mathcal{Y}$ 与 $\Gamma(\mathcal{Y},P_\mathcal{Y})\cong\Gamma(T^*\mathcal{Y},\mathcal{O})$ (5)。
- 1.1.3–1.1.5：微分算子层 $\mathcal{D}_S$、正规化子 $\tilde{\mathcal{D}}_S$、商出理想得 $\mathcal{D}_\mathcal{Y}$；
  **$\mathcal{D}_\mathcal{Y}$（层，花体）与 $D_\mathcal{Y}$（代数，斜体）在底本中并存**，译文逐处照录。
- 1.2：整体量子化的条件（1.2.3、1.2.5），第 2 章的定理 2.5.5 以它为前提。
- 1.3：与第 2 章的接口。

## 3. 第 2 章（p15–60）——全书重心

- 2.1：$\operatorname{Bun}_G$ 是维数 $(g-1)\dim G$ 的光滑栈；切空间 $H^1(X,\mathfrak{g}_\mathcal{F})$、余切 $H^0(X,\mathfrak{g}_\mathcal{F}\otimes\omega_X)$；
  典范丛 $\omega=\det R\Gamma(X,\mathfrak{g}_\mathcal{F})^\vee$。
- 2.2「Hitchin 构造 I」：$\mathcal{C}=\mathcal{C}_\mathfrak{g}=\operatorname{Spec}(\operatorname{Sym}\mathfrak{g})^G$、$\mathcal{C}_{\omega_X}$、
  $\operatorname{Hitch}(X)=\Gamma(X,\mathcal{C}_{\omega_X})$；Hitchin 纤维化 $p:T^*\operatorname{Bun}_G\to\operatorname{Hitch}(X)$；
  定理 2.2.4（[Hit87]、[Fal93]、[Gi97]）。
- 2.3「Hitchin 构造 II」、2.4、2.5「量子化 I」：定理 2.5.5 断言数据满足扭整体量子化条件，于是得 $\mathfrak{z}^{(x)}(X)$。
- 2.6：$\mathcal{D}_X$-概形的一般性讨论（定义 2.6.1，命题 2.6.2 的 $H_\nabla$）。
- 2.7「量子化 II」：$\mathcal{O}:=\mathbb{C}[[t]]$、$K:=\mathbb{C}((t))$；$\operatorname{Hitch}=\mathcal{J}\mathcal{C}_{\omega_X}$、$\mathfrak{z}^{cl}(X)=H_\nabla(X,\mathfrak{z}^{cl})$；
  2.6.7 的遗忘函子有左伴随 $\mathcal{J}$，$(\mathcal{J}A)_X=\mathcal{J}(A_X)$ (26)。
- 2.8 水平性、2.9 $\mathfrak{z}_\mathfrak{g}(\mathcal{O})$ 的交换性、2.10 $T^*\operatorname{Bun}_G$ 的几何（附录性质）、
  2.11 局部系统之栈、2.12 Beauville–Laszlo 定理。

## 4. 第 3 章（p61–121）

- 3.1.1：$B$、$N=[B,B]$、$H=B/N$，$\mathfrak{n}\subset\mathfrak{b}\subset\mathfrak{g}$，$\mathfrak{g}$ 的典范递降滤链（$\mathfrak{g}^0=\mathfrak{b}$、$\mathfrak{g}^1=\mathfrak{n}$）。
- 3.1.2：$B$-丛 $\mathfrak{F}_B\subset\mathfrak{F}_G$、扭李代数、联络 torsor $\operatorname{Conn}$、投影 $c$。
- 3.1.3（定义）：$G$-oper $=(\mathfrak{F}_B,\nabla)$ 满足 $c(\nabla)\in\operatorname{gr}^{-1}\mathfrak{g}_\mathfrak{F}\otimes\omega_X$ 且各单负根分量处处非零。
- 3.1.4/3.1.5：$\operatorname{Aut}=\mathrm{Z}$；完备正亏格时 oper 结构唯一（Harder–Narasimhan 旗）。
- 3.1.6：$\mathrm{GL}_n$-oper = 带联络的完全滤链（$\operatorname{gr}_i$ 可逆、$\nabla(E_i)\subset E_{i+1}\otimes\omega_X$ 且 $\operatorname{gr}_i\to\operatorname{gr}_{i+1}\otimes\omega_X$ 同构）。
- 3.2–3.8：$\mathfrak{g}$-oper 与 $G_{ad}$、形变、局部系统、[DS85] 的联系等。
