## 4. 原书缺陷

1. **(149) 极限箭头方向**：`μ_∞tors(Bun_G) := lim_{⟶ n} μ_n tors(Bun_G)`，右向箭头是正极限的写法；按定义应为逆极限 `lim_{⟵ n}`。这是本单元最实质的一处数学瑕疵，译文照录并加 Tutor Note。
2. **p129 下标不一致**：`⟨g_1,χe⟩ = χ(φ(g))·⟨g,e⟩`，左 g₁ 右 g，等式两侧指的不是同一元素。
3. **p130 记号漏下标**：`i:G(O)→…` 应为 `G(O_S)`（同段 (158) 用的就是 `G(O_S)`）。
4. **未定稿痕迹**：p128、p130 各留一处作者自注 `(we should check the sign!!!)`，译文照译为「（我们应当核对符号！！！）」。两处符号确实都有正负号风险（`(Res)_*` 的推前与 `(ψ(g),cl(ℰ,e))_P^{-1}` 的逆），属原书未完成的核对。
5. **p124 与 p127 对 `Res` 的两种说法**（留数 / 边界态射）不统一，见疑点 4。
6. **跨页断句**：p131 末句断在 "equipped"，此断法使中译本必须在页界处截断句子；已按原书页界处理并注明。

> 以上 1–3、5 均已在正文相应位置以 `% [Tutor Note: …]` 注明（共 4 条注释：#1、#2、#3、p131 断句）。
