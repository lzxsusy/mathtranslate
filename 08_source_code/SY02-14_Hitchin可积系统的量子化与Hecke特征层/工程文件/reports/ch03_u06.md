## 原书缺陷（疑似）

| 页 | 现象 | 判断 |
| --- | --- | --- |
| p.115 | $\exp(-ne_{1}/2t)$、$u_{1}(t)$ 中的 $n(n-2)/4t^{2}$ | 线性分数有二义：字面可读作 $(ne_{1}/2)\,t$、$(n(n-2)/4)\,t^{2}$；由 3.8.9 的共轭计算（$n=1$ 时应得 $-1/4t^{2}$）可知应为 $e_{1}/(2t)$、$n(n-2)/(4t^{2})$。照录原文写法，未改 |
| p.116–p.117 | 3.8.13 证明：「若把 $t$ 换成 $\lambda t$，该联络换成 $\frac{d}{dt}+t^{-1}q(\lambda t)$」 | 换元后 $d/dt$ 会带因子 $\lambda^{-1}$，原书未写出；因下文只用到 $\lambda\to0$ 时 $q(\lambda t)\to q(0)$，论证不受影响。照译 |
| p.117 | 3.8.14：$A_{\mathfrak{g}}(K)/I_{1}$ 的元素与其原像同用 $\tilde{u}_{jk}$ | 记号重载，易与 $A_{\mathfrak{g}}(K)$ 的元素混；原书如此，照录 |
| p.119 | (143) 中 $(\mathfrak{a}_{\mathfrak{g}})^{\le 0}$ 与 $\mathfrak{a}_{\mathfrak{g}}^{<0}$、$\mathfrak{a}_{\mathfrak{g}}^{\le 0}$ 三种写法混用 | 括号不统一；照录，未统一 |
| p.114 | 3.8.5 的 $m<i(1-n)$ | 条件是否应为 $m\le i(1-n)$ 无法由上下文判定；照录 |
| p.116 | 3.8.12 命题的 $\operatorname{Res}(\operatorname{Op}_{\mathfrak{g}}(O))\subset W\backslash\mathfrak{h}$ 中把 $\operatorname{Res}$ 的值域当作子集写 | 记号松（$\operatorname{Res}$ 的值域是 $\operatorname{Spec}\operatorname{Inv}(\mathfrak{g})=W\backslash\mathfrak{h}$，与 $\mathfrak{h}$ 同一记法）；照译 |

以上无「引用编号残缺」「拼写残缺」类硬错。唯一需要读者注意的排版二义（p.115 的线性分数）已在正文就地加注一条：

> `% [Tutor Note: 原书 p.115 把 $\exp(-ne_{1}/2t)$ 与 $n(n-2)/4t^{2}$ 印作线性分数，字面亦可读作 $(ne_{1}/2)t$、$(n(n-2)/4)t^{2}$；由本段共轭计算（$n=1$ 时应得 $-1/4t^{2}$）可知应为 $e_{1}/(2t)$、$n(n-2)/(4t^{2})$。底本如此，正文照录。]`

其余各条只是记号松紧或行文省略，不构成笔误，故不加注（全单元 `Tutor Note` 共 1 条）。
