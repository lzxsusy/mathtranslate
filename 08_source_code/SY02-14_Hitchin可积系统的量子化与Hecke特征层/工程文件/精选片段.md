# 精选片段：十处判定链

每一条都写「原文长什么样 → 译本怎么处理 → 凭什么这么定」。这是本书校订里最需要判断力的一批点，
也是资料卡（`datasets/bdh/cards/corrections/`）的主要取材来源。

---

## 1. p.163：`Aut₂ O ⋉ SOₙ(K)` 的叉积方向（记号）

**原文**：（页面图上）$\operatorname{Aut}_2 O\ltimes SO_n(K)$。
**判定**：文本层把 ⋉ 与 ⋊ 一律读成同一个宽度的符号；把该处放大到 600 dpi，可见左端的短竖线在左、长笔画向右下，
是 `\ltimes`（⋉）而非 `\rtimes`（⋊）。
**处置**：`ch04_u04.tex` 6 处 `\rtimes` → `\ltimes`，并在 `工程文件/校对/lead修复记录.md` 备案。
**为什么不能猜**：半直积的左、右之分决定哪个因子是正规子群；写反了「$SO_n(K)$ 作用在 $\operatorname{Aut}_2 O$ 上」这句话就反了。

## 2. p.293：`𝒫ic` 是花体不是正体（字体）

**原文**：$\mathcal{P}ic_{cr}$、$\mathcal{P}ic(\hat S)$（放大到 600 dpi 可见花体 P 与斜体 ic）。
**判定**：底本此处用**花体 P**，与 `\operatorname{Pic}` 的正体 P 不同；全书其余 `Pic` 也多为花体。
**处置**：主译曾批量把 17 处 `\mathcal{P}ic` 改成 `\operatorname{Pic}`，经校订员提示、放大核对后**全部回退**。
**为什么不能统一**：`\operatorname{Pic}` 与 `\mathcal{P}ic` 在数学上是同一个函子，但在**影印对照**的体例下，
字形是原文信息的一部分；读者拿译本对原书时必须能一眼对上。

## 3. p.136：`L_1 ∩ L_2` 应为 `L_+ ∩ L_−`（原文笔误，照录）

**原文**：$L_1\cap L_2$（下标是数字）。
**判定**：同段前文一直用 $L_+$、$L_-$ 记 Lagrange 三元组的两项；此处出现数字下标，是底本排印之误。
**处置**：**译文照录 $L_1\cap L_2$，加 Tutor Note 说明应为 $L_+\cap L_-$**，不擅自改正。
**纪律依据**：§3「不擅改原书笔误（保留＋批注）」；校正写在批注与勘误卡里，正文保持可对照。

## 4. p.42 与 p.70：`???` 是底本未解析的引用（照录）

**原文**：正文里直接印着「???」。
**判定**：这是 LaTeX 编译时未解析的 `\ref`，作者交稿时就没修好；不是 OCR 缺失。
**处置**：照录 `???` + `% [Tutor Note: 原书 p.42 此处交叉引用印作「???」…]`；
0.2(e) 处另在批注中指出完整陈述在 5.2.6。
**为什么不能替作者补**：补一个「看起来对」的编号等于伪造原文；读者会以为底本此处是好的。

## 5. p.238：`strata` 被译成「层」（术语，P1）

**原文**：`… strata on affine Grassmannians …`。
**判定**：「层」在本书里专指 sheaf（凝聚层、扭 D-模层），把 stratification 的「分层」译成「层」，
会让 7.11 的适用对象从「仿射 Grassmann 流形的分层」变成「其上的层」，整条论证错位。
**处置**：改为「分层」（`r-ch07a` 唯一一条 P1）。

## 6. p.208：`D(𝒢ℛ_X^{(J')})` 与 (267) 不一致（原文不自洽，照录）

**原文**：正文写 $D(\mathcal{GR}_X^{(J')})$，而公式 (267) 里是另一个上标。
**判定**：两处指同一个对象，底本自身笔误；无法判断作者想统一成哪一个。
**处置**：照录两处，加批注指出不一致。

## 7. p.91 与 p.68：`h` 与 `ħ`（原书排印不一致）

**原文**：p.68 印 $\hbar$（带横杠），p.91 起印斜体 $h$（无横杠）。
**判定**：同一形变参数，作者前后用了两种字形；不是译者输入错误。
**处置**：逐页照录（`\hbar` 与 `h` 各按页面图），不强行统一。

## 8. p.336–337：`\mathrm{Cl}` 与 `\mathcal{C}l` 两套 Clifford 记号（原书有意为之）

**原文**：同一页同时出现直立 $\mathrm{Cl}^{\cdot}_i$ 与花体 $\mathcal{C}l^{\cdot}_i$。
**判定**：放大核对后确认，前者指量子/准经典的 Clifford 代数，后者指经典分次对象，是**两套不同的记号**，不是笔误。
**处置**：逐处保留两套字形；`r-ch07b` 只把一处误写成 `\operatorname{Cl}` 的改回 `\mathrm{Cl}`。
**反例**：若当成不一致而统一，7.13 里「$E^\flat:=\overline{\mathcal{C}l}^0_1$ 是 $\mathrm{Cl}^{\cdot}$ 的李子代数」
这句话就变成同义反复，全段的数学内容消失。

## 9. p.319：`U^{\natural}_1` → `U^{\flat}_1`（符号）

**原文**：$\natural$ 与 $\flat$ 在文本层都读成同一个占位符。
**判定**：同页其他位置明确用 $\flat$（如 $E^\flat$），且 7.15 的语境是「平坦」而非「自然」。
**处置**：改为 `U^{\flat}_1`（`r-ch0810` 的 P1）。

## 10. p.233：`\tilde u_i` 连用两次（原文笔误，照录）

**原文**：同一段两次写 $\tilde u_i$，第二次显然应为另一个 letter。
**判定**：无法确定作者本意（是 $u_i$ 还是 $\tilde u_i$ 的另一支），只能照录。
**处置**：照录 + 批注 + 勘误卡（「译文未改，照原文保留」）。
