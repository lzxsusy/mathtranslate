## 2. 翻译方法

1. **分节翻译**：8 个独立译稿（每节一个 `.tex`），严格一段对一段、一句对一句；不增删论证、
   不改动作者行文逻辑、不添加原文没有的物理解释。
2. **术语统一**：先立术语表（index 指数、holonomy 和乐、anomaly 反常、signature 号差、
   bordism/cobordism 配边、spin 结构、Clifford 代数、行列式线丛……），全篇统一；专名首现
   「中文（English）」，其后只用中文；`Dirac 算子`、`de Rham 上同调` 等算子/理论名保留拉丁写法。
3. **交叉审校**：每节由**另一位译者**逐句对读原稿、逐条核查批注的事实正确性；审校意见回给
   原译者修订（共修订约 90 处：批注数学断言、文献归属、编号体例、术语统一），再复跑机器校验。
4. **批注体例**：`% [Tutor Note: 易错/含糊/笔误/术语——内容]`，每条单行、紧贴所注段落/公式；
   编译后不显示，另在**附录 A** 全文汇编，便于通读。
