## 三、编译方法

- **一键编译通过判据**：`file:line` 错误 0、Undefined 0、Missing character 0、Overfull 0。

## 四、译校体例

1. **页码对照**：正文中 `% [原文 p.N]` 标注对应原书页码；图注末尾标「（原书 p.N）」。
2. **编号**：公式用 `\tag{原编号}` 手工给号；各类陈述用专门环境并手工抄原书编号（如 `\begin{lemma}{2.30}`），不自动计数、不重排。原书陈述后紧跟「证明」者用带星号环境（`lemma*` 等），以保留原书无 □ 的版式。
3. **图**：全部自扫描页裁出，图号与图注照原书；裁图经逐幅目视复核。
4. **译校批注**：以源码注释 `% [Tutor Note: ...]` 给出（不进入正文），书末「附录 A：译校批注」按章汇集并注明原书页码。分三类：易错预警、省略论证的点拨、背景直觉。原书疑似笔误一律照原样排，只在批注中指出并给出正确形式。
5. **本节重点与章末评注**：每节「本节重点」方框与每章末「本章回顾与评注」方框均为中译本所加，非原书内容；可用 `main.tex` 中的 `\showtakeawayfalse`、`\showchapterreviewfalse` 一键隐藏。
6. **术语**：以附录 A 为准。有稳定通行中文名者用中文；无稳定译名或硬译反碍对照文献者保留原文（operad、Fukaya 范畴、Floer 同调、Gromov–Witten 不变量、Calabi–Yau 等）。人名一律不译。
7. **日文特有词的处理**：体→域、補題→引理、系→推论、注意→注、概複素構造→近复结构、概正則曲線→伪全纯曲线、運動量写像→动量映射、シンプレクティック商→辛商。
8. **§6.6 追记与正文的关系**：原书 2008 年追记指出 §5/§6 若干处定理（如补題 5.83、定理 6.215 等）的订正，译文在追记中照录，并以批注提示与正文对读。

## 七、已知偏差与限制

1. **底本为扫描件＋日文 OCR 文字层**：正文意思可信，公式文字层基本不可用；全部公式均回原书页面图像逐符号核对。个别页若图像模糊，已在批注注明。
2. **参考文献**为脚本自动转录（404 条中 359 条编号可自动识别，其余因 OCR 丢失方括号并入相邻条目），**未逐条校对**；仅作检索用，引用时请核对原书。
3. **原书索引（p.405–415）未收入**：原书索引页码无法映射到译本页码，且中译术语与原书日文索引词条不同；改以「附录 A 术语对照表」提供检索。若需索引版，可后续据 `work/glossary.tsv` 生成。
4. **A∞ 记号**：原书排作上标 $A^\infty$（L∞ 同），中译本统一按通行数学记法改用下标 $A_\infty$、$L_\infty$，并在批注中说明。
5. **个别原始笔误**：照录原书并在批注说明，未擅自改正；读者若据原书核对，会发现译文与原文此处一致。
6. **章末评注、本节重点、批注**均为中译本所加，非原书内容；可一键隐藏（见第四节第 5 条）。
7. **未做逐句回译校对**；交叉校对以「公式逐符号核对＋结构核对＋边界接缝核对」为主。译文若有疏漏，欢迎指正。
