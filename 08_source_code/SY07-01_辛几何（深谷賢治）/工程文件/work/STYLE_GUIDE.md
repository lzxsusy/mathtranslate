## 1. 工作方法（每页的固定流程）

1. 读 `work\split\pNNN.txt`，把握本页论证结构与页码（用于定位、抄录人名/文献号）。
2. **打开 `work\pages\pNNN.png` 用 read_image 逐页看**：正文意思、公式的每个符号、上下标、花体、括号层级、图。
   - 文字层与页图冲突时，**以页图为准**。
   - OCR 常见错误：`ー`→`一`、`入`→`人`、`基`→`墓`、`；`乱入、`ミラ一`、`シンプレクティ；；ク`；公式文本层基本不可用。
   - 遇到看不清的公式：用 `work\tools\crop.py` 裁 400–600 dpi 放大核对（用法见 §6）。
3. 用中文写译文，直接写入你的 chunk 文件（UTF-8 无 BOM、LF 换行）。
4. 每译完 3–5 页，落盘一次（防止中途丢失）。
5. 全部完成后自检（§13），再向 Lead 回报（§14）。

> **绝对不要编译**。编译、页码编排、交叉引用由 Lead 统一处理。
> 不要修改 `src\preamble.tex`、`src\main.tex`、别人的 chunk、`work\` 下的任何文件。

## 2. 页面标记（每页开头必须有）

每个原书页的起始处插入一行注释：

```latex
% [原文 p.17]
```

（p.N 为原书印刷页码，即 PDF 页号 − 10。）图、长公式跨页时，移到下一段之前即可。

## 3. 章节标题

- 章标题：`\chapter{中文标题}`（**只有该章第一个 chunk 写**，见 BRIEF 的分工）。
- 节标题：`\section{中文标题}`，只由**该节起始页所属的 chunk** 写；下一页续写的 chunk 不重复写。
- 小节：`\subsection{...}`。
- 标题译文见 `work\glossary.tsv` 末尾的章节对照，或 BRIEF 的任务书。

## 4. 编号公式（最重要）

**每一个原书编号公式，必须有且只有一个 `\tag{原编号}`，编号一字不差。**

```latex
\begin{equation}
  \omega = \sum_{i=1}^n \rd p_i\wedge \rd q_i \tag{2.3}
\end{equation}
```

- 多行公式用 `align`，每行一个 `\tag{...}`；**一条编号跨多行时，`\tag` 放在编号出现的那一行（通常是最后一行）**。
- 无编号公式：`\[ ... \]` 或 `equation*`，**绝不自造编号**。
- 正文引用公式用纯文本「式 (2.3)」，**不要用** `\ref` / `\eqref`。
- 原书三条公式共用一个编号时，只写一次 `\tag`。
- 公式里的标点：公式内部不加标点；句末标点放在公式之后。

**已知**：OCR 漏掉了式 (4.16)，ch04b 的译者请在页图上找到它并补 `\tag{4.16}`。

## 5. 陈述环境（定义/定理/引理/命题/推论/例/注/问/问题/猜想/反例/记号/公式）

**编号一律手工抄原书编号**（原书在每章内统一连续编号，如「補題 2.30」「定義 2.31」）。

```latex
\begin{definition}{2.31}
  正文……
\end{definition}

\begin{lemma}{2.30}
  正文……
\end{lemma}

\begin{proof}
  证明正文……
\end{proof}
```

可用的环境名（第一个参数是原书编号）：

| 环境 | 显示 |
|---|---|
| `definition` | 定义 |
| `theorem` | 定理 |
| `lemma` | 引理（原书「補題」） |
| `proposition` | 命题 |
| `corollary` | 推论（原书「系」） |
| `example` | 例 |
| `remark` | 注（原书「注意」） |
| `question` | 问 |
| `problem` | 问题 |
| `conjecture` | 猜想（原书「予想」） |
| `counterexample` | 反例 |
| `notation` | 记号（原书「記号」） |
| `formulaenv` | 公式（原书「公式」） |

- `proof` 可选参数写标题：`\begin{proof}[证明]`（默认就是「证明」）。
- 原书「[証明]」方括号不必保留；「証明終わり」的 ■ 由环境自动加。
- **陈述末尾的 □ / ■**：原书陈述末尾有 □ 者（定义、问题、假设、无证明的定理等），模板已自动加；
  但**若该陈述后面紧跟「证明」**（原书此时陈述末尾没有 □），请用带星号的环境名：
  `theorem*`、`lemma*`、`proposition*`、`corollary*`（显示同样为「定理 1.6」等，只是不加 □）。
  例：
  ```latex
  \begin{lemma*}{2.30}
    陈述……
  \end{lemma*}
  \begin{proof}
    证明……
  \end{proof}
  ```
- 若原书某陈述**没有编号**，用 `\begin{definition}{}`（空参数）或直接写粗体标题。

## 6. 图

- 图在页图里，需要从原书页裁出来：
  ```powershell
  $py = "<本地路径>"
  & $py "C:\...\work\tools\crop.py" --page 51 --box 0.10,0.18,0.90,0.52 --dpi 400 --out "C:\...\src\figures\fig2.1.png"
  ```
  `--box` 是页面**宽/高比例**（左,上,右,下），先看页图估计；裁完**必须 read_image 复核**：完整、不截断、不带相邻正文与图注残影、不带原图号。
- 正文写法：
  ```latex
  \begin{figure}[htbp]
    \centering
    \includegraphics[width=0.6\textwidth]{figures/fig2.1.png}
    \figtitle{2.1}{原书图注的中译文（原书 p.41）}
  \end{figure}
  ```
- 图号、图注按原书；图注译文末尾加「（原书 p.N）」。
- 若图是极简单示意图、裁图成本过高，可不插图，但必须在正文用 `\figtitle{2.1}{……（原书 p.41）}` 保留图号与图注，并加一条批注说明原图略去。**优先裁图。**

## 8. 批注（Tutor Note）

在需要提醒的段落**之后**单独一行写：

```latex
% [Tutor Note: 这里的 $J$ 与前面 §1.3 的复结构 $J_0$ 不是同一个对象；作者省略了下标，初读易混。]
```

要求：

- 每 2–3 页至少 1 条，每节至少 3 条。**宁精勿滥**。
- 只写三类，且必须给具体信息：
  1. **易错预警**：符号约定、指标、次数、上下标、正负号、花体/正体；
  2. **省略论证的点拨**：作者写「显然」「容易看出」而实际略去了什么、依据哪条定理；
  3. **背景直觉**：一两句几何/物理意义（点到为止）。
- 禁止空话（「很重要」「值得注意」）。禁止在注释里出现 `%` 字符（会截断注释）、不要写跨行公式。
- 原书疑似笔误：**正文照抄原书**，批注写「原书 p.N 作 X，与……不符，疑为笔误，正确形式应为 Y」；**不许悄悄改正文**。

## 9. 「本节重点」与「章末评注」

- **本节重点**（`\takeaway{...}`）：每个 `\section` 的开头（导读段之后）一个，1–3 句、不超过约 120 字；必须给出**本节的核心对象/工具/结论**之一二，不写「本节介绍……」。由该节的译者写。
- **章末评注**（`\chapterreview{...}`）：每章末尾一个，约 700–1100 字，五段式：①全章地位 ②知识脉络 ③核心结论 ④辨析与提醒 ⑤评注（作者处理方式的局限与与相邻章节的衔接）。**只由该章最后一个 chunk 的译者写**（见 BRIEF）。

## 10. 文字层可靠度（必须知道）

| 内容 | 可信度 |
|---|---|
| 正文单词、段落边界、章节标题、人名、文献号 | 高（可用作定位与抄录） |
| **公式、上下标、分式、矩阵、希腊字母、花体** | **不可信，一律回页图逐符号抄** |
| 页眉页脚、页码 | 可用 |

由此推论：**任何「原书笔误」的指控，都先用 400+ dpi 裁图复核原文**，确认后才写批注。

## 11. 语言（中文数学文风）

目标是「数学工作者的中文」，不是「日语语法的中文」。

- 一句一个逻辑重心，主谓早出现，修饰语短。
- **禁止**：`被……所……`、`进行……的讨论/计算`、`对于……而言`、`关于……的讨论`、`使得……得以……`、一逗到底、一句超过 70 汉字（公式列举句可到 90）。
- 连续三个「的」要拆。
- 被动尽量改主动。
- 标点：中文全角（，。；：？！（）“”——）；英文术语/数字与汉字之间留**半角空格**（`辛流形 M`、`第 3 章`、`$k$-线性`）。
- **希腊字母与数学符号必须进数学模式**：正文写 `$\sigma$ 模型`，不许直接写 `σ`（否则 PDF 缺字）；
  `$C^*$ 代数`、`$\R$`、`$\omega$` 同理。
- 日文「」引号译成中文“”；「、」按语义译成顿号或逗号。
- **允许**拆长句、调语序、补主语；**禁止**增删信息、改数学内容、把作者的「显然」扩写成证明、删掉作者的评论性句子。

## 12. 术语（冻结）

- 以 `work\glossary.tsv` 为准，**不得擅自改译或自造中文名**。
- 保留英文的术语（operad、Fukaya、Floer、Gromov、Calabi–Yau 等）首次出现处可括注中文通名，此后一律原文。
- 遇到表里没有的新术语：用最通行的中文名，**在回执里登记**（日文→中文），由 Lead 统一裁决。
- 易错：

| 日文 | 不是 | 而是 |
|---|---|---|
| 体（代数学） | 体 | 域（field） |
| 束（fiber） | 层 | 丛（但 sheaf 语境才是「层」） |
| 概複素構造 | 概复结构 | 近复结构 |
| 概正則曲線 | 概全纯曲线 | 伪全纯曲线 |
| 補題 | 补题 | 引理 |
| 系 | 系 | 推论 |
| 注意 | 注意 | 注 |
| 運動量写像 | 动量映射 | 动量映射（✓） |
| マスロフ | 马思洛夫 | Maslov |
| フレアー | 弗莱尔 | Floer |

## 13. 禁止事项（违反即返工）

1. 不编译；不改 `preamble.tex` / `main.tex` / 别人的 chunk / `work\` 下文件。
2. 不写 `\documentclass`、`\usepackage`、`\begin{document}`、`\newcommand`、`\label`、`\ref`、`\cite`。
3. 不自造公式编号、定理编号、图号；不重排编号。
4. 不在正文留整段未翻译日文（人名/术语原文除外）。
5. 不用 Markdown（`**粗体**`）；强调用 `\textbf{}`。
6. 不写全角空格 U+3000；不改文件编码（UTF-8 无 BOM）；不用 CRLF 以外的奇怪字符。
7. 不把公式写成文字描述；不省略公式。
8. 不「修正」原书笔误（只写批注）。
9. 不在 `% [Tutor Note: ...]` 里写 `%`。
