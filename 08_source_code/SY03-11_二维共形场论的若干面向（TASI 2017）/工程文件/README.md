
导言区已写死 `fontset=fandol`（TeX Live 自带的中文字体，跨平台可用）；若在 Windows 上希望使用宋体/黑体，可改为 `fontset=windows`。已加载 `xcolor` 以满足 `hyperref` 的彩色链接设置。

本交付环境中的 TeX Live 可以完成 XeTeX 排版（生成 `.xdv`），但其 `xdvipdfmx` 驱动在本机被环境限制、无法生成 PDF，因此**随包 PDF 是另行排版生成的**（见上节说明）；`.tex` 已按可编译状态组织，并用静态检查脚本核对了括号/环境配对、`\label`–`\ref` 完整性、`\cite` 与文献键一致性、图片文件存在性。在正常的 TeX Live 机器上应可直接编译。

## 三、译校体例（摘要）

1. **术语**：以中文学界通行译名为准（规范场论、能标、中心荷、共形块、自举、轨形、陪集、模不变性……）；无通行译名者保留英文（如 parafermion、cigar、WZW、Virasoro）。完整术语冻结表见 `术语表.md`。
2. **公式**：逐式对照页面图像核对；编号公式用 `equation` + `\label` 自动编号，正文一律 `\eqref`，不硬编码编号。**原文疑似笔误一律照原样排，并在 `% [Tutor Note: ...]` 中说明**，不做悄悄修正。
3. **批注**只写三类：易错预警（指标、符号、因子约定）、含糊点拨（作者写"显然/可以证明"而省略的论证）、背景直觉。全部批注可在 `译注汇总.md` 中按章检索。
4. **图表**：21 张图全部从底本矢量内容按图形包围盒裁出（非截图拼贴），图注翻译并标原书页码。
5. **语言**：中文数学文风，消灭"被……所""进行……的""对于……而言"等翻译腔；英文术语与数字两侧留半角空格。

## 四、原文疑似笔误登记

编译/阅读时请留意（正文一律照原样保留，批注已注明；未做"悄悄修正"）：

| 位置 | 情况 |
|---|---|
| 式 (3.69)（原书 p.19） | 由 $c=1+6Q^2$、$h=\frac{Q^2}{4}+P^2$ 直接代入应为 $h+\tilde h-\frac{c}{12}=2P^2-\frac{1}{12}$，原文作 $2P^2$（疑为能量零点约定或笔误）。 |
| 式 (3.6)–(3.7)（p.8–9） | 反全纯后代的横杠/波浪号在原文若干处缺失或错置；照原样排并在批注中指出。 |
| 式 (4.13)（p.23） | Sugawara 张量被积项印作 $d_{ab}j^a(w)j^a(z)$，第二个流的指标应为 $b$。 |
| p.31 正文 | "D1–D4 CFT" 按上下文（同段 $Q_5$ 依赖、$\mathrm{Sym}^{Q_1Q_5+1}(K3)$）应为 D1–D5。 |
| 式 (5.27) 附近（p.41） | 左端第二个算符印作 $\phi_i^{RR}$（按指标结构应为 $\phi_j^{RR}$）；$t$ 道分子印作 $\delta_{i\ell}\delta_{ij}$（按 $s,t,u$ 置换对称应为 $\delta_{i\ell}\delta_{jk}$）。 |
| 图 16 (b) 图注（p.39） | 印作 $\Delta_\phi=\frac{55}{12}$（$c=2$）；同图 (a) 的 $7/12=(c-1)/12$，$\frac{55}{12}$ 与该关系不符，疑为 $5/12$ 之误。 |
| 记号 | 反全纯权在原文中 $\bar h$ 与 $\tilde h$ 两种写法并存（§2.3 同一节内亦混用）。译文原则上照原文；§3、§4 按原文用 $\tilde h$，§5 依原文统一为 $\tilde h$；§2 内按原文保留混用并加批注说明二者同义。 |
