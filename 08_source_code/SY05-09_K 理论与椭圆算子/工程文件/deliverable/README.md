## 3. 底本与页映射

- 底本 PDF 的第 1 页是 arXiv 封面，第 2 页是目录，正文自第 3 页起；**PDF 页 = 原书页**，无偏移。
- 译本正文中每个原书页的起点都有注释标记：`% ===== 原书 p.N =====`，便于对照。PDF 里不可见，源码里可检索。
- 原书**全部公式与定理环境都不编号**（用 `Definition.`、`Theorem (…)`、`Claim.` 等标签直接标注）。译本遵照此点：`\[…\]` 无编号展示公式，定理类环境用 `\newtheorem*`（不编号）；节号、小节号保留原书编号（第 0 节到第 4 节，附录 A、B）。
- 原书无图、无表；10 处交换图是纯文本排版的 xymatrix 风格图，译本用 `tikz-cd` 重画，位置与箭头方向逐幅对页图核过。

## 5. 编译方法

环境：Windows + MiKTeX（XeLaTeX）；字体用系统 ctex 默认（SimSun / SimHei 等）。

```powershell
# 整书编译（在工程根执行）
powershell -ExecutionPolicy Bypass -File .\build.ps1
# 产物：work\main_build\main.pdf → 自动复制到 deliverable\

# 单块编译（译校时用）
python src\tools\compile_chunk.py c00     # c00 … c08
# 产物：work\tmp_c00\wrap.pdf

# 全量自检（结构统计 + 编译统计 + 禁用句式扫描）
python check.py
```

- `build.ps1` 跑两遍 XeLaTeX，统计 pages / errors / overfull / underfull / undefined / missing character。
- `compile_chunk.py` 会按块表补上 section / subsection 计数器，使单块 PDF 的节号与合书一致（c01 显示 1.4–1.7，c02 显示第 2 节……附录 c07/c08 显示附录 A/B）。
- **注意**：`build.ps1` 含中文文件名，必须以 UTF-8 **带 BOM** 保存，否则 Windows PowerShell 5.1 会按 ANSI 解码而写坏文件名。

## 8. 已知的原文笔误

原书有若干排版与表述问题，译本一律**照译 + 【译者注】+ 登记**，不改正文。全部条目见读书笔记第 11 章，最要紧的几条：

1. **p.14**：$\mu(E)=(-1)^n\Td(E)^{-1}$ 漏因子，应为 $(-1)^n e^{c_1(E)}\Td(E)^{-1}=(-1)^n\Td(\overline E)^{-1}$（与 p.17 的公式一致；不影响指标定理的最终形式）。
2. **p.25**：$\sigma_m(x,\lambda\xi)=\lambda^m\sigma_m(x,\lambda\xi)$ 右端应为 $\sigma_m(x,\xi)$；$p_f$ 的首指数 $e^{-\langle x,\xi\rangle}$ 漏 $i$。
3. **p.21**：$(-1)^{n(n+1)}$ 缺 $/2$；$\xi(X)$ 应为 $\chi(X)$。
4. **p.18**：三处 $[\T\R^n]$ 应为 $[\T\R^k]$；中间一步 $(1)^n$ 应为 $(-1)^n$。
5. **p.31**：$a\text{-}\mathrm{ind}_{SO(2)}\lambda_2$ 应为 $\rho_2$。
6. **p.45**：「$V=\C^n$ 为平凡表示」应为标准表示。

## 9. 术语与文风

- 术语以 `work/glossary.tsv` 为唯一裁决（约 230 条，合并自本工程既有的 Zois、Hines 两份 K 理论讲义术语表，并新增本论文的 40 余条）。术语冻结后再并行翻译。
- 关键译名：K 理论 / 向量丛 / 象征（symbol）/ 椭圆复形 / 解析指标 / 拓扑指标 / 指标类 / Thom 同构 / 粘合函数 / Wiener–Hopf 算子 / 齐性空间 / 诱导表示 / 逆紧映射（proper map）；人名与标准示性类（Chern、Todd、Bott、Atiyah–Singer）保留英文。
- 文风硬指标：禁用句式（「被……所」「进行……的」「对于……而言」「众所周知」「不难发现」等）全篇 0 命中；中文全角标点；汉字与公式/拉丁字母之间由 xeCJK 自动处理间距，不手加空格。
- 原文用 $TX$ 记**余切**丛（现代记号 $T^*X$）。译本保留原文字面，并在首次出现处加【译者注】说明，全篇 $K(TX)$ 一律指余切丛的 K 群。
