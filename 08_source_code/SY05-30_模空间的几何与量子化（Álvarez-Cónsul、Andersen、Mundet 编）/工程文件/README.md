## 约定

- 所有文件 UTF-8 + LF；TSV 用制表符，不用逗号。
- `work/en/` 里的文本是**底本抽取物**，只供检索与核对，**不得**当作译文引用。
- 页标记格式 `=== PDF p.N | folio M ===`；`folio` 是印刷页，`PDF` 是 PDF 页。
- 本目录不放大文件（页图 230 张在仓外 `C:/Users/admin/Downloads/gqms_pages/`，需要时按 `编译说明.md` 重渲染）。
