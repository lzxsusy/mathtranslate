### 2.4 `\figomit` 规程（动笔前先定，写进 STYLE_GUIDE 或 main.tex 注释）

现状：`源码/main.tex` **没有** `\figomit`，也没有 figure 相关宏；`\inputif` 在第 94 行。建议：

1. 在 `main.tex` 导言区加宏（语义：占位框 + 保留编号 + 保留图注 + 保留 `\label`）：
   ```latex
   \newcommand{\figomit}[3][4cm]{% #2=图号文本（如 1.11），#3=图注
     \begin{center}\fbox{\parbox[c][#1][c]{0.86\linewidth}{\centering
       \small ［图 #2 请对照原书印刷页 \pageref{fig:#2}］}}\end{center}}
   ```

## 3. 公式与记号风险（10 处必防 + 6 处待核）

> 每处给「位置（行号/式号）→ 原文写法 → 中文建议 → 陷阱」。原文照抄自 ch01.txt（连字与丢符号保留原样，`¯` 即提取层里的上划线）。

**R1 PGL^(N)♯ vs PGL^(N)#（co-扩张 vs 中心扩张）**
- 位置：L980–L988（§1.4 首段）；式 (1.3)(1.4) 的定义见 L478–L494。
- 原文：*"The former defines a centrally extended loop group PGL#(N) = PGL(N) ⋉ℂ×, while the latter corresponds to the co-extended one PGL♯(N) = PGL(N) ⋊ℂ×; see, e.g., [15]. For our purposes we shall use the group PGL♯(N), since it admits cluster parameterisation."*
- 中文：中心扩张圈群 $\widetilde{PGL}^{\#}(N)$；**余扩张**圈群 $\widetilde{PGL}^{\sharp}(N)$（本章主角）；译文统一用 `\sharp` 与 `\#` 两个不同上标，并在首现加译者注「♯ 与 # 是两种不同扩张」。
- 陷阱：①提取层里 ♯/# 都丢了（变成私用区字符），只能靠上下文判断；②半直积方向也相反（中心扩张 ⋉、余扩张 ⋊），照抄容易抄反；③全文还有第三种记号 $\widehat{\mathcal{G}}$（圈群本身，L83）与 $\widehat{PGL}(N)$——三重 hat 叠加要在 LaTeX 里写清（`\widehat{PGL}^{\sharp}(N)`）。

**R2 r-矩阵与 Poisson–Lie 括号 (1.1)(1.2)**
- 位置：L363–L400、(1.1) L370、(1.2) L405，§1.2 开头对 r 的定义 L352–L362。
- 原文：`{g ⊗, g} = −½[r, g⊗g]`（(1.1)）；`r = Σ_{α∈Δ+} d_α e_α⊗e_{−α} + ½Σ_{i∈Π} d_i h_i⊗h_i`（(1.2)）。
- 中文：指标位置一个都不能动：$-\tfrac12[\,r,\ g\otimes g\,]$；建议写成 `\operatorname{Ad}` 之外的括号时保留 `\{g\otimes,g\}` 的整体写法，并加译注说明「左边抄写的是 $g$ 的两个拷贝的 Poisson 括号」。
- 陷阱：①负号与 ½ 常被排版成 $-\frac{1}{2}$ 后漏负号；②$d_\alpha=(\alpha,\alpha)/2$（原文随后说「为简化假设 simply laced，此时 $(\alpha,\alpha)=2$、$d_\alpha=1$」，译文若不保留这个假设句，读者会对 (1.2) 的系数产生疑问）；③$e_{-\alpha}$ 与 $e_{\bar\alpha}$ 是同一物（原文 $\bar\alpha$ 记号在 L400 一带出现）。

**R3 (1.3)/(1.4) 的 sign(i) 从未定义**
- 位置：L478–L494。

- 陷阱：①全文没有给 sign 下定义（我通读确认：只有 (1.3)(1.4) 四处引用）；②$e_{\bar i}$ / $e_{-i}$ / $\bar e_i$ 三种写法在正文交替出现（L483、L492、L3451 一带），必须统一为一种（建议 $e_{\bar i}$）并说明 $e_{\bar i}:=e_{-i}$；③$C_{ij}$ 在 (1.3) 与 (1.4) 中的对称性假设只在 simply laced 下成立，须在节首保留该假设句。

**R4 仿射指标、Λ 与 coextension**
- 位置：(1.12)(1.13) L1014–L1026；wiring 图与 Λ 的作用 L1034–L1065；附录 D 的 Λ 描述 L3683–L3685。
