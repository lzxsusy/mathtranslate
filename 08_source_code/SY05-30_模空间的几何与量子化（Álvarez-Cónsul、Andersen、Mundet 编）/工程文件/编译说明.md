# 编译说明（SY05-30）

## 依赖

- TeX 发行版：MiKTeX（Windows）或 TeX Live ≥ 2022；引擎 **xelatex**（必须，用了 fontspec + 中文字体）。
- 字体：Noto Serif SC、Noto Sans SC（正文与标题）；Consolas（等宽，Windows 自带）。
  Linux 上可换 `fonts-noto-cjk`；没有 Noto 时把 `main.tex` 里两行 `\setCJK...font` 换成本机字体即可。
- 宏包：amsmath、amssymb、amsthm、mathtools、fontspec、geometry、fancyhdr、enumitem、xcolor、tikz、tikz-cd、hyperref（TeX 发行版自带）。

## 编译

```bash
cd 源码
xelatex -interaction=nonstopmode main.tex
xelatex -interaction=nonstopmode main.tex
xelatex -interaction=nonstopmode main.tex
```

## 常见问题

1. `! Font \TU/NotoSerifSC(0)/... not loadable` — 没装 Noto Serif SC。改 `main.tex` 第 20 行附近的字体设置。
2. `! Package tikz Error: Cannot parse this coordinate` 或 `\tikz@quote@@parser has an extra }` — 交换图箭头标签里有 `|` 或多写了一个 `'`。见 STYLE_GUIDE §5。
3. 页数比预期少/多 > 2 — 先看 `main.log` 里 `No file main.toc` 或 `Rerun to get` 提示，确认三遍都跑了。
4. Windows 上 `main.pdf` 被阅读器占用导致写入失败 — 关掉 PDF 阅读器再编译。
