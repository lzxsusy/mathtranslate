# 资料卡 · 02 论证地图

本讲义不是「一条定理贯穿到底」，而是**三段接力**：先把实曲线的拓扑说清（§2.1），再用覆盖空间造出正确的群（§2.2），最后让这个群去作用在表示簇上（§2.3）。下面拆成 10 步，每步给「依据」与「缺了它会坏在哪」。行号指译本 `源码/chapters/`。

## 一、主链 D1–D10

### D1 类比的对象：代数基本群是覆盖范畴的伽罗瓦群（引言，p.9）

$\pi_1(X;x)$ 的三种等价说法：道路同伦类、万有覆盖的自同构群、覆盖范畴的伽罗瓦群。Grothendieck（SGA-1）取**第三种**作代数基本群的定义：它是适当覆盖范畴的伽罗瓦群，也是基域绝对伽罗瓦群的**增广**。于是「黎曼面的拓扑基本群」是「复代数曲线的代数基本群」的离散类比。

- **依据**：引言（`preface` 前的章首，译本 p.9）；[6] SGA-1。
- **坏在哪**：不取「覆盖范畴」这个定义，后面就无法问「定义在 $\mathbb{R}$ 上时，离散类比是哪个群」——道路定义在 $\mathbb{R}$ 上没有对应物。

### D2 实结构：把「定义在 $\mathbb{R}$ 上」翻译成反全纯对合（§2.1.1，p.10）

$X_P(\mathbb{C})=\{(u,v)\mid P(u,v)=0\}$ 带共轭 $\sigma:(u,v)\mapsto(\bar u,\bar v)$；$X_P(\mathbb{R})=\operatorname{Fix}(\sigma)$。非奇异时 $X_P(\mathbb{C})$ 是黎曼面，$\sigma$ 是反全纯对合 ⇒ **Real 黎曼面**（定义 2.1.1）。$\mathbb{C}$ 上的 Real 结构都长这样：$V_{\mathbb{R}}=\operatorname{Spm}\mathbb{R}[T]$、$V_{\mathbb{C}}=\operatorname{Spm}\mathbb{C}[T]$、$V_{\mathbb{R}}\cong V_{\mathbb{C}}/\sigma\cong\mathbb{C}^+$。

- **依据**：§2.1.1；定义 2.1.1；式 (2.1)–(2.3)；命题 2.1.2。
- **坏在哪**：若把「实曲线」理解成「实平面曲线」，就丢掉了 $X_P(\mathbb{R})=\varnothing$ 的情形（如 $x^2+y^2+1=0$），而那正是定理 2.3.4 里 $\kappa$ 不满的来源之一。

### D3 两种模型等价：Real 黎曼面 $\simeq$ 克莱因曲面（§2.1.3，p.15–17）

克莱因曲面 = 带**双解析**图册（$\varphi_i:U_i\to V_i\subset\mathbb{C}^+$，转移映射双解析）的曲面；可以非可定向、可以带边。Alling–Greenleaf：这样的图册总存在（定理 2.1.13），且存在解析 double $(\tilde\Sigma,\tau,p)$，$p\circ\tau=p$、$\tilde\Sigma/\tau\cong\Sigma$（定理 2.1.15）。两个范畴**等价**，于是「$\Sigma/\tau$ 是带边/非可定向曲面」与「$\Sigma$ 是 Real 黎曼面」是同一件事。

- **依据**：定义 2.1.9/2.1.10/2.1.12/2.1.14；定理 2.1.11（Schwarz 反射，构造 double 的局部工具）、2.1.13、2.1.15；注 2.1.16。
- **坏在哪**：double 构造是后面所有「$X/\sigma$ 上的几何」的合法性来源。没有它，$\pi^{\mathbb{R}}_1$ 与轨形基本群的等同（例 2.2.19）就是空话。

### D4 拓扑分类：$(g,k,a)$ 完全决定同胚型（§2.1.2，p.12–14）

$\Sigma^\tau$ 是有限个圆周（命题 2.1.3），个数 $k$ 满足 Harnack $k\le g+1$（定理 2.1.5）；$\chi(\Sigma/\tau)=1-g$（引理 2.1.6）；分离性 $a\in\{0,1\}$ 由 $\Sigma\setminus\Sigma^\tau$ 是否连通决定（式 (2.4)）。Weichold（定理 2.1.8）：$(g,k,a)$ 相等 $\iff$ 存在与 $\tau$ 交换的同胚 $\iff$ $\Sigma/\tau\cong\Sigma'/\tau'$；可行三元组恰为 $a=0:1\le k\le g+1,k\equiv g+1\ (2)$；$a=1:0\le k\le g$。

- **依据**：命题 2.1.3；定义 2.1.4；定理 2.1.5；引理 2.1.6；式 (2.4)；定义 2.1.7（double 三元组）；定理 2.1.8。
- **坏在哪**：$a$ 不是装饰——它决定 $\Sigma/\tau$ 可定向与否，也决定 $\pi^{\mathbb{R}}_1$ 是否存在「分裂」（习题 2.2.30 与习题 2.1.21 的关系）。只记 $(g,k)$ 会把两类不同曲面混为一谈。

### D5 万有覆盖不是实覆盖：这就是必须换群的原因（§2.2.2，p.23–27）

$\tilde X$ 是 $X$ 的万有覆盖，$p:\tilde X\to X$。若 $X$ 是克莱因曲面，一般**不存在**连通的万有实覆盖：用单值化，上半平面的实结构必共轭于 $z\mapsto-\bar z$，实点集连通；而亏格 $\ge2$ 的克莱因曲面可以有空的实点集，它不能被上半平面覆盖。所以不能照搬「$\pi_1=\operatorname{Aut}(\tilde X/X)$」，得把「覆盖 $\mathrm{Id}_X$ 或覆盖 $\sigma$」的自同构一起收进来（定义 2.2.10）。

- **依据**：§2.2.2 开头的讨论；定义 2.2.7（实覆盖）；式 (2.13)–(2.15)。
- **坏在哪**：这一步是全篇的**概念枢纽**。误以为 $\tilde X$ 是实覆盖，就会以为 $\pi^{\mathbb{R}}_1=\pi_1$，于是正合列 (2.17) 与 $\kappa$ 全部消失。

### D6 群结构与正合列（§2.2.2，p.25–29）

$\pi^{\mathbb{R}}_1$ 对**反群**封闭：$(f\cdot g):=g\circ f$；增广 $\alpha:\pi^{\mathbb{R}}_1\to\mathbb{Z}/2\mathbb{Z}$ 把全纯送 0、反全纯送 1，$\ker\alpha=\pi_1$ 正规（命题 2.2.8）⇒ 正合列 (2.17)。$x$ 为实点时，提升 $\tilde\sigma$（引理 2.2.11）给出共轭作用，$\pi^{\mathbb{R}}_1\cong\pi_1\rtimes_{\tilde\sigma}\mathbb{Z}/2\mathbb{Z}$（命题 2.2.13，推论 2.2.14）。

- **依据**：命题 2.2.8、2.2.12、2.2.13；引理 2.2.11；注 2.2.15；推论 2.2.14。
- **坏在哪**：反群的约定（$f\cdot g=g\circ f$）不是洁癖——它保证 $\pi^{\mathbb{R}}_1$ 左作用在纤维上（命题 2.2.9），与覆盖伽罗瓦理论的方向一致。写成 $f\circ g$ 会让所有作用反向。

### D7 非实点：$\Gamma$ 模型与「增广」的语言（§2.2.2，p.29–31）

$x\notin\operatorname{Fix}(\sigma)$ 时没有「$\tilde\sigma^2=\mathrm{Id}$」可用，改取 $\Gamma=\{$环路$\}\sqcup\{x\to\sigma(x)$ 道路$\}$ 带乘积 $\gamma\boxtimes\gamma'$（视 $\gamma'(1)$ 取 $\gamma*\gamma'$ 或 $(\sigma\circ\gamma)*\gamma'$），则 $\Phi:\Gamma\cong\pi^{\mathbb{R}}_1$，且与 (2.17) 交换（命题 2.2.17）。

- **依据**：引理 2.2.16；命题 2.2.17；例 2.2.20（$\mathbb{CP}^1$ 挖三点，显式展示 $\langle b_1,b_2,b_3\mid b_i^2=1\rangle$）。
- **坏在哪**：这一步把「抽象的反群」变成「可以写生成元与关系的东西」。例 2.2.20 是全文唯一可逐字验算的例子，读 §2.3 前应先算一遍。

### D8 分类定理：实覆盖 $\simeq$ 左 $\pi^{\mathbb{R}}_1$-集（§2.2.3，p.32）

$\operatorname{Fib}_x$ 与 $Q(F)=(\tilde X\times_{\pi_1}F,\ \pi^{\mathbb{R}}_1/\pi_1)$ 互为准逆（定理 2.2.21）。证明要点：用命题 2.2.9 让 $\pi^{\mathbb{R}}_1$ 作用；取 $h\in\pi^{\mathbb{R}}_1$ 映到 $-1$，定义 $\Phi(y,v)=(y\cdot h^{-1},h\cdot v)$ 保持 $\pi_1$-轨道、平方为恒等（因 $h^2\in\pi_1$），$\tau$ 与 $h$ 的选取无关。

- **依据**：定理 2.2.21；定理 2.2.6（普通情形）；命题 2.2.9。
- **坏在哪**：这是「$\pi^{\mathbb{R}}_1$ 是正确概念」的**唯一**判据。若它不分类实覆盖，定义 2.2.10 就只是一个人为的群。

### D9 表示：增广同态，不是普通同态（§2.3.1，p.35–36）

$\pi^{\mathbb{R}}_1$ 的元素有「全纯/反全纯」之分，所以表示必须让全纯部分用 $\mathbb{C}$-线性变换、反全纯部分用 $\mathbb{C}$-反线性变换：$\rho:\pi^{\mathbb{R}}_1\to GL^\pm(V)$ 且与到 $\mathbb{Z}/2\mathbb{Z}$ 的增广交换（图 (2.21)）。酉情形用 $U^\pm(V,h)$；取 $u\in U(V)$（不用 $U^\pm$）作等价，才能把 $[\rho]$ 送到 $[\rho|_{\pi_1}]$。

- **依据**：式 (2.20)–(2.22)；线性实结构 $\alpha$；引理 2.3.1；定义 2.3.2、2.3.3；习题 2.3.5/2.3.6。
- **坏在哪**：允许 $u\in U^\pm$ 作等价，$\Phi$ 就不是良定义的映射——这正是定义 2.3.3 只用 $U(V)$ 的理由，原文专门解释了一句。

### D10 主定理：$\Phi$ 的像落在 $\kappa$ 的不动点集中（§2.3.2，p.37–38）

正合列 (2.17) 给出 $\mathbb{Z}/2\mathbb{Z}\to\operatorname{Out}(\pi_1)$，于是 $\mathbb{Z}/2\mathbb{Z}$ 作用在表示簇上：$[\rho]\mapsto[\rho\circ\operatorname{Ad}_{\tilde\sigma}^{-1}]$（外作用 (2.23)）；Galois 共轭 $\operatorname{Ad}_\alpha$ 给出另一个对合。两者合成 $\kappa$（式 (2.25)）。定理 2.3.4：$\Phi(R(\sigma,\alpha))\subset\operatorname{Fix}(\kappa)$。证明是一行共轭计算：$\operatorname{Ad}_\alpha\circ\chi\circ\operatorname{Ad}_{\tilde\sigma}^{-1}(f)=(\alpha\rho(\tilde\sigma)^{-1})\chi(f)(\alpha\rho(\tilde\sigma)^{-1})^{-1}$，而 $\alpha\rho(\tilde\sigma)^{-1}\in U(V)$。

- **依据**：式 (2.23)–(2.25)；定理 2.3.4；习题 2.3.7–2.3.10。
- **坏在哪**：$\kappa$ 的两个因子各是一个对合，但复合**不必**是对合（$\tilde\sigma$ 一般非二阶，故 $^{-1}$ 不能省）。把 $\kappa$ 当成「$\rho\mapsto\bar\rho$」会得到错误的定理。

## 二、三条旁支（读的时候容易漏）

- **B1 反射原理 → double 的构造**（定理 2.1.11 → 定理 2.1.15）：局部把 $V_i$ 与 $\bar V_i$ 沿实轴粘起来，才能造出 $\tilde\Sigma$；习题 2.1.25 就是这条的局部版。
- **B2 覆盖伽罗瓦理论 → 实覆盖伽罗瓦理论**（定理 2.2.6 → 2.2.21）：普通情形是「$\pi_1$-集」，实情形要额外记住 $\tau$ 与 $h$ 的作用；证明里的 $\Phi(y,v)=(y\cdot h^{-1},h\cdot v)$ 就是补这个洞的地方。
- **B3 轨形基本群**（例 2.2.19）：无实点时 $\pi^{\mathbb{R}}_1\cong\pi_1^{\mathrm{top}}(X/\sigma;[x])$，这是 Thurston 的定义；本讲义绕开轨形、用覆盖空间定义，但结论必须与它一致——这是对定义 2.2.10 的**外部校验**。
