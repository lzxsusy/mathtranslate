## 与底本的三处系统性差异

1. **范围**：只译前言与第 2 章。第 1/3/4 章（Fock–Marshakov 的 dimer 可积系统、Teleman 的五讲 TQFT、Wentworth 的 Higgs 丛与局部系统）各留一份任务书；`通读笔记.md` 已给三章的速读要点，避免后续译者从零开始。
2. **页码**：译文标印刷页；资料卡同时给印刷页与 PDF 页（`pages` / `pdf_pages`），并注明「印刷页 = PDF 页 − 10」这一本书特有口径（版权页、目录各多一页）。
3. **原文笔误**：定理 2.1.15 证明中 $f$ 的定义域、命题 2.2.9 证明中漏写的逆号，都**照排底本**并加 `annote` 说明，不改原文数学内容（`疑点清单.tsv` Q005、Q006）。
