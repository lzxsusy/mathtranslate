## 五个「为什么可以这样跳」的节点

1. **为什么 Galois 侧可以用 $(\rho,N)$ 而不是 $\rho$？**
   因为定理 1.3 的 $L$/$ε$ 三公理只在 Weil–Deligne 表示上才有归纳结构（$0$ 次归纳要求 $N$）；单用 $\rho$ 无法把 $\Sp_m$ 的 $N$ 因素拆出来。

2. **为什么超尖点等价于「一切真抛物 $J_P=0$」？**
   因为 $J_P$ 与 $I_P$ 伴随（引理 2.9），而超尖点的定义禁止「出现为真抛物诱导的子商」；伴随性把「$J_P\pi\neq0$」翻译成「$\pi\hookrightarrow I_P\sigma$」（引理 2.10 的证明链，见推导卡 `supercuspidal-criterion`）。

3. **为什么一般表示可以化归到超尖点？**
   BZ 分类把每个不可约 $\pi$ 唯一写成 $Q(\Delta_1,\dots,\Delta_r)$，每段 $\Delta_i=\Delta_i(\pi_i,m_i)$ 由**超尖点** $\pi_i$ 与段长 $m_i$ 决定；于是 $\rec_n$ 只需在 $(\pi_i,m_i)$ 上定义（3.1.7）。

4. **为什么 $\mathrm{rec}_n$ 的归纳公式长那样？**
   $\Sp_{m}$ 是 $W_K\times\SL_2$ 的表示，它的 $W_K$-限制正是 $j=0,\dots,m-1$ 的扭转链；段长 $m_i$ 因此变成 $\Sp_{m_i}$ 的维数，底层 $\rho$ 就是这些扭转链的直和。

5. **为什么惯性侧能被 Bernstein 分量索引？**
   因为 $I_K$ 上 $\Sp_m$ 作用平凡，$\rec_n(\pi)|_{I_K}$ 只剩各超尖点块 $\rec_{n_i}(\pi_i)$ 重复 $m_i$ 次；再用引理 4.3（$I_K\triangleleft W_K$、$W_K/I_K\cong\mathbb Z$ 交换）把非分歧扭转吸收掉（推导卡 `inertia-from-bernstein`）。
