# 04 术语、文献与勘误 —— SY02-43

## 一、术语来源分级

本工程的术语一律按下表分级标注。**A 级**＝底本或经典原始文献的直接用词；**B 级**＝社区白名单（nLab、Stacks Project、ProofWiki）或**香蕉空间**的实际用例；**I 级**＝本仓既有冻结译名（跨工程一致）；**U 级**＝无任何外部依据、由译者按构词法与上下文自行裁定。

香蕉空间的核对方式与完整证据见 `工程文件/work/术语外部核对_香蕉空间.md`（2026-11-27，经 `bananaspace.org` 站内 API 逐词检索）。要点：该站对 $p$ 进表示论覆盖极薄，50 个检索词中**只有 8 个有专条**（局部域、导子、测度、深度、局部类域论、一般线性群、迹、特征标），**「超尖点」「容许表示」「Weil–Deligne」「惯性群」「驯惯性」「野惯性」全部零命中**。因此本工程只能对「香蕉空间确实用过」的词取 B 级，其余退回 I 级。

## 五、与香蕉空间用词不一致的四处（有意为之）

1. **「$L$ 函数」 vs 「$L$-函数」**：香蕉空间用空格，本工程用连字符，理由是与「$L$-因子」「$\varepsilon$-因子」并列时保持构词一致。
2. **「惯性群」 vs 「惯性子群」**：香蕉空间导航框用「惯性子群」（因为它主要写扩张），本工程写「惯性群 $I_K$」（底本用 group，且 $I_K$ 在 $W_K$ 中本就不是「子群」意义上的从属对象）。
3. **「局部 Langlands 对应」 vs 「局部 Langlands 纲领」**：香蕉空间两者并用；本工程取「对应」，因为定理 2.13 陈述的是一个**双射**，不是纲领。
4. **「佐竹同构」 vs 「Satake 同构」**：两者都通行，本仓 SY02-38 已冻结为后者，跨工程一致性优先。

以上四条已同时写入 `工程文件/STYLE_GUIDE.md` 的术语硬约定表，供后续工程复用。
