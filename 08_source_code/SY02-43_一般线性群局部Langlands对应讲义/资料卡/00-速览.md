# 00 速览 —— SY02-43《一般线性群的局部 Langlands 对应》

## 这是什么

Zijian Yao 在哈佛 2017 年秋学习讨论班上写的 36 页粗糙讲义，把 $\GL_n$ 的局部 Langlands 对应（LLC）拆成两半搭起来：**Galois 侧的 Weil–Deligne 表示**与**自守侧的超尖点表示**，中间用 Bernstein–Zelevinsky 分类把一般表示化归为「超尖点 + 段长」。本工程是它的中文译注本（37 页）加 29 张资料卡。

## 三分钟路线

1. **只想知道 LLC 在说什么**：读译本 §2.3（p21–22，定理 2.13 五条）+ `datasets/yao17/cards/concepts/llc-statement.json`。
2. **想知道为什么只需在超尖点上验证**：读 §3.1（p23–26，BZ 分类 + 3.1.7 归纳公式）+ 推导卡 `induction-to-supercuspidal`。
3. **只关心惯性侧**：读 §4（p32–35）+ 推导卡 `inertia-from-bernstein`。

## 译本的三个特点

1. **不补证明**：底本说「standard」「we omit」的地方，译注只给一句「可以怎么补」，不替作者写完整论证。
2. **留白照录**：§3.4、§3.5.1、§3.6.1–§3.6.2、§5、§6 的空缺一律标「底本此处未写」，让读者看得见作者的知识边界。
3. **编号严格对上**：定理 2.13 的五条、定理 3.1 的七条在资料卡里被逐条引用，译本与底本编号一致。

## 一句话读法

先读 §2.3 的定理 2.13（知道目标是什么），再回到 §1 的 Weil–Deligne 表示（知道左边长什么样），然后用 §3.1 的 BZ 分类（知道怎么把右边化归），最后读 §4（知道惯性侧为什么能对接）。§1 与 §3.1 是全文最值得精读的两节。
