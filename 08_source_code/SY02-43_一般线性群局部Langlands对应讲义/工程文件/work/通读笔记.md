# 通读笔记 —— SY02-43《一般线性群的局部 Langlands 对应》

底本：Zijian Yao, *Notes on Local Langlands for GLn*，哈佛 2017 秋学习讨论班，36 页（印刷页 = PDF 页）。
读法：全文分三段读——p1–p9（§1，Galois 侧）、p10–p22（§2，自守侧 + LLC 陈述）、p23–p36（§3–§6，分类与惯性）。
本笔记只记**结构与判断**，不复述公式；逐条疑点见 `疑点清单.tsv`。

## 0. 一句话总览

作者把「$\GL_n$ 的局部 Langlands 对应」拆成两半来搭建：一半是 Galois 侧的 Weil–Deligne 表示（**有 $N$、有惯性类型、有 $L$/$ε$ 因子**），一半是自守侧的超尖点表示（**用 Jacquet 函子判定**）；中间用 Bernstein–Zelevinsky 分类把一般表示化归为「超尖点 + 段长」，于是**只需在超尖点上验证 LLC**，惯性侧则由 Bernstein 分解推出。§5–§6 只剩标题，作者已明言是未完成稿。

## 1. §1（p2–p9）Galois 侧：把 $\rho$ 变成 $(\rho,N)$

- **1.1（p2–p6）** 先定义 Weil 群 $W_K$（$I_K$ 与 Frobenius 整数幂的半直积）与驯特征标，再把「Weil–Deligne 表示」定义为 $(\rho,N)$：$\rho$ 连续、$N$ 幂零、$N\rho(\sigma)=\rho(\sigma)N$、$\rho(\tau)N\rho(\tau)^{-1}=q^{-v_K(\tau)}N$。随后三条基本性质：$N$ 必幂零（p4）、半单时不可约（p4–5）、$(\rho,N)\cong\bigoplus\Sp_m(r)$（p5）。
- **1.1.4–1.1.8（p6–7）** 转入 $L$/$ε$ 因子：Tate 先对拟特征标定义 $L(\chi)$ 与显式 $ε(\chi,\psi,dx)$，定理 1.3 用「对特征是 Tate 的、短正合列乘性、0 次归纳」三条公理把 $L$/$ε$ 唯一延拓到 $W_K$ 的表示；推论 1.4 给出导子 $c(\rho)$ 与 $L,\varepsilon$ 的关系。
- **1.2（p7–9）** 核心是引理 1.5：任意 $\ell$ 进表示 $\rho$ 都能造出 $N=\log\rho(\sigma)$，从而 $\rho\mapsto(\rho,N)$ 满射；配合引理 1.2 的单性得推论 1.7：$\WD$ 是范畴等价。1.2.3 定义惯性类型 $\rec_n(\pi)|_{I_K}$，引理 1.9 给出「惯性类型相同」的判据（块数、块长、$\rho_i|_{I_K}$ 逐项相同）。
- **判断**：§1 是整篇最「自足」的一节，几乎可以直接当 Weil–Deligne 表示的小型导引读；引理 1.5 的证明思路（模 $\ell$ → pro-$\ell$ 核 → $t_\ell$ 分解 → 取 $\log$）是本讲义相对教科书最有价值的部分。

## 2. §2（p10–p22）自守侧：容许、超尖点、LLC 陈述

- **2.1（p10–16）** 光滑 → 容许 → Hecke 模（引理 2.1/2.2）→ Satake（球面 Hecke 代数 $\cong\mathbb C[t^{\pm1}]^{S_n}$，Gelfand 技巧）→ 定理 2.5（光滑不可约 ⇒ 容许）与定理 2.8（Harish-Chandra 特征标）。这一节的骨架是「表示范畴 ≃ 非退化 Hecke 模」。
- **2.2（p16–20）** 定义 $\Ind/\ind/\Res$ 与 $\psi_!$，用 $\psi_!$ 造朴素 $J_P$/$I_P$ 并证明伴随；再用模特征标 $\delta_P^{1/2}$ 正规化（p18 有 $\GL_2$ Borel 的显式计算 $\delta(\mathrm{diag}(a,d))=|ad^{-1}|$）；超尖点定义（p20）+ 引理 2.10（超尖点 ⇔ 一切真抛物 $J_P=0$）、2.11、2.12。
- **2.3（p21–22）** 定理 2.13 五条性质（$n=1$ 类域论、Steinberg、扭转、$L$/$ε$ 相容、$\det$ 相容），Henniart 的四步策略 (i)–(iv)，定理 2.14（超尖点/本质 $L^r$/一般表示在对应下的像），命题 2.15（含 Paskunas 的工作）。
- **判断**：§2 的写法是「先建范畴、再讲诱导、最后才陈述 LLC」；读者若跳过 2.1 直接读 2.3，会因为「容许」与「非退化 Hecke 模」的等价而看不到为什么定理 2.13 的每一条都能验。

## 3. §3（p23–p31）分类与不变量

- **3.1（p23–26）** Zelevinsky 段 $\Delta(\pi,m)$、linked/precedes、条件 $(*)$，定理 3.1 七条（标准表示、不可约判据、唯一不可约商、Langlands 商、超尖点支撑、Steinberg、$n=2$ 分类）。3.1.7 给出归纳公式：$\rec_n(\pi)=\bigoplus_i\Sp_{m_i}(\rec_{n_i}(\pi_i))$。
- **3.2（p26–28）** 本质 $L^r$、平方可积、缓增（定理 3.2、3.3、推论 3.4）；generic 与 Whittaker 模型（$\theta_\psi$、引理 3.5、定理 3.6：generic ⇔ $\rec_n(\pi)$ 可约）。
- **3.3–3.6（p29–31）** 结构引理 3.7（五个分解）、非分歧、Iwahori-不动向量（原文「to be added」）、导子与深度（3.4 只有标题）、深度 0 的五条等价图（p30）、JPPS 的 $ε$ 公式与引理 3.8（$c(\pi)=c(\rec_n\pi)$）。
- **判断**：§3 是「把 LLC 化归到超尖点」的技术核心；p25 的超尖点支撑条件排版只写到 $j=1,\dots,m_i-1$，按定义应为 $j=0,\dots$（见疑点清单 B-1）。§3.4 与 §3.5.1 的留白说明作者本打算补导子与新向量，但未写。

## 4. §4（p32–p35）惯性 Langlands

- **4.1（p32–33）** Bernstein 分量 $R(L,\varsigma)$、引理 4.1（分量相等 ⇔ 惯性等价）、Bernstein 中心、定理 4.2（$\Rep^\infty_n=\prod R(L,\varsigma)$），$\GL_2$ 的三类分量。
- **4.2（p33–35）** 惯性对应：引理 4.4（同分量 ⇔ $\rec_n(\pi)|_{I_K}$ 同构）、引理 4.5（generic 时同一 Galois 惯性类型 ⇒ $\pi|_K\cong\pi'|_K$）；反例 $\mathrm{triv}$ 与 $\St_2$ 同分量但 $K$-限制不同构。
- **4.3（p35）** 类型、$K$-型、极小 $K$-型；与 Bushnell–Kutzko 型的区别。
- **判断**：§4 是全文最「有洞见」的一节——它把 §3 的 BZ 分类与 §1 的惯性类型对接起来；但底本对「为什么 generic 条件删不掉」只用一句 Remark 带过，译注里补了反例。

## 6. 通读后的三个判断（影响译法）

1. **不补证明**：底本大量「we omit」「proof is standard」，若替作者补，会把 36 页膨胀成 100 页并引入作者没有的路线。译注只给「可以怎么补」的一句话，不写完整论证。
2. **编号必须严格对上**：定理 2.13 的五条、定理 3.1 的七条在资料卡里被逐条引用，编号一漂就对不上；故节内小节数与底本必须一致。
3. **留白照录**：§3.4、§3.5.1、§3.6.1–3.6.2、§5、§6 的空缺是底本信息的一部分（说明作者的知识边界），译本必须让读者看得见，而不是抹平。
