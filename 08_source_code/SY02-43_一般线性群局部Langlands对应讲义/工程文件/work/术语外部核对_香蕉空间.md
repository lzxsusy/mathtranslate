## 4. 裁定

1. **香蕉空间有据者照用**：惯性群（子群）、尖点表示、局部 Langlands 对应、Langlands 纲领（保留拉丁）、$L$ 函数（站点写法）。
2. **香蕉空间无专条者沿本库既有冻结译名**（本库 SY02-18/24/38/41 已冻结，且与社区通行用法一致）：
   - supercuspidal = 超尖点（不写「超尖」）；
   - admissible = 容许的 / 容许表示；
   - unramified / ramified = 非分歧 / 分歧的；
   - conductor = 导子（香蕉空间有「导子」专条，词形一致）；
   - $L$-parameter = $L$-参数、$L$-packet = $L$-包。
3. **无据且本库无先例者自拟并登记**：$\varphi$-半单（Frobenius 半单）、本质平方可积、缓增、一般的（generic）、Zelevinsky 段、惯性等价、Bernstein 分量/中心、类型/$K$-型/极小 $K$-型、模特征标、球面 Hecke 代数。每一条的理由写进 `资料卡/04-术语文献勘误.md`。
4. **一处与站点写法的差异要说明**：站点把 $L$-函数写作「$L$ 函数」（空格），本工程沿用「$L$ 函数」指全局对象、用「$L$-因子」指局部因子；这是**对象不同**而非译法冲突。

## 5. 结论对译法的影响

- 香蕉空间对 $p$ 进表示论（超尖点、Jacquet 函子、Bernstein 分解、类型）几乎零覆盖，因此本工程**不能**以香蕉空间为唯一依据；它的实际作用是把「惯性子群 / 尖点表示 / 局部 Langlands 对应 / $L$ 函数」这四五个高频词锚定在社区写法上，其余沿本库冻结表。
- 所有对照逐条写入 `资料卡/04-术语文献勘误.md` 的「术语来源」表，读者可据此判断每个译名的依据等级（A 原文 / I 本库 / U 自拟）。
