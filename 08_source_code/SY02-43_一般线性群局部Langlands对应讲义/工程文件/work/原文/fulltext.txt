4.3. Types.
Finally, we brieﬂy discuss the theory of types.
4.3.1. Standard deﬁnitions.
Deﬁnition. Let σ be a smooth irreducible representation of K, let s = (L, ς) ∈
B(GLn) be an element in the Bernstein center.
(1) σ is a type for (L, ς) if for all smooth irreducible representations π ∈Rep∞
n ,
π|K contains σ ⇔π ∈R(L,ς).
(2) σ is a K-type for (L, ς) if for all smooth irreducible representations π,
π|K contains σ ⇒π ∈R(L,ς).
(3) Let π ∈R(L,ς) be a smooth irreducible representation in R(L,ς), a minimal
K-type for π is a K-type σ for (L, ς) of minimal dimension occurring in π|K.
Note that each type is trivially a K-type, and both notions only depend on the
pair (L, ς) ∈B(GLn), while the deﬁnition of a minimal K-type for π depends on the
particular π ∈R(L,ς). To wit, there could be many K-types for a given s = (L, ς);
for each irreducible π ∈R(L,ς), a K-type σ may or may not appear in π|K. Among
those which appear in π|K, the minimal dimensional ones are the minimal K-types
for π.
Remark. Our deﬁnition of type agrees with the one given in [9], which is slightly
diﬀerent from [4]. We refer to latter notion as Bushnell-Kutzko types, which is
a pair (J, σ) where J is a compact open subgroup and σ a smooth irreducible
representation of J – namely it allows more general compact open subgroups than
K = GLn(OK).
