# 通读笔记 —— Fargues《局部 Langlands 对应的几何化：综述》

- 底本：Laurent Fargues, *Geometrization of the local Langlands correspondence: an overview*,
  2016-02-02，46 页（印刷页 = PDF 页）。
- 记录者：Lead（数译工程）。状态：全文速读 1 遍已完成（2026-11-23），逐章细读由各章译手完成并回报。
- 用途：开译门槛文件（《数学文献翻译纪律》§1.0），供译手统一理解全局，不代替各章细读。

## 一、三句话主旨

1. 在 Fargues–Fontaine 曲线族 $X_S$ 的 $G$-丛叠 $\Bun_G$ 上，每个离散局部 Langlands 参数
   $\varphi:W_E\to{}^{L}G$ 应当对应一个 $S_\varphi$-等变的 Hecke 特征层 $\cF_\varphi$（猜想 4.4）。
2. 这个层在基本点处的茎给出 $G$ 的**扩充纯内形式** $J_b$ 的局部 Langlands 对应，
   并满足尖点性、Hecke 特征性、特征层性与局部/整体相容四条性质；
   其中「特征层性」正是把它与 $G(E)$ 的稳定分布联系起来的关键。
3. 由这套构造可以推出 Kottwitz 关于基本 Rapoport–Zink 空间上同调离散部分的猜想（§8），
   并在环面（含 $\mathrm{GL}_1$）情形验证猜想（§9）。

## 二、论证地图（按节）

- **导引（p.1–3）**：陈述猜想的非形式版本。曲线 $X_S$ 与 $\Bun_G$ 已在 [10] 中构造；
  本文给出 Hecke 对应、$B(G)\cong|\Bun_{G,\ol\FF_q}|$、基本点的剩余 gerbe、
  扩充纯内形式 $J_b$，以及特征层性的含义（Frobenius 迹 = 稳定分布在椭圆正则元上的限制）。
  末段给出全文结构。
- **§1 曲线（p.3–16）**：先在两情形下定义 adic 曲线 $X_S=Y_S/\varphi^\ZZ$（定义 1.5），
  再由 untilt 理论（§1.3：倾斜、完满、菱形、定义 1.8/1.12）说明
  $X_S$ 上的闭子概形由次数 1 本原元决定（命题 1.22、1.23）；
  §1.4 给出本原元与 untilt 的对偶（引理 1.16、命题 1.18、推论 1.21），
  §1.4.3 顺带引入 Hilbert 菱形（不用于陈述猜想）。
  §1.5 是技术核心：定义 $P_R=\bigoplus_d H^0(X_R,\oo(d))=O(Y_R)^{\varphi=\pi^d}$，
  取 $X^{\mathrm{sch}}_R=\mathrm{Proj}(P_R)$（定义 1.24）；等特征时用 Lubin–Tate 形式群的
  Weierstrass 分解把 $X^{\mathrm{ad}}\to X^{\mathrm{sch}}$ 显式化（§1.5.2），
  不等特征时用 Lubin–Tate 对数照样构造（§1.5.3）；
  最后给出 $X^{\mathrm{sch}}$ 的内蕴刻画（命题 1.27、推论 1.28）与 GAGA 等价（定理 1.29）。
  §1.6 把 untilt 解释为 $X^{\mathrm{sch}}$ 上的 Cartier 除子，并证明沿该除子的形式完备化是
  $\mathrm{Spf}(B^+_{\mathrm{dR}}(R^\sharp))$（命题 1.30、1.31、1.33）——这一步是后面
  Beauville–Laszlo 单值化与 Hecke 叠定义的支点。
- **§2 叠 $\Bun_G$（p.16–23）**：定义 $\Bun_G$（定义 2.1）并说明它是叠（命题 2.2），
  再把「光滑菱形叠」这一尚无定义的概念当作愿望（Hope 2.3）来用；
  用 Kedlaya–Liu 的振幅估计与 Quot 格式技巧给出可表性与光滑呈现（命题 2.4、2.5、2.9、2.10）。
  §2.2 用 Dieudonné–Manin 分类识别 $\Bun_{X}$ 的点：定理 2.11（[10]）说 $F$ 代数闭时
  $E(-)$ 本质满，定理 2.12 给出 HN 滤过分裂，定理 2.13 给出
  $B(G)\cong H^1_{\text{ét}}(X^{\mathrm{sch}},G)$，猜 2.14 断言等特征时同样成立
  （作者明确「此后一律承认」）。§2.3–2.4 讲连通分支（Kottwitz 映射 $\kappa$）与 HN 分层；
  §2.5 定义自同构层 $\wt J_b$（定义 2.19），指出它与 $J_b(E)$ 的差别是本构造的特征现象；
  §2.6 给出基本点的单值化（定理 2.26）与一般 HN 层的推广。
- **§3 $\BdR$-仿射 Grassmann 簇与 Hecke 叠（p.23–28）**：定义 $\Gr$（定义 3.1），
  用 untilt 与 Beauville–Laszlo 粘接重新描述它（命题 3.4）并得到 $BL:\Gr\to\Bun_G\times\Spa(E)^\diamond$；
  猜想 $BL$ 在光滑拓扑下满（猜想 3.8、3.9）。§3.3 在两情形下把 $\Gr$ 具体化：
  等特征时是 Pappas–Rapoport 扭仿射 Grassmann 簇的完满化（命题 3.10、推论 3.11），
  不等特征时 Scholze 证明 $\Gr^{\le\mu}$ 是菱形（定理 3.14）。
  §3.4 定义 Hecke 叠 $\Hck^{\le\mu}$（定义 3.17）与两投影 $\overleftarrow h,\overrightarrow h$（定义 3.19），
  证明 $\overrightarrow h$ 是 $\Gr^{\le\mu}$ 的局部平凡纤维化（命题 3.20）。
  §3.5 提出几何 Satake 的假想版本（猜想 3.21），其中 $IC_\mu$ 的取值与 $r_\mu$ 的构造是全文两条暗线之一。
- **§4 猜想的陈述（p.28–29）**：先定义离散参数与尖点参数（定义 4.1），
  说明没有 tempered $L$-参数的自然类比（注 4.2），给出粗糙版本（猜想 4.3）与精确版本（猜想 4.4）；
  精确版本含六条：(1) 中心特征，(2) 尖点性 $j_!j^*$，(3) 基本点处 $x_b^*\cF_\varphi$ 的分解
  （局部 Langlands 对应），(4) Hecke 特征性，(5) 特征层性，(6) 局部/整体相容。
  末尾两条注（4.5、4.6）讨论中心非连通与 $b$ 非基本时与 Jacquet 函子的关系。
- **§5 特征层性（p.29–31）**：把 (5) 展开为 Frobenius 作用与 $\delta$ 的作用相等，
  并化为 $S_\varphi$-同型分量上标量全为 1 的陈述；给出推论：稳定分布 $T_\varphi$ 在椭圆正则元上
  由 Frobenius 迹给出（含 Kottwitz 符号 $e(J_\delta)$）；注 5.1–5.4 讨论符号、内窥分布、
  非分歧扩域上的加强版与文献来源。
- **§6 $F$-等晶体、$p$-可除群与向量丛的修正（p.31–34）**：§6.1 紧化 $Y$（$\overline{Y}$）；
  §6.2 证明 $B^+_{\mathrm{cris}}$ 的截面落在 $\overline Y$ 的层里，从而
  $(\Spec(R^\circ/\varpi_R)/\Spec\ZZ_p)_{\mathrm{cris}}$ 上的 $F$-等晶体 $\simeq$ $Y$ 上的
  $\varphi$-等变向量丛（命题 6.1、推论 6.3、定理 6.4）；
  §6.3 把 $p$-可除群的协变 Dieudonné 晶体变成曲线上的向量丛（定义 6.8、注 6.9），
  用 Hodge 滤过与 Fontaine 比较定理（命题 6.7、6.11）造出
  $u:\mathrm{BT}^{d,h}\to\Hck_\mu$（推论 6.10、命题 6.12）。
  本节的关键是：$\overleftarrow h\circ u$ 给出 Hodge–de Rham 周期，$\overrightarrow h\circ u$ 给出 Hodge–Tate 周期。
- **§7 局部/整体相容（p.34–36）**：在 PEL 型 Shimura 数据上，用 Scholze 的完满化
  $\mathrm{Sh}_\infty$（定理 7.1）与 §6 的 $u$ 构造交换图，从而**定义** Hodge–Tate 周期态射
  $\pi_{\mathrm{HT}}$，并把局部/整体相容写成
  $R\pi_{\mathrm{HT}*}(\overline{\QQ}_\ell[\dim\mathrm{Sh}])[\Pi^p]=m\cdot i_*\overleftarrow h_*\cF_{\varphi_{\Pi_p}}$。
  注 7.2–7.5 讨论 Newton 分层、尖点性条件的动机（Igusa 簇与 Jacquet 函子）、
  等特征情形（shtuka 模空间）与 $\ell=p$ 的类比。
- **§8 基本 RZ 空间上同调上的 Kottwitz 猜想（p.36–42）**：§8.1 用
  $\mathrm{GL}_n$、$\mu=(1,0,\dots,0)$、$b$ 的显式矩阵把猜想算成
  Drinfeld 塔上同调实现局部 Langlands/Jacquet–Langlands 的经典陈述，并指出新预言：
  $[\PP^{n-1}/\mathrm{GL}_n(E)]$ 上存在一个反常层，其中间次上同调实现 LLC（注 8.1）。
  §8.2.1 定义局部 shtuka 模空间 $\mathrm{Sht}(G,b,\mu)$（关于 $\breve\QQ_p{}^\diamond$ 的菱形，
  带 $G(\QQ_p)\times J_b(\QQ_p)$ 作用与 Weil 下降数据），给出两个周期态射与 admissible locus 构造，
  由此推出命题 8.2（Kottwitz 猜想的精确形式，含 $IC$ 与 minuscule 特例）。
  §8.2.2 说明 $\mathrm{Sht}(G,b,\mu)$ 与 RZ 空间的关系：Scholze–Weinstein 定理
  $\cM_\infty\cong\mathrm{Sht}(G,b,\mu)$（定理 8.7）。
- **§9 交换情形（p.42–46）**：§9.1 在 $\mathrm{GL}_1$ 上验证：命题 9.1 给出 Hecke 对应的显式描述，
  命题 9.2 验证 Hecke 性与特征层性（关键用 Lubin–Tate 特征 $\chi_{\mathrm{LT}}$ 与类域论）；
  §9.2 对一般环面 $T$ 做同样的事（命题 9.3、9.5），并给出 $r_\mu$ 的显式形式 $r_{\mu'}=\mathrm{Ind}\mu'$。
- **文献表（p.46）**：32 条，其中 [10]（Fargues–Fontaine 曲线书）与 [27]（Scholze 讲义）是全文技术支柱。

## 四、阅读顺序（建议）

1. 导引 → §1.1–1.4（曲线、untilt、菱形、本原元）→ §2.1–2.2 与 §2.5–2.6.1（$\Bun_G$、
   $B(G)$、$\wt J_b$、基本点单值化）→ §3.1–3.2、3.4（$\Gr$、$BL$、Hecke 叠）→ §4。
   这条线足以理解猜想的陈述。
2. 想看懂猜想的**动机**：接 §9（环面验证，最短的非平凡检验）与 §5（特征层性）。
3. 想看懂**推论**（Kottwitz 猜想）：§6 → §7 → §8；§7 依赖 §6 的 $u$，§8 依赖 §6 的 $u$ 与 §7 的图。
4. 全书的逻辑依赖是：§1 →（§2, §3）→ §4 → §5；§6 → §7, §8；§4 → §8, §9。
