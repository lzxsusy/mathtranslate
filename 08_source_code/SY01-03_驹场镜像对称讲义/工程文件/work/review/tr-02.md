### M1. tr02b.tex 第 50 行 · 式 (4.10) · 第二个对易子括号内的 λ 多了一条横线

- **页码/式号**：印刷 p.20（PDF p.21），式 (4.10) 的第二行末尾。
- **原图**（1800 dpi 裁 `crop.py 21 385 71 460 92`）：`+[\bar\sigma,\lambda_-]\bar\lambda_+]` —— 括号内是**无横线**的 `\lambda_-`，只有括号**外**的 `\lambda_+` 带横线；括号内 σ 带横线。
- **现状**：`+[\overline{\sigma},\overline{\lambda}_-]\overline{\lambda}_+`
- **判定**：与原图不符（多了一条横线，把 `\lambda_-` 写成了 `\overline{\lambda}_-`）。同项前半 `-\lambda_+[\sigma,\overline{\lambda}_-]` 中括号内 λ 带横线、括号外 λ 不带，恰好互为对偶，可与本项对照自检。
- **可直接替换**（整行替换，仅改一处）：

```latex
&\qquad +(v_{01})^2+D^2-\frac{1}{4}[\sigma,\overline{\sigma}]^2-\lambda_+[\sigma,\overline{\lambda}_-]+[\overline{\sigma},\lambda_-]\overline{\lambda}_+\Big],\tag{4.10}
```

（即把 `+[\overline{\sigma},\overline{\lambda}_-]\overline{\lambda}_+` 改为 `+[\overline{\sigma},\lambda_-]\overline{\lambda}_+`）
