## 疑点与请示（Lead 必读）

原文疑似笔误/含糊处（均照原样译，未擅自改动）：

1. **例 5.3 首句对象所在范畴**：原文（300dpi/900dpi 图与 PDF 文字层一致）作「対象 X₁, X₂, X₃, X₄ ∈ C̃ に対し、X̃₁,…,X̃₄ ∈ C̃ を…」，而例 5.2 是 X_i ∈ C、X̃_i ∈ C̃。译文照原印作 ∈C̃。数学上两种读法都成立（X̃_i := X_i[r_i] 仍在 C̃ 内），但「例 5.2 と同様」提示可能多打了一个波浪号。**请示是否统一为 ∈C**；若保留原样，读者可能误以为 C̃ 还能再取平移扩张。
2. **d(h₂₄) = −ρ₂₃·ρ₃₄ = 0**（p.50 末）：若按字面 d(h₂₄)=0，则 m̃_*(Φ) 的 (2,4) 分量为 ρ₂₃ρ₃₄≠0，与 p.51 结果矩阵 (2,4)=0 及「m̃_*(Φ) 除 𝒳-𝒵 块外为平凡」矛盾；作者的「=0」应是在说上同调类为零。译文照录并加批注。
3. **Φ_{X̃₂₃} := (0 ρ₁₂; 0 0)**（p.52）：按例 5.2 的 Φ 中 X̃₂⊕X̃₃ 子块，该 (1,2) 分量应为 ρ₂₃。疑原文笔误，译文照录并加批注。
4. **定理 5.4 末尾孤立「□」**：原书在三条 • 之后右侧另起一行单独印 □，全篇无「証明」段。译文按原样加 `\hfill$\square$`。**请示：保留还是删去**（若认为它是排版残留，删去更干净）。
