\noindent\textbf{摘要}\quad
Kontsevich 在表述同调镜像对称猜想时，提出了从 $A_\infty$ 范畴构造三角范畴的方法。
若三角范畴能按这种方法由 $A_\infty$ 范畴构造而出，就说该三角范畴具有\textbf{$A_\infty$ 增广}。
已知三角范畴未必总有 $A_\infty$ 增广；反过来，可以提出这样的问题：
若它带有 $A_\infty$ 增广，这个增广是否唯一？
一般说来，三角范畴的 $A_\infty$ 增广并不唯一。
本文以 [12] 为主，讨论这一事实，并讨论反过来 $A_\infty$ 增广唯一的若干例子。
\end{minipage}
\end{center}
