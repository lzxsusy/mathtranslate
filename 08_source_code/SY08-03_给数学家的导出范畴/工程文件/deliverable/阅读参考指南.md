# 阅读参考指南（给第一次读这篇讲稿的人）

## 一、这篇讲稿值不值一读

值。它是“导出范畴”最短的入门路径：13 页，没有一条要查书的证明，所有结论都在文中用锥
和长正合列推出来。读完能回答三个问题：为什么同调不够、导出范畴在形式化什么、导出函子
为什么长成那样。缺点也明显：例子密、跳步多、节号还有错位（校勘 1），所以本译本加了
20 条译注与 7 个校勘框。

## 二、按背景选路线

| 你的背景 | 建议路线 | 大约用时 |
| --- | --- | --- |
| 拓扑 | §2.1 → §5（图 1、图 2 与式 5.1–5.2）→ §6 的 $\R\Gamma$ 例 | 2 小时 |
| 代数几何 | §2.2–2.3 → §3 → §4 → §6 的 $\Tor$、$\R\mathcal Hom$ 例 | 3 小时 |
| 范畴论 | §4（定义 4.1、4.2、注 4.3）→ §5 公理 → 附录 D.3 论证三 | 2 小时 |
| 只想懂个大概 | §1 + §4 + 附录 D.1 论证地图 | 40 分钟 |

## 三、五个必读段落

1. §2.3 末尾的黑框标语「复形好，（上）同调坏」——全文的论点。
2. 定义 4.2 与紧随其后的屋顶图——导出范畴的定义就在这一页。
3. §5 式 (5.1) 与式 (5.2)——拓扑的锥如何变成代数里的特异三角。
4. §6 例 6.6——de Rham 定理就是“常数层的导出函子”。
5. 附录 D.3 论证二——锥为什么同时是核与余核，这是全书的技术心脏。

## 四、容易卡住的地方（译本已处理）

- **$\R\Gamma$ 与 $H^i$ 的关系**：见译注 19；一句话，$\R\Gamma$ 作用在复形上，$H^i$ 是它的分次。
- **为什么只需添一步逆**：见译注 14；关键是拟同构类满足 Ore 条件，两个屋顶可以再化成一个。
- **$\Sigma$ 为什么不可逆**：见译注 17；三角范畴只要求 $\Sigma$ 是等价，逆不必存在；
  要逆就得升级到稳定范畴。
- **原文 §3 的例子**：不要照着学，它是错的（校勘 3）；用译注 12 的
  $A=\C[\epsilon]/\epsilon^2$ 例子。
- **Dolbeault 命名**：原文把全纯 de Rham 复形叫 Dolbeault（校勘 4），读的时候心里换回来。

## 五、读完接什么

- 想补基础：Gelfand–Manin《Methods of Homological Algebra》第 III 章（本书 [GM]）。
- 想看几何应用：Huybrechts《Fourier–Mukai Transforms in Algebraic Geometry》第 1–3 章。
- 想看三角范畴的公理细节：Neeman《Triangulated Categories》第 1 章。
- 想看后续形式化：附录 D.4 给了 dg 范畴、稳定 ∞-范畴、导出代数几何三条线，各配一句
  “为什么需要它”。
- 想动手：附录 D.5 五道习题，难度从“验证 $\Sigma\dashv\Omega$”到“给对偶公式找反例”。
