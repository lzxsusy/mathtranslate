# 审校报告

**对象**：David Grabovsky, *Chern–Simons Theory in a Knotshell*（2022-09-14，38 页）中译本
**审校**：全文逐页对照原 PDF 页面图像（170 dpi，公式与脚注必要时 230 dpi 局部放大）＋ 逐式重算符号/因子/量纲
**结论一句话**：这是一篇写得相当好的教学综述，物理图像清晰、路线（U(1) 现象学 → 非阿贝尔路径积分 → 正则量子化）安排合理；但**有 6 处实质性数学/表述问题、8 处排印或符号笔误**，另有 26 处"只引不证"的关键步骤。译文一律照录原文、另加批注，未作静默修正。

---

## 一、总体评价

### 1.1 优点

1. **物理直觉完整**：用 U(1) 理论把"电荷自带磁通 → 绕行即 AB 相位 → 任意子统计 → 环绕数"这条链条讲透，再上非阿贝尔理论，读者不会在形式化中失去物理。
2. **技术核心抓得准**：把全文的技术枢纽放在**标架化**（标架反常）上，而不是像许多综述那样一带而过；这正是 §3.3–§3.4 最值得读的部分。
3. **文献脉络清楚**：Witten 1989、Dunne、Bar-Natan–Witten、APS、Atiyah–Bott、Quillen、Segal、Verlinde 都点到了，适合作为进入该领域的路线图。

### 1.2 局限（读者须知）

1. 多处关键论证**只给结论**：Bott 定理、APS 指标定理、Atiyah–Bott 维数公式、Borel–Weil–Bott、Quillen 行列式线丛、Lickorish–Wallace 手术定理，均"引而不证"。这符合综述体例，但读者若想真正掌握，需要按批注追文献。
2. 若干**符号/归一化约定未明说**（$\varepsilon^{012}$、$\eta$ 的 $\frac12$、$c_2(G)=2h^\vee$），照抄文献公式极易差因子 2 或 4。
3. 个别地方是**作者的笔误**（见第二节），不是读者的错。
4. 原文把 1989 年之后的进展（Khovanov 同调）也归入"Witten 的工作直接给出"，史实上宜作区分。

## 三、经回图复核确认"不是笔误"的 4 处（为作者澄清）

审校不只是挑错。以下几处初看可疑，回图与重算后确认原文无误，特此记录，避免后来者误改：

1. **(3.26) 中段的"/"其实是波浪箭头**。原式（p.21）为
   $$\Lambda=\exp\!\Big(\tfrac{i\pi}{2}\eta[0]\Big)=\exp\!\Big(\tfrac{id\pi}{2}\eta_g\Big)\ \leadsto\ \exp\!\Big(i\pi d\Big[\tfrac{\eta_g}{2}+\tfrac1{12}\tfrac{I[g]}{2\pi}\Big]\Big)=\exp(i\pi d\Xi).$$
   箭头表示"把 $\frac{\eta_g}{2}$ 替换为 $\Xi$"这一步代换，不是相除。相位全程取 $+$，与 (3.27) 括号内的 $+\frac{I[g]}{24\pi}$ 完全一致。**文本提取把箭头识别成了 "/"，是本项目最初的怀疑来源，已排除。**
2. **(3.32) 的系数**：$Z=\sqrt{2/(k+2)}\sin\frac{\pi}{k+2}\sim k^{-3/2}$ 与 $\mathrm{SU}(2)$ 陈–西蒙斯理论的标准结果一致；`c_2(SU(2))=4` 即 $2h^\vee$（$h^\vee=2$），故重整化能级 $k+\frac{c_2}{2}=k+2$，前后自洽。
3. **(3.28) 的 $d=24$**：$d=\dim\mathrm{SU}(5)=24$，标架变换相位 $e^{2\pi isd/24}=e^{2\pi is}=1$，标架依赖确实整体消失。
4. **p.11 "correponding"**：文本提取如此，回图实为 "corresponding"，非笔误（未加批注）。

2. **建议人工复核的 3 处**（均已批注、未改正文）：
