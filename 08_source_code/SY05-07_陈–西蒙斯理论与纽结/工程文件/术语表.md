# 术语表与符号表（Chern–Simons Theory in a Knotshell 中译本）

本表是译本的**唯一术语裁决书**。正文用词一律以此为准；若读者发现正文与下表不一致，以正文为准并请告知译者。

## 一、符号表（沿用原文，不做「统一」）

| 记号 | 含义 | 约定与禁区 |
|---|---|---|
| $M$ | 3 维时空流形 | 与模空间 $\mathcal{M}$、黎曼面 $\Sigma$ 区分 |
| $\Sigma$ | 2 维黎曼面 | $M=\Sigma\times\R$ 中只看 $\Sigma$ |
| $G,\ \mathfrak{g}$ | 规范群、其李代数 | 群用正体 $G$，代数用哥特体 $\mathfrak{g}$ |
| $A=A_\mu\dd x^\mu$ | 联络（规范场） | $\mathfrak{g}$ 值 1-形式；也叫主联络 |
| $F$ | 曲率（场强） | $F=\dd A+A\wedge A$；平坦联络即 $F=0$ |
| $k$ | 陈–西蒙斯能级（level） | 量子化后 $k\in\Z$；注意 §5 中 $q$ 用 $k+N$ 修正 |
| $D_\mu=\partial_\mu+[A_\mu,\cdot]$ | 协变导数 | 非阿贝尔时含李括号；平坦背景下记 $D$ |
| $\varepsilon^{\mu\nu\rho}$ | 全反对称符号 | **约定 $\varepsilon^{012}=+1$**；(2.6) 的 $\rho=\frac{k}{2\pi}B$ 以此为准 |
| $\varepsilon^{ij}$ | 空间全反对称符号 | 2 维：$\varepsilon^{12}=+1$，且 $\varepsilon^{ij}=\varepsilon_{ij}$ |
| $\delta^{(2)},\delta^{(3)}$ | 狄拉克 δ 函数 | 复坐标下的 $\delta(z-w)$ 归一化另有约定，见译注（(2.24) 处） |
| $\star$ | 霍奇星算子 | $\star F$ 为 1-形式 |
| $\Tr$ | 迹 | 取 $\mathfrak{g}$ 的基灵型的一个倍数；$\mathrm{SU}(N)$ 基础表示取 $\Tr(T^aT^b)=\delta^{ab}/2$ |
| $\Omega^k(M)$ | $k$ 次微分形式空间 | |
| $H^n_{\mathrm{dR}}(M,E)$ | 平坦丛 $E$ 上的德拉姆上同调 | 由 $D\circ D=0$ 定义 |
| $W_R[\gamma]$ | 表示 $R$ 中的威尔逊圈 | 路径有序指数之迹；阿贝尔时退化 |
| $\Phi[\gamma_1,\gamma_2]$ | 高斯环绕积分／环绕数 | 含 $1/4\pi$ 归一化，取整数值 |
| $\Phi_s[\gamma]$ | 自环绕数 | 依赖标架，$\Phi_s\to\Phi_s+t$ |

| $\Delta$ | 拉普拉斯算子 $\star D\star D$ | 鬼场动能算子 |
| $L=\star D+D\star$，$L_\pm$ | 类狄拉克算子及其分次部分 | $L_+$ 守 $\Omega^0\oplus\Omega^2$，$L_-$ 守 $\Omega^1\oplus\Omega^3$ |
| $T_\alpha$ | 雷–辛格挠率 | 行列式之比 $|\det\Delta/\sqrt{\det L_-}|$ |
| $c_2(G)$ | 二次卡西米尔（**本文等于 $2h^\vee$**） | $\mathrm{SU}(2)$ 取 $4$，故重整化能级 $k+\frac{c_2}{2}=k+2$ |
| $d$ | $\dim G$ | 标架变换相位 $e^{2\pi isd/24}$；$\mathrm{SU}(5)$ 时 $d=24$ |

| $\mathcal{Z},\mathcal{Z}(M,L)$ | 配分函数／带链环的配分函数 | 与生成泛函 $\mathcal{Z}[J]$ 同字母，靠参数区分 |
| $\mathcal{C}[g]$ | 引力抵消项 $\frac{dI[g]}{24}$ | 花体 |

## 四、译名裁定记录（易混点）

1. **holonomy = 和乐**，不用「完整群」「全纯」；和乐群 = holonomy group。
2. **framing = 标架化**（动作/性质），**标架**（对象）。不用「框架」以免与 frame 混淆；标架反常 = framing anomaly。
3. **level = 能级**（CS level）。不用「水平」——后者在中文里易作形容词。
4. **linking number = 环绕数**，**winding number = 绕数**。两者不可互换：前者是两曲线互绕（整数值 $\Phi$），后者是映射 $S^1\to U(1)$／$S^3\to G$ 的同伦类。
5. **torsion = 挠率**（Ray–Singer torsion 雷–辛格挠率）；不译「扭转」——扭转留给 twist。
6. **skein relation 保留英文**：中文文献「绞结关系」「拆接关系」并用，无统一名，按用户手册第 2.1 节保留英文。
7. **Chern–Simons 用半角连字符双写 `--`**（LaTeX 中破折号），不写成「陈-西蒙斯」「Chern-Simons」。
8. **模空间 $\mathcal{M}$ 与流形 $M$** 必须用花体/正体区分；原文在 §3.2 用 $\mathcal{M}$ 表示平坦联络模空间。
9. **$g$ 三重身份**：度规、群元、亏格（见正文 §1 译注 7）。读到 $g$ 先判身份。
10. **$q$ 的两个定义**：$q=e^{2\pi i/k}$（树图/阿贝尔类比）与 $q=e^{2\pi i/(k+N)}$（$\mathrm{SU}(N)$ 精确值）。原文自己更正，译文保留层次。
