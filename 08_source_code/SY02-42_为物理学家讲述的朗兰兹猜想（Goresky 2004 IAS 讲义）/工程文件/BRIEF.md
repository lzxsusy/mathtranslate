## 1. 底本性质与选题理由

底本是一份**面向物理学家**的朗兰兹猜想导读，不是研究论文：

- 它从 $\GL(n,\bbQ)$ 的原始猜想陈述出发（§2），先把「域」这一层全部铺开（§3：有限域、数域、局部函数域、$p$ 进域、整体函数域、高维域），
- 再分别把两侧的机器讲清楚：Galois 侧是平展上同调与 Frobenius 特征值（§4），自守侧是模形式、Hecke 算子与 Hecke 特征形式（§5），
- 然后在§6 用平代环把自守侧整体改写成「自守表示 + Satake 参数」，
- §7 说明 $n=2$ 为什么能行（Eichler–Shimura 与上同调分解），$n\ge3$ 为什么不行（Shimura 簇不存在），
- §8 给出一般形式并**停在标题**上——六节正文全空，其中一节正是「Geometric Langlands」。

选定理由：仓库 `04_playbook/20_朗兰兹纲领文献补遗_2026-11.md` 的 C 类缺口是「几何 Langlands 入口」，
而本库已译的 SY02-40（Sandvik）、SY02-38（Anschütz）、SY99-04（Raskin）、SY02-16（算术与几何朗兰兹纲领）
都假定读者已经知道「两侧分别是什么」。
本文恰好是**从零到一的那一层**：它把「哪一侧是什么、为什么需要平代环、$n=2$ 为什么能做成」讲完，
最后两页把话头交给几何版本。作为导引性文献，它的价值不在深度，而在**顺序**。

## 3. 五步逻辑链

1. **陈述**（§2）：给每个 $\Gal(\Qbar/\bbQ)$ 的 $n$ 维表示配一个自守表示，使两边的 $L$ 函数相等。
2. **铺地基**（§3）：把「域」这一层列清楚——同一个猜想在数域、$p$ 进域、函数域上是什么意思。
3. **造左侧**（§4）：$Y$ 上平展上同调 + Frobenius 作用 = 一个 Galois 表示，它的特征值编码在 $\zeta(Y,s)$ 里。
4. **造右侧**（§5–§6）：模形式 $\to$ Hecke 特征形式 $\to$ 自守表示 $\to$ Satake 参数（Hecke 特征值）。
5. **对照**（§7–§8）：$n=2$ 用 Shimura 簇的上同调分解做成（7.1.1）；$n\ge3$ 因 Shimura 簇不存在而失效；出路是换群、换域、换范畴（§8，正文空）。
