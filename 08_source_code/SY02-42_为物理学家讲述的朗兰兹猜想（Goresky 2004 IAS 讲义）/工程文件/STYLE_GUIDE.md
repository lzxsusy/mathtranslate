# STYLE_GUIDE —— SY02-42 为物理学家讲述的朗兰兹猜想

> 本文件只管**这一篇**的文体与体例。与 `04_playbook/01_数学文献翻译纪律.md` 冲突时，以 playbook 为准。

## 1. 底本的文体特征

Goresky 这篇是**讲义体的综述**，不是研究论文：

- 句子短、断句密，大量「换句话说」「于是」「不难验证」；
- 定义不编号，只有公式编号（14 条）与尾注（28 条）；
- 作者会在正文里直接说「这里略过」「这是 work in progress」——这类自述**必须照译**，不能替作者补完；
- 末尾有大段留白的节（§7.3、§8.2–8.7），是这篇文章的结构特征，不是排版事故。

译文的语气目标：**像一位数学家在黑板上边写边讲**，不是像教材。允许「我们」「不妨」「注意」这类口语连接。

## 2. 逐句译，不并句

- 原文一句 → 译文一句。原文用分号断开的长句，译文也用分号，不合并成一句长中文。
- 中文单句超过 60–70 字必须断句（playbook §语言纪律）。
- 禁用「被……所……」「对……进行……的讨论」「有着……的特点」这类翻译腔。
- 英文人名、缩写与汉字之间留半角空格：`Hecke 算子`、`Satake 参数`、`Frobenius 元素`、`$\GL(n)$ 的`。

## 3. 编号：一律照原文，不重排

| 类型 | 记法 | 例 |
| --- | --- | --- |
| 公式 | 原文编号原样，用 `\tag{}` 手工写 | (2.0.1)、(4.4.1)、(6.1.1)、(8.7.2) |
| 节 | `\section`/`\subsection` 跟随原文层级；原文无标题的小节用空标题 | §8.1 只有编号没有标题 |
| 尾注 | `\en{n}` → 文末「注释」列表，编号 1–28 与原文一致 | 注 6、注 25 |
| 参考文献 | 照录 22 条，方括号标签不改 | [AcRi] 之类不改写 |

**不改**原文的公式编号、节编号、文献标签——这是下游对齐卡（`资料卡/03-条款索引.md`）的锚点。

## 4. 术语

以 `工程文件/work/glossary.tsv` 为准。三条最容易错的：

1. **adele** → 平代环（不是「阿代尔」「阿黛尔环」）；
2. **cuspidal** → 尖点的；**cusp form** → 尖点形式（不译「尖形式」）；
3. **étale cohomology** → 平展上同调（不译「艾达尔上同调」）。

人名一律不译：Hecke、Satake、Frobenius、Eichler–Shimura、Baily–Borel、Langlands、Jacquet–Langlands、Deligne。

## 5. 两种框

### 5.1 译注（橙框 `yizhu`）

用途只有四类：

1. **术语背景**：这个词在这里是什么意思、为什么这样译；
2. **原文疑误**：原文写错了什么、按什么改的；
3. **原文空缺**：这一节没有正文，本该讲什么（**必须标注「译者按」并说明无原文依据**）；
4. **原文含糊**：同一符号两义、引证标记与公式号混淆之类。

每条译注标题格式：`译注 n —— 类别：一句话`。正文先引原文，再给解释，最后一句写清「读者该带走什么」。
**没有 A/B 级来源支撑的内容，一律写成「译者按（上下文推断，无外部依据）」。**

### 5.2 本节重点（蓝框 `keytakeaways`）

每节末尾一条，只回答「这一节在整个论证里负责什么」。三到五句，不重复正文，不引入新事实。

## 6. 公式与记号

- 与原文同一套记号：$\bbA$ 平代环、$\he$ 上半平面、$\Qbar$ 代数闭包、$\Ql$ $\ell$ 进数、$\Fr_p$ Frobenius。
- 原文用 $\sigma_p$ 与 $\Fr_p$ 混称 Frobenius，译文统一为「Frobenius 元素 $\Fr_p$」，首次出现时用 `（原文记作 $\sigma_p$）` 注明。
- 平展上同调写成 $H^i_{\et}(Y,\Ql)$；$\bbC$ 系数版本写 $H^i(Y(\bbC),\bbQ)$，两者不混。
- 「$\ell\neq\char(E)$」这类条件照译，不省略。

## 7. 排版

- A4，左右边距 2.6 cm，字号 10.5 pt（ctex `fontset=windows`）。
- 公式用 `equation*` + `\tag{}`，不用自动编号（否则编号会漂）。
- 目录与书签用 hyperref `colorlinks=true`，链接色 `blue!60!black`。
- 页眉左侧为节名，右侧为页码；「注释」「参考文献」两节另设页眉。

## 9. 本次翻译的三个决定

1. **尾注照录为文末「注释」**，不用 `\footnote`——因为原文注释是 1–28 连续编号，且注 6、注 25 很长，用脚注会挤爆版面。
2. **§7.3 与 §8.2–8.7 的空节保留标题 + 一条译注**，不代拟正文。这是本文最有信息量的地方之一：作者自己标出了缺口在哪。
3. **原文的 `\en{n}` 全部保留为上标**，读者可以随时跳到底部注释，不改变原文的阅读节奏。
