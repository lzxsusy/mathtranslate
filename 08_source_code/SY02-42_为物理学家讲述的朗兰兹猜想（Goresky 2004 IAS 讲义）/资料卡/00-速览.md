# 00 速览 —— SY02-42 为物理学家讲述的朗兰兹猜想

## 一句话

Goresky 在 I.A.S. 给物理学家讲的五次课，会后扩写成 20 页；它按「域 → Galois 侧 → 自守侧 → 对照 → 推广」五步，
把朗兰兹猜想里每个词讲清楚，最后用两页把话头交给几何版本——而这两页的正文是空的。
