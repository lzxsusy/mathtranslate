## 三条硬约束

1. **数据类型必须一致**：两侧都是「每个素数给一个无序 $n$ 元组」，不是矩阵、不是有序组。
2. **非分歧是前提**：$\Fr_p$ 与 Satake 参数都只在非分歧处有定义；有限个分歧素数要另设局部因子。
3. **几何载体只在 $n=2$ 存在**：$\GL(n,\bbR)$ 的对称空间是 Hermitian 的当且仅当 $n=2$；这决定了 §7 的成败。

## 为什么 $n=2$ 能成、$n\ge3$ 不能

```
n=2:  GL(2,R)/(O(2)·R>0) = 上半平面  ── 一维复流形 ──► 模曲线 X（代数曲线）
                                                            │
                                              H^1_ét(X, Q_l) 秩 2 ──► 2 维 Galois 表示 ✔

n=3:  GL(3,R)/(O(3)·R>0) 维数 3，总维数 5  ── 非 Hermitian ──► 不是代数簇
                                                            │
                                              没有 H^1_ét，路线断 ✘
```
