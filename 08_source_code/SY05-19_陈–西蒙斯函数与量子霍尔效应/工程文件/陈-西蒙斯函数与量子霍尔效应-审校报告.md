   无中文全角标点（已用脚本全篇扫描，0 例）。

   `keytakeaways` 环境（原子盒，不会被分页切开，也不与节标题拆散）；表格三线、书眉无、页码居中。
5. **可编辑性**：源码分区注释（`% ==== 第 N 节 ====`），宏定义集中在导言区
