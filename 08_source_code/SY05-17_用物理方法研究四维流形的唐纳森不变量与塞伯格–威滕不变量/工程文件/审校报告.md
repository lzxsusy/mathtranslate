## 一、工作流与核验方法

本次翻译按"先读懂、再动笔、后核验"三阶段进行，不采用任何机器翻译中间产物。

**1. 文字层与版面层双轨取材。**
PDF 由 pdfTeX 生成，文字层可提取（183,715 字符），但 pdfTeX 的数学排版把所有公式拆成
"每行一个符号"的碎片（例如 `∫`、`X`、`αβ`、`(1.2)` 各占一行），**直接依文字层转写必然
导致公式错位**。因此凡是公式，一律以 132 dpi 页面位图（`pages/pageNNN.png`）逐符号核对，
文字层只用于散文段落。这一点是全部核验工作的基础。

**2. 公式编号逐条对账。**
原文共 **316 条**编号公式，译本保留 **316 条**，逐条用 `\tag{}` 复现原编号（不重新编号，
以保证与原文及文献可对照）。分节核对结果：

## 四、译者批注（Tutor Note）分布

译本在源码中插入 **151 条** `% [Tutor Note: …]` 批注（不进入排版结果），按性质分三类：

- **【易错】** 符号约定陷阱。例如：Berezinian 测度的次序因子 $(-1)^{n(n-1)/2}$；
  $Q=\psi^i\partial_i+H_a\partial_{\chi_a}$ 作为**左分次导子**时 $Q(\chi s)$ 的符号；
  $F^+$ 是否带 $1/2$ 因子（(1.11) 与 (1.31)、(4.70) 的口径差异）；$\epsilon^{AB}$ 的缩并方向；
  Hodge 星号在 $b_2^+=1$ 时对 $\lambda_\pm$ 分解的依赖。
- **【省略】** 作者以 "it is obvious / one can show / straightforward" 跳过的论证。例如：
  §3.4 (3.40) 与 §3.3 Thom 同构的逐项对应（含 Whitney 和
  $\mathrm{Eul}(E)=\mathrm{Eul}(TM)\mathrm{Eul}(\mathrm{Coker})$）；
  §4.3.2 "虚拟维数 = 鬼数反常"的等价性；§5.7.1 $E(u),P(u)$ 全纯性论证的物理来源
  （R-对称性反常 + $u$ 平面单值性，以及 $\alpha,\beta$ 只能由穿墙/爆破公式定出）；
  §7.3 (7.16) 之后绝对收敛性与 $\lambda_+=0$（阿贝尔瞬子）导致的发散；
  附录 D 的 Gysin 序列论证（$H^k(BG)\to H^{k+4}(BG)$ 被零夹住 ⇒ $BG$ 上同调四重周期，
  而 $(\mathbb{Z}_2)^n$ 不周期）。
- **【约定/呼应】** 术语与记号的前后一致性。例如 §1.2 的扭子 $\Gamma_w$ 如何决定 §4.7.2 的
  自旋$^c$ 结构求和；§5.4.2 的 $\mathbb{Z}_2$ 对称性 $u\to-u,\ a\to ia$ 如何给出 (9.1) 第二支
  及其相对相位 $i^{\chi_h}$；(6.1) 的 $\mathrm{d}u/\mathrm{d}a_d$ 与 (5.38) 的 $\mathrm{d}u/\mathrm{d}a$
  分属**不同对偶标架**，绝不可混用。

每条批注都放在其所批注段落的正上方，便于在 `.tex` 源码中对照阅读与修改。

   生成重复锚点。已在导言区设 `hypertexnames=false` 消除警告，链接功能正常，但
