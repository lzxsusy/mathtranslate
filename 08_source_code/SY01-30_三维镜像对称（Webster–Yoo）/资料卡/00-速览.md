# 00 速览：三维镜像对称

## 一句话

三维 $\mathcal N=4$ 超对称规范理论的**希格斯分支**与**库仑分支**互为镜像；Webster 与 Yoo 用「辛对偶」把这条物理对偶翻译成辛奇点及其消解的数学命题，并说明库仑分支一侧应理解为 BFN 空间上的同调代数。

## 三条主线

1. **物理侧**：三维 $\mathcal N=4$ 理论的低能物理只由两个辛簇决定——希格斯分支 $\mathfrak M_{\mathrm B}$ 与库仑分支 $\mathfrak M_{\mathrm A}$；镜像对称说 $\mathfrak M_{\mathrm A}(\mathcal T)\cong\mathfrak M_{\mathrm B}(\mathcal T^\vee)$，且这一对偶来自 4d $\mathcal N=2$ 理论的 $S$ 对偶在 3d 的约化。
2. **数学侧**：希格斯分支有具体构造（$T^*N$ 的超凯勒商），库仑分支没有——本文采纳 BFN 的答案：库仑分支是 BFN 空间的 $\operatorname{Spec}$，其坐标环是 BFN 空间的 Borel–Moore 同调（定义 3.5–3.6）。
3. **对偶的可检验形式**：在阿贝尔/超环面情形给出定理 3.7（$\mathfrak M_{\mathrm A}(T^*\mathbb C^n,G)\cong\mathfrak M_{\mathrm B}(T^*\mathbb C^n,{}^LF)$）；在 ADE 箭图情形给出命题 3.8（库仑分支 = 仿射 Grassmann 流形中横截切片）；§4 列出五条可继续推进的方向（稳定包络、范畴 $\mathcal O$ 的 Koszul 对偶、线算子、Langlands、Betti 版本）。
