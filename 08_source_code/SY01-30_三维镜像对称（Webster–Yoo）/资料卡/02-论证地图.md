# 资料卡 · 02 论证地图

**一句话结构**：三维 $\mathcal N=4$ 超对称规范理论有 A、B 两种拓扑扭转；取扭转后理论的边界代数，得 $\mathfrak A_A(T)$ 与 $\mathfrak A_B(T)$，取谱即得两个真空模空间 $\mathfrak M_A$（库仑分支，A 扭转侧）与 $\mathfrak M_B$（希格斯分支，B 扭转侧）；「三维镜像对称」断言 $\mathfrak M_A(T)\cong\mathfrak M_B(T^\vee)$。全文把这句话拆成两半落地——$\mathfrak M_B$ 写成全纯辛商（定义 3.1），$\mathfrak M_A$ 写成 BFN 空间上的 Borel–Moore 同调（定义 3.5–3.6）——在阿贝尔情形证明它（定理 3.7），再用超环面簇、箭图规范理论、Slodowy 切片等例子把它坐实（例 3.2–3.4、3.9–3.11、命题 3.8），最后给出五个进阶方向（§4）。

## 二、逐节要点

### §1 引言：辛奇点之屋（原文 p3–7 / 译本 p.3–7）

- **1.1（p3–4 / p.3–4）** 摆出贯穿全文的一对样例：$X_n^{(A)}=T^*\mathbb{CP}^{n-1}$（$M^{\mathrm{rk}\le1}_{n\times n}$ 的辛消解）与 $X_n^{(B)}=\mathbb{C}^2/(\mathbb{Z}/n)$（crepant 消解）。两者互为「辛对偶」，证据是四条巧合（原文以 1.–4. 手工列出，未用计数器）：(i) 各自的参数空间与对方消解的二阶上同调对偶；(ii) 环面不动点个数相同（$n$）；(iii) 分层块数相同（2）；(iv) 两边的范畴 $\mathcal O$ 互为 Koszul 对偶。
- **1.2（p4–7 / p.4–7）** 逐节路线图；正文以**问题 1.1（p6 / p.5）**收束：是否存在统一原理解释这四条巧合？这就是「辛对偶」一词的由来，也是全文的动机。
- 结构上，§1 只给现象与问题，不给定义；真正的数学机器在 §2（物理）与 §3（两个分支的构造）。

### §2 物理起源（原文 p7–12 / 译本 p.7–11）

- **2.1 量子场论（p7–9 / p.7–8）** 先把 QFT 的语言摆好：场、局部算子、态–算子对应，为后面「把理论扭转化成 TQFT」做铺垫；**例 2.1（p8 / p.7）** 用自由标量场（时空 $(M,g)$、场空间 $C^\infty(M)$、作用量 $\int\varphi\Delta_g\varphi$）演示这套语言——点 $x$ 处的局部算子就是「在 $x$ 取值」，而 Laplacian 扮演哈密顿量。
- **2.2 拓扑量子场论（p9–10 / p.8–9）** Atiyah–Segal 函子；$Z(S^{d-1})$ 是交换代数，故有**真空模空间** $\mathfrak M=\operatorname{Spec}Z(S^{d-1})$；态–算子对应把「局部算子」变成「边界条件」。
- **2.3 从量子场论到拓扑量子场论（p10–11 / p.9–10）** 拓扑扭转把超对称代数里的一个超荷变成标量且幂零，得到拓扑理论。可扭转的条件：$d=3$ 需 $n\ge4$，$d=2$ 需 $n_\pm\ge2$；三维 $\mathcal N=4$ 恰好给出**两个**扭转 $Q_A,Q_B$——这正是「A 模型 / B 模型」在三维的来源。**例 2.2（p10 / p.9）** 写出 $d=3$（$\mathcal N=k$）与 $d=2$ 的超对称代数，奇部为 $S\otimes W$（$S\cong\mathbb C^2$ 为自旋表示），并给出超李括号。
- **2.4 镜像对称（p11–12 / p.10–11）** 先回顾二维镜像：两个 sigma 模型的 A/B 模型互换（$X\leftrightarrow X^\vee$）。三维版本：把柱体 $S^1\times\mathbb R^2$ 上的边界条件代数记为 $\mathfrak A_{A/B}(T)=Z^T_{A/B}(S^2)$，于是 $\mathfrak M_A=\operatorname{Spec}Z_A(S^2)$（库仑分支）、$\mathfrak M_B=\operatorname{Spec}Z_B(S^2)$（希格斯分支）；**镜像对称就是 $\mathfrak M_A(T)\cong\mathfrak M_B(T^\vee)$**。这一句是全文的靶心。
- **2.5「Future Direction」（原文不印）** 源文件把整节（含小节标题、`\phil` 批注、extended TQFT 与 $k$-范畴的讨论、A/B 模型已知–未知对照表、四条 bullet）全部包在 `\maybelater{…}`（宏体为空）里，从「`To extract any nontrivial content…`」那一段起、到 `\end{itemize}}` 才闭合 → **原文 PDF 中一个字符都不出现**，译本亦不译。原文 §2.4 的末句「3d mirror symmetry is also known to respect topological twists…」即 §2 的终点。

### §3 希格斯分支与库仑分支（原文 p12–19 / 译本 p.11–18）

§3 开篇（p12 / p.11）先给出柱体 $\mathrm{Cyl}_\delta$ 上两类边界条件的函子式刻画，作为定义 3.1 与 3.5 的共同出发点：

- **(fns:A)**：侧面局部常值、上下底面**全纯**的映射空间上的**局部常值**函数代数（A 模型侧）；
- **(fns:B)**：侧面局部常值、上下底面**局部常值**的映射空间上的**全纯**函数代数（B 模型侧）。

- **3.1 希格斯分支（B 模型侧，p13–15 / p.12–15）**
  - **定义 3.1（p13 / p.12）**：$\mathfrak A_B(X,G)=Z_B(S^2)=\mathbb C[\mu^{-1}(0)]^G$，$\mathfrak M_B=\operatorname{Spec}$。即**全纯辛商**：$\mu^{-1}(0)$ 中的闭 $G$-轨道 ↔ 模空间中的点。
  - **例 3.2（p13 / p.13）** 标量 $\mathbb C^\times$ 作用：$\mathfrak M_B(T^*\mathbb C^n,G)\cong M^{\mathrm{rk}\le1}_{n\times n}$（秩 ≤1 矩阵簇）。
  - **例 3.3（p14 / p.13）** 行列式为 1 的对角子群：$\mathfrak M_B\cong\mathbb C^2/\mathbb Z_n$，其 crepant 消解正是 $T^*\mathbb{CP}^{n-1}$——与 §1.1 的样例接上。
  - **例 3.4（p15 / p.14）** 单顶点箭图（$v\leftarrow w$）：$\mathfrak M_B\cong\{C\in M_{w\times w}(\mathbb C):C^2=0,\ \operatorname{rk}C\le v\}$。
  - **3.1.1 阿贝尔 / 超环面规范理论（p13 / p.12）**：$G=(\mathbb C^\times)^k$ 作用于 $T^*\mathbb C^n$，辛商 $\mu^{-1}(0)/\!/G$ 即**超环面簇**（环面超凯勒簇）；其辛消解＝取 GIT 稳定点再商掉剩余环面。
  - **3.1.2 箭图规范理论（p14 / p.13）**：$N=\operatorname{Hom}(\mathbb C^v,\mathbb C^w)\oplus\operatorname{Hom}(\mathbb C^w,\mathbb C^v)$、$G=\mathrm{GL}(v)$，得 Nakajima 箭图簇；文中用 E1.、E2. 两个箭图分别给出幂零锥 $\mathcal N$ 与 $\operatorname{Sym}^n\mathbb C^2$（Hilbert 概形 / Springer 消解的语境，p15）。
- **3.2 库仑分支（A 模型侧，p15–19 / p.15–18）**
  - **定义 3.5（p16 / p.15）**：BFN 空间
    $$R_{G,N}=\{(n_+,n_-,g_\pm)\mid g_\pm n_-(t)=n_+(t)\}/\big(G[[t]]\times G[[t]]\big),$$
    其中 $n_\pm\in N(\!(t^{\pm1})\!)$、$g_\pm\in G(\!(t^{\pm1})\!)$。
  - **定义 3.6（p16 / p.15）**：$\mathfrak A_A(T^*N,G):=H_*^{BM}(R_{G,N})$（Borel–Moore 同调，带等变结构），$\mathfrak M_A=\operatorname{Spec}$。
  - **定理 3.7（p17 / p.16）**：阿贝尔情形（$G\subset D$ 为对角环面的子群，$F=D/G$）
    $$\mathfrak M_{A/B}(T^*\mathbb C^n,G)\cong\mathfrak M_{B/A}(T^*\mathbb C^n,{}^L F),$$
    即库仑分支与希格斯分支在 Langlands 对偶环面 ${}^LF$ 下互换——这是全文的核心定理（对任意阿贝尔 $G$ 成立）。
  - **3.2.1 阿贝尔（p16 / p.15）**：BFN 空间的显式计算，定理 3.7 的技术背景。
  - **3.2.2 箭图（p17–19 / p.17–18）**：**命题 3.8（p17 / p.17）**——ADE 箭图规范理论的库仑分支同构于仿射 Grassmann 中 $\overline{\mathrm{Gr}}^{\lambda}$ 内 $\overline{\mathrm{Gr}}^{\mu}$ 的一般点的横截切片（引自 [BFNplus, Thm 3.10]）；**例 3.9（p18 / p.17）** E1. 与 E2. 两个箭图都满足 $\mathfrak M_A\cong\mathfrak M_B$（作者明言这是偶然）；**例 3.10、3.11（p18 / p.17）** 一对互为镜像的超环面例（$\mathbb C^2/\mathbb Z_n$ 与 $M^{\mathrm{rk}\le1}$ 互换）；随后给出仿射 A 型好箭图理论的库仑分支＝另一仿射 A 型理论的希格斯分支（[nakajimaCherkisBow2017]），与已知 **rank-level 对偶**吻合，并说明 $T^*\mathrm{Gr}(w,v)$ 与 two-row Slodowy 切片的对应（p18–19 / p.17–18）。

### §4 进阶方向（原文 p19–22 / 译本 p.18–22）

- **4.1 稳定包络（p19–20 / p.19）** 用 Aganagić–Okounkov 的椭圆稳定包络把 $\mathfrak M_A$ 与 $\mathfrak M_B$ 的上同调/K-理论对上；核心猜想是存在 $\mathfrak M_A\times\mathfrak M_B$ 上的「Mother」类，其限制给出两边的稳定包络；FI 参数 ↔ 质量参数。译本译注 9（p.19）解释此概念。
- **4.2 范畴 O 的 Koszul 对偶（p20 / p.19–20）** 用 $\Omega$-背景做形变量子化，$\mathfrak A$ 的滤过给出范畴 $\mathcal O$；**猜想 4.1（p20 / p.20）**：镜像对的两个范畴 $\mathcal O$ 互为 Koszul 对偶。作者指出其**物理解释仍未知**（p20 / p.20）。
- **4.3 线算子（p20–21 / p.20–21）** 线算子代数 $Z(S^1)$：A 扭转一侧是 $N(\!(t)\!)/G(\!(t)\!)$ 上的 D-模，B 扭转一侧是小环路空间上的拟凝聚层；两者互为「Wilson ／ 't Hooft」型对偶（引 Hilburn–Raskin 的 $N=\mathbb C,\ G=\{1\}$ 情形）。
- **4.4 与四维场论及 Langlands 纲领的联系（p21 / p.21）** Kapustin–Witten 的 4d $\mathcal N=4$ S-对偶→3d 镜像；Elliott–Yoo 的箭图实现；Ben-Zvi–Sakellaridis–Venkatesh 的相对 Langlands。
- **4.5 Betti 三维镜像对称（p21–22 / p.21–22）** de Rham 版本依赖全纯/代数结构，Betti 版本只依赖拓扑，因此更「A 模型」；但作者说在 BFN 框架里**很难想象如何在库仑分支上构造所需的超凯勒度量**（p22 / p.22），纯拓扑的 **2-范畴** $Z(\mathrm{pt})$ 仍只是「理想情况下」的纲领（交换情形已有部分进展，p22 / p.22）。

## 四、论证的三个薄弱处 / 未解决处

1. **库仑分支的 Betti／纯拓扑构造仍是纲领**。A 模型侧的整个机器（定义 3.5–3.6）建立在 BFN 空间的 Borel–Moore 同调上，本质是 de Rham／代数式的表述；§4.5 把 Betti 版三维镜像对称明确写成 Teleman 提出的纲领（p21–22 / p.21–22），并承认在 BFN 框架中很难想象如何在库仑分支上构造所需的超凯勒度量（p22 / p.22）。也就是说，「A 侧」目前是用代数几何造的，纯拓扑版本还没有落地。
2. **2-范畴尚未构造，度量难题未解**。3d 镜像对称的本义应是边界条件 2-范畴的等价，而非仅仅两个真空模空间的一一对应；但作者只把它写成「理想情况下」的设定——给每个理论的 A/B 扭转各配一个 $Z(\operatorname{pt})$ 并猜想其等价（p22 / p.22），目前仅有交换情形的部分进展（Gammage–Hilburn–Mazel-Gee、Doan–Rezchikov）。同时，作者明言很难想象在库仑分支上构造所需的超凯勒度量（p22 / p.22）。因此定理 3.7 只是「点层面」的陈述。
3. **原文 §5 整节留白**。源文件 L890–903 的 `\section{Future directions}` 整节被包在作者自定义的空宏 `\maybelater{…}`（定义见源 L70：`\newcommand{\maybelater}[1]{}`）之内，编译后不出现；同样命运的是整个 §2.5（含小节标题、`\phil` 批注、全文讨论与「已知–未知」对照表，源 L451–485）。成品里读者看到的「未来方向」只有 §4 五小节，作者原本的路线图（含 Betti 库仑分支、2-范畴等）从未印出。
4. **附记（非用户指定的三条之外的存疑点）**：定理 3.7 只覆盖阿贝尔 $G$；非阿贝尔情形全文只有命题 3.8（ADE，且引自 [BFNplus]），没有一般的非阿贝尔镜像定理。§1.1 的四条「巧合」也只是现象归纳，问题 1.1 至今未答。
