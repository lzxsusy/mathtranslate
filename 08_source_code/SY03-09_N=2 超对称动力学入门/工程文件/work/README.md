## 三、编译方法

环境：**TeX Live 2026 + XeLaTeX + makeindex**。在交付包根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

`build.ps1` 把源码镜像到 ASCII 可写目录（`…\default-workspace\n2build`），依次运行
`xelatex → makeindex → xelatex ×2`，并把 `main.pdf` 与 `main.log` 拷回；日志会打印
file:line 错误 / `!` 错误 / Undefined / Missing character / Overfull 计数。

**字体要求（重要）**：原稿 `preamble.tex` 使用 Fandol（中文）与 **CMU Serif（`cmunrm.otf` 等）**。
TeX Live 默认不含 CM Unicode 字体，需安装 **cm-unicode** 包（CTAN `fonts/cm-unicode`），
把 `fonts/otf/*.otf` 放到 `texmf-dist/fonts/opentype/public/cm-unicode/` 后运行 `mktexlsr`；
本交付包即以此方式在本机验证（0 error / 0 missing character）。
若目标机器没有 cm-unicode，可改 `preamble.tex` 中 `cmunrm/cmunbx/cmunti/cmunbi` 为
`lmroman10-regular/bold/italic/bolditalic`（视觉几乎相同），并在 README 记录该替换。
`texglyphlist.txt` 必须与 `main.tex` 同目录（xdvipdfmx 的数学字形映射）。

## 四、译校体例与本次校对做了什么

**体例**（沿用原稿并统一）：
1. 公式编号由 `\numberwithin{equation}{subsection}` 自动生成，图/表编号按节；
   交叉引用统一 `\eqref{}`/`\ref{}`，不手写编号。
2. 中文标点：句号「。」、逗号「，」、分号「；」、引号「“”」、括号「（）」；**数学环境内部用英文标点**。
3. 术语按 `glossary.tsv` 冻结（库仑支、希格斯支、超多重态、预势、驯服穿孔……）；人名/模型名保留英文。
4. 原文笔误：正文照原文排，`% [Tutor Note: ...]` 给出正确形式与判断依据（不擅改原文结论）。

**本次校对的实际工作**（相对原草稿）：
1. **底本版本核查**：确认底本 PDF 是 arXiv **v2**；发现 arXiv 最新 e-print 是 **v3**（含 2018 年修订），
   两版在若干处有实质差异。本工程**一律以 v2 为准**，并把 v2 与 v3 的差异记录为「原文笔误/修订登记」
   （见 §五），避免把 v3 的修订误当成原稿错误。
2. **全稿标点归一**：把原稿中作汉语句号使用的半角「.」统一改为「。」（共 **2574 + 133 = 2707 处**），
   数学环境内的句点保持英文「.」；统一「Witten 指标」等术语写法。
3. **逐块内容校对**（Lead 2 块 + 7 位校对者 + 工程/QA 2 附录）：逐段对齐 v2 英文源码与页图，
   核查漏译/错译/公式逐符号/图表/脚注/`\cite`/术语/标点；改动与理由逐条记录在 `work/review/*.md`（交付包不含）。
4. **结构审计**：剥去源码注释与 `\if0…\fi` 恒假块后，草稿与 v2 原文逐块 1:1
   （section 16/16、subsection 57/57、equation 725/725、align 24/24、multline 8/8、figure 122/122、
   table 3/3、footnote 18/18、`\cite` 142/142、label 缺失 0/多余 0）。
5. **编译修复**：原稿因缺 CM Unicode 字体无法在本机编译（fontspec 报错、缺字）；补装字体后达到
   0 file:line 错误 / 0 Undefined / 0 Missing character / 0 Overfull。
6. **Tutor Note 增补**：校对过程中新增若干条批注（原文笔误、v2/v3 差异、易错点），汇总见 `译注汇总.md`。

**与读书笔记的关系**：`读书笔记/` 是独立文档（独立 PDF + 独立源码 + 独立 build.ps1），
内容是按全书结构重写的阅读笔记（关键公式、物理理解、问题清单、译名札记），与译注本分开交付。

## 七、已知偏差与限制

1. **底本版本**：本译本严格按 **v2**；对照 arXiv 最新 **v3** 时，§3.3.2、(11.5.10)/(11.5.11)、
   p.109 的 z=0 等处会看到差异——那是 v3 的修订，不是本译本错误。
2. **图**：原书 122 张矢量图直接以 `figures/*.pdf` 引用（图内文字不重排、不翻译）；
   图内使用的 Mathematica 字体等未随主文档嵌入（字体在主文档字体集之外，属正常）。
3. **参考文献**为英文原貌（学术惯例不译），条目数与 v2 源一致；不做逐条重排校对。
4. **索引**由原稿的 `\index{}` 条目 + makeindex 生成，条目翻译由原稿给出，本次仅核对编号与排序。
5. **校对深度**：为逐块人工对照 + 脚本审计，但**不是逐字重译**——未发现问题的句子保留原草稿措辞；
   「我们」与「作者」的叙述人称按原稿，未统一改写。
6. **英文括注**：重要术语在首次出现处视上下文括注英文，未强制每个术语都括注（与原文风格一致）。
7. **数学标点**：显示公式末尾的句点保留英文「.」（与原文排版一致），正文中文句末为「。」。
