## 一、页码体系

- **PDF 页号 = 原书印刷页码 + 20**（正文 p.1 = PDF 21，p.140 = PDF 160）。
- 卷首导论：PDF 5–20 = 罗马页 v–xx（PDF 5 = v，PDF 18 = xviii，PDF 19–20 = xix–xx 目次）。
- 页标记写法：正文 `% [原文 p.17]`；卷首先导 `% [原文 p.vii]`。
- 页眉页脚（`50——第1章`、`§1.2 … 11`）**不译**。

## 三、通用规则

1. 章标题只由该章第一个 chunk 写；节标题只由「该节起始页」所属 chunk 写。
2. 跨页/跨块句由「句子起始页」所属 chunk 写完；下一 chunk 从该句之后接续，不重写。
3. 块首若不是从新节开始，直接续写正文。
4. 页标记首尾相接，不允许重叠；空白页不写页标记。
5. 章末评注：第 1 章 tr04、第 2 章 tr08、第 3 章 tr05。
