## 1. 工作方法（每页的固定流程）

1. 读 `work\split\pNNN.txt`，把握本页论证结构与日文原文（用于定位与理解）。
2. **打开 `work\pages\pNNN.png`（read_image）逐页看图**：正文意思、公式的每个符号、上下标、花体、括号层级、图。
   - 文字层与页图冲突时，**以页图为准**。
   - 日文 OCR 的典型错误：`ー`→`一`、`入`→`人`、`基`→`墓`、`とと`→`こと`、`とこ`→`ここ`、`ノレープ`→`ループ`、`ミラ一`、`プレーミング`→`フレーミング`、`タンク’ル`→`タングル`；公式文本层基本是乱码（`鈭?`、`；；`）。
3. 用中文写译文，直接写入你的 chunk 文件（UTF-8 无 BOM，LF 换行）。
4. **每译完 3–5 页就落盘一次**（防止中途丢失）。
5. 全部完成后自检（§14），再向 Lead 回报（§15）。

> **绝对不要编译**。编译、页码编排、装配由 Lead 统一处理。
> 不要修改 `src\preamble.tex`、`src\main.tex`、`src\frontmatter\*`、别人的 chunk、`work\` 下的任何文件。

## 2. 页面标记（每页开头必须有）

每个原书页的起始处插一行注释：

```latex
% [原文 p.17]
```

（p.N 为原书印刷页码 = PDF 页号 − 20。卷首导论用 `% [原文 p.vii]` 这种罗马页码写法。）
图、长公式跨页时，标记移到下一页正文开始之前。

---

## 3. 章节标题

- 章标题：`\chapter{中文标题}`——**只有该章第一个 chunk 写**（ch01a / ch02a / ch03a），章标题译文见 BRIEF §3。
- 节标题：`\section{中文标题}`——只由**该节起始页所属的 chunk** 写；下一页续写的 chunk 不重复写。
- 原书的「要約」译作 `\section{小结}`（各章末）。
- 原书的「今後の方向と課題」译作 `\chapter{今后的方向与课题}`。
- **标题不加编号**（LaTeX 自动编号；`\chapter`/`\section` 的编号顺序必须与原书一致：3 章、15 节）。若发现编号对不上，报告 Lead。

---

## 4. 编号公式（最重要）

**每一个原书编号公式，必须有且只有一个 `\tag{原编号}`，编号一字不差。**

```latex
\begin{equation}
  \sigma=\frac{1}{24\pi^{2}}\Tr\left(X^{-1}\rd X\wedge X^{-1}\rd X\wedge X^{-1}\rd X\right) \tag{1.8}
\end{equation}
```

- 多行公式用 `align`/`gather`，每行一个 `\tag{...}`；一条编号跨多行时，`\tag` 放最后一行。
- 无编号公式用 `\[ ... \]` 或 `equation*`，**绝不自造编号**。
- 正文引用公式用纯文本「式 (1.8)」，**不要用** `\ref`/`\eqref`。
- 原书几条公式共用一个编号时，只写一次 `\tag`。
- **编号以页图为准**：`tags.txt` 是 OCR 自动统计，已知漏检 1.10、2.35、3.8（可能只是 OCR 没读到）。你看到页图上有编号而 `tags.txt` 里没有，**照样要写 `\tag`**；反之页图没有编号就绝不加 `\tag`。
- 公式太宽导致 Overfull 时，用
  `\begin{equation}\resizebox{0.96\textwidth}{!}{$\displaystyle ...$}\tag{X.Y}\end{equation}`。

## 5. 陈述环境（定义/定理/引理/命题/推论/例/注）

原书的陈述编号是**每章一个连续序列**（定義・定理・命題・系・補題・注意・例 共用），**一律手工抄原书编号**。

```latex
\begin{definition}{1.1}
  正文……
\end{definition}

\begin{proposition}{1.6}
  正文……
\end{proposition}

\begin{proof}
  证明正文……
\end{proof}
```

可用环境（第一个参数是原书编号）：

| 环境 | 显示 | 对应日文 |
|---|---|---|
| `definition` | 定义 | 定義 |
| `theorem` | 定理 | 定理 |
| `lemma` | 引理 | 補題 |
| `proposition` | 命题 | 命題 |
| `corollary` | 推论 | 系 |
| `example` | 例 | 例 |
| `remark` | 注 | 注意 |
| `problem` | 问题 | 問題 |
| `assumption` | 假设 | 仮定 |
| `notation` | 记号 | 記号 |
| `formulaenv` | 公式 | 公式 |

- `proof` 用法：`\begin{proof} ... \end{proof}`；原书「[証明]」的方括号不必保留。
- **陈述末尾的 □ / ■**：原书陈述末尾有 □ 的，用**不带星号**的环境（模板自动加 □）；若该陈述后面紧跟「証明」（原书此时没有 □），用**带星号**的环境：`theorem*`、`lemma*`、`proposition*`、`corollary*`（显示同样带编号，只是不加 □）。
- 没有编号的陈述用空参数：`\begin{remark}{}`，或直接用 `\para{小标题}` 的粗体段落。

## 6. 图

原书的图**全部是扫描页里的一部分**，必须自己从页图裁出来：

```powershell
$py = "<本地路径>"
& $py "<本地路径>" --page 72 --box 0.10,0.30,0.90,0.55 --dpi 400 --out "<本地路径>"
```

- `--box` 是页面**宽/高比例**（左,上,右,下）；整页 394×590 pt。先用 read_image 看 pNNN.png 估比例。
- **裁完必须 read_image 复核**：完整、不截断、不带相邻正文/图注残影；**图号（図X.Y）与图注不要裁进去**（图注由 `\figtitle` 排）。
- 正文写法：

```latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.6\textwidth]{figures/fig2.1.png}
  \figtitle{2.1}{辫群及其生成元（原书 p.52）}
\end{figure}
```

- 图号、图注按原书；图注译文末尾加「（原书 p.N）」。
- 一页里有 2 幅图时，可以并排：`\includegraphics[width=0.45\textwidth]{...}\hfill\includegraphics[width=0.45\textwidth]{...}`。
- **无法裁干净时**：可用 TikZ 重画（只限简单线图），或在正文保留 `\figtitle` 并加一条批注说明原图略去。优先裁图。

## 8. 批注（Tutor Note）

在需要提醒的段落**之后**单独一行：

```latex
% [Tutor Note: 这里的 $LG$ 指 $G$ 的环路群，与 $\mathfrak{g}$ 的仿射化 $L\mathfrak{g}$ 不是同一对象；作者未区分记号，初读易混。]
```

要求：

- 每 2–3 页至少 1 条，每节至少 3 条。**宁精勿滥**。
- 只写三类，且必须给具体信息：
  1. **易错预警**：符号约定、指标、次数、上下标、正负号、花体/正体、$\pi$ 因子与 $2\pi\sqrt{-1}$；
  2. **省略论证的点拨**：作者写「明らか」「容易に」而实际略去了什么、依据哪条定理；
  3. **背景直觉**：一两句几何/物理意义（点到为止）。
- 禁止空话（「很重要」「值得注意」）；禁止在注释里出现 `%` 字符（会截断注释）、不要写跨行公式。
- 原书疑似笔误：**正文照抄原书**，批注写「原书 p.N 作 X，与……不符，疑为笔误，正确形式应为 Y」；**不许悄悄改正文**。

## 9. 「本节重点」与「章末评注」

- **本节重点**（`\takeaway{...}`）：每个 `\section` 的开头（节标题之后、正文之前）一个，1–3 句、不超过约 120 字；必须给出**本节的核心对象/工具/结论**之一二，不写「本节介绍……」。由该节的译者写。
- **章末评注**（`\chapterreview{...}`）：每章末尾一个，约 600–1000 字，五段式：①全章地位 ②知识脉络 ③核心结论 ④辨析与提醒 ⑤评注。**只由 BRIEF §6 指定的 chunk 写**。
- 各章「小结」（原书要約）是**原书内容**，照译，不是我们加的评注。

## 10. 文字层可靠度（必须知道）

| 内容 | 可信度 |
|---|---|
| 正文单词、段落边界、章节标题、人名、文献编号 | 高（用于定位与抄录） |
| **公式、上下标、分式、矩阵、希腊字母、花体、括号层级** | **不可信，一律回页图逐符号抄** |
| 页眉页脚、页码 | 可用（`50——第1章` 之类） |

由此推论：**任何「原书笔误」的指控，都先用 400+ dpi 裁图复核原文**，确认后才写批注。

## 11. 语言（中文数学文风）

目标是「数学工作者的中文」，不是「日语语法的中文」。

- 一句一个逻辑重心，主谓早出现，修饰语短。
- **禁止**：`被……所……`、`进行……的讨论/计算`、`对于……而言`、`关于……的讨论`、`使得……得以……`、一逗到底、一句超过 70 汉字（公式列举句可到 90）。
- 连续三个「的」要拆；被动尽量改主动。
- 标点：中文全角（，。；：？！（）“”——）；英文术语/数字与汉字之间留**半角空格**（`辛流形 $M$`、`第 3 章`、`$k$-线性`）。
- **希腊字母与数学符号必须进数学模式**：写 `$\sigma$ 模型`、`$\omega$`、`$\mathfrak{g}$`，不许直接写 `σ`/`ω`/`g`（否则 PDF 缺字）。
- 日文「」引号译成中文“”；「、」按语义译成顿号或逗号；「・」译成「·」或去掉。
- 人名保留英文原形：Witten、Jones、Chern、Simons、Kontsevich、Vassiliev、Virasoro、Sugawara、Verlinde、Hecke、Kirby、Dehn、Heegaard、Riemann、Hilbert、Hermite、Möbius、Feynman、Grassmann。
- **允许**拆长句、调语序、补主语；**禁止**增删信息、改数学内容、把作者的「明らか」扩写成证明、删掉作者的评论性句子。

## 12. 术语（冻结）

- 以 `work\glossary.tsv` 为准，**不得擅自改译或自造中文名**。
- 保留英文的术语（KZ、Witten、Jones、tangle、framing、level、Hessian 等）按 glossary 的备注处理；首次出现处可括注中文通名。
- 遇到表里没有的新术语：用最通行的中文名，**在回执里登记**（日文→中文），由 Lead 统一裁决。
- 日文常见陷阱：

| 日文 | 不是 | 而是 |
|---|---|---|
| 体（代数学） | 体 | 域（field） |
| 束（fiber） | 层 | 丛（但 sheaf 语境才是「层」） |
| 補題 | 补题 | 引理 |
| 系 | 系 | 推论 |
| 注意 | 注意 | 注 |
| 要約 | 要约 | 小结 |
| 複素直線束 | 复直线束 | 复线丛 |
| 組みひも | 组绳 | 辫子 / 辫群 |
| タングル | 缠结 | tangle（保留英文） |
| プレーミング | 预绞 | 标架 / framing |
| レベル | 水平 | level（保留英文） |

## 13. 禁止事项（违反即返工）

1. 不编译；不改 `preamble.tex` / `main.tex` / `frontmatter` / 别人的 chunk / `work\` 下文件。
2. 不写 `\documentclass`、`\usepackage`、`\begin{document}`、`\newcommand`、`\label`、`\ref`、`\eqref`、`\cite`。
3. 不自造公式编号、陈述编号、图号；不重排编号。
4. 不在正文留整段未翻译日文（人名/术语原文除外）。
5. 不用 Markdown（`**粗体**`）；强调用 `\textbf{}`。
6. 不写全角空格 U+3000；UTF-8 无 BOM；LF。
7. 不把公式写成文字描述；不省略公式；不省略原书编号公式。
8. 不「修正」原书笔误（只写批注）。
9. 不在 `% [Tutor Note: ...]` 里写 `%`、不写跨行公式。
10. 不写 `\begin{center}` 包围整段正文；不手工画表格线。
