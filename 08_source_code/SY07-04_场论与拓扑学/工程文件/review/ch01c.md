## 6. 必须改 / 可选改

### 必须改（3 条，均在 `% [Tutor Note:]`，正文无误）

**M1｜第 50 行批注：$\iota_j(f)$ 的说法有误**
- 原文：`当 $f$ 是多项式（无极点）时各 $\iota_j(f)$ 都是零次项`
- 问题：无极点时 $\iota_j(f)$ 是只含**非负次项**的 Taylor 级数（一般有无穷多项，不是「只有零次项」）。另「同一点的不同展开彼此相容」也说得不对，$\iota$ 是把同一个 $f$ 在**不同点** $p_j$ 处分别展开。
- 建议改为：「当 $f$ 无极点时，各 $\iota_j(f)$ 只有非负次项；若对每个 $j$ 都有 $\iota_j(f)=0$，则 $f$ 在各 $p_j$ 附近恒为 $0$，由解析延拓的唯一性得 $f\equiv0$，$\iota$ 为单射。」

**M2｜第 204 行批注：符号与下标笔误**
- 原文：`$-2(k+1)$ 来自 $V_1$ 与 $d_1$ 的搭配，等价于 $d_1-\lambda_1=k+1$`
- 问题：① 式中是 $+2(k+1)$，不是 $-2(k+1)$；② 由 $d_1=k-\lambda_1+1$ 得的是 $d_1+\lambda_1=k+1$，不是 $d_1-\lambda_1=k+1$。
- 建议改为：「$+2(k+1)$ 来自 $V_{\lambda_1}$ 与 $d_1$ 的搭配，即 $d_1+\lambda_1=k+1$」。

**M3｜第 264 行批注：与图 1.2 实际不符**
- 原文：`图中箭头只标出“外侧 $n+1$ 条边”的指向`
- 核实：700 dpi 复核 p.33 图 1.2，**每条边都有箭头**（含内部边 λ、μ 与底部外侧边 λ₃、λ₄），并非只标外侧边。
- 建议改为：「图中每条边上的箭头只标出该边的定向（相对顶点的指向），不代表最高权的大小；真正约束每条边权的是三价顶点处的 level $k$ Clebsch–Gordan 条件……（后半句原样保留）」。

### 可选改（3 条，不影响正确性）

**O1｜第 201 行用词**：`若 $\lambda_1+\lambda_2+\lambda_3\le2k$，上述不等号恒成立` → 建议「上述不等式（即 $2(k+1)-(\lambda_1+\lambda_2+\lambda_3)+2(n_2+n_3)\ne0$）恒成立」。原书「上の不等号はつねに成立する」指的就是这个 ≠0，翻成「不等号」读者会找不到对象。
