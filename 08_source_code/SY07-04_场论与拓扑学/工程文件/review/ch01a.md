## 七、必须改（M，4 项）

### M1 ★ 最重要 — p.10 末行 Tutor Note 的数学错误 + 误判原书笔误

- **位置**：`ch01a.tex` L297（文件末条批注）
- **现状（原文照录）**：
  > `% [Tutor Note: 末句的 $H^{2}(LG,\Z)$ 疑为笔误：$LG$ 单连通（本节刚证），故 $H^{2}(LG,\Z)=0$；而式 (1.7) 的 $\omega$ 定义在 $\Lie(LG_{\C})$ 上，这里应为 $H^{2}(LG_{\C},\Z)\cong\Z$。正文照原书，未改。]`
- **原文（p.10 末，页图已复核）**：「実は，$H^{2}(LG,\Z)\cong\Z$ で，これは，(1.7) で定義される $\omega$ の de Rham コホモロジー類で生成されることが知られている。」
- **判据（批注错在哪）**：
  1. **「单连通 ⇒ $H^2=0$」是错的**。单连通只给出 $H_1=0$、$H^1=0$，对 $H^2$ 无约束（$S^2$ 即反例：单连通而 $H^2(S^2,\Z)=\Z$）。
  2. 实际计算：$LG\cong G\times\Omega G$（求值纤维化有截面，故平凡），$G=SU(2)$ 时 $H^2(G;\Z)=0$、$H^2(\Omega G;\Z)=\Hom\bigl(H_2(\Omega G),\Z\bigr)=\Hom(\pi_3(G),\Z)=\Z$（Hurewicz，$\Omega G$ 单连通），Künneth 的 Tor 项因 $H^1(G)=H^1(\Omega G)=0$ 消失，故
     $$H^{2}(LG;\Z)\cong\Z .$$
  3. 因此**原书没有笔误**，$H^2(LG,\Z)\cong\Z$ 是对的；而且本节前文（p.10 第 4 行）自己就说「$\omega_0$ の de Rham コホモロジー類は，$H^2(LG,\Z)$ の要素を定める」，末句与之一致（$\omega=\omega_0+d\beta$，同一个类）。
  4. 顺带：批注给出的「应为 $H^2(LG_\C,\Z)$」本身也是 $\Z$，但那是另一个群，不能用来「纠正」原书。
- **可直接替换的文本**（把 L297 整行替换为）：
  ```
  % [Tutor Note: $LG$ 单连通只保证 $H^{1}(LG,\Z)=0$，$H^{2}$ 一般不为零。事实上 $LG\cong G\times\Omega G$，故 $H^{2}(LG,\Z)\cong H^{2}(G,\Z)\oplus H^{2}(\Omega G,\Z)\cong 0\oplus\Hom(\pi_{3}(G),\Z)\cong\Z$，同理 $H^{2}(LG_{\C},\Z)\cong\Z$。末句把 (1.7) 的 $\omega$ 与其上同调类等同看待（本节已证 $\omega=\omega_{0}+d\beta$，$\omega_{0}$ 的类属 $H^{2}(LG,\Z)$），并非笔误。]
  ```
- **备注**：这是本次校对唯一的**实质性错误**。按 STYLE_GUIDE §8「原书疑似笔误」的流程，这条批注在**归因环节**就站不住（判据本身是伪命题），必须撤。若 tr01 想保留「$\omega$ 定义在 $\Lie(LG_\C)$ 上」这一提醒，可并入上面的替代表述。

- **位置**：`ch01a.tex` L17
- **现状**：「核心工具是由**二维上同调** $H^{2}(L\mathfrak{g},\mathbb{C})\cong\mathbb{C}$ 给出的 2-余循环」
- **问题**：$H^2$ 的 2 是**次数（degree）**，不是维数；且 $H^{2}(L\mathfrak{g},\mathbb{C})\cong\mathbb{C}$ 只有 **1** 维。「二维上同调」会被读成「2 维的上同调」，与后面的 $\cong\mathbb{C}$ 直接矛盾。本节正文（L80）用的是「$p$ 次上同调群」，正确。
- **可直接替换的文本**：
  ```
  \takeaway{本节从环路群 $LG$ 出发，造出环路代数 $L\mathfrak{g}$ 的中心扩张。核心工具是由 2 次上同调 $H^{2}(L\mathfrak{g},\mathbb{C})\cong\mathbb{C}$ 给出的 2-余循环；同一套余循环还给出仿射 Lie 代数、Virasoro 代数以及 $LG_{\mathbb{C}}$ 上的基本复线丛。}
  ```

### M4 — p.5「Cartan 部分代数の基底のひとつ $H$」误译为「一个基」

- **位置**：`ch01a.tex` L136
- **原文（p.5）**：「$\mathfrak{g}$ の Cartan 部分代数の**基底のひとつ** $H$ をとると」
- **现状**：「取 $\mathfrak{g}$ 的 Cartan 子代数的一个**基** $H$」——「基底のひとつ」是「基中的**一个元素**」，不是「一组基」。基是集合，$H$ 是单个元素，说「一个基 $H$」在数学上讲不通。
- **可直接替换的文本**：把
  ```
  取 $\mathfrak{g}$ 的 Cartan 子代数的一个基 $H$
  ```
  改为
  ```
  取 $\mathfrak{g}$ 的 Cartan 子代数的一个基元 $H$
  ```
  （若嫌「基元」生僻，可用「取 $\mathfrak{g}$ 的 Cartan 子代数的一组基中的一个元素 $H$」。）
