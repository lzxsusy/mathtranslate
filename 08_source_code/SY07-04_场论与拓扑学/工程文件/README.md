## 施工标准（必读，每次按此执行）

本项目（含后续补译、校订、译注重写）一律按《数学文献翻译纪律》**v2.0** 执行——**它是硬标准，不是参考资料**：

## 三、编译方法

本机实测的硬约束（**换机器需重测**）：LuaLaTeX 在本机无法写非 ASCII 路径与 Desktop 的 `.log`，因此 `build.ps1` 采用「**镜像编译**」：

```powershell
# 在项目根执行；脚本会把 src/ 与 figures/ 复制到 default-workspace\kohnobuild 再编译，最后把 PDF 拷回
powershell -ExecutionPolicy Bypass -File build.ps1
# 只编译单块（草稿自检）：
powershell -ExecutionPolicy Bypass -File build.ps1 -Chunk ch01a
```

- 引擎：LuaLaTeX（TeX Live 2026，`<本地路径>`）；
- 文档类：`ctexbook`，B5 纸，字体由 ctex 自动选用系统字体（无需 fontconfig / fontset）；
- 主要宏包：amsmath/amssymb/mathrsfs/bm、graphicx、xcolor、booktabs/array/multirow/longtable/multicol、enumitem、fancyhdr、caption、tcolorbox、tikz、hyperref；
- 编译 3 遍（目录/交叉引用稳定）；`main.pdf` 回拷到 `src/`。

**验收判据**（本项目最终一次运行）：`file:line` 错误 0、Undefined control sequence 0、Missing character 0、Overfull hbox 0。

## 四、译校体例

1. **逐页对照**：每页以 `% [原文 p.N]` 标记；译文按原书分页顺序推进，公式逐符号对照 200 dpi 页图抄录（扫描件公式的文本层不可用）。
2. **公式编号**：一律 `\tag{原编号}`，与原文一一对应；除 OCR 漏检的三条由译者回页图补出外，不改号、不重排、不自造。
3. **陈述编号**：原书每章内「定義・定理・命題・系・補題・注意・例」共用连续编号，全部手工照录，不用 LaTeX 自动计数器；陈述末尾有 □ 者用无星环境，后接「証明」者用带星环境（`theorem*` 等），证明末尾 ■ 由模板自动补。
4. **图**：从扫描页裁出（400–600 dpi），裁图不含原图号与图注；图号、图注照原书写 `\figtitle{X.Y}{译文图注（原书 p.N）}`。原书无图注者写「原书无图注（原书 p.N）」。图内自带的日文字标属扫描图像内容，未翻译（见「已知限制」）。
5. **术语**：以 `work/glossary.tsv`（≈230 条，日→中）为准；人名、模型名、缩写保留英文原形（Witten、Jones、Chern–Simons、KZ、WZW、tangle、framing、level 等）；首次出现可括注中文通名。
6. **行文**：中文数学文风；缩略语与数字两侧留半角空格；「1 次/2 次微分形式」「KZ 方程」「复线丛」「辫群」「共形块」「融合规则」「和乐」「单值」等为全书统一译名。
7. **译注**：正文中 `% [Tutor Note: ...]` 形式的批注不入版面，统一收在书末《译校批注》附录与 `译注汇总.md`（脚本生成）。只写三类：易错预警、省略论证的点拨、背景直觉。
8. **「本节重点」与「章末评注」**：为本译本所加（原书无），用于提示结构与易错点；可在导言区用 `\showtakeawayfalse`、`\showchapterreviewfalse` 关闭。原书各章末的「要約」照译为 `小结`（不编号）。
9. **参考文献**：原书的叙述式文献评注照译；条目按学术惯例保留英文/日文原貌，仅对 OCR 明显讹误作最小订正（未逐条核对详情）。
10. **标点**：中文全角；人名之间的连接号用 `--`（半角 en dash，避免 ctex 把 U+2013 当全角标点）。

## 五、原文笔误登记表

正文一律照原书排，只在批注中指出。经译者核对（500–900 dpi 裁图复核）后的登记如下：

| # | 原书页 | 原文 | 说明 / 正确形式 |
|---|---|---|---|
| 1 | p.13 | $u_m^{*}H=2m\,u_m$ | 右端漏对偶基星号，按 $\langle u_m^{*},Hu_n\rangle=2m\delta_{mn}$ 应为 $u_m^{*}H=2m\,u_m^{*}$ |
| 2 | p.18 | $\tilde f'\colon\Sigma\to G$ | 同句称其为 $f$ 到 $B'$ 的扩张，定义域应为 $B'$ |
| 3 | p.19 | $\Tr(f^{-1}\bar\partial f\wedge\partial gg^{-1})$ | 与常见写法 $\Tr(\partial gg^{-1}\wedge f^{-1}\bar\partial f)$ 差一符号（约定问题，照录原书） |
| 4 | p.57 | 式 (2.19) $G_1(x)=G_2(x)F$ | 全节未定义 $G_2$；按上下文（$G_0$ 在 $x=0$、$G_1$ 在 $x=1$ 附近解析延拓）疑为 $G_0$ |
| 5 | p.71 | 引理 2.8 右端 $J(K;\nu)$ | $K$ 未定义，按 cabling 的两分支 $K_0,K_1$ 应为 $J(K_0;\nu)$ |
| 6 | p.96 | $L_{\Sigma,a}$ 与 $L_{\Sigma,\alpha}$ 混用 | 下标 a/α 混用，应为 $L_{\Sigma,\alpha}$（$\alpha$ 为 $A$ 在边界上的限制） |
| 7 | p.98 | $c(g,\alpha)^{k}$ | 与 (2.38) 定义的 $c(a,g)$ 自变量次序相反，疑为 $c(\alpha,g)^{k}$ |

> 上表只收「经裁图复核、可写成具体判据」的项；存疑但无法定论者不列入，改在对应批注中说明。

**记号切换（非笔误，仅提示）**

| 原书页 | 情况 | 处理 |
|---|---|---|
| p.10 | $H^{2}(LG,\Z)\cong\Z$ | **不是笔误**：$LG\cong G\times\Omega G$，$H^{2}(\Omega G,\Z)\cong\Hom(\pi_{3}(G),\Z)\cong\Z$；原书与本节 $\omega_0$ 的论述自洽。批注已给出该分解 |
| p.128 | 「按 $q-1$ 的幂展开」后公式写作 $\tau(M)=\sum\lambda_n(M)(t-1)^{n}$ | 变量由 $q$ 切换为 $t$，页图确认原书如此；正文照录，批注说明 |

## 七、已知偏差与限制

1. **索引未收**：原书 p.141–148 的和文索引、欧文索引未收入译本（转录成本高）；读者可用 `术语对照表.tsv` 与正文页标记 `% [原文 p.N]` 对照原书。
2. **图内日文字标未译**：全部插图直接裁自扫描页，图内标签、子图注仍为日文（如 図2.24 的三个子图标题）。若需完全中文化，须重绘（TikZ）或人工修图。
3. **参考文献条目未逐条校对**：叙述评注已译；条目按 OCR 转录，仅订正明显讹误（如 `Stasheff`、`Twistor` 之类），人名/卷期/页码可能有 OCR 讹误。
4. **公式的文本层不可信**：全部公式按页图逐符号抄录；仍有小概率 OCR/视觉歧义导致的个别符号偏差，欢迎对照原书页图指正。
5. **「本节重点」「章末评注」为译者所加**，与原书体例不同；可用开关关闭。
6. **§3.1/§3.3 的完成方式**：负责这两块的译者进程在提交前中断（未留下成品），由 Lead 按同一规范从页图与文字层重译；其校核范围与其他块相同（`\tag` 逐条对页图、图逐幅复核、编译零错误），但未经过第二人交叉校对。
7. **未做逐句回译**：交叉校对覆盖编号、公式逐符号（每块 8–10 条）、结构、漏译、术语、接缝，不等于全文逐句复核。
7. **页码差异**：译文页数与原书不同，检索请用页标记（`% [原文 p.N]`）或原书页码。
