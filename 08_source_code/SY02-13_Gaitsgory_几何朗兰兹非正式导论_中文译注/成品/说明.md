需要 PDF 时，可在本机重新编译：

```bash
cd 源码
xelatex main.tex && xelatex main.tex && xelatex main.tex
```

fancyhdr, tikz, tikz-cd, enumitem, xcolor, hyperref）与字体 Noto Serif SC / Noto Sans SC。
