## 3. 与底本的三处系统性差异

1. **外引编号**。底本正文引 `C.2.1`、`C.3.2`、`C.6.1`、`L.3.12`、`V.14.11`、`I.10.6` 等编号，指向作者未发表的配套讲义（其文献表 [9]、[10]）。本书无附录，这些条目无从核对；译文**照录原编号**，不猜内容，并在译者说明中交代。
2. **页码映射**。底本印刷页 = PDF 页 − 4（前 4 页为封面、空白、目录）。译文页码标注一律用印刷页，资料卡的 `pages`/`pdf_pages` 同时给出两者。
3. **编号体例**。原书节号每章从 1 起、条目号「节.条」。译本保留该体例（`\thesection` 改为纯序号），因此第 2 章 §1 的第 2 条印作「引理 1.2」而不是「1.2.2」——与正文引用「由 1.2」一致。

## 4. 校注（42 条）

`annote` 环境（左侧细竖线 + 小字「校注」）插在相关条目之后，每条末尾标 `[来源：底本 p.N，…]`。四类：

1. **底本笔误**（最多）：把 `φ_{jk}∘φ_{kl}` 印成 `ψ_{jk}∘ψ_{kl}`（p.2–3）、`T` 与 `T′` 混用（p.85）、把 1.22 引作「21」（p.97）、把 1.25 引作 1.21/1.24（p.108、112）、`α̌(λ)` 应为 `α̌(ν)`（p.119）等。
2. **引理编号错位**：2.9 说「由 1.22」，但 1.22 只断言张量仍有限生成，能给出「局部化局部自由」与 2.9 公式的是 1.24——**照录原编号并出注**，不擅自改书。
3. **公式脱漏**：p.9 一串等式缺一步，按 `L_{fξ}ω = fL_ξω + ξ(f)ω = L_ξ(fω)` 补全并出注。
4. **存疑不改**：p.49 的消没区间 `i<−ℓ(w)`/`i>0` 疑上下界印反（若按仿射直像读应为 `i<0`/`i>ℓ(w)`）；p.54 `T_X=𝒪(−α)` 疑为余切层；p.79 9.5 称两闭子空间都余维 1。这类只在注里说「疑」，正文照录，读者自行核对。

另有若干 OCR 级错字（`O`→`O′`、`ν(L^C_w)`→`ν(L_{w_C})`、`c_v`→`c_D`、`W_Θ/W`→`W_Θ\backslash W`）**静默改正**，不占校注配额，登记在疑点清单的「处理」列。
