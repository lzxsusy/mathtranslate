# 翻译单元须知（SY07-11）

你是这本书中文译本的一名分单元译者。**只译分配给你的行段**，不要改别人的文件，不要动 `main.tex`。

## 1. 材料位置

| 东西 | 路径 |
| --- | --- |
| 英文原文（按章切分，保留页标记） | `工程文件/work/en/chNN.txt` |
| 已经译好的第 1 章（**体例样板，务必先读**） | `源码/chapters/ch01.tex` |
| 术语表（**强制性**，en/zh/备注，tab 分隔） | `工程文件/work/术语表.tsv` |
| 全书通读笔记（主线、各章内容、记号） | `工程文件/work/通读笔记.md` |
| 编译自检用 preamble | `工程文件/work/sub/harness.tex` |
| 你的输出 | `源码/chapters/<单元名>.tex`（单元名由派工消息给出） |

原文文件里的行号是文件绝对行号；页标记形如 `===== BOOK PAGE 17 (PDF 21) =====`，表示此后内容属于**印刷页 17**（= PDF 页 21）。引用页码一律用印刷页。

原文是 PDF 文本抽取，带常见缺陷，译时自行还原，**不必**为每个抽取噪声加校注：

- 连字 ligature：`diﬀerential`→differential、`ﬂag`→flag、`ﬁ`→fi、`ﬀ`→ff；
- 负号/不等号：`λ̸ = 0` 即 λ ≠ 0，`⊄` 即 ⊄；
- 行末断字：`intertwining` 被切成 `intertwin-` + `ing`；
- 花体/希腊字母有时丢字，读上下文补全。

## 2. 输出格式（严格遵守）

- 中文标题：一级用 `\section{...}`（章标题只由该章第一个单元给出，见派工消息）；**不写编号**，编号由 LaTeX 自动生成。
- 定理类环境：`\begin{lemma}...\end{lemma}`、`\begin{theorem}`、`\begin{proposition}`、`\begin{corollary}`、`\begin{definition}`、`\begin{example}`、`\begin{remark}`；证明用 `\begin{proof}...\end{proof}`。环境内**不写编号**，且必须与原文条目**一一对应、顺序一致**（原书编号「节.序号」由环境自动生成，漏一条就全错位）。
- 每条编号条目给标签：`\label{lem:2.3}`（引理）、`\label{thm:2.1}`、`\label{prop:2.2}`、`\label{cor:2.4}`、`\label{def:1.1}`、`\label{rem:1.2}`、`\label{ex:1.1}`；公式用 `\label{eq:2.1}`。正文里引用本书条目写 `\ref{lem:2.3}`（会印成「2.3」）。
- 引用**本书之外**的文献照录原样：`[2, 14.11]`、`C.3.2`、`L.3.12`，不要改写成 `\ref`。
- 数学：`\(...\)` 与 `\[...\]` 或 `equation`/`align*`。多行公式用 `align*` 并对齐；过宽的行拆成两行（`&\quad-` 续行），若整块仍超宽，可用 `{\small ...}` 包住该公式块。交换图表用 `tikz-cd` 的 `\begin{tikzcd}...\end{tikzcd}`。
- 可用宏（preamble 已定义，**不要新增宏**；确实需要就在报告里说明）：`\Diff \Der \Symb \ord \Gr \Hom \End \Ext \Tor \Aut \Pic \im \Id \Spec \Supp \rank \ch \N \Z \Q \R \C \D \calO \calU \calL \g \h \bb \n \m \p \s \uu \lla \kk \zz \ttt \dd`。花体用 `\mathcal{}`，德文花体用上面的 `\g \h ...`。
- 不要用 `\index`（索引由脚本统一插入）。不要加 `\chapter`（除派工明确要求）。

## 3. 语言（手册纪律 v2.1）

- 一句一重心；长句不超过 60–70 汉字；能用短句就用短句。
- 禁用句式：「被……所」「进行……的」「对于……而言」「关于……的讨论」式冗余；「使得」尽量换成「于是」「从而」。
- 全角标点（，。；：？！），引号用「」；括号内是英文时用半角括号。
- 英文术语、人名、书名两侧留半角空格：`Borel 子代数`、`Verma 模`、`Kazhdan–Lusztig 算法`。
- 人名一律拉丁字母，不音译。术语照 `术语表.tsv`；表里没有的，先按「有通行中译用中译、无则保留英文」处理，并在报告里列出来。

## 4. 校注

原文有**实质问题**时才加（笔误、跳步、术语歧义、与前后文矛盾），一般每单元 0–3 条。格式：

```latex
\begin{annote}
底本此处把 $A$ 印作 $B$。按上下文（3.2 的证明）应为 $A$，已改。[来源：底本 p.52，3.4 的证明]
\end{annote}
```

每条末尾必须给依据：`[来源：底本 p.N，…]`（原书自证/上下文）或 `[来源：《Lectures on algebraic D-modules》（本库 SY07-10）§x.y]`（作者前作，可用）或 `[译者按（无外部依据）：…]`。**不许**引用知乎/百度百科/CSDN 之类。

## 5. 自检（必须做）

1. 写完后，把 `harness.tex` 和你的文件复制到**以你的单元名命名的**私有临时目录（如 `/tmp/u-ch03d/`；**不要**用 `/tmp/u/`，那是别人也在用的）：
   ```bash
   D=/tmp/u-<你的单元名>; mkdir -p $D && cp 工程文件/work/sub/harness.tex $D/harness.tex
   cp 源码/chapters/<你的文件> $D/body.tex
   export PATH="/c/Users/admin/AppData/Local/Programs/MiKTeX/miktex/bin/x64:$PATH"
   cd $D && xelatex -interaction=nonstopmode harness.tex >/dev/null 2>&1; xelatex -interaction=nonstopmode harness.tex > log.txt 2>&1
   grep -n "^!" log.txt | head; grep -c "Overfull" log.txt; grep -c "Missing character" log.txt
   ```
   目标：0 个 `!` 错误、0 个 Overfull、0 个 Missing character（未定义引用警告可忽略，因为只编了片段）。若有，改到干净为止。
2. 不要提交临时目录里的东西。
