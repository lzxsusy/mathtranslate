# 通读笔记：《Localization and Representation Theory of Reductive Lie Groups》

底本：Dragan Miličić，作者自排讲义（pdfTeX 1.40.18，2017-10-22），129 印刷页，6 章 + 参考文献。
印刷页 = PDF 页 − 4。通读依据：全书文本抽取（`工程文件/work/en/ch01.txt`–`ch06.txt`，按章切分，页标记保留）。

## 全书主线

一句话：**把约化李群的表示论翻译成旗簇上的 D-模理论**，其技术核心是一个「局部化」等价

```
M_qc(D_λ)  ⇄  M(U_θ)
   ∆_λ(V) = D_λ ⊗_{U_θ} V        （局部化）
   Γ(X, −)                        （整体截面，右伴随）
```

Ch1 造机器（扭微分算子层与它的自同构/同构类），Ch2 在旗簇上把它算清楚（D_λ 的上同调、Borel–Weil–Bott、平移原理），Ch3 建立局部化函子并证明它在 λ 反支配时是范畴等价，Ch4 把 G-等变结构加进来（Harish-Chandra 层，供后续研究单表示与特征簇用），Ch5–Ch6 把这套几何语言用于 Verma 模与广义 Verma 模的重数计算（Kazhdan–Lusztig 算法）。

依赖关系：Ch1 → Ch2 → Ch3 →（Ch4 独立成一支，用到 Ch2 的 D_λ 与 Ch3 的 Γ/∆）→ Ch5、Ch6 各自只需 Ch1–Ch2 的结论加组合工具（Weyl 群、KL 多项式）。

## 逐章

### 第 1 章 微分算子层（p.1–16）

- §1 扭层：给 X 上微分算子层 D_X 配一个「提升」i:T_X→D_X（向量场 ↦ 一阶算子），得到扭层 (D,i)。核心是 **Aut(D_X,i_X) ≅ Z¹(X)**（闭 1-形式群，理 1.2），于是同构类由 H¹(X, Z¹_X) 分类，类记 t(D)（1.3）。之后是一整套函子性：用可逆层 L 扭（1.4、1.7–1.10）、沿态射拉回（1.5–1.6）、反代数 D^∘ 仍是扭层且 t(D^∘) = −t(D) + H¹(dlog)(i(ω_X))（1.11–1.13）。
- §2 齐性扭层：X = G/P 时，把 (D,γ,α) 与 U(g) 在整体截面上的作用绑在一起（γ 是 Lie 代数同态 g→Γ(X,D)，α 是 G-等变结构），得到双射 **λ ∈ I(b₀*) ↔ 齐性扭层同构类**，标准代表元 D_{X,λ} = U^∘/J_λ（2.4）。2.3 的构造分两步（Levi 分解 D₀ = L₀U₀，然后用特征标或 k→V→k 的扩张造 ω）。

读法提示：§1 的 1.1–1.3 是全书的记号来源；1.4–1.10 只需记住「扭层对 L、对态射都有函子性」，细节可在 Ch2 用到时回查。§2 的 2.3 证明较长，但结论（λ ↔ 层）是 Ch2 全部计算的起点。

### 第 2 章 D_λ-模的上同调（p.17–34）

- §1 把 Ch1 §2 特殊化到旗簇：b_x、n_x、B_x、h = b/n、g^∘、b^∘、n^∘、h^∘、U^∘、D_h = U^∘/n^∘U^∘；**D_λ = D_h/I_λD_h，且 D_λ = D_{X,λ+ρ}**（这里的 +ρ 平移是全书最容易错的地方）。U_θ = U(g)/J_θU(g)（θ 是 λ 在 Weyl 群下的轨道）。
- §2 平移原理：D_λ-模与 D_μ-模（λ−μ 整）之间的翻译函子，模掉 n-有限部分后是等价。
- §3 消没定理：λ 反支配时 H^i(X, D_λ) = 0（i > 0），故 Γ 正合。
- §4 非消没定理：λ 支配且正则时上同调集中在某个次数（对偶版本）。
- §5 Borel–Weil–Bott：把 D_λ 的上同调算成 Weyl 群作用下的线丛上同调。
- §6 D_λ 的上同调：汇总出 H^i(X, D_λ) 的显式描述，这是 Ch3 证明局部化等价的关键输入。

### 第 3 章 U_θ-模的局部化（p.35–84）

- §1 局部化函子 ∆_λ 与整体截面 Γ，伴随对；1.1 引理：λ 反支配时 V → Γ(X, ∆_λ(V)) 是同构。商范畴 QM_qc(D_λ)。
- §2 局部化与 n-同调：Γ(X, ∆_λ(V)) 与 V 的 n-同调一致，这是「等价」的量化形式。
- §3 交织函子：用旗簇上的对应（Bruhat 胞腔的闭包、deman 对应）造函子，实现 Weyl 群作用；这是全书技术含量最高的一节。
- §4 逆函子：构造 Γ 的左伴随/右伴随，完成范畴等价的双向。
- §5 不可约 D_λ-模的整体截面。
- §6 交织函子与完整复形。
- §7 与有限维模张量积。
- §8 单反射的交织函子（把 §3 的一般构造在 s_α 上算成具体公式）。
- §9 支集与 n-同调：支集在 Schubert 簇上的模与其 n-同调的关系。

### 第 4 章 Harish-Chandra 模（p.85–92）

- §1 旗簇上的群作用：K-轨道仿射嵌入（1.1–1.3）。
- §2 Harish-Chandra 对 (g, K)。
- §3 HC 模与 HC 层：局部有限的 (g,K)-模 ↔ 旗簇上带 K-等变结构的 D-模。
- §4 HC 模的 n-同调。
- §5 不可约 HC 层。

### 第 5 章 Verma 模（p.93–112）

- §1 最高权模范畴：固定 b₀、h₀、R₀⁺、n̄₀；最高权模 = 有限生成 + U(b₀)-有限；Verma 模 M(λ) = U(g)⊗_{U(b₀)} C_λ；1.1 给出等价刻画，1.2 证明该范畴对正合列封闭。
- §2 Kazhdan–Lusztig 算法：用 Hecke 代数与 KL 多项式算 Verma 模的合成重数，含 Jantzen 滤过与翻译函子两种途径。

### 第 6 章 广义 Verma 模（p.113–129）

- §1 Weyl 群中的陪集：Σ 约化根系、Θ ⊂ Π、W^Θ 的分解 w = w't（1.2，ℓ 可加）、Σ⁺_w 与 ℓ(ws_α) = ℓ(w)+1 的判别（1.1）。
- §2 广义 Verma 模：由抛物子代数 p = m + n 造 M_p(λ)，与 Ch5 的 M(λ) 的关系（投影/嵌入）。
- §3 广义 Verma 模的 KL 算法：把 Ch5 §2 的算法搬到陪集 W^Θ 上。
