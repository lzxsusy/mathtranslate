## 编译

```bash
cd 源码
export PATH="/c/Users/admin/AppData/Local/Programs/MiKTeX/miktex/bin/x64:$PATH"
xelatex -interaction=nonstopmode main.tex      # 第 1 遍：写 .aux/.toc/.idx
makeindex main.idx                             # 术语索引（imakeidx）
xelatex -interaction=nonstopmode main.tex      # 第 2 遍：目录、交叉引用
xelatex -interaction=nonstopmode main.tex      # 第 3 遍：索引页码落定
```

或用一键脚本（在工程根目录）：

```bash
bash 工程文件/build.sh            # 只编译 + 自检
bash 工程文件/build.sh --index    # 先按术语表重建 \index 再编译
```

## 验收标准

`log.txt` 中：

- `!` 错误 **0**
- `Overfull` **0**
- `Underfull` **0**（正文段落允许极少数，公式/表格不允许）
- `Missing character` **0**（缺字说明某个汉字没有字体覆盖）
- `undefined` 引用 **0**（章节、公式、索引都要有定义）

## 常见问题

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| `Missing character: There is no 〇 in font Noto Serif SC` | 用了字体没有的字 | 换字或改用 `\CJKfontspec` 指定其他字体 |
| `Overfull \hbox` 在长公式行 | 行宽超出版心 | 拆 `align*`（`&\quad-` 续行）或整块 `{\small ...}` |
| 定理编号错位 | 漏写某个条目环境 | 与原文「节.序号」逐条比对；编号由 `\thetheorem` 自动生成，不手写 |
| 索引页码全是 `??` | 没跑 `makeindex` | 按上面三步走 |
| `\index` 里的拼音键乱序 | 没装 pypinyin | 装 `pypinyin`，或让脚本退化为汉字序 |

## 自检脚本

`工程文件/tools/insert_index.py`：读 `工程文件/work/术语表.tsv`，按 `main.tex` 的 `\inputif{}` 顺序扫描各章，在**每个术语首次出现处**（跳过数学模式）插入 `\index{拼音@中文\|hyperpage}`。幂等：先清除旧 `\index` 再插入。
