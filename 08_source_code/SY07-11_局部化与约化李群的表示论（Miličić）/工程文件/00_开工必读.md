# 开工必读（SY07-11）

一分钟版：这是 Miličić《Localization and Representation Theory of Reductive Lie Groups》的**整本中文翻译**，6 章 129 印刷页。底本 PDF 133 页，**印刷页 = PDF 页 − 4**。

## 工序（按顺序，不跳步）

1. **通读**（译前）：`work/通读笔记.md` 记全书主线与逐章内容；`work/疑点清单.tsv` 记原文问题（12 条，已全部处置）；`work/术语表.tsv` 冻结术语。
2. **样板章**：第 1 章由主译自己译完（`源码/chapters/ch01.tex`），定下体例：`\label{lem:1.1}` + `\ref{}`、`annote` 校注带来源、宏表固定。
3. **分单元**：第 2–6 章切成 15 个单元（每单元 7–22K 英文词符，约 8–12 印刷页），每个单元一名译者，读到 `work/sub/单元须知.md` 后照做，产出 `源码/chapters/chNNx.tex`。
4. **合稿**：主译通读各单元，统一术语、补 `\ref{}`、清 Overfull，`build.sh` 三遍编译到零缺陷。
5. **索引**：`build.sh --index` 按术语表在首次出现处插 `\index`，书末生成「术语索引」。
6. **入库**：译稿段落进 `01_corpus_zh/zh_paragraphs.jsonl`，术语进 `01_corpus_zh/termbase.jsonl`。
7. **资料卡**：`datasets/mloc/`（暂定名，SCHEMA 仿 `datasets/dmod/`），约 70 张 concept/example 卡，带 `sources`（印刷页 + PDF 页 + anchor）与 `verification`。
8. **台账与清单**：`RELEASE_REGISTER.csv` 加 SY07-11 行；`tools/make_stats.py --write`、`tools/build_manifest.py`、`tools/check_manifest.py`（mismatch/missing/unlisted 全 0）；同步 `00_README.md`、`CHANGELOG.md`、`_meta/stats.json` 里的计数。
9. **推送**：`git push atomgit master:main`，再 `git push gitee master:main`（gitee 只走命令行，浏览器被劫持）。

## 不可动摇的五条

1. 数学正确性高于文采；不懂就标「存疑」进疑点清单，**不臆造**。
2. 术语先定，全书一致；术语表、正文、索引三处同步。
3. 译注必须可追溯（原书页码 / 作者前作 / 译者按），来源黑名单不碰。
4. 先通读，再落笔；每章开译前细读该章。
5. 书籍**不发成品 PDF**：仓库里只有源码、工程文件、资料卡。

## 已知坑

- 底本有指向作者未发表讲义的交叉引用 `C.3.2` / `L.3.12` / `V.14.11` / `I.10.6`，本书无附录，**照录**并在《译者说明》交代。
- 第 2 章起 `D_λ := D_{X,λ+ρ}`，与第 1 章 §2 相差 ρ（Q001）。
- PDF 文本抽取含连字（`ﬂ`/`ﬀ`）、`λ̸ = 0`（即 λ ≠ 0）、行末断字；`grep` 要加 `-a`（文件里有 `\x00`）。
- 本机 PowerShell 没有 heredoc；写多行脚本用 write 工具落 `.py` 再跑；控制台中文要 `PYTHONIOENCODING=utf-8`。
