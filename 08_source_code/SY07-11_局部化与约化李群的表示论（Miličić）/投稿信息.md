## 与底本的两处系统性差异

1. **交叉引用**：底本里有 `C.3.2`、`C.6.1`、`L.3.12`、`V.14.11`、`I.10.6` 这类编号，指向作者未发表的配套讲义（底本参考文献 [9]、[10]），本书没有附录。译文**照录原编号**，在《译者说明》中统一交代。
2. **页码**：译文一律标印刷页；资料卡同时给印刷页与 PDF 页（`pages` / `pdf_pages`）。
