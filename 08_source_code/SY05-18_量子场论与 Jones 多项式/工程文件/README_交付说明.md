## 八、已核对的记号约定（供教授续改时参考）

- 联络取**反厄米**（anti-Hermitian）约定：$D_i\epsilon=\partial_i\epsilon+[A_i,\epsilon]$，
  $F_{ij}=\partial_iA_j-\partial_jA_i+[A_i,A_j]$，(1.1) 为 $A_i\to A_i-D_i\epsilon$。
- 陈–西蒙斯作用量：$\mathcal{L}=\dfrac{k}{4\pi}\int\Tr\left(A\wedge\mathrm{d}A+\dfrac{2}{3}A\wedge A\wedge A\right)
  =\dfrac{k}{8\pi}\int\epsilon^{ijk}\Tr\left(A_i(\partial_jA_k-\partial_kA_j)+\dfrac{2}{3}A_i[A_j,A_k]\right)$。
- Tr 取 Cartan–Killing 形式的倍数，$\Tr(T^aT^b)=\delta^{ab}$（Witten 归一化）；若改用
  $\Tr(T^aT^b)=\frac12\delta^{ab}$，则 (3.1) 系数须由 $k/8\pi$ 改为 $k/4\pi$。
- Jones 参数：$q=\exp\!\big(2\pi i/(N+k)\big)$，$SU(2)$ 时 $q=\exp\!\big(2\pi i/(k+2)\big)$；
  与 $t=q^{-1}$ 的 Jones 多项式标准记法相差 $t\leftrightarrow q^{-1}$。
- 标架反常：$k\to k+c_2(G)/2$ 的平移；$SU(N)$ 时 $c_2=N$，故 $k\to k+N$。
