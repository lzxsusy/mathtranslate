十二条判定链（1–8 为 v1.0 施工期，9–12 为 v1.1 校订期）：每条给出「意图 / 动作 / 证据 / 结论」。用于复查译者的判断过程，而不是复述译文。

## 1. 为什么先冻结编号体制再动笔

- **意图**：PCMI 体例下定理与公式共用一个计数器，一旦配错 `\newtheorem`，全书编号会整体错位。
- **动作**：读 `pcmi.cls` 第 168 行，确认 `\numberwithin{equation}{subsection}`；再用 pymupdf 抽原 PDF 文本层，确认印刷页上确有 `Definition 1.1.1 / Theorem 1.1.3 / (1.1.4) / Lemma 1.1.5` 的混排。
- **证据**：`工程文件/work/numbering_orig.txt` 首现序列。
- **结论**：preamble 里写成 `\newtheorem{thm}[equation]{定理}` 并把 15 个定理环境全部挂 `[equation]`；编译后 §1.1 逐条为 1.1.1 定义、1.1.2 定义、1.1.3 定理、(1.1.4)、1.1.5 引理、1.1.6 引理、(1.1.7)、1.1.8 注，与原文一致。

## 2. 「仿射 Grassmann 簇」这一译名

- **意图**：`affine Grassmannian` 不能译成「仿射格拉斯曼流形」（它不是流形，且是归纳概形）。
- **动作**：查本库 `01_corpus_zh/数语规范/TERMS.tsv`；查学界通行译法。
- **证据**：本库无该条；通行译名为「仿射 Grassmann 簇」。
- **结论**：定「仿射 Grassmann 簇」，人名保留原文，中文与英文之间加半角空格。

## 3. `transversal slice` 译「横截片」而非「切片」

- **意图**：$S^\la_{\le\mu}$ 不是任意切片，而是与对偶 Schubert 簇横截相交的子簇。
- **动作**：查本库既有译法。
- **证据**：SY02-15 术语表已定「横截片」。
- **结论**：沿用 I 级译法，保持本库一致。

## 4. `\xymatrix` 图的处理

- **意图**：§2.5 的三节点图（Bruhat–Tits / Kac–Moody）必须保留，但译文的 preamble 未加载 xy。
- **动作**：先试 tikz-cd，报 `No shape named 'tikz@f@1-2-2' is known`（空单元）；再试 plain tikz 三节点 + 两条 `\draw`。
- **证据**：编译日志。
- **结论**：plain tikz 成立；教训是 tikz-cd 不留空单元，三角图用 plain tikz。

## 5. 附录编号 A.1 还是 1.1

- **意图**：原文附录用 `\section` 后自动变 A，子节应为 A.1。
- **动作**：初版 `\ctexset` 把编号硬编码成 `\arabic{section}.\arabic{subsection}`，编译后目录显示 `1.1 等变反常层范畴`。
- **证据**：目录页渲染图（`work/proof/my_p03.png`）。
- **结论**：删掉 `number=` 键让 ctex 用 `\thesection`，附录正确显示 A／A.1／A.1.1。

## 6. 译本 PDF 抽不出中文怎么办

- **意图**：按手册要做 PDF 端编号对账。
- **动作**：`pymupdf.get_text()` 只得到 5 处中英混排；`pdftotext` 报 `Missing language pack for 'Adobe-GB1' mapping`、`Unknown font tag 'F7'`。
- **证据**：`工程文件/work/mine.txt` 长度 77,045 但中文全为空白；`numbering_mine.txt` 仅 0 项。
- **结论**：改用两条替代审计——标签集合对账（193 个原文 label 全部命中，补 21 个附录 label）+ 源码推算编号（284 个对象，与原文首现序列逐条吻合）。**不谎称做了 PDF 对账**。

## 8. 一句「脚注不能带字母标记」的代价

- **意图**：作者脚注是 1、2、3，译注必须另起序列。

## 9. nLab 有页面 ≠ 有定义

- **证据**：四页原文（2026-11-25 逐页读过，非按搜索摘要判断）。

## 10. 「会议年」不是「出版年」

- **意图**：核 v1.0 的 82 条参考文献。
- **动作**：写 `check_bib.py`，解析原文 amsrefs 的 `date`/`series`/`volume`/`eprint` 字段，与译文 `\bibitem` 逐条比对。
- **证据**：BBD 原文作 Astérisque **100**（1982），译文写 `\textbf{100} (1981)`——1981 是 Luminy 会议年份；KL/Sp/Ti 同类（会议 1979/1977，出版 1980/1979）。
- **结论**：统一取原文 `date` 为出版年，会议年只作 `eventdate`；22 条重写后复算硬问题 0。教训：机械转换 bib 时，会议集的 `date` 与 `eventdate` 必须分开取，否则会排出 `,  (1977), 3--27.` 这种空括号。

## 11. 原文笔误：加注还是直接改

- **意图**：§1.3 的 $\pi_0(G)=\bZ$ 与 §5.6 的 $(A_2)$ 都是原文错，但处理方式不同。
- **动作**：核上下文——前者在 $G=\bG_m$ 时 $\pi_0(G)=1$，与同句前文 $\pi_0(\Gr_G)\cong\bZ$ 矛盾，属实质错误；后者只是漏 `\m`，同式左侧写作 $\mA_1$，可自证。
- **证据**：原文 1003–1004 行、3347 行。
- **结论**：实质错误**加译注 + 登记疑点清单**（读者须看见原文写法）；纯记号漏字**直接补正 + 登记 `typos.txt`**。分界线是「不加注会不会误读」。
