## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Environment defn undefined` | 本工程的定义环境叫 `dfn` | 用 `\begin{dfn}` |
| `Missing character: There is no 拉` | amscd/tikz 标注里直接写了中文 | 包 `\text{}`：`@V{\text{拉回}}VV` |
| 附录子节显示 `1.1` 而非 `A.1` | `\ctexset` 里硬写了 `number=\arabic{section}` | 删掉 `number=` 键 |
| 目录缺「参考文献」 | `thebibliography` 不自动进目录 | `\clearpage\phantomsection\addcontentsline` |
| `Numbering` 与原文不符 | 定理环境没挂到 `[equation]` 计数器 | 检查 `\newtheorem{thm}[equation]{定理}` 与 `\numberwithin{equation}{subsection}` |
