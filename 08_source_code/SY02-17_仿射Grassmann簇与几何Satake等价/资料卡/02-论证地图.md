# 资料卡 02 · 论证地图

全书的逻辑是一条**单向的构造链**：空间 → 几何 → 范畴 → 等价 → 族化版本。下面用 D1–D6 标出六段主链，给出每段「要什么、靠什么、结论是什么」。

```
D1 造空间            D2 造几何            D3 造族
Gr_G = LG/L^+G  ──►  Schubert/横截片  ──►  BD Grassmann 簇
（可表、格模型）      （维数、Picard、        （分解结构、
                       中心扩张）              融合积）
        │                    │                    │
        └────────────┬───────┴────────────────────┘
                     ▼
D4 造范畴      Sat_G = (P_{L^+G}(Gr), ⋆)  半单 + 卷积反常 + 纤维函子 H*
                     │
                     ▼
D5 造等价      MV 理论（半无限轨道 S_λ、CT 函子） ⇒ Tannaka 群 = Ĝ
                     │
                     ▼
D6 自举        融合积给交换约束 ⇒ Sat_G ≃ Rep(^L G^geo)，且 Sat_{X^I} ≃ Rep(Ĝ^I, Loc(X^I))
                     │
                     ▼
              落到经典 Satake（KL 多项式 = BK 滤过分次维数）
```

## D1 造空间（§1）

- **要什么**：把「曲线上的 $G$-丛 + 一点处平凡化」参数化成一个几何对象。
- **靠什么**：$\GL_n$ 情形用格（定义 1.1.1–1.1.2），用 $t^N R[[t]]^n\subset\Lambda\subset t^{-N}R[[t]]^n$ 的界给出有限型逼近（定理 1.1.3、引理 1.1.5–1.1.6）；一般 $G$ 用射流群与 fpqc 商（§1.3）；Beauville–Laszlo 定理把 $\bP^1$ 上的丛化成两个圆盘上的粘合（§1.4）。
- **结论**：$\Gr_G$ 是可表归纳概形，且 $\Gr_G\cong[L\underline G/L^+\underline G]$；$\Pic$ 与中心扩张的阶由 $\mO(1)$ 定出（§1.5）。

## D2 造几何（§2）

- **要什么**：在 $\Gr$ 上做相交论与线丛论。
- **靠什么**：Cartan 分解 → Schubert 簇 $\Gr_\mu$ 射影、$\dim\Gr_\mu=(2\rho,\mu)$；对偶 Schubert 簇与横截片给出 Birkhoff 分解；$\Theta=\Gr^{\ge\theta}$ 给出丰沛除子。
- **结论**：$\Pic^e(\Gr_G)=\bZ\mO(1)$（定理 2.4.2）；$\Gr_{\underline G}\cong G_\Ga/P_S$，中心扩张与仿射 Kac–Moody 群一致（§2.5，定理 2.5.5 Borel–Weil）。

## D3 造族（§3）

- **要什么**：把 $\Gr$ 变成曲线 $X$ 上的族，使卷积积有交换性来源。
- **靠什么**：BD Grassmann 簇 $\Gr_{X^I}$（定义 3.1.1、定理 3.1.2 可表），其对角限制给出 $\Gr$ 的自乘积；**分解结构**（定理 3.2.2）说沿 $X^I$ 的分解子概形，$\Gr_{X^I}$ 分裂成各 $\Gr_{X^{I_j}}$ 的乘积。
- **结论**：卷积映射可以「展开」为 $X^{(\phi)}$ 上的外积再取 $j_{!*}$，即融合积（§5.4 命题 5.4.1）；同时得到 $\Pic^e(\Gr_{\Ran}/\Ran)\simeq\Pic^e(\Gr_x)$（§3.4）。

## D4 造范畴（§5.1–§5.2）

- **要什么**：让「$\Gr$ 上的反常层」成为可以谈张量积、交换性的范畴。
- **靠什么**：$L^+G$ 作用满足条件 (S)，故 $\on{P}_{L^+G}(\Gr)$ 有意义；半单性（命题 5.1.1）来自 IC 层茎上同调的纯性 + 轨道维数奇偶性；卷积反常（命题 5.1.3，奇迹定理）来自半无限几何或 BD 邻近圈。
- **结论**：$(\Sat_G,\star)$ 是幺半范畴；超上同调 $\on{H}^*$ 经 $R_G$-双模结构（引理 5.2.2–5.2.3）成为纤维函子，$\Sat_G$ 是中性 Tannaka 范畴（定理 5.2.7）。

## D5 造等价（§5.3）

- **要什么**：算出 Tannaka 群 $\tilde G=\Aut^\otimes\on{H}^*$。
- **靠什么**：范畴 Satake 变换 $\on{CT}:\Sat_G\to\Sat_T$ 用半无限轨道 $S_\la$ 分解 $\Gr$；MV 理论给出 $\on{H}^*_c(S_\la,\IC_\mu)$ 的纯维数与集中次数（定理 5.3.13）；Plücker 关系给出 $\tilde B\subset\tilde G$，根数据由支配权半群 + 单根集唯一确定。
- **结论**：$\tilde G\cong\hat G$（定理 5.3.2），并带典范带钉（定理 5.3.20：$c_1(\mO(1))$ ↦ 主幂幺元）。

## D6 自举与落地（§5.4–§5.6）

- **要什么**：把 $\Sat_G\simeq\on{Rep}(\hat G)$ 升级为带 $\Ga_k$ 作用的版本，并推广到多重点。
- **靠什么**：融合积给出交换约束（命题 5.4.1 + 推论 5.4.5）；$B=\mO_{\bG_m}$ 的 $\hat G^T$-模结构给出 ${}^LG^{\on{geo}}$；$\mR_{X^I}=\boxstar\mR_X$ 给出 $S_I$。
- **结论**：$F:\Sat_G\simeq\on{Rep}^c_{\Ql}({}^LG^{\on{geo}})$（定理 5.5.7）；$S_I:\on{Rep}(\hat G^I,\on{Loc}(X^I))\simeq\Sat_{X^I}$（定理 5.5.10）；与经典 Satake 同构对接（§5.6），KL 多项式 = Brylinski–Kostant 滤过的分次维数。

## 作者未说透的三处（译者按）

1. **§5.3 的「根数据由支配权半群 + 单根集唯一确定」（引理 5.3.x 的证明）**：原文只说「细节留作练习」。补一句：${\xch}^+$ 给出 Weyl 房，从而给出 $W$；$W$ 与 $\Delta$ 给出 $\Phi$，再对偶即得 $\Phi^\vee$。
2. **§5.5 中为何 $B$-模范畴等于 ${}^LG^{\on{geo}}$ 的表示**：原文只写「$B$-mod」，实质是用 Deligne 修正 ${}^LG=\hat G\rtimes\bG_m$ 把 $\bG_m$-分次并进群作用；这一点在 §5.5 开头一句带过，读时容易漏。
3. **§4.3 中「$G$ 半单时 $u_x$ 才是同构」**：原文在定理陈述里给了条件，但反例（$\GL_1$ 时的 Picard 群）只在注里暗示。
