## 三、文献

参考文献 82 条，由脚本 `scripts/make_bib.py` 从原文 amsrefs 源（`\bib{key}{type}{...}`）机械转换，key 与次序与原印刷本一致；作者名由「姓, 名」改为「名 姓」，标题与刊物名保持英文原样（不译）。原文中 4 条 `in preparation`／`Preprint` 照留。

**第二轮审计（2026-11-25，v1.1）**：`scripts/check_bib.py` 逐条比对原文 `\bib` 字段与译文 `\bibitem`（出版年 / 丛书 / 卷 / 书名 / eprint / note），得**硬问题 0 条、可选项 7 条**（可选项全是题献、会议名一类附注，见 `work/bib_report.txt`）。

修正的系统性错误有两类，共 22 条：

1. **把「会议年」当成「出版年」，并丢掉丛书名**，导致排版出现 `,  (1977), 3--27.` 这类空括号。涉及 BBD、Be、Lu、So、KL、Sp、Ti、SGA4.5、DM/MS、Dr、Gortz、Gr，以及补丛书的 BD0、BeLu、Se2。例：BBD 原文作 Astérisque **100**（1982），译文曾写 `\textbf{100} (1981)`——1981 是 Luminy 会议年份；KL/Sp/Ti 原文作 Proc. Sympos. Pure Math. **XXXVI / XXXIII**（1980 / 1979），译文曾用会议年 1979 / 1977。
2. **preprint 条目丢 eprint/note**，有的整条只剩「作者 + 标题 + 逗号」：MVy 缺 `arXiv:0712.4160`、RZ 缺「Appendix to \cite{Z11}」、Sch 缺 Berkeley 讲义链接、St 缺 `stacks.math.columbia.edu`、Yu 缺「收于本卷（These Proceedings）」。

**判断依据**：以原文 amsrefs 的 `date`/`series`/`volume` 字段与出版社信息为准；`date` 与会议 `eventdate` 不同时取前者。修复脚本 `scripts/fix_bib.py`（行号 + 行内片段双重 guard），复算一次即得硬问题 0。
