# 通读笔记 · SY02-17

底本：Xinwen Zhu, *An introduction to affine Grassmannians and the geometric Satake equivalence*, arXiv:1603.05593（95 页）。行号指 `工程文件/work/原文/main.tex`。

## 三句话主旨

1. 仿射 Grassmann 簇 $\Gr_G=LG/L^+G$ 是「曲线上的主丛 + 一点处的平凡化」这个模问题的参数空间，因而本身就带几何意义，而非仅为群论构造。
2. 它上面的反常层构成幺半范畴 $\Sat_G$，MV（Mirkovič–Vilonen）理论用半无限轨道算出其纤维函子的值，由此得到中性 Tannaka 范畴，其 Tannaka 群恰是 Langlands 对偶群 $\hat G$。
3. 把 $\Gr$ 换成 Beilinson–Drinfeld Grassmann 簇 $\Gr_X$、把卷积换成融合积，就能把上述等价「自举」到整条曲线的多重点版本，这是几何朗兰兹纲领的局部基石。

## 论证地图（按节）

- **§0 引言（555–726）**：格的模解释 → $V=\Gamma(\bP^1,\mO(n))$ 的秩 $n$ 子模 = $\Bun_n(\bP^1)$ 的局部模型；仿射 Springer 纤维与 ADLV（affine Deligne–Lusztig variety）的动机；Satake 同构的经典形式，及其「几何化」的猜想形式（式 (0.1)）；范围与内容；约定（$k$-空间 fpqc 拓扑、归纳概形、主丛、圆盘、群论数据）。
- **§1 第一讲（727–1254）**：$\GL_n$ 情形用格给出 $\Gr$ 的函子化定义与可表性（Thm 1.1.3）；一般 $G$ 用射流群 $LG$、$L^+G$、fpqc 商 $[L\underline G/L^+\underline G]$；Beauville–Laszlo 定理（$D\cup D'$ 上丛的粘合）；行列式线丛与中心的确定；$\Omega K$ 的拓扑解释；$p$-进版（Witt 向量）。
- **§2 第二讲（1255–1765）**：Cartan 分解与 Schubert 簇 $\Gr_\mu$ 的射影性、$\dim\Gr_\mu=(2\rho,\mu)$、奇点（正规、Cohen–Macaulay、Gorenstein、有理奇点）；插叙 Gr 中某些子归纳概形；对偶 Schubert 簇与横截片 $S^\la_{\le\mu}$、Birkhoff 分解；Picard 群（$\Theta$ 除子、$\mO(1)$ 丰沛、$\Pic^e=\bZ\mO(1)$、Dynkin 指数）；中心扩张与仿射 Kac–Moody 代数、Borel–Weil 定理。
- **§3 第三讲（1766–2194）**：BD Grassmann 簇 $\Gr_{X^I}$ 的定义与可表性；Iwahori 形变、卷积 Grassmann 簇、对称化；分解结构（Thm 3.2.x 四条）；Ran 空间 $\Ran(X)$ 与 $\Gr_{\Ran}$；$\Gr_{\Ran}$ 上刚性化线丛。
- **§4 第四讲（2195–2457）**：单点单值化 $u_x:\Gr_x\to\Bun_G$ 与其逆（$G$ 半单时）；$\Pic^e(\Bun_G)\cong\Pic^e(\Gr_x)$；非阿贝尔 theta 函数与共形块、Verlinde 公式的低维验证；adèle 单值化（Weil）、$\Gr_{\Ran,\on{indep}}$、$\Gr_{\Rat}$、$u_{\Rat}$ 是 $\underline G_{\Rat}$-主丛。
- **§5 第五讲（2458–3402）**：$\Sat_G$ 的定义与半单性；卷积积反常（奇迹定理）；超上同调作为纤维函子；Tannaka 群 $\tilde G\cong\hat G$（MV 理论：半无限轨道 $S_\la$、$\on{CT}$ 函子、Bott–Samelson 型论证、Plücker 关系给出 $\tilde B$、典范带钉）；融合积给出交换约束；自举到 ${}^LG^{\on{geo}}$ 与 $\Sat_{X^I}$；最后与经典 Satake 同构对接（Kazhdan–Lusztig 多项式 = Brylinski–Kostant 滤过的分次维数）。
- **附录 A（3405–3700）**：A.1 等变反常层与等变上同调（GKM 形式性、局部化定理、pro-代数群作用于归纳概形）；A.2 ULA 层的定义与五条基本性质、ULA 与反常性的关系。
