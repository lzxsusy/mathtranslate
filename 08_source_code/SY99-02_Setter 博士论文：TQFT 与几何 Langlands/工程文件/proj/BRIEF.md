## 各块内容提要（帮你快速进入）

- **ch02**：非阿贝尔电磁对偶的直观（规范场 ↔ 磁单极，Wilson 线 ↔ 't Hooft 算子）→
  $\cN=4$、$d=4$、规范群 $G$ 的约定（场含量、作用量、超对称变换、复化耦合 $\tau=\theta/2\pi+4\pi\ii/e^2$）→
  S-对偶（$G\leftrightarrow\LG$、$e\leftrightarrow 4\pi/e$、$\tau\to-1/\tau$）→ 拓扑扭转的一般框架与 $\cN=4$ 的三种扭转
  （Vafa–Witten、GL）→ GL-扭转理论：扭转参数 $t\in\C\cup\{\infty\}$（图 2.1 是 $t$ 的黎曼球）、场含量、作用量 $S=\delta Q V+S_{top}$、BRST 变换。
- **ch03**：先把 4d A-模型（把 $\cN=4$ 沿 $t=0$/$t=1$ 扭转后得到的拓扑理论）写成通用形式：
  场含量（$\phi,\psi,\ldots$）、作用量、BRST 变分、局部可观测量的 BRST 上同调；再谈「带规范场」的版本
  （Donaldson–Witten 理论作为特例、物质场部分、局部可观测量），最后证明 Vafa–Witten 理论就是带规范场的 4d A-模型的特殊情形。
- **ch04**：一般 2d/3d/4d TFT 的范畴结构：2d TFT 的边界条件构成范畴（态射=边界交接处的局部算子，图 4.1–4.2）；
  2d TFT 构成 2-范畴（1-态射=壁，2-态射=壁上的局部算子，图 4.3–4.6）；3d TFT 的边界条件构成 2-范畴；
  4d TFT 的面算子构成 2-范畴（图 4.7，融合 $\odot$）。这一章几乎没有公式，全是结构性论述（**务必忠实翻译，不要自行简化**）。
- **ch05**：把拓扑规范理论在 $S^1$ 上紧化（小半径极限）：紧化后的 3d 理论、把高维规范场约化为 3d 的场、
  Wilson 线/面算子如何约化；然后分别讨论 Vafa–Witten 理论（$t=i$ 附近）与 GL-扭转理论在 $t=0,1,i$ 时的 $S^1$ 紧化，
  以及得到的 3d 拓扑理论（含复 Chern–Simons、$T^*[\text{复群}]$ 上的 Rozansky–Witten 模型、$\cN=4$ 3d 规范理论等）。
- **ch06a**：Gukov–Witten 面算子（在 4d 理论中沿曲面 $\Sigma$ 插入的奇异性参数化，参数 $\alpha,\beta,\gamma$）；
  $t=\ii$、$G=U(1)$ 情形：用 $\cM_H=T^*\C^*$ 上的 RW 模型与 B-型 3d 规范理论的边界条件分类面算子，
  再拼起各 sector，并讨论面算子上的线算子；$t=\ii$ 非阿贝尔推广；$t=1$、$G=U(1)$ 的规范 sector 边界条件
  （Dirichlet / Neumann 条件，§6.4.1）。
- **ch06b**：接 §6.4.2：物质 sector 的 Dirichlet/Neumann 条件 → 电磁对偶下 DD/NN/DN/ND 四种组合的配对；
  §6.4.4 提出 $t=1$ 时面算子的 2-范畴猜测（模范畴）；§6.5 讨论 $t=0$、$G=U(1)$ 的对应结构。
  **图 6.1**（p.77）是摩天楼层 ↔ 边界线算子的示意图。
- **ch07**：2d A-模型的标准构造（靶空间 $X$ 为 Kähler、场 $\phi,\chi,\ldots$、作用量、BRST）；
  然后是「修正 A-模型」：引入 Ising/向量多重态、扭转的旋转群、等变拓扑项（§7.3）、局部可观测量（§7.4）、
  边界条件（A-膜/余迷向子流形，§7.5）、等变 Maslov 指标（§7.6）。

- **ch08**：把 Vafa–Witten 理论在亏格 $g\ge2$ 的黎曼面 $C$ 上紧化：约化作用量与场（Higgs 丛、Hitchin 模空间 $\cM_H(G,C)$ 的
  超凯勒结构），并说明得到的修正 A-模型以 $\cM_H(G,C)$ 为靶空间。
- **ch09**：2d σ-模型的拓扑缺陷（defect）与粘合条件：一般形式（$GL$-对偶、黎曼面、$T^*M$、粘合矩阵 $(\mathbf{A},\mathbf{B})$）；
  玻色 σ-模型的拓扑缺陷 ↔ 拓扑双膜；几何描述（$R_+,R_-$ 子丛、$\Omega$-拉格朗日子丛、可积性）；
  (0,1)/(0,2) 超对称 σ-模型的缺陷；T-对偶。**注意：定义 1–7、命题 1–10 的编号照抄原文**。
- **appA**：A-型 2d 拓扑规范理论（含 $T^*M$ 上的 RW 模型）、B-型 2d 拓扑规范理论、带规范场的 2d B-模型。
- **appB**：3d A-模型、带规范场的 3d A-模型、Rozansky–Witten 模型、B-型 3d 拓扑规范理论、带规范场的 RW 模型。
- **appC**：相伴纤维丛的全空间、把 $X$ 上的等变上同调类拉回到 $E$（Cartan 模型、等变微分形式、沿纤维积分）。

## 常见误判提醒
1. **文字层里数学几乎必然错**（`\frac{m}{2}` 抽成 `2m`、下标丢、`\mathcal{N}`→`N`、`\int` 拆散、希腊字母乱）；
   显示公式必须看 `pages/pNNN.png` 逐符号核对。
2. `tags_bypage.txt` 里同一 tag 在一页出现两次的多半是**行文引用**（"in (1.2)"），不是新公式。
3. 原文的 "it is easy to see / one can show / it follows" 处需要 `% [Tutor Note: …]` 补论证。
4. 原文的图注（"Figure X.Y: …"）**不写进正文文字**，用 `\figtitle{X.Y}{中文图注}` 放在 figure 环境里。
5. 术语统一：先查 `glossary.tsv`；新词自己定译法后回报 Lead。
6. 英文斜体强调（如 *topological*）→ `\emph{…}`；原文的 “quotes” → “中文引号”。
7. 原文没有表格（0 张表）——如果你以为看到了表，那是**方框公式**或排版框，见 STYLE_GUIDE §3.4。
