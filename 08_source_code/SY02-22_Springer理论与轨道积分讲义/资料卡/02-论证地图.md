# 资料卡 02 · 论证地图

全书四讲的逻辑不是并列的四块，而是同一条链的四段：**几何对象 → 对称性 → 算术计数 → 整体化**。下面给出依赖关系与每段的「入口／出口」。

## 第一段：几何（§1）

- **入口**：$\sN$ 的 $G$-轨道有限、$\sB$ 是旗簇。
- **核心构造**：$\tg=\{(X,B): X\in\Lie B\}$，$\pi_{\frg}:\tg\to\frg$ 是 Grothendieck 修改（同时消解）；限制到 $\sN$ 得 Springer 消解 $\pi:\tN=T^*\sB\to\sN$。
- **纤维**：$\sB_e=\pi^{-1}(e)$。三条可算的性质构成后文的「模型」：维数 $d_e$（1.4.4）、分支数与标准 Young 表（$A$ 型，1.3.6）、分支群 $A_e=\pi_0(\tilG_e)$。
- **出口**：定理 1.5.1（Springer 对应）把 $\Irr(W)$ 翻译成 $\sN$ 上的等变局部系统。证明走三条独立路线（§1.5.9 Fourier、§1.5.10 对应、§1.5.11 单值），其中 Fourier 路线依赖定理 1.5.7（BBD：$\calS=\bR\pi_*\Ql[\dim\sN]$ 反常、$\End\calS=\Ql[W]$）。

## 第二段：局部域上的类比（§2）

- **入口**：$F=k\lr{t}$、$G$ 分裂、$LG$ 与 $\Gr_G=LG/L^+G$。
- **核心构造**：$\sX_\gamma=\{gL^+G: \Ad(g^{-1})\gamma\in\frg(\calO_F)\}$。它是无穷维的、常常非约化的（§2.5.1 非约化性），这一点与 §1 的 $\sB_e$ 不同，也是「必须取 $\red$」的原因。
- **三条支撑**：
  1. 有限性（定理 2.5.2，Kazhdan–Lusztig）：$\sX_\gamma$ 有紧子概形、商 $\L_\gamma\bs\sX_\gamma$ 是真代数空间——这才使 §3 的计数合法。
  2. 维数（定理 2.5.12，Bezrukavnikov）：$\dim\sX_\gamma=\frac12(\val_F\Delta(\gamma)-c(\gamma))$，与 §1 的 $d_e$ 同形。
  3. 对称（定理 2.6.2，Lusztig／Sage）：$\tilW\rtimes\Sym(\xch(T))$ 中至少有 $\tilW$ 作用在 $\homog{*}{\sY_\gamma}$ 上。
- **出口**：中心化子的正则化 $J$ 与局部 Picard 群 $P_a=LG_\gamma/L^+J_a$（§2.3.6）——这是 §4.4 乘积公式右端的因子。

## 第三段：计数（§3）

- **入口**：$F$ 局部非阿基米德、$\varphi\in\sS(\frg(F))$。
- **链条**（三段，每段都可单独检查）：
  1. §3.2：轨道积分 → 群胚上的计数（引理 3.2.8）。关键在于 $\frg(\calO_F)$ 的 $\Ad$-轨道有限、$\GL_n$ 情形可化为分式理想（3.2.9）。
  2. §3.3：$\sX_\gamma(k)=X_\gamma$（引理 3.3.1）⟹ $O_\gamma(\one)=\#(\wt\L_\gamma\bs\sX_\gamma)(k)$；再用 Grothendieck 迹公式把它写成 Lefschetz 数（定理 3.3.4）。这一步要求 $\cohog{1}{k,\wt\L_\gamma}=0$，否则扭形式会破坏计数（§3.3.6–3.3.7 处理）。
  3. §3.4：稳定化。$K_\gamma$ 的体积（Néron 模型）与稳定上同调配对，得到定理 3.4.8。证明梗概（§3.4.11）里 $\theta:\cohog{1}{k,\wt\L}\surj\cohog{1}{k,LG_\gamma}\cong\cohog{1}{F,G_\gamma}$ 与六项正合列是全节技术核心。
- **检验**：§3.5 用 $\SL_2$ 的四个例子把上述配方全部跑一遍，得到 $1$、$q+1$、$q+2$、$2(q+1)$ 四个数，并与上同调的 Frobenius 作用逐一对照——这是全书唯一一处完整可验算的地方。
- **出口**：§3.6 把稳定轨道积分写进基本引理的内窥形式。

## 第四段：整体化（§4）

- **入口**：光滑射影曲线 $X$、$\calL$、Hitchin 模叠 $\calM_{G,\calL}$（§4.1）。
- **Hitchin 纤维化** $f:\calM_{G,\calL}\to\calA_{G,\calL}=\prod_i\cohog{0}{X,\calL^{\otimes d_i}}$（§4.2）。$\GL_n$ 情形有谱曲线 $Y_a$，$\calM_a\cong\cPic(Y_a)$（命题 4.3.2）；$\Sp_{2n}$ 情形换成 Prym（命题 4.3.5）。
- **乘积公式**（定理 4.4.2）：$\calM_a$ 在模去整体 Picard $\calP_a$ 与各局部 $P_{a_x}$ 之后，等于各点仿射 Springer 纤维之积。这是「整体 ↔ 局部」的唯一桥梁，也是 Ngô 证明基本引理的几何核心。
- **整体对称**（定理 4.5.2）：Iwahori 层结构 $\Mpar_{G,\calL}\to\calA_{G,\calL}\times X$ 上，$\tilW$ 作用在 $\bR\fpar_!\Ql$ 上；扩张到 $\Sym(\xch(T))\rtimes\tilW$ 即分级 DAHA。

## 哪一步最脆

1. **§2.5 的归约链**：分裂环面 ⟶ 一般情形（$\mu_m$-下降）⟶ Levi 归约，三步都依赖估值估计 $\val_F(c_\alpha)\ge-(2\text{ht}(\alpha)-1)n$。阅读时建议只跟 $\SL_2$ 的例子（§2.4.1、§2.6.4）走一遍。
2. **§3.3.6–3.3.7 的扭形式**：为什么 $\L_\gamma$ 的 $\cohog{1}$ 消没能让点数等于上同调，这是全节最容易跳步的地方。
3. **§4.4 的 $\twtimes{H}$**：乘积公式两侧的群作用都要先模掉，读者容易误以为它是直积。
