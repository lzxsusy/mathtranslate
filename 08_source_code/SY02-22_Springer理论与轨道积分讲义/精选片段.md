# 精选片段 · SY02-22

十条判定链：每条给出「意图 / 动作 / 证据 / 结论」。用于复查译者的判断过程，而不是复述译文。

## 1. 先冻结编号体制，再动笔

- **意图**：PCMI 体例下，定理、公式、小节共用一个计数器；一旦 `\newtheorem` 挂错计数器，全书的 `\ref` 会整体错位，事后再改等于全文重排。
- **动作**：读底本 `工程文件/work/src/pcmi.cls`，确认 `\numberwithin{equation}{subsection}`；再读 `ZhiweiYunPCMI.tex:64-92`，发现作者重定义了 `\subsubsection`：`\setcounter{subsubsection}{\value{equation}}` → 调旧版（自增 1）→ `\refstepcounter{equation}`，等于让每个 `\subsubsection` 吃掉一个公式号。
- **证据**：`工程文件/work/numbering_test.tex` 的编译结果：`0. 引言` / `0.1.1.` / `定理 0.1.2` / `(0.1.3)` / 空标题小节 `0.1.4.` / `(0.1.5)`。
- **结论**：译文 preamble 原样复现该机制，并把 `\thesubsubsection` 写成 `\thesubsection.\arabic{subsubsection}`（写成 `\thesection.\thesubsection...` 会印出 `0.0.1.1`）。

## 2. 空标题的 `\subsubsection{}` 一个都不能删

- **意图**：原文有 161 个 `\subsubsection`，其中相当一部分是空标题（只用来给下一段编号）。若「合并」或删掉，后面所有编号会连锁错位。
- **动作**：逐块翻译时保留每个 `\subsubsection{}`，包括空标题的裸编号。
- **证据**：译本第 23 页渲染（`工程文件/work/main_p24.png`）印出 `2.2.4.`、`2.2.5.`，与原文 PDF 第 17–21 页抽出的序列 `2.2.1 / 2.2.3 / 2.2.4 / 2.2.5 / 2.2.7 / 2.2.8`（`work/pdftext_17_21.txt`）逐一吻合。
- **结论**：编号机制复现正确；后续 250 个编号对象的全量比对（见第 8 条）以此为基。

## 3. 定理标题的本地化与 `\newtheoremstyle` 的坑

- **意图**：中文习惯是「定理 1.5.1（Springer）」，编号在前、作者名在括号里；原文 `\swapnumbers` 加自定义 `\swappedhead` 也是这个外观。
- **动作**：写 `\newtheoremstyle{cnplain}`，第 9 参数直接写 `\thmname{#1}\thmnumber{...}\@ifempty{#3}{}{（#3）}`。
- **证据**：第一版把第 9 参数写成宏名 `\headE`，编译报 `! You can't use '\ ' after \the.` 与 `! You can't use 'blank space ' after \the.`；第 7 参数（head punct）留空也报同样的错。改回直写、第 7 参数给 `{\relax}` 后通过。
- **结论**：`\newtheoremstyle` 的第 7、9 参数不能传带参数展开的宏；渲染核验（`work/style_test.png`）确认「定理 0.1（Springer）　内容」的间距正常。

## 4. `loop group` 译「环路群」而不是「环群」

- **意图**：`loop group` 在 §2.1 反复出现，必须与样板工程一致，否则读者在 SY02-17／SY02-22 之间切换时会对不上。
- **动作**：查 `R/01_corpus_zh/数语规范/TERMS.tsv`（T0673 作「环群」），再查 `SY02-17/工程文件/work/glossary.tsv`（冻结为「环路群」）。
- **证据**：两份表冲突；用户指令要求与 SY02-17 一致。
- **结论**：取「环路群／正环路群」，在 `glossary.tsv` 的依据栏写明分歧来源；初稿遗留的 12 处「圈群」已全文 sed 统一并重编译。

## 5. `alteration` 译「修改」

- **意图**：`Grothendieck alteration` 是专名，不能译成「变换」或「改动」——`alteration` 在代数几何里固定指「真、一般有限」的映射，与「变换」相混会误导。
- **动作**：保留原文作者脚注给出的定义（proper 且 generically finite），中文用「修改」。
- **证据**：原文 §1.2 的脚注；语义上它与同一段的「同时消解」指同一个映射（译注「译1」指出这一点）。
- **结论**：定「Grothendieck 修改」，术语表登记 A 级，首见 §1.2。

## 6. `semismall` / `small` 译「半小」/「小」

- **意图**：§1.5 的整个证明（定理 1.5.7）依赖 $\pi$ 是半小（semismall）、$\pi_\frg$ 是小（small）这两个条件；译名必须能直接对应条件本身，不能意译成「半小型的」之类。
- **动作**：照原文脚注的定义直译：proper surjective $f:X\to Y$，$\{y:\dim f^{-1}(y)\ge d\}$ 的余维至少 $2d$（半小）或 $2d+1$（小）。
- **证据**：原文 §1.5 脚注（译者注：该脚注同时给出两个定义，译文保留为一处脚注）。
- **结论**：「半小映射」「小映射」，形容词与名词分开写，不合成一个词。

## 7. 五处 `\xymatrix` 的原样保留

- **意图**：原文的交换图用 `xy` 的 `\xymatrix` 写（`tgg`、`Slo`、`Slo U`、`Oga`、`Ogb` 等 5 处），直接换成 tikz-cd 会改动语义标签的位置。
- **动作**：preamble 加载 `\usepackage[all]{xy}`，且**放在 tikz 之后**（顺序颠倒会报 `! Package xy Error`）；其余简单图仍用 tikz-cd。
- **证据**：编译日志 0 error；渲染页 `work/main_p13.png` 中 `Slo`／`Slo U` 两图正常。
- **结论**：`xy` 与 tikz 共存可行，但顺序不可换；tikz-cd 的单元不能留空（否则 `No shape named`），三角图用 plain tikz。

## 8. 编号对账：两条腿，PDF 抽文不可靠

- **意图**：要证明 250 个编号对象与原文逐一相同，不能只靠「看起来对」。
- **动作**：写 `工程文件/scripts/sim_numbering_sy022.py`，把原文正文与译文各串成一个文档，按 `pcmi.cls` 的计数器规则推演一遍，输出编号序列比对；另写 `label_check_sy022.py` 比对 `\label`／`\cite` 集合。
- **证据**：250 个对象（equation 37、theorem 10、prop 3、lemma 2、remark 2、section 5、subsection 30、subsubsection 161）序列完全一致；label 123 对 123、cite 56 对 56，无缺无多。
- **结论**：先试过从 PDF 抽文比对（`number_check_sy022.py`），但译本 PDF 抽不出中文、原文抽出的 `N.M.K` 又混入 `\cite` 里的页码（如 4.14），不可用；判据只认源码推演 + label 集合。

## 9. `amsrefs` → `thebibliography` 的脚本化

- **意图**：原文 56 条文献用 `amsrefs` 的 `\bib{key}{type}{...}` 写（835 行），手工转 56 条极易出错，且 `\cite` 的 key 必须一字不差。
- **动作**：写 `工程文件/scripts/bib2tex.py`：正则抓 `\bib{key}{type}{...}`，用配平花括号的函数拆字段，按类型（article／book／incollection／proceedings／unpublished）分别拼装，丢掉 `issn`／`isbn`／`doi`／`review`。
- **证据**：生成的 `源码/chunks/ch18.tex` 含 56 个 `\bibitem`，与正文 56 个 `\cite` key 一一对应；编译 0 undefined citation。
- **结论**：文献不动一个 key、不改一个年份；只把英文标题保留为 `\emph{}`，其余按中文格式重排。

## 10. 笔误的处理：照译、译注、登记，三步缺一不可

- **意图**：译者不能替作者改正文（改了读者对不上原文），但也不能装作没看见。
- **动作**：E1（原文 1251 行把环路群叫成「正环路群」）、E2（原文 1431 行 `$b_i=\sum b_it^i$` 应为 `$b=\sum b_it^i$`）都按原文照译，紧跟一条 `\zy{…}` 译注指出错处、给出应为的写法、附来源（原文行号文脉），并在 `资料卡/04-术语文献勘误.md` 登记。
- **证据**：译本第 23 页脚注「译3」（`work/final_p24.png`）、§2.4.1 脚注「译4」；勘误表 E1／E2 两行。
- **结论**：正文一字不改，读者靠脚注与勘误表定位；这也是全书的译注体例（其余 6 条为易错预警与含糊点拨，同样每条带来源）。

## 11. 术语一致性回归

- **意图**：分块翻译跨越 19 个块、多次编译，术语漂移是最大的隐性缺陷。
- **动作**：全部译完后用 `grep` 扫全书，检查英文残留、黑名单句式（「被…所」「进行…的」「对于…而言」「使得…得以」）与冻结术语。
- **证据**：残留仅两处——§3.7 译注内的 "orbital integral"（解释双关所需）与参考文献的英文标题；黑名单句式 0 命中；`圈群` 5 个文件 12 处已统一为 `环路群`。
- **结论**：一致性检查必须在全书完成后做，靠分块时的自觉不够。
