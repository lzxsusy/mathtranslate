## 本工程的编号体制（与其他工程不同，勿套用）

底本用 `pcmi.cls`：`\numberwithin{equation}{subsection}`，且定理类环境全部挂 `[equation]`，因此**定理、公式、小节共用一个计数器**，印成 `section.subsection.counter`（定理 1.5.1、公式 (1.5.2)、小节 1.5.3）。更要紧的是作者重定义了 `\subsubsection`，让每个小节（包括空标题的）消耗一个公式号——复现代码在 `preamble.tex` 的 `\makeatletter ... \makeatother` 段，**照抄即可，不要改成 tikz/ctex 的默认编号**。

## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `You can't use '\ ' after \the.` | `\newtheoremstyle` 第 9 参数传了宏名，或第 7 参数留空 | 第 9 参数直写 `#1#2#3`，第 7 参数给 `{\relax}` |
| 小节编号印成 `0.0.1.1` | `\thesubsubsection` 写成 `\thesection.\thesubsection.\arabic{...}` | 写 `\thesubsection.\arabic{subsubsection}` |
| 全局编号从某个定理起整体 +1 | 少写了一个空标题 `\subsubsection{}` | 与 `work/orig/chNN.tex` 逐行比对，补齐 |
| `! Package xy Error` | `\usepackage[all]{xy}` 放在 tikz 之前 | 调换顺序：tikz 在前，xy 在后 |
| `Undefined control sequence \CC` / `\cohog` | `preamble_macros.tex` 缺原文 313–338 行的 `\def\A..\Z{\mathbb{·}}` | 该段已前置补入 `% mathbb %` 段 |
| `Undefined control sequence \Mpar` | 原文宏在第 798–799 行，超出脚本抽取范围 | 已手工追加到 `preamble_macros.tex` 末尾 |
| `\sB -> \xspace` 报错 | 未加载 xspace | `\usepackage{xspace}` |
| 脚注里的中文出现在数学模式 | 译注正文写了 `$…中文…$` | 中文进 `\text{}`，或移出数学模式 |
| `Numbering` 与原文不符 | 定理环境没挂 `[equation]` | 检查 `\newtheorem{thm}[equation]{定理}` 与 `\numberwithin{equation}{subsection}` |
| 目录缺「参考文献」 | `thebibliography` 不自动进目录 | `\clearpage\phantomsection\addcontentsline` |
