## 一句话主旨

Springer 纤维、仿射 Springer 纤维与 Hitchin 纤维是同一套几何直觉在三种域（代数闭域／局部域／整体曲线）上的化身：它们都承载 Weyl 群或其扩张的作用，而这些作用在轨道积分与迹公式里被翻译成表示论。

## 四步逻辑链

1. **局部几何**：$\pi:\tN=T^*\sB\to\sN$ 的纤维 $\sB_e$，维数 $d_e$、分支数、分支群 $A_e$（§1.2–§1.4）；$W$ 作用在 $\cohog{*}{\sB_e}$ 上，即 Springer 对应（§1.5）。
2. **$p$-进类比**：$\sX_\gamma\subset\Gr_G$，有限性（定理 2.5.2）、维数公式（定理 2.5.12）、$\tilW$ 作用（定理 2.6.2）；中心化子正则化 $J$ 与局部 Picard 群 $P_a$（§2.3.6）。
3. **算术**：$O_\gamma(\one)$ = 仿射 Springer 纤维上的点数 = Lefschetz 数（§3.2–§3.3）；稳定化与 Néron 模型（§3.4）；进而在 §3.6 接上基本引理。
4. **整体化**：Hitchin 纤维化（§4.2）、谱曲线与 $\cPic$（§4.3）、乘积公式（定理 4.4.2）、整体 Springer 作用（定理 4.5.2）。

## 踩过的坑（本工程特有）

1. **编号体制**：`\subsubsection` 消耗 equation 计数器，空标题也必须保留（161 处），否则全局错位；`\thesubsubsection` 只能写 `\thesubsection.\arabic{subsubsection}`。
2. **宏抽取范围**：`port_orig_macros.py` 只抓了原文 340–797 行，漏掉 313–338 的 `\def\A..\Z` 与 798–799 的 `\Mpar`／`\fpar`，两处已手工补入。
3. **`xy` 与 tikz 的顺序**：`\usepackage[all]{xy}` 必须在 tikz 之后，否则报错。
4. **`\newtheoremstyle`**：第 9 参数不能传宏，第 7 参数给 `{\relax}`。
5. **对账**：译本 PDF 抽不出中文，PDF 抽文比对不可用；判据是「label 集合」+「源码推算编号」两条腿。
6. **中文进 bash**：heredoc／argv 传中文会变 GBK，多行 Python 一律先落 `.py` 再跑。
