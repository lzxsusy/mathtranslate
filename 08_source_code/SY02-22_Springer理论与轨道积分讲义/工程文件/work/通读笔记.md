## 二、贯串全书的四条主线

1. **同一个计数器**。原文用 `pcmi.cls`，`\numberwithin{equation}{subsection}`，而且把 `\subsubsection` 也挂到公式计数器上，于是「定理 1.5.3」「(1.2.4)」与节标题序号共用一个递增序列。译文的导言区必须把这套机制原样复现，否则后续编号全错。这也是本书最需要在版面上小心的地方：`\subsubsection{}` 的空标题也要占一个号。
2. **三类纤维与三类对称性**。第一讲的 Springer 纤维 $\sB_e$ 带 Weyl 群作用；第二讲的仿射 Springer 纤维 $\sX_\gamma$ 带仿射 Weyl 群（及其中心化子格 $\L_\gamma$）作用；第四讲的 Hitchin 纤维带 Picard 簇作用。作者在引言里就用一张表把三者并列，全书反复用「纤维 + 对称性 + 表示论」这条线索串起来。
3. **从计数到上同调**。第三讲的核心是轨道积分等于某个商叠的 $k$ 点计数，再由 Grothendieck 迹公式得到上同调的 Frobenius 迹。这一步（定理 3.3.7、3.4.9）是全书技术核心，Ngô 的乘积公式（第四讲定理 4.4.1）则是它的整体版本。
4. **基本引理**。第三讲 §3.6 用两页陈述基本引理并指向 Ngô 的文章；第四讲的整体 Springer 作用与 Hitchin 纤维化正是 Ngô 证明的几何基础。读全书时可以把它当成「基本引理的几何背景」一课。

### 第一讲 Springer 纤维（910–1241）
- §1.1 The setup（`ss:notation`）：$G$ 连通约化、伴随群单、$\chark$ 大；$\frg$、$\sN$、$\sB$、$\tB=T^*\sB$。
- §1.2 Springer 纤维：$\mu:\tN=T^*\sB\to\sN$ 即 Springer 消解，$\sB_e=\mu^{-1}(e)$；Grothendieck 修改 $\tg=\frg\times_{\frg\sslash G}\frg$（`sss:Gr alt`），交换图 (1.2.1)，三个脚注解释 regular / regular semisimple。
- §1.3 例子：正则幂零（`sss:regular Spr`，用 $\SL_2$-三元组证明 $\sB_e$ 单点）、$\SL(V)$ 的旗（三个空标题 sss）、$\SL_3$ 次正则（`sss:SL3 subreg`）、$\SL_4$、A 型分支（`sss:Spr type A`，用标准 Young 表与共轭分拆）、$\Sp_4$（`sss:Sp4`）、次正则一般情形（`sss:subreg`）。
- §1.4 几何性质：连通性、等维性、维数公式 (1.4.3)、中心化子作用、纯性、奇偶消没。

## 四、语言与术语上的注意点

1. 原文大量用「essentially」「morally」，译文按惯例译「本质上」「原则上」，不逐字硬译。
2. 原文用第一人称复数（"we"），译文统一用「我们」，与样板工程一致。
3. 「Springer fiber」「affine Springer fiber」「Hitchin fiber」一律「Springer 纤维」「仿射 Springer 纤维」「Hitchin 纤维」，英文与中文之间加半角空格。
4. 记号 $\sB$、$\tB$、$\sN$、$\tN$、$\frg$、$\frt$ 在译文里保持原样，只在首次出现处用译注说明。
5. 原文的脚注很少（第一讲 3 条、第二讲若干），保留原编号；译者注走独立的 manyfoot 序列（「译 1」）。
