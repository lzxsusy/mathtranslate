# 报告 03 · 编号与术语对账

## 目标

证明两件事：① 译本的编号与原文逐条相同（不是「看起来对」）；② 术语全稿一致、无英文残留、无黑名单来源。

## 动作与证据

### 1. 标签集合对账

`工程文件/scripts/label_check_sy022.py`：分别抽原文（`\begin{document}` 到 `\begin{bibdiv}`）与译文 `chunks/*.tex` 的 `\label{}` 集合，再抽 `\cite{}` 的 key 集合，比对 missing／extra／重复。

| 项 | 原文 | 译文 | 结果 |
| --- | --- | --- | --- |
| `\label` | 123 | 123 | 集合完全相同，无重复 |
| `\cite` key | 56 | 56 | 集合完全相同，无缺无多 |
| `\bibitem` | — | 56 | 与 cite key 一一对应，无孤立条目 |

### 2. 编号序列推演

`工程文件/scripts/sim_numbering_sy022.py`：把原文正文与译文 chunks 各串成一个文档，按 `pcmi.cls` 的计数器规则（`\numberwithin{equation}{subsection}`；定理类共用 equation 计数器；`\subsubsection` 先取 equation 值再 `\refstepcounter{equation}`）各推演一遍。

| 类型 | 数量 |
| --- | --- |
| equation | 37 |
| theorem | 10 |
| prop | 3 |
| lemma | 2 |
| remark | 2 |
| section | 5 |
| subsection | 30 |
| subsubsection | 161 |
| **合计** | **250** |

250 个编号对象的序列逐一相同（0 mismatch）。

### 3. 抽样核对（与原文 PDF 对照）

用 `pymupdf` 抽原文 PDF 第 17–21 页文本层（`work/pdftext_17_21.txt`），§2.2 的小节号序列为 `2.2.1 / 2.2.3 / 2.2.4 / 2.2.5 / 2.2.7 / 2.2.8`，其中 2.2.2 与 2.2.6 是公式号；译本渲染（`work/main_p24.png`）与该序列完全吻合，说明「空标题小节也占号」的机制复现正确。

### 4. 不可用的判据（记录以免重犯）

`number_check_sy022.py` 曾试图用「原文 PDF 抽出的 `N.M.K`」与 `.aux` 比对：译本 PDF 抽不出中文（fandol 字体），原文抽文又混入 `\cite` 里的页码（如 4.14、6.10），且 `.aux` 只覆盖有 label 的对象。该判据作废，结论以第 1、2 条为准。

### 5. 术语一致性

`grep` 全稿：

| 检查 | 结果 |
| --- | --- |
| 英文残留 | 2 处：§3.7 译注内的 "orbital integral"（解释双关所需）、参考文献英文标题（应保留） |
| 黑名单句式「被…所／进行…的／对于…而言／使得…得以」 | 0 命中 |
| 冻结术语 | 发现 5 个文件 12 处「圈群／正圈群」，与术语表的「环路群／正环路群」不符 → 全部 sed 统一后重编译 |

## 结论

- 编号：250 个对象、123 个 label、56 个 cite／bibitem 全部对齐。
- 术语：112 条冻结表；一处回归（圈群）已修正；三处与 `TERMS.tsv` 的分歧有书面说明。
- 译注 8 条，全部带 `[来源：…]`，无黑名单来源。

## 遗留

- `\cite` 的中文化（「定理 4.14.1」）属排版习惯，不改变编号本身，若上游要求保留英文原样可批量回退。
