# 资料卡 02 · 论证地图

## 一、全书逻辑链

```
模形式/自守形式 = Γ\G/K 上的量子力学（L01）
        │  把「函数」换成「层」、把「谱」换成「几何」
        ▼
Fourier 变换（L03–L04）──有限/局部紧交换群上的对偶
        │  把 S^1 换成 G_m：Pontrjagin → Cartier（L05）
        ▼
电磁对偶 = 规范理论的 Fourier 变换（L06–L07）
        │  一维 TFT：局部算子 = 矩阵，谱分解 = 对角化
        ▼
拓扑量子力学 / 拓扑 Maxwell 理论 → 类域论（L08–L09、L13）
        │  交换情形已完整；非交换要「群 G 代替 G_m」
        ▼
扩张 TFT 与边界条件（L11–L12）：把「点」也赋予范畴
        │  Tannakian 重构（L14）：张量范畴 ⟹ 群 G^∨
        ▼
Bun_G、Hecke 代数（L17–L19）──几何侧的「函数空间」与「算子」
        │  局部算子代数 = Hecke 代数；谱分解 = Hecke 特征层
        ▼
TFT 的谱分解定理（L21–L24）：Z 沿 Spec 分解为特征层的积分
        │  对偶侧 = Loc_{G^∨}（局部系统叠）
        ▼
仿射 Grassmann 簇 Gr_G（L26）→ 几何 Satake：Perv(Gr_G) ≃ Rep(G^∨)（L27–L29）
        │  范畴化：把「特征函数」升成「Hecke 特征层」（L30）
        ▼
经典 Langlands：自守形式 ↔ Galois 表示，L 函数匹配（L31）
```

## 二、四个技术支柱

| 支柱 | 内容 | 讲次 | 作用 |

## 四、四条关键论断及其位置

1. **「几何 Langlands 是 Fourier 变换的巨大推广」**——L01 提出，L03–L06 铺垫，L22 兑现（原文 p.2、p.8–21、p.62–65）。
2. **「类域论 = 一维几何 Langlands」**——L08–L09、L13 用拓扑 Maxwell 理论与 $\mathrm{Pic}(X)$ 说明（原文 p.24–29、p.35–38）。
3. **「$G^\vee$ 来自 Tannakian 重构」**——L14 给出（原文 p.38–41），L27 在 $\mathrm{Perv}(\Gr_G)$ 上再用一次（原文 p.74–76）。
4. **「谱分解 = Hecke 特征层的积分」**——L22 陈述、L29 落到 $\Bun_G$ 上（原文 p.62–65、p.78–81）。

## 五、讲义的性质与读法提醒

- 这是**课堂记录**，不是教材：论证常以「这是 deep theorem」「细节略」带过，
  定理多引自 Gaitsgory、Nadler–Yun、AGKRRV 等文献，讲义给的是**图景与动机**。
- 作者反复强调「not all that complicated」与「be careful」并存：前者指结构清晰，
  后者指层的选取（Betti/de Rham/有限域）会改变陈述，读时须看清所在设定。
- 第 10 讲底本无正文，第 25 讲底本无标题；两处不影响主线。
