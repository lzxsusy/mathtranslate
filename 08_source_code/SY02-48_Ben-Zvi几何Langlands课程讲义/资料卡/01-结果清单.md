## 三、贯穿全书的四个断言（非编号条目）

1. **几何 Langlands = 二维 TFT 的谱分解**（L01、L22、L31）：$G$ 的谱侧由 $G^\vee$ 的局部系统给出，自守侧由 $\Bun_G$ 上的层给出；谱分解就是把「函子」写成「沿谱的积分」。
2. **电磁对偶即几何 Langlands 的物理化身**（L06–L07、L23–L24）：Montonen–Olive 对偶在 4d 规范理论中交换 $G$ 与 $G^\vee$，紧化到二维后给出 Hecke 特征层。
3. **特征标给出谱侧的最初近似**（L13、L15）：$\mathrm{Loc}(\mathrm{Pic})$ 中的特征局部系统定义 Hecke 特征层；扩张 TFT 把这个构造抬到边界条件上。
4. **经典的 Satake 与几何 Satake 是同一件事的两个影子**（L19、L28）：前者是球 Hecke 代数同构，后者是幺半范畴等价；$Z(G^\vee)$ 与 $\pi_1(G)$ 的 Cartier 对偶是连接两者的桥。
