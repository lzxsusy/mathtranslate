## 零、一句话主线

Ben-Zvi 把**几何 Langlands 纲领**讲成「**拓扑场论的谱分解**」：
二维拓扑场论（TFT）的局部算子代数是一族交换代数，谱分解把 TFT 拆成「特征层的积分」；
几何 Langlands 就是某个特定 TFT（规范场论的拓扑扭曲）在 Hecke 算子下的谱分解，
其对偶侧用电磁对偶（S 对偶）实现。于是：

- Fourier 变换 ⟷ 电磁对偶 ⟷ 谱分解，是同一个故事的三层；
- 类域论 = 一维（交换）情形，几何 Langlands = 高维（非交换）情形；
- 「函子性/对偶群 $G^\vee$」来自 Tannakian 重构；
- 最终目标是自守形式与 Galois 表示的对应及 $L$ 函数匹配。

这条线索解释了课程为何前半（1–16 讲）几乎不碰 Langlands 本身，
而在讲 TFT、对偶、Tannakian 与 Betti/de Rham；后半（17–31 讲）才落到 $\Bun_G$、Hecke 与几何 Satake。

## 一、动机与 Fourier（第 1–4 讲，p.2–15）

- **L01（p.2–5）**：课程纲领。模形式/自守形式 = 算术局部对称空间 $\Gamma\backslash G/K$ 上的
  调和分析（量子力学）；$\mathrm{SL}_2(\mathbb Z)$、同余子群 $\Gamma(N)$、$\Gamma_0(N)$；
  数域、位、$\mathrm{SL}_2(\mathbb Q_p)$；提出「Langlands 是 Fourier 变换的巨大推广」。
  有「Odysseus / Charybdis / Scylla / Calypso」的比喻，照译。
- **L02（p.5–8）**：两个 TFT 的对照——有限群 $G$ 的 Dijkgraaf–Witten 型 TFT 与
  「$\mathrm{Rep}(G)$ 的 TFT」（即 $G$ 的量子力学/规范理论），说明同一 TFT 的两种描述；
  引入 $Z(\mathrm{Rep}(G))$ 式中心结构，为后面的谱分解埋伏笔。
- **L03（p.8–11）**：谱理论与层论。把「算子代数的谱」翻译成几何：
  交换代数 $\rightsquigarrow$ 仿射概形 $\mathrm{Spec}$；模 $\rightsquigarrow$ 拟凝聚层；
  谱分解 $\rightsquigarrow$ 层的直和分解。这是全书的技术脊梁（9 个编号条目，本讲最密）。
- **L04（p.11–15）**：Fourier 理论。$\mathbb R^n$ 的经典 Fourier 变换与
  「函数空间 ≅ 函数空间」的对偶；Poisson 求和；有限交换群上的 Fourier 变换
  （即 Pontrjagin 对偶的初阶），提示「Fourier = 函子」。

## 二、对偶与拓扑场论（第 5–8 讲，p.15–27）

- **L05（p.15–18）**：Pontrjagin 对偶（局部紧交换群 $\leftrightarrow$ 特征标群）与
  Cartier 对偶（交换群概形 $\leftrightarrow$ 其对偶，用 $\mathbb G_m$ 代替 $S^1$）；
  「对偶的对偶 = 自身」；有限群情形与 Fourier 变换一致。
- **L06（p.18–21）**：电磁对偶。$\mathrm{U}(1)$ 规范理论的 S 对偶把「电」与「磁」互换，
  耦合常数 $\tau\mapsto -1/\tau$；对偶群 $\mathrm{U}(1)^\vee=\mathbb Z$；
  与 Fourier 变换的结构同构：**电磁对偶 = 规范理论的 Fourier 变换**。
- **L07（p.21–24）**：拉氏量量子场论。路径积分、配分函数、拓扑扭曲（topological twist）、
  超对称量子力学；说明为何「拓扑」场论可以精确计算。
- **L08（p.24–27）**：拓扑量子力学、拓扑 Maxwell 理论与类域论。一维 TFT 的局部算子 =
  矩阵；$\mathrm{U}(1)$ 拓扑 Maxwell 理论的谱分解给出**类域论**（idele 类群、Weil 群）；
  本讲是「一维情形已是 Langlands」的关键示范。

## 三、类域论、扩张 TFT 与 Tannakian（第 9–16 讲，p.27–46）

- **L09（p.27–29）**：类域论与函数域。整体类域论（idele 类群 ↔ 交换 Galois 群）、
  函数域情形（曲线 $X$、$\mathrm{Pic}$、$\mathbb A_X$），为几何化做准备。
- **L10（p.29）**：**底本只有一行日期，无标题无正文**。译本只给说明。
- **L11（p.29–33）**：边界条件与扩张 TFT。有边界的 TFT 给边界条件一个范畴；
  扩张 TFT（extended TFT）把点也赋予数据（$n$ 范畴）；局部算子与边界条件的对偶。
- **L12（p.33–35）**：扩张 TFT 与拓扑 Maxwell 理论。用扩张 TFT 重述 $\mathrm{U}(1)$ 理论，
  边界条件 = 层的对象，缺陷 = 函子。
- **L13（p.35–38）**：几何类域论。曲线 $X$ 上 $\mathrm{Pic}(X)$ 与
  「$X$ 的 étale 基本群」的对应；几何化后的类域论 = 一维几何 Langlands。
- **L14（p.38–41）**：Tannakian 重构。张量范畴 + 纤维函子 ⟹ 群概形 $G$；
  「对偶群 $G^\vee$ = $\mathrm{Rep}(G)$ 的自同构群」；这是 $G^\vee$ 出现的机制。
- **L15（p.41–43）**：$1$-平移的 Cartier 对偶。导出/平移（shifted）版本的 Cartier 对偶，
  处理 $\mathbb G_m[1]$ 之类；为 Betti/de Rham 对偶铺路。
- **L16（p.43–46）**：Betti 与 de Rham。Betti 侧（拓扑/奇异上同调、局部系统）
  与 de Rham 侧（$\mathcal D$ 模、平坦联络）的对照，及 Riemann–Hilbert 对应。

## 四、$\Bun_G$ 与 Hecke（第 17–20 讲，p.46–59）

- **L17（p.46–49）**：主 $G$-丛的模叠 $\Bun_G$。曲线 $X$ 上 $G$-丛的分类、
  $\Bun_G$ 的几何（光滑性、连通分支 = $\pi_1(G)$，即与 $\mathrm{Pic}$ 的关系）。
- **L18（p.49–53）**：Hecke 代数。Hecke 对应 $\Hck$（修改一点处的丛）、
  几何 Hecke 算子、$\Hck$ 作为 $\Bun_G$ 上反常层的卷积代数；
  与经典 Hecke 算子（模形式）的类比。
- **L19（p.53–57）**：算术局部对称空间上的 Hecke 代数。回到数论侧：
  双陪集 $\Gamma\backslash G(\mathbb A)/K$、Hecke 算子的交换性、Satake 同构。
- **L20（p.57–59）**：TFT、界面与边界条件。界面（interface）= 两个 TFT 之间的畴；
  界面上的局部算子；用界面统一「Hecke 算子 = 一个界面」。

## 五、局部算子、谱分解与缺陷（第 21–24 讲，p.59–69）

- **L21（p.59–62）**：局部算子的交换代数。二维 TFT 中局部算子构成交换代数
  （由「点不可移动」得出交换性）；$\mathrm{Spec}$ 的几何解读。
- **L22（p.62–65）**：TFT 中的谱分解。TFT 的谱分解定理：$Z$ 沿 $\mathrm{Spec}$ 的分解、
  特征层（eigensheaf）的积分表示；这是全书的技术高潮之一。
- **L23（p.65–67）**：缺陷与缺陷算子。缺陷（defect）作为「把 TFT 撕开再缝合」的对象；
  缺陷算子 = 边界条件的对偶；没有编号条目，纯散文，注意句子切分。
- **L24（p.67–69）**：缺陷算子与 Maxwell 理论。在 $\mathrm{U}(1)$ 拓扑 Maxwell 理论里
  显式计算缺陷算子，验证谱分解；同样无编号条目。

## 六、仿射 Grassmann 簇、几何 Satake 与经典 Langlands（第 25–31 讲，p.69–89）

- **L25（p.69–71）**：**底本标题为空**，正文讲 $G^\vee$ 与「对偶侧」的物理解释；
  2 个编号条目。译本用「无标题的一讲」。
- **L26（p.71–74）**：仿射 Grassmann 簇 $\Gr_G = G(\!(t)\!)/G[\![t]\!]$。
  格（lattice）描述、$\Gr$ 的 Schubert 胞腔、$\Gr_{\mathrm{Gr}}$ 与 $G^\vee$ 的关系。
- **L27（p.74–76）**：几何 Satake 对应。$\mathrm{Perv}(\Gr_G)$ 作为张量范畴
  $\cong \mathrm{Rep}(G^\vee)$（Tannakian 重构再登场）；卷积积与融合积。
- **L28（p.76–78）**：抛物诱导与限制。$\mathrm{Perv}$ 沿 Levi 的抛物诱导、
  「$G^\vee$ 与 Levi 对偶」；为 L29 做准备。
- **L29（p.78–81）**：几何 Satake 续。3 个 Theorem：Satake 等价、纤维函子的存在、
  与 $\Bun_G$ 上 Hecke 算子的相容性。
- **L30（p.81–85）**：范畴化。为什么 Langlands 对应要范畴化（函数空间 → 范畴、
  谱分解 → 层的分解）；2 范畴与导出结构；Hecke 特征层作为「范畴化的特征向量」。
- **L31（p.85–89）**：经典 Langlands。整体 Hecke 代数、Hecke 特征函数、
  $L$ 函数 = 特征多项式的倒数；Galois 表示的 $L$ 函数；两者的匹配（含作者的
  `(TODO: p versus ρ was not clear, beware/sorry!)` 自注，照译）；末尾参考文献表 17 条。

## 七、难点与注意

1. **物理词汇密集**：TFT、twist、defect、interface、boundary condition、path integral。
   一律按 glossary；「twist」在拓扑场论语境译「扭曲」，在层论语境（$1$-shifted）另作处理。
2. **$G$ 与 $G^\vee$ 双向使用**：正文常直接写 $G$，靠上下文区分「群」与「对偶群」；
   凡原文明确写 $G^\vee$ 才译「对偶群 $G^\vee$」，不自行补。
3. **公式拍扁**：文本层 $\prod$ 拆成 `Y`、$\coprod$ 变 `a`、$\otimes$ 偶尔丢失，
   L31 的 $L$ 函数公式尤须对页面图。
4. **口语与 TODO**：底本是现场记录，含「yeet」「be careful」与 10 余处 `(TODO: …)`，
   照译保留，报告 §三 登记。
5. **编号条目分布不均**：L01、L08、L12、L16、L23、L24、L31 为 0 条（L08 亦仅 1 条），L03（9 条）、L14（6 条）
   最密；译手按 `work/条目总表.tsv` 核数。
6. **讲师原话的笔误**：如 L31 "sinilar"（similar 之误）、"p versus ρ" 自注、
