## 三、疑点

1. **(11.13) 首项写法**：原文作 $0\to H^1(\Sigma;\cO_\Sigma)/H^1(\Sigma;\Z)\to H^1(\Sigma;\cO_\Sigma^\times)\to H^2(\Sigma;\Z)$，与通常指数正合序列 $0\to H^1(\Sigma;\Z)\to H^1(\Sigma;\cO_\Sigma)\to H^1(\Sigma;\cO_\Sigma^\times)\to H^2(\Sigma;\Z)$ 的写法不一致（原文把首项写成商）。译文照原文排印，未改；若按后者，左端应是 $H^1(\Sigma;\Z)$ 而非商。
2. **$\cC$ 的取值**：p.31 定义中 $\cC$ 为任意对称幺半 2-范畴；同页下取 $\cC=\mathcal{C}at_\C$。原文在 $\QCoh$ 与 $\mathcal{C}at$ 之间反复切换字体，译文按语义分别写 `\cC` 与 `\mathcal{C}at_\C`。
3. **页末孤括号**：p.30、p.32 段末的孤立「(」是 PDF 页面 ◀ 标记被文本层捕获的残留，不译。
4. **题词与记录者注**：p.29 的「There's a pun here…」题词与「Note: I missed Thursday's lecture…」记录者注均照译，保留其「注：」「（注：…）」的口吻。
5. **(11.5) 的配对记号**：原文 $Z(N)=\langle Z(N_1),Z(N_2)\rangle_{Z(P)}$，下标为 $Z(P)$，译文照排；该式的「范畴化意义」原文只作定性说明，未给定义。
6. **脚注编号**：原文脚注 10、11、12 在译文中为自动编号，正文引用处只留脚注标记，不写原编号。
