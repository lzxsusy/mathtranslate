## 三、疑点

1. **$W^{un}$ 与 $W^{ur}$ 混用**：p.27 正文先写 $W^{un}(C)$，随即写「极大阿贝尔商 $W^{ur,ab}(C)$」；p.28 定理又写 $W^{un,ab}(C)$。原文 un／ur 不统一（当为 unramified 的两种缩写），译文照原文，未合并。
2. **$F$ 一字母两义**：p.28「设 $\rho$ 是局部系统，看成映射 $\rho\colon\pi_1^{\et}(C)\to F$，其中 $F$ 是某个系数域」中的 $F$ 与全讲的函数域 $F=k(C)$ 同字母而不同义。原文如此，译文保留，读者可由上下文分辨。
3. **$\mathrm{Cl}_F$ 的字体**：p.27 原文用花体 $\mathrm{C}\ell_F$ 类的类群记号，译文写 `\mathrm{Cl}_F`（`\ell` 版在中文段落中易与字母 l 混淆），语义不变。
4. **$\Pic^\vee(C)\cong\mathrm{Loc}(C)$**：p.28 原文如此（未写 $\mathrm{Loc}_1$），与 p.27 的 $\mathrm{Loc}_1(\Spec\cO_F)$ 记号不同；译文照原文。
5. **「$\mathbb{Q}_\ell$ 与 $\mathbb{C}$ 同构」一段**：原文强调该同构高度不典范且不尊重拓扑，译文照译并保留感叹号语气。
