## 三、疑点

1. 原 (18.14) 印作 $\C[K\backslash G/K]=\C[G\times K\times G/K]^G$，与下一句「it sits inside $\C[G/K\times G/K]$」及数学均不符；译文按 $\C[G/K\times G/K]^G$ 排，并在该处加译注说明原文如此（p.51）。
2. 原 (18.10) 作 $f\boxtimes h=\pi_1^*f\cdot\pi_2^*h$，但前句变量为 $f,g$，$h$ 疑为 $g$ 之误；译文照录 $h$，未改。
3. 原 (18.5) 的 $\cH_{G,K}=(V_{G,K})^K$ 与 (18.7) 的等号链按原文；$V_{G,K}=\C[G]\otimes_{\C[K]}\C$ 的左、右模结构未展开。
4. 例 18.5 中 $T^2=(q-1)T+q$ 与 $(T+1)(T-q)=0$ 的符号、以及 $q=1$ 时的讨论，均按原文。
