## 三、疑点

1. **下标笔误**：p.15 原文作 $\Lambda^\vee\subset\Hom(\Z^n,\Z)$，而同句上面写的是 $\Lambda\subset\Z^d$，$n$ 应为 $d$。译文照原文排印，加译注说明（\yizhu 第 1 条）。
2. **交换子写法**：p.16 原文作 $\xi f = f\xi + \hbar f'$，按字面即 $[\xi,f] = \hbar f'$（与 $p_j = i\frac{d}{dq_j}$ 的符号约定相合）。未改，加译注说明（\yizhu 第 2 条）。
3. **Fourier 反演式**：p.15 原文作 $f(x) = \int_V \widehat{f}(t)e^{2\pi i\langle x,t\rangle}dt$；按反演公式左边应是 $\widehat{f}(x)$ 或被积函数中的 $f$。译文照原文排印，未改，留待 lead 判断是否需要统一为反演式。
4. **作者自我更正照译**：p.17 先说「我们期待 $\mathbb{G}_a$ 映到 $\mathbb{G}_a$」，随即指出 $\mathbb{G}_a$ 的 Cartier 对偶其实是形式完备化；两说并存于原文，译文照原顺序保留，不合并。
5. **表达式记号**：$T := \R^d/\Lambda = \Lambda\otimes_\Z U_1$ 中两个写法同段并列（原文如此），译文照原文。
