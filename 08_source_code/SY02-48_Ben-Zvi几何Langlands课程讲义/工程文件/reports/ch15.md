## 三、疑点

1. **(15.6) 交换图文本层损坏**：原文该图两个箭头都标成 $\pi_2$、且 $G$ 与 $G^\vee[1]$ 的位置交错。按 (15.7) $\pi_{2*}(\pi_1^*\cF\otimes L)$ 复原为 $G\xleftarrow{\pi_1}G\times G^\vee[1]\xrightarrow{\pi_2}G^\vee[1]$ 的 `tikzcd`。原图若另有第三个箭头，图不完整。
2. **(15.12) 的 $f'$**：原文印作 $\xi f=f\xi+f'$。译文写成 $\xi f=f\xi+\xi(f)$，即在一般向量场下把 $f'$ 读作 $\xi$ 作用于 $f$（当 $\xi=\partial_x$ 时两者一致，与前句「$T_X\to\End(\cF)$」相容）。这是本讲唯一一处对原文符号的改写，特此登记。
3. **非叠 $\Pic(C)$ 多一个因子**：原文说「非叠的 $\Pic(C)$ 分解为 $\Z\times\mathrm{Jac}(C)\times B\G_m$」，而上一句已声明非叠对象不含 $B\G_m$。译文按 $\Z\times\mathrm{Jac}(C)$ 排出，并加译注说明原文多印的因子。
4. **原文公式损坏**：p.43 的 $V_{\mathrm{dR}}=V\,\text{?}\hat V$ 是 $V/\hat V$ 的文本层损坏；p.42 短正合列 $0\to\G_m\to L\to G\to 0$ 与 p.41 的箭头也在文本层丢失，均按数学惯例补全。
5. **(QC)(Z)**：p.41 原文写作 "(QC)(Z)"（括号错位），译文作 $\QCoh(\Z)$；同句「或 $\Z$-分次向量空间」说明所指。
6. **$\C[G]$ 与域 $k$**：p.41 在「对域 $k$」的语境里却写 $G^\vee:=\Spec(\C[G],*)$，前后记号的基域不一致（$\C$ 疑为原文笔误或排版习惯）。译文照原文保留 $\C$。
7. **抽取伪影未入正文**：p.43 首行「Arun Debray June 3, 2021」与散落的孤立括号「(」是 PDF 抽取残留（后者在原文里对应被截断的脚注/括号），不属于讲授内容，故未译入。
8. **$\mathrm{Jac}(C)\simeq\mathrm{Jac}(C)^*$**：p.42 断言 Jacobian 自对偶（主极化），原文未给理由，译文照译。
9. **$A^*$ 与 $A^\vee[1]$**：p.42 说「$A^*$ 与 $A^\vee[1]$ 之间有等价，即 $A^*$ 是 $A$ 上乘性线丛构成的阿贝尔簇」。前者是导出范畴层面的陈述，后者是集合层面的描述，原文混用一次，译文照原样。
