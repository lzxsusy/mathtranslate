## 三、疑点

1. **原文编号错位（已处理）**：p.44 第二组列表里，第（3）条（辛情形、Fukaya 范畴）被印在（1）（2）之前。译文按编号移回（1）（2）之后，并加译注说明；内容一字未改。
2. **$M_\lambda\cong M_{\lambda+z}$**：原文 p.45 印作 "$M_\lambda\cong M_{\lambda+z}$"，而上下文说 $n\in\Z$、$M_\lambda$ 只依赖单值 $\exp(\lambda)$。按此应作 $M_{\lambda+n}$（或 $M_{\lambda+1}$），"$z$" 疑为文本层损坏。译文写 $M_{\lambda+n}$，特此登记。
3. **脚注里的 $\QCoh^{!}(\cF)$**：原文脚注 18 写 "ind-coherent sheaves, $QC^{!}(F)$"，$F$ 疑为 $X$（或 $M$）之误；译文照原文排作 $\QCoh^{!}(\cF)$，未改。
4. **忘却映射的「核」**：p.46 原文 "the kernel is $\Gamma(\mathrm{Jac}(C),\Omega^1)\cong T^*_e\mathrm{Jac}(C)\cong H^0(C;\Omega^1)$"，接着说 forgetful map 是仿射丛。此处 "kernel" 与「纤维」混用（映射的核按通常意义是 $0$，此处指纤维）。译文照原文作「其核为……」，并保留「仿射丛」一句，未擅改为「纤维」。
5. **$\Omega$ 与 $\Omega^1$ 不一致**：p.46 的 $T^*\mathrm{Jac}(C)\cong\mathrm{Jac}(C)\times H^0(C;\Omega)$ 与前式 $H^0(C;\Omega^1)$ 记号不同（同义）。译文照原文分别保留 $\Omega$ 与 $\Omega^1$。
6. **$\pi_1(\mathrm{Jac}(C))=H_1(C;\Z)$**：原文用等号，严格说应为同构（或典范等同）。译文保留等号。
7. **括号与语法破碎**：p.45 原文 "these finite difference operators has the same relation as for $D_{\C^\times}$)" 多一个右括号且主谓不一致；译文按语义整理为「这些有限差分算子与 $D_{\C^\times}$ 具有相同的关系」，未保语法错误。
8. **抽取伪影未入正文**：p.43/p.45 的「Arun Debray June 3, 2021」作者行与孤立括号「(」属 PDF 抽取残留，未译入。
9. **（TODO：？？）**：p.44「这是对无穷小邻近对象的一种等变性（TODO：？？）」原文只留两个问号，未补猜内容，照译。
10. **整段道歉**：p.45「（TODO：漏了一个，抱歉。总体而言，今天我对于对象何时该是拓扑空间、何时是代数簇一直很困惑，也就是 $\C^\times$ 与 $\G_m$ 或 $\C/\Z$ 之类何时有区别。这可能让笔记相当不清楚。抱歉。）」照译全段，未删节。
