## 三、疑点

1. **记号排印**：原文把因子化同调排成 `$R\otimes\Sigma$`，同一段又说它「另有一个名字，记作 $\int_\Sigma R$」，二者不一致，疑 live-TeX 时上标丢失。译文照原文排印，并在首现处加译注说明（不擅自改记号）。
2. **人名下标不一致**：p.71 讲意大利饺时先说「从 $P_1$ 出发、到 $P_2$ 结束」，紧接着又说「因此 $P_0$ 与 $P_1$ 必须在 $x$ 之外一致」，$P_0$ 与 $P_2$ 疑有一处笔误。译文照原文，未改。
3. **记号不统一**：同段「拼成一个张量积 $\Sigma\Vect_{\Z\text{-}\mathrm{gr}}$」无 $\otimes$，而 (25.4) 作 $\Sigma\otimes\QCoh(\mathrm{pt}/\G_m)$。译文照原文分别排印。
4. **版式伪影**：p.70 段落之间有一处手写状残留「B · C」，p.71 若干段首有孤立「(」；均为 PDF 版式残留，未译。
5. **口语与铅笔注**：`(TODO: which dimension?)`、`(TODO: not sure about this)`、`(TODOcite)` 等一律照译为「（TODO：……）」，未删。
