## 三、疑点

1. 原文用 $F_C$ 表示函数域、$F$ 表示数域，$F_C$ 未在文中定义；译文照录，未改写（p.47）。
2. 双陪集公式 (17.5a)(17.5b) 的 $\prod'$ 与嵌套商位置已按页面图 p047 核对；文本层中 $\prod'$ 曾拍扁，译文按图排。
3. 原文口语 "throw away the stabilizers" 译「扔掉稳定化子」，未术语化；加译注说明其含义是取群胚的底层同构类集合（p.47）。
4. 原文 $pt$（单点）未改为 $\mathrm{pt}$，与后文 $pt/G$ 的写法保持一致。
