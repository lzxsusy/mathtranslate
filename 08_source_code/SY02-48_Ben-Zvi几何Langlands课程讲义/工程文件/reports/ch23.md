## 三、疑点

1. **$\Box$ 是底本的占位记号**：p66 "Let □ be a tangential structure" 在页面上就是一个方框字形（非缺字、非 OCR 噪声），译文用 `\Box` 逐字保留，并加译注说明。
2. p66 中部的"⌣·⌢"是装饰性分隔符（页图上是一条波浪线），不是内容，不译。
3. p66 "our gate an object of the 2-category …" 一段末尾的"$Z^{n+1}_{\cM^0_Z})$"多一个右括号，按语义删去。
4. p66 "群同态 $H_n\to O_n$"底本如此（切结构的一般表述），保留，未改成 $BH_n\to BO_n$。
5. p67 "To be a little more precise, this means that TODO." 中的 TODO 是作者未写完的句子，照译为"这意味着 TODO。"，未补写。
6. **排版改动**：p66 那两个"对闭 $(n-1)$-流形 $M$，赋 $\cO(\Map(\pi_0(M),X))$，即 $R\otimes\pi_0(M)$"式的长行内公式导致 Overfull 40.2pt（压右边距约 3 字），已改为两行 `align*`，Overfull 归零；语义与原文一一对应。
7. 原文"$Z(M)\in B^{n+1}_{\cM^0_Z}(M)$"与"$B_{\cM^0_Z}(N)$"是同一族记号在高一维/低一维的两种用法，译文照底本保留上标差异。
