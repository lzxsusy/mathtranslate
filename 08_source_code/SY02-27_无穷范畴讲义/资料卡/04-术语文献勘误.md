## 一、术语定名

### 1.1 原则

1. **先冻结后动笔**：每讲开译前先查 `glossary.tsv`；同一英文词全书只用一个中文名，新词先入表。
2. **依据分三级**：**A** = Lurie《Higher Topos Theory》《Higher Algebra》《Kerodon》原文用语或书内自带对照；
   **B** = 同类中文教材/讲义的通行译法（仅作旁证，须与 A 或上下文相容）；**I** = 译注者据上下文推断，
   首次出现处标“〔译者按（无外部依据）〕”或 `[来源：I]`。
3. **保留不可译缩写**：$\infty$、$(\infty,1)$、$E_k$、$E_\infty$、$t$-结构、Kan、Yoneda、Dold–Kan、
   Lurie、Quillen、Joyal、Bousfield、Boardman–Vogt–May 等一律不作音译或意译。
4. **人名不音译**；术语首次出现附英文原词（如“拟范畴（quasi-category）”）。
5. **避免与经典术语撞车**：`straightening / unstraightening` 不译“平展/去平展”（“平展”已是 étale 的通行译名），
   统一作**拉直 / 反拉直**，见 §1.3。

### 1.3 易混词对

| 词对 | 区别 | 译本处理 |
| --- | --- | --- |
| weak equivalence / equivalence | 前者是模型范畴的类 $W$；后者是 $\infty$-范畴内部的可逆态射 | 分别作“弱等价”“等价”，不互换 |
| fibration / cofibration | 模型结构的两个类，方向对偶但中文不都加“余” | 纤维化 / 上纤维化 |
| limit / homotopy limit | 前者是 1-范畴的泛锥；后者要求同伦连贯的锥 | 极限 / 同伦极限 |
| strict / weak $n$-category | 结合律取等号 / 只到高阶同伦 | 严格 / 弱 |
| monoidal / symmetric monoidal | 前者只有结合子；后者另有交换子与辫 | 幺半 / 对称幺半 |
| algebra / module | 操作子上的代数 vs 环上的模 | 代数 / 模，$\Alg_{E_k}$、$\Mod_R$ 不混 |
| presentable / accessible | 可表现 = 可表现 + 余完备；accessible 单说“可及” | 可表现 / 可及 |
| compact / finite | 紧 = $\Hom(X,-)$ 保滤过余极限；有限是构造性概念 | 紧 / 有限 |
| straightening / unstraightening | 函子 ↔ 笛卡尔纤维化的互逆构造 | 拉直 / 反拉直（不用“平展”） |
| truncation / skeleton | 截断保留低阶同伦；骨架是范畴的等价代表 | 截断 / 骨架 |
| connected / connective | 空间连通 vs 谱在负次数无同伦群 | 连通 / 连接 |
