## 一、这本书是什么

一本**不重技术**的 $\infty$-范畴入门：作者自己的定位是“给这一领域基础参考文献（Lurie 的 HTT、HA、
Kerodon）当向导”。全书 27 讲，每讲 4–12 页，讲与讲之间是**同一门课的时间顺序**，不是自成章的书：
第 1–5 讲把“同伦连贯的范畴”从口号落到拟范畴这个模型；第 6–12 讲在这一模型里重做极限、Yoneda、伴随；
第 13–18 讲进入可表现性与稳定同伦论（谱、$t$-结构、导出范畴、Dold–Kan）；
第 19–27 讲是高阶代数（笛卡尔纤维化、拉直、操作子、代数、模、张量积、$E_\infty$-环）。

**不假设读者学过 $\infty$-范畴**，但假设学过研究生代数、代数拓扑与同调代数（第 1 讲 §2 从
Eilenberg–MacLane 的定义讲起，第 2 讲直接用 Quillen 模型范畴）。

## 四、阅读路径

1. **零基础通读**（约 2 周）：1 → 2 → 3 → 4 → 5，然后 6、11、12；跳过 8、10 的模型范畴细节。
2. **想用 $\infty$-范畴做代数几何**：1–5，6–7，11–13，19–20（拉直），再按需 21–22。
3. **稳定同伦/导出代数**：1–5，13–18，22–25。
4. **只查定义**：`01-概念.tsv` 按 PDF 页排序；`index.jsonl` 是全量索引；`cards/concepts/*.json` 是单卡。

## 六、统计口径

- 概念卡以“**一个可独立命名的数学对象或构造**”为单位；同一对象在不同讲的重复出现只在首现讲立卡，
  后续讲用 `depends_on` 指回。
- 命题卡只收**有编号的**陈述（Definition/Theorem/Proposition/Lemma/Corollary/Exercise/Remark 等），
  编号段落（$n.m$）若只是定义的一部分则不另立卡。
- 每张卡的 `quote` 是底本英文原句（≤120 字符），可在 `工程文件/work/src/lecNN.txt` 中检索到；
  `rights: rewritten` 表示释义而非直译。
- 对齐卡只收**能写成 Lean 命题**的概念—命题对；缺口按 `04_playbook` 的 G1（定义层）/G2（推理层）/
  G3（库外对象）分类，本资料卡全部为 `gap`，不冒充 `certified`。
