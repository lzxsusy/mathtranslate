# 通读笔记 · SY02-47

底本：Sam Raskin（讲授），Lin Chen（笔记），*Notes for “Geometric Langlands for Projective Curves”*，2025 年 7 月 7–11 日，18 页。PDF 页 = 印刷页，偏移 0。

## 1. 三句话主旨

- **问题**：给定光滑射影曲线 \(X/k\) 上秩 1 或 \(\mathrm{SL}_2\) 的局部系统 \(\sigma\)，如何在 \(\mathrm{Bun}_{G}\) 上构造一个层 \(\mathcal F_\sigma\)，使它的 Hecke 作用恰好是“与 \(\sigma\) 的张量积”？
- **方法**：先用几何类域论（Deligne 的 \(\mathrm{Sym}^d X\) 下降）处理 \(G=\mathbb G_m\)；再用常数项、Fourier–Deligne 变换与 Hecke 函子处理 \(G=\mathrm{PGL}_2\)；最后用 \(\mathrm{Rep}(\check G)_{\mathrm{Ran}}\) 把 Hecke 函子、Whittaker 系数与范畴化几何 Langlands 统一起来。
- **结论**：\(\mathrm{PGL}_2\) 情形有 Drinfeld–Laumon–FGV 定理；一般 \(G\) 情形有特征层的存在唯一性（\(\mathrm{char}\,k=0\)，Arinkin–Beraldo–Campbell–Chen–Faergeman–Gaitsgory–Lin–Raskin–Rozenblyum），以及 \(D\text{-}\mathrm{mod}(\mathrm{Bun}_G)\simeq \mathrm{IndCoh}_{\mathrm{Nilp}}(\mathrm{LS}_{\check G})\) 的范畴等价（Gaitsgory–Raskin 系列）。

## 2. 论证地图

```
§1.1 层论三情形（Betti / ℓ-进 / de Rham）
   │
§1.2 交换情形：χ_σ on Bun_{G_m}
   │   Construction 1.2.2（Betti，用 π_1）
   │   Construction 1.2.4（Deligne，Sym^d X + 下降）
   ▼
§1.3 非交换起点：G = PGL_2，F_σ 只要求 perverse
   │   Bun_{PGL_2} = Bun^{even} ⊔ Bun^{odd}；Bun_B 分层；U_n 开子叠
   ▼
§2.1 尖点性：CT_* = q_* p^!；CT_*F = 0
   │   Prop 2.1.5（d > 2g−2 时 !-限制为 0）
   │   Thm 2.1.8（第二伴随）⇒ Cor 2.1.10（*-限制为 0）⇒ Cor 2.1.11（从 U_n 干净延拓）
   ▼
§2.2 系数：coeff_0(F) = C·(Bun^Ω_N, p_N^! F ⊗^! φ^!(exp))
   │   模形式类比：a_n ↔ coeff_D；a_1 ↔ coeff_0
   ▼
§3.1 coeff_D；Goal 3.1.2（coeff_D(F_σ) ≃ ⊗ Sym^{n_i}(σ_{x_i})）
   │   Prop 3.1.4（F 由两个相邻系数唯一确定；仅 PGL_2）
   ▼
§3.2 Fourier–Deligne 变换：把 coeff_d 写成 restriction ∘ Four ∘ p^!_{−d}
   │   证明 Prop 3.1.4
   ▼
§3.3 Thm 3.3.1（Drinfeld–Laumon–FGV）：F_σ 存在、perverse、分支上不可约、Hecke 特征层
   ▼
§4.1 一般 G：几何 Satake；Hecke 函子 H_V；Rep(Ĝ)_Ran → End(Shv(Bun_G))
   ▼
§4.2 Hecke 特征层的正确概念：Rep(Ĝ)_Ran-线性函子；H_V(F) ≃ F ⊠ V_σ
   ▼
§4.3 Conj 4.3.1 / Thm 4.3.2（存在唯一、perverse、尖点、半单、特征圈、通用秩）
   ▼
§5.1 Whittaker 系数：coeff_D(F) ≃ coeff_0(H_{⊠V_{λ̌_i},x}(F))（几何 Casselman–Shalika）
   │   coeff^ult：Shv(Bun_G) → Rep(Ĝ)_Ran；尖点上全忠实
   ▼
§5.2 范畴化：Loc: Rep(Ĝ)_Ran → QCoh(LS_Ĝ)；LG,coarse；Arinkin–Gaitsgory 修正；
        LG: DMod(Bun_G) ≃ IndCoh_Nilp(LS_Ĝ)
```

关键依赖链：§3.3 的 \(F_\sigma\) 存在性依赖 §3.2 的 Fourier 反演与 §2.1 的尖点延拓；§4.3 的一般定理把 §3.3 作为 \(G=\mathrm{PGL}_2\) 的特例；§5.1 把 §3.1 的系数推广到 Whittaker 系数；§5.2 把 §5.1 的函子范畴化。

## 3. 体裁清单（原创 vs 引用）

- §1.1–§1.3：课程设定与经典构造。交换情形归功于 Deligne（未发表；课堂称 Construction 1.2.4）；非交换起点是 Drinfeld–Laumon 的 \(\mathrm{PGL}_2\) 理论。
- §2.1：常数项与“第二伴随”归功于 Drinfeld–Gaitsgory；尖点延拓的推论是课堂整理。
- §2.2–§3.2：系数与 Fourier 变换的论证是 Drinfeld 的 \(\mathrm{GL}_2\) 证明的讲义版；Prop 3.1.4 是课堂给出的唯一性论证。
- §3.3：Thm 3.3.1 归功于 Drinfeld、Laumon、Frenkel–Gaitsgory–Vilonen。
- §4.1–§4.2：几何 Satake 归功于 Mirković–Vilonen；Hecke 函子与 \(\mathrm{Rep}(\check G)_{\mathrm{Ran}}\) 的表述是 Gaitsgory 学派的。
- §4.3：Thm 4.3.2 是 2024 年几何 Langlands 证明的综述，作者列表见原文。
- §5.1：几何 Casselman–Shalika 归功于 Frenkel–Gaitsgory–Vilonen；\(\mathrm{coeff}^{\mathrm{ult}}\) 的全忠实性归功于 Beraldo 与 FGV。
- §5.2：\(\mathrm{Loc}\) 的伴随性归功于 Lurie、Gaitsgory–Rozenblyum；范畴化定理归功于 Gaitsgory–Raskin 系列。

## 4. 阅读顺序

1. **核心**：§2.1（尖点）→ §3.1–§3.3（\(\mathrm{PGL}_2\) 主定理）→ §4.1–§4.3（一般 \(G\)）。
2. **可后读**：§1.1 的层论三情形（术语准备）；§1.2 的交换情形（动机，但技术独立）。
3. **最后读**：§5.1–§5.2（Whittaker 与范畴化，是全局图景，不依赖前面全部细节也能把握主旨）。

## 5. 原文的总体特征

- 这是**课堂笔记**，不是发表论文：句子短、跳步多、笔误多，定理陈述常省略“char \(k=0\)”“\(g>1\)”等技术条件。
- 大量使用“standard”“well-known”“one can check”，译文保留这种语气，但在译注中补足可核的定义或出处。
- 记号混用：\(\check G\) 与 \(\hat G\)、\(\mathrm{Bun}_G\) 与 \(\mathrm{Bun}_{G}\)、\(e\)（系数域）与 \(e\)（单位对象）在不同段落含义不同，译文按上下文统一并在符号表中登记。
