## 一句话

这 18 页回答的是：**从一条光滑射影曲线 $X$ 上的局部系统出发，怎样一步步构造出 $\operatorname{Bun}_G$ 上的 Hecke 特征层，并最终把整个层范畴与 $\check G$-局部系统的归纳凝聚层等同起来**。

## 四条主线

1. **交换情形（第一讲）**：$G=\mathbb{G}_m$。Deligne 用 $\operatorname{Sym}^d X\to\operatorname{Bun}^d_{\mathbb{G}_m}$ 的 Abel–Jacobi 映射，把秩 $1$ 局部系统 $\sigma$ 变成 $\operatorname{Bun}_{\mathbb{G}_m}$ 上的 lisse 层 $\chi_\sigma$；这是几何类域论的模型，也是后面所有构造的「一维影子」。
2. **$\mathrm{PGL}_2$ 情形（第二、三讲）**：先把「尖点」定义为常数项 $\mathrm{CT}_*=q_*p^!$ 的消没；再用系数函子 $\operatorname{coeff}_D$ 把层变成向量空间；然后用 Fourier–Deligne 变换把 $\operatorname{coeff}_d$ 化到向量丛 $E_d^\vee$ 上的限制，证明尖点层由两个相邻系数唯一确定；最后陈述定理 3.11：不可约 $\mathrm{SL}_2$-局部系统对应 $\operatorname{Bun}_{\mathrm{PGL}_2}$ 上的尖点反常层 $\mathcal{F}_\sigma$。
3. **一般约化群（第四讲）**：用几何 Satake 等价把 $\operatorname{Rep}(\check G)$ 变成局部 Hecke 叠上的层，从而定义整体 Hecke 函子 $\mathrm{H}_V$；把「在所有点同时做 Hecke 作用」的相容数据收进 $\operatorname{Rep}(\check G)_{\mathrm{Ran}}$；Hecke 特征层就是以 $\sigma$ 为特征值的 $\operatorname{Rep}(\check G)_{\mathrm{Ran}}$-线性函子。定理 4.15（2024）给出存在性、半单性与特征圈。
4. **Whittaker 与范畴化（第五讲）**：Whittaker 系数 $\operatorname{coeff}_D$ 把「$q$-展开」几何化；几何 Casselman–Shalika 把它写成「先 Hecke、再 $\operatorname{coeff}_0$」。最后把 $\operatorname{Rep}(\check G)_{\mathrm{Ran}}$ 的作用范畴化，得到 $\mathrm{LG}:\operatorname{DMod}(\operatorname{Bun}_G)\to\operatorname{IndCoh}_{\mathrm{Nilp}}(\operatorname{LS}_{\check G})$，主定理 5.16 断言它是等价。

## 读法（约 3 小时）

- **第 1 小时**：第一讲。抓住三件事：$\operatorname{Bun}_{\mathbb{G}_m}$ 的三部分分解、Abel–Jacobi 的纤维为什么是射影空间、Hecke 性质为什么能「粘」出整个 $\operatorname{Bun}_{\mathbb{G}_m}$ 上的层。若只读一段，读构造 1.8。
- **第 2 小时**：第二、三讲。先看尖点定义与命题 2.5 的证明（$d>2g-2$ 的消没），再看 $\operatorname{coeff}_D$ 与 Fourier 变换如何把「唯一性」化到 $E_d^\vee$ 上的限制；最后看定理 3.11 的陈述。
- **第 3 小时**：第四、五讲。第四讲信息密度最高：先读几何 Satake（定理 4.2），再读 Hecke 函子（定义 4.4），然后直接跳到定义 4.10 与定理 4.15。第五讲先读 Whittaker 系数（定义 5.1）与几何 Casselman–Shalika（定理 5.4），最后读主定理 5.16。

## 与 SY02-45 的关系

SY02-45 是 Scholze 的 Bourbaki 报告（56 页），讲的是**证明本身**：五部曲怎么拼、每一块引用谁、特征 0 与特征 $p$ 各自怎么走。本篇是 Raskin 的**课程纲要**（18 页），讲的是**定义与陈述的路线图**：先把 $\mathrm{GL}_1$、$\mathrm{PGL}_2$、一般 $G$ 的对应各自说清楚，再指向范畴化。

建议顺序：先读本篇建立「每个定理在讲什么」，再读 SY02-45 看「每个定理怎么证」。两篇共用 $\check G$、$\operatorname{Bun}_G$、$\operatorname{LS}_{\check G}$、$\mathrm{IndCoh}_{\mathrm{Nilp}}$ 等记号，但本篇不展开 shtuka、Kac–Moody 局部化与 Frobenius 迹，这些在 SY02-45 里才是主角。
