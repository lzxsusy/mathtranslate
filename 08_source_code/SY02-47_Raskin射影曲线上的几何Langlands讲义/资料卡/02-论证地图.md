## 第一讲：为什么 Deligne 构造能下降

**问题**：只在 $L=\mathcal{O}(D)$ 上定义 $\chi_\sigma$，怎么保证它与 $D$ 的选取无关？

1. **先在一族上定义**：$\operatorname{Sym}^d X$ 参数化次数 $d$ 的有效除子，也参数化「$(L,s)$，$s\in\Gamma(X,L)$ 非零」；$\mathrm{add}_d:X^d\to\operatorname{Sym}^d X$ 把 $d$ 个点加起来，$\sigma^{(d)}$ 就是 $\sigma^{\boxtimes d}$ 的 $S_d$-不变量。
2. **沿 Abel–Jacobi 下降**：$\mathrm{AJ}_d:\operatorname{Sym}^d X\to\operatorname{Bun}^d_{\mathbb{G}_m}$ 的纤维是 $\mathbb{P}\Gamma(X,L)$。$d>2g-2$ 时 $H^1(X,L)=0$，故 $\Gamma(X,L)$ 是 $d+1-g$ 维仿射空间，射影化后是 $\mathbb{P}^{d-g}$，单连通；单连通纤维上的局部系统是常值的，故 $\sigma^{(d)}$ 沿 $\mathrm{AJ}_d$ 下降。
3. **用 Hecke 性质粘起来**：下降只给出每个 $\operatorname{Bun}^d_{\mathbb{G}_m}$ 上的层；Hecke 性质 $\chi_\sigma|_{L(x)}\cong\chi_\sigma|_L\otimes\sigma_x$ 把它们沿 $x\in X$ 粘成整个 $\operatorname{Bun}_{\mathbb{G}_m}$ 上的 lisse 层。
4. **归一化**：$\chi_\sigma|_{\mathcal{O}_X}\cong\underline{\e}$ 固定整体常数；否则可乘 $\e^\times$ 中的标量。

**关键引用**：Deligne, LNM 163；Feng 的几何类域论讲义给出同一构造的另一个写法。**原文缺陷**：p4 把纤维写成 $\Gamma(X,L)\setminus\{0\}$，应为 $\mathbb{P}\Gamma(X,L)$（见 `04-术语文献勘误.md` 第 1 条）。

## 第二讲：为什么尖点性要写成 $\mathrm{CT}_*=q_*p^!$

**问题**：尖点性是一个「沿抛物子群消没」的条件；为什么用 $q_*p^!$ 而不是 $q_*p_*$？

1. **$p^!$ 是「沿纤维取紧支集」**：$p:\operatorname{Bun}_B\to\operatorname{Bun}_G$ 把 $(0\to L\to\mathcal{E}\to\mathcal{O}\to0)$ 送到 $\mathcal{E}$；$p^!$ 先把 $\mathcal{F}$ 拉回到 $B$-丛侧，保留「$\mathcal{E}$ 上纤维方向」的信息。
2. **$q_*$ 再沿 $L$ 推前**：$q$ 把同一个扩张送到 $L$；$q_*$ 把 $B$-丛侧的层变成 $\operatorname{Bun}_{\mathbb{G}_m}$ 上的层。复合后，$\mathrm{CT}_*\mathcal{F}$ 记录「$\mathcal{F}$ 沿所有 $L$-方向的边界行为」。
3. **与 Verdier 对偶交换**：$p^!$ 的选择使 $\mathrm{CT}_*\simeq D\,\mathrm{CT}^!\,D$（注 2.7）；若用 $p_*$，这个交换性会坏掉，尖点性也就不再与对偶交换。
4. **第二伴随把 $!$ 侧和 $*$ 侧连起来**：定理 2.8 断言 $\mathrm{CT}^d_*\simeq\mathrm{inv}\circ\mathrm{CT}^{-d}_!$；这是后面「$!$-消没」推出「$*$-消没」的关键。
5. **命题 2.5 的机制**：$d>2g-2$ 时扩张自动分裂，$q_d$ 的纤维是 $B H^0(X,L)$（原文误写 $B H^1$）；$B\mathbb{G}_a$ 上的层范畴平凡，故 $q_{d,*}$ 是等价，$\mathrm{CT}^d_*\mathcal{F}=0$ 就迫使 $p_d^!\mathcal{F}=0$。

**为什么尖点性对应「不可约」**：在 Langlands 哲学里，尖点自守表示对应不可约 Galois 表示；几何侧把「沿真抛物消没」翻译成「没有来自 Levi 的成分」，于是尖点层对应不可约 $\sigma$。讲义没有证明这个哲学陈述，只把它作为动机（第二讲开头）。

## 第三讲：Fourier 变换为什么能证明唯一性

**问题**：命题 3.4 说尖点层由两个相邻系数决定；为什么「两个」就够？

1. **先把 $\operatorname{coeff}_d$ 写成向量丛上的限制**：对 $d>0$，$H^0(X,L)=0$，故 $q_{-d}:\operatorname{Bun}^{-d}_B\to\operatorname{Bun}^{-d}_{\mathbb{G}_m}$ 是向量丛 $E_d$，纤维 $H^1(X,L)$；$E_d^\vee$ 的纤维是 $H^0(X,L^\vee\otimes\Omega)$，分类 $(L,s:L\to\Omega)$。
2. **Fourier 变换把 $!$-拉回变成限制**：练习 3.7 断言 $\operatorname{coeff}_{d+2g-2}=\mathrm{restriction}\circ\mathrm{Four}\circ p_{-d}^!$；即先在 $\operatorname{Bun}^{-d}_B$ 上 $!$-拉回，做 Fourier，再限制到 $E_d^\vee\setminus\{0\}$。
3. **零截面给出常数项**：$E_d^\vee$ 的零截面对应 $s=0$，其 $!$-限制正是 $\mathrm{CT}^{-d}_*$；尖点性给出该限制为零，于是 $\mathrm{Four}(p_{-d}^!\mathcal{F})$ 由非零部分完全决定。
4. **非零部分上的拉回全忠实**：Fact 3.8/3.9 说纤维连通光滑的映射上，反常层的拉回全忠实；$\operatorname{Sym}^{d+2g-2}X\to E_d^\vee\setminus\{0\}$ 正是这样的映射，故 $\mathrm{Four}(p_{-d}^!\mathcal{F})$ 由它在 $\operatorname{Sym}^{d+2g-2}X$ 上的限制（即 $\operatorname{coeff}_{d+2g-2}$）决定。
5. **两个相邻系数足够**：把 $d$ 与 $d+1$ 的两个系数合起来，就恢复 $\mathrm{Four}(p_{-d}^!\mathcal{F})$ 在整个 $E_d^\vee$ 上的信息，从而恢复 $p_{-d}^!\mathcal{F}$，再沿 $p_{-d}$ 下降回 $\mathcal{F}$ 在 $U_n$ 上的限制。

**为什么只对 $\mathrm{PGL}_2$**：上面的论证用「$\operatorname{Bun}_B\to\operatorname{Bun}_G$ 的纤维是向量空间」这一特殊结构；对一般 $G$，抛物子群的纤维是更大的叠，两个系数不足以恢复整个层。注 3.5 明确警告这一点。

## 第四讲：从几何 Satake 到 Hecke 特征层

**问题**：局部 Satake 等价只是一个点上的陈述，怎么变成整体 $\operatorname{Bun}_G$ 上的 Hecke 作用？

1. **局部核**：定理 4.2 给 $\operatorname{Rep}(\check G)\simeq\operatorname{Shv}(L^+G\backslash LG/L^+G)$；$V\mapsto\mathcal{S}_V$ 是「局部 Hecke 修改」的核。
2. **整体对应**：$\operatorname{Hecke}_x$ 分类 $X$ 上两个 $G$-丛及在 $X\setminus\{x\}$ 上的同构；图 $\operatorname{Bun}_G\xleftarrow{\overleftarrow{h}}\operatorname{Hecke}_x\xrightarrow{\overrightarrow{h}}\operatorname{Bun}_G$ 把局部修改放到整体上。
3. **整体 Hecke 函子**：$\mathrm{H}_{V,x}(\mathcal{F})=\overrightarrow{h}_*(\overleftarrow{h}^!\mathcal{F}\otimes^!\pi^!\mathcal{S}_V)$；练习 4.6 的卷积性 $\mathrm{H}_{V_1,x}\circ\mathrm{H}_{V_2,x}\cong\mathrm{H}_{V_1\otimes V_2,x}$ 说明它确实是 $\operatorname{Rep}(\check G)$ 的作用。
4. **把所有点收进一个范畴**：对有限集 $I$ 与 $V_i$，$\mathrm{H}_V$ 作用在 $\operatorname{Bun}_G\times X^I$ 上；对 $\alpha:I\to J$ 取 colimit，得 $\operatorname{Rep}(\check G)_{\mathrm{Ran}}$，它作用在 $\operatorname{Shv}(\operatorname{Bun}_G)$ 上（问题 4.7 的答案）。
5. **本征值**：固定 $\sigma$，求值函子 $\mathrm{ev}_\sigma$ 把 $\operatorname{Rep}(\check G)_{\mathrm{Ran}}$ 送到 $\operatorname{Vect}$；Hecke 特征层就是与 $\mathrm{ev}_\sigma$ 相容的 $\operatorname{Rep}(\check G)_{\mathrm{Ran}}$-线性函子。练习 4.12 把它还原成 $\mathrm{H}_V(\mathcal{F})\cong\mathcal{F}\boxtimes V_\sigma$。
6. **定理 4.15**：2024 年团队证明这样的 $\mathcal{F}_\sigma$ 存在、唯一、perverse、尖点、半单；特征圈为 $[\mathrm{Nilp}]$。这一步是整篇讲义引用的最重结果。

## 第五讲：Whittaker 系数与范畴化

**问题**：为什么要把 $\operatorname{coeff}_D$ 提升为 $\operatorname{coeff}^{\mathrm{ult}}$，再把整个 $\operatorname{DMod}(\operatorname{Bun}_G)$ 与 $\operatorname{IndCoh}_{\mathrm{Nilp}}$ 等同？

1. **Whittaker 系数是「$q$-展开」的几何化**：模形式的 $a_n$ 是 $f$ 与 $e^{-2\pi in\tau}$ 的积分；几何侧把 $n$ 换成除子 $D$，把积分换成 $\operatorname{Bun}^{\Omega(-D)}_N$ 上的 $!$-拉回与 $\exp$ 层的 $!$-张量，再取整体截面。
2. **几何 Casselman–Shalika**：定理 5.4 说 $\operatorname{coeff}_D=\operatorname{coeff}_0\circ\mathrm{H}_{\boxtimes V_{\check\lambda_i}}$；即「取第 $D$ 个系数」等于「先沿 $D$ 做 Hecke，再取常数项」。这把 Whittaker 系数与 Hecke 作用接起来。
3. **终极版本**：把所有 $D$ 的系数装配成一个函子 $\operatorname{coeff}^{\mathrm{ult}}:\operatorname{Shv}(\operatorname{Bun}_G)\to\operatorname{Rep}(\check G)_{\mathrm{Ran}}$；定理 5.7 说它在尖点子范畴上全忠实。
4. **范畴化**：定理 5.9/5.10 把 $\operatorname{Rep}(\check G)_{\mathrm{Ran}}$ 的作用经 $\operatorname{Loc}$ 分解到 $\operatorname{QCoh}(\operatorname{LS}_{\check G})$；于是 $\operatorname{coeff}^{\mathrm{ult}}$ 分解为 $\operatorname{DMod}(\operatorname{Bun}_G)\to\operatorname{QCoh}(\operatorname{LS}_{\check G})$。
5. **粗版与修正**：$\mathrm{LG}_{\mathrm{coarse}}$ 在尖点处是等价（定理 5.12），但全局不可能是等价（常层被送到零）；Arinkin–Gaitsgory 把目标换成 $\operatorname{IndCoh}_{\mathrm{Nilp}}$，主定理 5.16 断言 $\mathrm{LG}$ 是等价。

## 三个「为什么」小结

| 问题 | 一句话答案 | 定位 |
|---|---|---|
| 为什么尖点性用 $q_*p^!$ | 使常数项与 Verdier 对偶交换，并让第二伴随把 $!$ 与 $*$ 连起来 | 定义 2.2、注 2.7、定理 2.8 |
| 为什么 $\mathcal{F}_\sigma$ 是 perverse 而非 lisse | 它支撑在整个 $\operatorname{Bun}_{\mathrm{PGL}_2}$（含非半稳定部分），奇异支撑非零；lisse 层无法同时尖点 | 定理 3.11、定理 4.15 |
| 为什么目标要换成 $\operatorname{IndCoh}_{\mathrm{Nilp}}$ | $\operatorname{QCoh}=\operatorname{Ind}(\operatorname{Perf})$ 在奇点处丢掉 $\operatorname{Coh}$ 的幂零方向；粗版把常层送到零，必有核 | 定理 5.12、定理 5.15/5.16、注 5.14 |
