## 三、典型修订举例

### 1. 断言强度与否定走形（全书最多）
- 第 3 章 p157：“this is proportional to an inner product … and is thus nondegenerate” 原译丢掉 “proportional to”，并弱化了 “is thus nondegenerate” → 改为“它与 $X'$ 理论中的内积成比例……因而非退化”。
- 第 3 章 p159：把原文的 “edge **irrelevant**” 与 “edge **relevant**” 前后译反（“边缘无关/相关”颠倒）。
- 第 4 章 p241 一带：“only known”“never”“are known as” 三处断言强度被抹平，如 “only known” 译作“已知的”，“never” 译作“不”。
- 第 3 章后半 p192：“Nor can they include the derivatives of the fields” 原译“它们也不需要包含场的导数”→ “它们也不能包含场的导数”。

### 2. 数学符号与公式
- 第 3 章 (3.83) 扭转公式：`T′ = T − ½∂J`、`T̄′ = T̄ + ½∂̄J̄` 两处符号全反（p167 与 p170 同一笔误重现，且与 `L′_m = L_m − (m/2)J_m` 不自洽）。
- 第 5 章式 (5.96)：`+n−1` → 原书 `−n`；式 (5.22) 恢复 `arg∫Ω`；式 (5.105)、(5.72) 的指标形式与原书对照后保留原样（原书疑误，见第四节）。
- 第 5 章 §5.4.5.5：译者把 `m_i` 系统性改写成 `m_i·d_i`、并自创 `ϑ_i = d_iθ_i`，导致 (5.108)(5.110)(5.111)(5.115)–(5.120) 整串公式与原书不符 → 按原书逐式复原。
- 第 6 章例 6.37(2)、练习 6.47 等一串符号整体翻转（彼此自洽但与全书约定相反），未回改，记录在案。
- 第 7 章例 7.1 与 §7.3.1 同一组数值：`−πa[E]/2`、`a`、`2πa` → 原书 `−2a[E]`、`a⁻¹`、`4πa`；另有 `a_i/π → a_i`、`¼ → (i/2)²` 等 6 处。
- 第 5 章前半 Cardy 条件公式右边多套了一个 `θ_b`，且 `H_{ba}` 应为 `H_{ab}`。

### 3. 漏译、增译与“多出原文”
- 第 1 章 §1.2.1 多出整句“Thomas–Yau 条件”（原文无此句）→ 删除。
- 第 4 章 §4.6.4“在经典几何中没有对应物”整句漏译 → 补回；§4.7.3 `dense open subset` 漏“稠密” → 补。
- 第 8 章 §8.4.1 “选择相对丰沛线丛”漏 “on $\widehat{\mathcal X}$” → 补全。
- 第 5 章后半删去多处译者臆测性增补（含一处孤儿 `\begin{proof}`）。

### 4. 术语
- isomorphism 一律“同构”，原译多处作“等价”（第 5、8 章）。
- injective resolution = “内射消解”，原译“单射消解”；fully faithful = “满忠实”，原译“充满忠实”。
- unimodular = “幺模”，原译“非退化”（第 5 章 §5.8.2）。
- “五次三维流形”（quintic threefold）与“五次曲面”（quintic surface）统一（第 5 章 6 处）。
- 参考文献：期号 `12(34)` 应为 `12(3–4)`、`410(24)` 应为 `410(2–4)`（原书跨行 `(3- 4)` 连字符丢失后粘成两位数）；`Commun. Math. Phys. 126:325–246` 区间颠倒应为 `325–346`；12 条期刊名/丛书名的连字符丢失（Calabi-Yau、Springer-Verlag、Landau-Ginzburg 等）。

### 5. 术语与记号的第二轮统一（全书 90 处）
- `quintic threefold` 的混合造词“五次三维超曲面”5 处 → “五次三维流形”（另有 13 处真正的 quintic hypersurface 语境保留“五次超曲面”）。
- 层版 Hom：`\mathcal Hom`（15 处，ch08 §8.2）→ `\mathcal{H}om`，与全书 `\operatorname{Hom}` 449 处区分。
- 裸写群名 `$SU(3)$`、`$SO(2)$` 等 7 处 → `\operatorname{SU}(3)`、`\operatorname{SO}(2)`；`\mathrm{id}` → `\operatorname{id}`。
- 第 5 章 5 处 `\mathbb Z` 补括号 `\mathbb{Z}`（该章其余均带括号，属笔误泄漏）。
- 第 7 章同一句里 `\mathbb{CP}^k` 与 `\mathbb P^k` 混排 → 统一为 `\mathbb{CP}^k`。
- `\BookRef` 显示串：17 处“图 10”改为“图10”、47 处“定理 7.12”类改为“定理7.12”，与全书 187 + 254 处的多数写法一致。

## 四、“原文疑误、译文正确”的保留项

以下位置译文与原书字面不同，但数学上更正确，**保留译文**并在校对日志中标注“原文疑误/译者补正”：

1. 第 1 章 p30：原书印作 `SO(d,d;ℤ)`，译文作 `O(d,d;ℤ)`；同章 p22 原书 `dim_ℝ M` 与本节 (4) 自相矛盾，译文取 `dim_ℂ X`。
2. 第 4 章 thm 4.78 / 4.88：译者补了原文缺失的（必要）前提条件。
3. 第 4 章 §4.4.5：`A = Mod(R)` 系统性改写为“交换 Noether 环上有限生成模范畴”、`D` 改 `D^∓`（与原书后文用法一致）。
4. 第 5 章 (5.115)、(5.117) 与 (5.118) 在原书中互相矛盾，译文按其中自洽的一支处理。
5. 第 5 章 §5.3.4.1 的 `1/ĉ`（原书）与译者 `1/√ĉ`（按 `q = √ĉ p` 自洽）。
6. 第 6 章：定理 6.103 补“紧、连通”；6.3.2-028～033 把 `α̃` 处理为 `Λ_ℝ` 的截面并调整 (6.4) 楔积次序；多处原书笔误被静默修正。
7. 第 7 章定义 7.30 自引入 `δ` 并写 `d_GH ≤ δ ≤ 2d_GH`（原书未给）。
8. 第 8 章 def 8.25 原书系数 `(−1)^{deg φ}` 应为 `q^{deg φ}`（译文正确）；ex 8.21 原书 `B` 疑为 `B̌`；8.4.5-043 原书 `0 ≤ j ≤ d−2` 与胞腔定义冲突，应为 `< d−2`；§8.5 译文补“保典消解”“在所考虑的对称性约束下”等必要前提。
9. 第 3 章译文对原书 `1/4 → 1/3`、`(3.30)` 的 `±i`、自由玻色归一化等处的调整均为修正原书笔误。

> 处理原则：**数学正确性优先于字面忠实**。凡译文对原书笔误的修正，均在校对日志中逐条记录，便于读者回查。
