## 4. 工作循环（逐块进行）

1. 用 `read` 打开一个 chunk 文件（10 页）。**不要一次读多个块**，读完一块做完一块。
2. 逐页逐段对照：英文段落 ↔ 中文段落（按 `page=` 和 `<<id>>` 对应）。
3. 发现错误 → 用 `edit` 工具在 tex 里改（`old_string` 要唯一；一般取一整句或一个独特短语）。
4. 每处改动立即记入你的日志（见 §7）。
5. 一块做完 → 再读下一块。
6. **上下文管理**：每做完 1–2 块，若上下文明显变大，用 `compress` 工具把已读的块折叠掉（摘要写清：已核对页码范围、改了哪些 `<<id>>`、还有什么待确认）。`acp_status` 可以看用量。千万不要因为上下文紧张就跳过剩余的块——宁可压缩，不要漏块。

## 5. 什么必须改，什么不要动

### 必修（P1，硬错误）
1. **漏译 / 跳译**：英文有整句、整段（含脚注）而中文没有；或反之中文多出原文没有的内容。
2. **意思译反 / 译歪**：否定、条件、因果、量词（some/all/exactly）、"not necessarily"、"iff" 等。
3. **数学错误**：公式、上下标、符号、符号方向、系数、指数、维数、取值范围、正负号、求和指标。**这是最高优先级**——公式错比文字错严重得多。
4. **术语错**：把数学/物理术语译错（如 "coherent sheaf" 译成"相干层"而不是"凝聚层"、"derived category" 译错等），或与术语表/全书惯用译法冲突。
5. **指代错**：this/it/former/latter 指错对象；上式/下式/前节/后节指错。
6. **引用错**：`\BookCite{refNNN}` 对应的文献编号、`\BookRef` 的章节/定理号、`\BookChapterRef{3}` 的章号与原文不符。
7. **专名错**：人名（数学家、物理学家）、流形名、模型名的中文音译或拼写错。
8. **图表标题错**：`\caption{...}` 与原文 Figure X.Y 标题不符（漏译、错译、编号错）。

### 可改（P2，明确瑕疵）
9. 中文病句到影响理解（不是"不优美"，是"读不懂"）。
10. 标点/引号/括号明显错配（中文用全角，`“”`、`《》`、`——`；数学内部仍用半角）。
11. 明显错别字、重复字、丢字。

### 不要动（P3）
12. **文风**：不重写句子，不把"本书介绍"改成"本著作阐述"。译得通顺就不动。
13. 译者选择的合理译法（只要不违背术语表）。
14. 排版/版式（字号、间距、浮动体位置）——那是 Lead 的事，发现了报告即可。
15. 不添加译者注、不删例子、不合并段落。

> 判断标准：**假设读者拿着英文原书对照读，会不会发现"这里跟原文不一样/说反了/少了内容/公式不对"**。会 → 改。只是"换个说法更好听"→ 不改。

## 6. LaTeX 安全规则（重要）

* 用 `edit` 做**最小替换**，不要用 `write` 重写整个 tex 文件（文件很大，重写容易丢内容）。
* 保持 `\SourceParagraph{id}{page}` 行原样不动。
* 保持数学环境原样：`$...$`、`$$...$$`、`\[...\]`、`equation`、`align` 等不要改写法。
* 保持所有宏调用：`\BookCite{}`、`\BookRef{}`、`\BookChapterRef{}`、`\BookSectionRef{}`、`\BookEqRef{}`、`\BookImage{}`、`\texorpdfstring{}{}`、`\cite`、`\ref`、`\label`。改引用要改参数或外面的显示文字，不要删宏。
* 中文里的破折号用 `——`（两个全角），不要用 `--`（会被当成 en dash）。
* `%` `&` `_` `#` 在正文里要转义（除非在数学模式）。
* 改完一处，**再读一遍你改的那几行**，确认没有把花括号、`$`、环境配平弄坏。一句话：`$` 成对、`{}` 成对、环境 `\begin`/`\end` 成对。
* 如果你要改的地方横跨多段/多行，宁可分几次小 edit。

## 10. 常见判断示例

* 英文 "Dirichlet brane is defined physically as an allowed end point for an open string" → 中文"Dirichlet 膜在物理上定义为开弦的允许端点" ✅ 不动。
* 英文 "the derived category of coherent sheaves" → 中文"凝聚层的导出范畴" ✅。
* 公式 `(-1)^{n(n-1)/2}` 被译成 `(-1)^{n(n+1)/2}` ❌ 必修。
* 英文 "This is not the case for B-branes." → 中文"B 膜的情况也是如此。" ❌ 否定丢失，必修。
* "See §2.5" → 中文"参见第 2.6 节" ❌ 引用错，必修。
* 一句译得拗口但意思对 → 不动。
