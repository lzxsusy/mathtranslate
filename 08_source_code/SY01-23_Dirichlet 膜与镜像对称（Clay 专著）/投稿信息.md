## 工程要点（给接手的人）

- 底本有完整文字层，`pdftotext -layout` 可直接取英文原文；**原书印刷页码 = PDF 页 − 10**。
- 译本页码与原书**不可互推**（530 页 vs 697 页）：对照原文一律用 `\SourceParagraph{id}{PDF页号}` 里的页号，不要用译本印刷页码。
- 编译：`cd 源码 && latexmk -xelatex main.tex`（输出 `build/main.pdf`）。`.latexmkrc` 已配好 `$out_dir='build'` 与 `biber --input-directory=.`——后者是必需的，否则 biber 会按 kpathsea 找到系统里同名的 `references.bib`，bbl 只有 5.8 KB。
- 图：`figures/` 222 个从底本 PDF 裁剪的矢量图，宽度表在 `figure-dimensions.tex`；图题按原书「每章单编号」还原，原书只有编号无说明的图用 `\BookNumberOnlyCaption`（属忠实还原，不是漏译）。
- 索引：`index-zh.tex` 由 `tools/build_chinese_index.py` 生成，页码走 `\BookIndexPage` → `\pageref*`，重编译自动更新，**勿手改**。
