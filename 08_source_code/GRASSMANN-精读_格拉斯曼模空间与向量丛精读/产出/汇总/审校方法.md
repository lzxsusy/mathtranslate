# 审校方法（Lead 内部工作文档）

> 本文件记录本工程「读 + 审校」的具体做法，供 Lead 自查、也供后来者复用。
> 权威说明仍是 `BRIEF.md`；本文件只细化操作。

## 1. 三条材料的分工

| 材料 | 用途 | 不许做的事 |
|---|---|---|
| `source\chapters\chNN.tex` | 中文正文与公式的**唯一权威** | 不许改；不许拿 PDF 文字层的公式覆盖它 |
| `zh-译文.pdf` | 版面、页码、定理盒、脚注实物 | 不许当公式来源（文字层把上下标拆散） |
| `original\en-原书.pdf` | 审校对照底本 | 不许改；不许整段照抄英文当译文建议 |

页码写法固定三种：`原书 p.N` / `中译 p.N` / `英文 PDF p.N`。换算只信 `BRIEF.md` §1.1 的页表，
不做线性外推（英文 PDF = 原书 + 9；中译与原书非线性，ch1 +6、ch9 −9）。

## 2. 一章的审校对读流程

1. **先通读中文 .tex 一遍**，只标「读不懂 / 明显别扭 / 公式看着不对」的位置，不急着下结论。
2. **再按节对读英文**：`python tools\pdf_pages.py text en A-B -o tmp\en_chNN.txt`，一段中文配一段英文。
   英文 PDF 的文字层比中文的干净，但仍可能断词；必要时 `png zh P` 渲页看排版。
3. **三类问题分开记**：
   - 译文问题（误译、漏译、增译、术语不统一、公式抄错、编号错位）→ `chNN-errata.tsv`；
   - 数学困难（证明跳步、构造看不懂）→ `chNN-批注.md` 的 `数学-难点` / `数学-补证`；
   - 跨章联系（同一概念在别章的角色）→ `批注` 的 `联系-他章` + `产出\汇总\交叉引用.md`。
4. **回查已有译注**：`产出\汇总\existing-notes.tsv` 按 `chapter` 过滤，先读该章全部条目再动笔。
   同一位置不得重复登记；若认为译注本身判断有误，登记 `type=existing-note-wrong`，并在批注里
   写清「译注怎么说 / 我认为应该怎样 / 证据」。
5. **每条 errata 必须能回查**：`loc_tex` 给 `chNN.tex:行号`，`original` 抄原文（≥10 字，便于 grep），
   `evidence` 给英文原句或 .tex 里的正确公式。做不到这三点的条目降级或删掉。

## 3. 类型与严重度判据

`type`：`translation-error`（译文错）/ `original-error`（英文原书错，中译照抄）/ `term`（术语不统一）/
`formula`（公式差异）/ `typo`（错字标点）/ `numbering`（编号错位）/ `existing-note-wrong`（已有译注说错）。

`severity`：
- `high`：读者按字面理解会得到错误数学（符号反了、条件漏了、定理陈述错）；
- `medium`：意思偏了但能猜回（量词、范围、指代错）；
- `low`：文字、标点、排版，不影响数学。

## 4. 验收抽查（对应 BRIEF §7）

- 字数：`python -c` 数汉字（去掉公式与英文）比 `wc -m` 可靠；导读 ≥1200、笔记 ≥1500。
- 批注编号：`grep -c "^## [0-9]"`，并检查 1..K 连续。
- tsv 列数：逐行 `awk -F'\t' '{print NF}'` 必须全等（errata 10 列、cards 7 列）。
- anchor：`chapters/chNN.tex:行号` 的行号必须落在该章文件内、且该行非空、且内容与卡题相关。
- 重复登记：拿该章 existing-notes 的前 3 条与 errata 逐条比对 `loc_book` + `original`。
- 交叉引用：导读/笔记里出现的「chK + 页码」与 BRIEF §1.1 对得上（抽 10 处）。

## 5. 常见坑（本机实测）

- 终端中文乱码：脚本结果写 UTF-8 文件再用 `ops_inspect_local_file` 读，不靠 stdout 判断。
- `ops_bash` 是 Git Bash，可用 heredoc，但 >1KB 的脚本先落盘再跑。
- 本地 `build_local.py` 编译结果不作数（缺字体、页数 167≠170）；版面一律看 `zh-译文.pdf`。
- PDF 文字层的中文公式会拆成 `DV f = V [f] + ˜D(V )(f)` 这种碎片，只用来定位。
