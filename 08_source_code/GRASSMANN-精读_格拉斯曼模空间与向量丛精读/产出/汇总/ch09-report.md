## 三、存疑

1. **§4 扭转与度数记账（`ch09.tex:157–159`，原书 p.175）**。正文说 $\mathcal{E}_{j(i)}(-bC'_i)$ 限制到 $C_i$ 是"乘以 $\mathcal{O}_{C_i}(bP_i)$"（次数 $+b$）。但 $\mathcal{O}(-C'_i)|_{C_i}=\mathcal{O}_{C_i}(-P_i)$，实算次数变化是 $-b$；把扭转为 $+bC'_i$ 才与正文一致。此外逐结点累加 $a$ 会给出 $2(M-1)a$，与条件 (a) 的 $r(M-1)a$ 不符。我倾向认为 $M=2$ 时原书正确、一般表述有笔误，但未完全核实；已写入批注 9 与笔记「疑问」1。
2. **§6 算例的维数等式（`ch09.tex:264`，原书 p.178）**。按正文自同态维数 $1,2,4,4,2$、首结点粘合 $3$ 维、其余 $4$ 维，算得 $3-13+1+15=6$；英文原式被减项为 $1+2+4+4+4+2=17$，算得 $2$。两者都不等于 $5=\rho$。可能是某个自同态维数或族维数印错，需对照 [T1] 原文；已登记 errata 第 1 条。
3. **`ch09.tex:77`「$h$ 维空间」的所指（原书 p.172）**。原文说 $E|_{C_1}$ 的这类限制构成"一个 $h$ 维空间"，同时又有"$h$ 维自同构集"作用其上（$h=\gcd(r,d_1)$）。我理解为 $h$ 个相同因子的选取参数，但未确认其与椭圆曲线上 $\dim U(r/h,d_1/h)$ 的关系；已写入笔记「疑问」3。
4. **§3 的两处未证断言（`ch09.tex:121`，原书 p.173）**。Hilbert 稳定性 ⇒ 条件 $(\ast)$、以及有理分支"至少两个结点且分裂型为 $\mathcal{O}^{\oplus j}\oplus\mathcal{O}(1)^{\oplus r-j}$"，本章只给结论；我的批注 6 只给了直觉（平衡分裂 + GIT 负权），严格证明需 [G2a]、[Sc2]，未展开，已在批注中标明。
5. **页码约定**。中文 PDF 页与页脚印刷号差 6（本章页脚 154–164 对应中译 160–170）。工程惯例「中译 p.N」指 PDF 页（7 条已有译注即如此），本报告与批注沿用；若 Lead 统一改为印刷号，ch09 全部页码需平移。
