## 三、存疑

1. **Lemma 3.2 的证明只有三行（ch05.tex:337–343）。** 作者说「ψ 由因子分解得到，令 V 为两个开集的交，V 在两侧都是邻域」。因子分解给的是 $\Gr$（不带 ${}_0$）的同构，而 ${}_0$ 是切出来的子簇，交出来的东西在 ${}_0\Gr^{d_i(\underline\lambda)}_{d_i(x)}$ 一侧为什么还是开邻域，我没有验证出来。这是全章我最卡的一处。
2. **§4.3 ψ 的构造（ch05.tex:435–437）没有跟上。** 「$[e_1],\dots,[z^{k-1}e_m]$ 是 $\mathbb{C}[z]^m/L$ 的基 ⟺ $V\cong\mathcal O(k)^{\oplus m}$」这一步之后，用 $p_i$（满足 $p_i-z^ke_i\in L$ 的 $\mathrm{Span}(B)$ 中元素）造同构 ψ；$p_i$ 的存在唯一性要求 $\mathrm{Span}(B)$ 在商里的像已经张满，而定义里没有直接说，我推不出来，需要查 [MVy, §4.5]。
3. **两个版本在对角线上的纤维维数没有对齐。** $SL_2$、$\underline\lambda=(\omega,\omega)$：卷积版（${}_0$）纤维 $m^{-1}(L_0)=\mathbb{P}^1$、维数 1；奇异版按 Proposition 2.4(ii) 是 $\overline{\Gr^{2\omega}}$，我算 $\dim=2$。两者只差「是否忘掉中间点」的对应，但我写不出这个对应，也不敢断言 ${}_0$ 条件切在闭轨道上剩下什么。
4. **「超 Kähler 旋转」只出现在引言（ch05.tex:49）**，正文没有兑现。作者说与 Cautis–Kamnitzer 的途径「预期通过超 Kähler 旋转关联」，并引 [KM] §10.2–10.3。这超出本章技术范围，我无法判断，只能记为「未写出的猜想」。
5. **Remark 2.10 的「过大」（ch05.tex:288–290）含义不明。** 换成一般光滑曲线后，平凡丛给「过小」、半稳定丛似乎给「过大」；「过大」是指失去纤维仿射性还是纤维无穷维，原文只写 too large，我猜前者但没有证据。
