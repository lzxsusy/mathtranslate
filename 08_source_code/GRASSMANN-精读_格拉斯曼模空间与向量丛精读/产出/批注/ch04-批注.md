## 1. 【数学-难点】扩张模空间为什么是纤维积——把群关系「抬到」李代数

- 位置：原书 p.70；ch04.tex:30–41
- 原文：「扩张模空间是一个有限维空间，其在一个稠密开集上具有辛结构，并带有 SU(n) 的 Hamilton 作用，其辛商即为 M(n, d)。扩张模空间的一个无穷维构造可在 [8] 中找到，即作为二维流形上所有联络的空间模去带基点规范群（based gauge group）的辛商。」
- 批注：读法是把下方的纤维积方图（L31–36）逐项对出来：M^ext → Lie(K) 的映射是 μ，M^ext → K^{2g} 的映射送 (h, X) 到 h，而 K^{2g} → K 是换位子积 Φ(k₁,…,k_{2g}) = ∏_{j=1}^{g} k_{2j−1}k_{2j}k_{2j−1}^{−1}k_{2j}^{−1}，并配 exp: Lie(K) → K。于是 M^ext = {(h, X) ∈ K^{2g} × Lie(K) : Φ(h) = exp X}，即「把 exp X 乘进去以后交换子为 1」的成对数据。几何动机：holonomy 把 π₁(Σ) 的 2g 个生成元送到 K，而 2g 个群元素之间有唯一一条关系 ∏[a_j, b_j] = 1，它在 K^{2g} 里无法直接「解」；抬到 Lie 代数就变成 Φ(h) = exp X，X 记录「差多少」。于是 μ(h, X) = X（差一个符号/中心元），μ^{−1}(0)/K = {Φ(h) = 1}/K = 平坦联络模空间 = 奇异的 M(n,d)。这一步的价值在于：奇异的商空间被换成了「光滑的扩张空间 + 矩映射」，等变上同调与局部化才有舞台。$\dim M^{ext} = 2g\dim K$；辛形式只在 Φ(h) 稳定子非平凡处退化——这正是 M(n,d) 的奇点来源，也是 §2 要部分消奇异的原因。
- 类型：数学-难点

## 2. 【数学-补证】D、1/n! 与 Weyl 积分：为什么除以 n!

- 位置：原书 p.71；ch04.tex:53
- 原文：「类 D 是 H_T^*(pt) 中由正根之积给出的类——它在 Kirwan 映射下的像是 K/T 的 Poincaré 对偶，因此它使我们能够将 μ~^{−1}(0)/K 上的积分替换为 1/n! 乘以 μ~^{−1}(0)/T 上的积分。」
- 批注：补两层。第一层是初等的：K 自由作用于 X 时，投影 X/T → X/K 的纤维是 W = N(T)/T 的一个自由轨道，故一般纤维有 |W| 个点；对 T-基本的类有 ∫_{X/K} = (1/|W|)∫_{X/T}。SU(n) 的外尔群是置换群 S_n，|W| = n!，这就是 1/n! 的来源（不是「除以 n 的阶乘」的巧合；若换成 SO(2m+1)，因子会变成 2^m m!）。第二层是 D 的角色：X/T → X/K 还有「纵向」方向（沿 K-轨道但不在 T-轨道方向的部分），D = ∏_{α>0} α 的零集恰是这些方向的退化轨迹，其积分把纵向部分积掉——这就是为什么 D 的次数是 n(n−1) = dim_R K/T，也正是「D 的像是 K/T 的 Poincaré 对偶」的定量含义。两件事不能互相替代：1/n! 数的是 Weyl 轨道的重数，D 负责纵向积分。另注意式 (1) 两边都是 T-积分（故没有 1/n!），而式 (9)(10) 的左端是 K-配对（没有 D）、右端是 T-积分并带 D，两处的 1/n! 与 D 是同一句话的两种写法，不是矛盾（详见批注 6）。
- 类型：数学-补证

## 3. 【数学-难点】A 与 B：哪个是穿墙项，怎么记

- 位置：原书 p.71；ch04.tex:55–68
- 原文：「项 A 通过研究"穿墙"（wall crossings），即与 μ^{−1}(0) 相交的子环面 T′ ⊂ T 不动点集的连通分支来计算。这第一项利用 Guillemin、Kalkman 与 Martin 的结果（见定理 6.1）计算。项 B 与非奇异辛流形的配对相同（见 [9]）。」
- 批注：按 (1) 的定义，A = ∫_{μ~^{−1}(ε)/T} κ(αβD) 取在正则值 ε 处，此处商光滑，正是 [9] 的非奇异配对；B = ∫_{0} − ∫_{ε} 才是跨过墙的差值。所以原文这两句接反了（译注 1 已指出，属实）。记法：把 A 记成「参考值」、B 记成「跳跃和」比记字母可靠——B 随 ε 的变化只在 ε 越过某个 μ(F) 时发生，F 是子环面 T′ 的不动点分支，故 B 是若干跳跃之和；A 只是拿来做差的基准。同一逻辑给出 §3 的一个细节：L84–88 只取「具有正矩映射的分支」，因为 ε > 0 时只有 μ_T(F) > 0 的分支会挡在 0 → ε 的路上被跨过。定理 6.1 的形式（两个正则值处的积分之差 = 夹在中间的不动点留数之和）就是 B 的显式化。
- 类型：数学-难点

## 4. 【数学-补证】式 (4) 的两次留数如何塌缩成一个系数

- 位置：原书 p.73；ch04.tex:108–127
- 原文：W = −2^{−3g} ∫_Jac Res_{y=0} Res_{Y=0} [ηe^{ω̄}|_Δ / (y^g Y^{2g−1})] · (1−y/2Y)^{−g−1} (1−y/4Y)^{−g} = −2^{−3g} Coeff_{t^{g−1}}[(1−t/2)^{−g−1}(1−t/4)^{−g}]，t = y/Y。
- 批注：记 f(t) = Σ_m c_m t^m（t = y/Y）。把 (1−y/2Y)^{−g−1}(1−y/4Y)^{−g} 写成 f(y/Y)；由 L114–118，ηe^{ω̄}|_Δ = c·Y^{3g−3}·γ^g/g!（c 为常数，正文把它归入 W，可设 c = 1），于是被积函数 = c Σ_m c_m y^{m−g} Y^{g−2−m}。Res_{y=0} 要求 m − g = −1，即 m = g−1，剩下 Y^{−1}；再 Res_{Y=0} 取 Y^{−1} 的系数，得 c·c_{g−1}。两次留数因此等价于「取 t^{g−1} 的系数」。这一步值得单列，因为它是全章唯一一次「几何积分 → 单变量系数」的塌缩，也是把 2g 维积分变成一维组合问题的关键；t = y/Y 不是独立变量而是比值，所以系数是无量纲数。验算（我独立算的）：g=2 时 [t¹] = 3/2 + 1/2 = 2，W = −2/2⁶ = −1/32；g=3 时 [t²] = 5/2 + 3/2 + 3/8 = 35/8，W = −(35/8)/2⁹ = −35/4096。g=2 的值可与 [13] §8 对照。
- 类型：数学-补证

## 5. 【数学-补证】权 2、−2、−4 与 Euler 类的三个因子是同一条信息

- 位置：原书 p.72；ch04.tex:99–105
- 原文：作用在 (3) 的三个直和项上「分别以权 2, −2, −4 作用」；等变 Euler 类为 (−y + 2Y)(y − 2Y)^g (y − 4Y)^g。
- 批注：规则是 e_T(L) = c₁(L) + wt(L)（wt 用 H_T²(pt) = Z·Y 的倍数写）。逐项：O(−1)，c₁ = −y，权 +2 ⇒ −y + 2Y，只出现一次（法向是爆破的秩 1 方向）；T_Jac ⊗ R(1,0;0,−1) ⊗ O(1)，c₁ = y，R 的矩阵 diag(1,−1) 权 0，O(1) 权 −2 ⇒ y − 2Y，rank T_Jac = g 故 g 次幂；T_Jac ⊗ R(0,0;1,0) ⊗ O(1)，幂零元 E₂₁ 权 −2，加 O(1) 的 −2 ⇒ y − 4Y，同样 g 次幂。正文说「T_Jac 是平凡的」指 T 在 Jac 上作用平凡，故 T_Jac 的等变结构只经 R 的矩阵进入——这句话容易被读成「T_Jac = 0」，其实是「T-作用平凡」。三个数 2、−2、−4 与三个底数 −y+2Y、y−2Y、y−4Y 是同一件事的两种写法，读漏一个就会把 Euler 类算错一次幂。
- 类型：数学-补证

## 6. 【数学-难点】D 的幂次：为什么 (2)(10) 右端比左端多一个 D

- 位置：原书 p.71–72、p.77；ch04.tex:79、266
- 原文：（2）κ^{K,0}(ηe^{ω̄})[M(2,0)~] = −½∫_{μ_T^{−1}(ε)/T} κ^{T,ε}(ηe^{ω̄}D²) − ½(∫_{μ~_T^{−1}(0)/T} κ^{T,0}(ηe^{ω̄}D²) − ∫_{μ~_T^{−1}(ε)/T} κ^{T,ε}(ηe^{ω̄}D²))；（10）(1/n!)∫_{μ^{−1}(ε)^s/T} κ^{T,ε}(ηe^{ω̄}D) = Res(Σ_F e^{⟨μ(F),X⟩}∫_F ηe^ω D²/e_F)。
- 批注：三个式子摆在一起看：式 (9) 左端是 K-配对（无 D），右端是 (1/n!) 乘 T-积分带 D¹——多出的这个 D 正是把「K 积分换成 T 积分」的换算因子，与批注 2 一致。但式 (2) 与 (10) 的右端是 D²，各自左端只有 0 个或 1 个 D：式 (2) 左端是 K-配对（0 个 D）而右端 D²；式 (10) 左端 D¹ 而右端 D²。也就是说，除了 (9) 里那个可以解释的 D，这两个式子还各多一个 D。正文没有交代它从哪来。我的两个候选解释，都未被文本支持：(a) 留数公式的分母 e_F 在权超平面 β_j(X) = 0 上有极点，而 D = ∏_{α>0}α 的零点恰在同一族超平面上，故留数公式的被积函数需要一个 D 来「抵消极点」——这最像 [11] 里非交换局部化公式的写法；(b) [M(2,0)~] 的基本类在 U(2)/SU(2) 的某个因子下带一个 D，但 §3 明说本节用 U(2) 作用，看不出这个因子。建议对照 [13] §8 与 [11] 逐项核；在核清之前，读 (2)(10) 时把 D² 当成「待证的常数因子」而不是已经理解的公式。这是本章我认为最需要补的一处。
- 类型：数学-难点

## 7. 【数学-难点】定义 5.1 的三处类型错位

- 位置：原书 p.73；ch04.tex:147–151
- 原文：n(β) = #{α : ⟨α, β⟩ < ⟨β, β⟩}，β 取「权子集的凸包中距 0 最近的点」。
- 批注：三处要读者自己补。(i) 权是 t* 的元素，而正文写 β ∈ A（A 是 G-模）；⟨α, β⟩ 要成立，A 必须被认同为 t* 或 t，正文没有说。照字面读会得到「把 t* 的元素和 A 的元素作内积」这种无意义的式子。(ii) 若 0 ∈ B，则 n(0) = 0，定义 5.2 的不等式 2n(β) ≥ ½dim A 对任何非平凡作用都不成立，于是没有任何作用平衡——与 §5 定理 5.6（SL(p) 弱平衡）和 L170 的 C* 例子直接冲突。所以要么 B 不含 0（「距 0 最近的非零点」），要么条件只对 β ≠ 0 提出；正文两种都没写，这个漏洞会一直咬到 L170 的例子（见批注 15）。(iii) 严格不等号 ⟨α, β⟩ < ⟨β, β⟩ 正是「β 落在墙的哪一侧」的判据：β 穿过超平面 ⟨α, β⟩ = ⟨β, β⟩ 时 n(β) 跳变，这就是 §2 的穿墙在权空间里的样子。三点建议对照 [15] 的原文核实；本章是 survey，转述时压缩了这些前提。
- 类型：数学-难点

## 8. 【数学-补证】IH 没有环结构，为什么还能说「配对由杯积给出」

- 位置：原书 p.74；ch04.tex:186–206
- 原文：（定理 5.5）若 σ₁, σ₂ ∈ V_M 且次数互补，则 σ₁ ∪ σ₂ = τ⟨σ₁, σ₂⟩；「这一结果表明，相交上同调中的配对由等变上同调中的杯积给出。」
- 批注：把逻辑链补齐。§4 说 IH 只有 Poincaré 配对、一般没有环结构（L143），所以「两个 IH 类的积」本身没有定义。定理 5.4 给出 κ^{ss}: V_M ≅ IH*(M//G)（V_M ⊂ H_G*(M^{ss})），注 1 说互补次数的两个 V_M 元素之积仍在 V_M，定理 5.5 进一步把这个积写成最高次类 τ 乘配对数。于是：(a) 在 V_M 这个「截面」里杯积封闭，可以定义；(b) 通过 κ^{ss} 搬到 IH 上，恰与 Poincaré 配对一致；(c) 配对数可以用等变上同调的杯积 + 拓扑交来算，不需要真的去碰 IH 的层论定义。反过来读也重要：若 σ₁、σ₂ 的次数不互补，σ₁∪σ₂ 可能跑出 V_M，κ^{ss}(σ₁∪σ₂) 不能当 IH 类用——定理 5.5 的互补次数假设不能省。
- 类型：数学-补证

## 9. 【数学-补证】S² 例：从 (10) 到 2 sinh X / X，以及两个符号问题

- 位置：原书 p.76–77；ch04.tex:286–302
- 原文：「h(X) = (e^X − e^{−X})/X = 2 sinh(X)/X」；「Fh_+(ξ) = H(ξ − 1)，Fh_−(ξ) = H(ξ + 1)」；H 是 Heaviside 函数。
- 批注：先验算 (10)。取 η = 1，T = S¹ 绕竖直轴转 S²，两个不动点是南北极 F_±，切空间权 ±1 故 e_{F_±} = ±X，μ(F_±) = ±1，于是 Σ_F e^{μ(F)X}/e_F = e^X/X + e^{−X}/(−X) = (e^X − e^{−X})/X ✓。再看 Fourier 那步：在 Re X < 0 时 ∫_1^∞ e^{tX}dt = −e^X/X，即 e^X/X = −∫_1^∞ e^{tX}dt；若约定 F(e^{tX}) = δ(ξ − t)，则 Fh_+ = −∫_1^∞ δ(ξ − t)dt = −H(ξ − 1)，同理 Fh_− = −H(ξ + 1)。两个整体负号相减后给出 h_+ − h_− ↦ H(ξ+1) − H(ξ−1) = χ_{(−1,1)}，正是「[−1,1] 的特征函数」。所以正文的两个公式各自都少了一个整体负号（或它的 F 定义自带负号），否则 h_+ − h_− 变换过去是 −χ，与它下一句的结论差一个符号。这不影响任何数值（正测度前推不看符号），但读的时候要自己补上，别以为算错了。支撑集才是要害：ξ > 1 与 ξ > −1 分别对应两极，相减剩下 [−1,1]——正是 S² 在矩映射下的像，也是 Duistermaat–Heckman 测度前推的几何内容（[6]）。
- 类型：数学-补证

## 10. 【译注-核对】译注 1（A/B 互换）属实

## 13. 【译文-问题】「带层结构」把 level 的「水平」义译丢了

- 位置：原书 p.70；ch04.tex:41；中译 p.73
- 原文：「在代数几何中，最接近的类似物是 Seshadri 的带层结构向量丛模空间 [25]」
- 批注：level structure（法语 niveau，Seshadri 的术语，见 [25]《Fibrés vectoriels sur les courbes algébriques》）指给向量丛附加的一类离散数据，与 sheaf（层）无关；译作「带层结构」会被读成「带一个层结构的丛」，而本章另一条主线恰好是「层」的模空间（Huybrechts–Lehn 就在同一句里），歧义正好落在最敏感的词上。建议「带水平结构的向量丛模空间」，并在 TERMINOLOGY.md 增补 level structure = 水平结构。这是本章 3 条译注之外我认为唯一影响理解的非数学译法；Seshadri 那本书里 niveau 的确切定义我未查原文（见笔记「疑问」），所以只改译名、不替作者补定义。
- 类型：译文-问题

## 14. 【译文-问题】「在例外除子内部垂直」把 normal 译成了「垂直」

- 位置：原书 p.72；ch04.tex:99；中译 p.74
- 原文：「这里 2×2 矩阵是 GL(2, C) 的 Lie 代数元素。第一个直和项垂直于例外除子，而后两个直和项在例外除子内部垂直。」
- 批注：英文 "The first summand is normal to the exceptional divisor and the last two are normal in the exceptional divisor."（英文行 277）这里的 normal 是「法向」，不是「垂直」：第一个直和项是例外除子 E 的法向（爆破方向，秩 1），后两个是「在 E 内部（相对 E 里的不动点分支）法向」的方向。译成「垂直」后，第二句极易读成「后两个直和项互相垂直」——它们其实是两个秩 g 的块，彼此之间没有法向关系，而且都是 E 内的方向。这个区别在算 Euler 类时才见分晓：三个因子 (−y+2Y)、(y−2Y)^g、(y−4Y)^g 分别对应「法向于 E」「E 内第一个法向」「E 内第二个法向」（批注 5）。建议改为「第一个直和项是例外除子的法向，后两个则在例外除子内部是法向的」。
- 类型：译文-问题

## 15. 【译文-问题】「当且仅当」比原文强，且这个加强是错的

- 位置：原书 p.74；ch04.tex:170；中译 p.76
- 原文：「例如，G = C* 在向量空间上的线性作用是线性平衡的，当且仅当正权的个数等于负权的个数。」
- 批注：英文只有 if（充分条件）："a linear action of G = C* on a vector space is linearly balanced if the number of positive weights equals the number of negative weights"（英文行 405–406）。译文把它升成充要，而这个加强在两种可能读法下都失败。(a) 若 0 ∉ B（这是让正文例句本身成立的唯一读法，见批注 7）：取 A = C²、权为 (1, 0)（一个非平凡方向 + 一个平凡方向），#正 = 1、#负 = 0，按「当且仅当」应判不平衡；但 B ∖ {0} = {1}，β = 1 时 n = #{α < 1} = 1（α = 0 计入），2n = 2 = ½ dim_R A，条件成立，故它**是**平衡的——反例成立。(b) 若 0 ∈ B：取标准例子 A = C²、权 (1, −1)，#正 = #负 = 1 按「当且仅当」应平衡；但 β = 0 给出 2n(0) = 0 < ½ dim_R A = 2，故不**平衡**——这时连正文自己的例句都失败。两种读法各杀一边，说明「当且仅当」不能要。是否登记 errata 取决于 Lead 的口径：它是增译、且加强后为假，我按 translation-error/medium 登记；若要更保守，可只在批注里提。建议改回「若……则……」，并在术语表注明这是单向条件。
- 类型：译文-问题

## 16. 【译文-问题】「轨迹」不是 loci 的意思

- 位置：原书 p.70；ch04.tex:28；中译 p.72
- 原文：「我们沿着具有最高维稳定子群的轨迹进行爆破」
- 批注：英文 "We blow up the loci with the highest dimensional stabilizers"（英文行 46）。loci 是「（稳定子维数最高的点构成的）子集/子簇」，不是某个群作用的「轨道（orbit）的轨迹」。译作「轨迹」会让读者去找一个群作用，而这里的对象是奇点分层里最坏的那一层。同一段紧接着说「重复这一过程」，爆破对象就是这些子簇；§3 的 Δ = (S¹)^{2g} 就是一个具体的这类子簇（L86）。建议「沿稳定子群维数最高的子簇（点集）爆破」。
- 类型：译文-问题

## 17. 【联系-他章】与第 1 篇：同一个模空间，一个在光滑处做量子化，一个在奇异处算相交数

- 位置：原书 p.69；ch04.tex:16、30–41
- 原文：「空间 M(n, d) 也可描述为 Riemann 曲面 Σ 的基本群的一个中心扩张到 SU(n) 中的表示空间……模去 SU(n) 的共轭作用。」
- 批注：这正是第 1 篇（Andersen–Gammelgaard，Hitchin 联络与 Toeplitz 算子，中译 p.7–29）的舞台：Hitchin 模空间 = 基本群表示模共轭 = 平坦联络模带基点规范群，本章 L30 的无穷维描述与它逐字对应。差别在用途：第 1 篇要在这个空间上做几何量子化（Verlinde 丛、Hitchin 联络、TQFT 的渐近展开），用的是复结构、联络、热核；本章一次都不碰复结构，只用辛结构 + 等变上同调 + 局部化，且只在模空间奇异处发力。合起来读能得到一个完整的图像：光滑部分归量子化，奇异部分归相交同调。建议读第 1 篇时回来对一下 L30 的「带基点规范群」，两处是同一个对象。
- 类型：联系-他章

## 18. 【联系-他章】与第 3、7 篇：穿墙的三种用法

- 位置：原书 p.70–71；ch04.tex:24–28、68
- 原文：「M(n, d) 可作为配备 SL(p)……全纯作用的有限维簇 R(n, d) 的几何不变量理论（GIT）商而得到。」
- 批注：本章的「穿墙」是子环面 T′ 的不动点分支随 ε 越过 μ(F) 而进出，数学上是 GIT 商随稳定性参数变化的双有理变换在**数值层面**的影子；第 3 篇（曲面稳定性、Reider 定理、Thaddeus 对）把同一现象用作构造双有理模型的工具（翻转），第 7 篇（Newstead 的 α-稳定凝聚系）把它写成带参数 α 的稳定性条件。三章共享「稳定性参数 → 模空间 → 穿墙」的骨架，但只有本章把穿墙的后果压成一个可算的数（式 (4) 的 W）。所以本章适合当作「穿墙的数值不变量」来读：先在第 3、7 篇里看清墙两侧模空间怎么变，再回来看本章如何用留数把变化量算出来。

## 19. 【背景-补充】§4 为什么只挑这三条性质，以及「IH 是直和项」的分量

- 位置：原书 p.73；ch04.tex:131–143
- 原文：「相交同调具有由 Poincaré 对偶给出的配对，但一般不具有环结构。相交上同调最初由 Goresky 与 MacPherson [3, 4] 定义。」
- 批注：三条性质不是随便挑的：Lefschetz 超平面定理与强 Lefschetz 定理是 IH 上仍然成立的「硬」定理（可用来做归纳、把高维问题化到超平面），Poincaré 对偶给出配对（本章要算的正是配对）。唯独环结构一般没有——两个 IH 类的杯积会跑出 IH，这正是 §5 要造 V_M 截面的原因（批注 8）。比这三条更关键、却容易被略过的是 L184 的一句：**IH*(M//G) 是 H*(M~//G) 的直和项**（κ_M 满射的实现）。这句话把「部分消奇异」与「相交同调」焊在一起：消奇异后的普通上同调足够大，能看见 IH，于是可以用 H*(M~//G) 里的类去算 IH 的配对，而不必直接构造 IC 层。参考文献 [22]（Kirwan–Woolf 的相交同调导论）是这条的入门读物。
- 类型：背景-补充
