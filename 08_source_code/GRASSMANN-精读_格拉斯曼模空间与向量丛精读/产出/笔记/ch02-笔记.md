# 第 2 篇读书笔记

> Aprodu & Farkas《Koszul 上同调及其在模空间中的应用》，中译 p.30–54 / 英文 PDF p.34–59 / 原书 p.25–50。行号指 `source/chapters/ch02.tex`。

## 一、主线（我自己的话复述）

这一章想说服读者：**曲线在射影空间里的方程，和曲线的内在几何（线性系、棱性、Clifford 指标），是同一个东西的两面**，而做翻译的字典就是 Koszul 上同调 K_{p,q}。

作者的组织非常"工具书"：§2 先把字典写清楚（定义 + 三个例子 + 核丛 + 对偶 + 维数公式），§3 把字典用到族上（定理 3.4 让 K_{p,q} 成为基上的凝聚层，定理 3.5 把非消没轨迹写成退化轨迹，定理 3.6 算类），§4 用它重述 Green 猜想与棱性猜想并给出已验证情形，§5 把它和 Hilbert 概形的极大秩问题、极小合冲猜想接起来。

我最欣赏的一步是定理 2.6：把 K_{p,q} 从"极小自由分解的 Betti 数"（需要坐标、不能搬到族上）改写为"截面乘法的上核"（只需层、可以搬到族上）。这不是技术上的方便，而是整章从"代数"转向"几何"的枢纽——正因为有了这一步，{K_{p,2}≠0} 才能被写成两个向量丛之间态射的退化轨迹，才能算虚类，才有 K₁₀ 的 7<78/11。

另一条暗线是"对偶"：定理 2.7 让 (p,q) 与 (r−n−p,n+1−q) 配对，于是"非消没"（p 小）与"消没"（p 大）是同一个事实的两种写法。§4.1 的 Betti 表、猜想 4.1 的两种形式、定理 4.5 的"只需验证 K_{g−d+1,1}=0"，全靠这条对偶。

## 二、关键构造的逻辑链

**链 1（定义层）：极小分解 → 双复形 → K_{p,q}。** S(X) 有极小分次自由分解 0→E_s→…→E_1→S→S(X)→0，E_p=⊕_{j>p}S(−j)^{β_{pj}}。Green 的做法是把 β_{pj} 重写成两个自然映射（缩并 ∧^{p+1}H⁰(L)⊗H⁰(L)^∨→∧^pH⁰(L)，乘法 H⁰(L)⊗H⁰(F⊗L^{q−1})→H⁰(F⊗L^q)）构成的双复形的上同调 K_{p,q}(X,F,L)（L148–168）。好处：不依赖坐标、可以逐项算、可以搬到族上。

**链 2（计算层）：核丛 → coker/ker → 维数。** 令 M_L:=Ker(H⁰(L)⊗O_X→L)。短正合列 0→∧^{p+1}M_L⊗F⊗L^{q−1}→∧^{p+1}H⁰(L)⊗F⊗L^{q−1}→∧^pM_L⊗F⊗L^q→0 把"外幂"换成向量丛；取上同调并用 Koszul 微分穿过 H⁰(∧^pM_L⊗F⊗L^q) 这一事实，得 K_{p,q}≅coker≅ker（定理 2.6）。取 F=O_X、q=2，得 K_{p,2}≅coker(∧^{p+1}H⁰(L)⊗H⁰(L)→H⁰(∧^pM_L⊗L²))——这正是定理 3.5 里 B 丛的来历。要算维数时走另一条支路：Serre 对偶把 H⁰(∧^{p+1}M_L) 换成 H¹，维数变成 χ，再用 Riemann–Roch 算出显式公式（定理 2.8）。这条链只在曲线（n=1）时闭合得漂亮，所以定理 2.8 是曲线定理。

**链 3（族与除子层）：3.4 → 3.5 → 秩相等 → 3.6 → 式(5)。** 定理 3.4 先把 K_{p,q}(X/S,L) 做成 S 上的凝聚层（纤维在开集 U 上正好是 K_{p,q}(X_s,L_s)，U 由所有 h^i(X_s,L_s) 取极小值确定）。定理 3.5 的关键观察是：K_{p,2}=0 等价于限制映射 φ:A→B 的单射性（A=H⁰(P^r,∧^pM_{P^r}⊗O(2))，B=H⁰(C,∧^pM_L⊗L^{⊗2})），于是 U_{g,p} 就是 φ 的退化轨迹。秩相等条件 r=2s+sp+p、g=rs+s、d=rs+r 保证退化轨迹是除子而非更高余维，s=1 时 G^r_d≅M_g（因为 g=2p+3、d=2g−2，只有典范丛）。定理 3.6 把 Z_{g,p} 延拓到 G~^r_d、并对 σ 推前算 c₁，得到类公式；式(5) 是 s=1 的显式结果，斜率恰为 6+12/(g+1)。

**链 4（Green 层）：式(1) ↔ 猜想 4.1 ↔ 定理 2.4+2.8。** 式(1) 说 K_{p,2}(C,K_C)=0 ⟺ p<Cliff(C)。定理 2.4 提供非消没（分解 K_C=L₁⊗L₂，得 K_{r₁+r₂−1,1}≠0），定理 2.8 提供数值阈值，两者夹出 Cliff 的可用范围。对偶把"p 形式"（p≥g−Cliff−1 ⟹ K_{p,1}=0）与"q 形式"（K_{Cliff−1,2}=0）互换（L605–608）。

**链 5（棱性层）：4.5 → 4.6 → 4.7/4.8/4.9 → 4.12/4.13 → 4.16。** 定理 4.5 是"任意 d 化到极大棱性"：若式(7) 成立而 K_{g−d+1,1}≠0，则把 C 改造成一条亏格 2g+3−2d、极大棱性 g+3−d 的稳定曲线 C′，由定理 4.6 得 C′ 携带 g¹_{g+2−d}，与极大棱性矛盾。定理 4.7（K_{2,2}≠0 ⟹ Cliff≤2）、定理 4.8（g≥12 时 K_{3,2}≠0 的七类曲线）、定理 4.9 是低 Clifford 的分类；定理 4.12/4.13 把 |K_C⊗O(x+y)| 与 K_C⊗O(x+y+z) 的 Koszul 上同调算清楚；定理 4.16 反过来从非消没推出束的存在。

**链 6（极大秩层）：5.1 → 5.4 → 5.8。** 极大秩猜想说限制映射 ν_n(C):H⁰(P^r,O(n))→H⁰(C,O_C(n)) 总有极大秩；强极大秩猜想把它参数化为 Σ^r_{n,g,d} 并预言 dim=ρ−1−|rank E_n−rank F_n|；极小合冲猜想（猜想 5.8）则是它的 Koszul 版本，s=1 退化为 Green、p=0 退化为定理 5.3（L918）。

## 三、我补的推导 / 例子 / 反例

**(a) 例 2.2 的完整证明（L176–182）。** 设 r=h⁰(L)−1，故待证的是 K_{r−1,2}≅H¹(O_X)。由定理 2.6 的 coker 形式（p=r−1、q=2、F=O_X）：

K_{r−1,2}≅coker(∧^rH⁰(L)⊗H⁰(L) → H⁰(∧^{r−1}M_L⊗L²))。

∧^rH⁰(L)≅H⁰(L)^∨（因 dim H⁰(L)=r+1）。由 0→M_L→H⁰(L)⊗O_X→L→0 取行列式得 det M_L=L^{−1}，于是 ∧^{r−1}M_L≅M_L^∨⊗L^{−1}（用 ∧^{r−1}E≅E^∨⊗det E），故 ∧^{r−1}M_L⊗L²≅M_L^∨⊗L。把上述正合列对偶再乘 L，得 0→O_X→H⁰(L)^∨⊗L→M_L^∨⊗L→0；取上同调，用 H¹(L)=0（非特殊）得

coker(H⁰(L)^∨⊗H⁰(L)→H⁰(M_L^∨⊗L))≅H¹(O_X)。

这正是 K_{r−1,2}。也就是说：非特殊丛的 Koszul 上同调把 H¹(O_X)（亏格）编码在 K_{h⁰−2,2} 里。

**(b) K_{0,2} 与"同维"。** q=2、p=0 时 K_{0,2}=coker(H⁰(L)⊗H⁰(L)→H⁰(L²))；反对称部分映到 0，故 K_{0,2}=coker(Sym²H⁰(L)→H⁰(L²))，K_{0,2}=0 ⟺ ν₂ 满射。例 5.2 与 K₁₀ 的情形里 dim Sym²H⁰= C(6,2)=15、h⁰(L²)=2·12+1−10=15，两空间同维，所以"不满射 ⟺ 不同构 ⟺ K_{0,2}≠0"。一般情形不同维（g=4 典范曲线：10 vs 9），只能得到"K_{0,2}=0 ⟺ 满射"，不能反过来说"K_{0,2}≠0 ⟺ 不同构"以外的更多东西。这一点决定了译注⑦的适用范围（见批注 8）。

**(c) 定理 2.8 的数值核对。** 取 (g,d)=(5,10)（L=K_C²，r=5）：p=1 时右端 = 1·C(5,1)·(6/2−10/5)=5·(3−2)=5，而 dim K_{1,1}−dim K_{0,2}=5 与"一般曲线的 K_{0,2} 维数"相符；p=2 时右端 = 2·C(5,2)·(6/3−2)=0；p=3 时右端 = 3·C(5,3)·(6/4−2)=−15/2。可见 p=d−g 是分界点：p<d−g 时公式在"K_{p,1} 非消没"一侧有内容，p≥d−g 时公式右端 ≤0，只能读作"K_{p−1,2} 的下界"。

**(d) 定理 3.5 的秩相等验证。** 取 p=1 的 s=1 情形：g=5、d=8、r=4，rank A=(p+1)C(r+2,p+2)=2C(6,3)=40，rank B=C(r,p)(−pd/r+2d+1−g)=4(−2+16+1−5)=40 ✓。取 p=2 的 s=1 情形：g=7、d=12、r=6，rank A=3C(8,4)=210，rank B=C(6,2)(−4+24+1−7)=15·14=210 ✓。这说明秩相等条件不是偶然的数值巧合，而是 r=2s+sp+p 的直接代入。

**(e) 接桥（bridge）的亏格账。** 定理 4.5 的证明要造一条稳定曲线 C′，使 g′=2g+3−2d 且 C 是它的子曲线、ω_{C′}|_C=K_C。若按原文"把 δ=g+3−2d 对点两两粘合"来做，亏格变成 g−δ=2d−3，与 [C′]∈M̄_{2g+3−2d} 矛盾；只有"在每对点上接一条 P¹（桥）"才使亏格每次 +1，得 g′=g+δ=2g+3−2d ✓。此时 C′ 的极大棱性为 [(g′+3)/2]=g+3−d ✓，而定理 4.6 取 g′=2d′−1 得 d′=g−d+2，其结论 K_{d′−1,1}≠0 即 K_{g−d+1,1}≠0，与定理 4.5 要证的形式一致。定理 4.16 的证明（L780："粘合 x 与 y 得 C′∈M̄_{2d−1}"，而 C∈M_{2d−2}）是同一个问题的第二次出现。这就是 errata 前两条。

**(f) 定理 2.7 的指标来源（启发式）。** p↦r−n−p：外幂对偶把 ∧^{p+1}H⁰(L) 换成 ∧^{r−p}H⁰(L)（dim H⁰(L)=r+1）；q↦n+1−q：Serre 对偶把 H⁰(L^{q−1}) 换成 H^{n}(K_X⊗L^{1−q})，于是"第 q 层 twist"变成"第 n+1−q 层"，n 同时出现在两处是因为 X 是 n 维。曲线 n=1、q=1 时得 K_{p,1}∨≅K_{r−1−p,1}，正是定理 2.8 证明开头用的形式（L267）。

## 四、疑问

1. **猜想 1.4 的"锐利性"第一句**（L63）：原文说"由 Green–Lazarsfeld 非消没定理 2.8 可推出 K_{d−2,1}(C,K_C⊗η)≠0"。非消没定理是 2.4，不是 2.8；我用 2.8 的区间算过，p=d−2 落在第二区间只会给出 K_{d−3,2}≠0，而要用 2.4 又需要一个"h⁰≥2 的分解因子"。这一步究竟怎么来，我没补出来（errata 第 4 条只处理编号，不解释推导）。
2. **定理 2.8 在 p>d−g 时**右端 ≤0（见三(c)），定理只声明 1≤p≤r。这些 p 上公式是否仍成立（此时 C(d−g,p)=0，公式退化为 dim K_{p,1}=dim K_{p−1,2}）？原文没有说，我倾向于"只在 p≤d−g 有信息"，但没有证据。
3. **§4.1 的 Betti 表对称性**写作 b_{i,j}=b_{g−2−i,3−j}（q↦3−q，L575），而定理 2.7 在 n=1 时给的是 q↦n+1−q=2−q。对典范曲线，经典的 Green 对偶确实是 3−q（Gorenstein 带来一次额外平移），但原文 L566 只说"对偶定理 2.7 适用"，没有解释这次平移。我想不通的是：定理 2.7 与表对称性在 q=1→{1 或 2} 上给出不同答案，而 L267 用的又是 2−q 的形式。可能是定理 2.7 侧还有一次 K_C 自对偶没写出来，但我没能补上。
4. **§4.2 定理 4.12/4.13 的联合证明**中，矛盾来自"dim W¹_n+δ≥2δ"（英文 p53）。δ=g+3−2d 的桥接账我能算，但从"K_{d+1,1}≠0 推出 W¹_n 的维数下界"这一步（Martens/Mumford/Keem 的界如何拼起来）我没有逐步验证。
5. **定理 2.10（Voisin 的 Hilbert 概形描述）**我只读懂了陈述：K_{p,q}(S,L) 是限制映射 H⁰(∧^q?)…的上核，"∧^nH⁰(L)≅H⁰(X^{[n]}_curv,det L^{[n]})"这一步为什么能把 Koszul 上同调写成截面上核，我没有推出来，暂记为黑箱。
6. **猜想 5.8 的量词**：若按字面读成"∀[C]∈M_g、∀L∈W^r_d(C)"，s=1 时它说每条曲线都满足 K_{p,2}(C,K_C)=0（g≥2p+3），而超椭圆曲线（Cliff=0）显然是反例。所以它应当是对一般曲线（或极大棱性曲线）陈述的，但原文措辞没有点明。

## 五、延伸

1. **接第 8 篇（Pareschi–Popa《阿贝尔簇上的正则性 III》）**：例 2.3 把 Castelnuovo–Mumford 正则性写成"K_{p,m+1} 对所有 p 消没"，第 8 篇则用正则性推一般消没（H^i(F⊗α)=0 对一般 α）。两者是同一现象的两个层次——一个用合冲的消没阈值定义 reg，一个用 reg 推出层上同调的消没。读第 8 篇时把"reg"读成"Koszul 阈值"会顺很多。
2. **接第 9 篇（Teixidor i Bigas《可约曲线上的向量丛及应用》）**：§3.2 的边界延拓（定理 3.6 要在 G~^r_d 上工作）用到了极限线性系、容许覆盖、半稳定等价与可约曲线上的无挠层，这些正是第 9 篇的主题。读第 9 篇时回头看我这条链 3，能明白"为什么 Koszul 闭链必须先在退化曲线上算"。
3. **接第 5 篇（Kamnitzer）**：格拉斯曼流形上的组合/表示论与本章的"外幂 + 缩并"是同一套线性代数；如果想把 K_{p,q} 的复形画成图，第 5 篇的图论语言（ crystal、MV 多面体）是好工具——不过这只是我的联想，本章没有涉及。
4. **进一步读**：Aprodu–Nagel《Koszul Cohomology and Algebraic Geometry》(2009) 第 2–4 章（定理 2.6/2.7/2.8 的标准处理）；Voisin 2002（g=2p+3 一般曲线）与 2005（g=2p+4）两篇原文；Green 1984 的原始对偶定理。
5. **计算实验**：用 Macaulay2 对具体曲线（如 g=10 的 K3 截面、g=6 的 (6,3,3) 完全交）算 K_{0,2}、K_{1,2} 的维数，验证"42 个 g⁴₁₂ 中失效的个数 = Z_{10,0} 的重数"（L835）；也可以对 g=6、d=9 的例 5.2 验证 ν₂ 是同构（此时 K_{0,2}=0）。
6. **能用在**：给定一条曲线（例如某个具体完全交），算它的 K_{p,2} 给出 Cliff 的上界，从而判断它是否满足 Green 猜想；或者反过来，用定理 3.5 的退化轨迹给 M̄_g 造新的有效除子，检验它是否违背斜率猜想。
