# 第 4 篇读书笔记

> 页码：中译 p.72–81 / 英文 PDF p.78–89 / 原书 p.69–80。行号指 source/chapters/ch04.tex。
> 读法：先自己推一遍 §2 的换算，再跟 §3 的算例对账，最后回看 §5 的一般框架。

## 一、主线（我自己的话复述）

这一章要解决的是一个「没有定义」的问题：当 M(n,d) 奇异时，相交数本来无从谈起。

普通上同调的麻烦有两层。第一层是杯积不闭：在奇异商上，两个上同调类的积可能落到「不该在的地方」，Poincaré 对偶也不再给出完美配对。第二层是几何的：奇点来自非平凡稳定子群（最坏处整个 SU(2)），不同稳定子维数的层叠在一起，闭链横截相交这件事本身就失去意义。补救的办法有两条，各有代价：部分消奇异（把商空间沿稳定子层逐层爆破成轨形）保住了普通上同调，但改动了空间，算出来的不再是原空间的相交数；相交同调 IH 天生带 Poincaré 配对，但没有环结构，无法直接做「两个类的积」。

本章的策略是不去修 IH 的层论，而是**换一个空间算**：把问题搬到等变上同调 H_K^* 上。等变上同调有两个好处——杯积永远是良定义的；并且当作用「平衡」时，Kiem 证明了 IH^*(M//G) 恰好是 H_G^*(M^{ss}) 的一个截面 V_M（定理 5.4），两个互补次数的 V_M 类之积仍在 V_M 里、且等于最高次类乘配对数（定理 5.5）。于是「相交数」=「等变上同调的杯积 + 拓扑交」，前者可算、后者是配对。

剩下的就是算。全章的技术可以拆成三个「换」：
1. **换群**：K 上的积分换成 T 上的积分，代价是乘 1/n!（|W(SU(n))| = n!）并插入 D = ∏_{α>0}α。这是式 (1)、(9) 的内容，L53 那一句话是全章的枢纽。
2. **换积分**：T 上的积分换成不动点集上的留数之和，公式是 (10)，定理 6.1 是它的「两个正则值之差」版本，注 6.2 处理周期性（除以 1−e^X）。
3. **换配对**：IH 的配对换成 V_M 上的等变杯积，依据是定理 5.4/5.5，而平衡条件（定义 5.2/5.3）与「SL(p) 弱平衡」（定理 5.6）保证这一切真的适用于 M(n,d)。

三个「换」串起来，就是本章的标题：奇异模空间里的相交配对，最后落成一个留数公式。§3 的 M(2,0) 是把这条流水线从头到尾走一遍的示范，也是全章唯一给出封闭数值的地方。

一个印象：这章是「survey 中的 survey」——它汇总 [13]，而 [13] 又汇总 [11][12][14][15][16]。所以本章的公式往往只有结论没有推导（式 (2) 直接引 [13] (8.2)，式 (10) 说「如 [11] 中那样」）。读它要接受这一点：把公式当成接口，推导去原文献找。

## 二、关键构造的逻辑链

按依赖顺序排，每一步都标出它在原文的位置与它解决什么。

1. **M(n,d) → M^ext → μ → 辛商**（L16–41）。奇异的商空间不好直接处理，于是造一个光滑的扩张空间，使原空间成为它的辛商：M^ext = {(h, X) : Φ(h) = exp X}，μ(h, X) = X，μ^{-1}(0)/K = {Φ(h)=1}/K = 平坦联络模空间。这一步把「奇异」从空间转移到了矩映射上——空间光滑了，μ 成了记录奇异性的对象。§2 的部分消奇异就是沿着 μ 的稳定子层做的。
2. **部分消奇异 M~ 与 IH 的直和项性**（L28、L45–47、L184）。爆破后 μ~^{-1}(0)/K 是轨形，普通上同调够用；更关键的是 κ_M 的满射分解（L180–184）给出「IH^*(M//G) 是 H^*(M~//G) 的直和项」。这句话是两条路线的焊点：消奇异后的空间足够大，能看见 IH。
3. **κ 的三重复合**（L180–184）。κ_M: H_G^*(M) → H_G^*(M~) → H^*(M~//G) → IH^*(M//G)。第一步是拉回，第二步是轨形的 Kirwan 映射，第三步是投影到直和项。κ_M 满射（L184），所以 IH 的每个类都有等变代表。
4. **平衡条件与 V_M**（L147–178、L186–206）。κ^{ss} 什么时候是双射？Kiem 的答案是「平衡」：在每个点 p，把辛切片 Ŵ_p 里的 H-不动部分 Ŵ_p^H 去掉，剩下 W_p，要求 H 在 W_p 上的作用线性平衡（2n(β) ≥ ½dim A），并对所有子群 K ⊂ H 也要求（定义 5.3）。满足时 V_M 存在且 κ^{ss} 双射。这一步是纯表示论的，跟模空间无关——所以下一层要验证它。
5. **弱平衡与 M(n,d)**（L208–212）。对 M(n,d) = R(n,d)^{ss}//SL(p)，Kiem 证明 SL(p) 的作用弱平衡（定理 5.6，引 [16] Prop 7.4）。于是第 4 步的抽象结果适用于本章真正关心的空间。注意「弱平衡」比「平衡」弱，只要求 V_M 的等变类在稳定部分上一致，够用于配对。
6. **主公式 (1)/(9)**（L53–68、L254–258）。κ^{K,0}(αβ) = (1/n!)∫κ^{T,0}(αβD)：左边是 K-配对，右边是 T-积分。D 与 1/n! 各管一件事（见批注 2），两者不能互相替代。
7. **(10) 与定理 6.1、注 6.2**（L265–317）。留数公式把 T-积分化成 Σ_F Res∫_F ⋯/e_F，e_F 是法丛的等变 Euler 类。定理 6.1 说两个正则值处的积分之差等于夹在中间的不动点留数之和；注 6.2 用周期性 μ^{-1}(a) ≅ μ^{-1}(a+1) 把无穷多面墙的求和写成 1/(1−e^X)。到这里，(1) 里的 B 就有了显式形式。
8. **§3 的算例**（L72–129）。M(2,0) 第一次爆破沿 Δ=(S¹)^{2g}，例外除子的不动点分支是 P(T_Jac) ≅ P^{g−1}×Jac，法丛 (3) 的三个直和项给出三个权 2、−2、−4 与 Euler 类 (−y+2Y)(y−2Y)^g(y−4Y)^g；把 ηe^{ω̄}|_Δ 换成 Y^{3g−3}γ^g/g! 的倍数后，两次留数塌缩成 t^{g−1} 的系数 (4)。第二次爆破只留一句「类似，见 [13] §8」——这正说明 §3 是示范而非通式。

## 三、我补的推导 / 例子 / 反例

**(1) 式 (4) 的两次留数为什么等于一个系数。** 记 f(t) = (1−t/2)^{−g−1}(1−t/4)^{−g} = Σ_m c_m t^m，t = y/Y。由 L114–118，ηe^{ω̄}|_Δ = c·Y^{3g−3}γ^g/g!（c 为常数，正文把它并进 W，可设 c = 1），于是被积函数是 c Σ_m c_m y^{m−g}Y^{g−2−m}。Res_{y=0} 要求 m − g = −1，即 m = g−1，余下 Y^{−1}；再 Res_{Y=0} 取 Y^{−1} 的系数，得 c_{g−1}。所以两次留数 = Coeff_{t^{g−1}} f(t)。关键在指数：Y^{3g−3}·Y^{1−2g} = Y^{g−2} 提供的那一个 Y^{−1} 余量，正好被 t^m 的 Y^{−m} 吃掉。t = y/Y 是比值，所以系数是无量纲纯数。

**(2) 数值验算。** g=2：f 的一次项 = 3/2 + 1/2 = 2，W = −2/2⁶ = −1/32。g=3：二次项 = 5/2 + (2)(3/4) + 3/8 = 35/8，W = −(35/8)/2⁹ = −35/4096。两个数我都用纸笔与 SymPy 对过；g=2 那个可与 [13] §8 的表格对照（我手头没有原文表格，只能给到这个程度）。

**(3) 三个权与三个 Euler 类因子。** 规则 e_T(L) = c₁(L) + wt(L)·Y。O(−1)：c₁ = −y、权 +2 ⇒ −y+2Y，秩 1。T_Jac⊗R(1,0;0,−1)⊗O(1)：c₁ = y、R 的 diag(1,−1) 权 0、O(1) 权 −2 ⇒ y−2Y，秩 g。T_Jac⊗R(0,0;1,0)⊗O(1)：幂零元 E₂₁ 权 −2、O(1) 权 −2 ⇒ y−4Y，秩 g。三个数 2,−2,−4 与三个底数是一一对应的；谁少算一个权，Euler 类就少一个因子，最后的 W 会差一次 t 的幂。这是我自己检查 (2)→(3)→Euler 类这条链的第一道关口。

**(4) 1/n! 的两个层次。** 几何上，X/T → X/K 的一般纤维是 W = N(T)/T 的自由轨道，故 |W| 个点，T-基本类的积分要除以 |W| = n!。另有 D 负责纵向积分（D 的零集是「沿 K-轨道但不在 T-轨道方向」的退化轨迹）。两件事不重复：1/n! 数的是 Weyl 轨道重数，D 积掉纵向。顺便解释了一个表面矛盾：式 (1) 两边都是 T-积分，所以没有 1/n!；式 (9)(10) 左端是 K-配对，右端是 T-积分并带 D，所以有 1/n!。同一句话的两种写法。

**(5) S² 例的符号。** 取 η = 1：不动点 F_±，e_{F_±} = ±X，μ(F_±) = ±1，(e^X/X) + (e^{−X}/(−X)) = 2 sinh X/X ✓。Fourier 那步：Re X < 0 时 ∫_1^∞ e^{tX}dt = −e^X/X，故 e^X/X = −∫_1^∞ e^{tX}dt；若 F(e^{tX}) = δ(ξ−t)，则 Fh_+ = −H(ξ−1)、Fh_− = −H(ξ+1)，相减得 χ_{(−1,1)}，正是 [−1,1] 的特征函数。正文两个公式都少一个整体负号（或它的 F 自带负号），否则 h_+ − h_− 变换成 −χ，与下一句结论差号。数值上无碍，因为前推的是正测度。

**(6) 一个反例推翻「当且仅当」**（对应批注 15）。取 A = C²，C* 的权为 (1, 0)（一个非平凡方向与一个平凡方向）。若 0 ∉ B（这是让 L170 例句本身成立的读法），则 B∖{0} = {1}，β = 1 时 n = #{α : α < 1} = 1（α = 0 计入），2n = 2 = ½dim_R A，条件成立 ⇒ 平衡；但正权数 1 ≠ 负权数 0，按「当且仅当」应判不平衡。矛盾。若改取 0 ∈ B，则标准例子权 (1,−1) 在 β = 0 处 2n(0) = 0 < 2 已经不平衡，与「正负各一 ⇒ 平衡」矛盾。两种读法各杀一边，所以「当且仅当」无论如何是错的，而原文的 if 是对的。

**(7) 一个自问自答：为什么 W 只依赖 g。** 因为 n = 2 已固定，1/2 = 1/n! 被吸收进系数，剩下的 g 只通过 T_Jac 的秩 g 与 2^{3g} 出现；g 也是 t^{g−1} 的指标。所以 (4) 是一族关于 g 的闭式，而不是一个数。

## 四、疑问（读不懂、想不通、需要查文献）

1. **β = 0 属不属于 B？** 定义 5.1 说 β 是「权子集凸包中距 0 最近的点」，空集与含 0 的子集都会让 0 成为候选。若 0 ∈ B，则 n(0) = 0，2n(0) ≥ ½dim A 永不成立，于是一切作用都不平衡——与定理 5.6 冲突。所以必须排除 0，但正文与译文都没写。这直接影响 L170 的例子（见上 (6)）。
2. **A 是什么空间？** β ∈ A，权 α ∈ t*，却要作 ⟨α, β⟩。要让这个式子有意义，A 必须是 t*（或 t）。本章没有说，读者只能从 L84「在 t* = R 中从 0 过渡到 ε」反推。这是定义 5.1 的类型错位。
3. **D² 从哪来？** 式 (2)(10) 的右端比左端多一个 D（批注 6）。两个候选解释（留数公式抵消极点 / 基本类带因子）都未被文本支持。这是全章我最想找人核的一处。
4. **式 (2) 第三项英文缺 e^{ω̄}**，中译 L79 静默补齐。我倾向于是英文排版漏（同式前两项、全部 D² 项都是 ηe^{ω̄}D²），但没有原稿无法证明；若英文原意就是 ηω̄D²，那中译反而改错了。
5. **d ≠ 0 时 M^ext 怎么构造？** L16 说表示空间是「基本群的中心扩张」的表示，但没有展开中心扩张 Γ → π₁(Σ) → π̂ 的层次，也没说 d 如何进入 μ。本章公式大多对一般 n, d 写，可我只在 §3（M(2,0)）看到完整的 M^ext。
6. **注 6.2 的周期性为什么成立？** μ^{-1}(a) ≅ μ^{-1}(a+1)（微分同胚）只说「可以证明」。我猜来自扩张模空间上某个 S¹ 作用的平移（把 degree/level 加一），但没找到论证。
7. **定理 5.7 的 V_U 与 V_M 是什么关系？** U = μ^{-1}(B)，V_U 是不是 V_M 在 U 上的限制？正文只说 α^iβ^j ∈ V_U 仅当 j < g−1，没有给两者的关系。
8. **定理 6.1 到 (10) 的那一步我没补全。** (10) 是单个 ε 处的积分，定理 6.1 是两个正则值之差；中间要用 (1) 把 A 选成一个基准，但 §6 没有把这个选择写出来。我按「B 的显式化」来理解 (10)，但严格推导缺一环。
9. **注 3 的 Prim_l 与 Sp(g) 表示**我只记了结构（g+1 个直和项、α,β,ξ 次数 2,4,6、c_n 递推），没有验证；ξ = αβ + 2γ 这个关系我也没有独立算过。

## 五、延伸（下一步读什么、能用在哪）

1. **补 [13] §8**：第二次爆破（沿 GΓ̂，L129）的完整计算，以及 M(2,0) 的最终配对值。本章只给了第一次爆破的 W，第二次只有一句「类似」。
2. **补 [11] 的留数公式**：批注 6 的 D² 之谜要靠 [11] 的非交换局部化公式解决；[23] Martin 的推导是 (9)(10) 的另一条路。
3. **可做的计算**：用 (4) 算 g = 2,…,6 的 W 序列（一个符号求和即可，我已在 (2) 里起头），再看是否能写成超几何/ Legendre 多项式的封闭形式——从 (1−t/2)^{−g−1}(1−t/4)^{−g} 的系数结构看，应该可以。
4. **与第 1 篇对照**：Verlinde 公式里的 1/n! 与本章 (9)(10) 的 1/n! 是不是同一个外尔群阶？如果同一个，两章的量子化与相交数就共享同一套换算；这是我在读 ch1 时想回头核的问题。
5. **与第 3、7 篇对照**：把穿墙的数值不变量（W）当作双有理变换的「度量」。第 3 篇的翻转是几何操作，本章的 W 是这个操作的数值影子；两者若能对上，就能用相交数判别翻转的等价类。
6. **工具化**：(4) 与 (10) 都是「系数抽取 + 留数」，可以直接写成符号计算脚本，用 SymPy 验证 g ≤ 5 的全部数值，并作为将来校对中译公式的自动检查。我在这份笔记里给的两个数（−1/32、−35/4096）就是手工版的这类检查。
