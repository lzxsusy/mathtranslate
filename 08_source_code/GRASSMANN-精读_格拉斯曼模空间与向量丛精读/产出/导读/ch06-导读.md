# 第六篇 · Max Lieblich · 曲线上层模空间的算术方面（中译 p.94–115）

## 一、这一章在书里干什么

这本书的前五篇（Hitchin 联络、Koszul 上同调、Reider 定理、相交配对、Beilinson–Drinfeld 格拉斯曼）基本都在复几何与镜像对称的一侧，第六篇是全书第一次把“模空间”当成算术对象来用，也是唯一一篇以 Brauer 群与有理点为主线的文章。作者 Lieblich 的问题不是“曲线上的稳定丛模空间长什么样”，而是：**它的形式（forms）上有多少有理点，Brauer–Manin 障碍是不是唯一障碍，而这与曲线函数域上 Brauer 类的周期-指标问题有什么关系。**

全章有两条线索。第一条是引言里的**定理 (L)**：设 $\mathscr{X}\to X$ 是算术曲面 $X\to\Spec\mathscr{O}_K$ 上在几何纤维与无穷远位都平凡的 $\mu_n$-gerbe，$\alpha$ 是它的 Brauer 类，则 $\mathrm{per}(\alpha)=\mathrm{ind}(\alpha)$ 当且仅当几何有理簇 $M_{\mathscr{X}_K/K}(n,\mathscr{O}(D_K))$ 上“次数 1 的 0-闭链”满足 Hasse 原则。这把“$\Br(K(X))$ 中一个类的复杂度”翻译成“一个具体簇上的局部-整体原则”，是 Artin–Tate 同构 $\Br_\infty(X)\cong\text{Ш}^1(\Spec K,\mathrm{Jac}(X_\eta))$ 的非阿贝尔精细化。第二条线索在 §4–§5：分歧的 Brauer 类不能直接这样处理，需要把分歧编码成根叠 $\mathscr{P}\to\mathbf{P}^1$，再研究 $\mathscr{P}$ 上“正则抛物丛”的模空间的形式；于是“周期-指标”变成“某个抛物模空间是否有有理点”，而 Kunyavskiĭ–Rowen–Tikhonov–Yanchevskiĭ 那类“Faddeev 指标 4”的双四元数代数恰好在这里给出一个反例式的现象：它看起来违背 Hasse 原则，其实是相伴模问题在某个位处根本没有局部点。

附录 A–C 是自足的技术包，值得单独读：A 讲 gerbe、扭曲层、稳定性与形变理论（论文里所有“光滑/无障碍”都从这里来），B 讲 Brauer 群的几何定义、指标与周期，C 讲分歧正合列、根叠与“分歧 $=$ 相对 Picard 模空间”的内蕴刻画。

## 二、读它之前要知道什么

第一层是**叠的语言**：gerbe（带 $\mu_n$ 带的、或带 $\mathbf{G}_m$ 带的）、惯性叠 $\mathscr{I}(\mathscr{X})=\mathscr{X}\times_{\Delta,\mathscr{X}\times\mathscr{X},\Delta}\mathscr{X}$、粗模空间与层化、扭子与伪扭子。这些在“记号与假设”（L50–61）里只给了一句定义，真正的入门材料是 Laumon–Moret-Bailly [16] 与 Giraud [10]。

第二层是**曲线上向量丛模空间的基本事实**：$\mathscr{M}_C(r,L)\to M_C(r,L)$ 是 $\mu_r$-gerbe，稳定层叠有限型、$r$ 与 $d$ 互素时拟固有；$g\ge2$ 时 $\Pic_C[r]\cong(\mathbf{Z}/r)^{2g}$ 且 $\Pic(C\otimes\overline K)=\mathbf{Z}$——后者是 §2 猜想 2.3 与 §3 定理 3.4 反复使用的条件。

第三层是**上同调工具**：至少会算 $\mu_n$ 的 Leray 谱序列低次项与边缘映射、Kummer 正合列给出的 $\mathrm{H}^2(-,\mu_r)\leftrightarrow$ $r$-挠 Brauer 类、以及类域论里的局部不变量 $\Br(K_\nu)\to\mathbf{Q}/\mathbf{Z}$。第 1 节的 Claim 1.4、Lemma 1.7 与 §2 的 Brauer–Manin 配对全都建在这上面。

第四层是**算术侧的常识**：周期与指标、Hasse 原则与 Brauer–Manin 障碍、$C_1$ 域上的 Tsen/Lang/Wedderburn 定理、Graber–Harris–Starr 定理、Esnault 关于有限域上簇的有理点定理。作者默认读者知道这些，只在 §2 用两页回顾。

第五层是**抛物丛与根叠**：Cadman [3]、Borne [2]、Biswas [1]。若完全不熟，可先读 §4 的 Def 4.1–4.4 与 Prop 4.3，再去查原文；本章只需要“权在 $\{0,\frac12\}$”这一特例。

不必先读第 1–5 篇，但第 2 篇（Koszul 上同调与模空间几何）与第 7 篇（$\alpha$-稳定凝聚系）能提供很好的对照。

## 三、怎么读（路线 / 可跳过的部分 / 第一遍看到哪）

**第一遍（约 1 小时）**：摘要（L11）＋引言（L17–43）＋§6 问题清单（L497–506）。这四块给出“为什么做、做出了什么、还差什么”，其中定理 (L) 的陈述与 §6 的五个问题要抄下来。

**第二遍（半天）**：§1 全文（L63–201），配附录 A.1（Def A.1.1/A.1.2 的斜率与稳定）与 A.2（Thm A.2.1 的三件套）。§1 是全章方法论的核心：形式 $\leftrightarrow$ 扭子 $T\leftrightarrow$ 类 $\overline\alpha\in\mathrm{H}^1(\Pic^d,\mathbf{R}^1\mathrm{pr}_{2*}\mu_r)\leftrightarrow$ Leray 边缘映射，最后落到定理 1.9（等平凡 Torelli）。读的时候把这条链画成图，后面 §3、§5 都在复用。

**第三遍**：§2–§3（L204–317）。§2 是背景（Question 2.1、Conjecture 2.2/2.3、Brauer–Manin 配对），§3 是三个定理：Thm 3.1（有限域上曲线 $\Br=0$，Lang+Wedderburn）、Thm 3.2（de Jong：代数闭域上曲面函数域 $\mathrm{per}=\mathrm{ind}$）、Thm 3.4（主定理：Conj 2.3 $\Rightarrow$ 非分歧类 $\mathrm{per}=\mathrm{ind}$）。Thm 3.2 与 3.4 的证明梗概都要对着附录 A.2 读。

**第四遍**：§4–§5（L319–495），最硬。§4 只需掌握 Def 4.1（正则）、Def 4.2（抛物丛与抛物次数）、Prop 4.3（$\mathscr{P}$ 上的层 $\leftrightarrow$ 抛物层，且次数相等）、Def 4.4（斜率稳定）；Prop 4.6（单有理）可先跳过证明，只记结论。§5 抓四条：Prop 5.1.3（$\mathscr{M}^*_{\mathscr{C}/k}$ 是 $\mathscr{M}^*_{\mathscr{P}/k}$ 的形式）、Def 5.2.1（Faddeev 指标）、Prop 5.2.2（Faddeev 指标 $2\Leftrightarrow$ 某抛物模空间有有理点）、Lemma 5.2.4 + Cor 5.2.5（例子的局部障碍）。

**可以跳过的部分**：Prop 4.6 证明里扩张丛 $B\to U$ 的细节；Prop 5.2.6 的证明（作者明说“此处从略”，L495）；Cor C.3 的证明（L702 明说略去）；A.2.3 的粘合细节（L585 引 [19]）；以及附录 A.2 中 $\mathrm{Ext}^1/\mathrm{Ext}^2$ 的技术推导，第一遍只需记住“障碍在 $\mathrm{Ext}^2$、扭子在 $\mathrm{Ext}^1$”。

**第一遍看到哪**：读到 §3 末即可（此时定理 (L) 的证明骨架已经完整），§4–§6 留到第二遍。若只有半天，就读“摘要 + 引言 + §1 + 定理 3.4 + §5.2 的结论”，这是本章的骨架。

## 四、核心结果（3–5 条，每条给编号 + 一句话 + 为什么重要）

**1. 定理 (L)（引言，中译 p.95）**：$\mathrm{per}(\alpha)=\mathrm{ind}(\alpha)$ 当且仅当几何有理簇 $M_{\mathscr{X}_K/K}(n,\mathscr{O}(D_K))$ 上次数 1 的 0-闭链满足 Hasse 原则。**为什么重要**：这是全章的主定理，把 Brauer 类的周期-指标问题等价于一个具体簇上的局部-整体原则；又因为该簇的 $\Pic=\mathbf{Z}$，条件还可改写成“Brauer–Manin 障碍是唯一障碍”，于是“非阿贝尔化”的 Artin–Tate 同构有了可检验的形式。

**2. 定理 1.9（等平凡 Torelli，中译 p.100）**：对 $\mu_r$-gerbe $\mathscr{C}_1,\mathscr{C}_2$，$\mathscr{C}_1\cong_r\mathscr{C}_2$ 当且仅当 $\mathscr{M}_{\mathscr{C}_1/S}(r,L)\cong_r\mathscr{M}_{\mathscr{C}_2/S}(r,L)$。**为什么重要**：它说明“必须保留叠结构”——例 1.8 与 Lemma 1.7 给出粗模空间层面 Torelli 失效的例子（$[\mathscr{M}_{\mathscr{C}}]-[\mathscr{M}_C]=[\mathscr{S}_M]$），这正是全章的哲学：粗空间丢掉的信息恰好是算术信息。

**3. 定理 3.4（主定理的非分歧版，中译 p.104）**：若猜想 2.3 成立，则任意 $\alpha\in\Br_\infty(C)$ 满足 $\mathrm{per}(\alpha)=\mathrm{ind}(\alpha)$。**为什么重要**：它把猜想变成工具；证明里“0-闭链 $\Rightarrow$ 复形 $P^\bullet$ $\Rightarrow$ 半单性给出真层”的套路（见批注 6）是本章最可迁移的技术。

**4. 定理 3.2（de Jong，中译 p.104）**：代数闭域上曲面函数域中任意 Brauer 类满足 $\mathrm{per}=\mathrm{ind}$。**为什么重要**：几何侧的基石；本章给了一个“用模空间有理点”的新证明（爆破把分歧关进一条纤维，再用 Graber–Harris–Starr + Tsen），说明算术问题与几何问题可以是同一套机器。

**5. 命题 5.2.2 + 推论 5.2.5（中译 p.109–110）**：$\alpha$ 的 Faddeev 指标为 2 当且仅当某个 $M^*_{\mathscr{C}/\mathbf{Q}}(2,L)$ 有 $\mathbf{Q}$-有理点；而对 $A=(17,t)\otimes(13,(t-1)(t-11))$，所有 $M^*_{\mathscr{C}/\mathbf{Q}}(2,L)(\mathbf{Q}_{17})$ 都是空集。**为什么重要**：这是本章的“戏剧性结论”——所谓“Hasse 原则失效”的分歧类，其实违背的是**局部**存在性；非分歧情形与 Hasse 原则的联系在分歧情形被换成了“局部障碍”，这正是 §6 问题 (1)(2) 的由来。
