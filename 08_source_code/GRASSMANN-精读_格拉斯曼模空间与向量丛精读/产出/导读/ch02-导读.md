# 第 2 篇 · Aprodu & Farkas · Koszul 上同调及其在模空间中的应用（中译 p.30–54）

> 范围：中译 p.30–54 / 英文 PDF p.34–59 / 原书 p.25–50。行号一律指 `source/chapters/ch02.tex`。
> 本章 25 个定理、7 个猜想，是全书概念密度最高的一篇；建议至少读两遍，第一遍读地图，第二遍读机器。

## 一、这一章在书里干什么

全书九篇各从一个侧面讲"模空间/向量丛怎么用来做几何"：第 1 篇从 Hitchin 系统与几何量子化出发，第 3 篇讲 Reider 定理与 Thaddeus 对（稳定性与向量丛），第 5 篇讲 Beilinson–Drinfeld 格拉斯曼流形与辛纽结同调，第 6 篇讲曲线上的层模空间的算术方面，第 7 篇讲 α-稳定凝聚系，第 8 篇讲阿贝尔簇上的正则性及其与一般消没的关系，第 9 篇讲可约曲线上的向量丛。本章是其中唯一以**曲线的合冲（syzygy）**为主角的一篇：它不问"曲线上有什么线性系"，而问"曲线在射影空间里的方程长什么样"，然后把这两件事严格地等同起来。

具体地说，本章干三件事。

1. **铺工具（§2）**。Green 的 Koszul 上同调本来是从极小分次自由分解的 Betti 数里长出来的；本章把它改写成"缩并 + 乘法"两个自然映射构成的双复形的上同调（L148–168），于是它变成可以逐项计算的对象。接着给出四件可用的工具：例 2.1–2.3 三个"字典"（正规生成、H¹(O_X)、Castelnuovo–Mumford 正则性都能读成某组 K_{p,q} 的消没）、核丛刻画（定理 2.6）、对偶（定理 2.7）、维数公式（定理 2.8）。
2. **造除子（§3）**。先把 K_{p,q} 搬到族上（定理 3.4：K_{p,q}(X/S,L) 是基概形 S 上的凝聚层，且其纤维在开集上就是 K_{p,q}(X_s,L_s)），再把 {K_{p,2}≠0} 写成两个向量丛之间态射的退化轨迹（定理 3.5），于是可以算虚类（定理 3.6、式(5)）。当秩相等条件 r=2s+sp+p、g=rs+s、d=rs+r 成立时，得到的 Z_{g,p} 是 M̄_g 上的虚除子，其斜率在 s≥2 时落在 6 与 6+12/(g+1) 之间——这就是斜率猜想的反例生产线。
3. **画猜想地图（§4–§5）**。用 K_{p,q} 重述 Green 猜想（Clifford 指标 = 消没指数）、棱性猜想、极大秩猜想、强极大秩猜想、极小合冲猜想，并给出已验证的若干情形与几个"用 Koszul 除子反推曲线存在性"的定理。

为什么在本工程里值得细读：本章是全书"把线性系/模空间的语言与方程/合冲的语言对齐"的样板。第 8 篇的一般消没与正则性、第 9 篇的极限线性系与可约曲线上的层，最终都要回到这里的 K_{p,q}；而 "K_{10} 的斜率 7 < 78/11" 又是全书用具体除子检验一般猜想的最干净的例子（§1，L83–90）。

## 二、读它之前要知道什么

按重要性排，缺哪条就会卡在哪一节：

1. **曲线的线性系**：g^r_d、W^r_d(C)、G^r_d(C)（§3.1，L367–391），Brill–Noether 数 ρ(g,r,d)=g−(r+1)(g−d+r)，以及"一般曲线的 W^r_d 维数恰为 ρ"这一预期。棱性 gon(C) 与 Clifford 指标 Cliff(C) 的定义（L17、L583–596）必须记牢：Cliff(C) 是 min{d−2h⁰(L)+2 : h⁰(L)≥2, h¹(L)≥2}。缺这条，§4.1 的式(1) 与猜想 4.1 就是空话。
2. **分次代数与极小自由分解**：S=Sym V（V 为 n 维）、齐次坐标环 S(X)、E_p=⊕_{j>p}S(−j)^{β_{pj}}、Hilbert 函数（L116–142）。至少要会算 S(−j)_d 的维数——这正是译注②的由来（见批注 6）。
3. **层上同调的基本工具**：Serre 对偶、Riemann–Roch、Bott 公式。定理 2.8 的证明是纯计算（L279–299），定理 3.5 的秩 rank(A)=(p+1)C(r+2,p+2)、rank(B)=C(r,p)(−pd/r+2d+1−g) 则要用 P^r 上 ∧^pM_{P^r}⊗O(2) 的上同调。
4. **模空间的语法**：M_g、M̄_g、稳定曲线、Deligne–Mumford 叠与粗模空间（L456）、极限线性系（L462）、容许覆盖与半稳定等价（L784）。这一条只需"知道有这回事"，§3.2 会现学现用。
5. **除子与斜率**：Pic(M̄_g) 由 λ 与 δ_0,…,δ_[g/2] 生成；D 的斜率 s(D) 是使 aλ−b(δ_0+…+δ_[g/2])−[D] 为边界除子的有效 Q-组合的最小 a/b（L77）；斜率猜想断言 s≥6+12/(g+1)（L79）。缺这条，§3.3 的全部动机（"为什么小斜率除子是反例"）都读不出来。

## 三、怎么读

**第一遍（约 2 小时，读地图）**：§1（L11–110）→ §4.1（L564–610）→ §5.1（L900–918）。只做一件事：把五个猜想抄在一张纸上，写出它们的关系。参考答案：式(1) 是 Green 猜想的等价形式；猜想 4.1 是它的"p 形式"；棱性猜想（§4.2）与定理 4.5 是"把一般 d 化到极大棱性"；猜想 5.8 在 s=1 时退化为 Green、在 p=0 时退化为定理 5.3（L918）；猜想 5.4 在 ρ=0 时等价于猜想 5.1（L870）。第一遍结束时，你应该能说出"K_{p,q}(C,K_C) 消没到哪里"这一句话。

**第二遍（约 3 小时，读机器）**：§2 全节。不要只读，要手算三件事：(a) K_{0,2}=coker(Sym²H⁰(L)→H⁰(L²))；(b) 例 2.2 的 K_{h⁰−2,2}≅H¹(O_X)（完整证明见批注 2）；(c) 定理 2.8 在 (g,d,p)=(5,10,1) 时两边都等于 5。算完再读 §2.3–2.4，定理 2.6 的"coker≅ker"就不再是魔术。

**第三遍（约 2 小时，读应用）**：§3 的定理 3.4→3.5→3.6→式(5) 链条，配 §3.1 的 Brill–Noether 除子背景；然后精读 §4.2 定理 4.5 的证明（L646–662），那里有一个漂亮的"接桥"构造，也是本章两处原文错误的所在（见批注 10）。

**可以跳过（第一遍）**：定理 3.6 的两个七次多项式 f(s,p)、h(s,p)（L524–534，只需记住结论 6<a/b₀<6+12/(g+1)）；命题 5.7 的证明（L897，只需结论）；§2.4 定理 2.10、2.12 的技术细节（Voisin 的 Hilbert 概形与 K3 特化，本章只作引用）；参考文献（L920–1024）。

**必须精读的三段**：定理 2.6 的证明（全章发动机）、定理 2.8 的证明（本章唯一完整的计算）、定理 4.5 的证明（接桥技巧与定理 4.6 的用法）。

## 四、核心结果

1. **Green 猜想与定理 4.4**（式(1) L15；猜想 4.1 L605；定理 4.4 L631）。K_{p,2}(C,K_C)=0 ⟺ p<Cliff(C)；等价地，p≥g−Cliff(C)−1 ⟹ K_{p,1}(C,K_C)=0。定理 4.4 给出极大棱性情形 g=2d−1≥7 的精确解：K_{d−1,1}(C,K_C)≠0 ⟺ C 携带 g¹_d。**为什么重要**：这是全章的目标陈述——"Clifford 指标 = Koszul 上同调开始消没的指数"；而定理 4.4 又是定理 4.5（任意 d）反证法的落点。
2. **定理 2.4（Green–Lazarsfeld 非消没，L196）**。若 L=L₁⊗L₂、h⁰(L_i)=r_i+1≥2，则 K_{r₁+r₂−1,1}(X,L)≠0。**为什么重要**：全章所有"非消没"的唯一来源；配合定理 2.7 的对偶变成"消没"，配合定理 3.5 变成"退化轨迹非空"。
3. **定理 2.6 与定理 2.7（核丛与对偶，L225、L235）**。K_{p,q} 同时是截面乘法的上核与连接映射的核；对偶给出 K_{p,q}(X,L)^∨≅K_{r−n−p,n+1−q}(X,K_X,L)（X 为 n 维、r=dim|L|）。**为什么重要**：前者把合冲变成截面上同调，使"算维数"（定理 2.8）与"造向量丛"（定理 3.5 的 B=H⁰(∧^pM_L⊗L^{⊗2})）成为可能；后者解释 Betti 表的中心对称。
4. **定理 2.8（维数公式，L251）**。dim K_{p,1}−dim K_{p−1,2}=p·C(d−g,p)·((d+1−g)/(p+1)−d/(d−g))。**为什么重要**：它给出 Cliff 的数值阈值——p 小时左边由 K_{p,1} 承担（非消没），p 大时由 K_{p−1,2} 承担；这是式(1) 的定量版本，也是 §4.1 一切"消没区间"的计算依据。
5. **定理 3.5 + 定理 3.6 + 式(5)（Koszul 闭链，L487、L513、L544）**。U_{g,p}={K_{p,2}≠0} 是 A→B 的退化轨迹，秩相等条件 r=2s+sp+p、g=rs+s、d=rs+r；s=1 时 [Z̄_{2p+3,p}]^virt=(1/(p+2))C(2p,p)(6(p+3)λ−(p+2)δ₀−6(p+1)δ₁−…)，斜率恰为 6+12/(g+1)。**为什么重要**：这是 M̄_g 上小斜率除子的生产线——把 p 取大、s 取 2 以上，得到的斜率就低于斜率猜想的下界，K₁₀ 的 7<78/11 就是这么来的（L83–90、L544–547）。
