# 第 4 篇 · Jeffrey · 奇异向量丛模空间中的相交配对（中译 p.72–81）

> 范围：中译 p.72–81 / 英文 PDF p.78–89 / 原书 p.69–80（原书 p.80 是空白背面页）。行号一律指 source/chapters/ch04.tex，页码一律写「原书 p.N」。
> 本章是一篇 survey：汇总 Jeffrey–Kiem–Kirwan–Woolf [13]（Transformation Groups 11 (2006)）的结果，用 §2、§4 两节铺背景，用 §3、§6 两节给算例与计算工具。全章 27 条参考文献，没有一条是装饰。

## 一、这一章在书里干什么

**一句话**：曲线上的向量丛模空间 M(n,d) 在 n、d 不互素时是奇异的（最坏的点稳定子群是整个 SU(2)），普通上同调的杯积不足以定义相交数；本章回答「奇异模空间上的相交数是什么、怎么算」。

具体分三层：

1. **问题**（§1，L14–41）。M(n,d) 是亏格 g ≥ 2 的 Riemann 面上秩 n、次数 d 的半稳定全纯向量丛模空间，可能奇异；它又是基本群中心扩张的表示空间模共轭（L16）。奇点来自非平凡稳定子群，稳定子维数越高越奇异。两条现成的路线：**部分消奇异**（沿高维稳定子层逐层爆破，得到轨形 M(n,d)~，其普通上同调仍带 Kirwan 映射）与**相交同调** IH*（天生带 Poincaré 配对，但没有环结构）。
2. **焊接**（§5，L145–248）。Kiem 的结果：当作用「平衡」时存在子空间 V_M ⊂ H_G*(M^{ss})，κ^{ss}: V_M → IH*(M//G) 是双射（定理 5.4）；互补次数的两个 V_M 类之积仍在 V_M，且等于最高次类 τ 乘配对值（注 1、定理 5.5）。于是 IH 的配对可以由等变上同调的杯积来算——这就是全章的合法性来源。
3. **计算**（§2、§3、§6）。§2 给主公式 (1)：K 上的积分 = 1/n! 乘 T 上的积分，D = 正根之积 = K/T 的 Poincaré 对偶（L53）；§3 是唯一从头算到底的例子 M(2,0)，把两次爆破的穿墙项化成幂级数系数 (4)（L129）；§6 给可算的留数公式 (10)、定理 6.1（Guillemin–Kalkman；Martin）与注 6.2。

**在全书里的位置**：九篇里只有本章正面处理「模空间奇异时怎么办」。第 1 篇（Andersen–Gammelgaard，中译 p.7–29）研究的是同一个模空间族在**光滑**情形下的量子化（Hitchin 联络、Toeplitz 算子、TQFT）；第 3 篇（曲面稳定性与 Reider 定理、Thaddeus 对）与第 7 篇（Newstead 的 α-稳定凝聚系）关心稳定性随参数变化引发的「穿墙」与双有理变换；本章只取穿墙的**数值后果**——相交数如何跳跃，并把它算成留数。所以本章是全书技术最「硬」、也最短的一篇（10 页），适合在读第 3、7 篇之后再回来。

## 二、读它之前要知道什么

按重要性排，缺哪条就会卡在哪一节：

1. **等变上同调与局部化**（读 §2、§6 的入场券）。H_K*(X)、结构映射 H_K*(pt) → H_K*(X)、限制映射 H_K*(X) → H_K*(μ^{-1}(0))、等变 Euler 类 e_F、Atiyah–Bott 不动点公式与 Duistermaat–Heckman 振荡积分（[1]、[2]）。本章的核心动作是「把积分写成不动点上的留数」，没有这套语言什么都读不动。
2. **辛几何与矩映射**（读 §1–§3）。矩映射 μ: X → k*、辛商 μ^{-1}(0)/K、轨形、辛切片（Sjamaar–Lerman [26]）、以及「扩张模空间」这个把辛商与矩映射解耦的构造。没有矩映射，式 (1) 里的 μ~^{-1}(0)/T 就是一串符号。
3. **GIT 与部分消奇异**（读 §1、§5）。稳定/半稳定、R(n,d)^{ss}//SL(p)、Kirwan 的部分消奇异（[18]）、稳定子分层与「维数最高的层先爆破」。本章的 M(n,d) = R(n,d)^{ss}//SL(p)（L208）与 M(n,d)~ 都是这套语言。
4. **相交（上）同调**（读 §4–§5）。Goresky–MacPherson 的 IH*（[3]、[4]）、Lefschetz 超平面定理、强 Lefschetz 定理（本工程统一译作「强」，别处常作「硬」）、Poincaré 对偶 IH_j ⊗ IH_{2n−j} → R、以及「一般没有环结构」这一条。前三者保证 IH 够用，最后一条决定了为什么需要 V_M。
5. **曲线上的向量丛**（读 §1、§6 的例子）。M(n,d)、稳定与半稳定、(n,d)=1 时半稳定即稳定故模空间光滑、Jacobian 与秩 g 的 T_Jac、Jac 上的 γ = Σ d^j d^{j+g}。§3 的所有权计算都落在 T_Jac 上，不知道 Jac 就不明白为什么 Euler 类里出现 g 次幂。
6. **外尔群与正根**（读 §2 的那句话）。D = ∏_{α>0} α，deg D = dim_R K/T = n(n−1)，|W(SU(n))| = n!。这三件事合起来才解释式 (1)–(10) 里的 1/n! 与 D 的幂次。

**最低配置**：1+2 就能读 §2–§3 的全部公式；3+4 是 §5 的门槛；5 只需要「知道有这些对象」。

## 三、怎么读

**第一遍（约 2 小时，读骨架）**：§1（L14–41）→ §2 的 L53 与式 (1)（L53–68）→ §6 的 (9)(10) 与定理 6.1（L252–310）。只做一件事：把「K 积分 → 1/n! × T 积分 → 不动点留数」这条链条画出来，并标出 D 在每一站的角色。第一遍结束时，你应该能说出式 (10) 右端每一项的几何含义（不动点、矩映射值、Euler 类、留数）。

**第二遍（约 2 小时，读算例）**：§3 全节（L70–129）。按 (2) → (3) → Euler 类（L103）→ (4) 的顺序手算，每步对照批注 4、5、6：三个权的来源、Euler 类的三个因子 (−y+2Y)(y−2Y)^g (y−4Y)^g、两次留数如何塌缩成一个系数。自检：g=2 时 (4) 给出 W = −1/32（批注 4 的验算）；g=3 时 −35/4096。这两个数是我在笔记里独立算的，可与 [13] §8 对照。

**第三遍（约 1.5 小时，读框架）**：§4（L131–143）只记三件事——Lefschetz 超平面定理、强 Lefschetz 定理、Poincaré 对偶；「没有环结构」这一句要划出来。然后 §5 先读定理 5.4、5.5、5.6 的陈述（L186、L198、L210），再回头读定义 5.1–5.3（L147、L153、L172）。定义里符号最密的是 W_p（辛切片 Ŵ_p = (T_p(G·p))^ω / T_p(G·p) 中 Ŵ_p^H 的补），批注 7 解释了为什么照字面读会卡住。

**可以跳过（第一遍）**：注 3 里 Prim_l 的定义与递推 (8) 的细节（L230–244，只需知道「V_M 有显式结构定理」）；参考文献（L319–373）；第二次爆破（L129）的构造细节，第一遍只需知道「与第一次同类」。

**三条译注**：译注 1（A/B 互换，L68）、译注 2（式 (3) 的 × 应为 ⊗，L99）、译注 3（定义 5.2 自引用应为 5.1，L168）。三条我都逐条核对了英文原书，**全部属实**（见批注 10–12）。另外本章「带层结构」（L41）与「在例外除子内部垂直」（L99）两处译法有问题，见 errata 与批注 13、14。

**编号陷阱**：本章的 definition/theorem/remark 按节共享编号，而 iremark 独立编 1–3。所以「注 1/注 2/注 3」是 Kiem 的三条注，「注 6.2」是 §6 的第二条 remark，两者不是同一套编号；正文里的「定理 5.4」指 §5 的第四条定理，不是全书第 5.4 条。

## 四、核心结果

1. **式 (1) 与 D（L53–68，原书 p.71）**。∫_{μ~^{-1}(0)/T} κ(αβD) = A + B，其中 A 是 ε 处的配对、B 是 0 与 ε 之差。D = 正根之积，其 Kirwan 像正是 K/T 的 Poincaré 对偶，所以 K 上的积分换成 1/n! 乘 T 上的积分（|W(SU(n))| = n!）。**为什么重要**：这是全章唯一的「降维」机制；式 (9)(10) 的 1/n!、定理 6.1 的求和都从这句长出来。原文把 A、B 的说明写反了（译注 1，属实），批注 3 给了一个记法。
2. **式 (4)：M(2,0) 的穿墙项（L108–127，原书 p.72–73）**。W = −2^{−3g} Coeff_{t^{g−1}}[(1−t/2)^{−g−1}(1−t/4)^{−g}]，t = y/Y。这是全章唯一从头算到底的量：几何（两次爆破的法丛）→ Euler 类 → 两次留数 → 一个系数。**为什么重要**：它示范了整条流水线；而且结果只依赖 g，说明这套方法能给出对所有亏格一致的闭式。
3. **定理 5.4 + 注 1 + 定理 5.5（L186–206，原书 p.74）**。平衡作用 ⇒ 存在 V_M ⊂ H_G*(M^{ss}) 使 κ^{ss}: V_M ≅ IH*(M//G)；互补次数的 σ₁, σ₂ ∈ V_M 满足 σ₁∪σ₂ = τ⟨σ₁,σ₂⟩。**为什么重要**：IH 没有环结构，但 V_M 上杯积封闭——这把「相交数」变成「等变上同调的杯积 + 拓扑交」，是后面一切计算的前提。
4. **式 (10) + 定理 6.1 + 注 6.2（L265–317，原书 p.76–77）**。(1/n!)∫κ^{T,ε}(ηe^{ω̄}D) = Res(Σ_F e^{⟨μ(F),X⟩}∫_F ηe^ω D²/e_F)；两个正则值处的积分之差等于夹在中间的不动点的留数之和（定理 6.1）；周期情形把求和写成 1/(1−e^X)（注 6.2）。**为什么重要**：这是可以真的算的公式；S² 例给出 h = 2 sinh X / X，把「留数」兑现成一个具体函数。
5. **定理 5.6/5.7（L210、L246，原书 p.75）**。SL(p) 作用是弱平衡的，故定理 5.4–5.5 适用于 M(n,d)；且 α^iβ^j ∈ V_U 仅当 j < g−1。**为什么重要**：前者保证前面的一般框架真的落在本章的模空间上（否则 §5 只是一般理论），后者给出 V_M 的第一个具体切片，也是唯一能用显然的生成元写下来的判据。
