# 第 9 篇 · Montserrat Teixidor i Bigas · 可约曲线上的向量丛及其应用（中译 p.160–170）

> 阅读坐标：中译 p.160–170；英文 PDF p.178–189；原书 p.169–179（英文 PDF p.190 是封底，不属本章）。源文件 `source/chapters/ch09.tex`（361 行，其中参考文献 61 行）。本章已有译注 7 处（`ch09.tex:45、51、87、200、204、242、269` 的脚注），本导读与批注均不重复登记。

## 一、这一章在书里干什么

这一篇是全书最短、也最"应用导向"的一篇：它不建立新理论，而是把三条已经成熟的技术路线摆在一起，示范如何用**可约曲线**（确切地说是紧型结点曲线）作退化，去证明一般光滑曲线上关于向量丛的定理。作者在 §1 末尾自己交代得很清楚：本文"不力求全面"，只展示若干"被证明行之有效的技术"（`ch09.tex:23`）。

三条路线是：

1. **Seshadri 紧化**（§2）。用深度为 1 的无挠层代替向量丛，用带权 $w_i$ 的 $\chi$-稳定性代替斜率稳定性，得到可约曲线上仍然紧的模空间；并证明它的分支由多重次数的等价类决定（命题 2.1）。
2. **Gieseker–Schmitt 的 Hilbert 紧化**（§3）。稳定丛在 $d$ 足够大时整体生成，于是给出曲线到格拉斯曼流形的映射；反过来取 Hilbert 概形中对应"浸入"的连通分支的闭包，再用 GIT 取商。这条路线与斜率稳定路线在光滑曲线上等价，在可约曲线上则给出"曲线不固定"的紧化——恰好是极限线性系所需要的那种退化。
3. **高秩极限线性系**（§4）。把 Eisenbud–Harris 的极限线性系从线丛推广到向量丛。定义里出现一个关键的整数 $a$（每个结点的"扭量"），条件 (a)(b)(c) 分别管次数守恒、结点消没阶互补、截面由结点值决定。

后两节是应用：§5 用可约曲线证明 **Lange 猜想**（$U(r,d)$ 的一般丛具有给定秩与次数的子丛，并给出余维数）；§6 把同一套退化技术用于 **Brill–Noether 存在性**（定理 6.1）与**高秩 Petri 映射的单射性**（定理 6.2：秩 2、典范行列式）。

所以这一章在书里的位置是"工具箱"：第 2 章讲曲线上的 Brill–Noether 理论，第 7 章讲极限线性系与凝聚系，本章把这两套语言接到高秩向量丛上。读的时候应当时刻问一句："这个构造在光滑曲线上退化回什么？"

## 二、读它之前要知道什么

1. **斜率稳定性与模空间 $U(r,d)$**。$\mu(E)=\deg E/\rank E$；对每个子丛 $F$ 有 $\mu(F)\le\mu(E)$ 即半稳定，严格小于即稳定；$r,d$ 互素时半稳定 = 稳定，$U(r,d)$ 射影。这是全章的出发点（`ch09.tex:11–15`）。
2. **可约曲线、结点、紧型、对偶图**。紧型 = 对偶图无圈 = Jacobian 紧致。本章的典型模型是 $g$ 条椭圆曲线首尾粘成一条链（`ch09.tex:202`）。要分清"分支 $C_i$ 上的次数"（多重次数）与"全曲线的次数 $d$"。
3. **无挠层与深度 1**。在不可约曲线上"无挠"就是没有挠子层；在可约曲线上要换成"任何挠截面在某个分支上恒为零"（`ch09.tex:29`）。直观上：层允许在结点处"掉秩"，这正是紧化时必须有 torsion-free 而不是 locally free 的原因。
4. **$\chi$ 与 Riemann–Roch、Serre 对偶**。本章的稳定性定义用 $\chi$ 而不是 $\mu$；证明里反复用 $\chi(E)=\chi(E|_{C_1})+\chi(E|_{C_2})-r$ 与"$h^0=0$ 时 $h^1=-\chi$"这类记账。若这两条不熟，§2、§5 的算术会跟不上。
5. **Hilbert 概形与 GIT**（§3 用）。只需知道"取 Hilbert 点、线性化、取稳定点之商"这个流程；幂零元、Hilbert 多项式的具体计算本章全部略过。
6. **极限线性系与 Brill–Noether 数**（第 2、7 章）。若读过第 7 章，§4 的定义会容易很多；若没读过，至少先接受"线性系 = 向量丛 + 截面空间"这个说法，并把 $\rho$ 当作"预期维数"来记。

## 三、怎么读（路线 / 可跳过的部分 / 第一遍看到哪）

- **第一遍（约 40 分钟）**：§1（`ch09.tex:11–23`）→ §2 的定义（`29–47`）与命题 2.1、2.2 的陈述（`56`、`83`）→ §4 定义 4.1（`136–149`）→ 定理 5.1、6.1、6.2 的陈述（`193`、`220`、`291`）。把"深度 1 + 极化 + $w$-秩"、"$a$ 与 (a)(b)(c)"、"$\rho$"三组记号记住，骨架就有了。
- **第二遍（细读）**：§2 两个命题的证明（`60–77`、`87–100`），尤其是 $(\ast)$ 为什么恰好给出 $r$ 个值，以及命题 2.2 中两个子层 $F$、$F'$ 的构造；§5 的维数记账（`185–193`），动手把 $h^1$ 算一遍；§6 的算例（`246–265`），把 $a=4$、$\rho=5$ 与维数等式逐项核对。
- **可以较快通过**：§3 的 GIT 细节（只需记住"光滑曲线上斜率稳定 = Hilbert 稳定"与"可约曲线上曲线会变"两个结论）；§4 中 `153–165` 的"验证极限确实是极限线性系"第一遍可跳，第二遍再回来看 $a$ 的构造与 (b) 的估计；§6 定理 6.1 的三组条件 (1)(2)(3) 形式复杂，第一遍只需知道它们是关于 $g$ 与 $d_1,k_1$ 的不等式。
- **必读的算例**：§6 的 $g=5,k=4,d=9$（`246–265`）。这是全书少见的把"极限线性系 + 维数记账"完整跑一遍的地方：五个分支上的丛、每个结点消没阶之和为 4、自同态维数 $1,2,4,4,2$、粘合维数 $3,4,4,4$，最后得到 $\rho=5$（按这组数实算为 $6$，与原文的 5 不符，见 errata 第 1 条）。读完后应能自己解释为什么 $a=4$。

## 四、核心结果（5 条，每条给编号 + 一句话 + 为什么重要）

1. **命题 2.1**（原书 p.171；`ch09.tex:56`）：两分支结点曲线上，关于一般极化半稳定的无挠层模空间连通，有 $r$ 个不可约分支，每个分支维数 $r^2(g-1)+1$。它把"Seshadri 紧化"具体化：分支数 = 多重次数的等价类数（$M=2$ 时为 $r$），维数与光滑情形一致；证明中的 $(\ast)$ 是全章反复出现的原型。
2. **命题 2.2**（原书 p.172；`ch09.tex:83`）：若稳定丛在分支 $\bar C$ 上的限制分裂为 $r$ 个线丛 $L_1\oplus\dots\oplus L_r$，则 $|\deg L_i-\deg L_j|\le\alpha-1$，其中 $\alpha$ 是 $\bar C$ 上的结点数。这是"限制不可能太不稳定"的定量版本，也是 §3 中"可约曲线上 Hilbert 稳定性满足类似条件"的对照物。
3. **定理 5.1（Lange 猜想）**（原书 p.176；`ch09.tex:193`）：若 $r'd-rd'-r'(r-r')(g-1)\ge0$，$U(r,d)$ 的一般丛有秩 $r'$、次数 $d'$ 的子丛；当 $0\le r'd-rd'\le r'(r-r')(g-1)$ 时，这样的丛构成模空间中余维 $r'(r-r')(g-1)-(r'd-rd')$ 的不可约子集。这是本章的主定理，其证明策略（特殊曲线 + 极限线性系）是全书退化论证的范例。
4. **定理 6.1**（原书 p.177；`ch09.tex:220`）：在 (1)(2)(3) 三组条件下，一般 $g$ 亏格光滑曲线上 $B^k_{r,d}$ 非空，且（至少）有一个维数恰为 $\rho$ 的分支。它把 Brill–Noether 存在性从线丛推到高秩；证明靠"一般纤维维数上界 + 特殊曲线上的下界"夹逼，是本章方法论的浓缩。
5. **定理 6.2**（原书 p.179；`ch09.tex:291`）：特征 $\ne2$ 的代数闭域上，一般曲线、秩 2、典范行列式的半稳定丛，对称 Petri 映射 $S^2H^0(C,E)\to H^0(S^2E)$ 单射。它说明高秩时 Petri 映射一般不单射，但"典范行列式 + 秩 2"是一个例外；这是定理 6.1 之外本章另一个被广泛引用的结论。
