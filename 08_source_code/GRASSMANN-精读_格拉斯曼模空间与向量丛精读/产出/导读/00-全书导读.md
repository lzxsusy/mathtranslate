# 《格拉斯曼流形、模空间与向量丛》全书导读

> 对象：*Grassmannians, Moduli Spaces and Vector Bundles*，Clay Mathematics Proceedings 第 14 卷，
> AMS / Clay Mathematics Institute，2011 年。原书 179 页，中译本 170 页（`zh-译文.pdf`），
> 中文 LaTeX 源 77,000 字。本导读给的是「怎么把九篇独立论文读成一本」的路线图，逐章细读见 `chNN-导读.md`。

## 一、这是一本什么书

这是一本**会议论文集**，不是教科书。2006 年 10 月，Clay 数学研究所在剑桥（麻省）举办研讨会
「向量丛的模空间：面向凝聚层的视角」（Moduli spaces of vector bundles, with a view toward coherent sheaves），
为刚从爱丁堡退休、自 1960 年代以来首次访美的 P. E. Newstead 致敬；本书由 Newstead、D. A. Ellwood、
E. Previato 编成，收录九篇彼此独立的综述/研究论文。

因此读它要换一副眼光：**没有统一的章节依赖，没有习题，符号也不完全统一**。九位（组）作者各写各的
主题，深浅不一：ch4 只有 10 页（中译）、ch8 有 25 页，ch2 概念密度最高（25 个 theorem、7 个 conjecture），
ch7 的开放问题清单最长（12 个 question）。把它当「九篇相互引用的长综述」读，比当「一本书从第一页读到
最后一页」读有效得多。

## 二、九篇为什么能凑成一本书

因为它们共享**三个对象**和**四套工具**。

三个对象：

1. **代数曲线上的向量丛与凝聚层**——ch2、ch7、ch9 的主战场，ch6 把它算术化（有限域、Brauer 群）。
2. **阿贝尔簇上的层与 Fourier–Mukai 理论**——ch8 的主线（GV-层、M-正则性），ch5 的 Beilinson–Drinfeld
   格拉斯曼流形是它在「曲线 × 形式圆盘」上的近亲。
3. **模空间的整体几何**——ch3（曲面上的模空间与 Reider 定理）、ch4（奇异模空间的相交上同调）、
   ch1（模空间的量子化）分别从双有理几何、辛几何、微分几何三个方向切同一个对象。

四套工具：

- **稳定性**：斜率稳定 / GIT 半稳定 / α-稳定（ch7）/ Bogomolov 型稳定性（ch3）/ 无挠层的斜率稳定（ch9）。
  同一个词在五章里含义不同，这是全书第一大坑（见 §五）。
- **上同调与消没**：Koszul 上同调（ch2）、一般消没 GV（ch8）、相交上同调（ch4）。
- **导出范畴与变换**：Fourier–Mukai（ch8）、Beilinson–Drinfeld 的卷积（ch5）、ch3 的「翻转」。
- **形变与局部化**：Hitchin 联络的形式展开（ch1）、等变局部化（ch4）、形变-障碍理论（ch6 附录 A）。

前言的作者自己给过一个更文学化的分类：Kamnitzer 属几何 Langlands，Pareschi–Popa 属导出范畴技术，
Aprodu–Farkas 与 Jeffrey 分别是「Koszul 上同调」与「辛几何方法」两条技术路线，Teixidor 处理可约曲线，
Arcara–Bertram 把曲面稳定性往三维推，Lieblich 用 Brauer 群连接算术，Andersen–Gammelgaard 谈模空间的量子化，
Newstead 本人综述凝聚系。**这段话就是全书的目录学**，值得先读两遍。

## 三、三条阅读路线

九篇不必按顺序读。按目的选一条：

**路线 A · 模空间主线（最正统，约 60 页）**：ch2 → ch7 → ch9 → ch6。
先看 ch2 建立「曲线上的层 + Koszul 上同调 + Brill–Noether 闭链」的语言；ch7 把「向量丛」放宽成
「凝聚系 (E,V)」并问存在性；ch9 把曲线放宽成可约曲线，讲紧化与极限线性系；ch6 再把底域放宽到
一般域/有限域，引入 gerbe 与扭曲层。四章连读，等于把「曲线上的模空间」从光滑复曲线一路推广到
算术情形。

**路线 B · 几何与量子主线（约 45 页）**：ch1 → ch3 → ch4。
ch1 从 Hitchin 联络与 Toeplitz 算子给出模空间的量子化与 TQFT 曲线算子的渐近展开；ch3 用稳定性条件
与「翻转」重证 Reider 定理、重访 Thaddeus 对；ch4 在奇异模空间上定义相交配对并用等变局部化计算。
三章的共同点是「模空间不只是参数空间，它自己带有几何结构（联络、双有理模型、相交同调）」。
前置最重的是 ch1（需要联络、曲率、辛几何），可先读 ch3、ch4 再回来。

**路线 C · 阿贝尔簇与表示论主线（约 40 页）**：ch5 → ch8。
ch5 讲 Beilinson–Drinfeld 格拉斯曼流形、Hecke 修正与卷积积，落点是辛纽结同调；ch8 讲阿贝尔簇上
GV-层与 M-正则性，落点是多典范映射与 Seshadri 常数。两章都靠「导出/卷积 + 消没」驱动，数学上最现代，
也最适合已经熟悉 Fourier–Mukai 的读者。

**最短路径**（只有两小时）：读本书前言（中译 p.1–6）+ ch7 §1–§2 + ch8 §1–§2 + ch2 §1。
这四段把「模空间、稳定性、上同调消没」三个词讲到能对话的程度。

## 四、九章一句话定位

- **ch1（Andersen–Gammelgaard，中译 p.7–29）**：把 Hitchin 射影平坦联络、Toeplitz 算子与
  Berezin–Toeplitz 形变量子化接起来，算出 TQFT 曲线算子渐近展开的前几项，并验证星积与
  Andersen–Mattes–Reshetikhin 的结果一致。
- **ch2（Aprodu–Farkas，中译 p.30–54）**：系统讲 Koszul 上同调 K_{p,q}(X;L) 与合冲，再用它构造
  Brill–Noether 闭链、Koszul 闭链、小斜率除子，最后把 Green 猜想、棱性猜想、强极大秩猜想、
  极小合冲猜想排成一张强弱关系网。
- **ch3（Arcara–Bertram，中译 p.55–71）**：先复述经典 Reider 定理（曲面上「大次数 ⇒ 有效除子」的
  数值判据），再用稳定性条件与翻转给出「重访」版证明，并把 Thaddeus 对解释为例外对象；§5 试探三维推广。
- **ch4（Jeffrey，中译 p.72–81）**：在向量丛模空间的奇点处做部分消奇异（Kirwan 方法），用相交上同调
  定义相交配对，陈述 Kiem 的等变上同调结果，并给出 M(2,0) 与 M(n,d) 上的计算框架。
- **ch5（Kamnitzer，中译 p.82–93）**：构造 Beilinson–Drinfeld 格拉斯曼流形（整体卷积版与整体奇异版），
  证明其半局部几何与切片解消一致，从而把仿射格拉斯曼的卷积结构接到辛纽结同调上。
- **ch6（Lieblich，中译 p.94–115）**：把曲线上的层模空间看成叠 Bun_{n,d}，用 gerbe、扭曲层与 Brauer 群
  把「模空间的几何」翻译成「非交换代数的算术」，附录 A–C 是 gerbe/形变理论/Brauer 群的自足摘要。
- **ch7（Newstead，中译 p.116–134）**：定义凝聚系 (E,V) 的 α-稳定性，按 (n,d,k) 的区域分节证明模空间
  的非空性/存在性，边界情形 k=n+1、k≥n+2 与奇异曲线各占一节，最后列 12 个开放问题。
- **ch8（Pareschi–Popa，中译 p.135–159）**：以 GV-层与 M-正则层为轴，证明 M-正则 ⇒ 张量积仍 GV、
  GV-层 nef、M-正则层生成，再用 Fourier–Mukai 推出多典范映射、Seshadri 常数与 Picard 丛的正则性结果。
- **ch9（Teixidor i Bigas，中译 p.160–170）**：在可约曲线上建立斜率稳定无挠层的模空间，比较其 Hilbert
  紧化与斜率稳定模空间，定义极限线性系，并给出 Brill–Noether 理论中的若干应用。

## 五、术语地图与阅读提示

**术语地图**（详细对照见各章导读 §五 与 `source\TERMINOLOGY.md`）：

- 模空间一族：模空间 moduli space / 模叠 moduli stack / 粗模空间 coarse moduli space / 紧化 compactification。
- 稳定性一族：稳定 stable / 半稳定 semistable / 斜率稳定 slope stability / GIT 商 GIT quotient /
  α-稳定 α-stable / S-等价 S-equivalence / Harder–Narasimhan 滤过。
- 层与上同一族：凝聚层 coherent sheaf / 无挠层 torsion-free sheaf / 扭曲层 twisted sheaf / 核丛 kernel bundle /
  合冲 syzygy / Koszul 上同调 / 一般消没 generic vanishing / M-正则 M-regular / 相交上同调 intersection cohomology。
- 几何与量子一族：Hitchin 联络 / 射影平坦联络 / Toeplitz 算子 / 星积 star product / 曲线算子 curve operator /
  映射类群 mapping class group / 辛纽结同调 symplectic knot homology。
- 算术一族：gerbe（本书保留英文）/ Brauer 群 / 周期-指标定理 period-index / 有理点 rational point。

**四条阅读提示**：

1. **页码三套，别混**。原书 p.N（AMS 页码）、中译 p.N（`zh-译文.pdf` 页序）、英文 PDF p.N 三者不同：
   英文 PDF 页 = 原书页 + 9；中译页与原书页是非线性平移（ch1 是 +6，ch9 是 −9）。页表见 BRIEF §1.1。
2. **编号体制四套，别把编号当错**。ch1 定理/定义各自独立编号（Theorem 1–13）；ch2/ch5/ch7/ch8/ch9 按节
   共享（Theorem 1.1）；ch3/ch4 混合（iquestion 独立 1–5、iremark 独立 1–3）；ch6 按小节混排（5.1.1、
   A.1.1）。看到「Theorem 3.4 之后直接 Theorem 4.1」不是漏编，是体制如此。
3. **81 处译注先看再读**。译者自己登记了 81 处「原书错误/译注」（清单在 `source\PROGRESS.md`，按篇分
   9 张表，本书已抄成 `产出\汇总\existing-notes.tsv`）。这些地方中译本已经处理过，读到不必再当新发现；
   本工程的审校只登记**新问题**，以及**译注本身说错**的情形（`type=existing-note-wrong`）。
4. **公式以 .tex 为准**。中文 PDF 的文字层把公式拆碎（例如 p.12 抽出来是 `DV f = V [f] + ˜D(V )(f)`），
   只适合定位页码与看版面；一切符号、上下标、括号以 `source\chapters\chNN.tex` 为准。

## 六、这本书没讲什么（边界与下一步）

三点边界，先划清，免得读的时候期待错位：

1. **书名里的「格拉斯曼流形」不等于经典的 G(k,n)**。经典格拉斯曼 G(k,n) 只在 ch2 里作为射影空间的
   参数空间隐现（Hilbert 概形、Koszul 复形的几何背景）；真正以「格拉斯曼流形」为标题对象的是 ch5 的
   **Beilinson–Drinfeld 格拉斯曼流形**（仿射格拉斯曼 + Hecke 修正 + 整体化），它是「曲线 × 形式圆盘」
   上的无穷维对象。读 ch5 前不要拿 G(k,n) 的直觉硬套。
2. **它不是教材，证明不齐**。多数章节的定理只给证明思路或引用原文（ch2、ch8 尤其如此），
   ch7 有一半篇幅在陈述「已知什么、还不知道什么」。把「证明跳步」当正常现象，需要细节时按脚注追原文。
3. **符号不统一**。同一个 $\mathcal{M}_g$ 在不同章可能指粗模空间或模叠；$K_{p,q}$ 在 ch2 是 Koszul
   上同调，在别处可能是别的对象。每章开头先读该章的「记号」节，不要跨章沿用符号。

**读完往哪走**（按路线）：

- 路线 A 之后：Newstead 的 *Introduction to Moduli Problems and Orbit Spaces*、Lazarsfeld 的
  *Positivity in Algebraic Geometry* II（Brill–Noether 与向量丛）、Le Potier 的凝聚系讲义。
- 路线 B 之后：Hitchin 的原始论文集（Hitchin 联络）、Kirwan 的 *Cohomology of Quotients*（部分消奇异）、
  Arcara–Bertram–Lieblich 的 Bridgeland 稳定性系列。
- 路线 C 之后：Mukai 的 Fourier–Mukai 原始论文、Pareschi–Popa 的正则性 I–II（本卷 ch8 是 III，
  需要前两篇的背景）、Kamnitzer 的辛纽结同调综述。

**一句话总纲**：这本书讲的不是「格拉斯曼流形」一个对象，而是「**用稳定性切出来的参数空间，如何承载
上同调、量子化与算术结构**」。九章是九个切面；把 §二 的三个对象、四套工具记住，剩下的都是细节。
