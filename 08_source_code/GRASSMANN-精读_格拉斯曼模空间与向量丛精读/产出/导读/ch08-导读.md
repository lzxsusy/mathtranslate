# 第 8 篇 · Pareschi & Popa · 阿贝尔簇上的正则性 III：与一般消没的关系及应用（中译 p.135–159）

> 阅读坐标：中译 p.135–159；英文 PDF p.150–177；原书 p.141–168（原书 p.168 为空白背面页）。源文件 `source/chapters/ch08.tex`（1062 行）。

## 一、这一章在书里干什么

这是全书唯一一篇以阿贝尔簇为主角的文章。前后八篇围绕格拉斯曼流形、曲线模空间、曲线上向量丛与相交理论打转，方法与语言都偏曲线／组合；本篇却整篇建立在导出范畴、Fourier–Mukai 变换与同调代数上，是全书方法上最"孤岛"的一篇。它的价值也正在这里：前面几篇反复出现的"线丛、向量丛、生成性质、正规生成、稳定性的数值判别"，在本篇被放进一个统一框架——阿贝尔簇上的**一般消没（generic vanishing, GV）**——里重新解释。

文章把两条原本各自发展的线索合起来：

- 一条是作者早先工作的 **$M$-正则性**（$M$-regularity），它本来是从"阿贝尔簇上向量丛的强生成性质"这个几何问题里长出来的；
- 另一条是作者与 Hacon 等人发展的 **$GV$-层／GV-对象**，即上同调支集轨迹的余维下界，工具是 Fourier–Mukai 变换。

本篇的核心发现是：**$M$-正则性恰好是 GV 条件的一阶强化**，而且这个"强化"有一个漂亮的代数判别——Grothendieck 对偶对象的 Fourier 变换是否无挠（命题 2.8）。有了这把钥匙，作者依次打开了五扇门：张量积下的封闭性（§3）、GV-层的 nef 性（§4）、生成性质与极大 Albanese 维数簇的多典范映射（§5–§6）、Seshadri 常数与 $M$-正则性指标的关系（§7.1）、以及 Jacobian 上 Picard 丛的消没（§7.2）与半齐次丛的数值判别准则（§7.3）。

按作者自己的分法，§2–§5 是"关系与基本性质"，§6–§7 是"应用"，取材于早先的预印本 [PP6]。所以读的时候可以把它当两篇文章：前半是概念机器，后半是机器加工出来的四五个具体结论。

## 二、读它之前要知道什么

1. **阿贝尔簇与 Fourier–Mukai 变换**。$X$ 是 $g$ 维阿贝尔簇，$\widehat X=\operatorname{Pic}^0(X)$，$P$ 是 $X\times\widehat X$ 上的正规化 Poincaré 丛，$\mathbf R\widehat{\mathcal S}(\mathcal F)=\mathbf R p_{\widehat X*}(p_X^*\mathcal F\otimes P)$。Mukai 反演定理（式 (1)）断言 $\mathbf R\mathcal S\circ\mathbf R\widehat{\mathcal S}\cong(-1_X)^*[-g]$，这是全章反复使用的"傅里叶变换可逆"。
2. **导出范畴与 Grothendieck 对偶**。$\mathbf R\Delta\mathcal F:=\mathbf R\mathcal H om(\mathcal F,\mathcal O_X)$；本篇大量用 $\operatorname{Ext}$、谱序列、以及"无挠 = 各阶 $\mathcal E xt$ 的支集余维足够大"这一 Auslander–Buchsbaum 型事实（引理 2.9）。
3. **上同调支集轨迹**。$V^i(\mathcal F)=\{\alpha\in\widehat X\mid h^i(X,\mathcal F\otimes\alpha)>0\}$。GV 是 $\operatorname{codim}V^i\ge i$，$M$-正则 是 $\operatorname{codim}V^i>i$；$IT_0$ 是所有 $V^i=\varnothing$（$i>0$），$WIT_k$ 是变换只在第 $k$ 次非零。
4. **对照物：Castelnuovo–Mumford 正则性**。全章把 $M$-正则性当作"阿贝尔簇上的 CM 正则性"来用；引言（`ch08.tex:13`）与 §5 开头（`ch08.tex:274`）都明说这一类比。若熟悉射影空间上 $H^i(F(m-i))=0$ 推整体生成的那套论证，本篇的 §5 会很好读。
5. **几何侧的工具箱**：消没定理（Kodaira、Nadel、Grauert–Riemenschneider）、渐近乘子理想层 $\mathcal J(\|L\|)$、充裕／nef／$k$-射流充裕、Seshadri 常数、射影正规与正规生成、主极化阿贝尔簇（PPAV）、Kummer 映射、Eagon–Northcott 复形、半齐次向量丛。

如果只读中文，建议先补三样：Poincaré 丛与 $\operatorname{Pic}^0$、导出函子与谱序列、以及充裕／nef 的定义。其余都可以在读的过程中现查。

## 三、怎么读（路线 / 可跳过的部分 / 第一遍看到哪）

- **第一遍（约 1 小时）**：§1 引言（`ch08.tex:11–32`）→ §2 的定义（定义 2.1、记号 2.2、命题与定义 2.7）→ 命题 2.8 的陈述 → §5 定理 5.1 的陈述。把"GV／$M$-正则／$IT_0$／无挠判别"四件事记住，本章的骨架就有了。
- **第二遍（细读）**：§2 的证明链（推论 2.6 → 引理 2.9 → 命题 2.8）。这是全章唯一一处真正需要动笔的地方：谱序列 $E_2^{ij}=\mathcal E xt^i(\mathcal E xt^j(\mathcal G,\mathcal O_X),\mathcal O_X)\Rightarrow\mathcal H^{i-j}\mathcal G$ 如何退化成 $E_\infty^{00}=E_2^{00}=\mathcal G^{**}$，从而"$\mathcal G$ 无挠"。读懂这一处，后面全是应用。
- **可较快通过**：§3（只需记住"局部自由因子时张量积保持 GV，两个都 $M$-正则则张量也 $M$-正则"，技巧是 Pontrjagin 积与群乘法 $m$ 满射保无挠）；§4（记住两步：同源归约到主极化，再用 Debarre 的"$M$-正则 ⇒ 充裕"取极限得 nef）。
- **§5 与 §6 必须绑读**：命题 5.5 是 §6 的引擎（$a_*\omega_Y$ 的 $M$-正则性来自 Green–Lazarsfeld 与 Ein–Lazarsfeld），定理 6.1 的证明只是把命题 5.5 与可约截面方法再跑一遍。注 6.6 解释了为什么 Chen–Hacon 只需 $\chi(\omega_Y)>0$，这是本章最值得读的一条 remark。
- **§7 可以按兴趣切**：§7.1 是 Seshadri 常数专题，与前后文相对独立；§7.2（Picard 丛 + Eagon–Northcott）与 §7.3（半齐次丛 + 数值判别）各自成体系，建议先读 §7.3 的定理 7.30、7.34 与例 7.36、7.37（结论漂亮、假设可检验），再回头看 §7.2 的技术证明。§7.2 里命题 7.22 证明中对 [vGI] 的回顾（`ch08.tex:726–762`）第一遍可跳过。

## 四、核心结果（5 条，每条给编号 + 一句话 + 为什么重要）

1. **定理 2.3 + 命题 2.8**（原书 p.144–145）：GV 有三种等价说法（支集轨迹余维、充分正线丛扭转的消没、$\mathbf R\Delta\mathcal F$ 满足 $WIT_g$）；而在 GV 层中，$M$-正则 $\iff$ $\widehat{\mathbf R\Delta\mathcal F}$ 无挠。这是全章的地基：把一个几何条件（支集维数）翻译成一个代数条件（无挠），后面所有"张量积""乘法映射"的证明都靠它。
2. **定理 3.2**（原书 p.146）：若 $\mathcal E$ 局部自由，$\mathcal F,\mathcal E$ 都是 GV（相应地都 $M$-正则），则 $\mathcal F\otimes\mathcal E$ 也是。意义在于"一般消没条件在张量积下稳定"这个基本问题第一次被解决；作者明说去掉局部自由性不知道是否成立，而在 CM 正则性的情形下反例是有的。
3. **定理 4.1 + 推论 4.2、4.3**（原书 p.147–148）：阿贝尔簇上每个 GV-层都是 nef 的；于是对任意 $a:Y\to X$（$X$ 阿贝尔簇），$R^j a_*\omega_Y$ 都 nef，有限满态射的迹零丛 $E_a$ 也 nef。这把"半正性"问题收进 GV 框架，是本章在圈子外被引用最多的一条。
4. **定理 5.1 + 命题 5.5**（原书 p.149–151）：$M$-正则 $\iff$ 对每个 $IT_0$ 局部自由 $H$ 与非空开集 $U\subset\widehat X$，求和映射 $\bigoplus_{\alpha\in U}H^0(\mathcal F\otimes\alpha^{-1})\otimes H^0(H\otimes\alpha)\to H^0(\mathcal F\otimes H)$ 满射；由此得到"$M$-正则 ⇒ 连续整体生成"，以及极大 Albanese 维数簇上 $\omega_Y^{\otimes k}$ 在例外轨迹外整体生成。
5. **定理 6.1、6.7 与 §7 的三组数值结果**（原书 p.152–165）：三典范 $\omega_Y^{\otimes3}$ 在例外轨迹外非常充裕（一般型 + 极大 Albanese 维数 + 像不被环面直纹化）；$\varepsilon(L)=\rho'(L)\ge\rho(L)\ge1$（Seshadri 常数被 $M$-正则性指标从下方控制）；$\mathcal I_{W_d}(2\Theta)$ 满足 $IT_0$；半齐次丛的乘法映射满射性由一个显式数值不等式支配（定理 7.30、7.34），由此得到 $(-1)$-$\Theta$-正则丛的正规生成与例 7.36、7.37 的经典结论。
