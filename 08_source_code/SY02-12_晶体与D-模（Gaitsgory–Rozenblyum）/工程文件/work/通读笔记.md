## 一、三句话主旨

1. **问题**：经典 D-模理论依赖 `𝒟_X` 层与光滑性，难以推广到奇异概形，更难推广到非线性对象（层的范畴、预栈）。
2. **方法**：在导出代数几何（char 0 的 connective DG 代数上的预栈）中，用 de Rham 预栈 `Y_dR` 定义晶体：左晶体 = `QCoh(Y_dR)`，右晶体 = `IndCoh(Y_dR)`；由此得到对任意预栈都有定义、且对拉回 `f^†` 函子性的稳定 ∞-范畴 `Crys(Y)`。
3. **结论**：`Crys(Y)` 带左、右两个 realization（分别落到 `QCoh(Y)`、`IndCoh(Y)`），二者由 `Υ_Y = −⊗ω_Y` 连接；在经典有限型概形上与（左/右）D-模的导出范畴等价（Thm 5.5.3 一线），在光滑簇上左右晶体等价；进一步把 Beilinson–Bernstein 的 twisting 理论（gerbe、TDO）在导出框架中重做，得到扭晶体 `Crys^{T,l/r}`。

### 2.2 关键定理链

- **Thm 2.4.4**（左右晶体等价）：`Υ_{Y_dR}: Crys^l(Y) → Crys^r(Y)` 是等价。证明化到 `Y` 为仿射概形沿闭浸入到光滑仿射 `Z` 的形式完备化，用 Čech 神经的全化与 [GR1, Prop 7.1.3/7.4.5] 的短正合列。
- **Prop 2.5.6**（Kashiwara）：`i^†` 诱导 `Crys^r(Z)_X ≃ Crys^r(X)`；证明用 `S^∧ = S×_{Z_dR}X_dR` 与 [GR1, Prop 7.4.5] 的 `ker j_S! ≃ IndCoh(S^∧)`。
- **Prop 3.1.3**：`Crys^r(X) ≃ Tot(IndCoh(X•/X_dR))`，是 §3 全部下降论证的引擎。
- **Prop 3.3.2**：`oblv^r_X` 有左伴随 `ind^r_X`，且 `(ind^r_X, oblv^r_X)` 单子；用 Barr–Beck–Lurie + Beck–Chevalley。
- **Prop 4.7.3**：仿射 DG 概形上 `D(Crys^r(X)^♥) ≃ Crys^r(X)`；这是 §5 把 Abel 范畴层面的 D-模比较提升为导出等价的枢纽。
- **Thm 5.5.3**（正文以 5.5.2–5.5.5 陈述）：经典有限型 `X` 上 `Crys^r(X) ≃ D-mod^r(X)`；先由 Kashiwara 化到光滑仿射，再用 Prop 4.7.3 化到心上的比较，最后用 Grothendieck 的经典计算（截断单纯对象上的拟凝聚层 = 带平坦联络的层）。
- **Prop 6.4.2**：`Tw ≃ Tw^{/red} ≃ Tw_a ≃ Tw^{/red}_a`；核心是指数映射 `exp: (O_S)^{/red} → (O^×_S)^{/red}` 同构（[GR1, 6.8.8]）。
- **Cor 6.5.3**：`Tw(Y) ≃ τ^{≤2}(H_dR(Y) ×_{H(Y)} *) [2]`；光滑经典 `X` 时化为 `τ^{≤2}Γ(X, Ω¹→Ω²,cl)[2]`，与 [BB] 的 TDO 一致。

## 三、逐节要点

### 0. 引言（pp.2–11）

- **0.1** 从平坦连接讲起：`∇: V→V⊗Ω¹`、`[∇,∇]=0`；对偶后是向量场 Lie 代数在 `V` 上的作用，等价于左 `𝒟`-模。经典定义的困难：奇异概形、非线性对象。Grothendieck 的出路：无穷小接近关系 `x,y: Spec(R)⇉X`（限制到 `Spec(red R)` 后相同），晶体 = 带 `x^*(F) ≃ y^*(F)` 及余循环条件的拟凝聚层。
- **0.1.3** 用 Simpson 的 de Rham 预栈：`X_dR(R) := X(^{cl,red}R)`；`Crys(X) := QCoh(X_dR)`。在 eventually coconnective 情形与 Grothendieck 定义等价。
- **0.2** 左右之分：光滑簇上左右 D-模经由 `⊗ω_X` 等价但不保遗忘函子；抽象地，左 realization 的拉回是 `*`-拉回，右 realization 的是 `!`-拉回；右 realization 的 t-结构函子性更好（Riemann–Hilbert 下即反常 t-结构）。历史：Beilinson 1990 年代用右晶体的 Abel 范畴；Lurie 指出放弃 t-结构后左晶体同样可行。
- **0.3** 理论形态：`Crys(Y)` 带 `oblv^l: Crys→QCoh`、`oblv^r: Crys→IndCoh`，由 `Υ_Y` 连接；本文只做局部理论（`Crys` 与 `f^†`），推前与伴随留待 [GR2]。
- **0.4** twisting：`Y_dR` 上的 `G_m`-gerbe 加沿 `Y→Y_dR` 的平凡化；线丛 `L` 给出 `T(L)`；光滑簇上 twisting 的 Picard 群胚对象空间 `H²(X,T)`、同构空间 `H¹(X,T)`（`T = Ω¹→Ω²,cl`），即 [BB] 的 TDO。
- **0.5** 逐节导读。**0.6** 约定（char 0、∞-范畴、DG 范畴、t-结构记号、`DGSch_aff`、`PreStk`、laft、`(−)^{cl,red}`）。**0.7** 致谢。

### 1. de Rham 预栈（pp.12–14）

- **1.1** `Y_dR(S) := Y(^{cl,red}S)`；等价刻画：`dR` 是 `Y ↦ ^{cl,red}Y` 沿 `red Sch_aff ↪ DGSch_aff` 的右 Kan 延拓；`dR` 与极限/余极限交换；沿 `DGSch_aff ↪ PreStk` 是左 Kan 延拓；对 `red Sch_aff ⊂ Sch_aff ⊂ DGSch_aff ⊂ DGSch_{qs-qc} ⊂ DGSch ⊂ PreStk` 都成立（Cor 1.1.9）。
- **1.2** `p_dR: Id→dR`；Čech 神经 `Y•/Y_dR`，每项 `Y_i/Y_dR` 是 `Y_i` 沿主对角线的形式完备化；有典范映射 `|Y•/Y_dR| → Y_dR`；`Y` 经典形式光滑（`Maps(S,Y)→Maps(^{cl,red}S,Y)` 在 `π₀` 上满）时该映射是同构（Lemma 1.2.4）。
- **1.3** `PreStk_laft`（收敛 + 各截断局部有限型）；**Prop 1.3.3**：`Y ∈ PreStk_laft ⇒ Y_dR ∈ PreStk_laft` 且 `Y_dR` 经典。证明分两步：收敛性显然；经典性化到 `X ∈ DGSch_aff,aft` 沿闭浸入 `i: X↪Z`（`Z` 光滑经典仿射有限型），用 `X_dR ≃ Y_dR`（`Y = Z_X^∧`）、`Y` 形式光滑因而经典形式光滑、Lemma 1.2.4，以及每个 `Y_i/Y_dR` 是 `Z_i` 沿 `X` 的形式完备化（[GR1, Prop 6.8.2]）。Cor 1.3.7 共尾性；Cor 1.3.9 左 Kan 延拓。

### 2. 晶体的定义（pp.15–24）

- **2.1** `Crys^l(Y) := QCoh(Y_dR) = lim_{S∈(DGSch_aff/Y_dR)^op} QCoh(S)`；对象 = 每个 `S` 给 `F_S`、每个 `f: S'→S` 给 `f^*(F_S) ≃ F_{S'}` 及高阶融贯。`f^†` 与 `f^*` 相容；`f` 在 `cl,red` 层面同构时 `f^†` 是等价。Lemma 2.1.7：经典形式光滑时 `Crys^l(Y) ≃ Tot(QCoh(Y•/Y_dR))`。Remark 2.1.8：左晶体 = Grothendieck 无穷小 site 上的拟凝聚层；与分层 site 的版本在经典形式光滑预栈、以及 eventually coconnective 的 laft DG 概形上一致，但对一般 DG 概形不然。
- **2.2** 默认 `PreStk_laft`；`Crys^l` 的极限表示可把指标范畴换成 `Sch_aff,ft`、`{}^{<∞}DGSch_aff,aft`、`DGSch_aff,aft`、`Sch_aff`（Cor 2.2.2/2.2.4）。
- **2.3** `Crys^r := IndCoh! ∘ dR`，`IndCoh!` 为 `IndCoh!_{{}^{<∞}DGSch_aff,aft}` 的右 Kan 延拓；`f^†` 与 `f^!` 相容；Lemma 2.3.11：经典形式光滑时 `Crys^r(Y) ≃ Tot(IndCoh(Y•/Y_dR))`；Lemma 2.3.12：`oblv^r` 保守。
- **2.4** `Υ_S: QCoh(S)→IndCoh(S)`，`F↦F⊗ω_S`，与 `f^!` 相容，给出 `Υ_{Y_dR}: Crys^l(Y)→Crys^r(Y)`；**Prop 2.4.4：它是等价**。此后 `Crys(Y)` 同时带两个 realization，`f^†` 与 `f^*`、`f^!` 都相容。
- **2.5** Kashiwara：闭浸入 `i: X↪Z`、补开 `j: Z°↪Z`；`Crys^r(Z)_X := ker(j^†)`，`i^†` 诱导 `Crys^r(Z)_X ≃ Crys^r(X)`（Prop 2.5.6）；左晶体版本见 Remark 2.5.7。

### 3. 下降性质（pp.25–29）

- **3.1** 无穷小群胚 `X×_{X_dR}X ⇉ X`；`Crys^r(X) ≃ Tot(IndCoh(X•/X_dR))`（Prop 3.1.3），对经典形式光滑的预栈也成立。
- **3.2** `DGSch_aff,aft` 上 h-拓扑（Zariski + 固有满）；`Crys^r` 满足 h-下降（Prop 3.2.2）、fppf 下降（Cor 3.2.4）、`<∞` 版本（Cor 3.2.6）；h-满射的 Čech 下降（Cor 3.2.7）。
- **3.3** `p_s, p_t: X×_{X_dR}X ⇉ X` 均 ind-固有；`oblv^r_X` 有左伴随 `ind^r_X`，`oblv^r_X∘ind^r_X ≃ (p_t)_*^{IndCoh}∘(p_s)^!`，且是单子（Prop 3.3.2）；`Crys^r(X)` 紧生成（Cor 3.3.3）。
- **3.4** 左晶体的 `ind^l_X` 只在 eventually coconnective 时与 `oblv^l` 伴随（Prop 3.4.11）；一般 DG 概形上左晶体没有 (3.3) 型等价（Example 3.4.5：`Spec(k[α]), deg α = −2`）。

### 4. t-结构（pp.30–40）

- **4.1** 左 t-结构 = `QCoh(Y_dR)` 的典范 t-结构；经典形式光滑时 `Crys^l(Y)^{≤0} = (oblv^l)^{-1}(QCoh(Y)^{≤0})`。
- **4.2** 右 t-结构：`Crys^r(X)^{≥0} := (oblv^r_X)^{-1}(IndCoh(X)^{≥0})`；`ind^r_X` t-正合（Prop 4.2.9）；`oblv^r` 在光滑经典 `X` 上 t-正合、在拟紧 `X` 上有界幅度（Prop 4.2.11）。
- **4.3** indscheme 上逐 `α` 定义右 t-结构；形式完备化 `Y` 与 `X` 的晶体范畴 t-等价（Lemma 4.3.7）。
- **4.4** 光滑经典 `n` 维 `X`：`Crys^l(X)^{≤0} = Crys^r(X)^{≤−n}`（Prop 4.4.2）；`id: Crys^l→Crys^r` 有界幅度（Prop 4.4.4）。
- **4.5** `Crys^r(X)` 在右 t-结构下左完备（Cor 4.5.4）；`Crys(X)` 在左 t-结构下也左完备（Cor 4.5.7）。
- **4.6** 粗糙归纳 `′ind^r_X` 与粗糙遗忘 `′oblv^r_X = Ψ_X∘oblv^r_X`；`oblv^r_X` 穿过 `Ξ_X` 的像 ⇔ `X` Gorenstein（Lemma 4.6.12，Drinfeld）。
- **4.7** 仿射 `X`：`Crys^r(X)^♥` 是 Grothendieck Abel 范畴，`D(Crys^r(X)^♥) ≃ Crys^r(X)`（Prop 4.7.3）。

### 5. 与 D-模的关系（pp.41–47）

- **5.1** 积分变换：`Q ∈ IndCoh(X×Y)` 给出 `F_Q`，核为 `(Δ_X×id_Y)^!`；`D^r_X ≃ (Δ̂_X)_*^{IndCoh}(ω_{X×_{X_dR}X})`（Prop 5.1.3）。
- **5.2** 八个复合函子（`oblv`、`ind`、`Υ`、`Ψ`、`Ξ` 的各种组合）的核，统一写成 `F{X}`（与 `Cone(O→j_*j^*O)[−1]` 张量）；关系式 (i)–(v)。
- **5.3** `D^r_X` 连接；最终余连接时其余三个核也最终余连接；光滑经典时 `D^l_X` 在心上。
- **5.4** 光滑经典 `X`：`Map((p2)_*(p1^*F1⊗Q),F2) ≃ Map(Q, Diff_X(F1,F2))`，取 `Q = D^l_X` 得代数同构 `D^l_X ≃ Diff_X`（Lemma 5.4.3）。
- **5.5** 经典有限型 `X`：`Crys^r(X) ≃ D-mod^r(X)`（5.5.1–5.5.6）；用 Kashiwara 化到光滑仿射，再用 Prop 4.7.3 与 Grothendieck 的经典计算（心上的比较）。

### 6. twisting（pp.48–57）

- **6.1** `pt/G_m` 分类栈；`G_m`-gerbe 的三个版本 `B^et`、`B^Zar`、`B^naive`；`Ge_{G_m}(Y)`。
- **6.2** `Tw(Y) := ker(Ge_{G_m}(Y_dR) → Ge_{G_m}(Y))`；线丛给出 `T(L)`；`Tw` 反变、把余极限送极限、是右 Kan 延拓（Lemma 6.2.6）。
- **6.3** `/red` 版本与 `G_a`-gerbe；指数映射给出三版本同构（Cor 6.3.7）。
- **6.4** `Tw ≃ Tw^{/red} ≃ Tw_a ≃ Tw^{/red}_a`（Prop 6.4.2）；affine `X` 上 twisting 未必局部平凡（Remark 6.4.7）；`Tw` 收敛、是右 Kan 延拓（Cor 6.4.10/6.4.13）。
- **6.5** `Tw(Y) ≃ τ^{≤2}(H_dR(Y)×_{H(Y)}*)[2]`（Cor 6.5.3）；光滑经典 `X` 上 `Tw(X) ≃ τ^{≤2}Γ(X,Ω¹→Ω²,cl)[2]`，与 [BB] 的 TDO 一致。
- **6.6** 无穷小群胚的 `G_m`-中心扩张 ↔ twisting（Cor 6.6.4）。
- **6.7** indscheme 版本（Prop 6.7.2）。

### 7. 扭晶体（pp.58–64）

- **7.1** `Crys^{T,l}(Y) := QCoh^T(Y_dR)`；`oblv^{T,l}`。
- **7.2** `Crys^{T,r}(Y) := IndCoh^T(Y_dR)`；`oblv^{T,r}`。
- **7.3** `Υ: Crys^{T,l} → Crys^{T,r}` 是等价（Prop 7.3.3）；`ind^{T,r} ⊣ oblv^{T,r}`；扭 Kashiwara。
- **7.4** 扭 t-结构；`ind^{T,r}` t-正合、`oblv^{T,r}` 有界幅度（Prop 7.4.3）；`Crys^{T,r}(X)` 左完备（Prop 7.4.11(a)）；仿射 `X` 上 `D(Crys^{T,r}(X)^♥) ≃ Crys^{T,r}(X)`（Prop 7.4.11(b)）。
- **7.5** 光滑经典 `X` 上 `Tw(X) ≃ TDO`，`Crys^{T,l}(X) ≃ D-mod^{T,l}(X)`（7.5.1）；`Crys^{T,r}(X)^♥` 局部 Noether、有限上同调维数（Prop 7.5.3）。
