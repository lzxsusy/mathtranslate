# 通读笔记 · SY01-25

> 按《数学文献翻译纪律》v2.1 第二公理「先通读后落笔」：以下为 Lead 在动笔前的通读产物。
> 通读方式：66 页全部过目（页面图像 + 文字层），重点页（§3、§4、§6、§8）逐段读。

## 1. 这是一篇什么样的文章

一篇 66 页的 **纲领性论文（letter 体，但篇幅是长文）**，2001 年 6 月挂 arXiv。作者是 Kontsevich 与
Soibelman。它的地位：SYZ 猜想（1996）之后、Fukaya 范畴的代数化之前，**第一次把「退化」当作镜像对称的
本体来对待**，并给出可操作的 A∞ 框架。今天读它，应当把它看成「SYZ 纲领的拓扑/范畴化版本」。

文章分两大块，性质完全不同：

- **纲领块（§1–§3）**：物理动机 + 几何猜想。语气是「我们猜想」「人们期待」，大量未证明的陈述，
  引用 [SYZ]、[GW]、[CG]、[Be]、[De]、[LTY]、[Mum]。
- **技术块（§4–§9）**：A∞-代数的框架与两个具体模型（Fukaya 型、de Rham 型），以及它们在
  非阿基米德几何上的实现。这一块是自足的，有定义、命题、定理（定理 1–4），可以独立读。

翻译时的语气必须区分这两块：纲领块不能译得像定理；技术块不能译得像散文。

## 2. 章节骨架与逻辑链

1. **§1 引言**：同调镜像对称（[Ko]）+ 环面纤维化对偶（[SYZ]）两条线；提出「大复结构极限 =
   环面纤维化坍缩」的微分几何模型；预告解析图景（非阿基米德）与微分几何图景等价。
2. **§2 共形场论的退化**：从 CFT 模空间的边界分层讲起。A 模型/B 模型是边界上的两个开分层，
   作者提出还有第三个「T-分层」（环面模型、Narain 格）。2.4 环面模型、2.5 WZW（SU(2)）是具体例子；
   2.6 画出 A/B 分层的示意图；2.7 把镜像对称解释为两个分层的相遇。
3. **§3 大复结构极限**：极大退化（定义 1）→ Calabi–Yau 流形族在 q→0 时的行为；Monge–Ampère 流形
   （定义 2）、Legendre 变换、整仿射结构（推论 1）、对偶环面纤维化（命题 2）；猜想 1–3 是几何核心。
4. **§4 A∞-框架**：指出通常 A∞-范畴定义的两个技术问题（横截性、单位元），引入非幺 A∞-代数、
   A∞-范畴、A∞-预范畴（定义 3–15）；4.4 有向预范畴是后文 Morse 情形的模型。
5. **§5 Fukaya 范畴**：5.1 标准辛空间里的 Fukaya 范畴（定义 16–17），5.2 环面纤维化的 Fukaya–Oh
   范畴（定理 1：存在第二纲集 Σ 使……）。
6. **§6 Morse–Smale 与 Morse 函数范畴**：6.1 Morse 记号，6.2 Morse A∞-范畴 M(Y)，
   6.3 de Rham A∞-范畴 DR(Y)，**定理 2：M(Y) 与 DR(Y) A∞-等价**；6.4 子复形上的 A∞-结构
   （[GS]、[Me] 的公式，用平面树重述），6.5 投影算子与同伦，6.6 定理 2 的证明。
7. **§7 凝聚层导出范畴的 A∞-结构**：刚性解析空间（定义 21–22），命题 9，构造范畴 C(Y)。
8. **§8 同调镜像猜想**：8.1 对象上的函子，8.2 态射的谱与半群，8.3 阿贝尔簇情形
   （**定理 4**：F(C_unram(Y)) 与 C(Y) 的满子范畴 A∞-等价）。
9. **§9 附录**：复几何情形（C 上）的对应构造：9.1 函子，9.2 Dolbeault 形式的扇形分解，
   9.3 半群 φ^t 及其生成元 Δ 的显式公式。

## 4. 难点与处理策略

1. **术语密度**：§7–§8 非阿基米德 + 导出范畴 + A∞ 三套术语叠加。策略：严格用 glossary.tsv；
   首次出现给英文；不新造词。
2. **原文的记号不稳定**：同一对象在不同节用不同记号（如 X_mer / X_form / X_q；C_ε / C((q))）。
   策略：照原文，不统一；在必要处加译注说明「原文此处记号与 §X 不同」。
3. **手绘示意图（p10、p11、p12）**：这是作者手画的草图，线条随意、无图题。策略：用 TikZ 复原
   结构（A/B 两个分层与交点、坍缩示意、路径扇形图），不加图题；在译注中说明「示意图依原文手绘复原」。
4. **物理术语**：CFT、SCFT、Narain 格、WZW 模型、Virasoro 代数、算子乘积展开。策略：用物理学界
   通行中文译名（共形场论、超共形场论、Narain 格、WZW 模型、Virasoro 代数、算子乘积展开），
   首次给英文缩写。
5. **作者的行文习惯**：长句、大量插入语、「It is believed that」「We expect that」。策略：拆句，
   但保留「我们期待/人们相信」这类语气标记——它们标记的是猜想而非命题，不能抹平。
6. **原文的错误**：至少已发现两处（§1 的 $H^2(X,\Z)$ 应为 $H^2(X^\vee,\Z)$；§2 附近疑似编号跳号）。
   策略：照译 + 加注；全部登记进 `疑点清单.tsv` 和附录 C《原文勘误与存疑》。
