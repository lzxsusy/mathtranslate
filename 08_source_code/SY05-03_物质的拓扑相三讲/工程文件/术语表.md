## 固定句式

- “It is obvious that...” → 「显然，……」；若作者跳过证明，加 `含糊` 批注。
- “Generically” → 「一般地」/「在一般情形下」。
- “We will see” → 「我们将会看到」。
- “Let us...” → 「让我们……」/「下面……」。
- “In other words” → 「换言之」。
- “On the other hand” → 「另一方面」。
- “It turns out that” → 「结果表明」。
- “up to a gauge transformation” → 「在相差一个规范变换的意义下」。
- “modulo torsion” → 「模去挠部分」。
- “half-filling” → 「半满」。
- “at half-filling” → 「在半满时」。
