## 3. 翻译与排版约定

1. **公式零改动**：所有行内/行间公式按原 LaTeX 源逐字符保留，包括指标位置、
   上下标、希腊字母、归一化因子、`\epsilon` 与 `\varepsilon` 的字形差异。
   译文不“顺手修正”原文公式；疑误一律写入 `% [Tutor Note: 笔误——...]`，正文保持原样。
2. **公式编号**：沿用原文 `\numberwithin{equation}{section}`，引言为第 0 节，
   第一/二/三讲为第 1/2/3 节，故公式号为 (0.x)、(1.x)、(2.x)、(3.x)，与原文一致。
3. **图号**：按原文顺序自动编号为图 1–43；每幅图注末尾以小字附
   “原文位置：Fig. N（PDF 第 P 页）”，便于与英文 PDF 对照。
4. **术语**：以中文学界通行译名为准（规范场论、和乐、反常、贝里联络、陈-西蒙斯、
   外尔费米子、狄拉克费米子、费米弧、拓扑绝缘体等）；主要条目见 `术语表.md`。
   人名首次出现用“中文（English）”，其后只用中文。
5. **批注**：`% [Tutor Note: 类别——内容]`，类别限“易错 / 含糊 / 笔误 / 术语”四种：
   - **易错**：张量缩并、指标升降、符号/归一化/定向约定、边界条件等；
   - **含糊**：作者以“显然 / 标准结果 / a short calculation”跳过之处，补出实质定理或计算；
   - **笔误**：原文符号、上下标、系数、文献信息的明显错误（正文不改）；
   - **术语**：易混术语（chirality/helicity、anomaly/inflow、Chern class/winding number 等）。
6. **不增删论证**：正文一段对一段、一句对一句；仅“本节重点”和 Tutor Note 为译注者所加。
7. **标点**：正文用中文全角标点；数学模式内不出现中文；引号统一为“”。

## 5. 原文笔误与可疑点（正文照录，批注指出）

以下条目已写入源码批注，正文未擅自改动；“疑”表示需要教授最终定夺。

**文字/排版类**

- 1.1 节：“the 3d **Nielson**-Ninomiya theorem” → 疑为 **Nielsen**。
- 1.2 节首句：“more **that** one could say” → 疑为 **than**。
- 1.3 节：“A **gap** crossing in which this determinant…” → 疑为 **band** crossing。
- 1.5 节首句：“**If** is also of some interest” → 疑为 **It**。
- 1.5 节：“near $\vec p=a=0$” → 标量 $a$ 与矢量 $\vec p$ 并列，应读作 $\vec p=0$ 且 $a=0$。
- 1.10 节：“**staight** line” → **straight**；“**intepret**” → **interpret**（2.10 节）。
- 2.2 节：“**Schdrodinger**” → **Schrödinger**；“**magnetc**” → **magnetic**；
  “**quantitities**” → **quantities**。
- 2.7 节图 28 图注：“indistinguishable **form** a bulk state” → **from**。
- 参考文献：[3] “(20110 55” → “(2011) 55”；[12] “A392 (1802)” → “(1984)”；
  [20] “{bf 108}” → “{\bf 108}”、“Zaheed” → “Zaheer”；[16]、[32] 作者名/期刊名有个别笔误。
  这些排版错误已在译本的参考文献中直接修正，并在批注中说明。

**公式/约定类（需教授定夺）**

- 1.2 节括注恒等式 $\gamma_0\gamma_1\gamma_0\gamma_2=\i\gamma_0\gamma_3\gamma_5$：
  按原文自述的 $\eta=\mathrm{diag}(-1,1,1,1)$ 与 $\gamma_5=\i\gamma_0\gamma_1\gamma_2\gamma_3$
  直接计算，右边差一负号；改用上指标 $\gamma_5=\i\gamma^0\gamma^1\gamma^2\gamma^3$ 即一致。
  详见 1.2 节批注。
- 1.10 节式 (1.50)/(1.53) 的指数 $\exp(\i k_1x_3+k_1x_1)$：代入 $H\psi=0$ 只能得到
  $k_1=0$，与局域化条件 $k_1<0$ 矛盾；疑应为 $\exp(-\i k_1x_3+k_1x_1)$。正文照录原文。
- 1.10 节“当 $x_3=0$ 处存在边界时”与前文“$x_1=0$ 处边界”不一致；疑为笔误，
  也可能是作者改取另一晶面而未声明。
- 1.11 节式 (1.55) 首项写 $\g^0\vec\gamma\cdot\vec p$，而本节开头写
  $H=\g_0\vec\gamma\cdot\vec p$；因 $\g_0=-\g^0$，两式差一符号，疑为原文笔误。
- 2.2 节脚注：“$\delta A_i=\partial A_i/\partial s=\delta_{i0}$”与式 (2.8)
  $A_0=s/\beta$ 不一致；按 (2.8) 应为 $\delta_{i0}/\beta$（差一个 $1/\beta$）。
- 2.3 节式 (2.15)：左端写 $J_2=-\delta I_{\rm eff}/\delta A_1$，但右端 $kF_{01}/2\pi$
  对应的是对 $A_2$ 的变分；下标 $A_1$ 疑应为 $A_2$，且负号须与 $E_i$ 的号差约定一并调整。
- 3.2 节式 (3.31)/(3.32) 的边界/质量台阶零模符号，与 1.11 节式 (1.59) 的符号约定
  互为镜像，批注中已说明核对方法。

> **学术声明**：以上“疑误”均为译注者按标准约定复算后的判断，不排除作者另有约定；
> 引用或继续推导时，请以英文原文与作者后续文献为准。译本正文一律保留原文写法。
