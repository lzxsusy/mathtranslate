## 建议阅读顺序（给编辑/读者）

1. 封面与「译者说明」（体例、符号约定、批注规则）；
2. 摘要、「引言」与目录——引言给全文的比喻骨架（谱定理 → 非阿贝尔傅里叶变换 → 巨象），并交代两个阶段的分期；
3. §1 全节——谱定理与非阿贝尔对偶的具体形状；
4. §2.5 主定理 + §3 全节——「它说了什么」与「为何为真」；
5. 需要技巧细节时再看 §4、§5；§6 是应用地图，可跳读；
6. 附录「译注汇总」可按概念检索批注，不必回正文翻脚注。
