# 通读笔记：Ben-Zvi《几何朗兰兹对偶是什么？》

## 0. 一句话

几何朗兰兹对偶 = **关于自守层的代数谱定理**：$\Bun_{G}$ 上的自守层（D-模或可构造层）
可以分解为「单色」的本征层，Hecke 算子在其上被对角化，而「颜色」由 $\check G$-局部系统给出。

## 1. 骨架（作者自己的三层递进）

全文绕着一个类比转：**谱定理 → 非阿贝尔傅里叶变换 → 几何朗兰兹对偶**。

1. **§1 这是什么类型的陈述。** 从线性算子的谱定理出发（$K$ 自伴 ⇒ $\mathcal H\cong\int^\oplus \mathcal H_\lambda$），
   指出它「把对象拆成单色构件」的实质是傅里叶变换；把群 $G$ 换成非阿贝尔群时，
   谱定理升级为**非阿贝尔傅里叶变换**，其「谱」不再是数，而是表示。于是陈述的形态是：
   > 自守侧的范畴 ≃ 谱侧（$\check G$-局部系统）上某种层的范畴。
   作者强调后者是**替换**而非「给出公式」：对偶的形状由「群 $G$ / 背景空间 / 对偶群 $\check G$ / 问答（what ↔ where）」四要素决定。

2. **§2 它说了什么。** 语言：范畴化调和分析。背景：$\Bun_{G}$ 是模栈（不是簇），有无限「尾巴」，
   必须保留（GLC 是表示论，丢掉内部对称性就背离学科精神）；阿贝尔情形即雅可比簇与几何类域论。
   谱侧：Betti 版（特征簇）与 de Rham 版（带平坦联络的 $\check G$-丛，$\Loc$ 是导出模栈）。
   主定理：$\Shv(\Bun_{G})\simeq\IndCoh_{\Nilp}(\Loc_{\check G})$。

3. **§3 为何为真：跳动的心脏。** 两件事：
   - **Hecke 算子**在 $\Bun_{G}$ 上层上以卷积作用，本质是「在一点修改丛」，如同拉普拉斯算子；
   - **因子化**让这些修改彼此交换（$\pi_{2}$ 交换性的代数几何版本；$\Gr\simeq\Omega^{2}BG$），
     于是得到对称幺半范畴 $\Sph_{G}$，其 Tannaka 谱即 $\Rep(\check G)$（几何 Satake），
     对偶群「从无到有」被造出来，并整体化为 $\QCoh(\Loc_{\check G})$ 对 $\Shv(\Bun_{G})$ 的**谱作用**。

4. **§4 如何具体化。** 两个阿贝尔化机制：
   - **Hitchin 纤维化**（半经典 / 微局部）：$\Higgs_{G}=T^{*}\Bun_{G}\to\bigoplus\Gamma(C,\Omega^{\otimes i})$，
     一般纤维是阿贝尔簇（谱曲线的 Prym），Nilp 纤维是「微局部化」的去处；
   - **Dolbeault 版 GLC** 是退化情形（只看到 $\Nilp$ 上的谱侧），与 SYZ 镜像、非阿贝尔 Hodge 理论相接。

5. **§5 如何证明。** 五篇论文拼起来：
   - 最佳情形：谱作用 + 「重数一」⇒ 对角化；
   - 泛函分析：为什么必须用 $\IndCoh$（奇异支撑 / 幂零奇异支撑）；
   - 相对 Langlands 与周期、Eisenstein 归纳、Whittaker 周期（白光）、Kac–Moody 局部化与 opers。
   - 证明的核心困难：把「局部」（几何 Satake）粘成「整体」（因子化 + 归纳）。

6. **§6 有什么用、下一步。** 分歧情形、表示论三角（量子群 / 环路群 / 正特征）、低亏格、
   Dolbeault 与量子 GLC、算术应用（局部 Langlands、函数域、Fargues–Scholze、Tamagawa 数）、
   以及物理（Kapustin–Witten 的 S-对偶、$A_{G}\simeq B_{\check G}$）。

## 4. 译完后回看：作者真正的论旨

作者并不在证明「GLC 有用」，而在说明它**是一个完整的结构理论**：
一旦接受「自守层 = 函数」「Hecke 算子 = 拉普拉斯」「$\check G$-局部系统 = 频率」这套词典，
GLC 的每一条技术假设（为什么必须是模栈、为什么必须用 $\IndCoh$、为什么需要因子化、
为什么证明要靠归纳与 Eisenstein）都变成**被迫的选择**而非技巧的堆砌。
译文的分寸就在于：这些「为什么」在原文里往往只是一句括号，译注要替读者把它们展开。
