# 通读笔记（全局图）

底本：Lin Chen, *Notes for Algebraic Geometry 1*, 2025-12-27，171 页。
页码映射：原书页 = PDF 页（页眉即页码），本笔记页码一律指原书页。

## 一、这本书要做什么

一句话：**用层论的语言重写「代数集 ↔ 交换环」的对偶，并把它推广到一般交换环**。

§0 把这个动机摆得很清楚：仿射代数集理论（零点定理 + Spm）在两处失效——
(1) 只对有限生成既约代数成立，数论里要用的 $\mathbb{Z}$、$\mathbb{Q}$、$\mathbb{Z}_p$ 都不在其中（p6）；
(2) 代数集必须是某个固定 $\mathbb{A}^n$ 的闭子集，「嵌入的」这个前提不是内蕴的（p5–6）。
出路是：把「极大理想」换成「素理想」，把「代数集」换成「局部环化空间」，即概形。

全书六部分正好是六级台阶：

| 部分 | 页 | 一句话 |
|---|---|---|
| I (预)层 | 9–25 | 把「局部给数据、整体粘起来」形式化 |
| II 概形的定义 | 27–45 | $\operatorname{Spec} R$ 加 Zariski 拓扑与结构层，粘成概形 |
| III 概形的语言 | 47–59 | 纤维积、$S$-概形、纤维、浸入 |
| IV (拟)凝聚层 | 61–83 | $\mathcal{O}_X$-模、$\widetilde{M}$、相对 Spec、有限型/凝聚 |
| V 基本性质 | 85–117 | 拟紧、分离、既约、仿射、诺特、有限型、紧合 |
| VI (拟)射影态射 | 119–163 | $\operatorname{Proj}$、扭转层、丰沛性、Chow 引理 |

附录 A 把用到的范畴论（加性、核余核、阿贝尔、正合）补齐，正文不假设读者学过同调代数。

## 二、各部分的读法与难点

### Part I（§1–3，p9–25）
预层是函子 $X^{\mathrm{op}}\to \mathcal{C}$，层是满足粘接条件的预层。三条主线：
层化（§3.1，伴随 $\sharp \dashv \iota$）、正像（§3.2）、逆像（§3.3–3.4，预层情形要先层化）。
难点在 §3.5 open base-change：$f^{-1}$ 与开浸入的交换性，后面 §13、§26 反复用。
术语地基：stalk 茎、germ 芽、skyscraper 摩天楼层（§2.3）。**此处定名错一个，后面全错。**

### Part II（§4–8，p27–45）
$\operatorname{Spec} R$ 上的 Zariski 拓扑以 $U(f)=\{\mathfrak p: f\notin\mathfrak p\}$ 为基，
结构层由局部化 $R_f$ 给出（§4.2）。概形 = 局部同构于仿射概形的局部环化空间（§5.2）。
§6 讲粘接（gluing）：把仿射概形沿开集粘成一般概形，并一口气给出一批例子
（$\mathbb{A}^n$、$\mathbb{P}^n$、$\operatorname{Spec} \mathbb{Z}$、$R_\mathfrak{p}$、$\widehat{R}_\mathfrak{p}$、$\operatorname{Spec} k[\varepsilon]$），
§7 给仿射判别准则（映入仿射概形的态射），§8 讲点函子（$R$-点与函子观点）。
难点：结构层的粘接（§4.2 的 sheaf 条件要逐条核对）、开浸入的刻画（§5.3）。

### Part III（§9–11，p47–59）
纤维积先对仿射情形构造（§9.2），再粘（§9.3–9.4）；§10 统一讲基变换（$S$-概形 §10.1、纤维 §10.2）、
基变换到局部概形（§10.3）是后面「几何纤维」的全部来源。
§11 讨论单/满态射，重点在**闭浸入**：它与拟凝聚理想层的对应（§11.4 定义理想）是
「子概形」这个概念的技术核心。难点：§11.2 层间满态射的判别（茎上满即满，但预层不然）。

### Part IV（§12–17，p61–83）
$\mathcal{O}_X$-模是「逐开集给 $\mathcal{O}_X(U)$-模，且限制映射相容」。
$\widetilde{M}$ 构造（§13.1）把仿射概形上的拟凝聚层与模一一对应（§13.3），
一般情形靠局部（§13.4）。§14 讲拟凝聚代数，相对 Spec（§14.2）与向量丛（§14.3）是同一件事的两面；
§15 用这套语言给出闭浸入的分类（闭浸入 ↔ 拟凝聚理想层）。
§16 的有限型/有限表现/凝聚是**技术条件**，为 §20、§23、§28 的有限性论证铺路。
难点：§12.4 张量与内 Hom 的层化（要说明「层化后仍与 $\mathcal{O}_X$-模结构相容」）。

### Part V（§18–24，p85–117）
这一部分全是「性质」：拟紧（§18.1）、分离（§18.2，对角线闭）、拟分离（§18.3）、
既约（§19）、仿射（§20，Serre 判别法：$H^1$ 消没的初等版本）、不可约与整（§21）、
诺特（§22）、有限型与有限表现（§23）、闭与紧合（§24，赋值判别法）。
读法建议：把 §18 当成词典，后面每定义一个新性质都回到 §18 对照。
难点：§20.5 是全书最长的一个证明（Serre 判别法），§24.3 的赋值判别法要配合 §10.3 的纤维看。

### Part VI（§25–30，p119–163）
$\operatorname{Proj} S$（§25）把齐次坐标几何化；§26 在其上定义 $\widetilde{M}$ 与扭转层 $\mathcal{O}(n)$，
并证明 $\mathcal{O}(1)$ 重言；§27 做相对版本（相对 Proj、射影丛、Segre 嵌入）。
§28 是全书技术高点：丰沛（ample）与极丰沛（very ample）的等价（§28.6），要用到 §26.4 的有限型情形。
§29 Chow 引理、§30 射影态射的闭性收尾。
难点：§25.1 的 $S_+ \not\subseteq \mathfrak p$ 条件（等价于 $\mathfrak p$ 不包含全部正次齐次元），
以及 §28.3–28.5 中「$f^m$ 生成」这类有限性论证的每一处下标。

### 附录 A（p164–170）
加性范畴 → 核与余核 → 阿贝尔范畴 → 加性/正合函子 → 本书中的用法（§A.5）。
正文只用到「$\mathcal{O}_X$-模范畴是阿贝尔范畴」「正合列可逐茎判定」这两件事。

## 三、记号与体例（翻译时必须统一的）

- 环 $R$ 默认含幺、交换；$\mathfrak p$ 素理想，$\mathfrak m$ 极大理想，$\kappa(\mathfrak p)=R_\mathfrak p/\mathfrak p R_\mathfrak p$。
- $\operatorname{Spec} R$ 素谱，$\operatorname{Spm} R$ 极大谱（只在 §0–§1 出现），$\operatorname{Proj} S$ 齐次谱。
- $\mathcal{O}_X$ 结构层，$\mathcal{O}_X\text{-}\mathbf{Mod}$ 模层范畴，$\mathbf{Sh}(X)$、$\mathbf{PSh}(X)$。
- 态射 $f\colon X\to Y$：$f^{-1}$ 逆像层（§3.4），$f_*$ 正像，$f^*$ 模的拉回（§12.3）。
- 原书小节标题与正文同行（run-in），译本改为另起一行，编号不变。
- 原书正文以文字给出编号（如「Theorem 20.3.2」），译本一律用 `\ref`，显示相同的数字。

## 四、原文的几处笔误（详见《疑点清单.tsv》，译文一律不擅改）

2. §20.4、§28.1 标题写作「Principle open …」，应为「Principal open …」。
3. 附录 A.5 标题「Abelian categories in theses notes」中「theses」应为「these」。
4. p7 「Roughtly」应为「Roughly」。
5. 若干处脚注编号与正文引用错位（逐页核对时记录在疑点清单）。
