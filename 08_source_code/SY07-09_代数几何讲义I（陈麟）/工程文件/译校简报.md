## 三、文件结构（照抄这个骨架）

```latex
% ======================================================================
%  secNN.tex —— 第 N 节 <中译标题>
%  底本：原书 pp.X–Y；原书标题：<English title>
% ======================================================================

\section{<中译标题>}\label{sec:N}

\subsection{<中译小节标题>}\label{sec:N.1}

正文……

\begin{definition}\label{def:N.1.1}
……
\end{definition}
```

规则（硬性）：
1. `\section` 后紧跟 `\label{sec:N}`；`\subsection` 后紧跟 `\label{sec:N.M}`。编号由 LaTeX 自动给出，
   与原书一致（`\setcounter{section}{-1}` 已在 main.tex 设好），**你不要写编号**。
2. 每个定理类环境在 `\begin{...}` 后**立刻** `\label{前缀:节.小节.序号}`，前缀如下：
   `def:` 定义、`thm:` 定理、`prop:` 命题、`lem:` 引理、`cor:` 推论、`ex:` 例、`rem:` 注记、
   `not:` 记号、`con:` 构造、`exc:` 习题、`warn:` 警告、`predef:` 预备定义、`claim:` 断言。
3. 正文引用一律 `\ref{...}` 或 `\cref{...}`，**不得硬编码编号文字**。引用别的节同理：
   原文写 "Theorem 20.3.2" 就写 `\ref{thm:20.3.2}`（前缀按上一行的规则推断）。
   其它节尚未写时它会显示 `??`，这是正常的，全书合并后自然解开。
4. 原书的小节标题与正文**排在同一行**（0.1. Algebraic sets. Before scheme…）。
   译本把标题独立成行（`\subsection`），正文另起，编号不变。
5. 不写 `\part`，不写前言、不写参考文献。

## 四、可用的环境与宏（preamble 已定义，直接用）

- 定理族（共用一套计数器，编号 = 节.小节.序号，与原书逐条对应）：
  `theorem`（定理）、`lemma`（引理）、`proposition`（命题）、`corollary`（推论）、`claim`（断言）、
  `conjecture`（猜想）、`definition`（定义）、`predefinition`（预备定义）、`example`（例）、
  `remark`（注记）、`notation`（记号）、`construction`（构造）、`exercise`（习题）、`warning`（警告）、
  `question`（问题）、`convention`（约定）。可选标题：`\begin{theorem}[Hilbert 零点定理]`。
- 证明：`\begin{proof} … \end{proof}`；概略用 `sketch`、`proofsketch`（打印「证明概略」），思路用 `proofidea`（「证明思路」）。
- 译注：`\begin{yizhu} …… [来源：……。] \end{yizhu}`（自动加粗「译注」+ 左侧竖线）。
- 数学宏（尽量用，保证全书面目一致）：
  `\Z \Q \R \C \N \F \A \PP \GG \cO \cM \cN \cF \cG \cI \cJ \cL \cE \cA \cU \cX \cY`
  `\Spec \Spm \Proj \Spv \Hom \uHom \cHom \End \Aut \id \coker \im \Ker \Pic \Supp \Ext \Tor \colim`
  `\omod`（`\cO_X`-mod）、`\omodP`、`\lto`（→）、`\lfrom`（←）、`\into`（↪）、`\from`、`\eop`（证毕小方块）、
  `\secref{12.3}`（第 12.3 节）、`\longmapsfrom`、`\mapsfrom`。
- 交换图：`tikz-cd` 已载入，用 `\begin{tikzcd} … \end{tikzcd}`；简单箭头用 `\arrow[r]`。
- 列表：需要 (i)(ii) 时写 `\begin{enumerate}[label=(\roman*),leftmargin=2em,itemsep=0.25ex]`（enumitem 已载入）。
- 公式编号：原书几乎不给公式编号，**不要**自作主张加 `\label{eq:...}`，除非原文显式引用某式。

## 五、译注：唯一需要「查」的东西

原书行文极简，很多概念一句话带过。凡属下列情形，写一条译注：
- 原文提到但未定义、未展开的概念（如「拟凝聚层为何以 M̃ 为局部模型」）；
- 容易读错的方向、记号冲突、条件遗漏；
- 原文的跳步（证明中省略的交换性、自然性）。

写法：
```latex
\begin{yizhu}
正文……，末句必须给出依据。
[来源：Stacks Project, Tag 00FV（Theorem 10.34.1，Hilbert Nullstellensatz），\url{https://stacks.math.columbia.edu/tag/00FV}（2026-11-17 访问）。]
\end{yizhu}
```
四种允许的依据格式（择一，**必须有**）：
1. `[来源：Stacks Project, Tag XXXX（编号与名称），\url{https://stacks.math.columbia.edu/tag/XXXX}（2026-11-17 访问）。]`
2. `[来源：nLab "<条目名>"，\url{https://ncatlab.org/nlab/show/<slug>}（Last revised YYYY-MM-DD；2026-11-17 访问）。]`
3. `[依据：原书 p.N 第 K 段]`（指原书自身别处的论述，用于互见）
4. `[译者按（上下文推断，无外部依据）：……]`（只在原文自身足以判定时用）

**质量判据**（不合则删）：一条译注必须含原文没有的信息点。若只是把原文换个说法，删掉。
每条 60–200 字，一条只讲一件事。译注内**不得出现 `%` 字符**（会被当注释）。

数量：每节 3–8 条；页数多的节按比例多写，但**宁少勿滥**。

## 七、语言纪律

- 中文数学文风：简洁、准确、少用「的」串联；一句 60–70 字以内。
- 禁用：「被……所……」「进行……的讨论」「对于……而言」「值得一提的是」「众所周知」。
- 全角标点（，。：；？！——「」），英文术语与数字两侧留半角空格（如「设 $R$ 是诺特环」）。
- 术语按 `工程文件\work\术语表.tsv`（en→zh）。表里没有的：有稳定通行译名就用中文，
  两种以上并行译法就保留英文原词（首次出现加中文括注）。**新术语在报告里列出来**，我统一补表。
- 人名保留拉丁字母（Zariski、Noether、Serre、Grothendieck、Hilbert、Bézout、Chow、Segre、Jacobson、Yoneda）。
- 原文自身的拼写错误（如 Algbera、Roughtly、addiontal）按显然本意翻译，不照抄错误；必要时在译注里说明。
