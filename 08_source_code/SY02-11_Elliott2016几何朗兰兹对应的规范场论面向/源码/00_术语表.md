## 四、书写约定

1. 章节、公式、定理编号**原样保留**：如「定理 1.1.9」「式 (3.2.1)」。
2. 文献引用保留方括号原样：`[Tes16]`、`[FO98]`，不译。
3. 人名保留原文拼写（Kapustin、Witten、Langlands、Hitchin、Nahm、Whittaker、Hecke、Iwahori 等）。
4. 数学公式一律用 LaTeX：行内 `$...$`，行间 `$$...$$`。
5. 译者补充一律写成 `> **译注**：……`，与正文区分。
6. 中文标点用全角；公式内标点用半角。
7. 「我们」保持第一人称复数，与原文 we 对应；作者自述用「本论文」。
