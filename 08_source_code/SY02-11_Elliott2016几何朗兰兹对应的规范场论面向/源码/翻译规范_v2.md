## 抽取文本的缺陷（必须自行修复）

## 文风（这是本次重译的核心目的）
旧译的问题：长句套长句、被动式堆叠、「被给出／被称作／进行……的处理」这类译文腔，读起来像机器翻译。新译文要求：

1. **按中文习惯断句**：英文一个长句常拆成两三个中文短句；先给主干，再补修饰。
2. **少用被动**：the map is given by → 「该映射由……给出」（可以）但优先「由……定义」「……等于」。
3. **术语与句式前后一致**：同一概念全书同一说法（见术语表）。
4. **忠实**：不添解释进正文（补充一律进译注），不删限定语（"for simplicity"「为简单起见」这类要留）。
5. **数学文本的语气**：用「我们」对应 we；作者自述用「本论文」；不写「笔者」。
6. 保持原文的分段与叙述顺序；原文的强调（italics）用中文着重或加粗体现（**加粗**优先）。

## 格式（与第 1 章定稿一致）
- 页锚：每一页正文开始前单独一行 `<!-- p.NN -->`（NN 为三位数字，如 `<!-- p.057 -->`）。**一页一个锚，页序严格递增，不得重复或缺失。** 若某页只有一两行（上一页段落延续），把锚放在该页首句之前即可，允许行内嵌在段落中（写成 `。<!-- p.058 -->随后，`）——但优先行首独占一行。
- 章节标题：`# 第 N 章　章名`、`## N.M　节名`、`### N.M.K　小节名`，编号与标题之间用**全角空格**。只写本章内容时也照此写（章标题行必须存在）。
- 定理/命题/引理/定义/例/注/猜想：`**定理 3.4.3**。正文……`（编号加粗，后接全角句号）。原文为 Definition/Theorem/Lemma/Proposition/Corollary/Example/Remark/Conjecture/Question 一律如此。
- 公式：独立公式用
  ```
  $$
  ...
  $$
  ```
  行内用 `$...$`。多行对齐用 `\begin{aligned}...\end{aligned}`。
- 列表：原文 itemize/enumerate 用 `-`／`1.`。
- 文献引用原样：`[Cos11b]`、`[CG15]`，方括号不译不改。
- 交叉引用：`第 3.4 节`、`定理 3.4.3`、`式 (3.2.1)`、`图 5.1`、`表 1.2`（编号原样）。
- 译注：单独引用块 `> **译注**：……`。只在真正需要时加（原文笔误、术语取舍需说明、与 nLab 通行表述有出入、译者补的短说明）。**每章 3–10 条为宜，不要每段都注。**
- 术语首现：`中文（English）`，同章内不重复标注。
- 标点：中文全角（，。：；？！「」），公式内半角。
- 人名不译：Kapustin、Witten、Langlands、Hitchin、Nahm、Whittaker、Hecke、Iwahori、Beilinson、Drinfeld、Costello、Gwilliam 等。
- `N=4` 写成 `N=4`（原样），不写 `$\mathcal{N}=4$` 除非原文如此。
