## 版本沿革：v1 已撤下，v2 取而代之（2026-11-15）

### v1（2026-11-12）为什么撤下

v1 是第一版中译，框架可用（章节、定理体例、页锚思路、术语表都在），但**问题出在句层**，
逐句对照底本后，密度高到无法靠局部补丁解决：

1. **数学内容译反**——p.16 BPS 界把「质量有下界」写成「有**上界**」，与紧邻的
   $E\ge\alpha|m|$ 自相矛盾；p.95 费曼积分被积函数漏掉负号；p.82 两个因子的次序对调；
   p.180「the second supercharge」译成「第二个直和项」；p.202 主从颠倒。
2. **术语不一与误译**——root datum 译作「根系数据」（与 root system 混淆，应为「根数据」）、
   shearing/smearing 混用、holonomy 译作「完整」、divergence 译作「全导数」、
   vanishing/nearby cycles 译作「消没闭链／邻近闭链」（应为「消没轮／邻近轮」）。
3. **公式、表格、交换图错位**——表 1.2 为「版面」删掉 $SL(mn;\mathbb{C})/C_m$、$Spin(8n)$、$Spin(8n+4)$ 数行；
   p.94 交换图列对不齐；p.135 的 2×3 交换图错位；p.159 图漏一条竖箭头。
4. **页锚错乱**——第 1 章缺 p.10、p.11、p.25、p.26、p.47 五处锚点（1.3.5 直接从 p.46 跳到 p.48），
   附录自 p.216 起整体滞后一页，另有 p.147/p.148、p.160/p.161 的成对错位。
5. **漏译**——**整条定理 B.8（p.228）未译**；致谢全节未译；p.37–38 关于奇异支撑的整句、
   p.163 关于截面配对的整句缺失。
6. **体例**——「本文」与「本论文」混用、公式内出现中文、全角/半角标点混用、页锚两位三位不一。

结论：v1 不是「几处笔误」，而是逐句层面不可靠——读 v1 有可能读到与原文相反的数学陈述。
因此 v1 整包撤下（不再作为可选版本提供），v2 覆盖同名路径。v1 的存疑清单与逐条差异保留在本包
`源码/08_校订说明.md` 的第八节，任何人仍可追溯「哪一处改过、为什么改」。

### v2（2026-11-15）做了什么

- **逐页重译**：以底本页脚号为准（页脚号 = PDF 页序，偏移 0），每页一个页锚 `<!-- p.NNN -->`，
  全书 **206 个页锚**（第 1 章 46、第 1 部分 49、第 2 部分 84、第 3 部分 13、附录 14），
  逐页连续、无缺、无重、无错位。
- **补全漏译**：定理 B.8、致谢全节、奇异支撑句、截面配对句全部补回。
- **参考文献重排**：从底本 p.204–p.213 全量重建 **137 条**（136 个唯一 key；原书自身两条同用 `[BD04]`，
  照录），修复 PDF 折行撕碎的条目、连字 ﬁﬂ、分解音标（`´e`→é 等 30 余处）。
- **四幅图矢量化**：图 5.1、6.1、6.2、6.3 是底本里的矢量线条（Feynman 图），不是位图。
  本次按 PDF 中每条路径的控制点与虚线样式（宽图 9.5 pt 虚线、小图 1.8 pt 点线）逐条转写为 TikZ，
  PDF 内为纯矢量，`成品/images/` 下另存 600 dpi PNG 供 Markdown 阅读。
- **nLab 校定**：按 15 个 nLab 词条（geometric Langlands correspondence、singular support、
  ind-coherent sheaves、factorization algebra、BV formalism、twistor space、L∞-algebra 等）
  插入 **16 条对照译注**，每条标词条名，供读者比照通行定义。
- **统一术语**：root datum→根数据、超 Yang–Mills、全纯–拓扑扭转、proper→真（proper）、
  on-shell→在壳（on-shell）等 16 组，写进 `00_术语表.md`。

正文汉字 71,675 → 73,927（+3%），前置件 575 → 1,215（补译摘要与致谢），
成品 PDF 113 页 / 1,236,270 B。旧译与 v2 的逐章字数对照表见 `源码/08_校订说明.md` 第二节。

## 如何重建 PDF

```
python make_book.py --pdf
```

需要 pandoc、xelatex（MiKTeX）、字体 Microsoft YaHei 与 Times New Roman；
`make_book.py` 会把 `![](images/*.png)` 换成 `tikzpicture`，因此 PDF 内不出位图。
命令行要点见脚本头部注释（`--toc`、`mathtools`、`tikz` 为必需）。
