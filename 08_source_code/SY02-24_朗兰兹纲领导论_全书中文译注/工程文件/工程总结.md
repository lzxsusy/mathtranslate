# 工程总结：SY02-24《朗兰兹纲领导论》全书中文译注

## 一、底本

- J. Bernstein, S. Gelbart (eds.), *An Introduction to the Langlands Program*, Birkhäuser, 2004, ISBN 0-8176-3211-5。
- 底本 PDF 283 页，2001 年 3 月希伯来大学高等研究院讲习班讲义；六位作者：Kowalski（1–3 章）、de Shalit（4–5 章）、Kudla（6–7 章）、Bump（8 章）、Cogdell（9–11 章）、Gaitsgory（12 章）。
- **页次**：PDF 相对印刷本缺 6 页，偏移从 8 递减到 2。逐章 PDF 页 / 印刷页对照见 `work/PAGE_MAP.md`；译文引用一律用印刷页码。

## 三、流程

1. 先按 `STYLE.md` 冻结术语与体例，再逐章派译：读通读笔记 → 逐句译 → 公式回页图核 → 写译注 → 单章 xelatex 自检。
2. 每章交 `src/chapters/chNN.tex` 与 `work/notes_chNN.md`（通读笔记、疑点清单、术语、自测记录）。
3. 主控合并：`\setcounter{chapter}{N-1}` 固定章号，`\thesection` 改为章内 1,2,3…，与原书节号一致。
4. 全书统一收口：`PunctStyle=kaiming` 消标点悬挂，`emergencystretch=3.5em` 消 overfull，逐页目检关键页。
5. 术语表由各章笔记表格与统一术语表合并生成（`mk_glossary.py`），译注汇总由 `annote` 环境抽取（`mk_notes2.py`）。

## 四、取舍与已知问题

- **节号**：全书 `\thesection` 统一为章内序号（1、2、3…），与原书「§1、§2」一致；不采用「章.节」形式。
- **段落编号**：第 12 章沿用 `\obx` 显式编号（1.1、2.3 式）以复现原书编码；其余章用 `\ob` 自增编号或原书式手写编号（第 3 章）。
- **缺页**：底本 PDF 缺 6 页，个别章（如第 1 章 p.21 起为第 2 章首页）边界依页眉判定；若日后取得完整 PDF，应按 `PAGE_MAP.md` 重抽并复核首尾。
- **未解疑点**：全书各章共约 20 条（各章 `notes_chNN.md` 末节），多为原书排印小疵与个别记号歧义，均已照录并出注说明。
- **公式**：一律回 150 dpi 页图逐符号核对；pdftotext 的公式不可用。
- **未做**：未做逐条外部文献复核（译注来源标注 A/B/I 分级，B 级已与原书交叉）；未做索引。
