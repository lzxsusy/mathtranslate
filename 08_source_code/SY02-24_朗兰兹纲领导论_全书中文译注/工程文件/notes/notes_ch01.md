## 三句话主旨

1. 本章以 Euler→Hecke 的时间顺序，把 Riemann zeta、Dirichlet L、Dedekind zeta、Hecke L 四类函数串成一条线，展示"Euler 乘积＋函数方程"如何把素数的分布编码成复零点。
2. 贯穿全章的三件套是：Euler 因子（局部数据）、导子（整体不变量）、根数与函数方程；它们从 Dirichlet 情形开始出现，到 Hecke 情形定型。
3. 全章反复申说的主题是" reciprocity（互反）"：把一个 L 函数分解成基域上更简单对象的 L 函数之积，就等于用基域的数据描述扩域中素数的分裂；类域论是其中已完全解决的交换情形，曲线情形则是几何类比。

## 逐节内容地图

- §1 Introduction（p.1）：写作纲领；解析数论视角；预告第 2 章给证明。
- §2 The Riemann zeta function（pp.1–4）：
  - 级数定义、Euler 乘积 (2.1)；Euler 由调和级数发散重证 Euclid 定理，并得 Σ_{p≤X}1/p = log log X + O(1)。
  - Riemann 的洞见：复变量、全纯性；完备化 Λ(s)=π^{−s/2}Γ(s/2)ζ(s) (2.2)、函数方程 (2.3)；ζ(0)=−1/2；平凡零点 s=−2n。
  - 伽马因子的地位：由 Poisson 求和/theta 函数获得 de facto 地位，Tate 论文才澄清为 Q 的阿基米德 Euler 因子；Euler 乘积一般形 (2.4)；脚注 2：数域上"因子数据"强于乘积。
  - 显式公式：命题 2.1（光滑紧支 φ，Mellin 变换 φ̂，辅助 ψ(x)=φ(x^{−1})/x，公式 (2.5)，积分沿 Re(s)=−1/2）。
  - ζ 在 Re>1 无零点（Euler 乘积），Deligne 首证有限域 RH 的关键分析输入；RH ⟺ ψ(X)=X+O(X^{β*}) 对 β*>sup Re ρ (2.6)；临界带、临界线；自守 L 函数临界带可右移。
- §3 Dirichlet L-functions（pp.4–7）：
  - 定理 3.1（算术级数中的素数，含 (1/φ(q))log log X 主项）；用 (Z/qZ)^× 上的调和分析（特征）证明。
  - 特征定义（含 χ̃ 提升、χ=0 on (x,q)≠1）；L(χ,s)=Σχ(n)n^{−s}=∏(1−χ(p)p^{−s})^{−1}，完全乘性；正交关系给出显示公式；Dirichlet 定理 ⟺ L(χ,1)≠0；χ₄ 的例子 π/4；脚注 3（部分和有界）。
  - 本原性与导子；q 素时非平凡特征皆本原；(3.1) L(χ,s)=L(χ̃,s)∏_{p|q/q̃}(1−χ(p)p^{−s})。
  - 偶/奇特征的 Λ 定义；Gauss 和 (3.2)；函数方程 (3.3)；ε(χ) 分段定义 (3.4)；三个 ubiquitous 特征（导子、根数、对偶特征）。
  - 二次特征：χ̄=χ，ε=±1；Gauss 算出 τ(χ)=√q 或 i√q，故 ε=+1。
  - Dirichlet 证明的三步：非实特征易；二次情形用解析类数公式；L(χ,1)≫q^{−1/2} 有初等证明；类数问题的进展反而依赖 L 函数估计（Landau、Siegel、Goldfeld）。
- §4 Dedekind zeta functions（pp.7–12）：
  - 定义、Euler 乘积；写成 Dirichlet 级数 (4.1)，系数 r_K(n) 编码素数分裂型（r_K(p)=d 完全分裂、=1 完全分歧）。
  - 代数数论回顾：r₁,r₂ 嵌入与绝对值/位、d_v、Nz=∏|z|_v；判别式 D=det(ω_i^σ)²；单位群秩 r₁+r₂−1、对数映射、调节子 R；w；类群 Pic(O)、类数 h(K)。
  - 分解群、惯性子群、Frobenius 共轭类 [𝔓,E/K]、σ_p；交换 G 时退化为自同构。
  - Λ_K(s)=π^{−r₁s/2}(2π)^{−r₂s}Γ(s/2)^{r₁}Γ(s)^{r₂}ζ_K(s)；亚纯、s=0,1 单极点；解析类数公式 (4.2) Res=2^{r₁}(2π)^{r₂}hR/(w√|D|)；函数方程 (4.3) Λ_K(s)=|D|^{1/2−s}Λ_K(1−s)，根数恒 +1。
  - 特殊值与动机（Deligne 框架；Phillips–Sarnak 的超越点）。
  - (4.4) ζ(s)L(χ,s)=ζ_K(s)（K=Q(√(χ(−1)q))）＝二次互反律的重新表述；(4.5) L(χ,1) 的类数公式形式；(4.6) 三类 Euler 因子；(4.7) 用 χ 刻画分歧/分裂/惰性；(4.8) 用 Legendre 符号刻画；χ(n)=∏_{p|n}(n/p)；q≡1,3 mod 4 与 D=χ(q)q；推出 (p/q)=(D/p)=(−1)^{(p−1)(q−1)/4}(q/p)。
  - 方法论收束：寻求 (4.4) 的推广＝寻求"互反律"；相对扩张；Artin L 函数与 Langlands 猜想；交换情形＝类域论。
- §5 Hecke L-functions, class-field theory（pp.12–17）：
  - 交换扩张、Frobenius 元；ζ_E(s)=∏_{ρ∈Ĝ}L(ρ,s) (5.1)，L(ρ,s)=∏_p(1−ρ(σ_p)(Np)^{−s})^{−1}，分歧用 C^{I_p} 上的 0/1 维表示处理；完全分裂时的因子核对；解析延拓不显然；脚注 5（系数部分和是否有界）。
  - 例 5.1：二次域的两个特征，L(χ₂,s) 的分裂/惰性 Euler 因子。
  - 类域论的 L 函数部分＝把 Galois 特征的 L 函数认成 Dirichlet/Hecke 特征；定理 5.2（Kronecker–Weber 的 L 函数形式）；推论 5.3（K ⊂ Q(μ_m)）及证明（用"完全分裂素数集决定扩张"）；注 5.4（与模性猜想的相似、Wiles 式证明）。
  - Hecke L 函数的定义：模 m、I_m、P_m、射线类群 H_m、U_m、权 ξ_∞:K^×/Q^×→C^×、χ((α))=ξ_∞(α)、本原性；(5.3)。
  - 例 5.5（理想类群特征、射线类特征、L(χ₀,s)=ζ_K(s)）；例 5.6（K=Q 回到 Dirichlet）；例 5.7（虚二次域权 u、实二次域权 (u₁,u₂)∈{0,1}²）。
  - 定理 5.8（Hecke）：整函数、伽马因子 Γ(ξ_∞,s)、(5.4) Λ(χ,s)=ε(χ)(|D|Nm)^{1/2−s}Λ(χ̄,1−s)。
  - 定理 5.9（Artin）：交换情形 L(ρ,s)=L(χ,s)，且局部相等 ρ(σ_p)=χ(p)（脚注 6：K≠Q 时局部陈述更强）。
  - 注 5.10（导子 f(ρ)、权 ξ_∞(ρ)，可暴力验证；与 Weil 的 level=conductor 类比）；注 5.11（导子—判别式公式 |D|=∏q_χ；Q(μ_ℓ) 时 ℓ−1 个特征、导子 1 与 ℓ，得 ℓ^{ℓ−2}）。
  - Hecke 特征的两类等分布应用；|{a:Na≤X}|=Res·X+O(X^{1−1/d})；例 5.12（Q(i)、Gauss 圆问题、误差 X^{1/3}、猜想 >1/4、光滑化 O(X^{−1/2})）。
- §6 Function fields（pp.18–20）：
  - Z 与 k[X] 的古老类比；F_q 上曲线 C、光滑射影模型、函数域 K=F_q(C)、闭点↔非阿基米德赋值、Z(C;s)=∏(1−(Nx)^{−s})^{−1}、T=q^{−s} 与 ∏(1−T^{deg x})^{−1}。
  - 引理 6.1：Z(C)=exp(Σ|C(F_{q^n})|T^n/n)，证明用 T(d/dT)log 与几何级数、N_n=Σ_{d|n}d·#{deg=d}。
  - 定理 6.2：Z=P_{2g}/((1−T)(1−qT))、P_{2g}∈Z[T] 首一 2g 次、函数方程 Z(C)=ε(C)q^{−χ/2}T^{−χ}Z(1/(qT))（χ=2−2g）、|α_i|=√q（Weil 的曲线 RH）；Schmidt、Riemann–Roch；Grothendieck–Deligne；上同调解释。
  - 注 6.3：s 变量下的函数方程 q^{χ(s−1/2)}；零点 Re(s)=1/2。
