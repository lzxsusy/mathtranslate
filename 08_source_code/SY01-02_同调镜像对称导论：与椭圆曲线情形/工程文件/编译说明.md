`1501.00730v1(2).tex` 是**自包含**的：导言区、正文、附录、参考文献全部在一个文件内，
不依赖任何 `\input`，也不会因为缺少子文件而编译失败。

## 编译方法

推荐 **XeLaTeX**（源码首行已含 `% !TEX program = xelatex` 魔法注释，TeXstudio /
TeXworks / VS Code LaTeX Workshop 会自动识别）：

```bash
xelatex 1501.00730v1(2).tex
xelatex 1501.00730v1(2).tex    # 第二遍：生成目录、页码
```

若本机中文字体环境特殊，可在导言区（约第 20 行）把

```latex
\usepackage[UTF8,scheme=chinese]{ctex}
```

改为显式指定字体集：

```latex
\usepackage[UTF8,fontset=windows,scheme=chinese]{ctex}   % Windows（宋体/黑体）
\usepackage[UTF8,fontset=mac,scheme=chinese]{ctex}       % macOS
\usepackage[UTF8,fontset=fandol,scheme=chinese]{ctex}    % 跨平台（TeX Live 自带 Fandol 字体）
```

## 依赖宏包（TeX Live 2018+ / MiKTeX 均自带）

`ctex, amsmath, amssymb, amsthm, mathtools, bm, amscd, tikz-cd, graphicx, caption, enumitem, xcolor, hyperref`

其中 `tikz-cd` 仅用于第 8 节与附录 A 的复杂交换图；若本机 TeX 发行版确实未安装该宏包，
可将其删去，但需把对应的 `tikzcd` 环境改为 `CD` 环境（源码中该处已有批注提示）。

## 关于批注与勘误

- 源码中以 `% [Tutor Note: ...]` 形式嵌入的批注共 **64 条**，均为 LaTeX 注释，**不参与排版**；
  在编辑器中检索 `Tutor Note` 即可逐条查看（易错约定、被省略证明的出处、原文笔误）。
- 文末“译校札记与勘误表”集中列出 12 条已核实的原文问题；正文对应处以“（原文如此，应为……）”标出。
- 论文侧边没有改动原文的章节、公式、定理与文献编号：定理环境按原文顺序自动复现原编号
  （1.1–1.11、2.1–2.18、…、A.1–A.12、B.1–B.6），公式 (4.1)、(7.1)、(7.2) 以 `\tag` 强制沿用原编号，
  便于与原文逐条对读。
