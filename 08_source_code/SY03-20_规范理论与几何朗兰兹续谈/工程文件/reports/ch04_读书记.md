# part4 读书记（§6 行列式线丛、§7 计算赫克本征值）

## 一、结构梳理

1. 本部分的目标是第二篇的技术核心：先把「赫克本征值」为何不是一个数、而是一个（扭曲）线丛上的截面讲清楚，再实际把它算出来。
2. §6 是全篇的工具箱。§6.1 纯代数地定义线丛配对 $\langle{\cal L},{\cal M}\rangle=\det H^*({\cal L})\otimes\det H^*({\cal M})\otimes\det H^*({\cal L}\otimes{\cal M})^{-1}\otimes\det H^*({\cal O})^{-1}$，用正合列 + 归纳（对除子的次数）证明其双线性与对称性，并把最困难的一步归结为「立方体定理」(6.16)。
3. §6.2 解释模空间上的含混性：$\Pic_c(D)$ 只把线丛定到同构类，选不同的万有线丛 $W\to W\otimes R$ 会把配对乘以 $R^d$，于是 $d\ne 0$ 时配对只在「被 gerbe 的 $d$ 次幂扭曲」的意义下典范——由此引出双次数 $(d,c)$ 与扭曲对偶性。
4. §6.3 以最低限度介绍 gerbe：局部平凡化相差用线丛张量、$U(1)$ 与 $\Z_n$ 的带、联络 $B$ 与 $B\to B+F$、$H=dB$、平坦性；三例分别是自旋结构的 $\Z_2$ gerbe、万有线丛给出的平凡 gerbe、$^L\!G$ 中心 $\Z_n$ 上的非平凡 gerbe（引 [KW] §7）。
5. §6.4 是第一部分的高潮：断言 $\langle{\cal L},{\cal M}\rangle$ 就是 $\Pic_c(D)\times\Pic_d(D)$ 上双次数 $(d,c)$ 的典范扭曲庞加莱线丛，并给出两条独立证明——Quillen 曲率（微分几何，式 (6.23)–(6.25)）与 $\theta:D\to\Jac(D)$（代数几何，式 (6.26)）。
6. §6.5 把工具用到 Hitchin 纤维上：谱覆盖 $\psi:D\to C$ 下 $\det H^*(D,{\cal L})=\det H^*(C,\psi_*{\cal L})$、$\det H^*(C,E)=\det H^*(C,\det E)$，把 $SU(N)\leftrightarrow PSU(N)$ 的扭曲对偶化归为 Jacobian 的对偶，并给出逆命题（$\Nm({\cal L})$ 平凡的线丛由 ${\cal O}(q)\otimes{\cal O}(q')^{-1}$ 张成）。
7. §7.1 阿贝尔情形：$U(1)$ 希格斯对、威尔逊算符与 't Hooft 算符、万有线丛的 $R^d$ 扭化，得到 $T\cdot{\cal B}={\cal B}\otimes(\otimes_i{\cal L}|_{p_i}^{d_i})$；§7.1.2「电场与磁场」说明 $c_1\ne 0$ 的膜为何不属于 $\MH$、低能描述为何必须含 $U(1)$ 向量多重态。
8. §7.2 非阿贝尔推广：$^L\!G=G=U(N)$、磁权取最高权、万有希格斯丛，本征空间分解给出 $T(^L\!w;y,p)\hat{\cal B}=\hat{\cal B}\otimes(\oplus_i{\cal M}|_{q_i})$，再推广到任意微小权 $\wedge^k V\otimes(\det V)^r$；§7.2.2「解释」处理中心 $U(1)$ 与 $\Delta$ 的遗留问题。
9. 贯穿两节的主线：同一件东西（配对/线丛）在两处出现——§6 把它当作几何对象造出来，§7 把它当作 't Hooft 算符的本征值来算；「本征值」从数变成线丛，是第二部分到第三部分的关键转折。

## 二、跳跃处（需要读者自己补的论证）

1. **(6.16) 立方体定理只验单项式**（§6.1 末）。作者明说「这一证明稍显朴素」，只对单项式验证即在一般情形成立，完整论述引 Deligne [40]。读者若要自洽，须知道立方体定理的两种表述（线丛在 $D_1\times D_2\times D_3$ 上的平凡化与除子的三次关系）等价。
2. **由 (6.25) 曲率到「就是庞加莱线丛」**（§6.4）。中间需要：曲率 2-形式在 $\Jac(D)\times\Jac(D)$ 上是常系数辛形式、其 de Rham 类给出第一陈类，再「曲率决定线丛（相差平坦因子）」。文中以 (6.18) 后「常数规范变换把配对乘 $\lambda^d$」的方式处理次数零，未展开最后一层。
3. **由 (6.27)(6.28) 到「$\langle{\cal L},\psi^*{\cal M}_0\rangle$ 不随 ${\cal L}$ 变」**（§6.5）。需要把 $\psi_*({\cal L}\otimes\psi^*{\cal M}_0)=E\otimes{\cal M}_0$ 与 $\Nm({\cal L})$ 固定这两件事同时用上；文中只说「由上述事实」，读者须自己接上。
4. **扩展博戈莫尔尼方程的解未验算**（§7.1.2）。$F=2\pi d\,\omega$、$\phi_0=2\pi y\,d$ 满足方程与边界条件只给结论；归一化（$\int_C\omega=1$ 与 $c_1=d$ 及 $\partial_y\phi_0=2\pi d$）需要读者自己核（本稿译注 T11 补了这一验算）。
5. **从赫克修正 $\Phi_i$ 到陈-帕顿丛的 $\oplus{\cal M}|_{q_i}$**（§7.2.1）。依赖式 (6.2) 的配对在纤维上的显式形式：把 $\Phi_i$ 造成的「加一个 $q_i$」翻译成配对值上的因子 ${\cal M}|_{q_i}$；文中未把这一步写开。

## 三、精彩处

1. **把模空间的含混性变成 gerbe**（§6.2）。经典上「这个对象只在同构类意义下良定义」是一句含糊的免责声明；作者把它解释成「被 gerbe 的 $d$ 次幂扭曲」，于是 $\Pic_c(D)$ 上的线丛配对被赋予精确的结构，而且立刻与 §6.3、§7 的物理（$B$ 场、电荷）对上。作者自己称之为「花哨的同义反复」，但这是全篇最有生产力的一次同义反复。
2. **同一事实两种独立证明**（§6.4）。Quillen 曲率的解析计算与 $\theta$ 映射的代数构造给出同一个庞加莱线丛；两条路各自独立，互證之余也说明「行列式线丛的曲率」与「$\theta$ 除子」是同一几何对象的两个面。
3. **用行列式把非阿贝尔化归阿贝尔**（§6.5）。$\det H^*(C,E)=\det H^*(C,\det E)$：左边可能依赖 $E$ 的所有高阶陈类，右边只看 $\det E$；一旦接受它，$SU(N)$ 的扭曲对偶就化为 $\Jac(D)$ 的对偶，Hitchin 纤维的对偶性不再需要非阿贝尔理论。
4. **'t Hooft 本征值与电侧公式逐项相同**（§7.1.1）。磁膜上的 't Hooft 算符作用给出 ${\cal B}\otimes(\otimes_i{\cal L}|_{p_i}^{d_i})$，与电侧威尔逊算符的公式完全一样；这是 S-对偶下「赫克算符 ←→ 't Hooft 算符」的定量版本。

## 四、术语观察

- **gerbe** 全文保留原文不译；**band（带）** 在译注中首次出现时给出中文，属原文未译的补充。
- **twisted** 统一作「扭曲」：「$d$ 次幂扭曲」「扭曲向量丛」「扭曲线丛」「扭曲对偶性」「扭曲庞加莱线丛」「离散扭转（discrete torsion）」，与索引术语表一致。
- **trivial / trivialized**：本部分最易混的一对。trivial 译「平凡」，trivialize（trivialized）译「（可被）平凡化」；§6.4 原文先用 "these flat gerbes are trivial"、后用 "can be trivialized"，两者分工不同（前者说 gerbe 本身平凡，后者说需选扭曲线丛作平凡化），中译分别对应，未改。
- **determinant line bundle** 译「行列式线丛」；文中 $\Det$（族上的线丛）与 $\det$（单点上的线）字形有别，二者不可混。
- **万有线丛 universal bundle / 万有希格斯丛 universal Higgs bundle**、**陈-帕顿丛 Chan-Paton bundle**、**微小权 minuscule weight**、**扩展博戈莫尔尼方程 extended Bogomolny equation**、**向量多重态 vector multiplet**、**单值变换 monodromy**：均与 `校对记录/索引术语.tsv` 一致。
- 本部分新增 `\index` 条目与术语表逐一对照，未发现一译多名。

## 五、遗留疑点

1. 原文疑误四处（$D\otimes\Pic_c(D)$、$\W=C\times\Jac(C)$、gerbe 基空间 $\M$ 与 $\MH$ 不一致、${\cal G}'$ 与 $\eG'$ 字形不一）均只登记未改，详见 `ch04_issues.md` 第四部分。
2. §6.4 的 trivial 与 can be trivialized 曾疑为自相矛盾，经核 PDF 断页处原文作 "are trivial"，中译「是平凡的」忠实，未改（详见 `ch04_issues.md` 第四部分第 1 条）。
3. 式 (6.23) 的 $\delta U\wedge\delta U$ 记号未明说 $\delta U$ 是联络的变分 1-形式；按作者惯例可读通，非错，未加译注。
4. 脚注 24（τ 的实部与虚部、$\Im\tau$）与正文 $d\ne 0$ 膜的讨论相扣，但 $\tau$ 的归一化（$\tau=\theta/2\pi+4\pi i/e^2$）在第二篇前文才定义，本部分读者可能需回看 §2；基础概念按分工由 part1–3 负责，未重复加注。
