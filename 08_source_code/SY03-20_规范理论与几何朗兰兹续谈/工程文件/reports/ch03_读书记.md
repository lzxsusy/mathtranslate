# ch03 读书记（part3：§4 't Hooft 算符与赫克修正、§5 磁本征膜）

读本：`源码/part3_zh.tex`（754 行）对照 `原文/EN_part3.txt`（印刷 p.34–59）。

## 结构梳理

- **§4 的总目标**：把四维 N=4 超杨–米尔斯理论中 't Hooft 线算符在希格斯丛模空间 $\MH$ 上的作用，翻译成黎曼面 $C$ 上丛的赫克修正；由此把几何朗兰兹的「赫克本征层」解释成 't Hooft 算符的「本征膜」。这是全文的核心论证，§4 给物理侧、§4.5 纳入希格斯场，§5 转向磁本征膜。
- **§4.1 本征膜**：因线算符彼此对易，可要求膜在它们作用下「变为自身的张量倍」；形式化定义是 $L\B=\B\otimes V$（$V$ 是向量空间，只在同构意义下确定）。这解释了为什么本征值不是数而是空间。
- **§4.2 电本征膜**：Wilson 算符在 B 模型中的作用=与万有丛在 $\pp\times\MH$ 上的限制作张量积（[KW] §8.1）；要求该丛平坦，故电本征膜对应 $C$ 上的平坦丛/局部系统——几何朗兰兹的电侧。
- **§4.3 't Hooft 算符与赫克变换**：把算符奇性写成 $\R\times C$ 上的扩展博戈莫尔尼方程（式 (4.11)-(4.16)），用 GNO 对偶把算符分类归结为 $^L\neg G$ 的表示，再把「在 $\pp$ 处作用」等同于「在 $\pp$ 处作赫克修正」；赫克修正的类型由 $^L\neg R$（$^L\neg G$ 的不可约表示）标记。
- **§4.4 基本例子**：按群从小到大验证上述等价：$U(1)$（$\O\to\O(m\pp)$，磁荷 $m$）、$U(2)$（微小权 $(1,0)$，修正空间 $\CP^1$，冒泡）、$SO(3)/SU(2)$（必须用 $\ad_0(E)$，$SO(3)$ 无微小权）、$U(N)/PSU(N)/SU(N)$（$\mathrm{Gr}(k,N)$、分数权重）。每个例子都在核对「赫克修正的类型 = $^L\neg G$ 的表示」。
- **§4.5 纳入希格斯场**：线算符位于 $C$ 中的点 $\pp$ 处，除丛之外还要与 $\varphi$ 相容。判据是：$\varphi_+$ 在 $\pp$ 处无极点 ⟺ 赫克修正「$\varphi$-不变」⟺ $\varphi_-(\pp)\cdot b=0 \bmod b$（$b$ 为 $\varphi_-(\pp)$ 的本征方向）。微小权时 $\varphi_-(\pp)$ 恰有两个本征方向，故恰有两个 $\varphi$-不变修正，分别对应谱覆盖上的两点 $\qq'$、$\qq''$（式 (4.45)）；$U(N)$ 时推广为 $N!/\#\Gamma$ 个，在谱曲线上逐层实现 $U(1)$ 的 $\L\to\L\otimes\O(\qq_i)^{m_i}$（式 (4.49)）。
- **§5 磁本征膜**：§5.1 预备（S-对偶把 $(B,B,B)$ 型膜映为 $(B,A,A)$ 型膜）；§5.2 Hecke 修正保持特征多项式、故保持希钦纤维 $\FF$，其作用是把 $\FF$ 对应到 $\Pic(D)$ 的另一个分支（$\O(\qq')$ 的次数为 1）；§5.3 定义「平移本征丛」（$f$ 的拉回 $\tilde f^*(\L)=\L\otimes\mathcal N_{\tilde f}$，本征值是一维空间）；§5.4 说明支撑在 $\FF$ 上、带平坦陈–帕顿线丛的 $\bf F$ 型膜正是磁本征膜，本征值为 $\oplus_i\mathcal N_i$。

## 跳跃处（读时需要自己补的论证）

1. **§4.3 式 (4.11)-(4.16)**：从四维线算符到 $\R\times C$ 上扩展博戈莫尔尼方程只给结果，未说明这是 4d 超对称方程的 BPS 约化，也未说明为何取 $t=1$ 不失一般性（正文把细节推给 [KW] §3）。
2. **§4.4.2 舒伯特胞腔/闭链**：「给定类型的赫克修正空间称为舒伯特胞腔，其紧化称为舒伯特闭链」一句带过，正文与脚注都没有定义仿射 Grassmannian，也没有说清「紧化 = 单极子冒泡」的机制，读者容易把 $\CP^1$ 的紧性当成理所当然（真正需要 $n-m\ge2$ 才有冒泡）。
3. **§4.5.2 恰两个 $\varphi$-不变修正**：从「$\varphi_-(\pp)$ 只是缩放齐次坐标 $u,v$」跳到「恰有两个 $\varphi$-不变修正」，$\CP^1$ 上两不动点的计数被省略——这正是理解 $\qq'$、$\qq''$ 来源的关键（本轮译注已补）。
4. **§5.2 保特征多项式 ⟹ 保纤维**：由式 (4.35) 直接断言赫克修正保持纤维 $\FF$，特征多项式 ↔ 谱覆盖 ↔ 纤维三者的对应没有展开；另外「$\O(\qq')$ 次数为 1 会置换 $\Pic(D)$ 分支」只用一句话带过。
5. **§5.4 共同本征膜必为平移本征丛**：断言更高秩膜不给出新的磁本征膜（式 (5.7)），依据只是「't Hooft 算符足够丰富」，缺少对「所有 $\Phi_i$ 的共同本征膜」的完整论证。

## 精彩处

1. **§4.4.2 的 $\CP^1$ 与冒泡**：把 $U(2)$ 的 $(1,0)$ 型赫克修正空间识别为 $\CP^1=P(E_{-,\pp})$，同时对应舒伯特胞腔与单极子冒泡——一个几何对象同时承载三种解释，是全文最漂亮的一段。
2. **§4.5.2 的线性化判据**：把「$\varphi_+$ 在 $\pp$ 处无极点」这个解析条件化为 $\varphi_-(\pp)\cdot b=0 \bmod b$ 的线性条件，再用 $\varphi_-(\pp)$ 的两本征方向得出恰两个 $\varphi$-不变修正并与谱覆盖的 $\qq'$、$\qq''$ 对应——这是把「赫克修正」与「希格斯场」接起来的技术核心。
3. **§4.5.5 + §5.3 的谱曲线逐层 $U(1)$ 图景**：在无分歧点附近把 $U(N)$ 规范理论局部看成 $U(1)^N$，赫克修正逐层是 $\L\to\L\otimes\O(\qq_i)^{m_i}$；$N!/\#\Gamma$ 个修正正是谱覆盖上 $\qq_i$ 的排序数，说明「逐层 $U(1)$」不只是直观图景而是精确对应。
4. **§5 的经济性**：仅用「赫克修正保特征多项式」就把磁本征膜的支撑限制在希钦纤维上，再把 $\bf F$ 型膜等同于平移本征丛，最后只需比较本征值 $\oplus_i\mathcal N_i$——推理链条极短，却把 §4 的构造整体搬到对偶侧。

## 术语观察

- **赫克修正 vs 赫克变换**：译文稳定区分 modification（对丛/对象作修正）与 transformation（映射/算符作用），§4.3 中两者交替出现而不混同，值得保持。
- **微小权 / 微小表示**（minuscule weight / representation）：全文判据用法一致（权构成单个外尔轨道）；$SU(2)$ 只有二维、$SO(3)$ 无、$U(N)$ 至多两值。
- **本征膜 / 电本征膜 / 磁本征膜 / $\bf F$ 型膜**：eigenbrane 系列译名统一；$\bf F$ 型膜特指支撑在希钦纤维 $\FF$ 上、带平坦陈–帕顿丛者。
- **「本征值」是空间不是数**：$L\B=\B\otimes V$ 中 $V$ 是向量空间，§5.3 又强调平移本征丛的本征值是一维空间的非零元；阅读时须记住这一约定，否则会把 $\oplus_i\mathcal N_i$ 误解为数。
- **单极子冒泡 / 舒伯特胞腔 / 舒伯特闭链 / 扩展博戈莫尔尼方程 / 陈–帕顿丛**：均为既有统一译名，与 `索引术语.tsv` 一致。
- **「伴随丛」**：用于 associated bundle，与 adjoint 语境同形（adjoint bundle/adjoint-valued），是本项目全局惯例，易混但未改。
- **$\mathrm{Spin}^c$**：正文排成 $\mathrm{Spin}_c$（下标），与原文上标不符，属排版层面的记号问题（已登记 issues）。

- 记号一物二名：同一希钦纤维在 §5.2/§5.4 作 $\FF$、在 §5.3 作 $\cF$（英文原文一律 $F$）；涉及公式符号，未改，待项目统一。
