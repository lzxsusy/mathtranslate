# ch01 读书记（part1：§1、§2.1–§2.6.3）

## 一、结构梳理

1. **§1 引言**：交代全书路线——本文只在「无分歧」情形讨论，目标是把 KW 的几何朗兰兹解释中的「磁本征膜」讲清楚；点出紧致化、拓扑扭曲、S-对偶三件套。
2. **§2.1 预备知识**：先用「$2+2=4$」说明为什么必须从四维 $\N=4$ 超杨-米尔斯出发（$d$ 维 QFT 对 $(d-2)$ 维流形给范畴），再把经典真空空间认成希格斯丛的超凯勒模空间 $\MH$，$\sigma$-模型靶空间取 $\CW=T^*\Y$ 并模去 $\G$，必要时再模去不稳定的点（Atiyah–Bott 型叠）。
3. **§2.2 希钦方程**：给出两套等价写法 (2.1)(2.2)；前者以 $G_\C$ 规范变换商掉平坦性，后者以 $G$ 规范变换商掉矩映射方程 $D\star\phi=0$。由此得到复结构 $I,J$；再经超凯勒商 $\CW///\G$ 得到 $\MH$，且只保留复结构 $I$，于是只剩全纯辛结构 $\Omega_I$。
4. **§2.3 $\MH$ 与余切丛**：稳定希格斯丛的模空间包含 $T^*\M$（$\M$ 为稳定 $G$-丛模空间）作为稠密开子集，$\Omega_I$ 在其上限制为自然辛结构；$T^*\M$ 在 $I$ 中全纯、在 $J,K$ 中不全纯但对三个辛形式拉格朗日。
5. **§2.4 希钦纤维化**：$\MH\to{\cal V}$，${\cal V}=\oplus_iH^0(C,K^{d_i})$，$\dim{\cal V}=(g-1)\dim G=\frac12\dim\MH$，故 $\ppi$ 满射、纤维是半维数的。
6. **§2.5 完全可积性**：$\MH$ 在 $I$ 中是完全可积哈密顿系统；用 $\CW$ 上 $\Omega_I$ 的泊松结构证明 $H_a=\int\alpha_a\Tr\varphi^2$（及一般 $H_{a,i}=\int\alpha_{a,i}{\cal P}_i(\varphi)$）两两对易，纤维是复环面（拉格朗日子流形）。
7. **§2.6.1 谱曲线**：把本征值方程 $\det(y-\varphi)=0$ 的根扫成 $C$ 的 $N$ 重覆盖 $\psi:D\to C$；分支点即判别式零点（分歧点整体构成分歧除子 $\cal R$）；本征线丛 ${\cal N}$（核）与余核线丛 ${\cal L}$ 在分歧点处仍可延拓，得到 ${\cal L}\cong{\cal N}({\cal R})$ 与 ${\cal L}\cong{\cal N}\otimes\psi^*(K^{N-1})$。
8. **§2.6.2 阿贝尔化**：$E$ 与 $\varphi$ 都能从 $D$ 上的线丛 $\cal L$ 推前回来：$E=\psi_*({\cal L})$、$\varphi=\psi_*(y)$；$D$ 的雅可比簇（Prym 型）作用在 $\MH$ 的纤维上。
9. **§2.6.3 会出现哪些线丛？**：确定 $\cal L$ 的次数 $c_0=N(N-1)(g_C-1)$，于是 $\mathrm{Pic}_{c_0}(D)\to\mathrm{Jac}(C)$，$\Lambda({\cal L})=\det\psi_*({\cal L})$，核 $\FF_{SU(N)}=\Lambda^{-1}({\cal O})$；最后用 $K^{1/2}$ 选特选点以消去基点依赖，并讨论奇/偶 $N$ 的差别。

## 二、跳跃处（3–5 处）

1. **§2.1 的「$2+2=4$」跳步**：正文从「$d$ 维 QFT 给 $(d-2)$ 维流形一个范畴」直接跳到「必须从 $2+2=4$ 维出发」，没有解释为什么恰是 $d-2$ 而非 $d-1$、边界条件范畴为何是范畴、以及为何要在二维 $C$ 上得到范畴（脚注只给 [14][15][16] 三篇文献）。→ 已加译注①（落点 L21）。
2. **§2.2 由 (2.1) 到 (2.2) 的等价性**：正文说两套方程等价、且分别给出复结构 $I$、$J$，但没写出 $A+i\phi$ 与 $F=dA+A\wedge A$ 如何把 (2.1) 变成 $\F=0$ 与 $D\star\phi=0$，也没说清「两个复结构」在 $\CW$ 的哪个层面同一。→ 译注④（L35）+ 译注⑤（L49）在两侧补了等价链条与「$J$ 来自平坦联络、$I$ 来自希格斯丛」的非阿贝尔 Hodge 对应背景。
3. **§2.4 满射性论证**：`3g-3` 个未知量、`3g-3` 个方程、一般解数 $2^{3g-3}$——这是 Bézout 式计数，并不是严格证明；正文没说明它在何种意义下成立、纤维实际是什么。→ 译注⑩（L106）指出这是启发式计数，只保证一般点纤维有限、映射满射，真正的纤维结构留到 §2.5。
4. **§2.6.1 分歧点处的延拓**：先用 $SU(2)$ 局部模型 (2.11)–(2.14) 把 $y^2=z$ 与 $s=(y,1)^T$ 算清楚，然后直接断言 (2.21)(2.22)（${\cal L}\cong{\cal N}({\cal R})$、${\cal L}\cong{\cal N}\otimes\psi^*(K^{N-1})$），中间「为什么 $\PP'(y)$ 的零点恰好就是分歧点、次数为什么是 $N-1$」需要读者自算。→ 译注⑬（L232）补了 $\PP'(y)$ 的次数与零点除子的对应。
5. **§2.6.3 末端选点**：从「核是复环面」跳到「取定 $K^{1/2}$ 的一支，使 $\FF_{SU(N)}$ 成为阿贝尔簇」，没有说明为什么必须选基点（阿贝尔簇需要原点）、也没有说明为什么奇 $N$ 与偶 $N$ 的差别只在 $K^{1/2}$ 的两支（[23]）。→ 译注⑮（L338）补了 $K^{1/2}$ 的选择与二阶平坦线丛。

## 三、精彩处（2–3 处）

1. **(2.3)(2.4) 的无限维—有限维桥接**：$\CW$ 是无限维超凯勒流形，用 $\G$ 的超凯勒商 $\CW///\G$ 得到有限维的 $\MH$；而 (2.4) 的 $\Omega_I=\frac{1}{\pi}\int\Tr\delta\phi_z\wedge\delta A_{\bar z}$ 只用 $A$ 与 $\phi$ 的一次项，就把辛结构写成了可计算的形式，并且同一支 $\Omega_I$ 既是全纯辛形式、又定义 K 型 A-模型。技术理由：这样把「几何量子化/$\sigma$-模型」级别的对象替换成了有限维模空间上的显式辛形式。
2. **(2.11)–(2.14) 的局部模型**：分支点处 $\Tr\varphi^2$ 有单零点，$2\times 2$ 矩阵 $\varphi\sim\begin{pmatrix}0&z\\1&0\end{pmatrix}$ 使 $y^2=z$，于是 $y$ 反而成了 $D$ 的局部坐标——「本征值不可对角化」的麻烦被一个坐标变换抹平，核丛 ${\cal N}$ 与截面 $s=(y,1)^T$ 一次算清。技术理由：这是全篇唯一把「谱曲线在分歧点处的定义」真正算出来的地方，后文 (2.15)–(2.20) 的余核丛 $\cal L$ 都靠它。
3. **§2.6.3 的自问自答**：先问「会出现哪些线丛？」，然后依次给出次数 $c_0$、$\mathrm{Pic}_{c_0}(D)\to\mathrm{Jac}(C)$、$\Lambda=\det\psi_*$、$\FF=\Lambda^{-1}({\cal O})$、$K^{1/2}$ 选点，把谱曲线、Prym 簇、't Hooft 通量三件事串在同一条线上。技术理由：$c_0$ 与 $\Lambda$ 的写法让后文 §5 的平移（'t Hooft 算符作用）成为 $\mathrm{Jac}(C)$ 上的平移，是全书几何朗兰兹论证的算术核心。

## 四、术语观察

- **本征值 / 特征多项式**：译稿严格分工——「本征值」指 $\varphi$ 的线性代数本征值（元素 $y$），「特征多项式」指 $\det(y-\varphi)$；$\PP(y)$ 与 $\chi$ 的用法由此自洽。
- **单值变换 = monodromy**：术语表既定译法，与「单值化」不同；本轮只把一译多名的「单形式」改成了「1-形式」，避免「单」字歧义。
- **分歧点 vs 分支点**：正文严格区分——分支点（branch point）指覆盖 $\psi:D\to C$ 的支点（即 $\Tr\varphi^2$ 或 $\Delta$ 的零点），分歧点（ramification point）指 $\psi$ 上对应的点；分歧除子 $\cal R$ 是后者在 $D$ 上的除子。
- **谱覆盖 spectral cover**、**推前 pushforward**、**叠 stack**、**本征膜 eigenbrane**、**超凯勒商 hyper-Kähler quotient**：译法与术语表一致。
- **「固有性」（properness）**：译者在 L129 加引号并括注「纤维的紧致性」，通俗可解，但中文教材里不常用；若全书统一，可在附录术语表补条。

## 五、遗留疑点

1. **原文三处笔误**：L51「$K$ 是 $E$ 的典范丛」（应为 $C$）、L69「$\Sigma$ 的完整超凯勒结构」（应为 $M_H$）、L92「$(w_2,\dots,w_n)$」（应为 $w_N$）——译文照译，未改，建议在附录 A 统一出校记（详见 `ch01_issues.md` 第二节）。
2. **$2^{3g-3}$ 的严格性**：原文 §2.4 末的计数是启发式的，译注⑩已说明；若后续 part 用到「满射」的严格证明，需回引 Hitchin / Ngô 的文献。
3. **偶 $N$ 时 $K^{1/2}$ 特选点的二义性**：原文只提到「偶 $N$ 情形有差别」，最终如何被 't Hooft 通量消解在 part2/part3，part1 无法收口。
4. **「单值变换」与「1-形式」**：part1 内的「单」字歧义已消除（改「单形式」为「1-形式」），但全书其他 part 仍有「一形式/1-形式」混用（part2 各 5/4 处），留给 lead 统一。
