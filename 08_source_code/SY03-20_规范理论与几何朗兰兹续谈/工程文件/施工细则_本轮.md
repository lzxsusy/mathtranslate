## 2 校对判据（只改真错）

**P1 必须改**：译反（肯定↔否定）；丢限定词（only/never/any/equivalent/precisely/assume/not necessarily 等）；
蕴含译成并列；公式符号/上下标/指标错；整句漏译；原文所无的整句增译；交叉引用错（\ref 指错）。
**P2 必须改**：同一术语一译多名（以 `索引术语.tsv` 与 termbase 为准）；同构/等价混用；引用编号不一致；
数字或量纲错；专名错（人名、群名、定理名）。
**不许动**：文风、断句、语气；作者原注的措辞；译者对原文笔误的既有处理（只在报告标「原文疑误/译者补正」）；
公式的排版美化；与原文语义一致但用词不同的改法。
**存疑不硬改**：判不准的写进 `校对记录/ch0N_issues.md` 的「存疑」区，并在 tex 对应句后加译注说明分歧
（若该处理更有助于读者），禁止凭记忆改。

## 3 译注要求（本轮的增值重点）

篇数：part1 12–15 条，part2 10–13 条，part3 14–17 条，part4 10–13 条。宁少而实，不凑数。
每条必须通过**五判据**：

1. **有来源**：末句带 `[来源：…]` 或 `[译者按（无外部依据）：…]`。
   - `[来源：nLab "Hitchin fibration"，https://ncatlab.org/nlab/show/Hitchin+fibration（Last revised 2024-05-12；2026-11-19 访问）；并见 Hitchin 1987, Proc. LMS 55, §2。]`
   - `[来源：[KW]（arXiv:hep-th/0604151）§3.2；原文 §4.3；2026-11-19 核对。]`
   - `[来源：本库 datasets/glc 卡 glc/concept/xxx；已回核 [原文 §2.4]。]`（I 级，必须回核 A/B）
   - 只有确实查不到时用 `[译者按（上下文推断，无外部依据）：…]`，且不得把推断说成事实。
2. **有增量**：必须含一个原文/译文没有的信息点（为什么、依据、量级、反例、指代落点）。删掉后读者无损失的
   = 复述，不算。
3. **术语类**：说清此处是哪个义项 + 与相邻术语的差别（如 Hitchin fibration 的 fiber 是阿贝尔簇而非环面；
   spectral curve 与 cameral cover 的区别）。
4. **指代/依赖**：写明确落点（原文 §N、式 (N)、定理/引理名），不许「见前文」「如前所述」。
5. **疑误**：先判定再落笔；判不了标「疑」，禁编造页码/定理号/访问日期。

**来源等级**：A = 原始论文/专著/作者他文（可作硬依据）；B = nLab、Stacks Project、EMS、DLMF、正式综述讲义
（须与 A 交叉，单独 B 标「待核」）；I = 本库资料卡/术语表（须回核）；**黑名单**：知乎、百度百科/知道、CSDN、
简书、公众号、B 站、个人博客、笔记类课程站、AI 摘要——不看、不引、不缓存。英文维基、MathOverflow 只能找线索，不得引用。
**禁止**照抄 nLab/维基句子；禁止编造 URL 与日期；web_fetch 未 200 的链接不写。

**译注位置与写法**：紧跟在被注句/词之后，`\transnote{…}`；正文中文用全角标点；译注内可用 `\textbf{}`、
`\emph{}`、数学 `$...$`，不得含裸 `%`、不得嵌套 `\footnote`。示例：

> 希钦纤维化的每条纤维是一个阿贝尔簇\transnote{原文此处说「a torus」，但纤维只在一般点上是环面；在奇异纤维上它是仿射阿贝尔簇的分支……[来源：[原文 §2.4] 与 Hitchin 1987 §6；2026-11-19 核对。]}。

**去重**：基础概念（希格斯丛、希钦方程、超凯勒、稳定/半稳定）由 part1 负责注；part2–4 只在
「此处用法与基础定义有出入」时才注，并在译注里引原文节号。各 part 主题分配：
- part1：紧致化与范畴化、拓扑扭曲（部分拓扑场论）、希格斯丛/希钦方程、复结构 I/J/K、超凯勒商、
  半稳定性与 Hitchin 定理、完全可积性、谱曲线与阿贝尔化、Prym 簇。
- part2：K 理论与 D-膜荷、PSU(N) 与 't Hooft flux、特选截面（distinguished section）、对偶环面（GNO 对偶）、
  拓扑观点与 $F_{SU(N)}$、辛形式的归一化、其他群的谱覆盖（cameral cover）。
- part3：本征膜、电本征膜（Wilson 线）、't Hooft 算符与 Hecke 修正、微小表示与权、U(1)/U(2)/SO(3)/PSU(N)
  例子、纳入希格斯场、磁本征膜、平移本征丛、$\mathfrak bF$ 型膜。
- part4：行列式线丛与配对（Pfaffian/theta）、Gerbe、Hitchin 纤维对偶、Hecke 本征值的计算（阿贝尔/非阿贝尔）、
  「解释」小节里的物理含义。

## 4 术语纪律

- 以译稿现有译法为准（`索引术语.tsv`），不得自造新译名；发现一译多名 → 报告 + 统一为既有高频译法。
- 首次出现的外文术语，若正文未给英文，可在译注中给「中文（English）」。
- 人名/群名按译稿既有写法（Witten=威滕？检查译稿实际用法并统一，报告里写明）。

## 5 技术规范

- 只改自己那一个 part 文件；不要碰 `main.tex`、`preamble.tex`、其他 part、附录（附录由 lead 统一生成）。
- 改完运行：`python 工程文件/tools/check_part.py 源码/partN_zh.tex`（检查花括号/$/环境配对、`%`、UTF-8）。
  **不要**运行 xelatex（lead 统一编译，避免并发冲突）。
- 文件是 UTF-8 无 BOM、LF；编辑用 write/edit 工具，保持缩进与空行风格。
- 不要新增 `\label`，不要改已有 `\label`；引用用 `\ref{}`/`\cite{}` 原样。
- 译注不要放在公式环境内部；不要放在 `\section` 标题里。

1. `源码/partN_zh.tex`：改好的正文 + 全部 `\transnote{…}`。

3. `校对记录/ch0N_读书记.md`：该部分结构梳理（5–10 行）、3–5 处「跳跃处」（作者省略了什么，在哪）、
   2–3 处「精彩处」（为什么这一步妙，给出技术理由）、术语观察、遗留疑点。
