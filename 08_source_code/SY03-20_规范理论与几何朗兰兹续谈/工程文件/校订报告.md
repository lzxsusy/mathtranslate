## 1 做法

1. **先通读后落笔**：通读全部 79 页原文与 62 页译文，产出 `通读笔记.md`（一页定位、逐节结构地图、逻辑链八步、十处跳跃、六处精彩处、术语观察）与 `疑点清单.tsv`（10 行，含已解 3 条）。原文 PDF 印刷页 = PDF 页 − 1，全文按印刷页锚对齐。
2. **一人一章、写作用域互斥**：四位校订译手分别负责 §1–2.6.3 / §2.6.4–3.4.1 / §4–5 / §6–7，各自只改自己那个 `partN_zh.tex`，逐段对照 `原文/EN_partN.txt`（带 `[[PDF p.N | printed p.M]]` 锚）与 PDF 页图；改动与疑点各写分章报告。另设一名独立核验员交叉核对本库既有资料卡，一名资料卡编者据本文裁切新数据集。
3. **译注按三类写**：易错预警（符号/指标/约定）、含糊点拨（作者省略的论证）、背景直觉（来源与落点）。每条都回答一个原文没有的信息点，并给出 `[来源：…]`；术语类必答"此处哪个义项、与相邻术语差别"；指代与依赖写明落点（节号/式号/定理名）。
4. **原文疑误不改**：与原文逐字一致而数学上可疑处，一律保留译文原样、只在分章报告登记；特别影响阅读的 3 处另加译注说明（见 §4）。

## 4 原文疑误（保留原文，只登记）
