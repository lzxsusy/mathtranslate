Unicode 数据资源说明
====================

本目录中的数据文件均保持原始文本内容. 工具只读取这些本地资源，
不会在构建过程中连接外部网站.

resources/cmaps/Adobe-GB1-UCS2
    Adobe GB1 至 Unicode 映射，版本 9.000.
    原文件头完整包含 Adobe 的版权声明、再分发条件和免责声明.

resources/glyphlist/glyphlist.txt
    Adobe Glyph List 2.0.
    原文件头标明 Apache License 2.0；完整许可文本附于
    licenses/Apache-2.0.txt.
    上游项目：https://github.com/adobe-type-tools/agl-aglfn

resources/glyphlist/pdfglyphlist.txt
    根据 Adobe Glyph List 2.0 与 PDF 1.5 参考资料编制的字符表.
    原文件头说明已完整保留.

resources/glyphlist/texglyphlist.txt
    lcdf-typetools 的 TeX 字形映射扩展，文件标注版本 2.95.
    lcdf-typetools 上游的原始 COPYING 附于
    licenses/lcdf-typetools-COPYING.
    上游项目：https://github.com/kohler/lcdf-typetools

Python 依赖仅以 requirements.txt 列出，不在本包中分发其运行库.
