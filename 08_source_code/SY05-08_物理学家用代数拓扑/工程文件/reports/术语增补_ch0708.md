## 需主审统一的用词（本译者已按此执行）
1. **转移函数 vs 粘贴函数**：$g_{ij}(x)$ 统一作「粘贴函数」（Čech 语境）；丛论语境出现「转移函数」时也不改，二者同指，建议术语表只收「粘贴函数」。
2. **上边缘**（不写「边界」）：与同调的「边缘」一致，避免与拓扑边界混淆。
3. **整 Stiefel--Whitney 类** $W_3$：原文 “integral third Stiefel–Whitney class”，译「整第 3 Stiefel--Whitney 类」，简称「整 Stiefel--Whitney 类」。
4. **二次精化**：原文 “quadratic refinement”，首次出现括注英文；不用「二次细化」。
