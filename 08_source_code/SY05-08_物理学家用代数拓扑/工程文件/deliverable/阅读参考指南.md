# 阅读参考指南

《物理学家用代数拓扑》（立川裕二）中文译注本使用说明与阅读路线建议。

---

## 一、这是一本什么样的书

- **性质**：东京大学 IPMU 研究生课程「数理物理学」的讲义，分两个学期：Part I（第 1–8 章）是完整一学期的材料，Part II（第 9–13 章）是第二学期的补充材料。
- **目标读者**：理论物理（尤其凝聚态、高能、弦论）方向的研究生与研究者，而不是数学系学生。作者在 §1.3 明说：数学对他而言像「一堆有用的 app」，本课程讲「有哪些 app、怎么用」，**不深入源码**（不逐条证明）。
- **写作风格**：口语化、跳跃、常有「这一点我课上不讲」的旁白；部分段落（标为 Aside 的附注节）可以整段跳过而不影响后面。
- **重要提醒**：作者在「致谢与免责声明」中声明，讲义内容远多于课上所讲，且许多数学与物理事实不加解释地给出；**读不懂某一段是正常的**，不必从头死磕。原书也不是严格教材：定义、命题的严格程度参差，个别地方有笔误（本译本已登记，见 `README.md` 第五节）。

## 三、三条阅读路线

### 路线 A：物理动机优先（拓扑绝缘体 / SPT / 反常）

ch1 → ch2 → ch3 → ch4（重点 §4.3–4.5）→ ch6（重点 §6.6）→ ch7 → ch9 → ch10 → ch11 → ch12 → ch13（重点 §13.3、§13.5）

这条路线基本是作者第一学期的顺序加上第二学期前半。ch5 可在读到 ch8（Maxwell 场、Chern–Simons）时再补。

### 路线 B：数学基础优先（补拓扑与同调）

ch1 → ch2 → ch4 → ch5 → ch6 → ch7 → ch13 → 回 ch9–ch12

先建立同伦/同调/示性类的语言，再看物理应用；ch10 的两张表等用到再查。

### 路线 C：速成（只为读懂「反常分类 = 配边/上同调」的文献）

ch1（§1.2）→ ch4（§4.1、§4.3、§4.5）→ ch6（§6.6）→ ch7（§7.5）→ ch9（§9.3–9.4）→ ch11（§11.2）→ ch12（§12.3）→ ch13（§13.3）

跳过所有关于具体计算的细节，只抓「哪个不变量分类什么相」的主线。

## 四、原书体例与本译本的对应

1. **编号陈述只在 Part I**：定义/例/定理等编号（如 `Definition 2.1.`）集中在第 1–8 章，共 277 个；Part II 是散文体，没有编号陈述，只有行内粗体小标题。读 Part II 时不必找「定理」，作者是边讲边推。
2. **Asides（附注）**：标为 "Aside" 的小节是作者插入的闲谈（如 §1.4「无用数学分支的罕见用处」、§2.6–2.7 流形趣闻），可整段跳过；本译本保留其标题与位置。
3. **灰底方框**：陈述环境在原书中是灰底方框，本译本保留该视觉提示。
4. **手绘图**：原书所有插图都是作者 iPad 手绘，本译本按原图裁切（未重绘），图注末尾标注原书页码。
5. **公式编号**：原书公式编号形如 `(2.1)`，本译本手工照抄，正文引用写「式 (2.1)」。
6. **参考文献**：原书用字母缩写键（`[Kit09]`、`[TK82]`、`[三24]` 等），本译本照录不译；正文中引用一律以纯文本键出现。
7. **本译本的页锚点**：源码中每页起始有 `% [原文 p.N]`；成品 PDF 中的页码是译本页码，引用原文请以正文里「（原书 p.N）」标注为准。
8. **译注批注**：以源码注释形式存在，不在成品 PDF 中显示；汇总见 `deliverable/译注汇总.md`，按章节与原书页码排列，读某段卡住时可去查对应页有没有批注。

## 五、常见卡点与建议

- **$\pi_n(S^m)$ 的计算（§4.3）**：作者只给事实与大表（表 1），不证明。物理读者记住「$\pi_n(S^n)=\Z$、$\pi_3(S^2)=\Z$、$\pi_4(S^3)=\Z_2$、稳定区有周期性」即可，细节用到再查。
- **纤维丛同伦群长正合列（§4.4）**：这是全书使用频率最高的工具，建议把 $\pi_n(F)\to\pi_n(E)\to\pi_n(B)\to\pi_{n-1}(F)$ 的箭头方向手写一遍，再对照 §4.5–4.6 的例子。
- **定向、spin 与 pin 结构（§3.6、§10.4）**：概念密集但结论简单——「$w_1=0$ 可定向、$w_2=0$ 有 spin、$w_1^2+w_2=0$ 有 pin$^-$」。bordism 与 fermion 的 8-周期性都建立在它上面。
- **K 理论与十重分类（§11.5–11.6）**：不必先学 K 理论，可先接受表 9（周期表）再回头看 $K$/$KO$ 的定义；表 7/表 8 是 $K$/$KO$ 的具体化，当字典用。
- **eta 不变量（§12.1）**：这是全书最技术的一段（APS 指标定理、谱流）。若目标只是「知道相互作用相由配边群分类」，可先读 §12.2–12.4，再回 §12.1。
- **谱序列（§13.4）**：AHLS 谱序列在本讲义里只作计算工具使用，作者没有系统讲谱序列；没有谱序列基础的读者可先接受「$E_2$ 页、微分 $d_r$、收敛」的用法，再补教材。

## 六、延伸阅读（按用途）

- **代数拓扑系统教材**：Hatcher《Algebraic Topology》（原书参考文献中的主要来源之一）；Milnor–Stasheff（示性类）。
- **物理侧**：Kitaev 关于拓扑相的综述与 2015 年后的 SPT 文献（原书 ch9–ch13 引用的 [Kit09]、[KTTW14]、[FH16] 等）；von Klitzing 的量子霍尔综述（原书图 8.2 出处）。
- **数学物理**：Nakahara《Geometry, Topology and Physics》可与本书第 2、3、5 章对读；作者自己的相关讲义与论文见原书参考文献。
- **原书引用**：所有条目见译本「参考文献」部分，键与原书一致，可直接按键检索原文。
