# 整书（3 pass，含目录与页码稳定）

编译日志判据（`build.ps1` 从 `src/main.log` 解析）：

- `Overfull \hbox/\vbox` 尽量为 0（大表可用 `\small`/`\resizebox` 处理）

## 四、译校体例

1. **陈述环境**：编号照抄原文（`\begin{definition}{2.1}`），环境名译为「定义/例/定理/引理/命题/推论/注/……」，与原文一一对应；原书放进灰底方框的陈述用灰底框排版；原书**无框**的 Remark 与讨论段（原文以右下角 ⌟ 收束）译为普通段落，段末以 ⌟ 标记，不做灰底，全书共 17 处。
2. **公式**：原书公式有编号（`(2.1)` 形），本译本用 `\begin{equation}…\tag{2.1}\end{equation}` 手工编号，正文引用统一带「式」字，作「式 (2.1)」；在「条件」「定理」「这两个操作」等名词性同位语与连续编号续引（如「(5.24)、(5.25)」）处仍作裸引用，以免粘成「条件式」。未编号公式照原文不编号。
3. **图**：原书手绘图按 300 dpi 裁切为 PNG（`src/figures/`），题注译为「图 X.Y：……」并保留原编号；图中手写标注不重绘、不改动。
4. **表**：原书排版表格用 `tabular`/`booktabs` 重排（不裁图），保留表号与表注。
5. **术语**：以 `deliverable/术语对照表.tsv` 为唯一依据（672 条），原则见该表表头；人名一律保留拉丁原文不音译；术语在正文、术语附录两处同步。
6. **批注**：以源码注释形式写在页锚点附近，共三类（易错预警、含糊处点拨、背景直觉），编译时不显示；汇总见 `deliverable/译注汇总.md`。每千汉字不超过 1 条，批注只给具体信息，不写空泛评语。
7. **中文文风**：全角标点；英文术语、数字与汉字之间留半角空格；避免「进行……的」「被……所……」等翻译腔；单句一般不超过 60–70 字；原文的口语旁白保持讲课语气。
8. **原文笔误**：不作数学改动，正文按最合理读法翻译，另在源码批注与下表登记。

## 七、已知偏差与限制

1. 原书是讲义而非教科书，作者本人声明「内容远多于课上所讲」，且明言其中数学陈述未必严格；本译本忠实翻译，不补充证明，也不修正作者有意为之的简略。
2. 原书手绘图的笔迹、箭头与手写标注不作重绘；个别图在裁切时保留了原页面的一段留白（为不切掉手写标注），阅读效果与原书一致。
3. 原书文字层存在跨行连字符粘连与上下标错序，本译本所有公式、定义与编号均回页图逐字核对；因此极少数页面在原文本身含混处，译文按最合理读法给出并在批注中标明。
4. 参考文献按原文自动转录、未逐条与出版信息核对，条目格式保持原文样式，不补 DOI、不统一缩写。
5. 原书部分引用键（如 `[三24]`、`[日07]`）为日文文献，保留原键与原题，未译。
6. 译本页边距、字号、章节样式按中文学术译注本惯例重排，不追求与原书版面一致；原书的灰底陈述框与粗体小节标题保留。
