  - 定理 3：$\mathrm{char}\,k>2$ 时 $\check G^{\mathrm{geo}}$ 连通；非 $A_{2n}(n\ge2)$/$B_3$ 时 $=\check G^{\mathrm{Aut}^\dagger(\check G),\circ}$；$A_{2n}$ 时 $=\check G$；$B_3$ 且 $\mathrm{char}>3$ 时 $=G_2$。
  - 猜想 2.14：$\varphi$ 与 Frenkel–Gross 连接 $\nabla^{^L G}(\check X_0,\dots,\check X_{r_\sigma})$ 之间的对应。
