## 一句话主旨

对任意分裂约化群 $\check G$，用 Gross–Reeder 的仿射一般特征 $\varphi$ 在 $\mathrm{Bun}_G(0,2)$ 上造一个显式的自守层 $A_\varphi$，证明它是 Hecke 特征层，其特征值 $\mathrm{Kl}_{\check G}(\varphi)$ 就是 Deligne 的经典 Kloosterman 层在一般约化群上的推广；再算清它在 $0,\infty$ 处的单值性（Coxeter 元、野惯性映满 $\check T(\zeta)$、break 全为 $1/h$）与整体几何单值群（基本是 $\check G^{\mathrm{Aut}^\dagger(\check G),\circ}$），并给出上同调刚性与 Swan 导子公式。

## 五步逻辑链

1. **结构群与局部化**（§1）：在 $\mathbb P^1$ 上引入群概形 $\mathbb G(m_0,m_\infty)$ 与层级 $I(0)\supset I(1)\supset I(2)$，$I(1)/I(2)\cong\mathbb A^n$；命题 1.1（每个 $G$-丛可约化到 $T$）保证 $\mathrm{Gr}_{G,x}\to\mathrm{Bun}_G$ 局部有截面，从而一切都在「大胞腔」$j_0:I(1)/I(2)\hookrightarrow\mathrm{Bun}_{G(0,2)}$ 上算。
2. **造层**（§2.1–2.2）：$A_\varphi:=j_{0,!}\mathrm{AS}_\psi$ 按分支 $\gamma\in\Omega$ 平移；引理 2.3 的 clean 性（$j_!=j_*$）使 $A_\varphi$ 同时是 $!$ 与 $*$ 扩张，这是它能作 Hecke 特征层的根。
3. **验证特征性**（§4）：$\mathrm{Hk}_V(A_\varphi)$ 反常（注 4.1–4.2）→ 分支间用不同点 Hecke 算子的交换性拉平 → 用 $V\otimes V^*\to\mathbf 1$ 证局部常值 → 得 $\check G$-局部系统 $\mathrm{Kl}_{\check G}(\varphi)$。
4. **算单值**（§5–§6）：$0$ 处的单值用 Görtz–Haines 的 $\Psi(\mathrm{IC}_\mu)$ 滤链 + 长度 $>0$ 的算子为零，得主幂幺元（定理 1(2)）；$\infty$ 处用 $\chi_c$ 的显式计算（定理 4：$\mathrm{Gr}_{\theta^\vee}$ 与 $\mathrm{Gr}_{\gamma^\vee}$ 的轨道分解）得 Swan 导子 $=r(\check G)$（定理 2）；整体几何单值群用 Gross 的命题 6.8（排除落在主 $PGL_2$）加 Dynkin 分类逐个型判定（定理 3）。
5. **函子性与猜想**（§7）：物理刚性、由局部单值性反推 $\varphi$、表 1 同一行不同群之间的 pushout；quasi-split 情形的预测。

## 已知坑

1. **$\check G$ 与 $G$**：原文 $G$ 在许多地方指「常数群概形 $\mathbb P^1\times G$」，扭群概形另有记号。抽文本二者不分，必须回页面图。
2. **$\theta$ 与 $\theta^\vee$**：$\theta$ 是最高根（长根），$\theta^\vee$ 是短余根；$V_{\theta^\vee}$ 是拟极小表示。§5.5 又引入短支配根 $\gamma$ 与其长余根 $\gamma^\vee$，三套记号不可混。
3. **公式缺号**：§5 的 (5.16)(5.19) 等不存在，是定理类占号所致。
4. **表 1、表 2** 是纯文本表，需重排为 booktabs 表格，列宽可能溢出，用 `\small` + `tabularx`。
5. **参考文献 [20][21][36]** 是预印本，无出版信息，照抄不补。
6. **p.57–58 是 arXiv 自动目录页**，不译，也不计入页数对账。
