# 朗兰兹纲领与共形场论讲义——中文译注本与读书笔记（工程说明）

本目录是对 Edward Frenkel 讲义 *Lectures on the Langlands Program and Conformal Field Theory*
（arXiv:hep-th/0512172v1，2005 年 12 月 15 日）的中文译注工程，包含**三件交付物**：

| 交付物 | 文件 | 规模 |
| --- | --- | --- |
| 中文译注本（全文翻译 + nLab 批注） | `成品/朗兰兹纲领与共形场论讲义_中文译注本.pdf` | 126 页，含 47 条译注 |
| 读书笔记（独立成册） | `成品/朗兰兹纲领与共形场论讲义_读书笔记.pdf` | 68 页，约 5.4 万汉字 |
| 工程文件（源码、术语表、QA 报告） | 本目录 | 见下 |

---

## 一、底本与来源

- **底本**：arXiv e-print（`https://arxiv.org/e-print/hep-th/0512172`，实为 gzip 压缩的单个
  `houches.tex`，9,222 行，467,679 字节）。解压后存于 `work/houches.tex`。
  正文、公式、编号、脚注、参考文献、`\index` 条目全部依据这份源码，而不是从 PDF 反推。
- **原 PDF**（128 页）用于核对版面与公式图像：`originals_pkg/07_originals/…/arXiv_hep-th_0512172.pdf`
  （另见工作目录下的文本抽取件 `_orig_text.txt`）。
- **平行参照**：桌面上另有一份 2019 年前后的旧中译（86 页，`_zh_text.txt`），译笔很好但无源码；
  本工程以原文源码为准重译，旧译只作措辞与术语参照，凡与原文不符处均按原文处理，并在
  `reports/*_qa.md` 中记录。
- **补充参考**：Frenkel, *Langlands Correspondence for Loop Groups*（Cambridge, 2007）中译本
  （`数译发布/shuyi/translations/SY02-08/成品/`），用于核对 oper、中心、Wakimoto 等概念。

## 二、译注本的做法

1. **只译文字，不译数学**：所有公式、编号、`\label`/`\ref`/`\cite`/`\index`/`\footnote` 原样保留；
   交换图（原作用 `amscd` 排印）原样重排。公式编号 (1.1)–(9.22) 与原文一一对应。
2. **译注（nLab 批注）**：原文是给物理学家的综述，许多概念只使用不解释。凡属此类，插入
   `[译注 n.m]`（红色粗体标号、小号缩进块），说明**这个概念是怎么发生的**：谁在什么年份、
   什么语境下引入，原文默认知什么，以及它在本讲义其余章节的位置。共 **47 条**：

   | 位置 | 条数 | 主题举例 |
   | --- | --- | --- |
   | 引言 | 9 | 朗兰兹对偶群、S-对偶与 't Hooft 算符、函数域、本征层、D-模、共形块、临界水平、T-对偶、oper |
   | §1 | 7 | 绝对伽罗瓦群、阿代尔/受限直积、Frobenius 共轭类、ACFT 刚性化、K-有限与 Harish-Chandra 对、尖点条件、权为 2 |
   | §2 | 5 | 为什么只考虑曲线、ℓ-进而非复表示、球 Hecke 代数与 Satake、Chebotarev 与匹配、函子性与 L G |
   | §3 | 4 | 反常层为什么必须出场、Bun_n 模空间、Hecke 对应、为什么允许无界复形 |
   | §4 | 2 | Fourier–Mukai 变换、Laumon–Rothstein 谱分解 |
   | §5 | 2 | Satake 同构、仿射 Grassmannian 与几何 Satake |
   | §6 | 2 | 非阿贝尔 Fourier–Mukai 的两个障碍、D-膜与拓扑扭转 |
   | §7 | 3 | 手征代数/顶点代数、射影平坦联络、WZW D-模 |
   | §8 | 6 | Sugawara 构造、Feigin–Frenkel 中心、opers 与 Drinfeld–Sokolov、Wakimoto 模、Miura 变换、自由场实现 |
   | §9 | 7 | 局部化函子、Beilinson–Drinfeld 定理、Hitchin 系统、其他局部系统、分歧与惯性群、抛物 Bun_{G,y}、正则奇异 oper |

   素材来源：`notes/nlab/A_arithmetic_geometric.md`（25 个 nLab 条目，数论/几何侧）、
   `notes/nlab/B_cft_physics.md`（22 个条目，CFT/物理侧）、`notes/discussion.md`
   （互联网讨论与 2005 年后进展）。nLab 无独立条目者（Sugawara、h∨、临界水平、余不变量层、
   Feigin–Frenkel 中心、Miura、Wakimoto、自由场实现）已如实标注并给最接近的条目，不编造链接。
3. **前置页**：译本说明（底本、原则、译注体例、术语、17 处原文笔误表及补充说明）、阅读指南
   （数域/几何/共形场论三栏对照、两条阅读路径、前置知识）。
4. **后置页**：参考文献（英文照录 [1]–[119]）、索引（由正文 130 余条 `\index` 重新生成，
   页码对应本书）、术语表（英汉对照 261 条，`latex/front/terms.tex`）。

## 三、读书笔记

`latex/notes/{p1,p2,p3}.tex`，独立主文件 `latex/notes_main.tex`，与译本共用导言区。
三部分对应译本三部分，每部分含：**导读**（论证骨架）、**逐节疏解**（对应每一小节：动机、
定义的直觉、关键命题的证明思路、与前后文的关系、易卡处）、**难点与译注索引**（指向译文正文
的 `[译注 n.m]`）、**延伸阅读**。第三部分另有**全书总结**（三栏对照表）与**2005 年之后的进展**
（Kapustin–Witten 2007、Ngô 2008、Arinkin–Gaitsgory 2015、Gaitsgory 等 2024 年 C 上猜想的
证明、p-进与相对 Langlands 等，均标明核实程度）。

## 四、工程结构与编译

```
Frenkel_朗兰兹纲领与共形场论_译注/
├─ 成品/                   两个成品 PDF
├─ docs/
│  ├─ BRIEF.md              工程说明（分工、块清单、硬规矩）
│  ├─ STYLE.md              翻译体例（禁止项、标点、术语铁律、自检清单）
│  └─ TERMS.md              术语表源文件（261 条，三栏 Markdown）
├─ latex/
│  ├─ main.tex              译注本主文件
│  ├─ notes_main.tex        读书笔记主文件
│  ├─ preamble.tex          导言区（由 work/gen_preamble.py 生成后手工修补）
│  ├─ tex/e00…e09d.tex      17 个译文块（含译注）
│  ├─ tex/biblio.tex        参考文献
│  ├─ front/{matter,terms}.tex   译本说明+阅读指南、术语表
│  ├─ notes/{front,p1,p2,p3}.tex 读书笔记
│  ├─ en/e00…e09d.tex       英文原文块（工作副本，不编入成品）
│  └─ ref/e00…e09d.txt      旧中译对应页文本（措辞参照）
├─ notes/
│  ├─ nlab/A_arithmetic_geometric.md, B_cft_physics.md
│  └─ discussion.md         互联网讨论与后续进展调研
├─ reports/                 各块 QA 报告（17 份 + 译注分工报告）
├─ work/                    脚本与中间产物（见下）
└─ _orig_text.txt, _zh_text.txt   原文/旧译文本抽取
```

编译（Windows + MiKTeX，需 xelatex 与 makeindex）：

```powershell
$env:PATH = "<本地路径>;$env:PATH"
cd latex
latexmk -xelatex -interaction=nonstopmode main.tex         # 译注本
latexmk -xelatex -interaction=nonstopmode notes_main.tex   # 读书笔记
```

或 `powershell -File latex\build.ps1`。**判据**：日志无 `! `、出现 `Output written on …`。
latexmk 结尾的 `exit code 1` + “you have not checked for MiKTeX updates” 只是 MiKTeX 更新提醒，
不是编译失败。

## 五、质量保证

- **结构核对**（`work/qc_check.py`）：逐块比对中英两版的 `equation/align/CD/displaymath/cite/
  index/footnote/label/ref/subsection` 计数与段落数，并扫描疑似未译的英文长串。
- **数学保真核对**（`work/math_diff.py`）：按出现位置抽取全部展示级公式与行内公式；展示级公式
  要求逐段按序完全一致，行内公式按多重集比较。17 块全部通过（差异仅为译注新引入的记号、
  或中文代词省略造成的等价表述）。
- **逐块 QA 报告**：`reports/<id>_qa.md`，记录结构计数、公式核对结果、原文笔误清单。
- **原文笔误**：不径改，照录并在 `latex/front/matter.tex` 的笔误表中说明；译者新发现的笔误
  亦在表中「补充」段与各 QA 报告里记录。
- **索引与目录**：`\index` 重新生成（130 余条），页码为本书页码；目录条目由 `\section` 自动生成，
  已核对无重复。
- **编译自检**：两次全量重编均为 0 error、0 `Missing character`、0 undefined reference。

## 六、已知问题与后续可做

1. **索引条目为英文**：因为原文 `\index{…}` 的键是英文（如 `D-module`、`Hecke eigensheaf`）。
   若希望中文索引，可在 `latex/tex/*.tex` 中把 `\index` 键改成中文后重编。
2. **术语表 261 条**：只收录出现频率较高或易歧义者，不是穷尽索引。
3. **读书笔记的薄弱处**（作者自述）：§3.6–3.7 的六函子细节从简；§5.6 几何 Satake 只给证明
   路线；§6.1 一般群的「不可约」沿用原文的临时定义。
4. 若要把本书并入「数译发布」库，可复制到
   `数译发布/shuyi/translations/SY03-21/成品/`（该目录现只存旧译本，二者可并存）。

## 七、工具与脚本（work/）

| 脚本 | 作用 |
| --- | --- |
| `gen_preamble.py` | 从 `houches.tex` 导言区生成中文版 `latex/preamble.tex` |
| `split_chunks.py` | 按章节把源码切成 17 块，生成 `latex/en/*.tex` 与 `latex/ref/*.txt` |
| `fix_keys.py` | 归一化跨行的 `\label`/`\ref` 键 |
| `gen_terms.py` | 合并共享术语表与本书专用术语 → `docs/TERMS.md` |
| `gen_front.py` | 生成 `latex/tex/biblio.tex` 与 `latex/front/terms.tex` |
| `zhu_e00.py`, `zhu_geo.py`, `zhu_more.py`, `zhu_num2.py` | 各批译注的插入脚本（幂等，锚点唯一） |
| `qc_check.py`, `math_diff.py` | 结构与数学保真核对 |
| `render_book2.py` | 渲染指定页为 PNG 供目视检查 |

> 本工程全部文本文件为 UTF-8（无 BOM）。请勿用 PowerShell 的 `Get-Content`/`Set-Content`
> 编辑这些文件（会把中文写成乱码），一律用编辑器或 Python 的 `io.open(..., encoding="utf-8")`。
