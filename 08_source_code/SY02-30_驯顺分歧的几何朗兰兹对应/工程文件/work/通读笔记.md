## 一、三句话主旨

1. 把「非分歧几何 Langlands」的三条主干结论（紧生成、AB 等价、Bezrukavnikov 等价、FLE/IFLE）整体搬到**因子化**的框架里：不再只谈单点 $x$，而谈曲线 $X$ 上的 Ran 空间。
2. 为此先补一块地基：证明带 Iwahori 层级结构的 $\mathrm{D}\text{-}\mathrm{mod}(\mathrm{Bun}^I_G)$ 紧生成（第 2 章），再构造 $x_0$ 处的因子化模范畴并给出三对等价（第 3 章）。
3. 论文的贡献不在单点结论，而在「单点结论 $\Rightarrow$ 全曲线因子化结论」这一步的机械：可熔性（fusability）+ 保守性 + 逼近定理（Thm 3.1.5.2）。

### 2.1 第 1 章：为什么要紧生成

- 紧生成的两条用处：内部（紧对象之间的态射决定一切态射，式 (1.1.1)–(1.1.3)）、外部（连续函子由紧对象上的取值决定，$\mathrm{Functs}(\mathcal{C},\mathcal{D})=\mathrm{Fun}_{\mathrm{exact}}(\mathcal{C}^c,\mathcal{D})$）。
- 非分歧 GL 猜想 $\mathrm{D}\text{-}\mathrm{mod}(\mathrm{Bun}_G)\simeq\mathrm{IndCoh}_{\mathrm{Nilp}}(\mathrm{LocSys}_{\check G})$ 的右边先验紧生成 ⇒ 左边紧生成是必要条件。
- 证明路线（[GR24a]）：谱作用 + 真空 Poincaré 层给出 $\mathrm{QCoh}(\mathrm{LocSys}_{\check G})\to\mathrm{D}\text{-}\mathrm{mod}(\mathrm{Bun}_G)$，其连续右伴随 $L_{G,\mathrm{coarse}}$ 把紧对象送到最终余连通对象；再用 $\Psi^{\mathrm{Nilp},\{0\}}$ 在最终余连通部分上是等价，把函子造出来。
- 分歧化：$H\subset G(\mathcal{O})$，$H$-层级结构 = $\mathcal{F}_{G,D_x}$ 到 $H$ 的约化，叠记 $\mathrm{Bun}^H_G$；$H=G(\mathcal{O})$ 退回 $\mathrm{Bun}_G$，$H=\{e\}$ 是全层级结构 $\mathrm{Bun}^{\infty x}_G$。
- 全篇的组织原则：先做 Iwahori 层级（$I=B$ 的原像），因为它同时是「最小可用」和「带组合结构」的层级。

### 2.2 第 2 章：紧生成的机器

**§2.1 是 [DG15] 的复述**（作者明说 "we will recall"），要点：

- 可截断（truncatable）叠：对优势余权 $\theta$，开子叠 $\mathrm{Bun}^{(\le\theta)}_G$ 余截断（co-truncative，即其对角可截断）。余截断 + 拟紧 ⇒ $\mathrm{D}\text{-}\mathrm{mod}$ 紧生成（Prop 2.1.2.3 的 QCA 路线，Prop 2.1.3.4）。
- 收缩（contractive）子叠：存在 $\mathbb{A}^1$-作用把 $\mathcal{Y}$ 收缩到 $\mathcal{Y}'$，且 $\mathcal{Y}'\subset\mathcal{Y}$ 闭；收缩 ⇒ 截断（Prop 2.1.4.3）。
- 分层策略：Harder–Narasimhan 分层把 $\mathrm{Bun}_G$ 拆成可数的、维数递增的部分，逐层检验四条件（开嵌入 / 满射 / 光滑 / 收缩），再用「截断的开闭子叠之有限并仍截断」合并。

**§2.2 用 $\mathrm{SL}_2$ 把整套机器跑一遍**，是本文最值得细读的教学段：

- 非分歧：$\mathrm{Bun}^{(n)}_B$（$0\to\mathcal{L}\to\mathcal{M}\to\mathcal{L}^{-1}\to0$，$\deg\mathcal{L}=n$）→ $\mathrm{Bun}^{(\le n)}_G$；四条件分别用「$\mathrm{Ext}^1(\mathcal{L}^{-1},\mathcal{L})=H^1(\mathcal{L}^{\otimes2})=0$」（满射）、「$\mathrm{SL}_2$-丛至多一条次数 $n$ 的线子丛」（开嵌入）、「$H^1(\mathcal{L}^{\otimes-2})=0$」（光滑）、「$\mathbb{G}_m$ 收缩」（收缩）。
- Iwahori：$\mathrm{Bun}^I_G$ 的点是 $(\mathcal{M},\mathcal{L}\subset x^*\mathcal{M})$；$\mathrm{Bun}^I_B$ 依 $\mathcal{L}$ 是否是 $x^*\mathcal{M}$ 的一维子空间分闭、开两层；用 $\mathrm{Aut}(\mathcal{M})$ 里把 $v$ 送到 $v$、把 $w$ 送到 $cv+w$ 的变换证明满射；光滑性归到 $H^1(\mathcal{L}^{\otimes2}(-x))=0$。

**§2.3 是本文的原创部分**，逻辑链：

1. 归约（§2.3.1）：$\mathrm{Bun}^I_G\to\mathrm{Bun}_G$ 局部有限型 ⇒ 只需证 $\mathrm{Bun}^{I,(\le\theta)}_G$ 余截断，阈值从 $2g-2$ 提到 $2g-1$。
2. 再按相对位置分层（Def 2.3.1.4 的 ${}^w\mathrm{Bun}^{I,(S)}_P$），把问题压到单个胞腔 ${}^w\mathrm{Bun}^{I,(S)}_G\to\mathrm{Bun}^I_G$ 的收缩性（Prop 2.3.1.5）。
3. 全局生成的技术核心（§2.3.3）：把 $\mathfrak{n}(P)_{\mathcal{F}_M}$ 拆成 $\bigoplus V_{M_\lambda,\check\alpha}$，逐块用 [DG15] 的次数界与 Serre 对偶；得到 Cor 2.3.3.7（$\mathrm{U}(P)$ 的提升性质）与 Cor 2.3.3.8（$(\mathfrak{g}/\mathfrak{p}^-)_{\mathcal{F}_{P^-}}$ 全局生成）。
4. 四条件（§2.3.4–2.3.7）：开嵌入化到 $M\backslash MwB/B$ 的群论恒等式；满射用 $\mathrm{U}(P)$ 提升到 $\mathrm{Aut}(\mathcal{F}_G)$；光滑用切复形的长正合列；收缩用 $\mathbb{G}_m\to Z(M)$ 的 $\mathbb{A}^1$-作用。
5. 多点（§2.3.8）：同一套证明，阈值变成 $2g-2+k$。

### 2.3 第 3 章：因子化

**§3.1 立语言**（复述 [ABC+24a] 与 [Bog24]）：

- Ran 空间、$\mathrm{Ran}^\subset$、$\mathrm{Ran}_{x_0}$、因子化范畴 / 因子化模范畴 / 因子化代数及其模（Def 3.1.1.1–3.1.1.12）。
- 三对主角：
  - AB：$(\mathrm{Whit}^!(G),\mathrm{Whit}^!(\mathrm{Fl}_G))\leftrightarrow(\mathrm{Rep}(\check G),\mathrm{QCoh}(\check{\mathfrak{n}}/\check B))$；
  - B：$(\mathrm{Sph}_G,\mathrm{Aff}_G)\leftrightarrow(\mathrm{Sph}^{\mathrm{spec}}_{\check G},\mathrm{Aff}^{\mathrm{spec}}_{\check G})$；
  - IFLE：$(\mathrm{KL}(G)_{\mathrm{crit}},\mathrm{IKL}(G)_{\mathrm{crit}})\leftrightarrow(\mathrm{IndCoh}^*(\mathrm{Op}^{\mathrm{mon-free}}_{\check G}),\mathrm{IndCoh}^*(\mathrm{Op}^{\mathrm{mer}}_{\check G}\times_{\mathrm{LS}^{\mathrm{mer}}_{\check G}}\check{\mathfrak{n}}/\check B))$。
- 逼近定理（§3.1.5）：$\mathrm{QCoh}^{\mathrm{co}}(\mathrm{L}^\nabla Y\times_{\mathrm{L}^\nabla Y_0}\mathrm{L}^+_\nabla Y_0)$ 到 $(\mathrm{L}^+f)_*\mathcal{O}_{T^+}$-因子化模的函子在最终余连通部分是等价（Prop 3.1.5.1 = [ABC+24a, Cor 4.5.7]；Thm 3.1.5.2 是本文加强版，允许 $Y_0=\mathrm{pt}/H\times X_{\mathrm{dR}}$）。

**§3.2 AB**：可熔性（Prop 3.2.1.1 = [Bog24, Thm 3.8]）+ 「只要在 $x_0$ 处是等价」⇒ 全曲线等价；中间物 $\mathrm{Whit}^!(LG)^\infty_2$ 与 Jacquet 函子；最后用 $\mathrm{Whit}^!(\mathrm{Fl}_G)^{\mathrm{Q-Lisse}}$ 绕过「$\mathrm{Whit}^!(\mathrm{Fl}_G)$ 不紧生成」的困难。

**§3.3 B**：先证因子化限制保守（Prop 3.3.1.2，归纳 + recollement），再构造 $(\mathrm{Sph}_G,\mathrm{Aff}_G)\to R_{\check G}\text{-}\mathrm{FactMod}$，最后逐点用 Dhillon–Taylor [DT25] 的单幂零 Betti 版本，做 de Rham 版。

**§3.4 IFLE**：先构造（$\mathrm{Rep}(\check G)$ 经 Satake 作用给出余作用），再归约到逐点（Prop 3.4.2.1），再证「Iwahori–Hecke 温性」（§3.4.3–3.4.4），其中特征标计算（式 (3.4.9) 附近的 oper 显式式）是全文最技术的一段。

## 五、术语与记号速查

- $\mathrm{Bun}_G$、$\mathrm{Bun}^I_G$、$\mathrm{Bun}^{\infty}_G$、$\mathrm{Bun}^H_G$；$I=B$ 的原像；$G(1)(\mathcal{O})$ 第一同余子群。

- $\mathrm{Op}_{\check G}$（oper 的仿射 D-概形），$\mathrm{Op}^{\mathrm{reg}}$、$\mathrm{Op}^{\mathrm{mer}}$、$\mathrm{Op}^{\mathrm{mon-free}}$、$\mathrm{Op}^{\lambda-\mathrm{nilp}}$。
- $\mathrm{Ran}$、$\mathrm{Ran}_{x_0}$、$\mathrm{Ran}^\subset$、$\cup$、$[\mathrm{Ran}\times\mathrm{Ran}]_{\mathrm{disj}}$。
- $\mathrm{FactAlgCat}$、$\mathrm{FactModCat}_{x_0}$、$a\text{-}\mathrm{FactMod}$、fusable（可熔）。
- $\mathrm{L}^+_\nabla$、$\mathrm{L}_\nabla$、$\mathrm{Conn}(H)$、$\mathrm{LS}^{\mathrm{reg}}$、$\mathrm{LS}^{\mathrm{mer}}$、$\check{\mathfrak{n}}/\check B$。
- 截断性三兄弟：truncative（截断的）、co-truncative（余截断的）、truncatable（可截断的）；contractive（收缩的）。

## 六、译前风险点

1. **公式密度极高**：第 2、3 章几乎每页都有交换图或带上下标的表达式，纯文本抽取必然走形，必须逐页回 PDF 图像核对（§3 纪律）。
2. **记号跨节漂移**：$\mathrm{Whit}^!$ 与 $\mathrm{Whit}^*$、$\mathrm{Sph}^{\mathrm{spec}}$ 的两种定义（Def 3.1.3.5 与 §3.3.1 的收紧版）、$\mathrm{Aff}^{\mathrm{spec}}$ 的两种定义（Def 3.1.3.6 与 Def 3.3.1.5）。译文需在首次出现处加译注说明「此处定义与 §3.3.1 不同」。
3. **引用外部结果极多**：26 条文献中 [ABC+24a]、[DG15]、[Bog24]、[BCG26]、[DT25] 五条是主要黑箱。译注只能给「出处 + 该文中的编号」，不能自行展开证明。
4. **四层编号**：定理编号形如 2.3.1.2（章.节.小节.序号），LaTeX 需自建三级前缀的计数器（见源码/preamble.tex）。
5. **未定义记号**：`cores_{x0}`（p.86）等，见疑点清单，按「保留原样 + 译注」处理。
