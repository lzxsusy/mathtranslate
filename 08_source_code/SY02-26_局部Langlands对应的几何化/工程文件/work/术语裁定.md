# 术语裁定（Lead 终裁，2026-11-23）

> 术语员报上来的 6 条「存疑待裁」+ 4 条本库译法冲突，Lead 逐条裁定如下。
> **裁定即冻结**：译文一律照此写，遇到异议写进 `疑点清单.tsv` 交 Lead，不许自己改。
> `glossary.tsv` 的「依据」列里 `存疑待裁` 已被本裁定覆盖。

## 一、六条存疑

| 英文 | 裁定 | 理由 | 允许的别名（首次出现括注） |
|---|---|---|---|
| perfectoid space | **完满空间** | 与 perfectoid field「完满域」、perfectoid ring「完满环」保持词根一致；「完美胚」生僻且与 perfect 混淆 | 完美胚空间 |
| diamond | **菱形** | 与既译「空间菱形 / 局部空间菱形」一致；「钻石」与 Hodge diamond（Hodge 菱形）撞车 | 钻石 |
| Langlands dual group | **朗兰兹对偶群** | 中文语境优先，且与「朗兰兹纲领」同前缀 | Langlands 对偶群 |
| excursion operator | **巡游算子** | 2026-11-23 主人裁定：excursion 取「巡游」义（沿参数巡游，非随机游走）；旧译「游走算子」、SY02-19 旧作「excursion 算子」，均保留为别名 | 游走算子（旧译，别名） |
| Hecke eigensheaf | **Hecke 特征层** | 与「Hecke 特征值」同族；「本征」是 eigenspace 的旧译，本库已不用 | Hecke 本征层 |
| G-torsor | **G-主丛** | 与「主丛」统一；「主齐性空间」留作 torsor 的完整译名，不用于 G-torsor | 主齐性空间 |

## 二、连带冻结（派生词，照此写不另议）

- perfectoid field = **完满域**；perfectoid ring = **完满环**；perfectoid algebra = **完满代数**；
  sousperfectoid = **不译**（保留英文，首现加译注）。
- diamond 相关：spatial diamond = **空间菱形**；locally spatial diamond = **局部空间菱形**；
  diamond space = **菱形空间**（不写「菱形空间的空间」）。
- v-sheaf = **v-层**；v-topology = **v-拓扑**；pro-étale = **不译**；lisse-étale = **不译**。
- solid = **固体**（solid sheaf = 固体层，solid module = 固体模）；condensed = **凝聚态**（以 glossary 第 148 行为准，勿写成「凝聚」）。
- Bun_G = **Bun_G**（不译）；shtuka = **shtuka**（不译）；anima = **不译**。
- unicomplete / ULA = **ULA**（不译，首现译注为「universally locally acyclic」）。

## 三、发现新术语怎么办

译文里遇到 glossary 没有的术语：
1. 先查 `_term_index.json` 与 `08_source_code/*/工程文件/work/glossary.tsv`；
2. 有旧译就照旧译（除非与本节裁定冲突）；
3. 都没有 → **保留英文**，写进报告「§5 术语新增」并给建议译名，Lead 并入后才可用中文。
