# 任务书 · 校对（Chapter I）

你接过的是别人刚译完的章块。**你的任务是挑错，不是重写。**

## 输入
- 原文：`01_pages/pNNN.txt` + PDF 渲染图（`00_原文/fargues-scholze-2102.13459v4.pdf`，页码 = PDF 页）
- 译文：`源码/sections/sNN-*.tex`（对应块）
- 译手报告：`reports/chI-x.md`
- 术语：`工程文件/work/glossary.tsv`、`symbols.tsv`
- 体例：`工程文件/BRIEF.md` §4、`工程文件/SPEC.md`

## 产出（只写这三个文件）
1. `reports/proof-chI-x.md` —— 校对报告，模板见下。
2. `工程文件/work/trace-proof-chI-x.md` —— ≥8 条决策记录（判断点/依据/结论与理由/事后确认），含 ≥1 条弯路。
3. **直接改** `源码/sections/sNN-*.tex` 里的错误（这是唯一被允许改他人文件的场景），但每处改动必须记进报告 §2 的清单。

## 校对维度（逐条过，不许抽样）
| # | 维度 | 查法 |
|---|---|---|
| 1 | 漏段/并段 | 原文段数 vs 译文段数逐节点数 |
| 2 | 术语不一致 | grep glossary 每一条在译文里的译法；同词异译逐处抓 |
| 3 | 公式错 | 每页含公式段落回图核对（dpi 150）；重点看上下标、符号、系数 |
| 4 | 编号 | 定理/定义/公式编号与原文一致；交叉引用 `\ref` 不断 |
| 5 | 译注质量 | 每条 `\yizhu`：来源是否真实存在、是否答非所问；`\yizhuw` 是否该有依据却被标无依据 |
| 6 | 过度翻译 | 文献标签 `[Far16]`、专名、英文术语是否被硬译 |
| 7 | 中文质量 | 长句是否读不通；「的的不休」；被动语态滥用 |
| 8 | 体例 | `\srcpage` 每页齐不齐；环境类型对不对 |
| 9 | 编译 | `cd 源码 && build.bat check sections\sNN-*.tex` → 0 error |
| 10 | 黑名单 | grep 「显然」「众所周知」「不难看出」等未加译注的套话 |

## 报告模板

```
# Chapter I · 块 X 校对报告
## 0. 结论
一句话：可交付 / 需返工（列出返工点）
## 1. 逐维度结果
| 维度 | 检查量 | 问题数 | 说明 |
## 2. 改动清单
| 序号 | 位置(页/行) | 原文 | 原译 | 改后 | 依据 | 类型 |
## 3. 未改动但存疑
| 位置 | 疑问 | 为何不改 |
## 4. 译注抽查
共 N 条，抽查 5 条，逐条判：来源成立 / 来源可疑 / 无依据（列出）
## 5. 编译与统计
## 6. 给 Lead 的建议
```

## 红线
- 不许因为「读着不顺」就改译文风格，只改错。
- 不许删译注（可疑的写进报告 §4，让 Lead 裁）。
- 不许改 main.tex / preamble.tex / glossary.tsv / 别的块。
- 改动清单必须与实际 tex 的 diff 一致，**不能只在报告里写而不改，也不能改了不报**。
- 不 git push。
