## 3. 编译方法

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1     # 三次 LuaLaTeX，输出 main.pdf
```

- 引擎：**LuaLaTeX** ＋ `ctex`，中文字体自动取系统字体（无需 fontconfig / `\setCJKmainfont`）。
- **本机两条硬约束**（换机器可能不同，实见于本机实测）：
  1. `lualatex` 在**非 ASCII 路径**下无法写 `.log`（报 `I can't write on file main.log`）；
  2. 子进程**不能写 Desktop**。
  故 `build.ps1` 先把 `src/`、`figures/` 镜像到 ASCII 可写目录
  `<本地路径>` 再编译，最后把 `main.pdf` 拷回。
  换机器时改 `build.ps1` 顶部的 TeX bin 候选路径与镜像目录名即可。
- 编译前必须设 `TMP`/`TEMP` 到可写目录（脚本已做）。
- `unit`：`main.tex` 用 `\InputIfFileExists` 逐块注入 `chunks/`，缺块也能编译（便于分块协作）。

## 5. 原文笔误与存疑登记表

> 说明：正文一律照原文排印，只在批注中指出并给出正确形式。下表各项均经 500–3000 dpi 局部裁图复核

| # | 原文页 | 位置 | 原文 | 说明 / 正确形式 |

| 2 | p.12 | §3.3 前一段 | "In principle **threre** can be multiple…" | 拼写错误，应为 **there** |
| 3 | p.16 | 式 (3.49) 分子首因子 | $E(a_i-a_j,Y_i,Y_j,s)+m$ | 由 (3.45)(3.46) 取 $\vec b=\vec a,\vec W=\vec Y$ 应得 $E-m$；同式第二组因子 $\epsilon_1+\epsilon_2-E-m$ 两处一致。同一式内两组因子的 $m$ 符号约定不统一，疑为笔误；译本照原文排印并批注（可核对锚点见批注） |

## 7. 已知偏差与限制

1. **参考文献为自动转录**：由 `tools/gen_refs2.py` 从 PDF 文字层解析，未逐条人工校对。
   文字层把上下标拍平（如 $N_C$ 记为 `NC`、$\mathbb{C}^2/\mathbb{Z}_p$ 记为 `C2/Zp`），
   此类数学记号在文献条目中**仅作检索用**，与原文印刷形不完全一致。
2. **图注为译者所译**，图内文字保留原文；图为 450 dpi 位图，缩放后与原矢量图略有差异（不放大超出原比例）。
3. **批注不进入排版**：`% [Tutor Note: ...]` 是 LaTeX 注释，只存在于源码中（另汇编为 `译注汇总.md`）；
   批注中的判断属译者意见，不代表原作者。
4. **引文编号**：原文对本卷其他综述用 `[V:n]` 记号，与普通文献 `[n]` 是两套独立编号，译本照原样保留。
5. **段落切分**：为可读性，个别原文超长段落（如 p.5 起近一页的段落）在公式后按句断开；
   已按原文行首缩进（x₀ = 83.0 pt 为段首、65.4 pt 为续行）逐处核对，其余段落与原文一一对应。
6. **译本为人工（LLM Agent）逐页看图转写**：已做三重 Gate（静态检查 / 真编译 / 成品 PDF 回读）
   与 8 轮交叉校对，但仍可能存在未被发现的排版或个别符号差异——发现请以原文 PDF 为准。
7. 原始探测与素材数据（`probe.md`、`tags.txt`、`split/`、`pages/`）保留在工作目录，可复现核对。
