## 底本

- 原书 108 个 PDF 页，**印刷页码 = PDF 页码**（页眉即页码）；正文 7–106，参考文献 107–108（24 条，保留英文）。
- 1–2 页出版信息、3–6 页原目录不译；原书无前言、无索引，正文自「概览」起。
- 章：概览 + ①五次三维超曲面的镜像对称 ②叠 ③Gromov–Witten 与虚技术 ④环面几何 ⑤环面退化与镜像对称 ⑥同调镜像对称初探。
- 编号环境 226（63 例 / 39 定义 / 20 定理 / 29 命题 / 10 引理 / 7 推论 / 37 笔记 / 4 提示 / 3 反例 / 10 事实 / 插叙·断言·猜想·问题各 1），编号公式 596，图 35（34 矢量 + 1 栅格）。译本编号逐条对应原书。
- 原书空号 1.65 与未写完的式 6.66 按原状保留；第 93 页「此处插入 Siebert 报告」是原文内容，照译。
- 译本增补中文索引 70 条（原书无索引）。
