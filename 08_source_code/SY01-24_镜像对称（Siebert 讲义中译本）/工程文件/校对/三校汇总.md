- 底本：Bernd Siebert 讲授、Jackson Van Dyke 记录，*Mirror Symmetry*（2019 年秋课程讲义，公开讲义、未正式出版；原 PDF 108 页，印刷页 7–106）
- 译本：《镜像对称：代数几何专题讲义》（ElegantBook，A4 11pt，103 页）
- 本轮定位：在前两轮「逐句对读 + 术语统一」之后，换一套判据——**以 nLab 与 Stacks Project 的权威陈述为准，复核译文的数学陈述与译名**，并与讲义英文原文交叉验证
- 产出：`chapters/ch01.tex`–`ch06.tex`、`overview.tex` 就地修订 32 行；本文件 + `chNN.jsonl`（114 条判定，逐条带证据）

## 1. 方法与分工

| 环节 | 做法 |
|---|---|
| 数学陈述 | 逐条译文对照 `orig_full.txt`（英文全文，4955 行）定位原句；凡陈述可疑处再查 nLab / Stacks 的等价定义或定理，三方一致才落笔 |
| 译名 | 先查库内既有译法（`01_corpus_zh`、`08_source_code` 的术语表），再查 nLab 条目名与 Stacks 章节名，最后看中文数学界的通行译名 |
| 覆盖 | 六部分各有一份 `chNN.md`（人读）+ `chNN.jsonl`（机读，字段 chapter/line/kind/zh_before/zh_after/evidence/severity/applied） |
| 硬规则 | 不新增/删除/重排编号环境；不动 `\Eq` 编号与 `\SourcePage`；不改 `\Term` 的 slug；不动 preamble；不编译整书（避免 aux 竞态） |
| 判定 | `applied=true` = 已落盘；`applied=false` + `kind=note` = 核过、判为「原文如此」或「译文更准」，**保留不改** |

英文原文是 PDF 抽文，有两个已知噪声：连字掉字母（`De nition`=Definition、`re exive`=reflexive、`a ne`=affine）、上下标被空格拆开（`R 1 ; 3`=R^{1,3}、`M g`=M̄_g）。所有引用原文行号的地方都按这个口径读。

## 5. 「原文如此 / 译文更准」清单（核过不修）

以下 88 条中挑出会被读者质疑的几类，全部已进 `chNN.jsonl`（`applied=false`）：

1. **overview.tex:25** σ 模型的「靶空间 $\mathbb{R}^{1,3}\times X$」。物理上 σ 模型的靶空间是 $X$，$\mathbb{R}^{1,3}\times X$ 是十维时空。讲义原文 p.7 即如此写，并带「无反常」脚注——属原作者的行文，不是译文错，保留。
2. **例 0.1 标题**：原文 "Quartic in $\mathbb{P}^4$"，实为五次超曲面；译本作「五次超曲面」，正确，保留。
3. **原文 "Lian, Liu, and Yan"**：Yau 的笔误；译本作 Yau，正确。
4. **ch01 特殊纤维**：原文说 "smooth for $z\neq0,1$"，与其后列举的 $z=5^{-5}$、$z=1$ 自相矛盾（$\psi=0$ 对应 $z=\infty$）；译本统一写成 $z\neq0,5^{-5},\infty$，保留。
5. **ch04:343 注 4.6**：原文 "the unique **maximal** one"，但扇公理下含 $\varphi(\sigma)$ 的锥族对交封闭，**极小**者才唯一。译文作「最小」是对的，原文疑误。
6. **ch02:409、495**：原文公式分别误作 $(2n-2)(g-1)-1$、$\lfloor(g+1)/2\rfloor$；译本正确。
7. **ch02:214**：原文确作 "genus 2"，按原样保留。
8. **ch05:97**：式 (5.8) 原文首项 $t^0xyz$，译文 $xyz$。等值，仅丢了「$t$-权为 0」的提示。
9. **ch05:277、279**：式 (5.65)(5.66) 的 $\bmod t^{k+1}/t^{k+2}$ 比原文抬了一阶，但与「插入 $1+ct^{k+1}z^m$ 作一阶提升」逐阶自洽，判为可接受的等价改写。
10. **ch03:128**：$Z_k$ 表示 cycle 群（「循环群」），与 ch03:199「循环类」同源。建议下一轮改「$k$-循环群」以免与 cyclic group 混淆——本轮不动，避免牵动索引。
