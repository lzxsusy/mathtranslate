## 五、逐句对照确认无误的要点

- §幺半群与锥：单参数子群 $t\mapsto t^m$、$\langle m,u\rangle\ge0$ 的判据、$M$ 与 $N$ 的对偶配对（(4.1)–(4.6)）逐式对应。
- Gordan 引理（Prop 4.2）与推论 4.1 的紧性论证；§凸几何事实 (a)–(j) 与原文十条一一对应，极射线与不可约生成元（(4.10)、Fact 4–6）无缺口。
- §幺半群环：$k[S]$ 的加法乘法、$\chi^m\chi^{m'}=\chi^{m+m'}$（(4.20)）、$k[M]=k[\ZZ^d]$、$T_N=\Spec k[M]$（(4.24)–(4.27)）逐式核对。
- §仿射环面簇：Prop 4.3（环面理想的二项式生成）证明中 $M$ 分次齐次性、$\sum_A\alpha_A=0$ 的判据与归纳替换 $x^A\to x^{A'}$ 与原文一致。
- §$k$ 有理点：$X(k)=\Hom_{\Mon}(\sigma^\vee\cap M,(k,\cdot))$（(4.16)）及例 4.4–4.6；$\operatorname{ord}_p(\chi^m)$ 与群 $\Hom(\sigma^\vee\cap M,k^\times)$ 的刻画。
- §环面开子概形：$U_\sigma\subset X$ 的开性、$U_{\sigma\cap\sigma'}=U_\sigma\cap U_{\sigma'}$（(4.30)）、$X(\Sigma)$ 的粘合（(4.31)–(4.34)）。
- §有理函数、维数与正规性：$\dim X(\Sigma)=d$、$X$ 正规（$k[\sigma^\vee\cap M]$ 为幺半群代数，正规）、$X$ 的奇点集为 $\bigcup_{\sigma\ \text{非光滑}}U_\sigma$ 的论断与原文一致。
- §环面分层：$\Spec k[\sigma^\vee\cap M]^{T_\tau}=\Spec k[(\tau^\perp\cap\sigma^\vee)\cap M]$（(4.63)）、商扇 $\Sigma_\tau$（(4.64)）与 $\dim X(\Sigma_\tau)=d-\dim\tau$。
- §整体化：扇的定义（Def 4.7，含 (i)(ii)）、支撑 $|\Sigma|$（(4.46)）、完备性与固有性的预告、$\PP^2$ 的扇（例 4.10）与 (4.57)–(4.60) 的坐标变换 $v_0=u_0^{-1}u_1$、$v_1=u_0^{-1}$、$w_0=u_1^{-1}$、$w_1=x_1/x_2$ 全部验算通过。
- §$\PP^d$：$v_i=e_i$、$v_0=-\sum e_i$（(4.61)–(4.62)）与 $\PP^d$ 的扇。
- §拟紧性（例 4.14）：$|\Sigma|=(\RR\times\RR_{>0})\cup\{(0,0)\}$ 非闭、$X(\Sigma)=\bigcup_{\text{可数}}\mathbb A^2$ 非拟紧、$\pi^{-1}(0)=\bigcup\PP^1$、$\pi^{-1}(\eta)=\mathbb G_{m/k(t)}$（(4.66)–(4.70)）与 Prop 4.8 的证明（用余维一层的不可约分支数）对应。
- §扇的态射与性质：Def 4.8 的 $\varphi(N)\subseteq N'$、诱导 $\Phi$ 的 (4.72) 与 (4.73)、Prop 4.9（$\Phi$ 连续/固有/闭嵌入/开嵌入/同构的判据）、例 4.15–4.20（含 $A_{k-1}$ 奇点 $xy=t^k$、格的改变、$\Bl_0\mathbb A^2$ 的仿射图）均验算通过。
- §多胞体与多面体：Def 4.12/4.13、Thm 4.11、$C(\Xi)$（(4.92)）与回收锥、Def 4.14 的 $\Xi^\circ$（(4.93)）、Note 4.10/4.11 的约定。
