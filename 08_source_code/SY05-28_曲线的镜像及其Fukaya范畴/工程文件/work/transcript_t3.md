## t3-03（原稿第 13 页，Talk 3 第 3 页）

- B 侧解释：在极大退化附近，［图：带结点的曲线］= 如下粘合的光滑化
  在 {−1,0,∞} 处粘合各 P^1：每个结点处的光滑化为 y y' = T^A
    y, y' = 在 P^1 上标记点附近选取的局部坐标 := 上面所选函数的逆
    T^A = area(P^1) 为光滑化参数
  · 等价地（对我们更方便），把每次粘合看成：
    把 P^1 ∋ 0 粘到裤子上：x y' = T^{A/2}
    把 P^1 ∋ ∞ 粘到裤子上：x' y = T^{A/2}　［↑ 局部坐标 x' = 1/x］
    ［图：两条裤子、结点处的坐标 y, y', x, x'］
  "图卡数据"的选取反映了：要不选 P^1 在结点附近的局部坐标，就没有完全典范的方式把裤子显式粘起来。
  · 图卡数据将决定 Floer 微分的"传播规则"。最典范的选取是
      { z, −(z+1)/z, −1/(z+1) } 或 { −(z+1), 1/z, −z/(z+1) }，
    它们显示循环对称性，即只需指定结点处三条腿的循环次序。于是 { p_1p_2p_3 = 1 ; p_i^{-1} + p_{i+1} + 1 = 0 }

## t3-04（原稿第 14 页，Talk 3 第 4 页）

- 于是每个顶点有一个 0 次生成元，其余交点处照常给出生成元。
  例：hom(L_1,L_2) 的生成元［两幅图，标 deg 0 / deg 1］
- 解释：把线丛 L 想成粘合而成
  · ［裤子 + 红蓝弧］↔ 每条裤子上取 O
  · ［球面 + "k 圈"］↔ P^1 上的 O(k)，在 0 与 ∞ 处有区分的三价点
- hom(L_1,L_2) 的生成元与下列对象对应
  · ［裤子图］↔ 裤子上的 contact fusion
  · ［球面上 k 圈对应 |k−1| 个生成元］↔ 在 0 与 ∞ 处为零的 O_{P^1}(k) 的截面，
    或更恰当说，H^•(P^1, L_1^∨ ⊗ L_2 ⊗ O(−p_0−p_∞))
  ★ 当 k > 0 时，端点处的生成元对应在 0 与 ∞ 处不为零的单项式，即 x^k 与 x^{-k}。
  ★ 当 k ≤ 0 时，会出现 Floer 微分 ∂a = T^{area} b，∂a' = T^{area} b'
    （［图：椭圆上 a,a',b］），使得复形的这一部分无论如何都有上同调 ≃ H^•(P^1, O(k))。
- 所以：若所有 P^1 都被"捏扁"（面积为 ∞）（⇔ B 侧不做光滑化），
  使得只出现这些"细"的 Floer 微分，则得到
    H^• hom(L_1,L_2) ≃ H^•(C_0, L_1^∨ ⊗ L_2)
  hom 的生成元对应每个 P^1 中 y 坐标的单项式。
  给 P^1 有限面积会使 Floer 理论形变，允许比"细"曲线更多的全纯曲线，
  这对应于把曲线 C_0 形变到上面描述的光滑化。

## t3-05（原稿第 15 页，Talk 3 第 5 页）

- ③ hom(L_1,L_2) = "CF(L_1,L_2)" 上 Floer 微分的提法：
  计数"刚性"（0 维！有限）的、边界在 L_1、L_2 上的全纯带，
  把 0 次生成元接到 1 次生成元；这些带可以穿过顶点，并按图卡数据的规定行事。
  e.g.［图：带穿过顶点，端点标 p_1,p_2,p_3，输入 a、输出 b，标 A、B］
   一条可能对 hom(A,B) 的 ∂ 有贡献的全纯带：输入 a、输出 b，
   进入顶点时为"1 次带"（几乎一次覆盖圆盘），离开时为"0 次带"。
- · 设一条带以次数 d_1 ≥ 1 从局部坐标 p_1 所标的腿进入顶点、以次数 d_2 ≥ 0 从标 p_2 的腿离开，
  则它被允许当且仅当在 p_1^{d_1} 于 p_2 的极点附近的幂级数展开中，p_2^{-d_2} 的系数非零；
  此时它按该系数作为重数计数。
  （一条合规则的带总权重为 ± T^{area}·(边界上局部系统的 holonomy)·Π(带穿过的各顶点处的重数)）
  Ex：［图：p_1 = z, p_2 = 1/z, p_3 = −1/(z+1)；次数 d_1 的带］
  带以次数 d_1 从腿 p_1 进入
  → 可以以次数 d_2 = d_1 从腿 p_2 离开，也可以以任一 0 ≤ d_3 ≤ d_1 从腿 p_3 离开
    （离开时带因子 ± (d_1 选 d_3)）。
  p_1 = 1/p_2 ⇒ p_1^{d_1} = p_2^{-d_1}
  p_1 = −1 − 1/p_3 ⇒ p_1^{d_1} = (−1)^{d_1}(1 + d_1 p_3^{-1} + C(d_1,2) p_3^{-2} + … + p_3^{-d_1})
  而：以次数 d_2 从腿 p_2 进入的带，可以以次数 d_1 = d_2 从腿 p_1 离开，也可以以任一 d_3 从腿 p_3 离开
  （p_2 = −p_3/(p_3+1) = −1 − p_3^{-1} − p_3^{-2} − …）
