## 这本书讲什么

以 Tate 上同调为语言，用「消没定理 ⟹ 局部类域论」这条路线重讲局部类域论（L2–L23），
收官处给出整体类域论的两个不等式（L19–L23）。主线是：

1. **局部不变量**：Hilbert 符号、范数群、驯分歧（L2–L5）——用显式公式算出范数群指数 `n`。
2. **同调代数工具箱**（L6–L12）：正合列、Herbrand 商、Tate 上同调、映射复形与投射消解。
3. **Tate 上同调与消没定理**（L13–L17）：`H^2(G, L^×)` 的周期性、`M^{hG}/M_{hG}`、消没定理的证明。
4. **范数群与 Kummer 理论**（L18）：`K^×/NL^× ≅ Gal(L/K)^ab`，给出 lcft 的现代证明。
5. **布劳尔群与整体情形**（L19–L23）：`Br^coh(K) ≅ Q/Z`、第一不等式（Herbrand 商）、第二不等式（下降）。
