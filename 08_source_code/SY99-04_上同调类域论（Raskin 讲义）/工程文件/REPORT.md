## 3. 校对轮（2026-11-26）

方法：拿到 MIT OCW 上公开的原讲义 PDF（与本译底本同一文件），用 `pdftotext -layout` 重抽一份保真文本（`raw_layout.txt`，349,524 字节 / 6,022 行），逐讲把中译与原 PDF 页面（`pdftoppm -r 150` 渲染）对照；页眉页码关系为 **physical = printed + 4**。

处置规则（较首译收紧）：原文能确证的排印/表述错误 → **径改并留 `% [原文疑误：…]` 注释**；仅属文本层丢字、或原文可通者 → 照原文排 + 注释说明；仅图表在文本层乱序者 → 按原 PDF 页面重排交换图。

|---|---|---|

校对轮改动较大者（容易看错的地方）：

- 第 19 讲断言 19.4 的交换图：原译把上下排左右顺序弄反、箭头一律向右；原 PDF（physical 86 / 印刷页 82）为 $H^2(G_2,L_1^\times)\to H^2(G_1,L_1^\times)$、$\frac1{[L_1:K]}\mathbb Z/\mathbb Z\leftarrow\frac1{[L_2:K]}\mathbb Z/\mathbb Z$，两列竖直箭头是「$\|$」。
- 第 20 讲断言 20.13 的蛇引理图：原图上方另有整行 $0\to0\to0$，$\varphi$ 标在下排向左箭头、$\psi$ 标在右列第二处竖直箭头。
- 第 23 讲断言 23.10 的图：原图左端用花括号把左上、左下两个 $\operatorname{Br}(F/E)$ 括在一起并标 $\times[F(\zeta_p):F]$，旧译把该标签错标成两条同层箭头之间的映射。
- 第 17 讲断言 17.2：原文未定义 $L_m$、且「对每个 $m$」在 $m=1$ 时与 $\#K^\times/NL^\times=n$ 矛盾（需 $n\mid m$）；图为包含 + 两个范映射的复合，故复合是取 $m$ 次幂。
