## 四、口径（必须遵守）

1. 术语按 `work/glossary.tsv`；`cocycle` 统一「上闭链」，`Tate cohomology` 统一「Tate 上同调」。
2. 原文排印错误：能确证的**直接订正并在 `.tex` 里留 `% [原文疑误：…]` 注释**（注释不进 PDF），
   逐条登记 `ERRATA.md`；无法确证者照译并加注。
3. 交换图一律按公开底本 PDF 的页面图重排，不靠抽取文本猜。
4. 底本 PDF、抽取文本（`lectureNN.txt` / `raskin_raw.txt`）、页面截图**一律不入仓**（`COMPLIANCE.md` R1 / L4）。
5. 译文为演绎作品：本库不代原作者授权、也不另设限制；版权归原作者与出版方；通知即撤。
