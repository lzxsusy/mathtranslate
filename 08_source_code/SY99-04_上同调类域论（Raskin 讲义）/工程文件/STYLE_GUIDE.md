# 译前约定（Raskin《上同调类域论》中文试译）

## 0. 源文件与产物

- 源：底本 PDF 的文本层，按讲切分为 `lectureNN.txt`（NN = 01..23）。**抽取文本不入仓**（L4）。
- 译文：`源码/chunks/lectureNN.tex`（**LaTeX 片段**，不带 `\documentclass` / `\begin{document}`）。
- 合稿：`源码/main.tex`（含导言区与 `\input{chunks/...}` 列表），在 `源码/` 下 `xelatex main` 三遍即出 PDF。
- 报告：翻译期每块交 `reports/R-blockNN.md`；发布仓只留汇总的 `工程文件/REPORT.md`。

## 1. 术语

- **`工程文件/work/glossary.tsv` 已冻结**，必须逐条遵守；不得自行改译、不得造新译名。
- 表里没有的专业词：先查本库 `01_corpus_zh/数语规范/TERMS.tsv`；再查检索插件。
  都查不到：音译/直译并**在报告里登记**为「新增术语」。
- 人名：首次出现「中文（English）」，如「阿廷（Artin）」「泰特（Tate）」「塞尔（Serre）」；
  以人名命名的术语按表（Artin 互反律、Tate 上同调、Hilbert 符号）不再拆开。
- 地名/机构不译（MIT、CIME）。

## 2. 数学

- 公式一律排成 LaTeX：行内 `$...$`，行间 `\[ ... \]`。源文本里的公式是 PDF 抽出来的乱序文本，
  **必须按数学含义重排**。
- 数字、上下标、正负号、$\mathbb{Q}/\mathbb{Z}/\mathbb{F}_q/\widehat{\ }$ 等必须与原文一致；拿不准的公式照以下格式标注并在报告登记：
  `% [TODO: 公式待核：原文抽出为 "..."，暂按 ... 排]`
- 保持原文的编号：定义 1.3、定理 1.5、例 1.6、式 (1.1) 直接用 `\textbf{定义 1.3.}` 这样的粗体行内标题，不建计数器。
- 交换图：能排成 `\[ \begin{CD} ... \end{CD} \]`（amscd）就排；不能就写成文字说明 + 保留原图元素，不做猜测。
  **校对轮口径**：图一律回到公开底本 PDF 的页面渲染图上核对，按原图重排（见 `ERRATA.md` 四例）。

## 3. 排版约定

- 讲标题：`\section*{第 N 讲\quad 标题}`；小节用 `\subsection*{}`（原文无编号则不加编号）。
- 陈述：`\textbf{定理 1.5（主定理 of lcft）.}` + 正文；证明：`\textit{证明.}` ... `\hfill$\square$`。
- 脚注 `\footnote{}`、引用 `[12]` 保持。
- 中文标点用全角，数学模式内不要出现中文标点。
- 不译：参考文献条目、索引页码。
- PDF 书签关闭（`hyperref` 的 `bookmarks=false`）：xdvipdfmx 下中文书签会产生畸形 PDF。

## 4. 质量自检（每块交稿前）

1. 讲内每一段都有对应译文，无整段漏译（可对照段落数）。
2. 所有 `$`/`\[` 成对；`{}` 配对；`\begin`/`\end` 配对。
3. 编号（定义/定理/例/式）与原文一一对应，不重不漏。
4. 报告里登记：术语表未覆盖词、公式 TODO、原文疑似笔误。

## 5. 检索插件实测（每块 6–10 条）

- 用 `kb_locate` 查本讲的核心概念，记录：
  `query | located | top1 cite | 是否真的答上（1–5 分）| 失败类型（专名丢失/别名缺失/覆盖缺口/切分噪声/无）`。
- 重点测「微妙之处」类问题（定理的条件为什么需要、某个构造的动机），不是查词义。
- 全库合计 83 条实测、16 条（19%）可用；主要失败类型见 `REPORT.md` §6。
