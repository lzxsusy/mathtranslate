## 一、术语取舍（有争议或易混的几处）

| 英文 | 本译 | 为什么不取别的 | 依据 |
|---|---|---|---|
| cohomological class field theory | 上同调类域论 | 不能简作「类域论」：本书专指用上同调重写 lcft 的那条路线 | 书名即如此 |
| `Claim` | 断言 | 不译「命题」（已用于 Proposition）、不译「引理」 | 全书 40+ 条，与 Prop./Lemma/Thm. 四级并列 |
| `coinvariant` | 余不变商 | 不译「余不变量」：`A_G` 是**商**，且与 `A^G` 对偶 | 定义 10.15、13.8 |
| `homotopy cokernel` | 同伦余核 | 与「锥（cone）」同义，但书中两者混用，保留「同伦余核」为主译 | 附录 10.1 |
| `uniformizer` | 素元 | 不译「一致化子」（旧译，易与 uniform 混淆） | 库内 TERMS 一致 |
| `place` | 素位 | 不译「位」单字（与 place/position 混） | `M_F` 素位集 |
| `Hilbert symbol` / `norm residue symbol` | 希尔伯特符号 / 范数剩余符号 | 前者专指 `n=2` 情形，后者是 `n` 次推广；书中两者都出现 | 术语表 |
| `cocycle` / `coboundary` | 上闭链 / 上边缘 | 全库统一，不译「余循环/上边界」 | TERMS |
| `inflation` | 膨胀 | 不译「膨胀映射」冗余；与「限制/余限制」并列 | L16 订正 |
| `Tate cohomology` | Tate 上同调 | 人名保留拉丁拼写，不译「泰特上同调」 | 术语表 |

**一处口径修正**：第 16 讲原译「限制与膨胀」应为「限制与余限制（corestriction）」。理由：膨胀只对正规子群有定义，
而定理 16.3 的证明恰恰在 `H ⊆ G`（不必正规）上用 `res` 与 `cor` 的复合等于乘以指数——这正是「限制∘余限制」而非「限制∘膨胀」。
原文（p70）此处措辞含混，已订正并留注。

## 五、照原文加注（2 条）与已核销（1 条）

1. **第 21 讲引理 21.3 证明**：原文称 `H ↦ φ^{-1}(H)`「因 `φ` 满射而单射」，但假设中 `φ` 只是一般连续同态。
   正确做法：对 `φ(G)` 施用同一计数论证（`φ(G)` 也拓扑有限生成），故 `ker φ` 只能是 `1`。
   译文照译原文，注中给出这条修法。
2. **第 19 讲注 19.17 附近**：原文作 "When `n = 1^2`… when `n = 2^2`…"，是按次数 `n²` 表述（`n=1,2` 即次数 1 与 4），
   非排出错字；译文按 `n=1,2` 排，语义一致。
3. **第 5 讲 `(2,ℓ)_2` 的指数**：抽取文本原有两处不可读字符，按 Serre 第 III 章公式读作
   `ε(1)ε(ℓ)+v(2)θ(ℓ)+v(ℓ)θ(1)`；由 `ε(1)=0`、`v(ℓ)=0` 化为 `(−1)^{θ(ℓ)}`，与结论一致，核销。
