# 00 速览 —— Raskin《上同调类域论》23 讲

> 一句话：**用 Tate 上同调做局部类域论**，把 lcft 从「范数群指数 = 扩张次数」化归为一条消没定理，
> 再用 Herbrand 商把同一套机器搬到整体域，证明 gcft 的第一、第二不等式。

## 二、三条阅读路线

1. **只要 lcft 的结论**：L1（陈述）→ L2（Hilbert 符号）→ L14–L18（同调版证明）→ L19（布劳尔群）。
2. **要用同调机器**：L6–L12 是自足的一章（正合列 → Herbrand 商 → Tate 上同调 → 映射复形/投射消解），
   与 L13（`M^{hG}` / `M_{hG}`）对读即可。
3. **关心整体情形**：L19（`Br^coh(K) ≅ Q/Z`）→ L20（第一不等式，Herbrand 商 `χ(C_E)=n`）→
   L21–L22（Artin/布劳尔互反、`H^1(G,C_E)=0`）→ L23（第二不等式的下降）。

## 三、五条主线（一句话版）

1. **Hilbert 符号就是 lcft 的 `n=2` 情形**：`(,)_K : K^×/(K^×)^2 × K^×/(K^×)^2 → {±1}`，
   由「二次扩域中范数」定义；双乘性来自 Hilbert 90 与范数群指数 2。
2. **范数群指数 `n` 是全部内容**：`K^×/NL^× ≅ Gal(L/K)`（推论 18.14）等价于 `#K^×/NL^× = n`，
   后者由两条不等式夹逼。
3. **消没定理是 lcft 的引擎**：`L/K` 完全分歧 ⟹ `(L^{unr,×})_{tG}` 无环（定理 15.3）；
   一般情形对 `L⊗_K K^unr` 消没（定理 15.5）。
4. **Herbrand 商把 Euler 特征搬到无穷群**：`χ(A)=#H^0/#H^1` 的正合列乘性（引理 6.4 的推论）
   给出 `χ(C_E)=n`，即第一不等式。
5. **第二不等式是「下降」**：先对含 μ_p 的特殊域证，再用 Kummer 理论 + 布劳尔群单射性推到一般
   （断言 23.10 的四角交换图）。
