## 1. 断言 1.8 —— `Gal_2(K) ≅ (K^×/(K^×)^2)^∨`（p4）

**目标**：把二次扩张的 Galois 群描述成 `K^×` 的模平方特征群。这是 lcft 的 `n=2` 情形。

**卡点**：两边都是无限的 `2`-挠投射有限群，不能靠「数元素」；必须先造映射，再证明它是同构。

**步骤**：
1. 给定 `σ ∈ Gal_2(K)`、`d ∈ K^×/(K^×)^2`，令 `χ_σ(d) = 0` 若 `σ(√d) = √d`，否则 `1`。
2. `χ_{σ_1σ_2} = χ_{σ_1} + χ_{σ_2}`：因为 `(σ_1σ_2)(√d) = (−1)^{χ_{σ_1}(d)}(−1)^{χ_{σ_2}(d)}√d`。
3. 两边都是投射有限 `2`-挠群，只需证 `σ ↦ χ_σ` 在取连续对偶后是同构。
4. 对偶化：`Hom_cts((K^×/(K^×)^2)^∨, Z/2) = K^×/(K^×)^2`；而 `Gal_2(K) → Z/2` 等同于给出二次扩张 `K(√d)`，
   即 `d ∈ K^×` 的模平方类。于是两边同构。

**注意**：第 2 步原文把第二个指数印成 `χ_{σ_1}(d)`，应为 `χ_{σ_2}(d)`（已订正，`ERRATA.md` 第 1 条）。

## 2. 引理 6.4 → 引理 6.7 —— 指标的乘性（p25）

**目标**：正合列下 `∏#X_偶 = ∏#X_奇`；由此 `χ` 对短正合列乘性。

**卡点**：原文给出的指标链 `#X_0…#X_n = #X_0…#X_{n−1}·#X_{n−1}/#Im(d_{n−1})`
里 `#X_{n−1}` 出现两次、两端差一个因子——归纳写错了（已按标准写法重排）。

**步骤**（标准归纳）：
1. 由正合列 `0 → X_0 → … → X_{n−2} → ker(d_{n−1}) → 0` 得
   `#X_0#X_2…#X_{n−2} = #X_1…#X_{n−3}·#ker(d_{n−1})`。
2. 由 `0 → ker(d_{n−1}) → X_{n−1} → X_n → 0` 得 `#X_{n−1} = #ker(d_{n−1})·#X_n`。
3. 代入即得 `#X_0…#X_n = #X_1…#X_{n−1}`。

**补全**：第 1 步用归纳假设，第 2 步用有限群同态的秩公式；两步都不需要有限性之外的正合性条件。
由此 `χ(M) = #(M/n)/#M[n]` 满足 `χ(M)χ(N) = χ(E)`（引理 6.7），这是全书唯一反复使用的计数工具。

## 3. 定理 9.2（Hilbert 90）—— `\hat H^1(G, L^×) = 0`（p38）

**目标**：循环扩张的 Tate 上同调 `\hat H^1` 消没；等价地 `N(x) = 1 ⟹ x = y/σy`（推论 9.3）。

**卡点**：作为抽象群的 `\hat H^1` 不知道「是一个域的乘法群」，必须用域结构造出一个 `y`。

**步骤**：
1. 取 `G = Z/n`，生成元 `σ`；`\hat H^1(G, L^×) = ker(N)/{y/σy}`。
2. 对 `x ∈ L` 定义 `K`-线性映射 `H_x: L → L`，`y ↦ x·σ(y)`（**不是**乘 `x`）。
   引理 9.5：`H_x` 的特征多项式为 `t^n − N(x)`。关键是 `H_x^n(y) = N(x)·y` 与
   「极小多项式整除 `t^n − N(x)` 且次数为 `n`」。
3. 若 `N(x) = 1`，则特征多项式为 `t^n − 1`，故 `1` 是特征值，`ker((H_x − 1) ⊗_K \bar K) ≠ 0`；
   对域而言取核与张量积交换，故 `ker(H_x − 1) ≠ 0`。
4. 取 `0 ≠ y ∈ ker(H_x − 1)`：`x·σ(y) = y`，即 `x = y/σy`。

**注意**：引理 9.5 的证明原文自己承认「并不完全成立」（在 `L` 里证 `y_2/y_1 ∈ K` 会出错，
因为特征值实际住在 `K` 里），随后改为在 `L ⊗_K \bar K ≅ ∏_{g∈G} \bar K` 中直接算出
`y_i = λ^i/(x·σx⋯σ^{i−1}x)·y_0`。这一段是全书少数「作者自陈有瑕」的地方，译文照译并加注。
另：其中「只要 `T(x) ≠ 0`，`y ↦ xy` 的特征多项式就含 `t^n − 1` 的非零倍」一句晦涩，
源文即如此（`T` 为迹），照译。

## 4. 消没定理 ⟹ 上同调 lcft（定理 15.3 / 15.4 / 15.5 ⟹ 14.2）（p66–67）

**目标**：`(L^×)_{tG} ≃ (Z[−2])_{tG}`（定理 14.2）。

**卡点**：`L^×` 是无穷群，`hCoker` 要在复形层面算，不能逐元素逼近。

**步骤**（完全分歧情形，`L^{unr} = L ⊗_K K^{unr}`）：
1. 四项正合列 `1 → L^× → L^{unr,×} →(x↦x/σx) L^{unr,×} →(v) Z → 0`（15.2）。
2. 把 (15.2) 写成两个复形的映射 `A → B`（`A = L^×` 在 `−1` 次，`B = L^{unr,×} →^{1−σ} L^{unr,×}`），
   `A ↪ B` 是单射，故由断言 10.12 得 `Coker(A → B) = Z` 在 `0` 次、微分为 `v`。
3. `B_{tG} = hCoker((L^{unr,×})_{tG} → (L^{unr,×})_{tG})`；由消没定理（定理 15.3）右端无环。
4. 于是 `(L^×[2])_{tG} = hCoker(A_{tG} → B_{tG}) ≃ Z_{tG}`，正是定理 14.2。

**推广**：一般 `L/K` 用定理 15.5（`[(L ⊗_K K^{unr})^×]_{tG}` 无环）+ 断言 15.6 的四项正合列
`1 → L^× → (L ⊗_K K^{unr})^× → (L ⊗_K K^{unr})^× → Z → 0`。

**失败点**：不能在 `L/K` 非分歧时直接用「`L^{unr} = L ⊗_K K^{unr} = ∏ K^{unr}`」——
非分歧时 `L ⊗_K K^{unr}` 是**若干** `K^{unr}` 的乘积，按嵌入编号，而不是一个；这正是定理 15.5 要处理的一般情形。

## 5. 消没定理本身的证明（L16–L17：定理 16.3 + 引理 17.3）（p70–75）

**目标**：`G` 有限、`X` 为 `G`-复形，若 `\hat H^0`、`\hat H^1` 消没则 `X_{tG}` 无环（进而定理 15.3）。

**卡点**：`G` 既不是循环也不是 `p`-群；必须把「无环」这个性质在群论上传递。

**步骤**：
1. 循环 `G`：`X_{tG}` 无环 ⟺ `\hat H^0(G,X) = \hat H^1(G,X) = 0`（定理 16.1）；`p`-群同样（定理 16.2）。
2. 一般 `G`：对每个 `p`-Sylow 子群 `G_p` 检查 `\hat H^0 = \hat H^1 = 0` 即可（定理 16.3）。
3. `ℓ`-群：取正规链 `1 ≠ G_0 ⊊ … ⊊ G_m = G`，商 `G_{i+1}/G_i` 循环（命题 17.1）。
4. 沿链归纳：`x ∈ K^×` 落在 `N: L_m^× → K_m^×` 的像中（断言 17.2，需 `n ∣ m`，否则与 `#K^×/NL^× = n` 矛盾）；
   于是每个 `X^{G_i}` 逐级无环，最终 `X_{tG} ≃ 0`（引理 17.3）。

**注意**：断言 17.2 原文只写「对每个 `m`」且未定义 `L_m`；译文补 `L_m := L K_m` 与条件 `n ∣ m`
（见 `ERRATA.md`，第 17 讲条目）。

## 6. 定理 18.2（存在定理）—— 范数群 = 闭且指数有限的子群（p76）

**目标**：把「是范数群」这个上同调条件翻译成 `K^×` 的群论条件。

**卡点**：证明要「从 `Γ` 造出一个扩张 `L`」，而 `Γ` 是抽象的闭子群。

**步骤**：
1. 必要性（引理 18.4）：范数群闭、指数有限。
2. 先证 `μ_n ⊆ K` 时 `(K^×)^n` 是范数群（推论 18.7）：用 Kummer 理论把 `(K^×)^n` 实现成
   `N((\bar K)^×)`，其中 `\bar K` 是 `K` 的 Kummer 扩张。
3. 一般 `Γ`：用引理 18.5（夹在两个范数群之间的子群仍「不可区分」）把 `Γ` 夹住，
   再用断言 18.6（`#A = #Hom(A, Z/n)`）做有限 `n`-挠群的对偶计数。
4. 得 `Γ = N L^×` 对某个有限扩张 `L/K` 成立。

**落点**：与命题 18.13（`H^1(G, L^×) = 0`，无限 Galois 情形）合起来得推论 18.14：
`K^×/NL^× ≅ Gal(L/K)^ab`，这就是 lcft 的群论形式。

## 7. 第一不等式：`χ(C_E) = n`（定理 20.9(1)，p87–91）

**目标**：整体域的循环扩张 `E/F`，`C_E` 的 Herbrand 商等于扩张次数 `n`。

**卡点**：`C_E` 是无限群，Herbrand 商本身只在分子分母都有限时有定义；必须先把 `χ` 拆成有限块。

**步骤**：
1. `0 → E^× → A_E^× → C_E → 1`，于是 `χ(A_E^×) = χ(E^×)·χ(C_E)`（引理 7.6 的乘性）。
2. 取 `S` 含全部分歧位与无限位，使 `A_{F,S}^× · F^× = A_F^×`（引理 20.12）；
   断言 20.13 的蛇引理图把 `C_E` 与 `A_{E,S}^×`、`E_S^×` 串起来，得 `ψ` 是同构。
3. `χ(A_{E,S}^×) = ∑_{v∈S} χ((E ⊗_F F_v)^×) = ∑_{v∈S} [E_w : F_v]`（断言 20.10 + 引理 7.8）。
4. 单位定理：`E_S^× ≅ (E_S^×)_tors × Z^{r}`，于是 `χ(E_S^×)` 可算（引理 20.14：两个不变格的 `χ` 相等）。
5. 三步相除即得 `χ(C_E) = n`。

**落点**：与第二不等式（定理 22.3）合起来给出 `#\hat H^0(Z/n, C_E) = n`，
从而 `C_F/N(C_E) ≅ Gal(E/F)`（定理 20.8）。

## 8. 第二不等式的下降（断言 23.10，p105）

**目标**：第二不等式只对「基域含 `μ_p` 的 `p` 阶循环扩张」成立时，推出对一般 `p` 阶循环扩张成立。

**卡点**：一般的 `E/F` 不含 `μ_p`，必须扩到 `F(ζ_p)` 上再「降回来」，而扩上去之后 `E` 变了。

**步骤**：
1. 由 `E/F` 得四角交换图：上排 `Br(F/E) → ⊕_v Br(F_v/E_w)`，中排 `Br(F(ζ_p)/E(ζ_p)) → ⊕_v Br(F(ζ_p)_w)`，
   下排 `Br(F/E)`；左列是「限制后膨胀」的复合，等于乘以 `[F(ζ_p) : F]`。
2. 该复合在 `Br(F/E)` 上单射：因为 `Br(F/E)` 是 `p`-挠（习题 2(c)），而 `[F(ζ_p):F] | (p−1)` 与 `p` 互素。
3. 由假设，中排（`E(ζ_p)/F(ζ_p)` 情形）单射，于是 `β` 单射。
4. 下排与上排的单射性由交换图逐项追踪：`γ` 单射 ⟹ `α` 单射。

**注意**：这张图的**左端花括号**把上、下两个 `Br(F/E)` 括在一起并标 `×[F(ζ_p):F]`，
不是「两条箭头之间的映射」——旧译曾错标，已按原 PDF（印刷页 106）重排，见 `ERRATA.md`。
