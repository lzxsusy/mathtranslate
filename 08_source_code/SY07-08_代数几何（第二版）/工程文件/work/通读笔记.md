## 一、三句话主旨

1. 本书在概形（scheme）上系统发展凝聚层的上同调理论，只要求读者具备 Atiyah–Macdonald 第 1–8 章的交换代数准备。
2. 覆盖 Grothendieck《Éléments de Géométrie Algébrique》(EGA) I–III 的主要材料：概形与态射、凝聚层、导出函子与谱序列、Čech 上同调、固有态射的上同调、高阶直接像的局部自由性，直到 Grothendieck 存在定理。
3. 它针对 Hartshorne 的两处不足而写：Hartshorne 只在射影态射情形证明固有态射的重要定理，且几乎不展开谱序列技术；本书补上这两块，并刻意与 Hartshorne §1.2、§1.4 少量重叠以保持自足。

## 二、作者意图与边界（序言要点）

- 第一版 2006 年由清华大学出版社出版（中文）；本英文第二版改正了第一版的错误、改进了表述、**新增了习题**（所以每节末的 Exercises 是第二版新内容，按节编号 1.,2.,…）。
- 作者另有一本 étale 上同调的书（World Scientific），覆盖 SGA 1, 4, 4½, 5, 7；本书 + Matsumura 构成读那本书的准备。
- **明确不包含**：如何用上同调方法研究代数簇的几何（相交理论等）；Serre 对偶。这些请读者查 Hartshorne 及其文献。
- 全书假设：所有环交换、含单位元 1，环同态把 1 送到 1。

## 四、体裁清单

- **正文条目**（共用一个计数器，按小节重置，编号 = 章.节.序号，如 1.2.3）：
  `Definition / Proposition / Theorem / Lemma / Corollary / Example / Remark / Construction`。
  → 中文环境：`definition / proposition / theorem / lemma / corollary / example / remark / construction`，编号自动生成。
- **习题**：每节末尾 `Exercises.`，编号 1.,2.,…（每节重置），全节共 3–10 题。
  → 中文 `exercises` 环境 + `enumerate`；引用格式「1.2 节习题 2」，label `ex:1.2.2`。
- **证明**：`Proof.` 起，□ 结尾。
- **交换图**：极多（尤其 1.3、2.1、2.2），含斜箭头、等号箭头、双行箭；全部用 `tikzcd` 按原图重画，逐图对图像核对。
- **无插图、无表格**（正文中没有 figure/table 环境；索引与参考文献是纯文本）。
- **编号公式**：正文中大量 `(1.2.1)` 式编号公式；中文版用 `equation`+`\label{eq:...}` 自动编号（按节）。
- **书的正文语言**：简洁的数学散文，句均 20 词左右，定义密集，跳步不多但常以「One can show that」「It is easy to see that」带过。

## 五、阅读顺序建议（译者也照此建立全局观）

1. 先读 1.1（范畴与层语言）→ 1.2（概形定义）→ 1.3（性质与相对观点）。这三节是全书的词汇表。
2. 再读 1.4（凝聚层与 Proj）与 1.5（形式完全化），后者若卡住可先跳到 2.7 看用途再回头。
3. 第 2 章按 2.1 → 2.2 → 2.3 顺序读（导出函子 → 谱序列 → Čech）；2.4 是前四节的第一个大验收；2.5–2.6 用 2.1–2.4 的机器；2.7 是全书收束。
4. 依赖关系：1.1 ⊂ 1.2 ⊂ 1.3 ⊂ {1.4, 1.5}；{2.1, 2.2} ⊂ {2.3, 2.4} ⊂ {2.5, 2.6, 2.7}。跨章引用：2.5 引 1.5（完全化）、2.4 引 1.4（扭层）、2.6 引 1.3（有限型/固有）。

## 六、翻译时要特别留意的点（通读发现）

1. **计数器共用一个**：定义/命题/定理/例/注/构造全部共用 1.2.3 式编号——翻译时不得漏条、不得加条，否则后文编号整体错位。
2. **习题编号与正文编号是两套**：习题 1.,2.,…，不参与 1.2.3 计数器。
3. **原书用 "O_X-module"**（不是 sheaf of O_X-modules 全称），中文写 `\cO_X-模`。
4. **原书大量用 (i)(ii)(iii) 分条**，中文保留 `(i)(ii)(iii)` 原样（与原文一致，便于对照）。
5. **"separated/quasi-separated/quasi-compact/proper" 的形容词式用法**密度极高（1.3），译文须统一：分离、拟分离、拟紧、固有。
6. 作者习惯："We leave to the reader to prove" → 「留给读者证明」；"By Zorn's lemma" → 「由 Zorn 引理」。Zorn 保留拉丁。
7. 1.5 与 2.7 的 Mittag-Leffler 条件、可代数化（algebraizable）是全书最易误解处，译注优先放在这里。
