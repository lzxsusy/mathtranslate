## 3. 译注（tnote）6 条

1. p.117 复形与上同调群定义之后：$B^i=\Image d^{i-1}$、$Z^i=\Ker d^i$ 的指标约定，与「上边缘态射」一词的用法（[依据：原书 p.117 定义式]）。
2. p.118 长正合序列构造之后：$\delta^i$ 的「图追踪」构造，及左/右正合函子的长正合序列来自蛇引理（[依据：原书 p.118–119]）。
3. p.119 内射对象定义之后：内射对象与「延拓性质」的等价、Baer 判据的范畴版；参 nLab「injective object」（[来源：https://ncatlab.org/nlab/show/injective+object ，访问日期 2026-11-14]）。
4. p.124 右导出函子定义之后：为什么要用 2.1.1(ii)(iii) 说明 $\R^iF$ 与内射分解的选取无关（[依据：原书 p.124]）。
5. p.128 可抹/可余抹定义之后：二者是对偶概念，原书只对共变情形陈述 2.1.4，反变情形由对偶范畴得到（[依据：原书 p.128 定义段]）。
6. p.131 2.1.6 证明之后：证明的三步骨架（Zorn 化归 → 造 $\cF\to\cI_1(\cF)$ → 超限归纳 + 基数论证），以及为何只依赖 $\cG$ 子模集合的基数（[依据：原书 p.131–133]）。

## 5. 存疑点（已逐页核对，均以 200dpi 页面图像为准）

- **p.130 大交换图**：四列竖直箭头在原书**全部印作 $\delta^{n-1}$**（$T'$ 侧两支也没有 prime），我放大 2.6 倍确认后照原书照录；随后收尾小图 $T'^{n-1}(C)\to T'^n(A)$ 的箭头原书亦作 $\delta^{n-1}$（不是 $\delta'^{n-1}$）。这是原书与常见教材写法的差异，未加注（属排印一致性，非笔误）。
- **p.131 2.1.6 首句**：原文 `I is injective if for every …` 只给一个方向（不含 only if），译文照译为「若…则 $\cO_X$-模 $\cI$ 是内射的」，未擅自补成充要条件。
- **p.132**：`$\phi'^{-1}(\cI_i(\cF))=\phi'^{-1}(\cI_{n'}(\cF))$` 中 $\phi'$ 是 $\cG'\to\cI_n(\cF)$ 的态射，原书对子模的原像写作 $\phi'^{-1}$，照录。
- **p.133**：基数不等式 $|\{i\in I:i<n\}|=\bigl|\bigcup_{j\in J}\{i\in I:i\le j\}\bigr|\le\sum_{j\in J}|\cS|\le|J||\cS|\le|\cS|$ 原书分三行排，已用 `aligned` 复现。
- **p.121–123 2.1.1 证明**中的三张大网格图按原书行列还原；p.122 `(f^n-g^n-d^{n-1}h^n)d^{n-1}=…` 的四行计算逐符号核对。
