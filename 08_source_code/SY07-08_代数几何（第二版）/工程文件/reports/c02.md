## 二、译注（3 条）

1. **层化中条件 (b) 不可省**：仅 (a) 得到的芽族一般不是层、$\theta_P$ 也未必同构；直观上 $\cF^+$ 是把 $\cF$ 的截面按「局部相等」等同后的最小层。[依据：原书 p.10 命题 1.1.5 的证明与 p.11 第 1 段]（p.11 之后）
2. **推论 1.1.8 (i) 的「子集」疑为「开子集」之误**：预层只在开子集上有定义，且 (ii) 明确写「开子集」；译文照录原文，读者按「开子集」理解。[依据：原书 p.12 推论 1.1.8 的 (i) 与 (ii)]（1.1.8 证明之后）
3. **(ii) 与 (i) 的对比**：预层可逐开集检验正合，层的正合不能用开集刻画——层的满射只是局部提升截面，不保证 $\cG(U)\to\cH(U)$ 满（见 1.1.8 (iv)），故只能用茎。[依据：原书 p.12–13 推论 1.1.9 与 p.12 推论 1.1.8 (iv)]（1.1.9 之后）
