1. **全量抽取**：脚本解析每个 `tnote` 块，记录所在块、起始行、结尾来源标记类型。
2. **A 类（缺来源）**：检查块内是否出现 `[依据：` / `[来源：` / `[译者按`。
3. **B 类（来源格式 / 黑名单）**：检查是否出现知乎、百度百科、CSDN、简书、公众号、B 站、个人博客等黑名单域名；检查 nLab / Stacks Project 是否给出 URL 或 Tag。
4. **C 类（依据对不对得上）**：
   - 先把译注里引用的 `\ref{it:a.b.c}` 用 `工程文件/work/items.tsv`（条目→原书页索引）解析，比较引用页是否落在该条目起始页或其后 1–2 页内；
