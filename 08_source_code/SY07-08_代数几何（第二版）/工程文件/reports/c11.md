## 3. 译注（tnote）4 条

1. p.134 Tor 的公式之后：$\Tor_i^A(M,N)\cong H^{-i}(M\tensor_A P^\cdot)$ 用的是上同调编号（因书中投射分解按上链编号 $P^{-1}\to P^0\to0$），并给出同调编号下的写法（[依据：原书 p.119 分解的编号与 p.134 的公式]）。
2. p.137 2.1.10 证明之后：Godement 分解 $C^\cdot(\cF)$ 的函子性来自「只用茎与松弛层」，配合 2.1.11 即可直接算 $H^i$（[依据：原书 p.136–139]）。
3. p.142 2.1.15 证明之后：$\Ext^1$ 与扩张的对应是 Yoneda 型对应，$\Phi$ 取拉回、$\Psi$ 取推出，两段「与选取无关」的论证分别对应 $d^0f$、$d^0\delta$（[依据：原书 p.141–142 的构造与两张交换图]）。
4. p.147 2.1.23 证明之后：2.1.21 (v)+2.1.20 (iv) 给出忠实平坦的几何含义（$\Spec B\to\Spec A$ 满），并说明 2.1.23 为何等价于 $I\subset\operatorname{rad}(A)$（[依据：原书 p.146–147，命题 2.1.21 (iv)(v) 与推论 2.1.23]）。

## 5. 存疑点（均以 200dpi 页面图像为准核对）

- **2.1.17 (iv)**：原书只写「有限生成的 $0\to N'\to N$」，未写右端 $N\to N''\to0$，译文照录（因为 (iv) 只需这一段就够）。
- **2.1.21**：原书证明只给出 (i)⇒(ii)⇒(iii)⇒(iv)⇒(i) 与 (i)⇒(v)，**未证 (v)⇒(i)**（已核对 OCR p.147 与页面图像，原书确实止于 (i)⇒(v) 的 □）。译文照录，未代补证明。
- **2.1.23 第一段**：由 1.5.7 得 $\widehat I\subset\fn$（$\fn$ 为 $\widehat A$ 的极大理想），此处 $\widehat I$ 指 $I\widehat A$；译文写 $\widehat I$ 并保留 $\phi^{-1}(\widehat I)=I$ 的显式式子，避免读者误读为 $I\subset\fn$。
- **2.1.10 命题陈述**：原书说「对任意 $i$，函子 $\cF\mapsto C^i(\cF)$ 正合」，译文按「函子 $\cF\mapsto C^i(\cF)$ 与 $\cF\mapsto\coker d^{i-1}_{\cF}$ 都正合」表述，与证明中两步一致。
- **2.1.11 证明**：$s_{ij}=s_j-s_i$ 的符号约定与 $s_{i_0j}-s_{i_0i}$ 的恒等式逐符号核对；原书此处有两个不同下标的 $s_{i_0i}$、$s_{i_0j}$，已放大确认。
