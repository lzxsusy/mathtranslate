## 5. 正文现有 `\idx` 键的缺陷清单（**需要你裁决 / 脚本要先处理**）

1. **同音同键（真冲突）**：`zhiji` 同时登记「直积」(`c01b.tex:2`) 与「支集」(`c07.tex:4`)。本表 `直积=zhiji`、`支集=zhiji2`（加后缀 2 去重），正文两条里必须改一条。
2. **同键两义**：`nijin` 同时用于「拟紧」(`c03.tex:60`) 与「拟紧态射」(`c04.tex:228`)。本表 `拟紧=nijin`、`拟紧态射=nijintaishe`（新键），建议改 c04 那条。
3. **键含大写/连字符，不符合「小写 ASCII 无空格」**：正文里有 `OXmo`、`Sgaixing`、`S-taishe`、`Picardqun`、`Segreyuqianru` 五个键。**本表已按规范改成** `oxmo`、`sgaixing`、`staishe`、`picardqun`、`segreyuqianru`（复合词同理：`ningjuoxmo`、`kedaishuhuaoxmo`、`oxmoceng`），原键名写入 note。正文这五个键需按表改名，否则脚本会认为是两个术语。
4. **同一术语两种写法**：Picard 群 = `Picardqun`(`c06.tex:51`) 与 `picardqun`(`c14.tex:433`)；类群 = `leiqun`(`c14.tex:604`) 与 `cartierleiqun`(`c14.tex:552`，显示「Cartier 类群」)。
5. **拼写疑误**：`succhuzi`（素除子，应为 `suchuzi`，`c14.tex:592`）；`cechshangtongtiaoqun`（应为 `cechshangtongdiaoqun`）。
6. **一个键挂「带修饰」的显示**：`shangbianyuan` 的显示是「上边缘态射」，于是索引条目「上边缘」(coboundary) 无处挂。本表：`上边缘=shangbianyuan`、`上边缘态射=shangbianyuantaishe`（新键），是否拆键请你定。
7. **显示参数里含 `\v{C}` 花括号（脚本必读）**：`cechfuxing`、`cechshangtongtiaoqun`、`jiaocuocechfuxing`、`cengtadecechfuxing` 四条 display 形如 `\v{C}ech 复形`。用 `\\idx\{([^}]*)\}\{([^}]*)\}` 这类简单正则提取会截断成 `\v{C`，并使后续匹配整体错位（我第一遍扫描就被这个坑到，误判为编码问题）。建议把 display 改成 `\v C`（无花括号）或字面字符 `Č`，或让脚本按花括号配对解析。
8. **重复登记同一 (键, 显示)**：`touying`、`fencihuan`、`baopo`、`lixiangceng`、`shuangfuxing` 各出现 2 次。无害，但批量补 `\idx` 时应按 (键, 显示) 去重。

## 8. 使用建议

1. 脚本补 `\idx` 时以本表 `pinyin` 列为**唯一键**；遇「同键 + 同显示」直接跳过（去重）。
2. 先修 §5 的 1/2/3/5 四类（同键冲突、大写键、拼写疑误），再批量补 §7 的高频词，否则同义条目会分裂。
3. 补索引时优先在**术语首次出现处**加 `\idx{键}{显示名}`（glossary 的 `first_page` 即此约定）；本表 `book_pages` 可用于核对首次出现页。
4. `note` 列里凡标「沿用正文键」的条目，键已存在于正文，**不要新建另一套键**。
