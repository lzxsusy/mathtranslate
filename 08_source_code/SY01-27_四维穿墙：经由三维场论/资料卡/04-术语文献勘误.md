## 二、记号对照（原文宏 → 译本）

| 原文宏 | 含义 | 译本用法 |
|---|---|---|
| `\degen` | BPS 简并度 $\Omega(\gamma;u)$ | 原样保留 `\degen`，渲染为 $\Omega$ |
| `\vm` | **4d** 库仑分支（复维 $r$） | `\vm`；正文「模空间 $\mathcal{B}$」 |
| `\CM` | **3d** 模空间（$\mathbb{R}^3\times S^1$ 上），是 $\mathcal{B}$ 上的环面丛 | `\CM`；勿与 `\vm` 混 |
| `\clat` | 电荷格 $\Gamma$（或 $\Gamma_u$） | `\clat` |
| `\hsymp` | 全纯辛形式 $\varpi(\zeta)$ | `\hsymp` |
| `\pz` | $(\zeta)$ 作为上标 | `\pz` |
| `\hk` / `\qk` / `\kahler` | 超凯勒 / 四元数凯勒 / 凯勒 | 同前，**已去掉 `\xspace`**（否则中文中间多空格） |
| `\sf` | `\mathrm{sf}`（半平坦上标） | preamble 中 `\renewcommand\sf{{\mathrm{sf}}}`（缺它会 86 处 `Missing {`） |
| `\CX`、`\CK`、`\CO`、`\CN` | 花体 $\mathcal{X}$、$\mathcal{K}$、$\mathcal{O}$、$\mathcal{N}$ | 同前 |
| `\IC`、`\IR`、`\IP`、`\IZ` | $\mathbb{C}$、$\mathbb{R}$、$\mathbb{P}$、$\mathbb{Z}$ | 同前 |

**公式编号**：`\numberwithin{equation}{section}`，与原文「按节编号」一致；原文不编号的行间公式译本用 `\[...\]`，不占号。

## 三、勘误（原文自身的问题）

译本一律「照录 + 译注」或「按 PDF 更正 + 译注」，不改动原文的数学内容。

| # | 位置 | 原文问题 | 译本处置 |
|---|---|---|---|
| 1 | 附录 A（原文 3365 行，式 A.11 附近） | 印作 `$X_{2,1}={}^{-1}x_2$`，上标错位 | 更正为 $x_2^{-1}$，并加译注说明 |
| 2 | 式 (6.1) | 质量项里的 $m$、$q$ 缺下标 $i$，与下文同类式子不一致 | 照录，译注 5 指出 |
| 3 | 式 (4.42) 第二行 | `\left( \dots \biggr)` 括号嵌套可疑 | 照录（配平、编译无碍），不擅自改 |
| 4 | 式 (6.6) | 源码含损坏字节 U+FFFD（PDF 中该处字符缺失） | 按 PDF 显示略去该字符，不影响式子 |
| 5 | 附录 B 首段 | 「fix $\bar\zeta$ and let $\zeta$ vary」，随后又写 $J^{(\zeta=0,\bar\zeta)}$，自相矛盾（应为固定 $\zeta$、让 $\bar\zeta$ 变，或反之） | 照录，译注指出底本笔误 |

> 另有 1 处**未发表内容**：原文 §5.1 前有一段整段被 `%` 注释掉（「Shifting the BPS rays」小节，原文 2271–2319 行），不在发表版中，译本**未译**——这是有意为之，不是漏译。
