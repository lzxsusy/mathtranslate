# 资料卡 · 02 论证地图

本文不是「定理—证明」式论文，而是一条**接力链**：物理设置 → 扭量构造 → 黎曼–希尔伯特问题 → 积分方程 → 度量 → 反过来证明 WCF。下面把这条链拆成可复核的步骤；每步给「依据」（节 / 式）与「若缺这一步会坏在哪」。

## 一、主链 D1–D10

### D1 4d → 3d 约化：BPS 粒子变瞬子（§1，译本 p5；§2.3，p15–17）

把 $d=4$、$\mathcal{N}=2$ 理论放在 $\mathbb{R}^3\times S^1$（$S^1$ 半径 $R$）。低能有效理论是以 $(\mathcal{M},g)$ 为靶空间的 $d=3$ sigma 模型，其中 $\mathcal{M}$ 是 4d 库仑分支。4d 的 BPS 粒子绕 $S^1$ 缠绕成 3d 的**瞬子**，其作用量 $\propto R\,|Z_\gamma|$。

- **依据**：§1（p5–6）；§2.3。
- **坏在哪**：没有这一步就没有「大 $R$ 展开」这个唯一的计算工具；§5–§7 全部建立在 $1/R$ 逐阶近似上。

### D2 度量连续性 ⇒ KS 公式的雏形（§1，p5–7）

$g$ 作为物理度量必须连续（低能有效作用量里不应出现无源奇点）。但对固定 $R$：跨过边缘稳定墙时 $\Omega(\gamma;u)$ 跳变，单瞬子贡献随之跳变。于是**单个瞬子的跳变必须由多瞬子贡献补偿**。作者指出，这个补偿关系在数学上就是 KS 乘积。

- **依据**：§1；§2.2 的 (2.18)（KS 乘积）、(2.19)（截断逐阶求解）。
- **坏在哪**：这是全文的「为什么」；没有它，后面所有构造只是「造出了一个度量」，不能说它就是物理度量，更不能反推 WCF。

### D3 扭量数据：把超凯勒结构换成 $\zeta$ 上的全纯数据（§3，p18–21）

超凯勒三复结构 $J_1J_2=J_3$ $\Rightarrow$ 一族复结构 $J^{\zeta}$（$\zeta\in\mathbb{CP}^1$）与全纯辛形式 $\varpi(\zeta)=-\frac{i}{2\zeta}\omega_++\omega_3-\frac{i}{2}\zeta\omega_-$。反向的**关键命题**（§3.2）：只要 $\varpi(\zeta)$ 满足三条性质（$\zeta\to0,\infty$ 的极点结构、$\zeta$-全纯性、实性），就唯一确定一个超凯勒度量 $g$。

- **依据**：§3.1–§3.2；§4.2 的超凯勒结构显式验证。
- **坏在哪**：这一步把「解度量」降级为「找一个 $\zeta$-全纯的辛形式族」；没有它，后面的 RH 问题无从谈起（RH 问题的未知量 $\mathcal{X}_\gamma$ 正是 $\varpi$ 的达布坐标）。

### D4 最简算例：$U(1)$ + 单个超多重态（§4，p22–34）

电荷 $q$ 的单超多重态。度量是 2-环面丛上的显式解，与 Ooguri–Seiberg 的已知精确解**逐项相符**；$\mathcal{X}_e$ 连续、$\mathcal{X}_m$ 跨 BPS 射线按 (4.52) 跳变，$(\mathcal{X}_m,\mathcal{X}_e)$ 给出映射 $\mathcal{X}:\mathcal{M}_a\to T_a$（4.53）。

- **依据**：§4.1（精确度量）、(4.11)（跑动耦合）、(4.30)、(4.52)、(4.53)。
- **坏在哪**：这是全篇唯一可逐式验算的算例，也是「跳变 = KS 辛同胚」的原型；跳过它，§5.1 的 RH 问题定义会显得凭空而来。

### D5 一般情形：无穷维黎曼–希尔伯特问题（§5.1，p35–38）

把 D4 的 $\mathcal{X}$ 推广到所有电荷：$\mathcal{X}_\gamma(u,\theta;\zeta)$ 在 $\mathbb{CP}^1$ 上分段全纯，跨每条 BPS 射线 $\ell$ 跳变 $\mathcal{X}^+=\mathcal{X}^-S_\ell$，其中 $S_\ell=\prod_{\gamma\in(\Gamma_u)_\ell}\mathcal{K}_\gamma^{\Omega(\gamma;u)}$；外加 $\zeta\to0,\infty$ 的渐近条件与实性条件。

- **依据**：§5.1（含「线性化」讨论与实性条件 $\bar{\mathcal{X}}_\gamma(\zeta)=\overline{\mathcal{X}_{-\gamma}(-1/\bar\zeta)}$）。
- **坏在哪**：问题定义一旦写错（跳变方向、复合次序、实性条件），解就不存在或不唯一；文中专门有一条脚注说明锥乘积取逆时针次序与 §2.2 顺时针的差别。

### D6 枢纽：RH 解对 $u$ 的连续性 ⇔ KS 公式（§5.2，p38–39）

设每个 $u$（远离墙）都有解。跨墙时两侧的极限若都存在，则「两侧一致」$\iff$ 两侧的总跳变 $A=\prod^{\curvearrowleft}_{\gamma=n\gamma_1+m\gamma_2}\mathcal{K}_\gamma^{\Omega(\gamma;u)}$ 相同 $\iff$ **KS 公式**。

- **依据**：§5.2；(2.18)。
- **坏在哪**：这一步把 WCF 从「猜想」变成「构造的自洽性条件」；它是 §7 反推证明的入口，也是本文标题「wall-crossing via 3d field theory」的字面含义。

### D7 求解：积分方程与 $1/R$ 展开（§5.3，p39–40；附录 C，p54–59）

把 RH 问题写成 Cecotti–Vafa 型的积分方程（(5.12)，代入 (2.16) 得显式形式 **(5.13)**），$R$ 大时迭代求解：存在性 + 首阶修正 (5.14)（单瞬子线性叠加），高阶项带 $R$ 依赖（多瞬子）。

- **依据**：§5.3；附录 C（有限维 $tt^*$ 的重新分析 + 无穷维推广）。
- **坏在哪**：不给出解，§5.4–5.7 的 $\varpi(\zeta)$ 与度量都无定义；而「首阶修正 = 单瞬子」正是 §7 最后一步识别斯托克斯因子的依据。

### D8 造度量并与物理比对（§5.4–5.7，p40–46）

由 $\mathcal{X}$ 构造 $\varpi(\zeta)$ 与 CR 方程（5.30–5.35）$\Rightarrow$ 超凯勒度量 $g$（封闭形式 + 大 $R$ 渐近）。§5.7 列出五条性质（连续、半平坦极限、光滑性与奇点位置、$\mathrm{vol}=R^{-r}$、$J_3$ 下即 SW 纤维化且 $\omega_+=-\frac{1}{4\pi}\langle dZ,d\theta\rangle$），逐条与物理预期对上。

- **依据**：§5.4–§5.7；(5.30)–(5.35)；性质 1 依赖 D6（连续性来自 WCF）。
- **坏在哪**：性质 1 是循环的关键——它正是「WCF 成立」的等价说法；作者在 §5.7 明说「最简单的自洽图像就是我们构造的度量确实就是物理度量」，这是**论证**而非证明。

### D9 加质量（§6，p46–47）

质量 $m_i$ 与三维周期质量 $\psi_i=2\pi Rm^3_i$ 进入修正项；味荷出现；标度/$U(1)_R$ 不变性写成 (6.13)–(6.14)。

- **依据**：§6.1–§6.2。
- **坏在哪**：没有质量参数，§7 的第 ③ 步（反常 Ward 恒等式）无法覆盖有味对称的一般情形。

### D10 反推：直接从规范理论证明 WCF（§7，p48）

不假设度量形式，只从物理导出 D8 所用的同一组方程：① CR 方程（5.30–5.31）来自约化理论的 $\mathcal{N}=4$ 超对称；② (5.32–5.33) 与 CR 方程同形（$\Lambda$ 当背景矢量多重态，非重整化定理技巧，参 Seiberg 1993）；③ (5.34–5.35) 来自反常 $U(1)_R$ 与标度不变性（反常 Ward 恒等式）；④ 斯托克斯因子在 $R$ 下不变，取 $R\to\infty$ 用单瞬子修正（D7）识别它，得 (7.1)。

- **依据**：§7；(5.30)–(5.35)；(5.42)、(5.43)、(6.13)、(6.14)；附录 B（①的几何意义）。
- **坏在哪**：④ 是唯一「识别」而非「导出」的一步，也是作者说「at least at a physical level of rigor」的原因。

## 二、依赖图

```
D1 4d→3d 约化
 └─ D2 连续性 ⇒ KS 雏形
      └─ D3 扭量数据（§3）
           ├─ D4 最简算例（§4）── 原型
           └─ D5 RH 问题（§5.1）
                ├─ D6 连续性 ⇔ KS（§5.2）   ← 枢纽
                └─ D7 积分方程 + 大 R（§5.3, 附录 C）
                     └─ D8 造 g + 五条性质（§5.4–5.7）
                          └─ D9 加质量（§6）
                               └─ D10 反推证明（§7）
```

**注意**：D6 与 D8 之间有**循环**——D8 的性质 1（连续性）用 D6，而 D6 假设解存在（由 D7 提供）。本文的破环方式是：把「解存在 + 连续」当作构造的**输出**，再验证它与物理度量相符；§7 则绕开整个构造，从物理直接得到方程。读的时候要清楚自己在环的哪一段上。

## 四、如果只记三件事

1. **物理要求度量连续**，而 $\Omega$ 会跳变——这个张力由 KS 乘积消化（D2 + D6）。
2. **扭量构造把几何问题变成 $\zeta$ 上的全纯问题**，RH 问题给出 $\mathcal{X}$，$\mathcal{X}$ 给出度量（D3 + D5 + D8）。
3. **§7 把方向倒过来**：物理 $\Rightarrow$ 方程 $\Rightarrow$ 斯托克斯因子 = KS 乘积 $\Rightarrow$ WCF（D10）。
