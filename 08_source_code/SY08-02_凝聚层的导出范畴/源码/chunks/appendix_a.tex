\section{译名取舍的几条原则}

\begin{enumerate}
  \item \textbf{有稳定通行译名者一律用中文}，并尽量采用国内教材的写法。“三角范畴”“特异三角”“正合函子”“厚子范畴”均属此类；其中 distinguished triangle 一词，国内有“特异三角”“ distinguished 三角”“正合三角”几种写法，本稿统一取“特异三角”，因为 exact triangle 在原文中另有所指（无特异结构时的三角），两者不宜混用。
  \item \textbf{无稳定译名或两种译名并行者保留西文}。flop 即属此类：国内有“翻转”“翻折”“弗洛普”等写法，无一通行，故正文一律写 flop，首次出现时以译注说明其含义（极小模型理论中的一种双有理变换，与 flip“翻转”相对）。
  \item \textbf{人名一律保留拉丁字母}，不音译。Fourier--Mukai、Postnikov、Koszul、Verdier、Serre、Grothendieck、Bondal--Orlov 等均照写；首次出现时给出全名（如“Mukai 的 Fourier 变换”）。
  \item \textbf{同一英文词在不同语境下的译法若确有分别，则分别固定}，并在注释中标明。例如 complex 在链复形语境下译“复形”，在概形语境下（与 real 相对）译“复的”，本稿以“复形”“复流形”区分。
  \item \textbf{译名一经固定，并行施工期间只读不改}。凡施工中发现新的、更合适的译法，先提案，待全稿统一处理，不在单章内擅自更改。
\end{enumerate}
