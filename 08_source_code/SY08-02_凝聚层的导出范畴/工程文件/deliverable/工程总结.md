# 工程总结 · SY08-02《凝聚层的导出范畴及其之间的等价》中文译注本

## 一、任务与底本

- 底本：D. O. Orlov, *Derived categories of coherent sheaves and equivalences between them*,
  Russian Mathematical Surveys **58**:3 (2003), 511–591；俄文原刊 Uspekhi Mat. Nauk **58**:3 (2003), 89–172。
- 规模：81 页（书页 511–591），五章 + 引言 + 参考文献 44 条。
- 产出：中文译注本（正文全译 + 术语对照表 + 译注汇编 + nLab 概念批注 + 定理索引），
  排版 100 余页，逐页对照原书页标记。

## 二、工序（按《数学文献翻译纪律》）

1. **提取**：`stage2.py` 用 pymupdf 逐页导出文字层（`work/text/`、`work/全文.txt`，页界 `===== BOOK PAGE N =====`），
   并 200 dpi 渲染 81 张页图（`work/pages/pNNN.png`，NNN = 书页 − 510）。
2. **通读**：`work/通读笔记.md`（主旨、论证地图、体裁清单、阅读顺序）与 `work/疑点清单.tsv`
   （17 条：类型、初步猜测、查证动作、结论、依据、状态）。
3. **定体例**：`工程文件/STYLE_GUIDE.md`（约 340 行）冻结章节译名、陈述环境 API、
   两类译注（`\yizhu` 可见 / `% [Tutor Note]` 只进附录）、来源分级与黑名单、语言与 LaTeX 硬规则。
4. **分块施工**：13 个块（引言、五章共 9 块、参考文献），每块由一位译者完成，
   交 `src/chunks/<块>.tex` + `work/reports/<块>.md`（六节报告）+ `work/proposals/<块>.tsv`（术语提案）。
5. **集成与校验**：Lead 统一编译、抽图、生成附录、写交付物。

## 三、翻译体例要点

- 陈述（定义/定理/命题/引理/推论/例/注）一律**照抄原书编号**，不用 LaTeX 自动编号；
  公式编号同样手工 `\tag{}`，全书保留原书 (1)–(46)。
- 每页起首写 `% [原文 p.N]`（N 为印刷页码），不进版面，用于逐页对账与附录 B/D 定位。
- 两类批注：
  * `\yizhu{…}`：概念性、可见，末尾须带 `【来源：…】`（A 级原书/经典教材，B 级 nLab/Stacks，须标注待核）或
    `〔译者按（上下文推断，无外部依据）：…〕`；
  * `% [Tutor Note: …]`：校勘性、不进正文，由 `tools/gen_notes.py` 汇总为附录 B。
- 原书笔误、页图与文字层不一致处**一律照录并批注**，不静默改字。

## 四、遇到的问题与处理

| 问题 | 现象 | 处理 |
| --- | --- | --- |
| 文字层公式不可信 | `q^T_X⊗ω^k_X` 抽成 `qTX ⊗ωk X`，交换图散成单字符 | 公式、交换图一律回页图核对；页图 200 dpi 随每块下发 |
| 交换图无法矢量抽取 | `page.get_drawings()` 全为 0：原书 PDF 是整页位图，箭头是文字层里的破折号/箭头字形 | 先试位图裁切（4 个脚本、8 轮校对），仍无法稳定分离正文行；**最终改为 TikZ 重绘**，由各块译者对照页图重排 |
| 并发编译互相覆盖 | 8 个译者同时 `lualatex`，`main.pdf/aux/log` 互相踩踏，出现 `! \OML/cmm/m/it/10.95` 之类怪错 | 每位译者用独立 `-output-directory=build_<块>`；Lead 用 `build` |
| 中文路径 | 仓库路径含中文，MiKTeX 无法写入 | 工作树用全 ASCII `orlov_derived_work\src\` 编译，交付时再镜像到仓库 |
| 西里尔字母缺字形 | `Missing character: There is no У (U+0423) in font lmroman10-italic` | preamble 引入 `\cyrfont`（Times New Roman / DejaVu Serif 回退） |
| `description` + `\item[附录 A]` 在 xelatex 下报错 | `! Argument of \enit@postlabel@i has an extra }` | 改用 `itemize` + `\item \textbf{附录 A}\quad …` |
| 附录 B 分组重复 | 同一章被切成两个「第 3 章」小标题 | `gen_notes.py` 改为按章合并后再排序 |
| 定理索引漏条目 | `\begin{lemma}[{[6]、[8]}]{1.1.2}` 因附加名含 `]` 被正则漏掉 | 正则改为允许一层嵌套方括号，条目由 60 增至 111 |
| 英文引文里的希腊字母 | `◦ α =` 未进数学模式，全书 3 条缺字 | 改成 `◦ $\alpha$ =` |
| 章末评注粘连 | `reviewbox` 未设段间距 | 加 `parskip=0.6em`（`takeawaybox` 加 0.4em） |

## 五、产出清单

- `src/`：`main.tex`、`preamble.tex`、`chunks/`（13 块 + 附录 A–D + 参考文献）、`frontmatter/`、`figures/`
- `tools/`：`stage2.py`（提取+渲染）、`pdf2png.py`、`crop.py`、`gen_terms.py`、`gen_notes.py`、`gen_index.py`、`pack.py`
- `work/`：通读笔记、疑点清单、分块源文本、页图、各块报告与术语提案、术语表
- `工程文件/`：STYLE_GUIDE、BRIEF、deliverable/（成品 PDF、README、研读札记、术语对照表、译注汇总、阅读参考指南、统计数据）

## 六、经验

1. **页图是唯一权威**。文字层能省一半工夫，但公式、下标、上下标、箭头方向必须回页图；凡「怎么抽都不对」的地方，九成是文字层坏了，不是原文错了。
2. **体例要前置**。陈述编号 API、译注两类、来源分级若不定死，13 个块的风格会各走一路，集成时改不回来。
3. **并发要隔离输出**。共享 `main.pdf` 是最容易浪费一小时的地方。
4. **图不要硬抽**。位图版式里，图与正文在同一文字层里，几何分离的判据总会漏；重绘反而更快、更一致。
