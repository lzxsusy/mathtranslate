# 阅读参考指南

这本书不是通读的书。Orlov 这篇综述密度极高，五章各自服务于不同的目的，读法应当随目的而变。
下面按「你想得到什么」给出四条路径，并附几条使用建议。

## 一、只想知道「导出范畴能决定什么」——两小时的路径

1. **引言**（本书 p.1–5）：三问三答的提纲。抓住三句话：光滑完备簇的导出范畴之间的正合函子都可以由积上的一个对象给出（第 3 章）；
   典范层或反典范层丰富时，$X$ 可以由 $\Db(X)$ 还原（定理 2.1.3）；自等价群是 $\operatorname{Pic}(X)\oplus\Z$ 加上自同构（定理 2.1.4）。
2. **定理 2.1.3 与 2.1.4 的陈述**（本书 p.23–28）：连同 §2.1 末的不变量讨论（$\HA(X)$、霍奇菱形竖列、陈特征与 $K$ 群）一起看，
   这是全书「导出范畴保留了几乎全部信息」这一主张的精确形式。
3. **定理 3.2.1 与 3.2.2**（本书 p.40–41）：全忠实 + 有右伴随 ⇒ 函子由核对象给出。这是第 3 章的主定理，也是引言中「等价总是几何的」的技术兑现。
4. **§2.2 的开头与定理 2.2.8**（本书 p.29–31）：半正交分解的最重要来源————爆破。

这条路径跳过了所有技术证明，但已经拿到全书的骨架。

## 二、要动手算一个例子——读第 2 章与第 4、5 章之一

- **flop 的例子**（§2.2，本书 p.29–38）：$Y\cong\PP^k$ 以法丛 $\cO_Y(-1)^{\oplus(l+1)}$ 嵌入 $X$，$l\leqslant k$ 时 $X$ 与 flop $X^+$ 的导出范畴等价（定理 2.2.10），
  $l<k$ 时只全忠实（定理 2.2.9）。这里的算术（式 (20)–(24)）是全章最值得抄一遍的部分。
- **K3 曲面**（第 4 章，本书 p.62–68）：判别准则是 Mukai 格上的 Hodge 等距（定理 4.2.1、4.2.4）。
  读之前先接受两件事：$\Db(S)$ 上有一个自然的格结构 $\tilde H(S,\Z)$，以及「等距」必须保 Hodge 分解。
- **阿贝尔簇**（第 5 章，本书 p.69–85）：等价于「等距同构 $f:A\times\hat A\to B\times\hat B$」（定理 5.1.16），
  自等价群有正合列 $0\to\Z\oplus(A\times\hat A)_k\to\Auteq\Db(A)\to U(A\times\hat A)\to1$（§5.3 末）。
  第 5 章的技术路线与第 4 章不同：它不是靠格的等距，而是靠半齐次向量丛的构造（§5.3）。

## 三、要学「三角范畴 + Fourier–Mukai」这套语言——读第 1 章 + 第 3 章前两节

- 第 1 章（本书 p.6–20）是全书的地基，但它不是教科书式的叙述：Verdier 公理只用一次，重点在**局部化**
  （分式演算 L1–L4、右余终子范畴、$\D/\cN$）与 **Deligne 的导出函子构造**（命题 1.1.9）。
  若你只熟悉「导出范畴 = 复形范畴的局部化」这一定义，第 1.1 节的 Serre 函子部分（定义 1.1.3 与引理 1.1.4–1.1.5）会是新的。
- §3.1 的 Postnikov 系统与卷积（本书 p.37–39）是第 3 章唯一的技术机器：先把条件 (25)–(28) 记住，
  后面所有「同构唯一确定」的论证都靠它。
- 补充读物：nLab 的 `triangulated category`、`derived category`、`Fourier-Mukai transform` 三条，
  本书**附录 C** 逐条给出了它们与原书的对应与差异（尤其：nLab 在 $(\infty,1)$ 层面表述，
  而 Orlov 用经典分式演算；nLab 的 `semiorthogonal decomposition` 只列两条公理，原书定义 2.2.3 还要求每项可容许）。

## 四、要引用其中的结果——先读附录 B 与附录 D

- **附录 D**（定理与定义索引）按出现顺序列出 111 条带编号的陈述与 53 个编号公式，每条标注原书页码，
  用于从「定理 3.2.1」这类引用快速跳到正文。
- **附录 B**（译注汇编）分「［校勘］」与「［概念］」两类：
  校勘记记录原书笔误、页图与文字层不一致、术语取舍理由（例如 §5.2 原书把核命题与推论都印作 5.2.4，而引言引作 5.2.3）；
  概念批注解释术语与工具的背景。
  **引用原书之前建议扫一眼对应页的校勘条**，以免把原书的排版错误当成数学内容。
- 原书只有 44 条参考文献、且多为 1990 年代的文献。若要把某个结论接到当代文献上，
  附录 C 里 nLab 条目的「补充」段落给了一些线索（例如定理 3.2.1 中「有右伴随」这一假设可去，
  见 Bondal–van den Bergh 2002；非 Fourier–Mukai 型三角函子的反例见 Rizzardo–Van den Bergh 2015）。

## 五、使用建议

1. **页码对账**：源码里 `% [原文 p.545]` 是原书印刷页码；本书正文不印原书页码，
   需要对照时查附录 D 的条目页码，或按「书页 = 原书页码 − 510」自行换算 PDF 页。
2. **译注与校勘不同**：正文里的〔译注〕框是给人看的补充；标着「［校勘］」的只出现在附录 B，
   它们是「原文如此，不是译错」的登记。
3. **符号表**：本书不单设符号表；记号在首次出现处就地说明，全部记号宏见 `src/preamble.tex` 末段
   （$\Db$、$\Rf$、$\Lf$、$\otL$、$\cO$、$\PP$、$\Ext$、$\RHom$ 等）。
4. **不建议跳读的地方**：§3.3–§3.4 的构造与证明（本书 p.42–61）是全篇技术核心，
   若跳过，第 3 章的主定理就只能当黑箱引用；至少读 §3.3 开头的路线说明（那一节开头的三段话把「先放大、再切掉」讲清楚了）。
