# 通读笔记 —— Orlov 2003 综述

底本：D. O. Orlov, *Derived categories of coherent sheaves and equivalences between them*,
Russian Math. Surveys 58:3 (2003) 511–591（81 页，书页 = PDF 页 + 510）。
本笔记依房规 §1.0 先于译文写成，是逐章细读后的滚动记录。

---

## 一、三句话主旨

1. 光滑完备簇之间的**任意**导出范畴等价，都由积簇上的一个对象（核）给出，即都是 Fourier–Mukai 型函子 Φ_E
   （定理 3.2.1，正文亦称主定理）。
2. 由此可以把「导出范畴等价」翻译成几何–格论条件，从而在两类簇上得到完全的分类：
   K3 曲面（Mukai 格的霍奇等距，定理 4.2.1/4.2.4）与阿贝尔簇（A×Â 上的等距同构，定理 5.1.16）。
3. 沿途建立三套工具：半正交分解（第 2 章）、Postnikov 系统与卷积（第 3 章）、
   以及代表函子与自等价群的计算（第 5 章）。

## 四、阅读顺序建议（写进附录 C 与交付说明）

1. **只想懂主定理**：引言 → §2.1（Lemma 2.1.1、Thm 2.1.3、Thm 2.1.5）→ §3.1 → §3.2 → §3.3–3.4 的证明骨架。
2. **想做 K3**：主定理 → §4.1（Mukai 格）→ §4.2（Thm 4.2.1 的证明，注意 Chern 特征与 Todd 类的计算）。
3. **想做阿贝尔簇**：主定理 → §5.1（等距同构与 U(A×Â)）→ §5.2（自等价群的正合列）→ §5.3（半齐次丛的第二证明）。
4. **想学三角范畴的技术**：§1.1（Serre 函子、分式演算、Deligne 构造）→ §2.2（半正交分解）→ §3.1（Postnikov 系统）。

## 五、与 nLab 的对应（附录 C 的骨架）

| 本文概念 | 原书位置 | nLab 条目（拟） | 差异要点 |
|---|---|---|---|
| triangulated category | §1.1, p.517 | `triangulated category` | nLab 用 (TR1)–(TR4) 编号，且把 T4 称 octahedral axiom；Orlov 的 T3/T4 顺序与 nLab 不同 |
| exact functor | Def 1.1.1 | `exact functor` / `triangulated functor` | nLab 区分 exact 与 triangulated |
| Serre functor | Def 1.1.3 | `Serre functor` | nLab 强调与 Serre duality 的联系与 Calabi–Yau 情形 |
| localization / calculus of fractions | §1.1, p.520–521 | `localization of a category`、`calculus of fractions` | Orlov 用左分式演算 L1–L4；nLab 用 Gabriel–Zisman |
| derived category | Def 1.2.3 | `derived category` | nLab 从 (∞,1)-范畴的视角重述（D(A) 是 chain complexes 的 ∞-localization 的 homotopy category） |
| right adapted subcategory | §1.2, p.525 | `adapted class`（nLab 无独立条目，见 `derived functor`） | 需注明 nLab 用「adapted class of objects」 |
| perfect complex | §2.1, p.531 | `perfect complex` | nLab 定义为 dualizable object；与「局部有限秩自由」等价，需交叉核对 |

| semi-orthogonal decomposition | Def 2.2.3 | `semi-orthogonal decomposition` | 一致；nLab 有 `admissible subcategory` |
| exceptional collection | Def 2.2.4 | `exceptional collection` | 一致 |

| Postnikov system / convolution | §3.1, p.544 | `Postnikov system`、`convolution`（或 `total complex`） | nLab 的 Postnikov 条目主要指拓扑；需说明这里的含义不同 |
