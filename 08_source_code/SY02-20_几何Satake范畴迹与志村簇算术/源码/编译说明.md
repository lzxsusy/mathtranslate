## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `! Undefined control sequence. l.N \allowdisplaybreaks` | 写在 `\usepackage{amsmath}` 之前 | 挪到 amsmath/bm/amscd 之后 |
| 成片 `\nc` 未定义 | `port_macros2.py` 只展开一行里的第一个 `\nc`，其余字面残留 | 在 `\input{preamble_macros}` 前加 `\newcommand{\nc}{\newcommand}` |
| `Single ampersand used with wrong catcode` | 用 `\resizebox` 包 tikz-cd | 不要包；改用 `\scriptsize` + `column sep` 调窄 |
| `Overfull \hbox (32pt too wide)` 出现在交换图 | tikz-cd 的 `\footnotesize` 两行节点太宽 | 降回 `\scriptsize`，或把 `\xymatrix` 的 `@C=` 调小 |
| `Missing character: There is no 中文` | amscd 箭头标注直接写中文 | 写 `@V{\text{拉回}}VV`；数学模式里的中文一律 `\text{}` |
| tikz-cd 报 `No shape named` | 单元格留空 | 空格处填 `{}` 或改用 plain tikz |
| 定理编号比原文大一位 | `\quash{}` 里的注被算进计数器 | 该段原文不出现，译文同样剔除（见 `资料卡/04`） |
| 译注编号与原文脚注冲突 | 两套计数器共用 | 用 manyfoot 的 `trans` 序列，`\zy{}` 插入 |

## 编号规则（复现原文）

- `\theoremstyle{plain}` + `\newtheorem{thm}{定理}[subsection]`，其余定理类环境一律 `[thm]`；
  `\numberwithin{equation}{subsection}`。
- 因此定理印作「定理 2.1.15.」（名在前、三段号、句点），公式印作 (2.1.15)，两套计数器互相独立。
- 正文中一切编号走 `\ref`/`\eqref`，不手写数字。
