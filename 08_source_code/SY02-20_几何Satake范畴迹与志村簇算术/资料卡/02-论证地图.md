## 依赖关系

1. **D2 是全文的枢纽。** D1 只提供动机：经典 Satake 是 $K$-环层次的同构，D2 把它抬到范畴层次。
   §2.2（D3）是同一件事的「去实现」版本，目的是让后续的迹构造不必依赖 $\ell$-进层。
2. **D4 与 D3 独立，是纯范畴论的。** 命题 3.1.1 给出 $\Tr_\sigma(\mC)$ 的显式 Hom 描述，
   这一步在 §3.2 与 §4 都要重算一次，所以作者把证明写全（原文：「因为它将启发下一小节中 $S$-算子的构造」）。
3. **D5 是 D4 的具体化。** $\mC=\on{D}^C(X)$ 时，命题 3.1.1 的抽象复合映射变成具体的
   $S$-算子（构造 3.2.5）；命题 3.2.9 把抽象的 $S_\mF$ 落到 $\End(\widetilde\delta_e)\cong H_W^{\on{op}}$ 上。
4. **D6 把 D2 与 D5 拼起来。** 障碍是 $Y=\frac{LG}{\Ad_\sigma LG}$ 不是代数叠，故 D6 用对应范畴
   $\on{D}^\Hk(X)$ 代替 $\on{D}(Y)$；这是 §4 节首那段与注 6.2.2(2) 反复解释的一点。
5. **D7 是取模 $p$ 纤维后的结果。** Shimura 簇给出到 $\Sht^\loc_\mu$ 的映射 $\loc_p$（命题 5.1.1），
   定理 5.1.3 说明模 $p$ 的 Hecke 对应确实存在，于是定理 5.1.5 才能在 $\mathbf J$ 上作用。
6. **D8 是技术储备。** 定义 6.1.1–6.1.4 与三条相容性引理是 §4、§5 里所有「对应」的记账依据。

## 读者可能卡住的三处

| 位置 | 难点 | 处理 |
| --- | --- | --- |
| §2.1 定理 2.1.15 之后 | 为何混合特征的证明要重做交换性约束 | 注 2.1.16 说明：混合特征下没有 Lusztig–Yun 那套等特征工具，作者反用 $P^\sigma_{y,w}(q)=P_{y,w}(-q)$ |
| §3.1 命题 3.1.1 的证明 | 为何 Hom 空间要用余极限、复合为何良定义 | 证明分四步：定义 $\Tr'_\sigma$、给出 $S_{u,v}$、验证合成、再证它与 2-余极限一致 |
| §4 节首 | 为何不用 $\on{D}(Y)$ | $Y$ 不是代数叠；$\on{D}^\Hk(X)$ 是 §6.2 定义的对应范畴，由注 6.2.2(2) 有 $\infty$-范畴版本 |
