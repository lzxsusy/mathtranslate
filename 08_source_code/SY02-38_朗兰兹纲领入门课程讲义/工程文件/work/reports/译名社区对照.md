## 二、结论

**总原则与本库及中文研究社区一致**：人名、定理名保留拉丁原名（Hecke、Langlands、Galois、Satake、Shimura、Frobenius 等），普通数学名词译中文。这与库内 138 部译注本的主流写法吻合（`Hecke` 447 个文件 vs「赫克」12 个；`Langlands` 528 vs「朗兰兹」142；`Satake` 178 vs「佐武」1；`Frobenius` 242 vs「弗罗贝尼乌斯」1），也符合中文数学论文与讨论班的通行做法。
