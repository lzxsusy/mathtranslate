# 00 · 开工必读（SY02-38）

> 任何（人或 agent）第一次进入本工程，先读这一页，再读 `BRIEF.md` 与 `STYLE_GUIDE.md`。

## 一、这是什么

Anschütz《Lecture notes for an introductory course on the Langlands program》（2020-07-22，103 页）的中文译注本。讲义体，12 讲，其中第 7、8、10 讲由 Ben Heuer 撰写。

- 底本 PDF 已在 `work/pages/` 逐页提取为文本（`pNNN.txt`，NNN = PDF 页）；**原文页 = PDF 页，无偏移**。
- 全书正文 p2–p101，参考文献 p102–103。

## 二、开工顺序（不许跳）

1. 读 `STYLE_GUIDE.md`（体例、术语、译注、LaTeX）。
2. 读 `work/通读笔记.md`（全书骨架、论证地图、三条提醒）。
3. 读 `work/疑点清单.tsv`（原文已知笔误与处理方式；`未解` 必须为 0）。
4. 读 `work/definitions.tsv` 与 `work/glossary.tsv`（术语冻结）。
5. 只写你被分到的 `源码/chapters/lectureNN.tex`。

## 三、硬规则速记

- 编号手写、原样保留（「定义 2.1」「定理 9.1」「(1)」不重编）。
- 页标记注释：`% ===== PDF p.011 =====`，单独一行，前后不空行。
- 译注：`\zhnote{…[来源：…]}` 或 `\zhnoteplain{…}`；每讲 3–8 条。
- 不补证、不改写、不合并条目、不加小节。
- 不确定的地方写进 `work/reports/lectureNN.md`，不要擅自改 `work/*.tsv`。

## 四、交接与验收

- 交稿：`源码/chapters/lectureNN.tex` + `work/reports/lectureNN.md`（5 行）。
- 验收：Lead 编译 `源码/main.tex`（xelatex ×3），检查页标记覆盖、术语一致性、译注来源、数学正确性。
- 编译环境：MiKTeX 26.5，`xelatex` 在 `C:\Users\admin\AppData\Local\Programs\MiKTeX\miktex\bin\x64\xelatex.exe`。
