# 精选片段 · SY02-18《shtuka 及其模空间导论》

判定链格式：**意图 → 动作 → 证据 → 结论**。共 8 条。

---

## 1. 选篇：为什么是 04 而不是 03、05、06

- **意图**：在 6 篇里按「与几何朗兰兹的关键程度、可保存程度」再选两篇。
- **动作**：读 README 导读，逐篇看标题、篇幅、体例、与已完成的 SY02-16 的关系。
- **证据**：01 是几何 Satake 的标准入门（95 页，讲稿扩充版）；04 是 shtuka 的数论侧入口（38 页，IHES 讲稿），直接接 SY02-16 的 §2/§3；03 与 01/02 内容重叠；05 自述「非正式」；06 是 Springer 理论背景。
- **结论**：选 01 + 04。04 篇幅短但密度高，适合与 01 并行推进。

## 2. 编号体制：`\sss` 与定理类共用计数器

- **意图**：让译文的定理号与原文逐条一致。
- **动作**：读原文 454 行 `\newcommand\sss{\subsubsection}`，注意到 amsart 下 `secnumdepth=2`，小标题不显示编号但仍 `\refstepcounter`。
- **证据**：原文「2.3.3. Example.」之前有 2 个 `\sss`；若译文把 `\sss` 改成纯 `\textbf`，定理号会整体前移。
- **结论**：定义 `\ssszh` 宏（`\refstepcounter{subsubsection}` + `\textbf`），空标题也照样步进；`sim_numbering.py diff` 结果 57/57，`mismatch 0`。

## 3. 题头格式：数字在前、各带句点

- **意图**：复现原文 amsart 的「2.3.3. Lemma.」样式。
- **动作**：先用 `\swapnumbers`，再改自定义 `\newtheoremstyle`。
- **证据**：原 PDF 文本层 `2.3.3. Example.`；`\swapnumbers` 只给「2.3.3 Lemma」缺数字后的句点。
- **结论**：用 `\newtheoremstyle{zhthm}{3pt}{3pt}{\itshape}{}{\bfseries}{.}{.5em}{\thmnumber{#2}.\enspace\thmname{#1}\thmnote{\ \ (#3)}}`，渲染为「2.3.3. 引理.」。

## 4. 空标题小标题也必须步进

- **意图**：§5.2 与 §5.2 之后有两处 `\sss{}`（原文 1653、1684 行），标题为空。
- **动作**：初版把空标题当普通段落处理，`sim_numbering.py` 报 `#45 orig=5.2.3 rmk mine=5.2.2 rmk`。
- **证据**：只差一项，且位置正是 1653 行。
- **结论**：补 `\ssszh{}` 到对应段落前，差异归零。

## 5. 宏移植：三种写法都要抓

- **意图**：把原文 432 个数学宏搬进 `preamble_macros.tex`。
- **动作**：初版正则只认 `\newcommand{\x}{...}`，得 203 个；补 `\newcommand\cX{...}`（无花括号）与 `\renewcommand\a\alpha`（单 token 宏体）两种写法。
- **证据**：`\c`、`\a`、`\r` 未定义导致正文大量报错；补后 203 → 432。
- **结论**：宏移植脚本必须按「三种写法 + 与内核重名改 `\renewcommand`」实现，单 token 宏体在两个范围内手补。

## 6. `\c` 与内核冲突

- **意图**：原文用 `\c` 表示复合 $\circ$。
- **动作**：初版用 `\providecommand{\c}{\circ}`，无效。
- **证据**：LaTeX 内核已有 `\c`（软音符），`\providecommand` 不会覆盖；编译报 `Command \c invalid in math mode` 与 `Missing character: There is no ̧ in cmmi12`。
- **结论**：必须 `\renewcommand{\c}{\circ}`；同理 `\a\b\d\r\G\D` 等一律用 `\renewcommand`。

## 7. xy-pic 与 tikz 的加载顺序

- **意图**：原文有 5 处 `\xymatrix`，译文统一改用 `tikz-cd`。
- **动作**：把 `\usepackage[all]{xy}` 放到 preamble 末尾。
- **证据**：放前面时 `tikz-cd` 的 `\arrow` 解析崩：`! Argument of \tikzcd@@arrow has an extra }`。
- **结论**：`xy` 必须在 `tikz` 之后加载；`tikz-cd` 标签含逗号要写成 `"{(\id,\Fr)}"`。

## 8. PDF 端编号对账不可行时的替代

- **意图**：用 PDF 文本层独立复核编号。
- **动作**：`pymupdf` 与 `pdftotext` 抽取译本 PDF 中文。
- **证据**：`Unknown font tag 'F7'`、`Missing language pack for 'Adobe-GB1'`，抽不出中文（与 SY02-17 同一现象）。
- **结论**：改用「源码计数器模拟」对账（`sim_numbering.py`），再用「标签集合对账」（`label_check.py`）兜底；两条互相独立，都过才算过。
