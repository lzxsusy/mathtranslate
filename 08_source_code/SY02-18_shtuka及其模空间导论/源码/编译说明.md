## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Environment defn undefined` | 定义环境名是 `dfn` | 改用 `\begin{dfn}` |
| `Command \c invalid in math mode` | `\c` 被当软音符 | `\renewcommand{\c}{\circ}` |
| `! Argument of \tikzcd@@arrow has an extra }` | xy 在 tikz 之前加载 | `\usepackage[all]{xy}` 放 preamble 末尾 |
| `Missing \endcsname inserted` | tikz-cd 标签含逗号 | 写成 `"{(\id,\Fr)}"` |
| `Missing character: There is no 拉` | amscd 箭头标注写中文 | 写成 `@V{\text{拉回}}VV` |
| 定理号比原文小 | `\sss` 没有步进计数器 | 用 `\ssszh`，不要用纯 `\textbf` |
