## 五个技术支点

1. **秩 1 自由**：$\mathcal S(X(F))^{G(O)}$ 是 $\mathbb C[\Rep\check G_X]$ 上的秩 1 自由模，生成元 $\mathbf 1_{X(O)}$（(8.11)–(8.13)，p37）。这一步把「球簇上的分析」整个换成「对偶群表示论的代数」。
2. **内积 ↔ Hom 的迹**：(11.4)–(11.11) 把 $\langle f,g\rangle$ 写成 $\operatorname{tr}(q^{-1/2}\mid\Hom(W,V\otimes\mathbb C[M^\vee]))$，再用 sheaf–function 对应换成 Frobenius 的迹。整个范畴化猜想就靠这一步「两侧都成了迹」。
3. **Koszul 对偶**：$B_{\check G}(\text{raviolo})=\QC^!(\check{\mathfrak g}[-1]/\check G)\cong\QCoh(\check{\mathfrak g}^*[2]/\check G)$（注 7.9，p33；例 13.1，p54）。它把「带双点的非分离簇」翻译成「余伴随表示」，于是矩映射登场。
4. **Beilinson 投影**：$(-)_{\mathrm{spec}}:\Shv(\Bun_G)\twoheadrightarrow\Shv_N(\Bun_G)$（(13.27) 的伴随，p58）。没有它，$P_X$ 落在太大的范畴里，匹配不成立。
5. **导出不动点**：$L$-层在 $\rho$ 上的纤维 $=\bigoplus_{x\in\check X^{\mathrm{fix}}}\wedge^*H^1(T_x)$（例 15.4，p64）。$L$-函数不是「数」而是「外代数的次数」，这是相对朗兰兹把算术对象搬进几何的最后一跳。

## 破环点（哪一步松了，结论怎么坏）

| 放松的条件 | 后果 | 依据 |
|---|---|---|
| $\check G_X\ne\check G$（去掉 strongly tempered） | (11.1) 的 $\mathbb C[\Rep\check G_X]$ 要换成带 $V_X$ 因子的形式；Plancherel 密度不再是纯 $q$-特征标 | (8.14)(8.15)（p37）、§11 开头的说明（p48） |
| $X$ 非球（如 $X=G$ 的单个左作用） | (8.16) 失效：$\operatorname{Func}(G(F))$ 的重数无穷，Peter–Weyl 直积分 (8.17) 就是反例 | (8.16)(8.17)（p37–p38） |
| 不做 shearing | (11.12) 为假：$H^*_G(X(\mathbb C))$ 与 $\mathbb C[M^\vee]^{\check G}$ 只有抽象同构，$\mathbb G_m$-分次不对 | (11.13)–(11.19)（p50） |
| 去掉 $\Shv_N$ 的限制 | $\Shv(\Bun_G)\simeq\QCoh(\Loc_{\check G})$ 是**假**的（左边有非局部常值对象） | 注 7.6（p31）、注 13.18（p56） |
| 在分歧点仍要求 $E_3$ | 分歧点处球无法离开区间 $x_0\times[0,1]$，$E_3$-结构丢失，Hecke 范畴退化 | 注 7.1（p29）、ch07 开头的分歧讨论 |
