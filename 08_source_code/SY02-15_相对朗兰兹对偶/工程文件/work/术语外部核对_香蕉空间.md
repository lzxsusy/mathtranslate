# 术语外部核对：香蕉空间（2026-11-27）

## 0. 为什么要做

用户要求：译名先按中文数学社区的约定核对，不能每本书自造一套。首选参照是**香蕉空间**（bananaspace.org）。本文件记录核对范围、命中情况、取舍，以及哪些差异留待 v1.1 处理。核对只用于**术语层**，不改已发布 v1.0 正文。

## 1. 访问方式与限制

- 真实站点：`https://www.bananaspace.org`；旧域名 `bananaspace.wiki` 已 DNS 失效。
- 直接 `curl` / `web_fetch` 会被 Cloudflare 拦成 403（`Just a moment...`）；本轮用本机 Edge 过验证后，经 `https://bananaspace.org/legacy/w/index.php` 与 `legacy/w/api.php` 读取页面与 JSON。
- 检索日期：2026-11-27。两轮共核对约 120 个标题：22 个重点词 + 三批批量 API 查询（`action=query&titles=A|B|…`，返回 `missing:true` 即无专条）。未做全站普查。
- **「无专条」只表示该标题没有独立页面，不表示社区不用这个词**；下文「判定」列区分「有页面依据」与「依本库 termbase / 通行译法」。

## 4. 结论与待办

1. **新卡（datasets/lawrge24）**：无交并、配边、配边范畴、衔接、几何 Satake 等价、球簇、超球簇、对偶群、小 Weyl 群、周期层、$L$-层、多重数自由——按上表执行。
2. **不改 v1.0 成品**：`不交并` 1 处、`仿射 Grassmann` 7 处与香蕉空间用字有差，但改动会牵动已发布 PDF 与页码锚；记入 v1.1 候选，待用户决定是否重编译。
3. **术语基**：本轮不新增 frozen 条目；卡集里出现的组合（如「相对 Cartan 子群」）已在工程术语表 114 条内，无需另造。
4. **核对局限**：香蕉空间对「相对 Langlands」方向覆盖极薄（搜「朗兰兹」仅 1 条命中「局部类域论」，搜「相对朗兰兹对偶」0 条），所以本书的核心术语不能靠它兜底；凡无页面依据的，卡内 `provenance_note` 只声明「依原文/本库术语表」，不假称社区标准。
