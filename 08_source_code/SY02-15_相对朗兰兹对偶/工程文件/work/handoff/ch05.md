## §5 已冻结的写法
- 长显示用 `\begin{equation}` + `\label{eq:5-N}`；三连等式用 `\[\begin{aligned} … \end{aligned}\]`，每行以 `&\qquad` 缩进，避免 Overfull。
- 原文的「注解列表」用 `enumerate[label=(\arabic*),leftmargin=2.0em]` 复现 (1)(2)…。

- 原文疑点一律「照原文 + `% [Tutor Note: …]` + reports 登记」，不加可见译注。

## §6 要点（第二日第三讲，p29–p31，L1250–L1370）
- 极短的一节（2 页），无编号公式、无图。
- 内容：$F=\mathbb Q_p$ 或 $\mathbb F_p((t))$ 的两维/一维之分；$A_G(F)=\Rep G(F)$，$\Theta_X$ 是 $X(F)$ 上的函数；目标是**理解无分歧部分**——Hecke 代数 $H=\Hecke(G(F),G(O))$ 作用在 $X(F)^{G(O)}$ 上并对角化。
- 两个例子：
  - **例 1（模型例）**：$X=\mathbb A^1,\ G=\mathbb G_m$；A 侧 $C_c(\mathbb Z)$ 带移位算子 $T$，$\delta_0\leftrightarrow 1$，$T\leftrightarrow$ 乘以 $z$；内积 $\int_{S^1}|f|^2\frac{d\theta}{2\pi}$；$\val:\mathbb F/O^\times\cong\mathbb Z_{\ge-\infty}$；$\mathbb Q_p$ 情形 $C_c(X(F))^{G(O)}$ 是把 $\hat{\mathbb Z}$ 上的函数；$H=\mathbb C[T^{\pm1}]$；$\langle f,g\rangle=\sum f(n)\overline{g(n)}q^{-n}$；$Tf(n)=f(n+1)q^{-1/2}$；朴素 Fourier 变换下 $\delta_0\mapsto\frac{1}{1-q^{-1/2}z}\neq1$，需重标定 $e_z:n\mapsto q^{n/2}z^n(1-q^{-1/2}z)$ 使 $\langle\delta_0,e_z\rangle=1$。
  - **例 2**：$G=\mathrm{PGL}_2^l\times\mathrm{PGL}_2^r$ 作用在 $X=\mathrm{PGL}_2$；Hecke 代数 $\mathbb C[T_l,T_r]$；$X(F)/G(O)\cong\mathbb Z_{\ge0}$，$(q+1)$-正则树的顶点与距离；$Tf(0)=(q+1)f(1)$、$Tf(1)=f(0)+qf(2)$、$Tf(n)=f(n-1)+qf(n+1)$；$C_c(X(F))^{G(O)}\to\mathbb C[\mathrm{Sl}_2/\text{conj}]$；内积 $\int_{SU_2/\text{conj}}f\cdot(\mathrm{SL}_2\ \text{的 }q\text{-特征标})\cdot d\text{Haar}$。
- 术语新增：shift operator（移位算子）、re-normalization（重标定）、regular tree（正则树）、q-character（q-特征标）。
- 注意：本节的「Example 1 / Example 2」是**无编号的 run-in 标题**（原文就写 Example 1: A Model Example），不是 `exmp` 环境；用 `\textbf{例 1（模型例）}\enspace` 起。
