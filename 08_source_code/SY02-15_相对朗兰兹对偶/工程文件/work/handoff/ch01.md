## 已经冻结的写法
- **定理类环境**：`thm / lem / prop / cor / conj / defn / exmp / exer / claim / rem` 全部 `[equation]`，印成「例 1.3.」「注 1.6.」。**不要**再用 `\begin{theorem}`。
- **图**：原文未编号的示意图一律 `\inlfig[宽]{fXX-name.png}`，放在正文里随文走，不加 caption、不浮动。图号 2.1–2.4、4.1–4.3 这类**编号图**要用 `figure` 环境 + `\caption`（`\numberwithin{figure}{section}`）。
- **译注**：`\zy{……}` 出脚注「【译注】……」，必须带 `[来源：A/B/I]` 或 `[译者按（无外部依据）：]`。
