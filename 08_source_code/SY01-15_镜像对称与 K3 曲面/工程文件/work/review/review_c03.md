## 一、必须改（3 条）

### 1. `c03.tex:94` —— 「保持 $\mathcal{D}^{+}$ 的连通分支」把修饰关系拧反

- **原文依据**（p007，(4.29) 之后第 1 句）：`ここで，$O(N)^+$ は $\mathcal{D}^+$ の連結成分を保つ $O(N)$ の指数 2 の部分群である.`
  即「$O(N)^+$ 是 $O(N)$ 中**保持连通分支 $\mathcal{D}^+$** 的指数 2 的子群」——「保持」的宾语是 $\mathcal{D}^+$ 这个连通分支本身。
- **现文**：`这里，$O(N)^{+}$ 是 $O(N)$ 中保持 $\mathcal{D}^{+}$ 的连通分支的指数 2 的子群。`
- **问题**：中文「保持 $\mathcal{D}^{+}$ 的连通分支」按「的」字结构只能读成「保持（$\mathcal{D}^{+}$ 的连通分支）」，把同位语「连通分支 $\mathcal{D}^{+}$」降格成了所属关系，句子不成立（$\mathcal{D}^+$ 本身就是连通分支，不存在「它的连通分支」）。数学内容虽可从上下文猜回，但译文表述错误，应改。
- **建议改法**：
  `这里，$O(N)^{+}$ 是 $O(N)$ 中保持连通分支 $\mathcal{D}^{+}$ 的指数 2 的子群。`

### 2. `c03.tex:36–40` —— (4.19) 前后两句黏连、句子断裂

- **原文依据**（p006）：`周期領域のコンパクト双対 $\check{\mathcal{D}}=\{[\Omega]\in\mathbb{P}(T_{\mathbb{C}})\mid(\Omega,\Omega)=0\}$ (4.19) における周期領域の閉包を $\mathcal{D}^{*}$ と書く.`
  ——这是**一个**句子：「把周期区域在（其紧对偶 (4.19)）中的闭包记作 $\mathcal{D}^{*}$」。
- **现文**（第 36、40 行）：
  ```
  周期区域的紧对偶为
  \begin{equation} \check{\mathcal{D}}=\{…\} \tag{4.19} \end{equation}
  把周期区域在其中的闭包记作 $\mathcal{D}^{*}$。其拓扑边界是
  ```
- **问题**：「紧对偶为」之后直接是公式，「为」的补语位置被公式占掉后没有收束，紧接着又起一个「把…记作…」；两句之间没有任何标点，读起来是「紧对偶为 (4.19) 把…记作…」。语义可以猜出，但句子断在中间，属明显的译文病句。
- **建议改法**（二选一，均保持「不补写」）：
  - **首选**（贴原文的单句结构）：
    ```
    把周期区域在其紧对偶
    \begin{equation} \check{\mathcal{D}}=\{…\} \tag{4.19} \end{equation}
    中的闭包记作 $\mathcal{D}^{*}$。其拓扑边界是
    ```
  - 次选（保留现结构，只补句子边界）：
    ```
    周期区域的紧对偶为
    \begin{equation} … \tag{4.19} \end{equation}
    这里，把周期区域在其中的闭包记作 $\mathcal{D}^{*}$。其拓扑边界是
    ```

### 3. `c03.tex:40–44` —— (4.20) 与「其中」之间同样缺句子边界

- **原文依据**（p006）：`その位相境界は $\mathcal{D}^{*}\setminus\mathcal{D}=\bigcup_{I\,:\,M_{\mathbb{R}}\text{ の等方部分空間}}B(I)$ (4.20) である．ここで，$B(I)=\mathbb{P}(I_{\mathbb{C}})\setminus(\bigcup_{J\subsetneq I}\mathbb{P}(J_{\mathbb{C}}))$ である.`
- **现文**（第 40 行末、44 行）：`其拓扑边界是 [ (4.20) ] 其中 $B(I)=\mathbb{P}(I_{\mathbb{C}})\setminus\bigl(\bigcup_{J\subsetneq I}\mathbb{P}(J_{\mathbb{C}})\bigr)$。`
- **问题**：与第 2 条同类——「其拓扑边界是」后无收束，公式之后直接接「其中 …」；末尾用的是中文句号，前半句却从未结束。中文里「……，其中 $B(I)=\cdots$。」是合法句式，缺的只是一个句读/领起词。
- **建议改法**：
  `其拓扑边界为` 〔(4.20)〕 `这里，$B(I)=\mathbb{P}(I_{\mathbb{C}})\setminus\bigl(\bigcup_{J\subsetneq I}\mathbb{P}(J_{\mathbb{C}})\bigr)$。`
  （即「是」改「为」，公式后加「这里，」；无需改动公式本身。）
