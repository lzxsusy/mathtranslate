# 编译说明

- 引擎：XeLaTeX（ctexart + fandol 字体），三遍：
  `xelatex main.tex && xelatex main.tex && xelatex main.tex`
- 主文件：`main.tex`（扉页、译者说明、目录，`\input{chunks/ch00.tex … ch04d.tex}`）。
- 单块自检：`xelatex test_chXX.tex`（各 test 文件只 input `preamble.tex` + 对应 chunk，节号/公式号从 1 起，属正常现象）。
- 依赖：TeX Live 2023+ 或 MiKTeX，宏包 `ctex, geometry, amsmath, amssymb, stmaryrd, tikz-cd, tcolorbox, manyfoot, hyperref, bookmark`。
- 成品：56 页；0 error / 0 Overfull / 0 Missing character；仅 stmaryrd 粗体回退一条字体提示。
- 注意：`\PP`、`\GG` 与文档类已有命令冲突，正文用 `\mathbb{P}`、`\mathbb{G}`；`\ker` 未定义处用 `\operatorname{Ker}`。
