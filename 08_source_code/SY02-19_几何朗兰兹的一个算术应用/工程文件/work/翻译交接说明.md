## 必须遵守的体例

1. **先读样板**：`源码/chunks/ch00.tex` 与 `源码/chunks/ch02a.tex`。中文数学文风、编号段落、脚注、公式环境一律照此。
2. **编号段落**：原文 `1.2.3.`、`2.1.4.` 这类编号用 `\pnum{正文}`；带小标题的用 `\pnumt{标题。}{} 正文`（标题自带句号）。不要把编号写死在正文里。
3. **定理环境**：`thm`/`prop`/`lem`/`cor`/`conj`/`notation`/`defn`/`example`/`remark`/`warning` 均已定义，共享计数器，直接 `\begin{thm}...\end{thm}`。定理号由 LaTeX 生成，**不要手写编号**；但正文里引用别处编号时照原文写（如“定理 4.3.3.1”）。
4. **公式编号**：用 `\begin{equation}...\end{equation}` 自动编号；行内不编号公式用 `\[ ... \]`。正文引用 `(2.6)` 等照原文写。
5. **数学记号**：优先用 `源码/preamble_macros.tex` 里的宏（`\Bun \Shv \IndCoh \QCoh \Dmod \LS \Rep \Aut \arthm \restr \unr \cusp \triv \nonres \et \dR \bG \bT \bB \hG \Fq \Fb \A \OO \ZZ \QQ \e` 等）。**禁止**自定义 `\PP`、`\GG`（与 LaTeX 冲突），需要时写 `\mathbb{P}`、`\mathbb{G}`。
6. **公式核对**：逐符号对照 `pNNN.png` 页面图。文本层（full.txt）里的数学已损坏，**不可**依赖。遇到原文明显笔误：正文保留原样，行末加 `% [Tutor Note: 说明]`，并在报告中登记。
7. **译注**：解释性补注用 `\zy{...}`（manyfoot 会生成译者注），内容必须带 `[来源：A/…]` 或 `[来源：B/…]`（A=原文/经典教材/原始论文；B=nLab、Stacks Project、ProofWiki），两者都没有就写 `[译者按（上下文推断，无外部依据）]`。不要滥用；能直译清楚就不加。
8. **文风**：全角标点；英文术语、数字与汉字之间留半角空格；行内公式后的句末标点放在公式外；避免翻译腔。术语一律按 glossary。
9. **脚注**：原文脚注用 `\footnote{...}` 原样保留（含长脚注）。原文中的 `[?]`、缺字等缺陷不要擅自补，保留并在报告中登记。

## 编译自检

在 `源码/` 下：

```
cp test_ch00.tex test_chXX.tex
# 把 test_chXX.tex 里的 chunks/ch00 改成 chunks/chXX
xelatex -interaction=nonstopmode -halt-on-error test_chXX.tex
```

要求：exit 0，日志中 `Overfull` 为 0（若个别长公式溢出，可调 `\!`、换行或 `\resizebox`，不要放宽版心）。测试文件只编译单块，节号/公式号从 1 开始是正常的，不必修正。
