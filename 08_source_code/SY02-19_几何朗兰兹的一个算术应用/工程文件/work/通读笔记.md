# 通读笔记 · SY02-19《几何朗兰兹的一个算术应用》

底本：Sam Raskin, *An arithmetic application of geometric Langlands*, Proc. Sympos. Pure Math. 112.1 (2025), 42 页。
通读方式：`work/原文/full.txt` 全文（3734 行，文本层数学严重损坏）+ `work/pages/p001–p042.png` 逐页核图。通读两遍：第一遍抓论证骨架，第二遍抓每个编号对象的精确定义与记号。

## 一、三句话主旨

1. 本文是 AGKRRV 几何朗兰兹理论的一次**算术落地**：用 `Shv_Nilp(Bun_G) ≃ IndCoh_Nilp(LS^restr_Ĝ)`（restricted GLC）与 Frobenius 迹，把函数域上的无分歧自守函数空间 `Aut^unr_{G,c}` 实现为算术局部系统叠 `LS^arthm_Ĝ` 上整体截面 `Γ(LS^arthm_Ĝ, ω)`。
2. 在此框架下，本文对 Michael Harris 的问题给出肯定回答：**分裂半单群在平凡 Langlands 参数处没有无分歧尖形式**（Theorem A），即 `Aut^unr_{cusp,[triv]} = 0`。
3. 证明的两条腿是：谱侧用 Eisenstein 级数与 `LS^arthm_Ĝ` 在平凡局部系统附近的显式坐标（Theorem 4.3.3.1）把问题局部化；再用 L-值 `ζ*_X(1)^{dim H}` 把谱 Eisenstein 与可计算的玩具模型（Borel–Weil–Bott / Weyl 特征标公式）比较，得到局部化映射的满射性，从而把尖形式挤为零。

## 二、论证地图（逐节）

### §1 Introduction（pp.1–4）

- **§1.1 背景与贡献**：AGKRRV 三篇 [2][3][4] 证明了几何朗兰兹的谱分解猜想（[32] 朱歆文独立得到另一证明）；作者受 Lafforgue [22] 与 Beilinson–Drinfeld 的启发，问"几何侧能对算术侧说什么"。本文的具体产出是 Harris 问题的肯定回答。
- **§1.2 设定与主定理**：`F_q`、`k = \bar F_q`、`ℓ ≠ p`、系数域 `e = Q_ℓ`；`G/F_q` 分裂约化，`Ĝ` 对偶群；`X_0/F_q` 光滑射影几何连通曲线，`X = X_0 × k`；`F = F_q(X_0)`，`A` 为 adele 环，`O` 为整 adele。`Aut^unr_{G,c}` 为 `G(F)\G(A)/G(O)` 上有限支撑函数；`Aut^unr_cusp` 为尖形式子空间。Langlands 参数 `ρ: W_X → Ĝ(e)` 连续、半单；Lafforgue 给出分解 (1.1)。**Theorem A**：`G` 半单非平凡，假设 [2] 的 restricted GLC 及其与 Eisenstein 级的相容性，则 `Aut^unr_{cusp,[triv]} = 0`。
- **§1.2.4 证明路线**：§3 造谱侧 Eisenstein 并证明局部化满射（Theorem 3.5.2.1）；§4 证明 `LS^arthm_Ĝ` 在平凡局部系统附近的坐标（Theorem 4.3.3.1），并显式计算谱 Eisenstein（Theorem 4.7.2.1），最后用 §3.7 的玩具模型（Lemma 3.7.1.1）收尾。Remark 1.2.4.1 强调只需平凡局部系统处的 restricted GLC。
- **§1.3 动机**：动机 I 是 Beuzart-Plessis–Harris–Thorne 的迹公式工作；动机 II 是 `PGL_n` 情形尖形式参数不可约，而一般 `G` 可约（Arthur `SL_2`）。**Conjecture 1.3.1**：`F ∈ Ĝ(e)` 半单，`σ_F: W_X → Z → Ĝ`，则 `Aut^unr_{cusp,[F]} = 0` 除非 `q` 是 `Ad_F` 的特征值。定理 A 是 `F = triv` 情形（`q` 不是平凡参数的特征值）。
- **§1.4 约定**：几何用 `k`、系数用 `e`；DG 范畴、`Shv`、`qLisse`、`DGCat_cont`、Lurie 张量积、`C^c`、t-结构；`LS^restr_H` 用右 t-正合对称幺半函子 `Rep(H) → qLisse(X)` 定义；Frobenius 拉回的自映射的不动点叠 `LS^arthm_H`；`p = char(k)` 满足 [2] §14.4.1。

### §2 The AGKRRV theory（pp.5–16）

- **§2.1 算术 vs 几何**：算术朗兰兹的对象是"原子"（不可约表示），几何朗兰兹的对象是"分子"（函数空间/范畴）；(2.1) `D-mod(Bun_G) ≃ IndCoh_Nilp(LS^dR_Ĝ)`，粗版为 `QCoh(LS^dR_Ĝ)`。`Bun_G(S) = Hom(X×S, BG)`；(2.2) `Bun_G(k) = G(F)\G(A)/G(O)`（Weil 对 `GL_n` 用下降，一般用 Steinberg/Harder）。用 D-模类比函数，Mellin 变换 `D-mod(G_m) ≃ QCoh(A^1/Z)` 作类比。谱作用 `QCoh(LS^dR_Ĝ) ↷ D-mod(Bun_G)` 由 Hecke 作用唯一刻画（Drinfeld–Gaitsgory）；纤维化图像 `C = ∫_Y C_y dy`，`D-mod(Bun_G)_σ` 为 Hecke 特征层范畴；`IndCoh_Nilp` 与 Plancherel 测度；例 2.1.12（`X = P^1`、`G = G_m`）说明必须用导出代数几何。
- **§2.2 受限变差的局部系统**：`ℓ`-adic 层；`LS^ét_Ĝ` 不存在（`O_e^×` 的 e-点太多），但有 e-点与形式完备性。**定义 LS^restr_H**：`S`-点为右 t-正合对称幺半函子 `Rep(H) → qLisse(X) ⊗ QCoh(S)`（2.2.4）。例 `G_a`（2.2.6）：对应复形 `C_ét(X)[1]`，同构于 `BH^0_ét × H^1_ét × ΩH^2_ét`（非典范），关键映射 `triv → triv[1]`；例 `G_m`（2.2.7）：ind-代数叠，连通分支 ↔ rank 1 lisse 层；工具 Tannaka 群 `Π_X`（2.2.8）；一般结构（2.2.9）：形式代数叠，`LS^restr_H → BH` 可表，连通分支 ↔ 半单 `H`-局部系统。
- **§2.3 restricted GLC**：`Shv_Nilp(Bun_G) ⊂ Shv(Bun_G)`（Beilinson [5] 奇异支撑）；**Conjecture 2.3.1**：`Shv_Nilp(Bun_G) ≃ IndCoh_Nilp(LS^restr_Ĝ)`；与 Whittaker/Eisenstein 的相容性唯一确定比较函子（2.3.1.2）；证据：char 0 由 de Rham GLC 推出、`G_m` 可直接验证、可化到 `P^1` 的导出 Satake。
- **§2.4 Frobenius**：`k = F_q`；Frobenius 自同构作用于 `Shv(X)`、`qLisse(X)`、`Shv(Bun_G)`；`LS^arthm_H` 为 `LS^restr_H` 的 Frobenius 不动点；e-点为 rank n lisse Weil 层；`LS^arthm_Ĝ` 是整体域 `F_q(X)` 的无分歧 Langlands 参数叠；`qLisse^φ` 非 Tannaka，`LS^arthm_H` 拟紧非形式（[2] Thm 16.1.4）。**迹**：`tr Frob` 在 `IndCoh_Nilp(LS^restr_Ĝ)` 上为 `Γ(LS^arthm_Ĝ, ω)`，在 `Shv_Nilp(Bun_G)` 上为 `Aut^unr_{G,c}`（[4] 主定理），得算术猜想 (2.4.4)。**典范映射** `τ: O → ω`（弱 Calabi–Yau 结构），Arthur `SL_2` 度量 `O` 与 `ω` 之差；例 2.4.5.1（光滑孤立点，`τ` 为同构）。
- **§2.5 Xue 定理与 Frobenius 迹**：(2.5) `tr(Frob, Shv_Nilp(Bun_G)) ≅ Aut^unr_c`；shtuka 构造：`I` 有限集、`V ∈ Rep(Ĝ^I)`，Hecke 函子 `H_V`、核 `K_V`；`Sht_{I,V}` 由 Frobenius 图拉回再沿 `Bun_G` 紧支撑推前；`I = ∅` 时得 `C_ét,c(Bun_G(F_q)) = Aut^unr_G`；`Sht_I` 的函子性（Lafforgue excursion operators）。2.5.3 逆命题（Hecke 变换局部常值 ⇒ 在 `Shv_Nilp` 中，[2] Thm 14.4.3）。2.5.4 定义 `Sht^tr_{I,V}`，目标 (2.6) `Sht^tr_{I,V} ≅ Sht_{I,V}[2|I|]`；2.5.5 用 [3] 的迹计算 + Beilinson 谱投影 `λ`；Xue [31] 说 `Sht_I` 取值在 `qLisse`，故 `λ Sht_I = Sht_I`；2.5.6 upper-! 变体 `Sht^!` (2.7)，再用 Xue 两次得 `Sht^! = Sht[2|I|]`，故 `Sht^tr = Sht^!`。

### §3 Spectral Eisenstein series（pp.16–25）

- **§3.1 自守 Eisenstein**：`Eis_!: Shv(Bun_T) → Shv(Bun_G)`（沿 `Bun_B → Bun_T` 的 `*`-拉回再沿 `Bun_B → Bun_G` 的 `!`-推前）；Prop 3.1.1.1：`Eis_!` 把 `qLisse(Bun_T)` 映入 `Shv_Nilp(Bun_G)`；伪 Eisenstein `ps-Eis: Aut^unr_{T,c} → Aut^unr_{G,c}`（先限制再沿纤维求和）；3.1.3 相容性：`tr(Eis_!)` 对应 `ps-Eis`，交换图 (3.2)。
- **§3.2 一般构造**：QCA 叠、ind-代数叠、ind-QCA；`f: Y → Z` 1-可表、`φ_Y`、`φ_Z` 交换，取不动点；3.2.3 `f` 可表 proper ⇒ (3.3) `Γ(Y^φ, ω) → Γ(Z^φ, ω)`；3.2.4 `f` 最终余连通 ⇒ (3.4) 反向；3.2.5 范畴框架（连续右伴随、lax 交换 `φ` ⇒ `tr_C(φ_C) → tr_D(φ_D)`）；3.2.6 复原两种情形。
- **§3.3 谱 Eisenstein**：对应 `LS^restr_B → LS^restr_T`（`p`，可表 proper）、`LS^restr_B → LS^restr_Ĝ`（`q`，拟光滑 1-可表）；Def 3.3.1.1：`Eisspec` 为复合。
- **§3.4 谱 vs 函数论**：(3.7) restricted GLC；Hecke 相容（`QCoh(LS^restr_Ĝ)`-模）；Eisenstein 相容（`P = B` 情形交换图）；Prop 3.4.2.1（拟光滑 ind-代数、闭锥形 `N ⊂ T^*[-1]Y`、`dφ[-1]` 在 `N_y` 上收缩到 0 ⇒ 迹同构）；(3.8) `Aut^unr_{G,c} ≅ Γ(LS^arthm_Ĝ, ω)` 为 `Exc_Ĝ`-模；Prop 3.4.3.1：`ps-Eis` 与 `Eisspec` 在 (3.8) 下相容。
- **§3.5 局部化**：`f: LS^arthm_B → A^1`、`g: LS^arthm_T → A^1`；`Γ(...,ω)[f^{-1}] := colim_{f·-}`；对应 (3.9)、映射 (3.10)；Lemma 3.5.1.1（与乘 `f,g` 交换；局部化为张量 `e[t,t^{-1}]`）。**Theorem 3.5.2.1**：存在 `δ_Ĝ`、`δ_T` 使 (3.11) 交换；(1) `δ_Ĝ` 在平凡 Weil 局部系统处非零；(2) 局部化后集中在 degree 0；(3) (3.12) `Eisspec` 满射。
- **§3.6 Theorem A 的证明**：`σ` 为 e-点，`ev_σ: Exc_Ĝ → e`，`m_σ ⊂ H^0(Exc)`；`Aut^unr_{G,c,[σ]}` 为 `m_σ`-挠；`Aut^unr_{G,cusp,[σ]} := ∩ Aut^unr_{G,cusp}`；Warning 3.6.1.1：尖形式有限维故 (3.13) 直和分解，紧支撑函数无此分解；3.6.2 `ps-Eis(Aut^unr_{T,c}) ∩ Aut^unr_{G,cusp} = 0`，故只需证 `ψ ∈ Aut^unr_{G,c,[triv]}` 在 `ps-Eis` 像中；3.6.3 局部化、`δ^n_Ĝ ψ = ps-Eis(ψ_0)`、`λ = δ_Ĝ(triv) ≠ 0`、多项式 `q(t) t^n ≡ 1 mod (t-λ)^m`，得 `ψ = ps-Eis(q(δ_T) ψ_0)`。
- **§3.7 玩具模型**：把 `LS^restr` 图换成 `B^Ĝ → B^T`、`B^Ĝ → B^Ġ` (3.14)，恒等自映射的不动点得 `Ĝ^ad/Ĝ`、`T^ad/T`、`B^ad/B`；`O → ω` 为同构；`Eisspec,toy` (3.15)；Lemma 3.7.1.1：两边集中在 degree 0 且满射（`Rep(T) = ⊕_{λ∈Λ} Vect`、`Rep(Ĝ) = ⊕_{λ∈Λ+} Vect`，Borel–Weil–Bott 把 `e_{T,w_0(λ)}` 送到 `e_{Ĝ,λ}`）；Remark 3.7.1.2：复合即 Weyl 特征标公式；Cor 3.7.2.1：对任意 `g ∈ Γ(Tˇ⫽W, O)`，`Eisspec,toy` 局部化后满射。

### §4 Grothendieck–Springer theory for `LS^arthm`（pp.25–42）

- **§4.1 基点与 Weil 群**：万有覆盖 `X̃`（`π_1^ét(X_0)`-torsor、`π_1^ét(X)`-torsor）；`Frob_X` 提升 `F̃rob_X`；`pZ` 作用 `γ`；`W_X → Z` 的分裂 `F`，`Fg = Ad_F(g)`；(4.1) `π_1^ét(Frob_X)(g) = Fg`；(4.2) `x_0^* ≅ Frob_X(x_0)^*`（`X ≠ P^1` 用 [2] Thm E.2.8，一般用仿射开集）。
- **§4.2 伴随商**：`LS^restr,∘_H` 中立连通分支 = 半单化平凡（unipotent）局部系统；`LS^arthm,∘_H` 为 Frobenius 不动点；`τ_H: H^ad/H → LS^arthm,∘_H` (4.3)；`χ_H` 由 `x_0` 限制给出，`χ_H ∘ τ_H = id`；Remark 4.2.2.1 `h ↦` Weil 表示；4.2.2.2 障碍：`GL_2` 扩张 `0 → σ_λ → σ → σ_1 → 0` 由 `H^1(Hom_Z(C_ét,•(X),σ_λ))` 分类，`λ` 为 `H^1_ét` 的 Frobenius 特征值时存在。
- **§4.3 非共振**：`R_X ⊂ e^×` 为 Frob 在 `H^1_ét(X,e) ⊕ H^2_ét(X,e)` 的特征值集；`1 ∉ R_X`，`q ∈ R_X`；`ch_V` 特征多项式；`(H^ad/H)^non-res` 为 `∏_{λ∈R_X} ch_h([h],λ) ≠ 0` 的开集（仿射）；**Theorem 4.3.3.1**：`τ_H: (H^ad/H)^non-res → LS^arthm,∘,non-res_H` 为同构。
- **§4.4 证明**：Lemma 4.4.1.1（`f` 同构 ⇔ 形式 étale + e-点上 1-群胚同构）；4.4.2 符号约定：lisse Weil 层 `(σ, α: σ ≅ Frob_X^* σ)`，`ρ(F)` 由 (4.4)，(4.5) 几何 Frobenius 作用；4.4.3 `τ` 形式 étale：切复形 `T_{LS^arthm_H,σ} = C_ét(X, h_σ[1])^Z = Ker(id - φ_σ)`，`T_{H^ad/H,[h]} = Ker(id - Ad_h: h[1] → h[1])`，`C_ét(X, h_{τ_H([h])}[1]) = C_ét(X,e) ⊗ h[1]`，`φ = φ_X ⊗ Ad_h^{-1}`；形式 étale ⇔ `1` 不是 `φ_X` 特征值与 `Ad_h^{-1}` 特征值之积 ⇔ 非共振；4.4.4 稳定化子显然；4.4.5 提升同构类：`H° =` Zariski 闭包 `ρ_0(π_1^ét(X))`，`θ = Ad_{ρ(F)}`，(4.6) `ρ_0(Fg) = θ(ρ_0(g))`；4.4.6 证 `H°` 平凡：可化到 `H°^ab = V`，取 `V^*` 特征向量 `μ` 特征值 `λ ∉ R_X`，得 (4.7) `ρ_0(Fg) = λ ρ_0(g)`，给出非零 `η ∈ H^1_ét(X,e)` 且 `φ_X(η) = λη`，矛盾。
- **§4.5 Theorem 3.5.2.1 的证明 setup**：`δ(t) = ∏_{λ∈R_X} ch_ğ(t,λ) = ∏_{λ∈R_X} (1-λ)^{dim Tˇ} ∏_{α∈Δˇ} (αˇ(t)-λ)`，`W`-不变，诱导 `Tˇ⫽W → A^1`；图 (4.8)；`δ_Ĝ` 在 `LS^{arthm,∘}_Ĝ` 上由 (4.8) 定义、其外为 0；`δ_T` 同理；(4.9) `Γ(LS^arthm_Ĝ,ω)[δ_Ĝ^{-1}] ≅ Γ((Ĝ^ad/Ĝ)^non-res, ω)` 集中在 degree 0；4.5.6 比较 `Eisspec` 与 `Eisspec,toy`（经 Thm 4.3.3.1），差一个可逆 L-值。
- **§4.6 L-值与迹**：4.6.1 类映射 `cl(F,α) ∈ Ω^∞ tr_C(T)`，K-理论 (4.10)；4.6.2 `H` unipotent，`O_{LS^restr_H}` 与 `τ_{0,*}^{IndCoh}(O_BH)` 的类；4.6.3 `ζ_X(t) = ∏_{n≥0} |X_0(F_{q^n})| t^n = P_X(t)/((1-t)(1-qt))`，`ζ^*_X(t) = (1-t)ζ_X(t)`，`ζ^*_X(1)` 非零；**Lemma 4.6.4.1**：`cl(τ^{IndCoh}_{0,*}(O_BH),α) ≅ ζ^*_X(1)^{dim H} cl(O_{LS^restr_H},α)`；证明 Step 1 玩具 `V × Ω^0W`、Koszul (4.11)、det 比 = `ζ^*_X(1)`（Grothendieck 迹公式）；Step 2 一般 `Z → Y` 拟光滑 (4.12)；Step 3 中心列 `1 = H_0 ⊂ … ⊂ H_r = H`，`Z_i = LS^restr_H ×_{LS^restr_{H/H_i}} B(H/H_i)`，归纳。4.6.5 发散级数与范畴迹（`τ: O_{Y^φ} → ω_{Y^φ}` 弱 CY；正则化迹 `tr^reg`；例 `Y = Ω^0A^1`、`φ = λ`、`F = O_0`，得 `Σλ^i "=" 1/(1-λ)`）；4.6.6 变体 `S⋉H`（实际 `S = Tˇ`、`H = Nˇ`），`ζ^*_{X,H,S}: S ⇢ A^1`，在 1 处取值 `ζ^*_X(1)^{dim H}`。
- **§4.7 结论**：`LS^{arthm}_{Tˇ,δ_T≠0}`；`ζ_{X,Nˇ,Tˇ}: LS^{arthm,∘}_{Tˇ} = Tˇ^ad/Tˇ → A^1` 在 `δ_T ≠ 0` 上可逆；**Theorem 4.7.2.1**：交换图 (4.16)+(4.17) 复合，使 `Eisspec` 与 `ζ_{X,Nˇ,Tˇ} · Eisspec,toy` 一致；由 Cor 3.7.2.1 得 §4.5.6 所需的满射性。Step 1：`B^B → LS^restr_B`、`B^Ĝ → LS^restr_Ĝ` 的 proper 态射给出 (4.16)；Step 2：`B^B → B^T`、`LS^restr_B → LS^restr_T` 的方块给出 (4.17)，用 Lemma 4.6.6.4 与 `vol_T`；Step 3：拼接 (4.16)(4.17) 得定理。
