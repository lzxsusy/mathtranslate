# SY02-19 精选片段（判定链）

> 用途：记录本项目施工中真正改变走向的判断，而非“做了什么”的流水账。每条含 **场景 / 判断 / 动作 / 证据 / 结论**。供归档与后续译者复盘；不替代 `09_thinking` 的 L2 批准链（本文件不构成审计结论）。

## 片段 1：先判定“未译”，再动工

- **场景**：用户要求翻译 Raskin 文章，前提是仓库里没有译本。
- **判断**：不能凭印象回答“没有”，必须对全仓做可复查的检索。
- **动作**：在 `03_translations_meta/`、`08_source_code/`、`04_playbook/` 中检索 `Raskin`、`arithmetic application of geometric Langlands`、`SY02-19`；并核对 `datasets/glc` 的内容。
- **证据**：全仓无 Raskin 条目；`datasets/glc` 是陈麟 GLC 讲义资料卡（154 张），与本文无关；SY02-16 是 ICM 2022 综述，非本文。
- **结论**：判定未译，新建 SY02-19；ID 顺延（17/18 已被并行工程占用，未触碰）。

## 片段 2：底本无 arXiv 版，改用出版社 PDF 为唯一底本

- **场景**：仓库惯例优先用 arXiv 源做底本，便于取 LaTeX 源码。
- **判断**：先查 arXiv，再决定底本。
- **动作**：arXiv API 按标题检索（`totalResults=0`）；尝试作者主页 `springer.pdf`（连接被关闭）。
- **证据**：两条路径均不可用；用户提供的 PDF 元数据 `creator=TexpadTeX`、`creationDate=2025-06-05`，42 页。
- **结论**：以出版社 PDF 为唯一底本；所有公式按页面位图逐符号核对，不依赖文本层（文本层 math 严重损坏）。

## 片段 3：`\PP`、`\GG` 宏与 ctex 冲突

- **场景**：按原文符号表批量定义宏，首次编译即报错。
- **判断**：不是“少加一个 `\newcommand`”，而是宏名与 LaTeX/ctex 既有命令撞车。
- **动作**：查 `.log` 定位重复定义；删除 `\PP`、`\GG`，正文改用 `\mathbb{P}`、`\mathbb{G}`；保留 `\A`、`\OO` 等未冲突者。
- **证据**：删除后 `test_ch02a.tex` exit 0、6 页、0 Overfull。
- **结论**：宏表不是越长越好；与文档类既有命令同名的宏必须让路。

## 片段 4：`\Fb` 的重复下标

- **场景**：正文写 `\Fb_q`，编译报 “Double subscript”。
- **判断**：`\Fb` 已含下标 `q`（定义为 `\overline{\F}_q`），不能再加 `_q`。
- **动作**：全局检索 `\Fb_`，改为 `\Fb`；在交接说明中写明此坑。
- **证据**：编译通过；`\Fb` 在 PDF 中显示为 `\overline{\mathbb{F}}_q`。
- **结论**：宏的“隐藏结构”要写进交接文档，否则并行译者必踩。

## 片段 5：脚注 8/9 是连续两个 `\footnote`

- **场景**：原文同一处有相邻两个脚注上标，照排时被误合并为一个。
- **判断**：这是原文的两个独立脚注，不是排版事故。
- **动作**：在正文同一位置连续写两个 `\footnote`；PDF 中呈现为相邻上标。
- **证据**：p.7 页面图显示 “...dim(X)=1). ⁸ ⁹”；中译本同位置两个上标。
- **结论**：脚注编号对账以页面图为准，不以文本层为准。

## 片段 6：原文 `[?]` 不猜、只登记

- **场景**：§2.1.9 两处引文写作 `[?]`，文本层无法恢复。
- **判断**：据上下文应为 [2]，但不能替作者改正文。
- **动作**：正文保留 `[?]`；加 `% [Tutor Note: 原文两处均作 [?]，据上下文应为 [2]]`；译文脚注说明。
- **证据**：p.7 页面图确为 `[?]`；同段讨论 Hecke 作用与 [2] §1.1/§1.5 对应。
- **结论**：笔误/占位符保留 + 登记，是纪律，不是保守。

## 片段 7：`O_X` 的疑似笔误

- **场景**：§2.2.2 写 `(O_X^×)^{2g}`，但同段讨论的是系数域 `e` 的单位群。
- **判断**：疑为 `O_S^×` 或 `O_\e^×`，不能确定唯一答案。
- **动作**：正文保留 `\OO_X`；加 `% [Tutor Note: 原文此处作 O_X，疑为 O_S]`；不擅自改。
- **证据**：p.10 页面图；上下文“`O_\e ⊆ \e` 为整元素赋值环”。
- **结论**：不确定的笔误只登记、不“修正”，避免二次错误。

## 片段 8：把“非共振”讲成可计算的坐标

- **场景**：§4.3–§4.4 是全文技术核心，直译会让读者不知道定理 4.3.3.1 为何重要。
- **判断**：必须在资料卡里把“形式 étale + 本质满”翻成“切复形比较 + unipotent 障碍”，否则论证地图是空的。
- **动作**：在 `资料卡/02-论证地图.md` 第 3 步写出切复形 `Ker(id−Ad_h) → Ker(id−φ_X⊗Ad_h^{-1})` 与非共振条件的等价关系；在 `01-结果清单.md` 标注该定理是“坐标化”而非“存在性”。
- **证据**：定理 4.3.3.1 陈述（p.28）；引理 4.4.1.1（p.29）；(4.6)(4.7) 的矛盾论证。
- **结论**：资料卡的解释承担“读者能否进入 §4”的责任，不能只抄目录。

## 片段 9：并行分工按“节边界”而非“页边界”

- **场景**：42 页、13 个 chunk，串行翻译耗时过长，准备并行。
- **判断**：按页分工会让相邻译者重复翻译同一页的跨页段落；必须按节/小节边界切。
- **动作**：把 ch02a–d、ch03a–d、ch04a–d 的边界对齐到 `§2.1/§2.2/§2.3/§2.4–2.5`、`§3.1–3.2/§3.3–3.4/§3.5/§3.6–3.7`、`§4.1–4.2/§4.3–4.4/§4.5–4.6/§4.7`；页范围只作参考。
- **证据**：`工程文件/BRIEF.md` 分块表；交接说明中的 chunk 清单。
- **结论**：并行译本的接缝必须落在结构边界，否则整合时会出现重复段落或漏段。

## 片段 10：定理 A 的证明不是“分析”，是“多项式消去”

- **场景**：§3.6 只有一页多，容易被误读为“由满射性直接推出”。
- **判断**：关键在 `ps-Eis(Aut_T) ∩ Aut_cusp = 0` 与局部化后的多项式恒等式，两者缺一不可。
- **动作**：在论证地图第 6 步写出 `δ_Ĝ^n ψ = ps-Eis(ψ_0)`、`q(t)t^n ≡ 1 mod (t−λ)^m` 的构造，并注明 `λ = δ_Ĝ(triv) ≠ 0`。
- **证据**：§3.6.2–3.6.3（pp.23–24）；定理 3.5.2.1(1) 保证 `λ ≠ 0`。
- **结论**：定理 A 的“算术应用”本质是：谱侧的满射性 + 尖形式与伪 Eisenstein 像的不相交性，用多项式把局部化因子除掉。

## 片段 11：L-值不是“修正项”，是坐标变换的雅可比

- **场景**：定理 4.7.2.1 说 `Eis^spec = ζ · Eis^spec,toy`，容易被当成“差一个常数”。
- **判断**：`ζ` 来自 `τ_{0,*}^{IndCoh}(O_{BH})` 与 `O_{LS^restr_H}` 的 K-理论类之比，是行列式比，不是常数。
- **动作**：在论证地图第 4 步写明 `ζ^*_X(1)^{dim H}` 的来源（引理 4.6.4.1），并指出 Grothendieck 迹公式的作用。
- **证据**：引理 4.6.4.1（p.33）、引理 4.6.6.4（p.39）、定理 4.7.2.1（p.39）。
- **结论**：把 L-值理解为“非共振坐标与玩具模型坐标之间的雅可比”，才能解释为何它可逆。

## 片段 12：不把“未解疑点”带进译文

- **场景**：开译前 `疑点清单.tsv` 有 18 条，其中若干涉及记号与 OCR。
- **判断**：纪律要求“未解 = 0 才准开译”，不能边译边猜。
- **动作**：逐条查页面图、上下文、原文献；18 条全部标“已解”，并写明依据（A/B/I）。
- **证据**：`工程文件/work/疑点清单.tsv` 20 行（含表头），状态列无“未解”。
- **结论**：疑点清单不是形式主义；它把“翻译时的犹豫”提前到了可以查证的阶段。
