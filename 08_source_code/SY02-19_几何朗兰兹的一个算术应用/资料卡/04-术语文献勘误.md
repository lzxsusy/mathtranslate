## 4. 与既有译名的冲突处理

- `perverse sheaf`：SY02-16 作“反常层”，本文沿用；若读者熟悉“反常束”，以术语表为准。
- `unipotent`：本库既有译法有“幂幺”“单幂”两种；本文统一“幂幺”，依据 A（原文 §4.2 的 unipotent 用法）。
- `proper`：既有译法“紧合”“固有”并存；本文按代数几何惯例“紧合”，首次括注英文。
- `ind-coherent`：既有译法“归纳凝聚”；不采用“ind-相干”，以免与“相干层”混淆。
