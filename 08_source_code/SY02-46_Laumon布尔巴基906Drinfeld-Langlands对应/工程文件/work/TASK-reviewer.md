## 判定为「错误」（必须报）
1. **漏译/增译**：整句、整段、条件、从句、括号说明缺失或多出（原文没有的数学断言尤其严重）。
2. **数学内容错**：公式、上下标、量词（存在/任意）、方向（→ 写成 ←）、范围（$i\le n$ 写成 $i<n$）、层级（定理/引理/命题/猜想）、"当且仅当"改"若"、正合列方向、对偶/逆、函子方向（$f_*$/$f^*$/$f_!$/$f^!$）。
3. **术语错**：与 `工程文件/work/glossary.tsv` 冲突；或与原文含义不符（如 pervers=反常层、proper 不译、champ=叠、gerbe 不译）。
4. **指代/编号错**：引用的编号（定义 2.1、引理 5.2、§3.2、式 (1.3)）指向错误对象；"前者/后者"颠倒。
5. **中文病句导致歧义**：句子读不通、主语缺失以致无法确定断言主体。

## 不算错误（不要报）
- 语序调整、断句、同义表达、增补的过渡词、译注的存在（译注只核其**内容**是否与原文/事实相符）。
- 排版、标点全角半角、空格（另有工具检查）。
- 你认为"更漂亮"的译法。

`severity`：`critical`（数学内容错/漏掉条件/增译数学断言）、`major`（术语错、编号错、漏译整句）、`minor`（读起来歧义但结论不错）。

最后给一节「无法判定」，列你拿不准、需要主控裁决的地方（附行号与理由）。
