# 通读笔记 · SY02-46（Laumon，布尔巴基 906）

底本：Gérard Laumon, *Travaux de Frenkel, Gaitsgory et Vilonen sur la correspondance de
Drinfeld–Langlands*, Séminaire BOURBAKI, 54e année (2001–2002), n° 906, Juin 2002, 19 页；
arXiv:math/0207078v1。印刷页 = PDF 页（页眉 `906–NN`）。

## 0. 一句话主旨

本报告陈述并解释 Frenkel–Gaitsgory–Vilonen（FGV）关于**处处非分歧、`G = GL(n)`、
`X` 射影**的 Drinfeld–Langlands（几何 Langlands）对应的定理：对 `X` 上每个不可约秩
`n` 局部系统 `E`，在秩 `n` 向量丛叠 `Fib_n(X)` 上存在一个反常层 `Aut_E`，它在每个连通
分支上不可约，并满足 Hecke 特征性质（定理 2.2）。证明路线：先在带截面 `s` 的模空间
`Fib'_n(X)` 上构造 `Aut'_E`（§4），用齐次 Fourier 变换逐层归纳构造（§5），用 Gaitsgory
的消没定理（§6）证明 `Aut'_E` 的 proper 性，最后沿遗忘截面 `Fib'_n → Fib_n` 下降（§7）。

## 1. 逐节论证地图

### 引言（p1）
- 1967 年 Langlands 猜想：整体域 `F` 上约化群 `G` 的自守表示 ↔ `F` 的取值于对偶群
  `^L G` 的 Galois 表示；`^L G` 的单位分支 `Ĝ` 的根是 `G` 的余根。
- `G = GL(n)` 时 `Ĝ = GL(n,C)`；函数域情形由 Drinfeld（`n = 2`，[Dr 1]）与 Lafforgue
  （任意 `n`，[La]）证明；数域情形仍未解决。
- Drinfeld–Langlands 对应（又称几何 Langlands）是 `k(t)` 的有限扩张上**分裂**约化群 `G`
  的猜想对应：`X/k` 光滑拟射影曲线，函数域 `F`；`X` 上 `G`-丛的模空间 ↔ `X` 上
  `Ĝ`-局部系统的模空间。
- `G = GL(1)`：Rosenlicht–Lang 几何类域论（Serre [Se]）；`G = GL(2)`：Drinfeld [Dr 2][Dr 3]。
- 相关：Beilinson–Drinfeld [B-D]、Braverman–Gaitsgory [B-G]、Lysenko [Ly 1][Ly 2]。
- 本报告只讲 `X` 射影（处处非分歧）、`G = GL(n)` 的 FGV 工作，它推广 [Dr 2]。

### §0 预备（p2–4）
- 处处非分歧情形下，对应应对每个三元组（底域 `k`、系数域 `C`、`C`-系数上同调理论）成立：
  (Betti) `k = C`，`C` 特征 0 代数闭，经典拓扑可构造层；(De Rham) `k` 特征 0，`C = k`，
  Zariski 全纯 D-模；(ℓ-adique) `k` 任意，`C = Q̄_ℓ`，`ℓ` 在 `k` 中可逆，étale ℓ-进层。
- 模空间一般是代数叠，用 [L-M] 的语言。三套理论对叠都未系统建立；FGV 用 ℓ-进并额外假设
  `char k = p > 0` 以有几何 Fourier 变换，但该限制不必要。
- **本文一律用 (Betti)**：`k = C`，`D^b_c(S)` 为 `S` 的解析叠上 `C`-向量空间可构造有界
  上同调复形的导出范畴；`S = [S/G]` 时为 Bernstein–Luntz 的 `D^b_{G(C)^an}(S(C)^an)`。
- 六种运算 `f_*, f_!, f^*, f^!`；中间反常 t-结构，心 `Perv(S)` 阿贝尔、Noether、Artin、
  对 `D` 自对偶。
- 向量丛 `π: V → S` 秩 `r`；`V = [V/G_m]`（数乘作用），`P(V) = [V°/G_m] ↪ V` 开浸入，
  余闭子叠是 `B(G_m/S)`。`G_m`-等变可构造复形即 `D^b_c(V)` 的对象。
- 齐次 Fourier 变换 `Four_{V/S}: D^b_c(V) → D^b_c(V^∨)` 是范畴等价，逆为
  `Four_{V^∨/S}`，与对偶交换、t-正合。`A = [A^1/G_m]`，`Ψ = β_*C`，`β: pt = [G_m/G_m] ↪ A`；
  `H^0(Ψ) = C`，`H^1(Ψ) = α_*C`（`α: B(G_m) ↪ A`），`Ψ` 非不可约反常层，是点状反常层
  `α_*C[−1]` 经常数反常层 `C` 的扩张。
- 配对 `μ: V ×_S V^∨ → A`，投影 `p, p^∨`；定义
  `(0.1) Four_{V/S}(K) = (p^∨)_!(p^*K ⊗ μ^*Ψ)[r−1]`，`p, p^∨` 不可表且 `(p^∨)_!` 不保持
  `D^b_c`（落到 `D^-_c`），但 `Four_{V/S}` 保持 `D^b_c`。
- 定义 (0.2)：`P(V)` 上反常层 `L` 称 **proper**，若遗忘支撑的态射 `j_!L → j_*L` 是同构；
  此时 `j_!L ≅ j_*L` 是 `V` 上反常层，等于中间延拓 `j_{!*}L`。
- 引理 (0.3)：`L` proper ⇔ `(π°)_!L = 0`，`π°: P(V) → S` 为典范投影。
- Radon 变换 `Rad_{P(V)/S}(L) = (q^∨)_!q^*L[r−1]`，`H ⊂ P(V^∨) ×_S P(V)` 为关联叠
  （直线含于超平面的对）。
- 引理 (0.4)：`L` proper ⇒ `Four_{V/S}(j_!L)` 也 proper，且在 `P(V^∨) = V^{∨°}` 上限制
  等于 `Rad_{P(V)/S}(L)`。

### §1 几何类域论（p4–6）
- `X` 连通射影光滑代数曲线（紧连通 Riemann 面），亏格 `g`；基点 `x0`；
  `H_1(X,Z) = π_1^{ab}(X)` 的基 `δ_1,…,δ_{2g}`；`H^0(X,Ω^1_X)` 的基 `ω_1,…,ω_g`；
  周期 `Π_i = (∫_{δ_i}ω_1,…,∫_{δ_i}ω_g) ∈ C^g` 在 `Z` 上线性无关，生成格 `Λ ⊂ C^g`；
  `J(X) = C^g/Λ` 是 `g` 维复环面；解析映射 `φ: X → J(X)`，`x ↦ (∫_{x0}^x ω_j)_j + Λ`，
  `x0 ↦ 0`。
- `Pic(X)` 参数化线丛同构类，张量积使其成为群概形，有正合列
  `1 → Pic^0(X) → Pic(X) →^{deg} Z → 0`；`Pic^0(X)` 是阿贝尔簇。
- **定理 1.1（Abel–Jacobi）**：`J(X)` 是 `Pic^0(X)` 的底复环面，`φ: X → J(X) ≅ Pic^0(X)`
  就是 `x ↦ O_X([x]−[x0])` 的代数态射。
- `φ` 诱导 `π_1(X,x0) → π_1(J(X),0)`，即商映射 `π_1(X,x0) ↠ Λ`；故每个特征标
  `χ: π_1(X,x0) → C^×` 有唯一 `Aut_χ: π_1(Pic^0(X),0) → C^×` 使 `χ = Aut_χ∘φ_*`。
- 局部系统 = 基本群的有限维表示，故解析地得到：
  **定理 1.2**：任意秩 1 局部系统 `E`，存在唯一（在原点刚性化的）秩 1 局部系统 `Aut_E`
  on `Pic^0(X)`，使 `φ^*Aut_E = E`；且 `m^*Aut_E ≅ Aut_E ⊠ Aut_E`（`m` 为群运算）。
- **代数证明**（p6）：`X^{(d)} = X^d/S_d` 是 `d` 次有效除子的模空间，`φ^{(d)}: X^{(d)} →
  Pic^0(X)`，`D ↦ O_X(D − d[x0])`；`d ≥ 2g−1` 时是秩 `d−g` 的射影丛，故纤维单连通。
  `E^{(d)} = (r_*E^{⊠d})^{S_d}`，纤维公式 `(1.3) (E^{(d)})_D = ⊗_x Sym^{d_x}E_x`。
  秩 1 时 `E^{(d)}` 在 `φ^{(d)}` 的纤维上常值，下降为 `Aut_E`。这是 GL(1) 情形。

### §2 主定理（p6–8）
- `n ≥ 2`；`Fib_n(X)` 为秩 `n` 向量丛叠：代数、光滑纯维 `n^2(g−1)`、有限型开集的递增并；
  `g ≥ 2` 时含稠密开集，它是稳定丛拟射影概形上的 `G_m`-gerbe；连通分支 `Fib_n^d(X)` 按
  次数 `d` 划分。
- 初等下修改：`L' ⊂ L`，`L/L'` 是集中于 `x` 的长度 1 摩天层，`deg L' = deg L − 1`。
- Hecke 叠 `Hecke_n(X)`：三元组 `(x, L, L' ⊂ L)`；Hecke 对应图，投影 `(q,p')` 与 `p`
  可表、射影、光滑，相对维数 `n−1` 与 `n`。
- Hecke 算子 `H(K) = (q,p')_*p^*K[n−1]`；迭代 `H∘H`，其在对角线补集
  `(X×X − Δ_X) × Fib_n(X)` 上的限制 `S_2`-等变。
- **定义 2.1**：不可约秩 `n` 局部系统 `E`，`Fib_n(X)` 上不可约反常层 `K` 相对 `E` 有
  Hecke 性质，若存在同构 `H(K) ≅ E ⊠ K`，使得诱导同构 `(H∘H)(K) ≅ E⊠E⊠K` 在开集
  `(X×X − Δ_X) × Fib_n(X)` 上的限制 `S_2`-等变。
- **定理 2.2**（`n=2` Drinfeld [Dr 2]；一般情形 FGV [F-G-V 2]、[Ga]）：对任意不可约秩 `n`
  局部系统 `E`，存在 `Fib_n(X)` 上反常层 `Aut_E`，限制到每个连通分支 `Fib_n^d(X)` 不可约，
  且相对 `E` 有 Hecke 性质。
- 证明分两步：① 在 `Fib'_n(X)`（`(L,s)`，`s: (Ω^1_X)^{⊗(n−1)} ↪ L`，模数乘）上构造
  可构造复形 `Aut'_E`，灵感来自 `GL(n)` 尖点自守形式的 Fourier 级数展开与 Shintani 系数
  公式（Grothendieck 函数–层字典），但并非简单照搬；② 在 `Fib'_n(X)` 的大开集上证明
  `Aut'_E` 是反常层，并沿遗忘 `s` 的态射下降到 `Fib_n(X)`；难点全在第二步。

### §3 反常层 `L^d_E`（p8–9）
- `Coh^d_0(X)`：一般秩 0（有限支撑）、长 `d = dim H^0(X,M)` 的凝聚层叠；`Coh_0` 为不交并。
  `Coh^d_0(A^1) = [gl(d)/GL(d)]`（`d` 维向量空间 + 自同态，`GL(d)` 共轭作用）；光滑曲线
  étale 局部同构于 `A^1`，故 `Coh^d_0(X)` étale 局部同构于 `[gl(d)/GL(d)]`。
- 有效除子 `D ↦ O_{X,D} = O_X/O_X(−D)`；`X^{(d)} → Coh^d_0(X)` 光滑，相对维数 `d`；
  任意 `M` 同构于 `⊕ O_{X,D_i}`；行列式态射 `det: Coh^d_0(X) → X^{(d)}`，
  `⊕O_{X,D_i} ↦ ΣD_i`；`X^{(d)}_{rss}` 为无重除子，`Coh^d_{0,rss} = det^{-1}(X^{(d)}_{rss})`。
- `E` 秩 `n`；`E^{(d)}` 在 `X^{(d)}_{rss}` 上秩 `n^d` 局部系统。
- **引理 3.1**：`E^{(d)}[d]`（`E^{(d)}` 放在次数 `−d`）是反常层，是它到 `X^{(d)}_{rss}` 的
  限制的中间延拓；`E` 不可约（半单）⇒ `E^{(d)}[d]` 不可约（半单）。
- `L^d_{E,rss} = det^*E^{(d)}|Coh^d_{0,rss}` 是秩 `n^d` 局部系统，不可约/半单性同上。
- **定义 3.2**：`L^d_E` 为 `L^d_{E,rss}` 到整个 `Coh^d_0(X)` 的中间延拓；`L^d_E` 不可约
  （半单）若 `E` 是；`X^{(d)} → Coh^d_0` 的 `d`-平移拉回等于 `E^{(d)}[d]`。

### §4 复形 `Aut'_E`（p9–11）
- 此后 `g ≥ 2`；`g = 0,1` 时无秩 `≥ 2` 不可约局部系统，对应为空。
- `Fib'_n(X)`：`(L, s)`，`s: (Ω^1_X)^{⊗n−1} → L`，模数乘。
- `U_n`：三元组 `(L, L•, s•)`，完全旗 `0 = L_0 ⊂ … ⊂ L_n = L`，`s_j: (Ω^1_X)^{⊗j−1} ≅
  L_{n−j+1}/L_{n−j}`（`j=1..n`），模数乘 `(s_j) ~ (t s_j)`。
- 态射 `f_n: U_n → Fib'^{n(n−1)(g−1)}_n(X)`（`s_n` 诱导的 `s`）；
  `g_n: U_n → A^1` 把三元组送到各扩张类
  `0 → L_j/L_{j−1} → L_{j+1}/L_{j−1} → L_{j+1}/L_j → 0` 之和，落在
  `Ext^1 ≅ Ext^1(O_X, Ω^1_X) ≅ C`。
- `G_m` 作用 `t·(L,L•,s•) = (L,L•,t·s•)`，`t·s• = (t^{n−j}s_j)`；`g_n` 等变；商上
  `g_n: U_n → [A^1/G_m] = A`；`L_n = (f_n)_!(g_n)^*Ψ[dim U_n]`。
- 对每个 `d` 有对应 `Mod'^d_n(X)`（`(Ω^1_X)^{⊗n−1} ↪ L' ⊂ L`，次数
  `n(n−1)(g−1)` 与 `n(n−1)(g−1)+d`）→ `Coh^d_0`；函子
  `M'^d_{n,E}(K) = p_*p'^*(K ⊗ q^*L^d_E)[nd]`。
- **定义 4.1**：`Aut'_E` 在分支 `Fib'^{n(n−1)(g−1)+d}_n(X)` 上定义为 `M'^d_{n,E}(L_n)`
  （`d ≥ 0`），`d < 0` 时为 0。

### §5 用 Fourier 变换构造（p11–13）
- `Coh_i(X)`（一般秩 `i` 凝聚层）、`Coh'_i(X)`（带 `s_i: (Ω^1_X)^{⊗i−1} ↪ M_i`，模数乘）；
  稠密开集 `Fib_i`、`Fib'_i`；连通分支按 `deg M_i` 的 `d` 划分。
- **引理 5.1**：存在常数 `c(g,n)`，使对 `d ≥ c(g,n)` 且
  `Hom_{O_X}(L, (Ω^1_X)^{⊗n+1}) ≠ 0` 的 `L ∈ Fib^d_n(X)`，`L` 非常不稳定：存在非平凡
  直和分解 `L = L_1 ⊕ L_2` 使 `Ext^1(L_1,L_2) = 0`。
- `C_i ⊂ Coh_i(X)`：次数 `≥ c(n,g) + i(i−1)(g−1)` 且 `Hom(M_i, (Ω^1_X)^{⊗n+1}) = 0` 的
  开集；于是 `Hom(M_i, (Ω^1)^{⊗i}) = 0`，由 Serre 对偶 `Ext^1((Ω^1)^{⊗i−1}, M_i) = 0`。
- `V_i`：`(M_i, s_i)`，`M_i ∈ C_i`；`V^∨_i`：扩张 `0 → (Ω^1)^{⊗i} → M_{i+1} → M_i → 0`；
  `π_i, π^∨_i` 对偶向量丛；开集 `V°_i = {s_i 单射}`，
  `V^{∨°}_i = {M_{i+1} ∈ C_{i+1}}`，典范同构 `V^{∨°}_i ≅ V°_{i+1}`。
- `G_m` 数乘作用取商，得基本图；`K_{E,1} = (ι_0)_*(π^{∨°}_0)^*L_E`（`L_E` 在 `C^d_0` 上
  为 `L^d_E` 平移 `d−1`），递推
  `K_{E,i+1} = (ι_i)_*(j_i^∨)^*Four_{V_i/C_i}((j_i)_!K_{E,i})`。
- **引理 5.2**：`K_{E,i}` 在 `V°_i ∩ Fib'^{i(i−1)(g−1)+d}_i` 上的限制等于
  `M'^d_{i,E}(L_i)`；特别 `K_{E,n}` 与 `Aut'_E` 在 `V°_n ∩ Fib'^{n(n−1)(g−1)+d}_n` 上一致。

### §6 消没定理（p13–15）
- `i ≥ 1`，`d ≥ 0`；`Mod^d_i(X)`：`(L, L' ⊂ L)`，`L'` 是下修改、余长 `d`；投影 `p', p, q`
  （`q` 取 `L/L'`）；`M^d_{i,E}(K) = p_*p'^*(K ⊗ q^*L^d_E)[id]`。
- **定理 6.1（Gaitsgory, [Ga]）**：`E` 不可约秩 `n`；对 `i = 1,…,n−1` 与 `d > in(2g−2)`，
  `M^d_{i,E}` 恒为零。
- **注 6.2**：证明长且技术，超出本报告范围；`i = 1` 时即 Deligne 结果（见 [Dr 2]）：
  `(φ^{(d)})_*E^{(d)} = 0`，对 `X` 上任意秩 `n > 1` 不可约局部系统与 `d > n(2g−2)`。
- **命题 6.3**：`E` 不可约秩 `n`；对 `i = 1,…,n−1`，`(j_i)_!K_{E,i} → (j_i)_*K_{E,i}` 是
  同构。证明思路：在 `Fib_i(X) ∩ C_i` 上 `V°_i` 是 `V_i → C_i` 的零截面补集；由引理 (0.3)，
  只需证 `(π°_i)_!K_{E,i} = 0`；由引理 5.2 与定理 6.1 得。
- 推论：`K_{E,i}` 不可约 ⇒ `(j_i)_!K_{E,i}` 不可约（中间延拓）；Fourier 变换保持反常性
  与不可约性，故归纳得 **推论 6.4**：`K_{E,n}` 在每个连通分支上的限制不可约。

### §7 下降（p15–17）
- 回顾两个一般结果：`χ_K(s) = Σ_i (−1)^i dim H^i(K_s)`（Euler–Poincaré 示性函数）。
- **引理 7.1（Deligne, [Il] 推论 2.10）**：`f: Y → Z` 紧合（概形或可表紧合叠态射），
  `K, K'` 局部同构 ⇒ `f_*K, f_*K'` 的 Euler–Poincaré 示性函数相同。
- **引理 7.2**：`V → S` 常秩 `r` 向量丛，`π: P(V) → S`；`P` 上不可约反常层 `K` 同构于
  `π^*(L)[r−1]`（`L` 为 `S` 上反常层）⇔ `χ_K` 沿 `π` 的纤维常值。
- `Y^d_n`（Drinfeld 引入）：`(L, s•)`，`L` 次数 `n(n−1)(g−1)+d`，`s• = (s_1,…,s_n)` 为一串
  单射 `(Ω^1_X)^{⊗(n−1)+…+(n−i)} ↪ ∧^i L`，满足 Plücker 关系，使 `s•` 在一般点处给出
  完全旗。它是三元组 `(L, L•, s•)` 的“部分紧化”；`(L,L•,s•) ↦ (L,s•)` 把三元组叠与
  开集 `Y^{d,°}_n` 等同（各 `s_i` 的余核无挠）。`G_m^n` 作用；`U_n`（resp. 商 `U_n`）是
  `Y^{0,°}_n` 模 `G_m`（resp. `G_m^2`）经 `t ↦ (t,t^2,…,t^n)` 的商。
- **命题 7.3（[B-G] 命题 1.2.2）**：遗忘态射 `(L,s•) ↦ (L,s_1)` 过商为可表紧合态射
  `f̃: Ỹ^d_n = [Y^d_n/G_m^n] → Fib'^{n(n−1)(g−1)+d}_n(X)`。
- `Φ ∈ D^b_c(Ỹ^0_n)` 为 `(g_n)^*Ψ` 沿 `[Y^{0,°}_n/G_m^2] → [Y^{0,°}_n/G_m^n] ⊂ Ỹ^0_n` 的
  紧支撑前推；`N^d_{n,E}(K) = p_*p'^*(K ⊗ q^*L^d_E)[nd]`（图 `Z^d_n → Coh^d_0`）。
- **引理 7.4**：`Aut'_E|Fib'^{n(n−1)(g−1)+d}_n = f̃_*N^d_{n,E}(Φ)`。

## 2. 数学难点（译文必须准确的地方）

1. **两套 “propre”**：态射的 propre = 紧合；反常层的 proper 是 (0.2) 的定义术语，保留
   `proper` 并在首现处加译注。切勿把 `faisceau pervers propre` 译成「紧合反常层」。
2. **`(π°)_!L = 0`**（引理 0.3）与 **`(p^∨)_!` 不保持 `D^b_c`**（p4）是两处容易混淆的 `!`。
3. **`E^{(d)}[d]` 的 `[d]` 是平移**：`E^{(d)}` 放在次数 `−d`；`[d]` 使其成为反常层。
4. **`det^*E^{(d)}`** 是行列式态射的拉回，不是 `det` 的张量积。
5. **`M'^d_{n,E}` 与 `M^d_{i,E}` 的下标不同**：前者在 `Fib'_n`，后者在 `Fib_i`；`[nd]` 与
   `[id]` 的平移也不同（原文如此）。
6. **`L_E` 的平移**：`L_E` 在 `C^d_0` 上等于 `L^d_E` **平移 `d−1`**（p13），不是 `d`。
7. **`U_n` 与 `U_n`（带上划线/商）**：原文用上划线区分三元组叠与其 `G_m`-商 `[U_n/G_m]`；
   译文用 `\mathcal U_n` 与 `\overline{\mathcal U}_n`（原文 TeX 第 1579、2091 行均为 `\overline`；
   初稿曾误记为下划线，已更正）。
8. **`Y^d_n`、`Ỹ^d_n`、`Z^d_n`** 三个叠的记号必须分清；`Ỹ` 是 `[Y/G_m^n]`。
9. **`Φ` 的紧支撑前推路径**：`[Y^{0,°}_n/G_m^2] → [Y^{0,°}_n/G_m^n] ⊂ Ỹ^0_n`，两步。
10. **`Ext^1` 计算**：`Ext^1(L_{j+1}/L_j, L_j/L_{j−1}) ≅ Ext^1((Ω^1)^{⊗n−j−1},
    (Ω^1)^{⊗n−j}) ≅ Ext^1(O_X, Ω^1_X) ≅ C`（原文如此；`g_n` 取这些类之和）。
11. **`c(g,n)` 与 `c(n,g)`**：原文两处写法顺序不同（p12），照译，不改。
12. **`d > in(2g−2)`**（定理 6.1）与 **`d > n(2g−2)`**（注 6.2）：照译，勿统一。
