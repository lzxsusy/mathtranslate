2. **[符号/约定]**　§引言：宏大总览｜`c01.tex`
   > 上文：`\operatorname{tr}F^{2}=d\left(\operatorname{tr}A\,dA+\frac{2}{3}A^{3}\…`
   记号约定：这里 $A^2\equiv A\wedge A=\tfrac12[A,A]$、$A^3\equiv A\wedge A\wedge A$，外积与 Lie 代数矩阵乘法同时进行；所以「$F=dA+A^2$」与教科书中常见的「$F=dA+\tfrac12[A,A]$」逐字相同，(1.3) 的系数 $2/3$ 正依赖于此。自查 (1.3) 的正确做法是展开 $d\operatorname{tr}F^2=2\operatorname{tr}(dF\wedge F)$，再用 Bianchi 恒等式 $dF=A\wedge F-F\wedge A$ 化简；若把 $A^2$ 误当 $\tfrac12[A,A]$ 的独立记号，系数就会错成 $1/3$ 或 $1/2$。
