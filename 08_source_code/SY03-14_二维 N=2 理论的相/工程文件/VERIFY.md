# 审校（Verification）规范 —— 独立第二遍，针对译者初稿

目标：在**不重写**译者的前提下，把「公式符号级」错误清零。译者已自检结构，你负责内容保真。

## 0. 你的产出

- 直接修改被审校的分片文件（这是你唯一可写的文件），做**最小必要修正**；
- 在该文件头注释区加一行：`% 审校：<你的名字> 已完成逐式核对（修正 N 处）`；
- 向 Lead 回报（格式见 §4）。

## 1. 必查项（按优先级）

### A. 公式（最高优先级，逐式）
对分片中**每一个**展示公式（含无编号的）：
1. `read_image` 打开对应 `pages/page-NN.png`，在图像上找到该式；
2. 逐个符号比对：上下标的**位置与层级**、`\bar`/`\tilde`/`\hat` 的位置、希腊字母、指标配对（自由指标两侧是否一致）、± 号、系数（1/2、√2、2π、e² 等）、括号、`\wedge`/`\cdot`、矩阵转置；
3. 看不清就用 `tools/crop.py` 放大（--dpi 600–800）；
4. 有差异 → 以**图像**为准修正；若图像本身可疑 → 保留原文并加 `% [原文疑误: ...]`（若译者已加且有依据，勿删）；
5. 检查 `\tag{x.y}` 与该式在原文中的编号一致（编号不连续或错位即为重错）。

### B. 完整性
- 逐段核对：原文每一自然段、每一句在译文中都有对应；**没有整段漏译、没有合并段落**；
- 脚注：原文有几个脚注，译文就有几个 `\footnote`（编号可不一致，内容必须对应）；
- 原文的无编号小标题（斜体/下划线独立行）均已保留为 `\subsection*`/`\subsubsection*`；
- 检查正文中提到的公式编号「式 (x.y)」在该分片或全书中有对应式存在。

### C. 语义
- 漏译、误译（尤其逻辑连接词、条件从句、否定式）、物理术语错误；
- 术语与 GLOSSARY 一致（不一致就修正；GLOSSARY 未收但学界通用的可保留并回报）；
- 数值/量词错误（如 "a few" 译成「几个」、dimension 4 译成 2 等）。

### D. 批注质量（Tutor Note）
- 逐条读：**技术断言是否成立**？有无幻觉（编造定理、编造文献、编造公式）？
- 发现错误断言：改正或删除（删时在回报中列出）；
- 若某段有明确的省略证明而译者未批注，可补一条（不超过 2 条）。

## 2. 纪律

- **不要**改译者的文风、不要重译整段（除非原译有实质性错误）；
- **不要**动其他分片、不要动 `main.tex`、`tools/`、SPEC/GLOSSARY；
- **不要**编译；
- 每处修正都要能指出「原文图像第几页哪个式子的哪个符号」。

## 3. 判据

- 一个式子只要有**一个符号**与图像不符，就是 error，必须修；
- 术语层面 minor 偏差可保留但要在回报中列出；
- 目标是：公式错误 0，漏译 0，批注幻觉 0。

## 4. 回报格式

```
审校文件：sections/xxx.tex（原作者：yyy）
覆盖：PDF 第 a–b 页
公式：逐式核对 N 个（带号 n1–n2 + 无编号 m 个），修正 k 处
修正清单：
 1) (x.y) …原… → 改…（依据：page-NN 图像）
 2) …
完整性：漏译 0 / 补译 x 段；脚注 x/x；小标题齐全
批注：Tutor Note N 条，删/改 m 条（理由）
遗留疑点：无 / 具体条目（附证据）
```
