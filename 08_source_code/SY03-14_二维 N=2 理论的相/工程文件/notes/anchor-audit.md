## 1. 方法与数据来源

- 以 `main.tex` 的 `\frag{...}` 顺序（15 个分片）遍历，用正则 `%\s*====\s*原文 PDF 第\s*(\d+)\s*页` 提取锚点及其"锚点前最后一段译文 / 锚点后第一段译文"。`sections/appendix-pagemap.tex` 只在正文里提了一句锚点格式，本身不含锚点（也不属正文分片），未计入。
- 页首/页末英文基准取自原 PDF 的文本层（PyMuPDF 逐页提取），等价于 `text/page-NN.txt` 的页首内容，且可避开部分 `text/*.txt` 为二进制/编码损坏的问题。公式与符号仍以 `pages/page-NN.png` 为最终依据（抽查了 p6、p8、p49、p58、p60、p61、p82 等页的图像）。
- 判定"锚点后紧跟的译文对应第 N 页页首"的标准：该译文是否落在第 N 页页首句内（含跨页句的断点处）。若第 N 页页首句已被译在锚点之前，记为"滞后"；若锚点后先出现第 N−1 页的内容，记为"提前"。
