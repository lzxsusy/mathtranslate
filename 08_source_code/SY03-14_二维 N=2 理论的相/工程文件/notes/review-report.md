## 五、两处关键判断的独立复核

**(3.19) 的 $2\pi$ 与 $4\pi$**（三位审校者独立计算，结论一致）：按 (2.31)
$\widetilde W(x)=-x\ln x\cdot p/\sqrt2$ 与 (2.30) 的 $\sqrt2\widetilde W'(D-iv_{01})$ 结构，
$D$ 项系数为 $-r-\frac{1}{2\pi}\sum_iQ_i\ln|\sigma|/\mu$，与 (3.12) 的 $r_{\rm eff}$ 逐字相符
**当且仅当** (3.19) 的分母为 $4\pi$；且 $4\pi$ 版本代入 $U=4e^2|\widetilde W'|^2$ 恰给出 (3.20)，
而 $2\pi$ 版本与 (3.21)(3.22) 差因子 2。故判 (3.19) 为原文笔误。

**p39 的 $\sqrt r$**：$r\ll0$ 相中 $D=0$ 要求 $|p|^2=-r/n>0$（与 p18、p54 的 $\sqrt{-r/n}$ 一致），
$m_\chi^2\propto-r$，故应为 $e\sqrt{-r}$；$r<0$ 时 $\sqrt r$ 为虚。判为原文笔误。

## 六、遗留与建议

1. **「拉格朗日量 / 拉氏量」**已统一为「拉格朗日量」；若教授偏好「拉氏量」（口语化但常见），
   可一条命令全局替换。
2. **「局域化」**（s03d，3 处）保留：指 SUSY localization，与几何上的「局部」不同义。
3. **脚注编号**：译文脚注编号由 LaTeX 重排，与原文页码上的编号不同（原文正文 11 条 + 标题页 1 条，
   内容逐页对应）。
4. **参考文献**：保留英文原貌（书目信息不可翻译）；编号用 LaTeX 的 `[n]` 体例，原文排作 "n."，
   正文引用本就写作 `[n]`，故不改。
5. **图表**：原文无插图、无表格（0 个矢量图元、0 个嵌入位图，经逐页渲染目视复核），
   本译本因此无 `\includegraphics`；「对齐数值」均为行间公式，已如实还原。
6. 若需与原文逐页对照，见书末附录「原文页码—译文页码对照表」。
