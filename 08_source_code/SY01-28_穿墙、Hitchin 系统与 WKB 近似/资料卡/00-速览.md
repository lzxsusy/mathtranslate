## 二、三条主线

**主线 I（物理来源，§3，占全篇近三分之一）**
6d (2,0) 超共形理论紧化在带穿刺点的黎曼面 $C$ 上得到 class $\CS$ 理论；再在 $S^1$ 上紧化到 3d，得到 $d=3,\CN=4$ 非线性 sigma 模型，其靶空间恰是 $C$ 上 Hitchin 系统的模空间 $\CM$。把 $S^1$ 与 $C$ 的紧化次序对调（「量子场论的 Fubini 定理」），Hitchin 方程就作为 BPS 方程出现——(1.1)–(1.3)（译本 p6），即 (3.32)–(3.34)（p28）。穿刺点处的奇点类型（正则/不规则）编码 6d 的「缺陷算子」，由五膜交叠的几何翻译成 $(A,\varphi)$ 的边界条件：(3.74)–(3.76) 正则情形、(3.115)–(3.116) 不规则情形。

**主线 II（几何构造，§4–§7）**
Hitchin 方程等价于 $\CP^1$ 上的一族平坦联络 $\CA(\zeta)=\frac{R}{\zeta}\varphi+A+R\zeta\bar\varphi$（(1.8)，p10），因此模空间带全纯辛形式 $\varpi_\zeta=\frac12\int_C\Tr\delta\CA\wedge\delta\CA$（(1.9)=(4.10)，p11/p57）。取 $C$ 的一个装饰三角剖分 $T$，每条边 $E$ 给一个 Fock–Goncharov 交比坐标 $X^T_E$（(5.2)，p60），其泊松括号就是同调交积（(5.9)，p61）。关键一步是把 $T$ 取成 **WKB 三角剖分** $T_\WKB(\vartheta,\lambda^2)$——由相位 $\vartheta$ 的 WKB 曲线 $\langle\lambda,\partial_t\rangle=e^{i\vartheta}$（(6.3)，p71）的叶状结构诱导，顶点落在 $\lambda^2$ 的零点与奇点上，并辅以「小平坦截面」装饰（(6.6)–(6.9)，p74）。这样得到的 $X^\vartheta_\gamma:=X^{T_\WKB(\vartheta)}_E$（(7.3)–(7.4)，p81）自动满足达布坐标的两条要求：泊松括号 (7.5)（p81），以及半平坦极限（(1.5)，p8）。

**主线 III（穿墙 = 辛同胚，§2、§6.6、§7.5–§7.8、§11）**
$\vartheta$ 变化时 WKB 叶状结构连续变形，只在 $\vartheta$ 撞上某条 BPS 射线 $\ell_{\gamma,u}=\{\zeta:Z_\gamma(u)/\zeta\in\R_-\}$ 的相位时，三角剖分发生 flip（超多重态，$\Omega=1$）或 juggle（矢量多重态，$\Omega=-2$），或 pop（味对称）。相应的坐标变换恰是 KS 变换：$X^+_\gamma=X^-_\gamma(1+X^-_{\gamma_{\rm hyper}})^{\langle\gamma,\gamma_{\rm hyper}\rangle}$（(7.33)，p86）与 $X^+_\gamma=X^-_\gamma(1-X^-_{\gamma_{\rm vect}})^{-2\langle\gamma,\gamma_{\rm vect}\rangle}$（(7.56)，p89）。于是 $\vartheta\mapsto\vartheta+\pi$ 这一整圈的净变换（omnipop）就是**谱生成元**
$$\mathbf S=\prod^{\circlearrowleft}_{\gamma:\ \vartheta<\arg(-Z_\gamma(u))<\vartheta+\pi}K_\gamma^{\Omega(\gamma;u)}$$
（(11.1)，p132；$S$ 正是 GMN1 黎曼–希尔伯特问题的斯托克斯矩阵）。§11 把 $\mathbf S$ 化为可显式计算的初等辛变换之积（星形引理与 ISP/RSP 公式 (11.8)–(11.15)，p133–134），从而给出**不需要预先知道中心荷相位**就能读出全 BPS 谱的算法——这是本文对 GMN1 的实质推进。

## 四、与前后文献的关系

**与 GMN1（arXiv:0807.4723，《穿墙、Hitchin 系统与 WKB 近似》的前篇）**
GMN1 在 $R\to\infty$（半平坦极限）下给出达布坐标 $X^{\rm RH}_\gamma$：用 3d 理论的 BPS 态与 KS 穿墙公式 (2.18) 定义一个黎曼–希尔伯特问题，其解即 $X^{\rm RH}$。GMN2 要做的是**去掉 $R\to\infty$**：证明对任意 $R$，WKB 三角剖分给出的 $X^\vartheta_\gamma$ 同样满足 GMN1 的三条公理，并在 $R\to\infty$ 时退回 $X^{\rm sf}_\gamma$（§13.5）。§14 进一步把 $X^{\rm RH}$ 满足的微分方程与本文比较，指出两者只在 $R$ 大时一致。**接口公式**：GMN1 (2.18)（KS 公式）与 (5.14)（半平坦一阶近似与常数 $c$）；GMN2 侧见 (7.33) 与 §13.5。

**与 GMN3（谱网络那一篇）**
GMN2 §6 已经把「WKB 曲线族」当作谱网络的前身使用（有限 WKB 曲线 ↔ BPS 态）。GMN3 把谱网络本身提升为主要对象，加入 framed BPS 态与叶层（lamination）；本卡的术语表据此冻结「谱网络／网络边／叶层」（编号待核）。

**与 GMW（2d–4d 穿墙）**
GMW 处理的是耦合 2d–4d 系统的穿墙，是「4d 谱 + 2d 谱」混合的另一种拼法；GMN2 §12 的范畴猜想与其动机同源（都指向 KS 的 DT 进路），但本文只作类比，未建立定理（§12 自陈粗略）。

## 五、读法建议

1. **先读 §1（译本 p6–12）**。它是作者自己写的导读，把「为什么是 Hitchin / 为什么是 WKB / 为什么穿墙等于辛同胚」讲了一遍；读完 §1 再读任何技术节都不会迷路。
2. **数学读者**走 §2 → §4 → §5 → §6 → §7 → §11，跳过 §3 与 §9–§10（原文 p5 明言可跳，但补一句：代价是穿墙的物理动机只剩结论）。核心是 §5（FG 坐标）与 §7（WKB 三角剖分给坐标）。
3. **物理读者**走 §1 → §3 → §9 → §10 → §11，§5–§7 只需记 (5.2)、(5.9)、(7.3)、(7.33)、(7.56) 五式。
4. **只想看穿墙机制**：§2.3（穿墙公理）→ §7.5–§7.6（三角剖分的初等变换 ⟹ KS 变换）→ §11.1（omnipop ⟹ 谱生成元）。这条线 20 页，是全篇最硬的部分。
5. **要算具体理论**：§9.4–§9.5（$N=1,2,3,4$ 与结合面体）、§10（$N_f=0,\dots,4$）、§11.4–§11.6（$SU(2)$ 各例的 $\mathbf S$ 显式分解）。
6. **别指望定理编号**：全文没有 `theorem` 环境（已 grep 确认 `\begin{prop}/lem/thm` 为 0），所有结果都以「编号公式 + 正文断言」的形式给出；引用时请引式号，不要引「定理 N」。
