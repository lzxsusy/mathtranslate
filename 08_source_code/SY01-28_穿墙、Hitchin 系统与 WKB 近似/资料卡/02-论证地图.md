## 二、逐步说明

### D1 从 6d (2,0) 到 class S
- **做什么**：把 $K$ 个 M5 膜放在 $\R^{1,3}\times C$ 上，低能得到 4d $\CN=2$ 理论；$C$ 的穿刺点装「缺陷算子」。
- **依据**：§3.1.1–3.1.3（译本 p19–24）；BPS 弦 (3.11) p22；电荷格 §3.1.4；动能项 §3.1.5。
- **最脆**：这一步全是物理推导，没有数学定理。穿刺点处的缺陷算子由 $(A,\varphi)$ 的奇点**定义**（p6 原文说得明白），所以「$C$ + 奇点类型 = 理论」这个字典的可信度取决于 §3.2 的膜构造，而膜构造只在若干例子里被独立的场论计算校验过。

### D2 紧化到 3d：靶空间 = Hitchin 模空间
- **做什么**：把 $C$ 与 $S^1$ 的紧化次序对调（「量子场论的 Fubini 定理」），先在 $S^1$ 上紧化得 5d SYM，再在 $C$ 上紧化，BPS 方程正是 Hitchin 方程。
- **依据**：§3.1.6，**(3.32)–(3.34) p28**，与 (1.1)–(1.3) p6 是同一组方程。
- **最脆**：交换紧化次序只在低能有效理论层面成立；「3d 靶空间恰是 $\CM$（作为黎曼流形，不只是复结构）」是本文全部几何构造的前提，本文只用不证。

### D3 Hitchin 方程 ⟺ 平坦联络族
- **做什么**：令 $\CA(\zeta)=\frac{R}{\zeta}\varphi+A+R\zeta\bar\varphi$，则 $\CA$ 对**任意** $\zeta\in\CP^1$ 平坦 ⟺ (1.1)–(1.3)。
- **依据**：(1.8) p10；§4.2.1 的 (4.13)–(4.15) p58。
- **最脆**：不脆。这是逐项验算，$\zeta$ 的三个幂次分别给出三式。

### D4 达布问题：三条公理
- **做什么**：不问「怎么造坐标」，先列坐标必须满足的三条：P1 泊松括号 (1.4) p8；P2 半平坦极限 (1.5) p8；P3 过 BPS 射线的 KS 跳变 (1.6) p9。然后证明「满足这三条的坐标若存在则唯一」。
- **依据**：§1（p8–9）、§2.2（p14–16）、§2.4（p17–18）。
- **最脆**：**P2 的表述是全文最含糊的一处**——它同时要求 $\zeta\to0,\infty$ 与 $R\to\infty$，但 §13 只证了 $R\to\infty$（见 D12）。P3 的 $\pm$ 号在 (1.6) 里没有定，靠 §7.7 的二次加细补。原文 (1.6) 那句「更精确的方程见下面的 (1.6)」是自指（勘误 B-1）。

### D5 FG 坐标及其泊松括号
- **做什么**：在装饰三角剖分 $T$ 上，每条边 $E$ 取交比 $X^T_E$ (5.2) p60；证明 $\{X^T_E,X^T_{E'}\}=\langle E,E'\rangle X^T_EX^T_{E'}$ (5.9) p61。
- **依据**：§5.1–5.5（p59–61）；附录 A 的基 $\CB(E_{ij},t)$ (A.1) p153 是同一构造的矩阵版。
- **最脆**：$X^T_E$ 只在 Zariski 开片 $U_T$ 上有定义（分母可能为零）；跨片比较要做解析延拓，原文靠「这些函数在 $\CM$ 上给出完备的规范不变函数组」（附录 A 的结论）来保证，但没给整体定义域。

### D6 初等变换群胚
- **做什么**：三角剖分之间由 flip / pop / juggle 连接；每种变换给出一组坐标变换公式 (5.15)–(5.19) p64–65，且都是辛变换。
- **依据**：§5.6–5.9（p62–70）；(5.30)–(5.40) p69–70 是 juggle 的代数准备。
- **最脆**：juggle 涉及「极限三角剖分」——允许退化面（图 19–20）与环（图 21–22），此时边不再是无向的、坐标可能取 $0$ 或 $\infty$。§5.9 的处理是本文技术上最容易被审稿人挑的地方：它要求三角剖分「足够一般」，而这句话的定量版本从未给出。

### D7 WKB 曲线与 BPS 态的对应
- **做什么**：WKB 曲线是 $\langle\lambda,\partial_t\rangle=e^{i\vartheta}$ 的积分曲线 (6.3) p71；整体分四类，**有限 WKB 曲线（闭合或起止于分支点）对应 BPS 态**，其中心荷 $Z_\gamma=\pi^{-1}\oint_\gamma\lambda$。
- **依据**：§6.1–6.3（p71–73）；(6.2) p70 的粗 WKB 近似；附录 C 的误差估计 (C.3)–(C.11) p160–161。
- **最脆**：**「有限 WKB 曲线 ↔ BPS 态」是物理对应，不是定理**。它的可靠性来自 (6.2) 的渐近展开 + 附录 C 的一致估计：只有当 $R\to\infty$ 时 WKB 近似才受控，而本文要处理**任意 $R$**。所以 D7 提供的是「$\vartheta$ 的临界值集合 = BPS 射线的相位集合」这一定性图象，定量跳变公式 (7.33) 则另行证明。

### D8 定义 WKB 三角剖分与装饰
- **做什么**：(6.4) p71：每个 WKB 曲线族取一条一般曲线，把 $C$ 切成面为三角形/退化三角形的胞腔，只取同痕类，得 $T_\WKB(\vartheta,\lambda^2)$；装饰是每个顶点处的「小平坦截面」$s^{(1)}$ (6.6)–(6.9) p74。
- **依据**：§6.4–6.5（p73–75）；图 25（diamond-disc，菱形/圆盘两种胞腔）、图 25–29（三类跳变的局部图象）。
- **最脆**：装饰的**离散选取**依赖「沿坠入奇点的 WKB 曲线指数式小」这一事实，而这条性质只在 $\zeta$ 落在对应半平面 $H_\vartheta$ 时成立。$L$ 个不规则奇点情形还要额外约定 $X^T_E=0$（§8，p94），这一步在原文里是一句话带过的。

### D9 $X^\vartheta_\gamma$ 是达布坐标
- **做什么**：(7.3)/(7.4) p81 定义 $X^\vartheta_\gamma$，(7.5) p81 证泊松括号；连同 (7.11)–(7.22) 的渐近，得到 P1 与 P2 的「$\zeta\to0$ 侧」。
- **依据**：§7.1–7.4（p78–83）；同调标号的计数 $\operatorname{rank}\hat\Gamma=6g_C+3n_{\rm sing}-6$。
- **最脆**：同调标号 $\gamma_E$ 的**符号约定**。$\langle\gamma_E,\hat E'\rangle=\delta_{EE'}$ 与 $\langle E,E'\rangle$ 的带符号计数必须相容，否则 (7.5) 与 (5.9) 差一个符号，整条链的 $\pm$ 会全线翻转。原文在 §7.1 用「逆时针时 $E$ 紧接 $E'$ 之前记 $+1$」固定它，但这句话只在图 14 的四边形里被检验过。

### D10 跳变 = KS 变换（核心）
- **做什么**：$\vartheta$ 越过 BPS 射线时，$T_\WKB$ 发生 flip（超多重态）或 juggle（矢量多重态）。在同调层面 (7.23)–(7.25) p85 给出 $\gamma_E$ 的变换，在坐标层面给出 (7.33) p86 与 (7.56) p89。
- **依据**：§7.5–§7.6（p84–91）；关键技术是 $m e^{-i\vartheta}\in i\R$ 时**无跳变**的证明（§7.6.3 p90）——它保证「味对称不产生穿墙」，从而 (7.33) 的指数只能是 $\langle\gamma,\gamma_{\rm hyper}\rangle$。
- **最脆**：**这是全篇最硬、也最容易出符号错的一步**。三个风险：(a) 退化边的 flip 与普通边的 flip 给的同调变换不同（$\gamma^-_{E_{41}}=\gamma^+_{E_{41}}-\gamma^-_E$ 只在 $\langle E,E_{41}\rangle=1$ 时对）；(b) 矢量多重态要对同一条边做两次 flip，故出现 $-2$ 次幂；(c) 若 $\langle E,E_{41}\rangle=2$，指数变 $-2$（§5.7 p65 的脚注）——这一条在 Nf=0 的例子里恰好被用到（$\tilde X_{\gamma_1}=X_{\gamma_1}(1+X_{\gamma_2})^2$）。

### D11 从 omnipop 到谱生成元
- **做什么**：$\vartheta\mapsto\vartheta+\pi$ 时叶状结构不变（(6.3) 的相位 $\vartheta$ 加 $\pi$ 给同一条曲线，因为 $\langle\lambda,\partial_t\rangle$ 与 $-\langle\lambda,\partial_t\rangle$ 定义同一族），装饰却在每个顶点换本征线——这个「同时 pop」就是 omnipop，其净变换是 $\mathbf S=\prod^{\circlearrowleft}K_\gamma^{\Omega(\gamma;u)}$ (11.1) p132。
- **依据**：§11.1（p132–137）；星形引理 (11.10) p133；(11.8)–(11.15) p133–135 把 $\mathbf S$ 化为初等辛变换之积；§11.2–11.6 的例。
- **最脆**：$\mathbf S$ 的**乘积分解唯一性**。原文说按 $\arg Z_\gamma$ 排序后分解唯一（p132），这依赖「没有两个 BPS 态的相位重合」——而在 BPS 射线的**端点**（$\arg Z_\gamma$ 相等）恰好是穿墙发生的地方。原文的处理是「取一般的 $\vartheta$」，把重合留给连续性/极限论证，没有给出定量的一致估计。这是 D11 与 D12 之间的缝。

### D12 $R\to\infty$ 与 GMN1 会合
- **做什么**：§13 用 sinh-Gordon 型的技巧证明 $X^\vartheta_\gamma=X^{\rm sf}_\gamma(1+O(e^{-cR}))$；§14 把 $X^\RH$ 满足的微分方程与本文比较。
- **依据**：§13.5 p150（结论）；(13.43) p151（$\omega_+$ 的分解）；§14 (14.1)–(14.7) p152。
- **最脆**：**常数 $c$ 未知**（只猜 $\pi\min|Z_\gamma|$）；且 §14 明说 (14.1)–(14.5) 不足以保证全纯，小 $R$ 时 RH 问题是否有解都未定。换句话说，D12 只把 GMN1 与 GMN2 在**大 $R$ 的渐近展开**里接上，没有证明两者是同一个解析对象。

## 四、三个技术支点

1. **交比 = 泊松**（D5）：$X^T_E$ 的定义 (5.2) 只用四个平坦截面的外积，而泊松括号 (5.9) 只用「两条边共享几个面」。这把「几何（三角剖分）」变成「代数（泊松括号）」，全篇由此可以把辛几何问题降为组合问题。
2. **flip = KS**（D10）：三角剖分的 flip 在同调上的作用 (7.23)–(7.25) 恰好是 KS 变换的指数 $\langle\gamma,\gamma_{\rm hyper}\rangle$。这是全文的核心恒等式；一旦接受它，穿墙公式就不再是「假设」，而是「三角剖分演化的必然」。
3. **omnipop = $\mathbf S$**（D11）：$\vartheta$ 转半圈等于「每个顶点同时换本征线」，而后者可以逐顶点、逐边地算成初等辛变换之积。这把「求 RH 问题的斯托克斯矩阵」变成「做有限次矩阵乘法」。

## 五、如果只记三件事

1. **坐标从哪来**：不是解方程解出来的，是**三角剖分的交比** (5.2)。取哪种三角剖分，就得到哪种坐标；取 WKB 三角剖分，就得到达布坐标。
2. **穿墙是什么**：$\vartheta$ 撞上 BPS 射线时三角剖分做 flip，坐标按 KS 变换跳 (7.33)/(7.56)。所以「穿墙 = 辛同胚」在本文里是**构造出来的**，不是拟合出来的。
3. **谱怎么算**：$\vartheta$ 转 $\pi$ 的净变换 $\mathbf S$ (11.1) 可以显式算成乘积；把 $\mathbf S$ 按 $\arg Z_\gamma$ 排序分解，就读出全部 $\Omega(\gamma;u)$。不需要预先知道 BPS 谱——这是相对 GMN1 与当时所有其他方法的实质优势。
