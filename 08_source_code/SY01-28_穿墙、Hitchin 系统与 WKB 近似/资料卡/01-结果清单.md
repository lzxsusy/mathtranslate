> **先说体例**：与 GMN1 一样，GMN2 **没有定理环境**——对 `源码/chunks/*.tex` 做 `grep '\\begin{prop}\|\\begin{lem}\|\\begin{thm}\|\\begin{defn}\|\\begin{cor}'` 结果为 **0**。所以本清单以「编号公式 + 该式前后的正文断言」为条款单位，而不是「定理 N」。这是原文的写作风格，不是翻译缺失。
