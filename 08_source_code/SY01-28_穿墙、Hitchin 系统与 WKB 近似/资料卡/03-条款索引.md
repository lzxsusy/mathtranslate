## 五、怎么用这张索引

1. **查式号 → 页码**：`eq_index.tsv` 有 315 条带标签的映射，可直接 grep；没有标签的式号（§2、§10 各一部分）用 PDF 搜索式号，或看本卡第一节。
2. **查节 → 页码**：用第二节的表；注意**原文页与译本页差 2–10 页**，引用原文页码时务必注明是哪一版。
3. **查图**：第四节给的是文件名，PDF 里图号与文件名一一对应；`figures/` 下是原始 PDF 矢量图，`-crop.pdf` 是裁切版。
4. **校对优先级**：先核 (7.33)/(7.56)（符号最易错）→ 再核 (11.1) 的乘积顺序（$\circlearrowleft$ 与 $\arg(-Z)$ 递增）→ 再核 (5.16)–(5.19) 的指数（$\langle E,E_{41}\rangle=2$ 的例外）。
