## 0. 一句话

## 2. §1 的论证链（已精读，可直接引用）

1. BPS 子空间刚性却依赖真空 ⟹ 穿墙；但**没有算法**。
2. 本文给一类（线性 $SU(2)$ 箭图）理论的算法；理论类 $\CS$ 来自 M5-膜在 $C$ 上紧化。
3. $R^3\times S^1$ 上低能 = $d=3,\CN=4$ sigma 模型，靶空间 = Hitchin 解模空间（用场论版 Fubini 定理倒序紧化）。Hitchin 方程即 (1.1)–(1.3)。
4. 边界条件 = 缺陷算符；横向五膜 ⟹ 正则/不规则奇性（3.2.4、3.2.6）。
5. Hitchin 几何复现 SW 理论：谱曲线 $\Sigma\subset T^*C$、SW 微分 $\lambda$；BPS 态 = 有限 WKB 曲线（$K=2$：直线，中心荷 $Z_\gamma=\pi^{-1}\oint_\gamma\lambda$，相位 $\vartheta$）；$K>2$ 用弦网。
6. 回扣 GMN1：由 D1/D2/D3 出发造度量；三条关键性质 P1（泊松括号 (1.4)）、P2（半平坦渐近 (1.5)）、P3（BPS 射线上的 KS 间断 (1.6)）。
7. 新构造：$\CA=\frac{R}{\zeta}\varphi+A+R\zeta\bar\varphi$ 平坦（(1.8)）⟹ 用 Fock–Goncharov 坐标；三角剖分随 $\vartheta$ 变，只有在 $\vartheta$ 撞上 BPS 射线时才换（flip/juggle/pop），于是间断恰是 KS 变换 ⟹ P3 自动成立。
8. 算法：半个 $\zeta$-平面里总变换 = 谱生成元 $\mathbf{S}=\prod K_\gamma^{\Omega}$，分解唯一 ⟹ 读出谱。
9. 遗留：小 $R$ 时 $X^\vartheta_\gamma$ 是否有极点未决（§14 讨论）。

## 3. 已确认的记号约定（§1 已核对）

- 圆半径 $R$；扭量参数 $\zeta\in\IC^\times$；$\vartheta=\arg\zeta$ 是中心荷相位的候选值。
- $Z_\gamma$ 中心荷；$\ell_{\gamma,u}=\{\zeta: Z_\gamma(u)/\zeta\in\IR_-\}$ 是 **BPS 射线**（原文 §1 如此定义，§2 起大量使用）。
- $X^{\rm RH}_\gamma$：RH 解；$X^{\rm sf}_\gamma$：半平坦达布坐标；$X^\vartheta_\gamma$：本文构造；$X^T_E$：Fock–Goncharov 坐标。
- $T_{\rm WKB}(\vartheta,\lambda^2)$：WKB 三角剖分，只依赖 $\lambda^2$ 因为边无向。
- $\mathbf{S}$ = 谱生成元 = omnipop 变换；$\Omega(\gamma;u)$ = BPS 简并度。
- $\varpi_\zeta=\frac12\int_C\Tr\delta\CA\wedge\delta\CA$：Hitchin 模空间上的全纯辛形式。
