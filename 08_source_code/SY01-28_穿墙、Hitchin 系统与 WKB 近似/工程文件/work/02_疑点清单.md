# 疑点清单 —— GMN2《穿墙、Hitchin 系统与 WKB 近似》

> 用法：**A 类**＝术语/译名与本系列已有约定冲突，须 Lead 裁决；**B 类**＝原文勘误或存疑，一律「照译 + 记录」，不许顺手改对；**C 类**＝施工中发现的、影响后续块的风险点。
> 每条都带位置（原文 .tex 行号 / 印刷页 / 公式号 / 译文文件名），便于回查。

## A 类：术语与译名

**A-1｜turning point 的译名冲突（已按冻结表处理，提请 Lead 追认）**

- 交接说明（`00_交接说明.md` 第 4 节）写的是「turning point → 转折点」；
- 但冻结的 `04_共享/术语/glossary_master.tsv` 第 72 行是 **turning point → 转向点**（状态「定」）；
- 处置：**按冻结表用「转向点」**，不改动旧行，也不新增同义词行；`STYLE_GUIDE.md` 的硬性表已写明「不用『转折点』」。
- 影响面：§6.1–§6.4 起大量出现，是本篇最核心的几何对象之一，必须在开工前定死。

**A-2｜「wall」在 WKB 语境下的译名（已定，记录在案）**

GMN1 的 wall = 模空间里的边缘稳定墙（穿墙）。GMN2 的 WKB 几何里另有一层用法：三角剖分的边/壁段（wall segment）、谱网络的边（edge）。二者**不得混用同一字**。处置已写入 `STYLE_GUIDE.md` 第八节第 3 条：WKB 一侧一律写「网络边」「壁段」，不写「墙」。

**A-3｜flip / juggle / pop / omnipop（已定，记录在案）**

四词是 Fock–Goncharov 与本文作者的造词，无通行中译。处置：**保留拉丁原文**（首次出现用 `\emph{}` 并加一句括注），不新造译名。§1 已按此执行。

**A-4｜class $\CS$ 与「S 对偶」的字母冲突（已定）**

原文 §1 用 class $S$（for ``six''），与 Seiberg–Witten 的 $S$、超对称的 $S$ 都会混。处置：译文中一律写作 `$\CS$`（花体 S），首次出现括注「取『六』之意」，与原文的 `\CS` 宏一致。

## B 类：原文勘误 / 存疑（照译，不改动）

**B-1｜(1.6) 的自指**

原文 §1（`wkb-paper.tex` 约 600 行一带，印刷 p.10）在性质 P3 里先给出 (1.6)，紧接着写「更精确的方程（尤其是 $\pm$ 号的选取）见下面的 (1.6)」——自我指涉。疑为作者从别处搬段落留下的接缝。译文照译（`(\ref{eq:KS-Transfm})`），不改写成「上式」。**待核**：§2.3 是否给出 $\pm$ 号的正式规则。

**B-2｜$\CX^{\sf}_{\gamma}$ 与 $\CX^{\rm sf}_{\gamma}$ 混写**

同一段内，定义处用 `^{\sf}`（即 `\mathrm{sf}`），后一句渐近关系用 `^{\rm sf}`。两者视觉相同、源码不同。译文统一用 `\sf` 宏（preamble 已 `\renewcommand\sf{\mathrm{sf}}`），不视为错误，仅记录。

**B-3｜P2 的渐近条件表述含混**

原文：「We require $\CX_{\gamma}^\RH \sim \CX_{\gamma}^{\rm sf}$, *both* as $\zeta\to 0,\infty$ *and* as $R\to\infty$.」——把「$\zeta\to0,\infty$」与「$R\to\infty$」并列为一个条件，但二者在 §13 的证明中并不对称（§13 只证 $R\to\infty$、$\zeta$ 在半平面内）。照译；**待核** §13.5 的确切陈述。

**B-4｜P3 正文与脚注 7 重复**

正文要求 $\CX^\RH_\gamma$ 在「带 $\Omega(\gamma;u)\ne0$ 的 BPS 射线之补集」上全纯；脚注 7 又把这个要求重述一遍（原文脚注：「More precisely, $\CX^\RH$ is holomorphic on the complement of the set of BPS rays with $\Omega\ne0$」）。照译两处，不合并。

**B-5｜$u(K)$ 的名实问题**

原文反复写「the superconformal $u(K)$ $(2,0)$ theory」，$u(K)$ 是 Lie 代数，严格的群应是 $U(K)$。这是该领域通行写法，照译，不作更正。

**B-6｜§1 对「数学读者可跳过 §3」的建议难以照办**

原文（印刷 p.6）称偏数学的读者可以跳过 §3 直接看 §4 的总结，只是「BPS 态的判定规则会显得缺乏动机」。实际上 §3 的奇性分类 (3.74)–(3.76)、(3.115)–(3.116) 是 §5–§8 的全部输入。译文照译这句话；但 `BRIEF.md` 的分块表**没有**把 §3 判为可跳过块（ch03–ch06 照常施工）。

**B-7｜§1 中「eq. (2.3)」「eq. (2.6)」的指向**

原文在回顾 GMN1 时写「more precise equations ... in (2.3)」一类的话，实际指向本篇 §2 的编号。译文已把这类跨块引用写成原文编号并加 `% TODO 合稿改 \eqref`，合稿时统一改为 `\eqref`。

## C 类：施工风险（供后续块使用）

**C-1｜三套 $X$ 的上标是本篇最大的串号风险**

$X^{\rm RH}_\gamma$ / $X^\vartheta_\gamma$ / $X^T_E$ 在 §5–§7 交叉出现，原文又都用同一个 `\CX`。已在 `STYLE_GUIDE.md` 第八节第 1 条立为硬性规则：上标逐字照抄，任何改写算错。

**C-2｜`\sect` 宏重置计数器**

原文导言区有 `\newcommand{\sect}[1]{\setcounter{equation}{0}\section{#1}}`，节号与公式号绑定。**按 PDF 页数估算公式编号必然出错**，必须逐节数。ch01 已按此核对：(1.1)–(1.9) 与原文一致。

**C-3｜原文 `\be` 是 `\bar e` 不是公式环境**

GMN2 导言区 `\def\be{\bar{e}}`；若把别的稿件里的 `\be…\ee` 当公式宏搬进来，会静默出错。译文一律 `equation` / `align`。

**C-4｜单字母宏污染**

原文导言区 `\def\a{\alpha}`、`\def\b{\beta}`、`\def\c{\check}`、`\def\p{\partial}` 等，若照抄会与 LaTeX 重音命令 `\c`、`\b` 冲突。preamble **只补了安全宏**（`\RH \WKB \IH \fg \qtr \tM \insfig`），不抄这些。

**C-5｜80 幅图与 `figures/*-crop.pdf`**

`\insfig{宽}{名}{图注}` 的第三参数是图注、第二参数是文件名；图目录里是 `-crop.pdf`。v0.1 只译 §1（无图），第 3 章起才开始用。
