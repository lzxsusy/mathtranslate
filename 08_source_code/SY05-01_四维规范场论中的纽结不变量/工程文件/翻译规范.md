## 1. 十条铁律（违反任何一条即为不合格）

1. **数学逐字不动。** `$...$`、`$$...$$`、`\[...\]`、`\begin{equation}...\end{equation}`、`align`、`gather`、`eqnarray`、`array`、`matrix` 等环境内部的内容，**一个字符都不许改**：包括空格、换行、`\,`、`\!`、`\quad`、上下标、希腊字母、`\left/\right`。你只翻译环境之外的正文。
2. **`\label{}`、`\ref{}`、`\eqref{}`、`\cite{}`、`\bibitem{}` 的参数原样保留**，绝不翻译、不重命名、不删除。
3. **不得增删公式、不得合并或拆分段落**（原文一个自然段=译文一个自然段，段落间空行保留）。
4. **不得"补课"。** 原文没说的物理，不许自己加；原文含糊的地方，用 `% [Tutor Note: ...]` 指出，而不是替作者圆场。
5. **符号不译。** $G$、$A$、$\phi$、$\t$、$q$ 等保持原样；算子名（$\Tr$, $\ad$, $\d_A$）保持原样。
6. **`\text{...}` 内的文字要译**（如 `\text{Tr}` 是算子名，保留；`\text{where ...}` 之类说明译成中文）。`\mathrm{}`、`\operatorname{}` 内的名字保留。
7. **图**：`\includegraphics` 行已经预置好（`figs/FigNN.png`），**不要改动**；其上方的 `% >>> 原文图 N（原稿第 P 页）` 注释保留。你只需把 `\caption{...}` 里的英文图注译成中文，并在图注**末尾**加上 `（原稿第 P 页）`，例如：`\caption{\small 一个纽结被置于四维流形 $\MM=W\times\R_+$ 的边界上。（原稿第 5 页）}`。`\label` 保留。
8. **人名、理论名、数学专名保留英文**：Witten、Gaiotto、Jones、Khovanov、Nahm、Virasoro、Chern-Simons、Langlands、Bethe、Gaudin、Knizhnik-Zamolodchikov、oper、thimble 等。参考文献条目一律不译。
9. **交叉引用中文化**：`fig.~\ref{x}`→`图~\ref{x}`；`section \ref{x}`→`第~\ref{x}~节`；`eq.~(\ref{x})`→`式~(\ref{x})`；`\cite{x}` 前加"文献"（如 `见文献~\cite{x}`）。`\ref` 后面的数字不要动。
10. **输出文件必须完整**：从片段第一行到最后一行全部处理，不得截断、不得省略（禁止"以下略"）。

## 2. 文体与术语

* 学术书面语，克制、准确；不要口语化，不要"让我们"、"我们可以发现"这类翻译腔泛滥（适度使用"我们"是原文风格，可保留）。
* 英文长句可拆成中文短句，但**逻辑关系（因果、让步、条件）不得改变**。
* 时态：原文现在时叙述物理内容→中文一般现在时；"we will show"→"我们将证明"。
* 保持原文的谨慎语气：`It is likely`→"很可能"；`we believe`→"我们相信"；`presumably`→"可以设想/大概"。**不得把猜测写成断言。**
* 中文标点用全角（，。；：？！）；数学与公式内用半角。数字/公式与中文之间不必手工加空格（xeCJK 自动处理）。

## 3. 批注规范 `% [Tutor Note: ...]`

在**关键推导处**插入 LaTeX 注释（以 `%` 开头，单独成行，可多行）。每 20KB 片段**至少 4 条、至多 10 条**，宁精勿滥。

必须覆盖的几类（有则必注）：
1. **易错预警**：涉及指标升降、张量缩并、符号约定、自对偶投影、留数计算、$q$ 的幂次（$q^{1/4}$ 等）之处。
   例：`% [Tutor Note: 易错点] 此处 $b^\pm$ 的投影约定为 $b^\pm=\frac12(b\pm\star b)$；若采用相反的 $\pm$ 约定，式 (\ref{...}) 的整体符号会翻转，核对时请以原文定义为准。`
2. **含糊点拨**：作者写 "It is obvious/clearly/it is easy to see" 而跳过证明之处。
   例：`% [Tutor Note: 省略证明] 作者称"显然"可把该积分化为共形块内积，实际省略了：先把路径积分在临界点附近作高斯近似，再用 Knizhnik-Zamolodchikov 方程把单值性条件翻译为退化场插入，参见 \cite{Teschner}。`
3. **约定差异**：与通行文献记号不同之处（如本文 $G$ 与 $G^\vee$ 的互换、$\t$ 的参数地位）。
4. **物理图像**：某个公式的几何/物理意义容易被符号淹没时，一句话点破。
5. **原文笔误**：若发现上下标、符号明显有误，**不要改公式**，用批注标明"原文如此，疑为笔误，按上下文应为……"。

格式：
```latex
% [Tutor Note: 易错点] 这里 $\t$ 的取值在 $\mathbb{RP}^1$ 上，$\t\to0$ 与 $\t\to\infty$ 需分别乘以 $\t$ 或 $\t^{-1}$ 才能取极限；直接令 $\t=0$ 会丢失一项。
```
禁止空泛批注（"此处较难，请仔细"之类不算）。

## 4. "本节重点"规范 `keytakeaways`

若片段中包含 `\section{...}` 行，则在该 `\section` 行**之后**（该节正文开始前）插入：

```latex
\begin{keytakeaways}
\begin{itemize}\setlength{\itemsep}{2pt}
  \item \textbf{物理图像}：……
  \item \textbf{数学工具}：……
  \item \textbf{主要结论}：……
\end{itemize}
\end{keytakeaways}
```

3–6 条；必须基于**该节实际内容**（可向下阅读本片段内的该节正文）；覆盖：核心物理图像、所用数学工具、得到的重要结论。不要写成空话。
