## 2. 词条是什么样

每个词条 = 一个概念 / 对象 / 工具，自带：

- `definition`：自足定义 + 符号表（符号先交代）；
- `theorems`：陈述 + 证明。**原书有证明 → `complete`，逐步给 `why`；原书只有轮廓/没证 → `sketch` + `gap_note` 写清缺哪一步**。禁止把「显然」当证明。
- `examples`：至少一个**能算**的例子，`computation` 给步骤，`result` 给具体结果（群、维数、系数、次数、上同调……），不是「例如可证」。
- `pitfalls`：真坑（符号约定、左右、箭头方向、页码笔误）。
- `related`：只填本单 §5 列出的 id，写一句关系；不要发明 id。
- `sources`：`{"book": "袁瑶, Langlands 纲领导论", "section": "第N讲 §x.y", "pages": [a, b]}`。

## 3. 页码规则（最容易错）

- 中译注本正文里的 `\sourcepage{N}` 表示**原书 PDF 第 N 页**（例：`lecture01.tex` 开头 `\sourcepage{3}`）。
- `sources.pages` 用**原书 PDF 页**，`[a,b]` 两个整数，`1 ≤ a ≤ b ≤ 207`（lint 上限）。
- 原书印刷页 = PDF 页 − 2（`page-map.tsv` 可核：原 PDF 3 ↔ 译本页标记 1）。词条里若提「原书 p.N」，N 用印刷页；`pages` 字段仍用 PDF 页。
- 页码必须能在 `源码/chapters/*.tex` 的页锚里对上，不许编。

## 4. 硬约束（lint 会卡）

- 路径与 `id` 完全一致：`entries/algebra/galois-extension.json` ↔ `id: "algebra/galois-extension"`。
- `id` 形如 `category/slug`，只含小写字母、数字、连字符。
- `category` ∈ `topology / geometry / algebra / qft / susy / condensed / math-phys`。
- `summary` ≤ 160 个汉字（只数汉字）。
- 每条定理：`statement` 非空；`complete` 至少 2 步；`sketch` 必须写 `gap_note`；每步都要 `text` 和 `why`。
- 每个例子：`result` 非空；`computation` 非空。
- 每个 `sources[].pages` 必须是两个整数且 `1 ≤ a ≤ b ≤ 207`。
- 整个词条 ≤ 20,000 字符（JSON 全部字符串加总）。
- 单处引用原文 ≤ 60 字；累计 ≤ 词条的 10%；不复制原书图。
- `rights` 一律 `"rewritten"`；`status` 一律 `"draft"`；`reviewed_by` 为 `[]`。
- 中文写作（术语首次出现给英文），数学用 `$...$` / `$$...$$`，JSON 里反斜杠要转义。

## 6. 写作纪律（重申）

1. **自足**：读者没读过袁瑶这本书，只看这一个词条也要能懂。符号先交代。
2. **证明要完整**：原书有证明就一步步写，每步 `why` 说清用了什么假设/引理。原书没证就别硬编，`sketch` + `gap_note`。
3. **例子要算**：给具体数值/群/维数/系数。例：`[Q(ζ_5):Q]=4` 并给出 Galois 群 ≅ (Z/5)^×；不要写「例如可验证」。
4. **改写不复制**：用你自己的话重写。术语用 `源码/terminology.tsv` 的译名；译名冲突时以术语表为准。
5. **只写你确认的**：拿不准的写进 `pitfalls` 或标 `draft`，不要冒充已证。
6. **统一体例**：文末 `related` 用 §5 的 id；`sources` 至少一条，能定位到讲与页。
