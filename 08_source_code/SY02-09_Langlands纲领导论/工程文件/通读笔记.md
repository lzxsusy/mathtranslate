## 一、三句话主旨

1. **问题**：Langlands 纲领要建立「数论/几何一侧的 Galois 表示」与「分析/表示论一侧的自守表示」之间的对应——在数域上它是「$n$ 维 Galois 表示 ↔ $\mathrm{GL}_n$ 的自守表示」，在函数域（曲线）上它变成「局部系统 ↔ 反常层（Hecke 特征层）」的几何对应。
2. **方法**：先把 $n=1$ 的类域论彻底讲通（局部/整体、阿代尔与伊代尔语言、Hecke 特征标），再把 $n=1$ 的两种等价表述翻译成几何语言（平展基本群、光滑层、Hecke 算子），然后逐层升级工具：反常层与 D-模给出「层论版」的函子性与对偶，约化群 + 根数据 + Satake 同构把「一般 $G$」搭好，最后用仿射 Grassmannian 与几何 Satake 把整个对应组织成一个范畴等价。
3. **结论**：数论侧给出 Langlands 对应的一般表述与 $n=1$ 的证明骨架；几何侧完整给出几何 Langlands 对应的表述、$n=1$ 情形（几何类域论）的证明思路（含 Deligne 用对称幂的证明），以及在 $k=\mathbb{C}$ 时几何 Satake 等价与半单性的最终论证。

## 二、全局结构：四层地图

全书是「一门课的两半」，前 9 讲数论、后 14 讲几何，但真正的骨架是四层：

| 层 | 内容 | 所在讲 | 作用 |
|---|---|---|---|
| L0 基础层 | Galois 理论、类域论、局部域、阿代尔/伊代尔 | L1–L5 | 提供「$n=1$」的完整答案与语言 |
| L1 表示层 | 模形式、Hecke 代数、自守表示、L 函数 | L6–L9 | 把 $n=1$ 的答案改写成「表示 ↔ 表示」的形状，为 $n>1$ 铺路 |
| L2 层论层 | 平展基本群、光滑层、反常层、D-模、Verdier 对偶 | L10–L14 | 提供几何化的语言与工具（对偶、六函子、$t$ 结构） |
| L3 几何对应层 | 几何 Hecke 算子、几何类域论、约化群与 Satake、几何 Satake | L12–L23 | 把「表示 ↔ 表示」升级为「层 ↔ 层」的范畴等价 |

一句话的阅读抓手：**每一层都在做同一件事——把「一侧的算术对象」换成「另一侧可以自由操作的代数/层对象」，而翻译字典就是函子性。**

## 三、逐讲内容与依赖关系（论证地图）

### 第一段 数论基础（L1–L5）

- **L1 基本定义与性质 / $\mathbb{Q}$ 的 Galois 扩张**：$\mathrm{Gal}(\overline F/F)$ 的 Krull 拓扑与无限 Galois 理论；阿贝尔扩张；$\mathbb{Q}(\zeta_m)/\mathbb{Q}$ 与 $(\mathbb{Z}/m\mathbb{Z})^\times$ 同构；Euler 函数与 Dirichlet 定理。
  依赖：无（全书的起点）。输出：$\mathbb{Q}^{\mathrm{ab}}$ 的描述这一「$n=1$ 的目标」。
- **L2 代数数论预备知识 / Frobenius 自同构 / 类域论**：整数环、分歧指数与剩余次数、分解群与惯性群、Frobenius 元素；整体类域论（Artin 互反律）的陈述。
  依赖：L1。输出：$\mathrm{Gal}(L/F)^{\mathrm{ab}} \cong$ 伊代尔类群/范数子群 —— 全书反复使用的「$n=1$ 定理」。
- **L3 局部整体原理 / 局部类域论 / 阿代尔与伊代尔**：局部域、非分歧扩张、局部互反映射 $\theta: K^\times/N_{E/K}E^\times \to \mathrm{Gal}(E/K)^{\mathrm{ab}}$；限制直积定义阿代尔环与伊代尔群。
  依赖：L2（局部版本先于整体版本讲，是标准顺序）。
- **L4 阿代尔环的进一步性质 / 阿代尔群 / 自守形式与自守表示**：阿代尔的拓扑性质、$\mathbb{A}^\times$ 上的自守形式、把自守形式组织成 $(\mathfrak{g},K)\times G(\mathbb{A}^f)$-模。
  依赖：L3。输出：全书最重要的技术对象——自守表示。
- **L5 $(\mathfrak{g},K)\times G(\mathbb{A}^f)$-模 / 自守表示的若干性质 / 局部理论 / 阿基米德理论**：可容许性、适度增长、重数一；局部成分与限制张量积；阿基米德处的 $(\mathfrak{g},K)$-模。
  依赖：L4。输出：局部–整体分解（Langlands 对应的「局部化」前提）。

### 第二段 表示论与模形式（L6–L9）

- **L6 模形式 / 从模形式到自守表示 / 从局部到整体**：模形式与尖点形式、Hecke 算子；经典模形式 ↔ $\mathrm{GL}_2(\mathbb{A})$ 的自守表示；局部成分与 L 函数。
- **L7 椭圆曲线 / Tate 模与 Hasse–Weil L 函数**：椭圆曲线、同源、$\ell$ 进 Tate 模给出的 Galois 表示；Hasse–Weil L 函数。
  依赖：L6；与 L2 的 Frobenius 对接。输出：$n=2$ 情形「Galois 侧」的具体对象。
- **L8 模曲线与模形式 / Hecke 算子与 Hecke 代数 / 权 $k=2$ 的主定理 / 权 $k>2$ 的主定理**：模曲线、Hecke 对应、菱形算子、Eichler–Shimura 型主定理（模形式 ↔ 椭圆曲线的 Galois 表示）。
  依赖：L6, L7。输出：$n=2$ 情形的「$n=1$ 类域论类比」。
- **L9 作为整体域的函数域 / 自守表示与 Galois 表示**：函数域 $F=\mathbb{F}_q(X)$；函数域上的类域论可以「几何地」重述——这是从数论侧跨到几何侧的桥。
  依赖：L1–L8。**全书最重要的转折点**：L10 起把 $X$ 换成复曲线、把 $\mathbb{F}_q$ 换成 $\mathbb{C}$。

### 第三段 几何语言与工具（L10–L14）

- **L10 平展基本群 / 光滑层 / 单值表示**：$\pi_1^{\text{ét}}(X)$、局部系统、光滑层与单值表示的三角等价。
  依赖：L1（射有限群）、L9（函数域视角）。输出：$\pi_1$ 的表示 = 局部系统，即几何侧的「Galois 表示」。
- **L11 关于光滑层的进一步讨论 / 阿代尔与向量丛 / 模叠**：向量丛与 $\mathrm{Bun}_G$、模叠与代数叠的语言。
  依赖：L10。
- **L12 几何情形中的 Hecke 代数 / 从函数到层 / Langlands 对应的几何表述**：Hecke 算子作用在 $\mathrm{Bun}_G$ 上的层；Hecke 特征层；几何 Langlands 对应的正式陈述。
  依赖：L10, L11, L6–L8（Hecke 代数的经典版本）。输出：全书的主目标陈述。
- **L13 Verdier 对偶 / 反常层 / 交复形**：导出范畴、Verdier 对偶、$t$ 结构、支撑/余支撑条件、交复形与中间延拓。
  依赖：L10–L12。输出：几何侧的核心技术工具（Hecke 特征层的正确范畴）。
- **L14 D 模 / 凝聚 D 模与完整 D 模 / Riemann–Hilbert 对应**：D 模、完整 D 模、Riemann–Hilbert 对应（平坦联络 ↔ 局部系统）。
  依赖：L13。输出：几何 Langlands 的「另一侧」语言，以及 L17 平坦联络讨论的基础。

### 第四段 几何类域论（$n=1$，L15–L17）

- **L15 $n=1$ 时的 Hecke 算子 $T^1$ / 曲线的对称幂 / Deligne 的几何证明**：$n=1$ 时 Hecke 算子退化为拉回–推前；对称幂；Deligne 用对称幂证明几何类域论。
  依赖：L12, L13。
- **L16 Artin 映射与 Artin 互反律 / 几何 Artin 互反律**：把 L15 的构造写成互反律的形式，并给出几何版本。
  依赖：L15。
- **L17 带平坦联络的丛 / 用 Fourier–Mukai 变换解释 / Jac**：带平坦联络的丛、Fourier–Mukai 变换、Abel–Jacobi 映射。
  依赖：L14, L15。输出：几何类域论的第三种（层论/Fourier 变换）解释。

### 第五段 约化群与 Satake（L18–L20）

- **L18 根数据与根系 / 约化群 / 环上的约化群**：根数据、根系、约化群与分裂/拟分裂、环上的约化群。
  依赖：无强依赖（群论预备），但放在此处的目的是为 $G$ 一般的对应做准备。
- **L19 约化群的 Bruhat 分解 / 球面 Hecke 代数 / Satake 同构**：Bruhat 分解、球面 Hecke 代数 $\mathcal{H}(G,K)$、Satake 同构 $\mathcal{H} \cong \mathbb{C}[X^\vee]^W$。
  依赖：L18。输出：$p$ 进侧「$G$ 的表示 ↔ 对偶群 $G^\vee$ 的表示」的具体实现。
- **L20 $\mathbb{C}[X^\vee]^W$ / Langlands 函子性**：把 Satake 同构升级为函子性的表述：$L$ 群、$L$ 函数、函子性猜想。
  依赖：L19。输出：数论侧 Langlands 对应的「一般 $G$」版本。

### 第六段 几何 Satake（L21–L23）

- **L21 仿射 Grassmannian / 仿射 Grassmannian 的胞腔 / 仿射 Grassmannian 上的反常层**：$\mathrm{Gr}_G$、Bruhat 型胞腔分解、权函子。
- **L22 卷积积**：$\mathrm{Gr}_G$ 上的卷积积（融合积），把 $\mathrm{Perv}(\mathrm{Gr}_G)$ 变成张量范畴。
- **L23 张量函子 / 等变反常层范畴的半单性 / $k=\mathbb{C}$**：纤维函子与 Tannaka 形式理论、几何 Satake 等价 $\mathrm{Perv}_{G(\mathcal{O})}(\mathrm{Gr}_G) \cong \mathrm{Rep}(G^\vee)$、$k=\mathbb{C}$ 时等变反常层范畴的半单性证明。
  依赖：L13（反常层）、L18–L20（对偶群与 Satake）。**全书终点**：几何 Langlands 对应的「群论核心」。

## 四、关键定理链（三条主线）

**主线 A：类域论（$n=1$）**
L1 $\mathbb{Q}^{\mathrm{ab}}$ 的描述 → L2 整体 Artin 互反律 → L3 局部互反映射 + 阿代尔 → L4–L5 自守表示化 → L9 函数域版本 → L15–L17 几何版本（Deligne 对称幂、几何 Artin 互反律）。

**主线 B：$n=2$ 与模形式**
L6 模形式 ↔ 自守表示 → L7 椭圆曲线的 Tate 模 → L8 模曲线 + Hecke + 主定理 →（几何侧）L12 Hecke 特征层。

**主线 C：一般 $G$ 与几何 Satake**
L18 根数据/约化群 → L19 Bruhat + Satake → L20 函子性与 $L$ 群 → L21–L23 仿射 Grassmannian + 卷积 + 几何 Satake 等价。

三条主线在 L12（几何 Langlands 对应的陈述）汇合：主线 A 给出 $n=1$ 的可解情形，主线 B 给出 $n=2$ 的经典动机，主线 C 给出一般 $G$ 的群论骨架。

## 五、体裁清单（原创 vs 引用）

- 全书是**课程讲义**：定义、定理、例题的组织是作者原创的编排，但**绝大部分数学内容是标准结果的整理与转述**，不是新定理。
- 明确标注「证明从略」的地方（如 L3 定理 2.1 局部互反映射、L8 主定理）应视为引用标准结果。
- 主要引用源（课程介绍与各讲参考文献）：
  1. E. Frenkel, *Lectures on the Langlands Program and Conformal Field Theory*（全书主骨架，尤其几何侧）；
  2. S. Gelbart, *An elementary introduction to the Langlands program*, Bull. AMS 10 (1984)；
  3. J. Bernstein & S. Gelbart, *An Introduction to the Langlands Program*, Birkhäuser 2003；
  4. A. W. Knapp, *Introduction to the Langlands program*（Proc. Symp. Pure Math. 61, 1997）；
  外加各讲末尾列出的专门文献（Deligne、Drinfeld、Gaitsgory、Mirković–Vilonen 等）。
- 对译注的直接影响：**凡「引用标准结果」处，译注可以放心引 A 级教材**（书目与章号在各讲参考文献里）；凡作者自己组织的「为什么这样做」的段落，译注只能做背景直觉，不得替作者补证明。

## 六、阅读顺序建议（给学生的路线）

1. **必修主干（按序）**：L1 → L2 → L3 → L4 → L5 → L6 → L7 → L8 → L9。
   这一段不要跳：L3 的阿代尔语言是后面所有「自守表示」的前提，L9 的转折是几何侧的入口。
2. **工具章（可并行、可先读）**：L13（反常层）、L14（D 模）、L18（根数据/约化群）。
   这三讲相对独立，卡在 L10–L12 时可以先读它们再回头。
3. **几何主线**：L10 → L11 → L12 → L15 → L16 → L17。
4. **收尾**：L19 → L20 → L21 → L22 → L23。
5. **省时读法**：只想抓几何 Langlands 的读者，可走 L1（只读定义与 $\mathbb{Q}(\zeta_m)$ 部分）→ L9 → L10 → L13 → L12 → L21 → L23；但会缺「Hecke 算子为什么长这样」的直觉。
