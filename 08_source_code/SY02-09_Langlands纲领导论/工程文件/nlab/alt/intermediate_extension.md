# 中间延拓  |  intermediate extension
concept: 沿开浸入 j: U→X 把 U 上的反常层延拓为 X 上反常层的函子 j_{!*}。
level: A
citation_zh: [来源：G. Williamson, \textit{An Illustrated Guide to Perverse Sheaves}, lecture notes（本讲参考文献）。]
citation_en: G. Williamson, An Illustrated Guide to Perverse Sheaves, lecture notes (bibliography of Lecture 13).
verified: 书目核对（未逐页翻原文）：lecture13.tex 的 references 列 Williamson 该讲义为该讲反常层教材；该讲第 3 节「交复形」正用到中间延拓
note: $j_{!*}$ 夹在 $j_!$ 与 $j_*$ 之间，是自对偶的中间对象；交复形 $\mathrm{IC}_X$ 由 $j_{!*}$ 逐层构造。
