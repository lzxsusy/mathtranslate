# Artin 映射  |  artin map
concept: 把伊代尔类群映到整体域绝对 Galois 群 ab 化的互反映射。
level: B
citation_zh: [来源：nLab \"Artin reciprocity law\"，\url{https://ncatlab.org/nlab/show/Artin+reciprocity+law}（Last revised 2024-06-30；2026-11-14 访问）。]
citation_en: nLab, "Artin reciprocity law", https://ncatlab.org/nlab/show/Artin+reciprocity+law (last revised 2024-06-30; accessed 2026-11-14).
verified: 2026-11-14 实抓该页（HTTP 200，注意 slug 须大写 A：`Artin+reciprocity+law`），Idea 原文："Emil Artin's reciprocity law is a reciprocity law in class field theory for global fields. It states, in consequence, that for each 1-dimensional Galois representation σ there exists a Dirichlet character χ such that the Artin L-function L_σ equals the Dirichlet L-function L_χ."。
note: Artin 映射 $C_K \to G_K^{ab}$ 的存在性与显式公式即 Artin 互反律；讲中用它叙述类域论的函子性。
