# 分歧指数  |  ramification index
concept: 有限扩张中素理想分歧的重数，记 e = v_P(pB)。
level: B
citation_zh: [来源：MathWorld 词条「Ramification Index（分歧指数）」，\url{https://mathworld.wolfram.com/RamificationIndex.html}（2026-11-14 访问）。]
citation_en: MathWorld, "Ramification Index", https://mathworld.wolfram.com/RamificationIndex.html (accessed 2026-11-14).
verified: 2026-11-14 实抓该页（HTTP 200），正文原文含 "measures multiplicity in ramified maps and field extensions"、"For a finite extension of local fields, it is the positive integer ... where ... are the maximal ideals"。
note: 本讲用于 pB = ∏ P_i^{e_i}；e_i = 1 即非分歧（unramified），e_i > 1 为分歧。
