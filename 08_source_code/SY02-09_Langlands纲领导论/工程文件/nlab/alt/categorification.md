# 范畴化  |  categorification
concept: 把集合层面的结构提升为范畴（或高阶范畴）层面结构的程序。
level: B
citation_zh: [来源：nLab \"vertical categorification\"，\url{https://ncatlab.org/nlab/show/vertical+categorification}（Last revised 2024-09-04；2026-11-14 访问）。]
citation_en: nLab, "vertical categorification", https://ncatlab.org/nlab/show/vertical+categorification (last revised 2024-09-04; accessed 2026-11-14).
verified: 2026-11-14 实抓该页（HTTP 200，13809 字符；注意 `categorification` 本身重定向到此页），Idea 原文："Roughly speaking, vertical categorification is a procedure in which structures are generalized from the context of set theory to category theory or from category theory to higher category theory."。
note: 讲中「范畴化」指用层范畴/导出范畴替代向量空间与函数，使 Langlands 对应提升为范畴等价（几何 Langlands）。
