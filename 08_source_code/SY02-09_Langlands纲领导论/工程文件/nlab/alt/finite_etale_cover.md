# 有限平展覆盖  |  finite etale cover
concept: 同时有限且平展的态射 Y→X，平展拓扑的覆盖即由它们给出。
level: B
citation_zh: [来源：nLab \"étale cover\"，\url{https://ncatlab.org/nlab/show/etale+cover}（Last revised 2022-05-17；2026-11-14 访问）。]
citation_en: nLab, "etale cover", https://ncatlab.org/nlab/show/etale+cover (last revised 2022-05-17; accessed 2026-11-14).
verified: 2026-11-14 实抓该页（HTTP 200），Definition 原文："An étale cover of an algebraic scheme X is a set {p_i: U_i → X} of étale morphisms locally of finite type which are jointly surjective in the sense that X equals the union of set-theoretic images"。
note: 有限平展覆盖 $Y \to X$ 即再要求 $Y \to X$ 有限；其范畴（逆向极限）给出平展基本群 $\widehat\pi_1(X)$，讲中用它替代拓扑通用覆盖。
