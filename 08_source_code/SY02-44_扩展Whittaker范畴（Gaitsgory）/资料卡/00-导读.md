# 00 导读 — 扩展 Whittaker 范畴该怎么读

## 一句话

这篇 17 页的笔记回答一个问题：**当你想要 $D(\mathrm{Bun}_G)$ 的全部 Fourier 系数（而不只是非退化那部分），该造一个什么范畴？** 答案是扩展 Whittaker 范畴 $\mathrm{Whit}(G)^{red,ext}_{glob}$（§7），它的谱侧对应在 §8 给出。

## 阅读顺序（推荐）

1. **§1–§2**：先接受「$D(\mathrm{Bun}_B^{rat})$ 是 $\mathcal H_{G,B}$-等变范畴」这个定义，看懂单子 $\widetilde\Omega$ 的构造即可；$\widetilde\Omega^\lambda$ 的显式公式（§2.3）单独看会卡，先记住结论。
2. **§3**：叶斯泰因级数与常数项。这一节是 §4 与 §7.4 的引擎；命题 3.3.1 的滤过（首项 $\widetilde\Omega$、末项 $w_0$）要在 §4.5 与 §8 里反复用。
3. **§5–§6**：Whittaker 与既约 Whittaker。注意 §5.2 的群胚 $(\mathcal H_N)_{X^I}$ 与特征 $\chi$：这是「对特征作等变」的几何实现。
4. **§7**（主角）：与 §6 逐条对照读——唯一的差别是 $\gamma_i^{red}:\check\alpha_i(P_T)\to\omega_X$ 允许取零。§7.4 的系数函子 $\mathsf{coeff}^{red,ext}$ 与 §7.5 的全忠实性是全文结论。
5. **§4 与 §8**（谱侧）：可放在最后读，也可先读 §4.1 的图 (4.1) 建立目标，再回来看几何侧。

## 三个最容易读漏的地方

1. **「既约」vs「扩展」**：既约只取非退化特征（$\gamma_i$ 非零），扩展把退化特征（$\gamma_i$ 可取零）也收进来。§7 开头用 (7.1) 把这个差别说成一句初等的话：$T(K)/Z_G(K)$ 在 $\mathrm{Char}^{\mathrm{n.d.}}$ 上单可迁。
2. **$\overline{\mathrm{Bun}}_B$ 到 $\mathrm{Bun}_N^{red,ext}$ 的闭嵌入 $\mathfrak i$**：设 $\gamma_i=0$ 就落进 $\overline{\mathrm{Bun}}_B$，所以 $D(\mathrm{Bun}_T^{rat})$ 是扩展 Whittaker 范畴的一个「层」；$(\mathfrak i^{rat})_!:=(\mathfrak i^{rat})_*$ 的写法是因为对闭嵌入 $*$-推前恰是 $!$-拉回的左伴随。
3. **$\mathsf{coeff}^{red,ext}$ 的两处 $!$**：$\mathbf{ind}\circ(\mathfrak r^{rat})^!\circ(\mathfrak p^{rat})^!$，两次都是 $!$-拉回（不是推前）。若按「系数应当是推前」的直觉去读，会与原文差一个方向。
