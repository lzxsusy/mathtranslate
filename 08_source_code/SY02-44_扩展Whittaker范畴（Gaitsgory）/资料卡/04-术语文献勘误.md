## 四、与既有工程的术语一致性

- 与 SY02-13（同作者《几何朗兰兹非正式导论》）：$\mathrm{Bun}$、$\mathrm{LocSys}$、$\mathrm{Eis}$、$\mathrm{CT}$、$\mathrm{Whit}$、$\mathbf{oblv}/\mathbf{ind}$、叶斯泰因级数、拟定理，全部沿用。
- 与 SY02-45（Scholze 布尔巴基 1252）：$\mathrm{QCoh}_N$、coefficient functor（系数函子）、Poincaré series（Poincaré 级数）、Gap 定理，用法一致；SY02-45 把 coefficient functor 译「系数函子」，本册从之。
- 已知分歧：SY02-45 把 perverse 译「反常层」、shtuka 保留英文；本册不涉及这两个词。
