## 二、流程回顾（哪些做对了）

1. **先通读、后落笔**：先写 `通读笔记.md`（三句话主旨 + 逐节论证地图），再做 `疑点清单.tsv`。本册的难点集中在三处：$\widetilde\Omega$ 的单子描述（§2.3）、$\CT\circ\Eis_!$ 的滤过（§3.3）、以及 §7.4 的系数函子链。它们都在通读阶段被标出，翻译时没有返工。
2. **公式一律看页图**：底本的 TeX 文本提取会把花体与上下标吃掉（$\mathfrak p$ 变 `p`，$\mathcal T_r$ 变空白）。17 张 150 dpi 页图是唯一可靠的公式依据；`en_raw.txt` 只用来定位行文。这条纪律在本册至少避免了三处误译。
3. **字体先查、再排版**：先用 pymupdf 读 PDF 字体表，确认映射字母是 Fraktur（EUFM10）、$\mathbf{oblv}/\mathbf{ind}$ 是粗直体（CMBX10）、$\mathsf{coeff}/\mathsf{Poinc}$ 是无衬线（CMSS10），再定宏。避免了「看起来差不多」的 $\mathfrak p$ 与 $\mathbf p$ 混用。
4. **笔误不「改正」**：14 处笔误全部照原文译，另加译注说明正确读法。这样既守纪律，也不让读者被原文的错误卡住。最要紧的两处是 §3.2 的两行恒等式（方向写反、$\mathcal T_r$ 未定义）与 §6.1 的「右伴随」。

## 三、工具链

- 底本渲染：pymupdf（Python），`get_pixmap(dpi=150)`；局部核对用 `clip` 参数按 bbox 高倍放大（400–500 dpi）。
- 排版：xelatex（MiKTeX 26.5）+ ctexbook + Noto Serif SC/Sans SC；tikz-cd 画交换图；amsthm 定理环境。
- 编译自检：`grep "^!\|Overfull\|Underfull\|Missing character" main.log`，并要求 `LaTeX Warning` 计数为 0。
- 目视验收：把成品页渲染成 110 dpi PNG 抽检（p11 的 (4.1) 图、p14 的 §5 开头、p18 的 (7.1)、p23 的 (8.1)）。

## 四、取舍

- **不设 chapter**：原书是单篇笔记，若用 `\chapter` 会把节号推成 1.x；故用 `\section` 从 1 起编号，`\thesection` 改为 `\arabic{section}`，节标题即原书节标题。
- **编号公式只保留原书那四条**：原书只给 (4.1)、(4.2)、(7.1)、(8.1) 编号，其余公式一律不编号；图表编号也不必强加。这样与原书对照时不必换算编号。
- **定理类环境自建**：原书的「编号段 + Quasi-Theorem/Lemma/Proposition」编号共用一套数字，无法直接套 amsthm 的自动编号，故用 `\ob`/`\othm` 显式给出编号（与 SY02-13 的模板一致）。
- **「Quasi-」不译成「准」**：译「拟定理/拟命题」，与系列其他册的译法一致；并在译者说明里交代：Quasi- 表示「证明依赖尚未建立的猜想（多为 [GL:formulation] 中的）」，而不是「几乎成立」。
- **成品随仓**：底本为作者自印预印本（L2 公开·受限，权利人通知即撤下）。成品 PDF 进 `成品/` 与 `deliverable/`，`RELEASE_REGISTER.csv` 记「成品在仓=是」；原文 PDF 不入仓。

1. **§3.2 的 $\mathcal T_r$**：本册按类型检查判为 $\CT^{rat}$，但未找到作者他文中的对应写法；若日后拿到 [GL:Eis] 原稿，应回核并更新译注 8。
2. **§8.2 的 Gap 定理**：原文只借其名。译注按「Drinfeld 提出、Arinkin 证明」交代，未展开定理内容；读者若要读 [GL:funct]，宜另配一条关于该定理的译注。
3. **文献**：原书 10 条只有代号与英文题名，无页码、无 arXiv 号。译文照录；若日后建库，应补出版信息。
