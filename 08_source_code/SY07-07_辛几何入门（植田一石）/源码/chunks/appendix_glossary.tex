\section*{B.11 记号约定}
\addcontentsline{toc}{section}{B.11 记号约定}

\begin{itemize}[leftmargin=1.6em,itemsep=3pt]
\item 辛形式 $\omega$；近复结构 $J$；黎曼度量 $g$；复结构 $I$。
\item 流形 $M$；切丛 $TM$；余切丛 $T^*M$；外微分 $\rd$。
\item 场论：$\nabla$ 为联络，$F_\nabla$ 为曲率，$\cA$ 为联络空间，$\cG$ 为规范群，$\cM$ 为模空间。
\item 原书用 $\mathbb{P}^2$ 等记法表示复射影空间，中译本统一写作 $\CP^2$。
\end{itemize}
