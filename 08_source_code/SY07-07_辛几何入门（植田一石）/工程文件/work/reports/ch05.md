| p.60 | 难点 | (5.1.15) 中 e^{tY}·x 关于 t 的导数正是基本向量场 Y̲ 在 x 处的值，故对 μ_Z 求导即 Y̲μ_Z。 |
| p.61 | 背景 | O 上的辛形式即 Kostant–Kirillov–Souriau 形式，它使 G 的余伴随轨道成为齐性辛流形，与 4.4 节 g* 上的 Lie–Poisson 结构相容。 |
| p.62 | 难点 | (5.1.34)–(5.1.37) 只是把 Cartan 同伦公式插入并整理；(5.1.40) 用到 [Y̲,Z̲]=L_Y̲Z̲，(5.1.41) 用到 L_Y̲ 是微分、与内乘的交换关系 L_Xι_Y−ι_YL_X=ι_[X,Y]。 |
| p.64 | 难点 | (5.1.54) 是把 d(e^{tY}·z)/dt=(Ye^{tY})·z 写成矩阵乘法后取 t=0；(5.1.61) 来自 Y*=−Y 即 \overline{Y_ij}=−Y_ji。 |
| p.64 | 背景 | 定理 5.1.9 即 Atiyah 与 Guillemin–Sternberg 的凸性定理（1982）；[10]、[55]、[57] 为相关原始文献，证明须用 Morse 理论，故原著从略。 |
| p.65 | 校勘 | 原书写「不依赖于 q∈π⁻¹(p) 的取法」，按文意应为 p∈π⁻¹(q)（下文正是按 p 在纤维中的选取来论证）；此处照录。 |
| p.66 | 校勘 | (5.2.6) 之后原书把 X,Y,X'',Y'' 说成「p 处 π⁻¹(0) 的切向量」，但 π 的定义域是 μ⁻¹(0)（下文即用 π 的商映射与 Ker π_*），故 π⁻¹(0) 应为 μ⁻¹(0)，此处照录。 |
| p.66 | 难点 | 非退化性：ω 限制到 μ⁻¹(0) 后核的维数至多为 dim G（由 (5.2.15)），而基本向量场张成的 dim G 维子丛已含于核中，故核恰为该子丛，商掉的正是它。 |
| p.67 | 背景 | Marsden–Weinstein 约化由 Marsden 与 Weinstein 于 1974 年提出，Meyer 亦于 1973 年独立得到；对余伴随轨道取商把「动量取固定值」推广为「动量落在轨道内」。 |
