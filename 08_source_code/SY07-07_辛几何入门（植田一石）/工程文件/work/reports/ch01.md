## 批注（共 8 条：背景 5 / 难点 0 / 校勘 3）
5 页共 8 条，平均 1.6 条/页。

| 原书页 | 类型 | 内容 |
|---|---|---|
| p.1 | 背景 | 「アカデミア」即柏拉图于公元前 387 年前后在雅典西北郊创立的学园（Akadēmeia），门匾传说见诸后世记述，真伪不详，但常被引作几何学地位的象征。 |
| p.1 | 背景 | 阿基米德墓上刻圆柱与内切球，典出 Cicero《Tusculanae disputationes》；他证明球体积为外切圆柱体积的 2/3，并希望以此作为自己的墓志。 |
| p.2 | 背景 | 「ハレー彗星」的回归预言见 Halley 1705 年《Astronomiae cometicae synopsis》；1705 年他据 Newton 力学算出周期约 75 年，并预言 1758 年回归。原书此处以「Halley ら」称之。 |
| p.3 | 背景 | 原书作「エルランゲン目録」，指 Klein 1872 年的 Erlangen Programm（埃尔朗根纲领）：以变换群对几何分类。 |
| p.3 | 背景 | 「シンプレクティック」一词由 Weyl 在 1939 年《The Classical Groups》中引入，取自希腊语 sym-plektikos（交织、缠绕）。 |
| p.3 | 校勘 | 三大作图问题的不可解性分别由 Wantzel（1837，三等分角、倍积立方体）与 Lindemann（1882，化圆为方，依据 $\pi$ 的超越性）证明。 |
| p.4 | 背景 | 「等位集合」指所有守恒量取定值的公共水平集；在 Liouville–Arnold 定理的假设下它是 $n$ 维环面 $T^n$，即 Lagrange 环面，见 6.1 节。 |
| p.5 | 校勘 | 原书此处作「古典力学から量子力学への以降」，「以降」当为「移行」之误，译文按「过渡」处理。 |
