## 六、方法与局限

1. **命令抽取**：先按行剥离 `%` 注释（保留 `\%` 转义），再把 `\\`（换行符）替换为空格，避免 `\\q_1` 被误认成 `\q`；然后正则 `\\([A-Za-z@]+)` 抽取。
2. **白名单**：按宏包分组手工维护，只收录该宏包确实提供的命令；白名单之外的拼写错误、漏定义、写错宏包名都会被报出。
3. **乱码检测**：逐行尝试 `line.encode('gbk').decode('utf-8')` 回环——双重编码行必然可回环且得到通顺中文；同时对「鈥锛銆鍒鏂鐨」等特征字与 U+FFFD 单独扫描。
4. **局限**：静态检查，不校验数学内容正确性；不检测 `\tag` 编号重复、环境配对、章标题重复等结构问题（由 `work/tools/audit_structure.py` 负责）；白名单无法覆盖未来新增宏包。
