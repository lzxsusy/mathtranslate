## 0. 总原则

1. 中文学界有稳定、无歧义通行译名者用中文；无稳定译名或硬译反碍对照文献者保留原文（operad、Fukaya 范畴、Floer 同调、Gromov–Witten 不变量、toric 等专名与缩写）。
2. 人名一律不译（Hamilton、Gromov、Arnold、Darboux、Moser、Kähler、Calabi–Yau、Toda、Iwasawa、Bruhat、Narasimhan–Seshadri、Harder–Narasimhan、Delzant、Atiyah、Stein、Liouville、Noether、Legendre、Fenchel、Poincaré、KAM、AKS、Yang–Baxter、Yang–Mills、Sobolev、Hermite、Jacobi、Kepler、Newton、Lagrange、Galilei、Archimedes、Platon）。
3. 日文汉字的「体」（代数）译「域」；「補題」=「引理」；「系」=「推论」；「注意」=「注」；「予想」=「猜想」；「概複素」=「近复」；「概正則」=「伪全纯」；「準同型」=「同态」。
