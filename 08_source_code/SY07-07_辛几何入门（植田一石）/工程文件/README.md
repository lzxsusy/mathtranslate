## 四、构建方法

需要 XeLaTeX（TeX Live 2026 或 MiKTeX）与 makeindex，中文由 ctexbook 宏包处理。

```powershell
# 全量编译：三遍 xelatex + makeindex，产物写入 deliverable/
powershell -ExecutionPolicy Bypass -File build.ps1

# 单块草稿：只排一个 chunk，快速查错，产物为根目录 tmp_<chunk>.pdf
powershell -ExecutionPolicy Bypass -File build.ps1 -Chunk ch05
```

脚本先把 `src/` 镜像到临时目录再编译，源目录不会被中间文件污染；草稿模式另生成 `draft.tex`，用 `\def\UEDAdraft{}` 标记草稿态。每遍编译后脚本用正则统计日志中的 `file:line`、`fatal`、`undefined`、`missingchar`、`overfull`、`undefref`，全部为 0 时打印 `BUILD OK`。版式为 B5（182×257 mm），正文 11pt，行距 1.12。

## 五、译校体例

1. **页码对照**：每页第一段前写 `% [原文 p.N]`；图注末尾标「（原书 p.N）」；原书页码 = 底本 PDF 页码 − 9。
2. **编号照录**：公式与陈述（定義／定理／命題／系／補題／例／注意 等）一律用原书编号「章.节.序号」，手工写入环境参数，不用 LaTeX 自动编号；多行公式逐行 `\tag`。
3. **插图**：原书仅 5 幅，均自扫描页裁出；其余原书无图处不补图。
4. **批注**：译校批注以源码注释 `% [Tutor Note: …]` 写在对应位置，不进正文；全书批注另按章汇集于「附录 A」，只分背景（人名、历史、术语来源、与物理的对应）、难点（原文跳步处为何成立）、校勘（疑似笔误与依据）三类。
5. **译本自加标记**：「本节重点」（`\takeaway`）与「本章回顾与评注」（`\chapterreview`）为译本所加，非原书内容，可用 `\showtakeawayfalse`、`\showchapterreviewfalse` 一键隐藏。
6. **索引**：原书五十音索引不照录，改设「附录 B：术语对照表」，并附记号约定。
7. **参考文献**：照录原书条目与原编号，书名不译，仅订正编号、作者名的明显排印错误。

术语处理原则：中文学界有稳定译名者用中文（如「辛流形」「动量映射」「近复结构」），无稳定译名或硬译有碍对照者保留原文（如 operad、Fukaya、Floer、Gromov–Witten）；人名一律不译。全书术语以附录 B 为准。

## 六、术语、标记与编译判据

- 原书「である」体译为中文陈述体，不用第一人称；不增删数学内容，必要的补充只出现在批注中。
- 交叉引用一律写文字（「由 (2.1.19)」「见 3.2 节」「第 6 章」），源文件中禁用 `\label`、`\ref`、`\cite`、`\input`、`\include`。
- 文献引用保留原书方括号编号（如 `[9]`），不改写为「文献 9」。
- 编译判据：`file:line = 0`、`fatal = 0`、`undefined = 0`、`missingchar = 0`、`overfull = 0`、`undefref = 0`；定稿快照六项均为 0。全书最近一次审计结果见 `work/reports/audit.md`。

## 七、原文疑似笔误登记

底本为影像扫描本，个别公式与文字疑有排印错误。处理办法是照原样译出，并在该处以「校勘」类批注说明依据，不径改原文。已确认的典型例子：

| 位置 | 原文 | 判断 |
|---|---|---|
| (3.2.16) | 求和上限写作 2n | 应为 n（该式对 i = 1, …, n 逐项相消） |
| 3.2 节 Darboux 定理证明 | 「ℝⁿ 中原点的邻域」 | 应为 ℝ²ⁿ（流形维数为 2n） |
| (5.1.8) | [Y, Z] 未加基本向量场下划线 | 与 (5.1.2) 体例不一致，疑排印时漏加 |
| 5.2 节定理 5.2.1 证明 | 「q ∈ π⁻¹(p) 的取法」 | 应为 p ∈ π⁻¹(q)（q 是底空间点，p 是纤维点） |
| 5.2 节同处 | 「p 处 π⁻¹(0) 的切向量」 | 应为 μ⁻¹(0) |

其余各章的疑似笔误散见附录 A 的「校勘」类批注，条条注明原书页码与判断依据。

## 九、已知偏差与限制

1. 原书五十音索引不收，改以附录 B 的术语对照表部分承担检索功能，覆盖范围不等于原索引。
2. 参考文献由扫描件 OCR 转录后人工校对，个别作者名的缩写、卷期页码仍可能有误，疑处记于 `work/reports/references.md`。
3. 原书复射影空间写作 ℙⁿ，本译本统一改用记号 ℂPⁿ，首次出现处以批注说明。
4. 插图仅收录原书 5 幅；原书正文其余图示（若有）以文字描述代替，并加批注标明。
5. 交换图（如定理 5.2.1 的约化图解）用 `array` 环境与箭头近似排出，视觉上不等同于专业绘图宏包的成品。
6. 附录 A、附录 B 由脚本自各 chunk 批注与术语表汇总生成，重生成时以源码为准。
7. 源文件统一为无 BOM 的 UTF-8；编码与宏使用情况见 work/reports/audit.md（2026-11-08 全量扫描：未定义宏 0、双重编码乱码 0、禁用命令 0）。
8. 本书为学术研读用的中文译注本，不替代原书；引用请以原书页码与原文为准。
