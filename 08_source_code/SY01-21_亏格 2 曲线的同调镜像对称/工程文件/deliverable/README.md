## 七、已知问题（原文疑点，均照原文排印并在译注中说明）

原书存在若干笔误、交叉引用失效与排印不一致，处理原则是**不臆造、不擅自改数学内容**，照原文排印并在 `\transnote` 或 `% [Tutor Note]` 中标明，逐条登记在 `reports/cNN.md`。以下为较重要者：

1. **p.16**「in Remark 1.3」应为注 1.2.3（笔误）；译文用交叉引用指向该注并加译注。
2. **p.17** Hermite 矩阵先写成 $\begin{pmatrix}a&b\\ \bar b&a\end{pmatrix}$，式 (1.6) 又用一般形式 $\begin{pmatrix}a&b+ic\\ b-ic&d\end{pmatrix}$，由 $c=0$ 回到实对称；照原文。
3. **p.35**「Figure 1.4」疑为图 1.9；**p.42** 原书「Figure ??」为坏引用，应为图 1.10。
4. **p.33**「$l$ sufficiently small」与上下文方向相反（疑应为充分大）；**p.33** 坐标计算第二分量字面结果与右侧不符。
5. **p.74 / p.77** 的基公式与原书 1.2.17 的排印不一致（一处末项漏 $\lambda$、一处括号内应为 $+$）；以原书 1.2.17 为准并加译注。
6. **p.98** 第二个长正合列 (**) 的矩阵，行内版与页下版有一行不同（$(0\,1\,0)$ 对 $(0\,0\,0)$）；两处照录并加注。
7. **p.105** 边界写作 $\overline{\mathcal M}/\mathrm{Aut}\setminus\mathcal M/\mathrm{Aut}$，第一项多一条上划线，疑为排版残留。
8. **p.83**「In Sections 4, 4, and 4」三处节号都印成 4，原书交叉引用已失效。
9. **p.91** 文字层把 $g(-\xi)=-g(\xi)$ 的第二个负号吞掉，页图核对原文无误。
10. **p.120**「$[0;1]\subset\mathbb R^4$」笔误；**p.128** Kuranishi 映射写作 $V_p\to\Gamma_p$，按其定义应为 $V_p\to E_p$；**p.124**「rotating $i$」疑为 $\ell_i$；**p.125** 面积式括号不配对。
11. **p.51** 首行 $d^2\alpha_3/d(\log d)$ 分母缺平方；**p.54**「$g_{yz}=g_{yz}$」应为 $F=g_{yz}$；**p.55** 区域 III 首行 $g_{xy}$ 应为 $g_{xz}$；**p.65** $d_{IIB}$ 的三个偏导与字面求导差 4 倍（后续估计结论不变）。
12. **p.56** 正文夹有作者工作批注「Fix $\varphi$ terms in first line.」；**p.13**「Hhnce」为 Hence 之误；**p.13** 例 1.3.27 证明中「$f\in\operatorname{Spec}\mathbb C[M]$」应为 $f\in\mathbb C[M]$。
13. 参考文献保留原书的大小写/拼写异常（如 `fukaya`、`june`、`Generalize`、`J Francis`），未做「修正」。
