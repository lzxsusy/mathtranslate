2. **样板块**：Lead 亲自做 c00（摘要/献词/致谢）与 c01（§1.1–1.2，12 页，全书最难定体例的块）。c01 译完后逐条复核 `work/glossary.tsv`（v0 草案 69 行），升为 **v1（104 条，全部冻结）**。

4. **逐块验收**（每块四步）：复跑 `compile_chunk.py`（errors/overfull/undefined/missing_char 四项必须为 0）→ BAD_LATEX 自查（字面编号、`\tag`、`\cite`、连字）→ 统计 env/公式/图/译注/行数 → 抽 1–2 页渲染目检。
5. **交叉双校**：c07 由另一 teammate 独立抽检 14 条公式/定理 + 5 条译注，发现 9 处问题（3 处译注事实错误、2 处错字、3 处增义），全部修正；其余块写 review 记录。
6. **整书与交付**：`build.ps1` 三遍 → `check.py` VERDICT PASS → 七件套 → 登记表状态改「已交付」。

## 二、遇到的问题与处理

### 2.1 块边界切在小节中间（四处）

原书按整页切块，但 §1.2 的收尾在 p.13 上半、§1.3 的收尾在 p.23 上部、§4.1 的收尾在 p.91 上部、§4.3 的收尾在 p.110 上部。若按页码硬切，定理编号会跨块重置、证明会被截断。**处理原则：小节归属优先于页码**——上一块收在页中，下一块从该页的新小节起。四处边界都写进 README 与交付说明，并在块首注释标明「上半/中部/下部」。

### 2.2 文字层不可信（最大的一类坑）

PDF 文字层把公式拍平，至少 5 处会直接导致错译：

- p.17 Hermite 矩阵：文字层作 $\begin{pmatrix}a&b\\ b&a\end{pmatrix}$，页图是 $\begin{pmatrix}a&b\\ \bar b&a\end{pmatrix}$（漏共轭）。
- p.6 的 $\mathrm{Hom}_{\bar{\mathbb C}}$：文字层丢掉下标的上划线，读起来像双线性而非共轭线性。
- p.9 断言 1.2.15 证明用上标 $\gamma^1,\gamma^2,n^1,n^2$，文字层全作下标。
- p.91 的 $g(-\xi)=-g(\xi)$：文字层吞掉第二个负号，一度被当成原书笔误登记（后经 500dpi 放大核对，原文无误，已撤回该条注）。
- p.105 的 $\overline{\mathcal M}/\mathrm{Aut}\setminus\mathcal M/\mathrm{Aut}$：文字层两处都带上划线，页图只有第一项有。

**教训**：凡公式、上下标、花体、负号，一律回 `work/pages/pNNN.png` 核对；`zoom.py` 按 PDF 点裁局部（130dpi 页图像素 × 72/130 = PDF 点）。「原文疑似笔误」的结论必须先看页图再登记——这次差点冤枉了原作者。

### 2.3 编号体系的三个雷

- **共享计数器**：原文所有定理类环境共用「章.节.序号」，preamble 已用 `\newtheorem{result}{结果}[subsection]` 实现。单块编译时 `compile_chunk.py` 预置 section/subsection 计数器，块内编号与整书一致。
- **禁止字面编号**：`check.py` 扫全文（**含 `%` 注释**）的字面编号正则，c01 首部注释写「引理 1.2.24、断言 1.2.25」直接 FAIL；c05 的「注 3.0.22」同样触发。跨块引用一律写「原书 1.2.17」或「§1.2 的基公式」，不用 `\ref`（单块编译会 undefined）。
- **块内只 ref 本块 label**：单块编译要求 undefined=0，跨块 `\ref` 必然失败；整书编译前另跑脚本核对 244 个 label 无重名、无悬空 ref（发现 c01/c09 各有一个 `rem:seidel`，改后者为 `rem:notation-seidel`）。

### 2.4 术语冻结与误译

- v0 草案把 **monodromy** 写成「单值化」（那是 uniformization），冻结时改为「单值性」。
- **Landau–Ginzburg** 草案音译「朗道–金兹堡」，但 c01 正文已用英文，c04 又用中文，全书不一致。冻结时统一为「Landau–Ginzburg 模型」（保留英文），并三同步：术语表、c04 正文、README 变更日志。
- 术语追加机制：每块完工后只「追加」新词条，不修改已冻结行；最终 241 条，无「待定」。

### 2.5 译注的事实准确性

c07 双校暴露出 3 条译注把数学事实说反了（例 4.2.3 的宽度与像、定义 4.2.5 的条状端极限方向、引理 4.3.8 的「算盘计数」错字）。说明：**译注本身也是译文，需要双校**；数学直觉类注释尤其容易「想当然」。

## 三、经验

1. **样板块先行**：c00+c01 定下文风、术语、评注体例与 LaTeX 习惯（嵌套可选标题要 `[{...}]` 保护、过长指数映射用 aligned 拆行），后续 10 块全部照此，返工极少。
2. **术语先冻结**：冻结不是形式，是并行施工的前提；c02–c09 六个 agent 同时开工，靠 104 条冻结译名才没有出现同词异译。
3. **页图是唯一真相**：文字层只用来定位段落，公式一律回页图；这条纪律这次至少拦下 5 处硬错。
4. **逐块编译闸门**：四项全 0 的硬门槛逼出了所有 overfull、缺字、undefined；比事后整书排查便宜得多。
5. **写作用域隔离**：每块只动自己的 chunk 与 figures、reports；README/glossary 只有 Lead 能改，避免了并行覆盖。
6. **交叉双校值得**：独立 agent 抽检 14 条就抓到 9 处问题，成本远低于读者发现错误的代价。
