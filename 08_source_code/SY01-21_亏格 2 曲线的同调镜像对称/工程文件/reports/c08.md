## 译文取舍
- 「categorical localization method」译「范畴局部化的方法」，与 c07 中原书 4.2.8 提到的 [AS] 局部化方法前后一致。
- 「directed category」译「有向范畴」，不译「定向范畴」，以免与流形的定向混淆。
- 「roofs 的等价类」保留 roofs 不译：这是局部化理论的标准叫法，译名不统一，硬译反易误导。
- 式 (4.5) 的三行按原书顺序（$K>L$、$K=L$、其他），未按数值大小重排；「else」译「其他」并加逗号，与 cases 环境对齐。
- 原文「TQFT, i.e. a functor from manifolds to vector spaces where cobordisms map to vector space homomorphisms」译「从流形到向量空间、把配边映到向量空间同态的函子」，保留「配边」这一标准译名。
- 「proper holomorphic group action of $\Gamma_B$ that we can quotient by」译「$\Gamma_B$ 有可商的正纯全纯群作用」；「proper」取「正纯」而不取「真」，与 c07 中「真变换（proper transform）」的用法区分开。
