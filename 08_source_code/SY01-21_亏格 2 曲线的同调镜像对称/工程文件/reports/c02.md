## 疑点与请示
1. **块边界（已按 Lead 批复方案 A 处理）**：§1.3 实际延伸到 p.23 中部——p.23 顶部先有推论 1.3.29（辛形式的定义）与注 1.3.30（$\OO(D)$ 丰富、$Y_\Delta$ 可嵌入射影空间），之后才是 §1.4「A 侧流形」。若按原 README 的 p.13–22 收块，这两条会落入 c03 的 `\subsection{A 侧流形}`，编号将变成 1.4.x，与原文 1.3.29/1.3.30 不符。故本块收至 p.23 上部，c03 从 p.23 中部的 §1.4 起。**请 Lead 在 README 进度表与总装时确认此边界**。
2. **定义 1.3.19 记号前后不一致**：本条正文用 $\langle u,v_i\rangle$（$u$ 取 $M$ 中点、$v_i$ 取 $N$ 中的法向量），而定义 1.3.18 与 1.3.20 用法向量 $\nu_i$、并用 $\mathbf v$ 专指多面体的顶点。原文如此，照录不改，仅加译者注提示「此处的 $v_i$ 即后文的 $\nu_i$」。
3. **断言 1.3.27 证明中「$f\in\operatorname{Spec}\C[M]$」**：按上下文，$f$ 是函数、$T_N=\operatorname{Spec}\C[M]$ 是空间，此处应为 $f\in\C[M]$。照录原文并加 `% [Tutor Note: ...]` 与译者注，未在正文静默改动。
4. **断言 1.3.27、1.3.28 标题的引用括号**：原文作「(Sections of $\OO(D)$, [CLS11][Proposition 4.3.3] )」「(Basepoint free, [CLS11][Proposition 6.1.1). ]」，双括号与错位括号是原文排版；译文保留两段方括号内容，但整条标题用 `[{...}]` 包裹，避免 amsthm 的可选参数在第一个 `]` 处截断。1.3.28 原文末尾多出的「)」未复制，理由同上（纯排版噪声）。
5. **推论 1.3.29 标题**同 4：原文「[Huy05][Example 4.1.2]」双括号照录。
6. **p.13 原文「transitions functions」**：应为 transition functions 之笔误，译文按「过渡函数」处理，不影响数学，登记备查。
7. **定义 1.3.7 的包含式**：原文作 $M=\operatorname{Span}_{\Z_+}\langle\pm e_1,\dots,\pm e_n\rangle\supset\{u\in\sigma^\vee(1)\}$，字面上把 $\{u\in\sigma^\vee(1)\}$ 写成 $M$ 的子集。结合上文「所有局部卡都含稠密环面」与下文「射线生成半群 $S_\sigma$」，此处想说的是 $\sigma^\vee$ 的射线生成元落在 $M$ 中；译文照录原式，另加译者注解释这一层。请 Lead 判断是否需要在勘误表中记一条。
