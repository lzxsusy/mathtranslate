# Fukaya 范畴与 Picard–Lefschetz 理论 · 中文译注本

## 一、这是什么

Paul Seidel, *Fukaya categories and Picard–Lefschetz theory*（EMS，2008）的中文译注本。底本为作者公开的英文 PDF（334 页）；初版（修订版 01）已由既有译本排成 LaTeX（243 页，止于 §20.7 末，无译者注）。本次在修订版 01 基础上做**逐段校对 + 译者注 + 读书报告**，不重译。

- 成品 PDF：`Fukaya范畴与Picard-Lefschetz理论_中文译注本.pdf`（301 页）
- 源码：`Seidel_Fukaya_修订版03_TeX及图片.zip`
- 读书报告：`读书报告.md`（同时收入成品 PDF 书末）
- 工作流：`工作流说明.md`
- 精选数据：`精选数据/`（译者注总表、修订总表、统计、原页对照、笔误登记）
- 术语表：`术语表.csv`

## 二、本次做了什么

1. **对齐原文**：按原书印刷页抽取英文，逐页建立 `p001`–`p326` 文本与 PNG 渲染。源码 `\SourcePage{n}` 记的是原书 **PDF 页**，印刷页 = `n − 8`；所有译者注页码均按印刷页标注。此前按 `SourcePage` 直接当印刷页造成的 8 页偏移已全部纠正。
2. **分块校对**：全书 82 个章节文件按原书页序分 12 段，每段一个子代理，只改自己区段的 `.tex`；逐句对照英文，公式、交换图与符号约定另据原书页面图像逐式核对。只改确凿的误译、漏译、术语不统一与公式/指标错误；原书自身笔误保留译文正确写法并登记，不回改。
3. **译者注**：统一书末尾注，正文只留数字上标，不改动正文语义。每条注以【原书 p.N】开头，注末给来源。共 **187 条**（A 级 125、B 级 51、C 级 11）。
4. **审计**：`\label` 集合与备份逐一比对（856 = 856，0 增删）；译者注条数与 TSV、`.ent` 三方一致（187 = 187 = 187）；黑名单来源 0；整书编译 0 error / 0 undefined / 0 overfull / 0 missing character。
5. **读书报告**：约 6000 字，述全书问题、三章结构、三套工具、主定理与局限，并给出阅读路线；收入书末。

## 三、编译

本机 MiKTeX 26.5：

```
powershell -NoProfile -File work\tools\build-local.ps1
```

脚本执行 `xelatex → makeindex → xelatex → makeindex → xelatex`，开始前删除旧的 `main.ent`（endnotes 中间文件）。也可在 `src\` 下按同样顺序手动执行。

依赖：XeLaTeX + ctex + elegantbook + endnotes + unicode-math；字体 SimSun / SimHei / KaiTi / FangSong / TeX Gyre Termes X / New Computer Modern Math。
