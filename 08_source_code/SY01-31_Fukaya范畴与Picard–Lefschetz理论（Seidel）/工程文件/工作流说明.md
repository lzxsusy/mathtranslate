## 2. 原文对齐

- 用 pymupdf 按印刷页抽取英文：`work\en\pages\pNNN.txt`，合订为 `work\en\book.txt`（含 `===== BOOK PAGE n =====` 标记）。
- 关键换算：**印刷页 = 原书 PDF 页 − 8**。源码 `\SourcePage{n}` 记的是 PDF 页，所以 `\znote` 的页码 = `n − 8`。最初误把 `SourcePage` 当印刷页，导致 12 个英文合订本整体偏移 8 页；发现后重建 `work\en\bundles\A01–A12.txt` 并通知全部子代理。
- 公式、交换图、上下标一律回渲染页 `work\pages\pNNN.png`（dpi 160）核对，不依赖文本层；文本层的 A∞ 会退化成 A1、上下标会丢失。

## 3. 批注体例

- 书末尾注（endnotes），正文只留数字上标，不改动正文语义。
- `\znote{印刷页}{注文……[来源：……]}`，来源必须写在第二个花括号内，否则会跑到正文。
- 每注以【原书 p.N】开头；来源分 A/B/C 三级：
  - A：原书前后文、作者他文、经典教材、原始论文；
  - B：nLab、Stacks Project、EMS（须实际打开并记访问日期；只作概念说明，涉及定理归属另举 A 级）；
  - C：上下文推断，写作“译者按（上下文推断，无外部依据）”。
- 全书注释在 `\backmatter` 的 `\theendnotes` 统一排出，标题“译者注”；编号连续。
- 与 elegantbook 的冲突：`note` 环境以 `\endnote` 作结束码，故 `main.tex` 先 `\let\elegantnoteend\endnote`，载入 `endnotes` 后再 `\let\latexendnote\endnote`、恢复 `\endnote`。
- 排版参数：`\enoteformat` 用 3.0em 悬挂缩进；长 nLab URL 在 `/`、`+` 后插 `\allowbreak`，否则附录出 overfull。

## 4. 分块并行

- 全书 82 个章节文件按原书页切成 12 段（每段 14–37 页），每段一个子代理，只改自己区段的 `.tex`。
- 每段流程：通读中文 → 读英文合订本 → 逐句对照 → 公式回页面图像 → 改确凿误译 → 写 7–20 条注 → 写 `report-Axx.md` 与 `notes-Axx.tsv` → 对每个改动文件跑 `work\tools\check.ps1`。
- 子代理之间不改同一文件；术语、label、编号、`\SourcePage` 冻结；并发上限 8，前 8 段先跑，空出名额再派 A09–A12。
- 单章自检脚本曾把 xelatex 的 stdout 重定向到 `check-<name>.out`，与 hyperref 的 `.out` 书签文件同名而报错；改为 `> nul` 后正常。
