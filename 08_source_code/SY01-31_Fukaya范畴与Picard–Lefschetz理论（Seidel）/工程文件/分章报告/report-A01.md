## 五、原书可疑处 / 笔误

1. **定理 A 的假设**：印刷 p4 印 `n ≥ 1`，p5 解释段与定理 B 后说明都按 `n > 1` 使用并明言 `n = 1` 应排除。原书自相矛盾（注 A01-04）。
2. **(1.21) 第三项**：原书印 `μ^n_{\mathcal A}(a_{n+m},\ldots,a_{n+1})`；被插入的运算吃 `m` 个自变量，应为 `μ^m`。译文作 `\mu^m_{\A}`，正确。
3. **拉回公式 (1.23) 前后**：原书印 `μ^r_{\mathcal M}(b, G^{s_r}(\ldots),\ldots)`、`t^r(b, G^{s_r}(\ldots),\ldots)`；自变量为 `b` 加 `r` 块共 `r+1` 个，应为 `μ^{r+1}`、`t^{r+1}`。译文作 `r+1`，正确；同页 `\RG` 公式（无 `b`）确用 `T^r`，恰可佐证这里是漏写。
4. **符号重载**：原书用 `§` 作符号（印刷 p20），与分节号同形；`†`、`∘`、`‡` 亦为临时符号，均只在局部定义，重读时需回查。
5. **引理 1.4 的证明**：末句原文引 “(1.12)”，但引理中的等式并未编号 (1.12)（(1.12) 是复合函子的等式）。译文改述为“本引理所陈述等式两侧的差”，回避了指错。

## 六、通读小结

这一区段是全书的地基。前言与引言交代动机：Fukaya 范畴把 Lagrangian 子流形的相交数据与伪全纯圆盘的计数压缩进一个 A∞ 结构，代价是对象与态射都极难直接计算。Seidel 的对策是退到正合（exact）的 Calabi–Yau 情形，再借 Picard–Lefschetz 理论把几何换成组合数据。定理 A、B 与推论 C 就是全书的目标陈述：存在一个“很强意义下有限”的有向 A∞ 范畴，它的导出范畴与 `F(X^1)`、`F(X)` 的导出范畴等价，于是计算化归为有限数据。

第 1 节随后把这套机器逐件搭好：非含幺 A∞ 范畴与函子、形式微分同胚、预自然变换与同伦、长度滤过与 Hochschild 上同调、扰动引理、模与 Yoneda 嵌入。主线很清楚——所有构造都只在拟同构意义下确定，因此每一步都得把符号公式显式写出来核对；读者若跳过符号，第 5、17、18 节会寸步难行。

最难懂的三处：一是 (1.8) 的 `†` 与 (1.9) 的 `∘`，它们把 `T` 所在块移位的代价写成 `(|T|-1)(|a|-1)` 的连乘，不亲手验一遍极易写错；二是同伦的传递性与对称性（(1.15)–(1.17)），难点在于同一个预自然变换在不同 `hom` 空间中的“化身”要分清；三是扰动引理 (1.18) 的递归展开，其实质就是经典同伦扰动引理的 A∞ 版本。

阅读建议：先读引言，把定理 A/B 当作路标而非细节；再按“定义—引理—构造”的顺序推进第 1 节；遇到 `§`、`†`、`∘`、`‡` 这类一次性符号时随手回查约定，不要凭记忆；凡遇公式，先数自变量个数再对符号，可避开原书本身的三处笔误。
