## 六、通读小结（400–600 字）

本区段是全书的技术枢纽。第 2 章先把“单位元”问题拆成严格含幺、同伦含幺、上同调含幺三层，并证明任意 c-含幺范畴都可用形式微分同胚严格化（引理 2.1），于是可放心地在 c-含幺框架中工作；随后依次建立函子范畴、同伦与同构、Morita 不变性和拟等价理论，核心是定理 2.9（拟等价有同伦逆）与 Yoneda 嵌入给出的 $\modcat(\A)\hookrightarrow\operatorname{fun}(\A,\modcat(\A))$。第 3 章把这些工具用于“构造对象”：先用拟表示统一处理直和、张量积、平移与映射锥，再定义正合三角，并用引理 3.7 把它翻译成三组方程加一条无上同调条件；命题 3.8 进一步说明正合三角恰是“三对象模型” $\mathcal D$ 的像，推论 3.9、3.10 由此导出稳定性。真正的技术难点在 §3l–§3r：扭曲复形 $\Tw\A$ 既是三角化包络，又让所有构造都有链层面的具体模型，引理 3.31 保证在 $H(\A)$ 与 $H(\Tw\A)$ 中判断正合性等价，命题 3.8 的正式证明则以扰动引理收尾。最难懂的三处是：引理 2.1 证明中 $z_n$ 的符号与 (2.4)–(2.5) 的组合、引理 3.7 中 (3.11) 的微分矩阵、以及命题 3.8 证明里 $T^1$ 与扰动引理的配合。建议读者第一遍只抓“拟表示—正合三角—三角化包络”这条主线，符号细节留待用时回查；遇到 (3.10)、(3.11) 这类长公式，先按链复形的映射锥去理解，再逐项核对符号，会比直接读公式省力得多。
