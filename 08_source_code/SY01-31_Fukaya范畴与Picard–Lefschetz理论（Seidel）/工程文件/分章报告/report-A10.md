## 五、原书可疑处 / 笔误

1. 原书 p263（17k）：“the Dehn twist $\tau_L$ along such a sphere”——同一句前半把该球面称作 $V$，全节其余各处亦作 $\tau_V$，此处 $\tau_L$ 应是 $\tau_V$ 之误。译本已作 $\tau_V$，未加注（改了反而与原文对不上）。
2. 原书 p252：“a sufficiently large closed interval $[0;1]\subset\mathcal R^4$”用分号分隔区间端点（原书排印习惯），非数学错误，未处理。

## 六、通读小结（400–600 字）

这一段是第 17 节的后半，也是全书由“几何构造”转向“代数结论”的枢纽。17g 把此前两条独立线索——伪全纯截面给出的 $(d,l)$，以及由 $(c,k)$ 经 $\mu^2$、$\mu^3$ 拼出的 $(\tilde d,\tilde l)$——用五族 Lefschetz 纤维化显式焊接，得到 (17.19) 的链映射方程；17h 把这套几何数据交给引理 5.3，用“映射锥无上同调”换得“$t$ 是同构”，从而说明 $Y_2$ 拟表示 $T_{Y_0}(\Y_1)$；17i 补上相对分次与相对 Pin 结构，使带符号的计数真正落地；17j 收束为定理 17.16、推论 17.17 与正合三角 (17.23)，再经 Hurwitz 移动与变异得到定理 17.20 与推论 17.21：扭曲复形范畴是 Lefschetz 纤维化的不变量；17k 把整套论证搬进 $\Z/2$ 等变情形，止于引理 17.23。

最难懂的三处：一是 17g 的“链闭合”，图 17.8 的五个族与图 17.9 六边形六条边如何对应，原书只用图形语言交代，须读者自己补出；二是 17h 的“无上同调即同构”，关键在引理 5.3(iii) 的映射锥，不回看第 5 节便无从下手；三是 17i 中相对 Pin 结构与定向符号的相互作用，(17.22) 的符号约定散见第 11、12 节。

建议按 17g → 17h → 引理 5.3 → 17i 的顺序读，并把 (17.19)、(17.21)、(17.23) 当作同一件事的三个侧面。译文整体准确，只查出两处笔误（17j 的例号、17k 的 $\kappa$）。
