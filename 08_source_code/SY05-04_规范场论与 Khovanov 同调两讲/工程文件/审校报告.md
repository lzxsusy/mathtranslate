## 6. 阅读警示（最重要的五处）

1. **$G$ vs $G_{\mathbb C}$**：规范群取紧实形式 $G$；丛的复结构、Hecke 修正
   用复化 $G_{\mathbb C}$。$G^{\vee}_{\mathbb C}$ 的下标常被 dvips 排到下一行，
   那是排版，不是另一个群。
2. **$\mathcal L$ 的双重身份**：全纯线丛（第一讲）与线性化算子（第二讲 p.15/p.17）。
   原文同用花体 L，靠上下文区分。
3. **$\phi$ 的阶数随维数变**：3 维 Bogomolny 中 $\phi$ 是 0-形式，
   4 维 KW 中 $\phi$ 是 1-形式。丢掉 $\phi\wedge\phi$ 项即从 (1.10) 回到 (1.5)。
4. **符号约定**：$F=\mathrm dA+A\wedge A$（数学约定）；KW 方程取
   $F-\phi\wedge\phi=\star\mathrm d_A\phi$（与 [15] 一致）。改用
   $F+\phi\wedge\phi$ 会使 $t\leftrightarrow t^{-1}$ 互换。
5. **“显然/短计算”三处**：p.15（Weitzenböck 公式 (2.8) 的推导）、
   p.18（$I'$ 的构造与 $W_a$ 的定义）、p.21（$L^{\dagger}$ 与 $-L$ 共轭）。
   均已在批注中指出应查 [15] §3、[21] §4–5、[22]。
