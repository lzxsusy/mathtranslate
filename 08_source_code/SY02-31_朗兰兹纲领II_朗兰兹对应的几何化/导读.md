## 1. 三十秒版本

经典 Langlands 对应说：$G(F)$ 的表示 ↔ Galois 群的 $L$-参数。问题是参数那一侧
不是几何对象。这本书的六篇给它造了六个"几何身体"：

- **概形**（Dat）：$Z^1(W_F,\hat G)\sslash\hat G$；
- **叠 + 凝聚层**（Zhu）：$\mathrm{Loc}^c_{G,F,\iota}$；
- **$v$-叠**（Fargues–Scholze）：$\mathrm{LocSys}_{\hat G}$ 与 $\mathrm{Bun}_G$；
- **刚性解析叠**（Emerton–Gee–Hellmann）：$(\phi,\Gamma)$-模的 $\mathfrak X_d$；
- **$S^1$-等变凝聚层**（Ben-Zvi–Chen–Helm–Nadler）：内插凝聚与可构造；
- **导出形变环**（Feng–Harris）：导出化的对应。

一句话：**这本书把"对应"从陈述句变成几何命题。**

## 3. 四条读法（按目的选一条，不要从头读到尾）

### 路线 A：只要"几何 Langlands 是什么"（约 60 页，1–2 天）

前言 → **A3 §1–§2**（125–137：$B(G)$、$\mathrm{Bun}_G$ 是 $v$-叠）→ **A3 §6**
（162–165：范畴几何化猜想与函子性）→ **A5 §1、§3**（421–443：$S^1$-内插与
$\mathrm{GL}_n$ 主定理）。

读完能准确说出：几何 Langlands 猜什么、为什么需要 $v$-拓扑、凝聚侧与可构造侧
是什么关系。**跳过**：A2 的导出形式空间、A4 的族化、A6 的导出形变。

### 路线 B：做 $p$-进表示论（约 300 页，2–3 周）

**A4 §1**（167–178：总纲猜想 1.4.3）→ **A4 §5.1**（204–219：$(\phi,\Gamma)$-模的
几何化、$\mathfrak X_d$、Hodge–Tate 过滤）→ **A4 §5.3**（227–243：算例
$\mathrm{GL}_2/\Q_p$）→ **A4 附录 E、F** → 回头读 **A1 §2–§4**（6–26：$Z^1$ 的
几何品性与连通分支）。

为什么这个顺序：A4 的猜想要"块 = 连通分支"，而"连通分支"的原始技术（l.c.i.、
形变环）在 A1；先看目标再看工具，比反过来省力。

### 路线 C：做几何表示论 / 层论（约 200 页，2 周）

**A2 全篇**（39–123：导出形式空间 → 参数叠 → 凝聚层 → Hecke 对应）→
**A5 全篇**（421–470：Koszul 对偶、$S^1$-内插、Soergel 与扭量）→ 需要时回查
**A3 §3–§5**（143–161：可构造侧与谱作用）。

A2 的命题 2.10（群上同调 = 导出形式空间）是全书的"翻译器"，务必先吃透。

### 路线 D：做导出代数几何 / 前沿（约 150 页，2 周）

**A6 全篇 + 附录 A**（471–567）→ **A4 附录 A–C**（范畴论、IndCoh/ProCoh、局部化）
→ **A2 §2**（43–64：导出形式空间的系统理论，作为技术模板）。

A6 的 8.2.3（导出 Hecke 代数 ≃ 导出 Galois 形变环）是全书技术上的最高点，
读懂它需要 IndCoh 的 $!$-拉回与 Tate 消没。

## 5. 预备知识清单（按"读哪篇需要什么"）

- **概形与形变**：Harshorne *AG* 或 Vakil；形变理论（加框架形变、余切复形）
  见 Fantechi–Göttsche 等的 *FGA explained* 或 Talpo–Vistoli 的综述。
- **导出代数几何**：Toën–Vezzosi 的综述；IndCoh 见 Gaitsgory–Rozenblyum。
  A4 附录 B 是很好的"最小可用版"。
- **$\infty$-范畴**：Lurie *Higher Topos Theory* 前几章，或 A4 附录 A（够用）。
- **$v$-叠与钻石**：Scholze 的 *Etale cohomology of diamonds*；A3 §2 是它的摘要版。
- **$p$-进 Hodge 理论**：Fontaine 的 $(\phi,\Gamma)$-模、Berger 的综述；
  A4 §5.1 给出了几何化版本。
- **几何表示论**：Ben-Zvi–Nadler 的 loop space 系列；A5 §2 是自足的入口。

## 6. 使用这个译本的三条约定

1. **页锚**：每页原文的第一个段落左侧有灰色小号数字（如 `42`），即印刷页码；
   PDF 阅读器里可点它跳到原文对应页（译本内锚点）。
2. **编号**：定理、命题、猜想、公式一律保留**原文编号**（如"定理 2.2"就是原书
   Dat 篇的定理 2.2），不重编。六篇各自独立编号，故"定理 2.2"在不同篇里指不同对象。
3. **译注**：脚注中标 `[来源：…]` 的是可查证的译法依据；标"上下文推断，无外部依据"
   的是译者判断，请以原文为准。原文笔误**照排并加注**，不擅自改动。
