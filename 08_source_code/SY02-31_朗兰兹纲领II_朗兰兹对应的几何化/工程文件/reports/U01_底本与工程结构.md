## 2. 通读分级与执行

按《数学文献翻译纪律》v2.1 §1.0，>150 页按**专著级**处理：目录、序言、各篇导言速读建立全局地图；每篇开译前细读该篇。执行情况：

- 全书逐页文本抽取（`lp2_work/pages/pNNN.txt`）与 140 dpi 页面图（`lp2_work/png/pNNN.png`），供逐符号回图核对；
- 抽取 679 条编号陈述清单（`lp2_work/statements.tsv`），作为编号审计底表；
- 产出 `work/通读笔记.md`（全局地图）与 `work/疑点清单.tsv`（未解 = 0 后才开译）。

## 3. 分块方案

按篇切块，每块 9–13 个印刷页（约一个 `\section` 的量级），共 47 块，命名 `ch-a<篇>-<序号>.tex`：

| 篇 | 块 | 页数 |
|---|---|---|
| 1 | a1-00 … a1-03 | 3–37 |
| 2 | a2-01 … a2-07 | 39–123 |
| 3 | a3-01 … a3-04 | 125–165 |
| 4 | a4-01 … a4-21 | 167–419 |
| 5 | a5-01 … a5-04 | 421–470 |
| 6 | a6-01 … a6-08 | 471–580 |

切块边界的选取原则：落在节边界或段落边界；不可避免的跨块句/跨块证明由下一块直接续写（不开新环境），并在块尾留注释说明承接点。

## 4. 版式与编号约定

- `ctexbook`，11pt，A4，`openany`，`fontset=windows`（SimSun/SimHei/STKaiti）。
- 篇题不编号（`\chapter` 无编号），节号按篇重排为 `\arabic{section}`，三级标题显示（`secnumdepth=3`），以复现底本「4.3.2」式的篇内编号。
- 定理类环境用包装写法 `\begin{thm}{原编号}`：计数器步进前把 `\theithm` 置为原文编号，因此 `\ref` 得到的是**原文编号**而非译本自动编号——这是本书大量交叉引用（含跨篇引用）能准确对应的前提。
- 页锚 `\ysrc{印刷页}`：页边灰色小字 + 内部 hypertarget `src:n`，每页一个，供纸书对照。
- 图表按底本重绘（tikz/tikz-cd），不保留位图占位；确需位图者用 figure 并登记。
- 文献条目保持英文原样（书名、期刊、DOI），正文引用写作字面 `[FS21]`，不使用 BibTeX。

## 6. 为什么不发布成品 PDF

底本为 AMS 在版会议论文集，译文属于演绎作品。按仓库 `04_playbook/17_仓库理念与上传规范.md` §3.3 与 R3 判定，本工程只发布**源码、工程文件、资料卡与对齐卡**，不把整书成品 PDF 放进仓库；读者可用 xelatex 三遍自行编译。
