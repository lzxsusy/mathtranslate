# U02 术语体系与译名决策

本工程术语表：`work/glossary.tsv`，229 条（A 级 218、B 级 4、未核 7）。等级含义沿用《数学文献翻译纪律》§2.5：A = 原书/经典教材/原始论文或本库既有译法（I 级并入 A）；B = nLab / Stacks Project 等白名单百科；未核 = 译出但尚未找到权威依据，已在资料卡 04 里挂账。

## 1. 三条前置决定

1. **先定术语再落笔**。47 个分块由不同译手完成，如果术语在译手之间漂移，全书必然裂开。因此 `glossary.tsv` 在开译前就写到 190 条，每块开译前必读；译手回报的「表外术语」由 lead 合并入表后，下一块才能用。
2. **本库既有译法优先**（I 级）。开译前用数译知识库插件（`kb_search`）检索同库已有译法，直接继承：`Langlands 参数`、`L-群`、`参数叠 $\mathcal L_G$`、`几何朗兰兹对应`、`模叠`、`粗模空间`、`叠`。这样 SY02-31 与 SY02-08/21/24/25 之间的读者不必重新学一套词。
3. **不音译、不生造**。除 shtuka 这类在中文文献里已普遍保留原文的词（音译「施图卡」反而增加检索成本）之外，一律意译；确需保留原文的，首次出现括注英文。

## 2. 关键译名与理由

| 英文 | 译名 | 理由 |
|---|---|---|
| stack | 叠 | 中文代数几何通行译法（Stacks Project 中译、国内教材一致）；「栈」在计算机语境里被占用，数学文本中易误读 |
| moduli stack | 模叠 | 「模空间」的叠化，构词与 moduli space 对应 |
| coarse moduli space | 粗模空间 | 与「细模空间」（fine moduli space）配对；底本第 1 篇正是在粗/细之间做文章 |
| coherent sheaf | 凝聚层 | 通行；与「相干」（coherent light）区分 |
| IndCoh | 导出凝聚层（IndCoh） | 该范畴的对象不是普通凝聚层，而是 Ind-对象；保留缩写是因为全书出现数百次，且与 ProCoh 成对 |
| constructible sheaf | 可构造层 | 通行 |
| derived | 导出 | 「派生」是旧译，本库统一改「导出」（导出范畴、导出叠、导出结构） |
| perfectoid space | 完美胚空间 | 中文数论文献通行（如「完美胚空间」系列讲义）；首现括注 perfectoid |
| diamond | 钻石 | Fargues–Scholze 的专名，中文文献已通用；不译「菱形」以免与几何图形混淆 |
| shtuka | shtuka | 保留原文（Drinfeld 原词，无公认中译） |
| v-stack | v-叠 | 拓扑名 v 保留字母，与 v-层、v-拓扑一致 |
| avatar | 具体形态 | 底本用 avatar 指「同一猜想的具体化身」，非「头像」，见疑点清单 p.3 |
| excursion operator | 游历算子 | excursion 在朗兰兹语境指「绕行、游历」，与游历代数（excursion algebra）配套 |
| pseudorepresentation | 伪表示 | 通行 |
| torsor | 挠子 | 通行（主齐性空间） |
| rigid analytic / adic space | 刚性解析 / adic 空间 | adic 保留（adic spectrum、adic space 已是固定搭配） |
| syntomic | 合冲的 | 通行；本书多作形容词（syntomic morphism 合冲态射） |
| parasoric / parahoric | parahoric（保留） | 中文无稳定译法，音译「抛物」会与 parabolic 混 |

## 3. 同一英文多译的处理

底本六篇作者不同，同一概念常有不同写法，译文按「读者不必回头查」的原则处理：

| 现象 | 处理 |
|---|---|
| 第 1 篇 `$Z^1/\hat G$` 与 `$Z^1\sslash\hat G$` 混用 | 前者指叠商（stack quotient），后者指 GIT 商（粗模空间），严格区分，不用同一符号 |
| 第 2 篇 `Dr_Λ` / `Dr_K` 混用 | 一律照录原文下标，另加译注说明疑为笔误（疑点清单 6 条） |
| 第 3 篇 `Bun_G` 与 `\mathrm{Bun}_G` | 统一宏 `\Bun_G` |
| 第 4 篇 `$\mathfrak A_{J_b}$` / `$\mathfrak A_{\mathcal G_b}$` | 照录 + 译注 |
| 第 6 篇 `derived` 三义（导出范畴 / 导出形变 / 导出叠） | 均译「导出」，靠宾语区分，不另造词 |

## 4. 译注体例

- 每条 `\tn{}` 必带依据：`[来源：nLab "…", URL（Last revised …；访问日期 …）]`、`[来源：Stacks Project, Tag 0ABC]`，或明确写「上下文推断，无外部依据」。
- 底本笔误一律**保留正文原样 + 译注说明**，绝不悄悄改字（§3 铁律）。全书 41 条译注中，28 条属此类。
- 译注不用黑名单来源（知乎、百度百科、CSDN、简书、公众号、博客、视频课笔记）。
