## 七、编译期修过的典型错误（留档）

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| `! Argument of \math@egroup has an extra }.` | 书签串里 `\overline\mathbb{Z}` 只吞一个 token | 标题写 `\overline{\Z}`；`bookmarks=false` |
| `! Undefined control sequence. \Gal` | chunk 用了未定义宏 | preamble 加 `\DeclareMathOperator{\Gal}{Gal}`、`\Sp`、`\QC`（`\providecommand{\QC}{\Qcoh}`） |
| `No shape named tikz@f@…` | tikzcd 箭头指向空单元格 | 箭头指到有内容的格子，或补节点 |
| `! Extra }, or forgotten \endgroup.` | `{\renewcommand{\qedsymbol}{}\end{proof}}` 分组包住 amsthm 的 `\end{proof}` | 改成 `\let\qedsymbolsave\qedsymbol` / `\renewcommand{\qedsymbol}{}` / `\end{proof}` / `\let\qedsymbol\qedsymbolsave` |
| Overfull 长 URL、长作者名 | 不可断行 | `\href{全长}{短显示}`；`refs` 加 `\raggedright`；`emergencystretch=3em` |
