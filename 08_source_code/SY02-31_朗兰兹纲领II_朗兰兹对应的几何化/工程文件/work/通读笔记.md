## 1. 全书的中心问题

经典 LLC：$\mathrm{Irr}(G(F))$ 与 Langlands 参数（$\varphi: W_F \to {}^L G$ 的等价类）之间的双射。本卷问的是下一层的问题：

1. **参数本身构成几何对象**（叠 $Z^1/\hatG$），那么表示一侧的「对应物」是什么？——候选：$\Qcoh(Z^1/\hatG)$（Zhu），或某个导出/解析范畴（Emerton–Gee–Hellmann）。
2. **「族中」的对应**（LLIF）：粗模空间上的函数环 ≅ Bernstein 中心（Helm），这是范畴化对应的粗投影。
3. **几何化的另一条路线**：Fargues–Scholze 把「局部」换成曲线 $X$ 上的 $\mathrm{Bun}_G$，用钻石与 $v$-叠，把 LLC 变成几何 Langlands 的局部化陈述。
4. **凝聚型 vs 可构造型**：$\ell$-进侧的六函子形式与参数叠上的凝聚层如何比较（Ben-Zvi–Chen–Helm–Nadler 的 "spine"）。
5. **导出结构**：对应在导出层面才自然（Feng–Harris）。

理解全书的钥匙：**参数叠不是拟紧的**，所以一切「凝聚层」都必须用导出/完备化/$\infty$-范畴的语言；这也是为什么第 4 篇要花 250 页铺垫范畴论与 IndCoh。

## 2. 逐篇速读

### 第 1 篇 Dat（印刷 3–37，PDF 16–50）

结构：§1 动机（CLLC 与 LLIF，样板段已译）；§2 「什么参数」（$W_F$ 的 1-余循环、$\hatG$-共轭、$\hatG$ 的 $\Z_\ell$-模型）；§3 连续性（Weil 群的拓扑生成元、$\ell$-进 vs $p$-进系数、$\hatG$-作用的不连续性）；§4 玩具模型：驯顺参数（$W_F$ 的驯顺商，参数空间是有限型概形，可用 Bernstein 分解）；§5 归约到驯顺情形 + 连通分支（用 $\varphi$ 的驯顺部分与 Wild 部分）；§6 粗模空间：$Z^1 \sslash \hatG$ 的几何、与 Bernstein 中心的关系、LLIF 的表述与 Helm/Hansen–Mann 的结果。

关键记号：$Z^1 = Z^1(W_F,\hatG)$，$\mathcal L_G$ 或 $Z^1/\hatG$ 表示参数叠；$\Lambda$ 系数环；$\Rep_\Lambda(G(F))$。

### 第 2 篇 Zhu（印刷 39–123，PDF 52–136）

结构：§1 总览（谱分解主题；可构造层与凝聚层两种层；正文限定特征 0、$k$-线性 dg 范畴）；§1.1 表示论中的可构造层（Kazhdan–Lusztig 的 $\mathcal O_0$ 与旗簇上 $N$-等变反常层；Springer 理论与非零锥上 $G$-等变反常层、有限 Hecke 代数）；§2 loop space 的 Koszul 对偶（定理 2.5/2.6 关于概形与几何叠的 loop space；2.7 拉回等价；2.9/2.10 等变局部化）；§3 非阿基米德情形（仿射 Hecke 代数 ≅ 凝聚 Springer 层的 Ext 代数，定理 3.1；$D(\mathrm{GL}_n(F)) \hookrightarrow \mathrm{QC}^{!}(\mathcal L_{F,\mathrm{GL}_n})$ 全嵌入，定理 3.2；Hecke 范畴与 $\mathrm{QC}^!$ 的等价，定理 3.3）；§4 阿基米德情形（twistor 直线上的驯顺几何朗兰兹，导出 Adams–Barbasch–Vogan/Soergel 的构造形式）。

## 3. 全局术语与记号约定（跨篇）

- 参数叠：Dat 用 $Z^1/\hatG$；Zhu 用 $\mathcal L_G$；Fargues–Scholze 用 $\varphi$-参数空间/钻石。译文保留各篇记号，**不统一**（统一会改变原文论证的可读性），但在术语表与译注中给出对照。
- 系数环 $\Lambda$：各篇都假定 $p$ 可逆（$p$-进情形另设）。
- $\ell$-进 vs $p$-进：$\ell \neq p$ 时用 $\Q_\ell$/$\Z_\ell$；$p$-进时用 $\Q_p$ 上的 Banach/解析表示，两者语言不可混用——这是全书最容易译错的地方。
- 「导出」一律译 derived（导出范畴、导出叠、导出形变），不译「派生」。
