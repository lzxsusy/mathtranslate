## 3. 怎么核对（按片，不按译本的 PDF 页）

1. 打开 `ch-aX-YY.tex`，按 `\ysrc{n}` 把译文切成页段；每段对应底本印刷页 n，即 `pages/p{n+13}.txt` 与 `png/p{n+13}.png`。
2. 对每一段做四项：
   - **完整性**：有没有漏句、漏脚注、漏 item、漏一行公式；有没有把下一节的开头吞进来或重复。
   - **数学正确性**：符号（上下标、花体/粗体、$\mathcal X$ vs $\mathfrak X$）、量词与范围（$\forall/\exists$、$p\mid v$、$v\nmid p$）、编号（定理/公式号必须与底本一致）、交换图方向。
   - **术语**：以 `glossary.tsv` 为准；未收录的新术语记下来并给建议译名与依据。
   - **语言纪律**：禁「被……所」「进行……的」「对于……而言」；长句是否断开；英文术语两侧是否留半角空格。
3. **公式必须回页面图核对**，文字层会丢重音、上下标、花体。
4. 底本自身的笔误（印错、漏括号、编号跳号）不要算译者的错；若译文已用 `\tn` 注明，标为「已处理」即可。

## 4. 问题记录格式

每条一行，写进报告：

```
[级别] chunk文件:行 | 印刷页 | 原文摘录（≤40 字） | 译文摘录（≤40 字） | 问题 | 建议改法 | 依据
```

级别：

- **A 数学错误**：符号/量词/编号错，会导致命题读错。必须回图确认后再报。
- **B 漏译或串行**：整句、整行公式、脚注、item 缺失，或段序错位。
- **C 术语/语言**：与 glossary 冲突、禁用句式、术语漂移。
- **D 体例**：页锚位置、环境名、标签、文献条目格式。
