# 04 术语、文献与勘误 · SY02-31

> 记录本工程在术语、文献、底本勘误三方面的处理原则与实例。页码为底本印刷页（`PDF 页 = 印刷页 + 13`）。

## 一、术语总原则（按 04_playbook/01 五条公理落地）

1. **数学正确性最高**：译名服从数学含义，不为字面对应牺牲含义。例：`diamond`（Fargues–Scholze 的
   $v$-层概念）译「钻石」并加注说明它是 perfectoid 空间的 $v$-商，不是几何意义上的菱形（p.127）。
2. **一词一译**：同一英文术语在同一篇内只用一个译名；跨篇不强行统一记号（见四、2）。
3. **不音译、不生造**：`shtuka` 不音译，保留原文并加注（「shtuka（$\varphi$-模的几何化对象）」）；
   `oper` 保留原文。
4. **首现括注**：术语首次出现给英文原文，如「凝聚层（coherent sheaf）」「钻石（diamond）」。
5. **改名三同步**：若术语改名，必须同时改术语表、全部译文、资料卡。本工程未发生改名。

## 三、文献处理

- 正文引用**照抄原文字面**：`[FS21]`、`[Hel20b, §4]`、`[Zhu25, Theorem 1.2]`，不用 BibTeX（理由见工作流记录 §3.6）。
- 文末 `References` 标题译「参考文献」，**条目保留英文原貌**（作者、标题、刊名、卷、页码、DOI、MR 号），不翻译、不补全、不删减。
- 底本条目信息不全（缺 DOI/MR）时不补：译本不冒充校勘版。
- 底本引用编号与正文一一对应；译文若发现正文引用了文末没有的编号，记入勘误（本工程未发现）。

## 四、跨篇记号不统一的处理

1. **参数叠**：Dat 用 $Z^1/\hat G$（p.4），Zhu 用 $\mathcal L_G$（p.39），Fargues–Scholze 用钻石/$v$-叠语言（p.125）。
   译文**保留各篇记号**，在首次出现处加注对照（「即第 1 篇的 $Z^1/\hat G$」）。理由：统一记号会改动原文的
   定义顺序与论证依赖，且读者查阅单篇时以该篇记号为准。
2. **$\ell$-进 vs $p$-进**：$\ell \neq p$ 与 $\ell = p$ 两套语言不可混；译文中「$\ell$-进」与「$p$-进」
   严格保留，遇到原文含糊处加译注。
3. **「对应」的三种限定**：LLC（局部朗兰兹对应）、LLIF（族中的 LLC）、CLLC（范畴化的 LLC）。首现给全称，
   之后用缩写，缩写不译。
