## 五、方法与局限

- **术语**：先查本库 `TERMS.tsv`（2277 条）与各工程 glossary，命中即从；本库无先例的，查香蕉空间导航框/正文用词，再查通行教材译名；三者皆无则保留英文并在译手报告中报备，不自造中文。
- **文献**：以 Crossref 为主（有 DOI 的可直接比对卷期页），Crossref 未收录的期刊（Münster J. Math.）与疑似著录错误（RR96 页码）转 zbMATH；讲义类底本查 arXiv abs 页与作者站点。
- **局限**：① 香蕉空间部分页面需人机验证，个别条目只能依赖搜索摘要与导航框，未逐页通读；② zbMATH 与 Crossref 对预印本的时间著录不同，本卡以正式出版为准；③ 底本笔误的判断以数学自洽与上下文为据，凡照原文排印处均已出注，**读者若发现判读有误，以原文为准**。
