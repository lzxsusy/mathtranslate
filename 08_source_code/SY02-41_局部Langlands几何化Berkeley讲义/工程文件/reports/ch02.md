## 三、疑点

1. **p.7 §2.1**：原文 `Let π ⊂ 𝒪_E be a uniformizer`，`⊂` 应为 `∈`（笔误）。正文照排 `\pi\subset\mathcal O_E`，加译注 A 说明，未改动原文写法。
2. **p.7 §2.2**：原文 `Let Ẽ = \bar{\mathbb F}_q((t))`，Ẽ 在本讲后文（§2.3 起改用 $C$、$\mathbb D^*_C$）再未出现，疑为作者预留记号；照录。
3. **p.8 注 2.8**：单位球写作 `{f ∈ A : |f_0| ≤ 1} = A_0`，下标 `0` 疑为笔误（应作 `|f| ≤ 1`）。加译注 B，正文照原文排印。
4. **p.9 定义 2.9**：开集族写作 `{|f| ≤ |g| ≠ 0}`，语法上 `≠ 0` 作用于 `|g|`；照排。
5. **p.10 例 2.18**：`𝔹*_C = ⋃_{ε>0} 𝔸(ε,1)` 的下标为 `ε>0`（取遍正实数），而下文说「对 $ε ∈ |C|$」；原文两处未统一，照译。
6. **p.11**：`rad` 送 $x\mapsto|T(\tilde x)|$，其中 $\tilde x$ 原文未定义（页面上 $x$ 上确有波浪号），疑为笔误或指 $x$ 的某个代表元；译文照排 `|T(\tilde x)|`。
7. **p.11**：「这可以看作 $\mathbb A(r,r^{1/q})$ 模去经由 $\phi:\mathbb A(r,r)\cong\mathbb A(r^{1/q},r^{1/q})$ 对边界环带所作的等同」——原文只说 boundary annuli，未指明内、外边界各对应哪一端；照译，不补。
