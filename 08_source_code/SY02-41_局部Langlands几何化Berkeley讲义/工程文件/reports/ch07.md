## 三、疑点

1. **p32 注 7.5 语义可疑**：原文「This functor could have been defined on $\Perf_{\Fq}$. However later we'll see that we want to work geometrically for various reasons.」——函子本就定义在 $\Perf_{\Fq}$ 上，此句逻辑上近乎同义反复（疑原文想说 $\Perf_{\Fp}$，或「本可以只作为抽象函子定义」）。已照字面译出，未改。
2. **p33 证明中「objects over $\overline{\mathbf F}_p$」**：同页其余处一律用 $\Fq$，此处开图核为 $\overline{\mathbf F}_p$，照印。
3. **p33 英文残句**：原文「the formal group law was arranged to by $X \mapsto X^q$」显系漏词（应为 arranged to be given by）。译文按「形式群律被安排成 $X \mapsto X^q$」达意，未加译注。
4. **p35 警告 7.18 的下标**：原文 $H^0(X_{S,E},\mathcal O_{Y_{S,E}}(n))$——底空间取 $X_{S,E}$ 而线丛下标为 $Y_{S,E}$，疑应为 $\mathcal O_{X_{S,E}}(n)$。译文照印，未改。
5. **p36 命题 7.19 的 $\mathcal O_{X,S}$**：原文两处（陈述与后文）皆作 $\mathcal O_{X,S}$，按上下文应为 $\mathcal O_{X_{S,E}}$。已加译注（唯一一条译注，来源 A，§7.7 p.36）说明，正文照印。
6. **p36「untilt 只生活在 $\breve E$ 上」**：原文 "a general untilt, which only lives over $\breve E$"，指 §7.4 以来一律在 $\breve E$ 上工作，非新概念，译文按「只生活在 $\breve E$ 上」直译。
