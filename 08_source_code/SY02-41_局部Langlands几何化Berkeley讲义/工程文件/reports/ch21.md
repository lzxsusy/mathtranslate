## 疑点

1. **p113 的 $\mathrm{Par}_G$**：分子、分母分别为 $\widehat G(A)$ 与 $\widehat G$-共轭，左端下标却作 $G$，疑为 $\mathrm{Par}_{\widehat G}$ 之笔误。图版如此，照录并加 A 级译注。
2. **p113 的 $\varphi$**：原文作 $\varphi\colon W_E\to\widehat G\in H^1(W_E,\widehat G)$，箭头之后紧跟 $\in$，语义应为 $\varphi\in H^1(W_E,\widehat G)$。照录，未改。
3. **p113 的 $[\pi]$**：原文说 $\pi\in\Rep(G_{b_2}(E))$，却令 $[\pi]$ 为 $\Bun_G^{b_1}$ 上对应的层。只有把 $\widetilde{\mathcal M}_{b_2}^{b_1}\to\Bun_G^{b_1}$ 读成 $G_{b_2}(E)$-主丛才自洽；照录，待 lead 复核 $b_1/b_2$ 是否有笔误。
4. **p114 的多余右括号**：原文「$GL_2(E)\cdot\Delta BC(\mathcal O(1)))$」在正文与公式中各多一个右括号；译文用配平的括号，未复制此笔误。
5. **p115 的拼写**：原文「is denotd」应为 denoted，「transition maps maps」重复 maps；不影响译文。
6. **p116 的 $B_{\mathrm{dR}}$ 字体**：原文混用正体 $\mathrm B^+_{\mathrm{dR}}$、黑板的 $\mathbb B_{\mathrm{dR}}$ 与正体 $B_{\mathrm{dR}}$。译文按定义统一为 $B^+_{\mathrm{dR}}$ 与 $\mathbb B_{\mathrm{dR}}$（后者即 $B^+_{\mathrm{dR}}[1/\xi]$）。
7. **p115 与 p117 的上标**：p115 是 $(\Spa\breveE)^\circ$（小圆圈），p117 是 $(\Gr_G^{\mathrm{Witt}})^\diamond$（菱形）；已对图放大确认，未混用。
8. **p116 的 $\theta$**：图版箭头为双头（$\twoheadrightarrow$，下头较淡），文本层亦作双头，故用 $\twoheadrightarrow$。
9. **p116 与 p117 的伪一致化子记号**：p116 作 $[1/[\varpi]]$，p117 作 $[1/\pi]$；照录，未统一。
