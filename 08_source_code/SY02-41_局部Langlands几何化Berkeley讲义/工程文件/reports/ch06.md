## 三、疑点

1. **p29 定义 6.9 的谱映射方向**：原文作「$|X|\to|Y|$ 是谱映射」，按定义应为 $|Y|\to|X|$（开集的原像）。译文照原文方向，未改。
2. **p28 定义 6.6 的等价关系**：原文作 $R\subset X\times X$（无纤维积下标），译文照原文；同理 p23（第 5 讲）的 $R\subseteq\tilde X\times\tilde X$ 亦无下标。
3. **p30 定理 6.14 证明中的单数**：原文作「These are the same as map $T=\Spa(A^\flat,A^{\flat+})\to S$」，语法上应为 maps。译文按「这些等同于映射……」处理，未加注。
4. **p31 命题 6.17 无证明**：原文只给出陈述，页面其余部分空白。译文照原文，仅保留陈述。
5. **p27 函子图的箭头**：原文两列竖箭头均自下而上（完满空间 → 解析 adic 空间、完满空间/$\Fp$ → 菱形），下方 tilt 箭头自左向右。译文用 `\arrow[u]` 与 `\arrow[r, "倾斜"]` 复现。
6. **p28 例 6.8 的 $\Perf_S$**：原文记 $S=\Spa(C,\oo_C)$ 为几何基点，全忠实嵌入 $\mathrm{ProFinSet}\hookrightarrow\Perf_S$；译文保留 $\Perf_S$ 记号，未展开。
7. **p30 的「$\mathcal Y_{S,E}$」与「$\{\pi\neq 0\}$」**：原图右列只写开出集 $\{\pi\neq 0\}$，未重复母空间 $\Spa W_{\oo_E}(R^+)$；译文照原图。
