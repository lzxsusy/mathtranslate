## 三、疑点（照原文，未擅改）

1. **p.53 命题 10.15 的记号**：条目内写作 $(\Omega^2)^\diam:=\PP^1_E\setminus\PP^1(E)$，
   而同一页上文及 p.54 的注 10.16 均作 $(\PP^1_E)^\diam$。疑为原文笔误（$\Omega$ 与 $\PP$ 形近）。
   译文照原文保留 $(\Omega^2)^\diam$，未改。
2. **p.52 例 10.8 的手绘图**：原图标签为手写简写（形如「$\cO(-1/2)\oplus\cO(1)$」、
   「$\cO(-1)\oplus\cO(1/2)$」），按秩 3、次数 0 应为 $\cO(-1/2)^{\oplus2}\oplus\cO(1)$ 与
   $\cO(-1)\oplus\cO(1/2)^{\oplus2}$。译文重绘时按补全后的写法标注。
3. **p.49 证明中的复合**：$N\widehat\otimes_S(S\widehat\otimes_R K(x))$ 原文即括号套括号，
   照译。
4. **p.50「Question: can one also descend perfect complexes?」** 原文无编号。为不占用条目编号、
   保持 10.1–10.16 与原文一一对应，译文以「问题：……」的正文行处理，未用 `question` 环境。
5. **p.51 图**：原图 |Bun_2| 用红色波浪箭头（自左向右指向特化方向），译文改为红色直箭头并保留
   「特化」标注；|Bun_1| 图上下省略号照原图。
6. **p.54 证明**：原文「non-zero maps $E\to E^2\to C^2\twoheadrightarrow L$」中的 $C$ 未在文中定义
   （按上下文应指该几何点对应的完备代数闭域，即 untilt 的 $C$），译文照录 $C$。
