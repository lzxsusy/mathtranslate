## 三、疑点

1. **p.2 §1.1**：原文 `Let E be an non-archimedean local ﬁeld`，`an` 应为 `a`（语法笔误）。译文按文意作「设 $E$ 为非阿基米德局部域」，不着痕迹。
2. **p.2 例 1.4 标题**：原文 `Parabolic inducton`，`inducton` 为 `induction` 拼写笔误。译文标题只写中文「抛物诱导」，不复制错拼。
3. **p.2 例 1.5**：原文把整体域上的群对写成 `(G, E)`，与局部化对象 `(𝔾, 𝔼)` 用同一记号，字面上矛盾（自守形式空间里同时出现 `G(E)` 与 `𝔾(𝔸_E)`）。按文意后者应为 `(𝔾, 𝔼)`，已加译注 A（原文 p.2）说明；正文照原样排印。
4. **p.3 例 1.10**：原文自守诱导 `φ := Ind_{W_{E'}}^{W_E}(χ′)`，`Ind` 下标取来源群、上标取目标群，与 glossary 的「抛物诱导」共用同一 `Ind`。译文沿用 `\Ind_{W_{E'}}^{W_E}(\chi')`，未加改动。
5. **p.4 定理 1.14 / p.6**：`D(\Bun_G,\Ql)`「is some kind of amalgam of the Rep(G_b(E);Q̄_ℓ)'s」，`amalgam` 不是严格术语，译文作「是诸 $\Rep(G_b(E);\Ql)$ 的某种汇总」，保留原文的含糊。
6. **p.5 定理 1.14**：结论「$G-\mathrm{Isoc}^b \cong [\mathrm{pt}/G_b(E)]$」中 `b` 与 `G_b` 的对应依赖前文 Kottwitz 分类，原文未在本页重述，译文照原文不补。

**核对提示（给后续各讲）**：`L01.txt` 文本层会丢掉上划线——p4 的 $\overline{\mathbb{F}}_q$（`X_{\bar F_q}`、`π₁(X_{\bar F_q})`）与 p5/p6 的 $\overline{\mathbb{F}}_q$ 在文本层里都成了 `Fq`，照文本层落笔会少一条横线。本讲已按页面图逐处补成 `\overline{\mathbb{F}}_q`（7 处 + `X_{...}` 内 3 处）。同类风险：`⋊`（U+22CA，文本层保留，图上易看成 `×`）、`⊕`→`M`、`⊔`→`a`、`ﬁ` 连字。
