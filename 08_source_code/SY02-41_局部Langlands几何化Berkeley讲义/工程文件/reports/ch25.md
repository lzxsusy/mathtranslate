## 疑点

1. **p134 与 p135 的 $U$ 记号不同**：25.2.3 的公式是 $\psi_s\colon\Lie\hat U_{\check\alpha_s}\cong\ZZ$（$U$ 上为 hat、$\alpha$ 上为 check）；25.3 条目列表第 3 条却是 $\Lie\check U_{\check\alpha_s}\cong\ZZ/\ell^n\ZZ(1)$（$U$ 上为 caron）。已放大 p134/p135 图版逐一确认，两处照原文分别作 `\hat U` 与 `\check U`，未统一。
2. **hat 与 caron 的 OCR 混淆**：文本层把两种重音几乎都渲染成「ˇ」或「b」（如「bG」＝$\hat G$、「ˇG」＝$\check G$），本讲所有 $\check G$/$\hat G$ 均按页面图与上下文（几何构造 vs 抽象对偶）区分，沿用第 24 讲的约定（疑点 6）。
3. **p133 的 $\Div^1_X=(\Spa\breve E)^\diam/\varphi^{\ZZ}$**：分母为 $\varphi$ 的整数幂（Frobenius），OCR 作「φZ」，按图版照录为 `\varphi^{\ZZ}`。
4. **p133 的「Künneth 公式」**：原文带引号，表示这是非正式说法；译文保留引号与未译的 Künneth。
5. **p136 的两条定义式**：$\mathrm{Sat}_G(\ZZ_\ell):=\varprojlim_n\mathrm{Sat}_G(\ZZ/\ell^n\ZZ)$ 与 $\mathrm{Sat}_G(\Ql):=\mathrm{Sat}_G(\ZZ_\ell)[1/\ell]$ 按原文作行间公式，不编号。
6. **p137 的 breve 记号**：原文 $\breve{\ZZ}_\ell$、$\breve{\QQ}_\ell$（OCR 作「˘Zℓ」「˘Qℓ」），按图版作 `\breve{\ZZ}_\ell`、`\breve{\QQ}_\ell`，指 $W(\ol{\FF}_q)$ 及其分式域。
7. **25.7 的「同样的技巧」**：原文未明说是哪一步的技巧（指 25.4.3 秩 1 的论证），译文照原文含混，未加译注（本讲译注额度未用）。
8. **p136 的 $\check G\cong\check G_{\mathrm{ad}}\times_{\mu_2}\check Z$**：与上一行的 $\Gr_G=\Gr_{G_{\mathrm{ad}}}\times_{\ZZ/2\ZZ}\pi_1(G)$ 在纤维积下标上用 $\mu_2$ / $\ZZ/2\ZZ$ 交替，照原文，未统一。
