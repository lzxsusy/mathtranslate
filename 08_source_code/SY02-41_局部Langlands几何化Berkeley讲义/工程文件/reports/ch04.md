## 三、疑点

1. **p.18 §4.3 的拉回函子**：原文写作 $\mathrm{Isoc}_{\breve E}\to\{\varphi_C\text{-等变的向量丛}/Y_{C,E}\}$，下标为 $\breve E$；而全篇其余各处均为 $\Isoc_E$。照原文保留下标，未擅自统一，请 lead 裁定是否改为 $\Isoc_E$。
2. **p.20 推论 4.14 的句子**：原文作 `We normalization the identification so that O(1) ↦ 1`，语法有误（应为 `We normalize`）。译文按后者理解，并加译注 A 记录原文笔误。
3. **p.19 例 4.6**：原文称「由注 4.5，有 $H^1(X_{C,E},\mathcal O(-1))=C^\sharp/E$」，但注 4.5 只给出 $n<0$ 时 $H^1$ 为无穷维 $E$-向量空间，等式本身来自该短正合列的长正合列。原文如此，译文照译，未补论证。
4. **p.21 的 $E\subset\mathbb A^1_C$**：原文先说「函子 $H^1(X_{C,?},\mathcal O(-1))$ 应当是 $\mathbb A^1_C/E$」，再说「其中 $E\subset\mathbb A^1_C$ 通过 untilt 的选取被嵌入为一个闭子集」——此处的 $E$ 实指 untilt 的集合而非域 $E$ 的作用，原文用同一字母。译文照译，未加注。
5. **p.20 定理 4.8 的量词**：`for any vector bundle E on X, and all n ≫ 0` 中的 `n ≫ 0` 同时约束「整体生成」与「$H^1$ 消没」。译文照原文语序，未拆开。
6. **p.17 的 $y=V(\pi-[t])$**：$\pi$ 为 $\mathcal O_E$ 的一致化子，$[t]$ 为 Teichmüller 提升；原文未重复说明，译文照译（译注 1 已交代 $\varpi$ 与 $\pi$ 的分工）。
