## 疑点

1. **p84 节标题**：页面图作 $D_{\acute ET}(\Bun_G)$（下标 ÉT 大写），正文各页则作 $D_{\acute et}$（小写）。任务指定按「ét($\Bun_G$)」写节标题，故首行取 `$\et(\Bun_G)$`（与 s20 的 `$\et(\Bun_G,\Lam)$` 体例一致），正文一律 $D_{\et}$；若要与 p84 图完全一致，可改首行为 `$D_{\acute ET}(\Bun_G)$`。
2. **底域的 $\ol{\Fq}$**：文本层作 `Fq`，页面图有上划线（p84 的 $\Perf_{\ol{\Fq}}$、p85 的 $X/\ol{\Fq}$ 与 $\Spa\ol{\Fq}$、p86 的 $C/\ol{\Fq}$ 与 $\Bun_G\times_{\ol{\Fq}}\Spa C$）；一律按图取 $\ol{\Fq}$。
3. **p88 系数公式**：$D_{\et}(*,\ZZ/\ell^n\ZZ)=\varprojlim_n D(\ZZ/\ell^n\ZZ)$ 左端按字面与右端不相容（对 $*$ 应有 $D_{\et}(*,\ZZ/\ell^n\ZZ)\cong D(\ZZ/\ell^n\ZZ)$），据上下文及下一式疑应为 $D_{\et}(*,\ZZ_\ell)$；已加译注（原文笔误）并照原文排出。
4. **p86 第 2 步三角形图**：左下 $[*/G_b(E)]$ 到顶端 $[*/G_b(E)]$ 的斜箭头原文为双线；译文用 `Rightarrow` 表示，含义（分裂的两条路径 / 恒等 2-态射）原文未说明。
5. **p86 半正交分解图**：曲线的逆向箭头原文无标签，译文亦未标；正文作 $i^b_!$、$(i^b)^*$，图中直线箭头标签为 $i_*$、$j_!$，与原书不完全统一（原文如此）。
6. **p87「The Theorem is a best replacement」**：原文未指明哪个定理，译文作「上述定理是最好的替代」。
7. **p84 定理 16.1 的 $G_b$ 与 $G_b(E)$**：$\Bun^b_G=[*/G_b]$ 中的 $G_b$ 是局部 pro-$p$ 群，$G_b(E)$ 是其 $E$-点；正文照原文区分，未统一。
8. **p86 推论 16.6 的「infinite semi-orthogonal decomposition」**：译「无限半正交分解」，与术语表 125 的「半正交分解」一致；「无限」指指标集为无限多个 $b$。
9. **p87 的方括号**：ULA 定义中 `[with respect to the map $\Bun_G\to*$]` 的方括号保留（原文为补充说明），脚注 37 照译。
