# 资料卡 02 · 论证地图

本书是综述，不追求把每件事都证明，而是把「范畴表示论」这条技术路线从玩具模型一路铺到局部几何朗兰兹的猜想与六条性质。下面按六条构造链（D1–D6）给出依赖关系；每条链注明它在原文中的位置、关键命题与「读者可以跳过的台阶」。

```
D1 玩具模型（群代数 = 卷积代数）§2
        │  把「表示 = 模」翻译成「作用 = 范畴作用」
        ▼
D2 Beilinson–Bernstein 局部化 §3 ──────────────┐
        │  旗流形上的 D-模 ≃ 中心特征为零的 g-模    │  等变性版本 §3.3
        │  隐藏对称性：D-mod(G)-作用 §3.4           │
        ▼                                          │
D3 范畴化：群的范畴表示 §4  ◄──────────────────────┘
   dg 范畴 → 不变量/余不变量 → 特征标层 → 生成定理
        │  (C^K, C_K, Beraldo–Gaitsgory, χ_C, D(K) 由 k-mod 生成)
        ▼
D4 环路群与 D-mod(LG) §5
        │  平缓归纳概形、两套对偶、中心扩张
        ▼

   (6.1) D-mod(LG)-mod ≃ 2-QCoh(LocSys)   ──性质 I–V 的逐项检验
        │
        ▼

```

## D1 玩具模型：把「表示」换成「作用」（§2）

**目的**：在有限群的层次上，把「$H$ 的表示」重写成「$\Fun(H)$ 这个代数在一个范畴上的作用」，从而让同一套语言在 $H$ 换成环路群 $LG$ 时仍然成立（$H$ 有限时 $\Fun(H)$ 是有限的代数，$LG$ 时 $\Dmod(LG)$ 是无界的 dg 范畴）。

- 关键一步：$H$ 的表示 $\leftrightarrow$ $\Fun(H)$-模（$\Fun(H)$ 用卷积作乘法）；更一般地，$k$-代数 $A$ 的模 $\leftrightarrow$ 半群映射 $H\to A$ 的延拓（§2.2，公式 (2.1)–(2.3)）。
- 第二块砖：$\Fun(X)$ 的自我对偶与积分变换，使「$H$ 在集合 $X$ 上的作用」给出 $\Fun(X)$ 上的模结构，其自同态代数是 $\Fun(X\times X/H)$（§2.3.3–2.3.4）。
- 第三块砖：幂幺主系列 $\Fun(G(\Fq))\otimes\Fun(\Fl_G(\Fq))\to\Fun(\Fl_G(\Fq))$ 与 Hecke 代数 $\Fun(\Fl_G\times\Fl_G/G)$（§2.3.5–2.3.6）。
- **读者可跳过**：例 2.3.8（$G=\GL_2$ 的显式计算）只看结论即可。

## D2 Beilinson–Bernstein 局部化：几何侧与代数侧的第一座桥（§3）

**目的**：把「$G$ 的旗流形上的 D-模」与「$\fg$ 的中心特征为零的模」等同起来。这是全书的技术心脏：它在 §6 被整体地「范畴化」到环路群。

- **主定理（定理 3.2.10）**：$\Gamma:\Dmod(\Fl_G)\to\fg\text{-}\mod_0$ 是 $t$-正合的等价。证明策略：先在 $\fg=\mathfrak{gl}_2$ 上显式验证（例 3.2.8），再用三个基本对应（例 3.2.14–3.2.16）说明 $\Gamma$ 把代数侧的中心商、结构层、$\delta_x$ 分别送到对应的模与点。
- **等变性（§3.3，定理 3.3.13）**：把 $G$-等变结构加进来，得到 Harish-Chandra 模范畴 $(\fg,K)\text{-}\mod$ 与 $\Dmod(\Fl_G)^{K}$ 的等价。技术难点：导出范畴层面不能直接取阿贝尔范畴的不变量（注 3.3.15），必须用等变 D-模。
- **隐藏对称性（§3.4，定理 3.4.10、3.4.12，Beilinson–Drinfeld）**：$\Dmod(X)$ 上除了 $\fg$ 的作用之外，还有 $\Dmod(K)$ 的（弱）作用。这条「多余」的对称性，正是把 $\fg$-模的表示论「范畴化」为 $K$ 的范畴表示的入口——局部化函子 $\on{Loc}$ 与整体截面 $\Gamma$ 都与 $\Dmod(K)$ 的作用相容。
- **依赖**：D2 的结论被 D3 当作「已会算的例子」，被 D6 当作「非临界水平的模型」。

## D3 范畴化：把「代数」换成「dg 范畴」（§4）

**目的**：把 D1 的「表示 = 模」升格为「表示 = 范畴作用」。这是「范畴表示论」一词的由来。

- 第一步（§4.2）：说清楚在哪个世界里工作——余完备 dg 范畴及其 Lurie 张量积、内 Hom、幺半结构。**这一节是全书的技术门槛**，读者若只关心结论，可先接受「$\Dmod(K)$ 是幺半 dg 范畴，故可以『作用』在别的 dg 范畴上」。
- 第二步（§4.3）：定义不变量 $\sC^K=\Hom_{\Dmod(K)\mod}(\Vect,\sC)$ 与余不变量 $\sC_K=\Vect\otimes_{\Dmod(K)}\sC$，证明 $\on{Oblv}\dashv\on{Av}_*$，并陈述 Beraldo–Gaitsgory「余不变量 $\to$ 不变量是等价」。四个基本例子（例 4.3.4–4.3.7）说明这套语言确实把 Harish-Chandra 模、等变 D-模、$\fg\mod$ 都收了进来。
- 第三步（§4.4）：特征标层 $\chi_\sC$——把「表示的迹」从元素层面提升到范畴层面，用矩阵系数函子 $\Hom_{\Dmod(K)}(\sC,\sC)\to\Dmod(K/K)$ 实现。五个例子（例 4.4.10–4.4.13）里最重要的是 $\sC=\Dmod(\Fl_G)$ 给出 Grothendieck–Springer 层与 Harish-Chandra 变换。
- 第四步（§4.5）：生成定理——$\Dmod(K)$ 由 $\fk\mod$ 生成（Beraldo），由此 $\Dmod(K)\mod\simeq(\fk\oplus\fk\mod^K)\mod$，把「范畴表示」压回「Harish-Chandra 双模」。这条定理在 §6.8–§6.9 反复被用到。

## D4 环路群：把 $G$ 换成 $G(\!(t)\!)$（§5）

**目的**：把 D3 的框架从有限维群搬到环路群 $LG$，这是局部几何朗兰兹的自守侧。

- $LG$ 是归纳概形，不是概形；$\Dmod(LG)$ 只能定义为对紧开子群 $K$ 的余极限（公式 (5.2)），沿 $*$-拉回。
- 两套对偶版本（注 5.3.3）：$*$-推前与 $!$-拉回各给一套 D-模范畴，$\Dmod(LG)$ 的构造选了前者；平凡化维数主丛后两者可等同。
- 中心扩张：$\widehat{\fg}_\kappa\mod$ 带 $\Dmod(LG)$ 作用（例 5.3.6），这是 §6.7 的 Kac–Moody 侧的入口。

## D5 猜想与六条性质的检验（§6.1–§6.7）

**主猜想（(6.1)）**：$\Dmod(LG)\mod\simeq 2\QCoh(\LS)$，其中 $\LS=\on{LocSys}_{\check G}$ 是 $\check G$-局部系统的模空间。**正确读法**是「对象层面 Hom 的等价 + 与复合相容」，不是底层 dg 范畴的等价（注 6.2.4 的 Morita 玩具模型解释了为什么）。

原文的组织方式是「逐条性质检验」：

| 性质 | 内容 | 位置 |
|---|---|---|
| I | 四组对应的总表（表 1） | §6.3 |
| II | 非分歧情形退回经典 Satake | §6.4 |
| III | 非分歧主系列与 Springer 消解 | §6.5 |
| IV | Whittaker 模型 | §6.6 |
| V | Kac–Moody 表示与 opers | §6.7 |

每条性质的检验都给出一个**已被证明的等价**（如 FGV 球–Whittaker、Frenkel–Gaitsgory 的球 Kac–Moody），或一个**明确的猜想**（如仿射 Skryabin 的 $W$-代数版本）。这是本书最实用的部分：读者可以按表逐格核对「哪一格已知、哪一格是猜想」。

## D6 缠绕算子、局部化与变体（§6.8–§6.10、附录 A）

- **两张 5×5 表（§6.8，表 2、表 3）**：把自守侧与谱侧的「缠绕算子」逐格配对。表的对角线是六个已知/未知的等价，非对角线的格子则是「应当存在但尚未构造」的函子。原文明确标注了哪些已证（导出 Satake、球–Whittaker、Bezrukavnikov、Arkhipov–Bezukravnikov）、哪些是猜想（Temp 猜想、Iwahori–Whittaker 与临界水平 Kac–Moody）。
- **局部化理论（§6.9）**：把 D2 的局部化升格到临界水平。核心障碍是 $\fgk\mod$ 在临界水平太大，必须重整化为 $\fgk\mod\otimes_{\QCoh(\Op)}\Vect$（§6.9.3–6.9.4），其几何解释是 $\op\to\LS$ 形式光滑。有了它，才能把 Hecke 特征层的作用与 Satake 层的作用对齐（§6.9.6）。
- **变体（§6.10）**：拟分裂群（含扭环路群）、量子局部几何朗兰兹（$\kappa$ 与 $\check\kappa$ 互换）、与四维 $\mathcal N=4$ 超对称规范理论的联系、受限变化的 étale 版本、Betti 版本。每条变体都给出相应的范畴等价陈述（公式 (6.34)、(6.35)）。
- **附录 A** 不是可跳过的技术附录，而是全书的「底层实现」：它解释为什么 $X(\Fq)$ 上的函数与 $X(\CC)$ 上的 D-模应当被视为同一件事的两个面向（函数–层对应），以及 Riemann–Hilbert 对应如何把「正则完整 D-模」翻译成「构造层」。§6 中所有「$\Dmod$ 侧对应 $\QCoh$ 侧」的断言，最终都要靠这里的词典来读。

## 三条主线（一句话版）

1. **代数 → 范畴**：表示论的对象从「向量空间 + 代数作用」升格为「dg 范畴 + 幺半范畴作用」（D1 → D3）。
2. **群 → 环路群**：$G$ 换成 $G(\!(t)\!)$ 时，旗流形换成仿射 Grassmann 簇、$\fg$-模换成 $\hat\fg_\kappa$-模、$\Rep(\check G)$ 换成 $\QCoh(\LS)$ 或 $\QCoh(\Op)$（D2 → D4 → D5）。
3. **定理 → 猜想**：每一步「已知」都在某个方向留下一个「猜想」，书里用两张表和六条性质把已知与猜想的边界画得很清楚（D5 → D6）。
