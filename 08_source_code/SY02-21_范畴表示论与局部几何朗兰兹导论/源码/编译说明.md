## 编号体制

原文用 `amsart`，定理类环境一律挂在 `subsubsection` 计数器上，公式用
`\numberwithin{equation}{section}`。译文用 `ctexart`，通过 `\newtheorem{theo}[subsubsection]`
等复现同一套编号：定理、命题、引理、推论、猜想、定义、注、例共用三位编号（如 3.2.10），
公式按节编号（如 (2.1)）。段首编号由 `\ssszh` 产生（run-in，编号不加粗），步进同一个
`subsubsection` 计数器。

## 与原文字体排式的对应

| 原文 | 译文 |
| --- | --- |
| `\section` 居中、小型大写 | `\ctexset{section=...\centering}`，粗体 |
| `\subsection`「2.1. Overview.」独立一行加粗 | 同（`format=\large\bfseries`，`aftername={.\enspace}`） |
| `\subsubsection{}`「2.1.1.」段首编号、不加粗 | `\ssszh` |
| `Theorem 3.2.10.`（粗体题头 + 斜体正文） | `zhthm` 定理样式，`定理 3.2.10.` |
| `Appendix A.` | `\zhappendix`（`\Alph{section}` + 前缀 `Appendix`） |
| 作者脚注 | 普通脚注，编号保号 |
| 译者所加注释 | `manyfoot` 另立序列，印作「译1」「译2」 |

## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Missing character: There is no 拉` | 数学模式或 `\xymatrix` 单元里直接写了中文 | 包进 `\text{…}` |
| `No shape named` | 空单元格，或 tikz-cd 单元格留空 | 交换图用 xy-pic，不留空单元 |
| `Command \mod already defined` | 原文宏与 amsmath 重名 | `\renewcommand{\mod}` |
| 编译报 `Undefined color 'blue!55!black'` | 未载入 xcolor（hyperref 只带 color） | 在 hyperref 之前 `\usepackage{xcolor}` |
| 定理号比原文小 | 用了 `\textbf` 手写编号 | 用 `\ssszh`，它会步进 `subsubsection` |
