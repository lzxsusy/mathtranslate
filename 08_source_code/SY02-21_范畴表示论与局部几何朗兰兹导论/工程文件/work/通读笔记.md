## 1. Introduction（339–496）
- 两条主线：群的范畴作用（categorical actions）与局部几何朗兰兹对应；二十年来 Beilinson、Drinfeld、Frenkel、Gaitsgory，近有 Beraldo、Raskin、Yang。
- 范畴作用是处理约化李代数表示的趁手框架，也是全书入口；局部几何朗兰兹的形式体系对仿射李代数与顶点代数表示论不可或缺（解决旧猜想、生出新猜想），在后半部登场。
- 作者自述取向：重类比、动机、历史前身，不追求完全严格；假定读者有李群李代数、代数几何、同调代数入门知识，不假定 D-模、反常层、高阶代数、导出/无限维代数几何。
- 组织：§2 有限群表示论（为范畴对应物铺垫）→ §3 BB 局部化与「隐藏对称性」→ §4 有限维代数群的范畴作用（含 dg-范畴工具箱）→ §5 环路群 → §6 局部几何朗兰兹与临界水平仿射 BB 局部化 → 附录 A（D-模、Riemann–Hilbert、函数-层对应）。

## 2. 群代数与卷积代数（497–862）
- 2.1 Overview：$\mathbb{F}_q$、局部域、实数上复数表示论之间的类比（Harish-Chandra 称之为表示论的 Lefschetz 原理）；范畴层面的原理：$G(\mathbb{C})$ 的范畴表示论应像 $G(\mathbb{F}_q)$ 的（一部分）复表示论，$G(\mathbb{C}(\!(t)\!))$ 的范畴表示论应像 $G(\mathbb{F}_q(\!(t)\!))$ 的。
- 2.2 The group algebra via convolution：有限 $H$-集 $X$ 上 $\Fun(X)$ 的自对偶（对角 $\Delta$、投影 $\pi$ 的 $(\Delta^!,\pi_*)$ 配对，即 $L^2$ 内积）；$\Hom_{\Rep(H)^\heartsuit}(\Fun(X),\Fun(Y))\simeq \Fun(X\times Y)^H$，积分变换（核 $K$）；$X=H$ 给出群代数 $k[H]$ 的卷积；$H$ 在 $X$ 上的作用给出 $\Fun(X)$ 的 $k[H]$-模结构。Remark 2.2.x：上标强调取阿贝尔范畴（有心结构）。
- 2.3 The principal series representation：$G(\mathbb{F}_q)$ 作用于 $\Fl_G(\mathbb{F}_q)$，得到无幂零主系列模 $\Fun(G(\mathbb{F}_q))\otimes_{\Fun(\Fl_G)}\Fun(\Fl_G)$；$\Fl_G(\mathbb{F}_q)\simeq G(\mathbb{F}_q)/B(\mathbb{F}_q)$，$(\Fl_G\times\Fl_G)/G\simeq B\backslash G/B$，卷积代数即 Hecke 代数 $\Fun(B(\mathbb{F}_q)\backslash G(\mathbb{F}_q)/B(\mathbb{F}_q))$；例：$\SL_2$ 的手算（$\mathbb{P}^1$、两轨道、Hecke 算子 $T$、$T^2=qT+(q+1)$ 一类关系）。

## 3. BB 局部化与隐藏对称性（863–2231）
- 3.1 Overview：$\Fun(\Fl_G(\mathbb{F}_q))$ 换成 $\Dmod(\Fl_G(\mathbb{C}))$；BB 给出 $\Dmod(\Fl_G)$ 与 $\fg\mod_0$（平凡中心特征的 $U\fg$-模）的等价；追问其对称性，得到群的范畴作用。
- 3.2 The Localization Theorem：$\fg=\mathfrak{sl}_2$ 显式算例（$\Dmod(\mathbb{P}^1)$ 的导出范畴、$t$-结构、Veronese 商）；Theorem 3.2.10（BB）：整体截面 $\Gamma(\Fl_G,-):\Dmod(\Fl_G)\to\fg\mod_0$ 是 $t$-正合等价；中心特征 $\chi$ 的一般化（$\fg\mod_\chi$、$\Dmod(\Fl_G)_\chi$）；Remark：只做平凡中心特征的来龙去脉；例：微分算子环与包络代数的中心商、结构层与平凡表示、点上的 $\delta$-模与 Borel 稳定化（Baby Verma / 最高权）。
- 3.3 Equivariance and Harish-Chandra modules：$H$-等变 D-模、$(\fg,H)$-模（Harish-Chandra 模）、导出等变（栈 $X/H$、$H$ 不必连通时的额外结构）、Theorem 3.3.13（BB）：$\Dmod(\Fl_G)^{H,\heartsuit}\simeq(\fg,H)\mod_0^\heartsuit$ 的交换图，及其导出版本；Remark：导出范畴必要性的「取正确的答案」；例：单轨道、有限轨道、$\delta$-模。
- 3.4 Hidden Symmetries：$\Dmod(K)$ 的卷积幺半结构（$K$ 代数群），$\Dmod(K)$-模范畴即 $K$ 的范畴表示；$\Dmod(K)\otimes\Dmod(K)\simeq\Dmod(K\times K)$、卷积 $*$ 与作用；命题：$\Dmod(K)\mod\simeq \DGCat$ 上的 $K$-作用；Theorem 3.4.10（Beilinson–Drinfeld）：$\on{Loc}:\fk\mod\rightleftarrows\Dmod(X):\Gamma$ 的伴随对（$\Dmod(K)$-等变）；Theorem 3.4.12：$H$-不变版本，$\Dmod(H\backslash K/H)$-等变伴随；推论：BB 局部化是 $\Dmod(G)$-表示的等价。

## 4. 群的范畴表示（2232–3603）
- 4.1 Overview：形式体系本于 Beilinson–Drinfeld、Frenkel–Gaitsgory，$\DGCat$ 与交错函子的形式化主要归 Gaitsgory；需要现代同调代数的细节。
- 4.2 From triangulated to dg-categories：三角范畴的缺陷（无函子范畴、无好商）；dg-范畴、$\DGCat$（连续函子、余完备、可表现）；张量积、紧对象、对偶性；例：$\Vect$、$\QCoh$、$\Dmod$、$A\mod$、$\Dmod(X)\otimes\Dmod(Y)\simeq\Dmod(X\times Y)$、$Y$ 是代数对象时的卷积幺半结构、模。
- 4.3 Basics of categorical representation theory：$K$-作用、$K$-等变函子、$\Dmod(K)\mod$、不变量（$\Hom_{\Dmod(K)\mod}(\sC,\sD)\simeq\udHom(\sC,\sD)^K$）、$\Dmod(X)^K\simeq\Dmod(X/K)$；Remark：不变量操作不幂等（与通常表示论的分水岭）。
- 4.4 Complements I - character sheaves：对偶性（紧生成 ⇒ 可对偶化；$\Dmod(X)$ 经 Verdier 对偶自对偶）、特征标层 $\och(\sC)$ 的定义与函子性（需连续右伴随）、例（$K$-簇的稳定化子、约化群的 Grothendieck–Springer 层）、与通常特征标的关系；Remark：解析/étale 层版本。
- 4.5 Complements II: generation：Harish-Chandra 双模与 $(\Dmod(K)\mod)_{\sC}$ 的同一、生成性定理（$K$-作用的生成元）、$H\backslash K/H$ 版本。

## 5. 环路群的范畴表示（3604–3901）
- 5.1 Overview：从约化群过渡到环路群，故事更丰富，是局部几何朗兰兹的舞台。
- 5.2 Loop groups：$LG$ 作为 ind-概形（$L^+G$-轨道、$\Gr_G$、$\Fl_G$）；仿射 Grassmann 簇与仿射旗簇；ind-概形的 D-模（$\Dmod(LG):=\colim \Dmod(L^iG)$，$L^+G$-等变/不变量）；例：加法群 $\mathbb{G}_a(\!(t)\!)$ 的显式构造；函子点描述；术语约定（$p$-adic 群）。
- 5.3 D-modules on loop groups and categorical actions：$\Dmod(LG)$ 的卷积幺半结构（用 $\Dmod(L^+G\backslash LG/L^+G)$、$\Dmod(L^+G\backslash LG)$ 的幺半结构）；$LG$ 在 $\Dmod(\Gr_G)$ 等上的作用；中心扩张 $\widetilde{LG}$ 与 $\psi$-等变（Whittaker）版本；例：placid ind-概形上的作用。

## 6. 局部几何朗兰兹与仿射 BB 局部化（3902–6905）
- 6.1 Overview：本节的猜想把环路群的范畴表示参数化；末尾回到环路群的 BB 局部化（Beilinson–Drinfeld、Frenkel–Gaitsgory、Raskin–Yang）。
- 6.2 A naive formulation：朴素陈述 $\Dmod(LG)\mod\simeq \QCoh(\LS)$（后用 IndCoh 与奇异支撑修正）；Morita 等价作玩具模型；$\TwoCoh$ / $\TwoIC$；$\LS$、$\Op$；函子 $f^*$ 与 $(\TwoIC,\otimes)$ 的幺半结构。
- 6.3 Properties I：（谱侧）$\Op$、$\LS$ 的几何；（自守侧）$\Dmod(\Gr_G)$、$\Dmod(\Fl_G)$、$\Dmod(LG/LN,\psi)$、$\fg_\kappa\mod$ 的对照表；Hecke 函子的交换性；$T$/$S$ 对偶。
- 6.4 Properties II: unramified representations：非分歧表示的参数化：$\Dmod(\Gr_G)$ 的 Hecke 作用、球 Hecke 代数、$\Rep(\cG)$ 的作用、$\QCoh(\on{pt}/\cG)$。
- 6.5 Properties III: unramified principal series：抛物诱导、$\Dmod(\Fl_G)$、$\QCoh(\widetilde{\sN}/\cG)$、Springer 层、中心特征、$\Op$ 的局部化；Remark（技术注记：$\Op$ 作为代数几何对象的未知性、形式化处理）。
- 6.6 Properties IV: Whittaker models：Whittaker 范畴 $\Whit$ = $(LN,\psi)$-等变 D-模；指数 D-模；与 $\fg_{-\kappa_c}\mod$ 的关系；半无限；tempered 与 Whittaker 模型；$\IW$（归纳 Whittaker 范畴）。
- 6.7 Properties V: Kac–Moody representations：$\fg_\kappa\mod$ 的范畴作用、临界水平 $\kappa_c$、Feigin–Frenkel、真空模、半无限上同调、$\Pos_\kappa$、$\Op$ 的量子化、W-代数。
- 6.8 Intertwining operators：$\TwoIC$、奇异支撑、拟光滑、导出 Satake 的谱侧、半无限交换图、Whittaker 与 Kac–Moody 的交错算子、深度滤过、Moy–Prasad。
- 6.9 Localization theory：仿射 BB 局部化、$\Dmod(\Fl_G)$ 的修正（IndCoh 与奇异支撑）、Hecke 特征层、Kazhdan–Lusztig 型猜想、$\fg_{\kappa_c}\mod$ 上的作用。
- 6.10 Siblings：拟分裂群、量子局部几何朗兰兹（Feigin–Frenkel 同构）、与物理的联系（3d/4d 超对称规范理论）、限制变差的局部几何朗兰兹、局部 Betti 几何朗兰兹。

## 附录 A（6906–7930）
- A.1 Overview：为什么从 $\Fun(X(\mathbb{F}_q))$ 到 $\Dmod(X(\mathbb{C}))$ 是自然的，三个主题：D-模、函数-层对应、Riemann–Hilbert 对应。
- A.2 Algebraic D-modules：$\sD_X$、$\Dmod(X)$、联络、de Rham 复形、$\delta$-模、行列式线 $\Omega_X$ 的介入、全局 $\sD_X$ 与拟凝聚 $\sD$-模、$\Dmod(X)$ 与函子 $f_*,f^!,f_!,\boxtimes$。
- A.3 The functions-sheaves correspondence：Grothendieck 层-函数字典：紧支撑层↔带紧支撑的函数、$*$-拉回/推、$\mathbb{F}_\ell$ 与 $\mathbb{C}$ 的类比、$\ell$-进与复拓扑；$\delta$-函数、常函数 1 与对偶层。
- A.4 The Riemann–Hilbert correspondence：正则完整 D-模 ↔ 构造层；Betti $D$-模；例（$\mathbb{G}_m$、$\mathbb{A}^1\to\mathbb{P}^1$、指数 D-模、$\OO\mapsto \mathbb{C}_X[d_X]$）。
