# 报告 02 · 正文分块与九批提交

## 1. 分块原则

- 按原文小节切，不按页切：一块 = 一个或两个小节（80–150 行原文），保证块内可独立编译、独立核对编号。
- 块与块的分界尽量落在 `\subsection` / `\subsubsection` 之前，避免把一条 `\ssszh` 段落切成两半。
- 每块的目标是「译完即可编译、可目视、可对数」，而不是「攒够页数再编译」。

## 3. 每批的固定动作

1. 读原文（`sed -n 'A,Bp'` 取行，或直接读 `samplez.tex` 片段）。
2. 译写 `源码/chunks/chNN.tex`，`\label` key 原样保留。
3. 编译两遍，过滤日志：`^!`、`^l.`、`Missing character`、`Overfull \hbox`。
4. 渲染该批起止页目视（`render.py`），检查：段首编号不加粗、定理题头、公式编号、表格宽度、页眉页码。
5. 用 pymupdf 抽取译本 PDF，核对本块编号序列与原文一致。
6. `git add` 本工程目录（+ 首次的 `RELEASE_REGISTER.csv`），commit，双远端 push。
