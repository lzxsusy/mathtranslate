# 局部同调镜像对称（中文译注本）

> Local Homological Mirror Symmetry — Si-Yang Liu, Kyungmin Rho
> arXiv:2611.07202v1 [math.SG] (2026-11-04)，原文 56 页
> 中译注本：82 页，含导读、术语表、页码对照表、译注索引、原文勘误表

## 这是什么

这是把一篇 2026 年 11 月出现在 arXiv 上的辛几何/镜像对称论文完整译成中文的**译注本**。与通常的「逐句翻译」不同，本译本做了三件事：

1. **翻译全文**（正文 + 附录 A，共 56 页原文），定理、公式、图表、编号全部与原书一致，可与原文逐页对照；
2. **加了 59 条译注**（橙色框，编号 1–59）：只写三类内容——容易读错的地方、原文含糊之处的点拨、必要的背景直觉；
3. **加了 25 个概念回顾**（紫色框）：对 HMS、映射柱、停止位、扇形下降、反常 Schober、扭 Künneth 公式等 20 余个概念各写一段「这是什么、在这篇文章里扮演什么角色」的小结，并给出 nLab 条目或文献出处。

另有 8 处「本节重点」（蓝色框）帮助回顾每章要点，一篇 4 页的**译者导读**先把全文的「故事」讲一遍。

## 版式说明

- **橙色「译注 N」框**：译者所加。想读「原汁原味」的读者可以忽略它们，正文不会被截断。
- **紫色「概念回顾」框**：译者所加，帮助没有相关背景的读者快速进入。
- **蓝色「本节重点」框**：每章末尾的要点回顾。
- 每页起始处有 `[原文 p.N]` 注释（在源码里，不显示在纸面上），配合附录 C 的页码对照表定位原文。
- 定理类环境（定理、定义、引理、命题、推论、问题、注记、例）**共享一个计数器、按节编号**，与原书完全一致；引用原文时用「定理 1.4」这样的编号即可直接对上。

## 阅读建议

只想了解这篇文章在做什么：读 `阅读参考指南.md` 第一节与书里的**译者导读**即可。
想读证明：按 §1 → §2 → §4 → §5 → §6 → 附录 A 的顺序，遇到概念卡住时查紫色框，遇到公式卡住时查对应译注。
想核对原文：用附录 C 的页码表 + 每节的 `[原文 p.N]` 注。

## 关于准确性

- 术语按项目冻结词表统一（见附录 B），例如 wrapped Fukaya category＝包裹 Fukaya 范畴、sector＝扇形、stop＝停止位、proper descent＝真下降。
- 概念框中的 nLab 条目与文献出处经检索核对；但**译注与导读是译者的一家之言**，不构成原文的一部分。
- 原文的笔误、记号不一致与存疑之处集中在附录 E，译文一律照原文排印，未擅自改动数学内容。
- 这是 AI 辅助完成的译本；数学内容建议与原文对照阅读，发现疑点请以原文为准并反馈。
