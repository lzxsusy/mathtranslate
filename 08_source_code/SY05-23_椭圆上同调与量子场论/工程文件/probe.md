## 二、看公式的正确姿势

文字层里的公式会散架（分式、上下标、花体、矩阵全乱）。凡是编号公式、凡是看不懂的符号，一律裁页面图来看：

```
cd 工程文件
python crop.py 16 0.30 0.55 d16_mid.png          # 第 16 页，纵向 30%–55%
python crop.py 16 0.10 0.85 0.30 0.65 d16_eq.png # 矩形区域
python crop.py 16 0.30 0.55 d16_mid.png --dpi 600
```

生成的 PNG 用 `read_image` 工具看（不是 `read`）。文件名建议带页号，避免覆盖。

## 四、已知坑

- PowerShell/控制台：跑 Python 前先 `$env:PYTHONIOENCODING='utf-8'`，否则中文报错乱码。
- 不要 `Get-Content` 判断中文内容，用 `read` 工具。
- 文字层里的 `fi`/`fl` 连字、`−`（U+2212）、`′` 等符号会在正文里出现，别抄进 .tex；.tex 里只用 ASCII 数学。
- 原 PDF 是 dvips/ps2pdf 老排版，部分页文字层顺序错乱；遇到明显跳行，以页面图为准。
