## c01 §1 引言（原文 p1–5，另含 p6 上半 §1.4–§1.5）

1. （原文 p.1）式 (1) 中“拓扑指标”那条箭头在原文画作实线，另两条为虚线，而正文统称 "dashed arrows"；照译。实线表示 string 定向这一已知映射，虚线才是待构造的部分。
2. （原文 p.1）式 (1) 的箭头标签是 $\mathrm{cocycle}_{-n}$（下标带负号），而紧邻的正文写作 cocycle$_n$；二者不矛盾：三角形针对 degree $-n$ 的场论，故下标随度数变号。
3. （原文 p.1）原文 p1 底部另有一条不编号的注（作者单位与 NSF 资助 DMS-2205835、DMS-2340239），译本把它移入封面，以保持正文脚注编号与原文一致（本块即原文脚注 1、2）。
4. （原文 p.2）原文 p2 写作 "Borcherd's proof"，应为 "Borcherds' proof"（Richard Borcherds，1992 年证明 monstrous moonshine）；按“笔误照排”处理，已登记 ERRATA。
5. （原文 p.2）原文 p2 写 "has lead to"，应为 "has led to"；中文无形态变化，照译，已登记 ERRATA。
6. （原文 p.2）“等变的 $\TMF\otimes\C$” 指复化（complexification），而非给 TMF 增加新的张量结构；原文以 “roughly” 限定。
7. （原文 p.2）concordance 是场论之间的一种等价关系（沿超区间族的同伦），比猜想 1.1 的“存在上闭链”强得多；本译保留原文 concordance 并附中文“协调类”。
8. （原文 p.3）式 (2) 的源范畴用不交并 $\bigsqcup$ 作幺半结构、目标用张量积 $\otimes$；这正是“配边→向量空间”的函子成为对称幺半函子的条件。
9. （原文 p.3）例 1.3 中刚性几何定义在 $\R^d$ 上，而等距群却写作作用在 $\R^n$ 上；原文如此（沿用 ST11 的记法，$n$ 记环境维数），此处应读作 $n=d$，照排不改。
10. （原文 p.4）定义 1.5 中的 $\mathbf 1$ 是取值为 $\Alg$ 幺半单位的常值函子，不是数字 1；式 (3) 中 $E$ 是自然变换 $\mathbf 1\Rightarrow\alpha$，2-胞的上下两条 1-态射分别是 $\mathbf 1$ 与 $\alpha$。

12. （原文 p.4）反射正性的等变数据含两处对合：配边上的定向反转、$\Alg$ 上由复共轭诱导的对合；二者作用后 Hermite 配对须为正定内积。
13. （原文 p.5）原文此处写 "Specializing to a smooth manifold X = X"，其中前一个 X 实为栈 $\cX$；原文记号混用，照译作 $\cX=X$。
14. （原文 p.5）原文 "and (at present) it unclear which one to take" 缺系动词，应为 "it is unclear"；照译，已登记 ERRATA。
15. （原文 p.5）$X/\!/^{\nabla}G$ 中的 $\nabla$ 表示保留联络数据；忘掉联络即得通常的商栈 $X/\!/G$。这是本文“背景规范场”的几何来源。
16. （原文 p.6）原文 "translating these structure into the bordism framework" 中 these structure 应为 this structure；中文不受影响，已登记 ERRATA。
17. （原文 p.6）$\Z/2$-分次张量积的对称同构含 Koszul 符号，即 $a\otimes b=(-1)^{|a||b|}b\otimes a$；这是全文一切“超”结构的统一约定。

4. （原文 p.7）原文第 3 号脚注。译文用 LaTeX 自动脚注，编号可能与原文不同，核对时以“无界算子+自伴”这条注释为准。
