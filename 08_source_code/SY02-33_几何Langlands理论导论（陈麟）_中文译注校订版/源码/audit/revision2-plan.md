1. 对照原PDF第5–83页（至References标题前）正文、83–85页参考文献，逐章核对119节的每个段落及公式。逐章记录完成情况，不能以节数和编号覆盖代替内容检查。

3. 检查48幅矢量裁切的边界、符号与箭头完整性、清晰度、长宽比、位置和页面比例。
