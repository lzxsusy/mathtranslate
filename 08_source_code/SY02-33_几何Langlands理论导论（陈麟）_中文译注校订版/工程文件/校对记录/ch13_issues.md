# ch13 审读问题（Whittaker 系数的保守性，原 PDF p64–p67）

## ch13.tex:106（原 PDF p67）
- 原文：Thus, if Nilp_Kos occurs as an irreducible component of SS(F), equivalently with non-zero characteristic-cycle multiplicity, then coeff(F) ≠ 0.
- 原译：因此，若 $\mathrm{Nilp}_{\mathrm{Kos}}$ 以非零特征圈重数出现，则 $\operatorname{coeff}(\cF)\ne0$。对反常层，这等价于 $\mathrm{Nilp}_{\mathrm{Kos}}$ 作为 $\operatorname{SS}(\cF)$ 的不可约分支出现。
- 类型：增译
- 改法：因此，若 $\mathrm{Nilp}_{\mathrm{Kos}}$ 作为 $\operatorname{SS}(\cF)$ 的不可约分支出现（等价地，以非零特征圈重数出现），则 $\operatorname{coeff}(\cF)\ne0$。
- 理由：原文的 equivalently 对一切可构造对象都成立——特征圈的支集就是奇异支撑，“作为 SS(F) 的不可约分支出现”与“以非零特征圈重数出现”本就是同一件事；译文加出的“对反常层”把这一等价性无端收窄到反常层，相当于给定理加了原文没有的假设。

备注：13.1–13.6 已逐句对照原文（含 p64–p67 的原版页面图），除上条外未发现误译、漏译或公式差异。
