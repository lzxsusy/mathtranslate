## 一、依据与流程

按 `04_playbook/01_数学文献翻译纪律.md` v2.1 与 `07_整书对照校订流水线.md` 执行：

1. **对齐单位**：用 `pdftotext -layout` 把原 PDF 按页分块（`work/pages/pNNN.txt`），按每章首个 `\srcpage{N}` 锚点确认章→页映射（ch01 p5–11 … ch16 p76–83）；公式与图一律回到 110 dpi 的页面图像（`work/png/pNNN.png`）逐式核对，不用抽取文本代替图像。
2. **八路只读审读**：把 16 章分成 8 组，各派一名审读员逐句对照原文（任务书 `AGENT_BRIEF.md`），产出 `review/chNN_issues.md`（位置/原文/原译/类型/改法/理由，只报真错误、禁润色）与 `review/chNN_notes.md`（待注点：概念、读者缺什么、建议来源）。共 39 条问题、约 90 个待注候选。
3. **逐条复核后断言式批改**：每条先回原文与页面图像确认，再以「片段必须恰好出现一次」的方式替换（`work/patch.py`、`work/ins.py`），命中数不符即整体退出、不写盘；全部改动按纯 LF 写回。
4. **译注**：按 §2.5 的来源分级写注，只写三类（易错预警／含糊点拨／背景直觉）；nLab 词条先抓 `Last revised`，无日期的条目只写访问日期；每条末句带 `[来源：…]`／`[依据：原书 p.N …]`／`[译者按…]` 之一。
5. **复核**：`work/final_audit.py` 比对 `\label` 集合、扫描黑名单与语言禁例、检查每条译注的来源标记；`work/gen_index.py` 校验 59 条译注全部带来源并生成附录；整书 `xelatex → biber → makeindex → xelatex ×2` 通过。

## 三、正文改动分类

**P1（数学错误，必改）**

- ch03：Tate 扭转约定写成 `σ(-(n-1)/2)`，与上一行的 `q_x^{d(n-1)/2}` 自相矛盾；原书 p20 为正号。
- ch15：权与余权整体颠倒（`X_*(\check T)^+` 应为 `X^*(\check T)^+`，根指标应带 `\check\alpha_i`），原书 p72 为准。
- ch14：`⊕` 被写成 `∏`（Hitchin 基的直和）。
- ch08：`α_d` 被写成 `α^d`；ch09/ch10/ch13：`temp` 记号一律误作下标，原书为上标 `D(Bun_G)^{temp}`。
- ch04：支撑参数 `χ_λ` 应为 `χ^λ`（3 处）；ch02：平凡丛 `P_0` 应为 `P^0`（3 处）。
- ch12：`infinite Jordan block` 被译成「无限维局部系统」，并增出「基本群的正则表示」；ch11 引用的局部到整体定理编号应为 Theorem 9.3.1。

**P1/P2（增译、漏译、术语）**

- 增译：ch08「采用相对反常归一化后」、ch12「及其 Hecke 输入」、ch13「对反常层」、ch16「满」「一重」等原文所无的限定，全部删除。
- 漏译：ch05「或对秩为 1 且非平凡的 E」。
- 术语统一：`stratum/strata` 一律「分层」（原「层片」「层」），`infinite level`「无限级」（原「无限层」），`restricted variant`「受限变体」（原四种译法），`chart`「图卡」（与 `atlas`「图册」区分），`generic` 从「通用」改「泛」（泛正 Hecke 核）。
- 翻译腔与欧化句：`up to` 由「按……约定选择」改为限定语「在……意义下成立」；「被……所」「进行……的讨论」等禁例全书为 0。

## 四、译注

59 条，覆盖 16 章（每章 3–4 条），统一用 `transnote` 环境排版（蓝色「译注 N」＋〈类型〉，双端缩进小字），并在书末「译注一览」按编号列出标题与页码。

选题集中于原书「说了但没展开」的四处：记号约定（`♥`、`^temp`、`[d](d/2)`、`χ^λ`）、构造的技术缺口（`IndCoh_Nilp`、左完备化、`inv^+`）、定理间的依赖（Deligne–Abel–Jacobi 与平均函子消失两条界、FGKV 比较、几何 Ramanujan），以及**作者用「几乎」「适当」「通常」带过而读者无法自补**的句子。

来源分布：nLab 词条（带 `Last revised` 者优先）与 Stacks Project 为主，均按 §2.5 与 A 级文献（原书、[AG15]、[BD91]、[FG05]、[FGKV98]、[GR24a]、[Laf18] 等）交叉；仅据原文可判者写 `[依据：原书 p.N]`；上下文推断且无外部依据者写 `[译者按…]`。全书译注中黑名单命中 0，「带来源标记」59/59。
