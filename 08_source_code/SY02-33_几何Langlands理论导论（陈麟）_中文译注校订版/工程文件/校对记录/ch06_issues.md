# ch06《洁净性》审读问题（原 PDF p37–p40）

## ch06.tex:92（原 PDF p39）

- 原文：After base change, fix a point (sT : Ω^(k−1)_X → T, M˚) ∈ Z̃.
- 原译：基变换后，固定点 $(s_{\mathcal T}:\Omega_X^{k-1}\to\mathcal T,\mathring M)\in\widetilde Z$。
- 类型：误译
- 改法：基变换后，取定一点 $(s_{\mathcal T}:\Omega_X^{k-1}\to\mathcal T,\mathring M)\in\widetilde Z$。
- 理由："fix a point" 是"取定一点"的祈使句，译成名词"固定点"后被读成不动点，既与上文 $\widetilde Z$ 恰是 $\Gm$-作用的固定点轨迹（ch06.tex:78）相混，也使句子失去了"取点"这一动作。
