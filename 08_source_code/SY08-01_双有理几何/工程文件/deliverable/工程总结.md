## 4. 关键裁定（质量闸门记录）

1. **尾符三档**：原书有一类陈述「声明末完全无符号」、证明紧跟其后（■ 只在 proof 末）。故定理类环境分三档：无后缀（书中不证，■）、`p` 后缀（无符号）、星号（证明在后文，□）；定义/例类尾符方向相反。**一律以页图为准**，全书逐条核对。
2. **术语反转**：冻结初期按日文漢語直译「因子／射／補題／系／卡蒂埃」，后发现中文数学界通行写法相反，遂全局改：divisor=**除子**（因子仅用于 factor）、morphism=**态射**、lemma=**引理**、corollary=**推论**、Cartier/Weil **保留拉丁字母**；「生成点」→**泛点**（general point 仍作「一般点」）、support=**支集**（supporting 仍作「支撑」）、abundance=**丰度** vs ample=**丰富**、contraction=**收缩**、big=**大**。共 62 处「系 N.N」、12 处「因子」、若干处旧词由 Lead 全局脚本替换并重编译验证。
3. **块边界**：§3.7 标题归 ch03c；ch03d 起 p.125、ch03e 起 p.133（据页眉数字核实）；跨页句归「句首所在页」的块；接缝处用 `\begin{proof}[证明（续）]` 接续，逐处人工核对无重复。
4. **图**：有编号插图照裁页图（图 1.4）；纯线条示意图按原图 TikZ 重绘、图内文字改中文；无编号示意图一律 TikZ、不编号。重绘图的有意差异在 README §8 记录。
5. **笔误照录 + 批注**：原书缺下标、编号引错、符号印作 ≅／=、日英不一致等，一律不动正文，加批注说明；日译本增补标「日译本增补」。
6. **索引不译**：原书 p.311–344 索引不逐页翻译，改以附录 A（术语）＋附录 D（编号条目）覆盖检索需求。

## 6. 遇到的问题与解法

- **无文字层 + 无日文 OCR**：译者只能读页图。对策：每块先看页图排版、再用英文原著 OCR 文本仅作语义参照；所有编号/尾符/公式逐字符对页图，批注说明日英差异。
- **MiKTeX 不能写中文路径/Desktop**：`build.ps1` 先把 `src/` 镜像到 ASCII 目录编译，再回拷 PDF 与日志。
- **MiKTeX「未检查更新」stderr 被记为 exit=1**：非错误，`build.ps1` 只认 LOG 五项统计与 `PDF ok`，日志中单列说明。
- **longtable 分页内核警告**（Infinite glue shrinkage）：实测无害，统计时剔除并单列 `benign-glue`（41）。
- **附录 D 行尾**：初版索引生成脚本写过 437 行每行只有单个 `\`，编译不报错但表格错乱；改为 `\\` 后全部正常。
- **ch07d 的 BOM 与 markdown 反引号**：末块交付时带 BOM、章末评注里 5 处 `$...$` 外层残留 markdown 反引号（`` `$f^m`$ ``），由 Lead 清除并改写为 `$f^m$`。
- **6.11/6.12 疑缺号**：初校基于旧快照报「第 6 章缺 6.11/6.12」；核对页图确认原书 p.239 确有这两条（t03 已补入），属快照过期，非真缺号。

## 9. 学习收获（Lead）

这个项目对我不只是"翻译任务"。为了写 8 篇研读札记，我被迫把每一章的证明链走一遍，收获集中在三处：

1. **方法论**：极小模型纲领的全部技术都在服务一个目标——把"双有理等价类"这个太大、无法参数化的对象，换成"标准模型/极小模型"这个可分类的对象；所有定理（锥定理、无基点、有理性、翻转存在、终止）都是这条流水线上的工位。
2. **取整方向的教训**：第 3 章的标准环用 $\lfloor m\Delta\rfloor$（下取整）才次可加，第 4 章的同时消解却用 $\lceil -a_i\rceil$（上取整），方向相反各有原因；这类"看似任意、实则有因"的细节，是读原著和读二手文献的分界线。
3. **历史定位**：本书停在 1998 年——三维完成、四维翻转未知（§7.6 直言是 MMP 最重要的未解决问题）。知道边界在哪里，比多记住几个定理更有用。

札记全文见 `deliverable/研读札记.md`（亦为成书附录 C），每篇含"与我原有理解的出入"与"待查疑问"，未解决的问题如实保留，不作掩饰。
