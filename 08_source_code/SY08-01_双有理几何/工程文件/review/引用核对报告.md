## 六、方法说明

脚本 `work/tools/check_cites.py`：剔除注释、数学模式与 LaTeX 可选参数后，用正则 `^[A-Za-z][A-Za-z'\-]*(?:\+[A-Za-z]*)?\d{2}[a-z]?$`（西文）与`^[\u4e00-\u9fff]{1,8}\s*\d{2}(?:--\d{2})?$`（日文文献）识别标签；引用内以逗号/分号切分，`Chap./Sec./p./§` 等定位词与纯页码忽略；日文标签比较时去掉空格并统一部分异体字（宮→宫、飯→饭）。仅覆盖形如 `[Tag]`、`[Tag, Chap.N]` 的文献引用，不含「定理 7.32(2)」这类数值引用。
