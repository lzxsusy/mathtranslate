# 研读札记 02 · 第 2 章 极小模型纲领引论（原书 p.47–94）

本章是全书从「几何操作」转向「纲领语言」的转折点。第 1 章还在曲面上逐个收缩 $(-1)$-曲线，本章开始把整套操作抽象成「锥定理 + 收缩 + 翻转 + 终止」的四件套，并明确宣告：**三维以上必须在允许奇点的簇范畴里工作**。我的收获主要不在具体定理，而在看清了这个范畴为什么是这样被设计出来的。

## 一、本章在做什么

- §2.1 用例 2.1（三维商奇点 $\frac{1}{r}(1,a,r-a)$）说明非奇异簇的范畴对 MMP 不封闭：收缩一条极射线后得到的簇一般带奇点。于是纲领改在「终端奇点」这一类上运行。四步流程：$K_X$ nef 则停；否则取极射线并收缩；收缩若为除子型（divisorial）就继续，若为小收缩则作翻转；如此循环。
- §2.2 把纲领相对化，并推广到解析情形、带群作用、对数对 $(X,\Delta)$。四者共用同一套锥定理与收缩定理，因此框架可以整体照搬——这一点我认为是本书写作上最省力也最诚实的地方：先做非奇异情形，再声明「所有论证都相对化」，把重复劳动一次性卖掉。
- §2.3 是真正的技术核心：用差异系数 $a(E,X,\Delta)$ 统一地定义终端、标准、klt、dlt 四档，并证明 dlt 在消解、收缩、翻转下保持。
- §2.4–2.5 提供纲领的燃料：小平消没定理与 Kawamata–Viehweg 消没定理。没有消没，翻转的存在性与相对收缩都无从谈起。

## 二、我抓到的技术要点

1. **差异系数是不变量，不是坐标量。** 定义 $K_Y=f^*(K_X+\Delta)+\sum a(E,X,\Delta)E$ 依赖于模型 $Y$，但 $a(E,X,\Delta)$ 只依赖 $E$ 对应的离散赋值 $v_E$（通过局部环 $\cO_{e,X}$ 与它的赋值环）。这正是 §2.3 全部分类「可以只谈赋值、不谈模型」的根据。第 3 章证明「翻转前后奇点类别不变」时，用的就是同一个不变性。
2. **klt 与 dlt 的差别只在系数 $\ge1$ 与 $<1$。** klt 要求所有 $a(E,X,\Delta)>-1$；dlt 放宽为「存在 snc 的对数消解，且系数 $\le1$ 的边界成分正规」。放宽的代价是边界必须既约——这解释了为什么第 5 章要用整整一节去证明 dlt 对的有理性（定理 5.22），而 klt 情形几乎是免费的。
3. **大（big）与 nef 的组合是可加的。** 命题 2.61 把「nef 且大」等价于「丰富 $\Q$-除子 + 小有效除子之和」，这是 Kawamata–Viehweg 消没定理能推广到「接近丰富」的全部秘密：附加一个足够小的有效除子，不改变消没的结论，却把条件降到可验证的数值层面。
4. **消没定理的系数条件 $0\le a_i<1$ 不能碰 1。** 一旦某个 $a_i=1$，klt 性失效，反例立刻出现（圆锥上的 $\cO(-D)$）。这是贯穿全书的一条红线，第 3 章处理 lc 对时必须先扰动 $\Delta\mapsto(1-\delta)\Delta+\epsilon H$ 化为 klt，原因就在这里。
5. **相对化不是装饰。** 定理 2.64 的相对形式（推论 2.68）才是第 3 章证明收缩与翻转时真正使用的版本：绝对形式要求 $X$ 射影，而收缩的底空间只是一般簇。

## 三、与我原有理解的出入

- 我原以为「终端奇点」是技术上不得不接受的妥协，读完 §2.1 才明白它是一个**刻意的选择**：终端奇点恰好是「使 $K$ 仍为 $\Q$-Cartier、且翻转不再引入更坏奇点」的最小类。换句话说，奇点类不是被发现的，而是被**筛选**出来的。
- 我原以为锥定理的陈述（第 3 章）与收缩的存在性是两件事。本章的四步流程说明两者必须同时成立才能称「纲领可执行」；而终止性（三维由森 1988 年解决，高维至今开放）与翻转存在性是仅存的两个缺口，本书 3.45、3.46 两段也诚实地标了出来。
- 我原以为「消没定理」是黑箱。§2.4 的证明路线——Hodge 理论把全纯上同调抬到拓扑上同调，再用 GAGA 与循环覆盖化归到 Serre 消没——让我第一次看清：小平消没的实质是「用拓扑压住全纯」，而不是某种解析技巧。

## 四、未解疑问

1. 例 2.1 的三维商奇点 $\frac1r(1,a,r-a)$ 在什么条件下不属于终端类？书中只给了「一般不终端」的例子，没有给出判据的完整证明，我打算在第 5 章 §5.3 回头核对。
2. 命题 2.42 与定理 2.44 证明 dlt 的稳定性，用的是消解上的组合论证；但「翻转之后 dlt 保持」是否可以不依赖消解、直接从差异系数的赋值定义得到？本书没有这样处理。
3. Kawamata–Viehweg 消没定理的系数条件中，$\sum D_i$ 必须是 snc 除子；命题 2.71 说曲面情形可以去掉 snc。三维以上是否有类似的放宽？书中未涉及，值得记为后续阅读线索。
