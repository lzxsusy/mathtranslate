# 统计口径说明

本文件说明 `work/tools/stats.py` 每个数字的定义、正则与基准来源，供 README 与工程总结引用。
脚本只读 `src/chunks/*.tex`、`src/main.tex`、`src/frontmatter/*.tex`；`--write` 时另写 `deliverable/统计数据.txt`。
所有数字现算，不读缓存；每块文件被他人改写后再跑一次即得新值。

## 0. 运行方式

```
python work/tools/stats.py            # 人类可读表 + 一行 JSON
python work/tools/stats.py --write    # 另写 deliverable/统计数据.txt
python work/tools/stats.py --json     # 只打印 JSON
```

交叉校验把「实际问题」与「基准值」并列打印；不一致打印 `MISMATCH got（基准 x）`，**保留实际值，不静默取其一**。`mismatch` 字段为不一致条数。

## 1. 页标记（原书页码）

- 定义：各 chunk 中 `% [原文 p.N]` 注释的**不同页码**个数，按 `p` 分组统计。
- 正则：`%\s*\[原文\s*p\.(\d+)\]`。
- 结果：正文（绪论至第 7 章）**296** 页，覆盖 p.1–297，唯一缺口 p.232（该页原书空白，已用像素核验暗像素比 0.0000）；全库 **308** 页（另含参考文献 p.299–310 共 12 页）；另 p.298 亦为空白页，因位置在章末与参考文献之间，未计入正文缺口清单。
- 基准来源：`review/终校报告.md` §3。

## 2. 陈述数与编号段

- 陈述：**环境条目 + 手排带标签条目**。
  - 环境条目：`\begin{env}` 出现次数，`env` ∈ {theorem, proposition, lemma, corollary, definition, example, remark, notation, principle, question, problem, conjecture, counterexample, assumption, formulaenv} × 后缀 {空, `*`, `p`}。中文类型名与 `src/preamble.tex:112-147` 的 `\fkstmt` 标签一致。
  - 手排带标签条目：行首 `\par\medskip\noindent\textbf{…}` 且内容为「标签 N.N」者，标签 ∈ {主张、断言、构造、构成、概述、概要、要约、定义、补充、命题、例、定理、引理、推论}。
- 编号段：**手排无标签编号段 + 编号证明**。
  - 手排无标签：同上正则但取不到中文标签者（如 `\textbf{5.36}`）。
  - 编号证明：`\begin{proof}[N.N（…）]`（如 `[4.41（定理 4.28 的证明）]`），正则 `\\begin\{proof\}\[(\d+\.\d+)（[^）]*）\]`。
  - 排除：以「（」开头的续接标题、含「续」的标题、含「的证明」的证明标题，均**不**计为新条目（与 `work/tools/gen_index.py` 的排除规则一致）。
- 正则：`^\s*(?:\\par\\medskip)?\s*(?:\\noindent)?\s*\\textbf\{([^{}]{1,80})\}` + `^(?:(\S{1,4})\s*)?(\d+\.\d+)(?!\d)`。
- 结果：陈述 **399** = 环境 387 + 手排带标签 12；编号段 **55** = 手排 53 + 编号证明 2；合计 **454** = 附录 D 行数。
- 环境分型：定理 85、引理 70、推论 59、命题 55、定义 50、注 39、例 19、记号 7、原理 2、猜想 1。
- 与附录 D「类型」列的差异解释：附录 D 的「定义 51」= 环境 50 + 手排「定义 2.28」1；「例 20」= 环境 19 + 手排「例 7.61」1；「编号段 55」= 上述 53 + 编号证明 2；其余类型逐项相等。
- 基准来源：`review/终校报告.md` §4（454 条、逐章 4/46/71/54/72/78/47/82）、`review/附录D_一致性终核.md`。

## 3. 编号公式

- 定义：`\tag{…}` 出现次数（原书带编号的公式；每个编号恰好一次）。
- 正则：`\\tag\{`。
- 结果：**11** 个——(1.1)–(1.6)（1.1–1.4 在 ch01b，1.5–1.6 在 ch01d）、(3.1)、(4.1)、(5.1)、(5.2)、(5.3)。
- 说明：陈述编号与公式编号是书中的两套编号，允许同号（如定理 1.1 与公式 (1.1)），不算重号。
- 基准来源：`review/终校报告.md` §4。

## 4. 译注

- 定义：正文各块中以 `% [Tutor Note` 起头的注释行数（半角或全角冒号均可）。
- 正则：`%\s*\[Tutor Note[:：]`。
- 结果：正文 **187** 条；参考文献另 **4** 条（书目说明，不计入正文译注）。
- 与附录 B 对齐：附录 B 由 `work/tools/gen_notes.py` 从正文自动汇总，当前收录 **187** 条（8 节），与正文一致；脚本的交叉校验把「正文译注数」与「附录 B 的 `\item` 数」并列比较，任一时刻两者不等即报 `MISMATCH` 并提示重跑 `gen_notes.py`。

## 5. 本章回顾与本节重点

- `\takeaway`：**38** 个（每节一条，跨块节只在节首块）；`\chapterreview`：**7** 个（每章末块一条）。
- 正则：`\\takeaway\{`、`\\chapterreview\{`。

## 6. 图与交换图

- 编号图：`\figtitle{…}` 次数，**7** 张（fig1.1–1.4、fig2.1、fig2.2、fig3.1），与 `src/figures/` 中的原书图一一对应。
- tikz：`\begin{tikzpicture}` 与 `\begin{tikzcd}` 合计 **46** 处（含重绘示意图与交换图；重绘示意图不带编号）。
- 正则：`\\figtitle\{`、`\\begin\{tikzpicture\}|\\begin\{tikzcd\}`。

## 7. 章、节、附录

- 章：《正文》非星号 `\chapter{` 共 **7** 章（第 1–7 章）。另星号章 **6** 个：绪论、附录 A–D、参考文献（`\chapter*{`）。
- 节：正文 `\section{` **38** 节；附录节 `\section*{` **16** 节（附录 B 8 + 附录 C 8）。
- 附录：`appendix_*` 四个文件（术语对照表、译注汇编、研读札记、定理与定义索引）。
- 正则：`\\chapter\{`、`\\chapter\*\{`、`\\section\{`、`\\section\*\{`。

## 8. 正文字数

- 定义：正文各块（绪论至第 7 章，不含附录与参考文献）的**汉字**个数。
- 清洗顺序：删 TeX 注释（含页标记）→ 删 `equation/align/gather/multline/eqnarray` 环境 → 删 tikz 环境 → 删 `\[…\]` → 删 `$…$` → 删命令名 `\cmd` → 删花括号 → 数 `[\u4e00-\u9fff]`。
- 结果：正文 **92792** 字；含附录与参考文献全库 **131375** 字。
- 说明：数学模式内的汉字（如 `\text{…}`）不计入；标点、数字、拉丁字母不计入。

## 9. main.tex 接入核对

- 取 `src/main.tex` 中全部 `\InputIfFileExists{…}`，与 `src/frontmatter/*.tex`、`src/chunks/*.tex` 做双向差集。
- 正则：`\\InputIfFileExists\{([^}]+)\}`。
- 结果：**39 项**（frontmatter 3 + chunks 36）与磁盘完全一一对应，无漏接、无多接。目录顺序：titlepage/preface/note → ch00a → ch01a–d → ch02a–e → ch03a–e → ch04a–e → ch05a–d → ch06a–c → ch07a–d → 附录 A–D → bib。

## 11. 已知限制

- 分块文件可能正被其他译者改写；每次运行的数字是**该时刻**的快照，报告里引用时应注明运行时间。
- 汉字计数不含数学模式内的汉字；若需「含数学文本」口径，应另加开关，当前不做。
- `\chapter*` 的星号章计数包含参考文献（`bib.tex`），若只需「绪论 + 附录」，取 6 − 1 = 5。
