## 6　脚本核心正则

```
ENV  = \\begin\{(def|thm|prop|lem|cor|ex|rem|not|...)(\*|p)?\}\s*(?:\[((?:[^\[\]]|\[[^\]]*\])*?)\])?\s*\{(\d+\.\d+)\}
HAND = ^\s*(?:\\par\\medskip)?\s*(?:\\noindent)?\s*\\textbf\{标签? N.N 尾部?\}
PRF  = \\begin\{proof\}\[(\d+\.\d+)（([^）]*)）\]
```

类型映射：theorem→定理、proposition→命题、lemma→引理、corollary→推论、definition→定义、
example→例、remark→注、notation→记号、problem→问题、conjecture→猜想、counterexample→反例、
principle→原理、question→问、claim→主张。手排标签：要约→概述、构成→构造、
主张/断言/定义/补充/例 照字面，无标签→编号段。

章名由编号前缀映射（ch01b 起各块自身无 `\chapter`）：绪论、有理曲线与标准类、
极小模型纲领引论、锥定理、极小模型纲领的二维奇点、极小模型纲领的奇点、三维翻模、半稳定极小模型。
