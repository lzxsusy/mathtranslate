## 1. 脚本假阳性（10 个）：正文已引用，写在陈述环境可选参数内

旧版 `strip_latex_options` 把 `\begin{env}[...]` 的可选参数整段删除，而项目惯例把文献标记写在陈述的**附加名**里（如 `\begin{propositionp}[{[Abh56, Prop. 4]}]{1.3}`），于是这些引用被漏计。逐条核实如下（均在正文、已能正常排印）：

| 标签 | 所在块 | 引用写法 |
|---|---|---|
| Abh56 | ch01a | `\begin{propositionp}[{[Abh56, Prop. 4]}]{1.3}` |
| Bla56 | ch01a | `\begin{example}[{[Bla56]}]{1.8}` |
| Zar62 | ch01c | `\begin{example}[{[Zar62]}]{1.27}` |
| Elk81 | ch05b | `\begin{theoremp}[{[Elk81, Fuj85, KMM87]}]{5.22}` |
| Fuj85 | ch05b | 同上（5.22 附加名内） |
| Kol83 | ch05b | `\begin{theorem*}[{[Kol83]}]{5.28}` |
| Kaw92b | ch06b | `\begin{definition}[{[Kol89, Kaw92b, K+92]}]{6.20}` |
| Iit77 | ch02b | 另有正文引用两处（`[Iit77]`，第 122、129 行附近） |
| BC94 | ch07d | 正文「[BC94, Ste93] 进一步计算…」 |
| Ste93 | ch07d | 同上 |

## 2. 真漏引（2 个，必须修）

**位置：`src/chunks/ch00a.tex` 第 63 行（原書「緒論」/ 英文 Introduction）**

- 英文底本（`work/en/ch00a_en.txt`）原文：

  > A few times we need the Leray spectral sequence (see **[God58, 4.17]**, **[HS71, VIII.9]** or **[Bre97, IV.6]** for proofs).

- 现行译文：

  > 有时会用到 Leray 谱序列（关于其证明，参见 [God58, 4.17]、[石井97, §2.6]，或 [宫西90, 2.28]）。

- 问题：原书列出「谱序列证明」的**三处**出处（God58、HS71、Bre97），译文只保留 God58，并把另两处替换成了日译本另加的石井/宫西参考书；`[HS71]`、`[Bre97]` 因此在全书中「bib 有、正文无引用」。
- 建议改法（保留日译本增补、补回原书两处；只动 t01 的 ch00a）：

  > 有时会用到 Leray 谱序列（关于其证明，参见 [God58, 4.17]、[HS71, VIII.9]，或 [Bre97, IV.6]；日译本另参 [石井97, §2.6]、[宫西90, 2.28]）。

  或最小改动：在句末补「；亦见 [HS71, VIII.9]、[Bre97, IV.6]。」两种改法都保持「三处出处并列」的原意。

## 4. 脚本修正说明（`work/tools/check_cites.py`）

- 旧逻辑：`\begin{env}[...]` / `\end{env}[...]` 的可选参数整段删除，导致写在附加名里的文献标记不被计入。
- 新逻辑：对手工配对的可选参数，只保留其中的方括号组内容（如 `[{[Abh56, Prop. 4]}]` → `[Abh56, Prop. 4]`），其余丢弃；`\item[...]`、普通 `\command[...]` 仍整体删除（避免把排版参数误当引用）。
- 效果：`refs` 409 → 450，`cited_tags` 154 → 162，`unused` 16 → 6，其余计数不变；`missing` 仍为 0。
- 局限（记录备查）：`\bibentry{...}` 与正文的比对以「标签字符串完全一致」为准；大小写与后缀（a/b/c）差异会分别报在 `case`、`suffix` 栏，本轮两者均为 0。
