## 3. 体例要点

- **页标记**：每页起首 `% [原文 p.N]`（N = 印刷页码），供校勘与回查；空白页不设标记。
- **编号**：定理/命题/引理/推论/定义/例/注/记号/猜想等一律照抄原书编号，不用 LaTeX 自动编号；原书编号公式恰有一个 `\tag{原编号}`。
- **尾符三档**（原书绪论 (16) 及其实际用法）：定理类默认 ■（书中不证）；证明紧跟其后者**声明末无符号**、■ 只在 proof 末（用带 `p` 后缀的环境）；证明在后文者用星号环境（定理类印 □、定义类印 ■）。**符号一律以页图为准。**
- **图**：全书编号插图 7 张（图 1.1–1.4、2.1、2.2、3.1）。其中 6 张为纯线条示意图，按原图 **TikZ 重绘**（`src/figures/figX.Y.tex`，形状/顶点/箭头一一对应，图内文字改用中文），1 张（图 1.4，含数学符号标注）**照裁页图**。原书无编号的示意图（树状图、链图、加权图、Dynkin 图等）一律 TikZ 重绘、不编号；交换图用 `tikzcd`（全书 46 个 tikz 环境）。
- **译注**：`% [Tutor Note: …]` 形式写在 LaTeX 注释里，正文排版时**不印**，另由 `work/tools/gen_notes.py` 汇总为「附录 B 译注汇编」（**187 条**），按章与页码排列。这是本书“译注本”定位的主要体现。
- **节首/章末**：每节一个 `\takeaway{…}`（≤120 字，共 38 个）；每章末一个 `\chapterreview{…}`（700–1100 字，五段式：全章地位／知识脉络／核心结论／辨析与提醒／评注），共 7 篇，由该章末块译者撰写。
- **术语**：`work/glossary.tsv` 冻结 **428** 条数据行（日／中／英／备注），附录 A 自动生成 **463** 条（含 9 条别名归并）；译者发现新术语写入 `work/proposals/<译者>.tsv`，由 Lead 裁定后并入主表。
- **附录 D**：由脚本 `work/tools/gen_index.py` 解析正文全部 `\fkstmt` 环境与手排编号段生成，**454 条**（陈述 399 + 编号段 55），按章分组，四列（编号／类型／条目／原书页），供检索与回查；与正文编号双向差集为空。

## 4. 研读札记（附录 C）

除译文与译注外，本工程另有一份 Lead 的读书笔记：`review/研读札记_NN_第N章.md`，每章一篇（绪论亦一篇，共 8 篇），记该章论题与组织、核心定理与证明策略、我学到的技术、与前后章的联系、以及存疑与待查。经 `work/tools/md2tex.py` 并入成书附录 C，并单独交付 `deliverable/研读札记.md`。它刻意与章末「本章评注」分工：评注面向读者概览全章，札记记录**译校者本人的理解与疑问**。

## 5. 编译

本机（MiKTeX + lualatex）不能写中文路径，故采用镜像编译：

```powershell
cd "<本地路径>"
powershell -ExecutionPolicy Bypass -File build.ps1              # 整书 → src/main.pdf
powershell -ExecutionPolicy Bypass -File build.ps1 -Chunk ch02a # 单块草稿 → tmp_ch02a.pdf
```

流程：把 `src/` 镜像到 `<本地路径>` → lualatex ×3 → 回拷 `src/main.pdf` 与日志（另存 `src/compile.log`）。日志统计 `file:line / fatal / undefined / missingchar / overfull`，另单列 `[benign-glue]`（longtable 分页时内核的无害警告，已实测无排版影响）。最终编译：`file:line=0 fatal=0 undefined=0 missingchar=0 overfull=0`，`[benign-glue=42]`，**BUILD OK**，成书 **325 页**、2,595,279 字节。

自检工具（`work/tools/`）：`check.py`（页标记单调性、`\tag` 重号、假名残留、禁用命令、环境配对、括号与 `$` 平衡、各类计数）、`fix_chunks.py`（机械修补）、`finalize_text.py`（编码统一 + 术语 sweep）、`term_scan.py`（术语终检门禁）、`stats.py`（统计与交叉校验）、`gen_glossary.py` / `gen_notes.py` / `gen_index.py`（重生成附录 A/B/D）、`md2tex.py`（札记 → 附录 C）、`export_deliverables2.py`（导出交付件）、`merge_glossary.py`（提案并表）、`qa_final.py`（终态复扫）、`crop.py`（页图裁切）。

## 8. 已知偏差与说明

- 原书索引（p.311–344）不逐页译出，改以「附录 A 术语对照表」+「附录 D 定理与定义索引」覆盖检索需求；这是本品与影印底本的主要差异。
- 日译本相对英文原著有若干增补（如记号 (0) 条、日本教材指引、译注性括注），凡属增补均于译注中标明「日译本增补」，不与原著混淆。
- 原书个别笔误（缺下标、编号引错、符号印作 ≅／= 等）一律**照录并加批注**，不改动正文。
- 页眉/页码以印刷页码为准；章扉页不设页标记；p.232、p.298 为原书空白页。
- 重绘图的**有意差异**：图 2.2 四栏标签统一右置（原图分列两侧）；图 1.1 五边形按页图比例略直化；图 3.1 扫描图三线归属按「虚线 $ay-rx=1$、实线 $ay-rx=0$、其右再加一条丰富上界实线」判读重绘。
- 附录 D 有 88 条「主题」栏偏短（如「记号同上」「设……」，只截到陈述开头），未逐条润饰；编号＋类型＋原书页已足以定位。
- 陈述环境的显示标签与原书用词有个别出入：原书「注意」在本译本统一样式下显示为「注」（已在 ch05a 的 5.31 处加批注说明）。
- 「解析空間」译「解析空间」、「解析多様体」译「解析流形」，以日文页图为唯一依据；个别处英文原著作 analytic space 而日文印「多様体」者，照日文（术语表 A 已注明）。
- 原书编号插图 7 张中 6 张为 TikZ 重绘（图内文字改中文），形状/顶点/箭头与页图一一对应；图 1.4 含数学符号标注，照裁页图。无编号示意图（树状图、链图、Dynkin 图等）亦为 TikZ 重绘、不编号。
- 编译日志中 `[benign-glue=N]` 为 longtable 分页时 LaTeX 内核的无害告警（已实测不影响版面），不计为错误。
