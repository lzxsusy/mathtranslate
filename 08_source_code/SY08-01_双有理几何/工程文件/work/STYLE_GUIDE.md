## 1. 文件与结构

- 每块一个文件：`src/chunks/<块名>.tex`，**只写本块内容**，不要 `\documentclass`／`\begin{document}`。
- 块名见 `work/BRIEF.md` 分工表。**不得新建其它 `.tex` 文件**；唯一例外是图的重绘文件：经 Lead 指派做「示意图重绘」时，可新建 `src/figures/figX.Y.tex`（纯 `tikzpicture`，无 `figure` 环境、无 `\figtitle`），并在 chunk 里用 `\resizebox{\linewidth}{!}{\input{figures/figX.Y.tex}}` 接入。除此之外任何 `\input` 都在禁止之列。
- 禁改：`src/main.tex`、`src/preamble.tex`、`src/frontmatter/*`、别人的 chunk、`work/` 下任何文件（你自己的产物除外）。
- 每页正文前写一行页标记：`% [原文 p.23]`（用该页页眉/页脚印的页码，不是 PDF 号）。
- 章标题、节标题的归属见 §3。

## 2. 编译约束

- 用 **lualatex**，`ctexbook`。中文标点用全角，**禁 U+3000（全角空格）**，缩进由 `\parindent` 负责。
- 一切希腊字母、数学符号必须进数学模式（`$\alpha$`），**正文里直接打 α/β/ω/≤/→ 会缺字**。
- 英文术语、专名、数字两侧各留一个半角空格：`Fano 簇`、`$K_X$ 为丰富`、`第 3 章`。
- 不用 `\label`/`\ref`/`\eqref`/`\cite`：交叉引用一律写纯文本，如“由定理 1.4”“式 (1.12)”。

## 3. 章标题与节标题

- `\chapter{...}` **只由该章第一个块写一次**（块表里标 `★章首` 的那一块）。格式：`\chapter{有理曲线与标准类}`，**不要**自己写“第 1 章”——`\ctexset` 会自动编号。
- `\section{...}` 只由**该节起始页所在块**写一次，`\subsection` 同理。跨块的节：下一块不重复写标题。
- 章末评注 `\chapterreview{...}` 由该章**最后一块**写（见 §7）。
- 各章统一译名（不得改动）：

| 原文 | 译名 |
|---|---|
| 序 論 | 绪论（不占章号：`\chapter*{绪论}` + `\addcontentsline{toc}{chapter}{绪论}` + `\markboth{绪论}{}`，见 ch00a） |
| 第1章 有理曲線と標準類 | 有理曲线与标准类 |
| 第2章 極小モデルプログラム入門 | 极小模型纲领引论 |
| 第3章 錐定理 | 锥定理 |
| 第4章 極小モデルプログラムの2次元特異点 | 极小模型纲领的二维奇点 |
| 第5章 極小モデルプログラムの特異点 | 极小模型纲领的奇点 |
| 第6章 3次元フロップ | 三维翻模 |
| 第7章 半安定極小モデル | 半稳定极小模型 |

节标题统一译名见 `work/BRIEF.md` 的表，**照抄，不得自创**。

## 4. 公式

- 原书**有编号**的公式：一律 `\begin{equation} ... \tag{1.12} \end{equation}`，编号半角照抄，**每个编号恰好出现一次**。本机 `\numberwithin{equation}{chapter}` 已开，但 `\tag` 会覆盖它，放心用。
- 原书**无编号**的独立公式：`\[ ... \]` 或 `equation*`。
- 多行对齐用 `align`/`gather`/`aligned`；编号写在行尾 `\tag{1.12}`。
- 公式内的中文（如 `\text{...}` 里的说明）用中文，其余不得塞中文。
- 行列式、矩阵、交换图：交换图**统一用 tikz-cd**（已装，可用），写法：

```latex
\begin{tikzcd}
X \arrow[r,"f"] \arrow[d,"\pi"'] & Y \arrow[d,"\sigma"] \\
X' \arrow[r,"g"'] & Y'
\end{tikzcd}
```

- 单行图（如 `\xymatrix` 风格的一行箭头链）也可用 `\[ A \to B \to C \]`。

## 5. 陈述环境（**本书记号规则与常见中文书相反，务必看清**）

原书“绪论”第 (16) 条自述：**证明末尾用 ■；定义、例等的末尾用 □；定理、命题等，不给证明时用 ■，证明在后面给出时用 □。** 实际排印时还有第三档：**证明紧跟在声明之后的，声明末尾什么符号都不印**，■ 只出现在证明末尾。

据此，每种陈述环境有三个变体（以定理为例）：

| 变体 | 声明末尾 | 何时用 |
|---|---|---|
| `\begin{theorem}{1.3}` | ■ | 定理，**书中不给证明** |
| `\begin{theorem*}{1.3}` | □ | 定理，**证明在后文别处给出**（不紧跟） |
| `\begin{theoremp}{1.3}` | **无** | 定理，**证明紧跟其后**（最常见） |

- 对应关系：`definition`/`definition*`/`definitionp`（□/■/无）、`proposition`/`proposition*`/`propositionp`、`lemma`/`lemma*`/`lemmap`、`corollary`/`corollary*`/`corollaryp`、`example`/`example*`/`examplep`（□/■/无）、`principle`/`principle*`/`principlep`（原理：□/■/无）、`question`/`questionp`。
- `remark`（注）、`notation`（记号）：**无尾符**，直接 `\begin{remark}{1.8}`。原书有时在页图上印「注意」，本译注本统一显示为「注」，并在该处用 Tutor Note 说明原书用词（见 ch05a 的 5.31）。
- `problem` / `conjecture` / `counterexample`：■。
- `\begin{proof}` … `\end{proof}`：尾符 ■ 自动给出（**不要再手打**）。
- **判据只有一条：看页图上符号落在哪里。** 声明末有符号就照符号选变体；声明末无符号而下一段就是「証明」→ 用 `p` 变体。

- 用法：`\begin{theorem}{1.3} 正文…… \end{theorem}`。**编号手工抄原书**，不要空参。可选附加名写在方括号里：`\begin{theorem*}[广中定理]{0.2}`。
- 原书只印编号、**不带标签词**的条目（如单独一行「1.1」，或「3.45」这种推进式编号段落）→ **手排** `\par\medskip\noindent\textbf{1.1}\quad 正文…`，尾符照页图；不要硬套定理环境。
- 陈述内部可以有多个带编号公式，写成 `equation`+`\tag`。
- 证明若被块边界切断：本块照常写 `\begin{proof}…\end{proof}`，内容止于本块最后一页；下一块开头写 `\begin{proof}[证明（续）]…\end{proof}` 接着写，**不重复**已译内容。两块的 proof 各自闭合。

> **术语以 glossary.tsv 为准，其中两条已按通行译法更正**：divisor = **除子**（“因子”只用于 factor）；morphism = **态射**。Cartier、Weil、Du Val、Kollár 等一律保留拉丁字母，不音译。日本漢語「補題」= 引理，「系」= 推论，「端射線」= 极射线。

## 7. 本节重点 / 章末评注

- **每节开头**（`\section` 之后第一个正文段之前）写 `\takeaway{...}`：1–3 句、≤120 字，说清本节的核心对象、工具、结论。跨块节只在节首块写。
- **每章末尾**（该章最后一块）写 `\chapterreview{...}`：700–1100 字，五段式——
 1. 本章在全书中的地位与要解决的问题；
 2. 知识脉络（依赖前章什么、为后章铺什么路）；
 3. 核心结论（逐条列出主定理及其意义，不是复述证明）；
 4. 辨析与提醒（易混概念、条件是否可去、常见误解）；
 5. 评注（历史背景、与后续发展/文献的关系、读法建议）。

## 8. 译者批注（Tutor Note）

- 形式：单独一行 LaTeX 注释 `% [Tutor Note: ……]`，**放在相关段落之后**。
- 三类内容：
 1. **易错预警**：这个条件为什么不能去掉、这个符号与前文哪个不同；
 2. **省略论证点拨**：原书跳过的 1–3 步，补出关键中间步骤；
 3. **背景直觉**：这个构造/定理的几何图像、与别处的联系。
- 密度：每 2–3 页至少 1 条，每节至少 2 条。**宁缺毋滥**，不要复述正文。
- 批注内**禁止**出现 `%`、禁止跨行公式、禁止 `\` 开头命令（除非是数学命令）；长度 40–150 字。
- 原书笔误/疑似笔误：正文**照抄不改**，用批注说明。判不准的写进回执“存疑”。

## 9. 语言

- 中文数学书面语，简明、准确。**禁**：“被……所”“进行……的”“对于……而言”“关于……的讨论”“使得……得以”“值得一提的是”“众所周知”滥用；禁一逗到底；单句 ≤70 汉字，长句拆开。
- 日语「」→ 中文“”；『』→《》。日文顿号、句号照用中文标点。
- 允许调整语序、拆分句子以符合中文习惯；**禁增删信息**，禁加原文没有的“显然”。
- 日文常见句末处理：
 - 「…である」→ 陈述句正常收尾；
 - 「…に他ならない」→“正是……”；
 - 「…という事実に注意しよう」→“注意……这一事实”；
 - 「…を満たす」→“满足……”；
 - 「…とおく」→“记……”；
 - 「…が成り立つ」→“……成立”；
 - 「逆に」「従って」「故に」「特に」「なお」→“反之”“因此”“故”“特别地”“另外”。
- 人名/定理名保留原文：Fano、Du Val、Kodaira（小平）、Mori（森）、Kollár、Kawamata（川又）、Reid、Shokurov、Clemens、Corti、Zariski、Hironaka（广中）。**首次出现**用“小平（Kodaira）”式，之后只用中文或只用原文（全书统一：Kodaira → 小平，Mori → 森，Kawamata → 川又，Hironaka → 广中，其余保留原文）。
- 参考文献引用标记照抄：`[Mor82]`、`[K+92, Chap. 18]` 原样保留，不要改成上标。
