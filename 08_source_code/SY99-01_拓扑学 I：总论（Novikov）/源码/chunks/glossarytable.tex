\chapter{术语对照表}

\noindent 本表按英文原词的字母顺序排列，每条给出英文原词与本书统一采用的中文译名。正文中名词首次出现时另以「中文（English）」的形式标注；人名一律保留拉丁原形，不列入本表。同一英文词在不同语境下有不同译名时，以正文首次出现处的用法为准。

\noindent 有三组术语极易混淆，特此点明：\emph{quasi-complex}（拟复，稳定法丛带复结构）与 \emph{almost complex}（殆复，切丛带复结构）是两个不同的概念，本书分别译作「拟复」与「殆复」，不通用；\emph{almost parallelizable} 统一译作「几乎可平行化」；\emph{pseudo-} 一律译作「伪」：伪微分算子、伪群、伪同痕、伪 Riemann 度量。
