## 2. 片段规则（硬性）

- **只输出片段**：禁止 `\documentclass`、`\usepackage`、`\begin{document}`、`\newcommand`、`\title`、`\tableofcontents`。
- 文件写到 `work/src/chunks/trNNa.tex`（UTF-8 无 BOM、LF 换行）。**不要**动别人的 chunk、`preamble.tex`、`main.tex`。
- 章节层级：`\section{…}` / `\subsection{…}`；**只写 BRIEF §3 指名归你的标题**，其余标题一律不写（否则重复）。
- 段落之间空一行。不要写 `\par`。不要用 markdown 语法（`**粗体**`、`##` 会原样印出）。
- 原文的行内粗体小标题（如 "**reduced K-theory**"）用 `\textbf{…}` 就地加粗；独立成段的用 `\para{…}`。
- 原文的 "Some examples:" 等提示语照译，不加边框、不造要点框。
- 原文 `[VBKT] 1.6`、`[AGP] 8.4.4.` 这类文献引用**照抄英文方括号**，不要改成 `\cite`，不要翻译键名。

## 3. 公式（本工程最关键的一条）

- 原文**没有任何编号公式**（实测 0 条）。因此：
  - **绝不允许**写 `\tag{}`、`\begin{equation}` 编号；展示式一律用 `\[ … \]`；
  - 正文引用公式写纯文本「式 (5.31)」之类（本稿基本用不到）。
- 所有展示式**逐符号照原文重排**：
  - 矩阵用 `\begin{pmatrix} … \end{pmatrix}`；
  - 分段函数用 `\begin{cases} … \end{cases}`；
  - 交换图用 `tikzcd`：`\begin{tikzcd} A \arrow[r,"f"] \arrow[d,"g"'] & B \arrow[d] \\ C & D \end{tikzcd}`；
  - 长链复合（如 $h_1^{-1}\circ h_0$）别随手拆行，按图像断行。
- **上下标、花体、希腊字母必须与 200 dpi 页图逐个对照**（文字层这里是坏的）。
  `\mathcal` vs 普通、`\bar`/`\tilde`、`p^{-1}` 与 `p^{-1}(U_i)` 的归属、`\cong`/`\xrightarrow{\cong}`、`\hookrightarrow` 等。
- `\left(` / `\right)` 必须配对；不要用 `$$…$$`。

## 4. 宏（preamble 已定义，直接用；**不要自造** `\newcommand`）

- 集合：`\R \C \Z \N \Q`
- 算子：`\GL \Hom \End \Aut \Vect \dd \id \rk \ie \eg \cf`
- 定理类环境（**编号手工给**，正文直立体，中文不用斜体）：
  ```latex
  \begin{defn}{3} … \end{defn}     % 定义 3.
  \begin{prop}{1} … \end{prop}     % 命题 1.
  \begin{lem}{1}  … \end{lem}      % 引理 1.
  \begin{thm}{5}  … \end{thm}      % 定理 5.
  \begin{proof} … \end{proof}      % 证明. …… □
  ```
- 其余符号用标准命令（`\mathbb{}`、`\mathcal{}`、`\operatorname{}`、`\oplus`、`\otimes`、`\cong`、`\simeq`、`\subset`、`\hookrightarrow`、`\sqcup`、`\bigcup`、`\bigsqcup`、`\coprod`、`\prod`、`\Omega`）。
- 原文的 `k = \R` 或 `\C`、`C^*`-代数、`P^1(\C)`、`BU_n`、`BO`、`\Omega BU` 都按原文写。

## 5. 批注（Tutor Note）

格式固定为 LaTeX 注释行，编译后不显示：

```latex
% [Tutor Note: p.5 命题 3 的证明里 ………]
```

要求（**密度：每页至少 1 条**，10 页小稿按块算：3 页块 ≥ 3 条）：
- **可验证的易错点**：给出核对方法或观察点（如「$H\otimes H\oplus 1 = H\oplus H$ 的分量写法，注意 $1$ 是一维平凡丛」）；
- **补出的省略论证**：作者写 "It is straightforward to verify" / "we will not discuss" 而跳过的实际论证；
- **原文笔误**：必须给正确形式 + 判断依据（相邻式自洽/文献对照/量纲），**并且先用 500 dpi 裁图复核原文**；
- **术语首现**：给英文原词；
- 不要写空话、不凑数。批注里可以有 `$…$`，但**不要出现不成对的 `$`**。

## 6. 图/表

本稿**实测 0 图 0 表**。不要插图、不要造表、不要画与原文无关的示意图。
原文 p2 的交换三角形、p5 的交换图属于**公式的一部分**，用 `tikzcd` 或 `array` 重排，编号不变（本来也没有编号）。

## 7. 页码标注

每进入新的一页（PDF 页），在内容前加一行注释：

```latex
% [原文 p.3]
```

片段开头再加一行：`% ===== 原文 pp.3–5 =====`。

## 8. 禁止事项（违反即返工）

1. 不改原文内容：**不删、不增、不"顺手修正"正文**。原文字句有误 → 照译 + 批注指出 + 给正确形式。
2. 不编造：图、表、公式、文献、作者没说过的结论，一个字都不加。
3. 不用 `\newcommand`、不改 preamble/main、**不编译**（编译由 Lead 统一做）。
4. 不用 markdown 语法。中文标点用「。，、」；数学环境内用英文标点。
5. 不留未翻译的整句英文（人名、书名、[VBKT] 等文献键、$C^*$、$H$-空间等记号可保留）。
6. 不写「本节重点」之类原文没有的框/标题。

## 9. 边界规定

- 你的块若从句子中间开始：**直接从该处续写**，不要重写上文，也不要把上文翻一遍。
- 跨页句子「开始者写完」（谁先开始这句谁负责写完）。
- 边界处若有歧义：**宁可多看一页图像**，并在回报里说明。
- 定义/命题/引理/定理的编号连续性是你和邻居的契约（见 BRIEF §3 的编号区间）。
