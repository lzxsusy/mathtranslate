xelatex -interaction=nonstopmode -halt-on-error main.tex

## 编号体制

- 公式按节编号：`\numberwithin{equation}{section}`（`preamble.tex`，第 18 行）。原文即如此，切勿删。
- 节/小节/图/公式编号全部由 LaTeX 生成；正文中的 `\ref`、`\eqref` 一律不手写。
- 附录 A–D 的公式自动变为 `(A.1)`、`(C.2)` 等；`main.aux` 是条款索引的唯一来源。

## 译注排版

- 短注：`\zy{...}`，由 `manyfoot` 的 `trans` 序列排成“译 n”脚注，与作者脚注分开编号。
- 长注：`\begin{yizhu}[标题] ... \end{yizhu}`，橙色边框，可跨页；每块至多一条（ch01 样板有两条，属历史遗留，后续各块均按一条执行）。
- 译注中的公式与正文共用计数器；如不希望译注公式影响正文编号，可在 `yizhu` 内用带星号环境。

## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 公式编号是 (1)、(2)…而不是 (2.1) | `\numberwithin{equation}{section}` 被删或放错位置 | 放回 `\usepackage{amsmath}` 之后 |
| 中文缺字（`Missing character`） | 用了系统没有的汉字或符号 | 换字，或给该字加 `\CJKfontspec` 回退 |
| 译注框在页底被切断 | `tcolorbox` 默认允许跨页 | 可加 `breakable` 选项；当前样式已可跨页 |
| 图找不到 | `\graphicspath{{figures/}}` 未生效，或文件名大小写不符 | 确认 `源码/figures/` 下 11 个 PDF 与 `\includegraphics` 完全同名 |
| `Undefined control sequence \N` | `macros.tex` 未加载或宏名拼错 | 确认 `preamble.tex` 末尾 `\input{macros}`；`\N` 定义在原文宏段 |
| 文献引用显示为 `[?]` | 只跑了一遍，或 `ch17.tex` 未 `\input` | 跑三遍；确认 `main.tex` 末尾有 `\input{chunks/ch17}` |
