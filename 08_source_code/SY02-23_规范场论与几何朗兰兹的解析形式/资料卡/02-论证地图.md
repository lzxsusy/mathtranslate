# 资料卡 02 · 论证地图

本文不是一篇“先给定义、再证定理”的论文，而是一条从**四维规范理论**出发、经过**膜量子化**与**镜像对称**、最后落到**二维手征代数**的论证链。下面按这条链给出依赖关系；每一段标出「入口／核心构造／出口」。

## 一图流

```
       (1) 四维 N=4 SYM on Σ×C，边界 B_cc / B_cc¯
                    │  低能 = M_H(G,C) 上的二维 σ-模型
                    ▼
       (2) A-模型膜量子化：A = Hom(B_cc,B_cc)
                    │  形变量子化；Hitchin 哈密顿量 → 微分算子 D_{P,α}
                    ▼
       (3) 电-磁对偶 = 镜像：M_H(G,C) 的 A-模型  ←→  M_H(G^∨,C) 的 B-模型（复结构 J）
                    │  B_cc ↦ B_op（全纯 oper 的结构层）
                    │  B_cc¯ ↦ B_bop（反全纯 oper 的结构层）
                    ▼
       (4) 本征态 ψ_u：u ∈ Υ = L_op ∩ L_bop（既全纯又反全纯的平坦 G^∨_C 丛）
                    │  Hitchin 特征值 = f_{P,α}(u)
                    ▼
       (5) 线算符：'t Hooft T_{R,p}（Hecke 函子）  ←→  Wilson W_{R,p}
                    │  积分核支撑在 Hecke 对应 Z_{R,p} 上；Wilson 在 ψ_u 基对角
                    ▼
       (6) 量子修正 WKB：预量子丛在 Hitchin 纤维 F 上平凡，L|_F ≅ S
                    │  特殊几何、半平坦坐标 X_γ = e^{Z_γ}、Voros 符号
                    ▼
       (7) 实丛：反全纯对合 τ，M_H^R 的实极化；U_τ 的四维图像；实点的实 Hecke 算符
                    │
                    ▼
       (8) 二维手征代数：BAA 边界与角的交汇
                    │  变形 Neumann + Dirichlet → 临界 level Kac–Moody；S_P 中心
                    │  Hecke 算符 = 谱流顶点算子；辛玻色子给波函数
                    ▼
       (9) 附录：A 局部算子上同调；B B-模型正定性；C oper 截面；D 奇异行为
```

## 第一段：四维图像与膜量子化（§1–§2）

- **入口**：四维 $\mathcal N=4$ 超杨–米尔斯理论在 $\Sigma\times C$ 上，$\Sigma$ 是带两条边界的长条。左右边界分别取 $B_{cc}$ 与 $B_{\bar{cc}}$ 的规范理论版本。
- **核心构造**：把 $\mathcal N=4$ 理论作 GL 扭化，紧化到 $C$ 上，低能有效理论是靶空间 $M_H(G,C)$ 的二维 σ-模型。$B_{cc}$ 来自四维的**变形 Neumann 边界条件**，因此是全纯-拓扑的；$B_{\bar{cc}}$ 是其共轭。
- **膜量子化**：$A=\operatorname{Hom}(B_{cc},B_{cc})$ 给出 $M_H$ 上全纯函数代数的形变量子化；Hitchin 哈密顿量 $H_{P,\alpha}$ 量子化为作用在半密度 $K^{1/2}$ 上的对易微分算子 $D_{P,\alpha}$。$A$ 与 $\bar A$ 交换，因为插入在相反边界，且四维中多出的两个维度允许把支撑滑开。
- **出口**：Hilbert 空间 $\mathcal H=\operatorname{Hom}(B_{\bar{cc}},B_{cc})$，即 $M(G,C)$ 上的 $L^2$ 半密度空间（在 $T^*M(G,C)\subset M_H$ 上）。

## 第二段：镜像与 oper（§2.5–§3）

- **入口**：$M_H(G,C)$ 与 $M_H(G^\vee,C)$ 之间的电-磁对偶，低能表现为镜像对称：一边是复结构 $I$ 下的 A-模型，另一边是复结构 $J$ 下的 B-模型。
- **核心构造**：$B_{cc}$ 与 $B_{\bar{cc}}$ 在 B-模型中的对偶是复拉格朗日子流形 $L_{\mathrm{op}}$（全纯 oper）与 $L_{\mathrm{bop}}$（反全纯 oper）的结构层。oper 由 Beilinson–Drinfeld 引入；局部条件是存在截面 $s$ 使 $s\wedge Ds=1$（$\mathrm{SL}(2)$），一般群用主嵌入 $\mathfrak{sl}(2)\to\mathfrak g^\vee$ 与相应的 $s_{R,n}$。
- **出口**：B-模型的谱是 $\Upsilon=L_{\mathrm{op}}\cap L_{\mathrm{bop}}$；基 $\psi_u$ 由既全纯又反全纯的平坦 $G^\vee_{\mathbb C}$ 丛给出，Hitchin 特征值为 $f_{P,\alpha}(u)$。中心 $Z(G^\vee)$ 非平凡时还要加边界平凡化数据 $\varepsilon$。

## 第三段：线算符（§4–§5）

- **入口**：Hecke 函子作用在 A-膜范畴上；在规范理论中它就是 't Hooft 线算符 $T_{R,p}$，电-磁对偶把它送到 Wilson 线算符 $W_{R,p}$。
- **核心构造**：$T_{R,p}$ 是 $(B,A,A)$ 型界面；折叠后支撑在 Hecke 对应 $Z_{R,p}\subset M_H\times M_H$ 上，$Z_{R,p}$ 是 $X_{R,p}$ 的余法丛。对应的量子算符由积分核 $F(x,y)$ 给出；核的全纯因子 $f\in H^0(Z,K_Z^{1/2})$ 与反全纯因子 $\bar f$ 相乘给出半密度。Wilson 算符由平坦联络的和乐定义，在 $\psi_u$ 基上对角，特征值由 $s_R$ 与 $\bar s_{R'}$ 的配对给出。
- **出口**：'t Hooft 与 Wilson 算符都在 $\psi_u$ 基上对角；它们的特征值分别由 oper 数据与和乐数据给出，从而把几何朗兰兹的 Hecke 本征层翻译成谱问题。量子修正的 WKB 条件 $\oint_\gamma \lambda_K\in 2\pi\mathbb Z$ 决定哪些 $(F,S)$ 真正给出物理态；特殊几何的半平坦坐标 $X_\gamma=e^{Z_\gamma}$ 给出近似全纯截面。

## 第四段：实丛与手征代数（§6–§9）

- **入口**：$C$ 上的反全纯对合 $\tau$ 给 $M_H$ 一个反全纯对合；把 $\tau$ 提升到 $G$-丛需要固定圆上的自同构 $x_S$，其平方在伴随形式中为 $1$。不动点分支 $M_H^R$ 是实辛流形，可看成实可积系统；四维图像是 $M_\tau=\mathbb R\times U_\tau$ 上的 A-模型。
- **核心构造**：$\tau$ 不自由时出现 $Z_2$ 轨形奇异；实点的 't Hooft 算符由 Dirac 单极解描述，条件是 $x_S(m)=-m$。更一般地，BAA 边界条件与角的交汇支持一个手征代数 $\mathcal V$：变形 Neumann 与 Dirichlet 的交汇给临界 level $\kappa_c=-h$ 的 Kac–Moody 代数，$S_P(z)$ 生成其中心；Hecke 算符实现为谱流顶点算子 $\Sigma_m$，其积分给出中心算子。
- **出口**：辛玻色子（symplectic bosons）实现这些顶点算子与波函数；$\mathrm{Sp}(8)\supset \mathrm{SL}(2)^3$ 的三基本表示例子给出三个对易的 Hitchin 作用，Ramond 扇区的“奇妙模”解释其对称性。这条线把 §4–§5 的算子代数与 §7 的边界条件统一起来。

## 附录的作用

- **附录 A**（`coho`）：沿典范余迷向膜的局部算子与 $\varphi F$ 理论的量子修正；用规范理论论证 $H^1(M_H,\mathcal O)=0$，从而 Hitchin 哈密顿量的量子化无障碍。
- **附录 B**（`bmodel`）：B-模型的 Hilbert 空间、局域化、手征环与 Hermitian 配对；讨论 $L_{\mathrm{op}}\cap L_{\mathrm{bop}}$ 的横截性与正定性。
- **附录 C**（`somex`）：$\mathrm{SL}(2,\mathbb C)$ 与 $\mathrm{SL}(3,\mathbb C)$ 的典范 oper 截面显式关系。
- **附录 D**（`wobbly`）：判别式附近波函数的奇异行为；"摇摆除子"（wobbly divisor）的局部模型。
