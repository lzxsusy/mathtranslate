# 资料卡 05 · 猜测卡：一篇“解释”而不是“证明”的认识论分级

> 本卡不重复论文内容，也不替代 `01-结果清单.md`。它只做一件事：把全文的核心断言逐条标上**证据等级**，并写清“为什么是这个等级”“要升级还缺什么”。
>
> 结论先行：原文摘要把自己定位为 **“a gauge-theoretic interpretation”**（一种规范场论解释），不是“证明几何朗兰兹猜想”。全文真正属于 **T（已证或可逐行核对）** 的条目是少数；大量核心新断言属于 **P（物理论证）** 或 **K（明确猜想）**；另有一部分是 **V（作者愿景）**。本卡末尾还有 **S（我们自己的延伸猜测）**，与原文严格分开。

## 0. 先给结论：这张卡怎么用

1. **不要把 P 当 T 引用。** “物理上自洽 + 与已知数学匹配 + 在多个例子里成立”不等于数学证明。
2. **不要把 K 当已证结果。** 原文写 “conjectured”“we expect”“proposal” 的地方，本卡一律标 K；即使它在 SU(2)、U(1) 等特例中已知，一般 G 仍未证。
3. **不要把 V 当命题。** “解析版本是正确框架”“波函数会起有益作用”是纲领性判断，不是可证伪的单点断言。
4. **S 只能当提问。** 本卡标 S 的条目没有任何原文或文献依据，只是我们觉得值得检验的方向；不得反过来冒充作者观点。
5. 引用本卡时，请连同级别一起引用，例如“SY02-23 资料卡 05，K01”，不要简写成“该文已证”。

## 1. 分级标准

| 代码 | 名称 | 判定标准 | 引用时怎么写 |
| --- | --- | --- | --- |
| **T** | 已证 / 可逐行核对 | 有严格证明的数学文献（期刊论文、权威专著，或数学界广为接受的手稿），或原文给出可逐行复核的显式计算 | “已证”“可直接计算” |
| **P** | 物理论证 | 在量子场论、σ-模型存在性、膜量子化、余切丛近似等假设下给出的推导；数学上未证明 | “物理推导，数学未证” |
| **K** | 明确猜想 | 原文或所引文献明确写 conjecture / expect / proposal，且陈述本身可证伪 | “猜想”“提案” |
| **V** | 作者愿景 | 作者明说 hope / expect / should 的纲领性判断，不是单个可证伪命题 | “作者愿景，不是定理” |
| **S** | 本卡延伸猜测 | 我们自己的推测，没有原文或文献依据 | “我们的猜测，无依据” |
| **D** | 定义 / 框架 | 定义、约定、构造框架，本身无真假 | “定义”“框架” |

判定时执行以下纪律：

- 不因“物理上很自然”升级；不因“作者是 Witten”升级；不因“很多例子匹配”升级。
- T 只认严格数学文献或原文可核对计算；非期刊数学手稿（如 Beilinson–Drinfeld 的量子化书稿）标 T 时在“依据”栏注明“数学手稿，非期刊论文”。
- K 必须有原文的 conjecture / expect / proposal 措辞；仅有“we believe”但不可证伪的，归 V。
- 同样是 expect：若它是单点、可证伪的断言，归 K（如 K02）；若是“这个框架会有用”式的纲领判断，归 V（如 V02）。
- P 与 T 的差别不是“可信度高低”，而是**证据种类不同**：P 可以是极有说服力的物理推导，但它不是数学定理。
- 对同一断言，若原文一部分已证、一部分未证，拆成两行，不合并。

## 9. 三个不要误读的句子

### 9.1 “抽象谱”是定理，“具体本征态由 $\Upsilon$ 参数化”不是

- 量子 Hitchin 代数 $\mathcal A$ 的抽象谱（一维复表示空间）$\cong L_{\mathrm{op}}$ 是 BD 的定理（T07）；这一点原文明确归给 [BD]。
- “$\mathcal H$ 上的具体本征态由 $\Upsilon=L_{\mathrm{op}}\cap L_{\bar{\mathrm{op}}}$ 参数化、Hitchin 算子作用为 $f(u)$ 乘法”依赖 P02、P03、P04，以及 K01 的横截性。
- 正确说法：“抽象谱是 $L_{\mathrm{op}}$（定理）；在膜量子化的物理框架下，具体本征态由 $\Upsilon$ 参数化（物理推导，数学上一般 $G$ 未证）。”

### 9.2 WKB 条件不是精确的量子化条件

- P08 是 $\sigma$-模型微扰论**最低阶**的结果；作者原话：“we do not claim that the result is exact”（原文 1880 行）。
- P09 的量子修正只是“可以论证”，不是定理。
- 正确说法：“经典 WKB 条件是半经典近似；量子修正在 $t\to\infty$ 渐近展开中成立，但未证。”

### 9.3 “规范场论解释”不是“证明几何朗兰兹”

- 摘要用 “interpretation”，不是 “proof”。
- 全文大量使用已知数学（Hitchin、BD、仿射 Grassmannian、Kac–Moody），把物理与数学**组装**起来；组装的自洽性是 P，不是 T。
- 正确说法：“本文给出一个规范场论解释，并在此框架内推导出一批自洽的结论；它没有证明几何朗兰兹猜想。”
