## 一句话

这篇论文把几何朗兰兹对偶的“解析形式”放进四维 $\mathcal N=4$ 超对称规范理论：Hitchin 哈密顿量、Hecke 算符以及 Wilson–'t Hooft 线算符，都被实现为同一个量子态希尔伯特空间上的具体算子，而该空间来自对希格斯丛模空间的膜量子化。

## 三条主线

1. **膜量子化与 Hitchin 对易族。** 复辛流形上的 A-模型给出形变量子化；在希格斯丛模空间 $\mathcal M_H(G,C)$ 上，典范余迷向膜 $\mathcal B_{cc}$ 的自同态代数正是 Hitchin 哈密顿量生成的交换代数。其抽象谱是 oper 簇 $L_{\mathrm{op}}$（BD 定理）；在膜量子化的物理框架下，具体本征态由同时全纯与反全纯的 oper 所对应的平坦 $G^\vee_{\mathbb C}$-丛参数化（见 05 的 P04）。
2. **Hecke / 't Hooft / Wilson 算符。** 几何朗兰兹的 Hecke 函子在规范理论中就是 't Hooft 线算符；电–磁对偶把它与 Wilson 线算符互换。't Hooft 算符在 $\mathcal M_H$ 上表现为 Hecke 对应的积分核，其全纯–反全纯分解给出与 Hitchin 本征态一致的特征值。
3. **手征代数与谱流。** 四维半 BPS 边界条件的角上出现手征代数；临界 level 的 Kac–Moody 代数、其 Sugawara 中心、谱流模与辛玻色子配分函数，给出 Hecke 算符的顶点算子实现，并把“量子”几何朗兰兹的 $\Psi$ 参数与二维 CFT 联系起来。

## 讨论班路线

- **第一讲（§1–§2.2）**：几何朗兰兹的两种表述；复辛流形、B 场、Chan–Paton 线丛；$B_{cc}$ 与 $B_{\bar c c}$；折叠图像；半密度与 Hermitian 配对。
- **第二讲（§2.3–§3）**：$\mathcal M_H$ 的量子化；Hitchin 哈密顿量；oper 与反 oper；$L_{\mathrm{op}}\cap L_{\bar{\mathrm{op}}}$ 上的本征态；Hitchin 特征值。
- **第三讲（§4）**：线算符；Wilson 与 't Hooft；Hecke 修正与 Hecke 对应；积分核；仿射 Grassmann 流形与单极子冒泡。
- **第四讲（§5–§6）**：量子形变 WKB 条件；特殊几何；实丛与 $\tau$ 不自由作用；实 Hecke 算符。
- **第五讲（§7–§9）**：BAA 边界条件与角；手征代数；临界 Kac–Moody；谱流模；辛玻色子与三基本表示；Ramond 扇区。
- **附录**：A（$\mathcal M_H$ 量子化的上同调论证）、B（B-模型 Hilbert 空间与正定性）、C（oper 截面恒等式）、D（波函数在判别式附近的奇异性）。
