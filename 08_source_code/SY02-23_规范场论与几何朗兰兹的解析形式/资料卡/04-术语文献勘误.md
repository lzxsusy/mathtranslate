## 四、译注来源分级说明

- **A 级**：原文自身（Gaiotto–Witten 的定义、公式、脚注），以及 Beilinson–Drinfeld、Kapustin–Witten、Etingof–Frenkel–Kazhdan、Witten 等原始文献。
- **B 级**：nLab、Stacks Project、ProofWiki、arXiv 上的同主题综述或教科书（如 Di Francesco–Mathieu–Sénéchal 的 CFT 教材）。
- **I 级**：本库既有译本（SY02-06《规范理论、分歧与几何朗兰兹纲领》、SY02-16《算术与几何朗兰兹纲领》）的术语与表述。
- 找不到上述依据、仅凭上下文推断的，统一写“译者按（无外部依据）”；宁可少注，不补虚构出处。
