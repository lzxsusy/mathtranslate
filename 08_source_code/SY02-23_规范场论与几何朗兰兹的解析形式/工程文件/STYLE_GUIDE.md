# 翻译风格指南（SY02-23）

本文件是《规范场论与几何朗兰兹的解析形式》中译本的施工标准。所有参与翻译与审校的智能体必须先读本文件、`work/glossary.tsv` 与样板 `源码/chunks/ch01.tex`。

## 1. 底本与基本策略

- 底本：Gaiotto–Witten, *Gauge Theory and the Analytic Form of the Geometric Langlands Program*, arXiv:2107.01732v4，LaTeX 源码 `工程文件/work/原文/GLDraft_D.tex`。
- 以 arXiv LaTeX 源码为工作底本；`源码/chunks/chNN.tex` 已按行切块，块首注释给出对应原文行号。
- **只译散文**：章节标题、正文、图题、表题、脚注、致谢。公式、`\label`、`\ref`、`\eqref`、`\cite` 键、`\begin{equation}` 等环境、图文件名、文献表一律保持原样。
- 不重排公式，不改编号，不新增/删除 `\label`。原文公式按节编号（`\numberwithin{equation}{section}`），译文沿用。
- 原文的数学笔误照译，另加译注说明并列入 `work/疑点清单.tsv` 的“勘误”栏；不要径改原文公式。

## 2. 语言与文风

- 学术书面语，准确优先，句子可适当拆分；避免口语、网络语、过度意译。
- 人称：作者自称“我们”；“本文”指原文文章；“本译本”指中文译本。
- 首次出现的关键术语给英文原文，如“希格斯丛（Higgs bundle）”；同一术语后文不再重复英文。术语以 `work/glossary.tsv` 为准。
- 人名保留拉丁拼写（Beilinson、Drinfeld、Hitchin、Nahm、Witten 等）；'t Hooft、Wilson、Hecke 等不音译。
- 数学名词按通行译法：coisotropic=余迷向，half-density=半密度，chiral algebra=手征代数，spectral flow=谱流，oper 保留英文，brane=膜。
- 数字与单位：公式中的数字不动；正文中的“四维”“二维”用汉字，具体数值用阿拉伯数字。
- 标点：中文全角标点；公式后的句号按句子是否结束决定；`\cite{}` 前不留空格。
- 破折号用“——”；范围用“–”（如“§2.1–2.2”）；连字符用于复合词（Kac–Moody、Calabi–Yau）。

## 3. 标题、图、表、脚注

- `\section{}`、`\subsection{}`、`\subsubsection{}` 的标题译中文；`\label` 原样保留。原文标题前若有空格，保留其结构，不要吞掉参数。
- `\caption{}` 译中文，`\label` 保留；图内文字（若图是 PDF 且不可改）不译，可在图题或译注中说明。
- `\footnote{}` 全部译中文；作者原脚注与译者注分开：作者脚注沿用 `\footnote`，译者注用 `\zy{}`（生成“译注”序列），二者不混。
- 较长的概念性说明用 `\begin{yizhu}[标题] ... \end{yizhu}`，每块至多一个，放在相关段落之后；短说明用 `\zy{}`。

## 4. 译注规范（最重要）

译注的目的：帮助读者跨越物理/数学背景与术语障碍，**不是**展示知识。所有译注必须满足以下之一：

1. **有外部依据**：给出可核查来源。分级：
   - A 级：原始论文、作者讲义、标准教科书（如 Beilinson–Drinfeld、Kapustin–Witten、EFK 原文、Deligne、Kontsevich 等）。
   - B 级：nLab、Stacks Project、ProofWiki、arXiv 综述。
   - C 级：本仓库既有译本的译注（注明工程编号与文件）。
2. **无外部依据**：若只是译者对原文的解读、提醒或术语说明，必须写明“译者按（无外部依据）”，且不得声称任何文献事实。

硬性禁止：
- 禁止编造文献、作者、年份、页码、定理编号。
- 禁止引用知乎、百度百科、CSDN、简书、微信公众号、博客、视频课笔记。
- 禁止把“我推测”“一般应该”写成确定事实。
- 禁止用译注引入原文没有的数学结论；若必须提及，只能写“此处原文未展开，读者可参考……”并给出真实来源。
- 不确定就删。宁可少一条，不可多一条幻觉。

格式：
- 短注：`\zy{……}`，30–150 字。
- 长注：`\begin{yizhu}[译者按：短语] …… \end{yizhu}`，150–500 字，最多一个。
- 每条注只讲一件事；先点明原文何处难，再给解释/来源。
- 引用文献用自然语言（作者、题名、期刊/arXiv 号），不要新增 `\bibitem`；必要时用 `\cite{}` 指向原文已有条目。

## 5. 数学环境与宏

- 保留 `$...$`、`\[...\]`、`equation`、`align`、`array`、`pmatrix` 等全部环境与内部代码。
- 保留原文宏：`\M_H`、`\N`、`\C`、`\op`、`\bop`、`\G`、`\g`、`\A`、`\B`、`\F`、`\O`、`\Z`、`\R` 等；不要把它们展开成 `\mathcal` 等，以免与原文排版不一致。
- 中文与行内公式之间按需要留空格；不要在多行公式环境内部插入中文。
- 若某段公式前后有 `%` 注释掉的内容，不要翻译或恢复。

## 6. 术语与一致性

- 以 `work/glossary.tsv` 为唯一术语表；遇到表外术语，先在报告中提出，不要自造译名。
- 同一概念全篇统一：例如“规范场论”与“规范理论”择一（本译本正文用“规范场论”，指一般理论时可用“规范理论”，但同一段落内保持一致）。
- 专名首现给英文，后文不再给；缩写首现给全称，如“半 BPS（half-BPS）”。

## 7. 交付与自检

每个块的译者须：
1. 只改自己负责的 `chunks/chNN.tex`，不碰其他块、不改 `main.tex`/`preamble.tex`。
2. 翻完后通读一遍中文，检查：漏译、错译、公式被破坏、`\cite`/`\ref` 键改动、括号不配对。
3. 译注逐条自问：来源是真的吗？没有来源是否已标明？能否删掉而不损失？
4. 在报告中列出：完成行号、译注条数及分级、存疑术语、发现的原文笔误。
5. 不运行全文档编译（由 lead 统一编译）；可用 `grep`/脚本检查自己文件的括号与 `\zy` 配对。

## 8. 交叉审校

翻译完成后，另派审校智能体逐块审读译注：
- 逐条核对来源是否存在、是否支持该说法；
- 找出“无依据却写得像事实”的注；
- 检查术语是否与 glossary 一致；
- 审校者直接修订译注（可删、可降级为“无外部依据”、可补真实来源），并在报告中记录删改理由。
