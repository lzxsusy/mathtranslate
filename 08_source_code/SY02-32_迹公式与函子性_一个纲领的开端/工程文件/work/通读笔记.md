## 一、三句话主旨

1. 基本引理既已由 Ngô 证明，稳定迹公式在原则上可用；Langlands 由此提出以迹公式为引擎、逐步建立函子性的纲领，本文是该纲领的**第一篇文章**，只处理数域与有限域上一维函数域。
2. 文章把「用 L 函数本身（而非仅其对数导数）比较」作为技术核心：函子性提升 $H\to G$ 归结为比较两侧迹公式的主部，而主部的极点阶由 $\rho$ 在 ${}^{\lambda}H$ 上的分解给出；为此需要把稳定迹公式的椭圆正则项**阿代尔化**，化成有限维 $F$-向量空间上的一族局部因子 $\theta_v$ 的 Poisson 求和。
3. 末节验证该 Poisson 和的首项 $\hat\theta(0)$（即 $s\downarrow1$、截断趋于无穷时的极限）恰是 $\int_{G(\mathbb A_F)}f$，也就是一维自守表示（平凡表示）的贡献——这是纲领能启动的第一个正号。

## 二、论证地图

```
Ngô 基本引理 ──► 稳定迹公式可用
                     │
        §1  L 函数与极点：函子性 = 两侧迹公式主部比较
                     │        （ρ|_{^λH} 分解决定极点阶；难点是「乘法 vs 加法」）
        §2  函数域上的几何引理：K_{ρ,d} 与 S^d H^*_c(U, L_ρ(σ))
                     │        （把 Hecke 算子的 d 次对称幂实现为对称积上的上同调）
        §3  稳定迹公式的复习：假设、测度、Steinberg–Hitchin 基、
                     │        椭圆正则项、沿稳定共轭类的积分 θ_v
        §4  阿代尔化：θ_v 在 A_v 上紧支 ⟹ 对 B_η(F) ⊂ B_η(A_F) 用 Poisson；
                     │        Getz 截断绕开 θ̂ 的衰减问题；双重极限定义 θ̂(0)
        §5  首项：θ̂_v(0;s) = ∫ f_v + O(q_v^{-3/2})，故 θ̂(0) = ∫ f
```

- 逻辑链：基本引理 → 稳定迹公式 → （§3）椭圆正则项的稳定化 → （§4）阿代尔化 → （§5）首项 = 一维表示贡献。§2 是唯一真正使用函数域几何的一节，作用是给出 Hecke 算子的上同调模型，为后续文章（[FN]）铺路。
- 关键跳跃（作者自认）：§4 的 Poisson 和对 $\hat\theta_{S'}$ 的绝对收敛只是「乐观且不完全正确」的猜测，$\theta_v$ 在判别式轨迹上奇异；SL(2) 情形留待 [L5]。
- 文章反复强调的困难：$L$ 函数是**乘法**对象，迹公式是**加法**对象；用 L 函数而非对数导数比较，会引入 $\zeta_F^m$ 型因子，主部不再干净。

## 四、阅读顺序（给读者/译者的建议）

1. 先读导引（p.1–3）与 §5 结论（p.46–47 开头），知道目标是什么。
2. 再读 §1（p.3–12），抓住「极点阶 = $\rho$ 在 ${}^{\lambda}H$ 上平凡重数」这一主线索。
3. §3 可按 3.1（假设）→3.2（测度）→3.3（Steinberg–Hitchin 基）→3.4（椭圆正则项）→3.5（$\theta_v$ 的几何解释）顺序读；3.2 与 3.5 的测度归一化是全文最易错处。
4. §4 只需抓住「$\theta_v$ 紧支 ⟹ 可对 $B_\eta(F)\subset B_\eta(\mathbb A_F)$ 用 Poisson」与「双重极限」两点；细节留待 [L5]。
5. §2 可在读完 §4 后回读，它是为 [FN] 准备的几何引理，与主线相对独立。

## 六、初读即记的疑点（已解/待核见疑点清单）
