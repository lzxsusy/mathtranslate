## 三、三个「如果读者只想知道」

1. **函子性为什么与迹公式有关？** 因为迹公式给的是 $\sum_\pi\prod\mathrm{tr}\,\pi_v(f_v)$，而函子性预测的是 $L(s,\pi,\rho)$ 的极点；$\rho$ 限制到 ${}^{\lambda}H$ 的分解把 $L$ 函数拆成 $\zeta_F$ 与 $H$ 的 $L$ 函数之积 (1.3)，而迹公式的几何侧正好能算 $H$ 的贡献。
2. **为什么需要 $S'$ 截断？** 因为 $\theta_v$ 只紧支有界、不光滑，Poisson 对偶的和不绝对收敛；截断让两侧都有限，二重极限再把 $S'$ 放回无穷。
3. **主项为什么是 $\int f$？** 因为 $\hat\theta_v(0;1)=\int_{G(F_v)}f_v$（(5.2)），而 (5.7) 保证乘积收敛；于是「主项 = 全空间体积」，与 $G$ 的表示论细节无关。
