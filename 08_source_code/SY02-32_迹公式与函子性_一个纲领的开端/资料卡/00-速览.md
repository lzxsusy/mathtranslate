## 一句话

把 **函子性** 从「对数导数的极点」改写成「$L$ 函数本身的极点」：用 **稳定迹公式** 的几何侧，把每个自守表示 $\pi$ 的局部 $L$ 因子写成某个 $H$ 的 $L$ 函数与 $\zeta_F$ 的乘积，而迹公式的 **主项** $\hat\theta(0)$ 恰好等于 $\int f$——「稳定迹公式 + 几何 Langlands 的想法」由此成为验证函子性的一个可执行纲领。

## 三条主线

1. **解析侧：用 $L$ 函数代替对数导数**（§1）。Arthur 分类给 $\pi$ 附一个参数 $\varphi:\mathrm{SL}_2\to{}^L G$；若把 $\rho$ 与 $\varphi$ 复合分解成 $\bigoplus_j\sigma_j\otimes\rho_{H,j}$，则 $L^S(s,\pi,\rho)$ 是若干 $L^S(s+i,\pi_H,\rho_{H,j})$ 的乘积 (1.3)。迹公式是加法、$L$ 函数是乘法，这一错位正是全文的核心困难。
2. **几何侧：$L$ 函数的 Euler 积就是 $\mathrm{Bun}_G$ 上的几何和**（§2）。$\prod_v L_v$ 展开后系数是 Hecke 叠上的复形；$G$ 为函数域上的群概形时，$K_{\rho,d}(F)=F\otimes S^dH^*_c(U,L_\rho(\sigma))$（Lemme 2.6），经典自守形式理论由此变成 $\bar{\mathbb Q}_\ell$ 上的几何理论。
3. **整体侧：把迹公式「阿代尔化」再取主项**（§3–§5）。测度、Steinberg–Hitchin 基、椭圆正则项逐层搭起稳定迹公式 (3.17)；把沿稳定类的求和改写成 $A(\mathbb A_F)$ 上 $\theta$ 的求和 (4.4)，用 Getz 截断 + Poisson 对偶化成对偶和 (4.10)；最后证明 $\hat\theta(0)=\int_{G(\mathbb A)}f$（Prop 5.6）。
