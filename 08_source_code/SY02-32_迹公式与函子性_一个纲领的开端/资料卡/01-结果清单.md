# 资料卡 · 01 结果清单

原文的编号断言只有 10 条（8 个 Lemma、2 个 Proposition），大量内容以「编号公式 + 节内陈述」出现。本表按节组织，每条给「地位」：

- **已证**：原文给出证明或直接计算；
- **引理**：引用文献（Kottwitz、Ono、Laumon、Ngô 等），原文只标出处；
- **论证**：纲领性论证，不是完整证明；
- **猜想/待证**：作者明说「留待」「希望能证」。

式号与原文一致，可直接在译本中翻到；页码见 03。

5. **$G$ 非拟分裂、$m_G\rho_G\tau(G)\ne1$** 的情形：§4 起假设 $G$ 半单单连通以避开。
