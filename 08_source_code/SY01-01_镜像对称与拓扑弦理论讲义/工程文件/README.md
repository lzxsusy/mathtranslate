## 3. 排版约定

1. **公式编号锁定原文**：每个带编号公式写作 `\begin{equation}\tag{3.21} ... \end{equation}`，
   编号照抄原文，可用 `\eqref{eq:3.21}` 交叉引用（标签名即编号）。代价是增删公式不会自动重排编号，
   这是为了与原文逐式对照而刻意选择的。
2. **节标题层级与原文完全一致**，编号由 LaTeX 自动生成，故与原文章节号相同：`\section` 为 1–4，
   `\subsection` 为 2.1、3.5、4.4 等，`\subsubsection` 为 3.4.1、4.5.3 等。
3. **「本节重点」方框**（蓝色，`keytakeaways` 环境）与**「译注」方框**（橙色，`yizhu` 环境）是译者
   所加，非原文内容。译注分四类：易错点、含糊点、物理图像、原文疑误；每一条在源码中还有一行
   `% [Tutor Note: 类型] 摘要` 注释，便于检索。
4. **原文笔误**：一律照原文保留公式，另加 `% [原文疑误: ...]` 行内注释与一条「原文疑误」译注说明理由，
   不擅自改动（清单见 §5）。
5. **页码锚点**：每个片段在原文每页起始处插入 `% ==== 原文 PDF 第 N 页 ====`，便于与原文对照。
6. **参考文献**：正文引用经脚本转为 `\cite{refN}`，渲染为 `[N]`，编号与原文一致；文献著录保留英文，
   期刊名斜体、卷号粗体、arXiv 号等宽（复现原文 CMTI/CMBX/CMTT 字体）。

## 4. 插图说明（图表审计结论）

原文 **没有带编号的 Figure/Table 环境**，也没有嵌入任何位图。逐页矢量审计（PyMuPDF `get_drawings`）
表明：

- 44 页中仅**第 31 页**存在一张实质性的矢量插图：全纯反常方程 (4.24) 与 (4.25) 之间的亏格 $g$
  黎曼面示意（四联图：$g$、$g_1$、$g_2$、$g-1$，标有 $D_i,D_k$ 与 $\tfrac12\bar C^{jk}_{\bar\imath}$）；
  原文未给图号与图注。
- 其余各页的 "drawing" 均为公式排版产生的分数线、上下划线、矩阵/表格框线，不构成图。
- 原文中的 A/B 对照表（式 3.2）是编号公式的一部分，已用 `equation` + `array` 复现并保留 `\tag{3.2}`，
  不作为表格处理。

因此译本只有 **图 1**：按原文位置插入 (4.24) 之后、(4.25) 之前，图注中译并注明
「原文第 31 页，式 (4.24) 之后；原文未编号，此处编号为译者所加」。裁切自 PDF 矢量（420 dpi，
2026×569 px），不是屏幕截图。

## 6. 审校批注与本节重点

- 每个 `\section` 开头有蓝色「本节重点」方框，提炼该节**物理图像 / 数学工具 / 关键结论**
  （3–5 条，非标题复述）；3.5、3.6、4.4、4.5 等较长小节也各自添加。
- 96 条橙色译注全部有实质内容，分三类：
  1. **易错点**：指标缩并、$\imath/\jmath$、$\bar\partial$ 方向、$2\pi$ 与 $1/2$ 因子、反常系数、
     $\chi/24$ 修正、联络矩阵的零结构等，均点名核对原文哪个公式/约定；
  2. **含糊点**：作者用 "it is obvious / one finds / it can be shown" 跳过之处，说明被省略的论证实质
     （如谱流同构、Griffiths 横截性推出 Picard–Fuchs、模空间边界导致全纯反常等）；
  3. **物理图像**：形式推导背后的物理（如 B 模型为何无瞬子、$tt^*$ 度规与 CPT 算符、镜像映射与
     瞬子数校验 $2875, 609250, 317206375$ 等）。
- 汇总索引见 `REVIEW-NOTES.md`；权威内容在源码 `yizhu` 环境中。
