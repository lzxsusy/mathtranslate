## 本节重点（keytakeaways）


### 01-s01 · 引言

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
\item **物理图像**：把 ${\EUN}=4$ 超对称杨-米尔斯理论放在 $\Sigma\times C$ 上、令 $\Sigma$ 的尺度趋于零，低能有效理论是以 $C$ 上 Hitchin 模空间 ${\EUM}_H$ 为靶空间的二维拓扑 sigma 模型；四维的电-磁对偶（$S$-对偶）在二维约化为 Hitchin 纤维化纤维上的 $T$-对偶，即镜像对称。
\item **数学工具**：超凯勒流形 ${\EUM}_H$ 及其复结构 $I$（稳定 Higgs 丛）与 $J$（平坦 ${}^L\negthinspace G_{\Bbb{C}}$-丛）、Hitchin 纤维化与 SYZ 纤维 $T$-对偶、Fourier--Mukai 变换、Hecke 特征层与 ${\cal D}$-模、Wilson 与 't Hooft 线算子。
\item **关键结论**：GNO 双群就是 Langlands 对偶群 ${}^L\negthinspace G$（Atiyah 于 1977 年的提示）；Montonen--Olive 对偶在 ${\EUN}=4$ 理论中自然扩展为 $SL(2,\Bbb{Z})$（计入 theta 角后）；全文的六个主要想法串起「扭化 $\to$ 紧化 $\to$ 膜 $\to$ 线算子即 Hecke 算子 $\to$ ${\cal D}$-模」这条链条。
\item **边界与展望**：本文只处理几何 Langlands 对应的非分歧情形；二维共形场论在其中的作用尚未阐明；分歧情形与更一般的边界条件留待后续工作。
\end{itemize}


### 02-s02 · ${\EUN}=4$ 超对称杨-米尔斯理论与 $S$-对偶

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
\item **物理图像**：十维超对称杨-米尔斯理论经维数约化给出四维 ${\EUN}=4$ 理论——十维规范场分解为四维规范场与六个标量场，十维的 16 分量旋量分解为四组四维 Weyl 旋量，即四个超荷；这是四维可能的最大超对称。
\item **数学工具**：Clifford 代数与旋量表示、$\Gamma$ 矩阵的手征性与 $\bar\Gamma$ 分次、超荷代数 $\{Q_a,Q_b\}=\sum_I\Gamma^I_{ab}P_I$、$Spin(6)\cong SU(4)$ 的 $R$-对称、复耦合 $\tau=\theta/2\pi+4\pi i/e^2$。
\item **关键结论**：四维作用量在要求关于导数二次时由两个参数 $e$ 与 $\theta$ 唯一确定；$\theta$ 是角变量（$\theta\cong\theta+2\pi$），$\tau\to\tau+1$ 是初等对称性；超荷代数在边界条件下出现附加的中心荷项，为下一小节的 $S$-对偶与几何 Langlands 纲领埋下伏笔。
\item **边界与展望**：本节只做「回顾」，真正的舞台是下一小节：$S$-对偶把 $\tau\to-1/\tau$ 与规范群的对偶 ${}^L\negthinspace G$ 联系起来。
\end{itemize}


### 04-s03 · 从 ${\EUN}=4$ 超对称杨--米尔斯理论得到的拓扑场论

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
\item **物理图像**：把 ${\EUN}=4$ 超对称杨--米尔斯理论的自旋群 $Spin(4)$ 换成它在 $Spin(4)\times Spin(6)$ 中的对角子群——这就是扭化；其效果是让某个超荷变成标量荷 $Q$，从而在任意四维流形上得到一族以 $\Bbb{CP}^1$ 为参数的拓扑场论，$S$-对偶作用在这个参数上。
\item **数学工具**：$Spin(4)$ 与 $R$-对称群 $Spin(6)=SU(4)_R$ 的表示论、${\EUN}=4$ 超对称变换律、十维旋量在四维语言下的分解、标量超荷确定的 $Q$-上同调，以及后文的消灭定理与单圈局域化。
\item **关键结论**：扭化后的拓扑超荷取 $Q=uQ_\ell+vQ_r$，参数 $t=v/u$ 只在 $t\mapsto-t$ 下等价（这一等价来自经典作用量的 $U(1)$ 对称性）；因此本质的区分是按 $t=\pm i$（平坦 $G_{\Bbb{C}}$ 联络）与实 $t$（椭圆方程、计数解）来划分的。
\item **边界与展望**：扭化在 Lorentz 号差下并不好用，故全文以欧氏号差为准，只在 $M=\Bbb{R}\times W$、$\Bbb{R}^2\times C$ 这类有「时间方向」的分解下临时回到 Lorentz 号差。本节随后将写出超对称拉格朗日量，并引入典范参数 $\Psi$。
\end{itemize}


### 08-s04 · 紧化与 Hitchin 模空间的几何

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
\item **物理图像**：把四维扭化 ${\EUN}=4$ 超对称杨--米尔斯理论放到 $M=\Sigma\times C$ 上，并令 $C$ 远小于 $\Sigma$；于是在 $\Sigma$ 上只剩一个以 Hitchin 模空间 $\MH(G,C)$ 为靶空间的超对称 sigma 模型，四维规范场论退居为构造 Wilson 算子与 't Hooft 算子的「母体」。
\item **数学工具**：$C$ 上的 Hitchin 方程 $F-\phi\wedge\phi=0$、$D\phi=D^*\phi=0$；当亏格 $g>1$ 时，$\MH(G,C)$ 是复维数为 $(2g-2){\rm dim}\,G$ 的复流形，它的奇点对应于带有连续未破缺规范对称性的可约解。
\item **关键结论**：$\MH$ 光滑点处的位形给出从 $\Sigma$ 到 $\MH$ 的常映射（零作用量），近似零作用量则给出缓变映射；$\Sigma$ 远大于 $C$ 的假设保证缓变映射存在且作用量很小，于是 $\Sigma$ 上的长距离物理就由该 sigma 模型描述。
\item **边界展望**：上述图像在 $\MH$ 的奇点处失效（此时 $\sigma\not=0$，解不必从 $C$ 拉回），$G=U(1)$、$U(N)$ 的情形也需要额外修正；本文因此始终避开奇点，只考虑不可约平坦丛的 Langlands 对应。
\end{itemize}


### 11-s05 · 二维拓扑场论

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
    \item **物理图像**：把第~\ref{sec:tqftfour}~节得到的四维扭化规范理论放到 $M=\Sigma\times C$ 上紧化（$C$ 是一张黎曼面），低能有效理论就是以 Hitchin 模空间 $\MH$ 为靶空间的二维拓扑 sigma 模型；$\MH$ 的超凯勒结构使它自动具有 $(4,4)$ 超对称。
    \item **数学工具**：四维扭化参数族 $\Bbb{CP}^1_g$ 与二维 $(2,2)$ 超对称所需的复结构对 $(J_+,J_-)$（即 $\Bbb{CP}^1_h\times\Bbb{CP}^1_h$ 中的一点）可以对齐，嵌入由 $w_+=-t$、$w_-=t^{-1}$ 给出，这里 $t$ 是四维扭化参数。
    \item **关键结论**：四维 $S$-对偶在二维表现为镜像对称——它交换 $A$-模型与 $B$-模型，从而把几何 Langlands 纲领表述为 Hitchin 模空间上膜范畴之间的等价。
    \item **边界与展望**：当 $J_-\ne\pm J_+$ 时所得模型既非 $A$-模型也非 $B$-模型，需要广义复几何才能把它约化为 $A$-模型；这正是本节后半与后续各节的出发点。
  \end{itemize}


### 15-s06 · 圈算子与线算子

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
\item **物理图像**：本节讨论的四维 TQFT 允许插入与定向一维子流形 ${\cal S}\subset M$ 相联系的算子。这些算子的参数不是普通的「点」，而是环路或通向无穷远的线，因而被称为圈算子与线算子。
\item **数学工具**：这类算子依赖 ${\cal S}$ 的同伦类而不只是同调类；在 $t=\pm i$ 处，可以用 $A$ 与标量场 $\phi$ 的复化联络 $\CA=A+i\phi$（或 $\overline\CA=A-i\phi$）的 holonomy 构造具有拓扑对称性的 Wilson 算子。
\item **关键结论**：Wilson 算子是四维理论中最基本的圈算子；它的磁对偶 't Hooft 算子将在第~\ref{sec:tophooft}~节引入。紧化到二维后，线算子可以被解释为作用在膜上的算子，这正是通向几何 Langlands 纲领的入口。
\item **边界与展望**：对有端点或通向无穷远的线算子须小心处理；在非紧四维流形上，静态线算子必须纳入量子化以构造物理态空间，这是本文应用中最重要的情况。
\end{itemize}


### 19-s07 · 通量与 $S$-对偶

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
    \item **物理图像**：规范群的中心 $\CZ=\pi_1(G_{\rm ad})$ 是有限阿贝尔群，并且具有自然的自对偶；这使离散磁通量 ${\bf m}$ 与离散电通量 ${\bf e}$ 可以取遍互为对偶的有限群 ${\bf M}$、${\bf E}$，从而让 $S$-对偶在量子理论中得以实现。
    \item **数学工具**：把理论放在 $M=S^1\times W$ 上，$\Gad$-丛的特征类 $\xi(E)$ 分解为 ${\bf a}\in H^1(W,\CZ)$ 与 ${\bf m}\in H^2(W,\CZ)$ 两部分；庞加莱对偶给出完美配对 $H^1(W,\CZ)\times H^2(W,\CZ)\to U(1)$，故二者互为对偶的有限阿贝尔群。
    \item **关键结论**：固定 ${\bf m}$ 有 Hilbert 空间解释，固定 ${\bf a}$ 则没有，因此须对 ${\bf a}$ 作傅里叶变换、引入特征标 ${\bf e}$，得到 ${\cal H}_{{\bf e},{\bf m}}$；$S$-对偶交换 ${\bf E}$ 与 ${\bf M}$，把 $({\bf e},{\bf m})$ 送到 $(-{\bf m},{\bf e})$，并把 $\tau$ 送到 $-1/\tau$。
    \item **边界与展望**：泛丛对伴随群 $G_{\rm ad}$ 存在，对单连通覆盖 $\bar G$ 则被非平凡类 $\zeta=\xi(\EUE_{\rm ad})\in H^2(\M,\CZ)$ 所阻碍；但它总可以作为扭化向量丛存在。
  \end{itemize}


### 21-s08 · 电特征膜

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
    \item **物理图像**：Wilson 线算子作用于膜，就是把 Chan-Paton 丛（或层）与泛丛在 $p\in C$ 处的表示版本 ${\EUE}_p(R)$ 作张量积；由于 ${\EUE}_p(R)$ 一般只是扭化向量丛，这一作用同时把离散电场 ${\bf e}_0$ 平移 $\theta_R$。
    \item **数学工具**：零膜的 Chan-Paton 层是天穹层 $U_x$，限制到点上一切丛都平凡，于是特征值只是一个固定向量空间 ${\EUE}_q(R)|_x$；随 $q$ 变化它成为 $C$ 上平坦丛的纤维（取复结构 $J$ 时即泛平坦 $G_{\Bbb{C}}$ 丛），这正是几何 Langlands 一侧的数据。
    \item **关键结论**：支撑在 $\MH$ 光滑点 $x$ 的零膜是电特征膜；对它作 $S$-对偶得到 $\MH(G,C)$ 中支撑在 Hitchin 纤维 ${\CMF}$ 上、带秩一平坦 Chan-Paton 丛的磁特征膜（type ${\CMF}$ 膜），后者对应几何 Langlands 纲领中的 Hecke 特征层与完整 ${\cal D}$-模。
    \item **边界与展望**：更精确地说，电特征膜是不同 ${\bf e}_0$ 的扭化零膜之和，磁特征膜是 $\MH$ 各拓扑分支上膜之和；本文后续各节用 't Hooft 算子与 Hecke 算子的对应来验证 type ${\CMF}$ 膜确实具有 Hecke 特征层所需的性质。
  \end{itemize}


### 22-s09 · 't Hooft 算子与 Hecke 算子

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
    \item **物理图像**：在 $\Psi=0$（即令 $t=1$、$\theta=0$）处，四维拓扑场论在二维约化为靶空间为 Hitchin 模空间 $\MH$、复结构为 $K$ 的 $A$-模型；支撑在 $\Bbb{R}\times p$ 上的静态 't Hooft 圈算子在二维就是该 $A$-模型中的缺陷，它靠制造指定的奇点来起作用。
    \item **数学工具**：$A$-模型的经典位形是全纯映射，其态空间的经典近似是常值映射空间的上同调（在 Floer 理论中即两个拉格朗日子流形之交的上同调，需按 Maslov 指标移动维数）；四维侧用消灭定理与 Bogomolny 方程 $F=\star D\phi_0$（BPS 单极子方程）把问题化到三维。
    \item **关键结论**：静态 't Hooft 算子实现 $G$-丛的 Hecke 变换。局部写 $E=\oplus_i{\cal L}_i$ 后，算子 $T({}^L w)$ 的作用恰为 ${\cal L}_i\to{\cal L}_i\otimes{\cal O}(p_0)^{m_i}$，这正是几何 Langlands 纲领中 Hecke 修正的标准数学定义，因此 't Hooft 算子对应 Hecke 算子。
    \item **边界与展望**：本节只处理普通 Bogomolny 方程；几何 Langlands 的实际应用需要放宽时间反演对称性，改用复化（扩展）的 Bogomolny 方程，此时 't Hooft 算子给出 Hitchin 对 $(E,\varphi)$ 的 Hecke 变换，见第~\ref{sec:extbog}~节。
  \end{itemize}


### 26-s10 · Bogomolny 方程与 Hecke 修正的空间

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
    \item **物理图像**：给定型 $^L\negthinspace w$ 的 Hecke 修正空间，可以呈现为三维流形 $W=I\times C$ 上带 't Hooft 算子奇点、并带适当椭圆边界条件的 Bogomolny 方程解模空间。$E_-$ 端固定联络 $A_-$（Dirichlet）而让 $\phi_0$ 自由，$E_+$ 端令 $\phi_0=0$（协变 Neumann）而让 $A$ 自由；交换两端的保向自同构 ${\cal PT}$ 同时反转时间坐标。
    \item **数学工具**：指标理论。Bogomolny 方程线性化给出椭圆复形 $0\to\Omega^0({\rm ad}(E))\to\Omega^1({\rm ad}(E))\oplus\Omega^0({\rm ad}(E))\to\Omega^2({\rm ad}(E))\to 0$，其指标即模空间的虚拟维数；Pauly 借助 Kronheimer 的 $U(1)$-不变瞬子与等变指标定理，把奇点的贡献化为不动点的贡献。
    \item **关键结论**：Hecke 修正空间的复维数 $\Delta$ 等于各 't Hooft 算子贡献之和 $\Delta=\sum_i\Delta_{\rho_i}$；无算子时维数为零，单个 $T(\rho)$ 时 $\Delta_\rho=\sum_k c_k$。对 $G=PSU(2)$、最高权 $(a/2,-a/2)$ 贡献为 $a$，与第~\ref{sec:spaceheck}~节的维数公式一致，并推广到任意紧 Lie 群 $G$。
    \item **边界与展望**：指标理论只给出（虚拟）维数，不直接构造模空间；要定义任意 $A$-膜的 Hecke 变换并用于几何 Langlands 对偶，还需放弃时间反演不变性、改用复化（扩展）的 Bogomolny 方程。
  \end{itemize}


### 31-s11 · $A$-膜与 ${\cal D}$-模

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
    \item **物理图像**：几何 Langlands 对应的左端已知是电特征膜（即 $\pi_1(C)\to{}^L\negthinspace G$ 的同态），其对偶是缠在 Hitchin 纤维上、带平坦 Chan-Paton 丛的磁特征膜；但通常表述的右端并不是 $\MH$ 上的 $(A,B,A)$ 型膜，而是 $G$-丛模空间上的 ${\cal D}$-模。本节的物理任务就是补上这最后一段翻译。
    \item **数学工具**：${\cal D}$-模是微分算子层的模；把 $\M(G,C)$ 上的 ${\cal D}$-模看成其余切丛的非交换形变上的 $B$-膜，则 $A$-膜的范畴与这类 $B$-膜范畴的等价（原文引 Kapustin 的论证）使「$A$-膜给出 ${\cal D}$-模」成为该等价的一个特例。
    \item **关键结论**：$\MH(G,C)$ 上复结构 $K$ 中的每个 $A$-膜都自动给出（粗略地说）$\M(G,C)$ 上的一个 ${\cal D}$-模；这就是所谓 A-膜到 D-模的翻译器，是几何 Langlands 纲领与规范理论对偶之间缺失的一环。
    \item **边界与展望**：严格处理不能只停留在稳定丛的模空间 $\M(G,C)$，而要在所有 $G$-丛的栈 ${\rm Bun}_G(C)$ 上构造 ${\cal D}$-模（Hecke 算子的作用方式要求如此）；相应地，所关心的膜必须能在底层规范理论中定义，而不只是在靶空间为 $\MH(G,C)$ 的 sigma 模型中定义，这一点在第~\ref{sec:zapendix}~节证明。
  \end{itemize}


### 35-s12 · 规范场论中的膜

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=2pt]
\item **物理图像**：本文关心的几类膜——零膜（$(B,B,B)$）、Hitchin 纤维（$(B,A,A)$）、典范余各向同性膜（$(A,B,A)$）——都可以提升为四维 ${\EUN}=4$ 超 Yang-Mills 理论中的边界条件。边界条件保持超对称的判据是超流的法向分量在边界上为零；由于约化到二维并扭化会再砍掉一半超荷，规范场论中保持四分之一超对称的膜，在 sigma 模型语言里称作 $1/2$ BPS 膜。
\item **数学工具**：用十个 $\Gamma_I$ 与 $\Gamma_{2367}$ 把超荷投影到扭化后保留下来的子空间，边界条件写成 $T\epsilon=\epsilon$、$\Gamma_{2367}\epsilon=\epsilon$；由费米子的边条件反推玻色子的边条件，再验证 $\bar\epsilon J_1=0$ 与 $\delta\lambda$、$\delta A_I$ 的变分相容；边界值上的 Hitchin 方程由 $F_{IJ}$ 在特定子空间内自对偶而自然出现。
\item **关键结论**：取 $T=\Gamma_{04}$ 并要求 $T\lambda\vert=\lambda\vert$，会推出 $F_{0I}+F_{4I}=0$（$I\neq0,4$）与 Hitchin 方程 $F_{23}=F_{67}$ 等，于是规范场在边界上的取值在 $\MH$ 中挑出一点 $p$，得到支撑在 $p$ 的零膜。改用 $\tilde T=T\Gamma_{2367}$ 可得另一构造：它在平坦时空中只保四个超荷，但在 $\MH$ 的光滑点处与旧构造在低能理论中等价。
\item **边界与展望**：当 $p$ 对应可约 Higgs 丛时，两种零膜构造未必等价（$A_4,A_5,A_8,A_9$ 的零模给出 Higgs 丛的对称性）；另一半超对称边界条件只在远离奇点处才与二维图像相符。事实上提升到规范场论并不唯一，本文只给出足以展示关键膜的少数简单构造。
\end{itemize}

## 易错点（77 条）


**[01-s01]** 按：原文说磁荷取值于「对偶群的权格」，这句话容易与「原群的余权格」混淆，二者其实是同一个格：${}^L\negthinspace G$ 的权格按定义就是 $G$ 的余权格。因此，若只强调电荷格与磁荷格互换，两种说法等价。但要注意，电-磁对偶互换的是「格」而不只是「群」：规范群的中心与整体形式会随之改变，这正是 GNO 与 Langlands 两套语言能够对上号的关键。


**[02-s02]** 按：本节的号差与符号约定必须成套地看：$ds^2=\mp(dx^0)^2+\cdots$ 中上符号对应 Lorentz 号差、下符号对应欧几里得号差；反厄米规范场约定 $A=-iA'$ 连带曲率 $F=-iF'$；欧几里得号差下还必须整体翻转拉格朗日量的符号才能让作用量的玻色部分正定。后面 BPS 方程与 Hitchin 方程的符号都建立在这些约定之上，抄公式时不要混用物理文献的厄米约定。


**[02-s02]** 按：$Spin(6)\cong SU(4)$ 是 ${\EUN}=4$ 理论的 $R$-对称群，四个超荷属于 $\mathbf{4}$ 与 $\bar{\mathbf{4}}$（见式 \eqref{eq:jugo}）。$R$-对称是超荷之间的对称性，与规范群 $G$ 无关；后文讨论拓扑扭化时，正是从 $SU(4)_{{\cal R}}$ 里挑出一个 $U(1)$ 或 $SU(2)$ 子群来定义扭化，因此这里的表示分解不是装饰，而是后文构造的出发点。


**[02-s02]** 按：手征性在十维与四维的记号不同：十维的 $\bar\Gamma=\Gamma_0\cdots\Gamma_9$ 特征值为 $\pm1$，而四维的 $\hat\Gamma$、$\Gamma'$ 特征值成了 $\pm i$（欧几里得号差下的约定）。式 \eqref{eq:yug} 说的不是「两者各自为正」，而是「两者的特征值互为相反数」。若按 Lorentz 号差的实特征值去套，会差出 $i$ 因子。


**[03-s02]** 按：「单连通型」（simply-laced）这一译名容易与拓扑上的「单连通」（$\pi_1(G)=0$）混淆，两者无关。simply-laced 指 Dynkin 图上没有多重边、所有根等长，即 $A_n$、$D_n$、$E_6$、$E_7$、$E_8$；与之相对的是 $B_n$、$C_n$、$F_4$、$G_2$（有长根与短根）。本文用 $n_{\frak g}$ 统一记这一「链环数」：单连通型为 $1$，$B_n$、$C_n$、$F_4$ 为 $2$，$G_2$ 为 $3$。译名以术语表为准。


**[04-s03]** 按：这一段同时出现两个「手征算子」，极易混淆。$\hat\Gamma_E=\Gamma_0\Gamma_1\Gamma_2\Gamma_3$ 是四维的，它区分 $Spin(4)$ 的两个 Weyl 表示 $(\btwo,\bone)$ 与 $(\bone,\btwo)$；而 $\bar\Gamma_E=\Gamma_0\cdots\Gamma_9$ 是十维的，它区分十维旋量的手征性，在四维语言里就是区分 ${\EUS}^\pm$。式~\eqref{eq:nohinks} 里的 $-i$ 只是一个约定，取决于我们选定的 Wick 转动方向 $ix^0_L=x^0_E$；但它是全文符号簿记的起点：后文式~\eqref{eq:banother} 的 $\Gamma_{89}\epsilon=-i\epsilon$、以及扭化超荷的 $\EUK=-1$ 标定，都由此决定。若把转动方向反过来，全篇的 $i$ 会一致地变号，而物理结论不变。


**[05-s03]** 按：这里说的三种扭化，不要与 ${\EUN}=2$ 理论的 Donaldson--Witten 扭化混为一谈。对 ${\EUN}=4$ 而言，三种扭化对应同态 $\varkappa:Spin(4)\to Spin(6)$ 的三种不等价取法（相差 Weyl 群的作用）：其中两种给出与 Donaldson 理论类似的瞬子不变量，只有第三种——本文的 GL 扭化——与几何 Langlands 纲领有关。一个实用的判据是 $S^+$ 中保留几个 $Spin'(4)$-不变旋量：前两种各保留一个，GL 扭化保留的则是两个独立不变旋量张成的整个二维复空间（正是这一点使后文出现以 $\Bbb{CP}^1$ 为参数的扭化族）。


**[05-s03]** 按：$({\bf 2},\bone)^{1}\oplus(\bone,{\bf 2})^{-1}$ 里的上标 $1,-1$ 是 $-i{\cal K}$ 的本征值 ${\EUK}$，而不是 ${\cal K}$ 本身的本征值——式~\eqref{eq:orml} 中 ${\cal K}$ 的定义带一个因子 $i$，所以 ${\cal K}$ 的本征值是 $i$ 与 $-i$，$-i{\cal K}$ 的本征值才是 $\pm 1$。这个约定贯穿全文：$\phi_\mu$ 的 ${\EUK}=0$，$\sigma,\bar\sigma$ 的 ${\EUK}=\pm 2$，扭化超荷的 ${\EUK}=1$，全部按此记账。另外 ${\bf 4}$ 与 $\bar{\bf 4}$ 的指数互为相反数：${\bf 4}$ 是 $({\bf 2},\bone)^{1}\oplus(\bone,{\bf 2})^{-1}$，$\bar{\bf 4}$ 是 $({\bf 2},\bone)^{-1}\oplus(\bone,{\bf 2})^{1}$，切勿混用。


**[05-s03]** 按：$t\sim-t$ 是唯一的平凡等价，这句话的分量全在「唯一」二字。理由本段已经给出，但值得用群论重述一遍：如果 $\epsilon_\ell$ 与 $\epsilon_\rr$ 的 ${\cal K}$ 本征值不同，那么由 ${\cal K}$ 生成的连通群 $\Bbb{C}^*$ 会连续地移动 $t$，把 $\Bbb{CP}^1$ 上的每个参数都推入同一个等价类，整族理论随之平凡化，$S$-对偶带来的对偶性也就无从谈起。正因为两者本征值相同（都等于 $-1$，见式~\eqref{eq:banother}），连通的 $\Bbb{C}^*$ 在 $t$ 上作用平凡，只剩下中心元给出的离散 $\Bbb{Z}_2$：$t\mapsto-t$。


**[05-s03]** 按：这里的 ${\EUK}$ 记账是全文最容易出错的地方：扭化旋量 $\epsilon_\ell,\epsilon_\rr$ 的 ${\EUK}=-1$，而由它们生成的超荷 $Q_\ell,Q_\rr,Q$ 的 ${\EUK}=+1$；因为 $\delta_T\Phi=[Q,\Phi\}$，$\delta_T$ 把每个场的 ${\EUK}$ 提高 $1$。于是费米场与玻色场的配对不按自旋，而按 ${\EUK}$ 的奇偶：${\EUK}=1$ 的费米场（$\psi,\tilde\psi$）是 $Q$ 的搭档，${\EUK}=-1$ 的（$\chi^\pm,\eta,\tilde\eta$）出现在 $\delta_T$ 的右边。这也解释了为什么 $\sigma$（${\EUK}=2$）在 $\delta_T$ 下不变：要把它映到某个 ${\EUK}=3$ 的场，而理论中没有这样的场。


**[06-s03]** 按：脚注里"取 $\delta_T\eta=0$ 与 $\delta_T\tilde\eta=0$ 的 $t$-依赖线性组合"这句话，是理解式~\eqref{eq:loopme} 中第三条方程 $D^*\phi=0$ 来历的关键。直接由式~\eqref{eq:helpme} 令 $\delta_T\eta=0$ 与 $\delta_T\tilde\eta=0$，得到的是 $vD^*\phi+u[\bar\sigma,\sigma]=0$ 与 $-uD^*\phi+v[\bar\sigma,\sigma]=0$；把两式按适当系数组合消去 $[\bar\sigma,\sigma]$，就得到 $D^*\phi=0$，但组合系数的行列式正比于 $u^2+v^2$，故只在 $t^2\not=-1$（即 $t\not=\pm i$）时可以这样做。$t=\pm i$ 时这两式线性相关，只能得到 $D^*\phi\pm i[\bar\sigma,\sigma]=0$，这正是后文在式~\eqref{eq:toopme} 之后特别说明的情形。


**[06-s03]** 按：消灭定理 1 是关于固定丛 $E$ 上的经典方程无解的陈述，而不是关于配分函数的陈述：它说的是对任意 $t\not=0,\infty$，方程 $\EUV^\pm(t)=\EUV_0=0$ 在 $E$ 上根本没有解，因此配分函数为零。这类"一阶方程 + 非零拓扑荷"的消灭现象在超对称方程中很常见（全纯曲线、Yang--Mills 瞬子、Seiberg--Witten 方程都有类似结论），其共同机制是把方程写成平方和等于拓扑荷的形式（见式~\eqref{eq:hombo} 与式~\eqref{eq:ormob}）：若平方和为零而拓扑荷非零，就不可能。定理 1 的证明只在 $t\not=0,\infty$ 有效，而 $t=0,\infty$ 处确实有解，这一点下文会说明。


**[07-s03]** 按：(3.35) 给出的代数对 $\EUK\geq 0$ 的场无需运动方程即成立。$\EUK$ 是扭化所用的那个 $U(1)$ 荷（第~\ref{sec:twisting}~节已逐个标定各场取值）：$A$ 与 $\phi$ 的 $\EUK=0$，$\psi$ 与 $\tilde\psi$ 的 $\EUK=1$，$\chi,\eta,\tilde\eta$ 的 $\EUK=-1$，而 $\sigma$ 的 $\EUK=2$、$\bar\sigma$ 的 $\EUK=-2$；相应地，$\delta_T$ 每作用一次便把 $\EUK$ 提高 1。$\sigma$ 位于最高处，$[\sigma,\sigma]=0$ 使 (3.35) 的最后一行 $\delta_T{}^2\sigma=0$ 与通式自洽；反过来，对 $\EUK<0$ 的 $\chi,\eta,\tilde\eta$，其变换含 $\sigma$ 以外的非线性项，代数在壳外并不闭合，这正是下一段需要辅助场的根源。


**[07-s03]** 按：$H$ 是 2-形式（其自对偶部分 $H^+$ 与反自对偶部分 $H^-$ 分别与 $\chi^+$、$\chi^-$ 配对），而前面那个 $P$ 是零形式；两者都是为使代数在壳外闭合而引入的辅助场，最后分别由代数运动方程消去。特别留意 (3.43) 中 $H^\pm$ 前的系数并不对称：$H^+$ 配 $\EUV^+(t)$，而 $H^-$ 配 $t\EUV^-(t)$。这个不对称正是 $\delta_t=\delta_\ell+t\delta_\rr$ 中 $t$ 的权重造成的（$\chi^+$ 与 $\chi^-$ 在 $\delta_\ell,\delta_\rr$ 下的相对权重不同）；若想当然地把两项都写成同一个系数，拓扑对称就会被破坏。


**[08-s04]** 式 (4.1) 中 $D^*\phi$ 的星号是 $C$ 上二维的 Hodge 星算子；$D\phi=0$ 与 $D^*\phi=0$ 是两个独立的实方程，不要把它误认成四维的 $D\star\phi=0$。原式第二行末尾的句点是排版遗留，与数学内容无关。


**[09-s04]** 按：$I$ 与 $J$ 的区分是本节乃至整个 §4 的枢纽，务必记牢。复结构 $I$ 中的线性全纯函数是 $A_{\bar z}$ 与 $\phi_z$：这把 $A$ 的 $(0,1)$ 部分读作全纯丛的结构、把 $\phi$ 的 $(1,0)$ 部分读作 Higgs 场，于是 $I$ 对应「半稳定 Higgs 丛」的图像；复结构 $J$ 中的全纯函数是 $\CA=A+i\phi$，即复平坦联络，于是 $J$ 对应「平坦 $G_{\Bbb C}$ 丛」的图像（记作 $Y$，而且 $J$ 不依赖 $C$ 的复结构）；$K=IJ$ 是第三个结构。相应地把参数对应关系记住：$w=-i\leftrightarrow J$，$w=1\leftrightarrow K$，$w=0\leftrightarrow I$，$w=\infty\leftrightarrow -I$。后面讨论 $S$-对偶时交换的是 $I$ 与 $J$（A-模型与 B-模型的靶空间互换），若把这两个复结构弄混，膜与 Hitchin 纤维的对应就会全部颠倒。


**[09-s04]** 按：(4.11) 的三个 moment map 方程 $\mu_I=\mu_J=\mu_K=0$ 就是 Hitchin 方程。具体地，$\mu_I=0$ 给出 $F-\phi\wedge\phi=0$；而 $\mu_J=0$ 与 $\mu_K=0$ 合起来等价于两个复方程 $D_z\phi_{\bar z}=0$ 与 $D_{\bar z}\phi_z=0$——取 $\mu_J$ 与 $\mu_K$ 的线性组合时，对称部分与反对称部分分别消去一个方向。这正是四维中 $D\phi=0$、$D\star\phi=0$ 两个实方程在二维的化身。另一个易混点是量纲：$\EUW$ 是无穷维仿射空间，$\epsilon$ 取值在 ${\rm ad}(E)$ 中，moment map 作为 $\EUW$ 上的「函数」其实取值在对偶空间（即分布）里，所以 (4.11) 中保留了 $\int_C\Tr\,\epsilon(\dots)$ 的积分形式；不要以为这是多余的记号。


**[09-s04]** 按：为什么二维 sigma 模型的 $\theta$ 角与四维规范理论的 $\theta$ 角相同？关键在于 $\int_\Sigma\Phi^*(\omega_I/2\pi)=1$ 与四维瞬子数是同一个拓扑量：$\omega_I/2\pi$ 是 $H^2(\MH,\Bbb{Z})$ 生成元的 de Rham 像，故它在二维的积分是整数；而这个整数正是四维第二 Chern 数（瞬子数）在约化下的像，所以两边用同一个 $\theta$ 加权。末段脚注提醒物理与数学文献对自对偶/反自对偶的约定差一个符号，故同一个位形在两边瞬子数标号相反（$\pm 1$）；这是约定问题，并非方程不一致。


**[10-s04]** 稳定性的方向容易记反：对 $G=SU(2)$，稳定要求每个 $\varphi$-不变线丛 ${\cal L}\subset E$ 的第一 Chern 类为负（半稳定则要求非正）。这里的「负」是就 ${\cal L}$ 的第一 Chern 数即次数而言，不是就某个斜率的大小而言。对一般 $G$，要看的对象变成 $E$ 到极大抛物子群 $P$ 的 $\varphi$-不变约化，其第一 Chern 类由 $P$ 中那个特殊的 $U(1)$ 给出。


**[10-s04]** $w=\Tr\,\varphi^2$ 不是函数而是二次微分，它取值于 $K_C^2$，所以 Hitchin 底空间是 ${\EUBB}=H^0(C,K_C^2)$ 而不是某个函数空间。对 $SU(2)$ 有 $\dim {\EUBB}=3g-3=\dim\M=\frac12\dim\MH$；这个「维数正好是一半」的事实正是后面纤维维数公式 (4.25) 的来源，也是完全可积性所需的函数个数。


**[11-s05]** 扭化只在欧几里得号差下成立：它破坏酉性（脚注给出了理由——紧群 $Spin(6)$ 与非紧的 $Spin(1,3)$ 之间不存在非平凡同态）。但一旦把时间方向分离出来写成 $M=\Bbb{R}\times W$，扭化就与时间无关，理论在 Lorentz 号差下也可以既酉又物理。读本文时不要因为第一句话就把扭化理论当作纯形式的玩具。


**[12-s05]** $w_+=-t$、$w_-=t^{-1}$ 这一嵌入是在把 $G$ 阿贝尔化（破缺到极大环面）之后算出的；它给出四维扭化参数 $t$（即 $\Bbb{CP}^1_g$ 上的仿射参数）与二维复结构对 $(J_+,J_-)$ 的对应关系。注意 $t$ 与 $-t$ 给出二维中相互等价的理论，这来自 $SU(4)_{\cal R}$ 的中心，而不是来自四维层面的等价。


**[12-s05]** 「复结构 $\hat J$ 中的 $A$-模型」只是简称：原文明确指出 $A$-模型真正依赖的是辛形式 $\omega_{\hat J}$，而不是复结构本身。后文把四维 $S$-对偶化归为二维镜像对称时，$A$-模型这一侧对应的正是 $\MH$ 的辛结构 $\omega_K$。


**[13-s05]** 按：${\cal I}_t$ 中 $I$ 与 $\omega_J$ 之所以「消失」，是因为 $J_\pm$、$\omega_\pm$ 的组合把这两项相消掉了；剩下的数据恰好是 $J$ 与 $\Omega_J=\omega_K+i\omega_I$。因此这族拓扑场论与 $C$ 的度量的无关性，根源在于超凯勒结构及其全纯二形式 $\Omega_J$ 都不依赖 $C$ 的度量，而不在于某个近似或特殊取值。


**[13-s05]** 按：$t=\pm i$ 是两个特殊值：此时模型是复结构 $\pm J$ 中的 $B$-模型，而非某个 $A$-模型的 $B$-场变换，因此 $\Psi$ 的推导在极点处不适用。另一个容易忽略的细节是 $B$-场的 $(0,2)$ 分量在 $B$-模型中会影响 $B$-膜的范畴，而 $(1,1)$、$(2,0)$ 分量不进入范畴。


**[13-s05]** 按：表中下标 $B$/$A$ 指模型类型，与复结构记号 $I,J,K$ 搭配：$J_B$ 是「复结构 $J$ 中的 $B$-模型」。$I_B$、$I_A$ 是自身的 $S$-对偶，这来自 \eqref{eq:yfog}（$S$ 保持 $I$ 中的 $B$-模型与 $A$-模型不变）；同时不要把复结构 $I$ 与广义复结构 ${\cal I}$ 混淆。


**[14-s05]** 按：手征环的双分次是 $H^q(X,\wedge^pTX)$，其中 $p$ 记 $\wedge^pTX$ 的阶、$q$ 记上同调次数，两者不要写反。「鬼数为零」指的是这个双分次中的 $(p,q)=(0,0)$ 部分，它恰好是全纯函数环。因此「$\MH$ 在复结构 $I$ 中手征环的零次部分 = 基 ${\EUBB}$ 上的全纯函数」这一步，实际上用到了 Hitchin 纤维的紧性——全纯函数在紧复子流形上为常数。


**[14-s05]** 按：膜类型的三个字母按复结构 $(I,J,K)$ 的次序排列，$B$/$A$ 分别指在该复结构中为 $B$-膜/$A$-膜。脚注的两个「不存在」来自超凯勒流形的复结构关系：在 $I,J$ 中全纯自动在 $K$ 中全纯，故没有 $(B,B,A)$；对 $A$-型也不可能有三个方向同时成立，故没有 $(A,A,A)$。


**[15-s06]** 按：式 (6.1) 指数上的负号来自协变导数约定 $D=d+A$（见脚注），换成 hermitian 规范场 $A'=iA$ 后就是通常的 ${\rm Tr}_R P\exp(i\oint A')$。这里的 $W_0$ 还是普通（未扭化）的 Wilson 圈算子；它一般不具有拓扑对称性，正是下面要修改的对象。


**[15-s06]** 按：$-i$ 与 $+i$ 给出的两个公式由 $\EUI$ 互换，注意不要漏掉 $t\not=\pm i$ 的例外：此时 $\CA$ 或 $\bar\CA$ 的 holonomy 不是拓扑不变量。括号内的提醒也很重要——消灭定理（把超对称位形等同于复平坦联络）依赖整体性假设，在有膜的情形可能失效，这一点在后文把线算子变成膜上算子时会反复用到。


**[16-s06]** Wilson 圈算子需要 ${\cal S}$ 的切向定向（1-形式 $ds$），而 't Hooft 圈算子需要的是法丛的定向（$\epsilon_3$）。两者并不独立：一旦 $M$ 可定向，\eqref{eq:delo} 的相容条件 $\epsilon_4=ds\wedge\epsilon_3$ 把二者联系起来。这一步在 \eqref{eq:juqu} 的分部积分中至关重要——正是用它才断定 $\partial V_\epsilon$ 的定向为 $ds\wedge d{\rm Vol}$，从而边界项的符号正确。若混用定向，会得到 $\delta_T{{\cmmib I}}_\theta=-m\Psi\int\delta_T\hat A$ 之类的符号错误。

一方面它是零膜的 $S$-对偶，即磁特征膜；另一方面它给出 $\M$ 上

因为几何 Langlands 的核心对应是：$C$ 上平坦 ${}^L G$-丛（局部系统）

Hitchin 纤维（粗体 $\cmmib F$），不要与 $\MH$、$\M$ 或膜符号

讨论。


**[33-s11]** 按：交换情形的对应链条值得记住：$({\cal B}_{c.c.},

把这个对应化归为同调层面的恒等式：平坦 $\CC^*$ 联络等同于
$H_1(M,\Bbb{Z})\to\CC^*$ 的同态，而

$H_1(C,\Bbb{Z})\simeq H_1({\rm Jac}(C),\Bbb{Z})$，即 Poincaré 对偶

${\rm Jac}(C)$ 上的平坦联络，它仅在 $\upsilon=0$ 时才是酉的，这也是

**[35-s12]** 按：$(B,B,B)$ 型膜的规范场论实现可以一句话概括：边界值是 Hitchin 方程

用 $A=\mathrm{Hom}(A_{c.c.},A)$ 定义典范余各向同性膜的说法一致。


**[36-s12]** 最后一段的时间反演论证值得记住其逻辑顺序：${\EUT}$ 是定义
典范余各向同性膜的边界条件的对称性（故可用来约束边界可观测
