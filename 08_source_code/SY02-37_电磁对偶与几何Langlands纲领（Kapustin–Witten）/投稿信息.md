## 内容提要

本文把四维 $\mathcal N=4$ 超对称杨–米尔斯理论的电磁对偶（S-对偶）与黎曼面上的几何 Langlands 对应
联系起来，是「规范场论 ↔ 几何 Langlands」这条主线的奠基性长文。全书骨架：

- **§1–§2**：几何 Langlands 纲领陈述（Hecke 特征层 ↔ 对偶群的局部系统）；四维 $\mathcal N=4$ 理论及其 S-对偶、GNO 对偶群 = Langlands 对偶群。
- **§3–§5**：把 S-对偶实现为拓扑扭化（Kapustin–Witten 扭化）后，理论在 $\Sigma\times C$ 上紧化成以 Hitchin 模空间 $\mathcal M_H(G,C)$ 为靶空间的 sigma 模型；S-对偶变成 $\mathcal M_H$ 上的镜像对称（Hitchin 纤维化 = SYZ 纤维化）。
- **§6–§8**：$\mathcal M_H$ 的三组复结构 $(I,J,K)$ 与超凯勒几何；A-膜/B-膜与 $(A,B,A)$ 型膜；Wilson 与 't Hooft 线算子分别对应电/磁特征膜；'t Hooft 算子作用于零膜即 Hecke 算子。
- **§9–§10**：'t Hooft 算子的乘积展开与单极子冒泡；Hecke 修正空间即带边界条件的 Bogomolny 方程解空间，维数由指标理论给出。
- **§11–§12**：A-膜（复结构 $K$）给出 $\mathcal D$-模，给出几何 Langlands 对应的「膜 ↔ D-模」翻译器；并讨论边界条件与退化情形。
