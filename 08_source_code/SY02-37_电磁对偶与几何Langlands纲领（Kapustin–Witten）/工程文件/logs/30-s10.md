## 附：本片核心内容

- 时间反演不变性在 §10 的框架中必须放弃：Hitchin 模空间的典型纤维与典范余迷离膜的支撑都不限于 $\phi=0$ 的位形，因此不能像普通 Bogomolny 方程那样只用实三维数据。
- BPS 方程 (10.35) 在 $t=1$ 化简为**扩展的 Bogomolny 方程** (10.36)：$D_{\bar z}\phi_z=0$、$\partial_y A_{\bar z}=-iD_{\bar z}\phi_0$、$\partial_y\phi_z=-i[\phi_z,\phi_0]$、$F_{z\bar z}-[\phi_z,\phi_{\bar z}]={ih\over2}\partial_y\phi_0$。其中 $\varphi=\phi_z\,dz$ 是 ${\rm End}(E)\otimes K_C$ 的全纯截面，故 $(E,\varphi)$ 是 Higgs 丛；相对普通 Bogomolny 方程，这里保留了 $\phi_0$（时间分量）与三维的 $D$、$\star$、$D^*$ 结构。
- 沿 $y$ 方向演化只在经过 't Hooft 算子时才改变 $(E,\varphi)$：丛作 Hecke 修正（(10.37)：$t_i=(z-z_0)^{-m_i}s_i$），而 $\varphi$ 是全纯场，**不能在一点修正同时保持全纯**，所以给定 $z\ne z_0$ 处的 $\varphi$ 后至多只有唯一全纯延拓；由此 Hecke 修正不因 $\varphi$ 而多出参数。
- $\varphi$ 在 Schubert 簇 $\bar\EUY({}^L\negthinspace w,z_0)$ 上定义一个向量场，其零点就是可能的 Hecke 修正；零点一般有限（正则半单情形），零点个数由 $\sum_{i<j}(m_i-m_j)$ 给出——这是本片的关键计数。
- $\varphi$ 的特征多项式不依赖 $y$，故沿 $y$ 的 Hecke 变换保持 Hitchin 纤维：缠在 Hitchin 纤维上的膜（磁特征膜）的支撑不变，这是磁特征膜存在的直观证据。
- 由此定义 Higgs 丛的 Hecke 对应 $\EUQ\subset\EUW_0\times\EUW_0$；在良好区域它是 $\MH\times\MH$ 的中间维数 $(B,A,A)$-膜，并且必须对 $\Omega=\pi_1^*(\Omega_I)-\pi_2^*(\Omega_I)$ 拉格朗日——负号保证对角（平凡）对应是拉格朗日的。
- 用 (10.42) 的线性化方程、Jacobi 恒等式与分部积分验证 (10.41) 的辛体积分为零，从而完成该膜是拉格朗日的验证。
