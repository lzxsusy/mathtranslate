## 附：本片核心内容

- 把 ${\EUZ}(^Lw_1,\dots,^Lw_n)$ 实现为 Kähler 流形：复结构 ${\cal I}$（坐标 $A_{\bar z}$、$B=A_y-i\phi_0$）+ 辛形式 (10.16) + Kähler 度量 (10.17)，复 Bogomolny 方程 (10.14) 在其下全纯。
- 规范群 moment map (10.19) 含边界项；$\mu=0$ 同时给出实 Bogomolny 方程 (10.15) 与边界条件 $\Tr\epsilon\phi_0=0$，这为 ${\EUZ}$ 的「一端 $\epsilon=0$、一端 $\phi_0=0$」边界条件提供了新解释，并使辛商等于复商（${\EUZ}={\EUZ}'$）。
- $D_I$（保持 $C$-纤维化的微分同胚群）保持复结构而不保持辛结构：沿 $y$ 移动 't Hooft 算子 = 部分消解（变辛结构），沿 $z$ 移动 = 部分形变（变复结构），二者拓扑等价。
- 两算子极限 $p'\to p$ 的模空间就是单个权 $^L\bar w={}^Lw+{}^Lw'$ 的模空间；这给出 OPE (10.20)：领头项 $T(^L\bar w,p')$，次领头项来自 $\bar\EUZ(^L\bar w,p')$ 的单极子冒泡奇异轨迹。
- 例子 $G=PSU(2)$、$^L G=SU(2)$：$\bar\EUZ{}^*=\Bbb{WCP}^2(1,1,2)$ 可形变为 $\Bbb{CP}^1\times\Bbb{CP}^1$、可消解为 Hirzebruch 曲面；一般群只能用基本权算子作最大部分消解，$SU(r+1)$ 因基本表示极小可完全消解。
