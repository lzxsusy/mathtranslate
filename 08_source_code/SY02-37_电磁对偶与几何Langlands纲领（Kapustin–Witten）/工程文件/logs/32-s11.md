## 附：本片核心内容

- c.c. 膜是 $\MH$ 上支撑全空间、Chan-Paton 为平凡线丛（带非平凡联络）的余各向同性 $A$-膜；条件 $(ω^{-1}F)^2=-1$ 与 $F=(\Im\tau)\omega_J$ 使它同时是复结构 $I,K$ 中的 $A$-膜、$J$ 中的 $B$-膜。
- 它没有世界面瞬子修正；$({\cal B}_{c.c.},{\cal B}_{c.c.})$ 弦的代数层在部分层化下由形变量子化确定，二阶数据（$\star$ 乘积与 $H^2$ 粘接）完全决定它。
- 时间反演把代数层映为其相反代数，自相反条件给出 ${\cal L}^2\simeq K_X$，于是 c.c. 弦层 $={\cal D}_{K_\M^{1/2}}$。
- 整体截面给出对易哈密顿量到 $\M$ 上相互对易微分算子的量子化（Hitchin / Beilinson–Drinfeld，水平 $k=-h$ 的流代数），这是几何 Langlands 中 Hecke 特征层的前身。
