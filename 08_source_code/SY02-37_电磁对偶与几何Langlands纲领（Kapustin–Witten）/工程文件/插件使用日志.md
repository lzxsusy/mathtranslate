## B. 外部服务与本地资源

### B1. arXiv e-print（关键突破）

```
curl -sS -L -o /tmp/kw06src.tar "https://arxiv.org/e-print/hep-th/0604151"
```

- HTTP 200，404,835 B（gzip）。解包得到 `glshort.tex`（616,783 B / 11,886 行，harvmac 源码）、
  `glshortspare.defs`（27,357 B，348 公式号 + 47 节号 + 146 文献号映射）、20 个 EPS 图。
- 评价：★★★★★ 有源码 = 公式、编号、`\cite` 全部免手抄，这是本次能在一晚上推进的根本原因。

### B2. MiKTeX / XeLaTeX

- `C:\Users\admin\AppData\Local\Programs\MiKTeX\miktex\bin\x64\xelatex.exe`（MiKTeX 26.5），`latexmk` 同目录。
- 评价：★★★★★ 中文字体 simsun/simhei/msyh/STKAITI 齐全，ctex 可用。

  `! Missing control sequence inserted.`（最小用例可复现，原因未明）；**从 preamble 删掉 mathtools 即全好**。

### D3. 本轮踩坑（值得进 playbook）

1. **harvmac 的 `\nref` / `\lref` 都不打印编号**：只有 `\ref` 与 `\refs{}` 打印。误把 `\nref` 当 `\ref` 会在正文里散出 82 个孤立 `[N]`。判断依据必须是**已出版 PDF**，不能只看源码。
2. **`\usepackage{mathtools}` 与 ctex/amsmath 组合**在 `equation`+`aligned`+`\sqrt` 下会报 `! Missing control sequence inserted.`，最小用例可复现；本工程不需要 mathtools，删掉即可。
3. **LaTeX2e 原生支持 `{\bf 4}`、`{\cal H}`、`{\rm d}`**，不要画蛇添足转成 `\mathbf{4}`/`\mathcal{H}`——自动转换会在下标组处吃掉花括号，把 36 片全转坏。
4. **`\m@th` 必须在 `\makeatletter ... \makeatother` 内定义**，否则报 `<recently read> \m`。
5. **自建脚手架必须逐片冒烟编译**：`check_shards.py` 二分 + `bisect_shard.py` 定位，比整篇编译一次一次试快一个数量级。
