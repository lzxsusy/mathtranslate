## 结构

- 轨道 T1 对偶、群论与耦合常数（14 条）
- T2 超对称、扭化与拓扑场论（14）
- T3 Hitchin 模空间与超凯勒几何（15）
- T4 广义复几何、sigma 模型与膜（18）
- T5 线算子、特征膜、单极子与 Hecke（21）
- T6 Langlands 对应、$\mathcal D$-模与几何背景（21）
- T7 深水区：盲测指出「只有断言」的四处机制补篇（4）

每条词条固定七段：数学侧定义、数学侧例子、物理侧定义、物理侧例子、对应（映射规则 + 原文锚点）、直觉、易错。
