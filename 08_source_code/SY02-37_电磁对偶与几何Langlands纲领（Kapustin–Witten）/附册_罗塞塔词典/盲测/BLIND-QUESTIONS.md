## 题目

1. 论文里的 $S$-对偶（$S$ 变换）为什么能把 A-模型与 B-模型互换？三个参数 $\tau,\ \Psi,\ t$ 分别是什么，各自在什么变换下变化？
2. 什么是特征膜（eigenbrane）？电特征膜与磁特征膜分别对应数学侧的什么对象？
3. 为什么 't Hooft 线算子可以翻译成 Hecke 算子？请给出二到三个关键步骤。
4. 典范余各向同性膜（canonical coisotropic brane）$B_{cc}$ 在数学上是什么？它为什么在 §11 出现？
5. Hitchin 模空间 $\mathcal M_H$ 的三个复结构 $I,J,K$ 分别与哪种拓扑扭化、哪种模型对应？
6. 什么是拓扑扭化（twisting）？为什么扭化之后理论变成拓扑场论？标量超荷 $Q$ 起什么作用？
7. 磁单极子如何实现 Hecke 算子？Nahm 极点在其中扮演什么角色？
8. 几何 Langlands 对应说的是哪两个范畴的等价？这两个范畴在物理侧分别由什么实现？
9. 规范群 $G$ 与 Langlands 对偶群 ${}^LG$ 是什么关系？为什么 't Hooft 通量取值于 $\pi_1(G)$，而 Wilson 线取值于 $Z({}^LG)$？
10. 谱曲线（spectral curve）与 Hitchin 纤维化的关系是什么？为什么 Hitchin 系统是可积系统？
