## 这个译本是什么

KW06 是「四维 $\mathcal{N}=4$ 超对称杨–米尔斯理论的 S-对偶 → 黎曼面上的几何 Langlands 对应」
这条主线的奠基性长文。本译本是**逐段 1:1 的中文学术译本 + 译注本**：

- 正文完整翻译，公式、编号、文献编号、节结构**与原文一一对应**（362 个编号公式全部保留原编号）；
- 每节开头有「本节重点」（物理图像 / 数学工具 / 关键结论 / 边界与展望）；
- 每 2–4 段有一条**译注**，分四类：易错点、含糊点拨、物理图像、原文疑误；
- 原文笔误一律照录，并在译注中标 `[原文疑误]`，不擅自改动原文数学。

## 三分钟读法

1. 先读 `思路导读/`：搞清「扭化 → 紧化 → 膜 → 线算子即 Hecke 算子 → D-模」这条骨架；
2. 再读正文：§1–§2 是纲领与四维理论，§3–§5 是扭化与紧化，§6–§8 是 Hitchin 模空间上的膜与线算子，
   §9–§12 是 't Hooft 算子、单极子冒泡、A-膜与 D-模；
3. 遇到术语迷路时查 `工程文件/GLOSSARY.tsv`（111 条）与本译本每片的「本节重点」。
