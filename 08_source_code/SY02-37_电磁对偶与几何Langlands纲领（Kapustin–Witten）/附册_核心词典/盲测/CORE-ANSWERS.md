## C1. 什么是拓扑扭化？为什么能把 N=4 变成拓扑场论？（2 分）

**扭化是什么（词典的定义）**：把时空旋转群与 R-对称群「对角化」。N=4 的 R-对称群为 Spin(6) ≅ SU(4)_R，取
- κ: Spin(4) → Spin(6)，由 diag(SU(2)_ℓ, SU(2)_r) ⊂ SU(4)_R 给出；
- Spin′(4) = (1 × κ)Spin(4) ⊂ Spin(4) × Spin(6)，

新理论的超对称生成元按 Spin′(4) 变换——这就是「重定自旋」。

**判据（哪个超荷平方为零、需要什么条件）**：取左、右手不变旋量 ε_ℓ、ε_r，令 ε = u ε_ℓ + v ε_r（(u,v) ≠ (0,0)），Q = u Q_ℓ + v Q_r，t = v/u ∈ CP¹∖{0,∞} 称扭转参数。要求
- **Q² = 0**。

这等价于两个条件：
1. (i) ε 在 Spin′(4) 下不变（正是「重定自旋」的内容）；
2. (ii) εᵀ Γ^μ ε = 0 对一切 μ，即 {Q,Q} = εᵀ Γ^μ ε P_μ 中的平移项消失。

两者一致：εᵀΓ^με 是 Spin′(4)-不变标量，而扭化后 Γ^μP_μ 无 Spin′(4)-不变分量，故 (i)⟹(ii)。

**为什么成为拓扑场论**：{Q,Q} 只剩平移项、系数又被 (ii) 杀掉，所以 Q 幂零；在 Q-上同调里 P_μ 作用为零，可观察量不感知度规与平移，只剩拓扑数据。**须标明**：词典只写到「平移项消失」，从「Q²=0」到「Q-上同调中平移为零、故理论拓扑」这一步没有单独写出来，也没有给「拓扑场论」的定义；这一步是按定义 3.1 的事实补的，不是词典原文。

**附带（词典的正式定理）**：扭化理论不以 t 为参数，而以典范参数
Ψ = Ψ(t,τ) = Re τ + i Im τ·(t − t⁻¹)/(t + t⁻¹)
为参数；定理 3.2：(i) 闭四维流形上无算子插入的配分函数与 t 无关；(ii) 更一般地 δ_t-闭算符的关联函数只依赖 (t,τ) 的组合 Ψ（总作用量 I = δ_t V + (iΨ/4π)∫_M Tr F∧F，V 与 t 无关）。严格部分是 §3.3 的消灭定理（一个 t 的解对一切 t 都解，且必来自平坦 G_C 联络）；「理论只依赖 Ψ」本身是 argued（缺把 Q-上同调类的 t-依赖严格化为对 Ψ 的依赖）。

**词典不足**：定义 3.1 只做了 KW 用的这一种扭化（一个特选 κ），没有「拓扑扭化」的一般定义与可能 κ 的分类；正文提到的「三种扭化」仅以引文出现（Vafa–Witten 1994），未列出三种是什么；「拓扑场论」全篇只被使用、未被定义。→ 缺拓扑场论的定义、三种扭化的名单、以及「Q²=0 ⇒ 拓扑」的显式推理链。

依据：词条 3「拓扑扭化与典范参数」定义 3.1（第 328–345 行）、定理 3.2 与证明要点（第 360–386 行）、物理侧与状态与出处（第 387–395、417–424 行）；τ 的约定见词条 1 定义 1.1（第 159–196 行）。

## C2. 几何 Langlands 对应的精确陈述及其状态（2 分）

**设定**：C 为 C 上光滑射影连通曲线，G 为复约化群，^L G 为其 Langlands 对偶群；Bun_G 为 C 上 G-丛的模栈，Loc_{^L G}(C) 为 C 上平坦 ^L G-丛（即局部系统 π₁(C) → ^L G）的模栈。只处理非分歧情形。

**陈述（两个层次）**：
1. 本征层形式：对每个 E ∈ Loc_{^L G}(C)，存在**非零 D-模** F_E，满足 Hecke 特征方程
   H_{V,z}(F_E) ≃ V_E|_z ⊗ F_E （z ∈ C，V ∈ Rep(^L G)），
   其中 V_E = E ×_{^L G} V，H_{V,z} 为 z 处的 Hecke 函子。
2. 范畴化形式：导出范畴的等价
   **D^b D-mod(Bun_G) ≃ D^b QCoh(Loc_{^L G}(C))，O_E ↦ F_E。**

**它是定理、猜想还是 argued？**
- **数学上：一般情形是猜想**，不是定理。词典明确写「完整范畴等价仍是猜想（近年 Gaitsgory 与合作者的系列论文宣称证明一般约化群情形，卷次与年份待核）」；Frenkel 2009 §3 式 (3.1) 也把它列为猜想。
- **已证特例（定理）**：GL₁ 的完整等价（定理 14.2，Laumon–Rothstein 的 Fourier–Mukai 变换）；GL₂（Drinfeld）；GL_n 的 Hecke 特征层**存在性**（Frenkel–Gaitsgory–Vilonen）；oper 情形（Beilinson–Drinfeld）。
- **KW06 的物理推导是 argued**：S-对偶 + 在 C 上紧化 + 镜像对称 + Bcc 翻译器，原文动词为 argued；缺的是把四维与二维的膜范畴严格定义并证明两步等价。

**词典不足**：Gaitsgory 等近年工作只以「宣称证明、卷次与年份待核」出现，读者无法据此判定一般群完整等价今天是否已获公认证明。→ 缺该证明的确定文献（年份/卷次/是否已通过同行评议）。

## C3. 特征膜（eigenbrane）及其电、磁两个来源（2 分）

**定义**：设 T 为二维拓扑场论，B 为其一个边界条件（膜）；X 为支撑在平行于边界的直线 L 上的线算子。把 L 推向边界，X 把 B 变成新膜 XB。若存在有限维向量空间 V 与同构
- **X B ≃ B ⊗ V**，

则称 B 是 X 的**特征膜**，V 为本征值。对一族交换线算子 {X_i}，共同特征膜要求 X_i B ≃ B ⊗ V_i 对每个 i 成立。若线算子 X_p 对 C 上每点 p 都有定义，则 V_p 随 p 构成 C 上的**平坦向量丛**（可带非平凡单值）——这就是「特征膜 = C 上平坦丛」的直观。

**两个物理来源 → 数学侧**：
- **电特征膜**：Ψ = ∞（纯 Wilson 扭化）处 Wilson 线的共同特征膜。物理实现是零膜 O_x（支撑在光滑点 x ∈ M_H(^L G)），定理 10.2（物理推导）给出 X_p(R)B_x ≃ B_x ⊗ E_p(R)|_x，本征值 V_p = E_p(R)|_x 构成 C 上平坦丛。**数学侧 ↔ 平坦 ^L G-丛 E**（谱数据；本征值就是 E 的表示丛的纤维）。
- **磁特征膜**：Ψ = 0（纯 't Hooft 扭化）处 't Hooft 线的共同特征膜。它是支撑在 Hitchin 纤维上的 (B,A,A) 型 type F 膜，经典范余各向同性膜 Bcc 翻译成 Bun_G 上的扭化 D-模。**数学侧 ↔ Hecke 特征 D-模 F_E**（Beilinson–Drinfeld 的 Hecke 特征层：H_R(F) ≃ V_R ⊗ F）。
- S-对偶交换电、磁两种特征膜，同时交换「^L G-局部系统 E」与「Hecke 特征层 F_E」，这正是几何 Langlands 两侧的物理对译。词典同时指出：零膜这类 (B,B,B) 型膜的扭化直和可实现电特征膜，磁特征膜（type F）是 (B,A,A) 型。

**无缺口**。定义、两个来源、数学对译、以及「零膜是电特征膜」的论证要点都在词条 10 内闭合。

依据：词条 10「特征膜」定义 10.1（第 874–889 行）、定理 10.2 与证明要点、物理侧、状态与出处（第 890–931 行）；词条 11 定义 11.1 末（Hecke 特征层，第 957–963 行）；词条 8 定义 8.1 与物理侧（type F 膜，第 733–779 行）；词条 15 命题 15.3（第 1314–1333 行）。

## C4. 「单极子模空间 = Hecke 修正空间」的三个关键环节与状态（2 分）

**环节一：ADHMN / Nahm 数据。** 秩 k 的 Nahm 数据是三族 k×k 反 Hermite 矩阵 T₁,T₂,T₃(s)（s ∈ I = [s₋,s₊]），满足 Nahm 方程
  dT_i/ds = ½ Σ_{j,k} ε_{ijk}[T_j,T_k]，
两端有单极点 T_i ∼ ρ(σ_i)/(2(s − s_±))，留数构成 su(2) 的 k 维不可约表示，模去 U(k) 规范作用。定理 12.2（ADHMN 对应，**定理**）：G = SU(2) 时 R³ 上荷 k 的 BPS 单极子模空间 M_k 与秩 k Nahm 数据模空间 N_k 自然同胚，且是超凯勒等距，dim_R M_k = 4k（Atiyah–Hitchin–Drinfeld–Manin 构造、Nahm 方程、Hitchin 1983 满射性、Donaldson 1984 等距）。

**环节二：Schubert 簇。** 设 p₀ ∈ C，^L w 为 ^L G 的支配余权，Y(^L w; p₀) 为 p₀ 处型 ^L w 的 Hecke 修正空间（G-丛 + p₀ 外的同构），Ȳ 为其紧化。命题 12.3：带 p₀ 处型 ^L w 的 't Hooft 奇点、两端取椭圆边界条件（一端 Dirichlet 固定 A、φ 自由；另一端 φ = 0 + 协变 Neumann）的奇异 Bogomolny 解模空间同构于 Ȳ(^L w; p₀)，而 Ȳ(^L w; p₀) 是仿射 Grassmann 流形 Gr_{^L G} 中 Schubert 簇 Ȳ(^L w) 的闭包。局部图像：E₋ = ⊕ᵢ Lᵢ 越过 p₀ 后变为 E₊ = ⊕ᵢ Lᵢ ⊗ O(p₀)^{m_i}。

**环节三：'t Hooft 算子的作用。** 数学侧「p₀ 处一次 Hecke 修正」↔ 物理侧「一个量子化磁荷单位缩成一点并被 't Hooft 算子吞掉」：U(1)-不变的瞬子沿 C²/U(1) = R³ 的奇点冒泡，权变化 (m+1, m−1) → (m, m) 就是型 ^L w 修正的退化。故 't Hooft 线作用于膜的方式就是对其支撑作 Hecke 修正；支撑在 Hitchin 纤维上的 type F 膜越过算子后仍支撑在同一纤维（φ 的特征多项式不随 y 变）。这正是「't Hooft 线算子的二维影子 = Hecke 算子」的几何机制。

**状态**：命题「单极子模空间 ≅ Hecke 修正空间」是 KW06 §10.5 pp.182–183 的构造性等同**加物理推导**，原文动词为 **argued**——不是数学定理。缺的一步：把「带 't Hooft 奇点的三维 Bogomolny 解」的模空间本身严格定义成数学对象，并证明它就是 Schubert 簇的紧化（原文只把 Schubert 簇的识别当作已引定理）。词典另给两条警告：Ȳ 整体**不**超凯勒，只有奇点附近局部超凯勒；k = a/2 的换算与 4k 对账是词典整理、原文未对账（拿 (1,0) 的 CP¹ 直接对 4k 会差因子 2，那只是权与荷的换算不同）。

**无缺口**（三环节与 state 均已闭合；缺的数学定义词典自己点明了，属原文缺口而非词典缺口）。

依据：词条 12「单极子模空间 = Hecke 修正空间」定义 12.1（第 1024–1052 行）、定理 12.2 与证明要点（第 1053–1069 行）、命题 12.3 与证明要点（第 1070–1083 行）、例 12.4（第 1091–1097 行）、状态与出处（第 1105–1115 行）；词条 11 物理侧（第 982–990 行）。

## C5. Hitchin 纤维化的一般纤维为何是复环面、维数多少、用什么定理（2 分）

**定理（Hitchin 1987b：完全可积性）**：G 紧半单、C 亏格 g ≥ 2，Hitchin 映射 π: M_H(G,C) → B 满足：(i) 在复结构 I 下全纯且满射；(ii) **一般纤维是复环面**（紧复阿贝尔簇，或它的主齐性空间），复维数 = dim_C B；(iii) dim_C B = Σ_{i=1}^{r}(2d_i − 1)(g − 1) = (g − 1)dim G = ½ dim_C M_H；(iv) 纤维是 Ω_I 的 Lagrange 子流形（对 ω_J, ω_K 亦然）。故**一般纤维的复维数是 (g−1)dim G，实维数 2(g−1)dim G**（G = SU(2) 时即 3g−3）。

**为什么不是实环面 T^{2r}**：r = rank G 只是 Casimir 谱的秩计数。注 5.4 的算术：纤维维数只依赖 dim G 与 g，与 rank 无关。G = SU(3)、g = 2：dim G = 8、r = 2，正确复维数 8；T^{2r} 的复维数只有 r = 2，**相差四倍**。G = SU(2)、g = 2：dim_C B = 3g−3 = 3，一般纤维是复 3 维环面（实 6 维），而 T^{2r} = T² 复维只有 1。纤维实维数恰为 dim_R M_H = 2(2g−2)dim G 的一半。

**用什么定理证明**：Hitchin 1987b 的完全可积性（Duke Math. J. 54）。词典给出的证明链是：
1. Riemann–Roch：dim H⁰(C, K_C^{⊗n}) = (2n−1)(g−1)（n ≥ 1），配合 Σ(2d_i−1) = dim G 得 (iii)；
2. 一般纤维是椭圆方程组的解，故**紧**；
3. ½dim_C M_H 个对 Poisson 括号两两交换的全纯函数的公共水平集是 **Lagrange 子流形**；**紧 Lagrange 子流形必为环面**，得 (i)(ii)(iv)。
另一条独立核对（例 5.3，谱覆盖）：G = SU(2)、g = 2 时谱曲线 Σ 的亏格 g_Σ = N²(g−1)+1 = 5，Prym(Σ/C) 维数 = 5 − 2 = 3 = 3g−3，等于纤维复维数；G = SU(3)、g = 2 时 d₁ = 2、d₂ = 3，dim_C B = 3 + 5 = 8，dim_C M_H = 16，纤维复 8 维。

**词典自己承认的一点**：KW06 §4.3 p.54–55 明说本文不用谱覆盖构造，故词典对环面性的论证是间接的（依赖纤维紧性的一般结果）。

**词典不足**：证明要点直接用了「紧 Lagrange 子流形必为环面」这一引理，但没有给它的出处（哪个定理/哪本书）与证明；「纤维是椭圆方程组解故紧」也只有一句。→ 缺「紧 Lagrange ⇒ 环面」引理的陈述与出处。

依据：词条 5「Hitchin 纤维化与可积系统」定义 5.1（第 500–525 行）、定理 5.2 与证明要点（第 526–555 行）、例 5.3（第 563–577 行）、注 5.4（第 578–583 行）、状态与出处（第 584–590 行）。

## 总判断

**能，但只是骨架层面，且需外部补丁。** 只读过这本核心词典的人，可以完整复述 KW06 的论证链：4d N=4 → 拓扑扭化（只依赖 Ψ）→ Hitchin 模空间与纤维化 → A/B-模型与膜的类型 → 线算子（Wilson/'t Hooft）→ 特征膜 → Hecke 算子/特征层 → 单极子模空间 = Hecke 修正空间 → 典范余各向同性膜 Bcc → 几何 Langlands 对应；并且能分清哪一步是定理、哪一步只是原文的物理推导（argued）——这一点比多数综述做得好，是本册最大的价值。但入口概念（拓扑场论、拓扑扭化、边界条件）只有用法没有定义，附录 A 的纯文本版面不可直接使用，「哪些已证」在关键处依赖「待核」。所以：**骨架可掌握，血肉需另配**。

## 最薄弱 3 处

1. **词条 3「拓扑扭化与典范参数」——缺入口概念的定义。** 只给了 KW 的一种对角嵌入 κ 与 Q²=0 的两条件，没有「拓扑扭化」的一般定义（任意 κ 的分类）、没有「三种扭化」的名单（仅引 Vafa–Witten 1994）、也没有从「{Q,Q}=εᵀΓ^με P_μ 的平移项消失」到「Q-上同调中 P_μ=0 ⇒ 观察量与度规无关 ⇒ 拓扑场论」的推理，全书更无「拓扑场论」的定义。后果：读者能背判据，却不能真正解释 C1 问的「为什么变成拓扑场论」。
