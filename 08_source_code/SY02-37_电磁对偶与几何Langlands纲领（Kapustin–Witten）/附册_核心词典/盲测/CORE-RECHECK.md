## D1 拓扑扭化：一般定义、三种扭化、Q²=0 ⇒ 拓扑

- **一般定义**：注 3.3(a) 给出「扭化是选一个子群 Spin′(4) ⊂ Spin(4) × Spin(6)，它与 Spin(4) 同构、在 R⁴ 上的作用与原 Spin(4) 相同，但对 N = 4 的超荷作用不同」；定义 3.1 另给出本册实际用的具体取法 Spin′(4) = (1 × κ)Spin(4)，κ 由 diag(SU(2)_ℓ, SU(2)_r) ⊂ SU(4)_R 给出。依据：CORE-TEXT.txt 第 328–335、387–389 行。
- **N = 4 的三种扭化**：注 3.3(a) 说「N = 4 恰有三种本质不同的扭化」——两种类似 Donaldson 理论（瞬子不变量可用 Seiberg–Witten 不变量表达，其一在 Vafa–Witten 1994 中被详研），第三种由 Marcus 1995 等研究、在 KW06 之前没有应用，即本册用的 GL 扭化。依据：CORE-TEXT.txt 第 390–392 行。
- **Q²=0 为什么导致拓扑场论**：链路完整。(i) Q²=0 的两个条件（ε 在 Spin′(4) 下不变；εᵀΓ^μ ε = 0，即 {Q, Q} 的平移项消失）及二者一致性，见第 342–345 行；(ii) 拓扑场论的定义（Atiyah 1988 公理化：配分函数与关联函数不依赖度规、只依赖光滑结构），见第 392–395 行；(iii) 推理链：取不变标量超荷 Q = εᵀQ，{Q, Q} = 2εᵀΓ^μ ε P_μ 的系数是普通数；取另一不变旋量 ε′ 使 ε′ᵀΓ^μ ε 可逆，则 P_μ 是 {Q, Q′} 的线性组合，即平移算符 Q-恰当；于是 Q-上同调中 P_μ = 0，可观察量不感知平移与度规，只剩拓扑数据——这就是 Atiyah 意义下的拓扑场论。依据：CORE-TEXT.txt 第 396–400 行。文本并注明 KW06 只写到「平移项消失」，(b)(c) 是本册按 Atiyah 定义补出的推理链，原文未如此陈述（第 399–400 行）。
- 结论：**已修复**（一般定义、三种扭化名单、含拓扑场论定义与「平移算符 Q-恰当」的完整推理链均在，且标明了哪一步是补的）。

## D4 Hitchin 纤维是复环面

- **现在的论证**：定理 5.2(ii) 断言一般纤维是复环面（紧复阿贝尔簇或它的主齐性空间），复维数等于 dim_C B。依据：CORE-TEXT.txt 第 543–556 行。
- 证明要点明确说：环面性**不能只由「紧 + Lagrange」得到**（一般 Kähler 流形上的紧 Lagrange 子流形不必是环面），Hitchin 1987b 用谱覆盖与 Prym 构造把它显式证成复阿贝尔簇的主齐性空间；KW06 §4.3 明言本文不用该构造。依据：CORE-TEXT.txt 第 570–574 行。
- **正确的论证链（文本给出的）**：谱曲线 det(φ − λ) = 0 在 T*C 中给出 C 的二重覆盖 Σ；Prym(Σ/C) 的维数为 g_Σ − g = (g − 1)dim G；一般纤维就是该 Prym（或它的主齐性空间）。例 5.3 以 SU(2)、g = 2 核对：g_Σ = N²(g − 1) + 1 = 5，dim Prym = 5 − 2 = 3 = 3g − 3 = ½ dim_C M_H。依据：CORE-TEXT.txt 第 589–596 行（维数公式见第 545–556 行）。
- **是否仍依赖「紧 Lagrange ⇒ 环面」**：作为正面推理已不再依赖，文本明确否定它；但证明要点末句与「状态与出处」仍保留旧话，称原文「对环面性的论证是间接的（依赖紧性 / 纤维紧性的一般结果）」（第 574、605–609 行），这与同段「不能只由紧 + Lagrange 得到」自相矛盾——紧性本身推不出环面，这句是旧论证的尾巴。
- 结论：**部分修复**（否定了旧推理并补上谱覆盖 + Prym 的正确链，但两处仍保留「依赖紧性的一般结果」的错误说法，前后矛盾）。
