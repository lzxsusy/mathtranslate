## 必须改

### 1. p020（第 270、282 行）术语「反典范除子」被写成「反正典范除子」

原文：p020「Y が**反正準因子**(anti-canonical divisor) である時」「一般の**反正準因子**が準滑らかになる重みの集合は」
现状：两处都作「反正典范除子」。`work/glossary.tsv` 规定「反正準因子 → 反典范除子」；现译多出一个「正」，「反正典范」不成词。
依据：glossary 第 147 行；p020 原图（800 dpi 裁图确认原文为「反 正 準 因 子」）。

建议替换（第 270 行整行）：

```
确定 $\PP(a_1,\ldots,a_{n+2})$ 的超曲面。当 $\tilde Y$ 除原点外没有奇点时，称 $Y$ 是拟光滑（quasi-smooth）的。拟光滑超曲面只具有来自外围的加权射影空间的商奇点。当 $Y$ 是反典范除子（anti-canonical divisor）时，即当 $Y$ 的定义方程的次数 $h$ 满足
```

建议替换（第 282 行整行）：

```
使一般的反典范除子拟光滑的权的集合，在 $n=1$ 时只有 $(1,1,1)$、$(1,1,2)$、$(1,2,3)$ 三个 [Sai74]。相应的加权射影平面的超曲面是椭圆曲线，对它们而言拓扑镜像对称没有深刻内容。
```

### 2. p020（第 284 行内脚注 \*9）「自明でない」误译为「非真」

原文：「V から高々加算個の**自明でない** Zariski 閉集合を取り除いた集合の上で成り立つ性質を…」
现状：「若某性质在从 $V$ 中去掉至多可数个**非真** Zariski 闭集所得的集合上成立…」
问题：「非真」在中文数学里意为「非正常的/不真的」（proper 的反面），与「自明でない＝非平凡」正好相反；very general 的定义要求去掉的是「非平凡/真」的 Zariski 闭集。

建议替换（脚注整段）：

```
给定 $\C$ 上的代数簇 $V$ 时，若某性质在从 $V$ 中去掉至多可数个非平凡的 Zariski 闭集所得的集合上成立，则称该性质在 $V$ 的非常一般的点（very general point）处成立。
```

（若追求与代数几何通行表述一致，也可用「至多可数个真 Zariski 闭子集」。）

### 3. p021（第 287 行）「母関数」未按术语表译作「生成函数」

原文：「Hodge 数の**母関数** $P(t,\bar t):=\sum_{p,q=0}^{n}h^{p,n-q}t^p\bar t^q$ を与える公式」
现状：「给出 Hodge 数**母函数** … 的公式」。`work/glossary.tsv` 规定「母関数 → 生成函数」，且全书其余部分（如 c03 的 (7.2)–(7.3)）已统一用「生成函数」。

建议替换（第 287 行整行）：

```
$n=3$ 时的权已由 [KS92a] 分类，已知共有 7555 个。朴素地考虑，这样得到的 Calabi--Yau 流形似乎会和 $\PP^4$ 的 5 次超曲面的情形一样，具有大的 $h^{1,n-1}$ 与小的 $h^{1,1}$，但照原样仍带有商奇点，因此必须把它解消。对个别例子具体构造解消未必显然，然而 Vafa [Vaf89] 在不具体构造奇点解消的情况下，导出了给出 Hodge 数生成函数 $P(t,\bar t):=\sum_{p,q=0}^{n}h^{p,n-q}t^p\bar t^q$ 的公式
```

### 1. p016（第 34 行后）：原文「q = n − q」疑为笔误，建议补一条 Tutor Note

原文：「Y と Ȳ の Hodge 数が **q = n − q** で定義される直線に関して鏡映対称になっている」（1100 dpi 裁图确认原文如此）。

建议在第 34 行之后插入一行：

```
% [Tutor Note: 原文此处作「q = n − q で定義される直線」，按 Hodge 数的镜像对称应为 q = n − p（即 p + q = n）；此处照原文保留。]
```

### 2. p017（第 70 行）：「与…与…与…」三连，语义读不断

现文：「后者又由小平--Spencer 理论与 Bogomolov--Tian--Todorov 定理**与**复结构变形的自由度一致。」

