## 必须改

1. p029 / (12.6) 下方（c07 第 122、124 行）：polyhedron 与 polytope 的译名自指，读者无法分辨。

   原文：「…で定義される $N_{\R}$ の部分集合を polyhedron と呼び、有界な polyhedron を多面体 (polytope) と呼ぶ。…錐であるような polyhedron を多面錐 (polyhedral cone) と呼ぶ。」
   即原文**有意**把（可能无界的）polyhedron 写作拉丁词、把 polytope 写作汉字「多面体」。现状把两者都译成「多面体」，得到「有界的多面体（polyhedron）称为多面体（polytope）」这种自指句。

   现状（第 122 行）：
   ```
   定义的 $N_{\R}$ 的子集称为多面体（polyhedron），有界的多面体（polyhedron）称为多面体（polytope）。多面体（polytope）也可定义为 $N_{\R}$ 的有限个点的凸包。特别地，作为 $N$ 的有限子集的凸包（convex hull，即包含该集合的最小凸集）给出的多面体（polytope）称为格多面体（lattice polytope）。
   ```
   现状（第 124 行）：
   ```
   关于 $\R^{>0}$ 作用不变的 $N_{\R}$ 的子集称为锥（cone），而为锥的多面体（polyhedron）称为多面锥（polyhedral cone）。
   ```
   建议改为（保留原文的拉丁词/汉字分工：polyhedron 留拉丁，polytope 译「多面体」，与 glossary 的「格子多面体→格多面体」「多面体→多面体」不冲突）：
   ```
   定义的 $N_{\R}$ 的子集称为 polyhedron（多面体），有界的 polyhedron 称为多面体（polytope）。多面体也可定义为 $N_{\R}$ 的有限个点的凸包。特别地，作为 $N$ 的有限子集的凸包（convex hull，即包含该集合的最小凸集）给出的多面体称为格多面体（lattice polytope）。
   ```
   ```
   关于 $\R^{>0}$ 作用不变的 $N_{\R}$ 的子集称为锥（cone），而为锥的 polyhedron 称为多面锥（polyhedral cone）。
   ```
   依据：原文用 polyhedron（拉丁）与 多面体（汉字，=polytope）区分两个概念；glossary 又冻结「多面体→多面体」「格子多面体→格多面体」，若逐字对译必然产生「多面体（polyhedron）称为多面体（polytope）」。若 Lead 不愿在正文保留拉丁词，最低限度也须删去第二处的「（polyhedron）」，写成「有界的多面体称为多面体（polytope）」，否则自指无法消除。

   原文：「一般に、平坦準コンパクト位相に関して局所的に乗法群の直積と同型であるような群スキームのことをトーラスと呼ぶ。」
