## 必须改

### 1. p026 / 式 (10.36) 及紧随其后的句子：`Ḡ` 应为 `Ǧ̄`，`𝕐` 应为 `ˇY`

原文（p026 图像，500 dpi 裁图已确认）：`Ǧ̄ := Ǧ/⟨ǰ⟩` `は ˇY に自然に作用するので、対応する軌道体を [ˇY/Ǧ̄] とおく。`
即：(10.36) 左边是 **带 check 的 G 再加横杠**（`\overline{\check G}`），不是 `\overline{G}`；作用的轨道体是 `ˇY`（`\check Y`），不是 `𝕐`（`\mathbb{Y}`）。

现状（c06.tex 第 226、228 行）：
```
    \overline{G}:=\check G/\langle\check J\rangle \tag{10.36}
自然作用于 $\mathbb{Y}$，故记对应的轨形为 $[\mathbb{Y}/\overline{G}]$。
```
建议改为：
```
    \overline{\check G}:=\check G/\langle\check J\rangle \tag{10.36}
自然作用于 $\check Y$，故记对应的轨形为 $[\check Y/\overline{\check G}]$。
```
连带处理：删除第 229 行的 Tutor Note
`% [Tutor Note: (10.36) 中的 $\overline{G}$ 定义为 ... 同一记号在原文中有两种含义；此处按原文保留。]`
该批注的诊断不成立——原文 (10.36) 是 `Ǧ̄`，(10.38) 的 `Ḡ` 是另一个符号，二者不冲突；改后本节 `Ḡ` 只出现在 (10.38)，`Ǧ̄` 只对应 `Ǧ/⟨ǰ⟩`，与定理 10.1、10.2 及第 249 行的用法自洽。
依据：p026 图像 (10.36) 左侧字形为「Ǧ + 上划线」，同页 定理 10.1 中的 `[ˇY/Ǧ̄]` 与此一致。

### 3. p026 / 式 (10.32)：指数是 `h`（无 hat），现状写成 `\check h`

原文（900 dpi 裁图确认）：`ǔ(α) = (α^{h ǔ̌_1}, …, α^{h ǔ̌_n})`——指数上的 `h` **没有** caron；同页 (10.30)(10.31) 的 `ǩ` 有明显 caron，两处字形不同。
现状（第 210 行）：
```
    \check\varphi(\alpha)=\left(\alpha^{\check h\check\varphi_1},\ldots,\alpha^{\check h\check\varphi_n}\right) \tag{10.32}
```
建议改为：
```
    \check\varphi(\alpha)=\left(\alpha^{h\check\varphi_1},\ldots,\alpha^{h\check\varphi_n}\right) \tag{10.32}
```
并在该式后加一行批注（本处疑原文笔误，按 STYLE「照原文 + 批注」处理）：
`% [Tutor Note: 原文 (10.32) 的指数作 h（无 caron），而 (10.30) 定义的是 ǩ、且 (10.31) 有 ǎ_i = ǩǔ_i；此处照原文保留，请审校确认是否应为 ǩ。]`

## 可选改

### 1. p022 开头：`从而，` 与原文语气不符
原文 p022 首行是 `となり、l ≠ 0 の項は`，承接 p021 末 (9.38) 的 `となる` 系辞，是并列（「……为 (9.38)，而 l≠0 的项为 ……」），不是因果。
现状：`从而，$l\neq 0$ 的项为`
建议：`而 $l\neq 0$ 的项则为`（并可在 align 末尾补句号，因原文 (9.41) 后有 `となる。`）

### 2. p023：「例如，给出 K3 曲面的 95 个权之一 $(2,4,5,11;22)$，可用于构成可逆多项式的单项式只有」
原句 `例えば、K3 曲面を与える 95 個の重みの 1 つである (2,4,5,11;22) は、…単項式を [10.6] の 5 つしか持たないが` 的「は」主语一直贯到「持たない」，中文现读起来主语悬空。
建议：`例如，给出 K3 曲面的 95 个权之一 $(2,4,5,11;22)$ 只有 5 个可用于构成可逆多项式的单项式 [10.6]，而用它们构不成可逆多项式，因此可知与该权对应的可逆多项式不存在。`

### 3. p026：[BH95, Kra] 那句有歧义
原文 `[CR11, Theorem 2] はより強く、[BH95, Kra] によって群作用を含む形で一般化された転置ミラー構成が位相的ミラー対を与える事を証明している。`
现状：`[CR11, Theorem 2] 更强：它证明了 [BH95, Kra] 中把转置镜像构造推广为包含群作用的形式后，仍给出拓扑镜像对。`（`[BH95, Kra] 中` 易被读成「在该文献之中」）
建议：`[CR11, Theorem 2] 更强：它证明了把转置镜像构造按 [BH95, Kra] 推广到含群作用的形式后，仍给出拓扑镜像对。`
