## 2. 片段规则（硬性）

- **只输出片段**：禁止 `\documentclass`、`\usepackage`、`\begin{document}`、`\newcommand`、`\title`、`\tableofcontents`、`\begin{thebibliography}`。
- 输出到 BRIEF 指定的 `src/chunks/cNN.tex`（UTF-8 无 BOM、LF 换行）。
- `\section{…}` = 原文「**N 标题**」。**节标题只由该节起始页所属块写一次**；若你负责的页里出现的是前一节的续文，**不要**再写 `\section`。
- 段落之间空一行；不要写 `\par`；不要用 markdown 粗体（`**…**`）。
- 原文行内粗体小标题（如「**定義.**」）→ `\para{标题。}`（本文基本不用）。
- 脚注：`\footnote{…}` 就地写。原文脚注编号 `*1 *2 …` 自动生成，不必管原编号；**脚注必须全部译出**（本文脚注含大量关键背景：一般化几何、K3 镜像、very general point、轨道体与 stack 的说明等）。
- 定理类环境：用 preamble 定义的 `definition / theorem / example / remark / problem / exercise`，**不要手写** `\textbf{定義 2.5.}`。带括号题名的写可选参数：`\begin{exercise}[Dolbeault 定理]`、`\begin{theorem}[\cite 略]`——**题名里的文献编号用纯文本**，如 `\begin{theorem}[{[CR11, Theorem 2]}]`。
- 参考文献引用一律**纯文本**：`[GP90]`、`[BB97, Proposition 5.5]`、`[CR11, Theorem 2]`；不要 `\cite`。

## 3. 公式（最关键）

- **编号公式必须与原文一一对应**：不缺、不重、不跳、不重排、不自造：
  ```latex
  \begin{equation}
      \sum_{i=1}^{k} w_i n_i = 0 \tag{2.4}
  \end{equation}
  ```
  多行用 `align`/`gather`，每个编号一行一个 `\tag{}`；一条编号跨多行时只在最后一行 `\tag`。
  **原文多行公式每一行都各自编号时（如 (9.27)–(9.30)、(12.24)–(12.26)），必须逐行 `\tag`。**
- 原文大量公式**没有编号**：用 `\[ … \]` 或 `equation*`，**绝不自己加编号**。
- 正文引用写纯文本：「式 (2.4)」「§30」「图 13.1」；不要 `\ref`/`\eqref`。
- 微分 `\dd`、偏导 `\partial`、花体 `\cO`、黑板体 `\R \C \Z \PP`；分式/根号/上下标/指标位置逐符号核对图像。
- 矩阵：`\begin{pmatrix} … \end{pmatrix}`；Hodge 菱形（一列数字的倒三角，如 (9.5)–(9.9)、(9.14)、(9.18)、(1.23)）用 `\begin{smallmatrix}` 或 `array` 按原版式排出，**不要用 figure**。
- 交换图/长正合列（如 (9.10)、(9.11)、(10.19)–(10.20)）用 `array`/`\xrightarrow` 排出；本文无 tikz-cd，**不要用 tikz**。
- 复杂分式幂 `(1-t^4)/(1-t)` 的 5 次方等，必须看图像确认括号层级。
- 公式里不要出现中文；中文说明写在公式外。

## 4. 术语与文风

- **以 `work/glossary.tsv` 为准**；表里没有的：数学术语用中国大陆通行译名；专有名词（人名、理论名、流形名）保留原文/英文（Kähler、Hermite、Lagrange、Poisson、Hamilton、Calabi–Yau、Fano、Gorenstein、Deligne–Mumford、Landau–Ginzburg、Hodge、Hochschild、Kontsevich、Batyrev–Borisov、McKay、Stanley–Reissner、Teichmüller 等）。
- 日文汉字 ≠ 简体：複素→复、実→实、体→域（field）、束→丛（fiber bundle）/层（sheaf，看上下文）、層→层、圏→范畴、関手→函子、射→态射、核→核、双対→对偶、半直交→半正交、完全→正合（exact 时）、軌道体→轨形、多様体→流形、微分形式→微分形式、接束→切丛。
- 人名：日本人名用汉字（植田、深谷、高橋、宮岡、川崎、小平、入谷、梶浦、野原、秦泉寺、橋本、三浦……）；欧美名照原文拼写。
- 中文数学文风：一句一个逻辑重心；消灭「被……所……」「进行……的讨论」「对于……而言」；「以及」不要堆叠；英文术语与数字两侧留半角空格（`Calabi–Yau 流形`、`第 3 节`、`$k$-线性`）。
- 全角中文标点；公式句末标点放在公式之后（……为 $x^2$。）。
- **不补写、不改写**：原文省略的论证、含糊的表述、疑似笔误，保留原样，只写 `% [Tutor Note: …]`。

## 5. 批注体例

- 对原文的疑问（疑似笔误、符号冲突、缺失引用）一律写成独立行注释：
  ```
  % [Tutor Note: 原文 (9.26) 的分母指数似应为 …，此处按原文保留，请审校确认。]
  ```
- **绝不**把「我觉得」写进正文；**不**补写原文省略的论证。
- 批注只写三类：易错预警（符号、指标、约定）、含糊点拨、背景直觉（一两句）。禁止「很重要／值得注意」这类空话。
- 每条批注必须给具体信息；LaTeX 注释里**不要再出现 `%`**。
- 每完成一个 chunk，在文件末尾写一行：`% CHUNK cNN DONE pages pXXX–pYYY`

## 6. 自检（交付前逐条走）

1. `\\tag{` 的条数 = BRIEF 给你的 tag 数（允许 ±0）；每个 tag 与 `tags_bypage.txt` 对得上。
2. 所有 `\begin{…}` 有对应 `\end{…}`；`\left(`/`\right)` 配对；`$` 成对。
3. 没有中文全角括号误用于数学、没有 markdown 语法残留、没有 `` ` `` 反引号。
4. 每个 `\section` 只在节起始页出现一次。
5. 输出文件 UTF-8 无 BOM、LF；不出现 `\r`。
6. 公式已逐条回 `pages/pNNN.png` 核对（尤其是分式、根号、上下标、矩阵、大运算符上下限）。
