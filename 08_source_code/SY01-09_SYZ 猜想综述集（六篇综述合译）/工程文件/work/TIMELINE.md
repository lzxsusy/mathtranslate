## 归属细则

1. **节标题**：`\section{...}` 写在标题所在页的块里（标题不跨页）。若标题行在页首而上一块最后一句跨页，标题归**本块**。
2. **图**：图连同图注归图所在页的块（第 4 章见 BRIEF 图归属表）；图题译文按 `\figtitle{4.N}{...}`。
3. **章首前置内容**：摘要挂 `\section*{摘要}`、致谢挂 `\section*{致谢}`，都归该章第一块 / 末块；由块负责人译。
4. **脚注**：脚注随其所注释的句子归属；跨界句子由写完整句的块负责脚注。
5. **编号公式**：按页归属；本集 41 个 tag 位置见 `tags\tags_all.txt`（块内清单见 BRIEF）。
6. **参考文献**：不翻译，Lead 脚本自动转录（英文原貌），译者不要写。
