## 1. 工作方法（每页的固定流程）

1. 读 `work\split\pNNN.txt`，把握本页论证结构与日文原文（用于定位与理解）。
2. **打开 `work\pages\pNNN.png`（read_image）逐页看图**：正文意思、公式的每个符号、上下标、花体、括号层级。
   - 文字层与页图冲突时，**以页图为准**。
   - 日文 OCR 的典型错误：`ー`→`一`、`入`→`人`、`とと`→`こと`、`とこ`→`ここ`、`ェ`→`エ`、`幕`→`冪`、`器`→`冪`、`雛`→`冪`、`屈`→`C`、`恥`→`R`、`凡`→`E`、`心`→`e`（下标）、`叫`→`n`、`炉`→`φ`、`ゆ`→`φ`、`由`→`ψ`、`如`→`a`、`巾`→`⊗`、`④`/`EB`→`⊕`。公式文本层基本不可用。
3. 用中文写译文，直接写入你的 chunk 文件（UTF-8 无 BOM，LF 换行）。
4. **每译完 3–5 页就落盘一次**（防止中途丢失）。
5. 全部完成后自检（§14），再向 Lead 回报（§15）。

> **绝对不要编译**。编译、页码编排、装配由 Lead 统一处理。

## 3. 章节标题

- 章标题：`\chapter{中文标题}`——**只有该章第一个 chunk 写**。
- 节标题：`\section{中文标题}`——只由**该节起始页所属的 chunk** 写；下一页续写的 chunk 不重复写。
- 附录：`\chapter{附录 A　Fredholm 算子的空间}`（付録 A/B/C 各一章）。附录 B、C 每篇前有原论文的「はじめに」，译作 `\para{引言}` 段落标题（不编号）。
- 原书编号：3 章 + 3 附录；每章节数见 BRIEF §3。LaTeX 自动编号必须与原书一致；若发现对不上，报告 Lead。

## 4. 编号公式

**每一个原书编号公式，必须有且只有一个 `\tag{原编号}`，编号一字不差。**

```latex
\begin{equation}
  K(X)\otimes\Q \;\cong\; \bigoplus_{i}\cdots \tag{2.4.2}
\end{equation}
```

- 编号形如 `(1.1)`、`(2.13)`、`(B.3.1)`、`(C.3.6)`、`(3.2.8)`。**以页图为准**：`work\census_out.txt` 只是 OCR 统计，已知大量漏检（第 1 章、第 2 章 OCR 只抓到 0–1 条，实际远多于此，务必逐页看页图）。
- 多行公式用 `align`/`gather`，每行一个 `\tag`；一条编号跨多行时，`\tag` 放最后一行。
- 无编号公式用 `\[ ... \]` 或 `equation*`，**绝不自造编号**。
- 正文引用公式用纯文本「式 (2.4.2)」，**不要用** `\ref`/`\eqref`。
- 公式太宽导致 Overfull 时，用
  `\begin{equation}\resizebox{0.96\textwidth}{!}{$\displaystyle ...$}\tag{X.Y}\end{equation}`。

## 5. 陈述环境（定义/定理/引理/命题/推论/例/注）

原书的陈述编号是**按节编号**：`章.节.序号`（如 定義 1.4.3、定理 2.2.1、補題 2.6.10）；附录 A 为 `A.1, A.2, …`（其中一节内再分号者作 `A.4.9`），附录 B 为 `B.节.序号`，附录 C 为 `C.节.序号`。**一律手工抄原书编号**。

```latex
\begin{definition}{1.4.3}
  正文……
\end{definition}

\begin{theorem}{2.2.1}
  正文……
\end{theorem}

\begin{proof}
  证明正文……
\end{proof}
```

可用环境（第一个参数是原书编号）：

| 环境 | 显示 | 对应日文 |
|---|---|---|
| `definition` | 定义 | 定義 |
| `theorem` | 定理 | 定理 |
| `lemma` | 引理 | 補題 |
| `proposition` | 命题 | 命題 |
| `corollary` | 推论 | 系 |
| `example` | 例 | 例 |
| `remark` | 注 | 注意 |
| `problem` | 问题 | 問題 |
| `assumption` | 假设 | 仮定 |
| `notation` | 记号 | 記号 |
| `formulaenv` | 公式 | 公式 |

- `proof` 用法：`\begin{proof} ... \end{proof}`；原书「証明」的方括号不必保留。
- **陈述末尾的 □**：原书陈述末尾有 □ 的，用**不带星号**的环境（模板自动加 □）；若该陈述后面紧跟「証明」（原书此时没有 □），用**带星号**的环境：`theorem*`、`lemma*`、`proposition*`、`corollary*`。
- 没有编号的陈述（如原书「注意」后无编号、或「例」无编号）用空参数：`\begin{remark}{}`，或直接用 `\para{小标题}` 的粗体段落。
- 原书编号可能跳号、也可能同一编号出现多次（OCR 看到的重复多半是正文引用），**同一编号只允许定义环境出现一次**，其余写成正文引用「由命题 2.4.4 可知」。

## 7. 批注（Tutor Note）

在需要提醒的段落**之后**单独一行：

```latex
% [Tutor Note: 原书这里的 $K(X)$ 指约化 K 群，记号 $\tilde{K}$ 在 p.38 才引入，此处先出现后定义，初读易混。]
```

要求：

- 每 3 页至少 1 条，每节至少 2 条。**宁精勿滥**。
- 只写三类，且必须给具体信息：
  1. **易错预警**：符号约定、下标、正负号、花体/正体、$\C$ 与 $\R$ 的系数域、$K$ 与 $K^{*}$ 的次数约定；
  2. **省略论证的点拨**：作者写「明らか」「容易に」而实际略去了什么、依据哪条定理；
  3. **背景直觉**：一两句几何/拓扑意义（点到为止）。
- 禁止空话（「很重要」「值得注意」）；禁止在注释里出现 `%` 字符（会截断注释）、不要写跨行公式。
- 原书疑似笔误：**正文照抄原书**，批注写「原书 p.N 作 X，与……不符，疑为笔误，正确形式应为 Y」；**不许悄悄改正文**。

## 8. 「本节重点」与「章末评注」

- **本节重点**（`\takeaway{...}`）：每个 `\section` 的开头（节标题之后、正文之前）一个，1–3 句、不超过约 120 字；必须给出**本节的核心对象/工具/结论**之一二，不写「本节介绍……」。由该节的译者写。
- **章末评注**（`\chapterreview{...}`）：每章/每附录末尾一个，约 600–1000 字，五段式：①全章地位 ②知识脉络 ③核心结论 ④辨析与提醒 ⑤评注。**只由 BRIEF §6 指定的 chunk 写**。

## 9. 文字层可靠度（必须知道）

| 内容 | 可信度 |
|---|---|
| 正文单词、段落边界、章节标题、人名、文献编号 | 高（用于定位与抄录） |
| **公式、上下标、分式、矩阵、希腊字母、花体、括号层级** | **不可信，一律回页图逐符号抄** |
| 页眉页脚、页码 | 可用（`第2章 45` 之类） |

由此推论：**任何「原书笔误」的指控，都先用 400+ dpi 裁图复核原文**，确认后才写批注。

## 10. 语言（中文数学文风）

目标是「数学工作者的中文」，不是「日语语法的中文」。

- 一句一个逻辑重心，主谓早出现，修饰语短。
- **禁止**：`被……所……`、`进行……的讨论/计算`、`对于……而言`、`关于……的讨论`、`使得……得以……`、一逗到底、一句超过 70 汉字（公式列举句可到 90）。
- 连续三个「的」要拆；被动尽量改主动。
- 标点：中文全角（，。；：？！（）“”——）；英文术语/数字与汉字之间留**半角空格**（`向量丛 $E$`、`第 3 章`、`$k$-线性`）。
- **希腊字母与数学符号必须进数学模式**：写 `$\varphi$`、`$\otimes$`、`$\mathbb{C}$`，不许直接写 `φ`/`⊗`（否则 PDF 缺字）。
- 日文「」引号译成中文“”；「、」按语义译成顿号或逗号；「・」译成「·」或去掉。
- 人名保留英文原形：Atiyah、Hirzebruch、Bott、Adams、Grothendieck、Morse、Thom、Singer、Fredholm、Janich（Jänich）、Chevalley、Serre、Hopf、Steenrod、Dieudonné、Kuiper、Swan、Bass、Milnor、Kervaire、Bott。
- **允许**拆长句、调语序、补主语；**禁止**增删信息、改数学内容、把作者的「明らか」扩写成证明、删掉作者的评论性句子。

## 12. 禁止事项（违反即返工）

1. 不编译；不改 `preamble.tex` / `main.tex` / `frontmatter` / 别人的 chunk / `work\` 下文件。
2. 不写 `\documentclass`、`\usepackage`、`\begin{document}`、`\newcommand`、`\label`、`\ref`、`\eqref`、`\cite`。
3. 不自造公式编号、陈述编号、图号；不重排编号。
4. 不在正文留整段未翻译日文（人名/术语原文除外）。
5. 不用 Markdown（`**粗体**`）；强调用 `\textbf{}`。
6. 不写全角空格 U+3000；UTF-8 无 BOM；LF。
7. 不把公式写成文字描述；不省略公式；不省略原书编号公式。
8. 不「修正」原书笔误（只写批注）。
9. 不在 `% [Tutor Note: ...]` 里写 `%`、不写跨行公式。
10. 不写 `\begin{center}` 包围整段正文；不手工画表格线。
11. 不写 `\footnote{}` 以外的脚注体例；原书「＊（訳注）」译作 `\footnote{译注：……}`。

## 13. 译注（原日译本的 ＊（訳注））

- 岩波日译本在页脚有译者注，标作「＊（訳注）……」或「＊」。**这属于底本内容，必须译**，用法：

- 日译本的「監訳者解説」是独立篇章（p.191–202），照译，不作脚注。
