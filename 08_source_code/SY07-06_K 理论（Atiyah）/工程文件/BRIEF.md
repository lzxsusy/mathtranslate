## 4. 块边界处理（重要，零返工的关键）

1. **章标题只由该章第一个 chunk 写**：ch01a 写 `\chapter{向量丛}`；ch02a 写 `\chapter{K 理论}`；ch03a 写 `\chapter{算子}`；appA 写 `\chapter{Fredholm 算子的空间}`（由 `\appendix` 自动排成「附录 A」）；appB1 写 `\chapter{K 理论中的幂算子}`；appC1 写 `\chapter{K 理论与实结构}`；kaisetsu 见 §6。
2. **节标题只由「该节起始页」所属 chunk 写**（见下表）；下一页续写的 chunk 不重复写。
3. **跨页/跨块句由「句子起始页」所属 chunk 写完**（可以写到下一页开头）；下一 chunk 从该句之后接着写，**不得重复**。块尾最后一句若是跨页句，在文件末尾用 `% 块尾跨页句：<该句原文首数字>` 登记。
4. 块首若不是从新节开始，**直接续写正文，不要写标题**。
5. 页眉页脚（`第2章 45`、`2.2 周期性定理 41`）**不译**；脚注要译（`\footnote{...}`，就地）。
6. 附录 B、附录 C 末尾的「参考文献」用
   `\section*{参考文献}` + `\addcontentsline{toc}{section}{参考文献}`，**不加编号**；条目照原书抄（日译本的文献条目是西文原文，不必翻译，只把括号里的日文说明翻译出来）。

## 6. 「本节重点」/「章末评注」/ 监译者解说体例

- **本节重点** `\takeaway{...}`：每个 `\section` 开头一个（节标题之后），1–3 句、≤120 字。
- **章末评注** `\chapterreview{...}`：600–1000 字，五段式（全章地位／知识脉络／核心结论／辨析与提醒／评注）。**归属**：第 1 章 → ch01c（tr02）；第 2 章 → ch02e（tr04）；第 3 章 → ch03b（tr05，放在 §3.2 之前的位置不合适——实际写在 ch03c 末尾更合理，**故改归 ch03c（tr06）**）；附录 A → appA（tr06）；附录 B → appB4（tr08）；附录 C → appC3（tr10）。
- **监译者解说（tr10）**：文件开头必须是

```latex
\chapter*{监译者解说}
\addcontentsline{toc}{chapter}{监译者解说}
\markboth{监译者解说}{监译者解说}
```

  三节标题用 `\section*{1. Atiyah 与 K 理论}` + `\addcontentsline{toc}{section}{1. Atiyah 与 K 理论}` 的写法，**不要**用 `\section`。
