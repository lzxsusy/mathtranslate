## 体例

- 原书页码以 `% [原文 p.N]` 标在每页起始处；PDF 页号 = 原书页码 + 9。
- 公式、陈述（定义/定理/命题/引理/推论/例/注）编号照录原书，不重排。原书的编号体系是三套计数器：**定义**独立计数；**定理/命题/引理/推论**共享一个计数器；**例**按章计数（同一节里「定义 1.3.2」与「命题 1.3.2」并存是原书体例，不是笔误）。
- 原书笔误只加 `% [Tutor Note: ...]` 批注，不改正文；122 条批注汇总在书末《译校批注》，每条注明原书页码与所在节。
- 每节前「本节重点」，每章（含附录）末「本章回顾与评注」，均可在导言区用 `\showtakeawayfalse` / `\showchapterreviewfalse` 关闭。
- 日译本页脚的「＊（訳注）」按脚注译出；附录 B、C 末尾的参考文献照原书抄录（条目为西文原文）。
- 术语见 `deliverable/术语对照表.tsv`（约 200 条）。

## 已知限制

1. **原书索引未收**（p.203–207，含记号索引与人名索引）。日译本索引为和文/欧文混排、多级缩进，重建成本高且易错；检索改由本书目录 + 术语表 + 页标记 + 译校批注承担。
2. 原书目录（p.vii–viii）不重排，由 LaTeX 自动目录代替。
3. 底本文字层 OCR 质量中等（公式基本是乱码，如 `巾`→⊗、`④`→⊕、`幕`→冪），所有公式一律按页图重排；个别扫描模糊处已在批注中说明。
4. 原书正误按原样排，疑误只入批注。若读者发现新疑点，请补 `% [Tutor Note: ...]` 后重跑 `gen_notes.py`。
5. 附录 A 的页码 / 定理编号：原书作「系 A.4」「引理 A.9」（BRIEF 早期的 A.4.9/A.9.1 是 OCR 噪声）。
