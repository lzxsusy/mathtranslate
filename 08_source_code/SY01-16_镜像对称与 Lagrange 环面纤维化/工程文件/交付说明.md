## 三、体例

1. **章节**：原文「N. 標題」一律译为「第 N 节 标题」，四级以内不再细分（原文亦无小节）。
2. **公式**：编号公式逐条用 `equation` + `\tag{N}`；原书未编号的居中公式用 `\[…\]`，绝不擅自加号。公式后接续的文字加 `\noindent`，与原书「公式后不缩进」的版式一致。
3. **文献引用**：保留原书标签（`[AAK]`、`[CPUa, Theorem 1.1]`、`[Pas14, Proposition 4.4]` 等）以纯文本排印，不用 BibTeX/`\cite`，以便与原书逐条对照。
4. **页码对照**：每个 chunk 开头有 `% ===== 原书 p.N =====` 注释，可在源文件中直接定位原书页。
5. **译注**：校读中发现的底本疑点、术语说明、背景知识，以 `% [Tutor Note: …]` 注释形式写在对应位置（不进入排版），另汇总于 `审校批注汇总.md`。
6. **排版参数**：11 pt、A4，版心 2.4/2.4/2.6/2.7 cm，页眉左侧英文题、右侧中文题与页码；中文用全角标点，英文术语与数字两侧留半角空格。

## 四、翻译与校勘原则

1. **公式以图像为准**：文字层（`work/split/pNNN.txt`）的数学符号不可靠，全部 27 个编号公式连同正文中的行内公式，均按 300 dpi 原页图像（`work/pages/pNNN_300.png`）逐符号核对后转写；核对手段为 `work/tools/crop.py <页> x0 y0 x1 y1 <输出> [dpi]` 局部放大。
2. **原书笔误照录**：凡是疑似底本排印错误，译文一律照原样排出，另在 `% [Tutor Note: …]` 中说明「原文如此、通常应作何」，不擅自改正（详见 `审校批注汇总.md` 第一部分）。仅对明显的假名/拉丁字母误植（如「ファーブレーション」「Fleor」）按正字处理，并在注中说明。
3. **术语统一**：以 `work/glossary.tsv` 为准。要点：Fukaya 范畴、导出范畴、相干层、三角范畴、wrapped Floer 上同调（wrapped 保留英文）、殆复、伪全纯、环面（toric）、纤维化、截面、格、扇、反典范因子、校准形式、特殊 Lagrange 子流形、热带仿射变换、整仿射变换、穿墙公式、amoeba、焦点-焦点（focus-focus）奇点、crepant 解消、普通二重点（conifold）。
4. **专名保留英文**：Lagrange、Calabi–Yau、Floer、SYZ、Liouville、Legendre、Bohr–Sommerfeld、Maslov、Hamilton、Newton、Laurent、Gromov–Witten、Kontsevich、Givental、Lian–Liu–Yau、Strominger–Yau–Zaslow、Abouzaid、Auroux、Katzarkov、Chan–Pomerleano–Ueda、Gross–Matessi、Pascaleff 等。
5. **文风**：全角中文标点；避免「被……所」「进行……的」「对于……而言」一类翻译腔；长句按中文习惯拆分，但不改变原文逻辑层次。
6. **独立校读**：初译完成后，由另一名译者独立通读、对照 300–600 dpi 原页裁图逐符号核对 (1)–(27) 与全文，报告列「必须修改」5 条、「建议修改」19 条；除两条经核实为报告行号定位偏移者外，均已改入源文件并重编。校读发现的问题与本译者的疑点合计 **20 条 Tutor Note**（甲部 14 条底本疑点、乙部 6 条说明性注），逐条记录于 `审校批注汇总.md`，处理过程见该文件丙部。

## 五、编译与自检

```powershell
# 在工程根目录
powershell -ExecutionPolicy Bypass -File build.ps1     # XeLaTeX 两遍 + 统计 + 复制到 deliverable/
python check.py                                        # 结构自检
```

- `build.ps1` 以 `<本地路径>` 编译 `src/main.tex` 两遍，报告页数、Overfull、Undefined reference、Missing character，并把 PDF 复制到 `deliverable/`。
- 注意：`build.ps1` 必须存为 **UTF-8 with BOM**（本机 `powershell` 是 5.1，无 BOM 时按 GBK 解析脚本中的中文路径会报 `Illegal characters in path`）；`src/chunks/*.tex` 则保持 UTF-8 无 BOM、LF。
- `check.py` 校验：编号公式 1–27 齐全且顺序正确、`\begin`/`\end` 环境配对、文件编码（无 BOM、无 CR）、数学模式内不得出现全角标点、不得出现 `\documentclass`/`\usepackage`/`\cite`/`\ref`/`\label` 与 Markdown 残留、`\section` 计数为 5。
- 本次交付的最终状态：`pages=11  Overfull=0  Undefined=0  MissingChar=0`，`check.py`：tags=27、sections=5、**0 errors 0 warnings**。
