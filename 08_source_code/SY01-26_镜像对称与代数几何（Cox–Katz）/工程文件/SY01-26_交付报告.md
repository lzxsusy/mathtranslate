## 二、方法

1. **原文数字化**：原书为纯扫描件（495 页，无文本层）。第一轮 200 dpi RapidOCR 有整行丢失，
   弃用；第二轮 300 dpi、`det_limit_side_len=1600`、8 进程重跑 483 页，正文完整、公式仍不可辨
   （逐条记入 `skipped`，共 632 条，不臆断）。
2. **切块**：按 `\SourcePage{N}`（N = PDF 物理页 = 印刷页 + 23）每 3 页一单元，共 153 个单元。
3. **并行校对**：子智能体每批 8 个，读单元中英对照，逐句产出 JSON 问题单（line/page/quote/new/problem/confidence）；
   机械替换时按 `manifest` 行号窗口定位、以 (file, quote, new) 去重。
4. **高风险复核**：对记号、同调/上同调、公式类问题，用第二份高分辨率扫描（`镜对称与代数几何.pdf`）
   渲染原页逐条核对——抽查的 u47（Δ∩M）、u81（homology class）、u94（1/(2πi)^d）全部属实。
5. **术语裁决**：与库内 27 个 SY01 工程对照（单值性 1049 次 vs 单值变换 386 次 vs 单值化 209 次），
   本书随库内主流改 2 条、保留 4 条，理由写在 `术语对照与冲突.md`。

按原著 §5.6 式 (5.72)（英文本 p.111；译本 `chapters/chapter05.tex:1662`）的闭式

$$Y=\frac{5}{(1+5^5z)y_0(z)^2}\Big(\frac qz\frac{dz}{dq}\Big)^3,\qquad q=\exp(y_1/y_0),$$
