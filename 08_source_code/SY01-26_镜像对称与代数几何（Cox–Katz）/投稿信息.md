## 三、校对方法

1. 原书为纯扫描件（无文本层）。RapidOCR 300 dpi、`det_limit_side_len=1600`、8 进程 OCR 全部 483 页
   （首轮 200 dpi 有整行丢失，弃用）。
2. 按译本 `\SourcePage{N}`（N = PDF 物理页 = 印刷页 + 23）切 153 个单元，每单元中英对照。
3. 子智能体每批 8 个并行，逐句产出问题单；机械替换按行号窗口定位，(file, quote, new) 去重。
4. 记号/同调/公式类高风险问题用第二份高分辨率扫描逐页复核。
5. 术语与库内 27 个 SY01 工程对照后裁决（详见 `工程文件/校对/术语对照与冲突.md`）。
