# MS-23 nef 分拆与 Batyrev 镜像构造

## 1. 一句话

把反典范除子按射线拆成整体生成除子之和，再取对偶多胞形造镜像完全交族。

## 2. 为什么需要它

- **超曲面框架不够用。** §4.1 的 Batyrev 构造只处理环面簇中的反典范超曲面（一个方程，p.076–079）；环面簇中的 Calabi–Yau 完全交（k 个方程）需要新的离散数据。§4.3 开篇即说这是「推广第 4.1 节研究的环面超曲面」，并引 [Borisov1]、[BB1] 作为两条路线（p.086）。
- **不引入 nef 分拆，镜像侧的多胞形 ∇ 无从定义。** 定义 4.3.1 的划分 Σ(1)=I_1∪…∪I_k 给出除子 E_j，再取 ∇_j=Conv({0}∪I_j)、∇=∇_1+…+∇_k，才有 P_∇、V̄°、V° 与 Hodge 数反射 (4.15)(4.16)（p.086）。镜像族 V° 的全部构造输入都来自这个分拆。
- **它同时是可检验的镜像证据与后续计算的入口。** [Borisov1] 保证 ∇ 自反（否则 §4.1 的 Batyrev 机器无法启动），[BB2] 给出可逐项核对的 (4.16)（p.086）；第 5 章「nef 完全交」小节把 §4.3.1 的分拆当成 nef 完全交的标准来源来算 GKZ/Picard–Fuchs（p.119 起，页码待核）。

## 3. 定义（全假设）

**3.1 背景与记号。** 设 M、N 为互相对偶的自由 Z-模，M≅Z^n，⟨·,·⟩:M×N→Z 为配对。Δ⊂M_R 是 n 维自反整多胞形：0∈IntΔ，且每个刻面可写成 ⟨m,v_Γ⟩=−1（v_Γ∈N 本原）（p.057、p.069；MS-09）。X=P_Δ 是 Δ 的法扇 Σ=Σ_Δ 决定的 n 维 Gorenstein Fano 环面簇（一般允许奇异）；Σ(1) 为一维锥（射线）生成元集。Δ 自反时 Σ(1) 恰是极多胞形 Δ°⊂N_R 的顶点集（p.086 原话）。对 ρ∈Σ(1)，D_ρ 为对应的不可约环面除子；由 p.069–070 命题 3.5.5，−K_X=Σ_{ρ∈Σ(1)}D_ρ 是丰沛 Cartier 除子。记 k 为下面分拆的块数，d=n−k 为完全交的维数。

**3.2 定义（定义 4.3.1，p.086）。** 设 k≥1，Σ(1)=I_1∪…∪I_k 是 Σ(1) 的分拆（两两不交、并为全集；本卡默认每块非空，见 §11 Q2）。令
$$E_j=\sum_{\rho\in I_j}D_\rho,\qquad j=1,\dots,k ,$$
则 −K_X=E_1+…+E_k 自动成立（p.086）。**若对每个 j，E_j 都是由整体截面生成的 Cartier 除子**（即 O_X(E_j) 为 Cartier 层，且其整体截面的赋值映射满：任意点的剩余域上该纤维由截面值生成，等价于 O_X(E_j) 无基点），则称该分拆为 **nef 分拆**。
组合翻译：设 Δ_j 是 E_j 对应的多胞形，即 Δ_j=Δ∩{m∈M_R: ⟨m,ρ⟩≥0 对所有 ρ∉I_j}（p.057–058 的除子—多胞形字典，式 (3.3)；MS-08）。若 E_j 是 Cartier 且由整体截面生成，则 Δ_j 是格多胞形，且 p.086 说 nef 分拆意味着
$$\Delta=\Delta_1+\cdots+\Delta_k\quad(\text{Minkowski 和}).$$
书随后用「不严格地说」把 −K_X=ΣE_j 与 Δ=ΣΔ_j 这两条本身也称为 nef 分拆；本卡采用严格的 Cartier+整体生成版本（§3.4）。

**3.3 从 nef 分拆到镜像完全交（p.086–087）。** 分三步。
（i）完全交：取 O(E_1),…,O(E_k) 的一般截面，其公共零点集是 X=P_Δ 中维数 d=n−k 的完全交 V̄；由 −K_X=ΣE_j 与伴随公式得 K_{V̄}=0，即 V̄ 是 Calabi–Yau 簇（p.086）。
（ii）去奇点：取 Δ 的法扇的极大射影细分 Σ'（§4.1，p.076 一带），得双有理射影态射 X_{Σ'}→P_Δ；V̄ 的严格变换 V⊂X_{Σ'} 仍是完全交，并且是**极小** Calabi–Yau 簇（[BB1, 命题 4.15]）。
（iii）对偶侧：对 j=1,…,k 令 ∇_j=Conv({0}∪I_j)⊂N_R（把 I_j 看作 Δ° 的顶点子集），则 Δ°=Conv(∇_1∪…∪∇_k)。[Borisov1] 的基本结果是：Minkowski 和 ∇=∇_1+…+∇_k 仍是**自反**多胞形，而且 ∇=∇_1+…+∇_k 本身也是一个 nef 分拆，[BB1] 称之为**对偶 nef 分拆**。对 ∇ 重复（i）（ii），得 V̄°⊂P_∇ 与极小 CY 完全交族 V°⊂X_{Σ°}（Σ° 为 ∇ 的法扇的极大射影细分）。**本书猜想**：V° 是 V 的镜像族（p.086；与 [LTe] 的射影空间完全交镜像构造相合）。

**3.4 本书用法。** Cox–Katz 一律采用定义 4.3.1 的严格版本（E_j 是 Cartier 且由整体截面生成），而不是「−K_X 拆出的某个除子和是 nef 除子」；「对偶 nef 分拆」按 [BB1] 的叫法；∇ 自反由 [Borisov1] 保证。此处「nef」指 Gorenstein Fano 环面簇上由整体截面生成的除子（即 basepoint-free），不能与一般 Kähler 锥里「nef 除子」的通常定义混同（p.086 未把两者等同）。

## 4. 最小例子（能算出）

**4.1 k=1：五次三维簇（queue 指定；p.084–086）。** n=4，X=P_Δ=P^4，Δ 是五次多项式的 Newton 多胞形，顶点为 (−1,−1,−1,−1)、(4,−1,−1,−1)、(−1,4,−1,−1)、(−1,−1,4,−1)、(−1,−1,−1,4)，即 Δ={−1≤m_i, Σm_i≤1}；Δ°=Conv{e_1,e_2,e_3,e_4,−u}，u=(1,1,1,1)（p.084）。于是 Σ(1)={e_1,…,e_4,−u}，共 5 条射线，恰为 Δ° 的 5 个顶点。
取 k=1、I_1=Σ(1)。则 E_1=Σ_{ρ∈Σ(1)}D_ρ=−K_{P^4}=5H，其中 H 为超平面类；h^0(5H)=C(9,4)=126=l(Δ)，且 5H 丰沛，故 E_1 是 Cartier 且由整体截面生成——这是 nef 分拆。Δ_1=Δ，Δ=Δ_1 自动成立。
d=4−1=3，V 就是 §4.2 的五次三维簇。按 p.080–082 的 Hodge 数公式，h^{1,1}(V)=l(Δ°)−n−1−Σ_{Γ°}l^*(Γ°)=6−4−1−0=1，h^{2,1}(V)=l(Δ)−n−1−Σ_Γ l^*(Γ)=126−4−1−20=101（l(Δ°)=6、Σ_Γ l^*(Γ)=20 的计数见 MS-09）。
对偶侧：∇_1=Conv({0}∪Σ(1))=Conv{e_1,e_2,e_3,e_4,−u}=Δ°（因 0∈IntΔ°），故 ∇=∇_1=Δ°，即 k=1 时对偶构造退回 §4.1–4.2 的 Batyrev 超曲面构造，V° 就是 p.085 的镜像族。核对式 (4.15)（d=3）：p=1 给 h^{1,1}(V)=1=h^{2,1}(V°)；p=2 给 h^{2,1}(V)=101=h^{1,1}(V°)。与已知镜像族 101/1 的 Hodge 数一致。

**4.2 k=2：P^3 中「三次曲面∩超平面」=椭圆曲线（定义 4.3.1 的非平凡计算）。** n=3，X=P^3，Δ=Conv{(−1,−1,−1),(3,−1,−1),(−1,3,−1),(−1,−1,3)}={−1≤m_i, Σm_i≤1}，Δ°=Conv{e_1,e_2,e_3,−u}，u=(1,1,1)，故 Σ(1)={e_1,e_2,e_3,−u}。
（a）取 I_1={e_1,e_2,e_3}，I_2={−u}。则 E_1~3H、E_2~H。数截面：l(Δ)=(n_1+n_2+n_3≤4 的非负整数个数)=C(7,3)=35=h^0(4H)=h^0(−K)；l(Δ_1)=C(6,3)=20=h^0(3H)；l(Δ_2)=4=h^0(H)。截面数分别与对应除子相容，且 3H、H 都丰沛，故 E_1、E_2 都是 Cartier 且由整体截面生成——是 nef 分拆。
（b）组合核对：Δ_1={m_i≥−1, Σm≤0}=Conv{(−1,−1,−1),(2,−1,−1),(−1,2,−1),(−1,−1,2)}，Δ_2={m_i≥0, Σm≤1}=Conv{0,e_1,e_2,e_3}。对 a∈Δ_1、b∈Δ_2 有 a_i+b_i≥−1、Σ(a+b)≤0+1=1，故 Δ_1+Δ_2⊂Δ；又 Δ 的 4 个顶点分别为 (−1,−1,−1)+0、(2,−1,−1)+e_1=(3,−1,−1)、(−1,2,−1)+e_2=(−1,3,−1)、(−1,−1,2)+e_3=(−1,−1,3)，都在 Δ_1+Δ_2 中，故 Δ=Δ_1+Δ_2。
（c）d=3−2=1：V 是一条平面三次曲线，即椭圆曲线（g=1，h^{1,0}=h^{0,1}=1，h^{1,1}=1）。式 (4.15) 在 d=1 时：p=0 给 h^{0,1}(V)=1=h^{1,1}(V°)，p=1 给 h^{1,1}(V)=1=h^{0,1}(V°)，自洽。
（d）对偶：∇_1=Conv{0,e_1,e_2,e_3}（4 个格点），∇_2=Conv{0,−u}=[0,−u]（线段），∇=∇_1+∇_2=Conv{0, e_1,e_2,e_3, −u, e_1−u,e_2−u,e_3−u}。它有 7 个刻面，法向量分别为 −e_1、−e_2、−e_3、(−2,1,1)、(1,−2,1)、(1,1,−2)、(1,1,1)，每面都取值 1，故 ∇ 自反（Borisov1 的保证在此可直接验算）；l(∇)=8（格点正是 {0,e_i,−u,e_i−u}）。对偶极多胞形 ∇°=Conv{e_1,e_2,e_3,(2,−1,−1),(−1,2,−1),(−1,−1,2),−u}，l(∇°)=23。注意 ∇≠Δ°：按 p.086 只有 Δ°=Conv(∇_1∪∇_2)=Conv{0,e_i,−u}（l=5），而 ∇=∇_1+∇_2 严格更大（l=8）；两者只在 k=1 时重合（见 §7 误解 2）。

**4.3 k=2：P^4 中四次 K3（同一机制的第二个可算例子）。** n=4，X=P^4，Δ={−1≤m_i, Σm_i≤1}，取 I_1={e_1,e_2,e_3,e_4}、I_2={−u}。E_1=4H、E_2=H，对应 Δ_1={m_i≥−1, Σm≤0}（l=70=C(8,4)=h^0(4H)）、Δ_2={m_i≥0, Σm≤1}（l=5=h^0(H)），且 Δ=Δ_1+Δ_2（Δ 的顶点 (4,−1,−1,−1)=(3,−1,−1,−1)+e_1 等）。d=4−2=2：V 是超平面 P^3 中的四次曲面，即四次 K3 曲面，h^{1,1}=20、h^{2,1}=0。核对式 (4.15)：p=1 给 h^{1,1}(V)=20=h^{1,1}(V°)；p=2 给 h^{2,1}(V)=0=h^{0,1}(V°)。

## 6. 推导流程（D1…Dn）

- **D1（输入）**：取 n 维自反整多胞形 Δ⊂M_R，X=P_Δ，Σ=Δ 的法扇；Δ 自反 ⟹ Σ(1)=Δ° 的顶点集，−K_X=ΣD_ρ（p.069–070 命题 3.5.5；p.086）。
- **D2（划分与除子）**：选 Σ(1)=I_1∪…∪I_k，令 E_j=Σ_{ρ∈I_j}D_ρ，得 −K_X=Σ_{j=1}^k E_j（p.086，定义 4.3.1 前一句）。
- **D3（nef 检验）**：验证每个 E_j 是 Cartier 且由整体截面生成；组合上等价于 Δ_j 是格多胞形、Δ=Δ_1+…+Δ_k（p.086；p.057–058 式 (3.3)）。
- **D4（完全交）**：取 O(E_1),…,O(E_k) 的一般截面，零点集 V̄⊂X 的维数为 d=n−k；伴随公式给出 K_{V̄}=0（p.086）。
- **D5（去奇点）**：取 Δ 的法扇的极大射影细分 Σ'（§4.1，p.076 一带），V̄ 的严格变换 V⊂X_{Σ'} 是极小 CY（p.086；[BB1, 命题 4.15]）。
- **D6（对偶多胞形）**：∇_j=Conv({0}∪I_j)⊂N_R；Δ°=Conv(∇_1∪…∪∇_k)（p.086，自反情形 Σ(1)=Δ° 顶点）。
- **D7（自反性）**：由 [Borisov1]，∇=∇_1+…+∇_k 自反，且 ∇=Σ∇_j 是对偶 nef 分拆（p.086）；对 ∇ 重复 D4–D5 得 V̄°⊂P_∇、V°⊂X_{Σ°}（p.086）。
- **D8（证据）**：Batyrev–Borisov 证 (4.15)（[BB1]）与 (4.16)（[BB2]）；「V° 是 V 的镜像族」仍为猜想（p.086）。
- **D9（统一）**：把 (Δ_1,…,Δ_k) 打包成式 (4.18) 的自反 Gorenstein 锥 σ，则对偶 (4.18) 给出 σ̌，命题 4.3.3 说明 σ̌ 来自对偶 nef 分拆；Cayley 技巧 (4.19)(4.20) 与 (p.088) 的广义 CY 把超曲面与完全交两种镜像统一为锥对偶（p.087–088；[BB3]）。

## 7. 常见误解与反例（≥2）

1. **误解：只要把 −K_X 写成除子和（或有任意 Minkowski 分解）就是 nef 分拆。** 反例（P^2）：Δ_{−K}=Conv{(−1,−1),(2,−1),(−1,2)}，Δ_{−K}=½Δ_{−K}+½Δ_{−K} 是合法的 Minkowski 分解，但对应除子 (3/2)H 不是 Cartier（Pic(P^2)=Z·H），故不满足定义 4.3.1；同时 E_j 必须是「按射线 0/1 系数」的除子和，不能任意取整系数。定义里的 Cartier 与整体生成两个条件都不可省（p.086）。
2. **误解：∇ 就是 Δ°。** 一般不对：§4.2 的 P^3 例中 Δ°=Conv{e_i,−u} 有 l=5，而 ∇=∇_1+∇_2 有 l=8；两者都是自反多胞形但不同。p.086 给出的关系只是 Δ°=Conv(∇_1∪…∪∇_k)；只有 k=1 时才有 ∇=Δ°（§4.1）。
3. **误解：Batyrev 镜像构造已经证明镜像对称。** p.086 明言「猜想 V° 是 V 的镜像族」，已证的是 (4.15)(4.16) 的 Hodge 数反射（[BB1]、[BB2]）；p.088 还指出刚性 CY 三维簇没有通常意义的镜像（H^{2,1}(V)=0 而镜像需 H^{1,1}(V°)=0，Kähler 流形不可能），说明这一图景有真实边界。
4. **误解：nef 分拆与 §4.1 的超曲面构造无关。** k=1 时 ∇=Δ°、V̄=V̄、镜像族就是 §4.1–4.2 的 Batyrev 镜像；§4.3 是 §4.1 的推广（p.086 明说「推广第 4.1 节研究的环面超曲面」），式 (4.17) 也是 (4.18) 的 k=1 特例（p.087）。

## 10. 形式化接口（Lean 可 sorry）

```lean
-- 沿用 MS-08/MS-09 的格与多胞形接口：M、N 为对偶自由 Z-模，M_R = M ⊗_Z ℝ
variable {n k : ℕ} (M N : Type) [AddCommGroup M] [AddCommGroup N]

structure NefPartition (Δ : LatticePolytope n) (k : ℕ) where
  I : Fin k → Finset N                     -- 划分 Σ(1) = ⨆_j I_j，两两不交
  cover : Finset.univ.biUnion I = rays Δ    -- I_j 覆盖且不重
  E : Fin k → ToricDivisor (P_Δ Δ)          -- E_j = Σ_{ρ ∈ I_j} D_ρ（p.086）
  isCartier : ∀ j, (E j).IsCartier
  globallyGenerated : ∀ j, (E j).GloballyGenerated  -- 定义 4.3.1，p.086

def Delta_j (P : NefPartition Δ k) (j : Fin k) : LatticePolytope n :=
  {m | ∀ ρ, nsmul (coeff (P.I j) ρ) m ≤ pairing m ρ}   -- Δ∩{⟨m,ρ⟩≥0, ρ∉I_j}

def nabla_j (P : NefPartition Δ k) (j : Fin k) : LatticePolytope n :=
  convexHull n (insert 0 (P.I j))                     -- ∇_j = Conv({0}∪I_j)

def nabla (P : NefPartition Δ k) : LatticePolytope n :=
  minkowskiSum P.nabla_j                              -- ∇ = ∇_1 + … + ∇_k

theorem borisov_reflexive (P : NefPartition Δ k) : IsReflexive P.nabla := by sorry

theorem hodge_reflection (P : NefPartition Δ k) (d : ℕ) (hd : d = n - k) (p : ℕ)
    (hp : 1 ≤ p ∧ p ≤ d) :
    h_pq 1 p P.V = h_pq 1 (d - p) P.Vstar := by sorry   -- 式 (4.15)，p.086

theorem string_hodge_reflection (P : NefPartition Δ k) (p q : ℕ) :
    h_st p q P.V = h_st (d - p) q P.Vstar := by sorry    -- 式 (4.16)，[BB2]

theorem nef_cone_duality (P : NefPartition Δ k) :
    IsReflexiveGorensteinCone (sigma P) ∧ index (sigma P) = k := by sorry
    -- 命题 4.3.3，p.087；σ 由式 (4.18) 构造
```
