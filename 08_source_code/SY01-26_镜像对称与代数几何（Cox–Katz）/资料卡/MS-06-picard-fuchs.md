# MS-06 Picard–Fuchs 方程

## 1. 一句话

周期积分随参数变化的线性微分方程，本书用它算 Yukawa 耦合。

## 2. 为什么需要它

- **它是算不变量链的第一环。** 本书第 5 章开篇说：知道周期所满足的 PF 微分方程，是计算 Calabi–Yau 三维簇 Yukawa 耦合的**前提**（PDF p.96）；本章给两条求法（Griffiths–Dwork 与超几何/GKZ）。
- **Yukawa 耦合直接从方程读出。** 一维情形 §5.6.1 由 Griffiths 横截性 ∫Ω∧∇²_δΩ=0 推出 ∫∇_δΩ∧∇³_δΩ=−(1/2)∫Ω∧∇⁴_δΩ，于是 Y=∫Ω∧∇³_δΩ 满足 δY=−(1/2)f₁(z)Y（PDF p.125）：PF 方程的首个系数 f₁ 唯一决定 Y（差常数）。
- **镜像映射由 PF 解定义。** §6.3 令 (1/2πi)log q_k=(1/⟨g₀,Ω⟩)Σ⟨g_j,Ω⟩m^{jk}，即 q 是 PF 解之比（PDF p.172）；五次时 q=c₁(x−770x²+⋯)，第 2.5 节用镜像对称定出 c₁=−1（式 (2.9)–(2.12)，PDF p.43–44）。没有 PF 解就没有 q。
- **最大幺幂边界点靠指标方程判定。** 若一维模空间中 T 最大幺幂 ⇔ 指标方程对某整数 ℓ 为 (λ−ℓ)⁴=0（命题，PDF p.102–103）；而指标方程只能从 PF 方程读出，MUM 点又是镜像映射定义域（§6.2）。
- **r 维情形它是方程组、不是一条方程**，且超几何方法只给出一部分方程（PDF p.117），因此 §5 用「理想」而不用「单条 ODE」作定义。

## 3. 定义（全假设）

设定：π:X→S 是光滑族（S 复流形，相对维数 n），配 Hodge 结构变分与 Gauss–Manin 联络。逐条假设如下（均见 PDF p.97–98，§5.1.2）：

1. **上同调层。** F⁰=R^nπ_*ℂ⊗O_S，带 Hodge 滤过 F^p⊂F⁰（p 从 n 到 0）。
2. **固定截面。** Ω(t) 是 F^n 在 p∈S 上取定的**局部**截面（在局部解析坐标 z₁,…,z_r 下写 Ω(z)）。
3. **算子环。** 𝒟=ℂ{z₁,…,z_r}[∂/∂z₁,…,∂/∂z_r] 是 S 上线性微分算子层在 p 处的局部化。
4. **联络即 𝒟-模结构。** Gauss–Manin 联络 ∇ 由「局部常值截面的导数为零」定义，它同时给 F⁰ 一个 𝒟-模结构。
5. **表征映射。** ∇ 确定 O_S-同态 φ:𝒟→F⁰，φ(X₁⋯X_ℓ)=∇_{X₁}⋯∇_{X_ℓ}Ω(t)（X_i 为坐标向量场）。
6. **Picard–Fuchs 理想。** I=ker φ⊂𝒟，即零化 Ω(t) 的全部算子（含不可交换的复合）。
7. **PF 方程与解。** 对 D∈I，D·y=0 称 PF 方程；O_S 的局部截面 y 若对**所有** D∈I 满足 D·y=0，则称 PF 方程的解。
8. **周期是解。** 设 γ_t 是 H_n(X_t,ℤ) 的局部常值 n 圈，y(t)=∫_{γ_t}Ω(t)。由式 (5.2) ∂/∂z_i∫_{γ_t}Ω=∫_{γ_t}∇_{∂/∂z_i}Ω 立即得 D·y=0；写成 y=⟨g(t),Ω(t)⟩，g 为 γ_t 的 Poincaré 对偶、∇ 的平坦截面。反向也成立：D∈I ⇔ D 零化所有周期（PDF p.75–76）。
9. **单参数正则形式。** 取 δ=z d/dz。若在 0 的邻域内 F⁰ 有解析关系 ∇_δ^mΩ+f₁(z)∇_δ^{m−1}Ω+⋯+f_m(z)Ω=0（f_i 在 z=0 解析），则 δ^m+f₁δ^{m−1}+⋯+f_m∈I，周期满足式 (5.6) δ^m y+f₁δ^{m−1}y+⋯+f_m y=0。**要求** z=0 是正则奇点，才可写指标方程 λ^m+f₁(0)λ^{m−1}+⋯+f_m(0)=0（PDF p.100–101）。
10. **整体化。** 上述局部构造经解析延拓、并限于代数微分形式的周期，可作为整个 S 上的代数微分方程理解（PDF p.75）。

**本书用法。** Cox–Katz 定义的是**理想 I=ker φ**（p.74–75），不是一条标量方程：CY 三维时 [BG] 证明 φ 满射，于是 F⁰ 的 𝒟-模结构完全由 I 决定（此时「解空间维数 = h^n」才可控）；标准教材常只写「周期满足的 n 阶 ODE」，本书口径是「I 的任一元素给出一个方程，全部周期 = I 的公共解」，并且 r 维模空间下 I 一般不由单个元素生成（见 §7）。

## 4. 最小例子（能算出）

**五次超曲面镜像族**（§5.4 例题，PDF p.110–111；方程另见式 (2.8)，PDF p.43）。设

$$f=x_1^5+x_2^5+x_3^5+x_4^5+x_5^5+\psi\,x_1x_2x_3x_4x_5,\qquad X_\psi=\{f=0\}\subset\mathbb{P}^4,$$

模掉 G=(ℤ/5)⁴ 的对角作用，令 z=ψ^{−5}，δ=z\,d/dz=−(1/5)ψ\,d/dψ。取 Ω₀=Σ(−1)^i x_i\,dx_0∧⋯，则 H³(X_ψ) 的一组基为（j=1,2,3,4）

$$\omega_j=(-1)^{j-1}\psi^j\,(x_1x_2x_3x_4x_5)^{j-1}\,\Omega_0/f^j .$$

**第 1 步（联络的显式作用）。** 逐项求导并用 f₀=f−ψe（e=Πx_i）消去，得

$$\delta\omega_j=-\tfrac{j}{5}\,(\omega_j+\omega_{j+1}),\qquad \omega_5:=0 .$$

**第 2 步（迭代）。** 反复作用得（常数向量，ω₁…ω₄ 为基）

$$\delta\omega_1=-\tfrac15(\omega_1+\omega_2),\quad \delta^2\omega_1=\tfrac1{25}(\omega_1+3\omega_2+2\omega_3),\quad \delta^3\omega_1=-\tfrac1{125}(\omega_1+7\omega_2+12\omega_3+6\omega_4),$$

$$\delta^4\omega_1=\tfrac1{625}(\omega_1+15\omega_2+50\omega_3+60\omega_4).$$

其中 625=5⁴。j=4 的项 ω₅ 极点阶数超出可控范围，须做极点约化；约化把常数 1/625 换成函数

$$c(z)=\frac{5z}{1+5^5z}=\frac{5}{\psi^5+5^5},\qquad 5^5=3125 .$$

自检：z→∞（即 ψ→0）时 c→5/3125=1/625，与第 2 步的常数结果吻合；c 的极点 z=−5^{−5} 恰是式 (2.8) 的第二个奇点。故

$$\delta^4\omega_1=c\,(\omega_1+15\omega_2+50\omega_3+60\omega_4).$$

**第 3 步（把 ω₂,ω₃,ω₄ 换回 δ^kω₁）。** 由第 1 步反解：

$$\omega_2=-\omega_1-5\delta\omega_1,\quad
\omega_3=\omega_1+\tfrac{15}{2}\delta\omega_1+\tfrac{25}{2}\delta^2\omega_1,\quad
\omega_4=-\omega_1-\tfrac{55}{6}\delta\omega_1-25\delta^2\omega_1-\tfrac{125}{6}\delta^3\omega_1 .$$

代入整理得

$$\delta^4\omega_1+c\,(24\,\omega_1+250\,\delta\omega_1+875\,\delta^2\omega_1+1250\,\delta^3\omega_1)=0,$$

即算子恒等式 δ⁴+1250c\,δ³+875c\,δ²+250c\,δ+24c ∈ I。乘以 (1+5⁵z) 并代入 c，得

$$(1+3125z)\,\delta^4y+6250z\,\delta^3y+4375z\,\delta^2y+1250z\,\delta y+120z\,y=0,$$

系数逐条对得上式 (2.8)：6250=2·5⁵，4375=7·5⁴，1250=2·5⁴，120=24·5（式 (2.8) 的 x 即本卡 z）。

**第 4 步（读出具体数值）。** z=0 处除首项外全部系数为 0，指标方程为 λ⁴=0：四重根 0，故 λ⁴=0 即 T 最大幺幂（命题，PDF p.102–104；MUM 点 (T−I)³≠0、(T−I)⁴=0）。唯一全纯解由式 (2.11) 给出

$$y_0=\sum_{n\ge0}\frac{(5n)!}{(n!)^5}(-1)^n z^n=1-120z+113400z^2-\cdots,$$

首项系数 5!/(1!)⁵=120、次项系数 10!/(2!)⁵=3628800/32=113400，与方程系数 120z 一致（z 的一次项：δ^k y 的常数项只有 k=0 非零，120z·1=0）。

## 6. 推导流程（D1…D8）

- **D1（几何设定）。** 光滑族 π:X→S 给出 F⁰=R^nπ_*ℂ⊗O_S 与 Hodge 滤过；局部常值截面的导数为零定义 ∇（§5.1.1–5.1.2，PDF p.97）。
- **D2（周期可微）。** 对局部常值 γ_t 用式 (5.2)，参数方向的导数等于联络作用（PDF p.75）。
- **D3（造理想）。** φ(X₁⋯X_ℓ)=∇_{X₁}⋯∇_{X_ℓ}Ω 定义 φ，I=ker φ；由 D2，D∈I 零化全部周期，反之亦然（PDF p.75–76）。
- **D4（单参数化）。** 写 ∇_δ^mΩ+Σ_{i=1}^m f_i∇_δ^{m−i}Ω=0（f_i 解析）⇔ δ^m+Σf_iδ^{m−i}∈I；z=0 正则奇点时取 z=0 的系数得指标方程（PDF p.100–101，式 (5.5)–(5.6)）。
- **D5（Griffiths–Dwork 算法）。** 把 H^n(ℙ^n∖V) 的元素写成 PΩ₀/f^k（deg P=kℓ−n−1），取留数落到 H^{n−1}(V)；用 ∇_{d/ds}(PΩ₀/f^k)=(−kPf′+fP′)Ω₀/f^{k+1} 与 Gröbner 基做极点约化；再取 F⁰ 的基 ω₁…ω_r，算 δω_i,…,δ^rω_i，r+1 个向量在秩 r 的空间中线性相关 ⇒ 系数给出 I 的元素（PDF p.106–108）。
- **D6（五次实例）。** 取 r=4 的基 ω₁…ω₄，用 δω_j=−(j/5)(ω_j+ω_{j+1}) 迭代 + 极点约化得 δ⁴ω₁=c(ω₁+15ω₂+50ω₃+60ω₄)，反解即得式 (2.8)（PDF p.110–111；方程见 p.43）。
- **D7（判 MUM）。** 由指标方程 λ⁴=0 与命题（i)(ii)，得 z=0 为最大幺幂边界点（PDF p.102–104）；解出 y₀ 与带 log 的 y₁…y₃。
- **D8（下游）。** y₀,y₁ 经 (1/2πi)log q=y₁/y₀ 给镜像映射（§6.3，PDF p.172–173）；f₁ 经 δY=−(1/2)f₁Y 给 Yukawa 耦合（§5.6.1，PDF p.125）。

## 7. 常见误解与反例（≥2）

1. **误解：PF 方程就是一条 n 阶标量 ODE。** 反例：P(1,1,2,2,2) 中次数 8 的 CY 超曲面镜像有 2 维复模（h^{2,1}=2），其 PF 方程是两个算子（阶数 2 与 3）组成的**方程组**，不是一条 ODE（PDF p.111–112、p.119）；(λ−ℓ)⁴ 型判据只适用一维模。
2. **误解：方程只由族 X→S 决定。** 反例：规范变换 Ω′=g(z)Ω（g=a_ℓz^ℓ+⋯，a_ℓ≠0）使指标方程变为 (λ−ℓ)^m+f₁(0)(λ−ℓ)^{m−1}+⋯+f_m(0)=0，根整体平移 ℓ（PDF p.101）——同一个族换截面得到不同方程；不变的只是理想 I（φ 满射时）与周期之比 y_k/y₀。
3. **误解：A-方程组/GKZ 超几何已经给出全部 PF 方程。** 反例：五次时五阶 GKZ 算子并不生成 I，缺的正是四阶算子 (2.8)，须对它因式分解取四阶因子（PDF p.117–118）；不完全性的两个来源是「缺少低阶方程」与「自同构」（PDF p.118）。
4. **误解：周期是单值函数。** 反例：只有 y₀ 在 MUM 点全纯，y_k=y₀\,log z_k/2πi+（全纯）（PDF p.105）；局部解 z^λf₀ 绕边界点一周乘 exp(2πiλ)（PDF p.101）。多值性正是单值性（monodromy）的来源。

## 10. 形式化接口（Lean 可 sorry）

```lean
-- 只列接口与关键假设，证明一律 sorry；Mathlib 尚无 Gauss–Manin 联络（版本待核）
import Mathlib.Analysis.Complex.Basic
import Mathlib.LinearAlgebra.Matrix.GeneralLinearGroup

namespace MirrorSymmetry

/-- 族 π : X → S（S 复流形，相对维数 n）上的 PF 数据：
    F⁰ = R^n π_*ℂ ⊗ O_S，Ω ∈ F^n 的局部截面，∇ 为 Gauss–Manin 联络（𝒟-模结构）。 -/
structure PFData (n : ℕ) where
  S : Type
  𝒟 : Type                            -- 算子环 ℂ{z}[∂/∂z]
  F0 : Type                           -- F⁰ 的截面空间
  omega : F0                          -- Ω(t)
  nabla : 𝒟 → F0 → F0                 -- X ↦ ∇_X
  leibniz : ∀ (d₁ d₂ : 𝒟) (s : F0), nabla (d₁ * d₂) s = nabla d₁ (nabla d₂ s)

/-- Picard–Fuchs 理想 I = ker φ。 -/
def pfIdeal {n : ℕ} (P : PFData n) : Set P.𝒟 := { d | P.nabla d P.omega = 0 }

/-- 周期 y(t) = ∫_{γ_t} Ω(t)，γ_t 是局部常值同调 n 圈（此处抽象为线性泛函）。 -/
def period {n : ℕ} (P : PFData n) : (P.F0 → ℂ) → P.F0 → ℂ := fun gamma => gamma

/-- 性质 1（书 PDF p.75–76，式 (5.2)）：周期是 PF 方程的解。 -/
theorem period_is_solution {n : ℕ} (P : PFData n) (gamma : P.F0 → ℂ)
    (h : ∀ d : P.𝒟, gamma (P.nabla d P.omega) = 0) :
    ∀ d ∈ pfIdeal P, gamma (P.nabla d P.omega) = 0 := by
  intro d hd; exact h d

/-- 一维模 CY 三维簇：T 最大幺幂 ↔ 指标方程 (λ−ℓ)⁴ = 0（书 PDF p.102–104，命题）。 -/
def MUM (T : Matrix (Fin 4) (Fin 4) ℂ) : Prop :=
  (T - 1) ^ 4 = 0 ∧ (T - 1) ^ 3 ≠ 0

theorem mum_iff_indicial (T : Matrix (Fin 4) (Fin 4) ℂ) (lam : Fin 4 → ℂ) :
    MUM T ↔ ∃ ℓ : ℤ, ∀ i, lam i = (ℓ : ℂ) := by sorry

end MirrorSymmetry
```
