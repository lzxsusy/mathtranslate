## 本轮做了什么

1. **OCR 原文**：原书为纯扫描件（495 页，无文本层）。用 RapidOCR 300 dpi、`det_limit_side_len=1600`
   重跑全部 483 页（首轮 200 dpi 有整行丢失，弃用），得到 `ocr2/pNNN.txt`。
2. **切块**：按 `\SourcePage{N}` 每 3 页一个单元，共 153 个单元（`units/uNN.tex` + `uNN.en.txt`）。
3. **逐句对照**：153 个单元分给子智能体（每批 8 个并行），对照中英逐句核查，产出 209 条问题
   （术语 89、错译 34、增译 28、记号 24、病句 14、漏译 13、数学 3、指代 1）。
   机械替换 136 条（0 条失配），其余经术语归一化处理。
4. **术语归一**：本书旧译把 monodromy 通篇译作「单值化」（149 处，与 uniformization 冲突）、
   把「虚拟基本类」写作「虚基本类」（140 处）、pencil 译作「线性束」、universal family 译作「通用族」，
   已统一为单值性 / 虚拟基本类 / 线性系 / 万有族；消失圈、代数叠、多胞形、自反多胞形保留本书用法并说明理由
   （见 `工程文件/校对/术语对照与冲突.md`）。
5. **原文核对**：抽查公式与记号，发现 5 处原书笔误（含 p16 求和下限、p98 `H^2` 应为 `H_2`、
   p278 射影丛关系式指数差一格），译本已吸收 AMS 勘误的地方按译注处理，不机械改回。
6. **译注**：新增「附录 C 译注汇编」（94 条，按原书 PDF 页排序），记录 OCR 不可辨处、术语与记号歧义、
   作者跳步；正文不加脚注，以免破坏原书页码对位。
7. **资料卡**：24 张，覆盖 L0 几何/Hodge 基础、L1 量子上同调与 Gromov–Witten、L2 镜像构造与物理侧，
   并与 SY01-24（Siebert 讲义术语表）、SY01-25（同调镜像对称资料卡）逐条对照，冲突登记在
   `资料卡/_冲突表.md`。
