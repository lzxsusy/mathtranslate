## Tutor Notes（4 条，均为源码注释）

1. p.081 Ricci 公式：原书作 $R(G)_{i\bar j}=\partial_i\partial_{\bar j}\det(G_{m\bar n})$，照录；通常写作 $-\partial_i\partial_{\bar j}\log\det(G_{m\bar n})$。
2. p.083 「ミラー写像」译名说明：镜像映射 / 镜像变换 分工。
3. p.086 记号校勘：此处原书作 $\R/2\pi\Lambda_{\R}$，p.76 作 $\R^2/2\pi\Lambda_{\Z}$，两处照录，疑为笔误。
4. p.088 T 对偶背景：半径 $R$ 与 $1/R$ 的圆周给出同一弦理论（$\alpha'=1$），故 $R_1\mapsto 1/R_1$ 不改变物理。
