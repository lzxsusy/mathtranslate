## 三、编译方法

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
# 单章草稿自检：
powershell -ExecutionPolicy Bypass -File build.ps1 -Chunk ch02
```

- 引擎：**LuaLaTeX**（TeX Live 2026，ctexbook 中文方案），编译 3 遍。
- 本机硬约束：lualatex 不能写非 ASCII 路径与 Desktop，`build.ps1` 先把 `src/` 镜像到 ASCII 目录（`-Root` 参数可指定，多人并行时各用各的）再编译，最后把 PDF 拷回 `src/main.pdf`。
- 一键通过判据：`file:line` 错误 0、Undefined 0、Missing character 0、Overfull 0。
- 质量闸门脚本：`check.py`（源码卫生／页标记／编号唯一性／语言病灶／术语一致性／批注格式／插图存在性）、`verify_pdf.py`（成品回读：章标题、编号出现、内嵌图、字体嵌入）。

## 四、译校体例

1. **页码对照**：源码每页开头写 `% ===== PDF p.NNN (原书 p.N) =====`（不进入成品）；图题末尾标「（原书 p.N）」。
2. **编号**：公式用 `\tag{原编号}` 手工给号；陈述用专门环境并手工抄原书编号（如 `\begin{definition}{1.2}`），不自动计数、不重排。原书陈述后紧跟证明、且原文无收尾符者用带星号环境。
3. **图**：全部自扫描页裁出，图号与图注照原书；裁图经逐幅目视复核，图内日文标注保留不译。
4. **译校批注**：以源码注释 `% [Tutor Note: …]` 给出，不进入正文；书末「附录 A：译校批注」按章汇集并注明原书页码。三类内容：易错预警、作者省略论证的点拨、背景直觉。**正文不使用译者脚注**（原书自身脚注照译）。
5. **术语**：以附录 B 为准。有稳定通行中文名者用中文；无稳定译名或硬译反碍对照文献者保留原文（Floer 同调、Gromov–Witten 不变量、Calabi–Yau 流形、D-模、flop、nef 等）。人名一律不译，正文不加敬称。
6. **日文特有词**：位相空間→拓扑空间、相空間→相空间、概複素構造→近复结构、正則写像→（代数几何）正则映射／（复几何）全纯映射、原始形式→原始形式、原初場→原初场、部分トーラス→子环面、アメーバ→阿米巴、反標準束→反典范丛。
7. **疑似笔误**：一律照录原书，只在批注中指出并给出通行形式；仅当不改则句不成句时径改，并在批注写明原文与理由。
8. **节号体例**：各章按原书自己的体例（罗马数字或阿拉伯数字），不强行统一。

## 七、已知偏差与限制

1. **底本为扫描件＋日文 OCR 文字层**：正文意思可信，公式文字层基本不可用；全部公式均回原书页面图像逐符号核对。个别页图像模糊处已在批注注明。
2. **原书索引（p.164–165）未转录**：原书索引为五十音排列，页码无法映射到译本页码，且中文读者按音序检索意义有限；改以附录 B 术语对照表（604 条）提供检索。
3. **原书每章末尾的作者读音标记**（如「［ふかやけんじ］」）在译本中省略。
4. **原书参考文献**照录日文原文，不译不补。
5. **第 3 章原书无参考文献表**，译本亦不设。
6. **未做逐句回译校对**；交叉校对以「公式逐符号核对＋结构核对＋边界接缝核对＋术语一致性」为主。
7. 本书为多人合著的编集本，**各章作者与文风不同**，第 1、3、5、7、9、11 章为「导读型」叙述，第 2、4、8、10 章偏技术，第 6、12 章偏物理与展望；译注本不强求各章体例统一。
