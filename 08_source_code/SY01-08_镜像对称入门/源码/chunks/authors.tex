\noindent\textbf{深谷賢治}（ふかや けんじ）

\medskip
1959 年生。1981 年毕业于东京大学理学部数学科。现任京都大学研究生院理学研究科教授，专业为几何学。

\medskip
主要著作有：《ゲージ理論とトポロジー》（Springer--Verlag 东京）、《シンプレクティック幾何学》（岩波书店）、《これからの幾何学》（日本評論社）、《電磁場とベクトル解析》（岩波书店）、《解析力学と微分形式》（岩波书店）、《双曲幾何》（岩波书店）等。
