### 体例决定（本块定下）

1. 原书 Remark 1–3 一律用 `remarkx`（lead 裁定），印「注 1／2／3」，独立计数器；不用 `remark` 环境，以免挤占 result 计数器。
2. 「$\cK_X$ 与 $K_X$」严格区分：花体记 $X$ 上\emph{作为层}的典范丛，直立体记其全空间（一个环簇）；$\hat Z$ 与 $\tilde Z$ 也严格区分（前者是除子，后者是导出概型）。
3. 「$\varphi$（分段线性函数）／$\phi$（Stein 函数）」这一对同音异形记号全程保留原文区别。
4. 引文说明性短语（如「[Aur18]」「[GPS20c, Example 7.25]」）一律嵌在句中、保留字面，不加 `\cite`。
5. 原文 p.18「we define define $\eta$」为重复笔误，译文按单次「定义」处理，未加译者注（不改信息量）。
6. 定理 1.4.2 中 $X_0(\check B)$ 的 $X$ 在原书是数学斜体，与花体 $\cX$（环簇退化族的空间）不同，译文照此区分。
