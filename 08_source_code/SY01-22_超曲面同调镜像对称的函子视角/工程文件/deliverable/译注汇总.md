# EN49 译注汇总

本文件汇总全书 `\transnote{}`（译注）共 **181** 条。
分类统计：易错预警 87 条、含糊点拨 54 条、背景直觉 40 条。

## C00（14 条）

- 易错预警：原文 “hypersurfaces of different kinds” 指两类超曲面（奇异超曲面、 极仿射超曲面），而不是“若干种不同维数的超曲面”。
- 含糊点拨：本译文中“深谷范畴”对应 Fukaya category，取日文汉字人名“深谷”的 通行写法；作者在正文中对它与 wrapped Fukaya 范畴并不严格区分，记号统一为 $\cW$，读者须依上下文判断。
- 背景直觉：A 侧指辛几何一侧，B 侧指代数几何一侧；“A 侧类比”意为把原本陈述 在导出范畴一侧（B 侧）的定理，改述为深谷范畴一侧（A 侧）的相应命题。
- 易错预警：“导出等价”与后文的“拟等价”不是同一个概念。前者指导出范畴之间的 等价，后者是 $A_\infty$ 范畴之间的弱等价；作者在本论文中对二者用法有别。
- 含糊点拨：“在 Seidel 自然变换处作范畴局部化”一句压缩了 §1.2 给出的定义。 直观上，这条自然变换记录了绕奇异纤维一周的单值变换；把可逆化施加其上，相当于宣告 “绕行一周不产生新信息”，从而抹去退化方向。
- 背景直觉：Landau--Ginzburg 模型是带全纯函数的代数簇，其镜像对应 Fano 簇。 作者把它当作奇异超曲面的“平滑替身”：奇异纤维难处理，而与它同伦的 LG 模型 $X\times\C$ 是光滑的，故可在后者上作计算。
- 易错预警：“大复结构极限”是复结构模空间边界上的一类退化，缩写常作 LCSL； 不要与“大体积极限”（large volume limit）混淆，后者属 K{\"a}hler 模空间一侧。
- 背景直觉：极仿射超曲面指 $(\C^*)^n$ 中的代数超曲面。取补集后维数升高一维， 却仍是同一类对象，这正是 §1.1 所述“补集也有镜像”的结构性来源。
- 易错预警：原文说补集“有两个自然镜像，其中之一是导出概型”，意思是两个镜像 之中有一个不是概型而是导出概型；不要读成“补集有一个导出概型的镜像”这种单数说法。
- 含糊点拨：“非几何等价”指该等价不能由两侧几何空间之间的映射实现，只是范畴 层面的等价；它由 Orlov 的导出 Kn{\"o}rrer 周期性给出，故称“以 Kn{\"o}rrer 周期性为 中介”。
- 背景直觉：Liouville 扇形是带角流形的辛块，可像积木一样粘合；把局部模型粘成 整体是本文第二部分的证明策略，作者称这些技巧“有独立价值”，即不依赖镜像对称也成立。
- 含糊点拨：原文 “reading many many drafts” 表明导师逐稿细读；“drafts of the papers in this thesis” 指本论文所含各篇文章的稿本，不是本论文本身的稿本。
- 背景直觉：“go to bat for” 是棒球习语，意为替人出头、为其力争；此处指 Auroux 为作者争取到 Berkeley 与 Harvard 的求学机会，故译作“出面奔走”。
- 易错预警：Rutherford Foundation 是新西兰皇家学会（Royal Society of New Zealand）下属基金会，不是英国 Rutherford 实验室或卢瑟福基金；专名一律保留英文。

## C01（15 条）

- 易错预警：原文 “putative equivalence” 中的 putative 意为“被假定的、尚待证明 的”，故译“应当存在一种等价”；HMS 至今没有一般证明，不宜译为“存在等价”。（p.1）
- 背景直觉：卡拉比–丘情形两侧都是紧流形，是最初的设定；Fano 情形 B 侧的镜像 不再是簇本身，而是“簇加全纯函数”，即 LG 模型——这正是本文反复使用的对象。（p.2）
- 含糊点拨：反常束（perverse schober）由 Kapranov--Schechtman 引入，是对 反常层取“范畴化”后的产物：把层的粘合数据换成范畴与函子的粘合数据。阅读时可先把它当作 “记账工具”，不必先掌握全部定义。（p.2）
- 含糊点拨：“内蕴”的镜像（the ‘intrinsic’ mirror）指不依赖额外选择、由给定 数据自然给出的镜像构造；作者用引号提示这只是习惯说法，并非严格术语。（p.2）
- 易错预警：$\Pi_n$ 有 $n+1$ 个变量，故 $\Pi_n\subset(\C^*)^{n+1}$；其镜像是 $\C^{n+1}$ 中 $n+1$ 个坐标因子之积为零的奇异超曲面。指标 $n$ 与 $n+1$ 容易写错，回页图 核对时须逐字对照。（p.3）
- 背景直觉：裤子是 $(\C^*)^{n+1}$ 中“一个仿射线性方程”定义的超曲面，也是构成 极仿射超曲面的最小单位；把超曲面作热带退化后，各块往往就是不同维数的裤子之积，故可由 组合数据（扇、多面体）算出两侧的量。（p.3）
- 背景直觉：柱面 $\{xy=t\}$ 的 wrapped Fukaya 范畴等价于 $\C[z^{\pm1}]$ 上的 有限生成模范畴，生成元 $z$ 对应绕柱面一周的拉格朗日圆圈；乘 $1+z$ 这条自然变换把 $\C[z^{\pm1}]$ 换成 $\C[z^{\pm1},(1+z)^{-1}]$，后者正是 $\C^*\setminus\{-1\}$ 上的函数 环。作者借此把“局部化”落到一个可手算的例子。（p.5）
- 含糊点拨：“正确的镜像等价”不是指唯一性，而是指所取的等价同时与两侧的自然 函子相容；作者把这一要求称为函子性镜像对称，并以“交织”（intertwine）说明函子与等价 之间的交换关系。（p.5）
- 易错预警：$D$ 是扭复形范畴的记号，与后文的 $D^\pi$（幂等完备的扭复形范畴） 不同；两者在原文中都是数学斜体的 $D$，不要误排成花体 $\cD$（花体 $\cD$ 在本论文中另指 一个满子范畴，见 §1.3.1 末段）。（p.7）
- 含糊点拨：$\operatorname{Sing}$ 记号的严格含义见 §6.1；在那里作者用矩阵分解 范畴给出它的具体模型。此处只需知道它是 B 侧一个只依赖 LG 模型 $(X\times\C,zf)$ 的范畴， 从而使“奇异纤维的 A 侧”有了“光滑簇上的 LG 模型”这一替身。（p.8）
- 含糊点拨：原文强调“不同的一种形式”，指通常的悬置把一个 LG 模型换成另一个、 不改变奇异纤维的等价类；而这里把奇异纤维 $f^{-1}(0)$ 的范畴与高一维的 LG 模型 $(X\times\C,zf)$ 的范畴等同起来，方向相反，故作者特别提醒不要混同。（p.9）
- 易错预警：定义 \ref{def:sing-ci} 的显示公式中，左侧各 $f_i$ 取 $0$，右侧各 $f_i$ 取 $t_i$，且局部化要同时在 $k$ 条自然变换处进行，写 $[s_1^{-1},\dots,s_k^{-1}]$； 不要漏掉下标或误写成单个 $s^{-1}$。（p.9）
- 背景直觉：顶针（thimble）是沿一条路径“扫过”的拉格朗日圆盘，其边界落在 Lefschetz 纤维的消失圈上；作者用“在可容拉格朗日子流形上取顶针”描述这个函子 $T$，直观 上就是把 B 侧的 LG 模型沿临界轨迹切出的拉格朗日球面搬到 A 侧。（p.10）
- 含糊点拨：LG--CY 对应把 LG 模型的 B 侧与一个卡拉比–丘流形的 A 侧联系起来； 这里是它的“开弦”版本，即把两侧的范畴（而非仅数值不变量）进行比较。（p.10）
- 含糊点拨：停点（stop）是流形上允许拉格朗日对象“终结”的边界区域；把停点去掉 （stop removal）会使范畴变小，在形式上表现为对某个满子范畴取商。作者在此把 $z(f-t)$ 到 $zf$ 的变化解释为停点的移动，正是不变量在此处的几何来源。（p.11）

## C02（14 条）

- 易错预警：原文说同调镜像对称“被预期为一个对合”（expected to be an involution），意思是镜像对称操作两次应回到原处，而不是说它作为函子是自同构。这一预期正是必须为奇异纤维本身定义深谷范畴的理由：若只在邻近纤维上定义，A 侧就无法与 B 侧对称地取镜像。（p.12）
- 含糊点拨：对数结构（log structure）在这里只是一个来自镜像对称的\emph{预期}，原文并未给出其定义或构造。它大致上记录边界除子与极点的数据，从而补充“沿哪个方向磨光”的信息；把它当作“把磨光唯一确定下来所需的额外数据”来读即可。（p.12）
- 易错预警：“$(-1)$-平移辛结构”中的平移量 $(-1)$ 是移位辛几何里的移位次数，与“负一次”或“倒数”无关；不要读成辛形式的次数为 $-1$。$d$-临界轨迹的 $d$ 同样是理论的名字（Joyce 的 $d$-critical loci），不是微分符号。（p.13）
- 易错预警：花体 $\cX_\varphi$、$\check\cX_{\check\varphi}$ 记环簇退化的\emph{全族}，罗马体 $X(B)$、$X(\check B)$ 记其一般纤维；中心纤维是 $\cX^0_\varphi$（上标 $0$，花体），不能与 $X(B)$ 混同。定理中的 $D$ 是退化族的底，不是除子。（p.13）
- 易错预警：定理 \ref{thm:lcsl} 中的大复结构极限写作 $X_0(\check B)$（罗马体 $X$ 带下标 $0$），与定理 \ref{thm:lvl-lcsl} 的花体 $\check\cX^0_{\check\varphi}$ 指同一类对象，只是记号不同。原文如此，照译，不要自行统一。另：$X(B)$ 与 $X(\check B)$ 是互为镜像的一对环簇，$\check B$ 上的数据才对应 $B$ 侧，方向容易读反。（p.14）
- 背景直觉：注 \ref{rem:lvl-direction} 点出了本论文与既有文献的分工。传统路线是“先在极限处证等价，再形变到一般纤维”；本文的路线是把奇异纤维的深谷范畴本身定义好，从而让“极限处的等价”就是一个关于奇异簇的陈述。两条路线合起来覆盖整个模空间。（p.15）
- 易错预警：$T^{\varphi(\alpha)}$ 中的 $T$ 是一个小实数，充当退化参数（相当于 SYZ 图景中的尺度）；$\varphi$ 才是分段线性函数，两者不要与温度、周期或平移混淆。取 $T\to0$ 时，各项按 $\varphi(\alpha)$ 的大小分层，这正是热带极限的来源。（p.15）
- 含糊点拨：条件 (2) 中的“极大”（maximal）不是“胞腔数目最多”，而是指该多面体分解在加细意义下不能再细分：每个胞腔都是与标准单纯形合同的整多面体。条件 (1) 则把 $f$ 的支撑限制在 $P$ 的边界上，这保证 $H$ 在 $(\C^*)^n$ 中的紧化只沿边界方向退化。（p.16）
- 易错预警：$\cK_X$ 与 $K_X$ 只差一个花体，含义却不同——花体记 $X$ 上\emph{作为层}的典范丛，直立体记典范丛的\emph{全空间}（一个环簇）。原文正是用这一对记号区分层与全空间，译文中不可合并。（p.16）
- 易错预警：$\hat Z$ 与 $\tilde Z$ 形状相近但不同。$\hat Z$ 是 $K_X\times\mathbb A^1$ 内的环簇反典范除子；$\tilde Z$ 是把 $X\times\{0\}$ 沿 $D$ 粘到 $D\times\mathbb A^1[-1]$ 上得到的导出概型。前者是除子，后者是导出概型，粘合的方向也容易读反。（p.16）
- 含糊点拨：$\tilde f_0$ 与 $\tilde f_\infty$ 是同一个补集在 $(\C^*)^{n+1}$ 中的两种极仿射描述，区别只在新增的 $z_0$ 方向上的行为：前者在 $z_0=0$ 处有极点，后者在 $z_0=\infty$ 处有极点。二者作为代数簇相同，但下面的分次数据不同，这正是 §1.5 后半部分的要点。（p.17）
- 背景直觉：$\eta_0$ 与 $\eta_\infty$ 只差乘以 $f$ 的幂，但前者在 $H$ 上无极点、后者有极点，于是“哪些拉格朗日量能带分次提升”就不同。这正是同一个辛流形上出现两个不同 dg 范畴的机制；$[\arg(f)]$ 这个上同调类则度量了两种分次之间的扭结。（p.18）
- 易错预警：$\overline{\cW}_0$、$\overline{\operatorname{Coh}}(Z)$ 上的横杠表示“同调分次模 $2$ 约化”，不是复共轭，也不是闭包或 Zariski 闭包。约化之后分次只到 $\Z/2$，这些范畴才成为 $\C((\beta))$-线性的。（p.19）
- 背景直觉：交换图表 (1.2) 是全文的“原型”。右侧 $i_{D,*}$ 是除子 $D\hookrightarrow X$ 的推前；左侧的 $\cup$ 是它在 A 侧的对应物——把定义在 $H$（$D$ 的镜像）上的对象“延拓”到 $(\C^*)^n\setminus H$ 上。所谓函子式镜像对称，就是断言这类由几何自然给出的函子，在镜像等价下逐一对得上。（p.20）

## C03（15 条）

- 背景直觉：四个函子里，$\rho$ 与 $j$ 是“看端”与“平行移动”这类直观操作；$\alpha_0$ 与 $\alpha_\infty$ 则是把 $\cW((\C^*)^n,f)$ 中已有的两类缠绕“打开”的函子。三条关系式的含义是：先开启缠绕再看端，等于 $\cap$、等于零、或等于恒等。（p.22）
- 易错预警：$j\cap$ 是函子 $j$ 与 cap 函子 $\cap$ 的复合，不是集合的交。$\cap$ 是 Abouzaid–Ganatra 的 cap 函子，与 §1.5.1 中交换图表 (1.2) 里的 $\cup$ 相对；两者分别对应几何中的 cap 与 cup。（p.22）
- 含糊点拨：原文只把三角形画出来、未写循环方向。按箭头读，它是 $\alpha_0\to j\cap\xrightarrow{+1}\alpha_\infty\to\alpha_0$：$+1$ 标在从 $j\cap$ 出发的那条箭头上，表示三角的第三个映射带分次移位 $1$。（p.23）
- 易错预警：条目开头的“（Conjecture 1.2）”“（Conjecture 1.3 (1)）”是 Auroux 论文 [Aur18] 内部的猜想编号，不是本书编号。译文照字面保留，不要误加 \texttt{\textbackslash ref}。（p.23）
- 易错预警：定理中 $\cW_\infty$ 与 $\cW_0$ 的下标，对应 §1.5 定义的两个分次 $\eta_\infty$ 与 $\eta_0$；它们与函子名 $\alpha_\infty$、$\alpha_0$ 的下标一致，但两者是不同层面的对象，不可混同。（p.24）
- 含糊点拨：$\overline{\cW}$、$\overline{\operatorname{Coh}}$ 上的横杠，是 §1.5 中由 $A_\infty$ 分次模 $2$ 约化得到的记号，表示微分 $\Z/2$-分次范畴，并非拓扑闭包。（p.24）
- 背景直觉：同伦推出定理在 A 侧负责“拼接”，真下降定理在 B 侧负责“拼接”；两侧的拼法在镜像对称下互相对应，这正是本节全部技巧的骨架。（p.25）
- 易错预警：这里的“两个（奇异）辛纤维丛”不是同一个纤维化的两种写法，而是 $f$ 与 $1/f$ 两个不同的纤维化；它们的奇异纤维位置互为颠倒，这正是下文“交换零与无穷”的来源。（p.25）
- 含糊点拨：“$F$ 满足定义的第二个条件”并不等于“$F$ 是扇形超曲面”：缺的是切于 Liouville 向量场这一条。原文用 while 转折，意在强调这个隐含条件才是障碍。（p.25）
- 易错预警：$H=W^{-1}(R_1)\cap\{\phi\le R_2-\eps\}$ 里的 $R_1$ 与 $R_2$ 是两个不同的大参数，分别控制纤维与截断，不能混同；$\rho$ 也与限制函子 $\rho$ 同名，但此处是正实数。（p.26）
- 背景直觉：Sylvan 的命题只保证“无穷远处某条纤维附近”有标准 Liouville 形式，所以 $z$ 只能与原 $W$ 的纤维同痕、而不与之相等。这正是这种构造的代价，也是它的用处。（p.26）
- 易错预警：$1/W$ 的问题不在“值太大”，而在于它在 $X$ 上并非处处有定义、且不再是多项式，故同伦推出定理的前提失效，只能改用单值性扭成的粘合。（p.26）
- 含糊点拨：$\operatorname{Coh}(Z)$ 与 $\operatorname{Coh}(\tilde Z)$ 之间的等价并非恒等，而是经“公共 Kn{\"o}rrer 稳定化”过渡得到的；原文用 stabilization 一词，指两个概型各自再添一对互为对偶的坐标后同构。（p.27）
- 背景直觉：“把 $f$ 换成 $1/f$”是 A 侧的整体单值性操作，其在 B 侧的代数类比就是 $\operatorname{Coh}(Z)\leftrightarrow\operatorname{Coh}(\tilde Z)$。会“交换零与无穷”，指两个缠绕函子 $\alpha_0,\alpha_\infty$ 在该等价下互换。（p.27）
- 易错预警：本节两套“§N”不可互换——左边的“§1”指本论文的节，括号前的“§1 of [Jef22]”指 [Jef22] 的节。译文一律照字面保留，读者须按出处区分。（p.28）

## C04（13 条）

- 易错预警：Stein 函数 $\phi$ 由标准欧氏范数 $|z|^2$ 限制得到，与 $W$ 无关；$|W|^2$ 只是实多项式，并不给出 Stein 结构。（p.29）
- 含糊点拨：Malgrange 条件是「在无穷远处 $\nabla_X|W|^2$ 不退化」的量化形式；三个常数 $R,\eps,\eta$ 彼此关联，不能独立选取。（p.30）
- 易错预警：由 $|\nabla_X\phi|\le 2|z|$ 推出 (2.1)，这一步只用 $\C^N$ 的标准度量；换用别的 Kähler 度量，其中的常数要跟着变。（p.31）
- 背景直觉：Grönwall 不等式把 $\phi$ 沿流线的增长压到指数级；指数增长在有限时间内有界，因此流线逃不到无穷远。（p.33）
