# SY02-08 译注本 v2 体例与写作规范（STYLE_GUIDE）

本文件对全体章节译手/校订人生效。与 `04_playbook/01_数学文献翻译纪律.md`（v2.1）冲突时，以 playbook 为准；本文件只做本书的具体化。

## 0. 一句话原则

**正文照译，公式不动，疑点必注，注必有源。**

## 1. 写作用域

- 每人只改自己名下的 `.tex`；不得改 `main.tex`、`preamble.tex`、其他章文件。
- 不得删除 `% [Tutor Note: ...]` 注释，不得删除 `keypoints` 环境，不得改动章节编号。
- 不新引 LaTeX 宏包（preamble 由 Lead 统一维护）。

## 2. 正文校订的边界

### 必须改（P1/P2）
- 改变数学含义：译反、丢限定词（“紧”“有限维”“非退化”等）、蕴含改成并列、量词范围错、公式符号/上下标错、漏译整句、增译原文没有的数学断言。
- 编号错位：定理/公式/节号与原文不对应，且能由页图确认。
- 术语一译多名、同构/等价混用、同一记号两种含义。
- 中文不成句、主谓宾残缺、指代不明到读不懂。

### 不许动
- 文风、断句习惯、译者对原书笔误的保留式处理（保留原文 + 说明）。
- 原书自身笔误：正文保留原样，用译注说明“原文印作 X，应为 Y”，不改公式。
- 已有 `keypoints` 的措辞（除非其中有事实错误，且改动记入 changes TSV）。

### 公式
- 默认零改动。只有同时满足以下两条才可改：
  1. 对照 `pages\pNNN.png` 确认是原书印刷错误或旧译录入错误；
  2. 有第二处独立出处（同书另一页推导、作者后续论文、标准教材）。
- 任何公式改动必须单独登记 `工程文件\reports\formula-fixes.tsv`，字段：
  `章 | 行号 | 原式 | 改为 | 依据页图 | 第二出处 | 说明`
- 拿不准就**不改**，改成译注说明。

## 3. 正式译注（编译后可见）

### 机制
- 在需要注释的词句后写：`\transnote{说明文字 [来源：…]}`
- 编译为脚注，前缀【译注】。不要手写 `\footnote{译注：...}`。
- 不要放在 `\[ \]`、`equation`、`align` 等数学环境内部；放在该公式所在句子的句末或公式后的正文里。
- 同段相邻两个注能合并就合并；一条注不超过 4 句、不超过半页。

### 只注三类
1. **易错**：符号约定、指标方向、水平/对偶 Coxeter 数、外微分方向、左右作用、 normalization。
2. **含糊**：作者写“显然”“容易看出”“同理”而实际用了非平凡定理/构造；补出所用定理名与出处。
3. **背景**：该构造在全书论证链中的位置、为什么需要它、与相邻概念的区别。

不注：单纯中英术语对照（进术语表）、纯重复正文的话、读者自己能查到的常识。

### 每条注的四要素
1. 卡点：读者会卡在哪（一句话）。
2. 背景：需要什么才能读懂（一句话）。
3. 结论：正确理解是什么（一到两句）。
4. 来源：方括号，见下。

### 来源格式
- A 级（优先）：
  `[来源：E. Frenkel, Langlands Correspondence for Loop Groups, CUP 2007, p.123.]`
  `[来源：V. Kac, Infinite-Dimensional Lie Algebras, 3rd ed., CUP 1990, 第 2 章.]`
  `[来源：Frenkel–Ben-Zvi, Vertex Algebras and Algebraic Curves, 2nd ed., AMS 2004, §3.2.]`
  `[来源：arXiv:2405.03599, §1.2（访问 2026-11-23）.]`
- B 级（须与 A 级交叉，正文不缓存网页全文）：
  `[来源：nLab "Affine Kac-Moody algebra"，https://ncatlab.org/nlab/show/affine+Kac-Moody+algebra（访问 2026-11-23）.]`
  `[来源：Stacks Project, Tag 0ABCD，URL（访问 2026-11-23）.]`
- 查不到外部依据：
  `[译者按（无外部依据）：…]`
- 只依据原书自身：
  `[依据：原书 p.123 的推导；并见 p.130 式 (4.2-7)。]`

**禁止**：编造 arXiv 编号、页码、定理号、URL；引用知乎/百度百科/知道/CSDN/简书/公众号/博客/视频课笔记；把 B 级网页当唯一依据下断言。

### 与旧批注的关系
- 旧 `% [Tutor Note: 类型（p.N）。…]` 是工作注，保留。
- 升级为正式译注时，在 `work\notes\<ch>.md` 记：旧注行号 / 旧注类型 / 新注位置 / 来源级别。
- 旧注有错就改正并在 notes 表标“旧注有误”。

## 4. 术语

- 以 `工程文件\work\glossary.tsv` 为唯一裁决书；表内没有的，先查 `01_corpus_zh/termbase.jsonl`，再查通行译名；仍无则保留英文并登记。
- 新术语在 changes TSV 的“类别”列写 `术语新增`，并在 notes 里给出建议行（中文/英文/首见页）。
- 固定英文写法见 GLOSSARY.md §6；`Harish-Chandra` 在 LaTeX 中写 `Harish--Chandra`。
- 人名不译；模型名不译；`oper`、`torsor`、`parahoric`、`holonomic`、`monodromic` 保留英文。

## 5. 页码与引用

- 正文提到原书页码时写“原书 p.N”（印刷页）；需要扫描件页码写“PDF p.NNN”。
- 页码换算：PDF 15–139 → −14；140–176 → −13；177–231 → −12；232–260 → −11；261–395 → −10；396–401 → −9。
- 引用原书公式用原编号，如“式 (4.2-7)”；不要用自动 `\eqref` 指向译本编号。
- 引用本书章节写“§4.2”“第 4 章”；新增两章写“前置导引 §2”“进展 §3”。

## 6. 交付物（每个章节译手）

1. 改后的 `<ch>.tex`（唯一允许改的文件）。
2. `工程文件\work\changes\<ch>.tsv`：`行号 | 类别 | 原文 | 原译 | 改为 | 理由`
   - 类别：`误译` / `漏译` / `术语` / `中文` / `编号` / `公式` / `译注` / `术语新增`。
   - “原文”填英文原句或公式（可截断，但必须能定位）。
3. `工程文件\work\notes\<ch>.md`：逐条译注清单：
   `编号 | 位置(行) | 类型 | 一句话卡点 | 来源 | 来源级别(A/B/按) | 对应旧注行号`
4. `工程文件\work\chapter-briefs\<ch>.md`：本章卡点清单（开工前先写，至少 8 条；格式见诊断报告模板）。

## 7. 自检清单（交活前逐条打勾）

- [ ] 公式零改动；若有，已登记 formula-fixes.tsv 并有页图 + 第二出处。
- [ ] `% [Tutor Note` 数量不少于开工前。
- [ ] `keypoints` 数量不少于开工前。
- [ ] 新增译注 ≥ 8 条（短章 ≥ 6 条），每条有来源或“译者按”。
- [ ] 没有黑名单来源。
- [ ] changes TSV 行数与实际改动一致，能按行号回查。
- [ ] 没有破坏 `\begin`/`\end` 配对、`$` 配对、`\tag` 编号。
- [ ] 中文标点统一（，。；：、“”），英文/数学与中文之间不强行加空格。
