- L48：p.10。这一步"太少"的具体机制是：$\hat\Z$ 射有限，任何到复代数群 ${}^L G$ 的连续同态都落在某个有限商 $\Z/n\Z$ 里，于是像集是有限阶元。共轭类的离散集合无法承载表示论中的连续族（例如非正则奇点带来的连续模），这正是后文引入联络的动机。
- L55：p.11。取泛点作基点是本书的简化。若不取基点，单值性表示只能在共轭意义下确定；对 $GL_n$ 这无碍（共轭类正是要的参数），但后面讲 ${}^L G$-丛时，"规范等价"与"共轭"的差别会显式出现，见 p.18 与式 (1.2-7)。
- L76：p.12 公式 (1.2-1)。这里的 $\nabla$ 取值在 $\End(E)$，而 $\End(E)$ 带自然的李代数结构（交换子），$\cT$ 也带向量场的李代数结构；(1.2-1) 说的就是"联络是李代数同态"，等价于曲率为零。符号约定：$\nabla_{\xi+\eta}=\nabla_\xi+\nabla_\eta$ 与 Leibniz 法则合起来表明 $\nabla$ 是 $\cO_X$-线性的一阶微分算子。
- L106：p.12--13 两处笔误，译文照原书保留。第一，指标个数：本节用 $N$ 表示坐标个数、$n$ 表示 $E$ 的秩，但这里两个求和都写成 $\sum_{j=1}^{n}$，应作 $\sum_{j=1}^{N}$。第二，第二个式子左端写成 $\nabla_{\partial_{y_j}}$，而右端自由指标是 $i$，应作 $\nabla_{\partial_{y_i}}$。此处极易误抄，请看原文图像核对。
- L107：p.13 规范变换的符号约定。$g\nabla_{\partial_{x_i}}g^{-1}=\nabla_{\partial_{x_i}}+gA_ig^{-1}-(\partial_{x_i}g)g^{-1}$ 来自把平凡化换成 $g^{-1}$ 后对 $\nabla(g^{-1}f)$ 用 Leibniz 法则；注意 $(n\times n)$ 矩阵的乘法次序不能交换，最后一项是 $-(\partial g)g^{-1}$ 而非 $g^{-1}\partial g$。这是全章符号错误的常见来源，后文 (1.2-4) 采用同一约定。
- L123：p.13。单值性给出的不只是一个同态，而是同态的共轭类：换基点 $\mathbf{x}_0$ 或换 $E_{\mathbf{x}_0}\simeq\C^n$ 的等同，只会把表示共轭掉。反过来，同态的共轭类由水平截面系统唯一决定。因此"平坦丛的同构类"与"$\pi_1$ 表示的共轭类"之间的对应是双向的（对 $GL_n$ 即 Riemann--Hilbert 对应），这是后文把 Langlands 参数解释为平坦丛的依据。
- L130：p.14。全纯丛的"全纯结构"由 $\bar\partial$-算子 $\nabla_{\partial_{\bar z_i}}$ 决定；平坦联络还缺 $\nabla_{\partial_{z_i}}$ 这一半。若 $X$ 是曲线（$N=1$），任何全纯联络都自动平坦：曲率是 2-形式，而曲线上 2-形式空间为零。这是维数上的事实，不涉及丛的具体形式。
