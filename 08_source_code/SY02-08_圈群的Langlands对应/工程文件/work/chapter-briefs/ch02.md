# ch02 通读简报（第 2 章 顶点代数，原书 p.31–60 / PDF p045–p074，1528 行）

## 一、全章结构与本版处理原则

本章是全书最长的一章，分三节：2.1 中心（单李代数情形、仿射情形、仿射 Casimir 元）；
2.2 顶点代数基础（场、定义、再论局部性、与 $\hat\fg_\kappa$ 相伴的顶点代数、顶点算子的定义、定理的证明）；
2.3 顶点代数中的结合性（三个区域、若干有用的事实、结合性的证明、结合性的推论）。

通读结论：全章无整段漏译，无“译反/丢掉限定词”级别的硬伤；编号公式 28 个、脚注 3 条、
keypoints 4 个、Tutor Note 24 条均在位。问题集中在三类：①三处录入/符号错误（下详 12、15、20 条）；
②四处中文生硬；③若干“读者会卡住但原书一笔带过”的机制（中心扩张的 2-上循环、临界水平与
$h^\vee$、完备化的逆向极限、正规序判据、$T=-\partial_t$、两处原书笔误、结合性等号的含义），
这些正是本版译注的落点。

原书自身笔误一律**保留原文 + 译注说明**（p.32 的 $\kappa=\lambda\kappa_0'$、p.41 的 $A,B\in\Z$、
p.48 与 p.50 交换子符号矛盾、p.52 式 (2.2-9) 的 $a^{\alpha_n}$）；原书 p.47 的
“$V_\kappa(\fg)_{\le i}$ 是 $m\le i$ 的单项式张成”经页图核对**不是笔误**（PBW 滤过按因子个数），
译文正确，不动。
