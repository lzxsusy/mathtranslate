# ch06 通读结论与卡点清单（第 6 章 Wakimoto 模）

底本：E. Frenkel, *Langlands Correspondence for Loop Groups*，第 6 章。

## 一、通读结论（约 520 字）

第 6 章是全书的技术核心：先以自由场实现构造临界水平的 $\gghat_{\kappa_c}$-模结构（§6.1），再把这套构造形变到任意水平并讨论共形/拟共形结构（§6.2），然后用半无限抛物诱导给出无坐标版本（§6.3），最后用 Wakimoto 模证明 Kac–Kazhdan 猜想（§6.4）。就译文而言，句法与术语的整体质量在本译本中属上乘，问题集中在两类：一是**中文长句的断句**（L153 的"所复形"、L854 缺"$H$ 的"、L943 的定语粘连、L1093 的"通过 0 延拓"），二是**原书自身排印错误的忠实照录**。

第二类最需要统稿注意：本章原书的印刷错误密度明显高于前后章，且集中在 §6.1.1 与 §6.2.2–§6.2.5——(6.1-6)(6.1-8)(6.1-9) 的末项、(6.2-5) 之后两条交换关系、命题 6.2.2 题设的 $\pi_0^{\kappa-\kappa_0}$；此外"注 6.1.1"是一处悬空引用（本章 6.1.1 是引理）。这些若径改会伤及译文与原书的对应关系，故一律保留原式、改以译注说明（N4、N7、N9、N15），仅 (6.3-4) 的求和范围 $\Delta_+\to\Delta'_+$ 一处因页图与同页上文双证而改正。读者若照 §6.1.1、§6.2.5 的公式验算，几乎必然卡住，这四条译注是本章的"防错入口"。

术语方面：Wakimoto 模、屏蔽算子、自由场实现、半无限抛物诱导、Miura 变换、临界水平均与 glossary.tsv 一致，无须改动。真正待裁决的是「商子模」（全章 10 处，glossary 未定，若全书改用"子商模"需整章替换）与 $\cA^{\mathfrak g}_{1,\mathrm{loc}}$／$\cA^{\mathfrak g}_{\le1,\mathrm{loc}}$ 的简写统一问题。

仍存疑四处：命题 6.2.4 的下标 $0$；原书 p.167 关于 $B_a=0$ 的论证与 (6.2-11) 的 $b_{i,-1}$ 项口径；上述 $\le1$ 记号；以及 §6.2.3 中 $a^*_{0,\beta}$ 与 $a^*_{\alpha,0}$ 的指标次序（原书 p.177 自身就不一致，译本照录）。
