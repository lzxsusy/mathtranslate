## 四、与审校报告「372 条 / 374 条 Tutor Note」的口径差异

1. **372 是真实条数。** 汇总文件声明 372 条，逐节条数（附录 22、ch01-1 15、ch01-2 36、ch02 24、ch03-1 22、ch03-2 27、ch04 20、ch05-1 18、ch05-2 21、
   ch06 20、ch07 15、ch08 23、ch09-1 12、ch09-2 22、ch10-1 22、ch10-2 14、ch10-3 29、ch10-4 9、preface 1）相加亦为 372；
   现 tex 中以 `% [Tutor Note:` 开头的注释行共 372 条，按文件逐一比对行号集合无缺号、无重号。
2. **374 的来历：** 审校报告 §1.4 的统计脚本按字符串 “Tutor Note” 计数，比 `% [Tutor Note:` 多出 2 处假阳性：
   (a) `源码/chapters/translator-note.tex` 第 51 行的体例说明 `\verb|% [Tutor Note: ...]|`（不是批注）；
   (b) `源码/chapters/ch09-1.tex` 第 666 行正文散文里提到 “Tutor Note” 一词。
   因此报告 §3.1 的 AU DIT 表把 U12 记为 13 条，而汇总文件中 ch09-1 实为 12 条。374 − 2 = 372。
3. **报告 §3.1 的拆解本身不自洽：** 它写「18 单元 372 + preface 1 + translator-note 1」。实际 18 单元共 371 条，加 preface 1 条 = 372；
   多出的 2 条正是上述假阳性，两者不能相加。
4. **与报告 §二「96 条原书疑似笔误」的差别：** 96 条 = A 类 59（影响数学内容）+ B 类 9（编号交叉引用）+ C 类 12（文字语法排版）+ D 类 16（记号不统一），
   来自报告作者对原书的独立核对，并非批注的子集；本台账中「原文笔误」54 条只是汇总中以「疑为笔误/前后矛盾/印作…」为主旨的批注。两个数字口径不同，不可相减对账。
5. **页码口径：** 印刷页优先取批注自述（“易错（p.2）”“请对照原书 p.32”），其次取 tex 中 `% ------ 印刷 p.N` 页锚点，
   再次按每文件 header 声明的印刷页覆盖范围做端点线性插值，插值结果在 TSV 中冠以 `≈`；PDF 页按审校报告 §1.1 的六段偏移表换算（印刷 1–125 +14、126–163 +13、164–219 +12、
   220–249 +11、250–385 +10、386–392 +9）。
