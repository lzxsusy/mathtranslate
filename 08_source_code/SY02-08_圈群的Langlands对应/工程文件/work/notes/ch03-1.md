## 二、改动分类

**中文 1 条**

1. L522：`……可延拓为 $U(V)$ 上的李括号、以及相应的映射 $U(V)\to\End V$ 也是李代数同态……` → `……可延拓为 $U(V)$ 上的李括号，且相应的映射 $U(V)\to\End V$ 也是李代数同态……`。“以及”连接的是两个并列分句，不能用顿号；改逗号并加“且”使逻辑层次清楚。
