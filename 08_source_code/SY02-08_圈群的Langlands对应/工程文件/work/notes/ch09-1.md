## 遗留问题（交 Lead）

1. **$\mathfrak n^\perp/\mathfrak b$ 记号（原书 p274，L491）。** 页图确印 $\mathfrak n^\perp/\mathfrak b\subset\mathfrak g/\mathfrak b$，并称其中的 $\mathbf O$ 是开稠的 $H$-torsor。但按 $\mathfrak g$ 上的不变内积，$\mathfrak n$ 的正交补恰是 $\mathfrak b$，$\mathfrak n^\perp/\mathfrak b$ 会退化为零维，与该断言不符；L491 既有 Tutor Note 写「$\mathfrak n^\perp$ 是 $\mathfrak b$ 的正交补」，与之亦不自洽。本单元不敢断言正确读法（可能是「$\mathfrak n^-$ 中与 $\mathfrak b$ 互补的 $\ell$ 维子空间」或其他约定），故**未写译注、未改 Tutor Note、未列公式改动**，请 Lead 定夺或转原作者核对。
2. **定理 9.3.6 证明 (i) 的跳步**（N14）：原书说 $v_{w_0}$-分量的首项「因此显然」由 $f_i$ 反复作用于 $v_{w^{-1}w_0}$ 得到，但未说明 $\mathbf v(t)$ 与 $v/t$ 项为何不影响首项次数。译注只点出错口位置，未补证明（补写会超出「译注不得增写证明」的口径）。
3. **「statement → 断言」的跨章一致性**：本单元改了 L396、L667 两处。若 ch09-2 或前章仍把 statement 译作「命题」，建议全书统一后再定稿。
4. **整优权／整优余权**：按「原书笔误保留原文」的口径未统一（L158、L463 作「整优权」，L251 作「整优余权」）。若 Lead 决定统一为「整优余权」，需改两处正文并同步 `glossary.tsv`。
5. **L771 与 L776 两个显示式近乎重复**：由 (9.3-13) 的摆放方式造成（见上「p282 的处理」）。数学无误，但排版上或可只留一处；本次不动，供 Lead 取舍。
