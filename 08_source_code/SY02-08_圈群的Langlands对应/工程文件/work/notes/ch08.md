## 二、改动分类

### 2.1 公式（0 条；原 E1 已撤回）

**E1（撤回）｜L86（§8.1.1，(8.1-3) 前，原书 p.223）**
曾拟把 $\operatorname{Sym}\mathfrak g((t))/\mathfrak b_+$ 改为 $\tilde{\mathfrak b}_+$。Lead 复核原书 p.223 放大页图：第一式分母确为 $\mathfrak b_+$（无波浪号），紧随其后的对偶空间才印 $\tilde{\mathfrak b}_+$；**原书两处本就不一致，旧译照录第一式并无错误**。故撤回该公式改动，`changes/ch08.tsv` 已删对应行，L97 既有 Tutor Note 保留「原书两处不一致」的说明。

### 2.2 误译（2 条）

**E2｜L320（§8.1.4，原书 p.230）**：`给出 $\mathfrak h$ 上的非零内积` → `给出 $\mathfrak h^*$ 上的非零内积`。原文 "a non-zero inner product on h*, which is the restriction of κ0∨ on ^Lg"；$\kappa_0^\vee$ 在 ${}^L\mathfrak g$ 上，限制到 ${}^L\mathfrak h=\mathfrak h^*$。

**E3｜L664（§8.2.4，原书 p.240）**：`我们将时常用下标标明所考虑的 Poisson 结构` → `我们有时会把它用作下标，以标明所考虑的 Poisson 结构`。原文 "which we will sometimes use as a subscript to indicate which Poisson structure we consider"：`sometimes` 是「有时」，旧译「时常」译反，且漏掉「用作下标」的宾语。

### 2.3 术语（1 条）

**E4｜L680（§8.2.5，原书 p.241）**：`Poisson 顶点代数的交换图` → `顶点 Poisson 代数的交换图`。glossary 裁决 vertex Poisson algebra = 顶点 Poisson 代数；改后全章 35 处一律，另 0 处异序。

### 2.4 中文（7 条）

- **E5｜L443**：「对它施加 $H$ 的、对应于 $G$ 的 外尔群最长元的自同构 $w_0$」改为「用 $H$ 的对应于 $G$ 的外尔群最长元的自同构 $w_0$ 作用在它上面」——「施加……自同构」搭配不通，且「的 外尔群」夹多余空格。
- **E6｜L761**：「$\mathfrak g$ 的 外尔群」→「$\mathfrak g$ 的外尔群」（术语替换残留空格）。
- **E7｜L801**：同 E6，第二处。
- **E8｜L452**：「有处于一般位置的包含 $\mathfrak b_{\mathcal F_{\mathcal B}},\mathfrak b_{\mathcal F'_{\mathcal B}}\subset\mathfrak g_{\mathcal F}$」→「包含关系」，原文 "the inclusions ... which are in generic position"，「包含」在此为名词，缺中心词。
- **E9｜L580**：「$B$-torsor $\mathcal F_{\mathcal B,0}$ 对一切 opers $(\mathcal F,\mathcal F_{\mathcal B},\nabla)$ 可以等同」→「对一切 opers $(\mathcal F,\mathcal F_{\mathcal B},\nabla)$，$B$-torsor $\mathcal F_{\mathcal B,0}$ 彼此可以典范等同」。原句状语后置，易读成「对每个 oper 各自可等同」；原意是这些 torsor 在一切 oper 上彼此典范等同。
- **E10｜L204、L219**：「对一般的 $\upsilon$」→「对 $\upsilon$ 的一般取值」（两处同改）。generic 在此指「一般取值」，「一般的 $\upsilon$」易误读为「普通的/平凡的 $\upsilon$」。

## 五、遗留

### 5.1 公式存疑 A41（保留原文，零改动）

- **位置**：§8.2.4，(8.2-11) 右端，原书 p.240（PDF p.251）；对照 (8.1-3) 原书 p.223 与 (8.1-5) 原书 p.226。
- **现象**：分次特征标恒等式三处指标不能同时成立——正根按 $\langle\alpha,\check\rho\rangle$ 计数给出 $1,\dots,d_i-1$（每个 $i$），而 (8.2-11) 右端上限印作 $d_i$；(8.1-3)、(8.1-5) 又以 $n_i\ge d_i+1$ 起算。
- **页图核对**：p.251 原书确实印 $\prod_{i=1}^{\ell}\prod_{n_i=1}^{d_i}(1-q^{n_i})^{-1}$，译文照录无误。
- **处置**：公式与译文均不动；已在 T13 说明矛盾所在并声明「无法仅凭本书判定哪一处是笔误」。
- **申请**：若统稿组要求定稿，需数学审读裁定 (8.1-3)、(8.1-5)、(8.2-11) 中哪一处为准；本稿不提出改法。
