## 二、改动分类（8 处正文文字，行号改前=改后）

**误译 3 条**
1. L759（原书 p.46）：`把 $\partial_t$ 解释为向量场` → `把 $-\partial_t$ 解释为向量场`。原书印作 “interpreting it as the vector field $-\partial_t$”；旧译漏负号，与紧随的 $[T,J^a_n]=-nJ^a_{n-1}$ 及 p.47 的“$T$ 对应 $-\partial_t$”自相矛盾。
2. L1077（p.52）：`（$j_s>0$）` → `（$j_s\ge 0$）`。原书定理 2.2.5 条件 (iv′) 为 $j_s\ge0$。
3. L1337（p.57）：`把它们作用到固定向量 $C\in V$ 上时它们确实“收敛”` → `把其中各项作用到固定向量 $C\in V$ 上时确实“收敛”`。原句 “they do ‘converge’ when we apply the terms to a fixed vector $C$”，terms 指 (2.3-1) 中的各项。

**公式 1 条（旧译录入错误，非原书笔误）**
4. L1076（p.52）：`$a^{\alpha_1}_{(j_1-1)}\cdots a^{\alpha_n}_{(j_n-1)}|0\rangle$` → `$a^{\alpha_1}_{(-j_1-1)}\cdots a^{\alpha_n}_{(-j_n-1)}|0\rangle$`。页图 2.2 倍裁切亲验为 $(-j_s-1)$；旧译漏两个负号，把负模写成正模，与定理 2.2.4 的 $n_i<0$ 冲突。

**漏译 1 条**
5. L236（p.34）：`对 Casimir 算子的一个显然猜想是` → `现在，Casimir 算子的一个显然的类比是`。原句 “an obvious guess for an equivalent to the Casimir operator”，漏译 equivalent to。

**中文 3 条**
6. L276（p.34）：`不能给出范畴 $\widehat{\fsl}_{2,\kappa}$-mod 中模上定义良好的算子` → `不能在范畴 $\widehat{\fsl}_{2,\kappa}$-mod 的模上给出定义良好的算子`（两个状语套叠，读不通）。
7. L290（p.36）：`却与它相差 $h_{m+n}$ 的无穷多次相加` → `却与它相差无穷多个 $h_{m+n}$ 之和`（infinite sum）。
8. L310（p.37）：`它们只相差／有限多个位置` → `它们彼此只在／有限多个位置上有差别`（differ at finitely many places）。
