## 遗留问题（交 Lead）

1. **存疑（未改）**：(7.2-5) 页图（PDF p216）确实印 $f_0\cdot a_{-1}\lvert-2\rangle=a_{-1}f_0\lvert-2\rangle-h_0\lvert-2\rangle$，但按 §7.2.2 的对易关系应为 $[f_0,a_{-1}]=-h_{-1}$，而 $h_{-1}\lvert-2\rangle=0$、$h_0\lvert-2\rangle=-2\lvert-2\rangle$；两端均不能直接给出书上的下一步 $=-b_{-1}\lvert-2\rangle$。底本如此，译文照原文，未动公式，待通读全书 §6.2 再定。
2. **存疑（未改）**：原书 p.211 印「the corresponding $\hat{\mathfrak{g}}_\kappa$-module is isomorphic to $W_{(\lambda,\lambda_0),\kappa+\kappa_c}$」，字面应为 $\hat{\mathfrak{g}}_{\kappa+\kappa_c}$；译文 L571 亦作 $\hat{\mathfrak{g}}_\kappa$，与底本一致。是否为原书笔误，需比对 [Frenkel–Ben-Zvi 2004] 的对应构造后定。
3. **备忘（非错）**：§7.2.2 证明中原文用 $V_{-2,n}$ 记 $z^{-n}$ 系数，译文改记 $V_{-2,-n}$；两套编号各自自洽、数学等价，已在 No.7 说明，未改。
4. 建议 glossary 补：第一类/第二类屏蔽算子、大胞腔（big cell）、半无限 BGG 复形、临界水平（critical level，若全书尚未收）、Wakimoto 模的右作用。
