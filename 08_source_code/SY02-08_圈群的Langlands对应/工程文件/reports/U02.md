- 原书疑似笔误：
  1. **p.12（PDF 26）** 坐标变换两处：两个求和都印作 $\sum_{j=1}^{n}$，但本节 $N$ 为坐标个数、$n$ 为丛的秩，应作 $\sum_{j=1}^{N}$；第二式左端印作 $\nabla_{\partial_{y_j}}$，而右端自由指标为 $i$，应作 $\nabla_{\partial_{y_i}}$。译文照原书保留并加批注。
  2. **p.17（PDF 31）** 方程 $(\partial_t+a/t)\Phi=0$ 的解印作 $\Phi_C(t)=C\exp(-at)$，应为 $\Phi_C(t)=Ct^{-a}=C\exp(-a\log t)$；否则该解单值性平凡，与紧接断言的单值性 $\exp(-2\pi ia)$ 矛盾。译文照原书保留并加批注。
  3. **p.18（PDF 32）** 与 p.17 单值性符号不一致：$A(t)=a/t$ 时 p.17 给 $\exp(-2\pi ia)$，此处对留数 $A_{-1}$ 给 $\exp(2\pi iA_{-1})$；按 $\Phi=t^{-A_{-1}}$ 应为 $\exp(-2\pi iA_{-1})$，亦可能作者此处改用顺时针绕行约定。作为**疑点**登记，未擅自改。
  4. **p.19（PDF 33）** “an irreducible representation of $\mathfrak{g}_{\mathrm{ss}}$” 疑漏 $((t))$，按上下文应为 $\mathfrak{g}_{\mathrm{ss}}((t))$（否则与 $\mathfrak{g}((t))=\mathfrak{g}_{\mathrm{ss}}((t))\oplus\mathfrak{r}((t))$ 的直和分解不符）。译文照原文保留并加批注。
  5. **p.26（PDF 40）** 引理编号重复：此处第二次出现 “Lemma 1.3.1”，按本节顺序应疑为 **1.3.2**；而 p.28 印作 “Lemma 1.3.2” 的引理（$H^2$ 一维）按序疑应为 **1.3.3**。译文用 `lemma` 环境自动编号，未手写编号，并在同处加批注。
  6. **p.29（PDF 43）** 定义 $\rho_g$ 时印作 $\rho_g(x)=\pi(\operatorname{Ad}_g(x))$，但本段对象是 $(M,\rho)$、并无 $\pi$，应为 $\rho_g(x)=\rho(\operatorname{Ad}_g(x))$（对照 p.25 同一构造 $\pi_g(x)=\pi(\operatorname{Ad}_g(x))$ 可确认）。译文照原书保留并加批注。
