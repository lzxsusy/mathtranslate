## 原书疑似笔误（译文一律照原印刷，均已在同处加批注）

1. **p.170（PDF p182）式 (6.1-8)**：$h_i(z)$ 的正规序乘积印作
   $:\!a^*_\beta(z)a^*_\beta(z)\!:$（两因子都带星号）；对照定理 6.1.3 应为
   $:\!a^*_\beta(z)a_\beta(z)\!:$。
2. **p.169/p.170（PDF p181–182）式 (6.1-6)、(6.1-9)**：末项印作
   $\chi_i(z)a^*_{\alpha,n}(z)$；对照 (6.1-10) 的 $b_i(z)a^*_{\alpha_i}(z)$，
   应为 $a^*_{\alpha_i}(z)$（多出下标 $n$）。
3. **p.179（PDF p191）交换关系**：印作
   $[L_n,a_{\alpha,m}]=-ma_{m+n}$ 与
   $[L_n,a^*_{\alpha,m}]=-(m-1)a^*_{\alpha,m-1}$；
   按共形权（$a$ 权 1、$a^*$ 权 0）应有
   $[L_n,a_{\alpha,m}]=-(m+n)a_{\alpha,m+n}$、
   $[L_n,a^*_{\alpha,m}]=-(m+n)a^*_{\alpha,m+n}$。原书两式疑有排印错误
   （第一式右端亦缺 $\alpha$）。
4. **p.175（PDF p187）命题 6.2.2 后**：Virasoro 作用所在的模印作
   $M_{\mathfrak g}\otimes\pi_0^{\kappa-\kappa_0}$；全章其余处均为
   $\pi_0^{\kappa-\kappa_c}$，此处应为 $\kappa_c$。
5. **p.182（PDF p194）命题 6.2.4**：$W_{\lambda,\kappa,x}$ 的定义印作
   $M_{\mathfrak g,x}\otimes\pi^{\kappa-\kappa_c}_{0,x}$，按最高权 $\lambda$
   的语境应为 $\pi^{\kappa-\kappa_c}_{\lambda,x}$（下标 $0$ 应为 $\lambda$）。
6. **p.186（PDF p198）式 (6.3-4)**：右端只对 $\beta$ 求和而系数为
   $c^\alpha_\beta(A)$（$\alpha$ 未求和），疑脱漏对 $\alpha$ 的求和。
7. **p.184（PDF p196）**：Fock 表示 $\pi^{\kappa_0}_0$ 的 Heisenberg 李代数印作
   $\mathfrak m_{\kappa_0}$（缺 hat，应为 $\widehat{\mathfrak m}_{0,\kappa_0}$）；
   同页“$\kappa_i$ on $\mathfrak m_i$, $0=1,\dots,s$”印作 $0=1$（应为
   $i=0,\dots,s$）。
8. **记号并存（非错误）**：(6.1-1)–(6.1-3) 中多项式参数印作 $a^*_\gamma(z)$，
   定理 6.1.3 中同类多项式印作 $a^*_\alpha(z)$；两处均按原文照录。
   另 p.183（PDF p195）末行 $W_{\chi(z)}$ 应为 $W_{\chi(t)}$（同一模，变量名笔误）。
