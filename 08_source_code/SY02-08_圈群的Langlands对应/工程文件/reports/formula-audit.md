# 公式编号完整性审计（U01–U08、U11、U14、U15、U17、U18）

方法：
1. 用 Python 读取各单元页段的 `text/pNNN.txt`（清理控制字符后），用正则 `\(([A-Z]?\.?[\d.]+-\d+)\)` 提取所有形如 `(x.y-n)` / `(A.x-n)` 的编号；按出现的行是否为“仅编号”（独立行）区分**编号公式**与**正文引用**。
2. 读取对应 `tex/chapters/*.tex`，提取全部 `\tag{...}`。
3. 双向比对：`原文独立编号 − tags`（漏标）、`tags − 原文全部出现`（多标/错号）、重复 tag；并按 `(章.节)` 前缀检查 tag 连续性与源最大编号。
4. 抽查：每单元取 2 个编号公式，回看 `pages/pNNN.png`（多数用局部放大裁剪）核对译文公式与原文一致；对 text 层“编号与公式同行”的异常项逐一回图确认。
