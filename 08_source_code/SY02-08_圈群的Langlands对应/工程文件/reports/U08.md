- 原书疑似笔误（均保留原文/原编号原样，同处加批注，未擅改）：
  1. p.150（PDF 163）§5.5.3：由上一行 $[\mathbf{h}_n,\mathbf{h}_m]=-n\delta_{n,-m}$ 与 $[\mathbf{h}_n,f_m]=\bar{\mathbf{h}}_n\cdot f_m$，令 $[\mathbf{h}_n+f_n,\mathbf{h}_m+f_m]=0$ 应得 $\bar{\mathbf{h}}_n\cdot f_m-\bar{\mathbf{h}}_m\cdot f_n=+n\delta_{n,-m}$，原书印作 $-n\delta_{n,-m}$（差一符号）。
  2. p.152（PDF 165）引理 5.5.3 陈述：“$i_*(\sigma)$ 与 $\omega$ 的上同调类在 $H^2(\mathfrak{g},\mathfrak{h}')$ 中相等”疑为“在 $H^2(\mathfrak{g},\mathfrak{h})$ 中相等”之误——$i_*(\sigma)$ 已取值于 $\mathfrak{h}$，且证明中 $i_*(\sigma)+d\gamma=\omega$ 要求二者同处 $H^2(\mathfrak{g},\mathfrak{h})$。
  3. p.156（PDF 169）：超导子 $T$ 的作用印作 $T\cdot a^*_{a,n}=-(n-1)a^*_{a,n-1}$，指标 $a$ 疑为 $\alpha$（同一小节上一行明确写 $M_{\mathfrak{g},+}=\mathbb{C}[a^*_{\alpha,n}]_{\alpha\in\Delta_+}$）。
  4. p.161（PDF 174）式 (5.6-11)：$\sum_{\alpha\in\Delta_+}\alpha(h)\alpha(h')=\kappa_c(h,h')$ 与紧随其后的理由（$\kappa_c=-\tfrac12\kappa_{\mathfrak{g}}$，$\kappa_{\mathfrak{g}}(h,h')=2\sum_\alpha\alpha(h)\alpha(h')$）矛盾，右端应带负号（即 $\sum_\alpha\alpha(h)\alpha(h')=-\kappa_c(h,h')$）；只有取 $-\kappa_c$，下文 $\omega(h_n,h'_m)=n\kappa_c(h,h')\delta_{n,-m}$ 才与 $i_*(\sigma)$ 一致。
  5. p.162（PDF 175）§5.6.5：先定义“真子集 $\Delta_P\subset\Delta_+$”，随后又说“求和只遍历 $\Delta_S$”，$\Delta_S$ 与 $\Delta_P$ 指同一集合（由 Levi 因子对应的单根子集 $S$ 生成的正根），属记号不一致，非数学错误。
  6. p.153（PDF 166）Clifford 反对易关系印作 $[\psi_{a,n},\psi_{b,n}]_+=[\psi^*_{a,n},\psi^*_{b,m}]_+=0$，左式第二个下标应为 $m$（该关系对一切 $m,n$ 成立，故不影响结论，仅为排版笔误，未另设批注）。
  7. p.147（PDF 160）§5.4 末句“This sequence is non-split as will see below”漏主语 we（排版/语法小疵，译文按通顺处理，不另设批注）。
