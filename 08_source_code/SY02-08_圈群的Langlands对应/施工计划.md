## 五、译注规范（与 STYLE_GUIDE 一致）

- 机制：`\transnote{...}`，编译为脚注，前缀【译注】；保留旧 `% [Tutor Note: ...]` 注释。
- 每条四要素：① 卡点是什么（为什么读者会卡）；② 需要什么背景；③ 正确理解/结论；④ 来源。
- 长度：1–4 句；不得超过半页。
- 只注三类：易错（符号/约定/方向）、含糊（作者跳步处补所用定理）、背景（范畴/构造的位置与直觉）。纯术语对照不进正文，进术语表。
- 与旧批注重合时：升级旧批注并在 notes 表登记旧 id；旧批注保留在源码注释中。
