## 7. 必须改（1 项）

### M1　脚注 43 的编号会错位（并连带 44–50 整体 +1）

- **位置**：`tr06a.tex:143`（框内标记）与 `tr06a.tex:149`（框外正文）
- **现状**：
  ```latex
  这个相互作用 SCFT 没有拉格朗日量描述\footnotemark，但它具有显然的
  ...
  \end{examplebox}
  \footnotetext{我们的意思是：不存在能用 $\cN=2$ 语言写出的拉格朗日量。……}
  ```
- **问题**：`latex.ltx` 中 `\footnotemark` 与 `\footnotetext`（二者都**不带**可选参数时）**各自**执行 `\stepcounter{footnote}`。于是框内标记显示 **43**（正确），页底脚注正文却显示 **44**（错），且计数器停在 44；其后 tr06b/tr06c 的 6+1 条脚注依次变成 **45–51**，与底本的 **44–50** 全部错一位（底本该块共 42–50 九条，条数是对的，只有编号整体偏移）。这是本块唯一会影响成品的硬伤。（补充：若 tcolorbox 内部把 `\@mpfn` 切到 `mpfootnote`，框内标记还会变成 a/b/c 之类——无论哪种情形，**页底脚注号一定与标记号不符**；下面两个方案都能一劳永逸。）
- **可直接替换的文本（二选一）**：

  **方案 A（最小改动，推荐）**——把两处都加上显式编号：
  ```latex
  % 第 143 行
  这个相互作用 SCFT 没有拉格朗日量描述\footnotemark[43]，但它具有显然的
  % 第 149 行
  \footnotetext[43]{我们的意思是：不存在能用 $\cN=2$ 语言写出的拉格朗日量。有可能存在一些 $\cN=1$ 的拉格朗日量，它们沿流流向 4d 的一个相互作用 $\cN=2$ 理论 [133]。超对称沿该流被明显破坏，但在红外恢复。这类流有很多例子，也被应用到（我们将在 §5.2 中引入的）$(G,G')$ 理论，例如参见 [134,202–211]。}
  ```
  （`\footnotemark[43]` 不步进计数器，`\footnotetext[43]` 会把 `c@footnote` 设为 43 且不步进，故下一条 `\footnote` 仍从 44 开始 ✓）

  **方案 B（更稳，需 Lead 改 `preamble.tex`）**——让 tcolorbox 内直接支持 `\footnote`：
  ```latex
  % preamble.tex 中 graphicx 之后加：
  \usepackage{footnote}
  \makesavenoteenv{examplebox}
  \makesavenoteenv{exercisebox}
  \makesavenoteenv{definitionbox}
  ```
  然后把 tr06a 的 143/149 两处改回一条普通脚注：
  ```latex
  这个相互作用 SCFT 没有拉格朗日量描述\footnote{我们的意思是：不存在能用 $\cN=2$ 语言写出的拉格朗日量。有可能存在一些 $\cN=1$ 的拉格朗日量，它们沿流流向 4d 的一个相互作用 $\cN=2$ 理论 [133]。超对称沿该流被明显破坏，但在红外恢复。这类流有很多例子，也被应用到（我们将在 §5.2 中引入的）$(G,G')$ 理论，例如参见 [134,202–211]。}，但它具有显然的
  ```
  （采用 B 时，tr06a:137–139 那段「排版说明」注释应一并删除；同时可顺带修掉 §8 中同类的三处隐患）

这三处用的是**普通 `\footnote` 直接写在 tcolorbox 里**。tcolorbox 默认不支持框内脚注（内容被排进 savebox，`\insert\footins` 被丢弃），脚注**正文很可能不会出现在页底**（计数器却会 +1）。tr-06 正是因为踩过这个坑才改用 `\footnotemark/\footnotetext`。建议：

1. 编译后逐页核对这三处脚注是否出现在页底；
2. 若确丢失，采用 **M1 方案 B**（`footnote` 宏包 + `\makesavenoteenv`）一次性解决——这同时也能把 tr06a 的那对 `\footnotemark/\footnotetext` 简化回普通 `\footnote`。
