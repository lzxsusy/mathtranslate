## 3. 编译方法

本机（Windows + TeX Live 2026）实测的三条硬约束：

1. `lualatex` 在**非 ASCII 路径**（例如中文目录）下无法写 `.log`，报 `I can't write on file main.log`；
2. 子进程（`lualatex.exe`）**不能写 Desktop**；
3. `TMP`/`TEMP` 必须显式指向可写目录。

因此 `build.ps1` 的做法是：把 `src/` 与 `figures/` **镜像到一个 ASCII 且可写的目录**再编译，成功后把
`main.pdf`/`main.log` 拷回。一条命令：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

编译引擎为 **LuaLaTeX × 3 遍**（目录/交叉引用需要多遍）。中文由 `ctex` 自动取系统字体，
**不需要** fontconfig 或手写 `\setCJKmainfont`。若要换机器编译，只需改 `build.ps1` 顶部的
`$bin`（TeX bin 路径）与 `$root`（镜像编译目录）两个常量。

编译结果（见 `compile.log`）：**file:line 错误 0 / `!` 错误 0 / Undefined 0 / Missing character 0**。

## 4. 译校体例

- **正文逐段全译**；专有名词、人名、缩写（SCFT、SQCD、SYM、Class S、S-fold、AGT）保留英文。
- **公式**：每个编号公式用 `\tag{X.Y}` 复刻原文编号；无编号公式用 `\[...\]`，绝不自造编号。
  全部数学符号均**逐页对照 200 dpi 页图抄写**（PDF 文字层的数学符号不可信）。
- **引用**：文献引用写成纯文本 `[1–4]`、`[20,21]`（不用 `\cite`，因此不做自动文献链接）。
- **图**：图 1–15 为原文矢量图按 450 dpi 截取，图内英文标注为原图固有、未重绘；图注为译者所译。
- **表**：用 `booktabs` 重排，表题中译，行列归属逐格核对原表。
- **定义 / 例 / 习题**：按原版样式重排（定义＝酒红左边框，例＝蓝色左边框，习题＝细黑全框），编号照抄。
- **批注**：解释性补充、易错点、原文笔误的判定，一律写在 `% [Tutor Note: ...]` 注释中，
  **不进入排版**；全部批注见随包交付的 `译注汇总.md`（共 198 条）。
- **参考文献不翻译**（学术惯例），保留英文原貌，由脚本自动转录。

## 7. 已知偏差与限制

1. **参考文献**由脚本从 PDF 文字层自动转录，**未逐条人工校对**；原文标题里的数学符号在文字层中
   被拍平（如 $C^2/Z_p$ 可能记成 `C2/Zp`），故只宜作检索用。已对 2 处文字层伪影（`T**4`/`T**5`）
   做定点还原为 $T^4/T^5$。
2. **图内英文标注**保留原样（截图为原文矢量图，未重绘）；图注为中文。
3. 原文个别**脚注编号**由 LaTeX 自动连续编号，条数与位置逐条核对过原文。
4. **交叉引用**：公式/图/表引用写成纯文本（`式 (3.13)`、`图 4`），不使用 `\ref`/`\eqref`，
   因此 PDF 中没有可点击的内部超链接。
5. 中文排版使用 `ctex` 默认字体（本机为 Windows 系统字体），与本机以外环境编译时字形可能不同。
6. **翻译是解释**：中译力求准确，但个别术语（如 magnetic quiver、S-fold、wild puncture）采用
   学界常用译法并在 `glossary.tsv` 中冻结；若与读者习惯不同，以英文原文为准。
