# 图源码说明（fig01–fig20）

本目录每个 `figNN.tex` 只含**一个 `tikzpicture` 环境**（无 figure 浮动体、无 `\caption`、无 `\label`），
可直接在正文中用 `\input{}` 引入。

- 依赖宏包：`tikz`，库 `arrows.meta, calc, patterns, decorations.pathmorphing`（实际只用到 tikz 核心）。
- 统一风格：`>=stealth`，线条 0.4–0.5pt，黑白线稿，无彩色、无灰度填充（fig05/fig06/fig11 的浅灰椭圆用 `black!12`，与原图一致）。
- 坐标按原书 PDF 的 point 值 1:1 搬家（`x=1pt,y=1pt`），因此图内字号与图形比例和原书一致。
- 少数图整体加了 `scale=…,transform shape`（1.05–1.12 倍），只为把宽度顶到 0.5 倍 `\linewidth` 以上，比例不变。
- 图内标注一律保留原文 ASCII/数学写法（`a)`、`N_f=1`、`n\!-\!2`、`k_1` 等），未加任何中文。

## 未能完全照原样的地方（如实说明）

1. **fig07、fig20 的宽度**：这两幅图原本就画得很小（原书分别约占正文宽 0.25、0.31），
   若按"0.5–0.9 倍 `\linewidth`"硬拉到 0.5，节点圆会变成 43–52pt 的巨圆，与全书其它箭图（20–23pt）严重不协调。
   故保留原生尺寸（fig07 已放大到原书 1.8 倍、宽约 114pt；fig20 宽约 140pt）。
   如需统一，可在这两个文件外面套 `\scalebox{1.7}{\input{...}}`。
2. **fig11 的线宽**：原 PDF 的黎曼面是把 1.2pt 轮廓导出成双线再填充的（`get_drawings()` 里能看到成对的路径），
   TikZ 里用 0.5pt 单线还原，视觉粗细接近但结构上不是"双线描边"。
3. **fig09、fig18 的取点精度**：这两页的插图在原 PDF 里是位图，坐标由 600–900dpi 渲染后量取，个别格点可能有 ≲1pt 偏差。
4. **fig05 的正则奇点叉号**：原图为 6×6pt，早期版本画成 6×7pt，现已改正为 6×6pt。
5. 各图字号沿用原书（10.6pt/11.7pt/12.5pt 等）并换算成 LaTeX 的 `\fontsize`，字形是 Computer Modern 而非原书的 Helvetica/Arial，
   因此同样字号的字面宽度略有差别。
