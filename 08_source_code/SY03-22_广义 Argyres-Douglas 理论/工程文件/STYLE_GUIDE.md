# 体例与术语裁定记录（SY03-22 广义 Argyres–Douglas 理论）

冻结日期：2026-11-20。术语的**唯一真值**是 `work/glossary.tsv`（132 条）；本文件只记体例与「两名译手提案互斥、由 Lead 定案」的裁定理由。

## 一、体例

- 人名、人名命名的术语一律保留拉丁字母，不音译：Argyres–Douglas（AD）、Hitchin、Kähler（凯勒）、Seiberg–Witten、Stokes、Dynkin、Nekrasov、Toda、Liouville、Kodaira、Teichmüller、Cartan、Darboux、Fayet–Iliopoulos（FI）。
- 人名复合用 en dash「–」，两侧不留空格（Argyres–Douglas、Seiberg–Witten、Yang–Yang）。拉丁字母/缩写与汉字之间留一个半角空格（「Hitchin 模空间」「Stokes 矩阵」「FI 参数」）。
- 公式编号照原文（3.9）（4.12），用 `\tag{}` 原样复刻，不缺不重不跳。行文引用写纯文本「式 (3.9)」，不用 `\ref`。
- 图表编号照原文（图 1、表 4），`\caption` 里注明原文编号。插图按原文重绘为黑白线稿，图内标注保留原文 ASCII 写法。
- 维度一律写「六维/四维/三维/二维」；仅在表头、图注、公式侧注中保留 6d/4d 省版面。
- 超对称数一律写 $\mathcal N$：$A_1$ 理论是 $\mathcal N=2$ 的，六维底本是 $\mathcal N=(2,0)$ 的。原文字字层丢掉花体是 OCR 所致，不构成「原文用正体」的证据。
- 缩写首见给「中文全称（English，缩写）」，之后只用缩写：超共形场论（SCFT）、AD 理论、SQCD、FI 参数。BPS 不展开。
- 语言纪律：禁「被……所」「进行……的」「对于……而言」；一句不超过 60–70 汉字；中文全角标点；禁音译、禁字面直译生造词。
- 译注三种：`\zhnote{}`（解释性补充，必须带 `[来源：…]` 或 `[译者按（无外部依据）…]`）、`\routenote{}`（论证路线，必须带原书页码 `p.NN`）、`\typo{}`（【原文如此】，标原文笔误而不改原文）。
- 原文笔误**照录不改**：正文保持原样，用 `\typo{}` 或 `\zhnote{}` 指出正确形式与依据。

## 三、内容层面的固定判断

1. 「极点的阶」可为分数（$r=n+j/k$），这是 AD 理论的特征，不是笔误。
2. 原文用 $n$ 表示三种不同的东西：§3 的极点阶或参数、§4 的 $(A_1,A_{N-1})$ 参数、§6 式 (6.2)–(6.5) 里实为规范群秩 $k$。译文一律照录，不擅自统一，遇到会引起误读处加译注。
3. 表 1、表 2、表 4 是同一套记账，数字照录；与正文公式对不上处加译注，绝不改数。
4. 「高阶极点系数 = 有量纲耦合，一阶极点系数 = 质量参数」是全篇的记账原则，每节都依赖它。
5. 原文把 $(A_2,A_3)$ 记作 $(A_1,E_6)$、$(A_2,A_4)$ 记作 $(A_1,E_8)$、$(A_2,A_3)\big|_{N=3}$ 记作 $(A_1,E_7)$：两套名字都保留，不统一。
