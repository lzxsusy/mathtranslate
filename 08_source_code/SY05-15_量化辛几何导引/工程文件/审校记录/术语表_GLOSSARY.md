# 术语表（GLOSSARY）

原则：
1. 优先采用中文学界通行译名；本书是数学书（辛几何/切触几何/同调代数），不是物理学论文，物理术语仅在原文出现处使用物理界译名。
2. 人名保留拉丁字母（Gromov、Floer、Arnold、Hofer、Weinstein、Fukaya…），定理名写成「Gromov 非压缩定理」这种「拉丁名 + 中文通名」。
3. 首次出现：中文（English）；同一章内后文不再括注。
4. 拿不准的术语：查《数学名词》（全国科学技术名词审定委员会）或 MathSciNet 惯用译法；实在无通行译名时保留英文并加括号说明。
