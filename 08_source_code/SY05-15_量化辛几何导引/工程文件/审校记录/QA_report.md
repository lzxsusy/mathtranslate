## 2. 问题清单（问题—文件—行号—建议）

### P1【高｜内容缺失】§10.4 末尾半页（PDF p315 上半页）无人承接，公式 (10.21) 缺失

- **文件/位置**：边界处——`qsg/tex/ch10a-s04.tex`（末，止于 PDF p314）与 `qsg/tex/ch10b-s01.tex`（首，起于 PDF p315 的 §10.5 标题）。
- **现象**：
  1. `ch10` 的公式编号缺 **(10.21)**：`qa_scan` 检出唯一缺号，`ch10a` 的最后一个编号是 (10.20)，`ch10b` 从 (10.22) 开始。
  2. 缺失内容为 p315 页首至「10.5」标题之间的 §10.4 收尾，约半页、含：`(ii)` 关于 `Rf_! = RΓ_c` 的段落、`(iii)` 关于 `RHom_{Sh(k_X)}(F,·)` 与双函子的段落、`C^{p,q} := Hom(F^p,G^q)`、**`Tot(C^{•,•}) := ⊕_k(⊕_{p+q=k}C^{p,q})` 即 (10.21)**、有界性说明（`D^-`/`D^+`）以及段末的 `//`。
  3. `ch10b-s01.tex:227` 引理 10.5.1 的正文引用了「按 (10.21) 中的方式定义」，目前是**悬空引用**。
- **根因**：`ranges.json` 把 ch10a 定为 p290–314、ch10b 定为 p315–342，但 §10.4/§10.5 的实际分界在 p315 中部，p315 上半页被两个页码范围同时「漏掉」。
- **建议**：二选一（推荐前者，因内容属 §10.4）：
  - 由 ch10a 译者在其最后一个文件末尾补 `% >>> p315` + 这半页译文（含 `\tag{10.21}`）；
  - 或由 ch10b 译者把该段补在 `ch10b-s01.tex` 的 `\section{10.5…}` 之前（同时 `% >>> p315` 移到文件最前）。
  修完后重跑 `check.py ch10b` 与 `check.py ch10a`，并用本报告 §6 的脚本确认 ch10 的 tag 无缺号。

### P2【高｜构建流程】共享目录 `qsg/main.aux` 被并发 xelatex 占用/写坏，导致 `build.py` 失败（非正文错误）

- **现象**：
  - 第 1 次 `python qsg/tools/build.py`：`pass1: exit 1`、`pass2: exit 1`；第一个错误
    `! Text line contains an invalid character.`，位置 **`qsg/main.aux` 第 1 行**（整行 NUL/`^^@` 字节）。
  - 第 2 次重试：第一个错误 `! Undefined control sequence.`，位置 **`qsg/main.aux` 第 39 行**（同样是 NUL 字节），
    随后大量 `invalid character`。两次都**不是** `.tex` 正文错误。
  - 直接原因：核查时存在**另一个仍在运行的 `xelatex` 进程**（PID 3152，16:23 启动），一直占用
    `qsg/main.aux`（读取该文件时报「正由另一进程使用」）。多进程并发编译同一 `main.aux` 会互相截断/写坏。
  - **隔离验证**：把当前快照复制到 `work/tmp/qa_build2/`（tex + figures + preamble + main.tex），在独立目录编译
    **两遍均 exit 0，`Output written on main.pdf (317 pages)`，`^!` 错误数 = 0**。说明当前 `.tex` 正文与图片本身可编译。
- **建议**：
  1. 清理构建产物后重跑，且**同一时刻只允许一个 build**：
     `Remove-Item qsg\main.aux,qsg\main.log,qsg\main.toc,qsg\main.out,qsg\main.pdf; Remove-Item qsg\build\*`
     （或由 lead 统一安排一次串行构建）；
  2. 长期方案：`build.py` 增加输出目录参数（`xelatex -output-directory=build`）或加锁，避免并发写同一 aux；
  3. 交稿前以隔离目录构建结果为准（本报告 §3 已给命令）。

### P4【低｜体例】ch07 有两幅交换图未用 figure 环境、无图注
