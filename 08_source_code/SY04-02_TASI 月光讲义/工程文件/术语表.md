## 七、句式与标点（强制）

- 中文全角标点：，。；：？！（）“”——。
- 英文术语、数字、人名与汉字之间留**半角空格**：`mock modular form` 的、`K3` 曲面、`第 3 节`。
- 行内公式前后的汉字不空格（LaTeX 自动处理），但公式与标点顺序为“……为 $x^2$。”。
- 禁用：“被……所……”“进行……的讨论/计算/研究”“对于……而言”“关于……的讨论”“使得……得以……”。
- 一句不超过约 60 字；公式列举句可放宽。
- 不增删内容；作者的“obvious/clearly”照译并在批注中点明省略的论证。
