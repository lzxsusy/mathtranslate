## Arnold 猜想与 Floer（上）同调

**`[1]`（第 208 行）易错预警**

> [Tutor Note: 易错点。“不动点非退化”（non-degenerate fixed points）这个条件不可省，也不是技术性的小毛病。所谓非退化，指对每个不动点 x，切映射 dφ_x − id 可逆；等价的说法是：φ 的图像与 M×M 中的对角线在 (x,x) 处横截相交。非退化性正是“Floer 复形可由有限个生成元自由生成”的前提——它保证 1-周期轨道是孤立的，于是 X(H) 有限（模空间的维数则是另一回事，由 Conley–Zehnder 指标决定）。另请注意 (1.1) 右边用的是有理系数**上同调**（原文写 H^i）：在一般（既非单调也非半正定）的辛流形上， Floer 理论通常只能在特征零的域上建立（原因见注 1.2 与本节末的讨论），所以系数取 Q 而不是 Z。把右端换成 Z 系数（含所有特征的挠）正是 Bai–Xu 与 Rezchikov 近年工作的目标，见本节末。]

### 哈密顿 Floer（上）同调与 Arnold 猜想

**`[2]`（第 248 行）记号约定**

> [Tutor Note: 符号约定陷阱（第一处高频翻车点）。原文采用 ω(·, X_H) = dH 来定义 X_H，并据此写出 Floer 方程 ∂_s u + J(∂_t u − X_{H_t}) = 0。但文献里另有一派约定（McDuff–Salamon 的部分章节、以及大量物理文献）取 ω(X_H, ·) = dH。须知这并不构成一套“独立的”新约定：由于 ω 非退化，ω(X_H,·)=dH 与 ω(·,X_H)=dH 只差 X_H 的一个整体符号，于是在 (1.2) 里 X_{H_t} 那一项会变号。（至于 X_H = ±J∇H 的写法，那只是选定度量 g = ω(·,J·) 之后对同一个 X_H 的改写，更不是第三种约定。）比对不同来源的公式时，务必先锁定三件事：(i) X_H 由 ω(·,X_H)=dH 还是 ω(X_H,·)=dH 定义；(ii) 相容性条件写成 ω(·,J·) 还是 ω(J·,·) 为正定；(iii) 复坐标取 z = s+it 还是 z = s−it。三者中任意一个与原文不同，(1.2) 里 X_{H_t} 的符号就会差一个负号。切勿把符号差异误判成笔误。]

**`[3]`（第 266 行）含糊点拨**

> [Tutor Note: 含糊点拨。作者强调 Floer 方程“形式上”是 A_H 的 L² 梯度流，这个“形式上”二字必须认真对待：自由环路空间 LM = C^∞(S¹,M) 其实是 Fréchet 流形（无穷维光滑流形），A_H 也是其上的光滑函数；真正的问题是 A_H 不是 Morse 函数——它的临界点不孤立（沿每条 1-周期轨道作 S¹-重参数化给出一个圆），线性化不是 Fredholm 算子，Palais–Smale 型紧性也不成立，因此无穷维 Morse 理论无法直接使用。Floer 的真正贡献在于把这个“梯度流”替换为一个椭圆 PDE 的模空间计数问题，从而绕开这些解析困难。另外，(1.3) 处作者点出非恰当情形下 A_H 是多值的（只在 LM 的某个覆盖空间上才良定义），此时能量恒等式 E(u) = A_H(x₋) − A_H(x₊) 只能逐同伦类成立。需要 Novikov 域的根本原因在于：Floer 微分要对无穷多个同伦类求和，必须用能量权 T^{E} 保证可和性（可和性由 Gromov 紧性给出，级数在 T-进拓扑下收敛）；多值性只是同一套形式系数顺带一并处理掉的附带问题。顺带一提：临界点方程 ẋ = X_H 与 (1.3) 的变分相容，依赖于 λ(ẋ) 项与 ∫H_t 项的相对系数，改动 λ 的归一化会平移 A_H。]

**`[4]`（第 295 行）易错预警**

> [Tutor Note: 易错预警。(1.4) 这样的边界公式要能推出 ∂² = 0，隐含了一个容易被忽略的条件：计数权 w 必须对拼接可乘，即 w([u]) = w([u₋])·w([u₊])。Novikov 情形下 w([u]) = T^{E([u])} 自动满足（能量在拼接处相加）；但一旦改用别的权——例如 §3.1 中的族 Floer 权 z^β = T^{∫β ω}·hol，或某些只计几何相交数的权——就必须先独立验证可乘性，否则 ∂² = 0 直接失效，整个复形无从谈起。这是把 Floer 理论“移植”到新设定（族 Floer、相对 Floer、谱 Floer）时最先翻车的地方。] 另请注意 (1.4) 左端用 ∂ 表示“取边界”，右端用 # 表示同伦类的拼接，符号 # 在不同文献中也写作 ∗ 或 +，比较时不要混淆。

**`[5]`（第 323 行）含糊点拨**

> [Tutor Note: 含糊点拨。“当所有层都正则时，球面冒泡只发生在实余维 2”这一句，本质是一个“维数计数”的断言：在模空间各层都正则（光滑且维数等于期望维数）的前提下，球面泡的层才恰好落在余维 2。需要注意两层意思要分开记账：· “正则性”是横截性条件——它可以靠选取一般位置的 (H,J) 达成，也可能无法达成；· “半正定/单调性”是几何条件——在单调、半正定等情形下，可以排除负指数多重覆盖球泡，从而使模空间的期望维数计数真的成立（[72] 就是这一路线的标准论证）。原文此处把前者一笔带过（“When all the strata ... are regular”），而下一段才点明：真正卡住早期证明的是“如何达成这一正则性”，以及在做不到时如何为模空间构造虚拟基本类（Kuranishi 结构 / polyfold，见 [46, 71, 82, 45]）。也就是说，虚拟技术针对的是**正则性** 这一侧，而不是半正定性这一侧；两者相关但不可混为一谈。]

### 拉格朗日 Floer（上）同调

**`[7]`（第 408 行）易错预警**

> [Tutor Note: 易错预警（第二处高频翻车点）。原文说拉格朗日情形下模空间维数“由 Maslov 指标决定”，哈密顿情形下“由 Conley–Zehnder 指标决定”，但没有交代分次本身何时存在。要得到 Z-分次（而非仅仅 Z/2 或 Z/2N 分次），哈密顿情形需要 2c₁(TM)=0，拉格朗日情形需要 L 的 Maslov 类为零；否则 HF* 只是 Z/2N-分次对象，A∞ 结构的符号规则（见 §2.1 式 (2.4) 的 deg 与 (−1)^*）也随之改变。跨文献比对公式时的第二个高频翻车点就在这里：先确认分次群，再谈公式是否一致。另外，char K ≠ 2 时需要给 L₀, L₁ 加 spin 结构以确定模空间定向——这一步原文在 (1.6) 之后才提，但它是“能否带符号计数”的前提，不能事后补。]

**`[8]`（第 438 行）含糊点拨**

> [Tutor Note: 含糊点拨。这里说“圆盘冒泡预期发生在实余维 1”，其中“预期”（expected）不是数学上的含糊，而是指一个维数计数：圆盘泡的模空间维数由 Maslov 指标给出。需要小心的是“哪一个指标”：与 ∂² 障碍对应的那一项，在 §2.1 中被记作 μ⁰，而 deg μ^d = 2−d 给出 deg μ⁰ = 2，所以 μ⁰ 计数的是 Maslov 指标 2、带一个边界标记点的圆盘（在 CF 的“L 上的链”模型里，维数 n + μ(β) − 2 取零值亦印证这一点），而不是 Maslov 指标 0 的圆盘。Maslov 指标 0 的圆盘是另一回事：它们造成 continuation 不再同构、从而产生“墙”与墙穿越（见 §3.1），不要与 μ⁰ 混为一谈。于是 ∂² 多出的那一项就是 μ⁰，它被恰当地称为 A∞ 结构的“曲率”（curvature）；整个 §2.1 的 bounding cochain 机制，本质上就是找一个规范变换（Maurer–Cartan 元素 b）把这个“曲率”消掉，使 μ⁰_b = 0 或 μ⁰_b = λ·1。换言之：本节末尾的“障碍”与下一节的“曲率”是同一个东西的两个名字，读的时候应当把这两处对上。]

**`[9]`（第 487 行）含糊点拨**

> [Tutor Note: 含糊点拨。原文说“i_* 的单射性保证了有界上链 b 的存在”，作者在此完全跳过论证。需要注意两点，否则容易读错定理 1.4 的假设层次： (i) 这里的 i_* 是**同调**上的前推 H_*(L;Q) → H_*(M;Q)（原文即如此写），不是上同调上的 i^*: H^*(M;Q) → H^*(L;Q)。二者并不等价（在 Poincaré 对偶下，前者单射对应后者满射），所以不能随手把下标改成上标。 (ii) 逻辑走向是：i_* 单射（或更一般地，开闭映射打到单位）⇒ 存在一个弱有界上链 b ⇒ HF((L,b),(L,b)) ≅ H_*(L;Q)，于是 Floer 复形的秩给出交点下界。注意脚注 3 明确说：这需要先作 bulk 形变（见 §2.4），也就是说 b 是对“经过 bulk 形变之后的 A∞ 结构”而言的弱有界上链，而不是对原结构而言。这个细节若漏掉，会误以为定理 1.4 与“L 不张成任何圆盘”是同一层次的假设。核对细节请直接查 [44, Theorem H] 及其前置章节。]

## Floer 理论的代数：深谷范畴

### Floer 复形上的运算

**`[14]`（第 623 行）易错预警**

> [Tutor Note: 易错预警。(2.2) 的第二个等号并非恒等式，它需要一次真正的展开：把 |du − X_H⊗β|² 用 ω-相容性展开后，交叉项会给出一个恰当形式，其积分在 S 有边时留下一个边界项（形如 ∫_∂S 的贡献）。只有在标准约定下——β 在边界 ∂S 上为零、而在各端处等于 dt——这个边界项才消失，(2.2) 才成立。原文直接写出等式而未提这一点，是因为这是该领域的公共约定。但若你自己构造 Floer 数据（尤其是作族 Floer 或相对 Floer 时），漏掉这个边界项会让能量估计差一个全微分，进而在 Gromov 紧性论证中出现“能量逃逸到边界”的假象。这是自建 Floer 理论时的第一号技术陷阱。] 另请注意 (2.1) 与 (1.2) 的记号对应：这里把近复结构的下标 J 写在 (0,1) 分量处，而 (1.2) 把它写在显式表达式里；两式在端处等价，但 (2.1) 的写法在 S 的拓扑变化时更便于讨论“扰动数据随定义域一致变形”。

**`[15]`（第 658 行）易错预警**

> [Tutor Note: 易错预警（第三处高频翻车点：张量因子的次序）。原文把 μ² 的因子写成 CF*(L₁,L₂) ⊗ CF*(L₀,L₁) → CF*(L₀,L₂)，即“输出在左的那个因子写在前面”。这是 Seidel 的约定。但相当多文献（含 FOOO 与不少导出范畴论文）把次序反写成 hom(L₀,L₁)×hom(L₁,L₂)，或者干脆声明“张量积在域上、次序无关”。次序在向量空间层面确实无关，但在 A∞ 的符号上绝对有关：交换两个因子的次序会引入 Koszul 符号 (−1)^{|x||y|}，从而改变 μ² 的符号，进而改变 A∞ 关系 (2.4) 中 (−1)^* 的具体形式。若与另一文献的公式差一个符号，先查这里的次序约定，再查 (2.4) 的 * 的定义，通常这两处能解释 90% 的符号分歧。]

**`[16]`（第 688 行）易错预警**

> [Tutor Note: 易错预警（(2.4) 的下标记账）。(2.4) 是全文最容易抄错的一个公式，请逐项核对三件事： (i) 参数的书写次序是 x_d, …, x_1（降序！），而 μ^k 作用的是其中连续的一段 (x_{j+k}, …, x_{j+1})（这一段内部是升序）。写成降序的用意是让“插入位置”由 j 与 k 同时指定；一旦手抄时把它写成升序，下标偏移就会整体错位。 (ii) 符号指数 * = deg(x_1)+…+deg(x_j) − j 只涉及前 j 个因子（即在 (2.4) 的印式中作为μ^k 右侧那一段、也就是降序表最右端的 x_1,…,x_j），而不是全部 d 个。其中的 “−j” 来自把 hom 复形作次数移位（desuspension）的约定，使 μ^1 的次数恰为 +1。若某文献没有这个 −j，它多半采用了未移位的分次，公式的符号形式随之不同（多出 (−1)^{j} 之类的因子）。 (iii) 求和项数是 (d+1)(d+2)/2（对每个 k，j 有 d−k+1 种取法，求和得 (d+1)(d+2)/2）。这正好是“在 d+1 个输入中选一段连续块”的方式数。可以用这个计数自查是否漏项。]

**`[17]`（第 713 行）含糊点拨**
