## 1. 必须改

### M1 —— p.6：`e6 ⊃ su(3)^3` 被当成笔误删掉（内容错误，务必改回）

- 位置：`c01.tex:154`（及 `c01.tex:155–156` 的批注）
- **原文**（p.6 第 1 栏，已用 1100 dpi 局部放大确认）：`For instance, T_su(3) is the Minahan–Nemeschansky SCFT with flavour symmetry e6 ⊃ su(3)^3.`
- **现状**：`例如 $T_{\fsu(3)}$ 是味对称性为 $\mathfrak{e}_6\supset\fsu(3)$ 的 Minahan–Nemeschansky SCFT。`，并加批注断言「上标 3 疑为原文笔误或排版残留」。
- **判断依据**：这句**没有笔误**。$T_{\fsu(3)}$ 是带三个满驯服穿刺的球面对应的 tinkertoy，**每个穿刺各带一个 $\fsu(3)$ 味对称性**，故总味对称性是 $\fsu(3)^3$；而 $\mathrm{E}_6$ 的极大子群 $\mathrm{SU}(3)^3$（秩 3+3=6 = rank $E_6$）恰好容纳这三个因子，这正是原文写 `^3` 的原因。删掉 `^3` 后 `e6 ⊃ su(3)` 仍是真命题（$E_6\supset SU(3)^3\supset SU(3)$），所以不会自相矛盾、但会**丢掉「三个穿刺」这一关键信息**，且与原图不符。
- **建议改法**（可直接替换 `c01.tex:154`）：

```latex
例如 $T_{\fsu(3)}$ 是味对称性为 $\mathfrak{e}_6\supset\fsu(3)^3$ 的 Minahan–Nemeschansky SCFT。
```

并把 `c01.tex:155–156` 的批注整段替换为：

```latex
% [Tutor Note: 原文 p.6 的 “e6 ⊃ su(3)^3” 是正确的：T_su(3) 的三个满驯服穿刺各带一个 su(3) 味对称性，
% 而 E6 的极大子群 SU(3)^3（秩 6 = 3+3）正好容纳这三个因子，故味对称性为 e6 ⊃ su(3)^3，不要当作排版残留删去。]
```

### M2 —— p.4 (1.2) / p.7 (1.6)：图形公式会**多出一个自动编号**

- 位置：`c01.tex:69–71`、`c01.tex:192–194`
- **原文**：式 (1.2)、(1.6) 是矢量图，编号印在图内右侧（`eq12.png`、`eq16.png` 里确实各带 `(1.2)`、`(1.6)`，已逐像素确认）。
- **现状**：用 `\begin{equation} … \includegraphics … \end{equation}` 且**没有 `\tag`**。preamble 未设 `\numberwithin`，因此这两条会各自被 amsmath **自动编号为 (1)、(2)**，与图内的 (1.2)/(1.6) 并存 → 版面上出现两个编号。更糟的是 (1.2) 图宽已 ≈`\textwidth`，多出的编号无处安放，会掉到下一行或触发 Overfull \hbox。
- 旁证：`c00.tex:64–65` 自己写着「原文全部 174 条编号公式均以 `\tag{}` 手工锁定编号」，与本处不一致。
- **建议改法**：
  - **(1.2)**：改 `equation*`、宽度保持 `\textwidth`（实测该图内容占原正文宽 99%，`\textwidth` 只放大 1.06×，图内 (1.2) 正好落在右边距）：
    ```latex
    \begin{equation*}
      \includegraphics[width=\textwidth]{eq12.png}
    \end{equation*}
    ```
  - **(1.6)**：改成 `equation*` 是必须的，但**宽度不建议用 `\textwidth`**（该图只含“图形+编号”、不含左侧留白，实测在原页占 x≈200–512 pt；拉到 `\textwidth` 会把图形放大 1.45×）。二选一：
    - (a) 省事：保持 `0.75\textwidth` + `equation*`，代价是图内 (1.6) 会停在右边距左侧约 2.6 cm（略歪，但不算错）；
    - (b) 推荐（我已按下面坐标实测重裁过，图完整、无相邻正文残迹）：把编号从图中裁掉，改用 `\tag{1.6}`：
      ```latex
      \begin{equation}
        \includegraphics[width=0.59\textwidth]{eq16.png}
        \tag{1.6}
      \end{equation}
      ```
      这样编号由 LaTeX 排在右边距、图形与原图等大（≈0.59 正文宽，实测原图无编号部分宽 265 pt），也顺带解决了 O3 的底部残迹。
