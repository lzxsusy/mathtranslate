# 阅读参考指南

《通过膜探测量子化》是一篇 101 页的研究论文，正文约 5.6 万汉字，公式编号 186 个，图 10 幅。它不是教材，默认读者熟悉辛几何与二维拓扑场论。下面给不同背景的读者几条路径。

## 一、预备知识

| 主题 | 需要到什么程度 | 可在本译本中跳过的部分 |
|---|---|---|
| 辛流形、Poisson 括号、Hamilton 向量场 | 熟练 | §2.1 前半可快读 |
| 预量子化、几何量子化、极化 | 知道定义即可 | §2.2 是全文术语的主要来源，建议细读 |
| 复流形、线丛、上同调、Hodge 理论 | 会算 $\bar\partial$ 上同调 | §3.1、§3.8 需要 |
| 二维 $\sigma$-模型、$A$/$B$-模型、膜 | 知道基本图像即可 | §2.4–§2.6 给的是物理图像，不必先学弦论 |
| 形变量子化 | 知道 Kontsevich 的存在性结论 | §2.5 末与 §4.1 会用到 |

不需要：Hitchin 模空间、几何 Langlands 的专门知识。§3.10 与 §5 只用到“平坦 $G$-丛模空间是复辛流形”这一事实。

## 二、四条阅读路径

### 路径 A：只想知道“膜量子化是什么”（约 1 小时）

§1 → §2.4（复化 $Y$）→ §2.5 前两小节（$\B_\cc$ 与 $\Hom(\B_\cc,\B_\cc)$）→ §2.6 开头（$\H=\Hom(\B,\B_\cc)$）→ 概念卡片 1。

关键句：膜量子化的“额外结构”不是极化，而是复化 $Y$；极化依赖被替换为 $Y$ 的选择依赖。

### 路径 B：关心与几何量子化的比较（约 4 小时）

§2.1–§2.3（复习几何量子化）→ §3.1–§3.3（最可算的余切丛情形）→ §3.6（叶与 $M$ 的相交行为决定极化类型）→ §3.7 或 §3.8（按你关心的实/复极化二选一）→ §3.9（超 Kähler 紧情形）。

注意：§3.6 是全文枢纽，读不懂它，后面的“一致/不一致”都无从谈起。

### 路径 C：关心对称性与几何 Langlands（约 3 小时）

§4.1（问题）→ §4.2–§4.3（界面与对应）→ §4.4（自同构）→ §4.6（酉性）→ §5 → §3.10（平坦 $G$-丛模空间）。

§4 的技术核心是“用界面代替函数”：辛同胚不直接作用在函数上，而是作为 $Y\times Y'$ 的拉格朗日对应、即拓扑界面，作用在态空间上。这条思路在几何 Langlands 中就是 Hecke 对应。

### 路径 D：只关心技术细节（按需查）

- 反常的显式计算：附录 A。
- $\Hom(\B_\cc,\B_\cc)$ 与 $\Hom(\B,\B_\cc)$ 的最低阶计算：附录 B.1。
- 高阶修正与“常数函数 1 的典则提升”：附录 B.2。
- 反代数与 $K^{1/2}$ 的来源：附录 C。
- 余各向同性膜的反常与 B-场平移：附录 D。

## 三、几个容易卡住的地方

1. **$\B_\cc$ 的 CP 丛为什么“平凡”**（§2.5）。原文取 $\sB=\omega_J$、$\sF=0$，于是 $\sF+\sB=\omega_J$，A-膜条件 $I=\omega_Y^{-1}(\sF+\sB)$ 给出复结构 $I$。这不是“没有丛”，而是把丛的曲率转嫁给了 B-场；作 B-场规范变换可换成 $\sB=0$、CP 丛为曲率 $\omega_J$ 的线丛。
2. **$\Hom(\B_1,\B_2)$ 的方向**（§2.3、§2.8）。本文约定“$\B_1$ 在下、$\B_2$ 在上”表示 $\Hom(\B_1,\B_2)$；合成是 $\Hom(\B_2,\B_3)\otimes\Hom(\B_1,\B_2)\to\Hom(\B_1,\B_3)$。§2.8 原文有一处 $\alpha$ 的方向与此约定不符（见译注汇总 Q16），译文按约定处理。
3. **“角”不是几何的角**（§2.8 起）。corner 指两条边界（或界面与边界）相交处的局部态/算子，它是 $\Hom$ 空间的元素，不是流形的角点。
4. **$\hbar$ 的位置**（§2.4–§2.5）。$\Omega=\Omega_0/\hbar$ 的写法把 $\hbar$ 吸收进辛形式；因此“$\hbar\to0$”就是“$\Omega\to\infty$”，也就是大体积/经典极限。文中“接近经典极限”都应这样理解。
5. **$(A,B,A)$ 与 $(B,A,A)$**（§3.9）。三个字母分别对应复结构 $I,J,K$；$(A,B,A)$ 表示关于 $I,K$ 是 A-膜、关于 $J$ 是 B-膜。字母顺序不要记反。
6. **两处“不一致”不是错误**。§3.9 说两种量子化作为向量空间同构但不保持 Hermite 内积；§3.11 说非紧叶作为 A-膜无模、作为 B-膜有模。这两处都是原文的实质结论，不是笔误。
