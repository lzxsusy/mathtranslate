## 二、底本选择

本项目的关键决定是**不用 PDF 重排，而用作者 LaTeX 源码**。

- 从 arXiv 取得 `Draft_D.tex`（4335 行，383 KB）与 11 个图 PDF。源码是最高保真底本：公式、编号、参考文献、图位置都可原样沿用，只需译正文与章节标题。
- 风险是源码含注释掉的旧节（3375–3403 的 Gauged quantization、3526–3584、4249 起的 More On Cotangent Bundles）。这些节不在 PDF 中，LaTeX 自动忽略，未译，也未从源码中删除（保留以备核对）。
- 页映射：PDF 页 = 印刷页 + 2。译本以印刷页为引用单位，已在“读法”中说明。

## 四、关键工程决定

1. **照搬原文的 `\def` 宏**。源码用 51–214 行的一大批单字母宏（`\B`、`\cc`、`\j`、`\S`、`\U` 等）。若在翻译时改写为常规命令，公式极易出错；因此 `preamble.tex` 逐条照抄这些宏，正文公式可直接复制源码。代价是 `\S` 在本译文中是 $\mathfrak L$ 而不是 \S，`\j` 是 $\mathsf j$，读源码时须记住。
2. **不做定理环境**。原文没有 theorem/proof 结构，只有定义段、构造段与物理论证。若强行加“定义 2.1”之类编号，会与原文编号体系冲突，故只保留 equation 编号。
3. **强调改粗体**。原文用无衬线字体表示强调；中文无对应，按仓库模板改为粗体（`\renewcommand{\emph}`）。
4. **图的处理**。10 幅图直接复用作者 PDF，不重绘；`figures/6.pdf` 原文件 xdvipdfmx 无法读取，用 `pdftocairo -pdf` 重新蒸馏后解决。`Correspondence.pdf` 统一改名为小写 `correspondence.pdf`（Linux 区分大小写）。
5. **方框的使用**。译注、校勘、概念卡片均用模板的 tcolorbox 环境，且必须成对闭合（`\begin{kanwu}[标题]…\end{kanwu}`），不能写成 `\kanwu{…}`——后者会把参数当标题、环境不关闭，导致后续 `figure` 报 “Not in outer par mode”。

## 六、遗留问题与下一轮建议

1. **译注偏少**。全文只有 4 条译注、1 张概念卡片。§3.10（平坦 $G$-丛）、§4.4（自同构）与附录 D 都可再加背景注；本轮因优先保证全文完整而未展开。
2. **B 级来源缺失**。按纪律，B 级须与 A 级交叉核对；余各向同性膜、$\Spinc$ 结构在 nLab 的条目零散，未能形成交叉，故本轮不标 B 级。下一轮可补 Stacks Project 的 $\Spinc$ 与 Hodge 理论条目。
3. **§2.8 的 $\alpha$ 方向**。原文写作 $\alpha\in\Hom(\F,\B_\cc)$，与复合 $\psi=\alpha\circ\beta$ 不符；译文按约定改为 $\Hom(\B_\cc,\F)$，但未在正文设校勘框，只在汇总中记录。下一轮可考虑加框。
4. **语言层**。译文按“准确优先”处理，长句较多；若面向本科读者，可再作一轮“拆句”润色，但须防止改变原文的谨慎语气（原文大量使用 “should”“it is reasonable to expect”）。
5. **未做的资料卡**。按用户要求，本轮不制作资料卡；待正文稳定后再补。
