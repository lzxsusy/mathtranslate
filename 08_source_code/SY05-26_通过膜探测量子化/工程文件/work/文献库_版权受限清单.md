# 版权受限 / 非 arXiv 清单

这些是「读这篇文章必须有、但 arXiv 上没有合法公开版」的条目。按优先级排，高 = 不读就有一整节读不懂；中 = 影响某个论证的细节；低 = 锦上添花。

**建议获取渠道**：① 学校/机构图书馆的 Springer、AMS、CUP、JSTOR 订阅；② 出版社单篇购买；③ 作者主页（少数老论文作者会自挂）；④ 馆际互借。清单里不给非授权镜像地址。

## 四、获取优先级建议

**第一周只要三样**：#1 或 #3（二选一，Bates–Weinstein 已有）、#2 Hall、#10 Hitchin 1987。这三样能撑起 §2.2、§3.7–§3.10 的全部对照阅读。

**第二周补**：#12 Witten 1988、#14 BMS、#13 Meinrenken–Sjamaar、#15 ADW。这四篇补 G7 与 G5。

**其余按需**：写到哪一节再取哪一篇，不要一次性搬。
