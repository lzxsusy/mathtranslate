用途：给 SY05-26 的后续精读、复核与资料库建设提供**下载清单 + 阅读路线 + 缺口映射**。

## 一、先看缺口：本文在哪儿是「悬空」的

按严重程度排。每条给出「缺口 → 补它的文献类」。

| 编号 | 缺口 | 具体表现 | 补法 |
|---|---|---|---|
| G1 | **复化 $Y$ 没有存在性定理** | §2.4 把 $Y$（带整体全纯辛形式 $\Omega$、$\Omega|_M=\omega$）当作输入，只给「$M$ 实代数簇 ⇒ $Y$ 复代数簇」一类例子；对一般紧辛流形是否有这样的 $Y$ 未讨论 | 复化理论（Grauert 复化、Whitney–Bruhat）＋复辛几何；本文自引里没有这一类 |
| G2 | **A-模型良定义只有充分条件** | §2.4 说「$Y$ 完备超 Kähler ⇒ A-模型存在」；但 §2.5 自己承认不知道 $T^*W$ 是否有完备超 Kähler 度量，只引 Kontsevich 判据。全文最常用的例子恰在这一条上悬空 | A-模型的范畴/TCFT 定义（Costello、Kontsevich）；形式形变 vs 实际形变的边界（Kontsevich 判据原文） |
| G3 | **内积正定性是最大的洞** | §2.7 说 Hermite 形式「非退化但一般不正定，只在接近经典极限时正定」——无证明、无判据、无反例；而 §4.6 的酉性证明以正定性为前提 | 几何量子化的正定性理论（Hall 第 23 章、Woodhouse）；A-模型态空间的内积没有标准文献，这可能是个真问题 |
| G4 | **只比到向量空间，没比 Hilbert 结构** | §3.9 明说「作为向量空间同构，但不保持 Hermite 内积」；紧情形（如 $S^2$）两边都是不可约表示，内积本由不变性定到常数倍，文中没算 | 几何量子化内积的显式公式（Hall/Woodhouse）＋ 一个 $S^2$ 的具体计算 |
| G5 | **§3.10 的 $e^{G_\kappa}$ 作者自认未解** | 膜量子化如何给出 WZW $G_\C/G$ 的配分函数因子与 Quillen 度量，文中明说「未解」 | ADW、Faltings、Andersen、Laszlo（本文已引）；Quillen 度量与共形块 |
| G6 | **反常只靠代数定理，无世界面独立计算** | 附录 D 用 Bezrukavnikov–Kaledin 的定理消反常；只处理秩 1、支撑全 $Y$ 的 $\B_\cc$ | Freed–Witten 的反常流入；Kapustin、Herbst 的高秩余各向同性膜 |
| G7 | **与几何量子化三条主线全部脱钩** | 没提 Berezin–Toeplitz（Kähler 情形最常用的量子化、有大 $\hbar$ 渐近）；没提「量子化与约化交换」（Guillemin–Sternberg / Meinrenken–Sjamaar）；没提 $\mathrm{Spin}^c$ 量子化（非整辛形式）。本文说「两边其实都是 $\mathrm{Spin}^c$ 结构」，比较时却假设 $\frL$ 存在，把更一般的那一面放掉了 | BMS 与 Ma–Marinescu；Meinrenken–Sjamaar；$\mathrm{Spin}^c$ 量子化文献 |
| G8 | **BKK/BEY 只验生成元** | §4.4 验证线性辛同胚与剪切在 $\A$ 上作用，未证 $\TAut=\Aut$（$n>1$ 未决）；「量子修正为零」依赖 $\C^{2n}$ 的伸缩，不能推到一般 $Y$ | BKK、BEY 原文；驯顺生成问题 |
| G9 | **§3.1 的代数刻画依赖未证假设** | 把 $\Hom(\B_\cc,\B_\cc)$ 等同于微分算子代数，依赖「只允许 $p$ 的多项式依赖」与 $\C^*$-不变性；对一般 $W$ 未证 | 齐次形变/等变形变的分类；Kontsevich 的 $\C^*$-等变版本 |
| G10 | **§5 假设 $\frL$ 有平方根** | 无平方根时只说「更麻烦」，未写；B-场版本被跳过 | 线丛平方根与 B-场的一般处理（可能要自己补） |

一句话总结：**这篇文章的物理直觉是完整的，数学地基是条件性的**——$Y$ 存在、A-模型存在、内积正定，三件事各差一个定理。

## 四、阅读顺序（五阶段，每阶段有验收）

**阶段 0（1 天）——把「膜量子化」这句话读懂**
读 GW 0809.0305 的引言与 §2；对照本文 §1、§2.4–§2.6。
验收：能不看书画出 $Y$、$\B$、$\B_\cc$、$\H=\Hom(\B,\B_\cc)$ 四件套，并说清「为什么 $\B_\cc$ 的 $\sF+\sB=\omega_J$」。

**阶段 1（2–3 天）——几何量子化对照面**
Bates–Weinstein 全本；Hall 第 22–23 章选读；Woodhouse 查 BKS 与半形式。
验收：能独立推出 §2.2 的半密度内积与 $\spinc$ 构造；能说清 BKS 核为什么依赖极化。

**阶段 2（3 天）——形变量子化与 A-模型**
Kontsevich 引言 + $\C^*$-等变构造；Kapustin–Witten §11；Fedosov 或 Cattaneo–Felder 二选一。
验收：能解释「为什么 $\Hom(\B_\cc,\B_\cc)$ 是 $\A_0$ 的形变」，以及 §3.1 的转移函数上闭链 $[\phi]$。

**阶段 3（3 天）——超 Kähler 与 Hitchin**
Hitchin 1987 + 1990；Kronheimer；§3.9–§3.10 对照读。
验收：能说清 $J_t$ 与 $\J_t$ 的区别，以及「$H^0_{\J_t}$ 与 $t$ 无关」为什么是膜量子化的预言。

**阶段 4（3 天）——Langlands 与 $e^{G_\kappa}$ 缺口**
Gaiotto–Witten 2107.01732 引言 + EFK 1908.09677 引言；ADW/Faltings/Andersen 选读。
验收：能复述「§3.10 的 $e^{G_\kappa}$ 为什么是未解问题」，并列出至少两条可能的补法。

**阶段 5（持续）——补 G7（Toeplitz/约化/$\mathrm{Spin}^c$）**
BMS + Ma–Marinescu 第 1 章；Meinrenken–Sjamaar 引言。这一层不急于读完，但要在资料库里立条目。

## 七、不必下载的

- 任何「膜量子化入门」的二手博客、知乎回答、视频课笔记——纪律黑名单，且这一题材的二手材料错误率高。
- 与本文无接口的 Langlands 大部头（如 Beilinson–Drinfeld 全套）：用到时再查，不要作为脚手架。
- 纯数学的复化理论专著：只需 Grauert 复化定理的陈述，找综述即可。
- 本文已引但只用作「已知结果」的文献（如 [ABott]、[KZ]、[WittenJ]）：知道结论即可，除非要做 §3.10 的细节。
