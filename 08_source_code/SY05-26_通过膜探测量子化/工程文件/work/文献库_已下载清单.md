## 用法

按仓库 `工程文件/work/文献脚手架清单.md` 的五阶段路线读；每篇读完在资料库里补一条 YAML（模板见该文件第六节），字段 `interfaces` 指向本文小节、`gaps_addressed` 指向 G1–G10。
