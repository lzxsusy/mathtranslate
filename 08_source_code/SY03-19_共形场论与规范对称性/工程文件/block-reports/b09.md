DIFFICULT:
- p.75 引理 4.3 的证明：要证 $\C_s\otimes\cV\simeq\cV(\mathcal{F}_s)$。原文只给「前两个与第五个同构显然」，实际的基变换同构 $H^1(C_s,\cO(k\sum s_j))=0$ 需要 $k\gg0$（次数 $kN>2g-2$ + Serre 对偶），而四个同构都通过 $\varinjlim_k$ 依赖这个 $k$；最后一步是「两列正合列 + 蛇引理」，原文一句「$\beta$ 满、$\gamma$ 同构 ⟹ $\delta$ 同构」带过，$\C_s$ 是域、张量右正合这一层默认了 ★★
- p.76 定理 4.4（$\cV_{\vec\lambda}$ 与 $\cV^\dagger_{\vec\lambda}$ 凝聚）：证明末句「Hence $\cV$ is also coherent」跳过了「分次凝聚 ⟹ 原层凝聚」（需滤过有界 + $\cO_\mathcal{B}$ 诺特），又一句「$W_m$ 有限维（命题 3.7）⟹ $\operatorname{gr}^F_\bullet W_m(\mathcal{B})$ 凝聚」也默认了 $\cO_\mathcal{B}$ 诺特；$\cV^\dagger$ 的凝聚性（对偶 $\underline{\operatorname{Hom}}$）完全未证。这是本块最大的缺口 ★★★
- p.76–77 (4.11) 的 $m\ge 4g-3$ 与 (4.13) 的 $m>\frac1N(2g-2)$：两个界为何恰好取到，原文无任何说明，只能从「$\vartheta_m$ 满射」与「$\pi_*\Theta_{\mathcal{C}/\mathcal{B}}(mS)$ 的维数估计」反推 ★★
- p.77 $\Theta'_{\mathcal{C},\pi}=d\pi^{-1}(\pi^{-1}\Theta_\mathcal{B}(-\log D))$ 与「水平分量在纤维上为常数」的等价性（给出的坐标式 $b_i(u)u_i\partial_{u_i}$）没有证明，需要对数极点的坐标刻画 ★
- p.78 交换图：从「(4.10) 与 (4.12) 交换」推「$\tilde p$ 单射、$p$ 同构」，关键是小平–Spencer 映射 $\rho$ 在通用族下是同构（这是 §1 的重结果），原文只引一句话；$\rho$ 与 $p$ 的相容性（为何取 $\frac{d}{d\xi_j}$ 的非正部分）也没有展开 ★★★

- p.79 命题 4.6 (2)：$D$ 的曲率恰为 $\frac{c_V}{12}\sum_j\operatorname{Res}((\ell_j'''m_j)d\xi_j)\cdot\mathrm{id}$。这一步要用 Sugawara 构造的 Virasoro 对易关系与 $T[\ell]$ 的「抹平」性质，原文归为 "easy consequence of the definition and Lemma 2.13"，实际计算量很大 ★★★
