DIFFICULT:
- p.54–55 定理 3.15（真空传播）的证明骨架：先把泛函造在 $\mathcal H_{\mathfrak X}\otimes\mathcal M_0$（$\mathcal M_0$ 为平凡表示的 Verma 模）上，再验证它穿过 $\mathcal H_0$。原文只说 "The linear functional is defined inductively"，未说明为何必须经过 Verma 模而不能直接在 $\mathcal H_0$ 上定义：$\mathcal H_0$ 的滤过 $F_p$ 与 $X(m)$ 的下降关系需要 $\mathcal M_0$ 的自由性来保证每一步只依赖前一步 ★★
- p.55–57 单射性归纳：核心是把 $\langle\tilde\Psi|u\otimes X(m)v\rangle$ 用 $\hat{\mathfrak g}(\tilde{\mathfrak X})$-不变性换成 $-\sum_{j=1}^{N}\langle\tilde\Psi|\rho_j(X[f])u\otimes v\rangle$，其中 $f$ 需同时满足 (3.25) 的 $f\equiv\eta^m\bmod(\eta^M)$ 与 (3.26) 的 $X\otimes\eta^k|v\rangle=0\ (k\ge M)$；$f$ 的存在性与两个条件为何相容原文未展开 ★★
- p.57 (3.31) 的组合恒等式：$(X_\theta[f])^n$ 展开为多重和 $\sum_{n_1+\cdots+n_N=n}\frac{n!}{n_1!\cdots n_N!}\prod\rho_j(X_\theta[f])^{n_j}$，再用 (3.30) 说明至少一个 $n_j\ge n/N$ 使该因子为零；「除以 $N$」正是这里 pigeonhole 的来源（若原文的 $n/N$ 无误，则 (3.30) 的 $n$ 应对应 $N$ 倍），译文照排并在译注中指出 ★★
- p.57 用 $\mathfrak{sl}(2,\C)$ 的有限维表示论：$H$ 在 $\overline{|0\rangle}$ 上特征值 $\ell$，由 $\dim<\infty$ 得 $F^{\ell+1}|\overline{0}\rangle=0$；原文只说 "by the representation theory"，未说明 $\ell$ 必须为非负整数（否则与有限维矛盾）★★
- p.58 定理 3.18（投影）：$\mathcal V^\dagger_{\vec\lambda}\to\Hom(V_{\lambda_1}\otimes\cdots\otimes\mathcal H_{\lambda_N},\C)$ 的像恰为 $V^{\dagger,0}_{\vec\lambda}=\{\langle\Phi|\mid\langle\Phi|X\otimes f=0,\ \forall f\in H^0(C,\mathcal O_C(*Q_N))\}$，且 $p$ 为同构。这是本节「投影/迹配对」机制的第一次完整出现：为何「$X\otimes f$ 对所有 $f$ 零化」正好对应对最后一个因子上的 $\hat{\mathfrak g}(\mathfrak X)$-作用零化，原文只给结论 ★★★
- p.58–60 定理 3.18 的证明：从 $F_p$ 到 $F_{p+1}$ 逐层延拓，需说明 (i) 右端 $\sum_{i\ne N-1}\langle\Phi^{(p)}|\rho_i(X[g])\cdots\rangle$ 与 $g$ 的选取无关（两个 $g$ 之差在 $Q_{N-1}$ 正则）；(ii) $f-b_{-p-1}h$ 的极点阶降一阶从而落在归纳假设适用范围；(iii) 最后用 $\mathfrak{sl}(2)$ 最高权论证把 $F_{p+1}\mathcal M$ 降到 $\mathcal H_{\lambda_{N-1}}$。三步原文各只有一两句 ★★★
- p.61–66 因子化定理 3.19 的整体逻辑：先用单态 $|0_{\mu,\mu^\dagger}\rangle$ 把 $V_\mu\otimes V_{\mu^\dagger}$ 里的平凡子模取出，得到 $\mathcal V^\dagger_{\mu,\mu^\dagger,\vec\lambda}(\tilde{\mathfrak X})\to\mathcal V^\dagger_{\vec\lambda}(\mathfrak X)$；再从 $\mathcal V^\dagger_{\vec\lambda}$ 的不可约分解 (3.37) 反过来造 $\langle\tilde\Psi_\mu|$ 证明满射。单射部分（p.65）依赖 $U(\langle\Psi|)\subset V_\mu^{\dagger\oplus n_\mu}$，满射部分（p.65–66）依赖在 $F_p\mathcal H_\mu\otimes F_q\mathcal H_{\mu^\dagger}$ 上的双层归纳；原文把两层归纳混在一段里，读者极易迷失 ★★★
- p.61 单态系数的确定：$|0_{\mu,\mu^\dagger}\rangle=\sum_j c_j e_j\otimes e_{m-j}$ 要求 $E$ 作用为零，得 $c_j(m-j+1)+c_{j-1}j=0$，故 $c_j=(-1)^j j!(m-j)!/m!$；原文印作 $(-1)^m$（见 ERRATA 8），若照印则不是不变量 ★★
