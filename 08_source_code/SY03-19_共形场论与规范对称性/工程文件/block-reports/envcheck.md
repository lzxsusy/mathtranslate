## 7. `check_env.py` 判定口径摘要

- 从 `main.tex` 读 `\section` 与 `\input` 顺序，自动建立「章 → 块」；
- 环境：`\begin{definition|theorem|proposition|lemma|corollary|example|remark}[N.M]`，`[N.M]` 必须是 `N.M` 形式；
- 检查：章内 1 起递增、重号、乱序、跨章串号、跨块接缝；图注 `\figomit{N.M}` 章内连续性（`\figomitn` 与首参非图号者视为无编号，只提示用法）；
- 译注数按 `% [Tutor Note` 计；`% >>>END` 存在即判该块「待译」；
- 输出：逐章表 + 接缝 + 三张清单（问题 / 待译缺号 / 其他观察）+ 统计；`--md 文件` 同时落盘。
