# ROADMAP_SPEC.md —《脉络梳理》写作规格（Lead 独占维护）

《脉络梳理》是本工程的**第二份独立交付物**，用途：给"要精读这本书的人"一张地图——全书在讲什么、按什么顺序读、哪里是重点、哪里会卡住、怎么补。

- 作者：Lead 指派的一名收尾译手（唯一写域：`脉络梳理.md`）。
- 素材：`TIMELINE.md`、`glossary.tsv`、`src/b*.tex`（已译全文）、`block-reports/*.md`（尤其 **`DIFFICULT:`** 字段）、`译注汇总.md`、`ERRATA.md`，以及对**各章开头页/定理陈述页/小结页**的复查（`pages/pNNN.png`）。
- 产物：`脉络梳理.md`（唯一源文件）→ Lead 用 pandoc 转 `脉络梳理.pdf`。

## 一、篇幅与格式

- 8 000–14 000 汉字；宁可具体，不要空泛。
- **Markdown**：`#` 一级标题只用于文档名；`##` 用于大节；表格用于清单。
- **每个自然段写成一行**（不要手动折行；pandoc 会把换行变成空格，中文里会多出一个空格）。
- 公式用 `$...$` / `$$...$$`，只用标准 LaTeX；不写 Unicode 数学符号。
- 引用原文一律给**印刷页码 + 编号**，如「定义 3.1（p.47）」「式 (5.17)（p.104）」。
- 难点用 ★ 标注（见第五节），不用 emoji。

## 二、必须包含的十节（顺序固定）

### 1. 一句话定位
这本书用一句话说是什么：**从复代数几何的视角把 WZW 共形场论"几何化"**——把物理上的共形块变成曲线模空间上的向量丛/层，并证明它带射影平坦联络。再说清楚它**不是**什么（不是物理教材，不推导路径积分；不是表示论教材，仿射李代数只讲用得到的部分）。

### 2. 全书骨架图
用文字/ASCII 依赖图画出六章的关系：
```
Ch1 曲线与模空间（几何舞台）
Ch2 仿射李代数与最高权表示（代数输入：可积表示、Sugawara、c_v）
        ↓
Ch3 共形块 = 带坐标的稳定带点曲线 ↦ 向量空间（构造 + 基本性质 + 关联函数）
        ↓
Ch4 层化：族上把这些向量空间粘成层；局部自由 + 因子化
        ↓
Ch5 层带射影平坦联络（平坦性 + 与 Hitchin 联络等同 + Verlinde 公式）
        ↓
Ch6 球面 P¹ 情形：顶点算子、KZ 方程、基本解、Hecke 代数（与 Ch5 相互印证）
```
每个箭头写一句"为什么需要前一章"。

### 3. 六章逐一详解（本书主体，篇幅最大）
每章固定六项：
1. **任务**：这一章要解决什么问题；
2. **输入**：需要前面哪些结果（给编号/页）；
3. **核心结果**：按编号列出 3–6 条最重要定理/定义（`定理 3.20（p.58）`）；
4. **证明策略**：作者怎么走（归纳/局部化/比较两条计算/引用外部定理）；
5. **输出**：这一章结束时拿到了什么，下一章怎么用；
6. **可跳过**：初读时可以整段跳过的部分及原因（如"§5.6 与 Hitchin 的对照，初读可只读结论"）。

### 4. 三条主线
把同一批结果按三条线重排，方便不同背景的读者：
- **几何线**：紧黎曼曲面 → 稳定带点曲线 → 形变/Kodaira–Spencer → 通用族 → 模空间 → 层 → 联络。
- **代数线**：单李代数 → 仿射化 ĝ → 可积最高权表示 → Sugawara/Virasoro → 共形块（真空向量、迹配对）→ 顶点算子。
- **分析/物理线**：射影平坦联络 ↔ 平坦化后局部常数解 ↔ KZ 方程 ↔ 顶点算子的 OPE ↔ Verlinde 公式。
每条线给"只读这条线时按页序读哪些页"的清单。

### 5. 精读路线（三档，必须给页码）
- **A. 速览（1–2 天，约 30 页）**：前言 + 记号 + 各章首段 + 每章核心定理陈述 + 第 3 章 §3.1、§3.3 的定理陈述。
- **B. 标准（1–2 周，约 80 页）**：Ch1 只读 1.1/1.2 关键定义、Ch2 全读、Ch3 全读、Ch4 §4.1/§4.3 定理、Ch5 §5.1/§5.3/§5.5。
- **C. 完整（4–6 周，168 页）**：全读，含 §5.6 与 §6.5；给出周计划（每周读哪些页、配哪些练习）。
每档说明"读完能做什么/不能做什么"。

### 6. 预备知识清单（带自测题）
分四块：复几何/代数几何（黎曼面、除子、层与上同调、形变理论）、李代数（根系、最高权、Weyl 群、Kac–Moody）、共形场论物理（OPE、Virasoro、WZW 作用量）、分析（Fuchs 型方程、单值化）。每块给 3–5 条"能答上来就算够"的自测题，并标出"不够时补哪本书的哪部分"（只写经典书名，不编造具体页码）。

### 7. 重点清单（表格）
| 章 | 必读 | 编号/页 | 为什么重要 |
把全书"如果只记 20 件事，记这 20 件"列出来。标准：后续章节反复引用、或定义了全局记号、或给出可计算判据。

### 8. 难点与跳步标注表（本书的第二个重点，篇幅要大）
逐章列出，每行一条：
| 章 | 位置（页、编号） | 现象 | 类型 | ★ | 补法 |
- **类型**：`跳步`（中间结论被省略）/ `引用外部`（用了别处定理）/ `记号切换`（同一对象两种写法）/ `笔误`（原文印错，见 ERRATA）/ `示意`（图或文字没说清）。
- **★ 语义（全文档统一）**：
  - ★ = 一跳步，读者自己补 1–3 行即可（如"这里把 $\partial$ 与 $\ol\partial$ 拆开算"）；
  - ★★ = 需补半页以内论证，且用到本领域标准工具（如 Kodaira–Spencer 映射的精确性、Serre 对偶、留数定理）；
  - ★★★ = 依赖外部定理/文献（如 [TUY] 的存在性、[Kac] 的表示论、Hitchin 的 Higgs 丛对应），精读时必须查外文。
- **补法**列写"具体动作"：补什么公式、查哪篇文献的哪条结论、或"回看 p.xx 式 (x.y)"。
- 必须覆盖各块报告 `DIFFICULT:` 的**全部**条目（可合并同类），并允许补充你自己读出的难点。

### 9. 各章自查练习
每章 3–5 题，用于检验是否真读懂（例：*"用式 (2.31) 验证 $c_v=\ell\dim\mathfrak g/\kappa$ 在 $\mathfrak g=\mathfrak{sl}_2$ 时等于 $3\ell/(\ell+2)$"*）。给答案要点（1–3 行），不要只出题。

### 10. 与其他文献的关系
本书在链条上的位置：与物理教材（WZW/CFT）、与 TUY/Ueno 的 modular functor 工作、与 Hitchin/Simpson 的联络理论、与 Kac 的表示论，各自补什么。只用 `src/refs.tex` 里出现过的文献 + 公认经典书，**不许编造文献**。

## 三、写作口径

- 面向"已经会基础代数几何、但没系统学过 CFT"的读者；讲清**动机**比复述定义重要。
- 每节开头一句"这一节干什么"，结尾一句"记下这几件事"。
- 不确定的地方写"（此处需对照原文 p.xx 核实）"，**不要编**。
- 与 `译注汇总.md` 的分工：译注是**逐点**的注解，脉络梳理是**整体**的地图；引用译注时给块号与条号，不重复其内容。
