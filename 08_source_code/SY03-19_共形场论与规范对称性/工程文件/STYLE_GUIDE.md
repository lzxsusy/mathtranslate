## 施工标准（必读，每次按此执行）

本项目（含后续补译、校订、译注重写）一律按《数学文献翻译纪律》**v2.0** 执行——**它是硬标准，不是参考资料**：

1. **先通读后落笔**（§1.0）：译前先通读全文并产出《通读笔记》《疑点清单》，疑点清单「未解」= 0 才准译第一句。
2. **译注必须有可追溯来源**（§2.5）：先查本库既有译法（corpus / 既往术语表），再查 nLab / Stacks Project / EMS / DLMF 交叉验证，最后落到 A 级原始文献；每条解释性译注带 `[来源：…]` 或 `[译者按（无外部依据）]`，禁止编造来源。
3. **来源黑名单与语料卫生**（§2.5.9）：知乎、百度百科/知道、CSDN、简书、公众号、博客、视频课笔记等一律不看、不引、不缓存；语料使用口径以 DATASHEET 与 LICENSE 为准：译文与语料是第三方底本的演绎作品，保留权利，仅限非商业学术研读，权利人通知即撤；自产元数据、术语、工程文档与工作流为 CC BY 4.0。

## §0 一句话

**照原文逐段译；公式逐条看图抄；编号一个不多一个不少；不插图、不造表、不编数学。**

## §1 页码体系

- **PDF 页 = 印刷页码 + 9**。例如印刷 p.1 是 `pages/p010.png`。
- 片段里所有位置标注写成 `% [原文 p.16]`（**写印刷页码**）。
- 每到新的一页（原文印刷页），在正文流里插一行注释 `% [原文 p.17]`。这行**只能插在两个段落之间**，不能插在数学环境或句子中间。
- 每个片段文件开头必须有：
  ```latex
  % ===== Block B07: 原文 p.54–66 | §3.3 共形块空间的基本性质 =====
  ```

## §2 片段规则（最重要）

- 每个块只产出**一个文件** `src/bNN.tex`，内容是可直接 `\input` 的**片段**。
- **禁止**出现：`\documentclass`、`\usepackage`、`\newcommand`、`\renewcommand`、`\DeclareMathOperator`、`\begin{document}`、`\end{document}`、`\input`、`\includegraphics`、`\tableofcontents`、`\maketitle`、`\section`、`\chapter`。
- **禁止**自己定义宏、环境、计数器。需要新宏 = 报告 Lead。
- **章标题**由 Lead 在 `main.tex` 里写。**小节标题由块自己写**：每个块开头（或块内小节交界处）写
  ```latex
  \subsection{稳定 $N$-点曲线}
  ```
  标题的中文译文**必须照任务书/`TIMELINE.md` 给的用字**，不要自己改词。小节自动编号（`1.1`、`1.2`…）与原文一致，**不要**手写编号。
- 块内若还有原书的三级跑头（如 `1.1.3 Kodaira-Spencer mapping.`），按 §2 末条处理，不用 `\subsubsection`。
- 原书的三级标题（如 `1.1.1 Compact Riemann surfaces.`）是**段首粗体跑头**，照此处理：
  ```latex
  \noindent\textbf{1.1.1 紧黎曼曲面.}\quad 一个连通的紧一维复流形称为紧黎曼曲面……
  ```
  （编号 `1.1.1` 照抄，标题译成中文，后面接正文，不换行。）

## §3 公式编号（唯一真值）

1. 每条原文编号公式 → `equation` + `\tag{}`：
   ```latex
   \begin{equation}
     z_\lambda = f_{\lambda\mu}(z_\mu, w^1,\dots,w^m). \tag{1.1}
   \end{equation}
   ```
2. 多行对齐且**每行各有一个编号**：用 `align`，每行 `\tag{...}`。
3. 多行对齐但**只有最后一行有编号**：前面的行 `\nonumber`，最后一行 `\tag{...}`。
4. **`\tag` 里的数字必须与原文完全一致**，不得重排、不得跳号、不得自造。编号是**章内连续**的：第 1 章 `(1.1),(1.2),…`，第 2 章 `(2.1),…`。
5. 原文无编号的显示公式 → `\[ ... \]`，**禁止**给它们编 `\tag`。
6. 正文中引用公式写**纯文本**：`式 (1.41)`，**禁止** `\eqref` / `\ref`。
7. 原文若把公式编号印错（重号、跳号、引错），**照原样排**，在 `% [Tutor Note: ...]` 里指出，并写进回报的 `ERRATA:` 行。

## §4 数学宏（只用 preamble 已定义的，禁止自造）

preamble 已提供：

```
\dd \ee \ii \Tr \SL \GL \End \Aut \id \Hom \Sym \ad \rank
\R \C \Z \Q \N \PP \HH \AA
\cA \cB \cD \cE \cF \cG \cH \cL \cM \cN \cO \cP \cS \cU \cV \cW \cX
\ol{#1} \eps \figomit{编号}{图注}
```

- `\dd` 是微分 `d`；`\ol{X}` = $\overline{X}$。
- 其他一律写**普通 LaTeX**（`\mathfrak{g}`、`\mathrm{SL}`、`\operatorname{Res}` 之类），**不要新建宏**。
- 数学里**不出现中文**；必须出现时用 `\mbox{中文}` 且尽量改写掉。
- 逐字对应原文符号，不要为了好看改符号：原文写 $\mathfrak{g}$ 就写 `\mathfrak{g}`，原文写 $\hat{\mathfrak{g}}$ 就写 `\hat{\mathfrak{g}}`。

## §5 批注格式（Tutor Note）

- 一律写在 LaTeX 注释里，**不进入排版**：
  ```latex
  % [Tutor Note: 这里 $\Omega^{1,0}$ 与 $\Omega^{0,1}$ 的分解用了 Hodge 分解；核对方法：取 $g=1$ 时 … ]
  ```
- 批注里可以自由用 `$...$`（注释不被 TeX 处理），但 `$` 必须成对（check_block.py 会数）。
- **批注必须值得写**，满足其一：
  1. **可验证的易错点**：给出核对方法（取特殊值 / 维数检验 / 与小 $g,n$ 比较）；
  2. **补出的省略论证**：说清用了什么定理、哪一步跳了、为什么成立；
  3. **原文笔误**：给出正确形式 + 判断依据；
  4. **术语/记号说明**：跨领域术语辨析，或原文记号切换处。
- **不要**写"这一段很重要""需要注意"这类空话；不要复述原文。
- 每块 **8–20 条**批注，宁缺毋滥。
- 批注不许出现不成对的 `}`、不许出现以 `\` 结尾的行。

## §6 环境（定理/定义/例/注）

原书**每章一套主计数器**，定义/定理/引理/命题/推论/例/注共用。用法：

```latex
\begin{definition}[1.1]
...
\end{definition}

\begin{theorem}[1.2]
...
\end{theorem}
```

可用环境：`definition`（定义）、`theorem`（定理）、`proposition`（命题）、`lemma`（引理）、`corollary`（推论）、`example`（例）、`remark`（注）。

- **编号必须手工给**，`[]` 里写原文编号（如 `[1.1]`），**禁止**依赖自动计数器。
- 原文没有编号的 → 用带星号的环境（`theorem*` 等），不带号。
- `[...]` 里不要出现数学。
- 原书的 "Proof." 照译「**证明.**」，结尾用 `\hfill$\square$`（若原文有证毕符号则照原样）；证明不放进环境。

## §7 禁止事项

1. **不插图**：不写 `\includegraphics`、不画 TikZ。原文有图的位置 →
   ```latex
   \figomit{1.1}{亏格为 $g$ 的黎曼曲面。}
   ```
   （第一个参数是原文 Figure 编号；第二个是**图注译文** + 只写原文图注与正文明确说过的内容，不许脑补。）正文里 "see figure 1.2" 照译成"见图 1.2"，不改编号。
2. **不造表**：原文若确有表格，**照抄重排**为 `tabular`（表题译成中文并保留 `Table N`），并在回报里写 `TABLE:` 行。若只是正文里提到某个表，不用管。
3. **不补文献**：正文方括号引用照抄（`[Ueno]`、`[TUY]`），参考文献由 Lead 统一处理（块 B17）。
4. **不改正文**：原文说错的、写怪的、笔误的，**照原样译**，在 Tutor Note + 回报 `ERRATA:` 里指出。
5. **不写 Markdown**：`**粗体**` 会原样印成星号。要强调用 `\emph{}` 或 `\textbf{}`。
6. **不写 Unicode 数学符号**：希腊字母写 `$\zeta$` 不写 `ζ`；`≤ ≥ ≠ → ∞ ∑ ∫` 一律 `\le \ge \ne \to \infty \sum \int`。
7. **不删原文内容**：包括打字错误、重复词、括号不配对（在批注里指出，正文照译）。
8. **不翻译人名/文献标题/期刊名**：Witten、Knizhnik、Zamolodchikov、Verlinde、Hitchin、Kontsevich 等保留拉丁字母。
9. **不做静默省略**：任何段落都要译；真搞不定写 `% [TODO-LEAD: ...]` 并在回报里说明。

## §8 边界规定

- **边界以小节标题为界**：TIMELINE.md 给了每块的起止小节与印刷页。块从**本节标题之后**的第一个字开始（标题由 Lead 写），到**下一节标题之前**的最后一个字结束。
- 边界页可能被两个块共用（前一节在这一页上半部结束，后一节在这一页下半部开始）：**各译各的，不要跨界**。
- **跨页句子**：谁开始谁写完（"开始者写完"）。宁可多看一页图像，不要交半句。
- 如果实际边界与任务书不符：**不要自己改**，照任务书写，并在回报里 `BOUNDARY: ...` 说明实际接续点。

## §9 写作风格（中文学术翻译）

- 用**成熟的数学中文**：「我们有」「由此得到」「注意到」「不失一般性」「如下」。
- 第一人称复数照译（"we" → "我们"）。
- 长句可以拆分，但**不许删信息、不许加解释**（解释进批注）。
- 术语严格按 `glossary.tsv`；glossary 里没有的，第一次出现给"中文（English）"，之后只用中文，并在回报里 `TERM:` 行列出新术语（Lead 会补进 glossary）。
- 中英混排直接接排，不手动加空格（xeCJK 会处理）。数字、公式与中文之间不要多余空格。
- 强调（原文斜体）→ `\emph{}`。
- 原文的 "Theorem 1.2" 等在正文中提及 → "定理 1.2"。

## §10 交付与回报

- 文件写到 `<本地路径>`，**UTF-8 无 BOM、LF 换行**。
  用 Python 写文件：`open(path,"w",encoding="utf-8",newline="\n")`；**不要**用 PowerShell `Out-File`（带 BOM，会炸）。
- 自己先跑：
  ```
  $env:PYTHONIOENCODING='utf-8'
  python check_block.py src/bNN.tex
  ```
  必须 `OK`。
- **不要自己编译**。不要动别人的文件，不要动 main.tex / preamble.tex。
- 回报写到 `block-reports/bNN.md`，并给 Lead 发一条消息：
  ```
  DONE b07 | 原文 p.54–66 | 公式 12 条（首 3.10 尾 3.21）| 环境: 定理 3.5, 引理 3.6… | 批注 15 条 | 图: 略 1 处
  BOUNDARY: 实际接续点（若有出入）
  TERM: 新术语（每行一条：en | zh）
  ISSUES: 需要 Lead 裁决/补宏/核对的问题（每条一行）
  ERRATA: 发现的原文笔误（每条一行：p.N | 原文 | 应为 | 依据）
  DIFFICULT: 本块里跳步/难懂的推导（每条一行：p.N | 一句话说清跳了什么、需要补什么）
  ```
  **`DIFFICULT:` 行非常重要**，它是《脉络梳理》里"重点/难点标记"的原始素材，务必写全。
