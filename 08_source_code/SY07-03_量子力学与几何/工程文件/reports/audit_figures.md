# 全书插图体检报告（task-20）

> 体检对象：`src/chunks/*.tex` 中被 `\includegraphics` 引用的全部裁切插图。
> 纪律：只改 `src/figures/` 下的 png（同名覆盖），未改动任何 tex。

## 1. 概览

| 项目 | 数量 |
|---|---|
| includegraphics 引用处 | 109 |
| 唯一图文件 | 107 |
| 重裁/替换 | 13 |
| 最终仍存疑 | 6（4 张为命名页码偏差、2 张正文行判定见 §4） |

结论：**共 107 张，重裁 13 张，仍存疑 6 张**（存疑项均不影响可用性，详见 §4、§5）。

## 2. 方法

1. **边缘检测**（`work/audit/figcheck.py`）：灰度化后取最外 2 像素边框，非白（<245）比例 >0.005 记 EDGE；宽 <400px 记 NARROW；长宽比 >8 记 WIDE。结果写 `work/audit/figcheck.tsv`。
2. **重新裁切**：以原书页 PDF 为源，用 `work/audit/recrop.py <PDF页> x0,y0,x1,y1 <文件名> [dpi]`（pt 坐标，默认 300dpi，小图 600dpi），同名覆盖 `src/figures/`。
3. **碎片/漏图排查**（`work/audit/fragcheck.py`）：零均值归一化互相关（ZNCC）在页面渲染中定位每张被引图的外框，再把该页 `get_drawings()` 的图形簇（gap 8pt，簇 ≥18×12pt）与之比对；重叠面积 <60% 的簇判为「页面图形未被嵌入」。结果写 `work/audit/fragcheck.json`。
4. **混入正文行**：取每张图上下各 12% 条带，逐行统计墨迹占比与连续墨段数，成行小字（多段、低占比）连续 ≥4 行者列为候选，再人工目检。
