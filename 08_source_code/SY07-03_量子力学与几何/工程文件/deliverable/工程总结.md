# 工程总结：《量子力学与几何》中文译注本

> 本文件记录本译注工程的**做法、决策与质量数据**，供日后复核、续译或同类工程借鉴。
> 数字统计截至合书终稿（见文末「终稿数据」一节）。

## 一、工程概况

| 项目 | 内容 |
| --- | --- |
| 底本 | Si Li, *Quantum Mechanics and Geometry*, preliminary draft (updated December 2025) |
| 作者 | 李思（Si Li），清华大学丘成桐数学科学中心 |
| 来源 | 作者主页 <https://sili-math.github.io/>，讲义 PDF 直链 `/notes/Quantum_Mechanics_and_Geometry.pdf`（版本页注 "version November 2025, 3rd Update"） |
| 底本规模 | 338 页 PDF（正文 336 页 + 前言等），191 条书签，6 章 3 部分 |
| 译注本 | 书名《量子力学与几何》，中文全译 + 译注 + 术语附录 |
| 工作方式 | 1 名 Lead（体例、样板、术语、工具、终审、合书）+ 7 名译者并行分块翻译 + 独立交叉审校 |

底本不是正式出版物，而是作者为研究生课程准备的讲义草稿（前言说明由求真书院 Notes Taker Program 的课堂笔记整理而来），因此**原书本身有零星笔误与记号不一致**——这类问题一律不改数学内容，只以 `% [Tutor Note: …]` 批注形式在正文外提示。

## 三、工作流程（六步）

1. **底本固定**：下载 PDF 后写入 `00_原文/`，此后所有引用都指向该文件，不改不换。实测 `Invoke-WebRequest` 在该站会卡在 65536 字节，改用 `curl.exe -L --retry 3` 才稳定下载。
2. **结构测绘**：用 pymupdf 提取书签（191 条）与逐页文本，确定**原书页 = PDF 页 − 1** 的页映射，建立全书「部分 → 章 → 节 → 页码」地图。这一步决定了后面所有块界与页标。
3. **体例冻结**：先由 Lead 译出样板块（ch01a，原书 p.11–29），同时写出 `译者手册.md`（10 节：页映射、分块、输出骨架、编号、公式、图、铁律、批注、自检、汇报格式）与 `术语对照表.tsv`。**先定体例与术语，再并行开工**，否则多块文风术语必然打架。
4. **分块并行**：按章切成 17 块（每块 15–30 页），7 名译者各领 1–3 块，块界一律落在自然段处并写块界注释。每块译完自检（lint + crosscheck + 单块编译），写 `reports/` 报告，`send_message` 报 Lead。
5. **验收与交叉复核**：Lead 逐块用统一脚本验收（见第五节），并对有疑点的块抽样对照页图人工核对；随后安排**另一名译者独立复核**已交稿块（复核者与译者不同人）。
6. **合书**：整书三过 xelatex → 检查 overfull/undefref/缺字 → 生成术语附录 → 全书通读校对 → 出交付 PDF 与配套文档。

## 四、关键技术决策

### 4.1 编排

- **公式不编号**：底本全篇公式无编号，只有极少数手标 `(*)`、`(**)`，故一律用 `\[…\]`/`equation*`，手标处用 `\tag{$*$}` 原样保留。好处是与底本一致，也不产生"式 (3.17) 在下一节"这类交叉引用负担。
- **陈述环境手工编号**：底本在同一节内用**单一计数器**（定义 1.1.1、例 1.1.2、定义 1.1.5…），类型不同但号连续。自动计数器无法复现，故 `definition{1.1.1}` 这样手工录入，编号照抄原文——这也使交叉引用（"由命题 4.2.21"）可直接写成文本。
- **标题不写编号**：`\chapter{}`/`\section{}` 交给 LaTeX 自动编号，标题内不出现 "1.8.2"；草稿单块编译时因无章计数器会显示 "0.1"，属正常现象。
- **页标**：每页正文前写 `% [原文 p.N]`（N 为原书页号 = PDF 页 − 1），使任何一句都可回溯原文。终审用脚本检查页标连续性与越界。
- **图分两类**：有彩色曲线、多支结构、大量数学标签的图，用 `figtool` 从 PDF 矢量层裁切为 PNG（300 dpi）；只有几何线条 + 英文词标签的简单示意图，允许 TikZ 按原图重绘并把图内标注译为中文。两类都在图后注明来源页。

### 4.2 排版

- XeLaTeX + ctexbook，b5paper，`\ctexset` 章名为「第 N 章」。
- 中文正文用宋体、西文用 Times 系列，术语首次出现给「中文（English）」。
- 全书宏统一：`\R \C \bra \ket \braket \mel \Tr \Ker \dim …`；`\rd \ii \ee \hs` 展开为**斜体** d、i、e 与 `\hbar`（与底本一致）；未定义的算子名用 `\operatorname{}`。
- 附录术语表由 `make_terms_appendix.py` 从 tsv 自动生成（9 组、双栏、`\filbreak` 防孤行）。

### 4.3 中文文风

`译者手册.md` §6 十条铁律中最影响成品的几条：不省译（底本的铺垫句、重复句、口语化说明全部译出）；不擅自"顺"句子结构（数学条件句的从属关系必须保留）；禁翻译腔（"被…所""进行…的""对于…而言"全为零）；长句拆到 60–70 汉字以内；全角标点，汉字与西文之间半角空格；公式变量与专名不译。

## 五、质量保障

### 5.1 工具链（`tools/`）

| 脚本 | 作用 |
| --- | --- |
| `extract_text.py` | 按块抽取底本文本，插入 `===== PDF PAGE n (原书页 n−1) =====` 标记 |
| `render_pages.py` | 全 338 页渲染 150 dpi PNG，作为公式核对与裁图基准 |
| `figtool.py` | `auto/grid/crop/show`：按矢量绘图簇自动裁图、给页面叠 10% 网格辅助手裁 |
| `lint.py` | 逐块检查：UTF-8 合法性、页标连续性、`\section`↔`\takeaway` 配对、章首/章末结构、陈述编号、禁用译法、翻译腔、半角标点、空节、TODO 残留 |
| `crosscheck.py` | 原文 vs 译文机械核对：行首陈述编号逐一比对、节标题数、页标记缺口、疑似未译英文行 |
| `release_check.py` | 交付前总检五步：页标记覆盖、全块 lint、全块 crosscheck、图片引用存在性、未引用图清单 |
| `make_terms_appendix.py` | 术语表 → LaTeX 附录 |
| `collect_notes.py` | 汇总全书 `% [Tutor Note: …]` → `译注汇总.md` |
| `merge_terms.py` | 合并各块术语增补进 `术语对照表.tsv` |
| `build.ps1` | 整书三过 / 单块草稿两过编译，解析日志统计 `file:line/fatal/missingchar/overfull/undefref`，全零才打 `BUILD OK` |

### 5.2 验收口径（每块必须同时满足）

1. `lint.py` 问题 0 条（提示项允许，须说明原因，如"本节跨块故 takeaway 在邻块"）；
2. `crosscheck.py` 「结构与编号一致」；
3. `build.ps1 -Chunk` 的 `LOG file:line=0 fatal=0 missingchar=0 overfull=0 undefref=0`；
4. 页标记覆盖该块页段，无缺口、无越界；
5. 有图块已核对引用图存在且图内无未译英文；
6. `reports/<块>.md` 写清覆盖范围、陈述编号表、公式核对要点、图处理、存疑处。

### 5.3 实际遇到的问题与处置

| 问题 | 现象 | 处置 |
| --- | --- | --- |
| 中文路径编译 | 旧工程为规避风险建过 ASCII 镜像目录 | 实测 XeLaTeX + ctexbook 可直接在中文路径编译，省掉镜像层 |
| 圈号缺字 | ①②③ 被排成空白（`Missing character`） | 根因是 xeCJK 默认把 U+2460–U+2473 归为非 CJK、落到 Latin 字体；加 `\xeCJKDeclareCharClass{CJK}{"2460 -> "2473}` 后正常，全书改用 Unicode 圈号 |
| 多字节字符损坏 | 某块用 `Get-Content -Raw \| -replace \| Set-Content` 批量改错字，101 个汉字被截成 `?` | 整块重写；规定正文只能用 write/edit 落盘，`lint.py` 增加 UTF-8/U+FFFD 检测 |
| 术语附录溢出 | 每组包 `minipage` 后该组无法跨页，出现 Overfull vbox | 去掉 minipage，让 `multicols` 在页级流动 |
| 宏风格分裂 | 一半块用正体 d/i/e，一半用斜体 | 以底本为准，改 `\rd/\ii/\ee` 定义一处解决 12 块 |
| 块界重复/漏句 | 相邻块各译半句，或同一句出现两次 | 块界一律加注释；验收时专项比对块首块尾与邻块 |
| 跨块小节缺 takeaway | §5.2 跨 ch05a/ch05b，两边都以为对方写 | 验收时逐一核对每个 `\section` 是否恰有归属自己的 takeaway |
| 越权删除 | 一名译者清理 `work/review/chk_*.png` 时删掉他人核对图 | 只是临时图，`src/figures` 未受影响；此后明确"不删他人目录文件" |

## 六、术语

`术语对照表.tsv` 是唯一依据，格式 `英文<TAB>中文<TAB>处理(译/保留)<TAB>备注`，分九组：量子力学基本概念、希尔伯特空间与算子、路径积分、伪微分算子与量子化、几何量子化、形变量子化、数学通用词、人名、各章译名增补。

几条须全书写死的选择：

- operator = **算子**（不用"算符"）；eigenvalue = **本征值**；eigenstate = **本征态**；eigenfunction = **本征函数**；characteristic function 在集合语境译**示性**、在算子语境译**本征**。
- symbol（伪微分算子语境）= **象征**；principal symbol = **主象征**。
- WKB、Moyal、metaplectic、Levi-Civita 等保留拉丁原文；人名按通行译名（外尔、维格纳、凯勒、托普利茨、弗雷德霍姆、施瓦茨、赫尔曼德、孔采维奇、费多谢夫、别列津、格拉森伯格、马尔可夫…）。

## 九、可改进处

- 校对粒度：逐块"译者自检 + 他人复核"能抓住绝大多数硬错误，但中文行文的润色仍集中在上层；若有更多人力，可在合书后做一次全文朗读式通读。
- 图：本工程以裁切位图为主，重绘为辅。图多且复杂的书（如本底本第 2、5 章的相空间图）若能全量 TikZ 重绘，印刷质量与检索性会更好，但成本约为翻译本身的两倍。
- 术语：术语表在开工时冻结、中途合并两轮增补，代价是少数早期块的术语需在复核时回改；更稳妥的做法是译完前两章后再冻结。
