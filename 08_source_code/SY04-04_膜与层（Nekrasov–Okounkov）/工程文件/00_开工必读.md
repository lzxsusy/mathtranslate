# 开工必读（SY04-04）

> 给下一个接手这个工程的人（或 agent）。**先读完这一页再动手**，比读 BRIEF 快。

## 一分钟版

- 底本：Nekrasov–Okounkov, *Membranes and Sheaves*（arXiv:1404.2323v1，2014，77 页正文），全文已译，65 页。
- 页映射：节级对照表在 `BRIEF.md`「结构页表」；**页码一律写「原文 pN / 译本 pM」**，两者差 8–11 页不等（§1–§2 差 0–2 页，§8–§9 差 10–11 页）。
- 译稿：`源码/MDT_zh.tex`（单文件，3,114 行），图在 `源码/figures/`。
- 编译：进 `源码/`，`xelatex MDT_zh.tex` ×2；基线 **65 页 / 0 error / 0 缺字 / 0 未定义引用**。
- 校订记录：`工程文件/校对报告.md`（20 处改动 + 3 类编译修复，含底本行号）；术语归档：`资料卡/04`。

## 工序（按顺序，不跳步）

1. **编译基线**：先跑一遍 `xelatex`，确认还是 65 页、0 error，再动任何字。
2. **改哪里先回源**：任何「原文是 X」的判断，必须先回底本 `MDT_original.tex`（仓外自备）找到原句行号，写进报告再改。
3. **公式编号不许变**：`\begin{equation}` 67 个、`\label` 129 个、`\eqref` 95 个，改完数量必须不变。
4. **术语回扫**：`grep -c` 每个术语的旧译（「扭结」「外部代数」「最小分解」「环面图」「唯一的极点」）必须为 0。
5. **落地回查**：改完 `grep` 报告里「改为」列的字串，确认命中；再重编译，比对页数。
6. **资料卡同步**：改动条数变了要同时改 `工程文件/校对报告.md` 与 `资料卡/04` 的统计行（当前 **20 处文字 / 19 行改动**）。

## 已知坑（都踩过）

- **原 zip 里的 PDF 与源码对不上**：源码在当前 LaTeX2e（2026 版）下编不过。三类根因：上下标后跟裸字体宏、
  `tikzcd` 箭头指向空网格、`\mathbf{\Phi}` 无字形。修法写在 `校对报告.md` §3，别把花括号又删了。
- **`\subsubsection{\ }` 的空标题**会印出 2.3.4、5.5.7 这类孤立编号——底本原样，不是排版事故。
- **页码别用 PDF 页数猜**：两版节级目录已抽出，用 `BRIEF.md` 的表；陈述页码见同页「编号陈述与页码」。
- **`source/` 与原文 PDF 不进仓**（L4）：需要时从 arXiv 取 1404.2323v1。
- **仓库工作区常有其他会话的脏改动**：只 `git add` 本工程路径，不要 `git add -A`。
- PowerShell 无 heredoc；Python 跑前 `export PYTHONIOENCODING=utf-8`。
