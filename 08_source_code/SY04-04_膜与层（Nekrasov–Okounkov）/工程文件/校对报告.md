## 1. 材料与流程

1. **通读定调**：中英逐节对齐成 10 个对照文件（`校对/00_前言摘要.txt` … `09_附录.txt`，按 `[Z块号]`/`[E块号]` 交替排版），先确认九节标题一一对应、图表/公式环境数目一致。
2. **机械审计**：`\label`/`\ref`/`\eqref`/`\footnote`/`equation`/`\cite`/`\bibitem` 计数与键集比对；显示公式逐块 diff；环境配对与花括号平衡检查。
3. **五路并行精读**：按节分组（导论+猜想轮廓 / DT 被积函数+膜指标 / 例子 / 平方根+精化 / 指标顶点+附录），各交出 P1/P2 候选表。
4. **逐条回源核验**：每条候选都回到 底本 `MDT_original.tex`（不入仓） 找原句（行号见下表），确认后才落地；可疑但原文无据的一律不采纳。
5. **英文残片扫描**：剥掉数学环境与命令后，对含中文的行做拉丁词频统计；除专名/术语外，仅 "The / of / index / M-theory" 一词组（L240 引用的报告标题 *The index of M-theory*）与 "section"（L116 `\newtheorem{Lemma}{引理}[section]` 的计数器名）属正常，无整句未译。
6. **落地回查**：「改为」列逐条 `grep` 回 `源码/MDT_zh.tex` 确认命中，再连跑 `xelatex` 两遍。

## 3. 编译修复记录（本次新发现，必须记档）

原 `MDT_zh.pdf`（65 页）与当前源码**不可能**由同一份 `.tex` 编译得到：本机 LaTeX2e <2026-11-01> + tikz-cd 对两类写法直接报错。已修，语义不变：

| # | 位置 | 现象 | 修法 |
|---|---|---|---|
| C1 | 全文 158 处 | 数学上下标后紧跟裸文本字体命令（`ds_\textup{TN}^2`、`\R^1_\textup{time}`、`\tO_\MM`）→ `! Missing { inserted. <to be read again> \__kernel_tl_set:Nx` | 正则把 `[_^]` 后单个宏包成花括号；`ds_\textup{TN}^2` 先改 `ds_{\textup{TN}}^2`（3 处） |
| C2 | 第 526–533 行交换图 | `tikzcd` 箭头指向不存在的空格子 → `Package pgf Error: No shape named tikz@f@1-3-2` | 改成三行网格布局；箭头标签 `"\displaystyle{\pi_\MM}"` → `"\displaystyle{\pi_{\MM}}"`（引号标签内裸宏会被 x-expand） |
| C3 | 前导区 `\newcommand{\bPhi}` | `\mathbf{\Phi}` 在 TU 编码下无希腊大写字形 → 6 条 `Missing character: There is no ^^H in font [lmromandemi10-regular]` | 改 `\boldsymbol{\Phi}`（amsmath 已加载） |

> 注：C3 的同源现象还有「数学模式下直接写 `\"a`（如 `$K\"ahler$`）」也会报 `^^H`；正文无此写法，`\textup{K\"ahler}` 正常，故未改。

编译结果：65 页，`err=0 / miss=0 / undef=0`，仅 2 处 Overfull（2.28pt、0.50pt，肉眼不可见，不动）。
