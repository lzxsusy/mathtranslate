## 三、术语定调建议（供后续译本统一）

1. **proper**：建议继续用「固有」，但在首次出现处保留 `proper` 夹注（现状已如此）；若日后与其他译本合刊，统一到「紧合」需全文替换 5 处。
2. **resolution / decomposition**：已分开（解消／分解），这是一个真实的歧义源，建议写入译名表长期保留。
3. **toric chart / toric diagram**：已分开（环面坐标卡／环面图）；遇到 toric geometry 的其他对象（toric variety=环面簇）时按「环面 X」模式延续。
4. **不动点轨迹**：凡 fixed locus 一律用「不动点轨迹」；单点情形才说「不动点」。
