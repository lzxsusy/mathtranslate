## 一句话

M-理论中 M2-膜的指标（Chow 簇上的等变 K-理论类）应当等于 Calabi-Yau 三流形 $X$ 的 Donaldson-Thomas 配分函数；本文给出这一对应的精确猜想（猜想 1），构造被积函数（修正的虚拟结构层与相互作用项 $\boldsymbol\Phi$），并用精化顶点公式（定理 2）等结构性定理把两个理论对接起来。

## 三条主线

1. **猜想 1：Chow 簇上的 K-理论等式**（§2，原 p15–p18 / 译 p12–p14）
   $$\mathbf S_{\mathrm{Chow}}\,\pi_{\mathcal M,*}\,\iota_*^{-1}\,\widetilde{\mathcal O}_{\mathcal M}
   \;=\;\pi_{\mathrm{PT},*}\bigl(\widetilde{\mathcal O}_{\mathrm{PT}}\otimes\boldsymbol\Phi\bigr)$$
   在 $\mathbb T^{K}(Z)\times G_{\boldsymbol q}$-等变 K-理论中成立。左边是 M2-膜指标，右边是 DT/PT 侧的配分函数，$\boldsymbol\Phi$（§3.2，原 p28 / 译 p23）描述 $X$ 各分支在 $Z$ 内的相互作用。
2. **被积函数与虚拟结构层**（§3–§4，原 p24–p36 / 译 p20–p29）：DT 模空间的修正虚拟结构层 $\widetilde{\mathcal O}_{\mathrm{DT}}$、M2-膜模空间 $\mathcal M(Z)$ 的紧化（多重曲线），以及两者之间的形变论。
3. **精化与顶点**（§7–§8，原 p54–p67 / 译 p45–p56）：把 $\mathrm{U}(1)$ 作用换成缩放 3-形式的 $\mathbb G_\kappa=G_{\boldsymbol\kappa}$，得 $\kappa$-平凡环面上的局部化公式与刚性（§7.3），最终证明指标顶点在多斜率极限下退化为 Iqbal–Kozcaz–Vafa 的精化顶点（定理 2）。

## 已证 vs 猜想

- **猜想**：猜想 1（主猜想）、猜想 2（零次数 DT 计数与 11 维超引力场的比较，原 p23 / 译 p18）。
- **已证**：定理 1（$\widetilde{\mathcal O}_{\mathrm{PT}}$ 的典范 $G_\kappa$-等变结构与整性，原 p55 / 译 p46）、定理 2（精化顶点公式，原 p67 / 译 p55）；§6 的平方根存在性（引理 6.1、命题 6.2、6.4、6.5、6.6）、§7 的局部化与刚性（命题 7.1、7.3、7.4，引理 7.2）、附录 A 的平衡引理证明（引理 8.2 + A.1 + A.2）均带完整证明。
- **例子即验证**：§5 的五组例子（约化局部曲线、双曲线、光滑曲线单次相互作用、高秩 DT 计数、构造高秩 DT 理论）用低阶情形检验猜想 1，是全篇最可直接核对的部分。
