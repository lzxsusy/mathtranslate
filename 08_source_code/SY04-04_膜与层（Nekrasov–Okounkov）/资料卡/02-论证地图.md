## 三、主要依赖链（证明在哪）

1. **猜想 1（主猜想）**：无证明，是全文假设。§5 用五个例子做低阶检验，§5.5 的命题 5.1 在猜想 1 下把它推到高秩。
2. **定理 1（精化的存在性 + 整性）** ← §7.1 的等变结构构造；依赖 §3 的修正虚拟结构层与 §6 的平方根（半整权）。
3. **命题 7.1 → 命题 7.3 → 命题 7.4（局部化 → 刚性）** ← 引理 7.2（$\det\mathcal N_+$ 与腔室无关、$\det\mathcal N=(\det\mathcal N_+)^2$）；刚性用 Witten 的 Morse 理论（`WittenMorse`）。
4. **引理 8.1 → 定理 2（顶点公式）** ← 环面 CY 三流形上的组合计算；定理 2 的收尾是「检验定义 (XiZ) 退化为公式 (Xip)」。
5. **引理 8.2（平衡引理）→ 附录 A** ← 引理 A.1 + 引理 A.2；平衡引理是定理 2 证明中的关键一步，把几何侧法丛的秩与顶点侧 $\Xi_Z$ 的秩对上。
6. **§6 的平方根链**：引理 6.1（一般框架）→ 命题 6.2（$\mathbf L_{12}\cong\mathbf L_{21}$）← 引理 6.3（Euler 型不变性）→ 命题 6.4（DT 侧平方根）；命题 6.5 + 6.6 给 M-理论侧的模 2 判据。

## 四、全文的三个「技术枢轴」

1. **虚拟结构层修正**（§3.1，定义 1）：不修正则 $\chi(\mathcal M,\mathcal O^{\mathrm{vir}})$ 不是整数/不是半整幂，K-理论陈述无法与 DT 侧对齐。
2. **相互作用项 $\boldsymbol\Phi$**（§3.2）：没有它，猜想 1 的右端只数单分支贡献；$\boldsymbol\Phi$ 显式依赖 $Q^{[C_i]}$（被 $\pi_{\mathcal M}$ 丢掉的 $\Cq$-不变曲线），把多分支相互作用补回来。
3. **平方根 + 半整权**（§6–§7）：$\mathcal K^{\mathrm{vir}}$ 的平方根使 $G_\kappa$ 作用可按 $\boldsymbol\kappa^{1/2}$ 分解（命题 7.4 的刚性），从而不动点的贡献可逐项算成顶点函数（定理 2）。

## 五、贯通阅读路线

- **想抓「对应关系为什么可信」**：§1.1 → §2.3（猜想 1）→ §5.1–§5.3（三个几何例子）。
- **想算一个具体例子**：§8.1（环面 CY 三流形上的 $T$-局部化）→ 引理 8.1 → 定理 2 → 附录 A 的平衡引理。
- **想理解精化**：§7.1（$\kappa$ 的作用）→ §6.4（平方根为何需要）→ §7.3（刚性）→ §8.3（顶点）。
- **想找与 DT/PT 文献的接点**：§2.3 的 K-理论翻译 + §3.1 的虚拟结构层修正，对照 `PT`、`PT2`、`Thom`、`BBS` 的经典定义。

## 六、地图的边界（诚实说明）

- 本文是「猜想 + 部分定理」型论文，主线（猜想 1、2）**没有证明**；§5 的例子是验证而非论证。
- §4（膜的指标）主要建立模空间与形变框架，其结论服务于 §3/§5 的陈述，本身不含独立的大定理。
- §2.4（11 维超引力场）与 §8.1（环面几何）技术密度高但与主线的连接是启发式的，读第一遍可跳过，第二遍再补。
