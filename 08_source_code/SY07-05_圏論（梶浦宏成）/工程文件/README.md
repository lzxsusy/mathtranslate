## 体例要点

1. **公式与定理编号照抄原书**（式 (3.8)、定義 3.29 等），便于与底本逐条对照；原书大量不编号的公式保持不编号。
2. **作者正誤表（2014-05-20 版 + 八面体公理专项）全部落实**：凡正誤表涉及的页面，正文按订正后的内容翻译，
   并在原处以 `% [Tutor Note: 底本 p.X 原印 …；据作者正誤表订正为 …。]` 记录底本原印内容。
   正誤表未涉及但可判定的笔误，一律「照印 + 批注」，不擅改正文（见 STYLE_GUIDE §9）。
3. **术语**：中文有稳定通行译名者用中文（范畴、函子、态射、模、复形、正合列、投射模、内射模……）；
   无通行译名者保留英文（operad、DG、A∞、Fukaya）；人名保留拉丁原名。本书特有用法：「移入加群」＝内射模（非「入射」）。
4. **图表**：交换图表、箭图、八面体图、金字塔图全部 TikZ 重画，节点标签译为中文，箭向与虚线照原图。
5. 排版：ctexbook（LuaLaTeX），A4，11pt；定理环境手工编号（`definition{3.29}` 等）。
