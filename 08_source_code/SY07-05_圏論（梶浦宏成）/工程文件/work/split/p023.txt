2.2.2
準同型写像
定義2.14
X, Y を加法群とする．（集合の間の）写像f : X →Y は，
• f(0X) = 0Y ，
• 任意のx, x′ ∈X についてf(x + x′) = f(x) + f(x′)
を満たすとき，加法群の間の準同型写像(homomorphism) という．
加法群X, Y に対して，加法群の間の準同型写像の成す集合を
Hom(X, Y ) := {f : X →Y }
(2.2)
と表す．
補題2.15
Hom(X, Y ) も加法群の構造を持つ．
証明
f, g ∈Hom(X, Y ) に対し，f + g ∈Hom(X, Y ) を(f + g)(x) :=
f(x) + g(x) ∈Y , x ∈X によって定めるとこの演算によりHom(X, Y ) が加法
群を成すことが確認できる．特に，すべてのX の元を0Y ∈Y にうつす準同型
写像0XY ∈Hom(X, Y ) がHom(X, Y ) のゼロ元となる．
□
定義2.16
加法群X とY が同型(isomorphic) であるとは，準同型写像
f : X →Y , g : Y →X であって
g ◦f = idX,
f ◦g = idY
を満たすものが存在するときをいう．このとき，f, g を同型写像(isomorphism)
と呼ぶ．
