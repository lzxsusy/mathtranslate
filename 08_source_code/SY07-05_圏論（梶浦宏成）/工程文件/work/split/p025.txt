実際X/Y は加法群の構造を持つ．まずX/Y の元はX の元x によって代表
されるが，任意のy ∈Y に対しx ∼x + y である．このとき，X の演算として
−(x+y) = −x−y ∼−x であるので，X/Y において逆元がy ∈Y の任意性によ
らずに定まっている．同様に，x, x′ ∈X をとったとき，任意のy, y′ ∈Y に対し
x ∼x+y, x′ ∼x′+y′ であるが，(x+y)+(x′+y′) = (x+x′)+(y+y′) ∼(x+x′)
であるのでy, y′ ∈Y の取り方によらずにX/Y 上の加法がX 上の加法から誘
導される．
上のように，x ∈X で代表されるX/Y の元を[x] と書くこともある．一方，
上のような演算を確認する場合，「任意のy ∈Y に対してx + y を考える」と
いう意味で便宜上[x] = x + Y と書くこともあり，以下でもその表記を使う．
2.2.4
部分環，イデアルと剰余環
部分加法群の定義（定義2.20）の類推から，部分環の定義は容易に見当がつ
くであろう．
定義2.22
R を環とする．部分加法群R′ ⊂R は，任意のa, b ∈R′ について
• 1R ∈R′，
• a · b ∈R′，
を満たすとき部分環(sub-ring) といわれる．
一般に，環R の部分環R′ ⊂R による剰余加法群R/R′ は環になるわけではな
い．環R に対し，部分加法群R′ ⊂R を考える．このとき，剰余加法群R/R′
にR から誘導される積が入るためにはa, b ∈R に対して
(a + R′) · (b + R′) = a · b + R′ · b + a · R′ + R′ · R′
より，R′ · R′ ⊂R′ に加えてR′ · b ⊂R′, a · R′ ⊂R′ が成り立てば
(a + R′) · (b + R′) = a · b + R′ が満たされることがわかる．これらの条件
を満たすR′ としてイデアルと呼ばれるものが定義される．ただし1R ∈R′ で
あることは条件に入れない．
定義2.23
環R の部分加法群I ⊂R が以下の性質を満たすとき，I をR のイ
デアル(ideal) と呼ぶ∗4．
(l) a ∈R, x ∈I に対してa · x ∈I，
(r) x ∈I, b ∈R に対してx · b ∈I．
1R ∈I とすると，例えば1 つ目の条件においてb = 1R とすることによりすべ
ての元a ∈R はa ∈I となってしまう．つまりこのときI = R となる．同様
にしてある可逆元a がI に含まれているとすればa−1 · a = 1R ∈I となるので
∗4 条件(l) を満たすものを左イデアル(left ideal)，条件(r) を満たすものを右イデアル
(right ideal) といい，両方満たすものは両側イデアル(two-sided ideal) とも呼ばれる．
加群の言葉を使うと右イデアルとはR を右R 加群としてみたときの右R 部分加群のこ
とに他ならない（cf. 例2.46）．左イデアルに関しても同様である．
