2.2.1
加法群，環と体
群G とは，集合であり，結合的な積構造◦: G × G →G を持ち，特に任意
の元g ∈G に対しg ◦idG = idG ◦g = g を満たす元idG ∈G が存在し，さ
らにg ◦g−1 = g−1 ◦g = idG となる元g−1 ∈G が存在するときをいうので
あった．この積構造◦が可換であるとき，つまりg ◦g′ = g′ ◦g, g, g′ ∈G で
あるとき，群G はアーベル群，あるいは加法群，加群などと呼ばれるのであ
るが，加法群という言葉を使うことにする．加法群G において，その可換積
の構造は4 則演算の足し算+ そのものであるので，◦= + と表す．このとき，
g−1 =: −g，そしてidG =: 0G と表す方が感じがでるであろう．
定義2.6
集合R が演算+ : R × R →R を持ち，以下の性質を持つとき，R
は加法群(additive group = abelian group) であると呼ばれる．
• a, b ∈R に対し，a + b = b + a．
• a, b, c ∈R に対し，(a + b) + c = a + (b + c)．
• a ∈R に対し，a + 0R = a となる元0R ∈R が存在する．
• a ∈R に対し，a + (−a) = 0R となる元−a ∈R が存在する．
定義2.7
加法群R が演算+ : R × R →R に加え積· : R × R →R を持ち，
以下の性質を持つとき，R は環(ring) であるといわれる．
• a, b, c ∈R に対し，(a × b) × c = a × (b × c)．
• a, b, c ∈R に対し，(a +b) ×c = a ×c +b×c, c ×(a +b) = c ×a +c ×b．
• a ∈R に対し，1R × a = a × 1R = a となる1R ∈R が存在する．
特に，環R がa, b ∈R に対しa × b = b × a を満たすとき，R は可換環
(commutative ring) であるという．
以下，掛け算a × b はa · b と表すこととする．
定義2.8
環R について，元a ∈R がa · a−1 = 1R = a−1 · a となる元
a−1 ∈R を持つとき，a をR の可逆元(invertible element) と呼ぶ∗2．このと
きa−1 ∈R をa の逆元(inverse element) という．可逆元でないR の元を非
可逆元(non-invertible element) という．
定義2.9
可換環R であって，ゼロ元以外のすべての元a ∈R, a̸ = 0R が可
逆元であるものを体(ﬁeld) という．
