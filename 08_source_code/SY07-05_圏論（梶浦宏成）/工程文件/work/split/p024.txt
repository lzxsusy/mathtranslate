定義より同型写像は全単射である．逆に全単射準同型写像f : X →Y が存在
すればその集合としての逆写像g : Y →X が準同型写像となる．つまり，加法
群の間の同型写像とは全単射準同型写像のことである．
定義2.17
A, B を環とする．加法群としての準同型写像f : A →B は，さ
らに単位元と積構造を保つとき，
• f(1A) = 1B，
• 任意のa, a′ ∈A についてf(a · a′) = f(a) · f(a′)，
環準同型写像(ring homomorphism) という．
注意2.18
一般に環準同型写像の空間は加法群の構造を持たない．
定義2.19
環A とB が同型(isomorphic) であるとは，環準同型写像f : A →
B, g : B →A であって
g ◦f = idA,
f ◦g = idB
を満たすものが存在するときをいう．f, g を同型写像という．
この場合も同型写像は全単射環準同型写像のことである．
2.2.3
部分加法群と剰余加法群
環R は，積構造を忘れることによって加法群とみることができた．まず，加
法群について，部分加法群と剰余加法群を定義しよう．
定義2.20
加法群X の部分集合Y は，加法について閉じているとき，つまり
任意のy, y′ ∈Y ⊂X について
−y ∈Y,
y + y′ ∈Y
となるとき，部分加法群(additive subgroup) といわれる∗3．
ここで，y ∈Y に対して−y とは，y ∈Y ⊂X のX の中での演算であり，
−y ∈X が特にY に属するといっているのが上の1 つ目の条件である．2 つ目
の条件についても同様に，+ はX における加法である．
定義2.21
X を加法群，Y ⊂X をX の部分加群とする．X の元達の間に同
値関係（2.1 節）を，「元x, x′ ∈X に対し，x′ −x ∈Y であるときx とx′ は
同値である」と定め，このことを
x ∼x′
と表す．実際，部分加法群の定義から，この∼は同値関係（2.1 節）を定める．
X の元の，この同値関係による剰余類の成す集合のことをX/Y と書き，X の
Y による剰余加法群(factor additive group) と呼ぶ．
∗3 任意のy, y′ ∈Y に対して−y ∈Y , y + y′ ∈Y という条件は，任意のy, y′ ∈Y につい
てy −y′ ∈Y というように1 つにまとめることができる．
