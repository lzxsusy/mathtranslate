応する．これらの散乱振幅から定まる代数構造は，点付きリーマン面のモジュ
ライ空間のコンパクト化の滑層分割(stratiﬁcation) に付随した特別な性質，一
般に位相的オペラッドなどの構造に支配されている．このような意味で，弦理
論とは点付きリーマン面のモジュライ空間のコンパクト化の成すオペラッドの
表現のことである．
1.4.2
弦理論とホモトピー代数
点付きリーマン面のモジュライ空間のコンパクト化に付随するオペラッド上
の表現として得られるものはホモトピー代数と呼ばれるクラスのものである．
（ただ，ホモトピー代数という言葉の定義は正確に定まっているわけではない．）
点付きリーマン面の種類を，弦理論として閉じるように制限して考えること
ができる．例えば開弦のみの理論（境界のみに点を持つリーマン面に対応）を
考えると，2 つのリーマン面に対し，それぞれその境界上の点をとってきて互
いに適切につなぎ合わせてできるリーマン面はまた境界のみにしか点を持たな
い．同様に，閉弦のみの理論（境界を持たないリーマン面に対応）はそれら自
身で閉じている．その他のクラス分けとして，ループを含まないリーマン面と
いうものを考えることができる．リーマン面のハンドルは閉弦のループとみな
される．同様に，境界が2 つ以上あるリーマン面は開弦のループを含むとみな
される．これらのループは弦理論における（標的空間M 上の場の理論の意味
での）量子効果とみなされる．ループを含まない理論をtree の理論といい，弦
の（半）古典論を記述するものとされる．
tree の開弦の理論，すなわちリーマン面として境界に点を持つディスクのみ
を考える理論は実はA∞オペラッドを定める．実際，点付きディスクのモジュ
ライ空間のコンパクト化としてスタシェフ多面体が得られる（cf. [32]）．よっ
て，tree の開弦の理論はA∞代数を成す．同様に，tree の閉弦の理論，すな
わち点付き球面の理論には，A∞代数（＝ホモトピー結合代数）のリー環版で
あるL∞代数（＝ホモトピーリー代数）が付随する．ただし，この場合，コン
パクト化の仕方が1 通りではなく，理論（リーマン面上の場の理論）に適合し
たコンパクト化を考える必要があり，Comm∞代数と呼ばれる構造を考える
こともある．tree の開弦と閉弦の混在した系に対応するホモトピー代数として
open-closed ホモトピー代数(OCHA) がある(cf. [32])．このような代数構造
は，例えば弦の場の理論においてZwiebach によって議論されてきた．弦の場
の理論とは，その場の理論としての散乱振幅が弦理論の散乱振幅を再現するよ
うに構成されるものである．ホモトピー代数の言葉でいえば，弦理論の散乱振
幅とは弦の場の理論の定義するホモトピー代数の極小模型のことである．この
ように，ホモトピー代数は弦理論の構造を記述する自然な枠組みである．
ループを含む弦理論に対しても対応する代数構造の枠組みの候補は存在する
が，一般論としてはまだ今のところそれらを有効に応用できる段階ではない．
