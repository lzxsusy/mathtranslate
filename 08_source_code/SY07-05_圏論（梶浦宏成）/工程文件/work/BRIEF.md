## 硬性流程（每位译者）
1. 读 `work\STYLE_GUIDE.md`（**全文，必须**）→ `work\glossary.tsv`（术语冻结表）→ 本 BRIEF 中你的一段。
2. 读你的 `work\split\pNNN.txt`（NNN = **原书页**，三位补零）把握论证结构与段落（**文字层只用来定位**）。
3. **逐页看 `work\pages\pNNN.png`**（`read_image`），公式逐符号抄成 LaTeX；
   看不清就用 `work\tools\crop.py` 裁局部放大（用法见文件头；原书页 N = PDF 页 N+7）。
4. 查 `work\errata_raw.txt`（作者正誤表；页段若在其覆盖范围 p19–p188，**逐条处理**），
   公式务必回 `work\pages_errata\E01.png … E11.png` 核对。
5. 写 `src\chunks\trNN{a,b}.tex`（UTF-8 无 BOM、LF；a→b 顺序拼接）。
6. 逐项过 STYLE_GUIDE §11 自检 → `send_message` 给 `lead` 回执（格式见 §12）。

## 公式与定理编号
- 编号公式共 117 条：`work\tags.txt`（tag→页）、`work\tags_bypage.txt`（页→tags）。**你的页段内的 tag 必须全部出现且编号一致**。
- `tags` 由脚本从右页边抓取，**可能漏抓**。以页面图像为准：图像上出现的编号就是真理；
  若发现 `tags_bypage.txt` 漏了某页编号，在回执中指出。
- 定理类标题（定義/定理/命題/補題/系/例/注意/主張/演習）编号**照抄原书**，手工输入。

## 常见误判提醒
1. 文字层里 `∫`、`∏`、`∑`、希腊字母、上下标几乎必然错；**只信 `work\pages` 图像**。
2. 书里大量公式**没有编号**，不要自己加编号。
3. 交换图表在 PDF 里是细线图形（1×1 像素线段的组合），文字层抽不出结构，**必须照图用 tikzcd 重画**。
4. 「移入加群/移入的」= 内射模/injective（本书不用「入射」）；「充満」= 全（full）；「例外的対象系」= 例外对象系。
5. 原文的粗体行内小标题 → `\para{…}`（preamble 已定义）。
6. 术语先查 `glossary.tsv`；新词自己定译法后**必须回报 Lead**。
