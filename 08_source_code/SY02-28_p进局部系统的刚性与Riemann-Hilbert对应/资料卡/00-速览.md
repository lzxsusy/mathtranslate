## 一句话

$p$ 进局部系统的 de Rham 性在几何族中是局部性质；证明工具是 pro-étale 周期层上的
$p$ 进 Riemann–Hilbert 对应，以及作为其分次片的 $p$ 进 Simpson 对应。

## 论证主线（五步）

1. **约化**：用奇点消解（Bierstone–Milman）把定理 1.3 化到光滑 $X$。
2. **几何 RH**：在 $\Xk$ 上用周期层 $\mathcal O_{B_{\dR}}$ 替代 $\OX$，定义
   $\mathrm{RH}(L)=R\nu'_*(\widehat L\widehat{\otimes}_{\Qp}\mathcal O_{B_{\dR}})$；
   关键是证明它是有限生成 $\OX\widehat{\otimes}\BdR$-模。
3. **分次与 Simpson**：令 $\mathcal O_C=\gr^0\mathcal O_{B_{\dR}}$，得
   $H(L)=R\nu'_*(\widehat L\widehat{\otimes}\mathcal O_C)$ 与 Higgs 场 $\vartheta_L$；
   证明 $H$ 是到幂零 Higgs 丛的张量函子（定理 1.6 / 2.1）。
4. **算术 RH**：对 $\mathrm{RH}(L)$ 取 Galois 上同调，得 $D^i_{\dR}$；连通且一点 de Rham 时，
   $D^0_{\dR}(L)$ 带滤过并与 $L$ 的 de Rham 结构对应（定理 1.5 / 3.9）。
5. **推出刚性**：$D^0_{\dR}$ 只依赖一点处的 de Rham 性，从而所有经典点处 de Rham；
   再用数域情形与志村簇特殊点得定理 1.1、1.2。

## 关键技术点

- **pro-étale 拓扑**：$p$ 进解析拓扑（甚至平展拓扑）不够细，必须用 Scholze 的 $X_{\proet}$；
  $\nu:X_{\proet}\to X_{\text{\'et}}$ 是自然投影。
- **周期层**：$\mathcal O_{B_{\dR}}$ 带可积联络与满足 Griffiths 横截性的递减滤过；
  其零次分次片 $\mathcal O_C=\gr^0\mathcal O_{B_{\dR}}$ 承载 Higgs 场。
- **幂零性**：$L$ 定义在 $X$ 上而非 $\Xk$ 上，故 $\mathrm{RH}(L)$ 带 $\Gal(\bar k/k)$ 作用；
  这正对应 Higgs 场的幂零性，是 $p$ 进 Simpson 对应在此情形比一般情形更强的关键。
- **算术 vs 几何**：算术族（特征簇上的族）需要 Hodge–Tate 权一致有界才 de Rham；
  几何族（局部系统）无需此条件，故「惊人地刚性」。
- **反例**：晶体、半稳定版本不成立；用一族大多数纤维好归约、少数纤维无半稳定归约的阿贝尔簇，
  取 $\Qp$ 的高阶顺像即可。
