\section*{译者说明}
\addcontentsline{toc}{section}{译者说明}

\textbf{原文性质。}这是刘若川与朱歆文关于 $p$ 进局部系统刚性的一篇研究论文，2017 年发表于
\textit{Inventiones mathematicae}。全文 35 页，分四节：第 1 节陈述主要定理并交代构造思路；
第 2 节建立 $p$ 进 Simpson 对应；第 3 节构造 $p$ 进 Riemann--Hilbert 对应（先几何、后算术）；
第 4 节给出刚性定理的证明与在志村簇上的应用。文章不是综述，定义、定理、证明与构造齐备，
关键处均有实质推导，适合作为几何朗兰兹方向 $p$ 进 Hodge 理论的硬文本。

\textbf{编号约定。}原文的定理与注各自按节独立编号：定理依次为 1.1--1.6，注依次为 1.1--1.10，
公式按节编号（如 (2.1)）。译文沿用这一体制：定理环境与注环境分别计数，均按节重置。
原文中无编号的「Conjecture」在译文中亦不编号。

\textbf{译注标记。}文中「译\emph{n}」为译者所加，使用独立脚注序列，不占用作者脚注的编号。
译注只写三类内容：易错预警、原文表述的存疑之处、必要的背景提示；凡属推断而非原文依据的，
均在注中说明。

\textbf{术语约定。}p-adic local system 译「$p$ 进局部系统」，\'etale 译「平展」，
rigid analytic variety 译「刚性解析簇」，perfectoid field 译「完满域」，tilt 译「倾斜」，
Shimura variety 译「志村簇」，reflex field 译「反射域」，eigenvariety 译「特征簇」。
de Rham、Higgs、Betti、Fontaine--Mazur、Hodge--Tate、Griffiths、Riemann--Hilbert
等专名保留原文。完整对照见 \texttt{资料卡/04-术语文献勘误.md}（待建）。
