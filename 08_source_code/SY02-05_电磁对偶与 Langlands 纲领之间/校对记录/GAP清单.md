## 2. 初判 GAP 的 3 条：复核后撤销

### 2.1 ch06 (6.94) —— 撤销（原判为误报）

- **位置**：`src/chapters/ch06.tex`，(6.94)
- **原文（p.087）**：`π_* k ∈ Shv(pt/K^× = Pic D^×)`
- **原判**：左端写的是 `Shv(pt/K^×)`，而 `Pic(D^×)` 是线丛的同构类群（≅ℤ），二者不可能相等，疑为原文笔误。
- **复核结论**：**误报**。原文里 `pt/K^×` 与 `Pic D^×` 之间写的是**等号**（作者把 Picard **栈**记作 `pt/K^×`，这是全章一致的用法），且 (6.88) 明写 `Pic(D_x^×) = pt/K^×`。所谓"线丛类群"是译者的误读——`Pic` 在这里指 Picard stack，不是 `H¹(𝒪×)`。
- **处置**：GAP 注释整段替换为解释性 Tutor Note，说明 `pt/K^×` 与 `Pic D^×` 是同一个栈的两个名字。

### 2.2 ch16 p.394 「composes / decomposes」 —— 撤销（证据充分）

- **位置**：`src/chapters/ch16.tex`（原 `ch16.tex:394`）
- **原判**：原书此处写 "spectrally **composes**"，与全书 "spectrally **decomposes**" 的用法不一致，疑为笔误，但无据。
- **复核结论**：**证据充分**。全书 14 处均作 "spectrally decompose(s) / de-"（ch01:224、ch03:14/32/215/402/585、ch10:1087/1634、ch11:1209/1315、ch13:173/904、ch14:229、ch15:565），仅 ch16:514 一处作 "composes"。译文按「分解」处理**方向正确**。
- **处置**：降级为 Tutor Note，注明全书用法统计。

### 2.3 ch17 p.298 「positive half of $G(\cO)$」 —— 撤销（有上下文依据）

- **位置**：`src/chapters/ch17.tex`（原 `ch17.tex:1164`）
- **原判**：作者说某物 "$G(\cO)$ 的正半部分" 不变，但 $G(\cO)$ 并无标准的"正半部分"定义。
- **复核结论**：**有解**。(17.149) 已给出读法，且结合 Iwahori 分解 $G(\cO)=I\,B^-(\cO)$（或 $B(\cO)\,I$）可确定所谓 positive half 指 $B(\cO)$ 一侧（上三角/正 Borel 部分）。作者未定义该词，但语义唯一。
- **处置**：降级为 Tutor Note，按 (17.149) + Iwahori 分解给出读法。

## 3. 存疑未决（6 项，如实登记）

> 这些不是"读不懂"，而是**两种理解都成立**或**印本不足以判定**。不做猜测性改写，仅记录在此并附候选解释。

### 3.1 ch05 (5.102)：$\overline{K^\times}$ 还是 $\widehat{K^\times}$

- **原文**：印本作 $K^\times$ 上加横线（overline），译本作 $\widehat{K^\times}$（widehat，完备化记号）。
- **为什么存疑**：在局部域语境中，$\widehat{K^\times}$ 表示完备化，$\overline{K^\times}$ 可读作闭包或代数闭包——**两种记号在此处都讲得通**，而印本的上加符号在低分辨率下 hat / bar 难分。
- **现状**：译本按 $\widehat{}$ 处理，旧注已按此解释；未改。

### 3.2 ch12 (12.78)(12.82)：右端靶对象 $\R$ 与原书印的 `#`

- **原文**：原书这两式的靶对象处印作 `#`（占位符，疑为编译残留）。
- **为什么存疑**：层侧系数域在几何 Langlands 中通常是 $\overline{\Q}_\ell$，而译本写 $\R$。`#` 究竟是 $\R$ 的排版事故、还是 $\Q_\ell$ 的丢失，**无法从上下文唯一确定**。
- **现状**：译本保留 $\R$ 并加注说明原书印作 `#`。

### 3.3 ch15 (15.6)(15.7)：$\hbar$ 还是 $h$

- **原文**：页面图 (15.6)(15.7) 印的符号形似 $\hbar$（h 带横杠）；`pdftotext` 文本层只留 `h`。
- **为什么存疑**：若为 $\hbar$（普朗克常数），则形变量子化参数的正确记号应是 $\hbar$，译本 8 处作 $h$ 皆错；若作者本意就是 $h$（课程笔记常见简写），则译本正确。**印本分辨率不足以 100% 判定**，且改动牵动 8 处正文 + 1 条注。
- **现状**：**未改**，登记为存疑。建议与作者确认后一次性统一。

### 3.4 ch04 (4.56)：$L^2(\mathrm{Maps}(S^1,\cdot))$ 的括号

- **原文**：印本为圆括号 `L²(Maps(S¹, …))`。
- **为什么存疑**：译本原用双重尖括号 `⟨⟨ ⟩⟩`（作者在别处用 $\langle\langle\cdot\rangle\rangle$ 表示"带某种结构的函数空间"）。复核确认此处印本是**圆括号**，已改回；但作者在全书是否一致地使用两种记号，**没有系统统计**，故列此备查。
- **现状**：已改为圆括号，并在旧注后追加「补记（校订）」更正原注的错误说法。

### 3.5 ch03 (3.45)(3.43)(3.53)(3.54)：花括号/上标残缺

- **原文**：这几式在印本上有花括号缺失、上标位置异常。
- **为什么存疑**：**能看出是排版事故**（如 (3.45) 的 `\left\{` 无对应 `\right\}`），但正确写法需从上下文重构，重构方式不唯一。
- **现状**：照原文保留，未"修好"，仅有 P3 记录。

### 3.6 ch13 (13.41)(13.90)(13.91)(13.21)：下标/指标缺失

- **原文**：(13.41) 的 $\bigotimes$ 无下标（按 (13.39) 应为 $\bigotimes'_{\mathfrak p\notin S}$）；(13.90)(13.91) 缺指标；(13.21) 的 $\prod_{x\in S}$ 与上下文矛盾（应为 $x\notin S$）。
- **为什么存疑**：四处都能从上下文推出**最可能**的写法，但作者是否另有约定无法确认。
- **现状**：照原文 + 加注说明（(13.41) 已加注；其余保留原文）。
