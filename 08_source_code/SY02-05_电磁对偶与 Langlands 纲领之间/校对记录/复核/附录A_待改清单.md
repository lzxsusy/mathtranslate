### A1 · `src/appendix_notes.tex:204` · A 类 · 严重度：中

- **现文锚**：`是作者留的占位符`（「(4.13)、(4.14) 右端的 “\#” 是作者留的占位符……」一段）
- **问题**：前半句「原书从未给出具体数值」**正确**（原书 p.46 只写 "for some scalar #"）；末句「这说明这里的 # 实际是与单位制约定有关的常数（例如 4π）」把注者的单位制换算当成原书结论——原书既未给 # 的值，也未声明用哪种单位制。这是任务书点名的「把推测写成事实」。
- **建议改为**（整段替换）：
> (4.13)、(4.14) 右端的 “\#” 是作者留的占位符，原书从未给出它的具体数值，也未指定单位制。它只能由所选单位制与量子化的归一化共同决定：例如在 Gauss 制下 b_Σ=(1/2πi)∫_ΣF 与 4πQ_{B,Σ} 之间正好差一个 4π 因子，但这只是把 # 与 4π 联系起来的**一种**约定，原书并未采用或声明任何一种；因此不能断言 # 就是 4π，阅读时把它当作待定的单位制常数即可。
- **依据**：原书 p.46 文本 `for some scalar #`，全段无 4π；`pages/p-046.png` 同。

### A2 · `:248` · A 类 · 严重度：高

- **现文锚**：`B 记号很`（「(4.43) 中出现的 “BH1(M,Z)” 在书中没有定义，B 记号很可能是笔误……」）
- **问题**：断言 B 记号「很可能是笔误或作者自己的速记」。原书 p.50 印 `T = flat connections ≃ H¹(M,R/Z=U(1)) ≃ BH¹(M,Z) → C_{M³}`；`B` 是**分类空间**（全书 `BG` 通用），H¹(M,Z)≅Z^b 为离散群时 `B H¹(M,Z) = K(Z^b,1) ≅ (S¹)^b ≅ T`，公式自洽。注文末尾关于「U(1) 取离散拓扑」的旁注本身不误，但与「B 是笔误」的结论无关，不能拿来支撑它。
- **建议改为**（整段替换）：
> (4.43) 中的 “BH¹(M,Z)” 是分类空间记号：B 作用于离散群 H¹(M,Z)≅Z^b，得到 K(Z^b,1)≅(S¹)^b≅T，正是式中的环面——所以它不是笔误，也不是作者私人的速记（全书 BG 均为此义）。等价地 T≃Hom(H₁(M),R/Z)≅H¹(M,Z)⊗_Z R/Z（后一步对有限生成 H₁ 成立）。若把 U(1) 取离散拓扑，则 Hom(H₁(M),U(1)) 变成离散群、不再是环面，这才是拓扑约定真正会影响的地方。
- **依据**：`en/ch04_en.txt` 中 (4.43) 原文；`src/chapters/ch04.tex` 同式；`BG` 在全书 ch05/ch06/ch09 的大量用法。
