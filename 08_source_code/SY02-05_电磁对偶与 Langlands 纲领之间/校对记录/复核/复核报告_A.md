## §2 逐条异议清单

### A. ch06:735–739 —— **注释失实（严重，误报 GAP，建议撤回）**

- **判断**：注释失实。新增的 `% [GAP: ...]` 把一个**不存在**的原文错误写成结论，且理由建立在误读上。
- **注释原文**（`src/chapters/ch06.tex:735-739`）：
  > `(6.94) 右端印作 Shv(pt/K^×)=Pic(D^×)，但按本章 (6.37)，Shv(pt/C^×) 是 Rep(C^×)，故左端应是 K^× 的表示范畴 Rep(K^×)；而 Pic(D^×) 是线丛的同构类群（≅Z），二者并不相等。…故照印；读者宜按紧随其后的 (6.100) Rep(K^×)=QC(Loc₁C) 来理解。`
- **证据（原文页 + 引文）**：
  1. 印本 p.087（`en/ch06_en.txt:699`）作 `π_*k ∈ Shv( pt/K^× (= Pic D^×) )`——花括号把 **pt/K^× 与 Pic D^× 直接等号相连**，即作者的意思是「pt/K^× 这个栈就是 D^× 上丛的 Picard 栈」。不是「Shv(...) 等于一个群」。
  2. 同章 (6.88)（印本 p.086；`src/chapters/ch06.tex` 的 6.88 阵列）明写 `Pic(D_x^×) = pt/K^×`。**书中 Pic(D^×) 自始至终指 Picard 栈 pt/K^×**，`≅Z` 的是同构类集合 `|Pic|`，不是作者写的 `Pic(D^×)`。
  3. 紧接 (6.94) 的原文是 `i.e. a representation of K^×`（`en/ch06_en.txt:701`）——作者自己就说这个层对应 K^× 的表示，与左端 `Shv(pt/K^×)` 完全自洽。
  4. (6.100) `Rep(K^×)=QC(Loc₁C)` 确实存在（`ch06.tex:776`），但它恰恰**支持**原文无错，而不是支持 GAP。
- **建议处理**：撤回该 GAP 注。若想保留说明价值，改写为一句事实性补注：「`Pic(D^×)` 在此指 Picard 栈 `pt/K^×`（见 (6.88)），非同构类群 `|Pic|≅Z`」，来源标 `[译者按（无外部依据）：依据本章 (6.88)]`。**这是本次十条改动里唯一必须回滚的一条。**

### B. ch01:215 —— 注释失实（中，位置说反且与同句自相矛盾）

- **判断**：注释失实（轻度但明确）。译文补 `0` 是对的，注把「缺哪一位」说反。
- **注释原文**（`src/chapters/ch01.tex:215`）：
  > `(1.16) 的印刷原图（p.012，即印刷页 11）上矩阵第二行只印出一个 $*$，$d$ 位置的元素缺失。标准定义取 $c\equiv 0\pmod N$，即 Γ₀(N)={… c≡0 …}`
- **证据（p.012，400 dpi 目视，裁图 `rev_crops/mat116b.png`）**：印本 (1.16) 右矩阵为
  row1 = `*  *`，row2 = **空  `*`**（第二行的 `*` 正对 `d` 列）。
  即 **`d` 位置的 `*` 印着，缺的是 `c` 位置（该处应填 0）**。注释说「$d$ 位置的元素缺失」与图不符；而同一句紧接着又说「标准定义取 c≡0」——自相矛盾（若 d 缺、c 有星号，就不可能 c≡0）。
- **建议处理**：改成「矩阵第二行 c 位置留白（标准定义该处为 0，即 c≡0 mod N），d 位印有 ∗；译文据定义补出 0，与印刷本此处的留白略有出入」。一句即可，无需动正文。

### C. ch14:36–41 —— 注释不严谨（中：「C^* 与 C_* 指同一链复形」是错的，且与注自身的论证矛盾）

- **判断**：注释失实（不严谨）。结论方向对（译文照原文写法），但**关键一句在数学上站不住**。
- **注释原文**（`src/chapters/ch14.tex:36-41`，末句）：
  > `再用张量–Hom 伴随把 C^*(M) 搬到另一侧，就是 (14.3) 的 C_*(M)⊗Z(M_in)→Z(M_out)。原书 (14.2) 用上标 C^*、(14.3) 用下标 C_*，指同一链复形，译文照原文未统一。`
- **证据（p.242 印本 + (14.2)/(14.3)）**：(14.2) 印本为 `𝒵 ∈ Hom(𝒵(S¹)^⊗2, 𝒵(S¹)) ⊗ C^*(M)`（⊗ 在 Hom 外，译文与此一致 ✓），(14.3) 为 `C_*(M) ⊗ Z(M_in) → Z(M_out)`。上标 `C^*` 在本书中一律是**上链（cochain）**（参 (6.20) `H^*(…)`、本章 (14.2)），下标 `C_*` 是**链**；两者互为**对偶**（`C^* ≅ (C_*)^∨`），不是同一个对象。
  注里「用张量–Hom 伴随把 C^*(M) 搬到另一侧」这一步之所以成立，**正是因为** `C^* = (C_*)^∨`；写成「指同一链复形」后，这一步反而没有依据了，注自身前后矛盾。另外 (14.2)/(14.3) 用不同指标是**正确的两种写法**，说「译文照原文未统一」会误导读者以为这是待修的疏失。
- **建议处理**：把末句改写为「(14.2) 用上链 `C^*`、(14.3) 用链 `C_*`，二者互为对偶；正是这层对偶（`C^*≅(C_*)∨`）使张量–Hom 伴随能把 `C^*(M)` 搬到另一侧，故两种写法都对，并非未统一」。其余部分（局部常值→局部系统）成立。
