## 二、校订方法

### 阶段一：逐章对照（13 个 agent，一人一章或两章）

对齐单位是**原文 PDF 页**（`pdftotext -layout` 按 `\f` 分页，第 N 段 = PDF 第 N 页）。译本没有 `\SourceParagraph` 锚点，因此改用三重锚点交叉定位：

1. **公式编号**（最可靠）——译本 `\begin{equation}\tag{N.k}` 与 `\diageq{N.k}{…}` 的编号与原书一一对应；
2. **章节标题**——`\section` / `\subsection` 数已核对一致；
3. **页码**——原书 PDF 页 = 书内印刷页 + 1（第 1 章印刷页 8 = PDF p.9）。

每个 agent 的工作范围互斥（只动自己那章的 `.tex` 与 `logs/log_chNN.md`），只用 `edit` 精确替换，不跑编译。

### 阶段二：交叉复核（3 个 agent，分三批）

复核 agent **不信任**校订 agent 的自述，逐条回原文（必要时把 PDF 页渲染成图放大看印刷体）验证：

- 改动是否真的落地（grep 回查）
- 改动是否**改错**（这是重点：把原文对的改成错的比漏改更糟）
- 是否**改出新错**（引号、括号、标签、花括号平衡）

结果：落地失败 0、改错 3 处（已回滚，见 §五）、改出新错 0。

### 阶段三：术语仲裁 + 附录专项审计

- **术语仲裁**（1 个 agent）：把全书术语按「英文原词 → 译本用词 → 出现文件/次数」列表，标记一名多译与一词多译，给出统一建议与依据（优先用仓库资料卡 `datasets/glc` 的 154 张卡背书）。
- **导语块审计**（1 个 agent）：译本每章开头 `keytakeaways`、每节开头 `sectionkey` 是**译者自创的导读块**（不属原文），最容易夹带错误而无人对照。专门审了 124 块。
- **附录 A 审计**（1 个 agent）：附录 A 的 225 条批注按可信度分 A/B/C/D 四级，A 类 = 断言与原文不符者 9 条。
- **附录 B 审计**（1 个 agent）：术语表逐条核对英文原词与译名。

### 3.3 公式符号错误（编号对、式子错）

- **ch11 (11.144)(11.145)**：原文的 `\int_C\Rep(G^\vee)`（沿紧 Riemann 面 $C$ 的积分/张量积）被译成未定义的 `R_C`——这是全书中唯一一处**凭空造符号**。
- **ch15 (15.27)–(15.32)**：因子化同调的积分号被写成 `\cZ_M`（`\mathcal{Z}`），应为 `\int_M`，4 处。
- **ch06**：$K_x\simeq\F_q((t))$ 漏上标 $n$，应为 $\F_{q^n}((t))$。
- **ch08**：$d\mathrm{Jac}$ → $\widehat{\mathrm{Jac}}$。
- **ch13 (13.39)**：原文印 `\mathcal{H}ecke`（花体 H 连写 ecke），译本作直立 `\mathrm{Hecke}`。
- **ch13 (13.106)**：`\Rep_{\mathbf{Cat}}` 的粗体 `Cat` 被改成了小写 `cat`（**复核发现这是校订 agent 改错的**，已回滚）。
- **ch12 (12.26)**：方块图整体错位——`coev` 的定义域被写成 $\End(V)$，底边对象与竖直映射全错位，(12.26) 的图意完全变了；已按 p.210 重排。
- **ch14 Thm 15**：`Konstant` → `Kostant`（人名）；`Rosenburg` 为原书错拼，**照原文保留并加注**。
- **ch09 导读块**：$G=\mathrm{PGL}_2$、$K=\Q_p$ 记号错。
- **ch10 导读块**（2 处）：余维 $k$ 的缺陷应由 $Z(S^{k-1})$ 标记，原写 $Z(S^{n-k})$，差一维。

## 四、注释工作

新增 **30 条** Tutor Note（总数 226 → 256），全部按规程带来源标签，四选一：

`[来源：本仓库资料卡 …]` / `[来源：已译文献《…》第 N 页]` / `[来源：作者《标题》(年)，§/Thm]` / `[译者按（无外部依据）：…]`

注释只写四类内容：原文跳跃的推导步骤、易混记号、结论的出处/名称、译文疑点但不必改正文者。**不刷注释**。

同时清理了既有注释中的硬错：

- ch01 (1.16)：原注称「矩阵第二行只印出一个 `*`，$d$ 位置元素缺失」——实际缺的是 **$c$ 位**（左端留空，本应印 $0$），$d$ 位的 `*` 是印着的；
- ch14 (14.1)–(14.3)：原注称 $C^*$ 与 $C_*$ 「指同一链复形」——二者**互为对偶**（$C^*\cong(C_*)^\vee$），经张量–$\Hom$ 伴随等同；
- ch13：删去「直立 Hecke 是原文如此」的错误说法；
- ch10：两条来源标签不合四选一规范，改写为「译者按（无外部依据）」并给出内部推理链；
- 全库 8 处畸形标签 `[来源：译者按（无外部依据）]` 修正为 `[译者按（无外部依据）]`。

## 五、复核纠错（改了又回滚的）

复核的价值就在于抓「改错」。本轮抓到 3 处，全部回滚或改正：

1. **ch13 (13.106)**：校订 agent 把原文粗体 `Cat` 改成小写 `cat`，理由是「表示的是范畴」——但**印本就是粗体 Cat**，回滚。
2. **ch13 (13.39)**：校订 agent 加注称「直立 Hecke 是原文如此」——放大 p.229 印本可见是 `\mathcal{H}ecke`，遂改为花体并重写该注。
3. **ch06 (6.94)**：校订 agent 判为 GAP（认为 $\Shv(\mathrm{pt}/K^\times)$ 与 $\Pic(D^\times)$ 不相等）——复核发现原文写作 `Shv(pt/K^× = Pic D^×)`，**等号是作者写的**，且 (6.88) 已说明 $\Pic(D_x^\times)=\mathrm{pt}/K^\times$（Picard **栈**，不是 $\cong\Z$ 的线丛类群）。GAP 撤销，改写为解释性注。
