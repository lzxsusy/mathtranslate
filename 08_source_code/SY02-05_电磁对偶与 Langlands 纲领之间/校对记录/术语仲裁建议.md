## 2. 分节说明

### 2.1 skyscraper sheaf → 摩天楼层（置信度：中）

**现状**：三种写法并存，且分布几乎正交——ch08 全线「天穹层」（8）、ch10 全线「摩天大楼」（3）、ch06/ch11/ch15/ch16 全线「摩天楼层」（16）；`appendix_notes` 1 处跟 ch08 作「天穹层」。术语表**没有**这条。

**依据**：② 仓库资料卡 `datasets/gtgl15/cards/concepts/skyscraper-zero-brane.json` 的卡名与 aliases 都是「摩天楼层」（"摩天楼层（零维膜）"、`摩天楼层`），这是本仓库唯一有正式卡片背书的写法；`src/` 内检索「天穹」除 ch08 外为 0，说明「天穹层」是孤例。（旁注：`D:\C-Offload\…\归档\02_几何朗兰兹与电磁对偶\` 里另有 2 个文件出现「天穹层」，但那是与本项目**同源**的旧译稿，属同一译者的用词，不是独立旁证，故不计入。）① 级：**无定论**——我没有核到任何已出版中文教材把 skyscraper sheaf 定为「天穹层」或「摩天楼层」；中文口语里 skyscraper 更常作「摩天大楼」，所以「摩天大楼」并非错译，只是与仓库约定不符。

**裁决理由（一句话）**：三者数学上等价、都无出版依据，只能按「仓库内占多数 + 有正式卡片」取「摩天楼层」，把 ch08 的 8 处和 ch10 的 3 处拉过来。

### 2.3 state space → 态空间（置信度：中，须拍板）

**现状**：三写并存，且 ch06 一章之内就三种都有：ch06 有「态空间」1（在 keytakeaways）、「状态空间」1（keytakeaways）、「状态向量空间」2（正文）。全局：态空间 15、状态空间 18、状态向量空间 2。

**裁决理由（一句话）**：选「态空间」的理由只有两条——它是本书本体章节（ch02/03/10，即 TFT 与谱分解部分）的用词，且比「状态空间」短、与「态射」「本征态」同族；但改 20 处 vs 改 15 处，成本几乎打平，**这是全表最该由 lead 拍板的一条**。

### 2.4 level structure → 级结构（置信度：高）——并纠正一个假冲突

## 3. 不应当统一的（必须分开）

这一节的词都「形似而实不同」，谁把它们合并谁就制造 P1 错误。

### 3.1 character sheaf ≠ character local system ≠ Hecke eigensheaf

| 英文 | 所指 | 本书现译 | 判定 |
| --- | --- | --- | --- |
| character sheaf（Lusztig 义） | 编码特征标的数据（术语表第 46 行） | 特征层 | **保留**（ch12、术语表 46 行） |
| character local system | $\chi\in\Loc(\Pic)$ 带 $\mu^*\chi\xrightarrow{\sim}\chi\boxtimes\chi$ | 特征局部系统 | **保留**（ch06 1、ch07 8、ch08 3） |
| Hecke eigensheaf | 被 Hecke 算子作用后本征的层 | 现混作「特征层」 | **改「（Hecke）本征层」**（ch11 9、术语表 28 行） |

作者自己在 ch07 §7.4 把前两个词混用（`en/ch07_en.txt` 同节先 "character local systems" 后 "a character sheaf"），这属于**原文本身的含混**，照译即可；但第三个（eigensheaf）在原文里从来是 "eigensheaf"，中文不该跟着混。仓库资料卡也证明这个混用不是孤例：`gaits04/cards/concepts/character-sheaf.json` 名为「特征层」，定义却是 character local system 那套（$\mu^*(X)\simeq X\boxtimes X$）——两个义项在仓库里同样并存。

### 3.2 层化（sheaf over base）≠ 分层（stratification）≠ 层（sheaf）

「层化」17 处（ch02 3、ch03 4、ch13 6、ch14 1、ch15 2、ch16 1）**没有一处**是 stratification，全是「沿 $\Spec A$ / $\Loc_{G^\vee}(C)$ / $T^*[n]X$ 成为底空间上的层」，即 sheaf-over-base / 谱分解的层论表述：

- ch02：「$A$-模沿 $\Spec A$ 层化」「$\mathcal H$ 在 $\R$ 上层化」
- ch03：「沿 $G^{\vee}$ 层化」「在 $\Spec U\mathfrak g=\mathfrak g^*$ 上作谱分解/层化」
- ch13：「这个作用是否沿 $\Loc_{G^\vee}(C)$ 分解（层化）」「$A$-侧是否在 $B$-侧上层化」
- ch14/ch15/ch16：「沿 $T^*[n]X$ 层化」「层化在局部算子的 $\Spec$ 上」

⇒ **层化保留，绝不能替换成「分层」**；反过来「分层」也不能写成「层化」。建议在术语表加两条并互相 see-also：`层化 / sheaf over the base` 与 `分层 / stratification`。

### 3.3 算子代数（operator algebra）≠ 操作子（operad）≠ 局部算子代数（local operator algebra）

- 操作子／operad：ch14 的 4 处 → 改「操作子」。
- 算子代数／operator algebra：ch15 2、ch16 2、ch17 1、notes 1 —— 指 $\End(\mathcal F)$、可观测量代数、算子代数谱，**合法，不动**。
- 局部算子代数／local operator algebra：ch10 2、ch15 2、notes 1 —— **合法，不动**（这是本书主线概念，见术语表「局部算子 / local operator」「因子化代数 / factorization algebra」）。
- 改完之后「算子代数 vs 局部算子代数」的伪撞车自动消失（前者是算子代数，后者是「局部算子构成的代数」）。

### 3.4 水平结构 ≠ level structure；horizontal 只用于 horizontal trace / horizontal line

改 ch06 的 9 处「水平结构」为「级结构」之后，全书「水平」剩下的 14 处**全部合法**：ch11 3 处（水平线 / horocycle）、ch13 7 处（水平迹 vs 竖直迹）、ch04 1 处（水平箭头）、notes 4 处（水平箭头 + 水平迹）。**不要把「水平」二字整体替换。**

### 3.5 切触（contact）≠ 切向（tangential）

「切触」是 contact 的定译（切触流形、切触结构、切触几何）；tangential structure 讲的是切丛上的（定向/自旋）结构。仓库 `functoriality/cards/concepts/lagrangian-correspondence.json` 的「带切触边界」是 contact boundary，佐证「切触」已被占用。**两词必须分开，不能因为字面都有「切」就合并。**

### 3.6 阿黛尔（adèle）≠ 伊代尔（idèle）；理想类群（ideal class group）≠ 伊代尔类群（idèle class group）

术语表第 36 行「阿黛尔 & adèle」与正文「伊代尔」是两个不同对象；ch05 同时出现 ideal class group（3 处「理想类群」）与 idèle class group（8 处「伊代尔类群」），**都对，不要互相替换**。

### 3.7 反常层（perverse sheaf）≠ 偏斜层

术语表第 9 行的说明文字已声明「perverse sheaf 亦译『偏斜层』」——那是**异体提及**，正条是「反常层」（4 处：ch11 1、ch12 1、术语表 1、notes 1）。**不要**把说明文字里的「偏斜层」也改掉，也不要据此把正文改成「偏斜层」。

### 3.8 球 Hecke（spherical）≠ 球面（sphere）

「球面」42 处全是几何球面（$S^{n-1}$、2-球面），「球」系列才是 spherical（球函数/球表示/球子群/球簇）。**两族不得互串**：把 spherical Hecke 写成「球面 Hecke」会让 $\Sph(V)$ 与 $S^2$ 混为一谈。

### 3.9 仿射 Grassmann 簇 ≠ 流形；ind-概形 ≠ 概形

ind-scheme 是可数正向极限的概形，**不是**有限维流形（`en/ch11_en.txt:146` "ind-proper ind-scheme"）。术语表把它写死成「流形」是数学错误，不是风格选择。

### 3.10 不要保留「导出凝聚层」这个写法

「导出凝聚层」在中文里会被读成 derived coherent sheaves（导出范畴里的凝聚层），那是**另一个对象**；IndCoh 是 ind-completion。两者在本章（ch16 讲奇异支撑与 $\QC^!$）恰好都会出现，混写会让读者分不清。

### 3.11 摩天楼层 / 天穹层 / 摩天大楼——这三个**要**统一

放在这里只是提醒：它属于 §2.1 的「必须统一」，不是「不应统一」。同理，「水平结构→级结构」「切触结构→切向结构」也都是必须统一项。
