## 二、P1 改动（3 处）

1. **CN 180–186（原文 p.210）(12.26) 图式整体错位**。原译的阵列把节点与箭头搬错：底左写成 $\End(V)$、底右写成 $\C$，左竖箭头 $\sum_i e_i\otimes e^i$ 成了 $\End(V)\to V\otimes V^{*}$，右竖箭头成了 $\mathrm{id}\colon\C\to\C$，底行成了 $\End(V)\xrightarrow{\operatorname{Tr}}\C$。原书 p.210 的方块是：顶左 $V\otimes V^{*}$、顶右 $\C$；底左 $\C$、底右 $\End(V)$；左斜 $\sum_i e_i\otimes e^i\colon\C\to V\otimes V^{*}$（coev），右斜 $\operatorname{Tr}\colon\End(V)\to\C$；底边 $\mathrm{id}\colon\C\to\End(V)$；另有一条绕行弧线标 $\operatorname{Tr}(\mathrm{id})=\dim(V)$。已按原图重排阵列（图 p.210 放大核对）。
2. **CN 376–388（原文 p.214）(12.49) 两个对应的节点画反**。原译两图顶节点都作 $X\times X$、$\Delta$ 从 $X\times X$ 指向 $X$；原书顶节点是 $X$：左图 $X\to\mathrm{pt}$、$X\xrightarrow{\Delta}X\times X$，右图 $X\xrightarrow{\Delta}X\times X$、$X\to\mathrm{pt}$。已改为顶 $X$，$\Delta$ 由 $X$ 指向 $X\times X$（图 p.214 放大核对）。
