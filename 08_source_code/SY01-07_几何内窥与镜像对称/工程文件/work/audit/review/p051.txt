4.7. The B-Field. At two points we have run into important parameters that are not
determined by the geometry of an A-brane, namely the ramification parameter α∗ at a
pole of D ⊂ Te∗ Y , and the twisting class ζ ′ of eqn. (4.23). In the abstract, any values
of these parameters make sense and can be used to construct twisted D-modules by
solving the twisted version of Hitchin’s equations with singularities. We would like to
know what values are relevant in the context of geometric Langlands.
   For the twisting parameter, we can make an argument based on holomorphy that
is very similar to what we have already said for the ramification parameter. The
cohomology class χ, like the twisting parameter ̺∗ , must be holomorphic in Lα − iLγ.
As we have just seen, Im χ is determined by the affine deformation by which a Zariski
open set in MH differs from the cotangent bundle T ∗ M. In [GW], by analyzing the
geometry of MH , it was shown that this is linear in Lγ, and hence Re χ is similarly
linear in Lα.

$E\to E\otimes K_Y$。更确切地说，$\varphi$ 的每个分支——或更准确地说，$\pi:D\to Y$ 每个分支对 $\varphi$ 的贡献——都恰如式 (4.21) 那样被扭化。于是 $\varphi$ 所满足的方程是

[begin equation]
(4.22)
\bar\partial_E\varphi=1\otimes\zeta,

这类扭化对 Hitchin 方程 (2.1) 有意义，我们可以把它稍作推广为

[begin equation]
(4.23)

[begin aligned]

F-\phi\wedge\phi&=1\otimes i\zeta'\\
d_A\star\phi&=1\otimes i\,\mathrm{Im}\,\zeta\\
d_A\phi&=1\otimes i\,\mathrm{Re}\,\zeta.

[end aligned]

[end equation]

除上一段所见到的由 $\zeta$ 给出的形变（它已被用实微分几何重写）之外，我们在第一个方程中还纳入了一个额外的实（脚注：这些方程右端出现因子 $i$ 的原因是：$\phi$ 与 $F$ 是取值于 $U_n$（$GL_n$ 的紧实形式）的 Lie 代数的形式；我们用反厄米 $n\times n$ 矩阵表示这个 Lie 代数。}闭 $(1,1)$-形式 $\zeta'$。在平凡等价的意义下，这些方程只依赖于 $\zeta'$、$\mathrm{Im}\,\zeta$、$\mathrm{Re}\,\zeta$ 的上同调类。这些类是三个实参数，就像分歧 Higgs 丛的通常参数 $(\alpha,\beta,\gamma)$ 一样。

我们预期，$\widetilde{T}^*Y$ 中的 A-膜应当通过求解这一扭化形式的 Hitchin 方程而映到 $Y$ 上的扭 D-模。$\zeta'$ 的正确选择不由 A-膜的几何决定，有点类似于 §4.4 中 $\alpha^*$ 的取值。这一问题将在 §4.7 中讨论。

在解出扭化方程 (4.23) 后，我们构造复值联络 $\mathcal{A}=A+i\phi$。通常 Hitchin 方程蕴含 $\mathcal{A}$ 平坦。然而在目前情形，$\mathcal{A}$ 并不平坦，而是具有中心曲率 $\mathcal{F}_0=i(\zeta'+i\,\mathrm{Re}\,\zeta)$。具有中心曲率 $\mathcal{F}_0$ 的联络描述的不是 D-模，而是扭 D-模，扭化为 $\mathcal{T}_\chi$，即第一 Chern 类为 $\chi=\mathcal{F}_0/2\pi i$ 的「线丛」。在更内蕴的描述中，扭化其实是按 $K_Y^{1/2}\otimes\mathcal{T}_\chi$ 进行的，其中 $K_Y^{1/2}$ 的角色已在前文描述过。

## B-场

有两处我们遇到了重要的参数，它们不由 A-膜的几何决定，即 $D\subset\widetilde{T}^*Y$ 的极点处的分歧参数 $\alpha^*$，以及式 (4.23) 的扭化类 $\zeta'$。抽象地说，这些参数的任意取值都有意义，都可用来通过求解带奇点的 Hitchin 方程的扭化版本构造扭 D-模。我们想知道在几何 Langlands 的语境中哪些取值是相关的。

对扭化参数，我们可以作出一个基于全纯性的论证，它与我们已就分歧参数所说的非常相似。上同调类 $\chi$，如同扭化参数 $\varrho^*$，必须全纯地依赖于 ${}^L\alpha-i{}^L\gamma$。正如我们刚刚看到的，$\mathrm{Im}\,\chi$ 由 $\mathcal{M}_H$ 中某个 Zariski 开集与余切丛 $T^*\mathcal{M}$ 相差的仿射形变所决定。在 [GW] 中，通过分析 $\mathcal{M}_H$ 的几何，已证明它关于 ${}^L\gamma$ 是线性的，因而 $\mathrm{Re}\,\chi$ 同样关于 ${}^L\alpha$ 是线性的。
