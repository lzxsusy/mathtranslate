    So to the Higgs bundle (E, ϕ) on C, we associate the following data: the spectral
curve π : D → C and the line bundle or torsion-free sheaf L → D. From this data, it is
possible to reconstruct the original Higgs bundle. One recovers E by E = π∗ (L). And
the Higgs field ϕ : E → E ⊗ K can similarly be recovered from π : D → C as π∗ (z),
where here multiplication by z is understood as a map from L to L ⊗ π ∗ (T ∗ C). In this
way, the Higgs bundle (E, ϕ) can be recovered from the pair (D, L).
    In this description, the base B of the Hitchin fibration parametrizes the possible
spectral curves D. For example, for G = SL2 , the equation defining D reduces to
z 2 + det ϕ = 0, so B is parametrized by the quadratic differential det ϕ = −Tr ϕ2 /2.
The Hitchin fibration is the map that takes a pair (D, L) to D. The fiber F of the
Hitchin fibration is parametrized by the possible choices of L for a given spectral curve
D.
    What line bundles L → D arise in this construction? For GLn , if we allow all Higgs
bundles (E, ϕ), with no restriction on det E, then all L → D can arise. Thus, L is
associated with an arbitrary point in Pic D. If we wish to associate (E, ϕ) to a local
system by solving Hitchin’s equations, then det E must have degree zero and we must
restrict L to a particular component of Pic D. A small computation with Riemann-
Roch shows that in order for E = π∗ (L) to be of degree zero, the degree of L must
be

### CHINESE TRANSLATION

设 $z$ 表示余切丛纤维上的线性函数，则曲线 $D$（称为谱曲线）由方程

[begin equation]
(4.1)
\det(z-\varphi)=0

[end equation]

定义。投影 $\pi:T^*C\to C$ 限制为 $n$ 重覆盖 $\pi:D\to C$。

一般地，$D$ 光滑且不可约，其亏格为 $g'=n^2g-n^2+1$，其中 $g$ 是 $C$ 的亏格。对通常的 Higgs 丛，$D\subset T^*C$ 是一条完备射影曲线；但对分歧的 Higgs 丛则不然，因为 $\varphi$ 有极点。在后一情形，通过添加若干不属于 $T^*C$ 的点，把 $D$ 完备化为一条射影曲线。

定义线丛 $\mathcal{L}\to D$ 为映射 $(\pi^*(\varphi)-z):\pi^*(E)\to\pi^*(E)\otimes K$ 的余核。更确切地说，$D$ 光滑时 $\mathcal{L}$ 是线丛，但一般情形下可能只是扭转无关层。

于是，对 $C$ 上的 Higgs 丛 $(E,\varphi)$，我们联系以下数据：谱曲线 $\pi:D\to C$ 以及线丛或扭转无关层 $\mathcal{L}\to D$。由这些数据可以重构原来的 Higgs 丛。$E$ 由 $E=\pi_*(\mathcal{L})$ 恢复；而 Higgs 场 $\varphi:E\to E\otimes K$ 同样可由 $\pi:D\to C$ 恢复为 $\pi^*(z)$，这里乘以 $z$ 被理解为从 $\mathcal{L}$ 到 $\mathcal{L}\otimes\pi^*(T^*C)$ 的映射。这样，Higgs 丛 $(E,\varphi)$ 便可由对 $(D,\mathcal{L})$ 恢复。

在这一描述中，Hitchin 纤维化的底 $\boldsymbol{B}$ 参数化可能的谱曲线 $D$。例如，对 $G=SL_2$，定义 $D$ 的方程约化为 $z^2+\det\varphi=0$，故 $\boldsymbol{B}$ 由二次微分 $\det\varphi=-\Tr\varphi^2/2$ 参数化。Hitchin 纤维化是把对 $(D,\mathcal{L})$ 映到 $D$ 的映射。Hitchin 纤维化的纤维 $\boldsymbol{F}$ 由给定谱曲线 $D$ 时 $\mathcal{L}$ 的可能选择参数化。

在这一构造中出现哪些线丛 $\mathcal{L}\to D$？对 $GL_n$，若允许所有 Higgs 丛 $(E,\varphi)$、对 $\det E$ 不加限制，则所有 $\mathcal{L}\to D$ 都可出现。于是 $\mathcal{L}$ 对应于 $\mathrm{Pic}\,D$ 中的任意点。若希望通过求解 Hitchin 方程把 $(E,\varphi)$ 联系到一个局部系统，则 $\det E$ 的次数必须为零，且必须把 $\mathcal{L}$ 限制到 $\mathrm{Pic}\,D$ 的某个特定连通分支。用 Riemann--Roch 作一个小计算可知，为使 $E=\pi_*(\mathcal{L})$ 的次数为零，$\mathcal{L}$ 的次数必须是

[begin equation]
(4.2)
\deg\mathcal{L}=n(n-1)(g-1).

[end equation]

（这一计算的另一版本见 §4.9。）

对 $SL_n$，必须进一步限制 $\mathcal{L}$，使 $\det E$ 平凡，而不仅是次数为零。

## 与 A-膜的关系

关于 $\mathcal{L}$ 次数的条件 (4.2) 可以有益地表述如下。设 $K_C^{1/2}$ 与 $K_D^{1/2}$ 分别表示 $C$ 与 $D$ 的典范丛的平方根。则 $\mathcal{L}$ 具有形式 $\mathcal{L}=\pi^*(K_C^{-1/2})\otimes K_D^{1/2}\otimes\mathcal{N}$，其中 $\mathcal{N}\to D$ 次数为零。一个富有提示性的重述方式是：我们可以用

[begin equation]
(4.3)
K_C^{1/2}\otimes E=\pi_*(K_D^{1/2}\otimes\mathcal{N})

[end equation]

来定义 $E$。
