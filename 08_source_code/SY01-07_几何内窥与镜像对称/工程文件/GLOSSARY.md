## D. 记号约定（冻结，不得改动）

- Langlands 对偶群：${}^{L}G$（上标 $L$ 在左肩；不要写成 $G^L$）。
- Hitchin 模空间：$\mathcal{M}_H(C;G)$ 或简称 $\mathcal{M}_H$ / $\mathcal{M}_H(G)$（按原文）。
- $G$-丛模叠：$\mathrm{Bun}_G$；带抛物结构的模叠按原文写。
- 膜：原文用 $\mathcal{A}$、$\mathcal{B}$、$\mathsf{B}$ 等花体/无衬线体，按图像；本译本统一用 `\mathcal{A}`、`\mathcal{B}`（若原文为花体）。
- 典范余迷向膜：$\mathcal{A}_{cc}$（下标 cc）。
- D-模层：$\mathcal{D}$，其上的模记作 $\mathcal{D}$-模。
- 谱曲线：$\Sigma$ 或按原文；谱覆盖记 $\widetilde{C}$ 或按原文。
- 微分：原文直立体 $\mathrm{d}$ 用 `\mathrm{d}`，斜体按原文。
- 虚数单位：$\mathrm{i}$；自然对数底：$\mathrm{e}$（若原文如此排版）。
- 交换图：用 `array` 环境重建（本工程未载 amscd；`\CD` 是 D-模记号）。
- 公式编号：照抄原文 `(x.y)`，用 `\tag{x.y}`；不要重排、不要跳号。
