## 二、文献按角色分类

> 只列与论证直接相关的代表条目；完整表见 `源码/sections/references.tex`（170 条，保留英文原貌）。

### 2.1 几何 Langlands 与 Hitchin 系统

- **Beilinson–Drinfeld [BD]**：Hitchin 可积系统与 Hecke 本征层的经典构造；§5–§6 的出发点。
- **Frenkel [F1, F2]**：几何 Langlands 纲领与分歧理论；本文的问题意识来源。
- **Frenkel–Gaitsgory–Vilonen [FGV]**：几何 Langlands 猜想的表述。
- **Gaitsgory [G?]、Braverman–Gaitsgory [BG]**：几何 Eisenstein 级数与 §6.6 的平行例子。
- **Hitchin [Hi1–Hi4]**：Hitchin 方程、稳定丛与可积系统、$G_2$ 谱曲线。
- **Hausel–Thaddeus [HT]**：Hitchin 系统的镜像对称；§2 的直接前驱。
- **Donagi–Pantev [DP]**：Hitchin 系统的 Langlands 对偶。
- **Kapustin–Witten [KW]**：电–磁对偶与几何 Langlands；本文物理框架的主引用。
- **Gukov–Witten [GW]**：规范场论、分歧与几何 Langlands；§1、§4 的分歧膜。

### 2.2 内窥、L-包与迹公式

- **Langlands [L1–L4]**：内窥的原始纲领与 L-包。
- **Labesse–Langlands [LL]**：$SL_2$ 的 L-不可区分性；定理 7.1 的直接来源。
- **Kottwitz [Ko]**：稳定迹公式的尖点 tempered 项。
- **Laumon–Ngô [LN]**、**Ngô [Ngo]**：基本引理与 Hitchin 纤维化的几何；§1.6、§9 的背景。
- **Dat [Dat]**：基本引理的几何进路（Bourbaki 报告）。
- **Arthur [Art1, Art2]**：函子性与迹公式；L-包的现代语境。

### 2.3 镜像对称、膜与 D-模

- **Kontsevich [Kon?]**：同调镜像对称的猜想；§2 的镜像对称框架。
- **Strominger–Yau–Zaslow [SYZ]**：SYZ 镜像对称；逐纤维 T-对偶。
- **Kapustin–Orlov [KO]**：A-膜、镜像对称与 Fukaya 范畴。
- **Beilinson–Bernstein–Deligne [BBD]**：反常层；§4 的 D-模／层翻译。
- **Donagi–Gaitsgory [DG]**：Higgs 丛的 gerbe；§10 的直接来源。
- **Lieblich [Li]**：扭层模空间；§10 的技术背景。
- **Laumon [La1–La5]**：Fourier 变换、几何 Langlands 与基本引理。

### 2.4 物理与例子

- **Kapustin–Witten [KW]**、**Gukov–Witten [GW]**：规范场论侧的主引用。
- **Seiberg–Witten [SW?]**：§3.11 的 Seiberg–Witten 理论对照。
- **Donagi–Witten [DW]**：超对称 Yang–Mills 与可积系统。
- **Bershadsky–Johansen–Sadov–Vafa [BJSV]**、**Aganagic–Dijkgraaf–Klemm–Mariño–Vafa [ADKMV]**：拓扑弦与可积层级。
- **Aspinwall [As]**、**Kronheimer [Kr]**、**Douglas–Moore [DM]**：ALE 空间、K3 与 D-膜的例子。

### 2.5 函数域与算术

- **Drinfeld [Dr1, Dr2]**：函数域 Langlands 与 $\ell$-进表示。
- **Lafforgue [Laf]**：函数域 Langlands 对应（$GL_n$）。
- **Laumon [La2, La3]**：函数域几何 Langlands 与 Eisenstein 级数。
- **Deligne [De]**：Weil 猜想 II；§8 的 Frobenius 迹语境。
- **Jacquet–Langlands [JL]**：$GL_2$ 的自守形式；L-包的经典来源。

## 五、术语一致性核查要点

1. **proper / improper** 全文保留英文；§8.7 的 improper Hecke 函子与 §8.10 的 Iwahori 情形是同一对术语，不能一处译“正常”、一处译“proper”。
2. **分歧 / 分支** 严格区分：ramification＝分歧，branch＝分支；§3 的“两个分支”与 §5 的“非分歧二重覆盖”不能混。
3. **分裂 / 非分裂** 指二次扩张中的点；不要与“分裂为两个直和项”的“分裂”混用，后者在 §6 一律写“直和分解”或“分裂为……直和项”。
4. **Hecke 本征层 / Hecke 本征函数** 成对出现；§8 的 $f_\pm$ 是函数，$\mathcal{F}_\pm$ 是层，不能互换。
5. **gerbe** 不译；§10 的 $\mathbb{C}^\times$-gerbe 与 §6 的“两种等价不可区分”是同一现象的两面。
6. **L-包** 不写“L 包”；**L-不可区分** 不写“L 不可区分”。
7. **模叠** 不写“栈”；**反常层** 不写“变态层”；**无挠层** 不写“挠无层”。
