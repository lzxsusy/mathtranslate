## 一句话结构

先建立「几何 Langlands＝Hitchin 纤维化的镜像对称」这一图景（§1–§2）；在亏格一把图景算成显式模型（§3）；再逐纤维把 A-膜翻成扭 D-模、把 Hitchin 纤维翻成谱覆盖／Prym 簇，得到 Hecke 本征层的分裂（§4–§6）；然后把几何分裂翻译成函数域上的 L-包与分数 Hecke 本征函数，并用经典判据和 Whittaker 函数验证（§7–§8、§11）；最后把 $SL_2$ 的图像推广到一般群并处理 gerbe 带来的不可区分性（§9–§10）。

## 逐节要点

### §1 引言（原文 pp. 3–13；译本 pp. 5–10）

- **在做什么**：把几何 Langlands 的镜像对称图景、内窥的几何解释、以及本文的三条可检验预言一次讲清。
- **关键对象**：Hitchin 纤维化 $\mathcal{M}_H(G)\to\boldsymbol{B}$；对偶群 ${}^{L}G$ 的局部系统；轨形点；分数 A-膜；Hecke 本征层。
- **新主张**：内窥局部系统的自同构群 $\Gamma$ 的不可约表示标记奇异纤维上的分数膜；Hecke 本征层按 $\Gamma$ 分裂；分裂出的层满足分数 Hecke 性质。
- **例子**：亏格一 $SL_2/SO_3$ 的例子被提前预告为「可完全算出」的模型。
- **产物**：三条预言（P1–P3）与全文路线图；后文所有计算都是对这三条预言的展开或检验。

### §2 对偶、膜与内窥（原文 pp. 13–21；译本 pp. 11–15）

- **在做什么**：搭语言：Hitchin 方程、Hitchin 纤维化、SYZ 镜像对称、A-膜／B-膜、A-膜到 D-模的映射、本征膜与本征层。
- **关键对象**：$G$-Higgs 丛 $(\mathcal{E},\varphi)$；Hitchin 底 $\boldsymbol{B}$；对偶环面 $T_b$ 与 $\check T_b$；典范余迷向膜；扭 D-模。
- **新主张**：一般纤维上的 T-对偶把 B-模型侧的局部系统与 A-模型侧的分支联系起来；A-膜只典范地给出扭 D-模，因为 $K_Y^{1/2}$ 无典范选择。
- **例子**：以 $SL_2$ 与 $SO_3$ 的对偶 Hitchin 纤维化作为贯穿例子。
- **产物**：§3–§6 所需的全部几何语言；「典范余迷向」与「扭化」两个技术约束在这里埋下。

### §3 亏格一中的显式例子（原文 pp. 21–42；译本 pp. 16–30）

- **在做什么**：在亏格 $1$、单分歧点的分歧 $SL_2$ 情形，把 Hitchin 模空间、Hitchin 底、奇异纤维、对称群全部算成方程。
- **关键对象**：方程 (3.15) 的模空间；参数 $w$；4 个 $A_1$ 轨形点；3 条奇异纤维；两条 $\mathbb{CP}^1$ 分支 $\boldsymbol{F}_{e_i}^{\pm}$；$\mathcal{Q}=\mathbb{Z}_2\times\mathbb{Z}_2$。
- **新主张**：$SO_3$ 侧的 4 个轨形点对应 $\mathbb{Z}_2$ 内窥局部系统；$SL_2$ 侧的 3 条奇异纤维各分裂为两支，两个二重点被 $\mathcal{Q}$ 置换。
- **例子**：这是全文唯一「所有东西都能写成方程」的模型，也是 §5 高亏格论证的直觉来源。
- **产物**：E1–E4 的显式数据；§4 的谱曲线、§5 的 Prym 簇、§6 的分数层都以它为原型。

### §4 A-膜到 D-模（原文 pp. 42–56；译本 pp. 31–40）

- **在做什么**：把 A-膜所对应的扭 D-模在谱曲线上具体化，处理极点、残差与中心扭转。
- **关键对象**：谱曲线 $D$；仿射形变 $\widetilde{T}^*Y$；$K_Y^{1/2}$；残差 $\operatorname{Res}$；中心扭转。
- **新主张**：有极点时必须用 $\widetilde{T}^*Y$；残差之和等于 $\zeta_{\mathbb{C}}$ 而非零；输出参数 $({}^{L}\alpha,{}^{L}\beta,{}^{L}\gamma)$ 到输入参数是线性的。
- **例子**：§3 的谱曲线与两条分支被用来算极点位置与残差。
- **产物**：D1–D3；为 §5 的「逐纤维 T-对偶」提供可计算的映射。

### §5 谱覆盖、Hecke 算子与高亏格（原文 pp. 56–76；译本 pp. 41–53）

- **在做什么**：把 Hitchin 纤维写成谱覆盖上的线丛／无挠层，识别 Prym 簇，并把亏格一的转移函子推广到高亏格。
- **关键对象**：谱覆盖 $C'$；Prym 簇 $\boldsymbol{P}_b$；正规化 $D'$；$SO_3$ 的类比；转移函子。
- **新主张**：亏格一时奇异纤维的正规化是非分歧二重覆盖；高亏格时内窥谱曲线的正规化亏格为 $2g-1$；$SO_3$ 模去 $\mathcal{Q}$ 后只剩一个分支，$\mathbb{Z}_2$ 轨形点出现在余维 $4g-4$。
- **例子**：$g=1$ 与任意 $g$ 的谱覆盖对照；$SO_3$ 的 Hitchin 纤维与 $SL_2$ 的纤维通过 $\mathcal{Q}$ 商联系起来。
- **产物**：S1–S4；§6 的「本征层分裂」现在有了纤维层面的解释。

### §6 本征层的范畴（原文 pp. 76–87；译本 pp. 54–62）

- **在做什么**：把「一个本征层分裂成两个」提升为范畴语言，定义分数 Hecke 本征层，并说明为什么两个直和项不可典范区分。
- **关键对象**：本征层范畴 $\mathcal{C}$；Hecke 函子；$\mathrm{Rep}(\Gamma)$；$\mathcal{F}=\mathcal{F}_+\oplus\mathcal{F}_-$；$\operatorname{Aut}_{\mathcal{E}}$。
- **新主张**：内窥例中正则 Hecke 本征层分裂为两个不可约直和项；分数 Hecke 本征层满足 (6.11)；$\operatorname{Aut}_{\mathcal{E}}$ 虽等价于 $\mathrm{Vect}$，却有两种不可区分的等价。
- **例子**：$\mathbb{C}^\times$、任意环面、中心作为自同构群、几何 Eisenstein 级数四组平行例子。
- **产物**：C1–C3；为 §8 的「分数 Hecke 本征函数」提供范畴模板。

### §7 经典情形（原文 pp. 87–96；译本 pp. 63–68）

- **在做什么**：回顾经典内窥：局部／整体 Langlands 对应、L-包、不变向量空间、improper Hecke 算子。
- **关键对象**：$W_F$、$PGL_2$ 参数 $\sigma$、L-包 $\Pi_\sigma$、$\prod_x K_x$-不变向量、双商 $\Bun^{\mathcal{O}(D)}_{SL_2}(\mathbb{F}_q)$。
- **新主张**：定理 7.1：$\bigotimes'_{x\in C}\pi_x$ 自守 iff $\#S$ 偶；这给出 L-包的精确判据。
- **例子**：$SL_2$ 的全局 L-包；$S$ 为 $D$ 中在二次扩张 $E/F$ 内非分裂的点集。
- **产物**：T7.1；§8 的算术构造与 §11 的 Whittaker 证明都以它为靶心。

### §8 从 Hecke 本征层到 Hecke 本征函数（原文 pp. 96–111；译本 pp. 69–79）

- **在做什么**：在函数域把 §6 的层分裂翻译成函数分裂，构造分数 Hecke 本征函数，验证其本征值，并说明 improper Hecke 函子为何不是等价。
- **关键对象**：$\Bun^{\mathcal{O}(D)}_{SL_2}(\mathbb{F}_q)$；$f^D_\sigma$；$f^D_{\sigma,\pm}$；$\sigma'=\sigma\otimes\nu$；$E/F$；Iwahori 情形。
- **新主张**：$f_++f_-$ 与 $f_+-f_-$ 分别对应 $\sigma$ 与 $\sigma'$ 的通常 Hecke 本征函数；$f_\pm$ 满足分数 Hecke 性质 (8.19)、(8.22)；improper Hecke 把两个不可约对象送到同一对象，故非等价；引理 8.1 给出 $\sigma'$ 的诱导表示描述。
- **例子**：$SL_2$ 的 $D$ 型与 Iwahori 型；阿贝尔情形作为对照。
- **产物**：F1–F3、L8.1；§9 的一般群推广直接复用「层分裂 → 函数分裂」的模板。

### §9 其他群（原文 pp. 111–119；译本 pp. 80–85）

- **在做什么**：把 $SL_2$ 的图像推广到一般约化群，陈述猜想 1，并写出分数本征膜／本征层的直和分解与 't Hooft 本征方程。
- **关键对象**：内窥 ${}^{L}G$-局部系统 $\mathcal{E}$；自同构群 $\Gamma$；$\boldsymbol{P}_b$；$\Gamma_b$；分数本征膜 $\mathcal{A}_R$。
- **新主张**：正则本征膜是本征膜的直和；分数膜满足 (9.7)；猜想 1：$\Gamma$ 阿贝尔，$\widehat{\Gamma}$ 是 $\pi_0(\boldsymbol{P}_b)$ 的商，最大自同构群 $\Gamma_b\cong\widehat{\pi_0(\boldsymbol{P}_b)}$。
- **例子**：$SL_2$ 情形由 §5 支持；阿贝尔情形可完全计算。
- **产物**：G4–G5、猜想 1；§10 的 gerbe 讨论为猜想 1 的「无典范基点」提供几何解释。

### §10 gerbe（原文 pp. 119–124；译本 pp. 86–89）

- **在做什么**：处理一个微妙之处：Hitchin 纤维只是 torsor，没有典范基点，因此「哪张 B-膜对应哪张 A-膜」没有典范选择。
- **关键对象**：$\mathbb{C}^\times$-gerbe $\mathcal{G}$；扭 B-模型；两张 B-膜 $\mathcal{B}_\pm$；两张 A-膜 $\boldsymbol{F}_1,\boldsymbol{F}_2$。
- **新主张**：正确陈述必须把 $\mathcal{M}_H(SO_3)$ 的 B-模型用 $\mathcal{G}$ 扭转；扭转后两张分数膜不可区分，这与 §6 的「两种等价不可区分」是同一现象。
- **例子**：$SL_2/SO_3$ 的亏格一模型；与几何 Langlands 通常陈述的比较。
- **产物**：G6–G7；把 §5–§6 的「分裂但不典范」提升为一条一致性要求。

### §11 附录：$SL_2$ 的 L-包（原文 pp. 124–127；译本 pp. 90–92）

- **在做什么**：用 Whittaker 函数给出定理 7.1 的另一个证明。
- **关键对象**：Whittaker 函数 $f_{\tilde\sigma}$；$\langle\delta+D\rangle$；$\Bun^{\mathcal{O}(D)}_{SL_2}$ 的像。
- **新主张**：$\langle\delta+D\rangle$ 奇偶决定 $f_{\tilde\sigma}$ 的限制是否为零；由于 $\langle\delta\rangle$ 恒偶，得到定理 7.1 的 $\#S$ 奇偶判据。
- **例子**：无新例子；是对 §7 判据的独立验证。
- **产物**：W1；让定理 7.1 不依赖 [LL] 的引用也可信。

## 三条论证链

1. **几何链**：§1 图景 → §2 Hitchin/SYZ → §3 亏格一模型 → §5 谱覆盖/Prym → §6 层分裂 → §9 一般群。
2. **算术链**：§1 预言 → §7 经典 L-包 → §8 分数 Hecke 本征函数 → §11 Whittaker 证明。
3. **一致性链**：§4 扭 D-模 → §5 逐纤维 T-对偶 → §10 gerbe；这条链不产生新定理，但决定前两条链的陈述是否自洽。
