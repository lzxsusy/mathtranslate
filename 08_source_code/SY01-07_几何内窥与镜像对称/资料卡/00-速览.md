## 一句话

这篇长文把几何 Langlands 对应解释为两个对偶 Hitchin 纤维化之间的镜像对称；当 B-模型一侧的 Hitchin 纤维出现轨形奇点（即内窥局部系统）时，A-模型一侧的奇异纤维上出现分数 A-膜，由此预言 Hecke 本征层按自同构群 $\Gamma$ 的不可约表示分裂，并满足「分数 Hecke 性质」；作者在亏格一模型和函数域上把这些预言算出来、验出来。

## 三条主线

1. **几何机制：从 T-对偶到分数膜。**
   一般 Hitchin 纤维是光滑对偶环面，逐纤维 T-对偶给出 B-膜与 A-膜的等价。纤维退化时，B-侧点成为 $\Gamma$-轨形点，其 B-膜范畴是 $\mathrm{Rep}(\Gamma)$；对偶的 A-侧奇异纤维分裂为若干分支，$\Gamma$ 的每个不可约表示对应一个分数 A-膜。只有这些分数膜的和才是 't Hooft 算子的本征膜。

2. **显式模型：亏格一、$SL_2/SO_3$。**
   在亏格 $1$、单分歧点的模型里，$SO_3$ 的 Hitchin 模空间有 4 个 $A_1$ 轨形点；$SL_2$ 的 Hitchin 底上有 3 条奇异纤维，各分裂为两条 $\mathbb{CP}^1$，并在两个二重点处相交。这是全文唯一可以逐式算到底的例子，也是「分数膜」而非「整膜」的图像来源。

3. **算术检验：从层到自守函数。**
   通过 A-膜 → 扭 D-模 → 反常层 →（有限域上）自守函数 的链条，把几何分裂翻译成 Hecke 本征函数的分裂；证明满足「分数 Hecke 性质」的函数确实存在，并用 Whittaker 函数在附录中证明 $SL_2$ 的经典判据（定理 7.1）。

- **上游：** [KW] Kapustin–Witten 的几何 Langlands／镜像对称图像；[GW] Gukov–Witten 的 A-膜与 D-模；[SYZ] 的 SYZ 猜想；[N1, N2] Ngô 关于基本引理与 Hitchin 纤维化的几何。

## 读法建议

- **第一遍（半天）：** §1 + §2 + §3。先抓住「轨形点 ↔ 奇异纤维」「$\mathrm{Rep}(\Gamma)$ ↔ 分数膜」这两组对应，再看亏格一例子如何把它们算成 4 个点和 3 条纤维。
- **第二遍（技术）：** §4–§6。重点是 A-膜到扭 D-模的链条、$K^{1/2}$ 与 gerbe 的来源、谱覆盖/Prym 模型，以及「正则 Hecke」与「分数 Hecke」的差别。
- **第三遍（算术）：** §7–§8 + §11。把几何分裂翻译成 L-包与 Hecke 本征函数；定理 7.1 与引理 8.1 是这一部分的锚点。
- **一般群：** §9–§10。先接受猜想 1，再看 §10 的 gerbe 如何解释「两张分数膜不可区分」；这一节也是全文最容易被误读为「已经证明」的地方。
