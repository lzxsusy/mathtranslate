## 5. 译注脚注标记：`\footnote[\text{译1}]` 走不通，改 manyfoot

- **意图**：译文要区分「作者脚注」与「译者注」，且作者脚注必须保原编号。
- **动作**：先试 `\footnote[\text{译1}]{...}`（报 `! Missing number, treated as zero.`，`<to be read again> \protect`），再试 `[\mbox{译2}]`（同样失败），试 `hyperfootnotes=false`（无效）。
- **证据**：LaTeX 的 `\footnote` 可选参数走 `\@xfootnotemark`，只接受能展开成数字的记号；`hyperref` 的补丁不改变这一点。
- **结论**：用 `manyfoot` 建独立序列 `\DeclareNewFootnote[plain]{trans}` + `\renewcommand{\thefootnotetrans}{译\arabic{footnotetrans}}`，`\zy{...}` 即 `\footnotetrans{...}`。实测作者脚注 1–8、译注「译 1–译 4」互不干扰。
