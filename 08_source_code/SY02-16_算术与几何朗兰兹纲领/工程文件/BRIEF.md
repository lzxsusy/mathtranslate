## 一句话主旨

几何朗兰兹把经典朗兰兹的「数 → 向量空间 → 范畴」一路范畴化，其核心机器是几何 Satake 等价；本文说明这台机器如何反过来作用于经典算术朗兰兹，并由此解决若干算术几何问题（局部模型、同余关系、Tate 圈、Rankin–Selberg 动机的 BBK）。

## 五步逻辑链

1. **起点**（§1）：几何 Satake 把仿射 Grassmann 簇上的反常层范畴等同于对偶群分类叠上的凝聚层范畴——朗兰兹对偶群由此从「神秘的外部输入」变成可构造的对象。
2. **局部化到分歧情形**（§1.2）：把球 Hecke 换成 Iwahori Hecke 范畴，Bezrukavnikov 等价把「单值/驯顺分歧」的表示论翻译成 Steinberg 叠上的凝聚层。
3. **整体化**（§1.3）：猜想 $\Coh(\Loc_{\hat G})\cong D_c(\Bun_G)$，Hecke 算子被实现为「谱作用」几何算子。
4. **反向流动**（§2）：把这套语言搬到算术侧——$p$ 进局部域用 $B(G)$ 与 $\kot(G)$，函数域用 shtuka 叠，再把 Jacquet–Langlands 提升写成谱作用 $S=T$。
5. **收成算术**（§3）：局部模型给出整模型与同余关系，Tate 圈给出 mod $p$ 上同调的一般 Tate 类，最后用 GGP＋Taylor–Wiles 把 Selmer 群压到一维。

## 纪律与已知坑

- **先通读后落笔**：通读笔记与疑点清单先于译文（`work/通读笔记.md`、`work/疑点清单.tsv`，未解 0）。
- **译注必须有来源或「译者按」**：本工程用 `\zy{...}`，经 manyfoot 独立序列排成「译 $n$」，不占作者脚注计数器；原文 8 个作者脚注保原编号。
- **脚注标记只能是数字**：`\footnote[\text{译1}]` 必报 `Missing number`，故用 manyfoot（见 `preamble.tex` 注释）。
- **数学模式内中文必须 `\text{}`**；tikz-cd 标签同理，否则报 `Missing character ... lmroman8`。
- **原文笔误照译不擅改**：数学性笔误在译文中按上下文写对并在 `资料卡/04-术语文献勘误.md` 登记（如 `Tanniyama`、`hypersepcial`、定理 2.2.4 的 `{}^{cl}\Loc_{{}^cG,Q}`）；文字性笔误按正确拼写翻译并登记。
