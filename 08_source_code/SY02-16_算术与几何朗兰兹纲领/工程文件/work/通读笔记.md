# 通读笔记 · SY02-16《算术与几何朗兰兹纲领》

底本：Xinwen Zhu, *Arithmetic and Geometric Langlands Program*, ICM 2022，arXiv:2504.07502，26 页。
通读方式：读 arXiv 源码 `work/原文/ICM-arXiv.tex` 全篇（1558 行），对照 `work/pages/p001–p026.png` 核图与公式。

## 一、三句话主旨

1. 几何朗兰兹的真正成就，是把朗兰兹对偶群从「外部给定的神秘对象」变成几何 Satake 等价所构造出来的东西——这是全篇的立论基石。
2. 有了这台机器之后，箭头可以倒过来：把算术侧的对象（局部参数、shtuka、$p$ 进整模型）写成几何侧（分类叠、凝聚层、反常层），Hecke 作用就变成几何的谱作用。
3. 这一倒流不是类比游戏，它确实产出了算术结论：局部模型的存在性、志村簇上的同余关系、mod $p$ 上同调中一般 Tate 圈的单射与满射、以及 Rankin–Selberg 动机的 Beilinson–Bloch–Kato 情形。

### §1 从经典到几何（528–780 行）

- **§1.1 几何 Satake**：先给范畴化式 (1.1)，再用「卷积代数 → 卷积层」的类比 (1.2)–(1.6) 由粗到细地逼近。定理 1.1.2 解决几何输入（仿射 Grassmann 簇可写成完全射影子簇的归纳极限），定理 1.1.4 是主定理（$\Coh(\mathbb{B}\hat G_\Lambda)^\heartsuit\cong \Perv(\Gr_{G,\Lambda})$），注 1.1.5 的五点是作者对「为什么这个定理重要」的展开：概念性定义、$\Ga_k$ 作用、导出 Satake、族版本与融合积、D-模版本。
- **§1.2 驯顺分歧局部**：把球 Hecke 换成 Iwahori Hecke 范畴 $\Hk_{\mathbf G}$，定理 1.2.2 给出 Bezrukavnikov 等价 $\Coh(S^{\mathrm{un}}_{\hat G})\cong \Shv_c(\Hk_{\Iw})$；定理 1.2.4 把它「单值化」，注 1.2.6 说明这只是 2-范畴化的局部朗兰兹的一个特例——作者在此明确承认真正的 2-范畴纲领尚未成形。
- **§1.3 整体**：猜想 1.3.1 是标准形式 $\Coh(\Loc_{\hat G})\cong D_c(\Bun_G)$，难点在 $\Loc_{\hat G}$ 不是有限型叠、$D_c(\Bun_G)$ 不局部紧；作者列出 de Rham/Dolbeault/Betti 三版本与 AGKRRV 的幂零奇异支撑版本。

### §2 从几何到经典（782–1066 行）

- **§2.1 范畴算术局部**：先做几何（定理 2.1.1 说明局部参数叠 $\Loc^\square_{{}^cG}$ 在 $\bZ_\ell$ 上是平坦有限型的局部完全交——这是让「凝聚层」有意义的前提），再陈述猜想 2.1.3，然后用定理 2.1.2 的四条性质说明 $\Shv_c(\kot(G))$ 确实是「正确的」范畴。例 2.1.6、2.1.7 是全篇的枢纽：导出 Satake 与范畴迹 $S_V=\on{Nt}_! r^! \Sat(V)$ 把「Hecke 作用」变成可计算的几何算子。
- **§2.2 函数域整体**：把 §2.1 的构造整体化，得到定义在 $\bZ_\ell$ 上的导出概形 $\Loc^\square_{{}^cG,\bQ}$（定理 2.2.1），再用 shtuka 叠的谱作用（定理 2.2.4）证明 Genestier–Lafforgue 型结论，并陈述凝聚性猜想 2.2.3 与推论 2.2.5。
- **§2.3 几何 JL**：定义 2.3.1 引入 prime-to-$p$ 平凡化内形式（这是让两个群在 $p$ 处可比较的技术装置），猜想 2.3.2 把 Jacquet–Langlands 提升写成谱作用之间的同构，定理 2.3.3 给出 $S=T$ 的两个方向。

### §3 应用（1070–1321 行）

- **§3.1 局部模型**：定理 3.1.1（AGLR）给出局部模型的存在性（除 $p=2$ 奇酉、$p=3$ 三对偶），注 3.1.2 列出三条待办：整模型性质、Pappas–Rapoport 凝聚猜想、Haines–Kottwitz 猜想。
- **§3.2 同余关系**：定理 3.2.1 是 $\Fr_p=T_p+V_p$（Eichler–Shimura 的 $\bZ_\ell$ 版本），定理 3.2.2 把它推广到 plectic（多实二次）情形，出现 $\prod_i(\bZ^{f_i}\rtimes\mathfrak S_{f_i})$ 的作用。
- **§3.3 Tate 圈**：先用 Newton 映射与基本 Newton 层定位「圈从哪来」，再用定理 3.3.1 的三条给出单射（相交矩阵非退化）与满射（迹公式比较），最后用例 3.3.3 把相交矩阵算成显式的 Hecke 算子 (3.3)，并由此得到 Deligne–Lusztig 簇上的示性数公式 (3.4)。**注意**：这里的「一般」是精确的技术条件（$V_\mu$-一般 / 强 $V_\mu$-一般），不能译成「generic」的日常义。
- **§3.4 BBK**：先铺陈 BBK 猜想三个对象（Chow 群、$L$-函数、Selmer 群）与 Abel–Jacobi 映射，再陈述定理 3.4.1（椭圆曲线的 $\Sym$ 情形）与定理 3.4.2（一般 Rankin–Selberg 情形）。证明路线是 GGP（把解析非消没变成周期积分非零）→ 构造 $\Theta_m^p$ → Kolyvagin 型论证；构造 $\Theta_m^p$ 又回头用到 §3.3 的 (3.3)(3.4) 与 §2 的谱作用。**全篇的闭环在这里合上。**
