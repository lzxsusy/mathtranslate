## 编译

```bash
cd 源码
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

三遍的理由：第一遍生成 `.aux`/`.toc`，第二遍解析 `\ref`/`\eqref`/`\cite` 与目录，第三遍收敛书签与页码（本项目无索引，不需要 `makeindex`）。

## 常见坑

1. 数学模式里的中文必须包 `\text{}`；tikz-cd 标签里直接写中文会 `Missing character`。
2. tikz-cd 的 `"…"'` 把标签放在箭头下方，默认 `"…"` 才是上方。
3. 普通 tikz 无 `leftrightarrow` 键，用 `\draw[<->]`；⇒ 箭头用 `double, -{Implies}`。
4. `\footnote[\text{译1}]` 不可用（只接受数字），译注一律用 `\zy{}`。
5. 定理环境名只有 `thm/prop/lem/cor/conj/defn/example/remark` 等短名，**没有** `conjecture`、`theorem`。
