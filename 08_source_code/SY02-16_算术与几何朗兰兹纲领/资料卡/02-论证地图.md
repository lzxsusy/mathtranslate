# 02 · 论证地图

## 主链

**D1 范畴化**（(1.1)）：数 $\to$ 向量空间 $\to$ 范畴 $\to$ 2-范畴。整篇就是这条线的两次落地：先落到几何侧（§1），再倒回算术侧（§2）。

**D2 几何侧的三级火箭**（§1.1–§1.3）：
1. 空间：$\Gr_G=LG/L^+G$ 的几何（定理 1.1.2 给出可用的“代数化”）；
2. 范畴：$\Perv(\Gr_G)$ 上的卷积幺半结构 (1.5)；
3. 等价：$\Sat_G$（定理 1.1.4）——对有偶群 $\hat G$ 的“构造”，这是全篇立论的关键：对偶群不再是外部输入。
进一步：把球 Hecke 换成 Iwahori（§1.2），得到不依赖球结构的局部版本；整体化为猜想 1.3.1。

**D3 倒流的三个技术前提**（§2.1）：
- 前提一（定理 2.1.1）：$\Loc^\square_{{}^cG}$ 必须“够好”（有限型、局部完全交），否则 $\Coh$ 无从谈起；
- 前提二（定理 2.1.2）：$\Shv_c(\kot(G))$ 必须“够好”（四条性质），否则不能称其为 LL 的算术侧；
- 前提三（例 2.1.6、2.1.7）：Hecke 作用必须能写成几何算子（导出 Satake ＋ 范畴迹），否则无法计算。
三条齐备，才有猜想 2.1.3 的可陈述性。

**D4 整体与 JL**（§2.2、§2.3）：把 D3 的局部构件粘到函数域（shtuka 叠，定理 2.2.4），并把 Jacquet–Langlands 提升写成谱作用 $S=T$（定理 2.3.3）。前者给重数结论，后者给“提升＝换一个叠”的概念解释。

**D5 算术应用的两条腿**（§3）：
- 腿一（§3.1、§3.2）：局部模型 → 整模型 → 同余关系（$\Fr_p=T_p+V_p$）。这是“几何对象可算”的直接产物。
- 腿二（§3.3）：Newton 分层 + 圈类映射，把“Tate 类”化成相交数；相交数由 (3.3) 的 Hecke 算子给出——而 (3.3) 的推导正是 D3 前提三的应用（$\Hom_{\Coh(\Loc)}(\mO,\tilde V)\otimes\Hom(\tilde V,\mO)\to H^{\cl}$）。**这里是全篇最紧的一扣：算术的相交数被几何的 Hom 空间算出来。**

**D6 闭环**（§3.4）：BBK 需要 Selmer 群的界；GGP 把 $L$-值非零转成周期积分非零；周期积分用 §2 的谱语言解释为对角圈；$\Theta_m^p$ 的构造又用 §3.3 的 (3.3)(3.4) 与 Taylor–Wiles 拼接。于是 §1 的几何机器与 §3 的算术结论首尾相接。
