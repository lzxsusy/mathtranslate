# 根系  |  root system
concept: 欧氏空间中有限、张成、不含 0 且对反射封闭的向量集。
level: B
citation_zh: [来源：MathWorld 词条「Root System（根系）」，\url{https://mathworld.wolfram.com/RootSystem.html}（2026-11-14 访问）。]
citation_en: MathWorld, "Root System", https://mathworld.wolfram.com/RootSystem.html (accessed 2026-11-14).
verified: 2026-11-14 实抓该页（HTTP 200），正文列出根系的定义条件（有限、张成、不含 0、反射封闭、整性），并有原文："The Lie algebra roots of a finite-dimensional complex semisimple Lie algebra form a root system in a real subspace of the dual vector space to the Cartan subalgebra. In this case, the reflections generate the Weyl group..."。
note: 讲中 $\Phi(G,T)$ 为极大环面 $T$ 的根系，$\Phi^\vee$ 为余根系；正根选定后才有支配余权。
